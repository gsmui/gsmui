> See also: `05.20-marketplace.md` (marketplace engine), `06.50-marketplace.md` (listing/order
> records). This document specifies the *marketplace presentation* and does NOT re-document the
> commerce schema, payout, or vendor model — those live in 05/06.

# Purpose

This document defines the marketplace UI: the public listing, the product detail page, the cart,
and the checkout hand-off to the billing domain (`08.29`). It composes product cards, vendor
badges, rating displays, and a multi-step purchase modal wired to Livewire.

---

## 1. Page Composition

| Screen | GsmUi Components | Livewire |
| --- | --- | --- |
| Listing | `gsmui:card`, `gsmui:search`, `gsmui:tabs`, `gsmui:rating` | `Marketplace::list()` |
| Detail | `gsmui:image-gallery`, `gsmui:rating`, `gsmui:button` | `Product::show()` |
| Cart | `gsmui:table`, `gsmui:button` | `Cart::items()` |
| Checkout | `gsmui:modal` → hand-off | `Cart::checkout()` |

## 2. Component Tree

```text
gsmui:layouts.app (or marketing layout)
└── <marketplace>
    ├── gsmui:search (wire:model.live="q")
    ├── gsmui:tabs (category)
    └── gsmui:card × N
        ├── gsmui:image (self-hosted)
        ├── gsmui:heading, gsmui:badge (vendor)
        ├── gsmui:rating (read-only)
        └── gsmui:button (add to cart)

gsmui:modal (checkout)
└── <summary>  (gsmui:table of cart lines)
    └── gsmui:button (proceed → 08.29 billing)
```

## 3. Data Flow — Browse → Checkout

```text
gsmui:button "Add to cart"
        │  wire:click="add($id)"
        ▼
Cart::$items  ──▶  gsmui:table re-render (tabular-nums totals)

gsmui:button "Checkout"
        │  wire:click="checkout()"
        ▼
Cart::checkout()  ──▶  create draft order (06.53-orders)  ──▶  redirect 08.29
```

- Ratings render read-only via `gsmui:rating` (no input events); interactive rating is a separate
  component, not an `interactive` prop (per AGENTS.md "separate component" rule).
- Images self-hosted only (`img-src 'self' data:`). Icons via `gsmui:icon`.

## 4. CSP & Styling

- Cart totals use `tabular-nums` to avoid width shift during live updates.
- Invalid coupon input layered with `data-invalid:` classes over base styles.

### 9.2 Checkout Validation

```php
public function validateCheckout(): array
{
    return [
        'email' => 'required|email',
        'name' => 'required|string|max:255',
        'card' => 'required|card', // Laravel Cashier validation
    ];
}
```

### 9.3 Checkout Processing

```php
public function processPayment(): void
{
    $this->validate($this->validateCheckout());

    $order = Order::create([
        'user_id' => auth()->id(),
        'items' => $this->cart['items'],
        'total' => $this->cart['total'],
        'discount' => $this->cart['discount'],
        'coupon' => $this->cart['coupon'],
        'status' => 'pending',
    ]);

    $payment = $this->chargeOrder($order);

    if ($payment->succeeded) {
        $order->update(['status' => 'completed']);
        $this->unlockProducts($order);
        $this->clearCart();
        $this->dispatch('show-toast', ['message' => 'Payment successful']);
        $this->step = 3;
    } else {
        $order->update(['status' => 'failed']);
        $this->dispatch('show-toast', ['message' => 'Payment failed']);
    }
}
```

## 14. Marketplace Data Flow

### 14.1 Product Query

```php
public function products(): Collection
{
    return MarketplaceEngine::query()
        ->when($this->q, fn ($query) => $query->where('name', 'like', "%{$this->q}%"))
        ->when($this->category, fn ($query) => $query->where('category', $this->category))
        ->when($this->sort, fn ($query) => $query->orderBy($this->sort))
        ->get();
}
```

### 14.2 Cart Management

```php
public function addToCart(string $productId): void
{
    $product = MarketplaceEngine::find($productId);

    $this->cart['items'][] = [
        'product_id' => $product->id,
        'name' => $product->name,
        'price' => $product->price,
        'quantity' => 1,
        'vendor' => $product->vendor->name,
        'thumbnail' => $product->thumbnail,
        'type' => $product->category,
    ];

    $this->cart['total'] = collect($this->cart['items'])->sum('price');
    $this->dispatch('show-toast', ['message' => 'Added to cart']);
}
```

### 14.3 Checkout Processing

```php
public function checkout(): void
{
    $this->validate($this->validateCheckout());

    $order = Order::create([
        'user_id' => auth()->id(),
        'items' => $this->cart['items'],
        'total' => $this->cart['total'],
        'discount' => $this->cart['discount'],
        'coupon' => $this->cart['coupon'],
        'status' => 'pending',
    ]);

    $payment = $this->chargeOrder($order);

    if ($payment->succeeded) {
        $order->update(['status' => 'completed']);
        $this->unlockProducts($order);
        $this->clearCart();
        $this->dispatch('show-toast', ['message' => 'Payment successful']);
        $this->redirect()->route('orders.show', $order->id);
    } else {
        $order->update(['status' => 'failed']);
        $this->dispatch('show-toast', ['message' => 'Payment failed']);
    }
}
```

## 29. Marketplace Offline Support

### 29.1 Service Worker Caching

```javascript
// Cache product thumbnails
self.addEventListener('fetch', (event) => {
    if (event.request.url.includes('/images/products/')) {
        event.respondWith(
            caches.match(event.request).then((response) => {
                return response || fetch(event.request).then((response) => {
                    const clone = response.clone();
                    caches.put(event.request, clone);
                    return response;
                });
            })
        );
    }
});
```

```sql
CREATE TABLE marketplace_orders (
```

## 40. Marketplace Error Handling

### 40.1 Error States

| Error | Display | Action |
| --- | --- | --- |
| Product not found | "Product not found" | Redirect to marketplace |
| Cart empty | "Your cart is empty" | Browse marketplace |

| Coupon invalid | "Invalid coupon" | Clear coupon input |
| Review duplicate | "You've already reviewed" | Edit existing review |
| Vendor not found | "Vendor not found" | Redirect to marketplace |

### 40.2 Error Recovery

- Auto-retry failed operations (up to 3 times)
- Fallback to cached product data
- Offline mode with cached products
- Graceful degradation for missing features

### 40.3 Error Logging

- Log all client-side errors to Sentry
- Log Livewire errors to Laravel logs
- Track error rates per product
- Alert on error rate spikes

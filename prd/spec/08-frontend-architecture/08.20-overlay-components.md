# Purpose

Overlay components — modals, popovers, tooltips, drawers, and dialogs — float above the app shell. They share one dialog/popover visual contract (verbatim from `AGENTS.md`), a focus trap, scroll-lock, and the native `popover` API where appropriate. All are CSP-safe and token-themed.

---

## 1. Shared Dialog Surface (verbatim from AGENTS.md)

Every popover/dialog panel uses this exact class string (copy from date-picker):

```blade
class="max-sm:max-h-full! rounded-xl shadow-xl sm:shadow-2xs
       max-sm:fixed! max-sm:inset-0! sm:backdrop:bg-transparent
       bg-white dark:bg-zinc-700 sm:border border-zinc-200 dark:border-white/10 p-3"
```

Rules:
- On `sm+` it is a bordered floating panel; on `<sm` it becomes a full-screen fixed sheet (`max-sm:inset-0!`).
- Surface is `bg-white dark:bg-zinc-700` — keep AA contrast against enclosed text (`08.16`).
- Never restyle the surface per-component; compose content inside it.

## 2. Scroll Lock (verbatim from AGENTS.md)

When a popover/modal is open, **lock body scroll** using the date-picker pattern: add `overflow-hidden` (or a `data-scroll-locked` class) to `<body>` on open and remove it on close. This prevents background scroll-through on touch.

## 3. `gsmui:modal`

`stubs/resources/views/gsmui/modal/index.blade.php`:

| Prop | Values | Default |
| --- | --- | --- |
| `flyout` / `variant` | `flyout` (drawer) \| `floating` \| `bare` | — |
| `position` | `right`\|`left`\|`bottom` | `right` |
| `scroll` | `body` (locks body scroll) | — |
| `dismissible` | bool (backdrop click closes) | `true` |
| `closable` | bool (close button) | `true` |

- Backdrop `fixed inset-0 z-50` + `bg-black/50 dark:bg-black/70`.
- Panel `role="dialog" aria-modal="true"`; flyout slides via `translate-x-full` transition (`08.15`).
- `Escape` closes (`@keydown.escape.window`); focus moves to panel on open, restores to trigger on close (`08.16`).

```blade
<gsmui:modal name="confirm-delete">
    <p>{{ __('Delete this item?') }}</p>
    <x-slot:footer>
        <gsmui:button variant="danger">{{ __('Delete') }}</gsmui:button>
    </x-slot:footer>
</gsmui:modal>
```

## 4. `gsmui:popover`

`stubs/resources/views/gsmui/popover/index.blade.php`:

- Uses the native `popover="manual"` attribute + `data-gsmui-popover` + `tabindex="-1"`.
- Visibility is toggled via `data-open`; hidden state uses `not-data-open:hidden` (fixes popover/display conflict).
- Panel applies the shared dialog surface (§1). Trigger is a native `<button aria-haspopup="dialog">`.
- Use `gsmui:popover` for menus, color pickers, date pickers (composes `ui-slider`), etc.

## 5. `gsmui:tooltip`

`stubs/resources/views/gsmui/tooltip/index.blade.php`:

| Prop | Values | Default |
| --- | --- | --- |
| `content` / `position` | `top`\|`right`\|`bottom`\|`left` | `top` |
| `align` | `start`\|`center`\|`end` | `center` |
| `interactive` | bool (`role="tooltip"`, focusable) | `false` |
| `kbd` | string (hint) | — |

- Non-interactive tooltips are `pointer-events-none`; shown on hover/focus (`@mouseenter`/`@focusin`).
- Positioned absolutely with `z-50`; uses `x-transition` opacity (`08.15`).
- Decorative by default; if it conveys info, give `interactive` + `role="tooltip"` + `id` linked from the trigger `aria-describedby`.

## 6. Drawers

Drawers are `gsmui:modal variant="flyout"` (or `gsmui:sidebar type="drawer"` for nav, `08.13`). They slide from an edge, lock scroll, and trap focus like modals. Use for filters, command palette surfaces, and mobile nav.

## 7. Accessibility Contract

- `role="dialog" aria-modal="true"` for modals; `popover` + `aria-haspopup` for popovers.
- Focus trap + restore; `Escape` to close; backdrop click dismisses only when `dismissible`.
- Tooltips: hover + focus parity; never keyboard-inaccessible.
- All overlays respect `prefers-reduced-motion` (transitions collapse, `08.15`).

#### 8.2.4 Popover Positioning

```javascript
function positionPopover(trigger, popover, placement = 'bottom', offset = 8) {
  const triggerRect = trigger.getBoundingClientRect()
  const popoverRect = popover.getBoundingClientRect()

  let top, left

  switch (placement) {
    case 'top':
      top = triggerRect.top - popoverRect.height - offset
      left = triggerRect.left + (triggerRect.width - popoverRect.width) / 2
      break
    case 'bottom':
      top = triggerRect.bottom + offset
      left = triggerRect.left + (triggerRect.width - popoverRect.width) / 2
      break
    case 'left':
      top = triggerRect.top + (triggerRect.height - popoverRect.height) / 2
      left = triggerRect.left - popoverRect.width - offset
      break
    case 'right':
      top = triggerRect.top + (triggerRect.height - popoverRect.height) / 2
      left = triggerRect.right + offset
      break
  }

  // Keep within viewport
  top = Math.max(8, Math.min(top, window.innerHeight - popoverRect.height - 8))
  left = Math.max(8, Math.min(left, window.innerWidth - popoverRect.width - 8))

  return { top, left }
}
```

## 9. Focus Management

### 9.1 Focus Trap

```javascript
function trapFocus(element) {
  const focusableElements = element.querySelectorAll(
    'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
  )
  const firstFocusable = focusableElements[0]
  const lastFocusable = focusableElements[focusableElements.length - 1]

  element.addEventListener('keydown', (e) => {
    if (e.key !== 'Tab') return

    if (e.shiftKey) {
      if (document.activeElement === firstFocusable) {
        lastFocusable.focus()
        e.preventDefault()
      }
    } else {
      if (document.activeElement === lastFocusable) {
        firstFocusable.focus()
        e.preventDefault()
      }
    }
  })

  firstFocusable.focus()
}
```

### 9.2 Focus Restore

```javascript
function openModal(name) {
  const trigger = document.activeElement
  const modal = document.querySelector(`[data-gsmui-modal="${name}"]`)

  // Show modal
  modal.classList.remove('hidden')

  // Trap focus
  trapFocus(modal)

  // Store trigger for restore
  modal._trigger = trigger
}

function closeModal(name) {
  const modal = document.querySelector(`[data-gsmui-modal="${name}"]`)

  // Hide modal
  modal.classList.add('hidden')

  // Restore focus
  modal._trigger?.focus()
}
```

### 9.3 Escape Key Handling

```javascript
document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') {
    const openModal = document.querySelector('[data-gsmui-modal]:not(.hidden)')
    if (openModal && openModal._dismissible) {
      closeModal(openModal.dataset.gsmuiModal)
    }
  }
})
```

## 10. Scroll Lock

### 10.1 Scroll Lock Manager

```javascript
class ScrollLockManager {
  constructor() {
    this.locked = false
    this.scrollY = 0
  }

  lock() {
    if (this.locked) return
    this.scrollY = window.scrollY
    document.body.style.overflow = 'hidden'
    document.body.style.position = 'fixed'
    document.body.style.top = `-${this.scrollY}px`
    document.body.style.width = '100%'
    this.locked = true
  }

  unlock() {
    if (!this.locked) return
    document.body.style.overflow = ''
    document.body.style.position = ''
    document.body.style.top = ''
    document.body.style.width = ''
    window.scrollTo(0, this.scrollY)
    this.locked = false
  }
}

const scrollLock = new ScrollLockManager()
```

### 10.2 Nested Overlay Handling

```javascript
let openOverlays = 0

function lockScroll() {
  openOverlays++
  if (openOverlays === 1) {
    scrollLock.lock()
  }
}

function unlockScroll() {
  openOverlays--
  if (openOverlays === 0) {
    scrollLock.unlock()
  }
}
```

## 13. Accessibility Deep-Dive

### 13.1 Modal Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Role | `role="dialog"` |
| Modal | `aria-modal="true"` |
| Label | `aria-labelledby` pointing to title |
| Description | `aria-describedby` for content |
| Close | `aria-label="Close"` on close button |
| Focus trap | Tab cycles within modal |
| Escape | Closes modal |
| Focus restore | Returns to trigger |

### 13.2 Popover Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Trigger | `aria-haspopup="dialog"` |
| Expanded | `aria-expanded="true/false"` |
| Panel | `role="dialog"` if interactive |
| Close | Escape closes popover |
| Focus | Focus moves to panel on open |

### 13.3 Tooltip Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Role | `role="tooltip"` for interactive |
| Label | `aria-describedby` from trigger |
| Hover | Show on hover AND focus |
| Delay | 300ms show, 100ms hide |
| Interactive | Focusable content |

### 13.4 Drawer Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Role | `role="dialog"` |
| Modal | `aria-modal="true"` |
| Label | `aria-labelledby` |
| Focus trap | Tab cycles within drawer |
| Escape | Closes drawer |
| Scroll lock | Body scroll disabled |

## 18. State Management for Overlays

### 18.1 Modal State

```php
class ModalManager extends Component
{
    public array $openModals = [];

    public function open(string $name): void
    {
        if (!in_array($name, $this->openModals)) {
            $this->openModals[] = $name;
        }
        $this->dispatch('modal:open', name: $name);
    }

    public function close(string $name): void
    {
        $this->openModals = array_filter($this->openModals, fn ($m) => $m !== $name);
        $this->dispatch('modal:close', name: $name);
    }

    public function closeAll(): void
    {
        $this->openModals = [];
        $this->dispatch('modal:closeAll');
    }

    public function isOpen(string $name): bool
    {
        return in_array($name, $this->openModals);
    }
}
```

### 18.2 Popover State

```php
class PopoverManager extends Component
{
    public ?string $openPopover = null;

    public function toggle(string $name): void
    {
        $this->openPopover = $this->openPopover === $name ? null : $name;
    }

    public function open(string $name): void
    {
        $this->openPopover = $name;
    }

    public function close(): void
    {
        $this->openPopover = null;
    }

    public function isOpen(string $name): bool
    {
        return $this->openPopover === $name;
    }
}
```

# Appendix: Overlay Component Compliance Index

## Behavioral Contract Summary

Every overlay component must declare and honor its stacking behavior, focus management, and dismissal rules. The table below is the canonical reference used by the compliance test suite.

| Overlay Type | Trigger | Focus Trap | Esc Closes | Backdrop | Stack Limit |
|---|---|---|---|---|---|
| Dropdown Menu | Button click | Yes | Yes | Transparent | 3 |
| Context Menu | Right click | Yes | Yes | Transparent | 2 |
| Modal Dialog | Button click | Yes | Configurable | Opaque | 1 |
| Popover | Click/Hover | No | Yes | Transparent | 5 |
| Tooltip | Hover/Focus | No | N/A | None | Unlimited |
| Toast | Programmatic | No | No | None | 5 |
| Drawer | Button click | Yes | Yes | Opaque | 1 |
| Command Palette | Keyboard shortcut | Yes | Yes | Opaque | 1 |

## Required Documentation Fields

Each overlay component's documentation page must declare:

1. **Trigger contract** - which events open and close the overlay.
2. **Focus lifecycle** - where focus moves on open, on close, and on nested dismissal.
3. **Dismissal matrix** - Escape, outside click, backdrop click, and programmatic close.
4. **Stacking rule** - maximum simultaneous instances and nesting policy.
5. **Accessibility mapping** - ARIA role, `aria-modal`, labelling strategy, and live-region usage.
6. **Reduced-motion behavior** - how enter/exit transitions degrade under `prefers-reduced-motion`.

## Compliance Gates

An overlay component may only be promoted to stable status after:

- The behavioral contract table passes automated assertions.
- The focus-trap audit reports zero leaks across keyboard-only navigation.
- The screen-reader narration test passes for all documented states.
- The stacking test verifies correct z-index ordering under maximum nesting.
- The reduced-motion test confirms no transition is required for comprehension.

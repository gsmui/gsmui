# Purpose

This document defines how the top-level GsmUi admin/platform dashboard is composed from GsmUi
Blade components, how each region binds to its Livewire component, and how data flows back to the
server. It covers the shell (sidebar + navbar), the KPI grid, the chart region, and the
recent-activity table, all wired through `wire:model` and server-pushed updates.

---

## 1. Page Composition

The dashboard is a single-page Livewire host (`Dashboard` Livewire component) with a persistent
shell and a swappable content region. Layout uses `gsmui:layouts.app` with `gsmui:sidebar` and
`gsmui:navbar`.

| Region | GsmUi Component | Livewire Binding | Notes |
| --- | --- | --- | --- |
| App shell | `gsmui:layouts.app` | host | Resolves `--gsmui-sidebar-width` |
| Navigation | `gsmui:sidebar` + `gsmui:navlist` | `Dashboard` | `gsmui:navlist` items from `navItems()` |
| Top bar | `gsmui:navbar` + `gsmui:search` | `Dashboard` | `gsmui:command` trigger on `⌘K` |
| KPI row | `gsmui:stat` × N | `wire:model="range"` | `tabular-nums` display |
| Charts | `gsmui:chart` | `$range` property | adapter via `Chart.js` |
| Activity | `gsmui:table` | `WithPagination` | `gsmui:pagination` footer |

## 2. Component Tree

```text
gsmui:layouts.app
├── gsmui:sidebar
│   ├── gsmui:brand
│   └── gsmui:navlist (items => Dashboard::navItems())
├── gsmui:navbar
│   ├── gsmui:search (wire:model="query")
│   └── gsmui:command (kbd ⌘K)
└── <content>
    ├── gsmui:stat (value, label, trend)  × 4
    ├── gsmui:chart (type, :series="$series", adapter)
    └── gsmui:table (:rows="$activity")
        └── gsmui:pagination
```

## 3. Data Flow to Livewire

```text
user picks range  ── wire:model="range" ──▶  Dashboard::$range
                                               │
                                               ▼
                                        Dashboard::updatedRange()
                                               │  (recompute aggregates)
                                               ▼
                                   $series / $stat / $activity  ──▶  browser
                                               │
                                               ▼
                                   <g-gsmui-chart> MutationObserver
                                   re-reads value attr => re-render
```

- The `gsmui:chart` web component reacts to `value` attribute changes via `MutationObserver`
  (per AGENTS.md JS conventions) — no manual re-init needed.
- Range `<input type="range">`-style controls fire both `input` and `change` events to match
  native behaviour.
- ARIA labels are set from Blade via `__()` (e.g. `__('Revenue trend')`).

## 4. State & Invalid Handling

- Disabled custom elements use `[&[disabled]]:shadow-none!` attribute selectors, not `:disabled`.
- Invalid fetch states layered with `data-invalid:` classes over base styles (never ternary-swap).
- Client reverts to last-good value silently on backend validation failure (no shake animation).

## 9. Dashboard Data Flow

### 9.1 Livewire Component

```php
class Dashboard extends Component
{
    public string $range = '7d';
    public string $query = '';
    public bool $statsLoading = true;
    public bool $chartLoading = true;

    public function mount(): void
    {
        $this->loadData();
    }

    private function loadData(): void
    {
        $this->statsLoading = true;
        $this->chartLoading = true;

        // Parallel data loading
        $this->stats = $this->computeStats();
        $this->chartData = $this->computeChartData();
        $this->activity = $this->getActivity();

        $this->statsLoading = false;
        $this->chartLoading = false;
    }

    public function updatedRange(): void
    {
        $this->loadData();
    }

    public function refreshStats(): void
    {
        $this->stats = $this->computeStats();
    }

    public function refreshChart(): void
    {
        $this->chartData = $this->computeChartData();
    }
}
```

### 9.2 Data Computation

```php
private function computeStats(): array
{
    $period = $this->getPeriodRange();

    return [
        'total_users' => User::count(),
        'users_change' => User::where('created_at', '>=', $period['previous'])->count(),
        'revenue' => Order::where('created_at', '>=', $period['current'])->sum('total'),
        'revenue_change' => $this->calculateChange(
            Order::where('created_at', '>=', $period['previous'])->sum('total'),
            Order::where('created_at', '>=', $period['before'])->sum('total')
        ),
        'orders' => Order::where('created_at', '>=', $period['current'])->count(),
        'orders_change' => $this->calculateChange(
            Order::where('created_at', '>=', $period['current'])->count(),
            Order::where('created_at', '>=', $period['previous'])->count()
        ),
        'conversion' => $this->calculateConversion($period['current']),
        'conversion_change' => $this->calculateConversionChange($period),
    ];
}

private function computeChartData(): array
{
    $period = $this->getPeriodRange();

    return [
        'labels' => $this->generateDateLabels($period['current']),
        'datasets' => [
            [
                'label' => __('Revenue'),
                'data' => $this->getRevenueByDate($period['current']),
                'borderColor' => 'rgb(59, 130, 246)',
                'backgroundColor' => 'rgba(59, 130, 246, 0.1)',
                'fill' => true,
            ],
        ],
    ];
}
```

```php
// Widget.php
class Widget
{
    public string $id;
    public string $type;
    public int $colspan = 1;
    public array $config = [];
    public bool $refreshable = true;
    public int $refreshInterval = 60; // seconds

    public static function fromArray(array $data): self
    {
        return new self(
            id: $data['id'],
            type: $data['type'],
            colspan: $data['colspan'] ?? 1,
            config: $data['config'] ?? [],
            refreshable: $data['refreshable'] ?? true,
            refreshInterval: $data['refreshInterval'] ?? 60,
        );
    }
}
```

### 18.2 Export Logic

```php
public function export(string $format): void
{
    $data = $this->getExportData();

    match ($format) {
        'csv' => $this->exportCsv($data),
        'xlsx' => $this->exportExcel($data),
        'pdf' => $this->exportPdf($data),
    };
}

private function exportCsv(array $data): void
{
    $headers = ['Date', 'Users', 'Revenue', 'Orders'];
    $rows = collect($data)->map(fn ($row) => [
        $row['date'], $row['users'], $row['revenue'], $row['orders']
    ]);

    $csv = collect($headers)->concat($rows)->map(fn ($row) => implode(',', $row))->implode("\n");

    response()->csv($csv, [
        'Content-Disposition' => 'attachment; filename="dashboard-export.csv"',
    ]);
}
```

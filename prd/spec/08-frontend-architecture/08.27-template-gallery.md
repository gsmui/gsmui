# 08.27 - Template Gallery

**Project:** GsmUi
**Section:** 08 - Frontend Architecture
**Framework:** Laravel 13 · Livewire 4 · Blade Components · GsmUi Component Library · Tailwind CSS v4 · Vite
**Version:** 1.0.0

---

> See also: `05.29-template-engine.md` (template engine), `06.40-templates.md` (template records).
> This document specifies the *template gallery presentation* and does NOT re-document the template
> schema or rendering pipeline — those live in 05/06.

# Purpose

This document defines the template gallery: a filterable grid of starter templates, each with a
live thumbnail/preview, metadata (author, tags, price), and an "Apply" flow that scaffolds the
template into a project via the template engine. It reuses the showcase card pattern (`08.26`).

---

## 1. Page Composition

| Region | GsmUi Components | Livewire |
| --- | --- | --- |
| Filters | `gsmui:search`, `gsmui:tabs` (category), `gsmui:select` (sort) | `wire:model.live` |
| Grid | `gsmui:card` (thumbnail + meta) | `Gallery::templates()` |
| Preview | `gsmui:modal` + `gsmui:frame` | `preview($id)` |
| Apply | `gsmui:button`, `gsmui:modal` (confirm) | `apply($id)` |

## 2. Component Tree

```text
gsmui:layouts.app
└── <gallery>
    ├── gsmui:search (wire:model.live="q")
    ├── gsmui:tabs (wire:model="category")
    └── gsmui:card × N
        ├── gsmui:image (thumbnail — inline/self-hosted)
        ├── gsmui:heading (title)
        ├── gsmui:badge (tags)
        └── gsmui:button (preview / apply)

gsmui:modal (preview)
└── gsmui:frame → rendered template (05.29)
```

## 3. Data Flow — Browse → Apply

```text
gsmui:search wire:model.live="q"
        │
        ▼
Gallery::$q  ──▶  TemplateEngine query (05.29)
        │
        ▼
$templates  ──▶  gsmui:card grid

gsmui:button "Apply"
        │  wire:click="apply($id)"
        ▼
Gallery::apply()  ──▶  scaffold via engine  ──▶  gsmui:toast ("Template applied")
```

- Thumbnails are self-hosted images only (`img-src 'self' data:`); no external image CDNs.
- Preview `gsmui:frame` uses `adoptedStyleSheets` for injected template CSS (CSP-safe).
- Modal scroll-lock mirrors the date-picker pattern (`max-sm:fixed! max-sm:inset-0!`).

## 4. Styling & State

- `gsmui:card` hover/focus uses native outline on focusable elements; no `focus:ring` custom rings.
- Disabled "Apply" (already-owned template) uses `[&[disabled]]:shadow-none!`.

## 9. Template Data Flow

### 9.1 Template Query

```php
public function templates(): Collection
{
    return TemplateEngine::query()
        ->when($this->q, fn ($query) => $query->where('name', 'like', "%{$this->q}%"))
        ->when($this->category, fn ($query) => $query->where('category', $this->category))
        ->when($this->sort, fn ($query) => $query->orderBy($this->sort))
        ->get();
}
```

### 9.2 Template Rendering

```php
public function preview(string $id): void
{
    $template = TemplateEngine::find($id);
    $this->previewTemplate = $template;
    $this->previewOpen = true;
    $this->dispatch('preview-opened', ['id' => $id]);
}
```

### 9.3 Template Application

```php
public function apply(string $id): void
{
    $template = TemplateEngine::find($id);
    $project = Project::find($this->projectId);

    $this->validate([
        'projectId' => 'required|exists:projects,id',
    ]);

    $this->applyProgress = 0;
    $this->applyStatus = 'Downloading template...';

    TemplateEngine::apply($template, $project, [
        'includeContent' => $this->includeContent,
        'includeAssets' => $this->includeAssets,
        'includeStyles' => $this->includeStyles,
        'overwriteExisting' => $this->overwriteExisting,
        'createBackup' => $this->createBackup,
    ]);

    $this->applyProgress = 100;
    $this->applyStatus = 'Template applied successfully';
    $this->dispatch('show-toast', ['message' => 'Template applied successfully']);
    $this->redirect()->route('project.show', $project->id);
}
```

## 16. Template Thumbnail System

### 16.1 Thumbnail Generation

Thumbnails are automatically generated from template screenshots:

```php
public function generateThumbnail(string $templateId): string
{
    $screenshot = Storage::disk('templates')->get("{$templateId}/screenshot.png");
    $thumbnail = Image::make($screenshot)
        ->resize(400, 300, function ($constraint) {
            $constraint->aspectRatio();
            $constraint->upsize();
        })
        ->encode('jpg', 85);

    Storage::disk('templates')->put("{$templateId}/thumbnail.jpg", $thumbnail);
    return "/templates/{$templateId}/thumbnail.jpg";
}
```

### 16.2 Thumbnail Sizes

| Size | Dimensions | Usage |
| --- | --- | --- |
| xs | 100x75 | List view, search results |
| sm | 200x150 | Card view, mobile |
| md | 400x300 | Card view, desktop |
| lg | 800x600 | Preview modal |
| xl | 1200x900 | Full preview |

### 16.3 Thumbnail Optimization

- Lazy loading for off-screen thumbnails
- WebP format with JPEG fallback
- Responsive images with `srcset`
- Blur-up placeholder effect
- CDN caching (1 day)

### 16.4 Thumbnail Accessibility

- Alt text: "Template name preview"
- Decorative images: `alt=""`
- Lazy loading: `loading="lazy"`

The apply process:

1. Download template files from storage
2. Extract archive to temp directory
3. Validate template structure
4. Run dependency checks
5. Create backup (if enabled)
6. Copy files to project
7. Update configuration files
8. Run migrations (if any)
9. Clear cache
10. Verify installation

### 18.2 Apply Progress Tracking

```php
public function apply(string $id): void
{
    $steps = [
        'Downloading template...',
        'Extracting files...',
        'Validating structure...',
        'Checking dependencies...',
        'Creating backup...',
        'Copying files...',
        'Updating configuration...',
        'Running migrations...',
        'Clearing cache...',
        'Verifying installation...',
    ];

    foreach ($steps as $index => $step) {
        $this->applyProgress = (($index + 1) / count($steps)) * 100;
        $this->applyStatus = $step;
        $this->dispatch('apply-progress', [
            'progress' => $this->applyProgress,
            'status' => $this->applyStatus,
        ]);
        // Perform step...
    }
}
```

### 18.3 Apply Rollback

If apply fails:

1. Stop at failed step
2. Rollback all changes
3. Restore from backup
4. Show error message
5. Log failure details

### 18.4 Apply Validation

```php
public function validateTemplate(string $templateId): array
{
    $errors = [];

    // Check Laravel version
    if (version_compare(app()->version(), $template->laravelVersion, '<')) {
        $errors[] = "Requires Laravel {$template->laravelVersion}";
    }

    // Check PHP version
    if (version_compare(PHP_VERSION, $template->phpVersion, '<')) {
        $errors[] = "Requires PHP {$template->phpVersion}";
    }

    // Check dependencies
    foreach ($template->dependencies as $package => $version) {
        if (!installed($package)) {
            $errors[] = "Missing dependency: {$package}";
        }
    }

    return $errors;
}
```

### 31.2 Favorites State Management

```php
public function toggleFavorite(string $templateId): void
{
    $userId = auth()->id();
    $exists = DB::table('user_template_favorites')
        ->where('user_id', $userId)
        ->where('template_id', $templateId)
        ->exists();

    if ($exists) {
        DB::table('user_template_favorites')
            ->where('user_id', $userId)
            ->where('template_id', $templateId)
            ->delete();
        $this->dispatch('show-toast', ['message' => 'Removed from favorites']);
    } else {
        DB::table('user_template_favorites')->insert([
            'user_id' => $userId,
            'template_id' => $templateId,
        ]);
        $this->dispatch('show-toast', ['message' => 'Added to favorites']);
    }

    $this->loadFavorites();
}
```

// Cache template thumbnails
self.addEventListener('fetch', (event) => {
    if (event.request.url.includes('/images/templates/')) {
        event.respondWith(
            caches.match(event.request).then((response) => {

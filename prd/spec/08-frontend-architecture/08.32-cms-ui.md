# 08.32 - CMS UI

**Project:** GsmUi
**Section:** 08 - Frontend Architecture
**Framework:** Laravel 13 · Livewire 4 · Blade Components · GsmUi Component Library · Tailwind CSS v4 · Vite · Monaco Editor (optional for raw blocks)
**Version:** 1.0.0

---

> See also: `05.26-cms-architecture.md` (CMS architecture), `06.91-cms.md` (content/collection
> records). This document specifies the *CMS authoring presentation* and does NOT re-document the
> content-model schema or delivery API — those live in 05/06.

# Purpose

This document defines the CMS UI: the collection/list view, the entry editor (structured fields +
rich text via `gsmui:editor`), the media library, and the publish/revision flow. It is the
authoring surface that produces the content consumed by the blog (`08.31`) and pages.

---

## 1. Page Composition

| Screen | GsmUi Components | Livewire |
| --- | --- | --- |
| Collections | `gsmui:navlist`, `gsmui:table` | `Cms::collections()` |
| Entry editor | `gsmui:field` + inputs, `gsmui:editor` | `Entry::edit()` |
| Media | `gsmui:image-gallery`, `gsmui:file-upload` | `Media::library()` |
| Publish | `gsmui:modal` (confirm), `gsmui:button` | `Entry::publish()` |

## 2. Component Tree

```text
gsmui:layouts.app (cms shell)
├── gsmui:navlist (collections)
└── <content>
    ├── gsmui:table (:rows="$entries") + gsmui:pagination
    └── gsmui:modal (entry editor)
        └── <form wire:submit="save">
            ├── gsmui:field → gsmui:input / gsmui:textarea / gsmui:select
            ├── gsmui:editor (rich text, bundled editor.js + editor.css)
            └── gsmui:button (publish) / gsmui:button as="div" (cancel)
```

## 3. Data Flow — Author → Publish

```text
gsmui:editor wire:model="entry.body"
        │  input + change events (native parity)
        ▼
Entry::$entry  ──▶  validate content model (05.26)
        │
        ▼
<form wire:submit="publish">
        │
        ▼
Entry::publish()  ──▶  CmsEngine persist (06.91)  ──▶  gsmui:toast
```

- `gsmui:editor` ships as `dist/editor.js` + `dist/editor.css` — bundled, no CDN (CSP-safe).
- Interaction logic uses `setAttribute`/`removeAttribute` from `utils.js` (MutationObserver-aware).
- Media upload uses `gsmui:file-upload` (self-hosted storage; `connect-src 'self'`).

## 4. CSP & Styling

- Editor CSS injected via `adoptedStyleSheets`; no external fonts.
- Invalid field layered with `data-invalid:`; disabled entry uses `[&[disabled]]:shadow-none!`.
- ARIA labels via `__()` (e.g. `__('Entry title')`).

### 5.1 `CmsCollections` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;
use Livewire\Attributes\Layout;
use Livewire\WithPagination;
use Livewire\Attributes\Url;
use App\Models\CmsCollection;

#[Layout('gsmui::layouts.app')]
class CmsCollections extends Component
{
    use WithPagination;

    #[Url(as: 'collection')]
    public ?string $activeCollection = null;

    public string $search = '';
    public string $sortBy = 'updated_at';
    public string $sortDirection = 'desc';
    public bool $showCreateModal = false;

    public string $newCollectionName = '';
    public string $newCollectionSlug = '';
    public string $newCollectionDescription = '';

    protected array $listeners = [
        'collectionCreated' => '$refresh',
        'collectionDeleted' => '$refresh',
    ];

    protected array $rules = [
        'newCollectionName' => 'required|string|min:2|max:255',
        'newCollectionSlug' => 'nullable|string|max:255',
        'newCollectionDescription' => 'nullable|string|max:500',
    ];

    public function getCollectionsProperty()
    {
        $query = CmsCollection::query()->withCount(['entries', 'publishedEntries']);

        if (filled($this->search)) {
            $query->where(function ($q) {
                $q->where('name', 'LIKE', "%{$this->search}%")
                  ->orWhere('slug', 'LIKE', "%{$this->search}%");
            });
        }

        return $query->orderBy($this->sortBy, $this->sortDirection)
                     ->paginate(20);
    }

    public function selectCollection(string $slug): void
    {
        $this->activeCollection = $slug;
    }

    public function createCollection(): void
    {
        $this->validate();

        $slug = $this->newCollectionSlug ?: str($this->newCollectionName)->slug()->toString();

        CmsCollection::create([
            'name' => $this->newCollectionName,
            'slug' => $slug,
            'description' => $this->newCollectionDescription,
            'created_by' => auth()->id(),
        ]);

        $this->showCreateModal = false;
        $this->reset(['newCollectionName', 'newCollectionSlug', 'newCollectionDescription']);
        $this->dispatch('toast', message: __('Collection created.'));
    }

    public function deleteCollection(int $collectionId): void
    {
        $collection = CmsCollection::findOrFail($collectionId);

        if ($collection->entries()->count() > 0) {
            $this->dispatch('toast', type: 'error', message: __('Cannot delete a collection with entries.'));
            return;
        }

        $collection->delete();
        $this->activeCollection = null;
        $this->dispatch('toast', message: __('Collection deleted.'));
    }

    public function render()
    {
        return view('cms.collections', [
            'collections' => $this->collections,
        ]);
    }
}
```

### 5.2 `CmsEntryEditor` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;
use Livewire\Attributes\Layout;
use Livewire\WithFileUploads;
use Livewire\Attributes\On;
use App\Models\CmsEntry;
use App\Models\CmsCollection;
use Illuminate\Support\Str;

#[Layout('gsmui::layouts.app')]
class CmsEntryEditor extends Component
{
    use WithFileUploads;

    public int $entryId = 0;
    public string $collectionSlug = '';
    public ?CmsEntry $entry = null;
    public ?CmsCollection $collection = null;

    public string $title = '';
    public string $slug = '';
    public string $body = '';
    public string $excerpt = '';
    public string $status = 'draft';
    public ?string $featuredImage = null;
    public array $customFields = [];
    public array $tags = [];
    public ?string $authorId = null;
    public ?string $scheduledAt = null;

    public bool $isDirty = false;
    public bool $isSaving = false;
    public bool $autoSaveEnabled = true;
    public ?string $lastSavedAt = null;
    public bool $showPublishModal = false;
    public bool $showPreview = false;
    public string $previewDevice = 'desktop';
    public string $publishTiming = 'now';

    protected array $listeners = [
        'bodyUpdated' => 'onBodyUpdated',
        'fieldUpdated' => 'onFieldUpdated',
        'confirmPublish' => 'publish',
        'confirmUnpublish' => 'unpublish',
    ];

    protected array $rules = [
        'title' => 'required|string|min:1|max:500',
        'slug' => 'nullable|string|max:255',
        'excerpt' => 'nullable|string|max:1000',
        'body' => 'required|string|max:100000',
        'status' => 'in:draft,published,archived',
    ];

    public function mount(int $entryId = 0, string $collectionSlug = ''): void
    {
        $this->collectionSlug = $collectionSlug;
        $this->collection = CmsCollection::where('slug', $collectionSlug)->firstOrFail();

        if ($entryId > 0) {
            $this->entryId = $entryId;
            $this->loadEntry();
        } else {
            $this->authorId = auth()->id();
        }
    }

    private function loadEntry(): void
    {
        $this->entry = CmsEntry::findOrFail($this->entryId);
        $this->title = $this->entry->title;
        $this->slug = $this->entry->slug;
        $this->body = $this->entry->body;
        $this->excerpt = $this->entry->excerpt ?? '';
        $this->status = $this->entry->status;
        $this->featuredImage = $this->entry->featured_image;
        $this->customFields = $this->entry->custom_fields ?? [];
        $this->tags = $this->entry->tags ?? [];
        $this->authorId = $this->entry->author_id;
        $this->lastSavedAt = $this->entry->updated_at->diffForHumans();
    }

    public function updatedTitle(string $value): void
    {
        if (empty($this->slug) || Str::slug($this->slug) === $this->slug) {
            $this->slug = Str::slug($value);
        }
        $this->markDirty();
    }

    public function updatedSlug(string $value): void
    {
        $this->slug = Str::slug($value);
        $this->markDirty();
    }

    public function onBodyUpdated(string $body): void
    {
        $this->body = $body;
        $this->markDirty();
    }

    public function onFieldUpdated(array $payload): void
    {
        $key = $payload['key'] ?? '';
        $value = $payload['value'] ?? '';

        if (array_key_exists($key, $this->customFields)) {
            $this->customFields[$key] = $value;
            $this->markDirty();
        }
    }

    public function updatedFeaturedImage(): void
    {
        $this->markDirty();
    }

    private function markDirty(): void
    {
        $this->isDirty = true;

        if ($this->autoSaveEnabled && $this->entryId > 0) {
            $this->dispatch('auto-save-debounce');
        }
    }

    public function save(): void
    {
        $this->validate();
        $this->isSaving = true;

        try {
            $data = [
                'title' => $this->title,
                'slug' => $this->slug ?: Str::slug($this->title),
                'body' => $this->body,
                'excerpt' => $this->excerpt,
                'status' => $this->status,
                'featured_image' => $this->featuredImage,
                'custom_fields' => $this->customFields,
                'tags' => $this->tags,
                'author_id' => $this->authorId ?? auth()->id(),
                'collection_id' => $this->collection->id,
                'updated_by' => auth()->id(),
            ];

            if ($this->entry) {
                $this->entry->update($data);
            } else {
                $this->entry = CmsEntry::create($data);
                $this->entryId = $this->entry->id;
            }

            $this->isDirty = false;
            $this->lastSavedAt = now()->diffForHumans();
            $this->dispatch('toast', message: __('Entry saved.'));
        } catch (\Exception $e) {
            $this->dispatch('toast', type: 'error', message: __('Failed to save: :error', ['error' => $e->getMessage()]));
        } finally {
            $this->isSaving = false;
        }
    }

    public function publish(): void
    {
        $this->save();

        if ($this->entry) {
            $this->entry->update([
                'status' => 'published',
                'published_at' => now(),
                'published_by' => auth()->id(),
            ]);
            $this->status = 'published';
            $this->showPublishModal = false;
            $this->dispatch('toast', message: __('Entry published.'));
            $this->dispatch('entry-published', entryId: $this->entry->id);
        }
    }

    public function unpublish(): void
    {
        if ($this->entry) {
            $this->entry->update(['status' => 'archived']);
            $this->status = 'archived';
            $this->showPublishModal = false;
            $this->dispatch('toast', message: __('Entry unpublished.'));
        }
    }

    public function schedulePublish(): void
    {
        $this->validate(['scheduledAt' => 'required|date|after:now']);
        $this->save();

        if ($this->entry) {
            $this->entry->update([
                'scheduled_at' => $this->scheduledAt,
                'status' => 'scheduled',
            ]);
            $this->dispatch('toast', message: __('Entry scheduled for :date.', ['date' => $this->scheduledAt]));
        }
    }

    public function uploadFeaturedImage($file): void
    {
        $this->validate(['featuredImage' => 'nullable|image|max:5120']);

        if ($file) {
            $path = $file->store('cms/featured', 'public');
            $this->featuredImage = $path;
            $this->markDirty();
        }
    }

    public function render()
    {
        return view('cms.entry-editor', [
            'entry' => $this->entry,
            'collection' => $this->collection,
            'collectionFields' => $this->collection->fields ?? [],
        ]);
    }
}
```

### 5.3 `CmsMediaLibrary` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;
use Livewire\Attributes\Layout;
use Livewire\WithFileUploads;
use Livewire\Attributes\Url;
use App\Models\CmsMedia;

#[Layout('gsmui::layouts.app')]
class CmsMediaLibrary extends Component
{
    use WithFileUploads;

    #[Url(as: 'type')]
    public ?string $filterType = null;

    public string $search = '';
    public array $selectedMedia = [];
    public bool $isMultiSelect = false;
    public ?string $insertCallback = null;

    public $uploads = [];
    public bool $isUploading = false;
    public int $uploadProgress = 0;

    public ?string $editingMediaId = null;
    public string $editAltText = '';
    public string $editCaption = '';

    protected array $listeners = [
        'mediaUploaded' => '$refresh',
        'insertMedia' => 'insertSelected',
    ];

    public function getMediaProperty()
    {
        $query = CmsMedia::query();

        if (filled($this->search)) {
            $query->where(function ($q) {
                $q->where('original_name', 'LIKE', "%{$this->search}%")
                  ->orWhere('alt_text', 'LIKE', "%{$this->search}%");
            });
        }

        if (filled($this->filterType)) {
            $query->where('type', $this->filterType);
        }

        return $query->orderBy('created_at', 'desc')->paginate(24);
    }

    public function uploadFiles($files): void
    {
        $this->isUploading = true;
        $this->uploadProgress = 0;

        $total = count($files);
        $uploaded = 0;

        foreach ($files as $file) {
            $path = $file->store('cms/media', 'public');
            $type = $this->guessType($file);

            CmsMedia::create([
                'disk' => 'public',
                'path' => $path,
                'original_name' => $file->getClientOriginalName(),
                'mime_type' => $file->getMimeType(),
                'size' => $file->getSize(),
                'type' => $type,
                'uploaded_by' => auth()->id(),
            ]);

            $uploaded++;
            $this->uploadProgress = (int) (($uploaded / $total) * 100);
        }

        $this->isUploading = false;
        $this->dispatch('toast', message: __(':count file(s) uploaded.', ['count' => $total]));
    }

    private function guessType($file): string
    {
        $mime = $file->getMimeType();
        return match(true) {
            str_starts_with($mime, 'image/') => 'image',
            str_starts_with($mime, 'video/') => 'video',
            str_starts_with($mime, 'audio/') => 'audio',
            str_contains($mime, 'pdf') => 'document',
            default => 'file',
        };
    }

    public function selectMedia(int $mediaId): void
    {
        if ($this->isMultiSelect) {
            if (in_array($mediaId, $this->selectedMedia)) {
                $this->selectedMedia = array_values(array_diff($this->selectedMedia, [$mediaId]));
            } else {
                $this->selectedMedia[] = $mediaId;
            }
        } else {
            $this->selectedMedia = [$mediaId];
        }
    }

    public function insertSelected(): void
    {
        $media = CmsMedia::whereIn('id', $this->selectedMedia)->get();
        $this->dispatch('media-inserted', media: $media->toArray());
        $this->selectedMedia = [];
    }

    public function deleteMedia(int $mediaId): void
    {
        $media = CmsMedia::findOrFail($mediaId);
        \Storage::disk($media->disk)->delete($media->path);
        $media->delete();
        $this->dispatch('toast', message: __('Media deleted.'));
    }

    public function updateMediaMeta(int $mediaId): void
    {
        $media = CmsMedia::findOrFail($mediaId);
        $media->update([
            'alt_text' => $this->editAltText,
            'caption' => $this->editCaption,
        ]);
        $this->editingMediaId = null;
        $this->dispatch('toast', message: __('Media details updated.'));
    }

    public function render()
    {
        return view('cms.media-library', [
            'media' => $this->media,
        ]);
    }
}
```

### 5.4 `CmsRevisionHistory` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;
use App\Models\CmsEntry;
use App\Models\CmsRevision;

class CmsRevisionHistory extends Component
{
    public int $entryId = 0;
    public array $revisions = [];
    public ?int $selectedRevisionId = null;
    public ?array $selectedRevision = null;
    public ?array $diffOutput = null;
    public bool $showDiff = false;

    public function mount(int $entryId): void
    {
        $this->entryId = $entryId;
        $this->loadRevisions();
    }

    private function loadRevisions(): void
    {
        $this->revisions = CmsRevision::where('entry_id', $this->entryId)
            ->with('user')
            ->orderBy('created_at', 'desc')
            ->get()
            ->toArray();
    }

    public function selectRevision(int $revisionId): void
    {
        $this->selectedRevisionId = $revisionId;
        $this->selectedRevision = CmsRevision::findOrFail($revisionId)->toArray();
        $this->diffOutput = $this->computeDiff();
        $this->showDiff = true;
    }

    private function computeDiff(): array
    {
        $revision = CmsRevision::findOrFail($this->selectedRevisionId);
        $current = CmsEntry::findOrFail($this->entryId);

        $fields = ['title', 'body', 'excerpt'];
        $diff = [];

        foreach ($fields as $field) {
            $old = $revision->content[$field] ?? '';
            $new = $current->{$field} ?? '';

            if ($old !== $new) {
                $diff[$field] = [
                    'old' => $old,
                    'new' => $new,
                    'changed' => true,
                ];
            }
        }

        return $diff;
    }

    public function restoreRevision(int $revisionId): void
    {
        $revision = CmsRevision::findOrFail($revisionId);
        $entry = CmsEntry::findOrFail($this->entryId);

        $entry->update([
            'title' => $revision->content['title'] ?? $entry->title,
            'body' => $revision->content['body'] ?? $entry->body,
            'excerpt' => $revision->content['excerpt'] ?? $entry->excerpt,
        ]);

        CmsRevision::create([
            'entry_id' => $entry->id,
            'user_id' => auth()->id(),
            'content' => [
                'title' => $entry->title,
                'body' => $entry->body,
                'excerpt' => $entry->excerpt,
            ],
            'action' => 'restore',
            'restored_from' => $revisionId,
        ]);

        $this->loadRevisions();
        $this->showDiff = false;
        $this->selectedRevisionId = null;
        $this->dispatch('toast', message: __('Revision restored.'));
    }

    public function render()
    {
        return view('cms.revision-history', [
            'revisions' => $this->revisions,
        ]);
    }
}
```

## 8. State Management

### 8.1 Entry Auto-Save Flow

```text
User types in editor / changes field
    │
    ▼
$wire.set() or wire:model
    │
    ▼
markDirty() → isDirty = true
    │
    ├──▶ dispatch('auto-save-debounce')
    │         │
    │         ▼  (JS listener, 2s debounce)
    │    $wire.call('save')
    │         │
    │         ▼
    │    Entry::update() → DB
    │         │
    │         ├──▶ isDirty = false
    │         ├──▶ lastSavedAt = now()->diffForHumans()
    │         └──▶ dispatch('toast', message: 'Entry saved.')
    │
    └──▶ Browser tab close warning (if isDirty)
```

### 8.2 Media Upload State

```text
User drops file or clicks browse
    │
    ▼
$wire.uploadFiles(files)
    │
    ├──▶ isUploading = true
    ├──▶ uploadProgress = 0
    │
    │  For each file:
    │    ├──▶ $file->store('cms/media', 'public')
    │    ├──▶ CmsMedia::create([...])
    │    └──▶ uploadProgress = (uploaded / total) * 100
    │
    └──▶ isUploading = false → dispatch('toast')
```

### 8.3 Revision Tracking

```text
Entry saved (via auto-save or manual)
    │
    ▼
CmsEntry::update()
    │
    ├──▶ CmsRevision::create() [on model observer]
    │    content snapshot: { title, body, excerpt }
    │    user_id: auth()->id()
    │    action: 'update' | 'publish' | 'restore'
    │
    └──▶ Available in CmsRevisionHistory component
         ├── View diff
         ├── Restore revision
         └── View revision history timeline
```

### 8.4 CMS State Persistence

```javascript
// Auto-save debounce — 2 second delay after last edit
let autoSaveTimer = null;

Livewire.on('auto-save-debounce', () => {
    clearTimeout(autoSaveTimer);
    autoSaveTimer = setTimeout(() => {
        Livewire.find('entry-editor').call('save');
    }, 2000);
});

// Warn before leaving with unsaved changes
window.addEventListener('beforeunload', (e) => {
    const editor = Livewire.find('entry-editor');
    if (editor?.serverMemo?.data?.isDirty) {
        e.preventDefault();
        e.returnValue = '';
    }
});
```

```php
// Sanitize HTML in entry body before saving
private function sanitizeBody(string $body): string
{
    // Strip dangerous tags and attributes

        . '<ul><ol><li><table><thead><tbody><tr><th><td>'
```

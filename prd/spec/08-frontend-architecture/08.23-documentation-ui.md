**Project:** GsmUi

**Framework:** Laravel 13 · Livewire 4 · Blade Components · GsmUi Component Library · Tailwind CSS v4 · Vite · Laravel Folio (optional)

> re-document the doc-source parsing or versioning model — those live in 05/06.

# Purpose

This document defines the documentation portal: the docs layout (sidebar nav, content region,
on-page TOC), code-block rendering, and — critically per AGENTS.md docs conventions — the
`@verbatim` handling required so that live `gsmui:` component demos are shown as source *and*
rendered as live previews without Blade double-processing.

---

## 1. Page Composition

Docs are optionally routed via Laravel Folio (`resources/views/pages/docs/*`) and rendered inside
`gsmui:layouts.docs`. The body is Markdown-compiled to Blade; component demos are embedded.

| Region | GsmUi Component | Binding |
| --- | --- | --- |
| Sidebar | `gsmui:navlist` (versioned tree) | `docsNav()` |
| Content | `gsmui:text`, `gsmui:heading`, `gsmui:code` | compiled body |
| Demo | `gsmui:card` (preview) + `gsmui:code` (source) | static |
| TOC | `gsmui:navmenu` (scroll-spy) | IntersectionObserver |
| Feedback | `gsmui:button` (was this helpful) | `DocsFeedback` |

## 2. Component Tree

```text
gsmui:layouts.docs
├── gsmui:navbar (search => docs index)
├── gsmui:navlist (version => pages)
└── <article>
    ├── gsmui:heading (h1..h3)
    ├── gsmui:text
    ├── <demo>  (see @verbatim below)
    │   ├── gsmui:card  (live preview)
    │   └── gsmui:code  (source listing)
    └── gsmui:navmenu (on-page TOC)
```

## 3. Data Flow — Docs Source → Render

```text
Markdown source (.md / .blade.md)
        │  docs-engine parse
        ▼
Blade view
        │  live demo blocks wrapped in @verbatim
        ▼
browser: preview rendered + source escaped inside <gsmui-code>
```

## 4. `@verbatim` Handling (MANDATORY per AGENTS.md)

Docs pages embed live `gsmui:` demos. Because the docs body is itself compiled Blade, any
`gsmui:` tag inside a demo would be processed as a real component instead of shown as source. The
convention:

- Wrap demo *source* in `@verbatim ... @endverbatim` so Blade does not parse the inner
  `gsmui:` tags; render that block through `gsmui:code` with a language hint.
- Render the *live* preview by duplicating the component OUTSIDE the `@verbatim` block (or by
  `@php` echoing a pre-rendered fragment) so it actually executes.
- Per AGENTS.md, after every docs change, open the page in Playwright and verify rendering
  **inside `@verbatim` blocks** where Blade components don't process.

Example skeleton:

```blade
<x-docs.variant level="3" title="Input">
    {{-- live preview --}}
    <gsmui:input wire:model="email" label="Email" />

    {{-- source, must NOT be re-processed --}}
    @verbatim
        <gsmui:input wire:model="email" label="Email" />
    @endverbatim
</x-docs.variant>
```

## 5. CSP & Styling

- Code highlighting uses bundled CSS via `adoptedStyleSheets` — no external fonts/CDN.
- `gsmui:code` never loads remote assets; inline SVG icons only.

## 6. Livewire Component Specifications

### 6.1 Docs Layout Livewire Component

```php
<?php

namespace App\Livewire\Docs;

use Livewire\Component;
use Livewire\Attributes\Layout;
use Livewire\WithPagination;
use Illuminate\Support\Facades\Cache;

#[Layout('gsmui::layouts.docs')]
class DocsPage extends Component
{
    public string $slug = '';
    public string $version = 'latest';
    public string $searchQuery = '';
    public array $tableOfContents = [];
    public ?string $activeHeading = null;
    public bool $searchOpen = false;

    protected array $debounceables = ['searchQuery'];

    public function mount(string $slug = 'index'): void
    {
        $this->slug = $slug;
        $this->version = request()->query('v', 'latest');
    }

    public function updatedSearchQuery(string $value): void
    {
        $this->searchOpen = strlen($value) > 0;
    }

    public function getSearchResultsProperty(): array
    {
        if (strlen($this->searchQuery) < 2) {
            return [];
        }

        return Cache::remember(
            "docs_search_{$this->version}_{$this->searchQuery}",
            3600,
            fn() => $this->performSearch($this->searchQuery)
        );
    }

    private function performSearch(string $query): array
    {
        return Cache::get("docs_index_{$this->version}", collect())
            ->filter(fn($page) => str_contains(
                strtolower($page['title'] . ' ' . ($page['body'] ?? '')),
                strtolower($query)
            ))
            ->take(20)
            ->values()
            ->toArray();
    }

    public function getNavTreeProperty(): array
    {
        return Cache::remember(
            "docs_nav_{$this->version}",
            3600,
            fn() => $this->buildNavTree()
        );
    }

    private function buildNavTree(): array
    {
        return [
            ['label' => 'Getting Started', 'url' => '/docs/getting-started', 'children' => [
                ['label' => 'Installation', 'url' => '/docs/installation'],
                ['label' => 'Quick Start', 'url' => '/docs/quick-start'],
                ['label' => 'Configuration', 'url' => '/docs/configuration'],
            ]],
            ['label' => 'Components', 'url' => '/docs/components', 'children' => [
                ['label' => 'Accordion', 'url' => '/docs/accordion'],
                ['label' => 'Button', 'url' => '/docs/button'],
                ['label' => 'Card', 'url' => '/docs/card'],
                // ... dynamically built from component registry
            ]],
            ['label' => 'Theming', 'url' => '/docs/theming'],
            ['label' => 'API Reference', 'url' => '/docs/api'],
        ];
    }

    public function getCurrentPageProperty(): ?array
    {
        return Cache::remember(
            "docs_page_{$this->version}_{$this->slug}",
            3600,
            fn() => $this->loadPage($this->slug)
        );
    }

    private function loadPage(string $slug): ?array
    {
        $path = resource_path("docs/{$this->version}/{$slug}.md");

        if (!file_exists($path)) {
            return null;
        }

        $content = file_get_contents($path);
        $frontmatter = $this->parseFrontmatter($content);
        $body = $this->compileMarkdown($this->stripFrontmatter($content));

        return array_merge($frontmatter, ['body' => $body, 'slug' => $slug]);
    }

    private function parseFrontmatter(string $content): array
    {
        if (preg_match('/^---\n(.+?)\n---/s', $content, $matches)) {
            return \Symfony\Component\Yaml\Yaml::parse($matches[1]) ?? [];
        }
        return [];
    }

    private function stripFrontmatter(string $content): string
    {
        return preg_replace('/^---\n(.+?)\n---/s', '', $content);
    }

    private function compileMarkdown(string $markdown): string
    {
        $parsed = app(\League\CommonMark\MarkdownParser::class)->parse($markdown);
        return app(\League\CommonMark\HtmlRenderer::class)->render($parsed);
    }

    public function render()
    {
        return view('docs.show', [
            'page' => $this->currentPage,
            'navTree' => $this->navTree,
            'searchResults' => $this->searchResults,
        ]);
    }
}
```

### 6.2 Docs Feedback Livewire Component

```php
<?php

namespace App\Livewire\Docs;

use Livewire\Component;
use Illuminate\Support\Facades\DB;

class DocsFeedback extends Component
{
    public string $slug = '';
    public bool $submitted = false;
    public ?string $feedback = null; // 'helpful' or 'not_helpful'
    public ?string $comment = '';
    public bool $showCommentForm = false;

    public function mount(string $slug): void
    {
        $this->slug = $slug;
    }

    public function rate(string $type): void
    {
        $this->feedback = $type;

        DB::table('docs_feedback')->insert([
            'slug' => $this->slug,
            'rating' => $type,
            'comment' => null,
            'created_at' => now(),
        ]);

        $this->showCommentForm = $type === 'not_helpful';
    }

    public function submitComment(): void
    {
        DB::table('docs_feedback')
            ->where('slug', $this->slug)
            ->whereNull('comment')
            ->latest()
            ->update(['comment' => $this->comment]);

        $this->submitted = true;
        $this->showCommentForm = false;
    }

    public function render()
    {
        return view('docs.components.feedback');
    }
}
```

### 6.3 Docs Search Livewire Component

```php
<?php

namespace App\Livewire\Docs;

use Livewire\Component;
use Livewire\Attributes\On;

class DocsSearch extends Component
{
    public string $query = '';
    public bool $isOpen = false;
    public int $selectedIndex = 0;
    public array $results = [];

    protected array $debounceables = ['query'];

    public function updatedQuery(string $value): void
    {
        if (strlen($value) < 2) {
            $this->results = [];
            return;
        }

        $this->results = $this->searchDocs($value);
        $this->selectedIndex = 0;
        $this->isOpen = true;
    }

    public function selectResult(int $index): void
    {
        if (isset($this->results[$index])) {
            $this->navigateTo($this->results[$index]['url']);
        }
    }

    public function handleKeydown(string $event): void
    {
        match($event) {
            'ArrowDown' => $this->selectedIndex = min($this->selectedIndex + 1, count($this->results) - 1),
            'ArrowUp' => $this->selectedIndex = max($this->selectedIndex - 1, 0),
            'Enter' => $this->selectResult($this->selectedIndex),
            'Escape' => $this->close(),
            default => null,
        };
    }

    public function close(): void
    {
        $this->isOpen = false;
        $this->query = '';
        $this->results = [];
    }

    private function searchDocs(string $query): array
    {
        // Search against pre-built index
        $index = cache()->get('docs_search_index_' . config('docs.version', 'latest'), []);

        return collect($index)
            ->filter(fn($page) => str_contains(strtolower($page['title'] . ' ' . strip_tags($page['snippet'] ?? '')), strtolower($query)))
            ->take(10)
            ->values()
            ->toArray();
    }

    private function navigateTo(string $url): void
    {
        $this->dispatch('navigate', url: $url);
    }

    public function render()
    {
        return view('docs.components.search');
    }
}
```

## 9. State Management Patterns

### 9.1 Scroll-Spy for On-Page TOC

```javascript
// docs-toc.js — IntersectionObserver-based scroll spy
export function docsToc() {
    return {
        headings: [],
        activeId: '',

        init() {
            // Extract headings from article body
            const article = document.getElementById('docs-article');
            if (!article) return;

            this.headings = Array.from(article.querySelectorAll('h2, h3')).map(el => ({
                id: el.id || el.textContent.toLowerCase().replace(/\s+/g, '-').replace(/[^\w-]/g, ''),
                text: el.textContent,
                level: parseInt(el.tagName.charAt(1)),
                el,
            }));

            // Ensure headings have IDs
            this.headings.forEach(h => {
                if (!h.el.id) h.el.id = h.id;
            });

            // Set up IntersectionObserver
            const observer = new IntersectionObserver(
                (entries) => {
                    entries.forEach(entry => {
                        if (entry.isIntersecting) {
                            this.activeId = entry.target.id;
                        }
                    });
                },
                { rootMargin: '-80px 0px -80% 0px', threshold: 0 }
            );

            this.headings.forEach(h => observer.observe(h.el));
        },
    };
}
```

```javascript
// docs-keyboard.js — Cmd+K search, navigation shortcuts
export function docsSearch() {
    return {
        isOpen: false,

        init() {
            window.addEventListener('keydown', (e) => {
                // Cmd+K / Ctrl+K to open search
                if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
                    e.preventDefault();
                    this.isOpen = true;
                    this.$refs.searchInput?.focus();
                }

                // Escape to close
                if (e.key === 'Escape' && this.isOpen) {
                    this.isOpen = false;
                    this.$refs.searchInput?.blur();
                }
            });
        },

        close() {
            this.isOpen = false;
            this.query = '';
            this.results = [];
        },
    };
}
```

## 17. Docs Search Implementation

### 17.1 Search Index Builder

```php
<?php

namespace App\Docs;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Str;

class DocsSearchIndex
{
    public function build(string $version): array
    {
        $pages = $this->loadAllPages($version);

        $index = collect($pages)->map(function ($page) use ($version) {
            return [
                'title' => $page['title'],
                'slug' => $page['slug'],
                'url' => "/docs/{$page['slug']}",
                'description' => $page['description'] ?? '',
                'snippet' => Str::limit(strip_tags($page['body'] ?? ''), 200),
                'tags' => $page['tags'] ?? [],
                'group' => $page['group'] ?? '',
                'boost' => $this->calculateBoost($page),
            ];
        })->toArray();

        Cache::tags(["docs_{$version}"])->put('docs_search_index', $index, now()->addHours(6));

        return $index;
    }

    private function loadAllPages(string $version): array
    {
        $path = resource_path("docs/{$version}");
        $files = glob("{$path}/**/*.md");

        return array_map(function ($file) use ($path) {
            $content = file_get_contents($file);
            $frontmatter = $this->parseFrontmatter($content);
            $slug = str_replace($path . '/', '', str_replace('.md', '', $file));

            return array_merge($frontmatter, [
                'slug' => $slug,
                'body' => strip_tags($this->compileBody($content)),
            ]);
        }, $files);
    }

    private function calculateBoost(array $page): int
    {
        $boost = 1;
        if (str_starts_with($page['slug'] ?? '', 'getting-started')) $boost += 3;
        if (str_contains($page['group'] ?? '', 'Components')) $boost += 2;
        if (!empty($page['tags'])) $boost += 1;
        return $boost;
    }

    private function parseFrontmatter(string $content): array
    {
        if (preg_match('/^---\n(.+?)\n---/s', $content, $matches)) {
            return \Symfony\Component\Yaml\Yaml::parse($matches[1]) ?? [];
        }
        return [];
    }

    private function compileBody(string $content): string
    {
        $content = preg_replace('/^---\n(.+?)\n---/s', '', $content);
        $parsed = app(\League\CommonMark\MarkdownParser::class)->parse($content);
        return app(\League\CommonMark\HtmlRenderer::class)->render($parsed);
    }
}
```

### 17.2 Search Result Ranking

Results are ranked by a combination of:

1. **Boost factor** — getting-started pages get +3, component pages get +2.
2. **Title match** — if query matches title exactly, score * 2.
3. **Tag match** — if query matches a tag, score * 1.5.
4. **Recency** — recently updated pages get a slight boost.

```php
private function rankResults(array $results, string $query): array
{
    usort($results, function ($a, $b) use ($query) {
        $scoreA = $a['boost'] * $this->matchScore($a, $query);
        $scoreB = $b['boost'] * $this->matchScore($b, $query);
        return $scoreB <=> $scoreA;
    });

    return $results;
}

private function matchScore(array $page, string $query): float
{
    $score = 1.0;
    if (stripos($page['title'], $query) !== false) $score *= 2.0;
    if (in_array(strtolower($query), array_map('strtolower', $page['tags'] ?? []))) $score *= 1.5;
    if (stripos($page['description'] ?? '', $query) !== false) $score *= 1.2;
    return $score;
}
```

## 23. Style Guide for Docs Content

### 23.1 Heading Conventions

- Use sentence case for headings: "Getting started" not "Getting Started".
- H1 is the page title — one per page, always.
- H2 separates major sections. H3 is for sub-sections within an H2.
- Add `id` attributes to headings for deep-linking via the URL fragment.
- Anchor links appear on hover (desktop) or via a copy-link button (mobile).

### 23.2 Code Block Conventions

- Always specify the language for fenced code blocks: ````blade`, ````php`, ````js`, ````css`.
- Code examples should be copy-pasteable and complete. No `// ... more code here` comments.
- Keep examples under 30 lines. Longer examples should be split into multiple blocks.
- Show the output/expected result when relevant.

## Open Questions / Risks

- Should previews be interactive (bound to a real Livewire component) or static? Affects build.
- Version switcher must reset `gsmui:navlist` active state — confirm scroll preservation.
- Search indexing for large doc sets may need Elasticsearch/Meilisearch in production.
- Confirm `@verbatim` handling works for nested component demos (e.g., a modal containing a form).
- Docs engine must handle both `.md` (plain markdown) and `.blade.md` (markdown with Blade) files.
- Interactive previews require a Livewire host component per demo — scope for v1?
- Consider adding dark mode code highlighting tokens for all supported languages.
- Docs build pipeline needs monitoring for broken links across versions.
- Consider adding contributor guidelines section for open-source community docs contributions.
- Performance budget: docs pages should load under 2 seconds on 3G connections.

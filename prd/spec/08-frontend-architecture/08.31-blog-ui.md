# 08.31 - Blog UI

**Project:** GsmUi
**Section:** 08 - Frontend Architecture
**Framework:** Laravel 13 · Livewire 4 · Blade Components · GsmUi Component Library · Tailwind CSS v4 · Vite · Laravel Folio (optional)
**Version:** 1.0.0

---

> See also: `05.27-blog-engine.md` (blog engine), `06.90-blog.md` (post/author records). This
> document specifies the *blog presentation* and does NOT re-document the post schema or RSS/SEO
> model — those live in 05/06.

# Purpose

This document defines the blog UI: the public listing (with category/tag filters), the article
page (prose rendering + code blocks), the author page, and the newsletter subscribe form. Posts
are optionally routed via Laravel Folio and rendered with the docs-style prose conventions.

---

## 1. Page Composition

| Screen | GsmUi Components | Livewire |
| --- | --- | --- |
| Listing | `gsmui:card` (post), `gsmui:search`, `gsmui:tabs` (category) | `Blog::index()` |
| Article | `gsmui:text` (prose), `gsmui:code`, `gsmui:heading` | static/FR |
| Author | `gsmui:avatar`, `gsmui:card` (posts) | `Blog::author()` |
| Subscribe | `gsmui:input`, `gsmui:button` | `Newsletter::subscribe()` |

## 2. Component Tree

```text
gsmui:layouts.marketing
└── <blog index>
    ├── gsmui:search (wire:model.live="q")
    ├── gsmui:tabs (category)
    └── gsmui:card × N
        ├── gsmui:image (self-hosted)
        ├── gsmui:heading (title)
        ├── gsmui:badge (tag)
        └── gsmui:button (read)

<article>  (prose)
├── gsmui:heading (title)
├── gsmui:text (body, prose)
├── gsmui:code (fenced blocks — bundled highlight)
└── <subscribe form>  (gsmui:input + gsmui:button)
```

## 3. Data Flow — Read → Subscribe

```text
gsmui:search wire:model.live="q"
        │
        ▼
Blog::$q  ──▶  filter posts (05.27)  ──▶  gsmui:card grid

gsmui:input wire:model="email" (subscribe)
        │  <form wire:submit="subscribe">
        ▼
Newsletter::subscribe()  ──▶  gsmui:toast ("Subscribed")
```

- Article code blocks use bundled highlighting through `adoptedStyleSheets` (no external font/CDN).
- Images self-hosted only (`img-src 'self' data:`); icons via `gsmui:icon`.
- Invalid email layered with `data-invalid:` classes; silent revert on failure.

## 4. CSP & Styling

- Prose uses `gsmui:text` with the content max-width token; no remote `@font-face`.
- ARIA labels via `__()` (e.g. `__('Search articles')`).

### 5.1 `BlogIndex` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;
use Livewire\Attributes\Layout;
use Livewire\WithPagination;
use Livewire\Attributes\Url;
use Illuminate\Support\Facades\Cache;

#[Layout('gsmui::layouts.marketing')]
class BlogIndex extends Component
{
    use WithPagination;

    #[Url(as: 'q')]
    public string $search = '';

    #[Url(as: 'category')]
    public ?string $category = null;

    #[Url(as: 'tag')]
    public ?string $tag = null;

    #[Url(as: 'page')]
    public int $page = 1;

    public string $sortBy = 'published_at';
    public string $sortDirection = 'desc';
    public int $perPage = 12;

    public ?string $highlightedPost = null;

    protected array $listeners = [
        'searchUpdated' => 'onSearchUpdated',
        'categorySelected' => 'onCategorySelected',
    ];

    public function mount(): void
    {
        $this->category = request()->query('category');
        $this->tag = request()->query('tag');
        $this->search = request()->query('q', '');
    }

    public function updatedSearch(string $value): void
    {
        $this->resetPage();
        $this->dispatch('search-updated', query: $value);
    }

    public function updatedCategory(?string $value): void
    {
        $this->resetPage();
    }

    public function updatedTag(?string $value): void
    {
        $this->resetPage();
    }

    public function onSearchUpdated(string $query): void
    {
        $this->search = $query;
        $this->resetPage();
    }

    public function onCategorySelected(?string $category): void
    {
        $this->category = $category;
        $this->resetPage();
    }

    public function selectTag(?string $tag): void
    {
        $this->tag = ($this->tag === $tag) ? null : $tag;
        $this->resetPage();
    }

    public function clearFilters(): void
    {
        $this->search = '';
        $this->category = null;
        $this->tag = null;
        $this->resetPage();
    }

    public function getHasActiveFiltersProperty(): bool
    {
        return filled($this->search) || filled($this->category) || filled($this->tag);
    }

    public function getPostsProperty()
    {
        return Cache::remember(
            "blog-posts-{$this->search}-{$this->category}-{$this->tag}-{$this->page}",
            300,
            fn () => $this->buildQuery()->get()
        );
    }

    public function getCategoriesProperty(): array
    {
        return Cache::remember('blog-categories', 600, function () {
            return \App\Models\Post::query()
                ->where('status', 'published')
                ->select('category', \DB::raw('COUNT(*) as count'))
                ->groupBy('category')
                ->orderBy('count', 'desc')
                ->pluck('count', 'category')
                ->toArray();
        });
    }

    public function getPopularTagsProperty(): array
    {
        return Cache::remember('blog-popular-tags', 600, function () {
            return \App\Models\Post::query()
                ->where('status', 'published')
                ->withCount('tags')
                ->orderBy('tags_count', 'desc')
                ->limit(20)
                ->pluck('tags')
                ->flatten()
                ->pluck('name', 'slug')
                ->toArray();
        });
    }

    private function buildQuery()
    {
        $query = \App\Models\Post::query()
            ->where('status', 'published')
            ->with(['author', 'tags', 'category']);

        if (filled($this->search)) {
            $query->where(function ($q) {
                $q->where('title', 'LIKE', "%{$this->search}%")
                  ->orWhere('excerpt', 'LIKE', "%{$this->search}%")
                  ->orWhere('body', 'LIKE', "%{$this->search}%");
            });
        }

        if (filled($this->category)) {
            $query->where('category', $this->category);
        }

        if (filled($this->tag)) {
            $query->whereHas('tags', fn ($q) => $q->where('slug', $this->tag));
        }

        return $query->orderBy($this->sortBy, $this->sortDirection)
                     ->paginate($this->perPage);
    }

    public function render()
    {
        return view('blog.index', [
            'posts' => $this->posts,
            'categories' => $this->categories,
            'popularTags' => $this->popularTags,
        ]);
    }
}
```

### 5.2 `BlogArticle` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;
use Livewire\Attributes\Layout;
use Illuminate\Support\Facades\Cache;

#[Layout('gsmui::layouts.marketing')]
class BlogArticle extends Component
{
    public string $slug = '';
    public ?object $post = null;
    public array $relatedPosts = [];
    public bool $showToc = true;
    public array $headings = [];
    public string $estimatedReadTime = '';

    public function mount(string $slug): void
    {
        $this->slug = $slug;
        $this->loadPost();
    }

    private function loadPost(): void
    {
        $this->post = Cache::remember(
            "blog-post-{$this->slug}",
            600,
            fn () => \App\Models\Post::query()
                ->where('slug', $this->slug)
                ->where('status', 'published')
                ->with(['author', 'tags', 'category'])
                ->firstOrFail()
        );

        $this->headings = $this->extractHeadings($this->post->body);
        $this->estimatedReadTime = $this->calculateReadTime($this->post->body);
        $this->relatedPosts = $this->getRelatedPosts();
    }

    private function extractHeadings(string $body): array
    {
        preg_match_all('/^#{2,3}\s+(.+)$/m', $body, $matches);
        $headings = [];

        foreach ($matches[1] as $index => $heading) {
            $headings[] = [
                'text' => $heading,
                'slug' => str($heading)->slug()->toString(),
                'level' => substr_count($matches[0][$index], '#'),
            ];
        }

        return $headings;
    }

    private function calculateReadTime(string $body): string
    {
        $wordCount = str_word_count(strip_tags($body));
        $minutes = max(1, (int) ceil($wordCount / 200));

        return trans_choice(
            ':minute min read|:minutes min read',
            $minutes,
            ['minute' => $minutes, 'minutes' => $minutes]
        );
    }

    private function getRelatedPosts(): array
    {
        return Cache::remember(
            "blog-related-{$this->slug}",
            600,
            fn () => \App\Models\Post::query()
                ->where('status', 'published')
                ->where('id', '!=', $this->post->id)
                ->where(function ($q) {
                    $q->where('category', $this->post->category)
                      ->orWhereHas('tags', fn ($t) => $t->whereIn('id', $this->post->tags->pluck('id')));
                })
                ->with(['author', 'tags'])
                ->limit(3)
                ->orderBy('published_at', 'desc')
                ->get()
                ->toArray()
        );
    }

    public function getTocEntriesProperty(): array
    {
        return collect($this->headings)->map(fn ($h) => [
            'text' => $h['text'],
            'slug' => $h['slug'],
            'indent' => $h['level'] === 3,
        ])->toArray();
    }

    public function shareOnTwitter(): string
    {
        $text = urlencode($this->post->title . ' — ' . url("/blog/{$this->slug}"));
        return "https://twitter.com/intent/tweet?text={$text}";
    }

    public function shareOnLinkedIn(): string
    {
        $url = urlencode(url("/blog/{$this->slug}"));
        return "https://www.linkedin.com/sharing/share-offsite/?url={$url}";
    }

    public function shareOnHackerNews(): string
    {
        $url = urlencode(url("/blog/{$this->slug}"));
        $title = urlencode($this->post->title);
        return "https://news.ycombinator.com/submitlink?u={$url}&t={$title}";
    }

    public function render()
    {
        return view('blog.article', [
            'post' => $this->post,
            'relatedPosts' => $this->relatedPosts,
            'headings' => $this->headings,
            'readTime' => $this->estimatedReadTime,
        ]);
    }
}
```

### 5.4 `NewsletterSubscribe` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;
use Illuminate\Support\Facades\RateLimiter;
use App\Models\NewsletterSubscriber;

class NewsletterSubscribe extends Component
{
    public string $email = '';
    public string $status = 'idle'; // idle | subscribing | success | error
    public string $errorMessage = '';
    public bool $showSuccess = false;

    protected array $rules = [
        'email' => 'required|email|max:255',
    ];

    protected array $messages = [
        'email.required' => 'Please enter your email address.',
        'email.email' => 'Please enter a valid email address.',
    ];

    public function subscribe(): void
    {
        $this->validate();

        $throttleKey = 'newsletter:' . $this->getEmailDomain();
        if (RateLimiter::tooManyAttempts($throttleKey, 3)) {
            $this->errorMessage = __('Too many subscribe attempts. Please try again later.');
            $this->status = 'error';
            return;
        }

        RateLimiter::hit($throttleKey, 3600);

        $existing = NewsletterSubscriber::where('email', $this->email)->first();

        if ($existing) {
            if ($existing->is_active) {
                $this->errorMessage = __('This email is already subscribed.');
                $this->status = 'error';
                return;
            }

            $existing->update(['is_active' => true, 'subscribed_at' => now()]);
        } else {
            NewsletterSubscriber::create([
                'email' => $this->email,
                'is_active' => true,
                'subscribed_at' => now(),
                'ip_address' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ]);
        }

        $this->status = 'success';
        $this->showSuccess = true;
        $this->email = '';
        $this->dispatch('newsletter-subscribed');
    }

    public function unsubscribe(): void
    {
        if (filled($this->email)) {
            NewsletterSubscriber::where('email', $this->email)
                ->update(['is_active' => false]);
            $this->dispatch('newsletter-unsubscribed');
        }
    }

    private function getEmailDomain(): string
    {
        return substr(strrchr($this->email, '@'), 1);
    }

    public function render()
    {
        return view('blog.newsletter-subscribe');
    }
}
```

## 8. State Management

### 8.1 Search State Flow

```text
User types in gsmui:search
    │  debounce 300ms
    ▼
wire:model.live.debounce.300ms="search"
    │
    ▼
BlogIndex::$search (public, #[Url])
    │
    ├──▶ resetPage()           [pagination reset]
    ├──▶ dispatch('search-updated', query: $search)
    └──▶ Cache::forget("blog-posts-{$search}...")  [cache invalidation]
              │
              ▼
        buildQuery() → DB query → paginate → re-render grid
```

### 8.2 Category/Tag Filter Flow

```text
User clicks category tab or tag chip
    │
    ▼
wire:click="$set('category', '...')"  or  wire:click="selectTag('...')"
    │
    ▼
BlogIndex::$category / BlogIndex::$tag (#[Url] — syncs to URL)
    │
    ├──▶ resetPage()
    └──▶ Cache::forget() → buildQuery() → re-render
```

### 8.3 URL State Synchronization

All filters are persisted in the URL via `#[Url]` attributes:

```text
/blog?q=laravel&category=tutorial&tag=livewire&page=2
```

This enables:
- Shareable filtered views
- Browser back/forward navigation
- Bookmark-able filter states

### 8.4 Newsletter Subscription State

```text
User submits email
    │
    ▼
wire:submit="subscribe"
    │
    ├──▶ $this->validate()        [email format]
    ├──▶ RateLimiter check         [throttle by domain]
    ├──▶ NewsletterSubscriber::create() or update()
    │
    ├── success: $this->status = 'success', $this->showSuccess = true
    └── error: $this->status = 'error', $this->errorMessage = '...'
```

## 17. Webhook Integration

### 17.1 Post Published Webhook

```php
// When a post is published, dispatch webhooks to subscribed services
class PostPublished implements ShouldBroadcast
{
    use Dispatchable, SerializesModels;

    public function __construct(public Post $post) {}

    public function handle(): void
    {
        // Notify subscribers
        NewsletterSubscriber::where('is_active', true)
            ->chunk(100, function ($subscribers) {
                foreach ($subscribers as $subscriber) {
                    SendNewPostNotification::dispatch($this->post, $subscriber);
                }
            });

        // Ping external webhooks (RSS readers, analytics)
        WebhookService::dispatch('post.published', [
            'post_id' => $this->post->id,
            'title' => $this->post->title,
            'slug' => $this->post->slug,
            'url' => url('/blog/' . $this->post->slug),
            'published_at' => $this->post->published_at->toIso8601String(),
        ]);
    }
}
```

### 17.2 Newsletter Delivery

```php
// queued job for newsletter delivery
class SendNewPostNotification implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public int $tries = 3;
    public int $backoff = 60;

    public function __construct(
        public Post $post,
        public NewsletterSubscriber $subscriber,
    ) {}

    public function handle(): void
    {
        Mail::to($this->subscriber->email)
            ->send(new NewPostMail($this->post));

        $this->subscriber->update([
            'last_notified_at' => now(),
        ]);
    }

    public function failed(\Throwable $exception): void
    {
        Log::error('Newsletter delivery failed', [
            'subscriber_id' => $this->subscriber->id,
            'post_id' => $this->post->id,
            'error' => $exception->getMessage(),
        ]);
    }
}
```

# Purpose

Navigation composes `gsmui:navlist`, `gsmui:navbar`, `gsmui:breadcrumbs`, and `gsmui:command` into a coherent, keyboard-accessible system. Active states are derived from the current route (Laravel/Folio), breadcrumbs reflect the route hierarchy, and the command palette offers a shortcut-driven alternative entry point — all CSP-safe and token-themed.

## 1. Component Inventory

| Component | File | Role |
| --- | --- | --- |
| `gsmui:navlist` | `navlist/index.blade.php` | Vertical `<nav>` list container (`flex flex-col gap-0.5`) |
| `gsmui:navbar` | `navbar/index.blade.php` | Horizontal top bar (see `08.12`) |
| `gsmui:breadcrumbs` | `breadcrumbs/index.blade.php` | `<nav aria-label="Breadcrumb">` + `<ol>` |
| `gsmui:command` | `command/index.blade.php` | Command palette / quick-search trigger |
| `gsmui:navmenu` | `navmenu/index.blade.php` | Dropdown nav menu (ARIA APG menu pattern) |

## 2. Nav Item Contract

A nav item is a link/button inside `gsmui:navlist`:

```blade
<a href="{{ route('dashboard') }}"
   @class([
       'flex items-center gap-2 rounded-md px-3 py-2 text-sm font-medium',
       'bg-zinc-100 text-zinc-900 dark:bg-white/10 dark:text-white' => $active,
       'text-zinc-600 hover:bg-zinc-100 dark:text-zinc-300 dark:hover:bg-white/5' => !$active,
   ])
   @if ($active) aria-current="page" @endif>
    <gsmui:icon name="home" variant="mini" />
    {{ __('Dashboard') }}
</a>
```

Rules:
- Active item sets `aria-current="page"` (WCAG/APG), not just color.
- No `cursor-pointer` (native `<a>`/`<button>` keep default cursor — AGENTS.md).
- Whole row is the hit target; icon is `shrink-0`.

## 3. Active-State Resolution

| Source | Mechanism |
| --- | --- |
| Static routes | `request()->routeIs('dashboard.*')` or `Route::is()` |
| Folio pages | `Str::startsWith(request()->path(), $pagePath)` or a Folio-derived `$activePath` |
| Livewire | Compare `request()->url()` to item URL |

Expose an `active()` helper in the layout composer (`app/View/Composers/NavComposer.php`) so items stay declarative.

## 4. Breadcrumbs

`gsmui:breadcrumbs` props: `separator` (icon name, default `chevron-right`), `size` (`sm`/`lg`/default). Items are `gsmui:breadcrumbs.item` (or plain `<li><a>`):

```blade
<gsmui:breadcrumbs>
    <gsmui:breadcrumbs.item href="{{ route('docs') }}">{{ __('Docs') }}</gsmui:breadcrumbs.item>
    <gsmui:breadcrumbs.item>{{ __('Icon System') }}</gsmui:breadcrumbs.item>
</gsmui:breadcrumbs>
```

- Last item is plain text (current page), no link.
- Separator is an inline `gsmui:icon` (decorative, `aria-hidden`).
- Crumb text uses `__()` for localization.

## 5. Laravel Folio Integration

When Folio is enabled (optional, per stack), navigation auto-builds from `resources/views/pages/*.blade.php`:

1. Each Folio page may declare `@section('nav', ['label' => 'Docs', 'group' => 'Reference'])`.
2. A `FolioNavCollector` aggregates sections into the `NavComposer` tree.
3. Active state resolves from the Folio URI match.

This keeps docs/marketing nav in sync with files (see `08.23-documentation-ui.md`).

## 6. Command Palette Link

`gsmui:command` renders a `ui-select` wrapper (see `06.20-components.md`). Bind it to the route index:

- `Ctrl/Cmd+K` opens the palette (global keydown listener, no external lib).
- Selecting an entry navigates via `window.location` / Livewire `navigate`.
- Palette items reuse the same `active`/icon contract so the palette mirrors the sidebar.

## 7. Open Questions / Risks

- Decide whether `navmenu` dropdown uses the native `popover` API (like `gsmui:popover`) or Alpine — prefer `popover` for APG parity and scroll-lock reuse.
- Folio auto-nav may over-couple nav to file layout; gate behind a config flag.
- Mobile: navlist collapses into a `gsmui:sidebar type="drawer"` toggled from the navbar (see `08.14`).

## 8. Deep Dive: Navlist Component

### 8.1 Navlist Container Contract

The `gsmui:navlist` component provides the vertical navigation container:

```blade
{{-- stubs/resources/views/gsmui/navlist/index.blade.php --}}
@props([
    'items' => [],
    'collapsed' => false,
    'size' => 'default', // 'sm' | 'default' | 'lg'
])

<nav aria-label="{{ __('Navigation') }}"
     @class([
         'flex flex-col gap-0.5',
         'text-sm' => $size === 'default',
         'text-xs' => $size === 'sm',
         'text-base' => $size === 'lg',
     ])>
    @forelse($items as $item)
        <gsmui:navlist.item
            :href="$item['href'] ?? '#'"
            :icon="$item['icon'] ?? null"
            :active="$item['active'] ?? false"
            :badge="$item['badge'] ?? null"
            :disabled="$item['disabled'] ?? false"
            :collapsed="$collapsed"
            :external="$item['external'] ?? false"
        >
            {{ $item['label'] ?? '' }}
        </gsmui:navlist.item>
    @empty
        {{ $slot }}
    @endforelse
</nav>
```

### 8.2 Navlist Item Contract

Individual nav items follow this structure:

```blade
{{-- stubs/resources/views/gsmui/navlist/item/index.blade.php --}}
@props([
    'href' => '#',
    'icon' => null,
    'active' => false,
    'badge' => null,
    'disabled' => false,
    'collapsed' => false,
    'external' => false,
])

@php
    $tag = $href ? 'a' : 'button';
    $classes = Gsmui::classes()
        ->add('flex items-center gap-2 rounded-md px-3 py-2 font-medium transition-colors')
        ->add(match(true) {
            $active => 'bg-zinc-100 text-zinc-900 dark:bg-white/10 dark:text-white',
            $disabled => 'text-zinc-400 dark:text-zinc-500 cursor-not-allowed',
            default => 'text-zinc-600 hover:bg-zinc-50 dark:text-zinc-400 dark:hover:bg-white/5',
        })
        ->add($collapsed ? 'justify-center px-2' : '');
@endphp

<{{ $tag }}
    href="{{ $href }}"
    @if ($active) aria-current="page" @endif
    @if ($disabled) aria-disabled="true" tabindex="-1" @endif
    @if ($external) target="_blank" rel="noopener noreferrer" @endif
    @class($classes)
>
    @if ($icon)
        <gsmui:icon name="{{ $icon }}" variant="mini"
                    class="{{ $active ? 'text-zinc-900 dark:text-white' : 'text-zinc-400 dark:text-zinc-500' }}" />
    @endif

    @unless ($collapsed)
        <span class="flex-1 truncate">{{ $slot }}</span>

        @if ($badge)
            <span @class([
                'inline-flex items-center rounded-full px-2 py-0.5 text-xs font-medium',
                'bg-zinc-200 text-zinc-700 dark:bg-white/10 dark:text-zinc-300' => !$active,
                'bg-white text-zinc-900 dark:bg-zinc-700 dark:text-white' => $active,
            ])>
                {{ $badge }}
            </span>
        @endif
    @else
        {{-- Collapsed: tooltip on hover --}}
        <gsmui:tooltip position="right">{{ $slot }}</gsmui:tooltip>
    @endunless
</{{ $tag }}>
```

```js

class CommandPalette {
  constructor(el) {
    this.input = el.querySelector('input[type="text"]');
    this.results = el.querySelector('[data-gsmui-command-results]');
    this.debounceTimer = null;
  }

  handleInput(e) {
    clearTimeout(this.debounceTimer);
    this.debounceTimer = setTimeout(() => {
      this.search(e.target.value);
    }, 150); // 150ms debounce
  }

  async search(query) {
    if (query.length < 2) {
      this.results.innerHTML = '';
      return;
    }
    // Client-side: filter pre-loaded route index
    // Server-side: Livewire wire:model.debounce.150ms
  }
}
```

## 12. Active-State Resolution Deep Dive

### 12.1 Laravel Route Matching

For traditional Laravel routes (not Folio):

```php
// app/View/Composers/NavComposer.php
class NavComposer
{
    public function compose(View $view)
    {
        $items = $view->getData()['items'] ?? [];
        $activePath = request()->path();

        $items = array_map(function ($item) use ($activePath) {
            $itemPath = parse_url($item['href'], PHP_URL_PATH);
            $itemPath = ltrim($itemPath, '/');

            $item['active'] = str_starts_with($activePath, $itemPath)
                && $itemPath !== '';

            return $item;
        }, $items);

        $view->with('items', $items);
    }
}
```

### 12.2 Folio Route Matching

When Folio is enabled, active states are derived from the Folio URI:

```php
// app/View/Composers/FolioNavComposer.php
class FolioNavComposer
{
    public function compose(View $view)
    {
        $folioPages = Folio::pages();
        $currentUri = Folio::currentUri();

        $items = collect($folioPages)
            ->map(function ($page) use ($currentUri) {
                return [
                    'label' => $page->metadata('nav.label', $page->title()),
                    'href' => $page->uri(),
                    'icon' => $page->metadata('nav.icon'),
                    'active' => $page->uri() === $currentUri,
                    'group' => $page->metadata('nav.group', 'General'),
                ];
            })
            ->groupBy('group')
            ->toArray();

        $view->with('navGroups', $items);
    }
}
```

### 12.3 Livewire Dynamic Active State

For Livewire components that change active state reactively:

```php
// In a Livewire component
class Dashboard extends Component
{
    public function getNavItemsProperty(): array
    {
        return collect($this->navItems)
            ->map(fn ($item) => array_merge($item, [
                'active' => request()->is(ltrim($item['href'], '/')),
            ]))
            ->toArray();
    }
}
```

### 12.4 Active State Fallback

When route matching fails:

```php
// Fallback: compare full URL
$item['active'] = request()->url() === $item['href'];

// Or: compare route name
$item['active'] = request()->routeIs($item['route'] ?? '');
```

```blade
        </a>
        {{-- More items --}}
    </div>
</nav>
```

### 13.3 Mobile Navigation Accessibility

- Drawer: focus trap, `Escape` to close, return focus to trigger.
- Bottom nav: each item is a proper `<a>` with `aria-label`.
- Active state: `aria-current="page"` on the active bottom nav item.
- Touch target: minimum 44×44px per WCAG 2.2.

## 17. Navigation Security

### 17.1 External Link Safety

External links include `rel="noopener noreferrer"` to prevent tab-napping:

```blade
<a href="{{ $item['href'] }}"
   target="_blank"
   rel="noopener noreferrer"
   @if ($item['external']) data-gsmui-external @endif>

    <gsmui:icon name="arrow-up-right" variant="micro" class="text-zinc-400" />
```

### 17.2 Route Validation

Nav items should only link to routes the current user can access:

```php
// In NavComposer
$items = collect($items)->filter(function ($item) {
    return !isset($item['permission']) || auth()->user()->can($item['permission']);
})->toArray();
```

### 17.3 CSRF Protection

Navigation actions that modify state (e.g., "mark as read") use POST with CSRF:

```blade

    </button>
```

## 18. Navigation State Management

### 18.1 Server-Side State

Navigation state (active item, open menus) is primarily managed server-side via Laravel routes:

### 18.2 Client-Side State

Some navigation state requires client-side management:

| State | Storage | Mechanism |
| --- | --- | --- |
| Sidebar collapse | `localStorage` | Persists across sessions |

| Command palette open | Component state | Livewire property |

### 18.3 State Synchronization

When client-side state affects server-side rendering:

```php
// Livewire component
class Navigation extends Component
{
    public bool $sidebarCollapsed = false;

    {
        $this->sidebarCollapsed = session('sidebar-collapsed', false);
    }

    public function toggleSidebar(): void
    {
        $this->sidebarCollapsed = !$this->sidebarCollapsed;
        session(['sidebar-collapsed' => $this->sidebarCollapsed]);
    }
}
```

## 22. Navigation Performance

### 22.1 Prefetching Strategy

```js
// Prefetch on hover (with delay to avoid accidental prefetches)
document.querySelectorAll('gsmui-navlist-item a').forEach(link => {
  let prefetchTimeout;

  link.addEventListener('mouseenter', () => {
    prefetchTimeout = setTimeout(() => {
      if (!link.dataset.prefetched) {
        const prefetch = document.createElement('link');
        prefetch.rel = 'prefetch';
        prefetch.href = link.href;
        document.head.appendChild(prefetch);
        link.dataset.prefetched = 'true';
      }
    }, 100); // 100ms delay
  });

  link.addEventListener('mouseleave', () => {
    clearTimeout(prefetchTimeout);
  });
});
```

## 34. Navigation Security

### 34.1 Route Authorization

Nav items should only appear if the user has permission:

```php
// In NavComposer
$items = collect($items)->filter(function ($item) {
    if (!isset($item['permission'])) return true;
    return auth()->user()->can($item['permission']);
})->toArray();
```

### 34.2 External Link Safety

```blade
<a href="{{ $href }}"
   @if ($external)
       target="_blank"
       rel="noopener noreferrer"
   @endif>
    {{ $label }}
</a>
```

### 34.3 CSRF for State-Changing Navigation

```blade
<form method="POST" action="{{ route('logout') }}">
    @csrf
    <button type="submit" class="nav-item">
        <gsmui:icon name="arrow-right-on-rectangle" variant="mini" />
        {{ __('Log out') }}
    </button>
</form>
```

### 34.4 Rate Limiting Search

Command palette search should be rate-limited:

```php
// In Livewire component
public function search(string $query): array
{
    RateLimiter::attempt('nav-search:' . auth()->id(), 30, function () use ($query) {
        return $this->performSearch($query);
    });
    return [];
}
```

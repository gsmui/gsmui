# 07.22 - Authentication

**Project:** GsmUi
**Architecture:** Fortify (web) + Sanctum (token/SPA) Authentication
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

GsmUi authenticates users through two complementary stacks: **Laravel Fortify** for the first-party web/SPA login, registration, password reset, and two-factor flows, and **Laravel Sanctum** for issuing and validating API tokens (used by the REST API in `07.21-api-architecture.md`) and SPA cookie auth. Both share the same `users` table and Eloquent `User` model, which uses Sanctum's `HasApiTokens` and Fortify's `TwoFactorAuthenticatable` traits.

This document specifies the *implementation mechanics*: service provider wiring, guard configuration, the session-vs-token decision matrix, 2FA, and password reset. The conceptual security posture (CSP, CSRF, threat model) is covered in `05.15-security.md`.

> See also: 07.21-api-architecture.md (Sanctum token usage), 07.23-authorization.md (roles/permissions after authentication), 05.15-security.md (defense-in-depth).

---

# 1. Service Provider Registration

Fortify and Sanctum are booted in their service providers. Fortify routes are enabled for the actions GsmUi supports.

```php
// app/Providers/FortifyServiceProvider.php
public function boot(): void
{
    Fortify::loginView(fn () => view('gsmui::auth.login'));
    Fortify::registerView(fn () => view('gsmui::auth.register'));
    Fortify::requestPasswordResetLinkView(
        fn () => view('gsmui::auth.forgot-password')
    );
    Fortify::resetPasswordView(
        fn ($request) => view('gsmui::auth.reset-password', ['request' => $request])
    );
    Fortify::twoFactorChallengeView(
        fn () => view('gsmui::auth.two-factor')
    );

    Fortify::authenticateUsing(function ($request) {
        $user = \App\Models\User::where('email', $request->email)->first();

        return ($user && \Hash::check($request->password, $user->password))
            ? $user
            : null;
    });
}
```

Sanctum simply needs its middleware alias registered (Laravel 13 auto-registers `auth:sanctum`).

# 2. Guard Configuration

GsmUi uses the `web` guard (session) for first-party pages and `sanctum` for API/token requests. Both resolve to the same `users` provider.

```php
// config/auth.php (excerpt)
'guards' => [
    'web' => [
        'driver' => 'session',
        'provider' => 'users',
    ],
    'sanctum' => [
        'driver' => 'sanctum',
        'provider' => 'users',
    ],
],
```

Usage in code always specifies the guard explicitly:

```php
// Web/Livewire context
$user = auth('web')->user();

// API/token context (07.21-api-architecture.md)
$user = auth('sanctum')->user();
// or route middleware: ->middleware('auth:sanctum')
```

# 3. Session vs Token Decision

| Context | Guard | Transport | Use case |
| ------- | ----- | --------- | -------- |
| First-party web | `web` (session) | Session cookie + CSRF | Livewire pages, dashboards |
| SPA (same-origin) | `sanctum` | Session cookie via `EnsureFrontendRequestsAreStateful` | Inertia/SPA clients |
| Mobile / CLI / MCP | `sanctum` | `Bearer` personal access token | REST API (`07.21`) |
| Third-party | `sanctum` | `Bearer` token, scoped abilities | Integrations |

Sanctum's SPA auth reuses the session guard when `stateful` domains are configured, so the same login endpoint serves both cookie and token clients.

# 4. Two-Factor Authentication (2FA)

Fortify's `TwoFactorAuthenticatable` trait adds `two_factor_secret` and `two_factor_recovery_codes` columns (see `06-database-design`). Enable the challenge in Fortify:

```php
// config/fortify.php
'features' => [
    \Laravel\Fortify\Features::twoFactorAuthentication([
        'confirm' => true,
        'confirmPassword' => true,
    ]),
],
```

Challenge flow:

```text
Login (valid credentials)
      │
Has 2FA enabled?
      ├── no  → issue session / token
      └── yes → redirect to two-factor challenge
                  │
              verify TOTP / recovery code
                  │
              issue session / token
```

Never issue a token until the 2FA challenge passes.

---

# 5. Password Reset

Fortify handles reset link generation and token verification against the `password_reset_tokens` table (`06-database-design`). The reset pipeline:

```text
POST /forgot-password
      │  Fortify sends signed reset link (queued mail, 07.28-mail.md)
      ▼
User clicks link → /reset-password?token=...
      │
POST /reset-password
      │  Fortify verifies token, updates password (hashed)
      ▼
Session revoked; user re-authenticates
```

Reset tokens are single-use and short-lived (default 60 min). After reset, all existing Sanctum tokens are optionally revoked.

# 6. Token Issuance & Scope

Token issuance mirrors `07.21-api-architecture.md`. Abilities restrict what a token can do:

```php
$token = $user->createToken(
    name: 'cli-device',
    abilities: ['components:read', 'themes:read'],
)->plainTextToken;

// Enforcement inside a controller/action:
abort_unless($request->user()->tokenCan('components:read'), 403);
```

# 8. Security Notes

| Control | Mechanism |
| ------- | --------- |
| Password hashing | `Hash::make` (bcrypt/argon), never plaintext |
| Brute-force | Fortify throttle + `07.21` rate limiter |
| CSRF | Session guard only; Sanctum tokens exempt (`05.15-security.md`) |
| Token leakage | Short-lived, scoped abilities, revocable |
| Recovery | One-time recovery codes, stored encrypted |

> See also: 05.15-security.md for the platform-wide CSP, CSRF, and secret-handling rules that surround these auth flows.

# 9. Fortify Actions Implementation

## 9.1 Login Action

```php
<?php

declare(strict_types=1);

namespace App\Domains\Auth\Actions;

use App\Domains\Auth\Events\LoginSuccessful;
use App\Domains\Auth\Events\LoginFailed;
use App\Domains\Auth\Events\TwoFactorRequired;
use App\Domains\Users\Models\User;
use Illuminate\Support\Facades\Hash;
use Illuminate\Validation\ValidationException;

final class LoginAction
{
    public function execute(string $email, string $password, bool $remember = false): array
    {
        $user = User::where('email', $email)->first();

        if (! $user || ! Hash::check($password, $user->password)) {
            event(new LoginFailed($email));

            throw ValidationException::withMessages([
                'email' => ['The provided credentials do not match our records.'],
            ]);
        }

        if ($user->hasTwoFactorEnabled()) {
            event(new TwoFactorRequired($user));

            return [
                'requires_two_factor' => true,
                'two_factor_token' => encrypt($user->id),
            ];
        }

        event(new LoginSuccessful($user));

        return [
            'requires_two_factor' => false,
            'user' => $user,
            'remember' => $remember,
        ];
    }
}
```

## 9.3 Password Reset Action

```php
<?php

declare(strict_types=1);

namespace App\Domains\Auth\Actions;

use App\Domains\Auth\Events\PasswordResetSuccessful;
use App\Domains\Auth\Events\PasswordResetRequested;
use App\Domains\Users\Models\User;
use App\Domains\Users\Jobs\SendPasswordResetEmailJob;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Str;

final class PasswordResetAction
{
    public function requestReset(string $email): void
    {
        $user = User::where('email', $email)->first();

        if (! $user) {
            // Don't reveal whether the email exists
            return;
        }

        $token = Str::random(60);

        \DB::table('password_reset_tokens')->updateOrInsert(
            ['email' => $email],
            [
                'token' => Hash::make($token),
                'created_at' => now(),
            ]
        );

        event(new PasswordResetRequested($user));

        SendPasswordResetEmailJob::dispatch($user, $token);
    }

    public function reset(string $email, string $token, string $password): void
    {
        $resetRecord = \DB::table('password_reset_tokens')
            ->where('email', $email)
            ->first();

        if (! $resetRecord || ! Hash::check($token, $resetRecord->token)) {
            throw \Illuminate\Validation\ValidationException::withMessages([
                'email' => ['The reset token is invalid or has expired.'],
            ]);
        }

        if (now()->parse($resetRecord->created_at)->addHours(60)->isPast()) {
            throw \Illuminate\Validation\ValidationException::withMessages([
                'email' => ['The reset token has expired.'],
            ]);
        }

        $user = User::where('email', $email)->firstOrFail();

        $user->update([
            'password' => Hash::make($password),
        ]);

        // Delete the reset token
        \DB::table('password_reset_tokens')
            ->where('email', $email)
            ->delete();

        // Optionally revoke all tokens
        $user->tokens()->delete();

        event(new PasswordResetSuccessful($user));
    }
}
```

## 9.4 Email Verification Action

```php
<?php

declare(strict_types=1);

namespace App\Domains\Auth\Actions;

use App\Domains\Auth\Events\EmailVerified;
use App\Domains\Users\Models\User;

final class EmailVerificationAction
{
    public function execute(User $user, string $token): bool
    {
        if ($user->email_verified_at !== null) {
            return true; // already verified
        }

        if (! hash_equals($user->email_verification_token, $token)) {
            return false;
        }

        $user->update([
            'email_verified_at' => now(),
            'email_verification_token' => null,
        ]);

        event(new EmailVerified($user));

        return true;
    }
}
```

## 9.5 Two-Factor Authentication Action

```php
<?php

declare(strict_types=1);

namespace App\Domains\Auth\Actions;

use App\Domains\Auth\Events\TwoFactorEnabled;
use App\Domains\Auth\Events\TwoFactorDisabled;
use App\Domains\Users\Models\User;
use Illuminate\Support\Facades\Crypt;
use PragmaRX\Google2FA\Google2FA;

final class TwoFactorAction
{
    private Google2FA $google2fa;

    public function __construct()
    {
        $this->google2fa = new Google2FA();
    }

    public function enable(User $user): array
    {
        $secret = $this->generateSecret();

        return [
            'secret' => $secret,
            'qr_code' => $this->google2fa->getQRCodeUrl(
                config('app.name'),
                $user->email,
                $secret
            ),
            'recovery_codes' => $this->generateRecoveryCodes(),
        ];
    }

    public function confirm(User $user, string $code, string $secret, array $recoveryCodes): void
    {
        $valid = $this->google2fa->verifyKey($secret, $code);

        if (! $valid) {
            throw \Illuminate\Validation\ValidationException::withMessages([
                'code' => ['The two-factor code is invalid.'],
            ]);
        }

        $user->update([
            'two_factor_secret' => encrypt($secret),
            'two_factor_recovery_codes' => encrypt(json_encode($recoveryCodes)),
            'two_factor_enabled_at' => now(),
        ]);

        event(new TwoFactorEnabled($user));
    }

    public function disable(User $user, string $password): void
    {
        if (! \Hash::check($password, $user->password)) {
            throw \Illuminate\Validation\ValidationException::withMessages([
                'password' => ['The password is incorrect.'],
            ]);
        }

        $user->update([
            'two_factor_secret' => null,
            'two_factor_recovery_codes' => null,
            'two_factor_enabled_at' => null,
        ]);

        event(new TwoFactorDisabled($user));
    }

    public function verify(User $user, string $code): bool
    {
        $secret = decrypt($user->two_factor_secret);

        if ($this->google2fa->verifyKey($secret, $code)) {
            return true;
        }

        // Try recovery codes
        return $this->verifyRecoveryCode($user, $code);
    }

    private function generateSecret(): string
    {
        return $this->google2fa->generateSecretKey();
    }

    private function generateRecoveryCodes(): array
    {
        return array_map(
            fn () => strtoupper(Str::random(4) . '-' . Str::random(4)),
            range(1, 8)
        );
    }

    private function verifyRecoveryCode(User $user, string $code): bool
    {
        $codes = json_decode(decrypt($user->two_factor_recovery_codes), true);

        foreach ($codes as $index => $existingCode) {
            if (hash_equals($existingCode, $code)) {
                unset($codes[$index]);
                $user->update([
                    'two_factor_recovery_codes' => encrypt(json_encode(array_values($codes))),
                ]);
                return true;
            }
        }

        return false;
    }
}
```

# 10. Authentication Controllers

## 10.1 Login Controller

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Auth;

use App\Domains\Auth\Actions\LoginAction;
use App\Http\Controllers\Controller;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

final class LoginController extends Controller
{
    public function show()
    {
        return view('gsmui::auth.login');
    }

    public function store(Request $request, LoginAction $action)
    {
        $validated = $request->validate([
            'email' => ['required', 'email'],
            'password' => ['required', 'string'],
            'remember' => ['sometimes', 'boolean'],
        ]);

        $result = $action->execute(
            $validated['email'],
            $validated['password'],
            $validated['remember'] ?? false
        );

        if ($result['requires_two_factor']) {
            return redirect()->route('two-factor.challenge')
                ->with('two_factor_token', $result['two_factor_token']);
        }

        $user = $result['user'];

        Auth::login($user, $result['remember']);

        $request->session()->regenerate();

        return redirect()->intended(route('dashboard'));
    }

    public function logout(Request $request)
    {
        Auth::logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return redirect('/');
    }
}
```

# 11. Authentication Middleware

## 11.1 Session Regeneration Middleware

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

final class RegenerateSession
{
    public function handle(Request $request, Closure $next): Response
    {
        if (! $request->session()->has('last_activity')) {
            $request->session()->put('last_activity', now()->timestamp);
            return $next($request);
        }

        $lastActivity = $request->session()->get('last_activity');
        $timeout = config('auth.timeout', 120); // minutes

        if (now()->timestamp - $lastActivity > ($timeout * 60)) {
            auth('web')->logout();
            $request->session()->invalidate();
            $request->session()->regenerateToken();

            if ($request->expectsJson()) {
                return response()->json(['message' => 'Session expired.'], 401);
            }

            return redirect()->route('login')->with('status', 'Your session has expired.');
        }

        $request->session()->put('last_activity', now()->timestamp);

        return $next($request);
    }
}
```

# 14. Token Management Service

```php
<?php

declare(strict_types=1);

namespace App\Domains\Auth\Services;

use App\Domains\Users\Models\User;
use Laravel\Sanctum\PersonalAccessToken;

final class TokenService
{
    public function issueToken(User $user, string $name, array $abilities = ['*'], ?\Carbon\Carbon $expiresAt = null): string
    {
        $token = $user->createToken(
            name: $name,
            abilities: $abilities,
        );

        if ($expiresAt) {
            $token->accessToken->update(['expires_at' => $expiresAt]);
        }

        return $token->plainTextToken;
    }

    public function revokeToken(User $user, int $tokenId): bool
    {
        return (bool) $user->tokens()->where('id', $tokenId)->delete();
    }

    public function revokeAllTokens(User $user): int
    {
        return $user->tokens()->delete();
    }

    public function listTokens(User $user): \Illuminate\Database\Eloquent\Collection
    {
        return $user->tokens()
            ->select('id', 'name', 'abilities', 'last_used_at', 'expires_at', 'created_at')
            ->get();
    }

    public function refreshToken(User $user, int $tokenId): ?string
    {
        $token = $user->tokens()->find($tokenId);

        if (! $token) {
            return null;
        }

        $newToken = $user->createToken(
            name: $token->name,
            abilities: $token->abilities,
        );

        $token->delete();

        return $newToken->plainTextToken;
    }

    public function findValidToken(string $token): ?PersonalAccessToken
    {
        $accessToken = PersonalAccessToken::findToken($token);

        if (! $accessToken) {
            return null;
        }

        if ($accessToken->expires_at && $accessToken->expires_at->isPast()) {
            $accessToken->delete();
            return null;
        }

        return $accessToken;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\RateLimiter;
use Symfony\Component\HttpFoundation\Response;

final class ThrottleLoginAttempts
{
    public function handle(Request $request, Closure $next): Response
    {
        $key = 'login:' . ($request->input('email') ?: $request->ip());

        if (RateLimiter::tooManyAttempts($key, 5)) {
            $decayMinutes = RateLimiter::availableIn($key);

            if ($request->expectsJson()) {
                return response()->json([
                    'message' => "Too many login attempts. Try again in {$decayMinutes} minutes.",
                ], 429);
            }

            return back()->withErrors([
                'email' => "Too many login attempts. Try again in {$decayMinutes} minutes.",
            ]);
        }

        RateLimiter::hit($key, 60);

        return $next($request);
    }
}
```

# 19. Auth Security Checklist

| Check | Implementation |
| --- | --- |
| Password hashing | `Hash::make()` (bcrypt/argon), verified via `Hash::check()` |
| Brute-force protection | Fortify throttle + custom `ThrottleLoginAttempts` middleware |
| CSRF | Session guard has CSRF token; Sanctum tokens exempt |
| Session fixation | `$request->session()->regenerate()` after login |
| Session timeout | `RegenerateSession` middleware checks `last_activity` |
| Token leakage | Short-lived, scoped abilities, revocable, logged on use |
| Recovery | One-time recovery codes for 2FA, stored encrypted |
| Email verification | Required for sensitive actions, signed URLs |
| Password min length | 12 characters (configurable) |
| Rate limiting | Login: 5/min, Password reset: 3/min, Token issue: 5/min |
| Secure cookies | `HttpOnly`, `Secure`, `SameSite=Lax`, encrypted |
| Secret storage | `.env` only, never committed; encrypted at rest |

# 27. Logout & Session Invalidation

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use Illuminate\Http\Request;

final class LogoutController extends Controller
{
    public function logout(Request $request)
    {
        $user = $request->user();

        // Revoke current access token if using Sanctum
        if ($user && $request->user('sanctum')) {
            $user->currentAccessToken()->delete();
        }

        // Logout from session
        auth('web')->logout();

        // Invalidate session data
        $request->session()->invalidate();

        // Regenerate CSRF token
        $request->session()->regenerateToken();

        return redirect('/');
    }

    public function logoutAllDevices(Request $request)
    {
        $user = $request->user();

        // Revoke all tokens
        $user->tokens()->delete();

        // Clear all sessions for this user
        if (config('session.driver') === 'redis') {
            \Cache::tags("user_sessions:{$user->id}")->flush();
        }

        auth('web')->logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return redirect('/')->with('status', 'Logged out from all devices.');
    }
}
```

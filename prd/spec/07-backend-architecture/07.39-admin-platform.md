# 07.39 - Admin Platform

**Project:** GsmUi
**Architecture:** Admin Service Layer + RBAC
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `05.24-admin-platform-architecture.md` (admin modules, data flow, authorization model). This document is the *implementation contract*: the `ModerationService`, the content-flag and admin-note services, and the RBAC check used by the admin UI and the MCP moderation tools.

# Purpose

The Admin Platform centralizes privileged operations that span every domain: user management, content moderation, financial operations, and system administration. The web admin UI and the MCP moderation tools (`07.38-mcp-server.md`) both call the same services, so behavior is identical regardless of entry point. Services here are the only place moderation state transitions are allowed — models never flip their own `status`.

The platform is built around a `ModerationService` that owns the flag → review → decision state machine, an `AdminNoteService` for staff annotations, and a `ContentFlagService` for user/automated reports. Authorization is delegated to Spatie `Permission` roles + a `can()` RBAC check, never inline booleans. All state transitions emit events for the audit log and analytics.

Goals:

- A single, testable state machine for content moderation.
- Staff annotations (notes) stored separately from content, never mutating the source row.
- Every privileged action emits an `AdminAction` event for the audit trail.
- RBAC enforced at the service boundary via `AuthService::authorize`.

## 1. Moderation State Machine

Content (showcase projects, blog comments, components) moves through a fixed lifecycle. `ModerationService` is the only writer of `status`; it validates every transition and rejects illegal ones with `IllegalTransitionException`.

```text
pending ──► approved
   │
   └──────► rejected (reason required)
approved ──► flagged ──► (pending | rejected)
rejected ──► pending (appeal)
```

```php
namespace App\Domains\Admin\Enums;

enum ModerationStatus: string
{
    case Pending = 'pending';
    case Approved = 'approved';
    case Rejected = 'rejected';
    case Flagged = 'flagged';

    /** Legal next states for a given status. */
    public function next(): array
    {
        return match ($this) {
            self::Pending  => [self::Approved, self::Rejected],
            self::Approved => [self::Flagged],
            self::Flagged  => [self::Pending, self::Rejected],
            self::Rejected => [self::Pending],
        };
    }
}
```

## 2. Moderation Service

`ModerationService` loads the moderatable entity through a small `Moderatable` contract (so it works across domains), validates the transition, records the decision, and dispatches an event. It depends on the audit/log services, not on the request.

```php
namespace App\Domains\Admin\Services;

use App\Domains\Admin\Contracts\Moderatable;
use App\Domains\Admin\Enums\ModerationStatus;
use App\Domains\Admin\Events\ContentModerated;

final class ModerationService
{
    public function __construct(
        private readonly \App\Domains\Admin\Services\AuthService $auth,
        private readonly \App\Domains\Admin\Services\AuditService $audit,
    ) {}

    public function decide(Moderatable $entity, ModerationStatus $to, ?string $reason = null): void
    {
        $this->auth->authorize('moderate', $entity);

        $from = $entity->moderationStatus();
        if (! in_array($to, $from->next(), true)) {
            throw new \App\Domains\Admin\Exceptions\IllegalTransitionException($from, $to);
        }
        if ($to === ModerationStatus::Rejected && blank($reason)) {
            throw new \App\Domains\Admin\Exceptions\ReasonRequiredException();
        }

        $entity->applyModeration($to, reason: $reason, by: $this->auth->staffId());

        $this->audit->log('moderation.decide', [
            'entity' => $entity->moderationKey(),
            'from' => $from->value, 'to' => $to->value, 'reason' => $reason,
        ]);

        ContentModerated::dispatch($entity->moderationKey(), $to, $reason);
    }
}
```

The `Moderatable` contract lets one service moderate anything:

```php
namespace App\Domains\Admin\Contracts;

use App\Domains\Admin\Enums\ModerationStatus;

interface Moderatable
{
    public function moderationKey(): string;          // "showcase:123"
    public function moderationStatus(): ModerationStatus;
    public function applyModeration(ModerationStatus $to, ?string $reason, string $by): void;
}
```

Usage:

```php
$project = app(\App\Domains\Showcase\Repositories\ShowcaseRepository::class)->find($id);
app(\App\Domains\Admin\Services\ModerationService::class)
    ->decide($project, ModerationStatus::Approved);

// or reject with a reason
app(\App\Domains\Admin\Services\ModerationService::class)
    ->decide($project, ModerationStatus::Rejected, reason: 'Off-topic / spam');
```

## 3. Content Flag Service

Users and automated systems raise flags; `ContentFlagService` records them and auto-escalates when a threshold is reached. Flags are immutable records (no update/delete), and raising one never changes the moderated entity's status directly — escalation flows through `ModerationService`.

```php
namespace App\Domains\Admin\Services;

use App\Domains\Admin\Enums\FlagReason;

final class ContentFlagService
{
    public function __construct(
        private readonly \App\Domains\Admin\Repositories\ContentFlagRepository $flags,
        private readonly \App\Domains\Admin\Services\ModerationService $moderation,
    ) {}

    public function raise(string $entityKey, FlagReason $reason, ?string $reporterId, string $detail = ''): void
    {
        $flag = $this->flags->create([
            'entity_key' => $entityKey,
            'reason' => $reason,
            'reporter_id' => $reporterId,
            'detail' => $detail,
            'created_at' => now(),
        ]);

        $count = $this->flags->openCount($entityKey);
        if ($count >= config('admin.flag_escalation_threshold', 3)) {
            $entity = app(\App\Domains\Admin\Contracts\ModeratableLocator::class)->resolve($entityKey);
            if ($entity->moderationStatus()->value === 'approved') {
                $this->moderation->decide($entity, \App\Domains\Admin\Enums\ModerationStatus::Flagged);
            }
        }
    }
}
```

| Flag reason | Auto-action |
| --- | --- |
| `spam` | Counts toward escalation |
| `abuse` | Counts toward escalation, high priority |
| `copyright` | Counts toward escalation, legal queue |
| `duplicate` | Counts toward escalation |

## 4. Admin Note Service

Staff annotations are stored in a dedicated `admin_notes` table keyed by `entity_key`, keeping moderation reasoning out of the content row and preserving a full history. Notes are append-only; edits create a new note version.

```php
namespace App\Domains\Admin\Services;

final class AdminNoteService
{
    public function __construct(
        private readonly \App\Domains\Admin\Repositories\AdminNoteRepository $notes,
        private readonly \App\Domains\Admin\Services\AuthService $auth,
    ) {}

    public function add(string $entityKey, string $body, bool $internal = true): void
    {
        $this->auth->authorize('annotate', $entityKey);

        $this->notes->create([
            'entity_key' => $entityKey,
            'staff_id' => $this->auth->staffId(),
            'body' => $body,
            'internal' => $internal,
            'created_at' => now(),
        ]);
    }

    /** @return \App\Domains\Admin\Models\AdminNote[] */
    public function history(string $entityKey): array
    {
        return $this->notes->forEntity($entityKey);
    }
}
```

## 5. RBAC Authorization

Authorization uses Spatie `Permission` roles (`admin`, `moderator`, `support`, `finance`) plus the `AuthService` facade for service-level checks. The service throws `ForbiddenException` rather than returning booleans, forcing callers to handle denial explicitly.

```php
namespace App\Domains\Admin\Services;

final class AuthService
{
    public function staffId(): string
    {
        return (string) auth()->id();
    }

    public function authorize(string $ability, mixed $target = null): void
    {
        if (! auth()->user()?->can($ability, $target)) {
            throw new \App\Domains\Admin\Exceptions\ForbiddenException($ability);
        }
    }

    public function hasRole(string ...$roles): bool
    {
        return auth()->user()?->hasAnyRole($roles) ?? false;
    }
}
```

Permission matrix (Spatie roles → abilities):

| Role | Abilities |
| --- | --- |
| `admin` | `*` (all) |
| `moderator` | `moderate`, `annotate`, `view_flags` |
| `support` | `annotate`, `view_flags` |
| `finance` | `billing:read`, `billing:write` |

```text
      ├─ AuditService::log
      └─ ContentModerated event

            ├─► Audit table
```

```php
namespace App\Domains\Admin\Services;

final class AdminWidgetRenderer
{
    public function __construct(
        private readonly \App\Domains\Admin\Contracts\AdminWidgetRegistry $registry,
        private readonly \Illuminate\Contracts\Cache\Repository $cache,
    ) {}

    /** @return array<string, array> */
    public function renderForUser(string $userId): array
    {
        $widgets = $this->registry->forUser($userId);
        $results = [];

        foreach ($widgets as $widget) {
            $results[$widget->name()] = $this->cache->remember(
                $widget->cacheKey(),
                $widget->cacheTtl(),
                fn () => $widget->data()
            );
        }

        return $results;
    }

    public function refresh(string $widgetName): array
    {
        $widget = $this->registry->get($widgetName);
        $this->cache->forget($widget->cacheKey());
        return $widget->data();
    }
}
```

## 8. Bulk Operations

Admin bulk operations apply actions to multiple entities at once, with proper authorization and audit logging.

```php
namespace App\Domains\Admin\Services;

final class BulkOperationService
{
    public function __construct(
        private readonly \App\Domains\Admin\Services\AuthService $auth,
        private readonly \App\Domains\Admin\Services\AuditService $audit,
    ) {}

    public function moderate(array $entityIds, string $entityType, ModerationStatus $status, ?string $reason = null): BulkResult
    {
        $this->auth->authorize('moderate.bulk');

        $results = ['success' => 0, 'failed' => 0, 'errors' => []];

        foreach ($entityIds as $id) {
            try {
                $entity = $this->resolveEntity($entityType, $id);
                app(ModerationService::class)->decide($entity, $status, $reason);
                $results['success']++;
            } catch (\Throwable $e) {
                $results['failed']++;
                $results['errors'][] = ['id' => $id, 'error' => $e->getMessage()];
            }
        }

        $this->audit->log('bulk.moderate', [
            'entity_type' => $entityType,
            'entity_ids' => $entityIds,
            'status' => $status->value,
            'reason' => $reason,
            'results' => $results,
        ]);

        return new BulkResult(
            total: count($entityIds),
            success: $results['success'],
            failed: $results['failed'],
            errors: $results['errors'],
        );
    }

    public function delete(array $entityIds, string $entityType): BulkResult
    {
        $this->auth->authorize('delete.bulk');

        $results = ['success' => 0, 'failed' => 0, 'errors' => []];

        foreach ($entityIds as $id) {
            try {
                $entity = $this->resolveEntity($entityType, $id);
                $entity->delete();
                $results['success']++;
            } catch (\Throwable $e) {
                $results['failed']++;
                $results['errors'][] = ['id' => $id, 'error' => $e->getMessage()];
            }
        }

        $this->audit->log('bulk.delete', [
            'entity_type' => $entityType,
            'entity_ids' => $entityIds,
            'results' => $results,
        ]);

        return new BulkResult(
            total: count($entityIds),
            success: $results['success'],
            failed: $results['failed'],
            errors: $results['errors'],
        );
    }

    private function resolveEntity(string $type, int $id): \Illuminate\Database\Eloquent\Model
    {
        return match ($type) {
            'showcase' => \App\Domains\Showcase\Models\ShowcaseProject::findOrFail($id),
            'post' => \App\Domains\Blog\Models\Post::findOrFail($id),
            'comment' => \App\Domains\Blog\Models\Comment::findOrFail($id),
            default => throw new \InvalidArgumentException("Unknown entity type: {$type}"),
        };
    }
}

final readonly class BulkResult
{
    public function __construct(
        public int $total,
        public int $success,
        public int $failed,
        public array $errors,
    ) {}
}
```

### 9.2 Data Import

```php
namespace App\Domains\Admin\Services;

final class AdminImportService
{
    public function importUsers(string $filePath, string $format): \App\Domains\Admin\Data\ImportResult
    {
        $data = match ($format) {
            'csv' => $this->parseCsv($filePath),
            'json' => json_decode(file_get_contents($filePath), true),
            default => throw new \InvalidArgumentException("Unsupported format: {$format}"),
        };

        $results = ['created' => 0, 'skipped' => 0, 'errors' => []];

        foreach ($data as $row) {
            try {
                if (\App\Models\User::where('email', $row['email'])->exists()) {
                    $results['skipped']++;
                    continue;
                }

                \App\Models\User::create([
                    'name' => $row['name'],
                    'email' => $row['email'],
                    'password' => bcrypt(Str::random(16)),
                ]);
                $results['created']++;
            } catch (\Throwable $e) {
                $results['errors'][] = ['email' => $row['email'] ?? 'unknown', 'error' => $e->getMessage()];
            }
        }

        return new \App\Domains\Admin\Data\ImportResult(
            total: count($data),
            created: $results['created'],
            skipped: $results['skipped'],
            errors: $results['errors'],
        );
    }

    private function parseCsv(string $filePath): array
    {
        $handle = fopen($filePath, 'r');
        $headers = fgetcsv($handle);
        $data = [];

        while (($row = fgetcsv($handle)) !== false) {
            $data[] = array_combine($headers, $row);
        }

        fclose($handle);
        return $data;
    }
}
```

## 10. System Health Monitoring

### 10.1 Health Check Service

```php
namespace App\Domains\Admin\Services;

final class SystemHealthService
{
    public function __construct(
        private readonly \Illuminate\Contracts\Cache\Repository $cache,
    ) {}

    public function check(): SystemHealthReport
    {
        return new SystemHealthReport(
            database: $this->checkDatabase(),
            cache: $this->checkCache(),
            queue: $this->checkQueue(),
            storage: $this->checkStorage(),
            ai_providers: $this->checkAiProviders(),
            search: $this->checkSearch(),
        );
    }

    private function checkDatabase(): ComponentHealth
    {
        try {
            $start = microtime(true);
            DB::select('SELECT 1');
            $latency = (int) ((microtime(true) - $start) * 1000);

            return new ComponentHealth(
                name: 'database',
                status: $latency < 100 ? 'healthy' : 'degraded',
                latencyMs: $latency,
                details: ['connection' => config('database.default')],
            );
        } catch (\Throwable $e) {
            return new ComponentHealth(
                name: 'database',
                status: 'unhealthy',
                error: $e->getMessage(),
            );
        }
    }

    private function checkCache(): ComponentHealth
    {
        try {
            $start = microtime(true);
            $key = 'health:check:' . Str::random(8);
            $this->cache->put($key, true, 10);
            $value = $this->cache->get($key);
            $this->cache->forget($key);
            $latency = (int) ((microtime(true) - $start) * 1000);

            return new ComponentHealth(
                name: 'cache',
                status: $value ? 'healthy' : 'degraded',
                latencyMs: $latency,
            );
        } catch (\Throwable $e) {
            return new ComponentHealth(
                name: 'cache',
                status: 'unhealthy',
                error: $e->getMessage(),
            );
        }
    }

    private function checkQueue(): ComponentHealth
    {
        try {
            $depth = app(\Illuminate\Queue\QueueManager::class)
                ->connection(config('queue.default'))
                ->size();

            return new ComponentHealth(
                name: 'queue',
                status: $depth < 1000 ? 'healthy' : ($depth < 5000 ? 'degraded' : 'unhealthy'),
                details: ['depth' => $depth],
            );
        } catch (\Throwable $e) {
            return new ComponentHealth(
                name: 'queue',
                status: 'unhealthy',
                error: $e->getMessage(),
            );
        }
    }

    private function checkStorage(): ComponentHealth
    {
        $freeBytes = disk_free_space(storage_path());
        $totalBytes = disk_total_space(storage_path());
        $usedPercent = $totalBytes > 0 ? (1 - $freeBytes / $totalBytes) * 100 : 0;

        return new ComponentHealth(
            name: 'storage',
            status: $usedPercent < 80 ? 'healthy' : ($usedPercent < 95 ? 'degraded' : 'unhealthy'),
            details: [
                'free_mb' => round($freeBytes / 1024 / 1024),
                'used_percent' => round($usedPercent, 1),
            ],
        );
    }

    private function checkAiProviders(): ComponentHealth
    {
        try {
            $results = app(\App\Domains\Ai\Services\AiProviderHealthMonitor::class)->checkAll();
            $allHealthy = collect($results)->every(fn ($r) => $r->healthy);

            return new ComponentHealth(
                name: 'ai_providers',
                status: $allHealthy ? 'healthy' : 'degraded',
                details: $results,
            );
        } catch (\Throwable $e) {
            return new ComponentHealth(
                name: 'ai_providers',
                status: 'unhealthy',
                error: $e->getMessage(),
            );
        }
    }

    private function checkSearch(): ComponentHealth
    {
        try {
            // Test Meilisearch connection
            $start = microtime(true);
            // $client->health();
            $latency = (int) ((microtime(true) - $start) * 1000);

            return new ComponentHealth(
                name: 'search',
                status: 'healthy',
                latencyMs: $latency,
            );
        } catch (\Throwable $e) {
            return new ComponentHealth(
                name: 'search',
                status: 'unhealthy',
                error: $e->getMessage(),
            );
        }
    }
}

final readonly class SystemHealthReport
{
    public function __construct(
        public ComponentHealth $database,
        public ComponentHealth $cache,
        public ComponentHealth $queue,
        public ComponentHealth $storage,
        public ComponentHealth $ai_providers,
        public ComponentHealth $search,
    ) {}

    public function overallStatus(): string
    {
        $statuses = [
            $this->database->status,
            $this->cache->status,
            $this->queue->status,
            $this->storage->status,
            $this->ai_providers->status,
            $this->search->status,
        ];

        if (in_array('unhealthy', $statuses)) return 'unhealthy';
        if (in_array('degraded', $statuses)) return 'degraded';
        return 'healthy';
    }
}

final readonly class ComponentHealth
{
    public function __construct(
        public string $name,
        public string $status, // 'healthy', 'degraded', 'unhealthy'
        public ?int $latencyMs = null,
        public ?string $error = null,
        public ?array $details = null,
    ) {}
}
```

```php
namespace App\Domains\Admin\Services;

final class CacheManagementService
{
    public function stats(): CacheStats
    {
        $stores = config('cache.stores');
        $stats = [];

        foreach (array_keys($stores) as $store) {
            try {
                $manager = cache()->store($store);
                $stats[$store] = [
                    'driver' => config("cache.stores.{$store}.driver"),
                    'prefix' => config("cache.stores.{$store}.prefix", ''),
                ];
            } catch (\Throwable $e) {
                $stats[$store] = ['error' => $e->getMessage()];
            }
        }

        return new CacheStats(stores: $stats);
    }

    public function flush(string $store = null): void
    {
        if ($store) {
            cache()->store($store)->flush();
        } else {
            cache()->flush();
        }
    }

    public function forgetKey(string $key, string $store = null): bool
    {
        $cache = $store ? cache()->store($store) : cache();
        return $cache->forget($key);
    }

    /** Warm critical caches (dashboard, menus, components) */
    public function warm(): void
    {
        // Pre-warm menu cache
        app(\App\Domains\Cms\Services\MenuService::class)->resolve('primary');

        // Pre-warm component registry
```

```php
namespace App\Domains\Admin\Services;

final class LogViewerService
{
    private const LOG_PATH = 'logs/';

    public function files(): array
    {
        $path = storage_path(self::LOG_PATH);
        $files = [];

        foreach (glob($path . '*.log') as $file) {
            $files[] = [
                'name' => basename($file),
                'size' => filesize($file),
                'modified' => date('Y-m-d H:i:s', filemtime($file)),
            ];
        }

        return collect($files)->sortByDesc('modified')->values()->all();
    }

    public function read(string $file, int $lines = 100, ?string $filter = null): array
    {
        $path = storage_path(self::LOG_PATH . $file);

        if (! file_exists($path)) {
            throw new \InvalidArgumentException("Log file not found: {$file}");
        }

        $handle = fopen($path, 'r');
        $logLines = [];
        $totalLines = 0;

        // Read from end of file
        fseek($handle, 0, SEEK_END);
        $fileSize = ftell($handle);

        $buffer = '';
        $position = $fileSize;

        while ($position > 0 && count($logLines) < $lines) {
            $readSize = min(8192, $position);
            $position -= $readSize;
            fseek($handle, $position);
            $buffer = fread($handle, $readSize) . $buffer;

            $logLines = explode("\n", $buffer);
            array_shift($logLines); // Remove first (partial) line
        }

        fclose($handle);

        if ($filter) {
            $logLines = array_filter($logLines, fn ($line) => str_contains($line, $filter));
        }

        return array_reverse(array_slice($logLines, 0, $lines));
    }

    public function tail(string $file, int $lines = 50): array
    {
        return $this->read($file, $lines);
    }
}
```

```php
namespace App\Domains\Admin\Services;

final class AdminTwoFactorService
{
    public function __construct(
        private readonly \App\Domains\Admin\Services\AuthService $auth,
    ) {}

    public function enable(string $userId, string $secret, string $code): void
    {
        $this->auth->authorize('2fa:manage');

        // Verify the TOTP code against the secret
        $google2fa = new \PragmaRX\Google2FA\Google2FA();
        if (! $google2fa->verifyKey($secret, $code)) {
            throw new \App\Domains\Admin\Exceptions\InvalidTwoFactorCodeException();
        }

        \App\Models\User::where('id', $userId)->update([
            'two_factor_secret' => encrypt($secret),
            'two_factor_enabled_at' => now(),
        ]);
    }

    public function disable(string $userId, string $code): void
    {
        $this->auth->authorize('2fa:manage');

        $user = \App\Models\User::findOrFail($userId);
        $google2fa = new \PragmaRX\Google2FA\Google2FA();

        if (! $google2fa->verifyKey(decrypt($user->two_factor_secret), $code)) {
            throw new \App\Domains\Admin\Exceptions\InvalidTwoFactorCodeException();
        }

        $user->update([
            'two_factor_secret' => null,
            'two_factor_enabled_at' => null,
        ]);
    }

    public function generateRecoveryCodes(string $userId): array
    {
        $this->auth->authorize('2fa:manage');

        $codes = [];
        for ($i = 0; $i < 10; $i++) {
            $codes[] = strtoupper(Str::random(4) . '-' . Str::random(4));
        }

        \App\Models\User::where('id', $userId)->update([
            'two_factor_recovery_codes' => encrypt(json_encode($codes)),
        ]);

        return $codes;
    }

    public function verifyRecoveryCode(string $userId, string $code): bool
    {
        $user = \App\Models\User::findOrFail($userId);
        $codes = json_decode(decrypt($user->two_factor_recovery_codes), true);

        if (in_array($code, $codes)) {
            // Remove used code
            $codes = array_diff($codes, [$code]);
            $user->update(['two_factor_recovery_codes' => encrypt(json_encode(array_values($codes)))]);
            return true;
        }

        return false;
    }
}
```

```php
                    'from' => $event->old_values[$key] ?? null,
                    'to' => $event->new_values[$key] ?? null,
```

```php
            'fields' => ['title', 'description', 'url'],
            'label' => 'Showcases',
            'icon' => 'star',
        ],
        'posts' => [
            'model' => \App\Domains\Blog\Models\BlogPost::class,
            'fields' => ['title', 'slug', 'excerpt'],
            'label' => 'Blog Posts',
            'icon' => 'document-text',
        ],
    ];

    public function search(string $query, ?string $type = null, int $limit = 10): array
    {
        $results = [];
        $targets = $type ? [$type => self::SEARCHABLE[$type]] : self::SEARCHABLE;

        foreach ($targets as $typeKey => $config) {
            $model = new $config['model'];
            $results[$typeKey] = [
                'label' => $config['label'],
                'icon' => $config['icon'],
                'items' => $this->searchModel($model, $config['fields'], $query, $limit),
            ];
        }

        return $results;
    }

    private function searchModel($model, array $fields, string $query, int $limit): array
    {
        return $model::query()
            ->where(function ($q) use ($fields, $query) {
                foreach ($fields as $i => $field) {
                    $method = $i === 0 ? 'where' : 'orWhere';
                    $q->{$method}($field, 'LIKE', "%{$query}%");
                }
            })
            ->limit($limit)
            ->get()
            ->map(fn ($item) => [
                'id' => $item->id,
                'title' => $item->name ?? $item->title ?? $item->email ?? 'Unknown',
                'subtitle' => $item->email ?? $item->slug ?? $item->description ?? '',
                'url' => $item->url ?? route('admin.' . class_basename($item) . '.show', $item->id),
            ])
            ->toArray();
    }
```

```php
final class UserFilterService
{
    public function apply(\Illuminate\Database\Eloquent\Builder $query, array $filters): \Illuminate\Database\Eloquent\Builder
    {
        if (isset($filters['search'])) {
            $search = $filters['search'];
            $query->where(function ($q) use ($search) {
                $q->where('name', 'LIKE', "%{$search}%")
                  ->orWhere('email', 'LIKE', "%{$search}%")
                  ->orWhere('username', 'LIKE', "%{$search}%");
            });
        }

        if (isset($filters['status'])) {
            $query->where('status', $filters['status']);
        }

        if (isset($filters['role'])) {
            $query->whereHas('roles', fn ($q) => $q->where('slug', $filters['role']));
        }

        if (isset($filters['registered_after'])) {
            $query->where('created_at', '>=', $filters['registered_after']);
        }

        if (isset($filters['registered_before'])) {
            $query->where('created_at', '<=', $filters['registered_before']);
        }

        if (isset($filters['has_snippets'])) {
            $query->has('snippets');
        }

        if (isset($filters['has_verified_email'])) {
            if ($filters['has_verified_email']) {
                $query->whereNotNull('email_verified_at');
            } else {
                $query->whereNull('email_verified_at');
            }
        }

        return $query;
    }

    public function sort(\Illuminate\Database\Eloquent\Builder $query, string $column, string $direction = 'desc'): \Illuminate\Database\Eloquent\Builder
    {
        $allowed = ['name', 'email', 'created_at', 'snippets_count', 'last_active_at'];
        $column = in_array($column, $allowed) ? $column : 'created_at';
        $direction = in_array(strtolower($direction), ['asc', 'desc']) ? $direction : 'desc';

        return $query->orderBy($column, $direction);
    }
```

### 31.2 Suspend Users Action

```php
namespace App\Domains\Admin\Services\BulkActions;

final class SuspendUsersAction
{
    public function __construct(
        private readonly \App\Domains\Admin\Services\AdminAuditService $audit,
    ) {}

    public function execute(array $userIds, string $adminId, ?string $reason = null): BulkActionResult
    {
        $suspended = 0;
        $failed = 0;

        \Illuminate\Support\Facades\DB::transaction(function () use ($userIds, $adminId, $reason, &$suspended, &$failed) {
            foreach ($userIds as $userId) {
                try {
                    $user = \App\Models\User::findOrFail($userId);

                    if ($user->id === $adminId) {
                        $failed++;
                        continue;
                    }

                    $old = ['status' => $user->status];
                    $user->update(['status' => 'suspended']);
                    $new = ['status' => 'suspended'];

                    $this->audit->record($adminId, 'user.suspended', 'User', $userId, $old, $new, ['reason' => $reason]);
                    $suspended++;
                } catch (\Throwable $e) {
                    $failed++;
                }
            }
        });

        return new BulkActionResult($suspended, $failed);
    }
}
```

```php
namespace App\Domains\Admin\Services;

final class AdminBackupService
{
    public function __construct(
        private readonly \Illuminate\Filesystem\FilesystemManager $filesystem,
    ) {}

    public function createFullBackup(): BackupResult
    {
        $startedAt = now();
        $backupId = $this->generateBackupId();

        try {
            $databases = $this->backupDatabases($backupId);
            $uploads = $this->backupUploads($backupId);
            $config = $this->backupConfig($backupId);

            $duration = $startedAt->diffInSeconds(now());

            return new BackupResult(
                backupId: $backupId,
                status: 'success',
                sizeBytes: $this->getBackupSize($backupId),
                durationSeconds: $duration,
                databases: $databases,
                uploads: $uploads,
                config: $config,
            );
        } catch (\Throwable $e) {
            return new BackupResult(
                backupId: $backupId,
                status: 'failed',
                sizeBytes: 0,
                durationSeconds: $startedAt->diffInSeconds(now()),
                databases: [],
                uploads: false,
                config: false,
                error: $e->getMessage(),
            );
        }
    }

    public function restoreFromBackup(string $backupId): bool
    {
        $this->restoreDatabases($backupId);
        $this->restoreUploads($backupId);
        return true;
    }

    public function listBackups(): array
    {
        return $this->filesystem->disk('backups')
            ->files('admin')
            ->map(fn ($file) => [
                'name' => $file->getFilename(),
                'size' => $file->getSize(),
                'created_at' => $file->lastModified(),
            ])
            ->sortByDesc('created_at')
            ->values()
            ->toArray();
    }

    private function generateBackupId(): string
    {
        return 'backup_' . now()->format('Y-m-d_His') . '_' . bin2hex(random_bytes(4));
    }

    private function backupDatabases(string $backupId): array
    {
        $tables = \Illuminate\Support\Facades\DB::select('SHOW TABLES');
        $backed = [];

        foreach ($tables as $table) {
            $tableName = array_values((array) $table)[0];
            $sql = \Illuminate\Support\Facades\DB::select("SHOW CREATE TABLE {$tableName}");
            $backed[] = $tableName;
        }

        return $backed;
    }

    private function backupUploads(string $backupId): bool
    {
        return true;
    }

    private function backupConfig(string $backupId): bool
    {
        return true;
    }

    private function getBackupSize(string $backupId): int
    {
        return 0;
    }

    private function restoreDatabases(string $backupId): void {}

    private function restoreUploads(string $backupId): void {}
}

final readonly class BackupResult
{
    public function __construct(
        public string $backupId,
        public string $status,
        public int $sizeBytes,
        public int $durationSeconds,
        public array $databases,
        public bool $uploads,
        public bool $config,
        public ?string $error = null,
    ) {}
}
```

# 07.35 - Documentation Engine

**Project:** GsmUi
**Architecture:** Doc Render Pipeline + Search Indexing
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.18-docs-engine.md` for the conceptual documentation architecture, and `06.70-documentation.md` (`documentation_pages`, `documentation_sections`, `documentation_versions`) + `06.71-doc-pages.md` for the persistence schema. This document specifies the **implementation contract** — the `DocRenderer` service, the markdown→block parsing pipeline, the search-indexing hook, and DI binding. It does NOT re-spec the schema.

The Documentation Engine is a structured knowledge platform, not a pile of Markdown. A `DocumentationPage` is parsed into front-matter metadata + an ordered tree of content blocks; those blocks render to Blade/Livewire (with interactive component examples delegated to the Component Engine `07.33`), and the page is indexed into Meilisearch (`07.24-search.md`) on publish. Component API docs are generated from component metadata (`07.33`) so there is no duplicated hand-written reference.

The goals of this contract are:

- Expose one `DocRenderer` that turns a `DocumentationPage` into rendered HTML + navigation metadata.
- Parse Markdown into a block tree (headings, admonitions, code fences, tabs) before rendering.
- Hook each published page into the search index via the `SearchService` from `07.24-search.md`.
- Generate component API docs from `ComponentRegistry.metadata()` rather than static files.
- Cache rendered HTML and invalidate on publish.

## 2. The `DocRenderer` Contract

`DocRenderer` parses a page and returns rendered HTML plus the metadata needed for navigation and search. It depends on the markdown parser, the component-doc generator, and (for indexing) the search service.

```php
namespace App\Domains\Docs\Contracts;

use App\Domains\Docs\Data\RenderedDoc;
use App\Models\DocumentationPage;

interface DocRenderer
{
    /**
     * Parse + render a documentation page to HTML.
     * Pure with respect to search/index side effects.
     */
    public function render(DocumentationPage $page): RenderedDoc;

    /** Index a published page into Meilisearch (see 07.24-search.md). */
    public function index(DocumentationPage $page): void;

    /** Remove a page from the search index (archive/unpublish). */
    public function unindex(DocumentationPage $page): void;
}
```

## 3. Markdown → Block Parsing

`MarkdownParser` + `FrontMatterExtractor` split a page source into front matter and an ordered block tree. Each block carries a type and payload so the renderer can map it to a Blade partial (admonition, tab group, code fence with copy button, etc.).

```php
namespace App\Domains\Docs\Support;

use App\Domains\Docs\Data\DocBlock;

interface MarkdownParser
{
    /** Returns ordered DocBlock[] from raw markdown body. */
    public function parse(string $body): array;

    /** Extracts + removes YAML front matter; returns [metadata, body]. */
    public function extractFrontMatter(string $source): array;
}
```

## 4. Example Service: Doc Renderer Manager

The manager extracts front matter, parses blocks, renders each block (delegating interactive component examples to `ComponentRenderer`), and assembles navigation metadata. `index()` maps the page into the `SearchService` shape from `07.24-search.md`.

```php
namespace App\Domains\Docs\Services;

use App\Domains\Components\Contracts\ComponentRenderer;
use App\Domains\Docs\Contracts\DocRenderer;
use App\Domains\Docs\Data\DocBlock;
use App\Domains\Docs\Data\RenderedDoc;
use App\Domains\Docs\Support\{MarkdownParser, ComponentDocGenerator};
use App\Domains\Search\Services\SearchService;
use App\Models\DocumentationPage;

final class DocRendererManager implements DocRenderer
{
    public function __construct(
        private MarkdownParser $parser,
        private ComponentDocGenerator $componentDocs,
        private ComponentRenderer $components,
        private SearchService $search,
    ) {}

    public function render(DocumentationPage $page): RenderedDoc
    {
        [$meta, $body] = $this->parser->extractFrontMatter($page->source);

        $html = '';
        foreach ($this->parser->parse($body) as $block) {
            $html .= $this->renderBlock($block);
        }

        return new RenderedDoc(
            html: $html,
            title: $meta['title'] ?? $page->title,
            section: $page->category,
            version: $page->version,
        );
    }

    private function renderBlock(DocBlock $block): string
    {
        if ($block->type === 'component-example') {
            // Pull live example from component metadata (no static duplication).
            return $this->components->renderNamed(
                $block->payload['component'],
                $block->payload['props'] ?? []
            )->html;
        }

        return view("docs.blocks.{$block->type}", $block->payload)->render();
    }

    public function index(DocumentationPage $page): void
    {
        $this->search->index('gsmui_docs', [
            'id' => $page->id,
            'title' => $page->title,
            'content' => strip_tags($this->render($page)->html),
            'section' => $page->category,
            'version' => $page->version,
        ]);
    }

    public function unindex(DocumentationPage $page): void
    {
        $this->search->remove('gsmui_docs', $page->id);
    }
}
```

## 5. Search Indexing Hook

Indexing is queued and idempotent. `PublishDocPageAction` dispatches `IndexDocPage` after commit; the job calls `DocRenderer::index()`. Soft-draft/archived pages are excluded via `shouldBeSearchable()` (`07.24-search.md` §4).

```text
PublishDocPageAction::run(page)
        │  DB::transaction
        ├─ set status = published, published_at = now
        ├─ cache rendered HTML
        └─ dispatchAfterCommit(DocPagePublished)
                    │
                    ▼
        IndexDocPage job → DocRenderer::index(page) → SearchService → Meilisearch
```

## 8. Reuse Rules

A doc service MAY:

- Parse markdown; render blocks; generate component API docs from metadata.
- Cache rendered HTML; index/unindex pages via `SearchService` (`07.24`).
- Delegate interactive examples to `ComponentRenderer` (`07.33`).

A doc service MUST NOT:

- Store raw HTML as the source of truth (store Markdown; render on demand/cache).
- Index drafts/archived pages.
- Re-implement component API docs by hand (use `ComponentDocGenerator`).

| Concern | Owner |
| --- | --- |
| Search index | `SearchService` (`07.24`) |
| Component examples | `ComponentRenderer` (`07.33`) |
| Theme tokens | `ThemeCompiler` (`07.32`) |
| Live playground links | Playground (`07.36`) |

# 11. Markdown Parser

## 11.1 Front Matter Extraction

```php
final class FrontMatterExtractor
{
    public function extract(string $source): array
    {
        $pattern = '/^---\n(.+?)\n---\n(.*)/s';

        if (!preg_match($pattern, $source, $matches)) {
            return [
                'metadata' => [],
                'body' => $source,
            ];
        }

        $metadata = yaml_parse($matches[1]) ?? [];
        $body = $matches[2];

        return [
            'metadata' => $metadata,
            'body' => $body,
        ];
    }
}
```

## 11.2 Markdown to Block Parser

```php
final class MarkdownBlockParser implements MarkdownParser
{
    public function parse(string $body): array
    {
        $blocks = [];
        $lines = explode("\n", $body);
        $currentBlock = null;

        foreach ($lines as $line) {
            // Heading
            if (preg_match('/^(#{1,6})\s+(.+)$/', $line, $matches)) {
                $blocks[] = [
                    'type' => 'heading',
                    'payload' => [
                        'text' => $matches[2],
                        'level' => strlen($matches[1]),
                    ],
                ];
                continue;
            }

            // Code fence
            if (preg_match('/^```(\w+)?/', $line, $matches)) {
                $language = $matches[1] ?? 'text';
                $code = $this->collectCodeBlock($lines);
                $blocks[] = [
                    'type' => 'code',
                    'payload' => [
                        'language' => $language,
                        'code' => $code,
                    ],
                ];
                continue;
            }

            // Admonition
            if (preg_match('/^:::(\w+)\s*(.*)$/', $line, $matches)) {
                $content = $this->collectAdmonition($lines, $matches[1]);
                $blocks[] = [
                    'type' => 'admonition',
                    'payload' => [
                        'type' => $matches[1],
                        'content' => $content,
                    ],
                ];
                continue;
            }

            // Component example
            if (preg_match('/^<x-docs\.example\s+component="(\w+)"/', $line, $matches)) {
                $props = $this->extractProps($line);
                $blocks[] = [
                    'type' => 'component-example',
                    'payload' => [
                        'component' => $matches[1],
                        'props' => $props,
                    ],
                ];
                continue;
            }

            // Paragraph
            if (!empty(trim($line))) {
                $blocks[] = [
                    'type' => 'paragraph',
                    'payload' => ['text' => $line],
                ];
            }
        }

        return $blocks;
    }
}
```

# 12. Component API Documentation Generator

## 12.1 Documentation Sections

```php
final class ComponentDocGenerator
{
    public function generate(string $componentName): array
    {
        $metadata = app(ComponentRegistry::class)->metadata($componentName);

        if (!$metadata) {
            throw new \InvalidArgumentException("Component '{$componentName}' not found");
        }

        return [
            'overview' => $this->generateOverview($metadata),
            'installation' => $this->generateInstallation($metadata),
            'props' => $this->generateProps($metadata['props']),
            'slots' => $this->generateSlots($metadata['slots']),
            'events' => $this->generateEvents($metadata['events']),
            'variants' => $this->generateVariants($metadata['variants']),
            'accessibility' => $this->generateAccessibility($metadata['accessibility']),
            'examples' => $this->generateExamples($metadata['examples']),
            'changelog' => $this->generateChangelog($metadata),
            'migration' => $this->generateMigration($metadata),
        ];
    }

    private function generateProps(array $props): string
    {
        $lines = [
            '## Props',
            '',
            '| Prop | Type | Default | Required | Description |',
            '| --- | --- | --- | --- | --- |',
        ];

        foreach ($props as $prop) {
            $default = $prop['default'] ?? '—';
            $required = $prop['required'] ? 'Yes' : 'No';
            $options = isset($prop['options']) ? ' Options: `' . implode('`, `', $prop['options']) . '`' : '';

            $lines[] = "| `{$prop['name']}` | `{$prop['type']}` | `{$default}` | {$required} | {$prop['description']}{$options} |";
        }

        return implode("\n", $lines);
    }

    private function generateVariants(array $variants): string
    {
        $lines = [
            '## Variants',
            '',
            'The component supports the following variants:',
            '',
        ];

        foreach ($variants as $variant) {
            $lines[] = "- **`{$variant['name']}`**: {$variant['description']}";
        }

        return implode("\n", $lines);
    }
}
```

## 13.2 Index Mapping

final class DocSearchIndexer
{
    public function index(DocumentationPage $page): void
    {
        $rendered = app(DocRenderer::class)->render($page);

        $document = [
            'id' => $page->id,
            'title' => $page->title,
            'content' => strip_tags($rendered->html),
            'section' => $page->category,
            'version' => $page->version,
            'category' => $page->type,
            'created_at' => $page->created_at->timestamp,
            'updated_at' => $page->updated_at->timestamp,
        ];

        app(SearchService::class)->index('gsmui_docs', $document);
    }

    public function unindex(DocumentationPage $page): void
    {
        app(SearchService::class)->remove('gsmui_docs', $page->id);
    }

    public function rebuild(): void
    {
        $pages = DocumentationPage::where('status', 'published')->get();

        foreach ($pages as $page) {
            $this->index($page);
        }
    }
}
```

## 13.3 Search Query Service

```php
final class DocSearchService
{
    public function search(string $query, array $filters = []): array
    {
        return app(SearchService::class)->search('gsmui_docs', [
            'q' => $query,
            'filter' => $this->buildFilters($filters),
            'limit' => $filters['limit'] ?? 20,
            'offset' => $filters['offset'] ?? 0,
        ]);
    }

    private function buildFilters(array $filters): array
    {
        $filterParts = [];

        if (isset($filters['section'])) {
            $filterParts[] = "section = '{$filters['section']}'";
        }

        if (isset($filters['version'])) {
            $filterParts[] = "version = '{$filters['version']}'";
        }

        if (isset($filters['category'])) {
            $filterParts[] = "category = '{$filters['category']}'";
        }

        return $filterParts;
    }
}
```

// app/Livewire/Docs/DocEditor.php
final class DocEditor extends Component
{
    public ?DocumentationPage $page = null;
    public string $title = '';
    public string $source = '';
    public string $type = 'guide';
    public string $category = 'general';
    public bool $isDirty = false;

    public function mount(?int $pageId = null): void
    {
        if ($pageId) {
            $this->page = DocumentationPage::find($pageId);
            $this->title = $this->page->title;
            $this->source = $this->page->source;
            $this->type = $this->page->type;
            $this->category = $this->page->category;
        }
    }

    public function updatedSource(): void
    {
        $this->isDirty = true;
        $this->dispatch('source-updated', html: $this->renderPreview());
    }

    public function save(): void
    {
        if (!$this->page) {
            $this->page = DocumentationPage::create([
                'author_id' => auth()->id(),
                'title' => $this->title,
                'slug' => Str::slug($this->title),
                'type' => $this->type,
                'category' => $this->category,
                'source' => $this->source,
                'status' => 'draft',
            ]);
        } else {
            $this->page->update([
                'title' => $this->title,
                'source' => $this->source,
                'type' => $this->type,
                'category' => $this->category,
            ]);
        }

        $this->isDirty = false;
        $this->dispatch('page-saved', pageId: $this->page->id);
    }

    public function publish(): void
    {
        $this->save();

        if ($this->page) {
            $this->page->update([
                'status' => 'published',
                'published_at' => now(),
            ]);

            // Index in search
            app(DocRenderer::class)->index($this->page);

            $this->dispatch('page-published', pageId: $this->page->id);
        }
    }

    private function renderPreview(): string
    {
        $rendered = app(DocRenderer::class)->render($this->page ?? new DocumentationPage([
            'source' => $this->source,
            'title' => $this->title,
        ]));

        return $rendered->html;
    }

    public function render(): View
    {
        return view('livewire.docs.doc-editor', [
            'types' => config('documentation.pages.types'),
            'categories' => $this->getCategories(),
            'preview' => $this->renderPreview(),
        ]);
    }
}

## 17.2 Doc Search Component

```php
// app/Livewire/Docs/DocSearch.php
final class DocSearch extends Component
{
    public string $query = '';
    public array $results = [];
    public bool $isSearching = false;

    public function updatedQuery(): void
    {
        $this->debounce(300);
        $this->search();
    }

    public function search(): void
    {
        if (empty($this->query)) {
            $this->results = [];
            return;
        }

        $this->isSearching = true;

        $this->results = app(DocSearchService::class)->search($this->query, [

## 25.2 Version Controller

```php
final class DocumentationVersionController
{
    public function create(string $version, string $label): DocumentationVersion
    {
        // Validate version format
        if (!preg_match('/^\d+\.\d+$/', $version)) {
            throw new \InvalidArgumentException("Invalid version format: {$version}");
        }

        // Check if version already exists
        if (DocumentationVersion::where('version', $version)->exists()) {
            throw new \InvalidArgumentException("Version {$version} already exists");
        }

        // Create version
        $docVersion = DocumentationVersion::create([
            'version' => $version,
            'label' => $label,
            'is_current' => false,
        ]);

        // Copy pages from current version
        $currentVersion = DocumentationVersion::where('is_current', true)->first();
        if ($currentVersion) {
            $this->copyPages($currentVersion, $docVersion);
        }

        return $docVersion;
    }

    public function setCurrent(string $version): void
    {
        DocumentationVersion::where('is_current', true)
            ->update(['is_current' => false]);

        DocumentationVersion::where('version', $version)
            ->update(['is_current' => true]);
    }

    public function archive(string $version): void
    {
        $docVersion = DocumentationVersion::where('version', $version)->first();

        if (!$docVersion) {
            throw new \InvalidArgumentException("Version {$version} not found");
        }

        // Archive pages
        DocumentationPage::where('version', $version)
            ->update(['status' => 'archived']);

        // Remove from search index
        DocumentationPage::where('version', $version)
            ->get()
            ->each(fn ($page) => app(DocRenderer::class)->unindex($page));

        // Mark version as archived
        $docVersion->update(['is_current' => false]);
    }

    private function copyPages(DocumentationVersion $from, DocumentationVersion $to): void
    {
        $pages = DocumentationPage::where('version', $from->version)
            ->where('status', 'published')
            ->get();

        foreach ($pages as $page) {
            $newPage = $page->replicate();
            $newPage->version = $to->version;
            $newPage->status = 'draft';
            $newPage->save();
        }
    }
}
```

## 26.2 Content Sanitizer

```php
final class DocContentSanitizer
{
    private array $allowedTags = [
        'p', 'br', 'strong', 'em', 'code', 'pre', 'a', 'img',
        'ul', 'ol', 'li', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6',
        'table', 'thead', 'tbody', 'tr', 'th', 'td',
        'div', 'span', 'blockquote', 'hr',
    ];

    private array $allowedAttributes = [
        'a' => ['href', 'title', 'target', 'rel'],
        'img' => ['src', 'alt', 'title', 'width', 'height'],
        'code' => ['class'],
        'pre' => ['class'],
        'div' => ['class'],
        'span' => ['class'],
    ];

    public function sanitize(string $html): string
    {
        $purifier = new \HTMLPurifier($this->getConfig());
        return $purifier->purify($html);
    }

    private function getConfig(): \HTMLPurifier_Config
    {
        $config = \HTMLPurifier_Config::createDefault();
        $config->set('HTML.Allowed', $this->buildAllowedTags());
        $config->set('CSS.AllowedProperties', []);
        $config->set('AutoFormat.RemoveEmpty', true);
        $config->set('Cache.SerializerPath', storage_path('app/docs-cache'));

        return $config;
    }

    private function buildAllowedTags(): string
    {
        $tags = [];
        foreach ($this->allowedTags as $tag) {
            $attrs = $this->allowedAttributes[$tag] ?? [];
            $attrStr = implode(',', array_map(fn ($a) => "{$a}", $attrs));
            $tags[] = $attrStr ? "{$tag}[{$attrStr}]" : $tag;
        }
        return implode(',', $tags);
    }
}
```

## 31.2 Translation Workflow

```php
final class DocTranslationService
{
    public function translate(DocumentationPage $page, string $targetLang): DocumentationPage
    {
        $sourcePage = $page->translate('en') ?? $page;

        $translatedContent = $this->translateContent(
            $sourcePage->source,
            $targetLang
        );

        return DocumentationPage::create([
            'author_id' => $page->author_id,
            'title' => $this->translateText($sourcePage->title, $targetLang),
            'slug' => $sourcePage->slug . '-' . $targetLang,
            'type' => $sourcePage->type,
            'category' => $sourcePage->category,
            'version' => $sourcePage->version,
            'source' => $translatedContent,
            'status' => 'draft',
            'language' => $targetLang,
        ]);
    }

    private function translateContent(string $markdown, string $targetLang): string
    {
        $blocks = app(MarkdownBlockParser::class)->parse($markdown);

        foreach ($blocks as &$block) {
            if (in_array($block['type'], ['paragraph', 'heading', 'admonition'])) {
                $block['payload']['text'] = $this->translateText(
                    $block['payload']['text'],
                    $targetLang
                );
            }
        }

        return $this->blocksToMarkdown($blocks);
    }
}
```

# 32. Documentation Plugin System

## 32.1 Plugin Architecture

```php
interface DocPlugin
{
    public function name(): string;
    public function version(): string;
    public function register(DocRenderer $renderer): void;
    public function boot(): void;
}

final class DocPluginManager
{
    private array $plugins = [];

    public function register(DocPlugin $plugin): void
    {
        $this->plugins[$plugin->name()] = $plugin;
        $plugin->register(app(DocRenderer::class));
    }

    public function boot(): void
    {
        foreach ($this->plugins as $plugin) {
            $plugin->boot();
        }
    }

    public function get(string $name): ?DocPlugin
    {
        return $this->plugins[$name] ?? null;
    }
}
```

## 32.2 Example Plugin: Mermaid Diagrams

```php
final class MermaidPlugin implements DocPlugin
{
    public function name(): string
    {
        return 'mermaid';
    }

    public function version(): string
    {
        return '1.0.0';
    }

    public function register(DocRenderer $renderer): void
    {
        $renderer->registerBlockType('mermaid', fn (array $payload) => $this->render($payload));
    }

    public function boot(): void
    {
        // Add Mermaid JS to documentation pages
        Script::add('mermaid', 'https://cdn.jsdelivr.net/npm/mermaid/dist/mermaid.min.js');
    }

    private function render(array $payload): string
    {
        $code = $payload['code'] ?? '';

        return <<<HTML
        <div class="mermaid">
            {$code}
        </div>
        HTML;
    }
}

**Project:** GsmUi
**Architecture:** Signed Webhook Transport (Outbound + Inbound)
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.21-billing/05.21.08-webhooks.md` for the billing webhook concept and `05.21-billing/05.21.07-payment-providers.md` for provider selection. This document specifies the **implementation contract** for GsmUi's generic webhook transport: outbound delivery with HMAC signatures and retries, and inbound verification with replay protection via idempotency keys.

Webhooks connect GsmUi to external systems — billing providers (Stripe/Paddle), customer automation, and the notification webhook channel (`07.27-notifications.md`). Two flows exist:

1. **Outbound** — GsmUi pushes events to registered subscriber URLs, signed so receivers can verify authenticity.
2. **Inbound** — External systems (e.g. Stripe) push events to GsmUi, verified by provider signature and deduplicated by event id.

Both flows are implemented as Services with explicit signing/verification boundaries; they never trust unverified payloads.

---

# 1. Outbound Webhook Dispatch

Outbound dispatch is handled by `WebhookDispatcher`, which signs each payload with an HMAC-SHA256 signature using the subscriber's secret.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Webhooks\Services;

use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Cache;

final class WebhookDispatcher
{
    public function dispatch(string $url, string $secret, string $event, array $payload): void
    {
        $timestamp = time();
        $signature = $this->sign($secret, $timestamp, $event, $payload);

        Http::withHeaders([
            'X-GsmUi-Signature' => $signature,
            'X-GsmUi-Timestamp' => (string) $timestamp,
            'X-GsmUi-Event'     => $event,
        ])->post($url, $payload);
    }

    private function sign(string $secret, int $timestamp, string $event, array $payload): string
    {
        $data = $timestamp . '.' . $event . '.' . json_encode($payload);
        return 'sha256=' . hash_hmac('sha256', $data, $secret);
    }
}
```

The receiver verifies by recomputing the HMAC over `timestamp.event.body` and comparing constant-time. A timestamp skew check (±5 min) prevents stale replays.

# 2. Inbound Webhook Verification

Inbound endpoints verify the provider signature before any business logic runs. Each provider supplies its own verifier implementing a shared `WebhookVerifier` contract.

```php
namespace App\Domains\Webhooks\Contracts;

interface WebhookVerifier
{
    public function verify(string $payload, string $signatureHeader, string $secret): bool;
}
```

```php
namespace App\Domains\Billing\Webhooks;

use App\Domains\Webhooks\Contracts\WebhookVerifier;

final class StripeWebhookVerifier implements WebhookVerifier
{
    public function verify(string $payload, string $signatureHeader, string $secret): bool
    {
        $computed = hash_hmac('sha256', $payload, $secret);
        return hash_equals($computed, $signatureHeader);
    }
}
```

Controller entry point:

```php
final class StripeWebhookController
{
    public function __invoke(Request $request, StripeWebhookVerifier $verifier): Response
    {
        $secret = config('services.stripe.webhook_secret');
        abort_unless(
            $verifier->verify($request->getContent(), $request->header('Stripe-Signature'), $secret),
            403
        );

        $event = json_decode($request->getContent(), true);
        app(InboundWebhookHandler::class)->handle('stripe', $event['id'], $event);

        return response()->json(['received' => true]);
    }
}
```

# 3. Idempotency

Inbound events may be delivered more than once (provider retries). GsmUi dedupes by the provider's event id using a Redis-backed idempotency guard (`07.25-cache.md` §6 locks) before dispatching to the handler.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Webhooks\Services;

use Illuminate\Support\Facades\Cache;
use App\Domains\Billing\Events\OrderPaid;

final class InboundWebhookHandler
{
    public function handle(string $source, string $eventId, array $event): void
    {
        $key = "webhook:{$source}:{$eventId}";

        if (Cache::has($key)) {
            return; // already processed — ignore replay
        }

        Cache::put($key, true, now()->addDays(7)); // 7-day replay window

        // Business dispatch — billing side effects (see 07.30-billing.md):
        if ($event['type'] === 'invoice.paid') {
            event(new OrderPaid(
                orderId: (int) $event['data']['object']['metadata']['order_id'],
            ));
        }
    }
}
```

For outbound, the subscriber endpoint may send an `Idempotency-Key` header; the dispatcher echoes it so the receiver can dedupe on its side too.

# 4. Retry & Failure Policy

| Flow | Retry | DLQ |
| --- | --- | --- |
| Outbound | Horizon `emails`-like `webhooks` queue, exponential backoff (`07.14-jobs.md`) | failed-webhooks table |
| Inbound | Receiver retries; GsmUi is idempotent so replays are safe | logged, no side effects |

Outbound dispatch that repeatedly fails is recorded for manual replay; no automatic unbounded retry.

## 8.2 Subscriber Registration Service

```php
namespace App\Domains\Webhooks\Services;

use App\Domains\Webhooks\Models\WebhookSubscriber;

final class SubscriberService
{
    public function register(int $userId, string $url, array $events): WebhookSubscriber
    {
        $this->validateUrl($url);
        $this->validateEvents($events);

        return WebhookSubscriber::create([
            'user_id' => $userId,
            'url' => $url,
            'secret' => Str::random(40),
            'events' => $events,
            'is_active' => true,
        ]);
    }

    public function rotateSecret(WebhookSubscriber $subscriber): string
    {
        $newSecret = Str::random(40);

        $subscriber->update(['secret' => $newSecret]);

        return $newSecret;
    }

    public function disable(WebhookSubscriber $subscriber): void
    {
        $subscriber->update(['is_active' => false]);
    }

    public function enable(WebhookSubscriber $subscriber): void
    {
        $subscriber->update([
            'is_active' => true,
            'failure_count' => 0,
        ]);
    }

    private function validateUrl(string $url): void
    {
        $parsed = parse_url($url);

        if (!$parsed || !in_array($parsed['scheme'] ?? '', ['https'])) {
            throw new InvalidWebhookUrlException('Webhook URL must use HTTPS');
        }

        // Block internal/private IPs to prevent SSRF
        $host = $parsed['host'];
        if (inet_pton($host) && !filter_var($host, FILTER_VALIDATE_IP, FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE)) {
            throw new InvalidWebhookUrlException('Webhook URL cannot point to private/internal IPs');
        }

        // Block localhost and common dev ports
        $blockedHosts = ['localhost', '127.0.0.1', '::1', '0.0.0.0'];
        if (in_array($host, $blockedHosts)) {
            throw new InvalidWebhookUrlException('Webhook URL cannot point to localhost');
        }
    }

    private function validateEvents(array $events): void
    {
        $validEvents = config('webhooks.events');

        foreach ($events as $event) {
            if (!in_array($event, $validEvents)) {
                throw new InvalidWebhookEventException("Invalid event: {$event}");
            }
        }
    }
}
```

# 9. Signature Verification Deep Dive

## 9.1 HMAC-SHA256 Signature Scheme

The signature covers the timestamp, event name, and payload to prevent:
- **Replay attacks**: Timestamp skew check (±5 minutes)
- **Tampering**: HMAC covers the full payload body
- **Event spoofing**: Event name is included in the signed data

```php
final class WebhookSignature
{
    public static function sign(string $secret, int $timestamp, string $event, array $payload): string
    {
        $data = "{$timestamp}.{$event}." . json_encode($payload, JSON_THROW_ON_ERROR);
        return 'sha256=' . hash_hmac('sha256', $data, $secret);
    }

    public static function verify(string $secret, string $signatureHeader, int $timestamp, string $event, array $payload): bool
    {
        // Check timestamp freshness
        $expectedTimestamp = time();
        if (abs($expectedTimestamp - $timestamp) > 300) { // 5 minutes
            return false;
        }

        $expectedSignature = self::sign($secret, $timestamp, $event, $payload);

        return hash_equals($expectedSignature, $signatureHeader);
    }
}
```

## 9.2 Provider-Specific Signature Schemes

| Provider | Header | Algorithm | Format |
| --- | --- | --- | ---|
| GsmUi (outbound) | `X-GsmUi-Signature` | HMAC-SHA256 | `sha256=<hex>` |
| Stripe | `Stripe-Signature` | HMAC-SHA256 | `t=<timestamp>,v1=<hex>` |
| Paddle | `Paddle-Signature` | HMAC-SHA256 | `h1=<hex>` |
| GitHub | `X-Hub-Signature-256` | HMAC-SHA256 | `sha256=<hex>` |

## 9.3 Multi-Signature Support

For rotating secrets, GsmUi supports verifying against multiple signatures.

```php
final class MultiSignatureVerifier implements WebhookVerifier
{
    public function verify(string $payload, string $signatureHeader, string $secret): bool
    {
        // Try primary secret
        if ($this->verifySingle($payload, $signatureHeader, $secret)) {
            return true;
        }

        // Try previous secret (during rotation window)
        $previousSecret = config('webhooks.previous_secret');
        if ($previousSecret && $this->verifySingle($payload, $signatureHeader, $previousSecret)) {
            return true;
        }

        return false;
    }

    private function verifySingle(string $payload, string $signatureHeader, string $secret): bool
    {
        $computed = hash_hmac('sha256', $payload, $secret);
        return hash_equals($computed, $signatureHeader);
    }
}
```

# 10. Retry & Backoff Strategy

## 10.1 Exponential Backoff

Failed outbound deliveries retry with exponential backoff plus jitter to prevent thundering herd.

```php
final class WebhookRetryPolicy
{
    public function backoff(int $attempt): int
    {
        // Base: 30s, 2min, 8min, 30min, 2hr
        $base = [30, 120, 480, 1800, 7200];
        $delay = $base[min($attempt, count($base) - 1)];

        // Add jitter (±20%)
        $jitter = $delay * 0.2 * (mt_rand() / mt_getrandmax());
        return (int) ($delay + $jitter);
    }

    public function maxAttempts(): int
    {
        return 5;
    }

    public function shouldRetry(WebhookDelivery $delivery): bool
    {
        return $delivery->attempt < $this->maxAttempts()
            && $delivery->response_status >= 500; // only retry server errors
    }
}
```

## 10.2 Failure Classification

| Response | Classification | Action |
| --- | --- | --- |
| 2xx | Success | Log, mark delivered |
| 4xx (except 408, 429) | Client error | Do not retry, mark failed |
| 408 | Timeout | Retry with backoff |
| 429 | Rate limited | Retry after `Retry-After` header |
| 5xx | Server error | Retry with backoff |
| Connection error | Network failure | Retry with backoff |
| No response (30s timeout) | Timeout | Retry with backoff |

## 10.3 Dead Letter Queue

After max retries, deliveries are moved to a DLQ for manual review.

```php
final class WebhookDeadLetterHandler
{
    public function handle(WebhookDelivery $delivery): void
    {
        // Record in DLQ
        WebhookDeadLetter::create([
            'subscriber_id' => $delivery->subscriber_id,
            'event' => $delivery->event,
            'payload' => $delivery->payload,
            'attempts' => $delivery->attempt,
            'last_error' => $delivery->error_message,
            'last_response' => $delivery->response_body,
        ]);

        // Disable subscriber after persistent failures
        $subscriber = $delivery->subscriber;
        if ($subscriber->failure_count >= 10) {
            $subscriber->update(['is_active' => false]);

            // Notify subscriber owner
            if ($subscriber->user) {
                Mail::to($subscriber->user->email)
                    ->queue(new WebhookDisabledNotification($subscriber));
            }
        }
    }
}
```

## 11.3 Middleware Stack

```php
// app/Http/Middleware/VerifyWebhookSignature.php
final class VerifyWebhookSignature
{
    public function handle(Request $request, Closure $next, string $provider): Response
    {
        $verifier = match ($provider) {
            'stripe' => app(StripeWebhookVerifier::class),
            'paddle' => app(PaddleWebhookVerifier::class),
            'github' => app(GitHubWebhookVerifier::class),
            'gsmui' => app(GsmuiWebhookVerifier::class),
            default => abort(500, "Unknown webhook provider: {$provider}"),
        };

        $secret = config("services.{$provider}.webhook_secret");
        $signatureHeader = $request->header($this->getSignatureHeader($provider));

        abort_unless(
            $verifier->verify($request->getContent(), $signatureHeader, $secret),
            403,
            'Invalid webhook signature'
        );

        return $next($request);
    }

    private function getSignatureHeader(string $provider): string
    {
        return match ($provider) {
            'stripe' => 'Stripe-Signature',
            'paddle' => 'Paddle-Signature',
            'github' => 'X-Hub-Signature-256',
            'gsmui' => 'X-GsmUi-Signature',
            default => 'X-Signature',
        };
    }
}
```

# 12. Webhook Security

## 12.1 SSRF Protection

Webhook URLs are validated against SSRF attacks before registration.

```php
final class SsrfProtection
{
    public function validate(string $url): void
    {
        $parsed = parse_url($url);
        $host = $parsed['host'] ?? '';

        // Resolve DNS and check for private IPs
        $ips = gethostbynamel($host);
        foreach ($ips as $ip) {
            if (filter_var($ip, FILTER_VALIDATE_IP, FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE) === false) {
                throw new SsrfDetectedException("URL resolves to private IP: {$ip}");
            }
        }

        // Block cloud metadata endpoints
        $blockedIps = ['169.254.169.254', '100.100.100.200'];
        foreach ($ips as $ip) {
            if (in_array($ip, $blockedIps)) {
                throw new SsrfDetectedException("URL resolves to cloud metadata endpoint");
            }
        }
    }
}
```

## 12.2 IP Allowlisting

For providers that publish static IP ranges, GsmUi can validate the source IP.

```php
final class IpAllowlistVerifier implements WebhookVerifier
{
    private const STRIPE_IPS = [
        '54.187.174.169',
        '54.241.143.138',
        '54.241.159.140',
        '34.234.23.2',
        '34.207.186.71',
    ];

    public function verify(string $payload, string $signatureHeader, string $secret): bool
    {
        $clientIp = request()->ip();

        if (!in_array($clientIp, self::STRIPE_IPS)) {
            Log::warning('Webhook from unknown IP', ['ip' => $clientIp]);
            return false;
        }

        return hash_equals(
            hash_hmac('sha256', $payload, $secret),
            $signatureHeader
        );
    }
}
```

# 19. Webhook Rate Limiting

## 19.1 Outbound Rate Limiting

GsmUi rate-limits outbound webhooks per subscriber to prevent abuse.

```php
final class WebhookRateLimiter
{
    public function __construct(private Cache $cache) {}

    public function allow(WebhookSubscriber $subscriber): bool
    {
        $key = "webhook:rate:{$subscriber->id}";
        $limit = config('webhooks.rate_limit.per_minute', 60);

        $current = $this->cache->get($key, 0);

        if ($current >= $limit) {
            return false;
        }

        $this->cache->put($key, $current + 1, now()->addMinute());
        return true;
    }

    public function remaining(WebhookSubscriber $subscriber): int
    {
        $key = "webhook:rate:{$subscriber->id}";
        $limit = config('webhooks.rate_limit.per_minute', 60);
        $current = $this->cache->get($key, 0);

        return max(0, $limit - $current);
    }

    public function reset(WebhookSubscriber $subscriber): void
    {
        $this->cache->forget("webhook:rate:{$subscriber->id}");
    }
}
```

## 19.2 Inbound Rate Limiting

Inbound webhooks from external providers are rate-limited to prevent abuse.

```php
// app/Http/Middleware/ThrottleWebhooks.php
final class ThrottleWebhooks
{
    public function handle(Request $request, Closure $next, string $provider = 'default'): Response
    {
        $limit = config("webhooks.providers.{$provider}.rate_limit", 100);

        $limiter = RateLimiter::attempt(
            "webhook:inbound:{$provider}:" . $request->ip(),
            $limit,
            fn () => true
        );

        if (!$limiter) {
            return response()->json(['error' => 'Rate limit exceeded'], 429);
        }

        return $next($request);
    }
}
```

# 23. Webhook Idempotency Deep Dive

## 23.1 Distributed Idempotency with Redis

The idempotency guard uses Redis SET NX with TTL to ensure atomicity across multiple workers.

```php
final class RedisIdempotencyGuard
{
    public function __construct(private Redis $redis) {}

    public function acquire(string $key, int $ttlSeconds = 604800): bool
    {
        // SET NX EX — atomic set-if-not-exists with expiry
        return (bool) $this->redis->set(
            "webhook:idempotency:{$key}",
            '1',
            'EX',
            $ttlSeconds,
            'NX'
        );
    }

    public function release(string $key): void
    {
        $this->redis->del("webhook:idempotency:{$key}");
    }

    public function isProcessed(string $key): bool
    {
        return $this->redis->exists("webhook:idempotency:{$key}") > 0;
    }
}
```

# 24. Webhook Event Transformations

## 24.1 Payload Normalization

Different providers send payloads in different shapes. The handler normalizes them to a standard format before dispatching domain events.

```php
final class PayloadNormalizer
{
    public function normalize(string $provider, string $eventType, array $payload): array
    {
        return match ($provider) {
            'stripe' => $this->normalizeStripe($eventType, $payload),
            'paddle' => $this->normalizePaddle($eventType, $payload),
            'github' => $this->normalizeGithub($eventType, $payload),
            default => $payload,
        };
    }

    private function normalizeStripe(string $eventType, array $payload): array
    {
        return [
            'provider' => 'stripe',
            'event_type' => $eventType,
            'provider_event_id' => $payload['id'],
            'data' => $payload['data']['object'] ?? [],
            'metadata' => $payload['data']['object']['metadata'] ?? [],
            'created_at' => $payload['created'] ?? time(),
        ];
    }

    private function normalizePaddle(string $eventType, array $payload): array
    {
        return [
            'provider' => 'paddle',
            'event_type' => $eventType,
            'provider_event_id' => (string) ($payload['alert_id'] ?? $payload['id']),
            'data' => $payload,
            'metadata' => $payload['metadata'] ?? [],
            'created_at' => $payload['created_at'] ?? time(),
        ];
    }

    private function normalizeGithub(string $eventType, array $payload): array
    {
        return [
            'provider' => 'github',
            'event_type' => $eventType,
            'provider_event_id' => $payload['after'] ?? uniqid(),
            'data' => $payload,
            'metadata' => [],
            'created_at' => $payload['repository']['updated_at'] ?? time(),
        ];
    }
}
```

```php
        ], $overrides);
    }

    public static function subscriptionCanceled(array $overrides = []): array
    {
        return array_merge([
            'id' => 'evt_' . Str::random(24),
            'object' => 'event',
            'type' => 'customer.subscription.deleted',
            'data' => [

                    'id' => 'sub_' . Str::random(24),
                    'object' => 'subscription',
                    'status' => 'canceled',
                    'canceled_at' => time(),
                ],
            ],
            'created' => time(),
            'livemode' => false,
        ], $overrides);
    }

    public static function signature(array $event, string $secret): string
    {
        $payload = json_encode($event);
        $timestamp = $event['created'];
        $signedPayload = "{$timestamp}.{$payload}";

        return 't=' . $timestamp . ',v1=' . hash_hmac('sha256', $signedPayload, $secret);
    }
}
```

## 26.1 Delivery Guarantees

| --- | --- | --- |

## 26.2 Outage Handling

| Provider Status | GsmUi Behavior |
| --- | --- |
| Stripe down | Queue inbound events, process when Stripe recovers |
| Paddle down | Queue inbound events, process when Paddle recovers |
| GsmUi outbound failing | Retry with backoff, DLQ after max attempts |
| Redis down (idempotency) | Fall back to database idempotency guard |
| Network partition | Queue events locally, process when network recovers |

# 27. Webhook Migration & Versioning

## 27.1 Webhook Versioning

GsmUi supports webhook API versioning to allow safe payload evolution.

```php
// config/webhooks.php
'api_version' => '2024-01-01',

// In dispatcher
public function dispatch(string $url, string $secret, string $event, array $payload): void
{
    $versionedPayload = [
        'api_version' => config('webhooks.api_version'),
        'event' => $event,
        'data' => $payload,
        'created_at' => now()->toISOString(),
    ];

    // Sign and send
    Http::withHeaders([
        'X-GsmUi-Signature' => $this->sign($secret, $versionedPayload),
        'X-GsmUi-Version' => config('webhooks.api_version'),
    ])->post($url, $versionedPayload);
}
```

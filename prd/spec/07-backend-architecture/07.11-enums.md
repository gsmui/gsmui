# 07.11 - Enums

**Project:** GsmUi
**Architecture:** Backed Enum Pattern
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `06.01-design-principles.md` §12 (ENUM strategy) for the database-level ENUM rules, and `05.08-repositories.md` for persistence context. This document specifies the **implementation contract** for GsmUi's backed enums: how string-backed enums map to database columns, how they are cast on Eloquent models, how labels are localized, and the hard rule that enums contain no business logic.

Enums model constrained, low-churn string sets (statuses, types, roles, channels) that are stored as readable `VARCHAR` values in MySQL (see `06.01-design-principles.md` §12 — string ENUMs, not integers, so values stay legible in queries and logs). They provide a single source of truth for allowed values and prevent magic strings from scattering across the codebase. An enum case is a constant; any logic that branches on an enum lives in a Service or Action, never inside the enum.

# 1A. Enum Architecture Overview

Enums model constrained, low-churn string sets that represent statuses, types, roles, and channels. They provide a single source of truth for allowed values and prevent magic strings from scattering across the codebase.

```text
┌─────────────────────────────────────────────────────────────────────────┐
│                    ENUM ARCHITECTURE                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Without Enums (fragile):                                               │
│  ┌─────────────────────────────────────────────────────────┐            │
│  │  if ($status === 'active') { ... }                      │            │
│  │  if ($status === 'trialing') { ... }                    │            │
│  │  if ($status === 'past_due') { ... }                    │            │
│  │  // Typos silently pass: 'actve'                        │            │
│  │  // Magic strings scattered everywhere                  │            │
│  └─────────────────────────────────────────────────────────┘            │
│                                                                         │
│  With Enums (safe):                                                     │
│  ┌─────────────────────────────────────────────────────────┐            │
│  │  if ($status === SubscriptionStatus::Active) { ... }    │            │
│  │  // Compile-time error on typo                          │            │
│  │  // Single source of truth for allowed values            │            │
│  │  // IDE autocompletion and refactoring support           │            │
│  └─────────────────────────────────────────────────────────┘            │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

# 1B. Enum vs Constants vs Config

| Approach | Type Safety | IDE Support | DB Mapping | Localization | Refactoring |
| --- | --- | --- | --- | --- | --- |
| String constants | No | Minimal | Manual | Manual | Search & replace |
| Config arrays | No | No | Manual | Manual | Manual update |
| Backed Enums | Yes | Full | Cast | Built-in | Find references |

Enums are the correct choice for GsmUi because they provide type safety, IDE support, and seamless Eloquent integration.

# 1E. Enum Decision Tree

```text
Should I use an Enum?
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  Is this a constrained set of values?                           │
│  ├─ NO  → Use a string/int with validation                     │
│  └─ YES → Does the set change frequently (weekly)?             │
│            ├─ YES → Use a string with validation               │
│            └─ NO  → Use an Enum                                │
│                                                                 │
│  Does the set need localization?                                │
│  ├─ YES → Enum with label() method                             │
│  └─ NO  → Plain Enum without label()                           │
│                                                                 │
│  Does the set need DB storage?                                  │
│  ├─ YES → String-backed Enum with Eloquent cast                │
│  └─ NO  → Plain Enum (not stored)                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

# 2A. Extended Backed Enum Contract

All GsmUi enums follow this contract:

| Requirement | Implementation | Rationale |
| --- | --- | --- |
| `string` backed | `enum Foo: string` | Readable in DB, logs, and queries |
| PascalCase case names | `case Active = 'active'` | PHP convention |
| snake_case values | `'active'`, `'past_due'` | DB-friendly, URL-safe |
| `label()` method | Returns localized string | UI display without magic strings |
| `values()` helper | Returns array of all values | Validation, config, testing |
| No business logic | Enum contains only cases + labels | Logic belongs in Services |

---

# 2B. Enum Case Naming Convention

| Convention | Example | Rationale |
| --- | --- | --- |
| PascalCase for case names | `case Active = 'active'` | PHP convention |
| snake_case for string values | `'past_due'` | DB-friendly, URL-safe |
| Singular nouns for types | `case Article = 'article'` | Represents one item |
| Past tense for statuses | `case Published = 'published'` | Represents a state |
| No prefixes in values | `'active'` not `'status_active'` | Column name provides context |

# 2C. Enum with Multiple Helpers

```php
enum SubscriptionStatus: string
{
    case Active = 'active';
    case Trialing = 'trialing';
    case PastDue = 'past_due';
    case Canceled = 'canceled';
    case Expired = 'expired';
    case Paused = 'paused';

    /**
     * Localized label for UI display.
     */
    public function label(): string
    {
        return __("billing.subscription.status.{$this->value}");
    }

    /**
     * Array of all case values for validation.
     */
    public static function values(): array
    {
        return array_column(self::cases(), 'value');
    }

    /**
     * Check if this status allows renewal.
     * NOTE: This is a simple mapping, not business logic.
     * Complex rules belong in Services.
     */
    public function isRenewable(): bool
    {
        return in_array($this, [self::Active, self::PastDue]);
    }

    /**
     * Get the next possible statuses from this state.
     */
    public function allowedTransitions(): array
    {
        return match ($this) {
            self::Active => [self::PastDue, self::Canceled, self::Paused],
            self::Trialing => [self::Active, self::Canceled],
            self::PastDue => [self::Active, self::Canceled, self::Expired],
            self::Canceled => [self::Active],
            self::Expired => [self::Active],
            self::Paused => [self::Active, self::Canceled],
        };
    }

    /**
     * Check if a transition to the given status is allowed.
     */
    public function canTransitionTo(self $target): bool
    {
        return in_array($target, $this->allowedTransitions());
    }
}
```

# 2E. Enum Anti-Patterns

| Anti-pattern | Why it's bad | Correct approach |
| --- | --- | --- |
| Business logic in enum | Violates single responsibility | Move to Service |
| Integer-backed enums | Not readable in DB/logs | Use string-backed |
| Dynamic enum cases | Enums are static by design | Use config or validation rules |
| Enum with database queries | Ties enum to persistence | Query in Service |
| Enum with HTTP request | Ties enum to HTTP layer | Use in Form Request validation |
| Enum with event dispatch | Side effects in enum | Dispatch in Action |
| Enum with cache calls | Side effects in enum | Cache in Service |

# 2. Backed Enum Contract

All GsmUi enums are `string` backed. Each case maps to the exact DB string. A `label()` method returns a localization key, never a hardcoded UI string, and a `values()` helper lists cases for validation/config.

```php
namespace App\Domains\Billing\Enums;

enum SubscriptionStatus: string
{
    case Active = 'active';
    case Trialing = 'trialing';
    case PastDue = 'past_due';
    case Canceled = 'canceled';
    case Expired = 'expired';
    case Paused = 'paused';

    public function label(): string
    {
        return __("billing.subscription.status.{$this->value}");
    }

    public static function values(): array
    {
        return array_column(self::cases(), 'value');
    }
}
```

# 3. DB ↔ Enum Mapping

Enums are stored as strings and bound to models via Laravel's native enum cast. No migration-level `ENUM` SQL type is used — a `VARCHAR` column with an application-level allowed-values contract keeps migrations flexible (add a case without a blocking schema change where the column is open `VARCHAR`).

```php
// Migration (open VARCHAR, validated by the enum at the app layer):
Schema::create('subscriptions', function (Blueprint $table) {
    $table->string('status'); // 'active', 'trialing', ...
    $table->index('status');
});

// Model cast:
use App\Domains\Billing\Enums\SubscriptionStatus;

protected $casts = [
    'status' => SubscriptionStatus::class,
];

// Usage:
$subscription->status = SubscriptionStatus::Active;
if ($subscription->status === SubscriptionStatus::PastDue) {
    // branch in service, not in enum
}
```

# 3B. Enum Cast Behavior

The Eloquent cast handles bidirectional conversion:

```php
// Reading from DB:
$subscription = Subscription::find(1);
$subscription->status; // SubscriptionStatus::Active (enum instance)

// Writing to DB:
$subscription->status = SubscriptionStatus::PastDue;
$subscription->save();
// DB stores: 'past_due'

// Querying:
Subscription::where('status', SubscriptionStatus::Active)->get();
Subscription::where('status', 'active')->get(); // Also works
```

# 5. Validation Helper

Form Requests (see `07.18-form-requests.md`) validate incoming strings against the enum using `Rule::enum()`:

```php
use Illuminate\Validation\Rules\Enum;

public function rules(): array
{
    return [
        'status' => ['required', new Enum(SubscriptionStatus::class)],
    ];
}
```

# 6. No Business Logic Rule

Enums must not contain conditional behavior, service calls, or state transitions. The anti-pattern below is forbidden:

```php
// FORBIDDEN — business logic inside an enum:
enum SubscriptionStatus: string
{
    case Active;
    public function canRenew(): bool   // ❌ logic belongs in a service
    {
        return $this === self::Active;
    }
}
```

Correct placement:

```php
// In a service (07.06):
if ($subscription->status === SubscriptionStatus::Active) {
    $this->billing->renew($subscription);
}
```

# 6A. No Business Logic Deep Dive

The rule is strict: enums contain no conditional behavior, service calls, or state transitions beyond simple mappings.

```php
// FORBIDDEN — business logic inside an enum:
enum SubscriptionStatus: string
{
    case Active = 'active';

    public function canRenew(): bool   // ❌ logic belongs in a service
    {
        return $this === self::Active;
    }

    public function nextBillingDate(): \DateTime  // ❌ business calculation
    {
        return now()->addMonth();
    }

    public function sendReminder(): void  // ❌ side effect
    {
        // Send email...
    }
}
```

Correct placement:

```php
// In a Service (07.06):
class SubscriptionService
{
    public function canRenew(Subscription $subscription): bool
    {
        return $subscription->status === SubscriptionStatus::Active;
    }

    public function calculateNextBillingDate(Subscription $subscription): \DateTime
    {
        return now()->addMonth();
    }
}
```

# 6B. What Enum Methods ARE Allowed

Simple mappings and lookups are acceptable:

```php
enum SubscriptionStatus: string
{
    case Active = 'active';
    case Trialing = 'trialing';
    case PastDue = 'past_due';

    // ALLOWED: Simple label lookup
    public function label(): string
    {
        return __("billing.subscription.status.{$this->value}");
    }

    // ALLOWED: Static helper for validation
    public static function values(): array
    {
        return array_column(self::cases(), 'value');
    }

    // ALLOWED: Simple boolean mapping (no I/O, no external calls)
    public function isRenewable(): bool
    {
        return in_array($this, [self::Active, self::PastDue]);
    }

    // ALLOWED: Transition lookup (no side effects)
    public function allowedTransitions(): array
    {
        return match ($this) {
            self::Active => [self::PastDue, self::Canceled],
            self::PastDue => [self::Active, self::Expired],
            default => [],
        };
    }
}
```

The test: **Can this method be pure (no I/O, no external calls, no state changes)?** If yes, it's allowed in the enum. If no, move it to a Service.

| Method Type | Allowed? | Example |
| --- | --- | --- |
| `label()` | Yes | Returns localized string |
| `values()` | Yes | Returns array of all case values |
| `isXxx()` | Yes (simple mapping) | `isActive()`, `isRenewable()` |

# 7B. Enum and Query Scope Integration

Enums work with Eloquent query scopes:

```php
// Model scope using enum:
class Component extends Model
{
    public function scopePublished(Builder $query): Builder
    {
        return $query->where('status', ComponentStatus::Published);
    }

    public function scopeInStatus(Builder $query, ComponentStatus $status): Builder
    {
```

```php
class UpdateSubscriptionRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'status' => [
                'required',
                new Enum(SubscriptionStatus::class),
                Rule::in(
                    SubscriptionStatus::from($this->subscription->status)
                        ->allowedTransitions()
                        ->pluck('value')
                        ->toArray()
                ),
            ],
        ];
    }

    public function withValidator($validator): void
    {
        $validator->after(function ($validator) {
            $currentStatus = SubscriptionStatus::from($this->subscription->status);
            $newStatus = SubscriptionStatus::from($this->input('status'));

            if (!$currentStatus->canTransitionTo($newStatus)) {
                $validator->errors()->add(
                    'status',
                    "Cannot transition from {$currentStatus->label()} to {$newStatus->label()}"
                );
            }
        });
    }
}
```

# 9AB. Enum Code Generation Pattern

For domains with many similar enums, use a base trait:

```php
trait HasLabelAndValues
{
    public function label(): string
    {
        $class = class_basename(static::class);
        $key = strtolower(str_replace('Status', '', $class));

        return __("{$key}.status.{$this->value}");
    }

    public static function values(): array
    {
        return array_column(self::cases(), 'value');
    }
}

// Usage:
enum ComponentStatus: string
{
    use HasLabelAndValues;

    case Draft = 'draft';
    case Review = 'review';
    case Published = 'published';
    case Rejected = 'rejected';
    case Archived = 'archived';
}
```

# 07.33 - Component Engine

**Project:** GsmUi
**Architecture:** Component Registry + Renderer Contract
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.17-component-engine.md` for the conceptual component architecture, and `06.20-components.md` (`components`, `component_variants`, `component_examples`, `component_docs`) for the persistence schema. This document specifies the **implementation contract** — the `ComponentRegistry` (discovery + metadata) and the `ComponentRenderer` contract (props → Blade/Livewire HTML), plus DI binding. It does NOT re-spec the schema.

The Component Engine is the foundation of GsmUi. Every UI element is registered with metadata (name, category, version, props, slots, variants, events, accessibility notes) and resolved at render time through a stable pipeline: resolve props → validate → apply variants → apply theme tokens → render Blade → optional Livewire hydration. The registry is the single source of truth for discovery (used by docs `07.35`, playground `07.36`, search `07.24`, and MCP `07.38`). The renderer is the only place that turns a component + resolved props into HTML.

The goals of this contract are:

- Expose one `ComponentRegistry` that discovers and returns component metadata by name/slug.
- Expose one `ComponentRenderer` that renders a registered component with a typed `ComponentProps` DTO.
- Keep prop resolution, variant resolution, and theme-token resolution as composable, testable steps.
- Decouple consumers (docs, playground, templates) from the concrete Blade classes.

## 2. The `ComponentRegistry` Contract

`ComponentRegistry` is the discovery + metadata authority. Third-party packages register components via the same contract (`05.17-component-engine.md` §Extensibility).

```php
namespace App\Domains\Components\Contracts;

use App\Domains\Components\Data\ComponentProps;
use App\Domains\Components\Models\Component;

interface ComponentRegistry
{
    /** Register a component class with metadata (called from service providers). */
    public function register(string $name, string $class, string $category, string $version): void;

    /** Resolve a registered component by name/slug. */
    public function resolve(string $name): ?Component;

    /** All registered components (optionally filtered by category). */
    public function all(?string $category = null): \Illuminate\Support\Collection;

    /** Metadata used by docs/playground/search (props, slots, variants, events). */
    public function metadata(string $name): ?array;
}
```

Example registration (from a component package provider):

```php
app(ComponentRegistry::class)->register(
    name: 'button',
    class: \Gsmui\Components\Actions\Button::class,
    category: 'actions',
    version: '1.0.0',
);
```

## 4. The `ComponentRenderer` Contract

`ComponentRenderer` is the render boundary. It resolves props, applies variants, applies theme tokens, and returns rendered HTML (Blade + optional Livewire hydration). Presentation layers (docs, playground, templates) call only this.

```php
namespace App\Domains\Components\Contracts;

use App\Domains\Components\Data\ComponentProps;
use App\Domains\Components\Data\ResolvedComponent;
use App\Domains\Components\Models\Component;

interface ComponentRenderer
{
    /**
     * Render a registered component with resolved props.
     * Returns the rendered HTML plus the resolved metadata for inspection.
     */
    public function render(Component $component, ComponentProps $props): ResolvedComponent;

    /** Render by name (lookup + resolve + render in one call). */
    public function renderNamed(string $name, array $rawProps = []): ResolvedComponent;
}
```

## 5. Example Service: Component Renderer Manager

The manager orchestrates the pipeline steps. Theme-token resolution delegates to the theme domain (`07.32-theme-engine.md`); variant resolution is a local support class.

```php
namespace App\Domains\Components\Services;

use App\Domains\Components\Contracts\{ComponentRegistry, ComponentRenderer, PropSchema};
use App\Domains\Components\Data\ComponentProps;
use App\Domains\Components\Data\ResolvedComponent;
use App\Domains\Components\Models\Component;
use App\Domains\Components\Support\VariantResolver;

final class ComponentRendererManager implements ComponentRenderer
{
    public function __construct(
        private ComponentRegistry $registry,
        private PropSchema $props,
        private VariantResolver $variants,
    ) {}

    public function render(Component $component, ComponentProps $props): ResolvedComponent
    {
        $resolvedProps = $this->props->resolve($component->name, $props->toArray());
        $variants = $this->variants->resolve($component, $resolvedProps);

        // Theme tokens are injected at render time by the theme view composer.
        $html = view($component->view, [
            'props' => $resolvedProps,
            'variants' => $variants,
        ])->render();

        return new ResolvedComponent(html: $html, props: $resolvedProps, variants: $variants);
    }

    public function renderNamed(string $name, array $rawProps = []): ResolvedComponent
    {
        $component = $this->registry->resolve($name)
            ?? throw new \App\Domains\Components\Exceptions\ComponentNotFoundException($name);

        return $this->render($component, $this->props->resolve($name, $rawProps));
    }
}
```

## 8. Reuse Rules

A component service MAY:

- Discover/register components; resolve metadata; validate props; apply variants.
- Delegate theme-token injection to the theme domain (`07.32-theme-engine.md`).
- Return rendered HTML and resolved metadata.

A component service MUST NOT:

- Hard-code color/radius values (use `--gsm-*` tokens via the theme composer).
- Mutate component metadata outside the authoring/packaging flow.
- Render consumers' arbitrary Blade (that is the playground sandbox, `07.36`).

| Consumer | Uses |
| --- | --- |
| Documentation (`07.35`) | `registry.metadata()` + `renderer.renderNamed()` |
| Playground (`07.36`) | `registry.metadata()` for prop inspector |
| Search (`07.24`) | `registry.all()` to index components |
| MCP (`07.38`) | `registry.metadata()` as resources |

## 10.2 Component Metadata Structure

Each component stores rich metadata used by docs, playground, search, and MCP.

```php
final class ComponentMetadataBuilder
{
    public function build(Component $component): array
    {
        return [
            'name' => $component->name,
            'slug' => $component->slug,
            'category' => $component->category,
            'version' => $component->version,
            'description' => $component->description,
            'view' => $component->view,
            'props' => $this->extractProps($component),
            'slots' => $this->extractSlots($component),
            'events' => $this->extractEvents($component),
            'variants' => $this->extractVariants($component),
            'accessibility' => $this->extractAccessibility($component),
            'examples' => $this->extractExamples($component),
            'dependencies' => $component->dependencies,
            'tags' => $component->tags,
        ];
    }

    private function extractProps(Component $component): array
    {
        return $component->props->map(fn ($prop) => [
            'name' => $prop->name,
            'type' => $prop->type,
            'required' => $prop->required,
            'default' => $prop->default,
            'description' => $prop->description,
            'options' => $prop->options,
        ])->toArray();
    }
}
```

## 10.3 Component Discovery

Components are discovered via service provider registration and file-system scanning.

```php
final class ComponentDiscoveryService
{
    public function discoverFromDirectory(string $directory): array
    {
        $components = [];

        $files = Finder::create()
            ->files()
            ->name('*.php')
            ->in($directory);

        foreach ($files as $file) {
            $class = $this->resolveClass($file);
            if ($class && $this->isComponent($class)) {
                $metadata = $this->extractMetadata($class);
                $components[] = $metadata;
            }
        }

        return $components;
    }

    private function isComponent(string $class): bool
    {
        return is_subclass_of($class, Component::class)
            || is_subclass_of($class, LivewireComponent::class);
    }
}
```

## 11.3 Prop Validation

```php
final class PropValidator
{
    public function validate(string $componentName, array $props): ValidationResult
    {
        $schema = app(PropSchemaDefinition::class)->define($componentName);
        $errors = [];

        foreach ($schema as $propName => $propDef) {
            $value = $props[$propName] ?? $propDef['default'] ?? null;

            // Required check
            if ($propDef['required'] && $value === null) {
                $errors[] = "Prop '{$propName}' is required";
                continue;
            }

            // Type check
            if ($value !== null && !$this->typeCheck($value, $propDef['type'])) {
                $errors[] = "Prop '{$propName}' must be of type {$propDef['type']}";
            }

            // Enum check
            if (isset($propDef['options']) && $value !== null && !in_array($value, $propDef['options'])) {
                $errors[] = "Prop '{$propName}' must be one of: " . implode(', ', $propDef['options']);
            }
        }

        // Unknown props
        $knownProps = array_keys($schema);
        $unknownProps = array_diff(array_keys($props), $knownProps);
        foreach ($unknownProps as $unknown) {
            $errors[] = "Unknown prop '{$unknown}'";
        }

        return new ValidationResult(
            valid: empty($errors),
            errors: $errors,
            resolved: $this->applyDefaults($props, $schema),
        );
    }
}
```

# 12. Component Rendering Pipeline

## 12.1 Full Pipeline

```text
renderNamed(name, rawProps)
        │
        ├─ registry.resolve(name)              → Component
        ├─ propSchema.resolve(name, rawProps)  → ComponentProps (validated + defaulted)
        ├─ variantResolver.resolve(component, props) → CSS classes

```

## 12.2 Accessibility Resolution

```php
final class AccessibilityResolver
{
    public function resolve(Component $component, ComponentProps $props): array
    {
        $aria = [];

        // ARIA role
        if (isset($component->metadata['aria_role'])) {
            $aria['role'] = $component->metadata['aria_role'];
        }

        // Disabled state
        if ($props->get('disabled')) {
            $aria['aria-disabled'] = 'true';
        }

        // Loading state
        if ($props->get('loading')) {
            $aria['aria-busy'] = 'true';
        }

        // Label
        if ($props->get('label')) {
            $aria['aria-label'] = $props->get('label');
        }

        // Described by
        if ($props->get('description')) {
            $aria['aria-describedby'] = $props->get('description_id');
        }

        return $aria;
    }
}
```

# 13. Component Variants

## 13.1 Variant Resolution

Variants map prop values to CSS classes using the theme token system.

```php
final class VariantResolver
{
    private const VARIANT_MAP = [
        'button' => [
            'primary' => [
                'classes' => 'bg-(--gsm-color-primary) text-(--gsm-color-primary-contrast)',
                'hover' => 'hover:opacity-90',
                'focus' => 'focus-visible:outline-2 focus-visible:outline-offset-2',
            ],
            'secondary' => [
                'classes' => 'bg-(--gsm-color-secondary) text-(--gsm-color-secondary-contrast)',
                'hover' => 'hover:opacity-90',
            ],
            'danger' => [
                'classes' => 'bg-(--gsm-color-danger) text-white',
                'hover' => 'hover:opacity-90',
            ],
            'ghost' => [
                'classes' => 'bg-transparent text-(--gsm-color-text)',
                'hover' => 'hover:bg-(--gsm-color-surface)',
            ],
            'link' => [
                'classes' => 'bg-transparent text-(--gsm-color-primary) underline',
                'hover' => 'hover:text-(--gsm-color-primary-hover)',
            ],
        ],
    ];

    public function resolve(Component $component, ComponentProps $props): array
    {
        $variant = $props->get('variant') ?? 'primary';
        $size = $props->get('size') ?? 'md';

        $classes = [];

        // Variant classes
        if (isset(self::VARIANT_MAP[$component->name][$variant])) {
            $variantDef = self::VARIANT_MAP[$component->name][$variant];
            $classes[] = $variantDef['classes'];
            if ($props->get('hover', true)) {
                $classes[] = $variantDef['hover'] ?? '';
            }
        }

        // Size classes
        $sizeClasses = match ($size) {
            'sm' => 'text-sm px-3 py-1.5',
            'md' => 'text-sm px-4 py-2',
            'lg' => 'text-base px-5 py-2.5',
            default => '',
        };
        $classes[] = $sizeClasses;

        return array_filter($classes);
    }
}
```

```php
final class ThrottleComponentRendering
{
    public function handle(Request $request, Closure $next): Response
    {
        $rateLimit = 60; // per minute

        if (RateLimiter::tooManyAttempts('component-render:' . $request->user()?->id, $rateLimit)) {
```

# 23. Component Livewire Integration

## 23.1 Livewire Component Base

```php
abstract class GsmuiComponent extends LivewireComponent
{
    public string $gsmuiVariant = 'primary';
    public string $gsmuiSize = 'md';
    public bool $gsmuiDisabled = false;
    public bool $gsmuiLoading = false;

    public function boot(): void
    {
        // Apply theme tokens
        $this->applyThemeTokens();
    }

    private function applyThemeTokens(): void
    {
        $theme = Theme::where('is_active', true)->first();
        if ($theme) {
            $compiled = app(ThemeCompiler::class)->compile($theme);
            $this->dispatch('theme-updated', tokens: $compiled->tokens);
        }
```

# 29. Component Artisan Commands

```php
final class ComponentCommands extends Command
{
    protected $signature = 'gsmui:component {action} {name?}';
    protected $description = 'Manage GsmUi components';

    public function handle(): int
    {
        return match ($this->argument('action')) {
            'list' => $this->list(),
            'info' => $this->info(),
            'validate' => $this->validateComponent(),
            'render' => $this->renderComponent(),
            default => $this->error('Unknown action'),
        };
    }

    private function list(): int
    {
        $components = app(ComponentRegistry::class)->all();

        $this->table(
            ['Name', 'Category', 'Version', 'Published'],
            $components->map(fn ($c) => [
                $c->name, $c->category, $c->version, $c->is_published ? 'Yes' : 'No',
            ])
        );

        return self::SUCCESS;
    }

    private function info(): int
    {
        $name = $this->argument('name');
        $metadata = app(ComponentRegistry::class)->metadata($name);

        if (!$metadata) {
            $this->error("Component '{$name}' not found");
            return self::FAILURE;
        }

        $this->info("Component: {$metadata['name']}");
        $this->info("Category: {$metadata['category']}");
        $this->info("Version: {$metadata['version']}");
        $this->info("Props: " . count($metadata['props']));
        $this->info("Slots: " . count($metadata['slots']));
        $this->info("Variants: " . count($metadata['variants']));

        return self::SUCCESS;
    }

    private function validateComponent(): int
    {
        $name = $this->argument('name');
        $result = app(PropValidator::class)->validate($name, []);

        if ($result->valid) {
            $this->info("Component '{$name}' schema is valid");
        } else {
            foreach ($result->errors as $error) {
                $this->error("  - {$error}");
            }
        }

        return $result->valid ? self::SUCCESS : self::FAILURE;
    }

    private function renderComponent(): int
    {
        $name = $this->argument('name');
        $result = app(ComponentRenderer::class)->renderNamed($name, []);

        $this->info("Rendered HTML:");
        $this->info($result->html);

        return self::SUCCESS;
    }
}
```

```php
final class ComponentAnalyticsService
{
    public function trackRender(string $componentName, array $props): void
    {
        ComponentRenderLog::create([
            'component' => $componentName,
            'props' => $props,
            'rendered_at' => now(),
            'user_id' => auth()->id(),
            'request_id' => request()->header('X-Request-ID'),
        ]);
    }

    public function getPopularComponents(int $days = 30): Collection
    {
        return ComponentRenderLog::select('component', DB::raw('COUNT(*) as render_count'))
            ->where('rendered_at', '>=', now()->subDays($days))
            ->groupBy('component')
            ->orderByDesc('render_count')
            ->limit(10)
            ->get();
    }

    public function getComponentStats(string $componentName): array
    {
        $renders = ComponentRenderLog::where('component', $componentName)
            ->where('rendered_at', '>=', now()->subDays(30))
            ->get();

        return [
            'total_renders' => $renders->count(),
            'unique_users' => $renders->unique('user_id')->count(),
            'avg_daily_renders' => $renders->groupBy(fn ($r) => $r->rendered_at->format('Y-m-d'))->count(),
            'popular_variants' => $this->getPopularVariants($renders),
        ];
    }
}
```

# 35. Component Service Provider

```php
// app/Providers/ComponentServiceProvider.php
final class ComponentServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton(ComponentRegistry::class, ComponentRegistryManager::class);
        $this->app->singleton(PropSchema::class, PropSchemaManager::class);
        $this->app->singleton(ComponentRenderer::class, ComponentRendererManager::class);
        $this->app->singleton(VariantResolver::class);
        $this->app->singleton(AccessibilityResolver::class);
        $this->app->singleton(ComponentAnalyticsService::class);
    }

    public function boot(): void
    {
        // Auto-discover components
        if (config('components.registry.auto_discover')) {
            $this->discoverComponents();
        }

        // Register Blade component namespace
        Blade::componentNamespace('Gsmui\\View\\Components', 'gsmui');
    }

    private function discoverComponents(): void
    {
        $paths = config('components.registry.discovery_paths');

        foreach ($paths as $path) {
            if (is_dir($path)) {
                $discovery = app(ComponentDiscoveryService::class);
                $discovered = $discovery->discoverFromDirectory($path);

                foreach ($discovered as $metadata) {
                    app(ComponentRegistry::class)->register(
                        $metadata['name'],
                        $metadata['class'],
                        $metadata['category'],
                        $metadata['version']
                    );
                }
            }
        }
    }
}
```

```php
final class LazyComponentLoader
```

## 53.2 Event Propagation

| Strategy | Description | Use Case |
| --- | --- | --- |
| Bubble | Events bubble up DOM | Standard behavior |
| Capture | Events captured on way down | Global handlers |
| Stop | Prevent propagation | Isolated components |
| Self | Only from element itself | Direct handlers |
| Once | Remove after first trigger | Initialization |

## 53.3 Performance Patterns

| Pattern | Description | Impact |
| --- | --- | --- |
| Lazy rendering | Render on demand | Faster initial load |
| Virtual scrolling | Render visible items | Large lists |
| Memoization | Cache computed values | Faster re-renders |
| Debouncing | Throttle rapid updates | Reduced computations |
| Web Workers | Offload heavy work | Better UX |
| Request idle | Defer non-critical work | Smoother interactions |

# 54. Component Engine Database Schema

```php
// component_registry table
Schema::create('component_registry', function (Blueprint $table) {
    $table->id();
    $table->string('name')->unique();
    $table->string('namespace');
    $table->string('category');
    $table->json('props');
    $table->json('slots');
    $table->json('events');
    $table->json('variants');
    $table->boolean('is_public')->default(true);
    $table->timestamps();

    $table->index('name');
    $table->index('category');
    $table->index('is_public');
});

// component_cache table
Schema::create('component_cache', function (Blueprint $table) {
    $table->id();
    $table->string('key')->unique();
    $table->text('value');
    $table->string('hash');
    $table->timestamp('expires_at');
    $table->timestamps();

    $table->index('key');
    $table->index('expires_at');
});

// component_events table
Schema::create('component_events', function (Blueprint $table) {
    $table->id();
    $table->string('event_type');
    $table->string('component_name');
    $table->json('properties');
    $table->foreignId('user_id')->nullable()->constrained('users');
    $table->timestamps();

    $table->index('event_type');
    $table->index('component_name');
    $table->index('user_id');
});
```

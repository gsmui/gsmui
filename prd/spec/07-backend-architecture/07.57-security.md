# 1. Content Security Policy (CSP)

CSP is delivered by a middleware registered in the `web` and `api` stacks. GsmUi ships zero external resources (no CDN fonts/scripts), enabling a strict policy.

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

final class ContentSecurityPolicy
{
    public function handle(Request $request, Closure $next): Response
    {
        $response = $next($request);

        $csp = implode('; ', [
            "default-src 'self'",
            "script-src 'self'",
            "style-src 'self' 'unsafe-inline'",        // adoptedStyleSheets + inline component CSS
            "img-src 'self' data:",
            "font-src 'self'",
            "connect-src 'self'",
            "frame-ancestors 'none'",
            "base-uri 'self'",
            "form-action 'self'",
            "object-src 'none'",
        ]);

        return $response->header('Content-Security-Policy', $csp);
    }
}
```

Add the other secure headers alongside:

```php
$response->withHeaders([
    'X-Frame-Options' => 'DENY',
    'X-Content-Type-Options' => 'nosniff',
    'Referrer-Policy' => 'strict-origin-when-cross-origin',
    'Permissions-Policy' => 'geolocation=(), microphone=(), camera=()',
    'Strict-Transport-Security' => 'max-age=31536000; includeSubDomains',
]);
```

Register in `bootstrap/app.php`:

```php
->withMiddleware(function (Middleware $middleware): void {
    $middleware->append(\App\Http\Middleware\ContentSecurityPolicy::class);
})
```

For environments exposing the policy config (publishable like gsmui-pro-csp), load the directive string from `config('gsmui-pro-csp.policy')` instead of hardcoding.

# 2. CSRF Protection

Laravel enables CSRF by default for `web` routes. Verify it is present and exempt only token/SPA flows correctly.

```php
// bootstrap/app.php
->withMiddleware(function (Middleware $middleware): void {
    $middleware->validateCsrfTokens(
        except: ['api/webhooks/stripe', 'api/webhooks/meilisearch']
    );
})
```

- All forms and Livewire requests run through the `VerifyCsrfToken` middleware (`05.15-security.md`).
- Sanctum SPA cookie auth uses `EnsureFrontendRequestsAreStateful` + CSRF cookie endpoint; token (Bearer) requests are stateless and exempt.
- Never disable CSRF globally. Exempt only explicit, signed webhook routes.

Controllers declare resource authorization via policies (`07.15-policies.md`); cross-cutting abilities use gates (`07.16-gates.md`). Spatie Permission supplies role/permission checks.

```php
final class ComponentController extends Controller

    {

```

Route-level gate guard for admin surfaces:

```php
Route::middleware(['auth:sanctum', 'can:access admin'])->group(
    fn () => Route::get('admin/users', AdminUserController::class)
);
```

Custom authorization middleware example (`can:publish themes`):

```php
Route::post('components/{component}/publish', [ComponentController::class, 'publish'])
    ->middleware('can:publish themes,component');
```

Spatie role seeding contract:

```php
use Spatie\Permission\Models\Role;

$role = Role::firstOrCreate(['name' => 'Moderator']);
$role->givePermissionTo(['moderate content', 'hide showcase']);
```

Policies contain authorization logic only — never business logic or queries that mutate state.

# 4. Secret Handling

Never commit secrets. Load from `.env`; in production use a vault (Laravel 13 encrypted env or cloud secret manager) injected at boot.

```dotenv
# .env (never committed)
STRIPE_SECRET=sk_live_***
MEILISEARCH_KEY=master_***
SANCTUM_STATEFUL_DOMAINS=gsmui.test
```

Access exclusively through `config()` (never `env()` outside config files):

```php
// config/services.php
'stripe' => [
    'secret' => env('STRIPE_SECRET'),
],

// usage
\Illuminate\Support\Facades\Config::get('services.stripe.secret');
```

Rotation policy:

- API keys rotated every 90 days; on leak, rotate immediately and revoke old.
- Encrypt stored credentials (recovery codes, external API creds) with `Crypt::encrypt()` (`05.15-security.md`).
- `.env.example` ships placeholder keys only.

CI must fail if a real secret is detected:

```yaml
secret_scan:
  script:
    - grep -rEn 'sk_live_|pk_live_|AIza[0-9A-Za-z_-]{35}' app config --exclude=*.example || true
```

# 5. Threat Model

## XSS

- Blade auto-escaping is default. Rich user HTML (component descriptions) passes through an allowlist sanitizer before storage/render — never `{{ }}` on raw user HTML.
- CSP (`#1`) neutralizes injected scripts even if escaping is missed.
- Set `Cookie::queue(Cookie::make('session', ..., false, true, true, false, 'lax'))` — HTTPOnly + Secure.

## SQL Injection

- Eloquent + Query Builder only. Parameter binding is automatic.
- Repository layer (`07.07-repository-layer.md`) forbids raw `DB::statement()` with concatenated input.
- `whereRaw()` permitted only with bound parameters: `whereRaw('downloads > ?', [$min])`.

## SSRF — Webhooks & AI Integrations

External fetch calls (webhook dispatch, AI provider calls, image proxy) must validate the target.

```php
final class SafeHttpClient
{
    /** @var string[] */
    private const BLOCKED = ['169.254.169.254', 'localhost', '127.0.0.1', '::1'];

    public function get(string $url): Response
    {
        $host = parse_url($url, PHP_URL_HOST);

        if (in_array($host, self::BLOCKED, true) || filter_var($host, FILTER_VALIDATE_IP) === false) {
            throw new \App\Exceptions\Infrastructure\ExternalServiceException(
                message: "Blocked outbound request to {$host}",
                userMessage: 'External request rejected.',
            );
        }

        return Http::timeout(5)->get($url);
    }
}
```

Webhook receivers verify signature + timestamp + replay:

```php
public function handle(Request $request): Response
{
    $sig = hash_hmac('sha256', $request->getContent(), config('services.stripe.webhook_secret'));
    abort_unless(hash_equals($sig, (string) $request->header('X-Signature')), 403);

    $ts = (int) $request->header('X-Timestamp');
    abort_if(abs(time() - $ts) > 300, 403, 'Replay window exceeded');

    // idempotent: dedupe by event id
    abort_if(EventReceipt::where('event_id', $request->input('id'))->exists(), 200);
    EventReceipt::create(['event_id' => $request->input('id')]);

    return response()->json(['ok' => true]);
}
```

AI integration (LLM component generation) treats model output as untrusted: sanitize before persisting, never execute, never reflect into `eval`/template eval.

# 6. Rate Limiting

Named limiters defined in `bootstrap/app.php` (aligns with `05.15-security.md` and `07.21-api-architecture.md`).

```php
use Illuminate\Cache\RateLimiting\Limit;
use Illuminate\Support\Facades\RateLimiter;

RateLimiter::for('login', fn ($r) => Limit::perMinute(5)->by($r->ip()));
RateLimiter::for('api', fn ($r) =>
    $r->user() ? Limit::perMinute(120)->by($r->user()->id)
               : Limit::perMinute(60)->by($r->ip()));
RateLimiter::for('search', fn ($r) => Limit::perMinute(30)->by($r->ip()));
RateLimiter::for('contact', fn ($r) => Limit::perHour(10)->by($r->ip()));
```

Applied at route level: `->middleware('throttle:login')`. On breach, log at `alert` to the audit channel (`07.54-logging.md`).

# 13. Authorization Patterns

## 13.1 Policy Authorization

```php
final class ComponentPolicy
{
    public function viewAny(User $user): bool
    {
        return true;
    }

    public function view(User $user, Component $component): bool
    {
        return $component->published_at !== null || $component->user_id === $user->id;
    }

    public function create(User $user): bool
    {
        return $user->hasRole('developer');
    }

    public function update(User $user, Component $component): bool
    {
        return $user->id === $component->user_id;
    }

    public function delete(User $user, Component $component): bool
    {
        return $user->id === $component->user_id || $user->hasRole('admin');
    }

    public function forceDelete(User $user, Component $component): bool
    {
        return $user->hasRole('admin');
    }
}
```

```php
final class SecretRotation
{
    public function rotate(string $secretName): void
    {
        $oldSecret = config("services.{$secretName}");
        $newSecret = $this->generateNewSecret();

        // Store new secret
        Config::set("services.{$secretName}", $newSecret);

        // Update vault/env
        $this->updateVault($secretName, $newSecret);

        // Log rotation
        Log::channel('audit')->info('secret_rotated', [
            'secret' => $secretName,
            'rotated_by' => auth()->id(),
        ]);
    }
}
```

# 18. Webhook Security

## 18.1 Signature Verification

```php
final class WebhookVerifier
{
    public function verifyStripe(Request $request): bool
    {
        $signature = $request->header('X-Signature');
        $timestamp = $request->header('X-Timestamp');

        // Check timestamp (prevent replay attacks)
        if (abs(time() - (int) $timestamp) > 300) {
            return false;
        }

        // Verify signature
        $expected = hash_hmac('sha256', "{$timestamp}.{$request->getContent()}", config('services.stripe.webhook_secret'));
        return hash_equals($expected, $signature);
    }
}
```

## 18.2 Idempotency

```php
final class WebhookHandler
{
    public function handle(Request $request): Response
    {
        $eventId = $request->input('id');

        // Deduplicate events
        if (EventReceipt::where('event_id', $eventId)->exists()) {
            return response()->json(['ok' => true]);
        }

        // Record event receipt
        EventReceipt::create(['event_id' => $eventId]);

        // Process webhook
        $this->processWebhook($request);

        return response()->json(['ok' => true]);
    }
}
```

# 19. SSRF Prevention

## 19.1 URL Validation

```php
final class SafeHttpClient
{
    private const BLOCKED_HOSTS = ['169.254.169.254', 'localhost', '127.0.0.1', '::1'];
    private const ALLOWED_SCHEMES = ['http', 'https'];

    public function get(string $url): Response
    {
        $parsed = parse_url($url);

        if (!in_array($parsed['scheme'] ?? '', self::ALLOWED_SCHEMES, true)) {
            throw new InvalidArgumentException('Invalid URL scheme.');
        }

        if (in_array($parsed['host'] ?? '', self::BLOCKED_HOSTS, true)) {
            throw new InvalidArgumentException('Blocked URL host.');
        }

        if (filter_var($parsed['host'] ?? '', FILTER_VALIDATE_IP)) {
            throw new InvalidArgumentException('IP addresses not allowed.');
        }

        return Http::timeout(5)->get($url);
    }
}
```

## 20.2 Intrusion Detection

```php
final class IntrusionDetector
{
    public function detect(Request $request): bool
    {
        $patterns = [
            '/etc/passwd',
            '../../',
            '<script>',
            'javascript:',
            'eval(',
            'UNION SELECT',
            'DROP TABLE',
        ];

        $input = $request->query() . $request->post();

        foreach ($patterns as $pattern) {
            if (str_contains($input, $pattern)) {
                Log::channel('security')->alert('intrusion_attempt', [
                    'pattern' => $pattern,
                    'path' => $request->path(),
                    'ip' => $request->ip(),
                ]);
                return true;
            }
        }

        return false;
    }
}
```

# 27. Security Incident Response

## 27.1 Incident Response Plan

```php
final class IncidentResponse
{
    public function handleSecurityIncident(string $type, array $context): void
    {
        // 1. Log the incident
        Log::channel('security')->alert("security_incident_{$type}", $context);

        // 2. Block malicious IP if applicable
        if (isset($context['ip'])) {
            $this->blockIp($context['ip']);
        }

        // 3. Notify admin team
        $this->notifyAdmins($type, $context);

        // 4. Preserve evidence
        $this->preserveEvidence($type, $context);

        // 5. Begin remediation
        $this->remediate($type, $context);
    }

    private function blockIp(string $ip): void
    {
        Cache::put("blocked_ip:{$ip}", true, now()->addHours(24));
        Log::channel('security')->info('ip_blocked', ['ip' => $ip]);
    }
}
```

## 27.2 Evidence Preservation

```php
final class EvidencePreserver
{
    public function preserve(string $incidentType, array $context): void
    {
        $evidence = [
            'incident_type' => $incidentType,
            'timestamp' => now()->toIso8601String(),
            'request_data' => $context,
            'server_state' => [
                'memory' => memory_get_usage(true),
                'cpu' => sys_getloadavg(),
                'uptime' => sys_get_uptime(),
            ],
            'database_state' => $this->captureDatabaseState(),
        ];

        $path = storage_path("evidence/{$incidentType}_" . now()->timestamp . '.json');

    }
}
```

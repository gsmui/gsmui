# 07.14 - Jobs

**Project:** GsmUi
**Architecture:** Background Processing & Queue System
**Framework:** Laravel 13 + Horizon + Redis
**Version:** 1.0.0

---

# Purpose

Jobs encapsulate long-running, resource-intensive, or asynchronous work that must not block the HTTP request lifecycle. Actions dispatch jobs after a successful business operation (see `05.09-actions.md`); jobs then execute on Horizon workers backed by Redis. This keeps controllers and Livewire components responsive while guaranteeing reliable retries, failure isolation, and observability.

This document specifies the concrete job contracts: a shared `AbstractJob` base, synchronous vs queued vs unique job shapes, job middleware for rate limiting and overlap prevention, retry/backoff configuration, and how jobs map onto the Horizon queue topology defined conceptually in `05.11-jobs.md`.

> See also: `05.11-jobs.md` (queue topology, priorities, naming, retry policy, worker scaling). This document is the *implementation contract* for those jobs.

---

# 1. Job Rules

1. **Pass IDs, not models.** Serialize `componentId`, not a `Component` instance (avoids stale-model and serialization issues).
2. **Never store secrets/tokens in the payload.** See `06.01` §8.
3. **Eager load inside the job.** Do not assume relationships are loaded by the dispatcher.
4. **Backoff on failure.** Always set `$tries`, `$timeout`, and `$backoff`.
5. **Idempotent.** Critical jobs (payments, licenses, webhooks) use `ShouldBeUnique` or an idempotency key (see `06.01` §15).

# 3. Abstract Job Base

All domain jobs extend a shared base for consistent queue/timeout defaults.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Shared\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;

abstract class AbstractJob implements ShouldQueue
{
    use Dispatchable;
    use InteractsWithQueue;
    use Queueable;
    use SerializesModels;

    public int $tries = 3;

    public int $timeout = 120;

    public array $backoff = [10, 30, 60];

    public string $queue = 'default';

    abstract public function handle(): void;
}
```

# 4. Queued Job (concrete)

```php
<?php

declare(strict_types=1);

namespace App\Domains\Themes\Jobs;

use App\Domains\Shared\Jobs\AbstractJob;

final class GenerateThemeAssets extends AbstractJob
{
    public string $queue = 'exports';

    public int $timeout = 180;

    public function __construct(
        public readonly int $themeId,
    ) {}

    public function handle(): void
    {
        $service = app(\App\Domains\Themes\Services\ThemeAssetService::class);

        $service->build($this->themeId);
    }
}
```

Dispatch:

```php
GenerateThemeAssets::dispatch($themeId)->onQueue('exports');
```

# 5. Unique Jobs

Use `ShouldBeUnique` to prevent concurrent or duplicate processing of the same logical unit of work.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Billing\Jobs;

use App\Domains\Shared\Jobs\AbstractJob;
use Illuminate\Contracts\Queue\ShouldBeUnique;

final class GenerateInvoicePdf extends AbstractJob implements ShouldBeUnique
{
    public string $queue = 'mail';

    public function __construct(
        public readonly int $orderId,
    ) {}

    public function uniqueId(): string
    {
        return "invoice:{$this->orderId}";
    }

    public function handle(): void
    {
        app(\App\Domains\Billing\Services\InvoiceService::class)->renderPdf($this->orderId);
    }
}
```

# 6. Job Middleware

Apply `RateLimiter` and `WithoutOverlapping` to protect external services and shared resources.

```php
use Illuminate\Queue\Middleware\RateLimited;
use Illuminate\Queue\Middleware\WithoutOverlapping;

public function middleware(): array
{
    return [
        new RateLimited('stripe'),
        (new WithoutOverlapping("subscription:{$this->billableId}"))->dontRelease(),
    ];
}
```

The `stripe` rate limiter is registered in `AppServiceProvider`:

```php
RateLimiter::for('stripe', fn () => Limit::perMinute(100));
```

# 8. Horizon Mapping

Queue assignment directly drives Horizon's `config/horizon.php`:

```php
'environments' => [
    'production' => [
        'high'    => ['connection' => 'redis', 'queue' => 'high',    'maxProcesses' => 6],
        'default' => ['connection' => 'redis', 'queue' => 'default', 'maxProcesses' => 4],
        'media'   => ['connection' => 'redis', 'queue' => 'media',   'maxProcesses' => 4],
        'search'  => ['connection' => 'redis', 'queue' => 'search',  'maxProcesses' => 2],
        'exports' => ['connection' => 'redis', 'queue' => 'exports', 'maxProcesses' => 2],
    ],
],
```

Dispatch onto the matching queue so worker pools scale independently (priority order: `high` → `default` → `mail` → `media` → `search` → `exports` → `imports` → `low` → `backups`).

# 9. Security & Serialization

```php
// Forbidden — leaks user/session context into the queue
WebhookProcess::dispatch(request()->all());

// Allowed — minimal, serializable payload

```

Sensitive queued data is encrypted at rest via Laravel's queue encryption configuration, not stored in plain payloads (see `06.01` §8).

# 12. Job Types Comparison

| Type | Use Case | Dispatch | Execution | Example |
| --- | --- | --- | --- | --- |
| Sync Job | Immediate, lightweight | `dispatchSync()` | Same process | Cache clear |
| Queued Job | Background, I/O-heavy | `dispatch()` or `dispatch()->onQueue()` | Horizon worker | Search indexing |
| Unique Job | Prevent duplicates | `dispatch()->uniqueId()` | Horizon worker (unique lock) | Invoice generation |
| Chained Jobs | Sequential workflow | `Bus::chain([...])` | Horizon workers in order | PDF → email → stats |
| Batched Jobs | Parallel workflow | `Bus::batch([...])` | Horizon workers in parallel | Process multiple items |

# 13. Job Lifecycle

```text
┌─────────────────────────────────────────────────────────────────────────┐
│                    JOB LIFECYCLE                                          │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  1. ACTION DISPATCHES JOB                                                │
│     ┌──────────────────────────────────────────────┐                    │
│     │  GenerateThemeAssets::dispatch($themeId)     │                    │
│     │  ->onQueue('exports');                       │                    │
│     └──────────────────────────────────────────────┘                    │
│                                                                         │
│  2. JOB STORED IN QUEUE (Redis)                                         │
│     ┌──────────────────────────────────────────────┐                    │
│     │  Redis LPUSH queues:exports {job payload}    │                    │
│     └──────────────────────────────────────────────┘                    │
│                                                                         │
│  3. HORIZON WORKER PICKS UP JOB                                         │
│     ┌──────────────────────────────────────────────┐                    │
│     │  Worker reads from Redis queue               │                    │
│     │  Deserializes job class                      │                    │
│     │  Calls handle() method                       │                    │
│     └──────────────────────────────────────────────┘                    │
│                                                                         │
│  4. JOB EXECUTES                                                        │
│     ┌──────────────────────────────────────────────┐                    │
│     │  ThemeAssetService::build($themeId)          │                    │
│     │  Generates CSS, JS, images                   │                    │
│     └──────────────────────────────────────────────┘                    │
│                                                                         │
│  5. SUCCESS OR FAILURE                                                   │
│     ┌──────────────────────────────────────────────┐                    │
│     │  Success: Job removed from queue             │                    │
│     │  Failure: Retry with backoff                 │                    │
│     │  Max retries: Move to failed_jobs table      │                    │
│     └──────────────────────────────────────────────┘                    │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

# 15. Abstract Job Base Extended

All domain jobs extend a shared base for consistent queue/timeout defaults:

```php
<?php

declare(strict_types=1);

namespace App\Domains\Shared\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;

abstract class AbstractJob implements ShouldQueue
{
    use Dispatchable;
    use InteractsWithQueue;
    use Queueable;
    use SerializesModels;

    public int $tries = 3;

    public int $timeout = 120;

    public array $backoff = [10, 30, 60];

    public string $queue = 'default';

    public function __construct()
    {
        // Default constructor — subclasses override
    }

    abstract public function handle(): void;

    public function failed(\Throwable $exception): void
    {
        report($exception);

        logger()->error('job.failed', [
            'job' => static::class,
            'error' => $exception->getMessage(),
            'queue' => $this->queue,
        ]);
    }

    public function retryUntil(): \DateTime
    {
        return now()->addMinutes(30);
    }
}
```

# 18. Job Middleware Deep Dive

```php
use Illuminate\Queue\Middleware\RateLimited;
use Illuminate\Queue\Middleware\WithoutOverlapping;
use Illuminate\Queue\Middleware\EnsureUnique;

final class ProcessPayment extends AbstractJob
{
    public string $queue = 'high';

    public function middleware(): array
    {
        return [
            new RateLimited('stripe'),
            (new WithoutOverlapping("payment:{$this->orderId}"))->dontRelease(),
            new EnsureUnique,
        ];
    }

    public function __construct(
        public readonly int $orderId,
        public readonly int $amountCents,
    ) {}

    public function handle(): void
    {
        app(StripeService::class)->charge(
            orderId: $this->orderId,
            amount: $this->amountCents,
        );
    }
}
```

Middleware types:

| Middleware | Purpose | Example |
| --- | --- | --- |
| `RateLimited` | Throttle external API calls | `new RateLimited('stripe')` |
| `WithoutOverlapping` | Prevent concurrent processing | `new WithoutOverlapping("order:{$id}")` |
| `EnsureUnique` | Prevent duplicate jobs | `new EnsureUnique` |
| `FIFO` | Process in order | `new FIFO` |
| `SkipIf` | Conditionally skip | `new SkipIf(fn () => $this->alreadyProcessed())` |

# 19. Retries & Backoff Extended

```php
final class SyncToStripe extends AbstractJob
{
    public string $queue = 'high';

    public int $tries = 5;

    public array $backoff = [5, 15, 60, 120, 300];

    public function __construct(
        public readonly int $orderId,
    ) {}

    public function handle(): void
    {
        app(StripeService::class)->syncOrder($this->orderId);
    }

    public function failed(\Throwable $exception): void
    {
        report($exception);

        // Notify admin after max retries
        if ($this->attempts() >= $this->tries) {
            Notification::send(
                User::where('is_admin', true)->get(),
                new PaymentSyncFailedNotification($this->orderId, $exception)
            );
        }
    }

    public function retryUntil(): \DateTime
    {
        return now()->addHours(2);
    }

    public function backoff(): array
    {
        return [5, 15, 60, 120, 300];
    }
}
```

Backoff strategies:

| Strategy | Pattern | Use Case |
| --- | --- | --- |
| Linear | `[10, 20, 30]` | General background work |
| Exponential | `[10, 30, 60, 120, 300]` | External API calls |
| Aggressive | `[5, 10, 15]` | Time-sensitive operations |
| Conservative | `[60, 120, 300, 600]` | Rate-limited services |

# 21. Job Security & Serialization Extended

```php
// FORBIDDEN — leaks user/session context into the queue
WebhookProcess::dispatch(request()->all());

// FORBIDDEN — stores model in payload (may be stale)
ProcessOrder::dispatch($order);

// FORBIDDEN — stores secrets in payload
ChargePayment::dispatch($orderId, $stripeSecretKey);

// ALLOWED — minimal, serializable payload
WebhookProcess::dispatch($eventId);

// ALLOWED — scalar ID only
ProcessOrder::dispatch($orderId);

// ALLOWED — secret from config, not payload
ChargePayment::dispatch($orderId);
```

Security rules:

| Rule | Reason | Example |
| --- | --- | --- |
| Pass IDs, not models | Models may be stale after dispatch | `$orderId` not `$order` |
| No secrets in payload | Queue may be accessed by others | Use `config()` for secrets |
| No request objects | Ties job to HTTP context | Use scalar values |
| No service objects | Hidden coupling | Listener constructs services |
| Encrypted payloads | Protect sensitive data | Laravel queue encryption |

# 22. Job Error Handling Extended

```php
final class ProcessRefund extends AbstractJob
{
    public string $queue = 'high';

    public int $tries = 5;

    public array $backoff = [5, 15, 60, 120, 300];

    public function __construct(
        public readonly int $orderId,
        public readonly int $amountCents,
    ) {}

    public function handle(): void
    {
        try {
            app(StripeService::class)->refund(
                orderId: $this->orderId,
                amount: $this->amountCents,
            );
        } catch (\Stripe\Exception\ApiErrorException $e) {
            logger()->error('refund.stripe_failed', [
                'order_id' => $this->orderId,
                'error' => $e->getMessage(),
            ]);

            throw $e; // Re-throw to trigger retry
        }
    }

    public function failed(\Throwable $exception): void
    {
        report($exception);

        logger()->error('refund.failed_permanently', [
            'order_id' => $this->orderId,
            'amount' => $this->amountCents,
            'error' => $exception->getMessage(),
            'attempts' => $this->attempts(),
        ]);

        // Notify admin after max retries
        if ($this->attempts() >= $this->tries) {
            Notification::send(
                User::where('is_admin', true)->get(),
                new RefundFailedNotification($this->orderId, $exception)
            );
        }
    }
}
```

# 24. Job Chain Pattern

Chain multiple jobs for sequential processing:

```php
use Illuminate\Support\Facades\Bus;

Bus::chain([
    new GenerateInvoicePdf($orderId),
    new SendInvoiceEmail($orderId, $userId),
    new UpdateRevenueStats($orderId),
])->onConnection('redis')->onQueue('high')->dispatch();
```

Chain patterns:

| Pattern | Use Case | Example |
| --- | --- | --- |
| Simple chain | Sequential processing | PDF → email → stats |
| Conditional chain | Branch based on result | Process → if success → notify |
| Error chain | Fallback on failure | Try → catch → compensate |
| Parallel chain | Fan-out then fan-in | Process items → aggregate results |

# 25. Job Batch Pattern

Process multiple jobs in parallel:

```php
use Illuminate\Support\Facades\Bus;

$batch = Bus::batch([
    new ProcessItem1($id),
    new ProcessItem2($id),
    new ProcessItem3($id),
```

# 26. Job Middleware Types

```php
final class ProcessPayment extends AbstractJob
{
    public function middleware(): array
    {
        return [
            // Rate limit external API calls
            new RateLimited('stripe'),

            // Prevent concurrent processing of same order
            (new WithoutOverlapping("payment:{$this->orderId}"))->dontRelease(),

            // Prevent duplicate jobs
            new EnsureUnique,

            // Process in FIFO order

            // Skip if already processed

    }
}
```

| `EnsureUnique` | Prevent duplicates | `new EnsureUnique` |

| `SkipIf` | Conditionally skip | `new SkipIf(fn () => $condition)` |

# 33. Job Anti-Patterns Complete List

| Anti-pattern | Why it's bad | Correct approach |
| --- | --- | --- |
| Business logic in job | Violates SRP | Delegate to Service |
| Non-idempotent job | Duplicate side effects | Use unique constraints |
| Missing failure handling | Silent failures | Implement `failed()` method |
| Job with too many responsibilities | Hard to maintain | Split into multiple jobs |
| Missing queue configuration | Default queue may be wrong | Set `$queue` explicitly |
| Missing timeout | Jobs may hang forever | Set `$timeout` |
| Missing tries | No retry on failure | Set `$tries` and `$backoff` |
| Job accessing request | Ties to HTTP context | Use scalar values only |
| Job with database queries | Performance impact | Batch or optimize queries |
| Job with secrets in payload | Security risk | Use config for secrets |
| Job with model in payload | Stale data risk | Pass scalar IDs |
| Job without middleware | No rate limiting | Add `RateLimited` middleware |
| Job without logging | No observability | Add structured logging |

```php
    }

    public function handle(): void
    {
        try {
            DB::table('licenses')->insert([
                'user_id' => $this->userId,
                'product_id' => $this->productId,
                'order_id' => $this->orderId,
                'created_at' => now(),
            ]);
        } catch (\Illuminate\Database\QueryException $e) {
            // Duplicate key = already granted
            if (str_contains($e->getMessage(), 'Duplicate entry')) {
                return;
            }
            throw $e;
        }
```

# 68. Job and Webhook Processing

```php
final class ProcessWebhook extends AbstractJob
{
    public string $queue = 'high';

    public int $tries = 5;

    public array $backoff = [5, 15, 60, 120, 300];

    public function __construct(
        public readonly int $webhookId,
        public readonly array $payload,
    ) {}

    public function handle(): void
    {
        $webhook = Webhook::find($this->webhookId);

        if (!$webhook) {
            return;
        }

        // Verify signature
        $signature = hash_hmac('sha256', json_encode($this->payload), $webhook->secret);

        if ($signature !== $this->payload['signature']) {
            logger()->warning('webhook.invalid_signature', [
                'webhook_id' => $this->webhookId,
            ]);

            return;
        }

        // Process webhook
        app(WebhookService::class)->process($webhook, $this->payload);
    }
}
```

```php
final class ExportData extends AbstractJob
{
    public string $queue = 'exports';

    public int $tries = 3;

    public int $timeout = 300;

    public function __construct(
        public readonly int $userId,
        public readonly string $type,
        public readonly array $filters = [],
    ) {}

    public function handle(): void
    {
        $user = User::find($this->userId);

        if (!$user) {
            return;
        }

        $data = match ($this->type) {
            'components' => Component::where('user_id', $user->id)->get(),
            'themes' => Theme::where('user_id', $user->id)->get(),
            'orders' => Order::where('user_id', $user->id)->get(),
            default => collect(),
        };

        $csv = $this->convertToCsv($data);

        Storage::disk('exports')->put("exports/{$user->id}_{$this->type}.csv", $csv);

        Mail::to($user->email)->send(new ExportReadyMail($this->type));
    }

    private function convertToCsv($data): string
    {
        $output = fopen('php://temp', 'r+');

        if ($data->isEmpty()) {
            return '';
        }

        // Header
        fputcsv($output, array_keys($data->first()->toArray()));

        // Rows
        foreach ($data as $row) {
            fputcsv($output, $row->toArray());
        }

        rewind($output);
        $csv = stream_get_contents($output);
        fclose($output);

        return $csv;
    }
}
```

```php
final class ImportData extends AbstractJob
{
    public string $queue = 'imports';

    public int $tries = 3;

    public int $timeout = 300;

    public function __construct(
        public readonly int $userId,
        public readonly string $filePath,
        public readonly string $type,
    ) {}

    public function handle(): void
    {
        $user = User::find($this->userId);

        if (!$user) {
            return;
        }

        $path = Storage::disk('imports')->path($this->filePath);

        $csv = array_map('str_getcsv', file($path));

        // Remove header
        $header = array_shift($csv);

        foreach ($csv as $row) {
            $data = array_combine($header, $row);

            match ($this->type) {
                'components' => $this->importComponent($user, $data),
                'themes' => $this->importTheme($user, $data),
                default => null,
            };
        }
    }

    private function importComponent(User $user, array $data): void
    {
        Component::create([
            'user_id' => $user->id,
            'name' => $data['name'],
            'slug' => Str::slug($data['name']),
            'description' => $data['description'] ?? '',
        ]);
    }

    private function importTheme(User $user, array $data): void
    {
        Theme::create([
            'user_id' => $user->id,
            'name' => $data['name'],
            'slug' => Str::slug($data['name']),
            'description' => $data['description'] ?? '',
        ]);
    }
}
```

```php
final class HealthCheck extends AbstractJob
{
    public string $queue = 'low';

    public int $tries = 1;

    public int $timeout = 30;

    public function handle(): void
    {
        $checks = [
            'database' => $this->checkDatabase(),
            'cache' => $this->checkCache(),
            'queue' => $this->checkQueue(),
            'storage' => $this->checkStorage(),
        ];

        $failed = array_filter($checks, fn ($check) => !$check);

        if (!empty($failed)) {
            Notification::send(
                User::where('is_admin', true)->get(),
                new HealthCheckFailedNotification($failed)
            );
        }
    }

    private function checkDatabase(): bool
    {
        try {
            DB::connection()->getPdo();
            return true;
        } catch (\Exception $e) {
            return false;
        }
    }

    private function checkCache(): bool
    {
        try {
            cache()->put('health_check', true, 10);
            return cache()->get('health_check') === true;
        } catch (\Exception $e) {
            return false;
        }
    }

    private function checkQueue(): bool
    {
        try {
            Queue::size();
            return true;
        } catch (\Exception $e) {
            return false;
        }
    }

    private function checkStorage(): bool
    {
        try {
            Storage::disk('local')->put('health_check.txt', 'ok');
            Storage::disk('local')->delete('health_check.txt');
            return true;
        } catch (\Exception $e) {
            return false;
        }
    }
}
```

# 07.48 - Models

**Project:** GsmUi
**Architecture:** Eloquent Base Model Conventions
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `06.01-design-principles.md` (audit fields, soft-delete policy, immutable records, encryption) for the schema contract that every GsmUi model must honor. This document is the *implementation contract*: the `BaseModel` abstract, casts, relationship conventions, global scopes, and `resolveRouteBinding` overrides that repositories and observers build on.

# Purpose

Eloquent models in GsmUi follow one shared contract so repositories (see `07.07-repository-layer.md`), observers (see `07.47-observers.md`), and factories (see `07.55-testing.md`) behave uniformly. This document specifies the `BaseModel` every domain model extends, the rules for casts and relationships, the global scopes that enforce soft-delete isolation, and the route-binding conventions used by controllers and Livewire.

Goals:

- **One base class** — every model extends `BaseModel` to inherit timestamp/soft-delete behavior, default guarded policy, and route-binding rules.
- **Typed by default** — all JSON/date/enum columns are declared in `casts()`; no raw `array` access on untyped attributes.
- **Scoped consistently** — `SoftDeletes` and any domain global scope are applied in one place.
- **Binding-aware** — `resolveRouteBinding()` resolves by `slug` where present, else by `id`, so route keys are human-friendly.

## 1. BaseModel Abstract

`BaseModel` centralizes cross-cutting model behavior. It is `abstract` and `declare(strict_types=1)`.

```php
declare(strict_types=1);

namespace App\Shared\Models;

use Illuminate\Database\Eloquent\Concerns\HasUuids;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\SoftDeletes;

abstract class BaseModel extends Model
{
    // Subclasses opt in to SoftDeletes by using the trait; the base does not force it,
    // honoring 06.01 §3 (user content soft-deletes, config tables do not).

    /** Default to guarding nothing explicitly; subclasses declare $fillable. */
    protected $guarded = [];

    /** Every timestamp is cast; subclasses add domain casts. */
    protected function casts(): array
    {
        return [
            'created_at' => 'datetime',
            'updated_at' => 'datetime',
            'deleted_at' => 'datetime',
        ];
    }

    /**
     * Route-model binding resolves by 'slug' when the model has one,
     * otherwise by the primary key. Controllers/Livewire get a typed model.
     */
    public function resolveRouteBinding($value, $field = null)
    {
        if ($field === null && $this->getRouteKeyName() === 'slug') {
            return $this->where('slug', $value)->firstOrFail();
        }

        return parent::resolveRouteBinding($value, $field);
    }

    public function getRouteKeyName(): string
    {
        return $this->hasColumn('slug') ? 'slug' : $this->getKeyName();
    }
}
```

## 2. Example Domain Model

A concrete model extends `BaseModel`, opts into `SoftDeletes` where it is user content, declares `fillable`, and centralizes casts including enum casting (see `07.11-enums.md`).

```php
declare(strict_types=1);

namespace App\Domains\Components\Models;

use App\Domains\Components\Enums\ComponentStatus;
use App\Shared\Models\BaseModel;
use Illuminate\Database\Eloquent\Relations\{BelongsTo, HasMany};
use Illuminate\Database\Eloquent\SoftDeletes;

final class Component extends BaseModel
{
    use SoftDeletes; // user content — 06.01 §3

    protected $fillable = [
        'name', 'slug', 'description', 'status', 'category_id', 'author_id', 'latest_version',
    ];

    protected function casts(): array
    {
        return array_merge(parent::casts(), [
            'status'        => ComponentStatus::class, // string-backed enum
            'latest_version' => 'integer',
        ]);
    }

    public function category(): BelongsTo
    {
        return $this->belongsTo(\App\Domains\Components\Models\ComponentCategory::class);
    }

    public function author(): BelongsTo
    {
        return $this->belongsTo(\App\Domains\Users\Models\User::class, 'author_id');
    }

    public function versions(): HasMany
    {
        return $this->hasMany(\App\Domains\Components\Models\ComponentVersion::class);
    }

    /** Domain global scope: default listing excludes soft-deleted rows (Eloquent default). */
    protected static function booted(): void
    {
        // Example: always eager-load the category for list views.
        static::addGlobalScope('with_category', fn ($q) => $q->with('category'));
    }
}
```

## 3. Casts Conventions

| Column kind | Cast | Notes |
| --- | --- | --- |
| `JSON` / `properties` | `array` | Decoded on read, encoded on write |
| Date/timestamp | `datetime` | UTC; display layer converts TZ |
| Backed enum | `ComponentStatus::class` | `null` allowed only when column nullable |
| Encrypted secret | `encrypted` | AES-256 (06.01 §8) |
| Boolean flag | `boolean` | Defaults to `false`, never `null` (06.01 §11) |

Casts are declared in `casts()` (Laravel 13 style), not the legacy `$casts` property.

---

## 4. Relationship Conventions

- Use typed return types (`BelongsTo`, `HasMany`) for IDE/static-analysis support.
- Name the inverse explicitly where the FK is non-standard (`belongsTo(User::class, 'author_id')`).
- Eager-load lists are centralized in the repository (see `07.07-repository-layer.md`), not scattered across controllers; a domain global scope may add a default `with()` for list views.
- Polymorphic relations (`morphTo`) follow `06.01-design-principles.md` §6 for billable entities.

## 5. Global Scopes

Global scopes enforce cross-cutting query behavior in one place:

```php
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Scope;

final class ApprovedScope implements Scope
{
    public function apply(Builder $builder, Model $model): void
    {
        if (! auth()->user()?->can('viewUnapproved', $model)) {
            $builder->where('status', \App\Domains\Components\Enums\ComponentStatus::Published);
        }
    }
}
```

Apply per model in `booted()` only where the scope is domain-specific; do not put business scoping in `BaseModel`.

---

## 6. resolveRouteBinding

- Models with a `slug` column bind by slug (human-friendly URLs, SEO-safe).
- The base falls back to `id` when no slug exists.
- `firstOrFail()` guarantees a 404 on missing key; callers never null-check.
- For encrypted/id-obfuscated keys, override `resolveRouteBinding()` to decrypt before querying.

```php
// Controller/Livewire usage:
Route::get('/components/{component}', [ComponentController::class, 'show']);
// {component} resolves to Component by slug or id automatically.
```

## 7. Immutability Guard (per 06.01 §2)

Financial/legal models (payments, invoices, license keys) extend `BaseModel` and block mutation via `booted()`:

```php
protected static function booted(): void
{
    static::updating(fn ($m) => abort(403, 'Immutable record.'));
    static::deleting(fn ($m) => abort(403, 'Immutable record.'));
}
```

This mirrors the `activity_logs` immutability guard in `06.111-activity-log.md`.

## 8. Model Conventions Summary

1. Extend `App\Shared\Models\BaseModel`.
2. `use SoftDeletes` only for user content (06.01 §3); config tables omit it.
3. Declare `$fillable`; keep `$guarded = []` from the base.
4. Centralize casts in `casts()`.
5. Type-hint relationships; name inverses explicitly.
6. Keep business logic out of models — move it to Services (07.06) and Actions (07.08).

## 10. Relationship Patterns

### 10.1 One-to-Many with Counter Cache

```php
namespace App\Domains\Components\Models;

use Illuminate\Database\Eloquent\Relations\HasMany;

class ComponentCategory extends BaseModel
{
    use SoftDeletes;

    protected $fillable = ['name', 'slug', 'description', 'components_count'];

    protected function casts(): array
    {
        return array_merge(parent::casts(), [
            'components_count' => 'integer',
        ]);
    }

    public function components(): HasMany
    {
        return $this->hasMany(Component::class, 'category_id');
    }
}

// In the Component model:
protected static function booted(): void
{
    static::saved(function (Component $component) {
        if ($component->wasChanged('category_id')) {
            $this->updateCategoryCounts($component);
        }
    });

    static::deleted(function (Component $component) {
        $this->updateCategoryCounts($component, -1);
    });
}

private static function updateCategoryCounts(Component $component, int $delta = 0): void
{
    $categoryId = $component->category_id ?? $component->getOriginal('category_id');
    if ($categoryId === null) return;

    $count = Component::where('category_id', $categoryId)->count() + $delta;
    ComponentCategory::where('id', $categoryId)->update(['components_count' => $count]);
}
```

### 10.2 Polymorphic Relationships

```php
namespace App\Domains\Media\Models;

use Illuminate\Database\Eloquent\Relations\MorphTo;

class Media extends BaseModel
{
    use SoftDeletes;

    protected $fillable = ['name', 'path', 'disk', 'mime_type', 'size', 'mediable_type', 'mediable_id'];

    protected function casts(): array
    {
        return array_merge(parent::casts(), [
            'size' => 'integer',
        ]);
    }

    public function mediable(): MorphTo
    {
        return $this->morphTo();
    }
}

// In any model that has media:
trait HasMedia
{
    public function media(): MorphMany
    {
        return $this->morphMany(Media::class, 'mediable');
    }

    public function getFirstMediaUrl(string $collection = 'default'): ?string
    {
        return $this->media()
            ->where('collection', $collection)
            ->orderByDesc('id')
            ->value('path');
    }
}
```

## 11. Query Scopes

### 11.1 Local Scopes

```php
namespace App\Domains\Components\Models;

use Illuminate\Database\Eloquent\Builder;

class Component extends BaseModel
{
    // ... existing code ...

    public function scopePublished(Builder $query): Builder
    {
        return $query->where('status', ComponentStatus::Published);
    }

    public function scopeDraft(Builder $query): Builder
    {
        return $query->where('status', ComponentStatus::Draft);
    }

    public function scopeForCategory(Builder $query, int $categoryId): Builder
    {
        return $query->where('category_id', $categoryId);
    }

    public function scopeForAuthor(Builder $query, int $authorId): Builder
    {
        return $query->where('author_id', $authorId);
    }

    public function scopeRecent(Builder $query, int $days = 30): Builder
    {
        return $query->where('created_at', '>=', now()->subDays($days));
    }

    public function scopeWithMinimumVersion(Builder $query, int $minVersion): Builder
    {
        return $query->where('latest_version', '>=', $minVersion);
    }
}
```

### 11.2 Global Scopes

```php
namespace App\Domains\Components\Scopes;
```

## 12. Route Binding

### 12.1 Slug-Based Binding

```php
namespace App\Shared\Models;

abstract class BaseModel extends Model
{
    // ... existing code ...

    public function resolveRouteBinding($value, $field = null)
    {
        // If the model has a slug and no specific field requested, bind by slug
        if ($field === null && $this->hasColumn('slug')) {
            return $this->where('slug', $value)->firstOrFail();
        }

        // For encrypted IDs
        if ($field === 'encrypted_id' || $field === null && $this->hasColumn('encrypted_id')) {
            $decrypted = decrypt($value);
            return $this->where('id', $decrypted)->firstOrFail();
        }

        return parent::resolveRouteBinding($value, $field);
    }

    public function getRouteKeyName(): string
    {
        return $this->hasColumn('slug') ? 'slug' : $this->getKeyName();
    }
}
```

### 12.2 Custom Route Key Resolution

```php
namespace App\Domains\Users\Models;

class User extends BaseModel
{
    // Users bind by username, not slug
    public function getRouteKeyName(): string
    {
        return 'username';
    }

    public function resolveRouteBinding($value, $field = null)
    {
        if ($field === null) {
            return $this->where('username', $value)->firstOrFail();
        }

        return parent::resolveRouteBinding($value, $field);
    }
}
```

### 12.3 Binding in Controllers

```php
// Route definition
Route::get('/components/{component}', [ComponentController::class, 'show']);

// Controller receives resolved model
public function show(Component $component): View
{
    // $component is already resolved by slug or id
    return view('components.show', compact('component'));
}

// Explicit field binding
Route::get('/users/{user:username}', [UserController::class, 'show']);
```

## 13. Soft Deletes Deep Dive

### 13.1 Soft Delete Configuration

```php
namespace App\Domains\Components\Models;

use Illuminate\Database\Eloquent\SoftDeletes;

class Component extends BaseModel
{
    use SoftDeletes;

    // Customize the deleted_at column name (optional)
    const DELETED_AT = 'deleted_at';

    // Customize the date format for the deleted_at column (optional)
    protected $dateFormat = 'Y-m-d H:i:s';
}
```

### 13.2 Soft Delete Behavior

| Operation | With SoftDeletes | Without SoftDeletes |
| --- | --- | --- |
| `delete()` | Sets `deleted_at` | Permanently removes row |
| `restore()` | Clears `deleted_at` | N/A |
| `forceDelete()` | Permanently removes row | N/A |
| `trashed()` | Returns true if deleted | N/A |
| Query scope | Excludes trashed by default | N/A |

### 13.3 Force Delete Protection

```php
namespace App\Domains\Shared\Traits;

trait PreventsForceDelete
{
    public static function bootPreventsForceDelete(): void
    {
        static::forceDeleting(function (Model $model) {
            // Only super-admins can force delete
            if (! auth()->user()?->hasRole('super-admin')) {
                abort(403, 'Force delete requires super-admin role.');
            }

            // Log the force delete
            ActivityLog::create([
                'user_id' => auth()->id(),
                'action' => 'force_deleted',
                'entity_type' => $model::class,
                'entity_id' => $model->getKey(),
                'old_values' => $model->toArray(),
            ]);
        });
    }
}
```

### 13.4 Cascade Soft Deletes

```php
// When a parent is soft-deleted, cascade to children
public function deleting(Model $model): void
{
    if ($model->isForceDeleting()) {
        return; // Don't cascade on force delete
    }

    // Soft delete related models
    $model->children()->each(function ($child) {
        $child->delete();
    });
}

// When a parent is restored, restore children
public function restoring(Model $model): void
    $model->children()->restore();
}
```

## 14. Immutability Guard

### 14.1 Financial Model Immutability

```php
namespace App\Domains\Billing\Models;

use App\Shared\Models\BaseModel;

class Payment extends BaseModel
{
    protected $fillable = [
        'user_id', 'order_id', 'amount', 'currency', 'status', 'stripe_id',
    ];

    protected function casts(): array
    {
        return array_merge(parent::casts(), [
            'amount' => 'decimal:2',
            'status' => PaymentStatus::class,
        ]);
    }

    // Block all mutations after creation
    protected static function booted(): void
    {
        static::updating(fn ($m) => abort(403, 'Payment records are immutable.'));
        static::deleting(fn ($m) => abort(403, 'Payment records are immutable.'));
    }
}
```

### 14.2 Selective Immutability

```php
class LicenseKey extends BaseModel
{
    protected $fillable = ['user_id', 'key', 'expires_at', 'revoked_at'];

    protected static function booted(): void
    {
        // Only certain fields can be updated
        static::updating(function (LicenseKey $key) {
            $allowedFields = ['revoked_at'];
            $changedFields = array_keys($key->getDirty());

            $unauthorized = array_diff($changedFields, $allowedFields);
            if (!empty($unauthorized)) {
                abort(403, 'License keys can only be revoked, not modified.');
            }
        });
    }
}
```

## 15. Model Factory Patterns

### 15.1 Factory Structure

```php
namespace Database\Factories;

use App\Domains\Components\Enums\ComponentStatus;
use App\Domains\Components\Models\Component;
use Illuminate\Database\Eloquent\Factories\Factory;

class ComponentFactory extends Factory
{
    protected $model = Component::class;

    public function definition(): array
    {
        $name = fake()->unique()->words(3, true);

        return [
            'name' => ucfirst($name),
            'slug' => str($name)->slug()->toString(),
            'description' => fake()->paragraph(),
            'status' => ComponentStatus::Draft,
            'category_id' => ComponentCategory::factory(),
            'author_id' => User::factory(),
            'latest_version' => 1,
        ];
    }

    public function published(): static
    {
        return $this->state(fn (array $attributes) => [
            'status' => ComponentStatus::Published,
            'latest_version' => fake()->numberBetween(1, 10),
        ]);
    }

    public function draft(): static
    {
        return $this->state(fn (array $attributes) => [
            'status' => ComponentStatus::Draft,
            'latest_version' => 0,
        ]);
    }
}
```

### 15.2 Using Factories in Tests

```php
final class ComponentTest extends TestCase

            'name' => $component->name,

    }

    public function test_published_component_has_version(): void
```

## 16. Model Events in Observers

### 16.1 Observer Integration

Observers respond to model lifecycle events. See `07.47-observers.md` for the complete observer implementation. The key model hooks that observers respond to:

```php
// Model booted() sets up lifecycle hooks
protected static function booted(): void
{
    // These can be used in observers instead
    static::creating(function (Component $component) {
        $component->token ??= ComponentToken::generate();
    });

    static::created(function (Component $component) {
        event(new ComponentCreated($component));
    });

    static::updated(function (Component $component) {
        if ($component->wasChanged('status')) {
            event(new ComponentStatusChanged($component));
        }
    });

    static::deleted(function (Component $component) {
        $component->unsearchable();
    });
}
```

### 16.2 Avoiding Observer Conflicts

When using both observers and model events:

```php
// ❌ Bad: duplicate logic in both observer and model events
class Component extends BaseModel
{
    protected static function booted(): void
    {
        static::created(fn ($c) => Cache::forget("components:list"));
    }
}

// ComponentObserver also does:
public function created(Component $component): void
{
    Cache::forget("components:list"); // Called twice!
}

// ✅ Good: choose one location — prefer observer for side effects
class Component extends BaseModel
{
    // No event hooks here — observer handles side effects
}

class ComponentObserver
{
    public function created(Component $component): void
    {
        Cache::forget("components:list"); // Called once
    }
}
```

## 18. Performance Considerations

### 18.1 N+1 Prevention

```php
// ❌ Bad: N+1 query
$components = Component::all();
foreach ($components as $component) {
    echo $component->category->name; // Extra query per component
}

// ✅ Good: eager loading
$components = Component::with('category', 'author', 'latestVersion')->get();

// ✅ Good: lazy loading for large datasets
Component::with('category')->chunk(100, function ($components) {
    foreach ($components as $component) {
        echo $component->category->name;
    }
});
```

### 18.2 Query Optimization

| Technique | When to use | Example |
| --- | --- | --- |
| `with()` | Known eager loads | `User::with('posts')->get()` |
| `chunk()` | Large datasets | `Component::chunk(100, ...)` |
| `cursor()` | Memory-constrained | `User::cursor()->each(...)` |
| `select()` | Only needed columns | `User::select('id', 'name')->get()` |
| `DB::raw()` | Complex aggregations | Subqueries, window functions |

### 18.3 Model Caching

```php
namespace App\Domains\Components\Models;

trait CachesModel
{
    public static function bootCachesModel(): void
    {
        static::saved(function (Model $model) {
            Cache::forget("model:{$model->getMorphClass()}:{$model->getKey()}");
        });

        static::deleted(function (Model $model) {
            Cache::forget("model:{$model->getMorphClass()}:{$model->getKey()}");
        });
    }

    public static function cachedFind(int|string $key): ?static
    {
        return Cache::remember(
            "model:" . static::class . ":{$key}",
            300,
            fn () => static::find($key)
        );
    }
}
```

## 19. Model Conventions Summary

1. Extend `App\Shared\Models\BaseModel`.
2. `use SoftDeletes` only for user content (06.01 §3); config tables omit it.
3. Declare `$fillable`; keep `$guarded = []` from the base.
4. Centralize casts in `casts()` (Laravel 13 style).
5. Type-hint relationships; name inverses explicitly.
6. Use local scopes for reusable query logic.
7. Keep business logic out of models — move it to Services (07.06) and Actions (07.08).
8. Use factories for test data; never hardcode test models.
9. Prevent N+1 queries with eager loading.
10. Use observers for side effects, not model event hooks.

### 27.1 Query Optimization Techniques

```php
// ❌ Bad: N+1 query

    echo $component->category->name;

Component::with('category')->cursor()->each(function ($component) {
```

## 30. Model Attribute Encryption

### 30.1 Attribute-Level Encryption

For models with sensitive fields that need column-level encryption:

```php
namespace App\Domains\Shared\Traits;

trait EncryptsAttributes
{
    public static function bootEncryptsAttributes(): void
    {
        static::saving(function (Model $model) {
            foreach ($model->getEncryptedAttributes() as $attribute) {
                if ($model->isDirty($attribute) && $model->{$attribute} !== null) {
                    $model->{$attribute} = encrypt($model->{$attribute});
                }
            }
        });

        static::retrieved(function (Model $model) {
            foreach ($model->getEncryptedAttributes() as $attribute) {
                if ($model->{$attribute} !== null) {
                    try {
                        $model->{$attribute} = decrypt($model->{$attribute});
                    } catch (\Throwable) {
                        // Value might not be encrypted yet
                    }
                }
            }
        });
    }

    protected function getEncryptedAttributes(): array
    {
        return property_exists($this, 'encryptedAttributes')
            ? $this->encryptedAttributes
            : [];
    }
}

// Usage:
class ApiKey extends BaseModel
{
    use EncryptsAttributes;

    protected array $encryptedAttributes = ['key', 'secret'];

    protected $fillable = ['name', 'key', 'secret', 'user_id'];
}
```

## 31. Model Soft Delete Cascades

### 31.1 Cascade Soft Deletes

```php
namespace App\Domains\Shared\Traits;

trait CascadeSoftDeletes
{
    public static function bootCascadeSoftDeletes(): void
    {
        static::deleting(function (Model $model) {
            if ($model->isForceDeleting()) {
                return;
            }

            $cascadeRelations = $model->getCascadeSoftDeleteRelations();

            foreach ($cascadeRelations as $relation) {
                $model->{$relation}()->each(function ($child) {
                    $child->delete();
                });
            }
        });

        static::restoring(function (Model $model) {
            $cascadeRelations = $model->getCascadeSoftDeleteRelations();

            foreach ($cascadeRelations as $relation) {
                $model->{$relation}()->restore();
            }
        });
    }

    protected function getCascadeSoftDeleteRelations(): array
    {
        return property_exists($this, 'cascadeSoftDeletes')
            ? $this->cascadeSoftDeletes
            : [];
    }
}

// Usage:
class Theme extends BaseModel
{
    use SoftDeletes;
    use CascadeSoftDeletes;

    protected array $cascadeSoftDeletes = ['components', 'versions'];

    public function components(): HasMany
    {
        return $this->hasMany(Component::class);
    }

    public function versions(): HasMany
    {
        return $this->hasMany(ThemeVersion::class);
    }
}
```

```php
trait HasStateTransitions
{
    public static function bootHasStateTransitions(): void
    {
        static::updating(function (Model $model) {
            if ($model->isDirty('status')) {
                $oldStatus = $model->getOriginal('status');
                $newStatus = $model->status;

                $allowed = $model->getAllowedTransitions();

                if (!isset($allowed[$oldStatus]) || !in_array($newStatus, $allowed[$oldStatus])) {
                    throw new \DomainException(
```

## 37. Model Conventions Summary

1. Extend `App\Shared\Models\BaseModel`.
2. `use SoftDeletes` only for user content (06.01 §3).
3. Declare `$fillable`; keep `$guarded = []` from the base.
4. Centralize casts in `casts()` (Laravel 13 style).
5. Type-hint relationships; name inverses explicitly.
6. Use local scopes for reusable query logic.
7. Keep business logic out of models.
8. Use factories for test data.
9. Prevent N+1 queries with eager loading.
10. Use observers for side effects.
11. Hide sensitive attributes in `$hidden`.
12. Use accessors/mutators for computed attributes.
13. Implement `jsonSerialize()` for API responses.
14. Cache frequently accessed models.
15. Test attributes, relationships, immutability, serialization.
16. Use `EncryptsAttributes` for column-level encryption.
17. Use `CascadeSoftDeletes` for parent-child cascades.
18. Use `HasStateTransitions` for status validation.
19. Use `Searchable` trait for search integration.
20. Validate attributes in model `saving` event.

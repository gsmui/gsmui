# 07.30 - Billing

**Project:** GsmUi
**Architecture:** Adapter-Based Billing Gateway
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.21-billing/05.21.01-overview.md` for the billing module overview, `05.21-billing/05.21.07-payment-providers.md` for provider selection, `05.21-billing/05.21.12-entitlements.md` for the entitlement model, and `05.21-billing/05.21.08-webhooks.md` for inbound payment webhooks. This document specifies the **implementation contract** — the `BillingGateway` service interface, concrete Stripe/Paddle adapters, and the `EntitlementService` that answers feature/access questions from subscription and purchase state.

GsmUi supports multiple payment providers (Stripe primary, Paddle for EU/VAT) without coupling business logic to any one SDK. A `BillingGateway` interface defines the operations the application needs (create checkout, fetch subscription, cancel, verify webhook). Provider adapters implement it; the active adapter is selected per request (user location / config) and bound in the container. Entitlement checks sit above the gateway and answer "can this user access X?" using subscription status and purchased items.

> See also: `07.29-webhooks.md` (inbound verification), `07.24-search.md` (no overlap), `07.12-events.md` (billing events like `OrderPaid`).

# 1. Gateway Interface Contract

The interface is provider-agnostic. It returns domain value objects, never SDK responses, so callers never import a provider SDK.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Billing\Contracts;

use App\Domains\Billing\Data\CheckoutSession;
use App\Domains\Billing\Data\SubscriptionSnapshot;

interface BillingGateway
{
    public function createCheckout(array $params): CheckoutSession;

    public function findSubscription(string $externalId): ?SubscriptionSnapshot;

    public function cancelSubscription(string $externalId): void;

    public function verifyWebhook(string $payload, string $signature): bool;

    public function name(): string; // 'stripe' | 'paddle'
}
```

Return types are read-only data objects (`07.09-dto-layer.md`):

```php
namespace App\Domains\Billing\Data;

final readonly class SubscriptionSnapshot
{
    public function __construct(
        public string $externalId,
        public string $status,      // maps to SubscriptionStatus enum (07.11-enums.md)
        public ?string $currentPeriodEnd,
    ) {}
}
```

# 2. Stripe Adapter

The Stripe adapter wraps the `stripe/stripe-php` SDK and translates SDK objects into the contract's value objects.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Billing\Adapters;

use App\Domains\Billing\Contracts\BillingGateway;
use App\Domains\Billing\Data\CheckoutSession;
use App\Domains\Billing\Data\SubscriptionSnapshot;
use Stripe\StripeClient;

final class StripeGateway implements BillingGateway
{
    public function __construct(private StripeClient $stripe) {}

    public function name(): string
    {
        return 'stripe';
    }

    public function createCheckout(array $params): CheckoutSession
    {
        $session = $this->stripe->checkout->sessions->create([
            'mode' => 'subscription',
            'line_items' => [['price' => $params['price_id'], 'quantity' => 1]],
            'success_url' => $params['success_url'],
            'cancel_url' => $params['cancel_url'],
            'metadata' => ['order_id' => $params['order_id']],
        ]);

        return new CheckoutSession(
            url: $session->url,
            id: $session->id,
        );
    }

    public function findSubscription(string $externalId): ?SubscriptionSnapshot
    {
        $sub = $this->stripe->subscriptions->retrieve($externalId);

        return new SubscriptionSnapshot(
            externalId: $sub->id,
            status: $sub->status,
            currentPeriodEnd: $sub->current_period_end
                ? date('Y-m-d H:i:s', $sub->current_period_end) : null,
        );
    }

    public function cancelSubscription(string $externalId): void
    {
        $this->stripe->subscriptions->cancel($externalId);
    }

    public function verifyWebhook(string $payload, string $signature): bool
    {
        // Delegates to StripeWebhookVerifier (07.29-webhooks.md)
        return app(\App\Domains\Billing\Webhooks\StripeWebhookVerifier::class)
            ->verify($payload, $signature, config('services.stripe.webhook_secret'));
    }
}
```

A `PaddleGateway` implements the same interface against the Paddle SDK; only the SDK calls differ.

# 3. Adapter Selection & Binding

The active gateway is resolved by a `BillingGatewayManager` that picks a provider based on config / user geo. It is bound once in the billing service provider.

```php
// app/Domains/Billing/Providers/BillingServiceProvider.php
public function register(): void
{
    $this->app->bind(BillingGateway::class, function ($app) {
        $manager = $app->make(BillingGatewayManager::class);
        return $manager->resolve(); // 'stripe' | 'paddle'
    });

    $this->app->singleton(BillingGatewayManager::class, fn ($app) =>
        new BillingGatewayManager([
            'stripe' => fn () => new StripeGateway(new StripeClient(config('services.stripe.secret'))),
            'paddle' => fn () => new PaddleGateway(config('services.paddle')),
        ])
    );
}
```

Selection logic (EU → Paddle, else Stripe) mirrors `05.21-billing/05.21.07-payment-providers.md` §Provider Selection Logic.

# 4. Entitlement Checks

`EntitlementService` answers access questions from subscription state + purchased items. It depends on repositories (`07.07-repository-layer.md`), not the gateway, for persisted state.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Billing\Services;

use App\Domains\Billing\Enums\SubscriptionStatus;
use App\Domains\Billing\Repositories\Contracts\SubscriptionRepositoryInterface;
use App\Domains\Users\Models\User;

final class EntitlementService
{
    public function __construct(
        private SubscriptionRepositoryInterface $subscriptions,
    ) {}

    public function can(User $user, string $feature): bool
    {
        $subscription = $this->subscriptions->activeForUser($user->id);

        if ($subscription === null) {
            return $feature === 'free_tier'; // only free features for guests
        }

        if ($subscription->status !== SubscriptionStatus::Active
            && $subscription->status !== SubscriptionStatus::Trialing) {
            return false;
        }

        return match ($feature) {
            'playground', 'theme_builder', 'api_access' => true,
            'team_seats' => $subscription->seats > 1,
            default => false,
        };
    }
}
```

Usage in a controller/middleware:

```php
if (! app(EntitlementService::class)->can($user, 'theme_builder')) {
    abort(403, 'Upgrade to Pro to use the theme builder.');
}
```

Entitlement types (subscription, purchase, system) are catalogued in `05.21-billing/05.21.12-entitlements.md`.

# 8. Stripe Adapter Deep Dive

## 8.1 Customer Management

The Stripe adapter manages customer objects and maps them to local users.

```php
final class StripeCustomerManager
{
    public function __construct(private StripeClient $stripe) {}

    public function findOrCreate(User $user): string
    {
        // Check if already linked
        if ($user->stripe_customer_id) {
            return $user->stripe_customer_id;
        }

        // Create or retrieve Stripe customer
        $customer = $this->stripe->customers->create([
            'email' => $user->email,
            'name' => $user->name,
            'metadata' => [
                'user_id' => $user->id,
                'gsmui_version' => config('app.version'),
            ],
        ]);

        $user->update(['stripe_customer_id' => $customer->id]);

        return $customer->id;
    }

    public function update(User $user): void
    {
        if (!$user->stripe_customer_id) {
            return;
        }

        $this->stripe->customers->update($user->stripe_customer_id, [
            'email' => $user->email,
            'name' => $user->name,
        ]);
    }

    public function detach(User $user): void
    {
        if (!$user->stripe_customer_id) {
            return;
        }

        $this->stripe->customers->delete($user->stripe_customer_id);
        $user->update(['stripe_customer_id' => null]);
    }
}
```

```php
final class StripeSubscriptionManager
{
    public function __construct(private StripeClient $stripe) {}

    public function changePlan(string $subscriptionId, string $newPriceId): void
    {
        $subscription = $this->stripe->subscriptions->retrieve($subscriptionId);
        $currentItem = $subscription->items->data[0];

            'cancel_at_period_end' => true,

    {
        $this->stripe->subscriptions->cancel($subscriptionId);
    }

    public function resume(string $subscriptionId): void
    {
        $this->stripe->subscriptions->update($subscriptionId, [
            'cancel_at_period_end' => false,
        ]);

    {
        $subscription = $this->stripe->subscriptions->retrieve($subscriptionId);
        $currentItem = $subscription->items->data[0];

        $this->stripe->subscriptions->update($subscriptionId, [

                    'id' => $currentItem->id,
                    'quantity' => $currentItem->quantity + 1,
                ],
            ],
            'proration_behavior' => 'create_prorations',
        ]);
```

# 9. Paddle Adapter Deep Dive

## 9.1 Paddle-specific Considerations

Paddle operates as a Merchant of Record, handling tax calculation and collection. This simplifies compliance but requires different API patterns than Stripe.

```php
final class PaddleGateway implements BillingGateway
{
    public function __construct(private array $config) {}

    public function createCheckout(array $params): CheckoutSession
    {
        // Paddle uses different checkout parameters
        $checkout = $this->client->checkout->generate([
            'items' => [
                [
                    'price_id' => $params['price_id'],
                    'quantity' => $params['quantity'] ?? 1,
                ],
            ],
            'settings' => [
                'success_url' => $params['success_url'],
                'display_name' => 'GsmUi Subscription',
            ],
        ]);

        return new CheckoutSession(
            url: $checkout['url'],
            id: $checkout['id'],
        );
    }

    public function verifyWebhook(string $payload, string $signature): bool
    {
        // Paddle uses HMAC-SHA256 with a different format
        $webhookKey = $this->config['webhook_secret'];

        $expectedSignature = hash_hmac('sha256', $payload, $webhookKey);

        return hash_equals($expectedSignature, $signature);
    }
}
```

## 9.2 Tax Handling with Paddle

Since Paddle handles taxes automatically, the `EntitlementService` does not need to calculate taxes. The invoice amounts from Paddle already include applicable taxes.

```php
final class PaddleInvoiceNormalizer

            'amount' => $paddleInvoice['total'],

            'reversed' => 'refunded',
            default => 'unknown',
        };
    }
}
```

## 10.2 Entitlement Resolution

```php
final class EntitlementResolver
{
    public function __construct(
        private SubscriptionRepositoryInterface $subscriptions,
        private PurchaseRepositoryInterface $purchases,
    ) {}

    public function resolve(User $user, string $feature): EntitlementResult
    {
        // Check subscription-based entitlement
        $subscription = $this->subscriptions->activeForUser($user->id);
        if ($subscription) {
            $featureConfig = config("billing.features.{$feature}");
            if ($featureConfig && in_array($subscription->plan_slug, $featureConfig['plans'])) {
                return EntitlementResult::granted(
                    source: 'subscription',
                    plan: $subscription->plan_slug,
                    expires_at: $subscription->current_period_end,
                );
            }
        }

        // Check purchase-based entitlement (lifetime license)
        $purchase = $this->purchases->activeForUserAndFeature($user->id, $feature);
        if ($purchase) {
            return EntitlementResult::granted(
                source: 'purchase',
                plan: null,
                expires_at: $purchase->expires_at,
            );
        }

        // Check trial eligibility
        if ($this->isTrialEligible($user, $feature)) {
            return EntitlementResult::trial(
                days_remaining: 14,
            );
        }

        return EntitlementResult::denied();
    }

    private function isTrialEligible(User $user, string $feature): bool
    {
        return !$this->subscriptions->hasHadTrialForFeature($user->id, $feature);
    }
}
```

## 10.3 Entitlement Middleware

```php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

final class RequireEntitlement
{
    public function handle(Request $request, Closure $next, string $feature)
    {
        $user = $request->user();

        if (!$user) {
            abort(401, 'Authentication required');
        }

        $result = app(EntitlementResolver::class)->resolve($user, $feature);

        if ($result->isDenied()) {
            if ($request->expectsJson()) {
                return response()->json([
                    'error' => 'Entitlement required',
                    'feature' => $feature,
                    'upgrade_url' => route('billing.upgrade', ['feature' => $feature]),
                ], 403);
            }

            return redirect()->route('billing.upgrade', [
                'feature' => $feature,
            ]);
        }

        if ($result->isTrial()) {
            $request->attributes->set('entitlement_trial', true);
            $request->attributes->set('entitlement_trial_days', $result->days_remaining);
        }

        return $next($request);
    }
}
```

```php
        private SubscriptionRepositoryInterface $subscriptions,
        private EntitlementService $entitlements,

    public function handle(SubscriptionUpdated $event): void
    {
```

# 12. Invoice Generation & Management

## 12.1 Invoice Generation Service

```php
final class InvoiceService
{
    public function generate(User $user, array $items, array $options = []): Invoice
    {
        $invoice = Invoice::create([
            'user_id' => $user->id,
            'number' => $this->generateNumber(),
            'status' => 'draft',
            'currency' => $options['currency'] ?? 'USD',
            'subtotal' => collect($items)->sum(fn ($item) => $item['amount'] * $item['quantity']),
            'tax_rate' => $options['tax_rate'] ?? 0,
            'total' => 0, // calculated after tax
            'due_at' => $options['due_at'] ?? now()->addDays(30),
        ]);

        foreach ($items as $item) {
            $invoice->lineItems()->create([
                'description' => $item['description'],
                'quantity' => $item['quantity'],
                'unit_amount' => $item['amount'],
                'total' => $item['amount'] * $item['quantity'],
            ]);
        }

        $taxAmount = $invoice->subtotal * ($invoice->tax_rate / 100);
        $invoice->update([
            'total' => $invoice->subtotal + $taxAmount,
            'tax_amount' => $taxAmount,
        ]);

        return $invoice;
    }

    private function generateNumber(): string
    {
        $prefix = 'GSM';
        $date = now()->format('Ym');
        $sequence = Invoice::whereMonth('created_at', now()->month)->count() + 1;

        return "{$prefix}-{$date}-" . str_pad($sequence, 4, '0', STR_PAD_LEFT);
    }
}
```

## 13.1 Coupon Management

```php
final class CouponService

    public function validate(string $code, User $user): Coupon
    {
        $coupon = Coupon::where('code', $code)->firstOrFail();

        if (!$coupon->isActive()) {
            throw new InvalidCouponException('Coupon is not active');
        }

        if ($coupon->expires_at && $coupon->expires_at->isPast()) {
            throw new InvalidCouponException('Coupon has expired');
        }

        if ($coupon->max_uses && $coupon->usage_count >= $coupon->max_uses) {
            throw new InvalidCouponException('Coupon usage limit reached');
        }

        if ($coupon->max_uses_per_user) {
            $userUsage = CouponUsage::where('coupon_id', $coupon->id)
                ->where('user_id', $user->id)
                ->count();

            if ($userUsage >= $coupon->max_uses_per_user) {
                throw new InvalidCouponException('You have already used this coupon');
            }
        }

        return $coupon;
    }

    public function apply(Coupon $coupon, int $amount): int
    {
        return match ($coupon->type) {
            'percentage' => (int) ($amount * (1 - $coupon->value / 100)),
            'fixed' => max(0, $amount - $coupon->value),
            default => $amount,
        };
    }

    public function recordUsage(Coupon $coupon, User $user, int $discountAmount): void
    {
        CouponUsage::create([
            'coupon_id' => $coupon->id,
            'user_id' => $user->id,
            'discount_amount' => $discountAmount,
        ]);

        $coupon->increment('usage_count');
    }
}
```

```php
    {
```

```php
        CreditTransaction::create([
            'credit_id' => $credit->id,
            'amount' => -$amount,
            'type' => 'spend',
            'reason' => $reason,
            'metadata' => $metadata,
        ]);

        return true;
    }
```

```php
final class SubscriptionLifecycleManager
{
    public function onSubscriptionCreated(SubscriptionCreated $event): void
    {
        // 1. Create local subscription record
        $subscription = $this->subscriptions->create([
            'user_id' => $event->userId,
            'plan_slug' => $event->planSlug,
            'status' => SubscriptionStatus::Active,
            'external_id' => $event->externalId,
            'current_period_end' => $event->currentPeriodEnd,
        ]);

        // 2. Grant entitlements
        $this->entitlements->grant($subscription->user_id, $event->planSlug);

        // 3. Send welcome email
        Mail::to($subscription->user->email)
            ->queue(new SubscriptionWelcome($subscription));

        // 4. Clear user cache
        Cache::forget("user:{$subscription->user_id}:entitlements");

        // 5. Dispatch domain event
        event(new SubscriptionActivated($subscription));
    }

    public function onSubscriptionCanceled(SubscriptionCanceled $event): void
    {
        $subscription = $this->subscriptions->findByExternalId($event->externalId);

        if ($subscription) {
            $this->subscriptions->update($subscription, [
                'status' => SubscriptionStatus::Canceled,
                'canceled_at' => now(),
            ]);

            // Revoke entitlements
            $this->entitlements->revoke($subscription->user_id);

            // Send cancellation email
            Mail::to($subscription->user->email)
                ->queue(new SubscriptionCanceledEmail($subscription));

            // Dispatch domain event
            event(new SubscriptionDeactivated($subscription));
        }
    }

    public function onPaymentFailed(PaymentFailed $event): void
    {
        $subscription = $this->subscriptions->findByExternalId($event->subscriptionId);

        if ($subscription) {
            $this->subscriptions->update($subscription, [
                'status' => SubscriptionStatus::PastDue,
            ]);

            // Send payment failed email
            Mail::to($subscription->user->email)
                ->queue(new PaymentFailedEmail($subscription, $event->failureReason));

            // Schedule grace period job
            SchedulePaymentGracePeriod::dispatch($subscription)
                ->delay(now()->addDays(3));
        }
    }
}
```

```php
    public function calculateForUser(User $user, int $amount): TaxCalculation
    {
        $address = $user->billingAddress;

        if (!$address) {

        if (config('billing.default_provider') === 'paddle') {

            currency: 'USD',

    {
        // EU VAT
        if ($address->country !== 'US' && $this->isEUCountry($address->country)) {
            return $this->getEUVatRate($address->country);
        }

        // US state tax
        if ($address->country === 'US') {
            return $this->getUSStateTax($address->state);
        }

        return 0;
    }
```

```php
    public function assess(User $user, array $paymentData): FraudRisk

        $riskScore = 0;

        $recentPurchases = Order::where('user_id', $user->id)
```

# 28. Billing Grace Period & Dunning

## 28.1 Grace Period Policy

When a payment fails, GsmUi enters a grace period before revoking access. This maximizes recovery while maintaining user trust.

| Phase | Duration | Actions |
| --- | --- | --- |
| Initial failure | 0 hours | Email notification, retry in 3 days |
| First retry | 72 hours | Second email, retry |
| Second retry | 168 hours (7 days) | Final warning email |
| Third retry | 336 hours (14 days) | Subscription paused |
| Final state | 480 hours (20 days) | Subscription canceled |

## 28.2 Dunning Service

```php
final class DunningService
{
    private const RETRY_SCHEDULE = [
        0,       // immediate
        259200,  // 3 days
        604800,  // 7 days
        1209600, // 14 days
        1728000, // 20 days
    ];

    public function processFailedPayment(PaymentFailed $event): void
    {
        $subscription = $this->subscriptions->findByExternalId($event->subscriptionId);

        if (!$subscription) {
            return;
        }

        $attempt = $subscription->payment_retry_count + 1;
        $maxAttempts = count(self::RETRY_SCHEDULE);

        if ($attempt >= $maxAttempts) {
            // Final attempt failed — cancel subscription
            $this->cancelSubscription($subscription, 'payment_failure');
            return;
        }

        // Schedule next retry
        $retryAt = now()->addSeconds(self::RETRY_SCHEDULE[$attempt]);

        $subscription->update([
            'payment_retry_count' => $attempt,
            'next_payment_retry_at' => $retryAt,
            'status' => SubscriptionStatus::PastDue,
        ]);

        // Send appropriate email based on attempt
        $emailClass = match ($attempt) {
            1 => PaymentFailedFirstAttempt::class,
            2 => PaymentFailedSecondAttempt::class,
            3 => PaymentFailedFinalWarning::class,
            default => PaymentFailedGeneric::class,
        };

        Mail::to($subscription->user->email)
            ->queue(new $emailClass($subscription));

        // Schedule retry job
        RetryPayment::dispatch($subscription)
            ->delay($retryAt);
    }
}
```

## 29.2 Webhook IP Verification

```php
final class WebhookIpVerifier
{
    private const STRIPE_IPS = [
        '54.187.174.169', '54.241.143.138', '54.241.159.140',
        '34.234.23.2', '34.207.186.71', '35.166.225.180',
        '35.167.204.100', '52.89.215.196', '52.12.165.31',
        '54.218.53.128', '54.218.87.89', '52.24.165.150',
    ];

    public function verify(): void
    {
        $ip = request()->ip();

        if (!in_array($ip, self::STRIPE_IPS)) {
            Log::warning('Stripe webhook from unknown IP', ['ip' => $ip]);
            abort(403, 'Unauthorized webhook source');
        }
    }
}
```

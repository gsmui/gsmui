# 07.31 - Marketplace

**Project:** GsmUi
**Architecture:** Service Layer + Billing Adapter (Marketplace Domain)
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.20-marketplace.md` for the conceptual marketplace architecture, and `06.50-marketplace.md` (`products`, `product_categories`, `product_tag`, `product_media`, `product_prices`) for the persistence schema. This document specifies the **implementation contract** — the `ProductService`, `ProductVersionService`, `OrderService`, `ReviewService`, and vendor `VendorService` interfaces, worked examples, DI binding, and the purchase-orchestration flow that sits on top of the billing gateway defined in `07.30-billing.md`.

The Marketplace domain is the commercial backbone of GsmUi: it lists digital products (components, themes, templates, icons, charts, plugins, snippets, asset packs, doc packs, MCP servers, AI skills, starter kits), manages the creator publishing pipeline, and orchestrates purchases through the billing gateway. Domain services must never import a Stripe/Paddle SDK class directly — every charge, refund, and entitlement decision routes through the contracts in `07.30-billing.md`.

The goals of this contract are:

- Expose one `ProductService` catalog interface (read + authoring) consumed by controllers, Livewire, and the API.
- Centralize the creator/vendor publish flow in `VendorService` (draft → pending_review → published).
- Own purchase orchestration in `OrderService`, which coordinates billing (`07.30-billing.md`), license issuance, and download enabling.
- Keep vendor-facing analytics and review aggregation behind `ReviewService` / `VendorService` so the presentation layer calls one contract.
- Preserve the immutable `products` status workflow (`draft → pending_review → published → archived`) defined in `06.50-marketplace.md`.

## 2. Product Catalog Service Contract

`ProductService` is the catalog read/write boundary. Reads power the storefront and search; authoring writes are owned by `VendorService`. The interface is what controllers, Livewire, and the API depend on.

```php
namespace App\Domains\Marketplace\Contracts;

use App\Domains\Marketplace\Data\ProductData;
use App\Domains\Marketplace\Models\Product;
use Illuminate\Contracts\Pagination\LengthAwarePaginator;

interface ProductService
{
    public function list(array $filters = []): LengthAwarePaginator;

    public function findBySlug(string $authorSlug, string $slug): ?Product;

    public function featured(int $limit = 8): \Illuminate\Database\Eloquent\Collection;

    /** Catalog metadata only — never mutates ownership/status. */
    public function updateCatalogData(Product $product, ProductData $data): Product;
}
```

## 3. Example Service: Product Catalog Manager

The concrete manager depends on the repository (per `07.07-repository-layer.md`) and returns typed models. Business rules such as "free product skips billing" live here, not in the repository.

```php
namespace App\Domains\Marketplace\Services;

use App\Domains\Marketplace\Contracts\ProductService;
use App\Domains\Marketplace\Data\ProductData;
use App\Domains\Marketplace\Models\Product;
use App\Domains\Marketplace\Repositories\Contracts\ProductRepository;

final class ProductCatalogManager extends \App\Shared\Support\AbstractService implements ProductService
{
    public function __construct(
        private ProductRepository $products,
    ) {}

    public function list(array $filters = []): LengthAwarePaginator
    {
        return $this->products->paginatePublished(
            perPage: $filters['per_page'] ?? 15,
            category: $filters['category'] ?? null,
            type: $filters['type'] ?? null,
            freeOnly: $filters['free'] ?? false,
        );
    }

    public function findBySlug(string $authorSlug, string $slug): ?Product
    {
        return $this->products->byAuthorAndSlug($authorSlug, $slug);
    }

    public function featured(int $limit = 8): \Illuminate\Database\Eloquent\Collection
    {
        return $this->products->featured($limit);
    }

    public function updateCatalogData(Product $product, ProductData $data): Product
    {
        return $this->transaction(function () use ($product, $data): Product {
            $updated = $this->products->update($product, $data->toCatalogArray());
            $this->dispatchAfterCommit(new \App\Domains\Marketplace\Events\ProductUpdated($updated->id));
            return $updated;
        });
    }
}
```

## 4. Vendor (Creator) Service Contract

`VendorService` owns the creator publish pipeline and the status workflow from `06.50-marketplace.md`. Authors create drafts, submit for review, and (on approval) publish. The actual status transition is performed by actions (`SubmitForReviewAction`, `PublishProductAction`) coordinated through this service.

```php
namespace App\Domains\Marketplace\Contracts;

use App\Domains\Marketplace\Data\ProductData;
use App\Domains\Marketplace\Models\Product;

interface VendorService
{
    public function createDraft(int $authorId, ProductData $data): Product;

    public function submitForReview(Product $product): Product;

    public function publish(Product $product): Product;

    public function archive(Product $product): Product;

    /** Vendor analytics: views, downloads, purchases, revenue. */
    public function analytics(int $authorId): \App\Domains\Marketplace\Data\VendorAnalytics;
}
```

The moderation review is performed by the Admin domain (`07.39-admin-platform.md`); `VendorService.publish()` is only reached after an approved `pending_review` state.

## 5. Order Service — Purchase Orchestration

`OrderService` is the single purchase entry point. It coordinates the billing gateway (`07.30-billing.md`), license issuance, and download enablement inside one action transaction. Free products bypass the gateway entirely.

```php
namespace App\Domains\Marketplace\Contracts;

use App\Domains\Marketplace\Models\Product;
use App\Models\User;

interface OrderService
{
    /**
     * Single purchase entry point. Returns the resulting license/order.
     * Free products (Product::is_free) skip the billing gateway.
     */
    public function purchase(User $buyer, Product $product, ?string $idempotencyKey = null): \App\Domains\Marketplace\Models\License;
}
```

```text
PurchaseProductAction::run(buyer, product, key)
        │
        ├─ product.is_free?
        │     ├─ yes → issue license directly
        │     └─ no  → app(PaymentGateway::class)            (07.30-billing.md)
        │                 .createCheckout(...)
        │
        ├─ on payment success → IssueLicenseAction (license_keys)
        │
        ├─ enable download (signed URL via DownloadService)
        │
        └─ dispatchAfterCommit(ProductPurchased)  → 05.20 events
```

## 7. Dependency Injection Binding

All marketplace contracts bind to their managers in the domain service provider. Repositories bind per `07.07-repository-layer.md`; billing contracts are reused from `07.30-billing.md` via the container.

```php
namespace App\Domains\Marketplace\Providers;

use App\Domains\Marketplace\Contracts\{ProductService, VendorService, OrderService, ReviewService};
use App\Domains\Marketplace\Repositories\Contracts\ProductRepository;
use App\Domains\Marketplace\Repositories\Eloquent\ProductRepositoryEloquent;
use App\Domains\Marketplace\Services\{ProductCatalogManager, VendorManager, OrderManager, ReviewManager};
use Illuminate\Support\ServiceProvider;

final class MarketplaceServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->bind(ProductRepository::class, ProductRepositoryEloquent::class);
        $this->app->bind(ProductService::class, ProductCatalogManager::class);
        $this->app->bind(VendorService::class, VendorManager::class);
        $this->app->bind(OrderService::class, OrderManager::class);
        $this->app->bind(ReviewService::class, ReviewManager::class);
    }
}
```

Usage from a controller or Livewire component:

```php
$products = app(ProductService::class)->list([
    'type' => 'themes',
    'free' => false,
    'per_page' => 12,
]);

$license = app(OrderService::class)->purchase($user, $product, $request->idempotency_key);
```

## 8. Reuse Rules

A marketplace service MAY:

- Apply catalog/business rules (free vs paid, featured eligibility).
- Call its repository and the billing contracts from `07.30-billing.md`.
- Dispatch domain events (`ProductPublished`, `ProductPurchased`, `ReviewCreated`).
- Own cache reads/writes for its own data (featured carousel, rating averages).

A marketplace service MUST NOT:

- Import a Stripe/Paddle SDK class (route through `PaymentGateway`).
- Mutate another domain's ledger directly (use events + the owning service).
- Render views or return HTTP responses.
- Hold mutable state between calls (stateless).

| Concern | Owner |
| --- | --- |
| Charge / refund | `PaymentGateway` (`07.30-billing.md`) |
| License generation | `IssueLicenseAction` (marketplace) |
| Secure download URL | `DownloadService` (marketplace) |
| Status workflow | `VendorService` + Admin moderation |
| Reviews/rating | `ReviewService` |

# 11. Product Media Management

## 11.1 Media Upload Pipeline

```php
final class ProductMediaService
{
    public function upload(Product $product, UploadedFile $file, string $type): ProductMedia
    {
        $this->validateFile($file, $type);

        $path = $product->id . '/' . $type;
        $filename = $this->generateFilename($file, $type);

        $diskPath = Storage::disk('products')->putFileAs($path, $file, $filename);

        return ProductMedia::create([
            'product_id' => $product->id,
            'type' => $type,
            'path' => $diskPath,
            'original_name' => $file->getClientOriginalName(),
            'mime_type' => $file->getMimeType(),
            'size' => $file->getSize(),
        ]);
    }

    public function delete(ProductMedia $media): void
    {
        Storage::disk('products')->delete($media->path);
        $media->delete();
    }

    private function validateFile(UploadedFile $file, string $type): void
    {
        $rules = match ($type) {
            'preview_image' => 'image|max:5120', // 5MB
            'screenshot' => 'image|max:5120',
            'icon' => 'image|max:2048', // 2MB
            'attachment' => 'file|max:10240', // 10MB
            default => 'file|max:10240',
        ];

        Validator::validate(['file' => $file], ['file' => $rules]);
    }
}
```

# 12. Search & Discovery

## 12.1 Product Search Service

```php
final class ProductSearchService
{
    public function search(string $query, array $filters = []): LengthAwarePaginator
    {
        $results = Product::query()
            ->where('status', 'published')
            ->where(function ($q) use ($query) {
                $q->where('name', 'LIKE', "%{$query}%")
                  ->orWhere('slug', 'LIKE', "%{$query}%")
                  ->orWhere('description', 'LIKE', "%{$query}%");
            });

        // Apply filters
        if (isset($filters['type'])) {
            $results->where('type', $filters['type']);
        }

        if (isset($filters['category'])) {
            $results->where('category_id', $filters['category']);
        }

        if (isset($filters['min_price'])) {
            $results->where('price', '>=', $filters['min_price']);
        }

        if (isset($filters['max_price'])) {
            $results->where('price', '<=', $filters['max_price']);
        }

        if (isset($filters['min_rating'])) {
            $results->where('rating_average', '>=', $filters['min_rating']);
        }

        if (isset($filters['free'])) {
            $results->where('price', 0);
        }

        return $results->paginate($filters['per_page'] ?? 15);
    }

    public function index(Product $product): void
    {
        app(SearchService::class)->index('gsmui_products', [
            'id' => $product->id,
            'name' => $product->name,
            'slug' => $product->slug,
            'description' => $product->description,
            'type' => $product->type,
            'category' => $product->category?->name,
            'price' => $product->price,
            'rating' => $product->rating_average,
            'vendor' => $product->vendor->name,
        ]);
    }
}
```

# 13. Vendor Analytics & Dashboard

## 13.1 Vendor Analytics Data

```php
final class VendorAnalyticsService
{
    public function getDashboard(int $vendorId): VendorDashboard
    {
        return new VendorDashboard(
            total_revenue: $this->getTotalRevenue($vendorId),
            monthly_revenue: $this->getMonthlyRevenue($vendorId),
            total_products: Product::where('vendor_id', $vendorId)->count(),
            published_products: Product::where('vendor_id', $vendorId)->where('status', 'published')->count(),
            total_downloads: $this->getTotalDownloads($vendorId),
            total_purchases: $this->getTotalPurchases($vendorId),
            average_rating: $this->getAverageRating($vendorId),
            pending_reviews: Review::whereHas('product', fn ($q) => $q->where('vendor_id', $vendorId))
                ->where('status', 'pending')
                ->count(),
            recent_sales: $this->getRecentSales($vendorId, 10),
            revenue_chart: $this->getRevenueChart($vendorId, 12),
        );
    }

    private function getMonthlyRevenue(int $vendorId): int
    {
        return Order::whereHas('product', fn ($q) => $q->where('vendor_id', $vendorId))
            ->where('status', 'completed')
            ->whereMonth('created_at', now()->month)
            ->sum('amount');
    }

    private function getRevenueChart(int $vendorId, int $months): array
    {
        return Order::whereHas('product', fn ($q) => $q->where('vendor_id', $vendorId))
            ->where('status', 'completed')
            ->where('created_at', '>=', now()->subMonths($months))
            ->selectRaw('DATE_FORMAT(created_at, "%Y-%m") as month, SUM(amount) as revenue')
            ->groupBy('month')
            ->orderBy('month')
            ->get()
            ->toArray();
    }
}
```

## 13.2 Vendor Payout Service

```php
final class VendorPayoutService
{
    public function calculatePayout(int $vendorId): PayoutSummary
    {
        $earnings = Order::whereHas('product', fn ($q) => $q->where('vendor_id', $vendorId))
            ->where('status', 'completed')
            ->whereNull('paid_to_vendor_at')
            ->get();

        $totalEarnings = $earnings->sum('vendor_amount');
        $platformFee = $earnings->sum('platform_fee');
        $payoutAmount = $totalEarnings - $platformFee;

        return new PayoutSummary(
            vendor_id: $vendorId,
            total_earnings: $totalEarnings,
            platform_fee: $platformFee,
            payout_amount: $payoutAmount,
            order_count: $earnings->count(),
            period_start: $earnings->min('created_at'),
            period_end: $earnings->max('created_at'),
        );
    }

    public function processPayout(int $vendorId, PayoutSummary $summary): void
    {
        // Create payout record
        $payout = VendorPayout::create([
            'vendor_id' => $vendorId,
            'amount' => $summary->payout_amount,
            'status' => 'pending',
            'period_start' => $summary->period_start,
            'period_end' => $summary->period_end,
        ]);

        // Mark orders as paid
        Order::whereHas('product', fn ($q) => $q->where('vendor_id', $vendorId))
            ->where('status', 'completed')
            ->whereNull('paid_to_vendor_at')
            ->update(['paid_to_vendor_at' => now()]);

        // Dispatch payout via payment provider
        PayoutDispatchJob::dispatch($payout);
    }
}
```

# 14. Product Versioning

## 14.1 Version Management

```php
final class ProductVersionService
{
    public function create(Product $product, ProductVersionData $data): ProductVersion
    {
        $this->validateVersion($product, $data->version);

        return ProductVersion::create([
            'product_id' => $product->id,
            'version' => $data->version,
            'changelog' => $data->changelog,
            'assets' => $data->assets,
            'status' => 'draft',
        ]);
    }

    public function publish(ProductVersion $version): void
    {
        $version->update(['status' => 'published', 'published_at' => now()]);

        // Update product's current version
        $version->product->update(['current_version' => $version->version]);

        // Notify purchasers of the update
        $this->notifyPurchasers($version);

        // Update search index
        app(ProductSearchService::class)->index($version->product);
    }

    private function validateVersion(Product $product, string $version): void
    {
        $latest = $product->versions()->latest()->first();

        if ($latest && version_compare($version, $latest->version, '<=')) {
            throw new InvalidVersionException("Version {$version} must be greater than {$latest->version}");
        }

        if (!preg_match('/^\d+\.\d+\.\d+$/', $version)) {
            throw new InvalidVersionException("Version must follow semantic versioning (x.y.z)");
        }
    }

    private function notifyPurchasers(ProductVersion $version): void
    {
        $purchasers = License::where('product_id', $version->product_id)
            ->where('status', 'active')
            ->with('user')
            ->get()
            ->pluck('user');

        foreach ($purchasers as $user) {
            Mail::to($user->email)
                ->queue(new VersionPublished($version));
        }
    }
}
```

# 15. Product Moderation & Review

## 15.1 Moderation Pipeline

```php
final class ProductModerationService
{
    public function submitForReview(Product $product): void
    {
        $product->update(['status' => 'pending_review']);

        // Notify moderators
        Notification::route('mail', config('admin.moderation_email'))
            ->notify(new ProductSubmittedForReview($product));
    }

    public function approve(Product $product, string $notes = ''): void
    {
        $product->update([
            'status' => 'published',
            'published_at' => now(),
            'moderation_notes' => $notes,
        ]);

        // Notify vendor
        Mail::to($product->vendor->email)
            ->queue(new ProductApproved($product));

        // Index in search
        app(ProductSearchService::class)->index($product);

        // Dispatch event
        event(new ProductPublished($product));
    }

    public function reject(Product $product, string $reason): void
    {
        $product->update([
            'status' => 'draft',
            'rejection_reason' => $reason,
        ]);

        // Notify vendor
        Mail::to($product->vendor->email)
            ->queue(new ProductRejected($product, $reason));
    }
}
```

```php
// app/Policies/ProductPolicy.php
final class ProductPolicy
{
    public function viewAny(User $user): bool
    {
        return true; // marketplace is public
    }

    public function view(User $user, Product $product): bool
    {
        return $product->status === 'published'
            || $product->vendor_id === $user->id
            || $user->is_admin;
    }

    public function create(User $user): bool
    {
        return $user->is_vendor || $user->is_admin;
    }

    public function update(User $user, Product $product): bool
    {
        return $product->vendor_id === $user->id
            || $user->is_admin;
    }

    public function delete(User $user, Product $product): bool
    {
        return $product->vendor_id === $user->id
            || $user->is_admin;
    }

    public function publish(User $user, Product $product): bool
    {
        return ($product->vendor_id === $user->id && $product->status === 'pending_review')
            || $user->is_admin;
    }

    public function purchase(User $user, Product $product): bool
    {
        return $product->status === 'published'
            && $product->vendor_id !== $user->id
            && !$this->alreadyPurchased($user, $product);
    }

    private function alreadyPurchased(User $user, Product $product): bool
    {
        return License::where('user_id', $user->id)
            ->where('product_id', $product->id)
            ->exists();
    }
}
```

# 28. Marketplace Security

## 28.1 File Upload Security

```php
final class MarketplaceFileSecurity
{
    public function validateUpload(UploadedFile $file, string $type): void
    {
        // Check MIME type against allowed types
        $allowedMimes = config("marketplace.media.allowed_mimes.{$type}", []);
        if (!in_array($file->getMimeType(), $allowedMimes)) {
            throw new InvalidFileTypeException("File type {$file->getMimeType()} not allowed for {$type}");
        }

        // Check file size
        $maxSize = config("marketplace.media.{$type}_max_size", 10240);
        if ($file->getSize() > $maxSize * 1024) {
            throw new FileTooLargeException("File exceeds maximum size of {$maxSize}KB");
        }

        // Scan for malware
        $scanResult = app(VirusScanner::class)->scan($file->getPathname());
        if ($scanResult->isInfected()) {
            throw new MalwareDetectedException("File contains malware: {$scanResult->threatName()}");
        }

        // Check for executable content
        if (in_array($file->getExtension(), ['php', 'phtml', 'php5', 'sh', 'exe', 'bat'])) {
            throw new InvalidFileTypeException("Executable files are not allowed");
        }
    }
}
```

## 28.3 Purchase Fraud Prevention

```php
final class PurchaseFraudDetector
{
    public function assess(User $user, Product $product, string $ipAddress): FraudAssessment
    {
        $signals = [];

        // Check purchase velocity
        $recentPurchases = Order::where('user_id', $user->id)
            ->where('created_at', '>=', now()->subHour())
            ->count();

        if ($recentPurchases > 5) {
            $signals[] = 'high_purchase_velocity';
        }

        // Check same IP multiple accounts
        $accountsFromIp = User::where('last_login_ip', $ipAddress)
            ->where('created_at', '>=', now()->subDay())
            ->count();

        if ($accountsFromIp > 3) {
            $signals[] = 'multiple_accounts_same_ip';
        }

        // Check account age
        if ($user->created_at->diffInHours(now()) < 1) {
            $signals[] = 'new_account';
        }

        // Check refund history
        $recentRefunds = Refund::whereHas('payment', fn ($q) => $q->where('user_id', $user->id))
            ->where('created_at', '>=', now()->subDays(30))
            ->count();

        if ($recentRefunds > 2) {
            $signals[] = 'frequent_refunds';
        }

        return new FraudAssessment(
            risk_level: $this->calculateRiskLevel($signals),
            signals: $signals,
            requires_review: count($signals) >= 2,
        );
    }
}
```

## 29.2 Currency Handling

```php
final class MarketplaceCurrencyService
{
    private const SUPPORTED_CURRENCIES = ['USD', 'EUR', 'GBP', 'JPY', 'CAD', 'AUD'];

    public function convert(int $amountCents, string $from, string $to): int
    {
        if ($from === $to) {
            return $amountCents;
        }

        $rate = $this->getExchangeRate($from, $to);
        return (int) round($amountCents * $rate);
    }

    private function getExchangeRate(string $from, string $to): float
    {
        return Cache::remember(
            "currency:{$from}:{$to}",
            now()->addHours(6),
            fn () => app(ExchangeRateApi::class)->getRate($from, $to)
        );
    }

    public function format(int $amountCents, string $currency): string
    {
        $divisor = $currency === 'JPY' ? 1 : 100;
        return $currency . ' ' . number_format($amountCents / $divisor, $divisor === 1 ? 0 : 2);
    }
}
```

```php
            'product_id' => $order->product_id,
            'buyer_id' => $order->user_id,
            'amount' => $order->amount,
            'currency' => $order->currency,

            ->whereJsonContains('events', $event)
            ->get();

            dispatch(new DeliverWebhookJob($subscriber, $event, $payload))
                ->onQueue('webhooks');
        }
    }
}
```

```php
// Update product ratings
final class UpdateProductRatings extends Command
{
    protected $signature = 'marketplace:update-ratings';

    public function handle(): int
    {
        $products = Product::withCount('reviews')
            ->having('reviews_count', '>', 0)
            ->get();

        foreach ($products as $product) {
            $avg = $product->reviews()->where('status', 'approved')->avg('rating');
            $count = $product->reviews()->where('status', 'approved')->count();

            $product->update([
                'rating_average' => round($avg, 2),
                'rating_count' => $count,
            ]);
        }

        $this->info("Updated ratings for {$products->count()} products.");
        return self::SUCCESS;
    }

    {
        $expired = License::where('status', 'active')
            ->where('expires_at', '<', now())
            ->update(['status' => 'expired']);

        $this->info("Expired {$expired} licenses.");
        return self::SUCCESS;
    }
}
```

```php
final class MarketplaceAnalytics
{
    public function getDashboardMetrics(string $period = '30d'): array
    {
        return [
            'overview' => $this->getOverview($period),
            'products' => $this->getProductMetrics($period),
            'vendors' => $this->getVendorMetrics($period),
            'revenue' => $this->getRevenueMetrics($period),
            'customers' => $this->getCustomerMetrics($period),
        ];
    }

    private function getOverview(string $period): array
    {
        $startDate = now()->subDays((int) $period);

        return [
            'total_products' => Product::count(),
            'active_products' => Product::where('status', 'active')->count(),
            'total_vendors' => Vendor::count(),
            'active_vendors' => Vendor::where('status', 'active')->count(),
            'total_orders' => Order::where('created_at', '>=', $startDate)->count(),
            'total_revenue' => Order::where('created_at', '>=', $startDate)->sum('total'),
            'average_order_value' => Order::where('created_at', '>=', $startDate)->avg('total'),
        ];
    }

    private function getProductMetrics(string $period): array
    {
        return [
            'top_products' => $this->getTopProducts($period),
            'new_products' => $this->getNewProducts($period),
            'product_views' => $this->getProductViews($period),
            'conversion_rate' => $this->getConversionRate($period),
        ];
    }
}
```

```php
// marketplace_products table
Schema::create('marketplace_products', function (Blueprint $table) {
    $table->id();
    $table->foreignId('vendor_id')->constrained('marketplace_vendors');
    $table->string('name');
    $table->string('slug');
    $table->text('description');
    $table->text('long_description')->nullable();
    $table->enum('type', ['component', 'template', 'plugin', 'theme', 'bundle']);
    $table->enum('status', ['draft', 'pending', 'active', 'archived']);
    $table->decimal('price', 10, 2);
    $table->decimal('original_price', 10, 2)->nullable();
    $table->string('version');
    $table->string('license_type'); // single, multi, enterprise
    $table->json('metadata')->nullable();
    $table->json('tags')->nullable();
    $table->integer('download_count')->default(0);
    $table->integer('view_count')->default(0);
    $table->decimal('rating', 3, 2)->default(0);
    $table->integer('review_count')->default(0);
    $table->timestamps();
    $table->softDeletes();

    $table->unique('slug');
    $table->index('vendor_id');
    $table->index('type');
    $table->index('status');
    $table->index('price');
});

// marketplace_licenses table
Schema::create('marketplace_licenses', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained('users');
    $table->foreignId('product_id')->constrained('marketplace_products');
    $table->string('key')->unique();
    $table->enum('status', ['active', 'expired', 'revoked']);
    $table->timestamp('expires_at')->nullable();
    $table->integer('activations')->default(0);
    $table->integer('max_activations')->default(1);
    $table->json('metadata')->nullable();
    $table->timestamps();

    $table->index('user_id');
    $table->index('product_id');
    $table->index('key');
    $table->index('status');
});

// marketplace_orders table
Schema::create('marketplace_orders', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained('users');
    $table->string('order_number')->unique();
    $table->decimal('subtotal', 10, 2);
    $table->decimal('tax', 10, 2)->default(0);
    $table->decimal('total', 10, 2);
    $table->enum('status', ['pending', 'processing', 'completed', 'failed', 'refunded']);
    $table->string('payment_method');
    $table->string('payment_id')->nullable();
    $table->json('metadata')->nullable();
    $table->timestamps();

    $table->index('user_id');
    $table->index('order_number');
    $table->index('status');
});
```

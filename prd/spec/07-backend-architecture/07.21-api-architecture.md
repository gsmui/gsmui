# 07.21 - API Architecture

**Project:** GsmUi
**Architecture:** REST API + Sanctum Token Authentication
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

Although GsmUi is primarily a Livewire application, core capabilities are exposed through a versioned REST API for mobile clients, CLI tools, MCP integrations, and third parties. The API is *service-first*: controllers are thin, delegate to the Action and Service layers (`07.06-service-layer.md`, `07.08-action-layer.md`), and transform results through Laravel API Resources.

This document specifies the *implementation mechanics* of the API: route versioning, controller skeletons, resource transformation, Sanctum token issuance, and rate limiting. The conceptual contract (endpoints, response envelopes, error codes) is defined in `05.14-api.md` and is not repeated here.

> See also: 05.14-api.md (API concept), 07.22-authentication.md (Sanctum token flows), 07.15-policies.md / 07.16-gates.md (authorization in controllers).

---

# 1. Versioning

Version is expressed in the URI. Each version owns a route file group.

```php
// routes/api/v1.php
Route::prefix('v1')->middleware(['auth:sanctum'])->group(function (): void {
    Route::apiResource('components', Api\V1\ComponentController::class);
    Route::apiResource('themes', Api\V1\ThemeController::class);
});
```

```text
/api/v1/components
/api/v1/themes
/api/v2/components   (future)
```

Breaking changes require a new version directory `app/Http/Controllers/Api/V{n}/`. Never remove fields within a major version; deprecate first.

# 2. Controller Skeleton

Controllers contain no business logic. They validate via Form Request (`07.17-validation.md`), execute an Action, and wrap the result in a Resource.

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Api\V1;

use App\Domains\Components\Actions\CreateComponentAction;
use App\Domains\Components\Dto\CreateComponentData;
use App\Http\Resources\V1\ComponentResource;
use App\Http\Requests\Api\V1\StoreComponentRequest;
use Illuminate\Http\JsonResponse;

final class ComponentController extends \App\Http\Controllers\Controller
{
    public function store(
        StoreComponentRequest $request,
        CreateComponentAction $action,
    ): JsonResponse {
        $component = $action->execute(
            CreateComponentData::fromRequest($request->validated())
        );

        return ComponentResource::make($component)
            ->response()
            ->setStatusCode(201);
    }

    public function index(\App\Domains\Components\Services\ComponentQueryService $query): JsonResponse
    {
        return ComponentResource::collection(
            $query->paginate(perPage: 15)
        )->response();
    }
}
```

# 3. API Resources

Resources decouple the internal model from the public schema, hide internals, and standardize the envelope.

```php
<?php

declare(strict_types=1);

namespace App\Http\Resources\V1;

use Illuminate\Http\Resources\Json\JsonResource;

final class ComponentResource extends JsonResource
{
    public function toArray($request): array
    {
        return [
            'id' => $this->id,
            'slug' => $this->slug,
            'name' => $this->name,
            'category' => $this->category,
            'downloads' => $this->downloads,
            'created_at' => $this->created_at?->toIso8601String(),
        ];
    }

    public function with($request): array
    {
        return ['success' => true];
    }
}
```

Collection responses inherit Laravel's `meta`/`links` pagination envelope (`05.14-api.md`).

# 4. Authentication: Sanctum Tokens

Token clients authenticate with a `Bearer` token issued by Sanctum. Session/SPA auth uses the same guard (`auth:sanctum`) for cookie-based requests.

```php
// app/Providers/AppServiceProvider.php (or AuthServiceProvider)
use Laravel\Sanctum\Sanctum;

public function boot(): void
{
    Sanctum::usePersonalAccessTokenModel(\App\Models\PersonalAccessToken::class);
}
```

Token issuance endpoint (thin controller delegating to an Action):

```php
final class TokenController extends Controller
{
    public function store(TokenRequest $request): JsonResponse
    {
        $token = $request->user()->createToken(
            name: $request->input('device'),
            abilities: $request->input('abilities', ['*']),
        );

        return response()->json(['token' => $token->plainTextToken]);
    }
}
```

Guards used in routes: `auth:sanctum` (token or SPA cookie). See `07.22-authentication.md` for the full Fortify + Sanctum flow.

# 5. Rate Limiting

Use Laravel's `RateLimiter` via route middleware. Define named limiters in `bootstrap/app.php` (Laravel 13 style).

```php
use Illuminate\Support\Facades\RateLimiter;
use Illuminate\Cache\RateLimiting\Limit;

RateLimiter::for('api', function ($request) {
    return $request->user()
        ? Limit::perMinute(120)->by($request->user()->id)
        : Limit::perMinute(60)->by($request->ip());
});

RateLimiter::for('search', fn ($request) =>
    Limit::perMinute(30)->by($request->ip()));
```

Applied per route group:

```php
Route::middleware(['auth:sanctum', 'throttle:api'])->group(/* ... */);
Route::middleware(['throttle:search'])->group(
    fn () => Route::get('search', SearchController::class)
);
```

Limits align with `05.14-api.md` (Public 60/min, Authenticated 120/min, Search 30/min).

# 6. Authorization in the API

Controllers never authorize inline. They rely on Policies (`07.15-policies.md`) via `authorizeResource()` and Gates (`07.16-gates.md`).

```php
public function __construct()
{
    $this->authorizeResource(Component::class, 'component');
}
```

For ad-hoc abilities:

```php
abort_unless($request->user()->can('publish themes'), 403);
```

# 7. OpenAPI Documentation

Generate OpenAPI specs from routes/resources (e.g. `scribe` or `l5-swagger`). Each Resource's `toArray()` is the source of truth for response schemas. Documented elements:

| Element | Source |
| ------- | ------ |
| Endpoints | `routes/api/v{n}.php` |
| Request shape | Form Request (`07.17-validation.md`) |
| Response shape | API Resource |
| Auth | `auth:sanctum` + token header |
| Errors | `05.14-api.md` status table |

## 9.1 Component Controller (Complete)

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Api\V1;

use App\Domains\Components\Actions\CreateComponentAction;
use App\Domains\Components\Actions\DeleteComponentAction;
use App\Domains\Components\Actions\UpdateComponentAction;
use App\Domains\Components\Dto\CreateComponentData;
use App\Domains\Components\Dto\UpdateComponentData;
use App\Domains\Components\Models\Component;
use App\Domains\Components\Services\ComponentQueryService;
use App\Http\Requests\Api\V1\StoreComponentRequest;
use App\Http\Requests\Api\V1\UpdateComponentRequest;
use App\Http\Resources\V1\ComponentResource;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\AnonymousResourceCollection;

final class ComponentController extends Controller
{
    public function __construct(
        private readonly ComponentQueryService $queryService,
    ) {
        $this->authorizeResource(Component::class, 'component');
    }

    public function index(Request $request): AnonymousResourceCollection
    {
        $components = $this->queryService
            ->search($request->input('q', ''))
            ->filterByCategory($request->input('category'))
            ->filterByVisibility($request->input('visibility', 'public'))
            ->sortBy($request->input('sort', 'updated_at'), $request->input('direction', 'desc'))
            ->paginate($request->input('per_page', 15));

        return ComponentResource::collection($components);
    }

    public function store(StoreComponentRequest $request, CreateComponentAction $action): JsonResponse
    {
        $dto = CreateComponentData::fromRequest($request->validated());
        $component = $action->execute($dto);

        return ComponentResource::make($component)
            ->response()
            ->setStatusCode(201);
    }

    public function show(Component $component): ComponentResource
    {
        return ComponentResource::make($component->load(['user', 'tags', 'media']));
    }

    public function update(
        UpdateComponentRequest $request,
        Component $component,
        UpdateComponentAction $action,
    ): ComponentResource {
        $dto = UpdateComponentData::fromRequest($request->validated());
        $component = $action->execute($component, $dto);

        return ComponentResource::make($component);
    }

    public function destroy(
        Component $component,
        DeleteComponentAction $action,
    ): JsonResponse {
        $action->execute($component);

        return response()->json(['message' => 'Component deleted.'], 200);
    }

    public function publish(Component $component): JsonResponse
    {
        abort_unless($component->status === 'draft', 422, 'Only draft components can be published.');

        $component->update(['status' => 'published', 'published_at' => now()]);

        return ComponentResource::make($component->fresh())
            ->response()
            ->setStatusCode(200);
    }
}
```

## 9.3 Marketplace Product Controller

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Api\V1;

use App\Domains\Marketplace\Actions\CreateProductAction;
use App\Domains\Marketplace\Actions\DeleteProductAction;
use App\Domains\Marketplace\Actions\UpdateProductAction;
use App\Domains\Marketplace\Dto\CreateProductData;
use App\Domains\Marketplace\Dto\UpdateProductData;
use App\Domains\Marketplace\Models\Product;
use App\Domains\Marketplace\Services\ProductQueryService;
use App\Http\Requests\Api\V1\StoreProductRequest;
use App\Http\Requests\Api\V1\UpdateProductRequest;
use App\Http\Resources\V1\ProductResource;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\AnonymousResourceCollection;

final class ProductController extends Controller
{
    public function __construct(
        private readonly ProductQueryService $queryService,
    ) {
        $this->authorizeResource(Product::class, 'product');
    }

    public function index(Request $request): AnonymousResourceCollection
    {
        $products = $this->queryService
            ->search($request->input('q', ''))
            ->filterByType($request->input('type'))
            ->filterByPriceRange(
                $request->input('min_price'),
                $request->input('max_price'),
            )
            ->sortBy($request->input('sort', 'sales_count'), $request->input('direction', 'desc'))
            ->paginate($request->input('per_page', 15));

        return ProductResource::collection($products);
    }

    public function store(StoreProductRequest $request, CreateProductAction $action): JsonResponse
    {
        $dto = CreateProductData::fromRequest($request->validated());
        $product = $action->execute($dto);

        return ProductResource::make($product)
            ->response()
            ->setStatusCode(201);
    }

    public function show(Product $product): ProductResource
    {
        abort_unless($product->status === 'published', 404);

        return ProductResource::make(
            $product->load(['user', 'tags', 'media', 'reviews'])
        );
    }

    public function update(
        UpdateProductRequest $request,
        Product $product,
        UpdateProductAction $action,
    ): ProductResource {
        $dto = UpdateProductData::fromRequest($request->validated());
        $product = $action->execute($product, $dto);

        return ProductResource::make($product);
    }

    public function destroy(Product $product, DeleteProductAction $action): JsonResponse
    {
        abort_unless($product->sales_count === 0, 422, 'Cannot delete a product with sales.');

        $action->execute($product);

        return response()->json(['message' => 'Product deleted.'], 200);
    }

    public function reviews(Product $product): JsonResponse
    {
        $reviews = $product->reviews()
            ->with('user')
            ->orderByDesc('created_at')
            ->paginate(10);

        return response()->json($reviews);
    }
}
```

## 9.4 User / Profile Controller

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Api\V1;

use App\Domains\Users\Actions\UpdateProfileAction;
use App\Domains\Users\Dto\UpdateProfileData;
use App\Domains\Users\Models\User;
use App\Http\Requests\Api\V1\UpdateProfileRequest;
use App\Http\Resources\V1\UserResource;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;

final class UserController extends Controller
{
    public function show(Request $request): UserResource
    {
        return UserResource::make(
            $request->user()->load(['teams', 'media'])
        );
    }

    public function update(UpdateProfileRequest $request, UpdateProfileAction $action): UserResource
    {
        $dto = UpdateProfileData::fromRequest($request->validated());
        $user = $action->execute($request->user(), $dto);

        return UserResource::make($user);
    }

    public function destroy(Request $request): JsonResponse
    {
        $user = $request->user();

        // Revoke all tokens first
        $user->tokens()->delete();

        // Dispatch deletion job (soft-delete then hard-delete after grace period)
        \App\Domains\Users\Jobs\DeleteUserJob::dispatch($user)->delay(now()->addDays(30));

        auth('web')->logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return response()->json(['message' => 'Account scheduled for deletion.'], 200);
    }

    public function changePassword(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'current_password' => ['required', 'current_password'],
            'password' => ['required', 'string', 'min:12', 'confirmed'],
        ]);

        $request->user()->update([
            'password' => \Hash::make($validated['password']),
        ]);

        $request->user()->tokens()->delete();

        return response()->json(['message' => 'Password updated. All sessions invalidated.'], 200);
    }
}
```

## 9.5 Search Controller

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Api\V1;

use App\Domains\Search\Services\SearchService;
use App\Http\Resources\V1\SearchResultResource;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Http\Resources\Json\AnonymousResourceCollection;

final class SearchController extends Controller
{
    public function __invoke(
        Request $request,
        SearchService $searchService,
    ): JsonResponse {
        $validated = $request->validate([
            'q' => ['required', 'string', 'min:2', 'max:200'],
            'types' => ['nullable', 'array'],
            'types.*' => ['string', Rule::in(['component', 'theme', 'product', 'doc', 'blog'])],
            'category' => ['nullable', 'string', 'max:100'],
            'page' => ['nullable', 'integer', 'min:1'],
            'per_page' => ['nullable', 'integer', 'min:1', 'max:50'],
        ]);

        $results = $searchService->search(
            query: $validated['q'],
            filters: array_filter([
                'types' => $validated['types'] ?? null,
                'category' => $validated['category'] ?? null,
            ]),
            page: $validated['page'] ?? 1,
            perPage: $validated['per_page'] ?? 20,
        );

        return response()->json([
            'data' => $results['hits'],
            'meta' => [
                'total' => $results['total'],
                'query' => $validated['q'],
                'page' => $validated['page'] ?? 1,
                'per_page' => $validated['per_page'] ?? 20,
                'processing_time_ms' => $results['processing_time_ms'],
            ],
        ]);
    }
}
```

# 13. Error Handling

## 13.1 API Exception Handler

```php
<?php

declare(strict_types=1);

namespace App\Exceptions;

use Illuminate\Auth\AuthenticationException;
use Illuminate\Database\Eloquent\ModelNotFoundException;
use Illuminate\Foundation\Exceptions\Handler as ExceptionHandler;
use Illuminate\Http\JsonResponse;
use Illuminate\Validation\ValidationException;
use Symfony\Component\HttpKernel\Exception\NotFoundHttpException;
use Throwable;

final class ApiExceptionHandler extends ExceptionHandler
{
    public function register(): void
    {
        $this->renderable(function (Throwable $e, $request) {
            if (! $request->expectsJson()) {
                return null; // delegate to parent
            }

            return $this->handleJsonException($e, $request);
        });
    }

    private function handleJsonException(Throwable $e, $request): JsonResponse
    {
        return match (true) {
            $e instanceof ValidationException => $this->formatValidationErrors($e),
            $e instanceof ModelNotFoundException => response()->json([
                'success' => false,
                'message' => 'Resource not found.',
                'errors' => ['resource' => ['The requested resource does not exist.']],
            ], 404),
            $e instanceof AuthenticationException => response()->json([
                'success' => false,
                'message' => 'Unauthenticated.',
            ], 401),
            $e instanceof \Symfony\Component\HttpKernel\Exception\AccessDeniedHttpException => response()->json([
                'success' => false,
                'message' => 'Forbidden.',
            ], 403),
            default => response()->json([
                'success' => false,
                'message' => $this->isProduction() ? 'Server error.' : $e->getMessage(),
            ], $this->getStatusCode($e)),
        };
    }

    private function formatValidationErrors(ValidationException $e): JsonResponse
    {
        return response()->json([
            'success' => false,
            'message' => 'Validation failed.',
            'errors' => $e->errors(),
        ], 422);
    }

    private function getStatusCode(Throwable $e): int
    {
        return $e->getCode() >= 400 && $e->getCode() < 600 ? $e->getCode() : 500;
    }

    private function isProduction(): bool
    {
        return app()->environment('production');
    }
}
```

## 15.2 Custom Middleware Implementations

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

final class ForceJsonResponse
{
    public function handle(Request $request, Closure $next): Response
    {
        $request->headers->set('Accept', 'application/json');

        return $next($request);
    }
}

final class EnsureJsonContentType
{
    public function handle(Request $request, Closure $next): Response
    {
        if ($request->isMethod('POST') || $request->isMethod('PUT') || $request->isMethod('PATCH')) {
            $contentType = $request->header('Content-Type', '');

            if (str_contains($contentType, 'application/json') === false) {
                return response()->json([
                    'success' => false,
                    'message' => 'Content-Type must be application/json.',
                ], 415);
            }
        }

        return $next($request);
    }
}

final class SetApiLocale
{
    public function handle(Request $request, Closure $next): Response
    {
        if ($locale = $request->header('Accept-Language')) {
            app()->setLocale(explode(',', $locale)[0]);
        }

        return $next($request);
    }
}

final class TrackApiRequest
{
    public function handle(Request $request, Closure $next): Response
    {
        $response = $next($request);

        \Log::channel('api')->info('API Request', [
            'method' => $request->method(),
            'path' => $request->path(),
            'status' => $response->getStatusCode(),
            'user_id' => $request->user()?->id,
            'ip' => $request->ip(),
            'duration_ms' => round((microtime(true) - LARAVEL_START) * 1000),
        ]);

        return $response;
    }
}
```

# 17. API Versioning Strategy

## 17.1 When to Create a New Version

Create a new API version when:
- Response schema changes (fields removed or renamed)
- Authentication mechanism changes
- Endpoint URI structure changes
- Breaking behavioral changes to existing endpoints

Never create a new version for:
- Adding new optional fields to responses
- Adding new endpoints within an existing version
- Adding new optional query parameters

## 17.2 Deprecated Fields

Mark deprecated fields in Resource `toArray()` with a `deprecated` annotation:

```php
'old_field' => $this->when(
    true,
    fn () => $this->old_field,
    fn () => null // return null instead of omitting when deprecated
),
```

Log usage of deprecated fields via a middleware that inspects response content.

## 24.2 Input Sanitization

```php
final class SanitizeInput
{
    public function handle(Request $request, Closure $next): Response
    {
        if ($request->isJson()) {
            $sanitized = $this->sanitizeArray($request->all());
            $request->merge($sanitized);
        }

        return $next($request);
    }

    private function sanitizeArray(array $data): array
    {
        return array_map(function ($value) {
            if (is_string($value)) {
                return strip_tags(trim($value));
            }
            if (is_array($value)) {
                return $this->sanitizeArray($value);
            }
            return $value;
        }, $data);
    }
}
```

## 24.3 API Key Authentication (Alternative)

For machine-to-machine auth, support API keys alongside Sanctum tokens:

```php
final class ApiKeyMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $apiKey = $request->header('X-API-Key');

        if ($apiKey) {
            $validKey = \App\Models\ApiKey::where('key', hash('sha256', $apiKey))
                ->where('active', true)
                ->first();

            if (! $validKey || $validKey->expires_at?->isPast()) {
                return response()->json(['message' => 'Invalid API key.'], 401);
            }

            $validKey->update(['last_used_at' => now()]);

            $request->attributes->set('api_key', $validKey);
        }

        return $next($request);
    }
}
```

# 25. API Response Wrapping

All responses use a consistent envelope. The `ApiResponse` trait provides helpers:

```php
trait ApiResponse
{
    private function successResponse($data = null, int $code = 200): JsonResponse
    {
        return response()->json([
            'success' => true,
            'data' => $data,
        ], $code);
    }

    private function errorResponse(string $message, int $code, array $errors = []): JsonResponse
    {
        return response()->json([
            'success' => false,
            'message' => $message,
            'errors' => $errors,
        ], $code);
    }

    private function paginatedResponse(LengthAwarePaginator $paginator, $resourceClass): JsonResponse
    {
        return response()->json([
            'data' => $resourceClass::collection($paginator->items()),
            'links' => [
                'first' => $paginator->url(1),
                'last' => $paginator->url($paginator->lastPage()),
                'prev' => $paginator->previousPageUrl(),
                'next' => $paginator->nextPageUrl(),
            ],
            'meta' => [
                'current_page' => $paginator->currentPage(),
                'from' => $paginator->firstItem(),
                'last_page' => $paginator->lastPage(),
                'path' => $paginator->path(),
                'per_page' => $paginator->perPage(),
                'to' => $paginator->lastItem(),
                'total' => $paginator->total(),
            ],
        ]);
    }
}
```

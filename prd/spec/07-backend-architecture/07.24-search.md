# 07.24 - Search

**Project:** GsmUi
**Architecture:** Laravel Scout + Meilisearch (Primary Engine)
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

Search is a first-class capability in GsmUi: users locate components, documentation, themes, templates, blog posts, and marketplace products in milliseconds. GsmUi implements search with **Laravel Scout** as the abstraction layer and **Meilisearch** as the primary engine, satisfying the conceptual architecture in `05.13-search.md`. Indexing is queued so it never blocks HTTP requests, and a `SearchService` (not Scout directly) is the only entry point presentation layers may call.

This document specifies the *implementation mechanics*: Scout driver configuration, the `Searchable` contract, per-model index definitions, engine tuning (filterable/searchable attributes, ranking), and reindex orchestration. The conceptual flow and UX are covered in `05.13-search.md`.

> See also: 05.13-search.md (search concept), 07.07-repository-layer.md (read path), 07.08-action-layer.md (reindex triggers), 05.10-events.md (indexing events).

---

# 1. Engine Configuration

Scout driver is selected per environment via `config/scout.php` and `.env`.

```php
// config/scout.php (excerpt)
'driver' => env('SCOUT_DRIVER', 'meilisearch'),

'meilisearch' => [
    'host' => env('MEILISEARCH_HOST', 'http://meilisearch:7700'),
    'key' => env('MEILISEARCH_KEY'),
    'index-settings' => [
        'gsmui_components' => [
            'searchableAttributes' => ['title', 'description', 'content', 'tags'],
            'filterableAttributes' => ['category', 'status', 'version', 'free'],
            'sortableAttributes' => ['downloads', 'updated_at'],
            'rankingRules' => [
                'typo', 'words', 'proximity', 'attribute',
                'downloads:desc', 'updated_at:desc',
            ],
        ],
        'gsmui_docs' => [
            'searchableAttributes' => ['title', 'content', 'section'],
            'filterableAttributes' => ['version', 'section', 'product'],
            'sortableAttributes' => ['updated_at'],
        ],
    ],
],
```

# 2. The Searchable Contract

Every searchable model implements `Laravel\Scout\Searchable` and exposes a normalized `toSearchableArray()`. GsmUi wraps this in a `SearchableResource` contract so presentation layers receive a uniform shape (`05.13-search.md`).

```php
<?php

declare(strict_types=1);

namespace App\Domains\Components\Models;

use App\Domains\Shared\Contracts\SearchableResource;
use Illuminate\Database\Eloquent\Model;
use Laravel\Scout\Searchable;

final class Component extends Model implements SearchableResource
{
    use Searchable;

    public function searchableAs(): string
    {
        return 'gsmui_components';
    }

    public function toSearchableArray(): array
    {
        return [
            'id' => (int) $this->id,
            'type' => 'component',
            'title' => $this->name,
            'description' => $this->description,
            'slug' => $this->slug,
            'content' => $this->readme ?? '',
            'tags' => $this->tags ?? [],
            'category' => $this->category,
            'status' => $this->status,
            'version' => $this->version,
            'free' => $this->price === 0,
            'downloads' => (int) $this->downloads,
            'updated_at' => $this->updated_at?->timestamp,
        ];
    }

    public function searchableTitle(): string { return $this->name; }
    public function searchableContent(): string { return (string) $this->description; }
    public function searchableUrl(): string { return route('components.show', $this); }
    public function searchableType(): string { return 'component'; }
}
```

# 3. SearchService (Presentation Boundary)

Presentation layers (Livewire, API) call `SearchService`, never Scout directly. The service builds the query, applies authorization-aware filtering, and aggregates per domain.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Search\Services;

use App\Domains\Components\Models\Component;
use App\Domains\Shared\Contracts\SearchableResource;
use Illuminate\Support\Collection;
use Laravel\Scout\Builder;

final class SearchService
{
    public function search(string $query, array $filters = []): Collection
    {
        return Component::search($query)
            ->when($filters['category'] ?? null, fn (Builder $b, $c) => $b->where('category', $c))
            ->when($filters['free'] ?? null, fn (Builder $b, $f) => $b->where('free', $f))
            ->take(20)
            ->get()
            ->map(fn (SearchableResource $m) => [
                'title' => $m->searchableTitle(),
                'url' => $m->searchableUrl(),
                'type' => $m->searchableType(),
            ]);
    }
}
```

Livewire usage (pagination via Scout's `paginate`):

```php
$results = app(SearchService::class)->search($this->query, $this->filters);
```

# 4. Indexing Pipeline

Index updates are queued. Models are auto-synced on save; bulk operations use queued jobs dispatched from Actions (`07.08-action-layer.md`) or domain events (`05.10-events.md`).

```text
Publish Component (Action)
      │
Domain Event: ComponentReleased  ──► 05.10-events.md
      │
Queue Job: IndexComponent
      │
Scout ->update() -> Meilisearch
```

```php
// Force reindex (deployment / recovery)
// php artisan scout:import "App\Domains\Components\Models\Component"
```

Soft-deleted or draft content must be excluded:

```php
public function shouldBeSearchable(): bool
{
    return $this->status === 'published';
}
```

# 5. Relevance Tuning

| Knob | Where | Effect |
| ---- | ----- | ------ |
| `searchableAttributes` | `config/scout.php` | Fields matched against query |
| `filterableAttributes` | `config/scout.php` | Fields usable in `where()` |
| `sortableAttributes` | `config/scout.php` | Fields usable in `orderBy()` |
| `rankingRules` | `config/scout.php` | Default ranking (typo, downloads, recency) |
| `typo` tolerance | Meilisearch default | Fuzzy matching on titles |

Tune per index (see `05.13-search.md` §Search Ranking). Avoid over-broad `searchableAttributes`, which dilutes relevance.

---

# 6. Fallback & Resilience

If Meilisearch is unavailable, Scout's `collection` driver (MySQL `where like`) provides degraded search, and failures are logged + retried. The application remains functional (`05.13-search.md` §Error Handling).

```php
try {
    return $this->search($query, $filters);
} catch (\Meilisearch\Exceptions\ApiException $e) {
    report($e);
    return $this->mysqlFallback($query, $filters);
}
```

# 8. Search Controller

## 8.1 API Search Controller

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers\Api\V1;

use App\Domains\Search\Services\SearchService;
use App\Domains\Search\Services\SearchSuggestionService;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Validation\Rule;

final class SearchController extends Controller
{
    public function __construct(
        private readonly SearchService $searchService,
        private readonly SearchSuggestionService $suggestionService,
    ) {}

    public function __invoke(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'q' => ['required', 'string', 'min:2', 'max:200'],
            'types' => ['nullable', 'array'],
            'types.*' => ['string', Rule::in(['component', 'theme', 'product', 'doc', 'blog'])],
            'category' => ['nullable', 'string', 'max:100'],
            'sort' => ['nullable', 'string', Rule::in(['relevance', 'downloads', 'rating', 'created_at'])],
            'page' => ['nullable', 'integer', 'min:1'],
            'per_page' => ['nullable', 'integer', 'min:1', 'max:50'],
        ]);

        $results = $this->searchService->search(
            query: $validated['q'],
            filters: array_filter([
                'types' => $validated['types'] ?? null,
                'category' => $validated['category'] ?? null,
            ]),
            sort: $validated['sort'] ?? 'relevance',
            page: $validated['page'] ?? 1,
            perPage: $validated['per_page'] ?? 20,
        );

        return response()->json([
            'data' => $results['hits'],
            'meta' => [
                'total' => $results['total'],
                'query' => $validated['q'],
                'page' => $validated['page'] ?? 1,
                'per_page' => $validated['per_page'] ?? 20,
                'processing_time_ms' => $results['processing_time_ms'],
                'facets' => $results['facets'] ?? [],
            ],
        ]);
    }

    public function suggest(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'q' => ['required', 'string', 'min:1', 'max:100'],
        ]);

        $suggestions = $this->suggestionService->getSuggestions($validated['q']);

        return response()->json(['data' => $suggestions]);
    }
}
```

# 9. Enhanced SearchService

```php
<?php

declare(strict_types=1);

namespace App\Domains\Search\Services;

use App\Domains\Components\Models\Component;
use App\Domains\Themes\Models\Theme;
use App\Domains\Marketplace\Models\Product;
use App\Domains\Documentation\Models\DocPage;
use App\Domains\Shared\Contracts\SearchableResource;
use Illuminate\Support\Collection;
use Illuminate\Support\Facades\DB;
use Laravel\Scout\Builder;

final class SearchService
{
    private const TYPE_MAP = [
        'component' => Component::class,
        'theme' => Theme::class,
        'product' => Product::class,
        'doc' => DocPage::class,
    ];

    public function search(
        string $query,
        array $filters = [],
        string $sort = 'relevance',
        int $page = 1,
        int $perPage = 20,
    ): array {
        $startTime = microtime(true);

        $types = $filters['types'] ?? array_keys(self::TYPE_MAP);
        $hits = collect();
        $total = 0;

        foreach ($types as $type) {
            $modelClass = self::TYPE_MAP[$type] ?? null;

            if (! $modelClass || ! class_exists($modelClass)) {
                continue;
            }

            $builder = $modelClass::search($query);

            // Apply filters
            if (isset($filters['category'])) {
                $builder->where('category', $filters['category']);
            }

            if (isset($filters['visibility'])) {
                $builder->where('visibility', $filters['visibility']);
            }

            if (isset($filters['status'])) {
                $builder->where('status', $filters['status']);
            }

            if (isset($filters['free'])) {
                $builder->where('free', $filters['free']);
            }

            // Apply sorting
            $builder = $this->applySorting($builder, $sort);

            // Get results
            $modelHits = $builder->paginate($perPage, 'page', $page);

            $hits = $hits->merge($modelHits->items());
            $total += $modelHits->total();
        }

        // Sort merged results if not relevance
        if ($sort !== 'relevance') {
            $hits = $this->sortMergedResults($hits, $sort);
        }

        $processingTime = round((microtime(true) - $startTime) * 1000, 2);

        return [
            'hits' => $hits->map(fn (SearchableResource $model) => [
                'id' => $model->id,
                'type' => $model->searchableType(),
                'title' => $model->searchableTitle(),
                'content' => $model->searchableContent(),
                'url' => $model->searchableUrl(),
                'thumbnail' => method_exists($model, 'getFirstMediaUrl')
                    ? $model->getFirstMediaUrl('thumb')
                    : null,
            ])->values()->all(),
            'total' => $total,
            'processing_time_ms' => $processingTime,
        ];
    }

    public function publicSearch(
        string $query,
        array $filters = [],
        int $page = 1,
        int $perPage = 20,
    ): array {
        $filters['visibility'] = 'public';
        $filters['types'] = $filters['types'] ?? ['component', 'theme', 'product', 'doc'];

        return $this->search($query, $filters, 'relevance', $page, $perPage);
    }

    public function indexAll(): void
    {
        $models = [
            Component::class,
            Theme::class,
            Product::class,
            DocPage::class,
        ];

        foreach ($models as $modelClass) {
            $modelClass::factory()->count(0); // just to check factory exists
            \Artisan::call('scout:import', ['model' => $modelClass]);
        }
    }

    public function reindexModel(string $modelClass): void
    {
        \Artisan::call('scout:import', ['model' => $modelClass]);
    }

    private function applySorting(Builder $builder, string $sort): Builder
    {
        return match ($sort) {
            'downloads' => $builder->orderBy('downloads', 'desc'),
            'rating' => $builder->orderBy('rating_avg', 'desc'),
            'created_at' => $builder->orderBy('created_at', 'desc'),
            default => $builder, // relevance = Meilisearch default ranking
        };
    }

    private function sortMergedResults(Collection $hits, string $sort): Collection
    {
        return $hits->sortByDesc(function ($hit) use ($sort) {
            return match ($sort) {
                'downloads' => $hit['downloads'] ?? 0,
                'rating' => $hit['rating_avg'] ?? 0,
                'created_at' => $hit['created_at'] ?? '',
                default => 0,
            };
        })->values();
    }
}
```

# 10. Search Suggestion Service

```php
<?php

declare(strict_types=1);

namespace App\Domains\Search\Services;

use App\Domains\Components\Models\Component;
use App\Domains\Themes\Models\Theme;
use App\Domains\Marketplace\Models\Product;
use Illuminate\Support\Collection;

final class SearchSuggestionService
{
    public function getSuggestions(string $query, int $limit = 5): array
    {
        $suggestions = [];

        // Component suggestions
        $components = Component::where('name', 'LIKE', "%{$query}%")
            ->where('status', 'published')
            ->limit($limit)
            ->get(['id', 'name', 'slug'])
            ->map(fn ($c) => [
                'type' => 'component',
                'title' => $c->name,
                'url' => route('components.show', $c->slug),
            ]);

        // Theme suggestions
        $themes = Theme::where('name', 'LIKE', "%{$query}%")
            ->where('status', 'published')
            ->limit($limit)
            ->get(['id', 'name', 'slug'])
            ->map(fn ($t) => [
                'type' => 'theme',
                'title' => $t->name,
                'url' => route('themes.show', $t->slug),
            ]);

        // Product suggestions
        $products = Product::where('name', 'LIKE', "%{$query}%")
            ->where('status', 'published')
            ->limit($limit)
            ->get(['id', 'name', 'slug'])
            ->map(fn ($p) => [
                'type' => 'product',
                'title' => $p->name,
                'url' => route('products.show', $p->slug),
            ]);

        return $components->merge($themes)->merge($products)->take($limit * 3)->all();
    }

    public function getPopularSearches(int $limit = 10): array
    {
        return \Cache::remember('popular_searches', now()->addHour(), function () use ($limit) {
            return \DB::table('search_logs')
                ->select('query', DB::raw('count(*) as count'))
                ->where('created_at', '>=', now()->subDays(7))
                ->groupBy('query')
                ->orderByDesc('count')
                ->limit($limit)
                ->pluck('query')
                ->toArray();
        });
    }

    public function getRecentSearches(int $userId, int $limit = 10): array
    {
        return \DB::table('search_logs')
            ->where('user_id', $userId)
            ->orderByDesc('created_at')
            ->limit($limit)
            ->pluck('query')
            ->toArray();
    }

    public function recordSearch(string $query, ?int $userId): void
    {
        \DB::table('search_logs')->insert([
            'query' => $query,
            'user_id' => $userId,
            'ip' => request()->ip(),
            'created_at' => now(),
        ]);
    }
}
```

```php
declare(strict_types=1);

namespace App\Domains\Search\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;

final class IndexModelJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public int $tries = 3;

    public function __construct(
        public readonly string $modelClass,
        public readonly int $modelId,
    ) {}

    public function handle(): void
    {
        $model = $this->modelClass::find($this->modelId);

        if ($model) {
            $model->searchable();
        }
    }

    public function failed(\Throwable $exception): void
    {
        \Log::error('Index model failed', [
            'model' => $this->modelClass,
            'id' => $this->modelId,
            'error' => $exception->getMessage(),
        ]);
    }
}
```

```php
declare(strict_types=1);

namespace App\Http\Livewire\Search;

use Livewire\Component;

final class SearchBox extends Component

    public array $filters = [];
    public string $sort = 'relevance';
    public int $perPage = 20;
    public array $results = [];
    public int $totalResults = 0;
    public bool $showSuggestions = false;
    public array $suggestions = [];

    public function updatedQuery(): void
    {
        if (strlen($this->query) >= 2) {
            $this->suggestions = app(SearchSuggestionService::class)
                ->getSuggestions($this->query, 5);
            $this->showSuggestions = true;
        } else {
            $this->suggestions = [];
            $this->showSuggestions = false;
        }
    }

    public function search(): void
    {
        $this->showSuggestions = false;

        $result = app(SearchService::class)->search(
            query: $this->query,
            filters: $this->filters,
            sort: $this->sort,
            perPage: $this->perPage,
        );

        $this->results = $result['hits'];
        $this->totalResults = $result['total'];

        // Record search for analytics
        app(SearchSuggestionService::class)
            ->recordSearch($this->query, auth()->id());
    }

    public function clearSearch(): void
    {
        $this->query = '';
        $this->results = [];
        $this->totalResults = 0;
        $this->filters = [];
        $this->sort = 'relevance';
    }

    public function applyFilter(string $key, $value): void
    {
        $this->filters[$key] = $value;
        $this->search();
    }

    public function render()
    {
        return view('gsmui::livewire.search.search-box');
    }
}
```

# 20. Search Caching Strategy

Cache frequent search results to reduce Meilisearch load:

```php
<?php

declare(strict_types=1);

namespace App\Domains\Search\Services;

use Illuminate\Support\Facades\Cache;

final class CachedSearchService
{
    public function __construct(
        private SearchService $searchService,
    ) {}

    public function cachedSearch(
        string $query,
        array $filters = [],
        string $sort = 'relevance',
        int $page = 1,
        int $perPage = 20,
    ): array {
        $cacheKey = $this->buildCacheKey($query, $filters, $sort, $page, $perPage);

        return Cache::tags(['search'])->remember(
            $cacheKey,
            now()->addMinutes(5),
            fn () => $this->searchService->search($query, $filters, $sort, $page, $perPage)
        );
    }

    private function buildCacheKey(string $query, array $filters, string $sort, int $page, int $perPage): string
    {
        return 'search:' . md5(serialize(compact('query', 'filters', 'sort', 'page', 'perPage')));
    }

    public function clearSearchCache(): void
    {
        Cache::tags(['search'])->flush();
    }
}
```

```php
declare(strict_types=1);

namespace App\Domains\Search\Services;

use Illuminate\Support\Facades\Http;

final class SearchHealthService
{
    private string $host;
    private string $key;

    public function __construct()
    {
        $this->host = config('scout.meilisearch.host');
        $this->key = config('scout.meilisearch.key');
    }

    public function isHealthy(): bool
    {
        try {
            $response = Http::withHeaders([
                'Authorization' => 'Bearer ' . $this->key,
            ])->get("{$this->host}/health");

            return $response->successful()
                && data_get($response->json(), 'status') === 'available';
        } catch (\Throwable $e) {
            report($e);
            return false;
        }
    }

    public function getIndexStats(string $indexName): ?array
    {
        try {
            $response = Http::withHeaders([
                'Authorization' => 'Bearer ' . $this->key,
            ])->get("{$this->host}/indexes/{$indexName}/stats");

            return $response->successful() ? $response->json() : null;
        } catch (\Throwable $e) {
            report($e);
            return null;
        }
    }

    public function getAllIndexStats(): array
    {
        try {
            $response = Http::withHeaders([
                'Authorization' => 'Bearer ' . $this->key,
            ])->get("{$this->host}/stats");

            return $response->successful() ? $response->json() : [];
        } catch (\Throwable $e) {
            report($e);
            return [];
        }
    }

    public function getVersion(): ?string
    {
        try {
            $response = Http::withHeaders([
                'Authorization' => 'Bearer ' . $this->key,
            ])->get("{$this->host}/version");

            return $response->successful()
                ? data_get($response->json(), 'pkgVersion')
                : null;
        } catch (\Throwable $e) {
            return null;
        }
    }
```

# 30. Search Reindex Command

```php
<?php

declare(strict_types=1);

namespace App\Console\Commands;

use App\Domains\Search\Jobs\ReindexAllModelsJob;
use Illuminate\Console\Command;

final class ScoutReindexCommand extends Command
{
    protected $signature = 'search:reindex
                            {--model= : Specific model class to reindex}
                            {--queue : Dispatch to queue instead of running inline}';

    protected $description = 'Reindex all or specific searchable models';

    public function handle(): int
    {
        $model = $this->option('model');
        $queue = $this->option('queue');

        if ($model) {
            if ($queue) {
                \App\Domains\Search\Jobs\IndexModelJob::dispatch($model, 0);
                $this->info("Dispatched reindex job for {$model}.");
            } else {
                \Artisan::call('scout:import', ['model' => $model]);
                $this->info("Reindexed {$model}.");
            }

            return self::SUCCESS;
        }

        if ($queue) {
            ReindexAllModelsJob::dispatch();
            $this->info('Dispatched full reindex job.');
        } else {
            $models = [
                \App\Domains\Components\Models\Component::class,
                \App\Domains\Themes\Models\Theme::class,
                \App\Domains\Marketplace\Models\Product::class,
                \App\Domains\Documentation\Models\DocPage::class,
            ];

            foreach ($models as $m) {
                $this->info("Reindexing {$m}...");
                \Artisan::call('scout:import', ['model' => $m]);
            }

            $this->info('All models reindexed.');
        }

        return self::SUCCESS;
    }
}
```

```blade
    @if($showSuggestions && count($suggestions) > 0)
        <div class="absolute z-50 w-full mt-1 bg-white border rounded-lg shadow-lg">
            @foreach($suggestions as $suggestion)
                <a href="{{ $suggestion['url'] }}" class="block px-4 py-2 hover:bg-gray-100">
                    <span class="text-xs text-gray-500">{{ $suggestion['type'] }}</span>
                    <span class="ml-2">{{ $suggestion['title'] }}</span>
                </a>
            @endforeach
        </div>
    @endif

    {{-- Search Results --}}
    @if(count($results) > 0)
        <div class="mt-4">
            <p class="text-sm text-gray-500">{{ $totalResults }} results found</p>
            <div class="space-y-4 mt-2">
                @foreach($results as $result)
                    <a href="{{ $result['url'] }}" class="block p-4 border rounded-lg hover:bg-gray-50">
                        <div class="flex items-center gap-2">
                            <span class="px-2 py-1 text-xs bg-blue-100 text-blue-800 rounded">{{ $result['type'] }}</span>
                            <h3 class="font-medium">{{ $result['title'] }}</h3>
                        </div>
                        <p class="mt-1 text-sm text-gray-600">{{ Str::limit($result['content'], 150) }}</p>
                    </a>
                @endforeach
            </div>
        </div>
    @endif
</div>
```

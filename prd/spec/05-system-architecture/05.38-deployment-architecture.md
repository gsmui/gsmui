# Purpose

This document details the deployment architecture, including infrastructure, deployment strategies, and operational procedures. It provides a comprehensive reference for how the platform is deployed, scaled, and maintained across different environments.

---

# Architecture Overview

The deployment architecture follows infrastructure-as-code principles with automated provisioning, configuration management, and deployment pipelines. The platform is deployed on cloud infrastructure with containers for isolation and scalability.

The architecture supports multiple deployment targets including development, staging, and production environments. Each environment is isolated with its own resources, configuration, and access controls. Deployments are automated through CI/CD pipelines with manual approval gates for production.

The infrastructure is designed for high availability with redundant components, automatic failover, and disaster recovery capabilities. Monitoring and alerting provide visibility into system health and performance.

### Nginx Configuration

```nginx
upstream php-fpm {
    server unix:/var/run/php/php8.4-fpm.sock;
}

server {
    listen 443 ssl http2;
    server_name gsmui.com;

    root /var/www/gsmui/public;
    index index.php;

    # SSL
    ssl_certificate /etc/letsencrypt/live/gsmui.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/gsmui.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512;

    # Security headers
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Content-Security-Policy "default-src 'self'" always;

    # Gzip compression
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css application/json application/javascript text/xml;

    # Static assets caching
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # Laravel routing
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP processing
    location ~ \.php$ {
        fastcgi_pass php-fpm;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_hide_header X-Powered-By;
    }

    # Deny hidden files
    location ~ /\. {
        deny all;
        access_log off;
        log_not_found off;
    }
}
```

# Deployment Strategies

## Blue-Green Deployment

Two identical environments (blue and green) are maintained. Only one serves production traffic at a time.

```text
Blue (Current Production)
    |
    +-- Serve Traffic
    |
Green (Staging New Version)
    |
    +-- Deploy New Version
    |
    +-- Run Tests
    |
    +-- Switch Traffic
    |
Blue (Now Staging)
    |
    +-- Ready for Next Deploy
```

### Advantages
- Zero downtime deployment
- Instant rollback capability
- Full testing before traffic switch
- No database migration conflicts

### Implementation

```bash
# Deploy to inactive environment
./deploy.sh green

# Run health checks
./health-check.sh green

# Switch traffic
./switch-traffic.sh green

# Verify
./verify.sh green

# Rollback if needed
./switch-traffic.sh blue
```

## Rolling Update

Gradually replace old instances with new ones while maintaining service availability.

```text
Load Balancer
    |
    +-- Instance 1 (old) -> Instance 1 (new)
    +-- Instance 2 (old) -> Instance 2 (new)
    +-- Instance 3 (old) -> Instance 3 (new)
```

### Implementation

```yaml
# Kubernetes deployment
apiVersion: apps/v1
kind: Deployment
spec:
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
  template:
    spec:
      containers:
        - name: gsmui
          image: gsmui:latest
```

## Canary Deployment

Route a small percentage of traffic to the new version before full rollout.

```text
Load Balancer
    |
    +-- 95% -> Blue (current)
    +-- 5% -> Green (new)
```

### Metrics Monitoring
- Error rates
- Response times
- User behavior
- Business metrics

## Deployment Scripts

```bash
#!/bin/bash
# deploy.sh

set -e

ENVIRONMENT=$1
VERSION=$2

echo "Deploying version $VERSION to $ENVIRONMENT..."

# Pre-deploy checks
./scripts/pre-deploy.sh $ENVIRONMENT

# Deploy application
ssh deployer@$ENVIRONMENT "cd /var/www/gsmui && \
    git fetch origin && \
    git checkout $VERSION && \
    composer install --no-dev --optimize-autoloader && \
    npm ci && \
    npm run build && \
    php artisan migrate --force && \
    php artisan config:cache && \
    php artisan route:cache && \
    php artisan view:cache && \
    sudo systemctl restart php8.4-fpm && \
    sudo systemctl restart nginx"

# Post-deploy verification
./scripts/post-deploy.sh $ENVIRONMENT

# Health check
./scripts/health-check.sh $ENVIRONMENT

echo "Deployment complete!"
```

## Manual Rollback

```bash
# Rollback to previous version
./scripts/rollback.sh production

# Rollback database migrations
php artisan migrate:rollback --step=5

# Clear and rebuild caches
php artisan cache:clear
php artisan config:cache
php artisan route:cache
```

## Database Rollback

```php
// Ensure all migrations are reversible
Schema::table('users', function (Blueprint $table) {
    $table->string('status')->default('active');
});

// Rollback
Schema::table('users', function (Blueprint $table) {
    $table->dropColumn('status');
});
```

# Events

## Deployment Events

| Event | Trigger | Action |
|-------|---------|--------|
| `deployment.started` | CI/CD pipeline begins | Notify team channel |
| `deployment.completed` | Health check passes | Update status page; notify stakeholders |
| `deployment.failed` | Health check fails | Auto-rollback; alert on-call; incident created |
| `deployment.rolled_back` | Manual or automatic rollback | Notify team; create post-mortem ticket |
| `migration.executed` | Database migration runs | Log schema change; verify integrity |

## Infrastructure Events

| Event | Trigger | Action |
|-------|---------|--------|
| `scaling.triggered` | CPU/memory threshold breached | Add/remove instances; notify ops |
| `ssl.expiring` | Certificate within 30 days | Auto-renew attempt; alert if fails |
| `backup.completed` | Scheduled backup finishes | Verify integrity; upload to secondary region |
| `backup.failed` | Backup job fails | Alert on-call; retry; create incident |
| `dns.propagated` | DNS record changed | Verify resolution; notify when global |

## Event Payload

else
    TARGET_ENV="blue"
fi

# Deploy to target environment
./scripts/deploy-to-environment.sh $ENVIRONMENT $TARGET_ENV $VERSION

# Run health checks
log "Running health checks..."
./scripts/health-check.sh $ENVIRONMENT $TARGET_ENV

if [ $? -eq 0 ]; then
    # Switch traffic
    log "Switching traffic to $TARGET_ENV..."
    ./scripts/switch-traffic.sh $ENVIRONMENT $TARGET_ENV
    
    # Verify switch
    log "Verifying traffic switch..."
    ./scripts/verify-switch.sh $ENVIRONMENT
    
    log "Blue-green deployment complete!"

#!/bin/bash
# scripts/backup-database.sh

set -e

ENVIRONMENT=$1
BACKUP_DIR="/var/backups/gsmui/database"
RETENTION_DAYS=30
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/gsmui_${ENVIRONMENT}_${DATE}.sql"

log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $1"
}

# Create backup directory
mkdir -p $BACKUP_DIR

# Dump database
log "Creating database backup..."
mysqldump \
    --user=$DB_USERNAME \
    --password=$DB_PASSWORD \
    --host=$DB_HOST \
    --single-transaction \
    --routines \
    --triggers \
    --events \
    $DB_DATABASE > $BACKUP_FILE

# Compress backup
log "Compressing backup..."
gzip $BACKUP_FILE

# Upload to S3
log "Uploading backup to S3..."
aws s3 cp "${BACKUP_FILE}.gz" "s3://gsmui-backups/database/${ENVIRONMENT}/${DATE}.sql.gz"

# Clean old backups
log "Cleaning old backups..."
find $BACKUP_DIR -name "*.sql.gz" -mtime +$RETENTION_DAYS -delete

log "Backup complete: ${BACKUP_FILE}.gz"

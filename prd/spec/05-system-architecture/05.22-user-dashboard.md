# Architecture Overview

The User Dashboard is a personalized interface that serves as the central hub for authenticated platform users. It aggregates data from multiple domain modules into a cohesive, tabbed experience that adapts to the user's subscription level and activity history.

Built on Laravel Livewire with Alpine.js for client-side interactivity, the dashboard uses a component-based architecture where each section (account, subscription, downloads, activity) is an independent Livewire component mounted within a shared layout. This separation allows lazy loading of individual sections and prevents state conflicts between unrelated data.

The dashboard communicates with backend services through Livewire's internal HTTP transport for UI updates and through standard HTTP requests for file downloads and external links. All data fetching happens server-side to ensure authorization checks are enforced and sensitive data never reaches the browser until explicitly permitted.

The layout uses a sidebar navigation pattern on desktop and a bottom navigation bar on mobile, with the Gsmui component library providing all UI elements including navigation, cards, tables, modals, and form components. The responsive design adapts from a two-column desktop layout to a single-column mobile layout with collapsible sections.

## Key Components

### Profile Management

The profile component uses a tabbed interface for organizing profile sections. The main tab shows basic information (name, email, avatar) with inline editing. The security tab provides password change, two-factor authentication setup, and active session management. The preferences tab handles notification settings, email frequency, and display options.

Avatar uploads use the Gsmui image cropper component with server-side processing for multiple sizes. The system stores original, thumbnail (64px), medium (256px), and large (512px) versions.

### Subscription Management

The subscription component displays the current plan in a prominent card with usage meters for constrained resources. The billing history renders as a filterable table with PDF invoice downloads. Payment method management uses Stripe Elements embedded in a secure iframe for PCI compliance.

Plan changes trigger a confirmation modal showing prorated charges and feature differences. Downgrades are scheduled at period end while upgrades take effect immediately with prorated billing.

### Download Manager

The download manager presents a searchable list of all purchased items with version selection. Each item shows the current version, available updates, and last download date. Download links are time-limited tokens that expire after 1 hour.

Version history allows downloading previous versions with a dropdown selector. License keys are displayed with a copy button and can be revoked and regenerated.

### Activity Timeline

The activity timeline uses infinite scroll with cursor-based pagination. Each activity entry shows an icon, description, timestamp, and optional metadata. The filter sidebar allows narrowing by activity type, date range, and target resource.

# Privacy and Security

## GDPR Compliance

The dashboard includes dedicated GDPR tools accessible from the account section. Users can request a complete data export containing all personal data, activity logs, download history, and subscription records. The export is generated as a ZIP file containing structured JSON and CSV files, delivered via email within 24 hours.

Account deletion initiates a 30-day grace period during which the account is deactivated but data is retained. If the user logs in during this period, they can reactivate. After 30 days, all personal data is permanently deleted with only anonymized analytics retained.

## Data Access Controls

All dashboard data is scoped to the authenticated user through `WHERE user_id = ?` clauses enforced at the repository level. Authorization is verified at multiple layers: Livewire component mounting, service method calls, and database query scopes.

API tokens are scoped to specific permissions and can be revoked at any time. Active sessions display device information, IP address, and last activity time, allowing users to identify and revoke unauthorized access.

## Session Management

Sessions use database-backed stores with encrypted cookies. The session driver is configured to `database` in production for better security and multi-server support. Session data is encrypted at rest and the session ID is rotated on every privilege level change.

# Performance Optimization

## Caching Strategy

Dashboard data uses a multi-layer caching approach:

- **User profile**: Cached for the session duration, invalidated on update
- **Subscription status**: Cached for 5 minutes, invalidated on payment events
- **Download list**: Cached for 10 minutes, invalidated on purchase
- **Activity timeline**: Not cached (real-time requirement)
- **Dashboard metrics**: Cached for 60 seconds with background refresh

## Lazy Loading

Each dashboard section is an independent Livewire component that can be lazy-loaded. The initial page load only renders the sidebar and account section. Other sections load on first visit and remain mounted for the session.

```php
// Lazy loading configuration
class SubscriptionSection extends Component
{
    public function mount(): void
    {
        $this->authorize('view subscription');
        $this->loadData();
    }
}
```

## Database Optimization

Dashboard queries use indexed columns and eager loading to minimize database round trips. The activity timeline uses cursor-based pagination to avoid offset performance degradation on large datasets.

```php
// Cursor-based pagination for activity
ActivityLog::where('user_id', $userId)
    ->orderByDesc('created_at')
    ->cursor();
```

## Frontend Performance

The dashboard uses Livewire's morph algorithm for efficient DOM updates. Alpine.js handles client-side state for interactive elements without full component re-renders. Assets are code-split so the dashboard bundle only includes components actually used on the page.

# Risk

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Dashboard exposes user data through insecure API endpoints | Low | Critical | Every endpoint enforces `WHERE user_id = ?` at repository level. Authorization checked at Livewire mount, service, and query layers. |
| Subscription sync with Stripe fails silently | Medium | High | Webhook monitoring with alerts. Scheduled reconciliation job every 6 hours. Manual sync capability for support staff. |
| Download link abuse (sharing signed URLs) | Medium | Medium | Signed URLs with 1-hour TTL. IP validation on download. Rate-limit downloads per license per hour. |
| GDPR data export produces incomplete data | Low | High | Automated test verifying export completeness against known data schema. Quarterly audit of export content. |
| Profile update race conditions cause data loss | Low | Medium | Optimistic locking on profile updates. Last-write-wins with timestamp validation. User notified of concurrent edit. |
| Mobile dashboard performance degrades with large datasets | Medium | Medium | Cursor-based pagination. Lazy loading of dashboard sections. Image compression for avatar uploads. |
| Session hijacking on shared devices | Medium | High | Session listing with device info. One-click "revoke all sessions" button. Force logout on password change. |
| Activity timeline becomes slow with years of history | Medium | Low | Archive activities older than 1 year to cold storage. Summary view for historical data. Cursor pagination for recent activities. |

```php
class ProfileCard extends Component
{
    public string $name = '';
    public string $email = '';
    public ?string $avatarUrl = null;
    public Carbon $memberSince;
    public ?Carbon $lastLogin = null;
    public bool $isEditing = false;

    // Edit form properties
    public string $editName = '';
    public string $editEmail = '';

    protected function getListeners(): array
    {
        return ['profile.updated' => 'refresh'];
    }

    public function mount(): void
    {
        $user = auth()->user();
        $this->name = $user->name;
        $this->email = $user->email;
        $this->avatarUrl = $user->avatar_url;
        $this->memberSince = $user->created_at;
        $this->lastLogin = $user->last_login_at;
    }

    public function startEditing(): void
    {
        $this->isEditing = true;
        $this->editName = $this->name;
        $this->editEmail = $this->email;
    }

    public function saveProfile(): void
    {
        $this->validate([
            'editName' => 'required|string|max:255',
            'editEmail' => 'required|email|max:255|unique:users,email,' . auth()->id(),
        ]);

        $user = auth()->user();
        $user->update([
            'name' => $this->editName,
            'email' => $this->editEmail,
        ]);

        $this->name = $user->name;
        $this->email = $user->email;
        $this->isEditing = false;

        $this->dispatch('profile.updated');
        session()->flash('success', 'Profile updated successfully');
    }
}
```

**Avatar Upload:**

```php
class AvatarUpload extends Component
{
    public ?string $temporaryUrl = null;
    public bool $showCropper = false;

    public function updatedFile(): void
    {
        $this->validate([
            'file' => 'required|image|max:5120|mimes:jpg,jpeg,png,webp',
        ]);

        $this->temporaryUrl = $this->file->temporaryUrl();
        $this->showCropper = true;
    }

    public function saveAvatar(): void
    {
        $user = auth()->user();

        // Delete old avatar
        if ($user->avatar_path) {
            Storage::disk('public')->delete($user->avatar_path);
        }

        // Process and store new avatar
        $path = $this->file->store('avatars', 'public');

        // Generate sizes
        $this->generateSizes($path);

        $user->update(['avatar_path' => $path]);

        $this->showCropper = false;
        $this->dispatch('avatar.updated');
    }

    private function generateSizes(string $path): void
    {
        $sizes = [
            'thumbnail' => 64,
            'medium' => 256,
            'large' => 512,
        ];

        foreach ($sizes as $size => $dimension) {
            Image::load(Storage::disk('public')->path($path))
                ->fit($dimension)
                ->save(Storage::disk('public')->path("avatars/{$size}/{$path}"));
        }
    }
}
```

```php
class PasswordChange extends Component
{
    public string $currentPassword = '';
    public string $newPassword = '';
    public string $newPasswordConfirmation = '';
    public bool $showCurrentPassword = false;
    public bool $showNewPassword = false;

    public function changePassword(): void
    {
        $this->validate([
            'currentPassword' => 'required',
            'newPassword' => 'required|string|min:8|confirmed',
        ]);

        $user = auth()->user();

        if (!Hash::check($this->currentPassword, $user->password)) {
            $this->addError('currentPassword', 'Current password is incorrect');
            return;
        }

        $user->update([
            'password' => Hash::make($this->newPassword),
        ]);

        // Revoke all other sessions
        $user->sessions()->where('id', '!=', session()->getId())->delete();

        $this->reset(['currentPassword', 'newPassword', 'newPasswordConfirmation']);
        session()->flash('success', 'Password changed successfully. Other sessions have been logged out.');
    }
}
```

**Two-Factor Authentication:**

```php
class TwoFactorSetup extends Component
{
    public bool $enabled = false;
    public ?string $qrCode = null;
    public ?string $recoveryCodes = null;
    public string $verificationCode = '';
    public string $password = '';

    public function mount(): void
    {
        $this->enabled = auth()->user()->two_factor_secret !== null;
    }

    public function enableTwoFactor(): void
    {
        $this->validate([
            'password' => 'required',
            'verificationCode' => 'required|string|size:6',
        ]);

        $user = auth()->user();

        if (!Hash::check($this->password, $user->password)) {
            $this->addError('password', 'Password is incorrect');
            return;
        }

        $secret = $this->generateSecret();
        $qrCode = $this->generateQRCode($secret);

        // Verify the code
        $google2fa = app(Google2FA::class);
        if (!$google2fa->verifyKey($secret, $this->verificationCode)) {
            $this->addError('verificationCode', 'Invalid verification code');
            return;
        }

        // Generate recovery codes
        $recoveryCodes = $this->generateRecoveryCodes();

        $user->update([
            'two_factor_secret' => encrypt($secret),
            'two_factor_recovery_codes' => encrypt(json_encode($recoveryCodes)),
        ]);

        $this->enabled = true;
        $this->recoveryCodes = json_encode($recoveryCodes);
        $this->qrCode = null;
    }

    public function disableTwoFactor(): void
    {
        $this->validate([
            'password' => 'required',
        ]);

        $user = auth()->user();

        if (!Hash::check($this->password, $user->password)) {
            $this->addError('password', 'Password is incorrect');
            return;
        }

        $user->update([
            'two_factor_secret' => null,
            'two_factor_recovery_codes' => null,
        ]);

        $this->enabled = false;
        session()->flash('success', 'Two-factor authentication has been disabled');
    }

    private function generateSecret(): string
    {
        return app(Google2FA::class)->generateSecretKey();
    }

    private function generateQRCode(string $secret): string
    {
        $google2fa = app(Google2FA::class);
        $url = $google2fa->getQRCodeUrl(
            config('app.name'),
            auth()->user()->email,
            $secret
        );
        return $google2fa->getQRCodeInline($url);
    }

    private function generateRecoveryCodes(): array
    {
        $codes = [];
        for ($i = 0; $i < 10; $i++) {
            $codes[] = strtoupper(bin2hex(random_bytes(5)));
        }
        return $codes;
    }
}
```

**Session Management:**

```php
class SessionManager extends Component
{
    public Collection $sessions;
    public string $currentSessionId;

    public function mount(): void
    {
        $this->currentSessionId = session()->getId();
        $this->sessions = auth()->user()->sessions()
            ->orderBy('last_activity', 'desc')
            ->get();
    }

    public function revokeSession(string $sessionId): void
    {
        if ($sessionId === $this->currentSessionId) {
            session()->flash('error', 'Cannot revoke current session');
            return;
        }

        auth()->user()->sessions()
            ->where('id', $sessionId)
            ->delete();

        $this->sessions = auth()->user()->sessions()
            ->orderBy('last_activity', 'desc')
            ->get();

        session()->flash('success', 'Session revoked successfully');
    }

    public function revokeAllSessions(): void
    {
        auth()->user()->sessions()
            ->where('id', '!=', $this->currentSessionId)
            ->delete();

        $this->sessions = auth()->user()->sessions()
            ->orderBy('last_activity', 'desc')
            ->get();

        session()->flash('success', 'All other sessions revoked');
    }
}
```

```php
class ApiTokenManager extends Component
{
    public Collection $tokens;
    public string $newTokenName = '';
    public ?string $newTokenValue = null;
    public array $availablePermissions = [
        'downloads' => 'Download components',
        'licenses' => 'Manage licenses',
        'profile' => 'View profile',
        'playground' => 'Access playground',
    ];
    public array $selectedPermissions = [];

    public function mount(): void
    {
        $this->tokens = auth()->user()->tokens()
            ->orderBy('created_at', 'desc')
            ->get();
    }

    public function createToken(): void
    {
        $this->validate([
            'newTokenName' => 'required|string|max:255',
            'selectedPermissions' => 'required|array|min:1',
        ]);

        $token = auth()->user()->createToken(
            $this->newTokenName,
            $this->selectedPermissions
        );

        $this->newTokenValue = $token->plainTextToken;
        $this->tokens = auth()->user()->tokens()
            ->orderBy('created_at', 'desc')
            ->get();

        $this->reset(['newTokenName', 'selectedPermissions']);
    }

    public function revokeToken(string $tokenId): void
    {
        auth()->user()->tokens()
            ->where('id', $tokenId)
            ->delete();

        $this->tokens = auth()->user()->tokens()
            ->orderBy('created_at', 'desc')
            ->get();

        session()->flash('success', 'Token revoked successfully');
    }
}
```

```php
class DownloadManager extends Component
{
    public Collection $downloads;
    public string $search = '';
    public string $sortBy = 'recent';
    public ?string $selectedProduct = null;

    public function mount(): void
    {
        $this->loadDownloads();
    }

    public function loadDownloads(): void
    {
        $query = auth()->user()->purchases()
            ->with(['product', 'latestVersion', 'license'])
            ->where('status', 'active');

        if ($this->search) {
            $query->whereHas('product', function ($q) {
                $q->where('name', 'like', "%{$this->search}%");
            });
        }

        $this->downloads = match ($this->sortBy) {
            'name' => $query->orderBy('name')->get(),
            'recent' => $query->orderBy('pivot_created_at', 'desc')->get(),
            'most_downloaded' => $query->withCount('downloads')
                ->orderByDesc('downloads_count')
                ->get(),
            default => $query->get(),
        };
    }

    public function download(string $productId, ?string $versionId = null): void
    {
        $purchase = auth()->user()->purchases()
            ->where('product_id', $productId)
            ->firstOrFail();

        // Verify license
        if (!$purchase->license || $purchase->license->status !== 'active') {
            session()->flash('error', 'No active license for this product');
            return;
        }

        // Generate download URL
        $version = $versionId
            ? $purchase->product->versions()->findOrFail($versionId)
            : $purchase->product->latestVersion;

        $downloadUrl = $this->generateDownloadUrl($purchase, $version);

        // Log download
        Download::create([
            'user_id' => auth()->id(),
            'product_id' => $productId,
            'version_id' => $version->id,
            'license_id' => $purchase->license->id,
            'ip_address' => request()->ip(),
        ]);

        return response()->json(['url' => $downloadUrl]);
    }

    private function generateDownloadUrl(Purchase $purchase, Version $version): string
    {
        $token = SignedDownloadToken::create([
            'user_id' => auth()->id(),
            'product_id' => $purchase->product_id,
            'version_id' => $version->id,
            'expires_at' => now()->addHour(),
        ]);

        return URL::temporarySignedRoute(
            'downloads.file',
            now()->addHour(),
            [
                'token' => $token->token,
                'product' => $purchase->product->slug,
                'version' => $version->version,
            ]
        );
    }
}
```

```php
class ActivityTimeline extends Component
{
    public Collection $activities;
    public string $filterType = 'all';
    public ?string $filterDateFrom = null;
    public ?string $filterDateTo = null;
    public bool $hasMore = true;
    public int $perPage = 20;

    protected $listeners = ['loadMore' => 'loadMore'];

    public function mount(): void
    {
        $this->loadActivities();
    }

    public function loadActivities(): void
    {
        $query = auth()->user()->activities()
            ->orderBy('created_at', 'desc');

        if ($this->filterType !== 'all') {
            $query->where('type', $this->filterType);
        }

        if ($this->filterDateFrom) {
            $query->where('created_at', '>=', $this->filterDateFrom);
        }

        if ($this->filterDateTo) {
            $query->where('created_at', '<=', $this->filterDateTo);
        }

        $this->activities = $query->take($this->perPage)->get();
        $this->hasMore = $query->count() > $this->perPage;
    }

    public function loadMore(): void
    {
        $lastActivity = $this->activities->last();
        if (!$lastActivity) return;

        $query = auth()->user()->activities()
            ->where('created_at', '<', $lastActivity->created_at)
            ->orderBy('created_at', 'desc');

        if ($this->filterType !== 'all') {
            $query->where('type', $this->filterType);
        }

        $moreActivities = $query->take($this->perPage)->get();

        $this->activities = $this->activities->merge($moreActivities);
        $this->hasMore = $moreActivities->count() === $this->perPage;
    }

    public function exportActivities(): void
    {
        $activities = auth()->user()->activities()
            ->orderBy('created_at', 'desc')
            ->get();

        $csv = $this->generateCsv($activities);

        return response()->streamDownload(function () use ($csv) {
            echo $csv;
        }, 'activity-' . now()->format('Y-m-d') . '.csv');
    }

    private function generateCsv(Collection $activities): string
    {
        $headers = ['Date', 'Type', 'Description', 'IP Address', 'Device'];
        $rows = $activities->map(fn ($a) => [
            $a->created_at->format('Y-m-d H:i:s'),
            $a->type,
            $a->description,
            $a->ip_address,
            $a->user_agent,
        ]);

        $callback = function () use ($headers, $rows) {
            $file = fopen('php://output', 'w');
            fputcsv($file, $headers);
            foreach ($rows as $row) {
                fputcsv($file, $row);
            }
            fclose($file);
        };

        return $callback();
    }
}
```

```php
class UserCache
{
    public function __construct(
        private Redis $redis,
    ) {}

    public function getProfile(int $userId): ?array
    {
        $key = "user:{$userId}:profile";
        $cached = $this->redis->get($key);

        if ($cached) {
            return json_decode($cached, true);
        }

        $profile = User::find($userId)?->toArray();
        if ($profile) {
            $this->redis->setex($key, 3600, json_encode($profile));
        }

        return $profile;
    }

    public function invalidateProfile(int $userId): void
    {
        $this->redis->del("user:{$userId}:profile");
    }

    public function getSubscription(int $userId): ?array
    {
        $key = "user:{$userId}:subscription";
        $cached = $this->redis->get($key);

        if ($cached) {
            return json_decode($cached, true);
        }

        $subscription = User::find($userId)?->activeSubscription?->toArray();
        if ($subscription) {
            $this->redis->setex($key, 300, json_encode($subscription));
        }

        return $subscription;
    }

    public function invalidateSubscription(int $userId): void
    {
        $this->redis->del("user:{$userId}:subscription");
    }
}
```

```php
class Handler extends ExceptionHandler
{
    public function register(): void
    {
        $this->renderable(function (NotFoundHttpException $e, $request) {
            if ($request->expectsJson()) {
                return response()->json([
                    'success' => false,
                    'error' => [

                        'message' => 'The requested resource was not found.',

                ], 404);
```

## Dashboard Middleware

```php
// app/Http/Middleware/DashboardMiddleware.php
class DashboardMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        // Check if user is authenticated
        if (!auth()->check()) {
            return redirect()->route('login');
        }

        // Check if email is verified
        if (!auth()->user()->hasVerifiedEmail()) {
            return redirect()->route('verification.notice');
        }

        // Check if account is active
        if (auth()->user()->status !== 'active') {
            auth()->logout();
            return redirect()->route('login')->withErrors([
                'email' => 'Your account has been suspended.',
            ]);
        }

        // Set dashboard timezone
        if (auth()->user()->timezone) {
            config(['app.timezone' => auth()->user()->timezone]);
            date_default_timezone_set(auth()->user()->timezone);
        }

        return $next($request);
    }
}
```

```php
// app/Services/DashboardAnalytics.php
class DashboardAnalytics
{
    public function track(string $event, array $data = []): void
    {
        ActivityLog::create([
            'user_id' => auth()->id(),
            'event' => $event,
            'data' => $data,
            'ip_address' => request()->ip(),
            'user_agent' => request()->userAgent(),
        ]);
    }

    public function getStats(string $period = '30d'): array
    {
        $user = auth()->user();
        $startDate = now()->sub($period);

        return [
            'logins' => $user->loginHistory()
                ->where('created_at', '>=', $startDate)
                ->count(),
            'downloads' => $user->downloads()
                ->where('created_at', '>=', $startDate)
                ->count(),
            'profile_updates' => ActivityLog::where('user_id', $user->id)
                ->where('event', 'profile.updated')
                ->where('created_at', '>=', $startDate)
                ->count(),
            'api_usage' => $user->apiCalls()
                ->where('created_at', '>=', $startDate)
                ->count(),
        ];
    }
}
```

```php
// app/Http/Middleware/PerformanceMonitoring.php
class PerformanceMonitoring
{
    public function handle(Request $request, Closure $next): Response
    {
        $start = microtime(true);

        $response = $next($request);

        $duration = (microtime(true) - $start) * 1000;

        // Log to performance monitoring
        PerformanceLog::create([
            'user_id' => auth()->id(),
            'path' => $request->path(),
            'method' => $request->method(),
            'duration_ms' => $duration,
            'status_code' => $response->getStatusCode(),
            'memory_usage' => memory_get_peak_usage(true),
        ]);

        // Alert if slow
        if ($duration > 1000) {
            Log::warning('Slow dashboard request', [
                'path' => $request->path(),
                'duration' => $duration,
                'user_id' => auth()->id(),
            ]);
        }

        return $response;
    }
}
```

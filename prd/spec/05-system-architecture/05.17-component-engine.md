# 05.17 - Component Engine Architecture

**Project:** GsmUi
**Architecture:** Design System + Component Engine
**Framework:** Laravel 13 + Livewire 4 + Blade + Tailwind CSS v4

# Purpose

The Component Engine is the foundation of GsmUi. Every UI element—from a simple button to a complete dashboard layout—is built on a consistent architecture that supports theming, accessibility, documentation, playground integration, and package distribution.

The engine powers:

* Blade Components
* Livewire Components
* Admin UI
* Documentation Examples
* Templates
* Playground
* Theme Engine
* Future SDKs

---

# Objectives

The Component Engine should:

* Provide a consistent API
* Support composability
* Be fully theme-aware
* Support slots and variants
* Be accessible (WCAG AA)
* Minimize JavaScript
* Be tree-shakable
* Be package-friendly
* Generate documentation metadata
* Enable live playground previews

# Risk

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Component API churn frustrates early adopters | High | High | Semver strictly enforced. Deprecation warnings 2 versions before removal. Migration guides for every breaking change. |
| Accessibility gaps discovered post-launch | Medium | High | Mandatory WCAG AA audit before each major release. Automated axe-core checks in CI. Community bug bounty for a11y issues. |
| Variant explosion creates maintenance burden | Medium | Medium | Cap initial variants at 9 per component. Use token-driven variants to reduce per-component CSS. Deprecate unused variants quarterly. |
| Blade rendering performance degrades with complex components | Medium | Medium | Profile every component render. Lazy-load Alpine.js for interactive components. Cache static renders. |
| Third-party packages register conflicting component names | Low | High | Namespace enforcement (`x-gsmui-*`). Prefix validation in registry. Collision detection on registration. |
| Livewire version upgrades break component hydration | Medium | High | Abstract Livewire integration behind a compatibility layer. Pin Livewire version per GsmUi release. |
| Large component library becomes hard to navigate | Medium | Low | Auto-generated documentation from metadata. Search integration. Category-based organization in docs and playground. |
| Cross-framework export (React, Vue) scope creeps | High | Medium | Defer cross-framework to Phase 2. Focus 100% on Blade/Livewire first. React/Vue export is a separate project. |

## Component Registration System

### Registry Architecture

The component registry is a central service that manages component discovery, metadata, and versioning.

```text id="creg01"
ComponentRegistry
   |
   +-- Discovery (scan packages)
   +-- Metadata (props, slots, events)
   +-- Versioning (semver tracking)
   +-- Documentation (auto-gen)
   +-- Playground (live preview)
```

### Registration Flow

```text id="creg02"
Package Loaded
   |
   v
Scan Component Classes
   |
   v
Extract Metadata (attributes)
   |
   v
Validate Schema
   |
   v
Register in Registry
   |
   v
Index for Search
   |
   v
Generate Documentation
```

### Registry Implementation

```php id="creg03"
class ComponentRegistry
{
    private array $components = [];

    public function register(array $config): void
    {
        $this->validate($config);
        $this->components[$config['name']] = [
            'name' => $config['name'],
            'class' => $config['class'],
            'category' => $config['category'],
            'version' => $config['version'],
            'props' => $config['props'] ?? [],
            'slots' => $config['slots'] ?? [],
            'events' => $config['events'] ?? [],
        ];
    }

    public function get(string $name): ?array
    {
        return $this->components[$name] ?? null;
    }

    public function getByCategory(string $category): array
    {
        return array_filter(
            $this->components,
            fn($c) => $c['category'] === $category
        );
    }
}
```

### Props Resolution

```php id="cpipeline02"
class PropsResolver
{
    public function resolve(Component $component, array $attributes): array
    {
        $props = [];
        foreach ($component->props() as $name => $definition) {
            if (isset($attributes[$name])) {
                $props[$name] = $this->cast($attributes[$name], $definition['type']);
            } elseif (isset($definition['default'])) {
                $props[$name] = $definition['default'];
            } elseif ($definition['required'] ?? false) {
                throw new MissingPropException($name);
            }
        }
        return $props;
    }
}
```

### Variant Resolution

```php id="cpipeline03"
class VariantResolver
{
    public function resolve(Component $component, string $variant): array
    {
        $variants = $component->variants();
        if (!isset($variants[$variant])) {
            throw new InvalidVariantException($variant);
        }
        return $variants[$variant];
    }
}
```

### Props Casting

```php id="cpipeline05"
class PropsCaster
{
    public function cast(mixed $value, string $type): mixed
    {
        return match ($type) {
            'string' => (string) $value,
            'int' => (int) $value,
            'float' => (float) $value,
            'bool' => filter_var($value, FILTER_VALIDATE_BOOLEAN),
            'array' => is_array($value) ? $value : [$value],
            'object' => is_object($value) ? $value : (object) $value,
            default => $value,
        };
    }
}
```

### Props Validation

```php id="cpipeline06"
class PropsValidator
{
    public function validate(array $props, array $schema): array
    {
        $errors = [];

        foreach ($schema as $name => $definition) {
            if ($definition['required'] ?? false) {
                if (!array_key_exists($name, $props)) {
                    $errors[$name] = "Prop '{$name}' is required.";
                }
            }

            if (isset($props[$name]) && isset($definition['options'])) {
                if (!in_array($props[$name], $definition['options'])) {
                    $errors[$name] = "Invalid value for '{$name}'.";
                }
            }
        }

        if (!empty($errors)) {
            throw new PropsValidationException($errors);
        }

        return $props;
    }
}
```

### Variant Composition

Variants can be composed from multiple sources.

```php id="cvar03"
class Button extends Component
{
    public function variantClasses(): string
    {
        $base = 'inline-flex items-center justify-center font-medium rounded-lg transition-colors';
        $variant = $this->getVariantClasses();
        $size = $this->getSizeClasses();
        $state = $this->getStateClasses();

        return collect([$base, $variant, $size, $state])->implode(' ');
    }

    private function getVariantClasses(): string
    {
        return match ($this->variant) {
            'primary' => 'bg-primary-500 text-white hover:bg-primary-600 focus:ring-primary-500',
            'secondary' => 'bg-secondary-500 text-white hover:bg-secondary-600 focus:ring-secondary-500',
            'danger' => 'bg-error-500 text-white hover:bg-error-600 focus:ring-error-500',
            'ghost' => 'bg-transparent text-gray-700 hover:bg-gray-100 focus:ring-gray-500',
            'outline' => 'border-2 border-primary-500 text-primary-500 hover:bg-primary-50 focus:ring-primary-500',
            default => 'bg-primary-500 text-white hover:bg-primary-600 focus:ring-primary-500',
        };
    }

    private function getSizeClasses(): string
    {
        return match ($this->size) {
            'xs' => 'px-2 py-1 text-xs gap-1',
            'sm' => 'px-3 py-1.5 text-sm gap-1.5',
            'md' => 'px-4 py-2 text-base gap-2',
            'lg' => 'px-5 py-2.5 text-lg gap-2',
            'xl' => 'px-6 py-3 text-xl gap-2.5',
            default => 'px-4 py-2 text-base gap-2',
        };
    }

    private function getStateClasses(): string
    {
        $classes = [];

        if ($this->disabled) {
            $classes[] = 'opacity-50 cursor-not-allowed';
        }

        if ($this->loading) {
            $classes[] = 'relative';
        }

        return implode(' ', $classes);
    }
}
```

### Focus Management

```php id="cfocus01"
class FocusManager
{
    public function trapFocus(Element $element): void
    {
        $focusable = $element->querySelectorAll(
            'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
        );

        $first = $focusable->first();
        $last = $focusable->last();

        $element->addEventListener('keydown', function ($event) use ($first, $last) {
            if ($event->key === 'Tab') {
                if ($event->shiftKey && document->activeElement === $first) {
                    $event->preventDefault();
                    $last->focus();
                } elseif (!$event->shiftKey && document->activeElement === $last) {
                    $event->preventDefault();
                    $first->focus();
                }
            }
        });
    }
}
```

```php id="csec03"
class ComponentSecurity
{
    public function escapeHtml(string $content): string
    {
        return htmlspecialchars($content, ENT_QUOTES, 'UTF-8');
    }

    public function sanitizeAttribute(string $value): string
    {
        return preg_replace('/[^a-zA-Z0-9\-_]/', '', $value);
    }

    public function validateUrl(string $url): bool
    {
        $parsed = parse_url($url);

        return in_array($parsed['scheme'] ?? '', ['http', 'https', 'mailto', 'tel']);
    }

    public function sanitizeSlot(mixed $slot): string
    {
        if (is_string($slot)) {
            return $this->escapeHtml($slot);
        }

        return '';
    }
}
```

# Conclusion

Theme Library is the central hub for managing purchased, created, and applied themes in GsmUi. It provides live preview, one-click application, and theme customization — transforming the look and feel of a user's projects. This page must balance visual richness (theme previews are inherently visual) with performance (theme metadata can be large). The theme application flow must be reliable and reversible.

# Risk

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Theme CSS conflicts with app styles | High | High | iframe sandbox for preview, scoped CSS on apply |
| Custom theme upload abuse | Medium | Medium | File validation, size limits (500KB), MIME check |
| Theme preview rendering differences | Medium | Medium | Standardized preview page, cross-browser testing |
| Theme version incompatibility | Low | High | Semantic versioning, compatibility matrix |
| Large theme files slow preview | Medium | Medium | Lazy-load theme CSS, progressive rendering |
| Apply theme fails mid-process | Low | High | Transactional apply with rollback |

# Security

| Concern | Implementation |
|---------|---------------|
| Theme ownership | All themes scoped to user_id, marketplace themes to creator_id |
| Custom CSS sanitization | Parse and validate CSS, block url(), expression(), @import |
| Upload file validation | Whitelist .css files only, max 500KB, virus scan |
| Theme application auth | Only project owner can apply themes |
| Marketplace payments | Stripe-verified purchases before theme access |
| Content policy | No prohibited content in custom themes (moderation queue) |

# Performance

| Metric | Target | Strategy |
|--------|--------|----------|
| Theme list load | < 400ms | Paginated grid, lazy-loaded thumbnails |
| Preview render | < 500ms | iframe with cached theme CSS |
| Theme application | < 2s | CSS variable swap, no page reload |
| Custom theme upload | < 3s | Direct S3 upload, background processing |
| Theme comparison | < 1s | Two iframes, shared CSS cache |
| Search themes | < 200ms | Full-text index on name + tags |

**Caching:**
- Theme metadata: 10-minute cache, invalidated on update
- Theme CSS: CDN-cached per theme version
- Preview screenshots: Generated on upload, cached indefinitely
- Applied theme: Stored in project config, instant load

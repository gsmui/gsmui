# 05.08 - Repository Layer Architecture

**Project:** GsmUi
**Architecture:** Repository Pattern + Domain-Driven Design
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

The Repository Layer abstracts data access from the Service Layer. Repositories are responsible for querying, persisting, and deleting domain entities while hiding Eloquent implementation details.

Repositories **do not contain business rules**. Their sole responsibility is persistence.

---

# Goals

* Isolate persistence logic
* Simplify testing
* Centralize database queries
* Improve maintainability
* Support caching strategies
* Allow future persistence changes
* Keep services database-agnostic

---

# Layer Position

```text
Presentation
      │
Application Services
      │
Repositories
      │
Eloquent Models
      │
```

# Repository Responsibilities

Repositories may:

* Query records
* Persist entities
* Delete entities
* Paginate
* Filter
* Search
* Perform eager loading
* Manage transactions delegated by services
* Apply query scopes

Repositories must **not**:

* Apply business rules
* Send emails
* Dispatch events
* Perform authorization
* Read HTTP requests
* Render responses

# Base Repository

A shared abstract repository provides common functionality.

Responsibilities:

* find()
* findOrFail()
* create()
* update()
* delete()
* paginate()
* exists()
* count()

Example:

```php
abstract class BaseRepository
{
    abstract protected function model(): Model;
}
```

Domain repositories extend this base.

---

# Repository Interfaces

Every repository exposes a contract.

Example:

```php
interface ComponentRepositoryInterface
{
    public function find(int $id): ?Component;

    public function create(array $data): Component;

    public function update(Component $component, array $data): Component;

    public function delete(Component $component): void;

    public function paginate(int $perPage = 15);
}
```

Services depend on interfaces rather than implementations.

---

# Eloquent Implementations

Example:

```php
class ComponentRepository implements ComponentRepositoryInterface

        protected Component $model

    public function find(int $id): ?Component

        return $this->model
            ->with('versions')
            ->find($id);

}
```

# Read vs Write

Repositories separate reading from writing conceptually.

Read:

* find
* search
* paginate
* exists

Write:

* create
* update
* delete
* restore

Business decisions remain in services.

# Eager Loading

Repositories own eager loading decisions.

Example:

```php
return $this->model
    ->with([
        'versions',
        'examples',
        'category',
    ])
    ->find($id);
```

Prevent N+1 queries by default.

Repositories never open transactions independently.

Transactions belong in Application Services.

Example:

```php

});
```

# Dependency Injection

Bind interfaces in a service provider.


# Error Handling

Repositories throw infrastructure exceptions only.

Examples:

* RecordNotFoundException
* DatabaseConnectionException
* QueryTimeoutException

Business exceptions remain in the Service Layer.

---

# Testing Strategy

Repository tests verify:

* CRUD behavior
* Relationships
* Pagination
* Filtering
* Query performance
* Soft deletes

Use an isolated test database.

# Performance Guidelines

* Prefer eager loading
* Select only required columns
* Index searchable fields
* Avoid N+1 queries
* Use chunking for large datasets
* Use cursor pagination where appropriate

# Anti-Patterns

Avoid:

* Business logic in repositories
* Calling repositories from Livewire components
* Cross-domain repository access
* Returning HTTP responses
* Sending notifications
* Dispatching events
* Reading session or request data

Repositories are persistence adapters, nothing more.

---

# Future Evolution

As domains are extracted into packages or services, repository interfaces remain stable while implementations may change (e.g., from Eloquent to external APIs or dedicated data services). This preserves the Service Layer and application workflows.

# Repository Implementation Patterns

## Base Repository Implementation

```php
// app/Shared/Repositories/BaseRepository.php

declare(strict_types=1);

namespace App\Shared\Repositories;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Pagination\LengthAwarePaginator;
use Illuminate\Support\Collection;

abstract class BaseRepository
{
    protected Model $model;

    abstract protected function model(): Model;

    public function __construct()
    {
        $this->model = $this->model();
    }

    public function find(int $id): ?Model
    {
        return $this->model->find($id);
    }

    public function findOrFail(int $id): Model
    {
        return $this->model->findOrFail($id);
    }

    public function findBySlug(string $slug): ?Model
    {
        return $this->model->where('slug', $slug)->first();
    }

    public function all(): Collection
    {
        return $this->model->all();
    }

    public function create(array $data): Model
    {
        return $this->model->create($data);
    }

    public function update(Model $model, array $data): Model
    {
        $model->update($data);
        return $model->fresh();
    }

    public function delete(Model $model): bool
    {
        return $model->delete();
    }

    public function paginate(int $perPage = 15, array $filters = []): LengthAwarePaginator
    {
        $query = $this->buildFilterQuery($filters);

        return $query->paginate($perPage);
    }

    public function existsBySlug(string $slug, int $exceptId = 0): bool
    {
        return $this->model
            ->where('slug', $slug)
            ->where('id', '!=', $exceptId)
            ->exists();
    }

    public function count(array $filters = []): int
    {
        return $this->buildFilterQuery($filters)->count();
    }

    protected function buildFilterQuery(array $filters): Builder
    {
        $query = $this->model->query();

        foreach ($filters as $key => $value) {
            if ($value !== null && $value !== '') {
                $query->where($key, $value);
            }
        }

        return $query;
    }
}
```

## Component Repository Implementation

```php
// app/Domains/Components/Repositories/Eloquent/ComponentRepository.php

declare(strict_types=1);

namespace App\Domains\Components\Repositories\Eloquent;

use App\Domains\Components\Contracts\ComponentRepositoryInterface;
use App\Domains\Components\Models\{Component, ComponentVersion};
use App\Shared\Repositories\BaseRepository;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Pagination\LengthAwarePaginator;
use Illuminate\Support\Collection;

final class ComponentRepository extends BaseRepository implements ComponentRepositoryInterface
{
    protected function model(): Component
    {
        return new Component();
    }

    public function findWithVersions(int $id): ?Component
    {
        return $this->model
            ->with(['versions' => fn($q) => $q->latest()])
            ->find($id);
    }

    public function findWithRelations(int $id): ?Component
    {
        return $this->model
            ->with([
                'author:id,name,avatar_url',
                'category:id,name,slug',
                'versions' => fn($q) => $q->latest(),
                'tags:id,name,slug',
                'examples' => fn($q) => $q->limit(5),
            ])
            ->find($id);
    }

    public function findBySlugWithRelations(string $slug): ?Component
    {
        return $this->model
            ->with([
                'author:id,name,avatar_url',
                'category:id,name,slug',
                'versions' => fn($q) => $q->latest(),
                'tags:id,name,slug',
            ])
            ->where('slug', $slug)
            ->first();
    }

    public function paginate(int $perPage = 15, array $filters = []): LengthAwarePaginator
    {
        $query = $this->buildFilterQuery($filters);

        return $query
            ->with([
                'author:id,name,avatar_url',
                'category:id,name,slug',
                'latestVersion:id,version',
            ])
            ->orderByDesc('created_at')
            ->paginate($perPage);
    }

    public function search(string $query, array $filters = []): Collection
    {
        return $this->model
            ->where(function ($q) use ($query) {
                $q->where('name', 'LIKE', "%{$query}%")
                  ->orWhere('description', 'LIKE', "%{$query}%")
                  ->orWhere('slug', 'LIKE', "%{$query}%");
            })
            ->when($filters['category'] ?? null, fn($q, $category) =>
                $q->where('category_id', $category)
            )
            ->when($filters['is_premium'] ?? null, fn($q, $isPremium) =>
                $q->where('is_premium', $isPremium)
            )
            ->with(['author:id,name', 'category:id,name'])
            ->get();
    }

    public function getPopular(int $limit = 10): Collection
    {
        return $this->model
            ->where('status', 'published')
            ->with(['author:id,name', 'category:id,name'])
            ->orderByDesc('download_count')
            ->limit($limit)
            ->get();
    }

    public function getRecent(int $limit = 10): Collection
    {
        return $this->model
            ->where('status', 'published')
            ->with(['author:id,name', 'category:id,name'])
            ->orderByDesc('created_at')
            ->limit($limit)
            ->get();
    }

    public function getFeatured(int $limit = 10): Collection
    {
        return $this->model
            ->where('status', 'published')
            ->where('is_featured', true)
            ->with(['author:id,name', 'category:id,name'])
            ->orderByDesc('featured_at')
            ->limit($limit)
            ->get();
    }

    public function getPublished(): Collection
    {
        return $this->model
            ->where('status', 'published')
            ->with(['author:id,name', 'category:id,name'])
            ->get();
    }

    public function countByCategory(): Collection
    {
        return $this->model
            ->select('category_id', \DB::raw('count(*) as total'))
            ->where('status', 'published')
            ->groupBy('category_id')
            ->with('category:id,name')
            ->get();
    }

    protected function buildFilterQuery(array $filters): Builder
    {
        $query = $this->model->query();

        if (isset($filters['status'])) {
            $query->where('status', $filters['status']);
        }

        if (isset($filters['category_id'])) {
            $query->where('category_id', $filters['category_id']);
        }

        if (isset($filters['author_id'])) {
            $query->where('author_id', $filters['author_id']);
        }

        if (isset($filters['is_premium'])) {
            $query->where('is_premium', $filters['is_premium']);
        }

        if (isset($filters['search'])) {
            $query->where(function ($q) use ($filters) {
                $q->where('name', 'LIKE', "%{$filters['search']}%")
                  ->orWhere('description', 'LIKE', "%{$filters['search']}%");
            });
        }

        return $query;
    }
}
```

```php
// app/Domains/Users/Repositories/Eloquent/UserRepository.php

declare(strict_types=1);

namespace App\Domains\Users\Repositories\Eloquent;

use App\Domains\Users\Contracts\UserRepositoryInterface;
use App\Domains\Users\Models\User;
use App\Shared\Repositories\BaseRepository;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Pagination\LengthAwarePaginator;
use Illuminate\Support\Collection;

final class UserRepository extends BaseRepository implements UserRepositoryInterface
{
    protected function model(): User
    {
        return new User();
    }

    public function findByEmail(string $email): ?User
    {
        return $this->model
            ->where('email', $email)
            ->first();
    }

    public function findWithProfile(int $id): ?User
    {
        return $this->model
            ->with(['profile', 'teams'])
            ->find($id);
    }

    public function findWithSubscription(int $id): ?User
    {
        return $this->model
            ->with(['subscriptions' => fn($q) => $q->active()])
            ->find($id);
    }

    public function paginate(int $perPage = 15, array $filters = []): LengthAwarePaginator
    {
        $query = $this->buildFilterQuery($filters);

        return $query
            ->with(['profile'])
            ->orderByDesc('created_at')
            ->paginate($perPage);
    }

    public function getProSubscribers(): Collection
    {
        return $this->model
            ->whereHas('subscriptions', fn($q) =>
                $q->where('status', 'active')
                  ->where('plan_id', '!=', null)
            )
            ->with(['profile', 'subscriptions'])
            ->get();
    }

    public function getActiveUsers(int $days = 30): Collection
    {
        return $this->model
            ->where('last_login_at', '>=', now()->subDays($days))
            ->with(['profile'])
            ->get();
    }

    public function search(string $query): Collection
    {
        return $this->model
            ->where(function ($q) use ($query) {
                $q->where('name', 'LIKE', "%{$query}%")
                  ->orWhere('email', 'LIKE', "%{$query}%");
            })
            ->with(['profile'])
            ->get();
    }

    protected function buildFilterQuery(array $filters): Builder
    {
        $query = $this->model->query();

        if (isset($filters['status'])) {
            $query->where('status', $filters['status']);
        }

        if (isset($filters['is_pro'])) {
            if ($filters['is_pro']) {
                $query->whereHas('subscriptions', fn($q) =>
                    $q->where('status', 'active')
                );
            } else {
                $query->whereDoesntHave('subscriptions', fn($q) =>
                    $q->where('status', 'active')
                );
            }
        }

        if (isset($filters['search'])) {
            $query->where(function ($q) use ($filters) {
                $q->where('name', 'LIKE', "%{$filters['search']}%")
                  ->orWhere('email', 'LIKE', "%{$filters['search']}%");
            });
        }

        return $query;
    }
}
```

# Repository Testing Patterns

## In-Memory Repository

```php
// tests/Support/InMemoryComponentRepository.php

declare(strict_types=1);

namespace Tests\Support;

use App\Domains\Components\Contracts\ComponentRepositoryInterface;
use App\Domains\Components\Models\Component;
use Illuminate\Support\Collection;
use Illuminate\Pagination\LengthAwarePaginator;

class InMemoryComponentRepository implements ComponentRepositoryInterface
{
    private array $components = [];
    private int $nextId = 1;

    public function find(int $id): ?Component
    {
        return $this->components[$id] ?? null;
    }

    public function findOrFail(int $id): Component
    {
        $component = $this->find($id);

        if (!$component) {
            throw new \App\Domains\Components\Exceptions\ComponentNotFoundException(
                "Component with ID {$id} not found"
            );
        }

        return $component;
    }

    public function create(array $data): Component
    {
        $component = new Component($data);
        $component->id = $this->nextId++;

        $this->components[$component->id] = $component;

        return $component;
    }

    public function update(Component $component, array $data): Component
    {
        foreach ($data as $key => $value) {
            $component->{$key} = $value;
        }

        $this->components[$component->id] = $component;

        return $component;
    }

    public function delete(Component $component): bool
    {
        unset($this->components[$component->id]);

        return true;
    }

    public function existsBySlug(string $slug, int $exceptId = 0): bool
    {
        foreach ($this->components as $component) {
            if ($component->slug === $slug && $component->id !== $exceptId) {
                return true;
            }
        }

        return false;
    }

    public function all(): Collection
    {
        return collect($this->components);
    }

    public function paginate(int $perPage = 15, array $filters = []): LengthAwarePaginator
    {
        $items = collect($this->components)->filter(function ($component) use ($filters) {
            foreach ($filters as $key => $value) {
                if ($value !== null && $component->{$key} !== $value) {
                    return false;
                }
            }
            return true;
        });

        return new LengthAwarePaginator(
            $items->slice(0, $perPage),
            $items->count(),
            $perPage,
            1
        );
    }
}
```

## Repository Event Integration

### Repository Events

```php
// Repository event integration

abstract class BaseRepository
{
    protected EventDispatcher $events;

    public function __construct()
    {
        $this->events = app(EventDispatcher::class);
    }

    public function create(array $data): Model
    {
        $model = $this->model->create($data);

        $this->events->dispatch(new ModelCreated(
            model: get_class($model),
            id: $model->id,
            data: $data,
        ));

        return $model;
    }

    public function update(Model $model, array $data): Model
    {
        $oldData = $model->toArray();

        $model->update($data);
        $model->refresh();

        $this->events->dispatch(new ModelUpdated(
            model: get_class($model),
            id: $model->id,
            old: $oldData,
            new: $model->toArray(),
        ));

        return $model;
    }

    public function delete(Model $model): bool
    {
        $result = $model->delete();

        $this->events->dispatch(new ModelDeleted(
            model: get_class($model),
            id: $model->id,
        ));

        return $result;
    }
}
```

```php
// Query logging middleware

class QueryLoggingMiddleware
{
    public function __construct(
        private readonly LoggerInterface $logger,
        private readonly float $slowQueryThreshold = 1000,
    ) {}

    public function beforeQuery(string $query, array $bindings): void
    {
        $start = microtime(true);

        return function (float $duration) use ($query, $bindings, $start) {
            $this->logQuery($query, $bindings, $duration);

            if ($duration > $this->slowQueryThreshold) {
                $this->logSlowQuery($query, $bindings, $duration);
            }
        };
    }

    private function logQuery(string $query, array $bindings, float $duration): void
    {
        $this->logger->info('Repository query', [
            'query' => $query,
            'bindings' => $bindings,
            'duration_ms' => $duration * 1000,
        ]);
    }

    private function logSlowQuery(string $query, array $bindings, float $duration): void
    {
        $this->logger->warning('Slow repository query', [
            'query' => $query,
            'bindings' => $bindings,
            'duration_ms' => $duration * 1000,
            'threshold_ms' => $this->slowQueryThreshold,
        ]);
    }
}
```

### Rate Limiting Middleware

```php
// Repository rate limiting middleware

class RateLimitingMiddleware
{
    public function __construct(
        private readonly RateLimiter $rateLimiter,
    ) {}

    public function handle(string $repository, string $method, callable $callback): mixed
    {
        $key = "repository:{$repository}:{$method}";
        $maxAttempts = $this->getMaxAttempts($method);

        if ($this->rateLimiter->tooManyAttempts($key, $maxAttempts)) {
            throw new RateLimitExceededException(
                "Too many {$method} attempts on {$repository}"
            );
        }

        $this->rateLimiter->hit($key, 60);

        return $callback();
    }

    private function getMaxAttempts(string $method): int
    {
        return match ($method) {
            'search' => 30,
            'create' => 10,
            'update' => 20,
            'delete' => 5,
            default => 60,
        };
    }
}
```

```php
    private function sanitize(array $data): array
    {
        return [
            'name' => e($data['name']),
            'slug' => Str::slug($data['slug']),
            'description' => strip_tags($data['description']),
            'category_id' => (int) $data['category_id'],
            'author_id' => (int) $data['author_id'],
            'is_premium' => (bool) $data['is_premium'],
            'status' => $data['status'] ?? 'draft',
        ];
    }
}
```

# 05.09 - Actions Layer Architecture

**Project:** GsmUi
**Architecture:** Application Layer – Actions Pattern
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

The Actions Layer represents the **Application Layer** of GsmUi. Every user operation, API request, scheduled task, or command is executed through a dedicated Action class.

Actions orchestrate business workflows while delegating domain logic to Services and persistence to Repositories.

This keeps controllers, Livewire components, Jobs, and Commands extremely small.

---

# Objectives

The Actions Layer should:

* Represent one business use case
* Coordinate Services
* Manage transactions
* Dispatch Events
* Return DTOs or Domain Models
* Be reusable across HTTP, Livewire, CLI, API, and Jobs
* Be independently testable

---

# Action Responsibilities

Actions are responsible for:

* Executing one business use case
* Coordinating multiple services
* Opening database transactions
* Dispatching events
* Returning results
* Throwing business exceptions

Actions **must not**:

* Render Blade views
* Return HTTP responses
* Query the database directly
* Contain SQL
* Handle UI state
* Perform authorization (except business preconditions)

---

# Standard Action Structure

```php
class CreateComponentAction
{
    public function __construct(
        private ComponentService $service
    ) {}

    public function execute(CreateComponentData $data): Component
    {
        return DB::transaction(function () use ($data) {
            return $this->service->create($data);
        });
    }
}
```

# Transaction Management

Actions own database transactions.

Example:

```php

    // execute workflow
```

* One transaction per use case
* Keep transactions short
* Avoid HTTP calls inside transactions

# Validation

1. Form Request
2. Livewire validation
3. DTO construction

# Authorization

* Policies
* Gates
* Middleware

* Active subscription

# Action Implementation Patterns

## CRUD Actions

### CreateComponentAction

```php
// app/Domains/Components/Actions/CreateComponentAction.php

declare(strict_types=1);

namespace App\Domains\Components\Actions;

use App\Domains\Components\Contracts\ComponentServiceInterface;
use App\Domains\Components\DTOs\{CreateComponentData, ComponentDTO};
use App\Domains\Components\Events\ComponentCreated;
use App\Domains\Users\Contracts\UserRepositoryInterface;
use App\Shared\Contracts\EventDispatcher;
use Illuminate\Support\Facades\DB;

final class CreateComponentAction
{
    public function __construct(
        private readonly ComponentServiceInterface $componentService,
        private readonly UserRepositoryInterface $userRepository,
        private readonly EventDispatcher $events,
    ) {}

    public function execute(CreateComponentData $data): ComponentDTO
    {
        return DB::transaction(function () use ($data) {
            // Validate author exists
            $author = $this->userRepository->findOrFail($data->authorId);

            // Create component
            $component = $this->componentService->create($data);

            // Log activity
            activity()
                ->performedOn($component)
                ->withProperties(['data' => $data->toArray()])
                ->log('component_created');

            return $component;
        });
    }
}
```

### UpdateComponentAction

```php
// app/Domains/Components/Actions/UpdateComponentAction.php

declare(strict_types=1);

namespace App\Domains\Components\Actions;

use App\Domains\Components\Contracts\ComponentServiceInterface;
use App\Domains\Components\DTOs\{UpdateComponentData, ComponentDTO};
use App\Domains\Components\Events\ComponentUpdated;
use App\Domains\Components\Exceptions\ComponentNotFoundException;
use Illuminate\Support\Facades\DB;

final class UpdateComponentAction
{
    public function __construct(
        private readonly ComponentServiceInterface $componentService,
    ) {}

    public function execute(int $componentId, UpdateComponentData $data): ComponentDTO
    {
        return DB::transaction(function () use ($componentId, $data) {
            // Verify component exists
            $existing = $this->componentService->findById($componentId);
            if (!$existing) {
                throw new ComponentNotFoundException("Component #{$componentId} not found");
            }

            // Update component
            $component = $this->componentService->update($componentId, $data);

            // Log activity
            activity()
                ->performedOn($component)
                ->withProperties([
                    'old' => $existing->toArray(),
                    'new' => $component->toArray(),
                ])
                ->log('component_updated');

            return $component;
        });
    }
}
```

### DeleteComponentAction

```php
// app/Domains/Components/Actions/DeleteComponentAction.php

declare(strict_types=1);

namespace App\Domains\Components\Actions;

use App\Domains\Components\Contracts\ComponentServiceInterface;
use App\Domains\Components\Exceptions\{ComponentNotFoundException, ComponentCannotBeDeletedException};
use App\Domains\Components\Enums\ComponentStatus;
use Illuminate\Support\Facades\DB;

final class DeleteComponentAction
{
    public function __construct(
        private readonly ComponentServiceInterface $componentService,
    ) {}

    public function execute(int $componentId): void
    {
        DB::transaction(function () use ($componentId) {
            // Verify component exists
            $component = $this->componentService->findById($componentId);
            if (!$component) {
                throw new ComponentNotFoundException("Component #{$componentId} not found");
            }

            // Business rule: Cannot delete published components
            if ($component->status === ComponentStatus::PUBLISHED) {
                throw new ComponentCannotBeDeletedException(
                    'Published components must be archived before deletion'
                );
            }

            // Delete component
            $this->componentService->delete($componentId);

            // Log activity
            activity()
                ->withProperties(['component_id' => $componentId])
                ->log('component_deleted');
        });
    }
}
```

## Publishing Actions

### PublishComponentAction

```php
// app/Domains/Components/Actions/PublishComponentAction.php

declare(strict_types=1);

namespace App\Domains\Components\Actions;

use App\Domains\Components\Contracts\ComponentServiceInterface;
use App\Domains\Components\DTOs\ComponentDTO;
use App\Domains\Components\Events\ComponentPublished;
use App\Domains\Components\Exceptions\{ComponentNotFoundException, ComponentCannotBePublishedException};
use App\Domains\Search\Contracts\SearchServiceInterface;
use App\Domains\Notifications\Contracts\NotificationServiceInterface;
use Illuminate\Support\Facades\DB;

final class PublishComponentAction
{
    public function __construct(
        private readonly ComponentServiceInterface $componentService,
        private readonly SearchServiceInterface $searchService,
        private readonly NotificationServiceInterface $notificationService,
    ) {}

    public function execute(int $componentId): ComponentDTO
    {
        return DB::transaction(function () use ($componentId) {
            // Verify component exists
            $component = $this->componentService->findById($componentId);
            if (!$component) {
                throw new ComponentNotFoundException("Component #{$componentId} not found");
            }

            // Business rule: Must have at least one version
            if ($component->versionsCount === 0) {
                throw new ComponentCannotBePublishedException(
                    'Component must have at least one version before publishing'
                );
            }

            // Business rule: Must have description
            if (strlen($component->description) < 50) {
                throw new ComponentCannotBePublishedException(
                    'Component description must be at least 50 characters'
                );
            }

            // Publish component
            $published = $this->componentService->publish($componentId);

            // Update search index
            $this->searchService->indexComponent($published);

            // Notify subscribers
            $this->notificationService->notifySubscribers(
                new ComponentPublished(
                    componentId: $published->id,
                    versionId: $published->latestVersionId,
                    categories: $published->categories,
                    tags: $published->tags,
                )
            );

            // Log activity
            activity()
                ->performedOn($published)
                ->log('component_published');

            return $published;
        });
    }
}
```

## Workflow Actions

### PurchaseTemplateAction

```php
// app/Domains/Marketplace/Actions/PurchaseTemplateAction.php

declare(strict_types=1);

namespace App\Domains\Marketplace\Actions;

use App\Domains\Marketplace\Contracts\{TemplateServiceInterface, MarketplaceServiceInterface};
use App\Domains\Billing\Contracts\BillingServiceInterface;
use App\Domains\Licensing\Contracts\LicenseServiceInterface;
use App\Domains\Marketplace\DTOs\{PurchaseTemplateData, OrderDTO};
use App\Domains\Marketplace\Events\OrderPaid;
use App\Domains\Billing\Events\InvoiceGenerated;
use Illuminate\Support\Facades\DB;

final class PurchaseTemplateAction
{
    public function __construct(
        private readonly MarketplaceServiceInterface $marketplaceService,
        private readonly BillingServiceInterface $billingService,
        private readonly LicenseServiceInterface $licenseService,
        private readonly TemplateServiceInterface $templateService,
    ) {}

    public function execute(PurchaseTemplateData $data): OrderDTO
    {
        return DB::transaction(function () use ($data) {
            // 1. Validate template exists and is available
            $template = $this->templateService->findById($data->templateId);
            if (!$template) {
                throw new TemplateNotFoundException("Template not found");
            }

            // 2. Check if user already purchased
            if ($this->marketplaceService->hasPurchased($data->userId, $data->templateId)) {
                throw new AlreadyPurchasedException("You have already purchased this template");
            }

            // 3. Process payment
            $payment = $this->billingService->processPayment([
                'user_id' => $data->userId,
                'amount' => $template->price,
                'currency' => 'USD',
                'description' => "Purchase template: {$template->name}",
            ]);

            // 4. Create order record
            $order = $this->marketplaceService->createOrder([
                'user_id' => $data->userId,
                'template_id' => $data->templateId,
                'amount' => $template->price,
                'payment_id' => $payment->id,
                'status' => 'completed',
            ]);

            // 5. Generate license
            $license = $this->licenseService->generate([
                'user_id' => $data->userId,
                'template_id' => $data->templateId,
                'order_id' => $order->id,
                'type' => 'single_use',
            ]);

            // 6. Update template download count
            $this->templateService->incrementDownloadCount($data->templateId);

            // 7. Dispatch events
            event(new OrderPaid(
                orderId: $order->id,
                userId: $data->userId,
                amount: $template->price,
            ));

            // 8. Log activity
            activity()
                ->performedOn($order)
                ->withProperties([
                    'template_id' => $data->templateId,
                    'amount' => $template->price,
                ])
                ->log('template_purchased');

            return OrderDTO::fromModel($order);
        });
    }
}
```

### GenerateThemeAction

```php
// app/Domains/Themes/Actions/GenerateThemeAction.php

declare(strict_types=1);

namespace App\Domains\Themes\Actions;

use App\Domains\Themes\Contracts\ThemeServiceInterface;
use App\Domains\AI\Contracts\AIServiceInterface;
use App\Domains\Themes\DTOs\{GenerateThemeData, ThemeDTO};
use App\Domains\Themes\Events\ThemeGenerated;
use App\Domains\Themes\Jobs\GenerateThemeAssets;
use Illuminate\Support\Facades\DB;

final class GenerateThemeAction
{
    public function __construct(
        private readonly ThemeServiceInterface $themeService,
        private readonly AIServiceInterface $aiService,
    ) {}

    public function execute(GenerateThemeData $data): ThemeDTO
    {
        return DB::transaction(function () use ($data) {
            // 1. Generate theme using AI
            $aiResult = $this->aiService->generateTheme([
                'style' => $data->style,
                'primary_color' => $data->primaryColor,
                'secondary_color' => $data->secondaryColor,
                'mood' => $data->mood,
                'reference' => $data->referenceImage,
            ]);

            // 2. Create theme record
            $theme = $this->themeService->create(new CreateThemeData(
                name: $data->name ?? "AI Theme " . now()->timestamp,
                slug: $data->slug ?? Str::slug($data->name ?? 'ai-theme'),
                description: $aiResult->description,
                authorId: $data->authorId,
                isPremium: false,
                colors: $aiResult->colors,
                typography: $aiResult->typography,
                spacing: $aiResult->spacing,
                tokens: $aiResult->tokens,
            ));

            // 3. Dispatch job to generate export assets
            GenerateThemeAssets::dispatch($theme->id)
                ->onQueue('exports');

            // 4. Dispatch event
            event(new ThemeGenerated(
                themeId: $theme->id,
                authorId: $data->authorId,
                aiModel: $aiResult->model,
            ));

            // 5. Log activity
            activity()
                ->performedOn($theme)
                ->withProperties([
                    'ai_model' => $aiResult->model,
                    'style' => $data->style,
                ])
                ->log('theme_generated');

            return $theme;
        });
    }
}
```

```php
// app/Domains/Showcase/Actions/ApproveShowcaseAction.php

declare(strict_types=1);

namespace App\Domains\Showcase\Actions;

use App\Domains\Showcase\Contracts\ShowcaseServiceInterface;
use App\Domains\Search\Contracts\SearchServiceInterface;
use App\Domains\Notifications\Contracts\NotificationServiceInterface;
use App\Domains\Showcase\DTOs\{ShowcaseDTO, ApproveShowcaseData};
use App\Domains\Showcase\Events\ShowcaseApproved;
use App\Domains\Showcase\Exceptions\{ShowcaseNotFoundException, ShowcaseAlreadyApprovedException};
use Illuminate\Support\Facades\DB;

final class ApproveShowcaseAction
{
    public function __construct(
        private readonly ShowcaseServiceInterface $showcaseService,
        private readonly SearchServiceInterface $searchService,
        private readonly NotificationServiceInterface $notificationService,
    ) {}

    public function execute(ApproveShowcaseData $data): ShowcaseDTO
    {
        return DB::transaction(function () use ($data) {
            // 1. Verify showcase exists
            $showcase = $this->showcaseService->findById($data->showcaseId);
            if (!$showcase) {
                throw new ShowcaseNotFoundException("Showcase not found");
            }

            // 2. Check not already approved
            if ($showcase->status === 'approved') {
                throw new ShowcaseAlreadyApprovedException("Showcase is already approved");
            }

            // 3. Approve showcase
            $approved = $this->showcaseService->approve(
                $data->showcaseId,
                $data->featured ?? false
            );

            // 4. Index in search
            $this->searchService->indexShowcase($approved);

            // 5. Notify author
            $this->notificationService->notifyUser(
                $showcase->authorId,
                new ShowcaseApproved(
                    showcaseId: $approved->id,
                    title: $approved->title,
                    featured: $data->featured ?? false,
                )
            );

            // 6. Log activity
            activity()
                ->performedOn($approved)
                ->withProperties([
                    'featured' => $data->featured ?? false,
                ])
                ->log('showcase_approved');

            return $approved;
        });
    }
}
```

## Import/Export Actions

### ExportThemeAction

```php
// app/Domains/Themes/Actions/ExportThemeAction.php

declare(strict_types=1);

namespace App\Domains\Themes\Actions;

use App\Domains\Themes\Contracts\ThemeServiceInterface;
use App\Domains\Themes\DTOs\{ThemeExportDTO, ExportThemeData};
use App\Domains\Themes\Jobs\BuildThemePackage;
use App\Domains\Storage\Contracts\StorageServiceInterface;
use Illuminate\Support\Facades\DB;

final class ExportThemeAction
{
    public function __construct(
        private readonly ThemeServiceInterface $themeService,
        private readonly StorageServiceInterface $storageService,
    ) {}

    public function execute(ExportThemeData $data): ThemeExportDTO
    {
        // 1. Verify theme exists
        $theme = $this->themeService->findById($data->themeId);
        if (!$theme) {
            throw new ThemeNotFoundException("Theme not found");
        }

        // 2. Export theme in requested format
        $export = $this->themeService->export($data->themeId, $data->format);

        // 3. Build package if needed
        if ($data->format === 'package') {
            BuildThemePackage::dispatch($data->themeId, $data->userId)
                ->onQueue('exports');

            return new ThemeExportDTO(
                themeId: $data->themeId,
                format: 'package',
                status: 'processing',
                message: 'Theme package is being built. You will be notified when ready.',
            );
        }

        // 4. Store export file
        $path = "themes/{$theme->slug}/exports/{$data->format}/{$theme->slug}.{$data->format}";
        $this->storageService->put($path, $export->content);

        // 5. Generate download URL
        $downloadUrl = $this->storageService->temporaryUrl($path, now()->addHour());

        // 6. Log activity
        activity()
            ->withProperties([
                'theme_id' => $data->themeId,
                'format' => $data->format,
            ])
            ->log('theme_exported');

        return new ThemeExportDTO(
            themeId: $data->themeId,
            format: $data->format,
            downloadUrl: $downloadUrl,
            filename: $export->filename,
            size: $export->size,
        );
    }
}
```

## Maintenance Actions

### CleanupMediaAction

```php
// app/Domains/System/Actions/CleanupMediaAction.php

declare(strict_types=1);

namespace App\Domains\System\Actions;

use App\Domains\Storage\Contracts\StorageServiceInterface;
use App\Domains\System\DTOs\CleanupResultDTO;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;

final class CleanupMediaAction
{
    public function __construct(
        private readonly StorageServiceInterface $storageService,
    ) {}

    public function execute(?int $olderThanDays = 30): CleanupResultDTO
    {
        $deletedCount = 0;
        $freedBytes = 0;

        DB::transaction(function () use ($olderThanDays, &$deletedCount, &$freedBytes) {
            // 1. Find orphaned media files
            $orphanedFiles = $this->findOrphanedFiles($olderThanDays);

            foreach ($orphanedFiles as $file) {
                // 2. Delete file
                $this->storageService->delete($file['path']);

                $deletedCount++;
                $freedBytes += $file['size'];
            }

            // 3. Clean temporary uploads
            $tempFiles = $this->findTemporaryFiles();
            foreach ($tempFiles as $file) {
                $this->storageService->delete($file['path']);
                $deletedCount++;
                $freedBytes += $file['size'];
            }

            // 4. Log cleanup
            Log::info('Media cleanup completed', [
                'files_deleted' => $deletedCount,
                'bytes_freed' => $freedBytes,
            ]);
        });

        return new CleanupResultDTO(
            filesDeleted: $deletedCount,
            bytesFreed: $freedBytes,
            completedAt: now(),
        );
    }

    private function findOrphanedFiles(int $olderThanDays): array
    {
        // Find files not referenced by any model
        return DB::table('media')
            ->where('created_at', '<', now()->subDays($olderThanDays))
            ->whereDoesntHave('referencedBy')
            ->get()
            ->toArray();
    }

    private function findTemporaryFiles(): array
    {
        return DB::table('media')
            ->where('is_temporary', true)
            ->where('created_at', '<', now()->subHours(24))
            ->get()
            ->toArray();
    }
}
```

### RefreshSearchIndexAction

```php
// app/Domains/Search/Actions/RefreshSearchIndexAction.php

declare(strict_types=1);

namespace App\Domains\Search\Actions;

use App\Domains\Search\Contracts\SearchServiceInterface;
use App\Domains\Components\Contracts\ComponentServiceInterface;
use App\Domains\Themes\Contracts\ThemeServiceInterface;
use App\Domains\Templates\Contracts\TemplateServiceInterface;
use App\Domains\Documentation\Contracts\DocumentationServiceInterface;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;

final class RefreshSearchIndexAction
{
    public function __construct(
        private readonly SearchServiceInterface $searchService,
        private readonly ComponentServiceInterface $componentService,
        private readonly ThemeServiceInterface $themeService,
        private readonly TemplateServiceInterface $templateService,
        private readonly DocumentationServiceInterface $documentationService,
    ) {}

    public function execute(?string $index = null): array
    {
        $results = [];

        DB::transaction(function () use ($index, &$results) {
            // 1. Clear existing index
            if ($index) {
                $this->searchService->clearIndex($index);
                $results[$index] = $this->reindexType($index);
            } else {
                // Reindex all
                $this->searchService->clearAllIndexes();

                $results['components'] = $this->reindexComponents();
                $results['themes'] = $this->reindexThemes();
                $results['templates'] = $this->reindexTemplates();
                $results['documentation'] = $this->reindexDocumentation();
            }

            Log::info('Search index refreshed', $results);
        });

        return $results;
    }

    private function reindexComponents(): int
    {
        $components = $this->componentService->getPublished();
        $count = 0;

        foreach ($components as $component) {
            $this->searchService->indexComponent($component);
            $count++;
        }

        return $count;
    }

    private function reindexThemes(): int
    {
        $themes = $this->themeService->getPublished();
        $count = 0;

        foreach ($themes as $theme) {
            $this->searchService->indexTheme($theme);
            $count++;
        }

        return $count;
    }

    private function reindexTemplates(): int
    {
        $templates = $this->templateService->getPublished();
        $count = 0;

        foreach ($templates as $template) {
            $this->searchService->indexTemplate($template);
            $count++;
        }

        return $count;
    }

    private function reindexDocumentation(): int
    {
        $docs = $this->documentationService->getAll();
        $count = 0;

        foreach ($docs as $doc) {
            $this->searchService->indexDocumentation($doc);
            $count++;
        }

        return $count;
    }
}
```

```php
// Action rate limiting middleware

class ActionRateLimitingMiddleware
{
    public function __construct(
        private readonly RateLimiter $rateLimiter,
    ) {}

    public function handle(object $action, callable $next): mixed
    {
        $key = 'action:' . get_class($action) . ':' . $this->getUserId();

        if ($this->rateLimiter->tooManyAttempts($key, $this->getMaxAttempts())) {
            throw new RateLimitExceededException(
                'Too many attempts. Please try again later.'
            );
        }

        $this->rateLimiter->hit($key, $this->getCooldownMinutes() * 60);

        return $next($action);
    }

    private function getMaxAttempts(): int
    {
        return config('actions.rate_limiting.default_max_attempts', 60);
    }

    private function getCooldownMinutes(): int
    {
        return config('actions.rate_limiting.cooldown_minutes', 1);
    }
}
```

```php
// Action performance tracking

class ActionPerformanceTracker
{
    public function track(string $actionClass, callable $callback): mixed
    {
        $start = microtime(true);

        try {
            $result = $callback();
            $duration = microtime(true) - $start;

            $this->recordSuccess($actionClass, $duration);

            return $result;
        } catch (\Exception $e) {
            $duration = microtime(true) - $start;

            $this->recordFailure($actionClass, $duration, $e);

            throw $e;
        }
    }

    private function recordSuccess(string $actionClass, float $duration): void
    {
        $this->metrics->increment('actions.success', [
            'action' => $actionClass,
        ]);

        $this->metrics->histogram('actions.duration', $duration, [
            'action' => $actionClass,
            'status' => 'success',
        ]);
    }

    private function recordFailure(string $actionClass, float $duration, \Exception $e): void
    {
        $this->metrics->increment('actions.failure', [
            'action' => $actionClass,
            'exception' => get_class($e),
        ]);

        $this->metrics->histogram('actions.duration', $duration, [
            'action' => $actionClass,
            'status' => 'failure',
        ]);
    }
}
```

```php
class BulkPublishComponentsAction

    public function execute(array $componentIds): array
    {
        return DB::transaction(function () use ($componentIds) {
            $results = [];

            foreach ($componentIds as $componentId) {
                try {

        if (!$component) {

        }
```

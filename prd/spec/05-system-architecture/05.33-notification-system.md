# Purpose

The Notification System provides real-time alerts and updates to users through multiple channels. It handles system notifications, activity notifications, and admin notifications with configurable delivery preferences and digest options.

---

# Architecture Overview

The notification system is built on Laravel's notification framework with extensions for multi-channel delivery, preference management, and digest aggregation. It uses a queue-based architecture for asynchronous delivery with retry logic for failed notifications.

The system separates notification creation from delivery. Events in the application dispatch notification jobs that are processed by queue workers. Each notification is routed to the appropriate channels based on user preferences and notification type.

The architecture supports immediate delivery for critical notifications, queued delivery for standard notifications, and batched delivery for digest summaries. This tiered approach ensures important notifications reach users quickly while non-urgent updates are batched for convenience.

# Delivery Strategy

## Priority Levels

| Level | Delivery | Retry | Expiry |
|-------|----------|-------|--------|
| Critical | Immediate | 5 times | 24 hours |
| High | Within 1 minute | 3 times | 48 hours |
| Medium | Within 5 minutes | 2 times | 7 days |
| Low | Batched (hourly) | 1 time | 30 days |

## Retry Logic

Failed deliveries are retried with exponential backoff:

1. First retry: 1 minute
2. Second retry: 5 minutes
3. Third retry: 30 minutes
4. Fourth retry: 2 hours
5. Fifth retry: 12 hours

After all retries are exhausted, the notification is marked as failed and logged for investigation.

## Rate Limiting

- Email: Max 10 per user per hour
- SMS: Max 3 per user per day
- Push: Max 20 per user per hour
- Webhook: Max 100 per endpoint per hour

```php
class NotificationWebSocket
{
    public function broadcast(User $user, array $notification): void
    {
        $channel = "user.{$user->id}.notifications";

        broadcast(new NotificationBroadcast($notification))->toOthers();
    }

    public function sendToChannel(string $channel, array $data): void
    {
        broadcast(new ChannelBroadcast($data))->toChannel($channel);
    }

    public function getUnreadCount(User $user): int
    {
        return Cache::remember("notifications:unread:{$user->id}", now()->addMinute(), function () use ($user) {
            return Notification::where('user_id', $user->id)
                ->where('is_read', false)
                ->count();
        });
    }

    public function markAsRead(int $notificationId, User $user): void
    {
        $notification = Notification::where('id', $notificationId)
            ->where('user_id', $user->id)
            ->firstOrFail();

        $notification->update([
            'is_read' => true,
            'read_at' => now(),
        ]);

        Cache::forget("notifications:unread:{$user->id}");

        broadcast(new NotificationRead($notificationId))->toUser($user);
    }

    public function markAllAsRead(User $user): void
    {
        Notification::where('user_id', $user->id)
            ->where('is_read', false)
            ->update([
                'is_read' => true,
                'read_at' => now(),
            ]);

        Cache::forget("notifications:unread:{$user->id}");

        broadcast(new AllNotificationsRead())->toUser($user);
    }
}
```

### Server-Sent Events

```php
class NotificationSseController extends Controller
{
    public function stream(): StreamedResponse
    {
        return response()->stream(function () {
            $user = auth()->user();

            // Send initial connection event
            $this->sendEvent('connected', ['user_id' => $user->id]);

            // Listen for notifications
            while (true) {
                if (connection_aborted()) break;

                $notification = $this->getNextNotification($user);

                if ($notification) {
                    $this->sendEvent('notification', $notification);
                }

                // Send heartbeat every 30 seconds
                $this->sendEvent('heartbeat', ['time' => now()->toIso8601String()]);

                sleep(1);
            }
        }, 200, [
            'Content-Type' => 'text/event-stream',
            'Cache-Control' => 'no-cache',
            'X-Accel-Buffering' => 'no',
        ]);
    }

    protected function sendEvent(string $type, array $data): void
    {
        echo "event: {$type}\n";
        echo "data: " . json_encode($data) . "\n\n";
        ob_flush();
        flush();
    }
}
```

## Advanced Preference Management

### Preference Hierarchy

```php
class NotificationPreferenceManager
{
    public function getEffectivePreferences(User $user, string $type): array
    {
        // 1. Check user-specific override
        $userPref = NotificationPreference::where('user_id', $user->id)
            ->where('type', $type)
            ->first();

        if ($userPref) {
            return $userPref->toArray();
        }

        // 2. Check user's role-based defaults
        $rolePref = RolePreference::where('role', $user->role)
            ->where('type', $type)
            ->first();

        if ($rolePref) {
            return $rolePref->toArray();
        }

        // 3. Fall back to system defaults
        return $this->getSystemDefaults($type);
    }

    protected function getSystemDefaults(string $type): array
    {
        return config("notifications.defaults.{$type}", [
            'email_enabled' => true,
            'in_app_enabled' => true,
            'sms_enabled' => false,
            'push_enabled' => false,
        ]);
    }

    public function updatePreference(User $user, string $type, array $settings): void
    {
        NotificationPreference::updateOrCreate(
            ['user_id' => $user->id, 'type' => $type],
            $settings
        );

        Cache::forget("preferences:{$user->id}:{$type}");
    }

    public function getDigestSettings(User $user): DigestSettings
    {
        return DigestSettings::firstOrNew(['user_id' => $user->id]);
    }

    public function updateDigestSettings(User $user, array $data): void
    {
        DigestSettings::updateOrCreate(
            ['user_id' => $user->id],
            [
                'frequency' => $data['frequency'] ?? 'realtime',
                'day_of_week' => $data['day_of_week'] ?? null,
                'time_of_day' => $data['time_of_day'] ?? '09:00',
                'timezone' => $data['timezone'] ?? $user->timezone,
                'included_types' => $data['included_types'] ?? [],
            ]
        );
    }
}
```

### Quiet Hours Manager

```php
class QuietHoursManager
{
    public function isInQuietHours(User $user): bool
    {
        $preferences = app(NotificationPreferenceManager::class)->getDigestSettings($user);

        if (!$preferences->quiet_hours_enabled) {
            return false;
        }

        $userTimezone = $preferences->timezone ?? 'UTC';
        $now = now()->timezone($userTimezone);
        $start = Carbon::parse($preferences->quiet_hours_start, $userTimezone);
        $end = Carbon::parse($preferences->quiet_hours_end, $userTimezone);

        if ($start->greaterThan($end)) {
            // Overnight quiet hours (e.g., 10 PM to 8 AM)
            return $now->greaterThanOrEqualTo($start) || $now->lessThanOrEqualTo($end);
        }

        return $now->between($start, $end);
    }

    public function shouldSuppress(string $type, User $user): bool
    {
        // Critical notifications bypass quiet hours
        if ($this->isCritical($type)) {
            return false;
        }

        return $this->isInQuietHours($user);
    }

    protected function isCritical(string $type): bool
    {
        $criticalTypes = [
            'security.alert',
            'payment.failed',
            'account.suspended',
        ];

        return in_array($type, $criticalTypes);
    }
}
```

## Digest System

### Digest Aggregator

```php
class DigestAggregator
{
    public function aggregate(User $user, string $frequency): Digest
    {
        $preferences = app(NotificationPreferenceManager::class)->getDigestSettings($user);

        $notifications = Notification::where('user_id', $user->id)
            ->where('is_read', false)
            ->where('sent_at', '>=', $this->getSinceDate($frequency))
            ->whereIn('type', $preferences->included_types ?? ['*'])
            ->orderByDesc('priority')
            ->get();

        if ($notifications->isEmpty()) {
            return new Digest(
                user: $user,
                notifications: collect(),
                summary: 'No new notifications',
            );
        }

        $grouped = $notifications->groupBy('type');
        $summary = $this->generateSummary($grouped);

        return new Digest(
            user: $user,
            notifications: $notifications,
            grouped: $grouped,
            summary: $summary,
            generated_at: now(),
        );
    }

    protected function getSinceDate(string $frequency): Carbon
    {
        return match($frequency) {
            'daily' => now()->subDay(),
            'weekly' => now()->subWeek(),
            'monthly' => now()->subMonth(),
            default => now()->subDay(),
        };
    }

    protected function generateSummary(Collection $grouped): string
    {
        $parts = [];
        foreach ($grouped as $type => $notifications) {
            $count = $notifications->count();
            $typeName = $this->getTypeName($type);
            $parts[] = "{$count} {$typeName}";
        }

        return implode(', ', $parts);
    }
}
```

### Webhook Manager

```php
class WebhookManager
{
    public function register(array $data): Webhook
    {
        return Webhook::create([
            'url' => $data['url'],
            'secret' => Str::random(40),
            'events' => $data['events'],
            'is_active' => true,
        ]);
    }

    public function trigger(string $event, array $payload): void
    {
        $webhooks = Webhook::where('is_active', true)
            ->whereJsonContains('events', $event)
            ->get();

        foreach ($webhooks as $webhook) {
            dispatch(new SendWebhook($webhook, $event, $payload));
        }
    }

    public function test(Webhook $webhook): WebhookTestResult
    {
        $payload = [
            'event' => 'webhook.test',
            'timestamp' => now()->toIso8601String(),
            'data' => ['message' => 'This is a test webhook'],
        ];

        $response = Http::withHeaders($this->getHeaders($webhook, $payload))
            ->timeout(10)
            ->post($webhook->url, $payload);

        return new WebhookTestResult(
            success: $response->successful(),
            status_code: $response->status(),
            response_body: $response->body(),
        );
    }

    protected function getHeaders(Webhook $webhook, array $payload): array
    {
        $signature = hash_hmac('sha256', json_encode($payload), $webhook->secret);

        return [
            'Content-Type' => 'application/json',
            'X-Webhook-Signature' => "sha256={$signature}",
            'X-Webhook-Event' => $payload['event'],
            'X-Webhook-Timestamp' => $payload['timestamp'],
            'User-Agent' => 'GsmUi-Webhook/1.0',
        ];
    }
}
```

### Webhook Verification

```php
class WebhookVerifier
{
    public function verify(Webhook $webhook, Request $request): bool
    {
        $signature = $request->header('X-Webhook-Signature');
        $timestamp = $request->header('X-Webhook-Timestamp');

        if (!$signature || !$timestamp) {
            return false;
        }

        // Check timestamp is within 5 minutes
        $requestTime = Carbon::parse($timestamp);
        if ($requestTime->diffInMinutes(now()) > 5) {
            return false;
        }

        // Verify signature
        $expectedSignature = 'sha256=' . hash_hmac(
            'sha256',
            $request->getContent(),
            $webhook->secret
        );

        return hash_equals($expectedSignature, $signature);
    }
}
```

```php
class NotificationAnalytics
{
    public function trackDelivery(Notification $notification, string $channel): void
    {
        NotificationLog::create([
            'notification_id' => $notification->id,
            'channel' => $channel,
            'status' => 'sent',
            'sent_at' => now(),
        ]);
    }

    public function trackOpen(Notification $notification): void
    {
        NotificationLog::where('notification_id', $notification->id)
            ->where('channel', 'email')
            ->update([
                'opened_at' => now(),
            ]);
    }

    public function trackClick(Notification $notification, string $url): void
    {
        NotificationLog::where('notification_id', $notification->id)
            ->update([
                'clicked_at' => now(),
                'clicked_url' => $url,
            ]);
    }

    public function getDeliveryStats(string $period = '7d'): DeliveryStats
    {
        $startDate = now()->subDays((int) str_replace('d', '', $period));

        $logs = NotificationLog::where('sent_at', '>=', $startDate);

        return new DeliveryStats(
            total_sent: $logs->count(),
            email_sent: $logs->where('channel', 'email')->count(),
            in_app_sent: $logs->where('channel', 'in_app')->count(),
            webhook_sent: $logs->where('channel', 'webhook')->count(),
            email_opened: $logs->where('channel', 'email')->whereNotNull('opened_at')->count(),
            email_clicked: $logs->where('channel', 'email')->whereNotNull('clicked_at')->count(),
            failed: $logs->where('status', 'failed')->count(),
            open_rate: $this->calculateOpenRate($logs),
            click_rate: $this->calculateClickRate($logs),
        );
    }

    public function getNotificationPerformance(string $type): array
    {
        return Notification::where('type', $type)
            ->where('created_at', '>=', now()->subDays(30))
            ->withCount(['logs as sent_count' => fn($q) => $q->where('status', 'sent')])
            ->withCount(['logs as opened_count' => fn($q) => $q->whereNotNull('opened_at')])
            ->withCount(['logs as clicked_count' => fn($q) => $q->whereNotNull('clicked_at')])
            ->first()
            ->toArray();
    }
}
```

```php
class NotificationFailedJobHandler
{
    public function failed(Notification $notification, string $channel, Throwable $exception): void
    {
        // Log the failure
        NotificationLog::where('notification_id', $notification->id)
            ->where('channel', $channel)
            ->update([
                'status' => 'failed',
                'error_message' => $exception->getMessage(),
                'failed_at' => now(),
            ]);

        // Check if we should retry
        $log = NotificationLog::where('notification_id', $notification->id)
            ->where('channel', $channel)
            ->first();

        if ($log->attempts < $log->max_attempts) {
            // Retry with exponential backoff
            $delay = pow(2, $log->attempts) * 60;
            dispatch(new RetryNotification($notification, $channel))
                ->delay(now()->addSeconds($delay));
        } else {
            // Max retries exceeded
            $this->handleMaxRetriesExceeded($notification, $channel);
        }
    }

    protected function handleMaxRetriesExceeded(Notification $notification, string $channel): void
    {
        // Mark as permanently failed
        NotificationLog::where('notification_id', $notification->id)
            ->where('channel', $channel)
            ->update(['status' => 'permanently_failed']);

        // Notify admin if critical
        if ($notification->priority === 'critical') {
            $this->notifyAdmin($notification, $channel);
        }
    }
}
```

```php
class WebhookEventFilter
{
    public function filter(Webhook $webhook, string $event, array $payload): bool
    {
        // Check if event is in webhook's subscribed events
        if (!in_array($event, $webhook->events)) {
            return false;
        }

        if ($webhook->filters) {

    protected function applyFilters(array $filters, string $event, array $payload): bool
    {
        foreach ($filters as $filter) {
            $field = data_get($payload, $filter['field']);
            $operator = $filter['operator'];
            $value = $filter['value'];

            $matches = match($operator) {
                'equals' => $field == $value,
                'not_equals' => $field != $value,
                'contains' => str_contains($field, $value),
                'greater_than' => $field > $value,
                'less_than' => $field < $value,
                default => true,
            };

            if (!$matches) {
                return false;
            }
        }

        return true;
    }
```

### Fallback Channel Manager

```php
class FallbackChannelManager
{
    protected array $fallbackChain = [
        'email' => ['in_app', 'push'],
        'sms' => ['email', 'in_app'],
        'push' => ['in_app', 'email'],
        'webhook' => ['email'],
    ];

    public function handleFailure(Notification $notification, string $failedChannel): void
    {
        $fallbacks = $this->fallbackChain[$failedChannel] ?? [];

        foreach ($fallbacks as $fallbackChannel) {
            if ($this->canSend($fallbackChannel, $notification)) {
                $this->sendViaFallback($notification, $fallbackChannel, $failedChannel);
                return;
            }
        }

        // All fallbacks exhausted
        $this->handleExhaustedFallbacks($notification, $failedChannel);
    }

    protected function canSend(string $channel, Notification $notification): bool
    {
        $rateLimiter = app(NotificationRateLimiter::class);

        if (!$rateLimiter->isAllowed($channel, $notification->user)) {
            return false;
        }

        $preferenceManager = app(NotificationPreferenceManager::class);
        $preferences = $preferenceManager->getEffectivePreferences($notification->user, $notification->type);

        return $preferences["{$channel}_enabled"] ?? false;
    }

    protected function sendViaFallback(Notification $notification, string $channel, string $originalChannel): void
    {
        $notification->update([
            'fallback_channel' => $channel,
            'fallback_reason' => "{$original_channel} delivery failed",
        ]);

        $job = match($channel) {
            'email' => new SendEmailNotification($notification),
            'in_app' => new SendInAppNotification($notification),
            'push' => new SendPushNotification($notification),
        };
```

```php
                'count' => $group->count(),

    {
        return match($notification->type) {
            'comment.new', 'comment.reply' => "comments:{$notification->data['post_id']}",
            'like.new' => "likes:{$notification->data['post_id']}",
            'follow.new' => "followers",
            default => $notification->type,
        };
    }

    protected function generateGroupSummary(Collection $group): string
    {
        $count = $group->count();
        $type = $group->first()->type;

        return match(true) {
            str_contains($type, 'comment') && $count > 1 => "{$count} new comments on your post",
            str_contains($type, 'like') && $count > 1 => "{$count} people liked your post",
            str_contains($type, 'follow') && $count > 1 => "{$count} new followers",
            default => $group->first()->title,
        };
    }
}
```

### Smart Delivery Timing

```php
class SmartDeliveryTiming
{
    public function getOptimalTime(User $user, string $channel): Carbon
    {
        $stats = $this->getUserEngagementStats($user, $channel);

        if ($stats->isEmpty()) {
            return now(); // Send immediately if no data
        }

        $bestHour = $stats->sortByDesc('engagement_rate')->first()->hour;

        $optimalTime = now()->setTime($bestHour, 0);

        if ($optimalTime->isPast()) {
            $optimalTime->addDay();
        }

        return $optimalTime;
    }

    protected function getUserEngagementStats(User $user, string $channel): Collection
    {
        return NotificationLog::where('user_id', $user->id)
            ->where('channel', $channel)
            ->where('created_at', '>=', now()->subDays(30))
            ->selectRaw('HOUR(created_at) as hour, AVG(CASE WHEN opened_at IS NOT NULL THEN 1 ELSE 0 END) as engagement_rate')
            ->groupBy('hour')
            ->get();
    }

    public function shouldDelay(Notification $notification, User $user): bool
    {
        // Don't delay critical notifications
        if ($notification->priority === 'critical') {
            return false;
        }

        // Don't delay if user is currently active
        if ($this->isUserActive($user)) {
            return false;
        }

        // Delay if it's quiet hours
        $quietHoursManager = app(QuietHoursManager::class);
        if ($quietHoursManager->isInQuietHours($user)) {
            return true;
        }

        return false;
    }

    protected function isUserActive(User $user): bool
    {
        return UserActivity::where('user_id', $user->id)
            ->where('created_at', '>=', now()->subMinutes(15))
            ->exists();
    }
}
```

## Notification Templates

### Template Engine

```php
class NotificationTemplateEngine
{
    public function render(string $templateName, array $data): array
    {
        $template = NotificationTemplate::where('name', $templateName)
            ->where('is_active', true)
            ->firstOrFail();

        return [
            'subject' => $this->renderVariable($template->subject, $data),
            'body' => $this->renderVariable($template->body, $data),
            'html' => $this->renderHtml($template, $data),
            'plain_text' => $this->renderPlainText($template, $data),
        ];
    }

    protected function renderVariable(string $template, array $data): string
    {
        preg_match_all('/\{\{(\w+(?:\.\w+)*)\}\}/', $template, $matches);

        foreach ($matches[1] as $index => $key) {
            $value = data_get($data, $key, $matches[0][$index]);
            $template = str_replace($matches[0][$index], $value, $template);
        }

        return $template;
    }

    protected function renderHtml(NotificationTemplate $template, array $data): string
    {
        $html = $template->html_body;

        // Replace variables
        $html = $this->renderVariable($html, $data);

        // Process conditionals
        $html = $this->processConditionals($html, $data);

        // Process loops
        $html = $this->processLoops($html, $data);

        return $html;
    }

    protected function processConditionals(string $html, array $data): string
        return preg_replace_callback('/@if\((\w+(?:\.\w+)*)\)(.*?)@endif/s', function ($matches) use ($data) {
            $value = data_get($data, $matches[1]);
            return $value ? $matches[2] : '';
        }, $html);
    }
}
```

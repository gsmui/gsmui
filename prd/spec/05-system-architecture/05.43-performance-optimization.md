# Data Flow

Performance optimization touches every data path in the GsmUi platform. Understanding these flows is critical for applying the right technique at the right layer.

## Request Lifecycle Optimization

`
User Request
    │
    ├── CDN Layer (static assets, cached pages)
    │       └── HIT ──> Return cached response
    │       └── MISS ──> Continue to origin
    │
    ├── Load Balancer (TLS termination, health checks)
    │
    ├── PHP Application
    │       ├── Route resolution (< 1ms)
    │       ├── Middleware stack (< 5ms)
    │       ├── Controller/Livewire (< 20ms)
    │       ├── Service layer (< 10ms)
    │       └── Query execution (< 50ms)
    │
    ├── Redis Cache Layer
    │       ├── Session data (< 1ms)
    │       ├── Query cache (< 1ms)
    │       └── Full-page cache (< 1ms)
    │
    └── Response (< 150ms total for cached, < 500ms for dynamic)
`

## Database Query Flow

`
Query Request
    │
    ├── Check Query Cache (Redis)
    │       └── HIT ──> Return cached result set
    │       └── MISS ──> Continue to database
    │
    ├── Check Read Replica Pool
    │       └── Available ──> Route to replica
    │       └── Unavailable ──> Route to primary
    │
    ├── Execute Query (with index hints)
    │
    ├── Store Result in Cache (TTL-based)
    │
    └── Return to Caller
`

## Asset Delivery Flow

`
Browser Request
    │
    ├── HTML Document (preloaded critical CSS)
    │
    ├── JavaScript Bundles
    │       ├── gsmui.js (core, cached long-term)
    │       ├── Component bundles (lazy-loaded)
    │       └── Vendor chunks (shared, cached)
    │
    ├── CSS
    │       ├── Critical CSS (inlined)
    │       └── Full CSS (async loaded)
    │
    └── Images
            ├── Above-fold (preload, WebP/AVIF)
            └── Below-fold (lazy load, placeholder)
`

## Queue Processing Flow

`
Event Dispatched
    │
    ├── High-Priority Queue (payments, auth)
    │       └── Dedicated worker pool (4+ processes)
    │
    ├── Default Queue (notifications, indexing)
    │       └── Shared worker pool (2+ processes)
    │
    └── Low-Priority Queue (analytics, cleanup)
            └── Background worker pool (1+ process)
`

Each queue uses Redis-basedHorizon for monitoring and auto-scaling based on depth.

# Security Considerations

Performance optimizations must not compromise security. Each optimization technique has specific security implications that must be addressed.

## Cache Security

| Concern | Mitigation |
|---------|------------|
| Cache poisoning | Validate cache keys; use signed cache entries |
| Stale auth data | Short TTL for user-specific cache (5 min max) |
| Data leakage across tenants | Cache tags per-user or per-team |
| Sensitive data in cache | Never cache PII in shared cache stores |

`php
// Secure caching pattern for user data
Cache::tags(["user:{}"])->remember(
    "profile:{}",
    now()->addMinutes(5),
    fn() => User::find()->only(['name', 'email', 'avatar'])
);
`

## CDN Security

- **Cache-Control headers**: Set 
o-store for authenticated pages.
- **Signed URLs**: Use signed URLs for downloadable assets.
- **Origin shield**: CDN never serves stale content for authenticated routes.
- **WAF integration**: Cloudflare/AWS WAF filters malicious requests before they reach origin.

## Queue Security

- Queue jobs serialize data to Redis; ensure no secrets are stored in job payloads.
- Use encrypted serialization for sensitive job data.
- Horizon dashboard requires admin authentication.
- Failed jobs containing PII are purged after 24 hours.

## Performance Monitoring Security

- Monitoring dashboards require admin authentication.
- Metrics endpoints are not publicly accessible.
- Log aggregation sanitizes PII before storage.
- APM traces do not capture request bodies containing passwords.

## Optimization Tradeoffs

| Optimization | Security Impact | Acceptable? |
|-------------|----------------|-------------|
| Full-page cache | May serve stale auth state | Only for public pages |
| Query cache | May expose stale permissions | Short TTL, user-scoped |
| CDN static cache | None for static assets | Yes |
| Lazy loading | None | Yes |
| Code splitting | None | Yes |
| Read replicas | Slight replication lag | Acceptable for reads |

# Conclusion

Performance optimization in GsmUi is applied systematically across frontend, backend, and infrastructure layers. The multi-tier caching strategy—Redis application cache, HTTP cache via Vite, database query cache, and CDN edge cache—ensures that repeated requests are served in under 150ms.

Key performance pillars:

1. **Measurement first**: Lighthouse scores above 95, database queries under 50ms, and initial page loads under 2 seconds are enforced through CI/CD benchmarks.
2. **Layered caching**: Each cache layer has clear ownership, TTL policies, and invalidation strategies tied to the module that owns the data.
3. **Queue isolation**: High-priority payment and authentication jobs run on dedicated worker pools, preventing slow analytics jobs from blocking critical paths.
4. **Security-conscious optimization**: Cache poisoning, data leakage, and stale auth states are mitigated through signed entries, user-scoped tags, and short TTLs.

Future improvements will push rendering to the edge, leverage predictive prefetching, and adopt WebAssembly for compute-intensive operations, ensuring the platform remains fast as it scales to millions of users.

### Image Optimization Pipeline

```php
<?php

namespace App\Performance\Images;

use Intervention\Image\ImageManager;
use Illuminate\Support\Facades\File;

class ImageOptimizer
{
    private ImageManager $manager;
    private array $formats = ['webp', 'avif', 'jpg', 'png'];
    private array $qualities = ['webp' => 85, 'avif' => 80, 'jpg' => 85, 'png' => 90];

    public function __construct()
    {
        $this->manager = new ImageManager(['driver' => 'gd']);
    }

    public function optimize(string $sourcePath, string $outputDir): array
    {
        if (!file_exists($sourcePath)) {
            throw new \RuntimeException("Source image not found: {$sourcePath}");
        }

        $image = $this->manager->read($sourcePath);
        $filename = pathinfo($sourcePath, PATHINFO_FILENAME);
        $results = [];

        // Generate responsive sizes
        $sizes = [320, 640, 768, 1024, 1280, 1920];

        foreach ($sizes as $width) {
            if ($image->width() <= $width) {
                $resized = $image->resize($width, null, function ($constraint) {
                    $constraint->aspectRatio();
                    $constraint->upsize();
                });
            } else {
                $resized = $image->resize($width, null, function ($constraint) {
                    $constraint->aspectRatio();
                    $constraint->upsize();
                });
            }

            // Generate WebP
            $webpPath = "{$outputDir}/{$filename}-{$width}w.webp";
            $resized->toWebp($this->qualities['webp'])->save($webpPath);
            $results[] = [
                'format' => 'webp',
                'width' => $width,
                'path' => $webpPath,
                'size' => filesize($webpPath),
            ];

            // Generate AVIF (if GD supports it)
            if (function_exists('imageavif')) {
                $avifPath = "{$outputDir}/{$filename}-{$width}w.avif";
                $resized->toAvif($this->qualities['avif'])->save($avifPath);
                $results[] = [
                    'format' => 'avif',
                    'width' => $width,
                    'path' => $avifPath,
                    'size' => filesize($avifPath),
                ];
            }

            // Generate JPEG fallback
            $jpgPath = "{$outputDir}/{$filename}-{$width}w.jpg";
            $resized->toJpeg($this->qualities['jpg'])->save($jpgPath);
            $results[] = [
                'format' => 'jpg',
                'width' => $width,
                'path' => $jpgPath,
                'size' => filesize($jpgPath),
            ];
        }

        // Generate srcset HTML
        $srcset = $this->generateSrcset($filename, $results);

        return [
            'original' => $sourcePath,
            'original_size' => filesize($sourcePath),
            'optimized' => $results,
            'total_optimized_size' => array_sum(array_column($results, 'size')),
            'savings_percent' => round(
                (1 - array_sum(array_column($results, 'size')) / filesize($sourcePath)) * 100, 1
            ),
            'srcset' => $srcset,
        ];
    }

    private function generateSrcset(string $filename, array $results): string
    {
        $entries = [];

        foreach ($results as $result) {
            $entries[] = "{$result['path']} {$result['width']}w";
        }

        return implode(', ', $entries);
    }

    public function generatePictureElement(array $optimizedImages, string $alt = ''): string
    {
        $webpSrcset = implode(', ', array_map(
            fn($img) => "{$img['path']} {$img['width']}w",
            array_filter($optimizedImages, fn($img) => $img['format'] === 'webp')
        ));

        $avifSrcset = implode(', ', array_map(
            fn($img) => "{$img['path']} {$img['width']}w",
            array_filter($optimizedImages, fn($img) => $img['format'] === 'avif')
        ));

        $jpgSrcset = implode(', ', array_map(
            fn($img) => "{$img['path']} {$img['width']}w",
            array_filter($optimizedImages, fn($img) => $img['format'] === 'jpg')
        ));

        $maxWidth = max(array_column($optimizedImages, 'width'));

        return <<<HTML
<picture>
    <source srcset="{$avifSrcset}" type="image/avif">
    <source srcset="{$webpSrcset}" type="image/webp">
    <img src="{$jpgSrcset}" srcset="{$jpgSrcset}" alt="{$alt}" width="{$maxWidth}" loading="lazy" decoding="async">
</picture>
HTML;
    }
}
```

# Backend Performance

## Query Optimization

### N+1 Detection and Prevention

```php
<?php

namespace App\Performance\Database;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;

class QueryOptimizer
{
    private array $queryLog = [];
    private int $nPlusOneThreshold = 10;

    public function enableQueryLogging(): void
    {
        DB::listen(function ($query) {
            $this->queryLog[] = [
                'sql' => $query->sql,
                'bindings' => $query->bindings,
                'time' => $query->time,
                'trace' => debug_backtrace(DEBUG_BACKTRACE_IGNORE_ARGS, 5),
            ];
        });
    }

    public function detectNPlusOne(): array
    {
        $similarQueries = [];

        foreach ($this->queryLog as $log) {
            $normalized = $this->normalizeQuery($log['sql']);
            $similarQueries[$normalized][] = $log;
        }

        $nPlusOneIssues = [];

        foreach ($similarQueries as $normalized => $queries) {
            if (count($queries) >= $this->nPlusOneThreshold) {
                $nPlusOneIssues[] = [
                    'query_pattern' => $normalized,
                    'count' => count($queries),
                    'total_time_ms' => array_sum(array_column($queries, 'time')),
                    'avg_time_ms' => array_sum(array_column($queries, 'time')) / count($queries),
                    'sample_trace' => $queries[0]['trace'],
                ];
            }
        }

        usort($nPlusOneIssues, fn($a, $b) => $b['count'] <=> $a['count']);

        return $nPlusOneIssues;
    }

    public function analyzeSlowQueries(float $thresholdMs = 100): array
    {
        $slowQueries = array_filter($this->queryLog, fn($log) => $log['time'] > $thresholdMs);

        $analysis = [];

        foreach ($slowQueries as $query) {
            $normalized = $this->normalizeQuery($query['sql']);

            $analysis[] = [
                'query' => $query['sql'],
                'normalized' => $normalized,
                'time_ms' => $query['time'],
                'bindings' => $query['bindings'],
                'suggestion' => $this->suggestOptimization($query['sql']),
            ];
        }

        usort($analysis, fn($a, $b) => $b['time_ms'] <=> $a['time_ms']);

        return $analysis;
    }

    public function getQueryStats(): array
    {
        $stats = [
            'total_queries' => count($this->queryLog),
            'total_time_ms' => array_sum(array_column($this->queryLog, 'time')),
            'avg_time_ms' => 0,
            'slowest_query' => null,
            'by_type' => ['select' => 0, 'insert' => 0, 'update' => 0, 'delete' => 0],
        ];

        if ($stats['total_queries'] > 0) {
            $stats['avg_time_ms'] = $stats['total_time_ms'] / $stats['total_queries'];
        }

        foreach ($this->queryLog as $log) {
            $type = strtolower(substr(trim($log['sql']), 0, 6));
            if (str_starts_with($type, 'select')) $stats['by_type']['select']++;
            elseif (str_starts_with($type, 'insert')) $stats['by_type']['insert']++;
            elseif (str_starts_with($type, 'update')) $stats['by_type']['update']++;
            elseif (str_starts_with($type, 'delete')) $stats['by_type']['delete']++;
        }

        $stats['slowest_query'] = $this->queryLog
            ? max($this->queryLog, fn($q) => $q['time'])
            : null;

        return $stats;
    }

    private function normalizeQuery(string $sql): string
    {
        $normalized = preg_replace('/\?/', '?', $sql);
        $normalized = preg_replace('/\b\d+\b/', '?', $normalized);
        $normalized = preg_replace('/\s+/', ' ', $normalized);
        return trim($normalized);
    }

    private function suggestOptimization(string $sql): string
    {
        $suggestions = [];

        if (preg_match('/WHERE.*LIKE/', $sql)) {
            $suggestions[] = 'Consider adding a full-text index for LIKE queries';
        }

        if (preg_match('/ORDER BY.*RANDOM/i', $sql)) {
            $suggestions[] = 'ORDER BY RAND() is slow; consider alternative approaches';
        }

        if (!preg_match('/LIMIT/', $sql) && preg_match('/SELECT.*FROM/is', $sql)) {
            $suggestions[] = 'Consider adding a LIMIT clause';
        }

        if (preg_match('/SELECT \*/', $sql)) {
            $suggestions[] = 'Select only needed columns instead of *';
        }

        return implode('; ', $suggestions) ?: 'No specific optimization suggestions';
    }
}
```

```php
<?php

namespace App\Performance\Queue;

use Illuminate\Support\Facades\Queue;
use Illuminate\Support\Facades\Redis;
use Illuminate\Queue\QueueManager;

class QueueMonitor
{
    private QueueManager $queue;

    public function __construct(QueueManager $queue)
    {
        $this->queue = $queue;
    }

    public function getQueueStats(): array
    {
        $connection = config('queue.default');
        $queues = config('queue.connections.' . $connection . '.queues', ['default']);

        $stats = [];

        foreach ($queues as $queueName) {
            $stats[$queueName] = [
                'depth' => $this->getQueueDepth($connection, $queueName),
                'processing' => $this->getProcessingCount($connection, $queueName),
                'failed' => $this->getFailedCount($connection, $queueName),
                'oldest_job_age_seconds' => $this->getOldestJobAge($connection, $queueName),
            ];
        }

        return [
            'connection' => $connection,
            'queues' => $stats,
            'total_depth' => array_sum(array_column($stats, 'depth')),
            'total_processing' => array_sum(array_column($stats, 'processing')),
            'total_failed' => array_sum(array_column($stats, 'failed')),
        ];
    }

    public function getWorkerStats(): array
    {
        $connection = config('queue.default');

        return [
            'connection' => $connection,
            'workers' => $this->getActiveWorkers($connection),
            'total_workers' => count($this->getActiveWorkers($connection)),
        ];
    }

    private function getQueueDepth(string $connection, string $queue): int
    {
        $redis = Redis::connection($connection);
        return $redis->llen("queues:{$queue}") ?? 0;
    }

    private function getProcessingCount(string $connection, string $queue): int
    {
        $redis = Redis::connection($connection);
        return $redis->llen("queues:{$queue}:processing") ?? 0;
    }

    private function getFailedCount(string $connection, string $queue): int
    {
        return \App\Models\FailedJob::where('queue', $queue)->count();
    }

    private function getOldestJobAge(string $connection, string $queue): ?int
    {
        $redis = Redis::connection($connection);
        $job = $redis->lindex("queues:{$queue}", -1);

        if (!$job) {
            return null;
        }

        $payload = json_decode($job, true);
        $createdAt = $payload['data']['command'] ?? null;

        if ($createdAt && isset($createdAt['createdAt'])) {
            return now()->diffInSeconds(\Carbon\Carbon::parse($createdAt['createdAt']));
        }

        return null;
    }

    private function getActiveWorkers(string $connection): array
    {
        $workers = [];
        $prefix = config("queue.connections.{$connection}.prefix", '');

        $workerKeys = Redis::keys("{$prefix}laravel_worker_*");

        foreach ($workerKeys as $key) {
            $workerData = Redis::hgetall($key);
            if (!empty($workerData)) {
                $workers[] = [
                    'id' => basename($key),
                    'status' => $workerData['status'] ?? 'unknown',
                    'queue' => $workerData['queue'] ?? 'default',
                    'pid' => $workerData['pid'] ?? null,
                    'started_at' => $workerData['started_at'] ?? null,
                ];
            }
        }

        return $workers;
    }
}
```

```php
<?php

namespace App\Performance\Database;

use Illuminate\Support\Facades\DB;

class IndexAnalyzer
{
    public function analyzeMissingIndexes(): array
    {
        $tables = DB::select('SHOW TABLES');
        $dbName = DB::getDatabaseName();
        $recommendations = [];

        foreach ($tables as $table) {
            $tableName = $table->{"Tables_in_{$dbName}"} ?? reset($table);
            $tableRecs = $this->analyzeTable($tableName);
            $recommendations = array_merge($recommendations, $tableRecs);
        }

        return $recommendations;
    }

    public function analyzeUnusedIndexes(): array
    {
        $unused = [];

        $indexes = DB::select("
            SELECT 
                s.TABLE_NAME,
                s.INDEX_NAME,
                s.COLUMN_NAME,
                s.SEQ_IN_INDEX
            FROM information_schema.STATISTICS s
            LEFT JOIN performance_schema.table_io_waits_summary_by_index_usage io
                ON s.TABLE_SCHEMA = io.OBJECT_SCHEMA
                AND s.TABLE_NAME = io.OBJECT_NAME
                AND s.INDEX_NAME = io.INDEX_NAME
            WHERE s.TABLE_SCHEMA = ?
            AND io.COUNT_READ = 0
            AND s.INDEX_NAME != 'PRIMARY'
            ORDER BY s.TABLE_NAME, s.INDEX_NAME
        ", [$dbName]);

        foreach ($indexes as $index) {
            $unused[] = [
                'table' => $index->TABLE_NAME,
                'index' => $index->INDEX_NAME,
                'column' => $index->COLUMN_NAME,
                'recommendation' => "DROP INDEX `{$index->INDEX_NAME}` ON `{$index->TABLE_NAME}`",
            ];
        }

        return $unused;
    }

    public function getTableStats(): array
    {
        $tables = DB::select('SHOW TABLES');
        $dbName = DB::getDatabaseName();
        $stats = [];

        foreach ($tables as $table) {
            $tableName = $table->{"Tables_in_{$dbName}"} ?? reset($table);

            $rowEstimate = DB::select("SELECT TABLE_ROWS, DATA_LENGTH, INDEX_LENGTH FROM information_schema.TABLES WHERE TABLE_SCHEMA = ? AND TABLE_NAME = ?", [$dbName, $tableName]);

            if (!empty($rowEstimate)) {
                $stats[] = [
                    'table' => $tableName,
                    'estimated_rows' => $rowEstimate[0]->TABLE_ROWS,
                    'data_size_mb' => round($rowEstimate[0]->DATA_LENGTH / 1024 / 1024, 2),
                    'index_size_mb' => round($rowEstimate[0]->INDEX_LENGTH / 1024 / 1024, 2),
                    'fragmentation_percent' => $rowEstimate[0]->DATA_LENGTH > 0
                        ? round((1 - ($rowEstimate[0]->DATA_LENGTH / max($rowEstimate[0]->DATA_LENGTH, 1))) * 100, 2)
                        : 0,
                ];
            }
        }

        usort($stats, fn($a, $b) => $b['data_size_mb'] <=> $a['data_size_mb']);

        return $stats;
    }

    private function analyzeTable(string $tableName): array
    {
        $recommendations = [];

        $indexes = DB::select("SHOW INDEX FROM `{$tableName}`");
        $columns = DB::select("SHOW COLUMNS FROM `{$tableName}`");

        $indexedColumns = array_column($indexes, 'Column_name');
        $allColumns = array_column($columns, 'Field');

        $foreignKeys = DB::select("
            SELECT COLUMN_NAME
            FROM information_schema.KEY_COLUMN_USAGE
            WHERE TABLE_SCHEMA = ? AND TABLE_NAME = ? AND REFERENCED_TABLE_NAME IS NOT NULL
        ", [DB::getDatabaseName(), $tableName]);

        $fkColumns = array_column($foreignKeys, 'COLUMN_NAME');

        foreach ($fkColumns as $fkColumn) {
            if (!in_array($fkColumn, $indexedColumns)) {
                $recommendations[] = [
                    'table' => $tableName,
                    'type' => 'missing_index',
                    'column' => $fkColumn,
                    'reason' => 'Foreign key column lacks an index',
                    'recommendation' => "CREATE INDEX `idx_{$tableName}_{$fkColumn}` ON `{$tableName}` (`{$fkColumn}`)",
                    'priority' => 'high',
                ];
            }
        }

        return $recommendations;
    }
}
```

## Query Cache Strategy

### Cache Manager

```php
<?php

namespace App\Performance\Cache;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\DB;

class QueryCacheManager
{
    private int $defaultTtl = 300;
    private array $ttlConfig = [
        'components' => 600,
        'users' => 120,
        'categories' => 3600,
        'settings' => 1800,
        'analytics' => 60,
    ];

    public function remember(string $key, callable $callback, ?int $ttl = null): mixed
    {
        $actualTtl = $ttl ?? $this->getTtl($key);

        return Cache::tags(['query_cache'])->remember(
            "query:{$key}",
            $actualTtl,
            function () use ($callback) {
                $start = microtime(true);
                $result = $callback();
                $duration = (microtime(true) - $start) * 1000;

                if ($duration > 50) {
                    \Illuminate\Support\Facades\Log::channel('performance')->info('Slow query cached', [
                        'key' => $key,
                        'duration_ms' => $duration,
                    ]);
                }

                return $result;
            }
        );
    }

    public function invalidate(string $pattern): void
    {
        $keys = Cache::tags(['query_cache'])->keys();

        foreach ($keys as $key) {
            if (fnmatch($pattern, $key)) {
                Cache::tags(['query_cache'])->forget($key);
            }
        }
    }

    public function invalidateForModel(string $model): void
    {
        $this->invalidate("query:*{$model}*");
    }

    public function flush(): void
    {
        Cache::tags(['query_cache'])->flush();
    }

    public function getStats(): array
    {
        $hitRate = Cache::tags(['query_cache'])->get('stats:hit_rate', 0);
        $totalQueries = Cache::tags(['query_cache'])->get('stats:total_queries', 0);
        $cachedQueries = Cache::tags(['query_cache'])->get('stats:cached_queries', 0);

        return [
            'hit_rate' => $hitRate,
            'total_queries' => $totalQueries,
            'cached_queries' => $cachedQueries,
            'cache_size_keys' => count(Cache::tags(['query_cache'])->keys()),
        ];
    }

    public function warmCache(): void
    {
        $this->warmComponentsCache();
        $this->warmCategoriesCache();
        $this->warmSettingsCache();
    }

    private function warmComponentsCache(): void
    {
        $components = DB::table('components')
            ->where('status', 'published')
            ->get();

        foreach ($components as $component) {
            Cache::tags(['query_cache'])->put(
                "query:component:{$component->slug}",
                $component,
                $this->ttlConfig['components']
            );
        }
    }

    private function warmCategoriesCache(): void
    {
        $categories = DB::table('categories')->get();

        Cache::tags(['query_cache'])->put(
            'query:categories:all',
            $categories,
            $this->ttlConfig['categories']
        );
    }

    private function warmSettingsCache(): void
    {
        $settings = DB::table('settings')->pluck('value', 'key')->toArray();

        Cache::tags(['query_cache'])->put(
            'query:settings:all',
            $settings,
            $this->ttlConfig['settings']
        );
    }

    private function getTtl(string $key): int
    {
        foreach ($this->ttlConfig as $pattern => $ttl) {
            if (str_contains($key, $pattern)) {
                return $ttl;
            }
        }

        return $this->defaultTtl;
    }
}
```

```php
        $recent = Cache::get($recentKey, []);
        $recent[] = ['value' => $value, 'time' => now()->timestamp];

        Cache::put($recentKey, $recent, now()->addHours(2));

            $values = array_column($recent, 'value');
            sort($values);
            Cache::put("{$key}:p95", $values[(int)(count($values) * 0.95)], now()->addHour());
        }
    }
```

## Service Worker

```javascript
// sw.js
const CACHE_NAME = 'gsmui-v1';
const STATIC_CACHE = 'gsmui-static-v1';
const DYNAMIC_CACHE = 'gsmui-dynamic-v1';

const STATIC_ASSETS = [
    '/',
    '/css/gsmui.css',
    '/js/gsmui.js',
    '/offline',
];

self.addEventListener('install', (event) => {
    event.waitUntil(
        caches.open(STATIC_CACHE).then((cache) => {
            return cache.addAll(STATIC_ASSETS);
        })
    );
    self.skipWaiting();
});

self.addEventListener('activate', (event) => {
    event.waitUntil(
        caches.keys().then((cacheNames) => {
            return Promise.all(
                cacheNames
                    .filter((name) => name !== STATIC_CACHE && name !== DYNAMIC_CACHE)
                    .map((name) => caches.delete(name))
            );
        })
    );
    self.clients.claim();
});

self.addEventListener('fetch', (event) => {
    const { request } = event;
    const url = new URL(request.url);

    // Skip non-GET requests
    if (request.method !== 'GET') return;

    // Skip API requests
    if (url.pathname.startsWith('/api/')) return;

    // Skip Livewire requests
    if (url.pathname.startsWith('/livewire/')) return;

    // Cache-first for static assets
    if (STATIC_ASSETS.some((asset) => url.pathname === asset)) {
        event.respondWith(
            caches.match(request).then((cached) => {
                return cached || fetch(request).then((response) => {
                    return caches.open(STATIC_CACHE).then((cache) => {
                        cache.put(request, response.clone());
                        return response;
                    });
                });
            })
        );
        return;
    }

    // Network-first for HTML pages
    if (request.headers.get('accept').includes('text/html')) {
        event.respondWith(
            fetch(request)
                .then((response) => {
                    return caches.open(DYNAMIC_CACHE).then((cache) => {
                        cache.put(request, response.clone());
                        return response;
                    });
                })
                .catch(() => {
                    return caches.match(request).then((cached) => {
                        return cached || caches.match('/offline');
                    });
                })
        );
        return;
    }

    // Cache-first for images
    if (request.destination === 'image') {
        event.respondWith(
            caches.match(request).then((cached) => {
                return cached || fetch(request).then((response) => {
                    return caches.open(DYNAMIC_CACHE).then((cache) => {
                        cache.put(request, response.clone());
                        return response;
                    });
                });
            })
        );
        return;
    }

    // Stale-while-revalidate for other resources
    event.respondWith(
        caches.match(request).then((cached) => {
            const fetchPromise = fetch(request).then((response) => {
                return caches.open(DYNAMIC_CACHE).then((cache) => {
                    cache.put(request, response.clone());
                    return response;
                });
            });

            return cached || fetchPromise;
        })
    );
});
```

# Advanced Alert Routing

## Multi-Channel Alert Routing

The alert routing system supports escalation chains, quiet hours, and per-team notification preferences.

```php
<?php

namespace App\Monitoring\Alerting;

use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Notification;

class AlertRouter
{
    private array $severityConfig = [
        'critical' => [
            'channels' => ['pagerduty', 'slack', 'email', 'sms'],
            'escalation_delay_minutes' => 5,
            'acknowledgment_timeout_minutes' => 15,
            'auto_escalate_after_minutes' => 30,
        ],
        'warning' => [
            'channels' => ['slack', 'email'],
            'escalation_delay_minutes' => 15,
            'acknowledgment_timeout_minutes' => 60,
            'auto_escalate_after_minutes' => 120,
        ],
        'info' => [
            'channels' => ['slack'],
            'escalation_delay_minutes' => 60,
            'acknowledgment_timeout_minutes' => null,
            'auto_escalate_after_minutes' => null,
        ],
    ];

    public function routeAlert(Alert $alert): array
    {
        $config = $this->severityConfig[$alert->severity] ?? $this->severityConfig['info'];

        if ($this->isInQuietHours($alert)) {
            $this->queueForQuietHours($alert, $config);
            return ['status' => 'queued', 'reason' => 'quiet_hours'];
        }

        $recipients = $this->getRecipients($alert);
        $notifications = [];

        foreach ($config['channels'] as $channel) {
            $channelRecipients = $this->filterRecipientsForChannel($recipients, $channel);

            foreach ($channelRecipients as $recipient) {
                $notification = $this->sendNotification($alert, $channel, $recipient);
                $notifications[] = $notification;
            }
        }

        $this->scheduleEscalation($alert, $config);

        return [
            'status' => 'sent',
            'notifications' => $notifications,
            'recipients' => count($recipients),
        ];
    }

    public function acknowledgeAlert(string $alertId, string $userId): bool
    {
        return DB::table('alerts')
            ->where('id', $alertId)
            ->where('status', 'active')
            ->update([
                'acknowledged_by' => $userId,
                'acknowledged_at' => now(),
                'status' => 'acknowledged',
            ]) > 0;
    }

    public function resolveAlert(string $alertId, string $resolution): bool
    {
        return DB::table('alerts')
            ->where('id', $alertId)
            ->update([
                'resolved_at' => now(),
                'resolution' => $resolution,
                'status' => 'resolved',
            ]) > 0;
    }

    private function isInQuietHours(Alert $alert): bool
    {
        $quietStart = (int) config('monitoring.quiet_hours.start', 22);
        $quietEnd = (int) config('monitoring.quiet_hours.end', 7);
        $currentHour = (int) now()->format('H');

        if ($quietStart > $quietEnd) {
            return $currentHour >= $quietStart || $currentHour < $quietEnd;
        }

        return $currentHour >= $quietStart && $currentHour < $quietEnd;
    }

    private function queueForQuietHours(Alert $alert, array $config): void
    {
        DB::table('alert_queue')->insert([
            'alert_id' => $alert->id,
            'severity' => $alert->severity,
            'config' => json_encode($config),
            'queued_at' => now(),
            'deliver_after' => $this->getNextQuietHoursEnd(),
        ]);
    }

    private function getNextQuietHoursEnd(): \Carbon\Carbon
    {
        $quietEnd = (int) config('monitoring.quiet_hours.end', 7);
        $nextEnd = now()->copy()->startOfDay()->addHours($quietEnd);

        if ($nextEnd->isPast()) {
            $nextEnd->addDay();
        }

        return $nextEnd;
    }

    private function getRecipients(Alert $alert): array
    {
        $teamRecipients = DB::table('team_members')
            ->where('team_id', $alert->team_id)
            ->where('receives_alerts', true)
            ->get();

        $onCall = DB::table('oncall_schedules')
            ->where('start_date', '<=', now())
            ->where('end_date', '>=', now())
            ->first();

        $recipients = [];

        foreach ($teamRecipients as $member) {
            $recipients[] = [
                'user_id' => $member->user_id,
                'channels' => json_decode($member->notification_channels, true),
                'role' => $member->role,
            ];
        }

        if ($onCall) {
            $recipients[] = [
                'user_id' => $onCall->engineer_id,
                'channels' => ['pagerduty', 'sms', 'slack'],
                'role' => 'oncall',
            ];
        }

        return $recipients;
    }

    private function filterRecipientsForChannel(array $recipients, string $channel): array
    {
        return array_filter($recipients, function ($recipient) use ($channel) {
            return in_array($channel, $recipient['channels'] ?? []);
        });
    }

    private function sendNotification(Alert $alert, string $channel, array $recipient): array
    {
        $notificationClass = match ($channel) {
            'pagerduty' => PagerDutyNotification::class,
            'slack' => SlackAlertNotification::class,
            'email' => EmailAlertNotification::class,
            'sms' => SmsAlertNotification::class,
        };

        Notification::send(
            \App\Models\User::find($recipient['user_id']),
            new $notificationClass($alert)
        );

        DB::table('alert_notifications')->insert([
            'alert_id' => $alert->id,
            'channel' => $channel,
            'recipient_id' => $recipient['user_id'],
            'sent_at' => now(),
        ]);

        return [
            'channel' => $channel,
            'recipient_id' => $recipient['user_id'],
            'sent_at' => now()->toIso8601String(),
        ];
    }

    private function scheduleEscalation(Alert $alert, array $config): void
    {
        if (!$config['auto_escalate_after_minutes']) {
            return;
        }

        DB::table('alert_escalations')->insert([
            'alert_id' => $alert->id,
            'escalation_level' => 1,
            'scheduled_for' => now()->addMinutes($config['auto_escalate_after_minutes']),
            'status' => 'pending',
        ]);
    }
}
```

```php
        return response()->json([

            'message' => 'Alert resolved',
        ]);
    }

    {
        $windows = MaintenanceWindow::query()
            ->where('end_time', '>=', now())
            ->orderBy('start_time')
            ->get();

        return response()->json([
            'status' => 'ok',
            'data' => $windows,
        ]);
    }

    public function createMaintenance(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'title' => 'required|string|max:200',
            'description' => 'sometimes|string|max:1000',
            'start_time' => 'required|date|after:now',
            'end_time' => 'required|date|after:start_time',
            'affected_services' => 'required|array',
            'notify_users' => 'sometimes|boolean',

            'active' => Alert::where('status', 'active')->count(),
            'acknowledged' => Alert::where('status', 'acknowledged')->count(),
            'resolved_today' => Alert::where('status', 'resolved')
                ->whereDate('resolved_at', today())
                ->count(),
            'by_severity' => [
                'critical' => Alert::where('status', 'active')->where('severity', 'critical')->count(),
                'warning' => Alert::where('status', 'active')->where('severity', 'warning')->count(),
                'info' => Alert::where('status', 'active')->where('severity', 'info')->count(),
            ],
            'mttr_minutes' => $this->calculateMTTR(),
        ];
    }

    private function calculateMTTR(): float
    {
        $resolved = Alert::where('status', 'resolved')
            ->where('resolved_at', '>=', now()->subDays(7))
            ->get();

        if ($resolved->isEmpty()) {
            return 0;
        }

        $totalMinutes = $resolved->sum(function ($alert) {
            return $alert->created_at->diffInMinutes($alert->resolved_at);
        });

        return round($totalMinutes / $resolved->count(), 1);
    }
}
```

```php
<?php

            'cache' => $this->getCacheSummary($period),
            'queue' => $this->getQueueSummary($period),

        return [
            'healthy' => $usedPercent < 90,
            'message' => round($usedPercent, 1) . '% used',
        ];
    }
```

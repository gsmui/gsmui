# Purpose

The Theme Engine is responsible for creating, managing, previewing, exporting, and applying themes across the entire GsmUi ecosystem.

Unlike a traditional CSS theme switcher, the GsmUi Theme Engine is a **Design Token Platform** that generates consistent UI across:

* Components
* Templates
* Documentation
* Admin Panel
* Dashboard
* Marketplace
* Playground
* Charts
* Blog
* Future Mobile Apps

The Theme Engine is built around **design tokens**, making it future-proof and extensible.

# Risk

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Token schema becomes too complex | Medium | High | Start with 5 core token groups (colors, typography, radius, shadows, spacing). Add groups incrementally based on real usage patterns. |
| CSS compilation performance degrades with large themes | Medium | Medium | Implement incremental compilation — only regenerate changed token groups. Cache intermediate results. |
| Theme inheritance chains create circular references | Low | High | Enforce DAG (directed acyclic graph) constraint at the database level. Validate inheritance chain on save. |
| Tailwind CSS v4 API changes break exports | Medium | High | Abstract Tailwind integration behind an interface. Pin to specific Tailwind version per GsmUi release. |
| Accessibility validation produces false positives | Medium | Low | Use established libraries (axe-core). Allow manual override with documented reasoning. |
| Theme marketplace piracy (sharing premium themes) | High | Medium | Encrypted theme packages with license-bound decryption keys. Watermark exported CSS with license tokens. |
| Scope creep into full design tool (Figma competitor) | High | High | Strictly limit scope to token-based themes. No vector editing, no layout tools. Theme Builder = token editor, not design tool. |
| Dark mode token duplication doubles storage | Low | Low | Support token overrides per mode. Only store deltas from light mode defaults. |

# Theme Engine Deep Dive

## Token Resolution Order

When a component renders, tokens are resolved in this order:

1. Component-level token overrides
2. Active theme tokens
3. Inherited theme tokens (parent chain)
4. Default fallback tokens

This ensures every component always has a valid token value.

### Builder State Management

```php id="tbuilder02"
class ThemeBuilder extends Component
{
    public Theme $theme;
    public array $tokens = [];
    public string $activeGroup = 'colors';
    public bool $hasUnsavedChanges = false;

    public function mount(int $themeId): void
    {
        $this->theme = Theme::with('tokens')->findOrFail($themeId);
        $this->tokens = $this->theme->tokens
            ->pluck('value', 'key')->toArray();
    }

    public function updateToken(string $key, string $value): void
    {
        $this->tokens[$key] = $value;
        $this->hasUnsavedChanges = true;
    }

    public function save(): void
    {
        $this->theme->updateTokens($this->tokens);
        $this->theme->compile();
        $this->hasUnsavedChanges = false;
    }
}
```

### Token Resolution

When resolving a token, the engine traverses the inheritance chain.

```php id="tinherit02"
class TokenResolver
{
    public function resolve(Theme $theme, string $key): string
    {
        if ($token = $theme->tokens()->where('key', $key)->first()) {
            return $token->value;
        }

        if ($theme->parent) {
            return $this->resolve($theme->parent, $key);
        }

        return $this->defaults[$key] ?? '';
    }

    public function resolveAll(Theme $theme): array
    {
        $tokens = $this->defaults;
        $chain = $theme->inheritanceChain();

        foreach ($chain as $t) {
            $tokens = array_merge(
                $tokens,
                $t->tokens->pluck('value', 'key')->toArray()
            );
        }

        return $tokens;
    }
}
```

### Inheritance Validation

Prevent circular references with DAG validation.

```php id="tinherit03"
class InheritanceValidator
{
    public function validate(Theme $theme, int $parentId): bool
    {
        $chain = $this->getChain($parentId);

        if (in_array($theme->id, $chain)) {
            throw new CircularInheritanceException();
        }

        if (count($chain) >= 5) {
            throw new MaxInheritanceDepthException();
        }

        return true;
    }

    private function getChain(int $themeId): array
    {
        $chain = [];
        $current = Theme::find($themeId);

        while ($current && $current->parent_id) {
            $chain[] = $current->parent_id;
            $current = $current->parent;
        }

        return $chain;
    }
}
```

## Accessibility Validation

### Color Contrast Checker

```php id="taccess01"
class ContrastChecker
{
    public function check(string $fg, string $bg): array
    {
        $fgLum = $this->relativeLuminance($fg);
        $bgLum = $this->relativeLuminance($bg);

        $ratio = (max($fgLum, $bgLum) + 0.05)
               / (min($fgLum, $bgLum) + 0.05);

        return [
            'ratio' => round($ratio, 2),
            'aa_normal' => $ratio >= 4.5,
            'aa_large' => $ratio >= 3,
            'aaa_normal' => $ratio >= 7,
            'aaa_large' => $ratio >= 4.5,
        ];
    }
}
```

### Compilation Job

```php id="tcompile02"
class CompileTheme implements ShouldQueue
{
    public int $tries = 3;
    public int $timeout = 120;

    public function handle(Theme $theme): void
    {
        $resolver = app(TokenResolver::class);
        $compiler = app(ThemeCompiler::class);

        $tokens = $resolver->resolveAll($theme);
        $css = $compiler->compile($tokens);
        $darkCss = $compiler->compileDark($tokens);
        $tailwind = $compiler->generateTailwindConfig($tokens);
        $json = $compiler->generateJson($tokens);

        Storage::disk('themes')
            ->put("{$theme->slug}/theme.css", $css);
        Storage::disk('themes')
            ->put("{$theme->slug}/theme-dark.css", $darkCss);
        Storage::disk('themes')
            ->put("{$theme->slug}/tailwind.theme.js", $tailwind);
        Storage::disk('themes')
            ->put("{$theme->slug}/tokens.json", $json);
    }
}
```

```php id="tver03"
    public function rollback(Theme $theme, string $version): void
    {
        $target = $theme->versions()
            ->where('version', $version)
            ->firstOrFail();

        $theme->update([
            'compiled_css' => $target->compiled_css,
```

## Theme Compiler Implementation

### CSS Generation Algorithm

```php id="tcomp01"
class ThemeCompiler
{
    public function compile(array $tokens): string
    {
        $css = ":root {\n";

        foreach ($tokens as $key => $value) {
            $css .= "  --gsm-{$key}: {$value};\n";
        }

        $css .= "}\n";

        return $this->minify($css);
    }

    public function compileDark(array $tokens): string
    {
        $css = ".dark {\n";

        foreach ($this->darkOverrides as $key => $value) {
            $css .= "  --gsm-{$key}: {$value};\n";
        }

        $css .= "}\n";

        return $this->minify($css);
    }

    private function minify(string $css): string
    {
        $css = preg_replace('/\s+/', ' ', $css);
        $css = preg_replace('/\s*([{}:;,])\s*/', '$1', $css);
        $css = preg_replace('/;}/', '}', $css);
        return trim($css);
    }
}
```

### Inheritance Chain Builder

```php id="tinherit05"
class InheritanceChainBuilder
{
    public function build(Theme $theme): array
    {
        $chain = [];
        $current = $theme;

        while ($current) {
            $chain[] = $current;
            $current = $current->parent;
        }

        return $chain;
    }

    public function resolveTokens(Theme $theme): array
    {
        $chain = $this->build($theme);
        $tokens = $this->defaults;

        // Apply tokens from parent to child (child wins)
        foreach (array_reverse($chain) as $t) {
            foreach ($t->tokens as $token) {
                $tokens["{$token->group}.{$token->key}"] = $token->value;
            }
        }

        return $tokens;
    }
}
```

## Theme Versioning System

### Version Management

```php id="tver04"
class ThemeVersionManager
{
    public function publish(Theme $theme, array $tokens): ThemeVersion
    {
        $version = $theme->versions()->latest()->first();
        $newVersion = $this->calculateNextVersion(
            $version?->version ?? '1.0.0',
            $this->determineChangeType($tokens)
        );

        $compiled = $this->compiler->compile($tokens);

        return $theme->versions()->create([
            'version' => $newVersion,
            'compiled_css' => $compiled['light'],
            'compiled_dark_css' => $compiled['dark'],
            'compiled_json' => $compiled['json'],
            'compiled_tailwind' => $compiled['tailwind'],
            'published_at' => now(),
        ]);
    }

    private function calculateNextVersion(string $current, string $type): string
    {
        $parts = explode('.', $current);

        return match ($type) {
            'major' => ((int)$parts[0] + 1) . '.0.0',
            'minor' => $parts[0] . '.' . ((int)$parts[1] + 1) . '.0',
            'patch' => $parts[0] . '.' . $parts[1] . '.' . ((int)$parts[2] + 1),
        };
    }
}
```

### Export Service

```php id="texp01"
class ThemeExportService
{
    public function export(Theme $theme, string $format): string
    {
        return match ($format) {
            'css' => $this->exportCss($theme),
            'json' => $this->exportJson($theme),
            'tailwind' => $this->exportTailwind($theme),
            'zip' => $this->exportZip($theme),
            default => throw new InvalidExportFormatException($format),
        };
    }

    private function exportCss(Theme $theme): string
    {
        $version = $theme->versions()->latest()->first();
        return $version->compiled_css;
    }

    private function exportJson(Theme $theme): string
    {
        $version = $theme->versions()->latest()->first();
        return $version->compiled_json;
    }

    private function exportZip(Theme $theme): string
    {
        $zip = new ZipArchive();
        $path = storage_path("exports/theme-{$theme->id}.zip");

        $zip->open($path, ZipArchive::CREATE);
        $zip->addFromString('theme.css', $this->exportCss($theme));
        $zip->addFromString('tokens.json', $this->exportJson($theme));
        $zip->addFromString('tailwind.config.js', $this->exportTailwind($theme));
        $zip->close();

        return $path;
    }
}
```

class SecureExportValidator
{
    public function validate(string $css): bool
    {
        $patterns = [
            '/url\s*\(\s*["\']?\s*javascript:/i',
            '/expression\s*\(/i',
            '/@import/i',
            '/behavior\s*:/i',
            '/-moz-binding/i',

        }

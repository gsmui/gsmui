# 05.03.15 - Container Sequence Diagrams

**Project:** GsmUi
**Architecture:** C4 Model – Level 2 (Container)
**Container:** Platform Interactions
**Framework:** Laravel 13 + Multiple
**Version:** 1.0.0

---

# Purpose

This document provides sequence diagrams for key interaction flows in the GsmUi platform. Sequence diagrams illustrate how containers communicate, the order of operations, and the data exchanged between components. Understanding these flows is essential for debugging, optimization, and onboarding.

# 1. Web Request Flow

```plantuml
@startuml

!theme plain

actor User

User -> LoadBalancer : HTTPS Request
LoadBalancer -> WebServer : Forward
WebServer -> Laravel : Route Request
Laravel -> Middleware : Authenticate
Middleware -> Controller : Authorized
Controller -> Service : Business Logic
Service -> Repository : Data Access
Repository -> MySQL : Query
MySQL --> Repository : Result
Repository --> Service : Model
Service --> Controller : Response
Controller --> Laravel : Render View
Laravel --> WebServer : HTML Response
WebServer --> LoadBalancer : Response
LoadBalancer --> User : HTTPS Response

@enduml
```

# 2. Job Dispatch Flow

```plantuml
@startuml

!theme plain

actor Application

Application -> Laravel : dispatch(Job)
Laravel -> QueueManager : Push to queue
QueueManager -> Redis : LPUSH queue:default {payload}
Redis --> QueueManager : OK
QueueManager --> Laravel : Dispatched
Laravel --> Application : Job ID

@enduml
```

---

# 3. Job Processing Flow

```plantuml
@startuml

!theme plain

actor Worker

Worker -> Redis : BRPOP queue:default
Redis --> Worker : {job payload}
Worker -> Laravel : Process job
Laravel -> JobClass : handle()
JobClass -> MySQL : Read data
MySQL --> JobClass : Data
JobClass -> Service : Business logic
Service --> JobClass : Result
JobClass --> Laravel : Complete
Laravel -> Worker : Success
Worker -> Redis : Remove from reserved
Worker -> Horizon : Record metrics

@enduml
```

# 4. Authentication Flow

```plantuml
@startuml

!theme plain

actor User

User -> Controller : POST /login (credentials)
Controller -> Auth : attempt()
Auth -> MySQL : Lookup user
MySQL --> Auth : User record
Auth -> Bcrypt : Verify password
Bcrypt --> Auth : Match
Auth -> Session : Create session
Session -> Redis : Store session data
Redis --> Session : OK
Session --> Auth : Session ID
Auth --> Controller : Authenticated
Controller --> User : Redirect + cookie

@enduml
```

# 5. Cache Hit Flow

```plantuml
@startuml

!theme plain

actor Application

Application -> Cache : remember('key', ttl, closure)
Cache -> Redis : GET cache:key
Redis --> Cache : Hit! {cached data}
Cache --> Application : Return cached data

@enduml
```

# 6. Cache Miss Flow

```plantuml
@startuml

!theme plain

actor Application

Application -> Cache : remember('key', ttl, closure)
Cache -> Redis : GET cache:key
Redis --> Cache : Miss (null)
Cache -> Closure : Execute
Closure -> MySQL : Query data
MySQL --> Closure : Data
Closure --> Cache : Data
Cache -> Redis : SET cache:key {data} EX {ttl}
Redis --> Cache : OK
Cache --> Application : Return data

@enduml
```

# Flow Characteristics

| Flow | Containers | Complexity | Frequency |
|------|-----------|------------|----------|
| Web Request | All | High | Very High |
| Job Dispatch | Queue, Redis | Low | High |
| Job Processing | Queue, MySQL, Services | Medium | High |
| Authentication | Web, Redis, MySQL | Medium | Medium |
| Cache Hit | Web, Redis | Low | Very High |
| Cache Miss | Web, Redis, MySQL | Medium | Medium |
| Search Query | Web, Meilisearch | Low | Medium |
| File Upload | Web, S3, MySQL | Medium | Low |
| Failed Job Recovery | Horizon, Redis | Low | Low |
| Database Transaction | MySQL | Medium | Medium |

# Container Communication Matrix

| From | To | Protocol | Purpose |
|------|----|----------|---------|
| Load Balancer | Web | HTTP/HTTPS | Traffic routing |
| Web | Redis | TCP | Cache, sessions, queue |
| Web | MySQL | TCP | Data access |
| Web | Meilisearch | HTTP | Search |
| Web | S3 | HTTPS | File storage |
| Queue Worker | Redis | TCP | Queue processing |
| Queue Worker | MySQL | TCP | Job data |
| Horizon | Redis | TCP | Metrics, state |
| Horizon | MySQL | TCP | Failed jobs |

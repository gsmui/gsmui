# Purpose

This document describes the security boundaries, trust zones, authentication mechanisms, authorization policies, and encryption strategies that protect the GsmUi platform. Security is enforced at multiple layers, from network perimeter to data at rest.

---

# Responsibilities

Security infrastructure is responsible for:

* Defining network trust zones
* Authenticating users and services
* Authorizing access to resources
* Encrypting data in transit and at rest
* Preventing common attacks (CSRF, XSS, SQL injection)
* Managing secrets and credentials
* Logging security events
* Enforcing rate limits

# Encryption

### Data in Transit

All external communication uses TLS:

```text
TLS 1.3 minimum
Valid certificates (Let's Encrypt / ACM)
HSTS headers
```

Internal communication:

* Web servers → Database: TLS (optional, private network)
* Web servers → Redis: TLS in production
* Queue workers → Redis: TLS in production

### Data at Rest

Sensitive data encrypted at rest:

| Data | Encryption |
|------|-----------|
| Passwords | Argon2id hash (Laravel default) |
| API tokens | Bcrypt hash |
| Database columns | AES-256 (Laravel encryption) |
| S3 objects | SSE-S3 or SSE-KMS |
| Backups | Encrypted at storage level |

# SQL Injection Prevention

Eloquent ORM prevents SQL injection:

```php
// Safe (parameterized)
User::where('email', $email)->first();

// Unsafe (raw)
User::whereRaw("email = '{$email}'")->first(); // DON'T DO THIS
```

Never concatenate user input into raw SQL.

# XSS Prevention

User content is escaped in Blade:

```blade
{{ $user->name }}  {{-- Escaped --}}
{!! $user->bio !!}  {{-- Unescaped — use sparingly --}}
```

Laravel's `e()` function escapes HTML entities.

# CSRF Protection

CSRF tokens protect state-changing requests:

```php
// Blade form
<form method="POST" action="/themes">
    @csrf
    <input name="name" />
</form>

// API
Route::post('/api/themes', [ThemeController::class, 'store'])
    ->middleware('auth:sanctum');
```

API routes using Sanctum are exempt from CSRF (use token auth instead).

# Rate Limiting

Rate limits prevent abuse:

```php
RateLimiter::for('api', function (Request $request) {
    return Limit::perMinute(60)->by($request->ip());

Route::middleware(['throttle:api'])->group(function () {
    // API routes

```

Queue dispatch is also rate-limited for external APIs:

```php
Http::timeout(10)->retry(3, 1000)->get('https://api.example.com');
```

# Advanced Authentication

### Multi-Factor Authentication (MFA)

GsmUi supports TOTP-based MFA for enhanced security:

```php
class TwoFactorAuthenticationController extends Controller
{
    public function enable(Request $request): JsonResponse
    {
        $user = $request->user();
        $secret = $this->generateSecret();

        $user->update([
            'two_factor_secret' => Hash::make($secret),
            'two_factor_enabled' => true,
        ]);

        return response()->json([
            'secret' => $secret,
            'qr_code' => $this->generateQrCode($user, $secret),
            'recovery_codes' => $this->generateRecoveryCodes(),
        ]);
    }

    public function verify(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'code' => ['required', 'string', 'size:6'],
        ]);

        $verified = Google2FA::verifyKey(
            $request->user()->two_factor_secret,
            $validated['code']
        );

        if (!$verified) {
            return response()->json(['error' => 'Invalid code'], 422);
        }

        return response()->json(['valid' => true]);
    }
}
```

### Encryption Key Rotation

```php
class EncryptionKeyRotator
{
    public function rotate(): void
    {
        $newKey = Str::random(32);

        // Re-encrypt sensitive data with new key
        User::chunk(100, function ($users) use ($newKey) {
            foreach ($users as $user) {
                $decrypted = Crypt::decryptString($user->encrypted_ssn);
                $user->encrypted_ssn = Crypt::encryptString($decrypted);
                $user->save();
            }
        });

        // Store new key securely
        config(['app.encryption_key' => $newKey]);
    }
}
```

### WAF Rules

```text
WAF Protection Rules:

  SQL Injection:
    - Detect UNION, SELECT, INSERT, UPDATE, DELETE
    - Block common injection patterns
    - Log suspicious queries

  XSS:
    - Detect <script>, <iframe>, javascript:
    - Filter event handlers (onload, onclick, etc.)

  Path Traversal:

    - Restrict file access

  Rate Limiting:
    - Limit requests per IP

```

### WAF Configuration

```php
// WAF middleware
class WafMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $rules = [
            'sql_injection' => $this->detectSqlInjection($request),
            'xss' => $this->detectXss($request),
            'path_traversal' => $this->detectPathTraversal($request),
            'rate_limit' => $this->checkRateLimit($request),
        ];

        foreach ($rules as $type => $detected) {
            if ($detected) {
                Log::warning("WAF blocked request", [
                    'type' => $type,
                    'ip' => $request->ip(),
                    'path' => $request->path(),
                ]);

                return response()->json(['error' => 'Forbidden'], 403);
            }
        }

        return $next($request);
    }
}
```

# Content Security Policy (CSP)

### CSP Configuration

```php
class CspMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $response = $next($request);

        $csp = [
            'default-src' => ["'self'"],
            'script-src' => ["'self'", "'unsafe-inline'"],
            'style-src' => ["'self'", "'unsafe-inline'"],
            'img-src' => ["'self'", 'data:', 'https:'],
            'font-src' => ["'self'"],
            'connect-src' => ["'self'"],
            'frame-ancestors' => ["'none'"],
            'form-action' => ["'self'"],
            'base-uri' => ["'self'"],
        ];

        $header = collect($csp)
            ->map(fn ($sources, $directive) => $directive . ' ' . implode(' ', $sources))
            ->implode('; ');

        $response->headers->set('Content-Security-Policy', $header);

        return $response;
    }
}
```

### Incident Response Automation

```php
class SecurityIncident
{
    public static function fromAlert(array $alert): self
    {
        $incident = self::create([
            'title' => $alert['name'],
            'severity' => $alert['severity'],
            'status' => 'open',
            'triggered_at' => now(),
        ]);

        // Auto-respond to critical incidents
        if ($alert['severity'] === 'critical') {
            self::autoContain($alert);
        }

        // Notify team
        Notify::route('slack', '#security')->notify(
            new SecurityAlertNotification($incident)
        );

        return $incident;
    }

    private static function autoContain(array $alert): void
    {
        match ($alert['type']) {
            'brute_force' => IPBlock::block($alert['ip']),
            'data_exfiltration' => AccountLock::lock($alert['user_id']),
            'privilege_escalation' => PermissionRevoke::revoke($alert['user_id']),
            default => null,
        };
    }
}
```

### Password Security

```php
class PasswordSecurity
{
    public function validatePassword(string $password): bool
    {
        // Minimum length
        if (strlen($password) < 12) {
            return false;
        }

        // Complexity requirements
        $hasUppercase = preg_match('/[A-Z]/', $password);
        $hasLowercase = preg_match('/[a-z]/', $password);
        $hasNumbers = preg_match('/[0-9]/', $password);
        $hasSpecial = preg_match('/[^A-Za-z0-9]/', $password);

        if ($hasUppercase + $hasLowercase + $hasNumbers + $hasSpecial < 3) {
            return false;
        }

        // Check against common passwords
        if ($this->isCommonPassword($password)) {
            return false;
        }

        // Check against breached passwords (HIBP API)
        if ($this->isBreachedPassword($password)) {
            return false;
        }

        return true;
    }

    private function isCommonPassword(string $password): bool
    {
        $commonPasswords = file_get_contents(storage_path('app/common-passwords.txt'));
        $commonPasswords = explode("\n", $commonPasswords);

        return in_array(strtolower($password), $commonPasswords);
    }

    private function isBreachedPassword(string $password): bool
    {
        $hash = sha1($password);
        $prefix = substr($hash, 0, 5);
        $suffix = substr($hash, 5);

        $response = Http::get("https://api.pwnedpasswords.com/range/{$prefix}");

        return str_contains($response->body(), strtoupper($suffix));
    }
}
```

### Brute Force Protection

```php
class BruteForceProtection
{
    private array $limits = [
        'login' => ['attempts' => 5, 'lockout' => 900],
        'password_reset' => ['attempts' => 3, 'lockout' => 3600],
        'api' => ['attempts' => 100, 'lockout' => 60],
    ];

    public function check(string $type, string $identifier): bool
    {
        $limit = $this->limits[$type];
        $key = "brute_force:{$type}:{$identifier}";

        $attempts = Cache::get($key, 0);

        if ($attempts >= $limit['attempts']) {
            return false;
        }

        return true;
    }

    public function record(string $type, string $identifier): void
    {
        $limit = $this->limits[$type];
        $key = "brute_force:{$type}:{$identifier}";

        Cache::increment($key);
        Cache::put($key, Cache::get($key, 0), $limit['lockout']);
    }

    public function reset(string $type, string $identifier): void
    {
        Cache::forget("brute_force:{$type}:{$identifier}");
    }

    public function getRemainingTime(string $type, string $identifier): int
    {
        $limit = $this->limits[$type];
        $key = "brute_force:{$type}:{$identifier}";

        $attempts = Cache::get($key, 0);

        if ($attempts < $limit['attempts']) {
            return 0;
        }

        return Cache::store('redis')->ttl($key);
    }
}
```

```php
                'themes.edit',
                'components.create',
                'components.edit',
                'content.publish',
            ],
            'description' => 'Content management',
        ],
        'author' => [
            'permissions' => [
                'themes.create',
                'themes.edit.own',
                'components.create',
                'components.edit.own',
            ],
            'description' => 'Content creation',
        ],
        'viewer' => [
            'permissions' => [
                'themes.view',
                'components.view',
                'docs.view',
            ],
            'description' => 'Read-only access',
        ],
    ];

    public function hasPermission(string $role, string $permission): bool
    {
        if (!isset($this->roles[$role])) {
            return false;
        }

        $permissions = $this->roles[$role]['permissions'];

        if (in_array('*', $permissions)) {
            return true;
        }

        if (in_array($permission, $permissions)) {
            return true;
        }

        // Check wildcard permissions
        foreach ($permissions as $p) {
            if (str_ends_with($p, '.*')) {
                $prefix = substr($p, 0, -2);
                if (str_starts_with($permission, $prefix)) {
                    return true;
                }
            }
        }

        return false;
    }
}
```

```php
class FileValidation
{
    public function validateFile(UploadedFile $file): void
    {
        // Check MIME type
        $allowedTypes = [
            'image/jpeg', 'image/png', 'image/webp', 'image/gif',
            'application/pdf',
            'application/zip',
            'text/plain',
        ];

        if (!in_array($file->getMimeType(), $allowedTypes)) {
            throw ValidationException::withMessages([
                'file' => 'File type not allowed',
            ]);
        }

        // Check file extension
        $allowedExtensions = ['jpg', 'jpeg', 'png', 'webp', 'gif', 'pdf', 'zip', 'txt'];

        if (!in_array(strtolower($file->getClientOriginalExtension()), $allowedExtensions)) {
            throw ValidationException::withMessages([
                'file' => 'File extension not allowed',
            ]);
        }

        // Check file size (10MB max)
        if ($file->getSize() > 10 * 1024 * 1024) {
            throw ValidationException::withMessages([
                'file' => 'File size must be less than 10MB',
            ]);
        }

        // Check file content (magic bytes)
        $handle = fopen($file->getPathname(), 'r');
        $header = fread($handle, 8);
        fclose($handle);

        if (!$this->isValidMagicBytes($header, $file->getMimeType())) {
            throw ValidationException::withMessages([
                'file' => 'File content does not match its declared type',
            ]);
        }
    }

    private function isValidMagicBytes(string $header, string $mimeType): bool
    {
        $magicBytes = [
            'image/jpeg' => "\xFF\xD8\xFF",
            'image/png' => "\x89PNG\r\n\x1A\n",
            'image/gif' => "GIF8",
            'application/pdf' => "%PDF",
            'application/zip' => "PK",
        ];

        return str_starts_with($header, $magicBytes[$mimeType] ?? '');
    }
}
```

# Security Testing Framework

### Automated Security Tests

```php
class SecurityTest extends TestCase
{
    public function test_sql_injection_prevention(): void
    {
        $payloads = [
            "' OR '1'='1",
            "'; DROP TABLE users; --",
            "' UNION SELECT * FROM users --",
        ];

        foreach ($payloads as $payload) {
            $response = $this->postJson('/api/search', ['q' => $payload]);
            $response->assertOk();
            $this->assertDatabaseIntact();
        }
    }

    public function test_xss_prevention(): void
    {
        $payloads = [
            '<script>alert("XSS")</script>',
            '<img src="x" onerror="alert(\'XSS\')">',
            'javascript:alert("XSS")',
        ];

        foreach ($payloads as $payload) {
            $response = $this->postJson('/api/themes', ['name' => $payload]);
            $response->assertOk();
            $this->assertDatabaseHas('themes', ['name' => htmlspecialchars($payload)]);
        }
    }

    public function test_csrf_protection(): void
    {
        $response = $this->postJson('/api/themes', ['name' => 'Test']);
        $response->assertStatus(419); // CSRF token mismatch
    }

    public function test_rate_limiting(): void
    {
        for ($i = 0; $i < 100; $i++) {
            $this->getJson('/api/themes');
        }

        $response = $this->getJson('/api/themes');
        $response->assertStatus(429);
    }
}
```

# Security Automation

### Automated Remediation

```php
class SecurityAutomation
{
    public function handleThreat(array $threat): void
    {
        match ($threat['type']) {
            'brute_force' => $this->blockIp($threat['ip']),
            'sql_injection' => $this->blockRequest($threat['request']),
            'xss_attempt' => $this->sanitizeOutput($threat['output']),
            'privilege_escalation' => $this->revokeAccess($threat['user']),
            'data_exfiltration' => $this->blockDataTransfer($threat['user']),
        };
    }

    private function blockIp(string $ip): void
    {
        Cache::put("blocked:{$ip}", true, 86400);
        Log::warning("IP blocked", ['ip' => $ip]);
    }

    private function blockRequest(array $request): void
    {
        Cache::put("blocked:request:" . md5(serialize($request)), true, 3600);
        Log::warning("Request blocked", ['request' => $request]);
    }

    private function revokeAccess(int $userId): void
    {
        User::find($userId)->tokens()->delete();
        Log::warning("Access revoked", ['user_id' => $userId]);
    }
}
```

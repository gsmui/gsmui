### Sandboxed Compilation

```php id="pprev02"
class PreviewCompiler
{
    private array $allowedDirectives = [
        'if', 'else', 'elseif', 'endif',
        'foreach', 'endforeach', 'forelse',
        'switch', 'case', 'default', 'endswitch',
        'slot', 'endslot',
        'component', 'endcomponent',
        'props',
    ];

    public function compile(string $blade): string
    {
        $sanitized = $this->sanitize($blade);
        $compiled = Blade::compileString($sanitized);

        return $this->render($compiled);
    }

    private function sanitize(string $blade): string
    {
        // Remove PHP directives
        $blade = preg_replace('/@php\s.*?\s@endphp/s', '', $blade);
        $blade = preg_replace('/@verbatim\s.*?\s@endverbatim/s', '', $blade);

        // Remove dangerous content
        $blade = preg_replace('/\{\{.*?exec.*?\}\}/', '', $blade);
        $blade = preg_replace('/\{\{.*?system.*?\}\}/', '', $blade);
        $blade = preg_replace('/\{\{.*?shell_exec.*?\}\}/', '', $blade);

        return $blade;
    }
}
```

## Theme Switching

### Implementation

```php id="ptheme01"
class ThemeSwitcher extends Component
{
    public string $currentTheme = 'default';
    public array $availableThemes = [];
    public string $mode = 'light'; // light, dark, auto

    public function mount(): void
    {
        $this->availableThemes = Theme::where('is_public', true)
            ->pluck('name', 'slug')
            ->toArray();
    }

    public function switchTheme(string $themeSlug): void
    {
        $this->currentTheme = $themeSlug;
        $theme = Theme::where('slug', $themeSlug)->firstOrFail();

        $this->emit('themeChanged', [
            'css' => $theme->compiled_css,
            'tokens' => $theme->tokens->pluck('value', 'key'),
        ]);
    }

    public function toggleMode(): void
    {
        $this->mode = match($this->mode) {
            'light' => 'dark',
            'dark' => 'auto',
            'auto' => 'light',
        };

        $this->emit('modeChanged', $this->mode);
    }
}
```

```php id="psnip02"
class SnippetService
{
    public function save(SnippetData $data, User $user): Snippet
    {
        return Snippet::create([
            'user_id' => $user->id,
            'title' => $data->title,
            'language' => $data->language,
            'content' => $data->content,
            'theme_id' => $data->themeId,
            'visibility' => $data->visibility,
            'tags' => $data->tags,

    public function duplicate(Snippet $snippet, User $user): Snippet
    {
        return $snippet->replicate([
            'user_id' => $user->id,

            'fork_count' => $snippet->fork_count + 1,
        ])->save();

    {
        $snippet->favoritedBy()->toggle($user->id);
        $snippet->update([
            'favorite_count' => $snippet->favoritedBy()->count(),
        ]);
    }
}
```

## Sharing System

### Share Link Generation

```php id="pshare01"
class ShareService
{
    public function createShareLink(Snippet $snippet, string $visibility): string
    {
        $shareToken = Str::random(32);

        Share::create([
            'snippet_id' => $snippet->id,
            'token' => $shareToken,
            'visibility' => $visibility,
            'expires_at' => $visibility === 'public'
                ? null
                : now()->addDays(30),
        ]);

        return url("/playground/shared/{$shareToken}");
    }

    public function resolveShareLink(string $token): Snippet
    {
        $share = Share::where('token', $token)
            ->where(function ($q) {
                $q->whereNull('expires_at')
                  ->orWhere('expires_at', '>', now());
            })
            ->firstOrFail();

        return $share->snippet;
    }
}
```

```php id="pinsp01"
    {
        $crawler = new Crawler($html);
```

## Version History

### History Tracking

```php id="phist01"
class VersionHistory
{
    public function record(Snippet $snippet, string $content): void
    {
        $lastVersion = $snippet->versions()->latest()->first();

        if ($lastVersion && $lastVersion->content === $content) {
            return; // No changes
        }

        $snippet->versions()->create([
            'version' => ($lastVersion->version ?? 0) + 1,
            'content' => $content,
            'created_at' => now(),
        ]);
    }

    public function restore(Snippet $snippet, int $versionId): string
    {
        $version = $snippet->versions()->findOrFail($versionId);
        return $version->content;
    }

    public function compare(Snippet $snippet, int $from, int $to): array
    {
        $fromVersion = $snippet->versions()->findOrFail($from);
        $toVersion = $snippet->versions()->findOrFail($to);

        return $this->diff->diff($fromVersion->content, $toVersion->content);
    }
}
```

### Implementation

```php id="pauto02"
class AutosaveService extends Component
{
    public string $content = '';
    public int $snippetId;
    public bool $isSaving = false;
    public string $lastSaved = '';

    protected $listeners = ['contentChanged'];

    public function contentChanged(string $newContent): void
    {
        $this->content = $newContent;
        $this->save();
    }

    public function save(): void
    {
        $this->isSaving = true;

        Snippet::where('id', $this->snippetId)->update([
            'content' => $this->content,
        ]);

        app(VersionHistory::class)->record(
            Snippet::find($this->snippetId),
            $this->content
        );

        $this->isSaving = false;
        $this->lastSaved = now()->format('H:i:s');
    }
}
```

### Input Sanitization

```php id="psec01"
class PlaygroundSanitizer
{
    private array $blockedPatterns = [
        '/exec\s*\(/',
        '/system\s*\(/',
        '/shell_exec\s*\(/',
        '/passthru\s*\(/',
        '/eval\s*\(/',
        '/file_get_contents\s*\(/',
        '/file_put_contents\s*\(/',
        '/curl/',
        '/fopen\s*\(/',
        '/fwrite\s*\(/',
    ];

    public function sanitize(string $code): string
    {
        foreach ($this->blockedPatterns as $pattern) {
            if (preg_match($pattern, $code)) {
                throw new SecurityViolationException(
                    "Blocked pattern detected: {$pattern}"
                );
            }
        }

        return $code;
    }
}
```

## Preview Engine (Extended)

### Sandboxed Compilation

```php id="pprev04"
class PreviewCompiler
{
    private array $allowedDirectives = [
        'if', 'else', 'elseif', 'endif',
        'foreach', 'endforeach', 'forelse', 'empty',
        'switch', 'case', 'default', 'break', 'endswitch',
        'slot', 'endslot',
        'component', 'endcomponent',
        'props',
        'verbatim', 'endverbatim',
    ];

    private array $blockedFunctions = [
        'exec', 'system', 'shell_exec', 'passthru',
        'eval', 'file_get_contents', 'file_put_contents',
        'fopen', 'fwrite', 'curl', 'proc_open',
    ];

    public function compile(string $blade): CompilationResult
    {
        $sanitized = $this->sanitize($blade);

        if ($this->containsBlockedContent($sanitized)) {
            return CompilationResult::blocked('Security violation detected');
        }

        try {
            $compiled = Blade::compileString($sanitized);
            $html = $this->render($compiled);

            return CompilationResult::success($html);
        } catch (\Exception $e) {
            return CompilationResult::error($e->getMessage());
        }
    }

    private function containsBlockedContent(string $code): bool
    {
        foreach ($this->blockedFunctions as $function) {
            if (preg_match("/{$function}\s*\(/i", $code)) {
                return true;
            }
        }

        return false;
    }
}
```

```php id="psnip04"
{
    public function save(SnippetData $data, User $user): Snippet
    {
        $snippet = Snippet::create([
            'user_id' => $user->id,
            'title' => $data->title,
            'language' => $data->language,

            'theme_id' => $data->themeId,

    public function duplicate(Snippet $snippet, User $user): Snippet
    {
        $newSnippet = $snippet->replicate();
        $newSnippet->user_id = $user->id;
        $newSnippet->title = $snippet->title . ' (Copy)';
        $newSnippet->save();

        SnippetFork::create([
            'original_snippet_id' => $snippet->id,
            'forked_snippet_id' => $newSnippet->id,
        ]);

        $snippet->increment('fork_count');

        return $newSnippet;
    }

    public function favorite(Snippet $snippet, User $user): void
    {
        $existing = UserFavorite::where('user_id', $user->id)
            ->where('snippet_id', $snippet->id)

        if ($existing) {
            $existing->delete();
            $snippet->decrement('favorite_count');
        } else {
            UserFavorite::create([
                'user_id' => $user->id,
                'snippet_id' => $snippet->id,
            ]);
            $snippet->increment('favorite_count');
        }
    }

    public function incrementViewCount(Snippet $snippet): void
    {
        $snippet->increment('view_count');
    }
}
```

## Version History (Extended)

### History Tracking

```php id="phist02"
class VersionHistory
{
    public function record(Snippet $snippet, string $content): void
    {
        $lastVersion = $snippet->versions()->latest()->first();

        if ($lastVersion && $lastVersion->content === $content) {
            return;
        }

        $snippet->versions()->create([
            'version' => ($lastVersion->version ?? 0) + 1,
            'content' => $content,
        ]);
    }

    public function restore(Snippet $snippet, int $versionId): string
    {
        $version = $snippet->versions()->findOrFail($versionId);
        return $version->content;
    }

    public function compare(Snippet $snippet, int $from, int $to): array
    {
        $fromVersion = $snippet->versions()->findOrFail($from);
        $toVersion = $snippet->versions()->findOrFail($to);

        return $this->diff->diff($fromVersion->content, $toVersion->content);
    }

    public function getHistory(Snippet $snippet): array
    {
        return $snippet->versions()
            ->orderBy('version', 'desc')
            ->limit(50)
            ->get()
            ->map(fn($v) => [
                'id' => $v->id,
                'version' => $v->version,
                'created_at' => $v->created_at->diffForHumans(),
            ])
            ->toArray();
    }
}
```

```php id="psec02"
class PlaygroundSanitizer
{
    private array $blockedPatterns = [
        '/exec\s*\(/',
        '/system\s*\(/',
        '/shell_exec\s*\(/',
        '/passthru\s*\(/',
        '/eval\s*\(/',
        '/file_get_contents\s*\(/',
        '/file_put_contents\s*\(/',
        '/curl/',
        '/fopen\s*\(/',
        '/fwrite\s*\(/',
        '/proc_open\s*\(/',
        '/popen\s*\(/',
        '/pcntl_exec\s*\(/',
    ];

    public function sanitize(string $code): string
    {
        foreach ($this->blockedPatterns as $pattern) {
            if (preg_match($pattern, $code)) {
                throw new SecurityViolationException(
                    "Blocked pattern detected"
                );
            }
        }

        // Remove PHP tags
        $code = str_replace(['<?php', '?>'], '', $code);

        return $code;
    }
}
```

# Risk

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Arbitrary code execution in sandbox escapes | Low | Critical | Whitelist Blade directives only. No `eval()`, no `exec()`, no filesystem writes. Sandbox runs in isolated PHP process with disabled functions. |
| Monaco editor bundle size impacts page load | High | Medium | Lazy-load Monaco on Playground page only. Use web workers for syntax highlighting. Consider CodeMirror as lighter alternative. |
| Blade compilation of user code has server-side vulnerabilities | Low | Critical | Compile in isolated process with timeout. Validate all Blade directives against whitelist. No access to `$app` or service container. |
| Preview rendering desyncs from actual component output | Medium | High | Use identical Blade compiler version as production. Run Playwright snapshot tests comparing playground vs. docs preview. |
| Autosave conflicts with concurrent sessions | Low | Low | Last-write-wins with timestamp validation. Optimistic locking on snippet updates. |
| Shared playground links are abused for spam | Medium | Medium | Rate-limit sharing. Require authentication to share. Content moderation queue for public playgrounds. |
| Export format produces invalid code | Medium | Medium | Validate exported code compiles before delivery. Run linting on exported Blade/PHP/HTML. |
| AI integration produces incorrect component suggestions | Medium | Low | AI responses are suggestions, not auto-applied. User always reviews before accepting. Cache common requests. |

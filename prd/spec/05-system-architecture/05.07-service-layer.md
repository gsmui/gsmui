# 05.07 - Service Layer Architecture

**Project:** GsmUi
**Architecture:** Domain-Driven Design + Service Layer Pattern
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

The Service Layer encapsulates all business logic for GsmUi. It acts as the application's use-case layer, coordinating repositories, domain rules, transactions, events, and integrations while keeping presentation code lightweight.

**Goals:**

* Centralize business logic
* Keep Livewire components thin
* Reuse logic across UI, CLI, Jobs, and APIs
* Simplify testing
* Prevent duplicated logic
* Support future API and microservice evolution

---

# Architecture Overview

```text
Presentation
(Blade / Livewire / API)

        │

Application Layer
(Actions + Services)

        │

Domain Layer
(Business Rules)

        │

Infrastructure Layer
(Repositories + Database + External Services)
```

# Core Principles

## 1. Thin Controllers

Controllers should never contain business logic.

Good:

```php
return $this->componentService->create($dto);
```

Bad:

* Validation
* Queries
* Transactions
* Payment logic
* Email sending

---

## 2. Thin Livewire Components

Livewire manages UI only.

Responsibilities:

* State
* Validation
* Rendering
* Events

Business logic belongs in Actions and Services.

---

## 3. One Responsibility

Each service owns one business capability.

Examples:

* ComponentService
* ThemeService
* BillingService

Avoid "God Services."

---

## 4. Stateless Services

Services should not maintain mutable state between requests.

All required context is passed through method parameters.

# Actions

Actions represent a single use case.

Examples:

```text
CreateComponentAction

UpdateComponentAction

DeleteComponentAction

PublishThemeAction

PurchaseTemplateAction

ApproveShowcaseAction
```

Responsibilities:

* Validate business preconditions
* Begin transaction
* Call services
* Dispatch events
* Return result

---

# Service Responsibilities

Services may:

* Apply business rules
* Call repositories
* Use value objects
* Dispatch domain events
* Coordinate multiple repositories
* Interact with external services
* Throw domain exceptions

Services should **not**:

* Render views
* Read request objects
* Access session state directly
* Contain HTML
* Return HTTP responses

---

# DTO Usage

All complex operations use DTOs.

Example:

```php
CreateComponentData

CreateThemeData

CreateOrderData

PublishBlogData
```

Benefits:

* Type safety
* Validation boundary
* Clear method signatures

---

# Repository Interaction

Services communicate with persistence only through repositories.

```text
Service

↓

Repository

↓

Eloquent Model

↓

Database
```

Never query models directly from controllers or Livewire components.

---

# Transactions

Transactions belong in the service layer.

Example:

```php
DB::transaction(function () {
    // Business operation
});
```

Rules:

* Keep transactions short
* Avoid network calls inside transactions
* Dispatch events after commit when appropriate

---

# Domain Events

Services publish events instead of invoking unrelated modules directly.

Examples:

```text
ComponentReleased

ThemePublished

OrderPaid

InvoiceGenerated

UserRegistered
```

Benefits:

* Loose coupling
* Extensibility
* Async processing

---

# Error Handling

Services throw domain-specific exceptions.

Examples:

```text
ComponentAlreadyExistsException

ThemeValidationException

SubscriptionExpiredException

InsufficientPermissionsException
```

Presentation layers convert exceptions into user-friendly responses.

---

# Query Services

Read-heavy operations use dedicated query services.

Examples:

```text
DocumentationQueryService

SearchQueryService

AnalyticsQueryService

DashboardQueryService
```

Responsibilities:

* Filtering
* Searching
* Pagination
* Aggregation
* Reporting

No write operations.

---

# Dependency Injection

All services use constructor injection.

Example:

```php
class ComponentService
{
    public function __construct(
        private ComponentRepository $repository,
        private EventDispatcher $events,
        private CacheService $cache,
    ) {}
}
```

Avoid service locators or static access.

---

# Cross-Domain Communication

Preferred order:

1. Service Contracts
2. Domain Events
3. Shared Interfaces

Avoid direct repository access across domains.

---

# Caching Strategy

Services own cache invalidation.

Examples:

* Documentation cache
* Theme cache
* Homepage cache
* Navigation cache

Pattern:

```text
Read

↓

Cache

↓

Repository

↓

Cache Result
```

---

# Validation

Validation occurs at multiple levels:

1. Livewire/Form Request (input)
2. DTO construction
3. Business rules in services

This prevents invalid state from entering the domain.

---

# Logging

Important service operations are logged.

Examples:

* Purchases
* Subscription changes
* Theme publication
* Component release
* Admin actions

Use `spatie/laravel-activitylog` for audit trails.

Each service requires:

# Anti-Patterns

Avoid:

* Fat Controllers
* Fat Livewire Components
* Repository-to-Repository calls
* Business logic in Models
* Direct HTTP access inside services
* Static helper dependencies
* Hidden side effects

---

# Service Contracts

Expose only interfaces where cross-domain use is required.

Example:

```php
interface ThemeExporter
{
    public function export(Theme $theme): string;
}
```

Concrete implementations remain internal.

---

# Performance Considerations

* Batch database writes where possible
* Use eager loading
* Cache read-heavy data
* Queue expensive operations
* Minimize transaction duration
* Avoid N+1 queries

---

Potential extractions:

## Dependency Injection Container

### Service Provider Registration

```php
// app/Providers/DomainServiceProvider.php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;
use App\Domains\Components\Contracts\{ComponentServiceInterface, ComponentRepositoryInterface};
use App\Domains\Components\Services\ComponentService;
use App\Domains\Components\Repositories\Eloquent\ComponentRepository;

class DomainServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->registerComponents();
        $this->registerThemes();
        $this->registerBilling();
        $this->registerSearch();
        $this->registerNotifications();
    }

    private function registerComponents(): void
    {
        $this->app->bind(ComponentServiceInterface::class, ComponentService::class);
        $this->app->bind(ComponentRepositoryInterface::class, ComponentRepository::class);
    }

    private function registerThemes(): void
    {
        $this->app->bind(ThemeServiceInterface::class, ThemeService::class);
        $this->app->bind(ThemeRepositoryInterface::class, ThemeRepository::class);
    }

    private function registerBilling(): void
    {
        $this->app->bind(BillingServiceInterface::class, BillingService::class);
        $this->app->bind(PlanRepositoryInterface::class, PlanRepository::class);
        $this->app->bind(SubscriptionRepositoryInterface::class, SubscriptionRepository::class);
    }

    private function registerSearch(): void
    {
        $this->app->bind(SearchServiceInterface::class, function ($app) {
            return new MeilisearchService(
                client: $app->make(MeilisearchClient::class),
                cache: $app->make('cache.store'),
            );
        });
    }

    private function registerNotifications(): void
    {
        $this->app->bind(NotificationServiceInterface::class, NotificationService::class);
    }
}
```

## Service Transaction Management

### Transaction Patterns

```php
// Transaction management patterns

class ComponentService implements ComponentServiceInterface
{
    public function create(CreateComponentData $data): ComponentDTO
    {
        return DB::transaction(function () use ($data) {
            // Create component
            $component = $this->repository->create($data->toArray());

            // Create default version
            $version = $this->versionService->createDefault($component->id);

            // Attach categories
            $this->attachCategories($component, $data->categories);

            // Dispatch event
            $this->events->dispatch(new ComponentCreated(
                componentId: $component->id,
                authorId: $data->authorId,
            ));

            return ComponentDTO::fromModel($component);
        });
    }

    public function publish(int $id): ComponentDTO
    {
        return DB::transaction(function () use ($id) {
            // Validate
            $component = $this->validateForPublishing($id);

            // Update status
            $component = $this->repository->update($component, [
                'status' => ComponentStatus::PUBLISHED,
                'published_at' => now(),
            ]);

            // Index in search
            $this->searchService->indexComponent($component);

            // Dispatch event
            $this->events->dispatch(new ComponentPublished(
                componentId: $component->id,
                versionId: $component->latestVersion->id,
            ));

            return ComponentDTO::fromModel($component);
        });
    }
}
```

### Event Dispatch Pattern

```php
// Event dispatch patterns

class ComponentService implements ComponentServiceInterface
{
    public function create(CreateComponentData $data): ComponentDTO
    {
        // Create component
        $component = $this->repository->create($data->toArray());

        // Dispatch event
        $this->events->dispatch(new ComponentCreated(
            componentId: $component->id,
            authorId: $data->authorId,
            name: $component->name,
            slug: $component->slug,
        ));

        return ComponentDTO::fromModel($component);
    }

    public function publish(int $id): ComponentDTO
    {
        // Update component
        $component = $this->repository->update($id, [
            'status' => 'published',
            'published_at' => now(),
        ]);

        // Dispatch event after database commit
        DB::afterCommit(function () use ($component) {
            $this->events->dispatch(new ComponentPublished(
                componentId: $component->id,
                versionId: $component->latestVersion->id,
            ));
        });

        return ComponentDTO::fromModel($component);
    }
}
```

## Service Caching Patterns

### Cache-Aside Pattern

```php
// Cache-aside pattern

class ComponentService implements ComponentServiceInterface
{
    public function findById(int $id): ?ComponentDTO
    {
        $cacheKey = "component:{$id}";

        return $this->cache->remember($cacheKey, 3600, function () use ($id) {
            $component = $this->repository->find($id);

            return $component ? ComponentDTO::fromModel($component) : null;
        });
    }

    public function update(int $id, UpdateComponentData $data): ComponentDTO
    {
        // Update component
        $component = $this->repository->update($id, $data->toArray());

        // Invalidate cache
        $this->cache->forget("component:{$id}");
        $this->cache->forget("component:slug:{$component->slug}");

        return ComponentDTO::fromModel($component);
    }
}
```

### Tag-Based Cache Invalidation

```php
// Tag-based cache invalidation

class ComponentService implements ComponentServiceInterface
{
    public function getPopular(int $limit = 10): Collection
    {
        return $this->cache->tags(['components', 'popular'])->remember(
            "popular:{$limit}",
            1800,
            function () use ($limit) {
                return $this->repository->getPopular($limit);
            }
        );
    }

    public function publish(int $id): ComponentDTO
    {
        $component = $this->repository->update($id, ['status' => 'published']);

        // Invalidate related caches
        $this->cache->tags(['components', 'popular'])->flush();
        $this->cache->tags(['components', 'featured'])->flush();

        return ComponentDTO::fromModel($component);
    }
}
```

### Error Response Pattern

```php
// Service error response pattern

class ComponentService implements ComponentServiceInterface
{
    public function publish(int $id): ComponentDTO
    {
        try {
            $component = $this->repository->findOrFail($id);

            if ($component->versions()->count() === 0) {
                throw new ComponentCannotBePublishedException(
```

```php
// app/Domains/Components/Services/ComponentService.php

declare(strict_types=1);

namespace App\Domains\Components\Services;

use App\Domains\Components\Contracts\ComponentServiceInterface;
use App\Domains\Components\Contracts\ComponentRepositoryInterface;
use App\Domains\Components\DTOs\{CreateComponentData, UpdateComponentData, ComponentDTO};
use App\Domains\Components\Enums\{ComponentStatus, ComponentCategory};
use App\Domains\Components\Events\{ComponentCreated, ComponentPublished, ComponentArchived};
use App\Domains\Components\Exceptions\{ComponentNotFoundException, ComponentAlreadyExistsException};
use App\Domains\Users\Contracts\UserRepositoryInterface;
use App\Shared\Contracts\SearchServiceInterface;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Cache;
use Illuminate\Contracts\Events\EventDispatcher;

final class ComponentService implements ComponentServiceInterface
{
    public function __construct(
        private readonly ComponentRepositoryInterface $repository,
        private readonly UserRepositoryInterface $userRepository,
        private readonly SearchServiceInterface $searchService,
        private readonly EventDispatcher $events,
    ) {}

    public function create(CreateComponentData $data): ComponentDTO
    {
        // Check uniqueness
        if ($this->repository->existsBySlug($data->slug)) {
            throw new ComponentAlreadyExistsException(
                "Component with slug '{$data->slug}' already exists"
            );
        }

        // Validate author exists
        $author = $this->userRepository->findOrFail($data->authorId);

        // Create component
        $component = $this->repository->create([
            'name' => $data->name,
            'slug' => $data->slug,
            'description' => $data->description,
            'category_id' => $data->categoryId,
            'author_id' => $author->id,
            'is_premium' => $data->isPremium,
            'repository_url' => $data->repositoryUrl,
            'documentation_url' => $data->documentationUrl,
            'status' => ComponentStatus::DRAFT,
        ]);

        // Attach tags
        if (!empty($data->tags)) {
            $this->attachTags($component, $data->tags);
        }

        // Dispatch event
        $this->events->dispatch(new ComponentCreated(
            componentId: $component->id,
            authorId: $author->id,
            name: $component->name,
            slug: $component->slug,
        ));

        return ComponentDTO::fromModel($component);
    }

    public function update(int $id, UpdateComponentData $data): ComponentDTO
    {
        $component = $this->repository->findOrFail($id);

        // Check slug uniqueness if changed
        if ($data->slug && $data->slug !== $component->slug) {
            if ($this->repository->existsBySlug($data->slug, exceptId: $id)) {
                throw new ComponentAlreadyExistsException(
                    "Component with slug '{$data->slug}' already exists"
                );
            }
        }

        // Update component
        $component = $this->repository->update($component, array_filter([
            'name' => $data->name,
            'slug' => $data->slug,
            'description' => $data->description,
            'category_id' => $data->categoryId,
            'is_premium' => $data->isPremium,
            'repository_url' => $data->repositoryUrl,
            'documentation_url' => $data->documentationUrl,
        ], fn($v) => $v !== null));

        // Sync tags if provided
        if ($data->tags !== null) {
            $this->syncTags($component, $data->tags);
        }

        // Dispatch event
        $this->events->dispatch(new ComponentUpdated(
            componentId: $component->id,
            changes: $data->toArray(),
        ));

        return ComponentDTO::fromModel($component);
    }

    public function publish(int $id): ComponentDTO
    {
        $component = $this->repository->findOrFail($id);

        // Business rule: Must have at least one version
        if ($component->versions()->count() === 0) {
            throw new ComponentCannotBePublishedException(
                'Component must have at least one version before publishing'
            );
        }

        // Business rule: Must pass validation
        $this->validateForPublishing($component);

        // Update status
        $component = $this->repository->update($component, [
            'status' => ComponentStatus::PUBLISHED,
            'published_at' => now(),
        ]);

        // Index in search
        $this->searchService->indexComponent($component);

        // Dispatch event
        $this->events->dispatch(new ComponentPublished(
            componentId: $component->id,
            versionId: $component->latestVersion->id,
            categories: $component->categories->pluck('slug')->toArray(),
            tags: $component->tags->pluck('name')->toArray(),
        ));

        return ComponentDTO::fromModel($component);
    }

    public function archive(int $id): ComponentDTO
    {
        $component = $this->repository->findOrFail($id);

        // Business rule: Can only archive published components
        if ($component->status !== ComponentStatus::PUBLISHED) {
            throw new ComponentCannotBeArchivedException(
                'Only published components can be archived'
            );
        }

        // Update status
        $component = $this->repository->update($component, [
            'status' => ComponentStatus::ARCHIVED,
            'archived_at' => now(),
        ]);

        // Remove from search index
        $this->searchService->removeComponent($component);

        // Dispatch event
        $this->events->dispatch(new ComponentArchived(
            componentId: $component->id,
            reason: 'Archived by author',
        ));

        return ComponentDTO::fromModel($component);
    }

    public function delete(int $id): void
    {
        $component = $this->repository->findOrFail($id);

        // Business rule: Cannot delete published components
        if ($component->status === ComponentStatus::PUBLISHED) {
            throw new ComponentCannotBeDeletedException(
                'Published components must be archived before deletion'
            );
        }

        // Soft delete
        $this->repository->delete($component);

        // Remove from search
        $this->searchService->removeComponent($component);

        // Dispatch event
        $this->events->dispatch(new ComponentDeleted(
            componentId: $component->id,
        ));
    }

    public function findById(int $id): ?ComponentDTO
    {
        $component = $this->repository->find($id);

        return $component ? ComponentDTO::fromModel($component) : null;
    }

    public function findBySlug(string $slug): ?ComponentDTO
    {
        $component = $this->repository->findBySlug($slug);

        return $component ? ComponentDTO::fromModel($component) : null;
    }

    public function list(array $filters = []): LengthAwarePaginator
    {
        return $this->repository->paginate(
            perPage: $filters['per_page'] ?? 15,
            filters: $filters
        );
    }

    public function search(string $query, array $filters = []): Collection
    {
        return $this->searchService->searchComponents($query, $filters);
    }

    private function validateForPublishing(Component $component): void
    {
        // Validate description length
        if (strlen($component->description) < 50) {
            throw new ComponentValidationException(
                'Component description must be at least 50 characters'
            );
        }

        // Validate has at least one example
        if ($component->examples()->count() === 0) {
            throw new ComponentValidationException(
                'Component must have at least one example'
            );
        }
    }

    private function attachTags(Component $component, array $tags): void
    {
        foreach ($tags as $tagName) {
            $tag = Tag::firstOrCreate(
                ['name' => $tagName],
                ['slug' => Str::slug($tagName)]
            );
            $component->tags()->attach($tag);
        }
    }

    private function syncTags(Component $component, array $tags): void
    {
        $tagIds = [];
        foreach ($tags as $tagName) {
            $tag = Tag::firstOrCreate(
                ['name' => $tagName],
                ['slug' => Str::slug($tagName)]
            );
            $tagIds[] = $tag->id;
        }
        $component->tags()->sync($tagIds);
    }
}
```

```php
declare(strict_types=1);

namespace App\Domains\Themes\Services;

use App\Domains\Themes\Contracts\ThemeServiceInterface;

    public function generate(GenerateThemeData $data): ThemeDTO

            'secondary_color' => $data->secondaryColor,
            'mood' => $data->mood,
            'reference' => $data->referenceImage,
        ]);

        // Create theme from AI result
        $theme = $this->repository->create([
            'name' => $data->name ?? "Generated Theme " . now()->timestamp,
            'slug' => $data->slug ?? Str::slug($data->name ?? 'generated-theme'),
            'description' => $aiResult->description,
            'author_id' => $data->authorId,
            'is_premium' => false,
            'colors' => $aiResult->colors,
            'typography' => $aiResult->typography,
            'spacing' => $aiResult->spacing,
            'tokens' => $aiResult->tokens,
            'generated_by_ai' => true,
            'ai_model' => $aiResult->model,
        ]);

        // Dispatch event
        $this->events->dispatch(new ThemeGenerated(
            themeId: $theme->id,
            authorId: $data->authorId,
            aiModel: $aiResult->model,
        ));

        return ThemeDTO::fromModel($theme);
    }

    public function publish(int $id): ThemeDTO
    {
        $theme = $this->repository->findOrFail($id);

        // Business rule: Must have complete tokens
        if (empty($theme->tokens)) {
            throw new ThemeCannotBePublishedException(
                'Theme must have design tokens before publishing'
            );
        }

        // Update status
        $theme = $this->repository->update($theme, [
            'status' => 'published',
            'published_at' => now(),
        ]);

        // Dispatch event
        $this->events->dispatch(new ThemePublished(
            themeId: $theme->id,
            authorId: $theme->author_id,
            name: $theme->name,
        ));

        return ThemeDTO::fromModel($theme);
    }

    public function export(int $id, string $format): ThemeExportDTO
    {
        $theme = $this->repository->findOrFail($id);

        // Generate export based on format
        return match ($format) {
            'css' => $this->exportAsCss($theme),
            'tailwind' => $this->exportAsTailwind($theme),
            'figma' => $this->exportAsFigma($theme),
            'json' => $this->exportAsJson($theme),
            default => throw new InvalidExportFormatException($format),
        };
    }

    private function exportAsCss(Theme $theme): ThemeExportDTO
    {
        $css = $this->generateCssVariables($theme);

        return new ThemeExportDTO(
            themeId: $theme->id,
            format: 'css',
            content: $css,
            filename: "{$theme->slug}.css",
            size: strlen($css),
        );
    }

    private function exportAsTailwind(Theme $theme): ThemeExportDTO
    {
        $config = $this->generateTailwindConfig($theme);

        return new ThemeExportDTO(
            themeId: $theme->id,
            format: 'tailwind',
            content: $config,
            filename: "tailwind.config.js",
            size: strlen($config),
        );
    }

    private function generateCssVariables(Theme $theme): string
    {
        $css = ":root {\n";

        foreach ($theme->tokens as $category => $tokens) {
            $css .= "  /* {$category} */\n";
            foreach ($tokens as $name => $value) {
                $css .= "  --gsmui-{$name}: {$value};\n";
            }
            $css .= "\n";
        }

        $css .= "}\n";

        return $css;
    }
}
```

```php
declare(strict_types=1);

namespace App\Domains\Billing\Services;

use App\Domains\Billing\Contracts\BillingServiceInterface;
use App\Domains\Billing\Contracts\{PlanRepositoryInterface, SubscriptionRepositoryInterface};

use App\Domains\Billing\Exceptions\{SubscriptionNotFoundException, PlanNotFoundException};
use App\Domains\Users\Contracts\UserRepositoryInterface;
use App\Infrastructure\Payments\Contracts\PaymentProviderInterface;
use Illuminate\Contracts\Events\EventDispatcher;

final class BillingService implements BillingServiceInterface
{
    public function __construct(
        private readonly PlanRepositoryInterface $planRepository,
        private readonly SubscriptionRepositoryInterface $subscriptionRepository,
        private readonly UserRepositoryInterface $userRepository,
        private readonly PaymentProviderInterface $paymentProvider,
        private readonly EventDispatcher $events,
    ) {}

    public function subscribe(CreateSubscriptionData $data): SubscriptionDTO
    {
        // Find plan
        $plan = $this->planRepository->findBySlug($data->planSlug);
        if (!$plan) {
            throw new PlanNotFoundException("Plan '{$data->planSlug}' not found");
        }

        // Find user
        $user = $this->userRepository->findOrFail($data->userId);

        // Check for existing subscription
        $existingSubscription = $this->subscriptionRepository->findActiveByUser($user->id);
        if ($existingSubscription) {
            throw new ActiveSubscriptionExistsException(
                'User already has an active subscription'
            );
        }

        // Create payment on provider
        $paymentResult = $this->paymentProvider->createSubscription([
            'customer_id' => $user->stripe_customer_id ?? $this->createStripeCustomer($user),
            'plan_id' => $plan->stripe_plan_id,
            'trial_days' => $plan->trial_days,
        ]);

        // Create subscription record
        $subscription = $this->subscriptionRepository->create([
            'user_id' => $user->id,
            'plan_id' => $plan->id,
            'status' => 'active',
            'provider_subscription_id' => $paymentResult->subscriptionId,
            'trial_ends_at' => $paymentResult->trialEnd,
            'ends_at' => $paymentResult->currentPeriodEnd,
        ]);

        // Dispatch event
        $this->events->dispatch(new SubscriptionCreated(
            subscriptionId: $subscription->id,
            userId: $user->id,
            planId: $plan->id,
        ));

        return SubscriptionDTO::fromModel($subscription);
    }

    public function cancel(int $subscriptionId): SubscriptionDTO
    {
        $subscription = $this->subscriptionRepository->findOrFail($subscriptionId);

        // Business rule: Can only cancel active subscriptions
        if ($subscription->status !== 'active') {
            throw new SubscriptionCannotBeCancelledException(
                'Only active subscriptions can be cancelled'
            );
        }

        // Cancel on provider
        $this->paymentProvider->cancelSubscription(
            $subscription->provider_subscription_id
        );

        // Update subscription
        $subscription = $this->subscriptionRepository->update($subscription, [
            'status' => 'cancelled',
            'cancelled_at' => now(),
        ]);

        // Dispatch event
        $this->events->dispatch(new SubscriptionCancelled(
            subscriptionId: $subscription->id,
            userId: $subscription->user_id,
            reason: 'Cancelled by user',
        ));

        return SubscriptionDTO::fromModel($subscription);
    }

    public function handleWebhook(string $provider, array $payload): void
    {
        match ($provider) {
            'stripe' => $this->handleStripeWebhook($payload),
            'paddle' => $this->handlePaddleWebhook($payload),
            default => throw new UnsupportedProviderException($provider),
        };
    }

    private function handleStripeWebhook(array $payload): void
    {
        $type = $payload['type'];

        match ($type) {
            'checkout.session.completed' => $this->handleCheckoutCompleted($payload),
            'invoice.paid' => $this->handleInvoicePaid($payload),
            'invoice.payment_failed' => $this->handlePaymentFailed($payload),
            'customer.subscription.updated' => $this->handleSubscriptionUpdated($payload),
            'customer.subscription.deleted' => $this->handleSubscriptionDeleted($payload),
            default => null, // Ignore unhandled events
        };
    }

    private function handleCheckoutCompleted(array $payload): void
    {
        $subscriptionId = $payload['data']['object']['subscription'];
        $customerId = $payload['data']['object']['customer'];

        // Find subscription by provider ID
        $subscription = $this->subscriptionRepository->findByProviderId($subscriptionId);

        if ($subscription) {
            // Update subscription status
            $this->subscriptionRepository->update($subscription, [
                'status' => 'active',
                'activated_at' => now(),
            ]);

            // Dispatch event
            $this->events->dispatch(new SubscriptionActivated(
                subscriptionId: $subscription->id,
            ));
        }
    }

    private function handleInvoicePaid(array $payload): void
    {
        $invoice = $payload['data']['object'];

        // Create invoice record
        $invoiceRecord = $this->invoiceRepository->create([
            'user_id' => $this->resolveUserIdFromStripeCustomer($invoice['customer']),
            'amount' => $invoice['amount_paid'],
            'currency' => $invoice['currency'],
            'status' => 'paid',
            'provider_invoice_id' => $invoice['id'],
            'pdf_url' => $invoice['invoice_pdf'],
        ]);

        // Dispatch event
        $this->events->dispatch(new InvoiceGenerated(
            invoiceId: $invoiceRecord->id,
            amount: $invoiceRecord->amount,
        ));
    }
}
```

```php
// Batch processing for bulk operations

public function bulkPublish(array $componentIds): array
{
    return DB::transaction(function () use ($componentIds) {
        $results = [];

        // Batch update
        $this->repository
            ->whereIn('id', $componentIds)
            ->where('status', ComponentStatus::DRAFT)
            ->update([
                'status' => ComponentStatus::PUBLISHED,
                'published_at' => now(),
            ]);

        // Dispatch batch event
        $this->events->dispatch(new ComponentsBulkPublished(

        return $componentIds;
```

```php
// Multi-level caching

public function getPopularComponents(int $limit = 10): Collection
{
    // Level 1: Application cache (5 minutes)
    $cacheKey = "components:popular:{$limit}";

    return Cache::tags(['components', 'popular'])->remember(
        $cacheKey,

        function () use ($limit) {

            return $this->repository
```

```php
// Domain exception hierarchy

abstract class ComponentException extends \RuntimeException
{
    abstract public function statusCode(): int;
    public function toArray(): array
    {
        return [
            'error' => class_basename($this),
            'message' => $this->getMessage(),
            'status_code' => $this->statusCode(),
        ];
    }
}

class ComponentNotFoundException extends ComponentException
{
    public function statusCode(): int { return 404; }
}

class ComponentAlreadyExistsException extends ComponentException

    public function statusCode(): int { return 409; }
}

class ComponentCannotBePublishedException extends ComponentException

    public function statusCode(): int { return 422; }

    public function statusCode(): int { return 422; }
```

## Exception Handling in Controllers

```php
// Controller exception handling

class ComponentController extends Controller
{
    public function store(StoreComponentRequest $request)
    {
        try {
            $component = $this->componentService->create(
                CreateComponentData::fromRequest($request)
            );

            return redirect()
                ->route('components.show', $component->slug)
                ->with('success', 'Component created successfully');

        } catch (ComponentAlreadyExistsException $e) {
            return back()
                ->withInput()
                ->withErrors(['slug' => $e->getMessage()]);

        } catch (ComponentValidationException $e) {
            return back()
                ->withInput()
                ->withErrors(['validation' => $e->getMessage()]);
        }
    }
}
```

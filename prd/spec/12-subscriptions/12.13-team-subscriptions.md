## Purpose

Define team subscription management — how teams subscribe, how members share entitlements, and how team ownership works.

## Team Subscription Architecture

```text
Team Owner
    ↓
Team Subscription (Team plan)
    ↓
Seats (1 owner + N members)
    ↓
Shared Entitlements (workspace, downloads, AI credits)
    ↓
Individual Entitlements (per-member profile, settings)
```

## Team vs. Individual Subscriptions

| Aspect | Individual | Team |
|---|---|---|
| Billing responsibility | Individual | Team Owner |
| Entitlements | Personal | Shared pool |
| Downloads | Personal limit | Shared pool |
| AI Credits | Personal | Shared pool |
| MCP Connections | Personal | Shared pool |
| Seat count | 1 | 2–5 (expandable) |
| Workspace | No | Yes |

## Team Creation Flow

```text
User selects Team plan
    ↓
Enters team name
    ↓
Payment processed
    ↓
Team created (owner = user)
    ↓
Owner gets admin access
    ↓
Invite members
    ↓
Members accept → seats consumed
```

## Team Ownership

### Owner Responsibilities

- Billing and payment method management
- Seat assignment and removal
- Invitation management
- Plan upgrade/downgrade
- Cancellation authority

### Owner Powers

- Add/remove members
- Transfer ownership (to another team member)
- Cancel team subscription
- View team usage analytics

## Shared Entitlements

Team members share a pool of resources:

```text
Team Plan: $49/month
    ↓
5 Seats
2000 AI credits/mo (shared)
Unlimited downloads (shared)
5 MCP connections (shared)
Team workspace (shared)
```

### Entitlement Resolution for Team Members

```php
class TeamEntitlementResolver
{
    public function resolve(User $user): Collection
    {
        $team = $user->currentTeam;

        if (!$team || !$team->subscription) {
            return collect([]); // No team or subscription
        }

        $teamSubscription = $team->subscription;

        if (!$teamSubscription->isActive()) {
            return collect([]);
        }

        // Resolve team-level entitlements
        return $this->resolveFromPlan($teamSubscription->plan);
    }

    public function has(User $user, EntitlementKey $key): bool
    {
        // First check personal subscription
        if (app(EntitlementService::class)->has($user, $key)) {
            return true;
        }

        // Then check team subscription
        $team = $user->currentTeam;
        if ($team && $team->subscription) {
            return $this->resolve($user)->contains('key', $key->value);
        }

        return false;
    }
}
```

### Seat Expansion

Teams can purchase additional seats beyond the base 5:

```text
Base: 5 seats at $49/month
Additional seat: $10/month/seat
Max seats: No hard limit (enterprise for large teams)
```

```php
class SeatExpansion
{
    public function calculatePrice(Team $team, int $additionalSeats): int
    {
        $baseSeats = $team->subscription->plan->max_team_members; // 5
        $basePrice = $team->subscription->plan->price;
        $seatPrice = config('subscriptions.additional_seat_price', 1000); // $10 in cents

        return $basePrice + ($additionalSeats * $seatPrice);
    }
}
```

### Invitation Implementation

```php
class TeamInvitationManager
{
    public function invite(Team $team, string $email, User $invitedBy): void
    {
        // Check seat availability
        if ($team->members()->count() >= $team->maxSeats()) {
            throw new NoSeatsAvailableException('No seats available');
        }

        // Check for existing pending invitation
        $existing = TeamInvitation::where('team_id', $team->id)
            ->where('email', $email)
            ->whereNull('accepted_at')
            ->first();

        if ($existing) {
            throw new InvitationAlreadySentException('Invitation already sent');
        }

        $invitation = TeamInvitation::create([
            'team_id' => $team->id,
            'email' => $email,
            'invited_by' => $invitedBy->id,
            'token' => Str::random(32),
            'expires_at' => now()->addDays(7),
        ]);

        // Send invitation email
        Mail::to($email)->send(new TeamInvitationMail($invitation));

        TeamMemberInvited::dispatch($team, $email, $invitedBy);
    }

    public function accept(string $token, User $user): void
    {
        $invitation = TeamInvitation::where('token', $token)
            ->whereNull('accepted_at')
            ->where('expires_at', '>', now())
            ->firstOrFail();

        // Check seat availability
        if ($invitation->team->members()->count() >= $invitation->team->maxSeats()) {
            throw new NoSeatsAvailableException('No seats available');
        }

        $invitation->team->members()->attach($user->id, [
            'role' => 'member',
            'joined_at' => now(),
        ]);

        $invitation->update([
            'accepted_at' => now(),
            'accepted_by' => $user->id,
        ]);

        // Set as current team
        $user->current_team_id = $invitation->team->id;
        $user->save();

        // Synchronize entitlements
        app(EntitlementService::class)->invalidate($user);

        TeamMemberJoined::dispatch($invitation->team, $user);
    }
}
```

## Detailed Team Creation Flow

### Scenario: User Upgrades to Team Plan

When an individual user decides to create a team by upgrading to the Team plan.

```text
User Flow:
1. User clicks "Create Team" or selects Team plan
2. System presents team creation form:
   - Team name (required)
   - Team slug (auto-generated, editable)
   - Billing email (defaults to user email)
   - Payment method selection
3. User enters team details
4. Payment processed for Team plan ($49/month)
5. Team created with user as Owner
6. User's personal subscription migrated to team
7. Team workspace provisioned
8. Welcome email sent with next steps
9. Onboarding wizard launched
```

```php
class TeamCreationService
{
    public function create(User $user, TeamCreationData $data): Team
    {
        // Validate user doesn't already own a team
        if ($user->ownedTeams()->count() > 0) {
            throw new AlreadyOwnsTeamException('You already own a team');
        }

        // Create team
        $team = Team::create([
            'name' => $data->name,
            'slug' => $this->generateSlug($data->name),
            'owner_id' => $user->id,
            'created_by' => $user->id,
        ]);

        // Add owner as member
        $team->users()->attach($user->id, [
            'role' => 'owner',
            'joined_at' => now(),
        ]);

        // Create team subscription
        $teamPlan = Plan::where('slug', 'team')->firstOrFail();

        $subscription = Subscription::create([
            'user_id' => $user->id,
            'billable_type' => 'team',
            'billable_id' => $team->id,
            'plan_id' => $teamPlan->id,
            'status' => SubscriptionStatus::Active,
            'period_start' => now(),
            'period_end' => now()->addMonth(),
        ]);

        // Process payment
        $this->billing->createSubscription($user, $teamPlan, [
            'metadata' => [
                'team_id' => $team->id,
                'type' => 'team',
            ],
        ]);

        // Migrate personal subscription if exists
        $this->migratePersonalSubscription($user, $team);

        // Provision team workspace
        $this->provisionWorkspace($team);

        // Set as user's current team
        $user->current_team_id = $team->id;
        $user->save();

        // Synchronize entitlements
        app(EntitlementService::class)->invalidate($user);

        // Send notifications
        $user->notify(new TeamCreatedNotification($team));

        // Log event
        TeamCreated::dispatch($team, $user);

        return $team;
    }

    protected function generateSlug(string $name): string
    {
        $slug = Str::slug($name);

        // Ensure uniqueness
        $originalSlug = $slug;
        $counter = 1;

        while (Team::where('slug', $slug)->exists()) {
            $slug = "{$originalSlug}-{$counter}";
            $counter++;
        }

        return $slug;
    }

    protected function migratePersonalSubscription(User $user, Team $team): void
    {
        $personalSubscription = $user->subscriptions()
            ->where('billable_type', 'user')
            ->where('status', SubscriptionStatus::Active)
            ->first();

        if ($personalSubscription) {
            // Credit remaining personal subscription
            $credit = $this->calculateProratedCredit($personalSubscription);

            // Cancel personal subscription
            $personalSubscription->update([
                'status' => SubscriptionStatus::Canceled,
                'canceled_at' => now(),
                'ends_at' => now(), // Immediate for migration
                'metadata' => array_merge($personalSubscription->metadata ?? [], [
                    'migrated_to_team' => $team->id,
                    'credit_applied' => $credit,
                ]),
            ]);

            // Apply credit to team subscription
            $team->subscription->applyCredit($credit);

            // Notify user of credit
            $user->notify(new SubscriptionMigratedNotification($credit));
        }
    }

    protected function provisionWorkspace(Team $team): void
    {
        // Create team workspace
        $workspace = TeamWorkspace::create([
            'team_id' => $team->id,
            'name' => $team->name . ' Workspace',
            'settings' => [
                'theme' => 'default',
                'permissions' => [
                    'member_invite' => true,
                    'member_remove' => true,
                    'settings_edit' => false,
                ],
            ],
        ]);

        // Create default project
        TeamProject::create([
            'workspace_id' => $workspace->id,
            'name' => 'Default Project',
            'created_by' => $team->owner_id,
        ]);
    }
}
```

## Team Member Management

### Invitation System

```php
class TeamInvitationService
{
    public function invite(Team $team, string $email, User $invitedBy, string $role = 'member'): TeamInvitation
    {
        // Check permissions
        if (!$this->canInvite($invitedBy, $team)) {
            throw new UnauthorizedException('You do not have permission to invite members');
        }

        // Check seat availability
        if ($team->members()->count() >= $team->maxSeats()) {
            throw new NoSeatsAvailableException('No seats available. Upgrade to add more members.');
        }

        // Check for existing invitation
        $existing = TeamInvitation::where('team_id', $team->id)
            ->where('email', $email)
            ->whereNull('accepted_at')
            ->where('expires_at', '>', now())
            ->first();

        if ($existing) {
            throw new InvitationAlreadySentException('An invitation has already been sent to this email');
        }

        // Check if user is already a member
        $existingUser = User::where('email', $email)->first();
        if ($existingUser && $team->users()->where('user_id', $existingUser->id)->exists()) {
            throw new AlreadyMemberException('This user is already a team member');
        }

        // Create invitation
        $invitation = TeamInvitation::create([
            'team_id' => $team->id,
            'email' => $email,
            'role' => $role,
            'invited_by' => $invitedBy->id,
            'token' => Str::random(64),
            'expires_at' => now()->addDays(7),
        ]);

        // Send invitation email
        Mail::to($email)->send(new TeamInvitationMail($invitation));

        // Log event
        TeamMemberInvited::dispatch($team, $email, $invitedBy, $role);

        return $invitation;
    }

    public function accept(string $token, User $user): void
    {
        $invitation = TeamInvitation::where('token', $token)
            ->whereNull('accepted_at')
            ->where('expires_at', '>', now())
            ->firstOrFail();

        // Check seat availability
        if ($invitation->team->members()->count() >= $invitation->team->maxSeats()) {
            throw new NoSeatsAvailableException('No seats available');
        }

        // Check if already a member
        if ($invitation->team->users()->where('user_id', $user->id)->exists()) {
            throw new AlreadyMemberException('You are already a team member');
        }

        // Add user to team
        $invitation->team->users()->attach($user->id, [
            'role' => $invitation->role,
            'joined_at' => now(),
        ]);

        // Mark invitation as accepted
        $invitation->update([
            'accepted_at' => now(),
            'accepted_by' => $user->id,
        ]);

        // Set as user's current team if they don't have one
        if (!$user->current_team_id) {
            $user->current_team_id = $invitation->team->id;
            $user->save();
        }

        // Synchronize entitlements
        app(EntitlementService::class)->invalidate($user);

        // Send welcome notification
        $user->notify(new TeamMemberJoinedNotification($invitation->team));

        // Log event
        TeamMemberJoined::dispatch($invitation->team, $user);
    }

    public function cancel(TeamInvitation $invitation, User $cancelledBy): void
    {
        if (!$this->canManageInvitations($cancelledBy, $invitation->team)) {
            throw new UnauthorizedException('You do not have permission to cancel invitations');
        }

        $invitation->delete();

        TeamMemberInviteCancelled::dispatch($invitation->team, $invitation->email, $cancelledBy);
    }

    public function resend(TeamInvitation $invitation, User $resentBy): void
    {
        if (!$this->canManageInvitations($resentBy, $invitation->team)) {
            throw new UnauthorizedException('You do not have permission to resend invitations');
        }

        if ($invitation->expires_at->isPast()) {
            // Extend expiration
            $invitation->update([
                'expires_at' => now()->addDays(7),
                'token' => Str::random(64),
            ]);
        }

        Mail::to($invitation->email)->send(new TeamInvitationMail($invitation));

        TeamMemberInviteResent::dispatch($invitation->team, $invitation->email, $resentBy);
    }

    protected function canInvite(User $user, Team $team): bool
    {
        $role = $team->users()->where('user_id', $user->id)->first()?->pivot->role;

        return in_array($role, ['owner', 'admin']);
    }

    protected function canManageInvitations(User $user, Team $team): bool
    {
        return $this->canInvite($user, $team);
    }
}
```

### Member Role Management

```php
class TeamMemberRoleService
{
    public function changeRole(Team $team, User $member, string $newRole, User $changedBy): void
    {
        // Check permissions
        if (!$this->canChangeRole($changedBy, $team, $member)) {
            throw new UnauthorizedException('You do not have permission to change member roles');
        }

        // Cannot change owner role
        if ($member->id === $team->owner_id) {
            throw new CannotChangeOwnerRoleException('Cannot change the owner role');
        }

        // Validate role
        if (!in_array($newRole, ['admin', 'member'])) {
            throw new InvalidRoleException('Invalid role');
        }

        // Update role
        $team->users()->updateExistingPivot($member->id, [
            'role' => $newRole,
        ]);

        // Log event
        TeamMemberRoleChanged::dispatch($team, $member, $changedBy, $newRole);
    }

    public function removeMember(Team $team, User $member, User $removedBy): void
    {
        // Check permissions
        if (!$this->canRemoveMember($removedBy, $team, $member)) {
            throw new UnauthorizedException('You do not have permission to remove members');
        }

        // Cannot remove owner
        if ($member->id === $team->owner_id) {
            throw new CannotRemoveOwnerException('Cannot remove the team owner');
        }

        // Remove from team
        $team->users()->detach($member->id);

        // Invalidate entitlements
        app(EntitlementService::class)->invalidate($member);

        // Log event
        TeamMemberRemoved::dispatch($team, $member, $removedBy);
    }

    public function transferOwnership(Team $team, User $newOwner, User $currentOwner): void
    {
        // Verify current owner
        if ($currentOwner->id !== $team->owner_id) {
            throw new NotOwnerException('Only the team owner can transfer ownership');
        }

        // Verify new owner is a team member
        if (!$team->users()->where('user_id', $newOwner->id)->exists()) {
            throw new NotMemberException('New owner must be a team member');
        }

        // Update team owner
        $team->update(['owner_id' => $newOwner->id]);

        // Update roles
        $team->users()->updateExistingPivot($currentOwner->id, ['role' => 'admin']);
        $team->users()->updateExistingPivot($newOwner->id, ['role' => 'owner']);

        // Log event
        TeamOwnershipTransferred::dispatch($team, $currentOwner, $newOwner);
    }

    protected function canChangeRole(User $user, Team $team, User $member): bool
    {
        $role = $team->users()->where('user_id', $user->id)->first()?->pivot->role;

        return in_array($role, ['owner', 'admin']) && $user->id !== $member->id;
    }

    protected function canRemoveMember(User $user, Team $team, User $member): bool
    {
        $role = $team->users()->where('user_id', $user->id)->first()?->pivot->role;

        return in_array($role, ['owner', 'admin']) && $user->id !== $member->id;
    }
}
```

```php
class TeamUsageTracker
{
    public function getUsageSummary(Team $team): TeamUsageSummary
    {
        $subscription = $team->subscription;

        return new TeamUsageSummary(
            team: $team,
            members: $team->members()->count(),
            maxMembers: $team->maxSeats(),
            downloads: $this->getDownloadUsage($team),
            aiCredits: $this->getAiUsage($team),
            mcpConnections: $this->getMcpUsage($team),
            storage: $this->getStorageUsage($team),
            apiCalls: $this->getApiUsage($team),
        );
    }

    protected function getDownloadUsage(Team $team): UsageMetric
    {
        $used = DownloadRecord::where('team_id', $team->id)
            ->where('recorded_at', '>=', $team->subscription->period_start)
            ->sum('quantity');

        return new UsageMetric(
            label: 'Downloads',
            used: $used,
            limit: PHP_INT_MAX, // Unlimited for team
            unit: 'downloads',
        );
    }

    protected function getAiUsage(Team $team): UsageMetric
    {
        $used = UsageRecord::where('team_id', $team->id)
            ->where('metric', 'ai_credits')
            ->where('recorded_at', '>=', $team->subscription->period_start)
            ->sum('quantity');

        $limit = $team->subscription->plan->limits['ai_credits'] ?? 2000;

        return new UsageMetric(
            label: 'AI Credits',
            used: $used,
            limit: $limit,
            unit: 'credits',
        );
    }

    protected function getMcpUsage(Team $team): UsageMetric
    {
        $used = McpConnection::where('team_id', $team->id)
            ->where('status', 'active')
            ->count();

        $limit = $team->subscription->plan->limits['mcp_connections'] ?? 5;

        return new UsageMetric(
            label: 'MCP Connections',
            used: $used,
            limit: $limit,
            unit: 'connections',
        );
    }

    protected function getStorageUsage(Team $team): UsageMetric
    {
        $used = Storage::where('team_id', $team->id)
            ->sum('size_bytes');

        $limit = $team->subscription->plan->limits['storage'] ?? 5368709120; // 5GB

        return new UsageMetric(
            label: 'Storage',
            used: $used,
            limit: $limit,
            unit: 'bytes',
        );
    }

    protected function getApiUsage(Team $team): UsageMetric
    {
        $used = UsageRecord::where('team_id', $team->id)
            ->where('metric', 'api_calls')
            ->where('recorded_at', '>=', $team->subscription->period_start)
            ->sum('quantity');

        $limit = $team->subscription->plan->limits['api_calls'] ?? 10000;

        return new UsageMetric(
            label: 'API Calls',
            used: $used,
            limit: $limit,
            unit: 'calls',
        );
    }
}
```

```php
class TeamSubscriptionMonitoring
{
    public function getMetrics(): array
    {
        return [
            'total_teams' => Team::count(),
            'active_teams' => Team::whereHas('subscription', function ($q) {
                $q->where('status', 'active');
            })->count(),
            'total_members' => DB::table('team_user')->count(),
            'average_team_size' => $this->getAverageTeamSize(),
            'invitations_pending' => TeamInvitation::whereNull('accepted_at')
                ->where('expires_at', '>', now())
                ->count(),
            'teams_at_seat_limit' => $this->getTeamsAtSeatLimit(),
        ];
    }

    protected function getAverageTeamSize(): float
    {
        $totalMembers = DB::table('team_user')->count();
        $totalTeams = Team::count();

        return $totalTeams > 0 ? $totalMembers / $totalTeams : 0;
    }

    protected function getTeamsAtSeatLimit(): int
    {
        return Team::whereHas('subscription', function ($q) {
            $q->where('status', 'active');
        })->get()
          ->filter(fn ($team) => $team->members()->count() >= $team->maxSeats())
          ->count();
    }
}
```

```php
// app/Hooks/TeamHook.php
class TeamHook
{
    public function beforeTeamCreation(User $owner, TeamCreationData $data): void
    {
        // Validate user doesn't already own a team
        if ($owner->ownedTeams()->count() > 0) {
            throw new AlreadyOwnsTeamException('You already own a team');
        }

        // Validate team name
        if (strlen($data->name) < 3) {
            throw new InvalidTeamNameException('Team name must be at least 3 characters');
        }
    }

    public function afterTeamCreation(Team $team, User $owner): void
    {
        // Create default workspace
        if (config('subscriptions.team.workspace_enabled')) {
            TeamWorkspace::create([
                'team_id' => $team->id,
                'name' => $team->name . ' Workspace',
            ]);
        }

        // Send welcome email
        $owner->notify(new TeamCreatedNotification($team));
    }

    public function beforeMemberInvitation(Team $team, string $email, User $invitedBy): void
    {
        // Check seat availability
        if ($team->members()->count() >= $team->maxSeats()) {
            throw new NoSeatsAvailableException('No seats available');
        }

        // Check for duplicate invitation
        $existing = TeamInvitation::where('team_id', $team->id)
            ->where('email', $email)
            ->whereNull('accepted_at')
            ->where('expires_at', '>', now())
            ->exists();

        if ($existing) {
            throw new InvitationAlreadySentException('Invitation already sent');
        }
    }

    public function afterMemberInvitation(Team $team, string $email, User $invitedBy): void
    {
        // Send invitation email
        Mail::to($email)->send(new TeamInvitationMail(
            TeamInvitation::where('team_id', $team->id)
                ->where('email', $email)
                ->latest()
                ->first()
        ));
    }

    public function beforeMemberRemoval(Team $team, User $member, User $removedBy): void
    {
        // Cannot remove owner
        if ($member->id === $team->owner_id) {
            throw new CannotRemoveOwnerException('Cannot remove the team owner');
        }
    }

    public function afterMemberRemoval(Team $team, User $member, User $removedBy): void
    {
        // Invalidate member's entitlements
        app(EntitlementService::class)->invalidate($member);

        // Notify removed member
        $member->notify(new TeamMemberRemovedNotification($team));
    }
}
```

## Team Subscription Best Practices

### Do's

- Always check seat availability before sending invitations
- Use role-based access control for team operations
- Track usage at the team level for shared resources
- Provide clear upgrade paths for teams needing more seats
- Send notifications for important team events

### Don'ts

- Don't allow removing the team owner
- Don't skip validation on team name and slug
- Don't forget to invalidate entitlements when members leave
- Don't expose internal team IDs in public URLs
- Don't ignore team-level usage limits

## Team Subscription Troubleshooting

### Common Issues

#### Invitation Not Received

1. Check the email address is correct
2. Verify the invitation hasn't expired
3. Check spam/junk folders
4. Verify mail service is working

#### Member Cannot Access Team Features

1. Verify the member has accepted the invitation
2. Check the team subscription is active
3. Verify the member's role has the required permissions
4. Check entitlement cache is up to date

#### Usage Not Tracking Correctly

1. Verify the team has an active subscription
2. Check the download/usage records are being created
3. Verify the tracker service is configured correctly
4. Check for race conditions in concurrent usage

### Debug Mode

Enable debug mode for teams:

```php
// config/subscriptions.php
return [
    'team' => [
        'debug' => env('SUBSCRIPTION_TEAM_DEBUG', false),
    ],
];
```

When debug mode is enabled:
- Detailed logs are written for all team operations
- Additional metadata is included in responses
- Usage tracking is bypassed for testing

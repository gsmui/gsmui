# 12.02 — Domain Model

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

---

## Purpose

Define the core domain entities, value objects, aggregates, and relationships that comprise the GsmUi subscription system. Domain entities encapsulate both state and behavior — they enforce invariants and emit events when state changes.

## Core Entities

### Plan

The Plan entity defines a subscription product — what it costs, how often it bills, and what features it includes.

```php
class Plan extends Model
{
    protected $fillable = [
        'name', 'slug', 'description', 'price', 'currency', 'interval',
        'trial_days', 'max_team_members', 'max_downloads_per_month',
        'features', 'is_active', 'is_visible', 'sort_order',
        'stripe_price_id', 'paddle_price_id', 'lemon_squeezy_price_id',
    ];

    public function subscriptions(): HasMany;
    public function hasTrial(): bool;
    public function isFree(): bool;
    public function annualPrice(): int;
    public function featureSlugs(): array;
}
```

**Invariants:**
- Price is in minor units (cents).
- Slug is unique and immutable after creation.
- `is_active = false` prevents new subscriptions but existing ones continue.
- `trial_days = 0` means no trial for this plan.

### Subscription

The Subscription entity is the aggregate root. It tracks the current state of a user's or team's subscription.

```php
class Subscription extends Model
{
    public function billable(): MorphTo;
    public function user(): BelongsTo;
    public function plan(): BelongsTo;
    public function items(): HasMany;
    public function statusHistories(): HasMany;
    public function usageRecords(): HasMany;
    public function entitlements(): HasMany;

    public function isActive(): bool;
    public function onTrial(): bool;
    public function onGracePeriod(): bool;
    public function canceled(): bool;
    public function pastDue(): bool;

    public function cancel(): void;
    public function resume(): void;
    public function swap(int $planId): void;
    public function incrementUsage(string $metric, int $quantity = 1): void;
    public function decrementUsage(string $metric, int $quantity = 1): void;
    public function usageForPeriod(string $metric, string $period = 'month'): int;
    public function remainingForPeriod(string $metric, string $period = 'month'): int;
}
```

**Invariants:**
- Status must follow the defined state machine transitions.
- `trial_ends_at` must be in the future when status is `trialing`.
- `ends_at` is set on cancellation and must be at period end.
- `cancel_at_period_end` gates end-of-period cancellation semantics.
- One active subscription per billable entity at a time.
- Usage records are append-only.


**Invariants:**

- `from_status` is null for the initial creation event.

### SubscriptionUsageRecord

Metered usage tracking for consumption-based billing.

```php

{
    public function subscription(): BelongsTo;

```

**Invariants:**
- `recorded_at` allows backdating usage from provider webhooks.
- Composite unique on `(subscription_id, metric, recorded_at)`.

### Entitlement

Resolved access rights derived from the current subscription state.

```php
class Entitlement extends Model
{
    public function subscription(): BelongsTo;

    public function isActive(): bool;
}
```

**Invariants:**
- Entitlements are recalculated on any subscription state change.
- An entitlement has `key`, `value` (boolean, numeric, or JSON), and `expires_at`.
- Expired entitlements are excluded from resolution queries.

### EntitlementGrant

Admin overrides and promotional grants that modify base entitlements.

```php
class EntitlementGrant extends Model
{
    public function grantee(): MorphTo;
    public function grantedBy(): BelongsTo;

    public function isActive(): bool;
}
```

**Invariants:**
- Grants can override plan entitlements (increase limits, grant premium access).
- Grants have an optional `expires_at`.
- `granted_by` tracks the admin who created the grant.

### Subscription Period Calculation

```php
class SubscriptionPeriod
{
    public function __construct(
        public readonly Subscription $subscription,
    ) {}

    public function start(): Carbon
    {
        return $this->subscription->current_period_start;
    }

    public function end(): Carbon
    {
        return $this->subscription->current_period_end;
    }

    public function daysTotal(): int
    {
        return $this->start()->diffInDays($this->end());
    }

    public function daysRemaining(): int
    {
        return max(0, now()->diffInDays($this->end()));
    }

    public function progress(): float
    {
        $total = $this->daysTotal();
        if ($total === 0) return 0;
        return 1 - ($this->daysRemaining() / $total);
    }

    public function isCurrent(): bool
    {
        return now()->between($this->start(), $this->end());
    }

    public function isExpired(): bool
    {
        return now()->isAfter($this->end());
    }
}
```

### Subscription Usage Tracking

```php
class SubscriptionUsage
{
    public function increment(Subscription $subscription, string $metric, int $quantity = 1): void
    {
        $record = SubscriptionUsageRecord::create([
            'subscription_id' => $subscription->id,
            'metric' => $metric,
            'quantity' => $quantity,
            'recorded_at' => now(),
        ]);

        // Check if limit reached
        $limit = $subscription->plan->getLimit($metric);
        $currentUsage = $this->usageForPeriod($subscription, $metric);

        if ($limit && $currentUsage >= $limit) {
            UsageLimitReached::dispatch($subscription, $metric);
        }
    }

    public function usageForPeriod(Subscription $subscription, string $metric, string $period = 'month'): int
    {
        $start = match ($period) {
            'day' => now()->startOfDay(),
            'week' => now()->startOfWeek(),
            'month' => now()->startOfMonth(),
            'year' => now()->startOfYear(),
            default => now()->startOfMonth(),
        };

        return SubscriptionUsageRecord::where('subscription_id', $subscription->id)
            ->where('metric', $metric)
            ->where('recorded_at', '>=', $start)
            ->sum('quantity');
    }

    public function remaining(Subscription $subscription, string $metric): ?int
    {
        $limit = $subscription->plan->getLimit($metric);
        if ($limit === null) return null; // Unlimited

        $used = $this->usageForPeriod($subscription, $metric);
        return max(0, $limit - $used);
    }
}
```

### Entitlement Resolution Query

```php
class EntitlementQuery
{
    public function resolveForUser(User $user): EntitlementSet
    {
        $set = new EntitlementSet();

        // 1. Free tier entitlements (always available)
        $this->applyFreeTier($set);

        // 2. Subscription-based entitlements
        $subscription = $user->activeSubscription();
        if ($subscription) {
            $this->applySubscriptionEntitlements($set, $subscription);
        }

        // 3. Add-on entitlements
        if ($subscription) {
            $this->applyAddOnEntitlements($set, $subscription);
        }

        // 4. Admin grants
        $this->applyGrants($set, $user);

        // 5. Promotional grants
        $this->applyPromotions($set, $user);

        return $set->filterActive();
    }

    protected function applyFreeTier(EntitlementSet $set): void
    {
        $freeFeatures = [
            'component.free' => true,
            'theme.free' => true,
            'template.download' => 5,
            'ai.chat' => 50,
            'ai.codegen' => 10,
            'api.access' => 'read_only',
            'api.keys' => 1,
            'playground.pro' => false,
        ];

        foreach ($freeFeatures as $key => $value) {
            $set->add($key, $value);
        }
    }

    protected function applySubscriptionEntitlements(EntitlementSet $set, Subscription $subscription): void
    {
        $planFeatures = $subscription->plan->features;

        foreach ($planFeatures as $key => $value) {
            $set->add($key, $value);
        }

        // Apply limits from plan
        $limits = $subscription->plan->limits;
        foreach ($limits as $key => $value) {
            $set->add("limit.{$key}", $value);
        }
    }
}
```

### Grant Resolution Priority

When multiple grants exist for the same key, the resolution priority is:

1. **Admin Override** — Highest priority, always wins
2. **Promotional** — Overrides plan defaults
3. **Beta Access** — Specific feature access
4. **Partner Discount** — Partner-specific terms
5. **Plan Default** — Base plan entitlements

```php
class GrantResolver
{
    public function resolve(User $user, string $key): ?EntitlementGrant
    {
        return EntitlementGrant::where('grantee_type', User::class)
            ->where('grantee_id', $user->id)
            ->where('key', $key)
            ->where('expires_at', '>', now())
            ->orderByRaw("CASE type
                WHEN 'admin_override' THEN 1
                WHEN 'promotional' THEN 2
                WHEN 'beta_access' THEN 3
                WHEN 'partner_discount' THEN 4
                ELSE 5
            END")
            ->first();
    }
}
```

```text
Subscription Aggregate
├── Subscription (root)
```

**Invariants:**
- One active subscription per billable entity
- Status transitions must follow the state machine
- Trial end date must be in the future when trialing
- End date must be set on cancellation
- Usage records are append-only

## Entitlement Aggregate

```text
Entitlement Aggregate
├── Entitlement (root)
├── EntitlementValue (value object)
├── EntitlementKey (value object)

```

**Invariants:**
- Entitlements are recalculated on subscription state change
- Expired entitlements are excluded from resolution
- Grants can only increase or override, not decrease base entitlements
- Grant expiry must be in the future

# Value Objects — Extended

## Period

```php
class Period
{
    public function __construct(
        public readonly Carbon $start,
        public readonly Carbon $end,
    ) {
        if ($end->isBefore($start)) {
            throw new InvalidPeriodException('End date must be after start date');
        }
    }

    public function isCurrent(): bool
    {
        return now()->between($this->start, $this->end);
    }

    public function isExpired(): bool
    {
        return now()->isAfter($this->end);
    }

    public function daysTotal(): int
    {
        return $this->start->diffInDays($this->end);
    }

    public function daysRemaining(): int
    {
        if ($this->isExpired()) return 0;
        return now()->diffInDays($this->end);
    }

    public function daysElapsed(): int
    {
        return $this->start->diffInDays(now());
    }

    public function progress(): float
    {
        $total = $this->daysTotal();
        if ($total === 0) return 1.0;
        return $this->daysElapsed() / $total;
    }

    public function overlaps(Period $other): bool
    {
        return $this->start->isBefore($other->end)
            && $other->start->isBefore($this->end);
    }
}
```

## Money

```php
class Money
{
    public function __construct(
        public readonly int $amount,
        public readonly string $currency = 'USD',
    ) {
        if ($amount < 0) {
            throw new InvalidArgumentException('Amount cannot be negative');
        }
    }

    public function add(Money $other): Money
    {
        $this->assertSameCurrency($other);
        return new Money($this->amount + $other->amount, $this->currency);
    }

    public function subtract(Money $other): Money
    {
        $this->assertSameCurrency($other);
        return new Money(max(0, $this->amount - $other->amount), $this->currency);
    }

    public function multiply(int $factor): Money
    {
        return new Money($this->amount * $factor, $this->currency);
    }

    public function divide(int $divisor): Money
    {
        return new Money((int) round($this->amount / $divisor), $this->currency);
    }

    public function percentage(float $percent): Money
    {
        return new Money((int) round($this->amount * ($percent / 100)), $this->currency);
    }

    public function format(): string
    {
        return number_format($this->amount / 100, 2);
    }

    public function toArray(): array
    {
        return [
            'amount' => $this->amount,
            'currency' => $this->currency,
            'formatted' => $this->format(),
        ];
    }

    protected function assertSameCurrency(Money $other): void
    {
        if ($this->currency !== $other->currency) {
            throw new CurrencyMismatchException(
                "Cannot operate on different currencies: {$this->currency} and {$other->currency}"
            );
        }
    }
}
```

```php
        RevokeEntitlementsJob::dispatch($event->subscription)
            ->delay($event->subscription->ends_at);

        // 4. Schedule win-back emails
        app(WinBackService::class)->schedule($event->subscription);
    }
}
```

```php
                'value' => is_array($value) ? json_encode($value) : $value,
                'expires_at' => $value['expires_at'] ?? null,
            ]);
        }
```

## Period Operations

```php
class Period
{
    public function __construct(
        public readonly Carbon $start,
        public readonly Carbon $end,
    ) {
        if ($end->isBefore($start)) {
            throw new InvalidPeriodException('End date must be after start date');
        }
    }

    public function isCurrent(): bool
    {
        return now()->between($this->start, $this->end);
    }

    public function isExpired(): bool
    {
        return now()->isAfter($this->end);
    }

    public function daysTotal(): int
    {
        return $this->start->diffInDays($this->end);
    }

    public function daysRemaining(): int
    {
        if ($this->isExpired()) return 0;
        return now()->diffInDays($this->end);
    }

    public function daysElapsed(): int
    {
        return $this->start->diffInDays(now());
    }

    public function progress(): float
    {
        $total = $this->daysTotal();
        if ($total === 0) return 1.0;
        return $this->daysElapsed() / $total;
    }

    public function overlaps(Period $other): bool
    {
        return $this->start->isBefore($other->end)
            && $other->start->isBefore($this->end);
    }

    public function extend(int $days): Period
    {
        return new Period($this->start, $this->end->addDays($days));
    }

    public function shrink(int $days): Period
    {
        return new Period($this->start, $this->end->subDays($days));
    }
}
```

```php
class Money
{
    public function __construct(
        public readonly int $amount,
        public readonly string $currency = 'USD',
    ) {
        if ($amount < 0) {
            throw new InvalidArgumentException('Amount cannot be negative');
        }
    }

    public function add(Money $other): Money
    {
        $this->assertSameCurrency($other);
        return new Money($this->amount + $other->amount, $this->currency);
    }

    public function subtract(Money $other): Money
    {
        $this->assertSameCurrency($other);
        return new Money(max(0, $this->amount - $other->amount), $this->currency);
    }

    public function multiply(int $factor): Money
    {
        return new Money($this->amount * $factor, $this->currency);
    }

    public function divide(int $divisor): Money
    {
        return new Money((int) round($this->amount / $divisor), $this->currency);
    }

    public function percentage(float $percent): Money
    {
        return new Money((int) round($this->amount * ($percent / 100)), $this->currency);
    }

    public function format(): string
    {
        return number_format($this->amount / 100, 2);
    }

    public function isZero(): bool
    {
        return $this->amount === 0;
    }

    public function isPositive(): bool
    {
        return $this->amount > 0;
    }

    public function isNegative(): bool
    {
        return $this->amount < 0;
    }

    protected function assertSameCurrency(Money $other): void
    {
        if ($this->currency !== $other->currency) {
            throw new CurrencyMismatchException(
                "Cannot operate on different currencies: {$this->currency} and {$other->currency}"

        }
    }
```

```php
class EntitlementService
{
    public function __construct(
        protected EntitlementResolver $resolver,
        protected EntitlementCacheManager $cache,
        protected EntitlementRepository $repository,
    ) {}

    public function resolve(User $user): EntitlementSet
    {
        // Check cache first
        $cached = $this->cache->get($user);
        if ($cached !== null) {
            return $cached;
        }

        // Resolve from database
        $entitlements = $this->resolver->resolveForUser($user);

        // Store in cache
        $this->cache->put($user, $entitlements);

        return $entitlements;
    }

    public function has(User $user, string $key): bool
    {
        return $this->resolve($user)->has($key);
    }

    public function value(User $user, string $key, mixed $default = null): mixed
    {
        return $this->resolve($user)->value($key, $default);
    }

    public function synchronize(Subscription $subscription): void
    {
        $entitlements = $this->resolver->resolveForSubscription($subscription);
        $this->repository->upsertForSubscription($subscription, $entitlements->toArray());
        $this->cache->invalidate($subscription->user);
    }

    public function revoke(Subscription $subscription): void
    {
        $subscription->entitlements()->delete();
        $this->cache->invalidate($subscription->user);
    }

    public function grant(User $user, string $key, mixed $value, ?Carbon $expiresAt = null): EntitlementGrant
    {
        $grant = EntitlementGrant::create([
            'grantee_type' => User::class,
            'grantee_id' => $user->id,
            'granted_by' => auth()->id(),
            'key' => $key,
            'value' => $value,
            'expires_at' => $expiresAt,
        ]);

        $this->cache->invalidate($user);

        return $grant;
    }

    public function revokeGrant(EntitlementGrant $grant): void
    {
        $grantee = $grant->grantee;
        $grant->delete();

        if ($grantee instanceof User) {
            $this->cache->invalidate($grantee);
        }
    }
}
```

## SubscriptionService Implementation

```php
class SubscriptionService
{
    public function __construct(
        protected SubscriptionStateMachine $stateMachine,
        protected EntitlementService $entitlements,
        protected BillingProvider $billing,
        protected PriceCalculator $calculator,
    ) {}

    public function create(Billable $billable, Plan $plan, array $options = []): Subscription
    {
        // Check for existing active subscription
        $existing = $billable->activeSubscription();
        if ($existing) {
            throw new SubscriptionAlreadyExistsException();
        }

        // Create subscription
        $subscription = $billable->subscriptions()->create([
            'plan_id' => $plan->id,
            'status' => 'incomplete',
            'quantity' => $options['quantity'] ?? 1,
            'metadata' => $options['metadata'] ?? [],
        ]);

        // Transition to appropriate state
        if ($plan->hasTrial() && ($options['start_trial'] ?? true)) {
            $this->stateMachine->transitionToTrialing($subscription, $options);
        } else {
            // Process payment and activate
            $this->activateSubscription($subscription, $options);
        }

        return $subscription;
    }

    public function cancel(Subscription $subscription, bool $immediately = false): void
    {
        $this->stateMachine->transitionToCanceled($subscription, [
            'immediately' => $immediately,
            'reason' => 'User requested cancellation',
        ]);
    }

    public function resume(Subscription $subscription): void
    {
        $this->stateMachine->transitionToActiveFromCanceled($subscription);
    }

    public function swap(Subscription $subscription, Plan $newPlan): Subscription
    {
        $currentPlan = $subscription->plan;

        if ($newPlan->price > $currentPlan->price) {
            // Upgrade
            return $this->upgrade($subscription, $newPlan);
        } else {
            // Downgrade
            return $this->downgrade($subscription, $newPlan);
        }
    }

    protected function upgrade(Subscription $subscription, Plan $newPlan): Subscription
    {
        // Calculate proration
        $proration = $this->calculator->calculateProration($subscription, $newPlan);

        // Charge difference
        if ($proration->prorated_charge > 0) {
            $this->billing->charge(
                $subscription->user,
                $proration->prorated_charge,
                "Upgrade to {$newPlan->name}"
            );
        }

        // Update subscription
        $subscription->update([
            'plan_id' => $newPlan->id,
            'metadata' => array_merge($subscription->metadata ?? [], [
                'upgraded_from' => $subscription->plan_id,
                'upgraded_at' => now()->toISOString(),
            ]),
        ]);

        // Sync entitlements
        $this->entitlements->synchronize($subscription);

        SubscriptionUpgraded::dispatch($subscription, $currentPlan);

        return $subscription;
    }

    protected function downgrade(Subscription $subscription, Plan $newPlan): Subscription
    {
        // Schedule downgrade for period end
        $subscription->update([
            'metadata' => array_merge($subscription->metadata ?? [], [
                'downgrade_to' => $newPlan->id,
                'downgrade_scheduled_at' => $subscription->current_period_end->toISOString(),
            ]),
        ]);

        ApplyDowngradeJob::dispatch($subscription, $newPlan)
            ->delay($subscription->current_period_end);

        SubscriptionDowngraded::dispatch($subscription, $newPlan);

        return $subscription;
    }
}
```

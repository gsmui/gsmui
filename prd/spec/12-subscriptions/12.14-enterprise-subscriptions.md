**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

## Purpose

Define enterprise subscription management — how enterprise contracts are created, managed, and fulfilled. Enterprise subscriptions differ significantly from self-serve plans: custom pricing, contract terms, invoicing, SSO, dedicated support, and white-label options.

## Enterprise Subscription Architecture

```text
Enterprise Lead
    ↓
Sales Process (custom quote, negotiation)
    ↓
Contract Signed
    ↓
Enterprise Subscription Created
    ↓
Custom Entitlements Applied
    ↓
Team Provisioning (SSO, SCIM, custom domain)
    ↓
Dedicated Support Access
```

## Enterprise vs. Self-Serve

| Aspect | Self-Serve | Enterprise |
|---|---|---|
| Acquisition | Web checkout | Sales-led |
| Pricing | Fixed | Custom quote |
| Billing | Credit card | Invoice / PO |
| Contract | Month-to-month / annual | Multi-year |
| Payment Terms | Immediate | Net 30/60/90 |
| Seats | Fixed tiers | Unlimited / custom |
| SSO | — | SAML / OIDC |
| Support | Community / Email | Dedicated |
| SLA | None | Custom |
| White Label | — | Available |
| On-premise | — | Available |

## Enterprise Flow

### Creation

```text
1. Sales team creates quote in admin panel
2. Quote includes: custom price, seat count, term, features
3. Contract uploaded to admin panel
4. Enterprise subscription created with `pending` status
5. On payment (or invoice), status → `active`
6. Custom entitlements applied
7. Organization admin receives welcome email
```

### Renewal

Enterprise subscriptions may have automatic renewal or manual renewal based on contract terms:

```php
class EnterpriseRenewal
{
    public function process(EnterpriseSubscription $subscription): void
    {
        if ($subscription->billing_type === 'invoice') {
            // Generate invoice and send to billing contact
            Invoice::generateForEnterprise($subscription);
            $subscription->organization->notify(
                new EnterpriseRenewalInvoiceNotification($subscription)
            );
        }

        // Auto-renewal for credit card enterprise subscriptions
        if ($subscription->billing_type === 'credit_card') {
            // Process payment
            $this->billing->charge($subscription);
        }
    }
}
```

## Enterprise Entitlement Grants

Enterprise subscriptions often require custom entitlements beyond standard plan features:

```php
class EnterpriseEntitlementManager
{
    public function applyCustomEntitlements(EnterpriseSubscription $subscription): void
    {
        // Clear existing grants for clean slate
        EntitlementGrant::where('grantee_type', 'organization')
            ->where('grantee_id', $subscription->organization_id)
            ->delete();

        // Apply contract-specific grants
        $grants = $subscription->contract->entitlements ?? [];

        foreach ($grants as $key => $value) {
            EntitlementGrant::create([
                'grantee_type' => 'organization',
                'grantee_id' => $subscription->organization_id,
                'key' => $key,
                'value' => $value,
                'granted_by' => auth()->id(),
                'expires_at' => $subscription->contract_end,
            ]);
        }

        // Invalidate all member caches
        foreach ($subscription->organization->members as $member) {
            app(EntitlementService::class)->invalidate($member);
        }
    }
}
```

## Contract Lifecycle

```text
Negotiation → Signed → Active → Renewal → Expired / Renewed
                                                    ↓
                                              Data retention period (90 days)
                                                    ↓
                                              Archived
```

| State | Description |
|---|---|
| Negotiation | Quote being prepared |
| Signed | Contract signed, not yet paid |
| Active | Paid and active |
| Renewal | Contract ending, renewal in progress |
| Expired | Contract ended |
| Archived | Past data retention period |

## Detailed Enterprise Creation Flow

### Scenario: Sales-Led Enterprise Onboarding

Enterprise subscriptions are created through a sales-led process involving custom quotes, contract negotiation, and manual provisioning.

```text
Enterprise Sales Flow:
1. Lead submits inquiry or is contacted by sales
2. Discovery call to understand requirements
3. Custom quote prepared:
   - Base price negotiation
   - Seat count and pricing
   - Custom features and entitlements
   - Contract term (1-3 years)
   - Payment terms (Net 30/60/90)
   - SLA requirements
   - Support level
4. Quote approved by customer
5. Contract signed (DocuSign)
6. Finance processes contract
7. Enterprise subscription created in system
8. SSO/SCIM configuration initiated
9. Custom domain setup
10. Dedicated support channel created
11. Onboarding kickoff meeting
```

```php
class EnterpriseCreationService
{
    public function create(EnterpriseCreationData $data): EnterpriseSubscription
    {
        // Validate organization
        $organization = Organization::findOrFail($data->organization_id);

        // Create enterprise subscription
        $subscription = EnterpriseSubscription::create([
            'organization_id' => $organization->id,
            'plan_id' => $data->plan_id,
            'status' => 'pending',
            'contract_start' => $data->contract_start,
            'contract_end' => $data->contract_end,
            'billing_type' => $data->billing_type,
            'billing_term' => $data->billing_term,
            'payment_terms' => $data->payment_terms,
            'custom_price' => $data->custom_price,
            'currency' => $data->currency,
            'max_seats' => $data->max_seats,
            'notes' => $data->notes,
            'contract_file' => $data->contract_file,
        ]);

        // Create custom entitlements
        $this->createCustomEntitlements($subscription, $data->entitlements);

        // Initiate SSO configuration if required
        if ($data->sso_required) {
            $this->initiateSsoConfiguration($subscription, $data->sso_config);
        }

        // Create dedicated support channel
        $this->createSupportChannel($subscription);

        // Log creation
        EnterpriseSubscriptionCreated::dispatch($subscription);

        return $subscription;
    }

    protected function createCustomEntitlements(EnterpriseSubscription $subscription, array $entitlements): void
    {
        foreach ($entitlements as $key => $value) {
            EntitlementGrant::create([
                'grantee_type' => 'organization',
                'grantee_id' => $subscription->organization_id,
                'key' => $key,
                'value' => is_bool($value) ? $value : json_encode($value),
                'value_type' => is_bool($value) ? 'boolean' : 'json',
                'granted_by' => auth()->id(),
                'expires_at' => $subscription->contract_end,
                'metadata' => [
                    'enterprise_subscription_id' => $subscription->id,
                    'type' => 'enterprise_custom',
                ],
            ]);
        }
    }

    protected function initiateSsoConfiguration(EnterpriseSubscription $subscription, array $config): void
    {
        SsoConfiguration::create([
            'organization_id' => $subscription->organization_id,
            'provider_type' => $config['provider_type'], // saml, oidc
            'provider_config' => $config['provider_config'],
            'status' => 'pending',
            'metadata' => [
                'enterprise_subscription_id' => $subscription->id,
            ],
        ]);
    }

    protected function createSupportChannel(EnterpriseSubscription $subscription): void
    {
        SupportChannel::create([
            'organization_id' => $subscription->organization_id,
            'type' => 'dedicated',
            'channel_name' => "#{$subscription->organization->slug}-support",
            'sla_hours' => $subscription->contract->sla_response_hours ?? 4,
            'metadata' => [
                'enterprise_subscription_id' => $subscription->id,
            ],
        ]);
    }
}
```

### Quote Generation

```php
class EnterpriseQuoteGenerator
{
    public function generate(QuoteRequest $request): EnterpriseQuote
    {
        // Calculate base price
        $basePrice = $this->calculateBasePrice($request);

        // Calculate seat pricing
        $seatPrice = $this->calculateSeatPrice($request, $basePrice);

        // Calculate custom features
        $customFeaturesPrice = $this->calculateCustomFeatures($request);

        // Calculate total
        $totalMonthly = $basePrice + $seatPrice + $customFeaturesPrice;
        $totalAnnual = $totalMonthly * 12;

        // Apply term discount
        $discount = $this->calculateTermDiscount($request->contract_term, $totalAnnual);
        $finalAnnual = $totalAnnual - $discount;

        return new EnterpriseQuote(
            base_price: $basePrice,
            seat_price: $seatPrice,
            custom_features_price: $customFeaturesPrice,
            total_monthly: $totalMonthly,
            total_annual: $totalAnnual,
            term_discount: $discount,
            final_annual: $finalAnnual,
            currency: $request->currency,
            payment_terms: $request->payment_terms,
            valid_until: now()->addDays(30),
        );
    }

    protected function calculateBasePrice(QuoteRequest $request): int
    {
        $basePlan = Plan::where('slug', 'enterprise')->first();

        // Start with base enterprise price
        $basePrice = $basePlan->price;

        // Adjust for custom requirements
        if ($request->custom_features->contains('white_label')) {
            $basePrice += 5000; // $50/month extra for white label
        }

        if ($request->custom_features->contains('on_premise')) {
            $basePrice += 10000; // $100/month extra for on-premise
        }

        if ($request->custom_features->contains('dedicated_support')) {
            $basePrice += 2000; // $20/month extra for dedicated support
        }

        return $basePrice;
    }

    protected function calculateSeatPrice(QuoteRequest $request, int $basePrice): int
    {
        $seats = $request->max_seats;

        if ($seats <= 10) {
            return 0; // Included in base
        }

        // Additional seats beyond 10
        $additionalSeats = $seats - 10;
        $pricePerSeat = 2000; // $20/seat/month

        return $additionalSeats * $pricePerSeat;
    }

    protected function calculateCustomFeatures(QuoteRequest $request): int
    {
        $price = 0;

        foreach ($request->custom_features as $feature) {
            $price += match ($feature) {
                'ai_unlimited' => 10000,
                'mcp_unlimited' => 5000,
                'storage_1tb' => 5000,
                'custom_domain' => 1000,
                'sso_saml' => 3000,
                'scim' => 2000,
                default => 0,
            };
        }

        return $price;
    }

    protected function calculateTermDiscount(string $term, int $annualPrice): int
    {
        return match ($term) {
            '1_year' => 0,
            '2_year' => (int) ($annualPrice * 0.10), // 10% discount
            '3_year' => (int) ($annualPrice * 0.20), // 20% discount
            default => 0,
        };
    }
}
```

## Enterprise Contract Management

### Contract Lifecycle

```php
class EnterpriseContractManager
{
    public function renew(EnterpriseSubscription $subscription): void
    {
        if ($subscription->billing_type === 'invoice') {
            // Generate renewal invoice
            $invoice = Invoice::generateForEnterprise($subscription, [
                'type' => 'renewal',
                'period' => 'annual',
                'amount' => $subscription->custom_price,
                'due_date' => now()->addDays(30),
            ]);

            // Send to billing contact
            $billingContact = $subscription->contacts()
                ->where('type', 'billing')
                ->first();

            Mail::to($billingContact->email)
                ->send(new EnterpriseRenewalInvoice($subscription, $invoice));

            // Update status
            $subscription->update(['status' => 'renewal']);

        } elseif ($subscription->billing_type === 'credit_card') {
            // Process automatic renewal
            try {
                $this->billing->charge($subscription);

                // Extend contract
                $subscription->update([
                    'contract_start' => $subscription->contract_end,
                    'contract_end' => $subscription->contract_end->addYear(),
                    'status' => 'active',
                ]);

                // Refresh entitlements
                app(EnterpriseEntitlementManager::class)
                    ->applyCustomEntitlements($subscription);

                EnterpriseSubscriptionRenewed::dispatch($subscription);

            } catch (PaymentFailedException $e) {
                // Handle failed renewal
                $subscription->update(['status' => 'renewal_failed']);

                // Notify finance team
                Notification::route('mail', config('enterprise.finance_email'))
                    ->notify(new EnterpriseRenewalFailedNotification($subscription, $e));
            }
        }
    }

    public function terminate(EnterpriseSubscription $subscription, string $reason): void
    {
        // Archive entitlements
        $this->archiveEntitlements($subscription);

        // Revoke SSO access
        $this->revokeSsoAccess($subscription);

        // Close support channel
        $this->closeSupportChannel($subscription);

        // Archive white-label configuration
        $this->archiveWhiteLabel($subscription);

        // Update status
        $subscription->update([
            'status' => 'terminated',
            'terminated_at' => now(),
            'termination_reason' => $reason,
        ]);

        // Notify organization
        $subscription->organization->notify(
            new EnterpriseSubscriptionTerminatedNotification($subscription, $reason)
        );

        EnterpriseSubscriptionTerminated::dispatch($subscription, $reason);
    }

    protected function archiveEntitlements(EnterpriseSubscription $subscription): void
    {
        EntitlementGrant::where('grantee_type', 'organization')
            ->where('grantee_id', $subscription->organization_id)
            ->update([
                'expires_at' => now(),
                'metadata' => json_encode(array_merge(
                    json_decode($this->metadata ?? '{}', true),
                    ['archived_at' => now()->toDateTimeString()]
                )),
            ]);
    }

    protected function revokeSsoAccess(EnterpriseSubscription $subscription): void
    {
        SsoConfiguration::where('organization_id', $subscription->organization_id)
            ->update(['status' => 'revoked']);

        // Revoke all SSO sessions
        SsoSession::where('organization_id', $subscription->organization_id)
            ->update(['revoked_at' => now()]);
    }

    protected function closeSupportChannel(EnterpriseSubscription $subscription): void
    {
        SupportChannel::where('organization_id', $subscription->organization_id)
            ->where('type', 'dedicated')
            ->update(['status' => 'closed']);
    }

    protected function archiveWhiteLabel(EnterpriseSubscription $subscription): void
    {
        WhiteLabelConfig::where('organization_id', $subscription->organization_id)
            ->update([
                'status' => 'archived',
                'archived_at' => now(),
            ]);

        // Remove custom domain
        $config = WhiteLabelConfig::where('organization_id', $subscription->organization_id)
            ->first();

        if ($config && $config->custom_domain) {
            $this->dnsManager->removeDomain($config->custom_domain);
        }
    }
}
```

```php
class EnterpriseSsoManager
{
    public function configureSaml(EnterpriseSubscription $subscription, SamlConfig $config): SsoConfiguration
    {
        // Validate SAML configuration
        $this->validateSamlConfig($config);

        // Create or update SSO configuration
        $ssoConfig = SsoConfiguration::updateOrCreate(
            [
                'organization_id' => $subscription->organization_id,
            ],
            [
                'provider_type' => 'saml',
                'entity_id' => $config->entity_id,
                'sso_url' => $config->sso_url,
                'slo_url' => $config->slo_url,
                'certificate' => $config->certificate,
                'metadata_url' => $config->metadata_url,
                'status' => 'configured',
                'settings' => [
                    'sign_requests' => $config->sign_requests,
                    'want_assertions_signed' => $config->want_assertions_signed,
                    'want_response_signed' => $config->want_response_signed,
                    'name_id_format' => $config->name_id_format,
                ],
            ]
        );

        // Generate service provider metadata
        $this->generateSpMetadata($ssoConfig);

        // Test connection
        $this->testSamlConnection($ssoConfig);

        return $ssoConfig;
    }

    protected function validateSamlConfig(SamlConfig $config): void
    {
        // Validate entity ID
        if (empty($config->entity_id)) {
            throw new InvalidSamlConfigException('Entity ID is required');
        }

        // Validate SSO URL
        if (!filter_var($config->sso_url, FILTER_VALIDATE_URL)) {
            throw new InvalidSamlConfigException('Invalid SSO URL');
        }

        // Validate certificate
        $cert = openssl_pkey_get_public($config->certificate);
        if (!$cert) {
            throw new InvalidSamlConfigException('Invalid certificate');
        }
    }

    protected function generateSpMetadata(SsoConfiguration $ssoConfig): void
    {
        $metadata = SamlMetadata::generate([
            'entity_id' => config('app.url') . "/saml/{$ssoConfig->id}/metadata",
            'acs_url' => config('app.url') . "/saml/{$ssoConfig->id}/acs",
            'slo_url' => config('app.url') . "/saml/{$ssoConfig->id}/slo",
            'certificate' => $ssoConfig->certificate,
        ]);

        $ssoConfig->update(['sp_metadata' => $metadata]);
    }

    protected function testSamlConnection(SsoConfiguration $ssoConfig): void
    {
        try {
            $client = new Client();
            $response = $client->get($ssoConfig->metadata_url);

            if ($response->status() !== 200) {
                throw new SamlConnectionException('Could not fetch IdP metadata');
            }

            $ssoConfig->update(['status' => 'verified']);
        } catch (\Exception $e) {
            $ssoConfig->update(['status' => 'verification_failed']);
            throw new SamlConnectionException('SAML connection test failed: ' . $e->getMessage());
        }
    }
}
```

```php
            throw new InvalidOidcConfigException('Issuer is required');

            throw new InvalidOidcConfigException('Client ID is required');
        }

        if (empty($config->client_secret)) {

        $response = Http::get($wellKnown);

            throw new OidcDiscoveryException('Could not fetch OIDC configuration');
        }

        return $response->json();
    }
```

```php
class EnterpriseScimManager
{
    public function configureScim(EnterpriseSubscription $subscription, ScimConfig $config): ScimConfiguration
    {
        $scimConfig = ScimConfiguration::updateOrCreate(
            [
                'organization_id' => $subscription->organization_id,
            ],
            [
                'provider_type' => $config->provider_type,
                'token' => Str::random(64),
                'endpoint' => config('app.url') . "/scim/{$subscription->organization_id}",
                'status' => 'configured',
                'settings' => [
                    'sync_users' => $config->sync_users ?? true,
                    'sync_groups' => $config->sync_groups ?? true,
                    'auto_provision' => $config->auto_provision ?? true,
                    'default_role' => $config->default_role ?? 'member',
                ],
            ]
        );

        return $scimConfig;
    }

    public function provisionUser(ScimConfiguration $config, array $userData): User
    {
        // Check if user already exists
        $existingUser = User::where('email', $userData['email'])->first();

        if ($existingUser) {
            // Update existing user
            $existingUser->update([
                'name' => $userData['name']['givenName'] . ' ' . $userData['name']['familyName'],
                'scim_id' => $userData['id'],
            ]);

            // Add to organization if not already a member
            $organization = Organization::find($config->organization_id);
            if (!$organization->users()->where('user_id', $existingUser->id)->exists()) {
                $organization->users()->attach($existingUser->id, [
                    'role' => $config->settings['default_role'],
                ]);
            }

            return $existingUser;
        }

        // Create new user
        $user = User::create([
            'name' => $userData['name']['givenName'] . ' ' . $userData['name']['familyName'],
            'email' => $userData['email'],
            'password' => Hash::make(Str::random(32)), // Random password
            'email_verified_at' => now(),
            'scim_id' => $userData['id'],
        ]);

        // Add to organization
        $organization = Organization::find($config->organization_id);
        $organization->users()->attach($user->id, [
            'role' => $config->settings['default_role'],
        ]);

        // Send welcome email
        $user->notify(new ScimProvisionedNotification($organization));

        return $user;
    }

    public function deprovisionUser(ScimConfiguration $config, string $scimId): void
    {
        $user = User::where('scim_id', $scimId)->first();

        if (!$user) {
            return;
        }

        // Remove from organization
        $organization = Organization::find($config->organization_id);
        $organization->users()->detach($user->id);

        // Deactivate user
        $user->update([
            'active' => false,
            'scim_deprovisioned_at' => now(),
        ]);

        // Revoke all sessions
        $user->sessions()->delete();

        // Revoke API tokens
        $user->tokens()->delete();
    }
}
```

```php
class EnterpriseWhiteLabelManager
{
    public function configure(EnterpriseSubscription $subscription, WhiteLabelConfig $config): WhiteLabelConfiguration
    {
        // Validate custom domain
        if ($config->custom_domain) {
            $this->validateCustomDomain($config->custom_domain);
        }

        // Create white label configuration
        $whiteLabel = WhiteLabelConfiguration::updateOrCreate(
            [
                'organization_id' => $subscription->organization_id,
            ],
            [
                'custom_domain' => $config->custom_domain,
                'logo_url' => $config->logo_url,
                'favicon_url' => $config->favicon_url,
                'primary_color' => $config->primary_color,
                'secondary_color' => $config->secondary_color,
                'custom_css' => $config->custom_css,
                'remove_branding' => $config->remove_branding ?? true,
                'status' => 'configured',
            ]
        );

        // Configure DNS for custom domain
        if ($config->custom_domain) {
            $this->configureDns($config->custom_domain, $whiteLabel);
        }

        // Generate custom theme
        $this->generateCustomTheme($whiteLabel);

        return $whiteLabel;
    }

    protected function validateCustomDomain(string $domain): void
    {
        // Check domain format
        if (!filter_var("https://{$domain}", FILTER_VALIDATE_URL)) {
            throw new InvalidDomainException('Invalid domain format');
        }

        // Check if domain is already in use
        $existing = WhiteLabelConfiguration::where('custom_domain', $domain)
            ->where('status', '!=', 'archived')
            ->exists();

        if ($existing) {
            throw new DomainAlreadyUsedException('This domain is already in use');
        }

        // Check DNS propagation
        $dnsRecords = dns_get_record($domain, DNS_A);
        if (empty($dnsRecords)) {
            throw new DomainNotConfiguredException('DNS records not configured for this domain');
        }
    }

    protected function configureDns(string $domain, WhiteLabelConfiguration $whiteLabel): void
    {
        // Create DNS records
        DnsRecord::create([
            'domain' => $domain,
            'type' => 'CNAME',
```

```php
class EnterpriseAnalytics
{
    public function getOrganizationUsage(Organization $organization, string $period = 'month'): array
    {
        $subscription = $organization->enterpriseSubscription;

        return [
            'users' => $this->getUserMetrics($organization, $period),
            'downloads' => $this->getDownloadMetrics($organization, $period),
            'ai_usage' => $this->getAiMetrics($organization, $period),
            'api_usage' => $this->getApiMetrics($organization, $period),
            'support_tickets' => $this->getSupportMetrics($organization, $period),
        ];
    }

    protected function getUserMetrics(Organization $organization, string $period): array
    {
        $totalUsers = $organization->users()->count();
        $activeUsers = $organization->users()
            ->whereHas('activities', function ($q) use ($period) {
                $q->where('created_at', '>=', now()->sub($period));
            })
            ->count();

        return [
            'total' => $totalUsers,
            'active' => $activeUsers,
            'utilization_rate' => $totalUsers > 0 ? $activeUsers / $totalUsers : 0,
        ];
    }

    protected function getDownloadMetrics(Organization $organization, string $period): array
    {
        $downloads = DownloadRecord::where('team_id', $organization->team_id)
            ->where('recorded_at', '>=', now()->sub($period))
            ->count();

        $uniqueDownloaders = DownloadRecord::where('team_id', $organization->team_id)
            ->where('recorded_at', '>=', now()->sub($period))
            ->distinct('user_id')
            ->count();

        return [
            'total' => $downloads,
            'unique_users' => $uniqueDownloaders,
        ];
    }

    protected function getAiMetrics(Organization $organization, string $period): array
    {
        $creditsUsed = UsageRecord::where('team_id', $organization->team_id)
            ->where('metric', 'ai_credits')
            ->where('recorded_at', '>=', now()->sub($period))
            ->sum('quantity');

        $limit = $organization->enterpriseSubscription?->custom_entitlements['ai_credits'] ?? 10000;

        return [
            'credits_used' => $creditsUsed,
            'credits_limit' => $limit,
            'utilization_rate' => $limit > 0 ? $creditsUsed / $limit : 0,
        ];
    }

    protected function getApiMetrics(Organization $organization, string $period): array
    {
        $apiCalls = UsageRecord::where('team_id', $organization->team_id)
            ->where('metric', 'api_calls')
            ->where('recorded_at', '>=', now()->sub($period))
            ->sum('quantity');

        return [
            'total_calls' => $apiCalls,
        ];
    }

    protected function getSupportMetrics(Organization $organization, string $period): array
    {
        $tickets = SupportTicket::where('organization_id', $organization->id)
            ->where('created_at', '>=', now()->sub($period))
            ->count();

        $resolved = SupportTicket::where('organization_id', $organization->id)
            ->where('resolved_at', '>=', now()->sub($period))
            ->count();

        return [
            'total_tickets' => $tickets,
            'resolved' => $resolved,
            'resolution_rate' => $tickets > 0 ? $resolved / $tickets : 0,
        ];
    }

    public function generateInvoice(EnterpriseSubscription $subscription, string $period): EnterpriseInvoice
    {
        $usage = $this->getOrganizationUsage($subscription->organization, $period);

        return EnterpriseInvoice::create([
            'enterprise_subscription_id' => $subscription->id,
            'organization_id' => $subscription->organization_id,
            'period' => $period,
            'base_price' => $subscription->custom_price,
            'usage_charges' => $this->calculateUsageCharges($subscription, $usage),
            'total' => $subscription->custom_price + $this->calculateUsageCharges($subscription, $usage),
            'currency' => $subscription->currency,
            'status' => 'draft',
        ]);
    }

    protected function calculateUsageCharges(EnterpriseSubscription $subscription, array $usage): int
    {
        $charges = 0;

        // AI overage charges
        $aiLimit = $subscription->custom_entitlements['ai_credits'] ?? 10000;
        if ($usage['ai_usage']['credits_used'] > $aiLimit) {
            $overage = $usage['ai_usage']['credits_used'] - $aiLimit;
            $charges += $overage * 10; // $0.10 per credit overage
        }

        // API overage charges
        $apiLimit = $subscription->custom_entitlements['api_calls'] ?? 100000;
        if ($usage['api_usage']['total_calls'] > $apiLimit) {
            $overage = $usage['api_usage']['total_calls'] - $apiLimit;
            $charges += $overage * 1; // $0.01 per API call overage
        }

        return $charges;
    }
}
```

```php
        if ($subscriptions->isEmpty()) {

        return $totalValue / $subscriptions->count();
    }
```

```php
// app/Hooks/EnterpriseHook.php
class EnterpriseHook
{
    public function beforeEnterpriseCreation(Organization $organization, EnterpriseCreationData $data): void
    {
        // Validate organization doesn't have active enterprise subscription
        if ($organization->enterpriseSubscription()->where('status', 'active')->exists()) {
            throw new ActiveEnterpriseSubscriptionException('Organization already has an active enterprise subscription');
        }

        // Validate custom price
        if ($data->custom_price < 10000) { // Minimum $100/month
            throw new InvalidCustomPriceException('Minimum enterprise subscription price is $100/month');
        }
    }

    public function afterEnterpriseCreation(EnterpriseSubscription $subscription): void
    {
        // Create billing contacts
        if ($subscription->contacts()->count() === 0) {
            $subscription->contacts()->create([
                'type' => 'billing',
                'name' => $subscription->organization->owner->name,
                'email' => $subscription->organization->owner->email,
            ]);
        }

        // Send welcome email
        $subscription->organization->notify(
            new EnterpriseWelcomeNotification($subscription)
        );
    }

    public function beforeEnterpriseRenewal(EnterpriseSubscription $subscription): void
    {
        // Check for outstanding invoices
        $outstandingInvoices = Invoice::where('enterprise_subscription_id', $subscription->id)
            ->where('status', 'unpaid')
            ->where('due_date', '<', now())
            ->count();

        if ($outstandingInvoices > 0) {
            throw new OutstandingInvoicesException('Cannot renew with outstanding invoices');
        }
    }

    public function afterEnterpriseRenewal(EnterpriseSubscription $subscription): void
    {
        // Refresh entitlements
        app(EnterpriseEntitlementManager::class)->applyCustomEntitlements($subscription);

        // Send renewal confirmation
        $subscription->organization->notify(
            new EnterpriseRenewalConfirmationNotification($subscription)
        );
    }

    public function beforeEnterpriseTermination(EnterpriseSubscription $subscription, string $reason): void
    {
        // Check if termination is allowed
        if ($subscription->status === 'pending') {
            throw new CannotTerminatePendingException('Cannot terminate pending subscription');
        }
    }

    public function afterEnterpriseTermination(EnterpriseSubscription $subscription, string $reason): void
    {
        // Archive all resources
        $this->archiveResources($subscription);

        // Send termination confirmation
        $subscription->organization->notify(
            new EnterpriseTerminationNotification($subscription, $reason)
        );
    }

    protected function archiveResources(EnterpriseSubscription $subscription): void
    {
        // Archive entitlements
        EntitlementGrant::where('grantee_type', 'organization')
            ->where('grantee_id', $subscription->organization_id)
            ->update([
                'expires_at' => now(),
                'metadata' => json_encode(array_merge(
                    json_decode($this->metadata ?? '{}', true),
                    ['archived_at' => now()->toDateTimeString()]
                )),
            ]);

        // Revoke SSO
        SsoConfiguration::where('organization_id', $subscription->organization_id)
            ->update(['status' => 'revoked']);

        // Archive white label
        WhiteLabelConfiguration::where('organization_id', $subscription->organization_id)
            ->update(['status' => 'archived']);

        // Close support channel
        SupportChannel::where('organization_id', $subscription->organization_id)
            ->update(['status' => 'closed']);
    }
}
```

## Enterprise Subscription Summary

The enterprise subscription system provides comprehensive management for large organizations, including custom pricing, contract terms, SSO/SAML integration, white-label options, dedicated support, and SCIM provisioning. It supports complex billing arrangements and provides detailed analytics for enterprise accounts.

- **Usage Analytics**: Detailed organization usage tracking

## Enterprise Subscription Best Practices

### Do's

- Always validate organization before creating enterprise subscription
- Use custom pricing based on actual usage and needs
- Configure SSO before enabling user access
- Set up dedicated support channel from day one
- Track usage analytics for business reviews

- Don't forget to set up billing contacts
- Don't ignore contract renewal reminders
- Don't skip data retention policies after termination

## Enterprise Subscription Troubleshooting

### Common Issues

#### SSO Configuration Failed

1. Verify SAML metadata URL is accessible
2. Check certificate is valid and not expired
3. Verify ACS URL is correct
4. Check IdP configuration matches SP settings

#### White Label Not Working

1. Verify DNS records are configured
2. Check SSL certificate is provisioned
3. Verify custom domain is not already in use
4. Check white label settings are saved

#### Invoice Not Generated

1. Verify billing contact is set
2. Check subscription status is active
3. Verify invoice template is configured
4. Check payment terms are set correctly

### Debug Mode

Enable debug mode for enterprise:

```php
// config/subscriptions.php
return [
    'enterprise' => [
        'debug' => env('ENTERPRISE_DEBUG', false),
    ],
];
```

When debug mode is enabled:
- Detailed logs are written for all enterprise operations
- Additional metadata is included in responses
- SSO/SCIM operations are bypassed for testing

# 12.10 — Entitlements

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

## Purpose

Define the entitlement system — how subscription features are resolved, cached, and enforced across the application. Entitlements are the bridge between subscription state and application feature access.

## Entitlement Architecture

```text
Subscription
    ↓
Plan Features ──┐
Add-on Purchases ──┤
Admin Grants ──────┤──→ Entitlement Resolution → Feature Gates
Promotional Codes ──┤
Team Inheritance ───┘
```

## Entitlement Model

### Entitlement Keys

Entitlements are identified by dot-separated keys following `domain.resource.action`:

```php
enum EntitlementKey: string
{
    case ComponentFree = 'component.free';
    case ComponentPro = 'component.pro';
    case ThemeFree = 'theme.free';
    case ThemePro = 'theme.pro';
    case TemplateDownload = 'template.download';
    case AiChat = 'ai.chat';
    case AiCodegen = 'ai.codegen';
    case McpConnect = 'mcp.connect';
    case ApiAccess = 'api.access';
    case PlaygroundPro = 'playground.pro';
    case SupportPriority = 'support.priority';
    case DownloadUnlimited = 'download.unlimited';
    case TeamWorkspace = 'team.workspace';
}
```

### Entitlement Value Types

| Type | Example | Description |
|---|---|---|
| Boolean | `component.pro: true` | Feature is available or not |
| Numeric | `downloads.remaining: 85` | Remaining usage count |
| JSON | `limits: {"ai_credits": 500, "mcp_connections": 1}` | Structured limits |
| Tier | `support: "priority"` | Tiered value |

## Resolution Order

```text
1. Admin Grants (highest priority — overrides everything)
    ↓ (if not found)
2. Promotional / Complimentary Access
    ↓ (if not found)
3. Team Inheritance (if team subscription)
    ↓ (if not found)
4. Plan Features (base entitlement)
    ↓ (if not found)
5. Free Tier Default (lowest priority)
    ↓ (if not found)
6. Denied
```

### Resolution Implementation

```php
class EntitlementService
{
    public function has(Billable $billable, EntitlementKey $key): bool
    {
        $entitlements = $this->resolve($billable);

        return $entitlements->contains(function (Entitlement $e) use ($key) {
            return $e->key === $key->value && $e->isActive();
        });
    }

    public function value(Billable $billable, EntitlementKey $key): mixed
    {
        $entitlements = $this->resolve($billable);
        $entitlement = $entitlements->firstWhere('key', $key->value);

        return $entitlement?->value ?? null;
    }

    public function resolve(Billable $billable): Collection
    {
        $cacheKey = "entitlements:{$billable->getMorphClass()}:{$billable->id}";

        return Cache::remember($cacheKey, 300, function () use ($billable) {
            return $this->resolveFromSource($billable);
        });
    }

    protected function resolveFromSource(Billable $billable): Collection
    {
        $entitlements = collect([]);

        // 1. Admin grants
        $grants = EntitlementGrant::where('grantee_type', $billable->getMorphClass())
            ->where('grantee_id', $billable->id)
            ->where(function ($q) {
                $q->whereNull('expires_at')->orWhere('expires_at', '>', now());
            })
            ->get();

        foreach ($grants as $grant) {
            $entitlements->push(new Entitlement([
                'key' => $grant->key,
                'value' => $grant->value,
                'source' => 'grant',
                'expires_at' => $grant->expires_at,
            ]));
        }

        // 2. Active subscription entitlements
        $subscription = $billable->activeSubscription();

        if ($subscription && $subscription->isActive()) {
            $planFeatures = $subscription->plan->features ?? [];

            foreach ($planFeatures as $feature) {
                // Only add if not already granted (grants take priority)
                if (!$entitlements->contains('key', $feature)) {
                    $entitlements->push(new Entitlement([
                        'key' => $feature,
                        'value' => true,
                        'source' => 'plan',
                        'expires_at' => $subscription->ends_at,
                    ]));
                }
            }

            // Add plan limits
            $limits = $subscription->plan->limits ?? [];
            foreach ($limits as $key => $value) {
                $entitlements->push(new Entitlement([
                    'key' => "limit.{$key}",
                    'value' => $value,
                    'source' => 'plan',
                ]));
            }
        } else {
            // 3. Free tier defaults
            $entitlements->push(new Entitlement([
                'key' => EntitlementKey::ComponentFree->value,
                'value' => true,
                'source' => 'free',
            ]));
            $entitlements->push(new Entitlement([
                'key' => EntitlementKey::ThemeFree->value,
                'value' => true,
                'source' => 'free',
            ]));
            // ... other free defaults
        }

        return $entitlements;
    }

    public function invalidate(Billable $billable): void
    {
        $cacheKey = "entitlements:{$billable->getMorphClass()}:{$billable->id}";
        Cache::forget($cacheKey);
    }

    public function synchronize(Subscription $subscription): void
    {
        // Recalculate and cache entitlements
        $this->invalidate($subscription->billable);
        $this->resolve($subscription->billable);

        EntitlementsUpdated::dispatch($subscription);
    }
}
```

## Entitlement Caching

### Cache Strategy

| Layer | Duration | Purpose |
|---|---|---|
| In-memory (request) | Current request | Avoid repeated Redis calls |
| Redis | 5 minutes | Fast entitlement lookups |
| Database | Persistent | Source of truth |

### Cache Invalidation Triggers

- Subscription status change
- Plan features updated
- Admin grant created/expired
- Payment recovered (grace → active)
- Manual invalidation

## Admin Entitlement Grants

Admins can override base entitlements for support or promotional purposes:

```php
// app/Actions/GrantEntitlement.php
class GrantEntitlement
{
    public function grant(User $admin, Billable $billable, EntitlementKey $key, mixed $value, ?Carbon $expiresAt = null): EntitlementGrant
    {
        $grant = EntitlementGrant::create([
            'grantee_type' => $billable->getMorphClass(),
            'grantee_id' => $billable->id,
            'key' => $key->value,
            'value' => is_bool($value) ? $value : json_encode($value),
            'value_type' => is_bool($value) ? 'boolean' : 'json',
            'granted_by' => $admin->id,
            'expires_at' => $expiresAt,
        ]);

        app(EntitlementService::class)->invalidate($billable);

        EntitlementGranted::dispatch($grant);

        return $grant;
    }

    public function revoke(EntitlementGrant $grant): void
    {
        $grant->delete();

        app(EntitlementService::class)->invalidate($grant->grantee);

        EntitlementRevoked::dispatch($grant);
    }
}
```

## Detailed Entitlement Resolution

### Resolution Algorithm

The entitlement resolution algorithm determines which features and limits a user has access to based on their subscription, grants, and other sources.

```php
class EntitlementResolver
{
    public function resolve(Billable $billable): EntitlementCollection
    {
        $cacheKey = "entitlements:{$billable->getMorphClass()}:{$billable->id}";

        return Cache::remember($cacheKey, 300, function () use ($billable) {
            return $this->resolveFromSource($billable);
        });
    }

    protected function resolveFromSource(Billable $billable): EntitlementCollection
    {
        $entitlements = new EntitlementCollection();

        // Layer 1: Admin grants (highest priority)
        $this->resolveAdminGrants($billable, $entitlements);

        // Layer 2: Promotional / Complimentary access
        $this->resolvePromotionalAccess($billable, $entitlements);

        // Layer 3: Team inheritance (if team subscription)
        $this->resolveTeamInheritance($billable, $entitlements);

        // Layer 4: Plan features (base entitlement)
        $this->resolvePlanFeatures($billable, $entitlements);

        // Layer 5: Free tier defaults (lowest priority)
        $this->resolveFreeTierDefaults($billable, $entitlements);

        return $entitlements;
    }

    protected function resolveAdminGrants(Billable $billable, EntitlementCollection $entitlements): void
    {
        $grants = EntitlementGrant::where('grantee_type', $billable->getMorphClass())
            ->where('grantee_id', $billable->id)
            ->where(function ($q) {
                $q->whereNull('expires_at')
                  ->orWhere('expires_at', '>', now());
            })
            ->get();

        foreach ($grants as $grant) {
            $entitlements->put($grant->key, new Entitlement(
                key: $grant->key,
                value: $this->parseValue($grant->value, $grant->value_type),
                source: 'admin_grant',
                priority: 100,
                expires_at: $grant->expires_at,
                metadata: [
                    'granted_by' => $grant->granted_by,
                    'grant_id' => $grant->id,
                ],
            ));
        }
    }

    protected function resolvePromotionalAccess(Billable $billable, EntitlementCollection $entitlements): void
    {
        $promotions = PromotionalAccess::where('user_id', $billable->id)
            ->where(function ($q) {
                $q->whereNull('expires_at')
                  ->orWhere('expires_at', '>', now());
            })
            ->get();

        foreach ($promotions as $promotion) {
            if (!$entitlements->has($promotion->entitlement_key)) {
                $entitlements->put($promotion->entitlement_key, new Entitlement(
                    key: $promotion->entitlement_key,
                    value: true,
                    source: 'promotion',
                    priority: 90,
                    expires_at: $promotion->expires_at,
                    metadata: [
                        'promotion_id' => $promotion->id,
                        'code' => $promotion->code,
                    ],
                ));
            }
        }
    }

    protected function resolveTeamInheritance(Billable $billable, EntitlementCollection $entitlements): void
    {
        $team = $billable->currentTeam;

        if (!$team || !$team->subscription || !$team->subscription->isActive()) {
            return;
        }

        $teamEntitlements = $this->resolvePlanEntitlements($team->subscription->plan);

        foreach ($teamEntitlements as $key => $entitlement) {
            if (!$entitlements->has($key)) {
                $entitlements->put($key, new Entitlement(
                    key: $key,
                    value: $entitlement->value,
                    source: 'team',
                    priority: 70,
                    expires_at: $team->subscription->ends_at,
                    metadata: [
                        'team_id' => $team->id,
                        'team_subscription_id' => $team->subscription->id,
                    ],
                ));
            }
        }
    }

    protected function resolvePlanFeatures(Billable $billable, EntitlementCollection $entitlements): void
    {
        $subscription = $billable->activeSubscription();

        if (!$subscription || !$subscription->isActive()) {
            return;
        }

        $planEntitlements = $this->resolvePlanEntitlements($subscription->plan);

        foreach ($planEntitlements as $key => $entitlement) {
            if (!$entitlements->has($key)) {
                $entitlements->put($key, new Entitlement(
                    key: $key,
                    value: $entitlement->value,
                    source: 'plan',
                    priority: 50,
                    expires_at: $subscription->ends_at,
                    metadata: [
                        'plan_id' => $subscription->plan->id,
                        'subscription_id' => $subscription->id,
                    ],
                ));
            }
        }
    }

    protected function resolveFreeTierDefaults(Billable $billable, EntitlementCollection $entitlements): void
    {
        $freeDefaults = [
            'component.free' => true,
            'theme.free' => true,
            'playground.basic' => true,
            'support.community' => true,
            'downloads.limit' => 10,
            'ai.credits' => 50,
        ];

        foreach ($freeDefaults as $key => $value) {
            if (!$entitlements->has($key)) {
                $entitlements->put($key, new Entitlement(
                    key: $key,
                    value: $value,
                    source: 'free_tier',
                    priority: 10,
                ));
            }
        }
    }

    protected function resolvePlanEntitlements(Plan $plan): EntitlementCollection
    {
        $entitlements = new EntitlementCollection();

        // Features
        foreach ($plan->features as $feature) {
            $entitlements->put($feature, new Entitlement(
                key: $feature,
                value: true,
                source: 'plan',
                priority: 50,
            ));
        }

        // Limits
        foreach ($plan->limits as $key => $value) {
            $entitlements->put("limit.{$key}", new Entitlement(
                key: "limit.{$key}",
                value: $value,
                source: 'plan',
                priority: 50,
            ));
        }

        return $entitlements;
    }

    protected function parseValue(mixed $value, string $type): mixed
    {
        return match ($type) {
            'boolean' => (bool) $value,
            'integer' => (int) $value,
            'json' => is_string($value) ? json_decode($value, true) : $value,
            default => $value,
        };
    }
}
```

## Entitlement Value Types

### Boolean Entitlements

Simple feature flags that are either enabled or disabled.

```php
class BooleanEntitlement
{
    public function __construct(
        public string $key,
        public bool $value,
        public string $source,
        public ?Carbon $expires_at = null,
    ) {}

    public function isActive(): bool
    {
        if ($this->expires_at && $this->expires_at->isPast()) {
            return false;
        }

        return $this->value === true;
    }
}
```

### Numeric Entitlements

Count-based limits that track usage against a maximum.

```php
class NumericEntitlement
{
    public function __construct(
        public string $key,
        public int $value,
        public string $source,
        public ?Carbon $expires_at = null,
    ) {}

    public function isActive(): bool
    {
        if ($this->expires_at && $this->expires_at->isPast()) {
            return false;
        }

        return $this->value > 0;
    }

    public function isUnlimited(): bool
    {
        return $this->value === PHP_INT_MAX;
    }

    public function remaining(int $used): int
    {
        if ($this->isUnlimited()) {
            return PHP_INT_MAX;
        }

        return max(0, $this->value - $used);
    }
}
```

```php
class JsonEntitlement
{
```

### Tier Entitlements

Hierarchical values where higher tiers include lower tier capabilities.

```php
class TierEntitlement
{
    public const TIERS = [
        'community' => 0,
        'email' => 1,
        'priority' => 2,
        'dedicated' => 3,
    ];

    public function __construct(
        public string $key,
        public string $value,
        public string $source,
        public ?Carbon $expires_at = null,
    ) {}

    public function isActive(): bool
    {
        if ($this->expires_at && $this->expires_at->isPast()) {
            return false;
        }

        return isset(self::TIERS[$this->value]);
    }

    public function meetsTier(string $requiredTier): bool
    {
        $currentLevel = self::TIERS[$this->value] ?? 0;
        $requiredLevel = self::TIERS[$requiredTier] ?? 0;

        return $currentLevel >= $requiredLevel;
    }
}
```

## Entitlement Caching

### Cache Architecture

```php
class EntitlementCacheManager
{
    public function getCacheKey(Billable $billable): string
    {
        return "entitlements:{$billable->getMorphClass()}:{$billable->id}";
    }

    public function remember(Billable $billable, Closure $resolver): EntitlementCollection
    {
        $cacheKey = $this->getCacheKey($billable);

        // Check in-memory cache first
        if (isset($this->memoryCache[$cacheKey])) {
            return $this->memoryCache[$cacheKey];
        }

        // Check Redis cache
        $cached = Cache::get($cacheKey);

        if ($cached) {
            $this->memoryCache[$cacheKey] = $cached;
            return $cached;
        }

        // Resolve and cache
        $entitlements = $resolver();

        Cache::put($cacheKey, $entitlements, 300); // 5 minutes
        $this->memoryCache[$cacheKey] = $entitlements;

        return $entitlements;
    }

    public function invalidate(Billable $billable): void
    {
        $cacheKey = $this->getCacheKey($billable);

        // Clear both caches
        unset($this->memoryCache[$cacheKey]);
        Cache::forget($cacheKey);
    }

    public function invalidateAll(): void
    {
        // Clear in-memory cache
        $this->memoryCache = [];

        // Clear Redis cache pattern
        $keys = Cache::getRedis()->keys('entitlements:*');
        foreach ($keys as $key) {
            Cache::forget($key);
        }
    }
}
```

### Cache Invalidation Triggers

```php
class EntitlementCacheInvalidator
{
    public function boot(): void
    {
        // Invalidate on subscription status change
        Model::without(function () {
            Subscription::observe(SubscriptionCacheObserver::class);
        });

        // Invalidate on plan feature changes
        Plan::observe(PlanCacheObserver::class);

        // Invalidate on admin grant changes
        EntitlementGrant::observe(GrantCacheObserver::class);
    }
}

class SubscriptionCacheObserver
{
    public function updated(Subscription $subscription): void
    {
        if ($subscription->isDirty(['status', 'plan_id', 'ends_at'])) {
            app(EntitlementCacheManager::class)->invalidate($subscription->billable);
        }
    }
}

class PlanCacheObserver
{
    public function updated(Plan $plan): void
    {
        if ($plan->isDirty(['features', 'limits'])) {
            // Invalidate all users on this plan
            Subscription::where('plan_id', $plan->id)
                ->each(fn ($sub) => app(EntitlementCacheManager::class)->invalidate($sub->billable));
        }
    }
}

class GrantCacheObserver
{
    public function created(EntitlementGrant $grant): void
    {
        $billable = $grant->grantee;
        if ($billable) {
            app(EntitlementCacheManager::class)->invalidate($billable);
        }
    }

    public function deleted(EntitlementGrant $grant): void
    {
        $billable = $grant->grantee;
        if ($billable) {
            app(EntitlementCacheManager::class)->invalidate($billable);
        }
    }
}
```

## Entitlement Collection

### Collection Class

```php
class EntitlementCollection extends Collection
{
    public function has(string $key): bool
    {
        return $this->contains(fn (Entitlement $e) => $e->key === $key && $e->isActive());
    }

    public function value(string $key, mixed $default = null): mixed
    {
        $entitlement = $this->first(fn (Entitlement $e) => $e->key === $key && $e->isActive());

        return $entitlement?->value ?? $default;
    }

    public function boolean(string $key): bool
    {
        return $this->value($key, false) === true;
    }

    public function numeric(string $key, int $default = 0): int
    {
        return (int) $this->value($key, $default);
    }

    public function json(string $key, array $default = []): array
    {
        return (array) $this->value($key, $default);
    }

    public function tier(string $key, string $default = 'community'): string
    {
        return (string) $this->value($key, $default);
    }

    public function for(string $source): self
    {
        return $this->filter(fn (Entitlement $e) => $e->source === $source);
    }

    public function active(): self
    {
        return $this->filter(fn (Entitlement $e) => $e->isActive());
    }

    public function expired(): self
    {
        return $this->filter(fn (Entitlement $e) => !$e->isActive());
    }

    public function toArray(): array
    {
        return $this->map(fn (Entitlement $e) => [
            'key' => $e->key,
            'value' => $e->value,
            'source' => $e->source,
            'priority' => $e->priority,
            'expires_at' => $e->expires_at?->toIso8601String(),
            'is_active' => $e->isActive(),
            'metadata' => $e->metadata,
        ])->toArray();
    }
}
```

## Entitlement API

### API Endpoints

```php
// routes/api.php
Route::middleware('auth:sanctum')->group(function () {
    // Get all entitlements
    Route::get('/entitlements', function () {
        $entitlements = app(EntitlementService::class)

        return response()->json([
            'entitlements' => $entitlements->toArray(),

            ->value(auth()->user(), EntitlementKey::from($key));

        return response()->json([
            'key' => $key,
            'value' => $value,
        ]);
    });
});
```

```php
class EntitlementTest extends TestCase
```

```php
{
    public function handle(EntitlementsUpdated $event): void
    {
        $added = $event->newEntitlements->diffKeys($event->oldEntitlements);
        $removed = $event->oldEntitlements->diffKeys($event->newEntitlements);
        $changed = $event->newEntitlements->filter(function ($value, $key) use ($event) {

                   $event->oldEntitlements->get($key) !== $value;

                'added' => $added->toArray(),
                'removed' => $removed->toArray(),
                'changed' => $changed->toArray(),
```

### Monitoring Service

```php
class EntitlementMonitoring
{
    public function getMetrics(): array
    {
        return [
            'total_entitlements_resolved' => $this->getTotalResolutions(),
            'cache_hit_rate' => $this->getCacheHitRate(),
            'average_resolution_time' => $this->getAverageResolutionTime(),
            'active_grants' => $this->getActiveGrantsCount(),
            'expiring_grants_7d' => $this->getExpiringGrantsCount(7),
            'expired_grants_24h' => $this->getExpiredGrantsCount(24),
            'entitlement_changes_24h' => $this->getEntitlementChangesCount(24),
        ];
    }

    protected function getTotalResolutions(): int
    {
        return Cache::get('entitlement_metrics:total_resolutions', 0);
    }

    protected function getCacheHitRate(): float
    {
        $hits = Cache::get('entitlement_metrics:cache_hits', 0);
        $misses = Cache::get('entitlement_metrics:cache_misses', 0);
        $total = $hits + $misses;

        return $total > 0 ? $hits / $total : 0;
    }

    protected function getAverageResolutionTime(): float
    {
        return Cache::get('entitlement_metrics:avg_resolution_time_ms', 0);
    }

    protected function getActiveGrantsCount(): int
    {
        return EntitlementGrant::where(function ($q) {
            $q->whereNull('expires_at')
              ->orWhere('expires_at', '>', now());
        })->count();
    }

    protected function getExpiringGrantsCount(int $days): int
    {
        return EntitlementGrant::where('expires_at', '>', now())
            ->where('expires_at', '<=', now()->addDays($days))
            ->count();
    }

    protected function getExpiredGrantsCount(int $hours): int
    {
        return EntitlementGrant::where('expires_at', '>=', now()->subHours($hours))
            ->where('expires_at', '<=', now())
            ->count();
    }

    protected function getEntitlementChangesCount(int $hours): int
    {
        return EntitlementAuditLog::where('created_at', '>=', now()->subHours($hours))
            ->count();
    }
}
```

```php
// app/Hooks/EntitlementHook.php
class EntitlementHook
{
    public function beforeGrant(EntitlementGrant $grant): void
    {
        // Validate grant doesn't exceed limits
        $existingGrants = EntitlementGrant::where('grantee_type', $grant->grantee_type)
            ->where('grantee_id', $grant->grantee_id)
            ->count();

        if ($existingGrants >= config('entitlements.max_grants_per_user', 50)) {
            throw new MaxGrantsReachedException('Maximum grants per user reached');
        }
    }

    public function afterGrant(EntitlementGrant $grant): void
    {
        // Invalidate cache
        app(EntitlementCacheManager::class)->invalidate($grant->grantee);

        // Log the grant
        activity()
            ->performedOn($grant->grantee)
            ->withProperties([
                'key' => $grant->key,
                'value' => $grant->value,
                'expires_at' => $grant->expires_at,
            ])
            ->log('entitlement.granted');
    }

    public function beforeRevoke(EntitlementGrant $grant): void
    {
        // Check if revoking would break critical functionality
        $criticalKeys = ['component.free', 'theme.free', 'support.community'];

        if (in_array($grant->key, $criticalKeys)) {
            throw new CannotRevokeCriticalEntitlementException(
                'Cannot revoke critical entitlement'
            );
        }
    }

    public function afterRevoke(EntitlementGrant $grant): void
    {
        // Invalidate cache
        app(EntitlementCacheManager::class)->invalidate($grant->grantee);

        // Log the revocation
        activity()
            ->performedOn($grant->grantee)
            ->withProperties([
                'key' => $grant->key,
                'value' => $grant->value,
            ])
            ->log('entitlement.revoked');
    }

    public function beforeExpiration(EntitlementGrant $grant): void
    {
        // Send warning notification
        if ($grant->grantee_type === 'user') {
            $user = User::find($grant->grantee_id);
            if ($user) {
                $user->notify(new EntitlementExpiringNotification($grant));
            }
        }
    }

    public function afterExpiration(EntitlementGrant $grant): void
    {
        // Invalidate cache
        app(EntitlementCacheManager::class)->invalidate($grant->grantee);

        // Log the expiration
        activity()
            ->performedOn($grant->grantee)
            ->withProperties([
                'key' => $grant->key,
                'expired_at' => now(),
            ])
            ->log('entitlement.expired');
    }
}
```

```php
// app/Webhooks/EntitlementWebhook.php
class EntitlementWebhook
{
    public function onEntitlementGranted(EntitlementGrant $grant): void
    {
        $this->sendWebhook('entitlement.granted', [
            'grantee_type' => $grant->grantee_type,
            'grantee_id' => $grant->grantee_id,
            'key' => $grant->key,
            'value' => $grant->value,
            'expires_at' => $grant->expires_at?->toIso8601String(),
        ]);
    }

    public function onEntitlementRevoked(EntitlementGrant $grant): void
    {
        $this->sendWebhook('entitlement.revoked', [
            'grantee_type' => $grant->grantee_type,
            'grantee_id' => $grant->grantee_id,
            'key' => $grant->key,
        ]);
    }

    public function onEntitlementsUpdated(Subscription $subscription): void
    {
        $entitlements = app(EntitlementService::class)->resolve($subscription->billable);

        $this->sendWebhook('entitlements.updated', [
            'billable_type' => $subscription->billable_type,
            'billable_id' => $subscription->billable_id,
            'entitlements' => $entitlements->toArray(),
        ]);
    }

    protected function sendWebhook(string $event, array $payload): void
    {
        $webhooks = WebhookEndpoint::where('events', 'like', "%{$event}%")
            ->where('active', true)
            ->get();

        foreach ($webhooks as $webhook) {
            Http::withHeaders([
                'X-Gsmui-Event' => $event,
                'X-Gsmui-Signature' => $this->generateSignature($payload),
            ])->timeout(10)->post($webhook->url, $payload);
        }
    }

    protected function generateSignature(array $payload): string
    {
        $secret = config('webhooks.secret');

        return hash_hmac('sha256', json_encode($payload), $secret);
    }
}
```

## Entitlement Cache Warming

### Cache Warmer Service

```php
class EntitlementCacheWarmer
{
    public function warmAll(): void
    {
        $users = User::whereHas('subscriptions', function ($q) {
            $q->where('status', 'active');
        })->get();

        foreach ($users as $user) {
            $this->warmForUser($user);
        }
    }

    public function warmForUser(User $user): void
    {
        $cacheKey = "entitlements:{$user->getMorphClass()}:{$user->id}";

        $entitlements = $this->resolveFromSource($user);

        Cache::put($cacheKey, $entitlements, 300);
    }

    public function warmForPlan(Plan $plan): void
    {
        $users = User::whereHas('subscriptions', function ($q) use ($plan) {
            $q->where('plan_id', $plan->id)
              ->where('status', 'active');
        })->get();

        foreach ($users as $user) {
            $this->warmForUser($user);
        }
    }

    protected function resolveFromSource(Billable $billable): EntitlementCollection
    {
        return app(EntitlementService::class)->resolve($billable);
    }
}
```

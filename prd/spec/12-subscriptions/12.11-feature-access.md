## Purpose

Define how entitlements are enforced as feature gates throughout the application — in Blade templates, Livewire components, API middleware, and backend services.

## Feature Gate Architecture

```text
Application Request
    ↓
Middleware / Component / Service
    ↓
EntitlementService::has(user, key)
    ↓
Cache check (Redis)
    ↓
Entitlement Resolution
    ↓
Grant / Deny
```

### Backend Service

```php
class AiChatService
{
    public function chat(User $user, string $message): string
    {
        $entitlement = app(EntitlementService::class);

        if (!$entitlement->has($user, EntitlementKey::AiChat)) {
            throw new EntitlementRequiredException('AI chat requires an active subscription');
        }

        // Check credit usage
        $remaining = $entitlement->value($user, EntitlementKey::AiChat);
        if ($remaining !== null && $remaining <= 0) {
            throw new InsufficientCreditsException('AI chat credits exhausted');
        }

        // Process chat
        $response = $this->ai->chat($message);

        // Decrement credits
        $subscription = $user->activeSubscription();
        $subscription?->incrementUsage('ai_chat_credits', 1);

        return $response;
    }
}
```

## Detailed Feature Gate Implementation

### Gate Registration

Feature gates are registered during application bootstrap, allowing centralized management of all access control points.

```php
class FeatureGateRegistry
{
    protected array $gates = [];

    public function register(string $key, callable $resolver): void
    {
        $this->gates[$key] = $resolver;
    }

    public function definition(string $key): ?array
    {
        return $this->gates[$key] ?? null;
    }

    public function all(): array
    {
        return $this->gates;
    }

    public function boot(): void
    {
        // Register all gates
        $this->register('component.free', fn (User $user) => true);
        $this->register('component.pro', fn (User $user) =>
            app(EntitlementService::class)->has($user, EntitlementKey::ComponentPro)
```

### Middleware Gate

HTTP middleware that protects routes requiring specific entitlements.

```php
class EntitlementMiddleware
{
    public function handle(Request $request, Closure $next, string $key, string $operator = '>=', mixed $value = null): Response
    {
        $user = $request->user();

        if (!$user) {
            return $this->unauthorizedResponse($key);
        }

        $entitlementService = app(EntitlementService::class);

        // Check if user has the entitlement
        if (!$entitlementService->has($user, EntitlementKey::from($key))) {
            return $this->forbiddenResponse($key);
        }

        // If value comparison is required
        if ($value !== null) {
            $entitlementValue = $entitlementService->value($user, EntitlementKey::from($key));

            if (!$this->compareValues($entitlementValue, $operator, $value)) {
                return $this->forbiddenResponse($key);
            }
        }

        return $next($request);
    }

    protected function compareValues(mixed $actual, string $operator, mixed $expected): bool
    {
        return match ($operator) {
            '=' => $actual == $expected,
            '!=' => $actual != $expected,
            '>' => $actual > $expected,
            '>=' => $actual >= $expected,
            '<' => $actual < $expected,
            '<=' => $actual <= $expected,
            default => false,
        };
    }

    protected function unauthorizedResponse(string $key): JsonResponse
    {
        return response()->json([
            'error' => 'Unauthenticated',
            'message' => 'Please log in to access this feature',
        ], 401);
    }

    protected function forbiddenResponse(string $key): JsonResponse
    {
        $gate = app(FeatureGateRegistry::class)->definition($key);

        return response()->json([
            'error' => 'Forbidden',
            'message' => "Access denied. Requires entitlement: {$key}",
            'upgrade_url' => '/billing',
            'required_entitlement' => $key,
            'feature_name' => $gate?->name ?? $key,
        ], 403);
    }
}
```

### Service Gate

Backend service classes that enforce entitlements before processing.

```php
class AiChatService
{
    public function chat(User $user, string $message, array $context = []): AiChatResponse
    {
        $entitlement = app(EntitlementService::class);

        // Check basic access
        if (!$entitlement->has($user, EntitlementKey::AiChat)) {
            throw new EntitlementRequiredException(
                'AI chat requires an active subscription',
                EntitlementKey::AiChat
            );
        }

        // Check credit usage
        $creditsUsed = $this->getUsage($user, 'ai_chat_credits');
        $creditsLimit = $entitlement->value($user, EntitlementKey::AiCredits) ?? 0;

        if ($creditsLimit > 0 && $creditsUsed >= $creditsLimit) {
            throw new InsufficientCreditsException(
                'AI chat credits exhausted',
                used: $creditsUsed,
                limit: $creditsLimit
            );
        }

        // Process chat
        $response = $this->ai->chat($message, $context);

        // Increment usage
        $this->incrementUsage($user, 'ai_chat_credits');

        return $response;
    }
}
```

```php
class UpgradePromptContextBuilder
{
    public function build(User $user, string $feature): UpgradePromptContext
    {
        $entitlement = app(EntitlementService::class);
        $gate = app(FeatureGateRegistry::class)->definition($feature);

        $requiredPlan = $gate?->requiredPlan ?? 'pro';
        $plan = Plan::where('slug', $requiredPlan)->first();

        return new UpgradePromptContext(
            feature: $gate?->name ?? $feature,
            requiredPlan: $plan->name,
            benefits: $gate?->benefits ?? [],
            canTrial: app(TrialService::class)->canTrial($user, $plan),
            currentPlan: $user->activeSubscription()?->plan?->name ?? 'Free',
            upgradeUrl: '/billing?plan=' . $plan->slug,
        );
    }
```

## Feature Access Middleware Stack

### Combined Middleware

```php
// app/Http/Middleware/FeatureAccessStack.php
class FeatureAccessStack
{
    public function handle(Request $request, Closure $next, ...$features): Response
    {
        $user = $request->user();

        if (!$user) {
            return $this->redirectOrAbort($request, 'login');
        }

        $entitlementService = app(EntitlementService::class);

        foreach ($features as $feature) {
            $key = EntitlementKey::tryFrom($feature);

            if ($key && !$entitlementService->has($user, $key)) {
                if ($request->expectsJson()) {
                    return response()->json([
                        'error' => 'Forbidden',
                        'message' => "Access denied. Requires: {$feature}",
                        'upgrade_url' => '/billing',
                    ], 403);
                }

                return redirect('/billing')
                    ->with('error', "This feature requires a subscription upgrade.");
            }
        }

        return $next($request);
    }
}
```

## Feature Gate Monitoring

### Monitoring Service

```php
class FeatureGateMonitoring
{
    public function getMetrics(): array
    {
        return [
            'total_checks_24h' => $this->getTotalChecks(24),
            'grant_rate_24h' => $this->getGrantRate(24),
            'denial_rate_24h' => $this->getDenialRate(24),
            'top_denied_features' => $this->getTopDeniedFeatures(),
            'upgrade_prompt_clicks' => $this->getUpgradePromptClicks(),
            'upgrade_conversions' => $this->getUpgradeConversions(),
        ];
    }

    protected function getTotalChecks(int $hours): int
    {
        return FeatureGateLog::where('created_at', '>=', now()->subHours($hours))
            ->count();
    }

    protected function getGrantRate(int $hours): float
    {
        $total = $this->getTotalChecks($hours);
        $granted = FeatureGateLog::where('created_at', '>=', now()->subHours($hours))
            ->where('granted', true)
            ->count();

        return $total > 0 ? $granted / $total : 0;
    }

    protected function getDenialRate(int $hours): float
    {
        return 1 - $this->getGrantRate($hours);
    }

    protected function getTopDeniedFeatures(): array
    {
        return FeatureGateLog::where('granted', false)
            ->where('created_at', '>=', now()->subDays(7))
            ->select('feature')
            ->selectRaw('count(*) as count')
            ->groupBy('feature')
            ->orderByDesc('count')
            ->limit(10)
            ->get()
            ->pluck('count', 'feature')
            ->toArray();
    }

    protected function getUpgradePromptClicks(): int
    {
        return Analytics::where('event', 'upgrade_prompt_clicked')
            ->where('created_at', '>=', now()->subDays(30))
            ->count();
    }

    protected function getUpgradeConversions(): int
    {
        return Subscription::where('status', 'active')
            ->where('created_at', '>=', now()->subDays(30))
            ->count();
    }
}
```

```php
// app/Hooks/FeatureGateHook.php
class FeatureGateHook
{
    public function beforeFeatureCheck(User $user, string $feature): void
    {
        // Log the check attempt
        if (config('feature-gates.logging')) {
            // Will be logged after check completes
        }
    }

    public function afterFeatureCheck(User $user, string $feature, bool $granted): void
    {
        // Log the result
        if (config('feature-gates.logging')) {
            FeatureGateLog::create([
                'user_id' => $user->id,
                'feature' => $feature,
                'granted' => $granted,
                'source' => $this->determineSource($user, $feature),
            ]);
        }

        // Track analytics
        if (config('feature-gates.analytics')) {
            if ($granted) {
                FeatureAccessGranted::dispatch($user, $feature, $this->determineSource($user, $feature));
            } else {
                FeatureAccessDenied::dispatch($user, $feature, 'entitlement_not_found');
            }
        }
    }

    protected function determineSource(User $user, string $feature): string
    {
        $entitlement = app(EntitlementService::class);

        if ($entitlement->has($user, EntitlementKey::from($feature))) {
            $entitlements = $entitlement->resolve($user);
            $ent = $entitlements->firstWhere('key', $feature);

            return $ent?->source ?? 'unknown';
        }

        return 'not_entitled';
    }
}
```

```php
class FeatureGateRateLimiter
{
    public function attempt(User $user, string $feature): bool
    {
        $key = "feature_gate:{$user->id}:{$feature}";
        $maxAttempts = config('feature-gates.rate_limit_max', 60);

        return RateLimiter::attempt($key, $maxAttempts, fn () => true, 60);

    {

    }

    {
        $key = "feature_gate:{$user->id}:{$feature}";
        RateLimiter::clear($key);
    }
}
```

### Rate Limit Middleware

```php
class FeatureGateRateLimitMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $user = $request->user();
        $feature = $request->route('feature');

        if (!$user || !$feature) {
            return $next($request);
        }

            return response()->json([
                'error' => 'Too many requests',
                'message' => 'You have exceeded the rate limit for feature checks.',
                'retry_after' => 60,
            ], 429);
        }

        return $next($request);
    }
}
```

## Feature Gate Caching

### Cache Strategy

```php
class FeatureGateCache
{
    public function get(User $user, string $feature): ?bool
    {
        $key = "feature_gate:{$user->id}:{$feature}";
        $duration = config('feature-gates.cache_duration', 60);

        return Cache::remember($key, $duration, function () use ($user, $feature) {
            $gate = app(FeatureGateRegistry::class)->definition($feature);

            return $gate?->check($user);
        });
    }

    public function invalidate(User $user, string $feature = null): void
    {
        if ($feature) {
            $key = "feature_gate:{$user->id}:{$feature}";
            Cache::forget($key);
        } else {
            // Invalidate all features for user
            $keys = Cache::getRedis()->keys("feature_gate:{$user->id}:*");
            foreach ($keys as $key) {
                Cache::forget($key);
            }
        }
    }

    public function warm(User $user): void
    {
        $registry = app(FeatureGateRegistry::class);

        foreach ($registry->all() as $feature => $gate) {
            $this->get($user, $feature);
        }
    }
}
```

## Feature Gate Summary

The feature gate system provides a comprehensive way to control access to features based on user entitlements. It integrates with Blade templates, Livewire components, API middleware, and backend services to ensure consistent access control throughout the application.

### Key Components

- **FeatureGateRegistry**: Central registry for all feature gates
- **EntitlementMiddleware**: HTTP middleware for route protection
- **Blade Directives**: `@feature` and `@featuregate` for template rendering
- **UpgradePrompt**: Component for showing upgrade prompts to users
- **AuditLogger**: Tracks all feature access attempts
- **RateLimiter**: Prevents abuse of feature check endpoints
- **Cache**: Optimizes feature check performance

## Feature Gate Best Practices

### Do's

- Always provide an upgrade prompt when access is denied
- Cache entitlement checks to improve performance
- Log all feature access attempts for analytics
- Use descriptive feature keys (e.g., `component.pro` not `premium`)
- Test both granted and denied scenarios

### Don'ts

- Don't expose internal feature gate logic to the client
- Don't skip rate limiting on feature check endpoints
- Don't forget to invalidate cache when entitlements change
- Don't hardcode feature gate checks - use the registry
- Don't ignore audit logging for compliance

## Feature Gate Troubleshooting

### Common Issues

#### Feature Check Returns False Unexpectedly

1. Verify the feature is registered in `FeatureGateRegistry`
2. Check the entitlement is assigned to the user
3. Verify the cache is not stale - try invalidating cache
4. Check if an admin grant is overriding the entitlement

#### Upgrade Prompt Not Showing

1. Ensure `showPrompt` prop is not set to `false`
2. Check the Blade directive is rendering correctly
3. Verify the user is authenticated

#### Middleware Not Working

1. Verify the middleware is registered in `RouteServiceProvider`
2. Check the feature key is valid (matches `EntitlementKey` enum)
3. Ensure the user is authenticated before the middleware runs

#### Cache Stale After Upgrade

1. Call `EntitlementService::invalidate($user)` after plan changes
2. Check `EntitlementCacheManager` is properly configured
3. Verify cache driver is working (Redis recommended)

### Debug Mode

Enable debug mode for feature gates:

```php
// config/feature-gates.php
return [
    'debug' => env('FEATURE_GATE_DEBUG', false),
];
```

When debug mode is enabled:
- Detailed logs are written for every feature check
- Cache bypass is enabled
- Additional metadata is included in responses

## Feature Gate Performance

### Optimization Tips

1. **Cache entitlement checks**: Use the built-in cache layer
2. **Warm cache for active users**: Run cache warming jobs
3. **Batch feature checks**: When checking multiple features, resolve entitlements once
4. **Use in-memory cache**: Enable for request-level caching
5. **Monitor cache hit rate**: Keep above 80%

### Performance Metrics

```php
class FeatureGatePerformance
{
    public function getMetrics(): array
    {
        return [
            'avg_check_time_ms' => $this->getAverageCheckTime(),
            'cache_hit_rate' => $this->getCacheHitRate(),
            'p95_check_time_ms' => $this->getP95CheckTime(),
            'p99_check_time_ms' => $this->getP99CheckTime(),
            'total_checks_24h' => $this->getTotalChecks(24),
        ];
    }

    protected function getAverageCheckTime(): float
    {
        return Cache::get('feature_gate_perf:avg_time', 0);
    }

    protected function getCacheHitRate(): float
    {
        $hits = Cache::get('feature_gate_perf:cache_hits', 0);
        $misses = Cache::get('feature_gate_perf:cache_misses', 0);
        $total = $hits + $misses;

        return $total > 0 ? $hits / $total : 0;
    }

    protected function getP95CheckTime(): float
    {
        return Cache::get('feature_gate_perf:p95_time', 0);
    }

    protected function getP99CheckTime(): float
    {
        return Cache::get('feature_gate_perf:p99_time', 0);
    }

    protected function getTotalChecks(int $hours): int
    {
        return FeatureGateLog::where('created_at', '>=', now()->subHours($hours))
            ->count();
    }
}
```

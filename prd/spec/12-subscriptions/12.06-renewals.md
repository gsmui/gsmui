# 12.06 — Renewals

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

---

## Purpose

Define how subscription renewals work — automatic billing, renewal timing, notification cadence, and failure handling. Renewals are the lifeblood of recurring revenue.

## Renewal Architecture

```text
Subscription Active
    ↓
Billing date approaches
    ↓
[ grace period before billing ]
    ↓
Renewal invoice generated
    ↓
Payment method charged
    ↓
Success ────────────── Failure
  ↓                        ↓
Active (renewed)      Past Due (retry)
```

## Renewal Flow

### Automatic Renewal

All paid subscriptions renew automatically. The billing provider handles the charge; the platform reconciles via webhook.

```text
T-7 days:  Renewal reminder email
T-1 day:   Payment method verification
T-0:       Provider charges payment method
           ↓
Webhook received: invoice.payment_succeeded
           ↓
Subscription status remains Active
           ↓
Entitlements synchronized (if plan changed)
           ↓
Renewal logged in status_histories
```

### Renewal Timing

| Interval | Renews Every | Billing Window |
|---|---|---|
| Monthly | 30 days | ±1 hour of original timestamp |
| Yearly | 365 days | ±1 hour of original timestamp |

### Renewal Price

The price at renewal is the price at subscription creation time, unless the plan price has changed and the platform explicitly applies the new price.

**Price locking:** Subscribers keep their original price for the duration of their subscription. Price increases apply only to new subscribers.

**Price migration:** When raising prices, offer existing subscribers the option to migrate to the new price (possibly with a discount period).

## Payment Retry Logic

When a renewal payment fails:

```text
Attempt 1: Immediate retry (webhook triggers retry)
    ↓ (fails)
Past Due status with Grace Period (3 days)
    ↓
Attempt 2: 24 hours after first failure
    ↓ (fails)
Notification: "Payment failed, update payment method"
    ↓
Attempt 3: 72 hours after first failure
    ↓ (fails)
Status → Unpaid
Entitlements revoked
```

```php
class PaymentRetryManager
{
    protected array $retrySchedule = [
        0,    // Immediate (webhook-triggered)
        24,   // Hours after first failure
        72,   // Hours after first failure
    ];

    public function scheduleRetries(Subscription $subscription): void
    {
        foreach ($this->retrySchedule as $hours) {
            if ($hours === 0) {
                ProcessRenewalJob::dispatch($subscription);
            } else {
                ProcessRenewalJob::dispatch($subscription)
                    ->delay(now()->addHours($hours));
            }
        }
    }

    public function maxRetriesReached(Subscription $subscription): bool
    {
        $attempts = $subscription->usageRecords()
            ->where('metric', 'renewal_attempts')
            ->count();

        return $attempts >= count($this->retrySchedule);
    }
}
```

Platform checks payment method expiry before renewal. If expiring within 30 days, notify user to update.

### Currency Fluctuation

Prices are locked in the plan's currency. No dynamic currency adjustment.

### Price Changes at Renewal

If plan price changed between cycles:

- **Price decrease:** Optionally apply to existing subscribers (goodwill).
- **Price increase:** Lock existing subscribers at original price. Offer migration.

```php
public function priceForRenewal(Subscription $subscription): int
{
    $originalPrice = $subscription->metadata['price_at_subscription'] ?? null;

    if ($originalPrice && $originalPrice !== $subscription->plan->price) {
        // Lock subscriber at original price

    return $subscription->plan->price;
```

## Renewal Webhook Handling

```php
// app/Http/Controllers/WebhookController.php
public function handleInvoicePaid(array $payload): void
{
    $subscription = Subscription::where('stripe_id', $payload['subscription'])->first();

    if (!$subscription) {
        return; // Webhook arrived before subscription was created
    }

    // Only process if currently active or past_due
    if (!in_array($subscription->status, ['active', 'past_due'])) {
        return;
    }

    $subscription->statusHistories()->create([
        'from_status' => $subscription->status,
        'to_status' => 'active',
        'changed_by' => null, // system
        'reason' => 'Renewal payment succeeded',
    ]);

    $subscription->status = 'active';
    $subscription->save();

    SubscriptionRenewed::dispatch($subscription);
}
```

# Automatic Renewal Flow

## Complete Renewal Process

```text
T-30 days: Check payment method expiry
    ↓ Expiring within 30 days → notify user
T-7 days:  Renewal reminder email
T-1 day:   Payment method verification
T-0:       Provider charges payment method
    ↓
Webhook received: invoice.payment_succeeded
    ↓
Subscription status remains Active
    ↓
current_period_start = old current_period_end
    ↓
current_period_end = now + plan.interval
    ↓
Entitlements synchronized (if plan changed)
    ↓
Renewal logged in status_histories
    ↓
Renewal confirmation email sent
    ↓
Usage meters reset for new period
```

## Renewal Implementation

```php
class SubscriptionRenewer
{
    public function renew(Subscription $subscription): RenewalResult
    {
        // Validate subscription can renew
        $this->validateRenewal($subscription);

        // Calculate renewal price
        $price = $this->calculateRenewalPrice($subscription);

        // Attempt payment through provider
        try {
            $paymentResult = $this->billing->charge($subscription, $price);

            // Payment succeeded
            $this->processSuccessfulRenewal($subscription, $paymentResult);

            return RenewalResult::success($subscription, $paymentResult);

        } catch (PaymentFailedException $e) {
            // Payment failed
            $this->processFailedRenewal($subscription, $e);

            return RenewalResult::failed($e);
        }
    }

    protected function validateRenewal(Subscription $subscription): void
    {
        if ($subscription->status !== 'active') {
            throw new RenewalException('Subscription is not active');
        }

        if ($subscription->cancel_at_period_end) {
            throw new RenewalException('Subscription is pending cancellation');
        }

        if (!$subscription->plan) {
            throw new RenewalException('Plan not found');
        }
    }

    protected function calculateRenewalPrice(Subscription $subscription): int
    {
        // Check for price lock
        $originalPrice = $subscription->metadata['price_at_subscription'] ?? null;

        if ($originalPrice && config('subscriptions.renewals.price_lock')) {
            return $originalPrice;
        }

        // Use current plan price
        return $subscription->plan->price;
    }

    protected function processSuccessfulRenewal(
        Subscription $subscription,
        PaymentResult $paymentResult
    ): void {
        // Calculate new period
        $newPeriodEnd = $this->calculateNewPeriodEnd($subscription);

        // Update subscription
        $subscription->update([
            'current_period_start' => now(),
            'current_period_end' => $newPeriodEnd,
            'metadata' => array_merge($subscription->metadata ?? [], [
                'last_renewal_at' => now()->toISOString(),
                'last_renewal_amount' => $paymentResult->amount,
            ]),
        ]);

        // Audit trail
        $subscription->statusHistories()->create([
            'from_status' => 'active',
            'to_status' => 'active',
            'changed_by' => null,
            'reason' => 'Renewal payment succeeded',
            'metadata' => [
                'amount' => $paymentResult->amount,
                'payment_id' => $paymentResult->paymentId,
            ],
        ]);

        // Sync entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // Reset usage meters
        app(UsageMeterService::class)->reset($subscription);

        // Dispatch event
        SubscriptionRenewed::dispatch($subscription, $paymentResult);

        // Send confirmation
        RenewalConfirmationMail::to($subscription->user)->send([
            'subscription' => $subscription,
            'amount' => $paymentResult->amount,
        ]);
    }

    protected function processFailedRenewal(
        Subscription $subscription,
        PaymentFailedException $e
    ): void {
        // Transition to past due
        app(SubscriptionStateMachine::class)->transitionToPastDue($subscription);

        // Schedule retries
        app(PaymentRetryManager::class)->scheduleRetries($subscription);

        // Dispatch event
        SubscriptionRenewalFailed::dispatch($subscription, $e);

        // Send notification
        RenewalFailedMail::to($subscription->user)->send([
            'subscription' => $subscription,
            'error' => $e->getMessage(),
        ]);
    }

    protected function calculateNewPeriodEnd(Subscription $subscription): Carbon
    {
        return match ($subscription->plan->interval) {
            'monthly' => now()->addMonth(),
            'yearly' => now()->addYear(),
            default => now()->addMonth(),
        };
    }
}
```

# Renewal Pricing

## Price Lock Logic

Subscribers keep their original price for the duration of their subscription. Price increases apply only to new subscribers.

```php
class RenewalPriceCalculator
{
    public function calculate(Subscription $subscription): RenewalPrice
    {
        $originalPrice = $subscription->metadata['price_at_subscription'] ?? null;
        $currentPrice = $subscription->plan->price;
        $currency = $subscription->metadata['currency'] ?? 'USD';

        // Price lock check
        if ($originalPrice && config('subscriptions.renewals.price_lock')) {
            $isLocked = $originalPrice !== $currentPrice;

            return new RenewalPrice(
                amount: $originalPrice,
                currency: $currency,
                is_locked: $isLocked,
                original_amount: $originalPrice,
                current_plan_amount: $currentPrice,
            );
        }

        return new RenewalPrice(
            amount: $currentPrice,
            currency: $currency,
            is_locked: false,
            original_amount: $currentPrice,
            current_plan_amount: $currentPrice,
        );
    }

    public function calculateWithDiscount(Subscription $subscription, Coupon $coupon): RenewalPrice
    {
        $basePrice = $this->calculate($subscription);
        $discount = $coupon->apply($basePrice->amount);

        return new RenewalPrice(
            amount: $basePrice->amount - $discount,
            currency: $basePrice->currency,
            is_locked: $basePrice->is_locked,
            original_amount: $basePrice->original_amount,
            current_plan_amount: $basePrice->current_plan_amount,
            discount_amount: $discount,
            coupon_code: $coupon->code,
        );
    }
}
```

## Price Migration

When raising prices, offer existing subscribers the option to migrate:

```php
class PriceMigrationManager
{
    public function notifySubscribers(Plan $plan, int $newPrice): void
    {
        $subscribers = $plan->activeSubscriptions()
            ->where('metadata->price_at_subscription', '!=', $newPrice)
            ->with('user')
            ->get();

        foreach ($subscribers as $subscription) {
            // Offer migration with discount
            PriceMigrationOfferMail::to($subscription->user)->send([
                'subscription' => $subscription,
                'old_price' => $subscription->metadata['price_at_subscription'],
                'new_price' => $newPrice,
                'discount_percent' => 20, // 20% discount for 3 months
                'offer_expires_at' => now()->addDays(30),
            ]);
        }
    }

    public function migrate(Subscription $subscription, bool $acceptOffer): void
    {
        if ($acceptOffer) {
            // Apply new price with discount
            $subscription->update([
                'metadata' => array_merge($subscription->metadata ?? [], [
                    'price_at_subscription' => $subscription->plan->price,
                    'price_migration_at' => now()->toISOString(),
                    'migration_discount' => 20,
                ]),
            ]);
        }
        // If not accepted, keep original price (price lock)
    }
}
```

# Payment Retry Logic

## Retry Schedule

| Attempt | Timing | Action |
|---|---|---|
| 1st | Immediate | Webhook-triggered retry |
| 2nd | +24 hours | Scheduled job retry |
| 3rd | +72 hours | Final retry attempt |
| After 3 | — | Status → Unpaid |

## Retry Manager

```php
class PaymentRetryManager
{
    protected array $retrySchedule = [
        0,    // Immediate (webhook-triggered)
        24,   // Hours after first failure
        72,   // Hours after first failure
    ];

    public function scheduleRetries(Subscription $subscription): void
    {
        foreach ($this->retrySchedule as $index => $hours) {
            $attempt = $index + 1;

            if ($hours === 0) {
                // Immediate retry
                ProcessRenewalRetryJob::dispatch($subscription, $attempt);
            } else {
                // Delayed retry
                ProcessRenewalRetryJob::dispatch($subscription, $attempt)
                    ->delay(now()->addHours($hours));
            }
        }
    }

    public function cancelRetries(Subscription $subscription): void
    {
        ProcessRenewalRetryJob::where('subscription_id', $subscription->id)
            ->cancel();
    }

    public function maxRetriesReached(Subscription $subscription): bool
    {
        $attempts = $subscription->metadata['payment_failure_count'] ?? 0;
        return $attempts >= count($this->retrySchedule);
    }

    public function getRetryAttempt(Subscription $subscription): int
    {
        return ($subscription->metadata['payment_failure_count'] ?? 0) + 1;
    }
}
```

## Renewal Retry Job

```php
class ProcessRenewalRetryJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        public Subscription $subscription,
        public int $attempt,
    ) {}

    public function handle(): void
    {
        // Reload fresh
        $this->subscription = $this->subscription->fresh();

        // Check if still past due
        if ($this->subscription->status !== 'past_due') {
            return; // Already recovered or transitioned
        }

        // Check if max retries reached
        if (app(PaymentRetryManager::class)->maxRetriesReached($this->subscription)) {
            app(SubscriptionStateMachine::class)->transitionToUnpaid($this->subscription);
            return;
        }

        // Attempt renewal
        $result = app(SubscriptionRenewer::class)->renew($this->subscription);

        if ($result->failed()) {
            // Increment failure count
            $this->subscription->update([
                'metadata' => array_merge($this->subscription->metadata ?? [], [
                    'payment_failure_count' => ($this->subscription->metadata['payment_failure_count'] ?? 0) + 1,
                    'last_retry_at' => now()->toISOString(),
                ]),
            ]);
        }
    }
}
```

# Payment Method Expiry Checking

## Pre-Renewal Check

```php
class PaymentMethodExpiryChecker
{
    public function checkBeforeRenewal(Subscription $subscription): void
    {
        $method = $subscription->user->defaultPaymentMethod();

        if (!$method) {
            // No payment method — notify user
            NoPaymentMethodWarning::dispatch($subscription);
            return;
        }

        if ($this->isExpiringSoon($method)) {
            // Expiring within 30 days — notify user
            ExpiringCardWarning::dispatch($subscription, $method);
        }
    }

    protected function isExpiringSoon(PaymentMethod $method): bool
    {
        $checkDays = config('subscriptions.renewals.payment_method_check_days', 30);
        return $method->expiresAt()->subDays($checkDays)->isPast();
    }

    public function checkAllSubscriptions(): void
    {
        // Run daily via scheduler
        $subscriptions = Subscription::where('status', 'active')
            ->where('current_period_end', '<=', now()->addDays(30))
            ->with('user')
            ->get();

        foreach ($subscriptions as $subscription) {
            $this->checkBeforeRenewal($subscription);
        }
    }
}
```

```php
class ArchivedPlanRenewalHandler
{
    public function handleRenewal(Subscription $subscription): RenewalResult
    {
        if ($subscription->plan->is_active) {
            // Normal renewal
            return app(SubscriptionRenewer::class)->renew($subscription);
        }

        // Plan is archived — find alternative
        $alternative = $this->findAlternative($subscription->plan);

        if ($alternative) {
            // Migrate to alternative
            return app(PlanMigrator::class)->migrate($subscription, $alternative);
        }

        // No alternative — cancel subscription
        app(CancellationService::class)->cancel(
            $subscription,
            'plan_archived',
            'Your plan is no longer available'
        );

        return RenewalResult::cancelled('Plan archived');
    }

    protected function findAlternative(Plan $archivedPlan): ?Plan
    {
        return Plan::where('is_active', true)
            ->orderByRaw("ABS(price - ?)", [$archivedPlan->price])
            ->first();
    }
}
```

# Renewal Analytics

## Key Metrics

| Metric | Description | Calculation |
|---|---|---|
| Renewal rate | % of subscriptions that renew | (Renewed / Total due) × 100 |
| Failed renewal rate | % of renewals that fail | (Failed / Total due) × 100 |
| Retry success rate | % of retries that succeed | (Retry succeeded / Total retries) × 100 |
| Average retries | Average retries before success | AVG(retry count for successful renewals) |
| Renewal revenue | Revenue from renewals | SUM(renewal payments) |
| Churn at renewal | Subscriptions that don't renew | (Not renewed / Total due) × 100 |
| Price lock impact | Revenue difference from price locking | SUM(original_price - current_price) |

## Analytics Queries

```php
class RenewalAnalytics
{
    public function renewalRate(string $period = '30d'): float
    {
        $start = Carbon::now()->subPeriod(1);

        $dueForRenewal = Subscription::where('status', 'active')
            ->where('current_period_end', '>=', $start)
            ->where('current_period_end', '<', now())
            ->count();

        $renewed = Subscription::where('status', 'active')
            ->where('current_period_end', '>=', $start)
            ->where('current_period_end', '<', now())
            ->where('metadata->last_renewal_at', '>=', $start)
            ->count();

        return $dueForRenewal > 0 ? ($renewed / $dueForRenewal) * 100 : 0;
    }

    public function retrySuccessRate(string $period = '30d'): float
    {
        $start = Carbon::now()->subPeriod(1);

        $totalRetries = ProcessRenewalRetryJob::where('created_at', '>=', $start)
            ->count();

        $successfulRetries = ProcessRenewalRetryJob::where('created_at', '>=', $start)
            ->where('status', 'completed')
            ->count();

        return $totalRetries > 0 ? ($successfulRetries / $totalRetries) * 100 : 0;
    }

    public function revenueByRenewalType(string $period = '30d'): array
    {
        $start = Carbon::now()->subPeriod(1);

        return SubscriptionUsageRecord::where('metric', 'renewal_payment')
            ->where('recorded_at', '>=', $start)
            ->groupBy('subscription_id')
            ->selectRaw('subscription_id, SUM(quantity) as amount')
            ->with('subscription.plan')
            ->get()
            ->groupBy('subscription.plan.interval')
            ->map(fn($group) => $group->sum('amount'))
            ->toArray();
    }
}
```

## Renewal Reminder Job

```php
class SendRenewalRemindersJob implements ShouldQueue
{
    public function handle(): void
    {
        $reminderDays = config('subscriptions.renewals.renewal_window_days', 7);

        $subscriptions = Subscription::where('status', 'active')
            ->where('cancel_at_period_end', false)
            ->where('current_period_end', '<=', now()->addDays($reminderDays))
            ->where('current_period_end', '>', now())
            ->with('user', 'plan')
            ->get();

        foreach ($subscriptions as $subscription) {
            $daysUntilRenewal = now()->diffInDays($subscription->current_period_end);

            // Determine which notification to send
            match (true) {
                $daysUntilRenewal === 7 => RenewalReminder7DayMail::to($subscription->user)->send([
                    'subscription' => $subscription,
                ]),
                $daysUntilRenewal === 1 => RenewalReminder1DayMail::to($subscription->user)->send([
                    'subscription' => $subscription,
                ]),
                default => null,
            };
        }
    }
```

```php
    {
        $renewalRevenue = SubscriptionUsageRecord::where('metric', 'renewal_payment')
            ->where('recorded_at', '>=', $start)
            ->sum('quantity');

        $previousPeriodRevenue = SubscriptionUsageRecord::where('metric', 'renewal_payment')
            ->where('recorded_at', '>=', $start->copy()->subPeriod())
            ->where('recorded_at', '<', $start)
            ->sum('quantity');

        return [
            'current_period' => $renewalRevenue,
            'previous_period' => $previousPeriodRevenue,
            'growth_rate' => $previousPeriodRevenue > 0
                ? round((($renewalRevenue - $previousPeriodRevenue) / $previousPeriodRevenue) * 100, 1)
                : 0,
        ];
    }

    protected function getRetryAnalysis(Carbon $start): array
    {
        $totalRetries = ProcessRenewalRetryJob::where('created_at', '>=', $start)->count();
        $successfulRetries = ProcessRenewalRetryJob::where('created_at', '>=', $start)
            ->where('status', 'completed')
            ->count();

        return [
            'total_retries' => $totalRetries,
            'successful_retries' => $successfulRetries,
            'success_rate' => $totalRetries > 0

    protected function getChurnAnalysis(Carbon $start): array

            ->where('updated_at', '>=', $start)
            ->with('plan')
            ->get()
            ->groupBy(fn($s) => $s->plan->slug)
            ->map(fn($subs) => $subs->count())
            ->toArray();

        return [
            'churned_by_plan' => $churned,
            'total_churned' => array_sum($churned),
            'churn_rate' => $this->calculateChurnRate($start),
        ];

    protected function getPriceLockImpact(Carbon $start): array
    {
        $subscriptions = Subscription::where('status', 'active')
            ->where('metadata->price_at_subscription', '!=', null)
            ->with('plan')
            ->get();

        $lockedCount = $subscriptions->filter(fn($s) =>
            $s->metadata['price_at_subscription'] !== $s->plan->price
        )->count();

        $revenueDifference = $subscriptions->sum(fn($s) =>
            $s->metadata['price_at_subscription'] - $s->plan->price
        );

        return [
            'subscriptions_with_locked_price' => $lockedCount,
            'total_revenue_difference' => $revenueDifference,
            'average_difference' => $lockedCount > 0
                ? round($revenueDifference / $lockedCount, 2)
                : 0,
        ];
    }
```

```php
class RenewalForecaster
{
    public function forecast(int $monthsAhead = 12): array
    {
        $currentMRR = app(MRRCalculator::class)->calculate();
        $churnRate = app(ChurnCalculator::class)->calculate('30d') / 100;
        $growthRate = $this->calculateGrowthRate();

        $forecast = [];
        $mrr = $currentMRR;

        for ($month = 1; $month <= $monthsAhead; $month++) {
            $churnedMRR = $mrr * $churnRate;
            $newMRR = $mrr * $growthRate;
            $mrr = $mrr - $churnedMRR + $newMRR;

            $forecast[] = [
                'month' => $month,
                'projected_mrr' => round($mrr, 2),
                'projected_arr' => round($mrr * 12, 2),
                'churned_mrr' => round($churnedMRR, 2),
                'new_mrr' => round($newMRR, 2),
            ];
        }

        return $forecast;
    }

    protected function calculateGrowthRate(): float
    {
        $recentGrowth = Subscription::where('created_at', '>=', now()->subDays(30))
            ->count();

        $totalActive = Subscription::where('status', 'active')->count();

        return $totalActive > 0 ? $recentGrowth / $totalActive : 0;
    }
}
```

```php
            $cohortStart = now()->subMonths($i)->startOfMonth();

                    $s->status === 'active' ||
                    ($s->canceled_at && $s->canceled_at->isAfter($cohortStart->addMonths($month)))

                    'month' => $month,
                    'retained' => $retained,
                    'rate' => $subscriptions->count() > 0
                        ? round(($retained / $subscriptions->count()) * 100, 1)
                        : 0,
                ];
            }

            $cohorts[] = [
                'cohort' => $cohortStart->format('Y-m'),
                'size' => $subscriptions->count(),
                'retention' => $retention,
            ];
        }

        return $cohorts;
    }
```

# Renewal Automation Rules

## Rule Engine

```php
class RenewalRuleEngine
{
    public function evaluate(Subscription $subscription): array
    {
        $rules = [
            $this->checkPaymentMethodExpiry($subscription),
            $this->checkRenewalWindow($subscription),
            $this->checkUsagePatterns($subscription),
            $this->checkChurnRisk($subscription),
        ];

        return array_filter($rules);
    }

    protected function checkPaymentMethodExpiry(Subscription $subscription): ?array
    {
        $method = $subscription->user->defaultPaymentMethod();

        if (!$method) {
            return [
                'rule' => 'no_payment_method',
                'action' => 'notify_user',
                'priority' => 'high',
            ];
        }

        if ($method->expiresAt()->subDays(30)->isPast()) {
            return [
                'rule' => 'payment_method_expiring',
                'action' => 'notify_user_to_update',
                'priority' => 'medium',
            ];
        }

        return null;
    }

    protected function checkRenewalWindow(Subscription $subscription): ?array
    {
        $daysUntilRenewal = now()->diffInDays($subscription->current_period_end);

        if ($daysUntilRenewal <= 7) {
            return [
                'rule' => 'renewal_approaching',
                'action' => 'send_reminder',
                'priority' => 'normal',
            ];
        }

        return null;
    }

    protected function checkUsagePatterns(Subscription $subscription): ?array
    {
        $usage = $subscription->usageRecords()
            ->where('recorded_at', '>=', now()->subDays(30))
            ->count();

        if ($usage === 0) {
            return [
                'rule' => 'no_usage',
                'action' => 'send_engagement_email',
                'priority' => 'low',
            ];
        }

        return null;
    }

    protected function checkChurnRisk(Subscription $subscription): ?array
    {
        $riskScore = $this->calculateChurnRisk($subscription);

        if ($riskScore > 0.7) {
            return [
                'rule' => 'high_churn_risk',
                'action' => 'send_retention_offer',
                'priority' => 'high',
                'risk_score' => $riskScore,
            ];
        }

        return null;
    }

    protected function calculateChurnRisk(Subscription $subscription): float
    {
        $factors = [
            'usage_decline' => $this->usageDeclineFactor($subscription),
            'support_tickets' => $this->supportTicketFactor($subscription),
            'payment_failures' => $this->paymentFailureFactor($subscription),
            'feature_adoption' => $this->featureAdoptionFactor($subscription),
        ];

        return array_sum($factors) / count($factors);
    }
}
```

## Recovery Jobs

```php
class RenewalRecoveryJob implements ShouldQueue
{
    public function handle(): void
    {
        // 1. Check for stuck past_due subscriptions
        $stuckPastDue = Subscription::where('status', 'past_due')
            ->where('grace_period_ends_at', '<', now()->subDays(7))
            ->get();

        foreach ($stuckPastDue as $subscription) {
            // Attempt to sync with provider
            $providerStatus = $this->getProviderStatus($subscription);

            if ($providerStatus === 'active') {
                // Provider shows active, sync locally
                app(SubscriptionStateMachine::class)->transitionToActiveFromPastDue($subscription);
            } elseif ($providerStatus === 'canceled' || $providerStatus === 'unpaid') {
                // Provider shows terminal state
                app(SubscriptionStateMachine::class)->transitionToUnpaid($subscription);
            }
        }

        // 2. Check for missing payment records
        $subscriptionsWithoutPayments = Subscription::where('status', 'active')
            ->whereDoesntHave('payments')
            ->get();

        foreach ($subscriptionsWithoutPayments as $subscription) {
            // Create missing payment record from provider data
            $this->reconcilePaymentRecords($subscription);
        }
    }

    protected function getProviderStatus(Subscription $subscription): ?string
    {
        return match ($subscription->provider) {
            'stripe' => app(StripeBillingProvider::class)
                ->getSubscriptionStatus($subscription->provider_subscription_id),
            'paddle' => app(PaddleBillingProvider::class)
                ->getSubscriptionStatus($subscription->provider_subscription_id),
            default => null,
        };
    }
}
```

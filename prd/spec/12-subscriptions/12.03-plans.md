# 12.03 — Plans

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

## Purpose

Define the complete specification for subscription plans — their pricing, feature configuration, display rules, and lifecycle. Plans are the product catalog of the subscription system.

## Plan Architecture

```text
Plan
  ├── Identity (name, slug, description)
  ├── Pricing (price, currency, interval)
  ├── Trial (trial_days)
  ├── Features (JSON feature slugs)
  ├── Limits (max_team_members, max_downloads, storage)
  ├── Provider IDs (stripe, paddle, lemon_squeezy)
  └── Display (is_active, is_visible, sort_order)
```

## Plan Lifecycle

```text
Draft  →  Active  →  Archived
                  ↓
             Active Subscriptions Continue
             No New Subscriptions Allowed
```

### States

| State | Can Subscribe | Existing Subscriptions | Display |
|---|---|---|---|
| Draft | No | N/A | Hidden |
| Active | Yes | Normal | Visible |
| Archived | No | Continue until period end | Hidden from new |

### Transition: Draft → Active

**Trigger:** Admin sets `is_active = true` and `is_visible = true`

**Actions:**
1. Plan appears in pricing page
2. Users can subscribe
3. Webhook provider prices must already be configured

### Transition: Active → Archived

**Trigger:** Admin sets `is_active = false`

**Rules:**
- Existing subscriptions continue until current period end
- No renewals on archived plans — subscriptions are migrated or canceled
- Plan is hidden from pricing page
- Provider price IDs remain for existing subscribers

**Actions:**
1. Set `is_active = false`, `is_visible = false`
2. Notify subscribers of plan deprecation
3. Schedule subscription migration job
4. Log in audit trail

## Pricing Rules

### Annual Discount

Annual plans are priced at 10 months of the monthly rate (2 months free):

```text
Pro Annual: $19 × 10 = $190/year (vs $228/year monthly)
Team Annual: $49 × 10 = $490/year (vs $588/year monthly)
```

### Proration

When upgrading mid-period, credit remaining on the current plan is applied to the new plan:

```php
public function calculateProration(Subscription $subscription, Plan $newPlan): float
{
    $daysRemaining = $subscription->period()->daysRemaining();
    $daysTotal = $subscription->period()->daysTotal();
    $credit = $subscription->plan->price * ($daysRemaining / $daysTotal);

    return max(0, $newPlan->price - $credit);
}
```

### Tax Handling

Taxes are calculated by the payment provider. Platform stores prices excluding tax.

### Update Plan

**Allowed changes without disruption:**
- Description
- Features (slugs only — adding new features is safe)
- Limits (increasing is safe; decreasing requires confirmation)
- `is_visible`
- `sort_order`
- Display name

**Breaking changes (require communication):**
- Price increase (existing subscribers keep current price)
- Price decrease (optionally apply to existing subscribers)
- Trial days change (affects new subscriptions only)
- Slug change (not allowed — use a new plan)

### Delete Plan

Plans are never hard-deleted. Set `is_active = false` to archive.

## Plan Validation

```php
class PlanValidator
{
    public function validate(array $data): void
    {
        // Price must be in minor units
        assert($data['price'] > 0 || $data['slug'] === 'free');

        // Trial requires webhook and payment method
        if ($data['trial_days'] > 0) {
            assert(/* payment provider configured */);
        }

        // Annual plans must have matching monthly plan
        if ($data['interval'] === 'yearly') {
            assert(/* monthly variant exists */);
        }

        // Slugs must be unique and kebab-case
        assert(preg_match('/^[a-z0-9-]+$/', $data['slug']));

        // Free plan must have price = 0
        if ($data['slug'] === 'free') {
            assert($data['price'] === 0);
        }
    }
}
```

## Multi-Currency Support

```php
class PlanPricing
{
    public function prices(string $planSlug): array
    {
        return Plan::where('slug', $planSlug)
            ->with('prices')
            ->first()
            ->prices
            ->groupBy('currency')
            ->map(fn($prices) => $prices->keyBy('interval'))
            ->toArray();
    }

    public function displayPrice(Plan $plan, string $currency = 'USD'): array
    {
        $monthly = $plan->prices
            ->where('currency', $currency)
            ->where('interval', 'monthly')
            ->first();

        $yearly = $plan->prices
            ->where('currency', $currency)
            ->where('interval', 'yearly')
            ->first();

        return [
            'monthly' => $monthly?->format() ?? '$0',
            'yearly' => $yearly?->format() ?? '$0',
            'yearly_monthly' => $yearly ? $yearly->divide(12)->format() : '$0',
            'savings' => $monthly && $yearly
                ? (($monthly->amount * 12) - $yearly->amount) / 100
                : 0,
        ];
    }
}
```

## Draft → Active Transition

```php
class PlanActivator
{
    public function activate(Plan $plan): void
    {
        // Validate plan is ready for activation
        $this->validate($plan);

        // Sync with payment providers
        $this->syncProviders($plan);

        // Activate plan
        $plan->update([
            'is_active' => true,
            'is_visible' => true,
        ]);

        // Dispatch event
        PlanActivated::dispatch($plan);
    }

    protected function validate(Plan $plan): void
    {
        // Must have at least one price
        if ($plan->prices()->count() === 0) {
            throw new PlanValidationException('Plan must have at least one price');
        }

        // Must have features defined
        if (empty($plan->features)) {
            throw new PlanValidationException('Plan must have features defined');
        }

        // Slug must be valid
        if (!preg_match('/^[a-z0-9-]+$/', $plan->slug)) {
            throw new PlanValidationException('Invalid plan slug');
        }
    }

    protected function syncProviders(Plan $plan): void
    {
        foreach ($plan->prices as $price) {
            if ($price->stripePriceId) {
                app(StripeBillingProvider::class)->syncPlan($plan, $price);
            }
            if ($price->paddlePriceId) {
                app(PaddleBillingProvider::class)->syncPlan($plan, $price);
            }
            if ($price->lemonSqueezyVariantId) {
                app(LemonSqueezyBillingProvider::class)->syncPlan($plan, $price);
            }
        }
    }
}
```

## Active → Archived Transition

```php
class PlanArchiver
{
    public function archive(Plan $plan, string $reason): void
    {
        // Check for active subscriptions
        $activeCount = $plan->activeSubscriptions()->count();

        if ($activeCount > 0) {
            // Notify subscribers
            $this->notifySubscribers($plan, $activeCount);

            // Schedule migration
            SchedulePlanMigrationJob::dispatch($plan)
                ->delay(now()->addDays(30));
        }

        // Archive plan
        $plan->update([
            'is_active' => false,
            'is_visible' => false,
        ]);

        // Log in audit trail
        activity('plan')
            ->performedOn($plan)
            ->withProperties(['reason' => $reason, 'active_subscribers' => $activeCount])
            ->log('Plan archived');

        PlanArchived::dispatch($plan, $reason);
    }

    protected function notifySubscribers(Plan $plan, int $count): void
    {
        // Send email to all active subscribers
        $subscribers = $plan->activeSubscriptions()
            ->with('user')
            ->get()
            ->pluck('user');

        foreach ($subscribers as $user) {
            PlanDeprecatedMail::to($user)->send([
                'plan' => $plan,
                'alternative_plans' => $this->getAlternatives($plan),
            ]);
        }
    }
}
```

# Plan Validation Rules

## Validation Schema

```php
class PlanValidator
{
    public function validate(array $data, ?Plan $existing = null): array
    {
        $rules = [
            'name' => 'required|string|max:255',
            'slug' => 'required|regex:/^[a-z0-9-]+$/|unique:plans,slug,' . ($existing?->id),
            'description' => 'nullable|string|max:1000',
            'price' => 'required|integer|min:0',
            'currency' => 'required|string|size:3',
            'interval' => 'required|in:monthly,yearly',
            'trial_days' => 'required|integer|min:0|max:90',
            'features' => 'required|array',
            'limits' => 'required|array',
            'is_active' => 'boolean',
            'is_visible' => 'boolean',
            'sort_order' => 'integer|min:0',
        ];

        return validator()->validate($data, $rules);
    }

    public function validateForActivation(Plan $plan): void
    {
        $errors = [];

        // Must have prices
        if ($plan->prices()->count() === 0) {
            $errors[] = 'Plan must have at least one price';
        }

        // Must have features
        if (empty($plan->features)) {
            $errors[] = 'Plan must have features';
        }

        // Free plan validation
        if ($plan->slug === 'free' && $plan->price !== 0) {
            $errors[] = 'Free plan must have price = 0';
        }

        // Trial validation
        if ($plan->trial_days > 0 && $plan->isFree()) {
            $errors[] = 'Free plans cannot have trials';
        }

        if (!empty($errors)) {
            throw new PlanValidationException(implode(', ', $errors));
        }
    }
}
```

# Plan Archival and Migration

## Archival Process

```text
Admin archives plan
    ↓
Active subscribers notified
    ↓
30-day migration window
    ↓
Subscribers must migrate or cancel
    ↓
After 30 days: remaining subscriptions canceled
    ↓
Plan status = archived (read-only for historical data)
```

## Migration Options

| Option | Description |
|---|---|
| Auto-migrate | Automatically move to recommended alternative |
| Manual selection | User chooses new plan |
| Keep current | Continue at current price (if possible) |
| Cancel | Cancel subscription with refund |

## Migration Job

```php
class PlanMigrationJob implements ShouldQueue
{
    public function handle(): void
    {
        $subscriptions = $this->plan->activeSubscriptions()
            ->with('user')
            ->get();

        foreach ($subscriptions as $subscription) {
            $alternative = $this->findAlternative($subscription);

            if ($alternative) {
                // Migrate to alternative plan
                app(PlanUpgrader::class)->swap($subscription, $alternative);
            } else {
                // No alternative found, cancel
                app(CancellationService::class)->cancel(
                    $subscription,
                    'plan_archived',
                    'Plan no longer available'
                );
            }
        }
    }

    protected function findAlternative(Subscription $subscription): ?Plan
    {
        // Find the closest plan by price
        return Plan::where('is_active', true)
            ->where('id', '!=', $this->plan->id)
```

```text
Plan created/updated in database
    ↓

    ↓

    ↓
Sync to Lemon Squeezy
    ↓
Update provider IDs on plan
    ↓
Log sync result
```

## Provider Sync Implementation

```php
class PlanProviderSyncer
{
    public function sync(Plan $plan): void
    {
        foreach ($plan->prices as $price) {
            if ($price->stripePriceId) {
                $this->syncStripe($plan, $price);
            }
            if ($price->paddlePriceId) {
                $this->syncPaddle($plan, $price);
            }
            if ($price->lemonSqueezyVariantId) {
                $this->syncLemonSqueezy($plan, $price);
            }
        }
    }

    protected function syncStripe(Plan $plan, PlanPrice $price): void
    {
        $stripe = app(StripeBillingProvider::class);

        if ($price->stripePriceId) {
            // Update existing price
            $stripe->updatePrice($price->stripePriceId, [
                'nickname' => "{$plan->name} - {$price->interval}",
                'active' => $plan->is_active,
            ]);
        } else {
            // Create new price
            $stripePrice = $stripe->createPrice([
                'product' => $plan->stripe_product_id,
                'unit_amount' => $price->amount,
                'currency' => strtolower($price->currency),
                'recurring' => [
                    'interval' => $price->interval === 'monthly' ? 'month' : 'year',
                ],
                'nickname' => "{$plan->name} - {$price->interval}",
            ]);

            $price->update(['stripe_price_id' => $stripePrice->id]);
        }
    }
}
```

## Version History

```php
class PlanVersionTracker
{
    public function record(Plan $plan, string $changeType, array $changes): PlanVersion
    {
        return PlanVersion::create([
            'plan_id' => $plan->id,
            'version' => $plan->versions()->count() + 1,
            'change_type' => $changeType,
            'changes' => $changes,
            'changed_by' => auth()->id(),
        ]);
    }

    public function diff(PlanVersion $old, PlanVersion $new): array
    {
        $diff = [];

        foreach ($new->changes as $key => $value) {
            if (!isset($old->changes[$key]) || $old->changes[$key] !== $value) {
                $diff[$key] = [
                    'old' => $old->changes[$key] ?? null,
                    'new' => $value,
                ];
            }
        }

        return $diff;
    }
}
```

```php
class PlanExperimentService

    public function assignVariant(User $user, PlanExperiment $experiment): Plan
    {
        // Deterministic assignment based on user ID
        $hash = md5($user->id . $experiment->name);
        $bucket = hexdec(substr($hash, 0, 8)) / 0xFFFFFFFF;

        return $bucket < $experiment->trafficSplit
            ? $experiment->control
```

# Plan Migration Strategies

## Automatic Migration

When a plan is archived, subscribers can be automatically migrated:

```php
class AutoMigrationStrategy
{
    public function migrate(Subscription $subscription, Plan $targetPlan): void
    {
        // 1. Calculate proration
        $proration = app(PriceCalculator::class)->calculateProration(
            $subscription,
            $targetPlan
        );

        // 2. Update subscription
        $subscription->update([
            'plan_id' => $targetPlan->id,
            'metadata' => array_merge($subscription->metadata ?? [], [
                'migrated_from' => $subscription->plan_id,
                'migrated_at' => now()->toISOString(),
                'migration_type' => 'auto',
            ]),
        ]);

        // 3. Sync entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // 4. Notify user
        MigrationCompletedMail::to($subscription->user)->send([
            'old_plan' => $subscription->plan,
            'new_plan' => $targetPlan,
            'proration' => $proration,
        ]);

        // 5. Log migration
        activity('plan_migration')
            ->performedOn($subscription)
            ->withProperties([
                'old_plan_id' => $subscription->plan_id,
                'new_plan_id' => $targetPlan->id,
                'proration' => $proration->toArray(),
            ])
            ->log('Auto-migrated to new plan');
    }
}
```

## Manual Migration

Users can choose their own migration path:

```php
class ManualMigrationStrategy
{
    public function getMigrationOptions(Plan $archivedPlan): array
    {
        return Plan::where('is_active', true)
            ->where('id', '!=', $archivedPlan->id)
            ->orderBy('price')
            ->get()
            ->map(fn($plan) => [
                'plan_id' => $plan->id,
                'name' => $plan->name,
                'price' => $plan->price,
                'interval' => $plan->interval,
                'feature_diff' => $this->calculateFeatureDiff($archivedPlan, $plan),
                'recommended' => $this->isRecommended($archivedPlan, $plan),
            ])
            ->toArray();
    }

    protected function calculateFeatureDiff(Plan $old, Plan $new): array
    {
        $oldFeatures = array_keys($old->features);
        $newFeatures = array_keys($new->features);

        return [
            'added' => array_diff($newFeatures, $oldFeatures),
            'removed' => array_diff($oldFeatures, $newFeatures),
            'unchanged' => array_intersect($oldFeatures, $newFeatures),
        ];
    }

    protected function isRecommended(Plan $archived, Plan $candidate): bool
    {
        // Recommend closest price match
        return abs($archived->price - $candidate->price) < 500;
    }
}
```

## Cohort Analysis

```php
class PlanCohortAnalyzer
{
    public function analyze(string $planSlug, int $monthsBack = 12): array
    {
        $cohorts = [];

        for ($i = 0; $i < $monthsBack; $i++) {
            $cohortStart = now()->subMonths($i)->startOfMonth();
            $cohortEnd = $cohortStart->copy()->endOfMonth();

            $subscriptions = Subscription::where('plan_slug', $planSlug)
                ->where('created_at', '>=', $cohortStart)
                ->where('created_at', '<', $cohortEnd)
                ->get();

            $retention = [];
            for ($month = 0; $month <= $monthsBack - $i; $month++) {
                $retained = $subscriptions->filter(fn($s) =>
                    $s->status === 'active' ||
                    ($s->canceled_at && $s->canceled_at->isAfter($cohortStart->addMonths($month)))
                )->count();

                $retention[$month] = [
                    'month' => $month,
                    'retained' => $retained,
                    'rate' => $subscriptions->count() > 0
                        ? round(($retained / $subscriptions->count()) * 100, 1)
                        : 0,
                ];
            }

            $cohorts[] = [
                'cohort' => $cohortStart->format('Y-m'),
                'size' => $subscriptions->count(),
                'retention' => $retention,
            ];
        }

        return $cohorts;
    }
}
```

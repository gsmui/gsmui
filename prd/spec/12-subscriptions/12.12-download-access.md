# 12.12 — Download Access

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

## Purpose

Define how download limits are tracked, enforced, and reset across plans. Download access is the primary value driver for paid subscriptions — controlling it directly impacts conversion and retention.

## Download Architecture

```text
User requests download
    ↓
Entitlement check (plan allows downloads)
    ↓
Rate limit check (downloads this period)
    ↓
Log download
    ↓
Serve file
```

## Download Limits by Plan

| Plan | Monthly Limit | Item Types | Concurrent |
|---|---|---|---|
| Free | 10 downloads/mo | Free items only | 1 |
| Pro | 100 downloads/mo | All items | 5 |
| Team | Unlimited | All items | 10 |
| Enterprise | Unlimited | All items | Unlimited |

## Download Tracking

### Usage Record

```php
class DownloadTracker
{
    public function record(User $user, Downloadable $item): void
    {
        $subscription = $user->activeSubscription();

        if ($subscription) {
            $subscription->incrementUsage('downloads', 1);

            // Track per-item download
            $subscription->usageRecords()->create([
                'metric' => "downloads.{$item->getMorphClass()}.{$item->id}",
                'quantity' => 1,
                'recorded_at' => now(),
            ]);
        }

        // Always log download event
        DownloadRecorded::dispatch($user, $item);
    }

    public function periodUsage(User $user): int
    {
        $subscription = $user->activeSubscription();

        if (!$subscription) {
            return 0;
        }

        $periodStart = $subscription->period()->start;

        return $subscription->usageRecords()
            ->where('metric', 'downloads')
            ->where('recorded_at', '>=', $periodStart)
            ->sum('quantity');
    }
}
```

### Limit Enforcement

```php
class DownloadEnforcer
{
    public function canDownload(User $user, Downloadable $item): bool
    {
        $entitlement = app(EntitlementService::class);

        // Check plan access to item type
        if ($item->isPremium() && !$entitlement->has($user, EntitlementKey::ComponentPro)) {
            return false;
        }

        // Check unlimited downloads entitlement
        if ($entitlement->has($user, EntitlementKey::DownloadUnlimited)) {
            return true;
        }

        // Check monthly limit
        $limit = $entitlement->value($user, EntitlementKey::DownloadLimit) ?? 10;
        $used = app(DownloadTracker::class)->periodUsage($user);

        return $used < $limit;
    }

    public function remaining(User $user): int
    {
        $entitlement = app(EntitlementService::class);

        if ($entitlement->has($user, EntitlementKey::DownloadUnlimited)) {
            return PHP_INT_MAX;
        }

        $limit = $entitlement->value($user, EntitlementKey::DownloadLimit) ?? 10;
        $used = app(DownloadTracker::class)->periodUsage($user);

        return max(0, $limit - $used);
    }
}
```

## Download Middleware

```php
// app/Http/Middleware/EnforceDownloadLimit.php
class EnforceDownloadLimit
{
    public function handle(Request $request, Closure $next): Response
    {
        $user = $request->user();
        $item = $request->route('item');

        if (!app(DownloadEnforcer::class)->canDownload($user, $item)) {
            if (app(EntitlementService::class)->has($user, EntitlementKey::DownloadLimit)) {
                $remaining = app(DownloadEnforcer::class)->remaining($user);

                return response()->json([
                    'error' => 'Download limit reached',
                    'message' => "You have {$remaining} downloads remaining this month. Upgrade for unlimited downloads.",
                    'remaining' => $remaining,
                    'upgrade_url' => '/billing',
                ], 429);
            }

            return response()->json([
                'error' => 'Upgrade required',
                'message' => 'This item requires a Pro subscription to download.',
                'upgrade_url' => '/billing',
            ], 403);
        }

        return $next($request);
    }
}
```

## Detailed Download Scenarios

### Scenario: Free User Downloading Free Item

A user on the Free plan downloading an item that is marked as free.

```text
User Flow:
1. User browses marketplace
2. User finds free item
3. User clicks "Download"
4. System checks:
   - Is user authenticated? Yes
   - Is item free? Yes
   - Does user have download remaining? Yes (10/month limit)
5. Download count incremented
6. File served
7. Download recorded in history
```

```php
class FreeItemDownloadHandler
{
    public function handle(User $user, Downloadable $item): StreamedResponse
    {
        // Verify item is free
        if ($item->isPremium()) {
            throw new PremiumItemException('This item requires a Pro subscription');
        }

        // Check download limit
        $enforcer = app(DownloadEnforcer::class);
        if (!$enforcer->canDownload($user, $item)) {
            throw new DownloadLimitReachedException(
                'Download limit reached. Upgrade for unlimited downloads.'
            );
        }

        // Record download
        app(DownloadTracker::class)->record($user, $item);

        // Serve file
        return $this->serveFile($item);
    }
}
```

### Scenario: Team User with Shared Pool

A team member downloading from the shared team download pool.

```text
Team Download Pool:
- Team Plan: Unlimited downloads (shared)
- Member A: Downloads 15 items
- Member B: Downloads 8 items
- Total team usage: 23 items
- Remaining: Unlimited
```

```php
class TeamDownloadHandler
{
    public function handle(User $user, Downloadable $item): StreamedResponse
    {
        $team = $user->currentTeam;

        if (!$team || !$team->subscription) {
            // Fall back to personal limits
            return app(PersonalDownloadHandler::class)->handle($user, $item);
        }

        // Check team-level access
        $teamEntitlement = app(TeamEntitlementResolver::class);
        if (!$teamEntitlement->has($user, EntitlementKey::DownloadUnlimited)) {
            // Check team download pool
            $teamUsage = $this->getTeamUsage($team);
            $teamLimit = $teamEntitlement->value($user, EntitlementKey::DownloadLimit);

            if ($teamUsage >= $teamLimit) {
                throw new TeamDownloadLimitReachedException(
                    'Team download limit reached'
                );
            }
        }

        // Record download against team pool
        $this->recordTeamDownload($team, $user, $item);

        // Serve file
        return $this->serveFile($item);
    }

    protected function getTeamUsage(Team $team): int
    {
        $periodStart = $team->subscription->period_start;

        return DownloadRecord::where('team_id', $team->id)
            ->where('recorded_at', '>=', $periodStart)
            ->sum('quantity');
    }

    protected function recordTeamDownload(Team $team, User $user, Downloadable $item): void
    {
        DownloadRecord::create([
            'user_id' => $user->id,
            'team_id' => $team->id,
            'downloadable_type' => $item->getMorphClass(),
            'downloadable_id' => $item->id,
            'quantity' => 1,
            'recorded_at' => now(),
        ]);

        DownloadRecorded::dispatch($user, $item, $team);
    }
}
```

### Download Tracker Service

```php
class DownloadTracker
{
    public function record(User $user, Downloadable $item, ?Team $team = null): DownloadRecord
    {
        $record = DownloadRecord::create([
            'user_id' => $user->id,
            'team_id' => $team?->id,
            'downloadable_type' => $item->getMorphClass(),
            'downloadable_id' => $item->id,
            'quantity' => 1,
            'recorded_at' => now(),
            'metadata' => [
                'file_size' => $item->file_size,
                'file_type' => $item->file_type,
                'ip_address' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ],
        ]);

        // Update user subscription usage
        $subscription = $user->activeSubscription();
        if ($subscription) {
            $subscription->incrementUsage('downloads', 1);
        }

        // Update team usage if applicable
        if ($team && $team->subscription) {
            $team->subscription->incrementUsage('downloads', 1);
        }

        // Dispatch event
        DownloadRecorded::dispatch($user, $item, $team);

        // Check if approaching limit
        $this->checkLimitThreshold($user);

        return $record;
    }

    public function periodUsage(User $user): int
    {
        $subscription = $user->activeSubscription();

        if (!$subscription) {
            return 0;
        }

        $periodStart = $subscription->period_start;

        return DownloadRecord::where('user_id', $user->id)
            ->where('team_id', null) // Personal downloads only
            ->where('recorded_at', '>=', $periodStart)
            ->sum('quantity');
    }

    public function teamPeriodUsage(Team $team): int
    {
        $periodStart = $team->subscription->period_start;

        return DownloadRecord::where('team_id', $team->id)
            ->where('recorded_at', '>=', $periodStart)
            ->sum('quantity');
    }

    public function getDownloadHistory(User $user, int $limit = 50): Collection
    {
        return DownloadRecord::where('user_id', $user->id)
            ->with('downloadable')
            ->orderBy('recorded_at', 'desc')
            ->limit($limit)
            ->get();
    }

    protected function checkLimitThreshold(User $user): void
    {
        $enforcer = app(DownloadEnforcer::class);
        $remaining = $enforcer->remaining($user);
        $limit = $enforcer->getLimit($user);

        if ($limit === PHP_INT_MAX) {
            return; // Unlimited
        }

        $usagePercent = (($limit - $remaining) / $limit) * 100;

        // Warn at 80%
        if ($usagePercent >= 80 && $usagePercent < 100) {
            $user->notify(new DownloadLimitWarningNotification(
                remaining: $remaining,
                limit: $limit,
            ));
        }

        // Alert at 100%
        if ($remaining <= 0) {
            $user->notify(new DownloadLimitReachedNotification(
                limit: $limit,
                resets_at: $this->getResetDate($user),
            ));
        }
    }

    protected function getResetDate(User $user): Carbon
    {
        $subscription = $user->activeSubscription();

        if (!$subscription) {
            return now()->addMonth();
        }

        if ($subscription->plan->interval === 'yearly') {
            return $subscription->period_end;
        }

        return $subscription->period_end;
    }
}
```

## Download Enforcement

### Enforcer Service

```php
class DownloadEnforcer
{
    public function canDownload(User $user, Downloadable $item): DownloadCheckResult
    {
        $entitlement = app(EntitlementService::class);

        // Check item access
        if ($item->isPremium()) {
            if (!$entitlement->has($user, EntitlementKey::ComponentPro)) {
                return new DownloadCheckResult(
                    allowed: false,
                    reason: 'premium_item',
                    message: 'This item requires a Pro subscription',
                    upgrade_url: '/billing',
                );
            }
        }

        // Check unlimited downloads
        if ($entitlement->has($user, EntitlementKey::DownloadUnlimited)) {
            return new DownloadCheckResult(
                allowed: true,
                reason: 'unlimited',
            );
        }

        // Check monthly limit
        $limit = $this->getLimit($user);
        $used = app(DownloadTracker::class)->periodUsage($user);
        $remaining = max(0, $limit - $used);

        if ($remaining <= 0) {
            return new DownloadCheckResult(
                allowed: false,
                reason: 'limit_reached',
                message: "Download limit reached. You have {$remaining} downloads remaining.",
                remaining: $remaining,
                limit: $limit,
                resets_at: $this->getResetDate($user),
                upgrade_url: '/billing',
            );
        }

        return new DownloadCheckResult(
            allowed: true,
            reason: 'within_limit',
            remaining: $remaining,
            limit: $limit,
        );
    }

    public function getLimit(User $user): int
    {
        $entitlement = app(EntitlementService::class);

        if ($entitlement->has($user, EntitlementKey::DownloadUnlimited)) {
            return PHP_INT_MAX;
        }

        return $entitlement->value($user, EntitlementKey::DownloadLimit) ?? 10;
    }

    public function remaining(User $user): int
    {
        $limit = $this->getLimit($user);

        if ($limit === PHP_INT_MAX) {
            return PHP_INT_MAX;
        }

        $used = app(DownloadTracker::class)->periodUsage($user);

        return max(0, $limit - $used);
    }

    protected function getResetDate(User $user): Carbon
    {
        $subscription = $user->activeSubscription();

        if (!$subscription) {
            return now()->addMonth();
        }

        return $subscription->period_end;
    }
}
```

## Download Middleware

### Middleware Implementation

```php
class EnforceDownloadLimit
{
    public function handle(Request $request, Closure $next): Response
    {
        $user = $request->user();
        $item = $request->route('item');

        if (!$user || !$item) {
            return $next($request);
        }

        $enforcer = app(DownloadEnforcer::class);
        $result = $enforcer->canDownload($user, $item);

        if (!$result->allowed) {
            if ($request->expectsJson()) {
                return response()->json([
                    'error' => 'Download limit reached',
                    'message' => $result->message,
                    'remaining' => $result->remaining,
                    'limit' => $result->limit,
                    'resets_at' => $result->resets_at?->toIso8601String(),
                    'upgrade_url' => $result->upgrade_url,
                ], $result->reason === 'limit_reached' ? 429 : 403);
            }

            return redirect($result->upgrade_url ?? '/billing')
                ->with('error', $result->message);
        }

        return $next($request);
    }
}
```

### Rate Limiting

```php
class DownloadRateLimiter
{
    public function attempt(User $user, string $key, int $maxAttempts, int $decayMinutes = 1): bool
    {
        $key = "downloads:{$user->id}:{$key}";

        return RateLimiter::attempt(
            $key,
            $maxAttempts,
            fn () => true,
            $decayMinutes * 60
        );
    }

    function remaining(User $user, string $key, int $maxAttempts, int $decayMinutes = 1): int
    {
        $key = "downloads:{$user->id}:{$key}";

        return RateLimiter::remaining($key, $maxAttempts);
    }
}
```

## Download Analytics

### Analytics Service

```php
class DownloadAnalytics
{
    public function trackDownload(User $user, Downloadable $item, ?Team $team = null): void
    {
        Analytics::track('item_downloaded', [
            'user_id' => $user->id,
            'team_id' => $team?->id,
            'item_type' => $item->getMorphClass(),
            'item_id' => $item->id,
            'item_name' => $item->name,
            'is_premium' => $item->isPremium(),
            'user_plan' => $user->activeSubscription()?->plan?->slug ?? 'free',
            'file_size' => $item->file_size,
        ]);
    }

    public function getPopularItems(string $period = 'month', int $limit = 10): Collection
    {
        return DownloadRecord::where('recorded_at', '>=', now()->sub($period))
            ->select('downloadable_type', 'downloadable_id')
            ->selectRaw('count(*) as download_count')
            ->groupBy('downloadable_type', 'downloadable_id')
            ->orderByDesc('download_count')
            ->limit($limit)
            ->get();
    }

    public function getUsageByPlan(string $period = 'month'): array
    {
        return DownloadRecord::where('recorded_at', '>=', now()->sub($period))
            ->join('users', 'download_records.user_id', '=', 'users.id')
            ->leftJoin('subscriptions', function ($q) {
                $q->on('users.id', '=', 'subscriptions.user_id')
                  ->where('subscriptions.status', 'active');
            })
            ->leftJoin('plans', 'subscriptions.plan_id', '=', 'plans.id')
            ->selectRaw('plans.slug as plan, count(*) as downloads')
            ->groupBy('plans.slug')
            ->get()
            ->pluck('downloads', 'plan')
            ->toArray();
    }

    public function getConversionMetrics(string $period = 'month'): array
    {
        $downloads = DownloadRecord::where('recorded_at', '>=', now()->sub($period))->count();

        $uniqueDownloaders = DownloadRecord::where('recorded_at', '>=', now()->sub($period))
            ->distinct('user_id')
            ->count();

        $upgrades = Subscription::where('status', 'active')
            ->where('created_at', '>=', now()->sub($period))
            ->where('plan_id', '!=', Plan::where('slug', 'free')->first()->id)
            ->count();

        return [
            'total_downloads' => $downloads,
            'unique_downloaders' => $uniqueDownloaders,
            'upgrades' => $upgrades,
            'conversion_rate' => $uniqueDownloaders > 0 ? $upgrades / $uniqueDownloaders : 0,
        ];
    }
}
```

```php
class DownloadAccessMonitoring
{
    public function getMetrics(): array
    {
        return [
            'total_downloads_24h' => $this->getTotalDownloads(24),
            'unique_downloaders_24h' => $this->getUniqueDownloaders(24),
            'limit_reached_count_24h' => $this->getLimitReachedCount(24),
            'popular_items' => $this->getPopularItems(),

            'average_downloads_per_user' => $this->getAverageDownloadsPerUser(),
        ];

    protected function getTotalDownloads(int $hours): int
    {
        return DownloadRecord::where('recorded_at', '>=', now()->subHours($hours))
            ->sum('quantity');
    }

    protected function getUniqueDownloaders(int $hours): int
    {
        return DownloadRecord::where('recorded_at', '>=', now()->subHours($hours))
            ->distinct('user_id')
            ->count('user_id');
    }

    protected function getLimitReachedCount(int $hours): int
    {
        return DownloadLimitReachedEvent::where('created_at', '>=', now()->subHours($hours))
            ->count();
    }

    protected function getPopularItems(): array
    {
        return DownloadRecord::where('recorded_at', '>=', now()->subDays(7))
            ->select('downloadable_type', 'downloadable_id')
            ->selectRaw('count(*) as download_count')
            ->groupBy('downloadable_type', 'downloadable_id')
            ->orderByDesc('download_count')
            ->limit(10)
            ->get()
            ->toArray();
    }

    protected function getConversionRate(): float
    {
        $downloaders = DownloadRecord::where('recorded_at', '>=', now()->subDays(30))
            ->distinct('user_id')
            ->count('user_id');

        $upgrades = Subscription::where('status', 'active')
            ->where('created_at', '>=', now()->subDays(30))
            ->count();

        return $downloaders > 0 ? $upgrades / $downloaders : 0;
    }

    protected function getAverageDownloadsPerUser(): float
    {
        $totalDownloads = DownloadRecord::where('recorded_at', '>=', now()->subDays(30))
            ->sum('quantity');

        $uniqueUsers = DownloadRecord::where('recorded_at', '>=', now()->subDays(30))
            ->distinct('user_id')
            ->count('user_id');

        return $uniqueUsers > 0 ? $totalDownloads / $uniqueUsers : 0;
    }
}
```

```php
class DownloadHook
{
    public function beforeDownload(User $user, Downloadable $item): void
    {
        // Check for rate limiting
        if (config('downloads.rate_limiting_enabled')) {
            $limiter = app(DownloadRateLimiter::class);
            if (!$limiter->attempt($user, 'download')) {
                throw new TooManyDownloadsException('Download rate limit exceeded');
            }
        }
    }

    public function afterDownload(User $user, Downloadable $item): void
    {
        // Check if approaching limit
        $enforcer = app(DownloadEnforcer::class);
        $remaining = $enforcer->remaining($user);
        $limit = $enforcer->getLimit($user);

        if ($limit !== PHP_INT_MAX) {
            $percentage = $limit > 0 ? (($limit - $remaining) / $limit) * 100 : 0;

            if ($percentage >= config('downloads.warning_threshold', 80)) {
                DownloadLimitWarning::dispatch($user, $remaining, $limit);
            }

            if ($remaining <= 0) {
                DownloadLimitReached::dispatch($user, $limit, $limit);
            }
        }
    }
}
```

### Don'ts

- Don't forget to handle concurrent download requests

## Download Access Implementation Checklist

When implementing download access for a new feature, follow these steps:

### 1. Define Download Limits

```php
// In PlanSeeder or migration
$proPlan->limits = array_merge($proPlan->limits ?? [], [
    'downloads' => 100,
]);
$proPlan->save();
```

### 2. Add Entitlement Key

```php
enum EntitlementKey: string
{
    case DownloadLimit = 'downloads.limit';
    case DownloadUnlimited = 'download.unlimited';
}
```

### 3. Implement Download Handler

```php
class MyDownloadHandler
{
    public function handle(User $user, Downloadable $item): StreamedResponse
    {
        // Check download eligibility
        $result = app(DownloadEnforcer::class)->canDownload($user, $item);

        if (!$result->allowed) {
            throw new DownloadLimitReachedException($result->message);
        }

        // Record download
        app(DownloadTracker::class)->record($user, $item);

        // Serve file
        return $this->serveFile($item);
    }
}
```

### 4. Add Middleware

```php
Route::middleware('download-limit')->group(function () {
    Route::get('/downloads/{item}', [DownloadController::class, 'download']);
});
```

### 5. Add Tests

```php
public function test_download_limit_enforced(): void
{
    $user = User::factory()->create();
    $plan = Plan::factory()->create([
        'limits' => ['downloads' => 2],
    ]);

    Subscription::factory()->create([
        'user_id' => $user->id,
        'plan_id' => $plan->id,
        'status' => SubscriptionStatus::Active,
    ]);

    // Create 2 downloads (at limit)
    for ($i = 0; $i < 2; $i++) {
        DownloadRecord::factory()->create([
            'user_id' => $user->id,
            'recorded_at' => now(),
        ]);
    }

    $item = Downloadable::factory()->create();
    $result = app(DownloadEnforcer::class)->canDownload($user, $item);

    $this->assertFalse($result->allowed);
}
```

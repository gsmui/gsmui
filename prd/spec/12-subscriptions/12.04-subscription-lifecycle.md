# 12.04 — Subscription Lifecycle

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

---

## Purpose

Define the complete subscription state machine — every state a subscription can be in, every legal transition between states, and the rules governing each transition. The lifecycle is enforced by the `SubscriptionService` and validated by domain invariants.

## State Machine

```text
                  ┌──────────────┐
                  │  Incomplete   │  (initial payment pending)
                  └──────┬───────┘
                         │ Payment succeeds (trial)
                         ↓
                  ┌──────────────┐
           ┌──────│   Trialing    │────────────────────────────┐
           │      └──────┬───────┘                             │
           │             │ Trial ends / converts               │
           │             ↓                                     │
           │      ┌──────────────┐    Payment fails             │
           │      │    Active     │─────────────────────┐       │
           │      └──────┬───────┘                      │       │
           │             │                              ↓       │
           │             │ Cancel                  ┌─────────┐ │
           │             ↓                          │ Past Due │ │
           │      ┌──────────────┐                  └────┬────┘ │
           │      │   Canceled    │                       │      │
           │      └──────┬───────┘                  Payment made │
           │             │ Period ends                   ↓      │
           │             ↓                      ┌──────────────┐│
           │      ┌──────────────┐              │    Active     ││
           │      │   Expired     │              └──────────────┘│
           │      └──────────────┘                               │
           │                                                    │
           │      ┌──────────────────┐                           │
           └──────│ Incomplete Expired│ ←────────────────────────┘
                  └──────────────────┘
                                                          
                  ┌──────────────┐
                  │    Unpaid     │  (provider-level collection)
                  └──────────────┘
```

## State Definitions

| State | Description | Access Granted | Can Renew | Can Resume |
|---|---|---|---|---|
| Incomplete | Initial payment pending | No | N/A | N/A |
| Trialing | Within trial period | Full plan access | N/A | N/A |
| Active | Paid and current | Full plan access | Yes | N/A |
| Past Due | Payment failed, grace period | Full plan access | No | Yes |
| Canceled | Canceled at period end | Until period ends | No | Yes (before expiry) |
| Expired | Period ended after cancel | No | No | No |
| Unpaid | Provider-level collection | No | N/A | N/A |
| Incomplete Expired | Initial payment timed out | No | N/A | N/A |

## State Transitions

### Incomplete → Trialing

**Trigger:** Initial payment method confirmed, trial period starts

**Rules:**
- Payment method must be valid (no charge yet)
- User must not have used trial on this plan before
- One trial per user lifetime (enforced at application layer)

**Actions:**
1. Set status to `trialing`
2. Set `trial_ends_at = now() + plan.trial_days`
3. Synchronize entitlements
4. Dispatch `TrialStarted` event
5. Log in `subscription_status_histories`

### Incomplete → Incomplete Expired

**Trigger:** Payment method not confirmed within 24 hours

**Actions:**
1. Set status to `incomplete_expired`
2. Dispatch `SubscriptionIncompleteExpired` event

### Trialing → Active

**Trigger:** Trial period ended, first payment succeeds OR manual conversion

**Rules:**
- Payment method must be valid and charged
- If trial ended without payment → transition to Past Due

**Actions:**
1. Set status to `active`
2. Clear `trial_ends_at`
3. Synchronize entitlements
4. Dispatch `SubscriptionConverted` event

### Trialing → Past Due

**Trigger:** Trial ended, payment method charge failed

**Actions:**
1. Set status to `past_due`
2. Set `trial_ends_at = null`
3. Start grace period
4. Dispatch `SubscriptionPastDue` event

### Active → Past Due

**Trigger:** Renewal payment failed

**Rules:**
- Grace period begins (3 days default)
- All access maintained during grace
- Retry payment up to 3 times

**Actions:**
1. Set status to `past_due`
2. Schedule payment retry job
3. Dispatch `SubscriptionPastDue` event
4. Notify user

### Past Due → Active

**Trigger:** Payment retry succeeds

**Actions:**
1. Set status to `active`
2. Clear grace period
3. Cancel pending retry jobs
4. Synchronize entitlements
5. Dispatch `SubscriptionPaymentRecovered` event

### Active → Canceled

**Trigger:** User or admin cancels subscription

**Rules:**
- Access continues until `ends_at` (current period end)
- Set `cancel_at_period_end = true`
- No further renewals

**Actions:**
1. Set status to `canceled`
2. Set `canceled_at = now()`
3. Set `ends_at = current_period_end`
4. Dispatch `SubscriptionCanceled` event
5. Notify user
6. Schedule entitlement revocation at `ends_at`

### Canceled → Active (Resume)

**Trigger:** User resumes before period end

**Rules:**
- Only possible before `ends_at`
- Must have `cancel_at_period_end = true`
- Cannot resume expired subscriptions

**Actions:**
1. Set status to `active`
2. Set `cancel_at_period_end = false`
3. Clear `canceled_at`
4. Clear `ends_at`
5. Cancel scheduled entitlement revocation
6. Dispatch `SubscriptionResumed` event

### Canceled → Expired

**Trigger:** Period end reached, subscription not resumed

**Actions:**
1. Set status to `expired`
2. Revoke all entitlements
3. Dispatch `SubscriptionExpired` event
4. Notify user

### Active → Unpaid

**Trigger:** Provider-level collection efforts exhausted

**Actions:**
1. Set status to `unpaid`
2. Revoke all entitlements
3. Dispatch `SubscriptionUnpaid` event

### Past Due → Unpaid

**Trigger:** Grace period exhausted, all retries failed

**Actions:**
1. Set status to `unpaid`
2. Revoke all entitlements
3. Dispatch `SubscriptionUnpaid` event
4. Notify user

## State Transition Enforcement

```php
class SubscriptionStateMachine
{
    protected array $allowedTransitions = [
        'incomplete' => ['trialing', 'incomplete_expired'],
        'trialing' => ['active', 'past_due', 'canceled'],
        'active' => ['past_due', 'canceled', 'unpaid'],
        'past_due' => ['active', 'unpaid', 'canceled'],
        'canceled' => ['active', 'expired'],
        'expired' => [], // terminal
        'unpaid' => [], // terminal
        'incomplete_expired' => [], // terminal
    ];

    public function transition(Subscription $subscription, string $newStatus): void
    {
        if (!in_array($newStatus, $this->allowedTransitions[$subscription->status] ?? [])) {
            throw new InvalidTransitionException(
                "Cannot transition from {$subscription->status} to {$newStatus}"
            );
        }

        $fromStatus = $subscription->status;
        $subscription->status = $newStatus;
        $subscription->save();

        $subscription->statusHistories()->create([
            'from_status' => $fromStatus,
            'to_status' => $newStatus,
            'changed_by' => auth()->id(),
        ]);
    }
}
```

## Grace Period Logic

```php
class GracePeriodCalculator
{
    public function isInGracePeriod(Subscription $subscription): bool
    {
        if ($subscription->status !== 'past_due') {
            return false;
        }

        $graceDays = config('subscriptions.grace_period_days', 3);
        return $subscription->updated_at->addDays($graceDays)->isFuture();
    }

    public function gracePeriodEndsAt(Subscription $subscription): Carbon
    {
        $graceDays = config('subscriptions.grace_period_days', 3);
        return $subscription->updated_at->addDays($graceDays)->endOfDay();
    }

    public function hasAccessDuringGrace(Subscription $subscription): bool
    {
        return $this->isInGracePeriod($subscription);
    }
}
```

# State Transition Details

## Incomplete → Trialing

### Trigger Conditions

| Condition | Required | Description |
|---|---|---|
| Payment method valid | Yes | Card must be valid and not expired |
| Trial not used | Yes | User hasn't trialed this plan before |
| Plan offers trial | Yes | `plan.trial_days > 0` |
| No active subscription | Yes | One active subscription per user |
| Webhook configured | Yes | Payment provider must be set up |

### Actions Sequence

```text
1. Validate payment method via provider API
2. Create subscription record with status = 'trialing'
3. Set trial_starts_at = now()
4. Set trial_ends_at = now + plan.trial_days
5. Set current_period_start = now()
6. Set current_period_end = now + plan.trial_days
7. Create subscription_status_histories record
8. Synchronize entitlements (full plan access)
9. Initialize usage meters for the trial period
10. Dispatch TrialStarted event
11. Schedule ExpireTrialJob for trial_ends_at
12. Send trial welcome email
```

### Code Implementation

```php
class SubscriptionStateMachine
{
    public function transitionToTrialing(Subscription $subscription, array $context = []): void
    {
        $this->validateTransition($subscription, 'trialing');

        $plan = $subscription->plan;
        $trialDays = $context['trial_days'] ?? $plan->trial_days;

        $subscription->update([
            'status' => 'trialing',
            'trial_starts_at' => now(),
            'trial_ends_at' => now()->addDays($trialDays),
            'current_period_start' => now(),
            'current_period_end' => now()->addDays($trialDays),
        ]);

        // Audit trail
        $subscription->statusHistories()->create([
            'from_status' => null,
            'to_status' => 'trialing',
            'changed_by' => auth()->id(),
            'reason' => 'Trial started',
            'metadata' => ['trial_days' => $trialDays],
        ]);

        // Entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // Usage meters
        app(UsageMeterService::class)->initialize($subscription);

        // Events
        TrialStarted::dispatch($subscription);

        // Scheduled jobs
        ExpireTrialJob::dispatch($subscription)
            ->delay($subscription->trial_ends_at);
    }
}
```

### Entry Guards

```php
protected function guardTrialing(Subscription $subscription): void
{
    // Check no existing active subscription
    $existingActive = Subscription::where('user_id', $subscription->user_id)
        ->where('status', 'active')
        ->where('id', '!=', $subscription->id)
        ->exists();

    if ($existingActive) {
        throw new TransitionGuardException('User already has an active subscription');
    }

    // Check trial eligibility
    $hasUsedTrial = Subscription::where('user_id', $subscription->user_id)
        ->where('plan_id', $subscription->plan_id)
        ->whereNotNull('trial_ends_at')
        ->exists();

    if ($hasUsedTrial) {
        throw new TransitionGuardException('Trial already used for this plan');
    }
}
```

## Trialing → Active

### Trigger Conditions

| Condition | Required | Description |
|---|---|---|
| Trial period ended | Yes | `trial_ends_at` is in the past |
| Payment succeeds | Yes | Provider charges payment method |
| Subscription status | Yes | Must be in `trialing` state |

### Actions Sequence

```text
1. Validate subscription is in trialing state
2. Attempt to charge payment method via provider
3. If charge succeeds:
   a. Set status = 'active'
   b. Set current_period_start = trial_ends_at
   c. Set current_period_end = now + plan.interval
   d. Clear trial_ends_at
   e. Create status_histories record
   f. Synchronize entitlements
   g. Dispatch SubscriptionConverted event
   h. Send conversion confirmation email
4. If charge fails:
   a. Transition to past_due
   b. Start grace period
```

### Code Implementation

```php
public function transitionToActive(Subscription $subscription, array $context = []): void
{
    $this->validateTransition($subscription, 'active');

    // Calculate new period
    $interval = $subscription->plan->interval;
    $periodEnd = match ($interval) {
        'monthly' => now()->addMonth(),
        'yearly' => now()->addYear(),
        default => now()->addMonth(),
    };

    $subscription->update([
        'status' => 'active',
        'current_period_start' => now(),
        'current_period_end' => $periodEnd,
        'trial_ends_at' => null,
    ]);

    // Audit trail
    $subscription->statusHistories()->create([
        'from_status' => 'trialing',
        'to_status' => 'active',
        'changed_by' => null, // system
        'reason' => 'Trial converted to active',
    ]);

    // Entitlements
    app(EntitlementService::class)->synchronize($subscription);

    // Events
    SubscriptionConverted::dispatch($subscription);

    // Email
    TrialConvertedMail::to($subscription->user)->send();
}
```

## Active → Past Due

### Trigger Conditions

| Condition | Required | Description |
|---|---|---|
| Payment fails | Yes | Provider reports payment failure |
| Subscription active | Yes | Must be in `active` state |
| Grace period available | Yes | Haven't exceeded retry limit |

### Actions Sequence

```text
1. Validate subscription is in active state
2. Set status = 'past_due'
3. Set grace_period_ends_at = now + grace_period_days
4. Increment payment_failure_count
5. Set last_payment_failure_at = now
6. Create status_histories record
7. Schedule payment retry jobs
8. Dispatch SubscriptionPastDue event
9. Send payment failed email
10. Show in-app banner
```

### Code Implementation

```php
public function transitionToPastDue(Subscription $subscription, array $context = []): void
{
    $this->validateTransition($subscription, 'past_due');

    $graceDays = config('subscriptions.grace_period_days', 3);

    $subscription->update([
        'status' => 'past_due',
        'grace_period_ends_at' => now()->addDays($graceDays),
        'metadata' => array_merge($subscription->metadata ?? [], [
            'payment_failure_count' => ($subscription->metadata['payment_failure_count'] ?? 0) + 1,
            'last_payment_failure_at' => now()->toISOString(),
        ]),
    ]);

    // Audit trail
    $subscription->statusHistories()->create([
        'from_status' => 'active',
        'to_status' => 'past_due',
        'changed_by' => null, // system
        'reason' => 'Payment failed',
        'metadata' => ['failure_count' => $subscription->metadata['payment_failure_count']],
    ]);

    // Schedule retries
    app(PaymentRetryManager::class)->scheduleRetries($subscription);

    // Events
    SubscriptionPastDue::dispatch($subscription);

    // Notifications
    PaymentFailedMail::to($subscription->user)->send();
}
```

### Grace Period Duration

| Retry Attempt | Timing | Action |
|---|---|---|
| 1st retry | Immediate | Webhook-triggered |
| 2nd retry | +24 hours | Scheduled job |
| 3rd retry | +72 hours | Final attempt |
| After 3 retries | — | Status → Unpaid |

## Active → Canceled

### Trigger Conditions

| Condition | Required | Description |
|---|---|---|
| User or admin request | Yes | Cancellation must be requested |
| Subscription active | Yes | Must be in `active` or `trialing` state |

### Actions Sequence

```text
1. Validate subscription is cancellable
2. Set status = 'canceled'
3. Set canceled_at = now()
4. Set ends_at = current_period_end
5. Set cancel_at_period_end = true
6. Create status_histories record
7. Schedule entitlement revocation at ends_at
8. Dispatch SubscriptionCanceled event
9. Send cancellation confirmation email
10. Schedule win-back emails
```

### Code Implementation

```php
public function transitionToCanceled(Subscription $subscription, array $context = []): void
{
    $this->validateTransition($subscription, 'canceled');

    $immediately = $context['immediately'] ?? false;

    if ($immediately) {
        $subscription->update([
            'status' => 'canceled',
            'canceled_at' => now(),
            'ends_at' => now(),
            'cancel_at_period_end' => false,
        ]);

        // Revoke entitlements immediately
        app(EntitlementService::class)->revoke($subscription);
    } else {
        $subscription->update([
            'status' => 'canceled',
            'canceled_at' => now(),
            'ends_at' => $subscription->current_period_end,
            'cancel_at_period_end' => true,
        ]);

        // Schedule revocation at period end
        RevokeEntitlementsJob::dispatch($subscription)
            ->delay($subscription->current_period_end);
    }

    // Audit trail
    $subscription->statusHistories()->create([
        'from_status' => 'active',
        'to_status' => 'canceled',
        'changed_by' => auth()->id(),
        'reason' => $context['reason'] ?? 'User requested cancellation',
        'metadata' => ['immediately' => $immediately],
    ]);

    // Events
    SubscriptionCanceled::dispatch($subscription);

    // Email
    CancellationConfirmedMail::to($subscription->user)->send([
        'access_until' => $subscription->ends_at,
    ]);

    // Win-back
    if (!$immediately) {
        app(WinBackService::class)->schedule($subscription);
    }
}
```

## Canceled → Active (Resume)

### Trigger Conditions

| Condition | Required | Description |
|---|---|---|
| User request | Yes | User wants to resume |
| Before period end | Yes | `ends_at` is in the future |
| Cancellation pending | Yes | `cancel_at_period_end = true` |

### Actions Sequence

```text
1. Validate subscription can be resumed
2. Set status = 'active'
3. Set cancel_at_period_end = false
4. Clear canceled_at
5. Clear ends_at
6. Create status_histories record
7. Cancel scheduled entitlement revocation
8. Synchronize entitlements
9. Dispatch SubscriptionResumed event
10. Send resume confirmation email
```

### Code Implementation

```php
public function transitionToActiveFromCanceled(Subscription $subscription): void
{
    $this->validateTransition($subscription, 'active');

    if (!$subscription->cancel_at_period_end) {
        throw new TransitionGuardException('Subscription is not pending cancellation');
    }

    if ($subscription->ends_at && $subscription->ends_at->isPast()) {
        throw new TransitionGuardException('Subscription has already expired');
    }

    $subscription->update([
        'status' => 'active',
        'cancel_at_period_end' => false,
        'canceled_at' => null,
        'ends_at' => null,
    ]);

    // Audit trail
    $subscription->statusHistories()->create([
        'from_status' => 'canceled',
        'to_status' => 'active',
        'changed_by' => auth()->id(),
        'reason' => 'Subscription resumed',
    ]);

    // Cancel scheduled revocation
    RevokeEntitlementsJob::where('subscription_id', $subscription->id)
        ->cancel();

    // Entitlements
    app(EntitlementService::class)->synchronize($subscription);

    // Events
    SubscriptionResumed::dispatch($subscription);

    // Email
    SubscriptionResumedMail::to($subscription->user)->send();
}
```

## Canceled → Expired

### Trigger Conditions

| Condition | Required | Description |
|---|---|---|
| Period end reached | Yes | `ends_at` is in the past |
| Not resumed | Yes | Subscription still canceled |

### Actions Sequence

```text
1. Validate subscription is canceled and past ends_at
2. Set status = 'expired'
3. Create status_histories record
4. Revoke all entitlements
5. Remove user from any team seats
6. Dispatch SubscriptionExpired event
7. Send expiration email
8. Clean up usage meters
```

### Code Implementation

```php
public function transitionToExpired(Subscription $subscription): void
{
    $this->validateTransition($subscription, 'expired');

    $subscription->update([
        'status' => 'expired',
    ]);

    // Audit trail
    $subscription->statusHistories()->create([
        'from_status' => 'canceled',
        'to_status' => 'expired',

    SubscriptionExpired::dispatch($subscription);

    // Email
    SubscriptionExpiredMail::to($subscription->user)->send();
}
```

# State Transition Validation

## Allowed Transitions Matrix

```php
class SubscriptionStateMachine
{
    protected array $allowedTransitions = [
        'incomplete' => ['trialing', 'incomplete_expired'],
        'trialing' => ['active', 'past_due', 'canceled'],
        'active' => ['past_due', 'canceled', 'unpaid'],
        'past_due' => ['active', 'unpaid', 'canceled'],
        'canceled' => ['active', 'expired'],
        'expired' => [], // terminal
        'unpaid' => [], // terminal
        'incomplete_expired' => [], // terminal
    ];

    public function canTransition(Subscription $subscription, string $newStatus): bool
    {
        $current = $subscription->status;
        return in_array($newStatus, $this->allowedTransitions[$current] ?? []);
    }

    public function validateTransition(Subscription $subscription, string $newStatus): void
    {
        if (!$this->canTransition($subscription, $newStatus)) {
            throw new InvalidTransitionException(
                "Cannot transition from {$subscription->status} to {$newStatus}"
            );
        }
    }

    public function transition(Subscription $subscription, string $newStatus, array $context = []): void
    {
        $this->validateTransition($subscription, $newStatus);

        $fromStatus = $subscription->status;

        // Call the specific transition method
        $method = 'transitionTo' . Str::studly($newStatus);
        if (method_exists($this, $method)) {
            $this->{$method}($subscription, $context);
        } else {
            // Generic transition
            $subscription->update(['status' => $newStatus]);
            $subscription->statusHistories()->create([
                'from_status' => $fromStatus,
                'to_status' => $newStatus,
                'changed_by' => auth()->id(),
            ]);
        }
    }
}
```

## Transition Guards

```php
class TransitionGuards
{
    public function guard(Subscription $subscription, string $newStatus): void
    {
        match ($newStatus) {
            'trialing' => $this->guardTrialing($subscription),
            'active' => $this->guardActive($subscription),
            'past_due' => $this->guardPastDue($subscription),
            'canceled' => $this->guardCanceled($subscription),
            'expired' => $this->guardExpired($subscription),
            'unpaid' => $this->guardUnpaid($subscription),
            default => null,
        };
    }

    protected function guardTrialing(Subscription $subscription): void
    {
        // No existing active subscription
        $hasActive = Subscription::where('user_id', $subscription->user_id)
            ->where('status', 'active')
            ->exists();

        if ($hasActive) {
            throw new TransitionGuardException('User already has an active subscription');
        }

        // Trial not already used
        $usedTrial = Subscription::where('user_id', $subscription->user_id)
            ->where('plan_id', $subscription->plan_id)
            ->whereNotNull('trial_ends_at')
            ->exists();

        if ($usedTrial) {
            throw new TransitionGuardException('Trial already used for this plan');
        }
    }

    protected function guardActive(Subscription $subscription): void
    {
        // Payment method must be valid
        if (!$subscription->user->hasValidPaymentMethod()) {
            throw new TransitionGuardException('No valid payment method');
        }
    }

    protected function guardCanceled(Subscription $subscription): void
    {
        // Cannot cancel already canceled subscription
        if ($subscription->status === 'canceled') {
            throw new TransitionGuardException('Subscription already canceled');
        }
    }
}
```

```php
class SubscriptionAuditTrail
{
    public function history(Subscription $subscription): Collection
    {
        return $subscription->statusHistories()
            ->with('changedBy')
            ->orderBy('created_at', 'desc')
            ->get();
    }

    public function lastTransition(Subscription $subscription): ?SubscriptionStatusHistory
    {
        return $subscription->statusHistories()
            ->latest()
            ->first();
    }

    public function timeInState(Subscription $subscription, string $state): int
    {
        $histories = $subscription->statusHistories()
            ->where('to_status', $state)
            ->orderBy('created_at')
            ->get();

        $totalSeconds = 0;
        foreach ($histories as $index => $history) {
            $exitHistory = $subscription->statusHistories()
                ->where('from_status', $state)
                ->where('created_at', '>', $history->created_at)
                ->first();

            $exitTime = $exitHistory?->created_at ?? now();
            $totalSeconds += $history->created_at->diffInSeconds($exitTime);
        }

        return $totalSeconds;
    }
}
```

# Lifecycle Automation

## Automated Workflows

| Workflow | Trigger | Action |
|---|---|---|
| Trial Expiry | trial_ends_at reached | Attempt payment, transition |
| Grace Period End | grace_period_ends_at reached | Transition to unpaid |
| Renewal | current_period_end reached | Process renewal |
| Downgrade | downgrade_scheduled_at reached | Apply downgrade |
| Entitlement Revocation | ends_at reached | Revoke all entitlements |
| Win-back Email | 3/7/14/30 days post-cancel | Send win-back sequence |

## Workflow Engine

```php
class SubscriptionWorkflowEngine
{
    public function runScheduledWorkflows(): void
    {
        // 1. Expire trials
        $this->expireTrials();

        // 2. End grace periods
        $this->endGracePeriods();

        // 3. Apply downgrades
        $this->applyDowngrades();

        // 4. Revoke entitlements
        $this->revokeEntitlements();

        // 5. Send win-back emails
        $this->sendWinBackEmails();
    }

    protected function expireTrials(): void
    {
        Subscription::where('status', 'trialing')
            ->where('trial_ends_at', '<=', now())
            ->each(function ($subscription) {
                app(TrialConverter::class)->convert($subscription);
            });
    }

    protected function endGracePeriods(): void
    {
        Subscription::where('status', 'past_due')
            ->where('grace_period_ends_at', '<=', now())
            ->each(function ($subscription) {
                app(SubscriptionStateMachine::class)->transitionToUnpaid($subscription);
            });
    }

    protected function applyDowngrades(): void
    {
        Subscription::where('status', 'active')
            ->whereNotNull('metadata->downgrade_to')
            ->where('metadata->downgrade_scheduled_at', '<=', now())
            ->each(function ($subscription) {
                $newPlanId = $subscription->metadata['downgrade_to'];
                $newPlan = Plan::find($newPlanId);

                if ($newPlan) {
                    $subscription->update(['plan_id' => $newPlan->id]);
                    app(EntitlementService::class)->synchronize($subscription);
                }
            });
    }
}
```

```php
class SyncSubscriptionStatusJob implements ShouldQueue
{
    public function handle(): void
    {
        $subscriptions = Subscription::where('provider', 'stripe')
            ->where('provider_subscription_id', '!=', null)
            ->get();

        foreach ($subscriptions as $subscription) {
            $providerStatus = $this->getProviderStatus($subscription);

            if ($providerStatus && $providerStatus !== $subscription->status) {
                // Log mismatch
                Log::warning('Subscription status mismatch', [
                    'subscription_id' => $subscription->id,
                    'local_status' => $subscription->status,
                    'provider_status' => $providerStatus,
                ]);

                // Optionally auto-fix
                if (config('subscriptions.auto_sync_status')) {
                    $subscription->update(['status' => $providerStatus]);
                    app(EntitlementService::class)->synchronize($subscription);
                }
            }
        }
    }

    protected function getProviderStatus(Subscription $subscription): ?string
    {
        return match ($subscription->provider) {
            'stripe' => app(StripeBillingProvider::class)
                ->getSubscriptionStatus($subscription->provider_subscription_id),
            'paddle' => app(PaddleBillingProvider::class)
                ->getSubscriptionStatus($subscription->provider_subscription_id),
            default => null,
        };
    }
```

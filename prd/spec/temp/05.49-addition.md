# Git Workflow Details

## Branch Naming Conventions

| Branch Type | Pattern | Example | Purpose |
|-------------|---------|---------|---------|
| Feature | feature/{ticket}-{slug} | feature/GSMUI-123-datatable | New features |
| Bugfix | bugfix/{ticket}-{slug} | bugfix/GSMUI-456-sort-fix | Bug fixes |
| Hotfix | hotfix/{ticket}-{slug} | hotfix/GSMUI-789-security-patch | Production fixes |
| Release | release/{version} | release/2.1.0 | Release preparation |
| Chore | chore/{ticket}-{slug} | chore/GSMUI-101-deps-update | Maintenance |
| Docs | docs/{ticket}-{slug} | docs/GSMUI-202-api-docs | Documentation |

## Branch Lifecycle

```
main (production-ready)
    |
    +-- develop (integration branch)
    |       |
    |       +-- feature/GSMUI-123-new-component
    |       |       +-- feature/GSMUI-123-add-tests
    |       |       +-- feature/GSMUI-123-add-docs
    |       |       --> Merge to develop
    |       |
    |       +-- bugfix/GSMUI-456-sorting-fix
    |       |       --> Merge to develop
    |       |
    |       +-- release/2.1.0
    |               --> Merge to main + develop
    |
    +-- hotfix/GSMUI-789-security-patch
            --> Merge to main + develop
```

## Commit Message Convention

```
<type>(<scope>): <subject>

<body>

<footer>
```

### Types

| Type | Description | Example |
|------|-------------|---------|
| feat | New feature | feat(components): add date picker component |
| fix | Bug fix | fix(auth): resolve login redirect loop |
| docs | Documentation | docs(api): add webhook endpoint docs |
| style | Formatting (no code change) | style(blog): fix paragraph spacing |
| refactor | Code restructuring | refactor(services): extract payment logic |
| test | Adding tests | test(components): add datatable tests |
| chore | Maintenance | chore(deps): update Laravel to 11.0 |
| perf | Performance improvement | perf(queries): optimize component listing |
| ci | CI/CD changes | ci(actions): add browser test job |
| build | Build system | build(vite): configure code splitting |
| revert | Revert commit | revert: feat(components): add picker |

### Scopes

| Scope | Description |
|-------|-------------|
| auth | Authentication and authorization |
| components | UI component library |
| api | REST API |
| admin | Admin dashboard |
| billing | Payment and subscriptions |
| blog | Blog system |
| showcase | Showcase platform |
| marketplace | Marketplace |
| templates | Template system |
| search | Search functionality |
| ai | AI features |
| ui | General UI/styling |
| db | Database changes |
| docs | Documentation |
| deps | Dependencies |
| ci | CI/CD |
| security | Security fixes |
| perf | Performance |

### Subject Rules

- Use imperative mood ("add feature" not "added feature")
- Don't capitalize first letter
- No period at end
- Max 72 characters

### Examples

```
feat(components): add date picker component

- Add Alpine.js-based date picker with range support
- Include month/year navigation
- Support keyboard navigation (arrow keys, Home/End)
- Add dark mode support
- Include Tailwind CSS styling

Closes GSMUI-123

---

fix(billing): resolve duplicate charge on trial conversion

Previously, trial conversion could charge the user twice due to
a race condition between the trial expiry job and the payment
webhook handler. This fix adds a mutex lock on the subscription
update to prevent concurrent modifications.

Fixes GSMUI-456

---

docs(api): add complete webhook documentation

Add documentation for all webhook events, payload formats,
retry behavior, and signature verification. Include code
examples for PHP, JavaScript, and Python.

Closes GSMUI-202
```

## Version Numbering

```
Semantic Versioning: MAJOR.MINOR.PATCH

MAJOR: Breaking changes
- Database schema changes
- API endpoint removal/renaming
- Component API changes
- Minimum PHP/Laravel version changes

MINOR: New features (backward-compatible)
- New components
- New API endpoints
- New admin features
- New marketplace features

PATCH: Bug fixes (backward-compatible)
- Security patches
- Performance improvements
- UI bug fixes
- Documentation corrections

Examples:
- 2.1.0 -> 2.1.1 (patch: bug fix)
- 2.1.0 -> 2.2.0 (minor: new feature)
- 2.1.0 -> 3.0.0 (major: breaking change)
```

# Coding Standards Deep Dive

## PHP Standards (PSR-12 Extended)

| Rule | Standard | Example |
|------|----------|---------|
| Indentation | 4 spaces | No tabs |
| Line length | 120 soft limit | Break long lines |
| Naming (classes) | PascalCase | `ComponentService` |
| Naming (methods) | camelCase | `getUserById()` |
| Naming (variables) | camelCase | `$userComponents` |
| Naming (constants) | UPPER_SNAKE | `MAX_RETRY_COUNT` |
| Naming (properties) | camelCase | `$downloadCount` |
| Visibility | Always explicit | `private $foo;` |
| Return type | Always declared | `public function get(): string` |
| Type hints | Always used | `function process(Component $comp): void` |
| Void returns | Explicit | `public function save(): void` |
| Null | Use nullable type | `?string` not `string = null` |
| Collections | Use type hints | `Collection<Component>` |

## JavaScript Standards

| Rule | Standard | Example |
|------|----------|---------|
| Syntax | ES6+ | const, let, arrow functions |
| Naming (variables) | camelCase | `userComponents` |
| Naming (functions) | camelCase | `getUserById()` |
| Naming (classes) | PascalCase | `ComponentService` |
| Naming (constants) | UPPER_SNAKE | `MAX_RETRY_COUNT` |
| Semicolons | Always | Required |
| Quotes | Single | `'string'` |
| Trailing commas | Yes | `[1, 2, 3,]` |
| Template literals | Preferred | `` `Hello ${name}` `` |

## Blade Standards

| Rule | Standard | Example |
|------|----------|---------|
| Component naming | kebab-case | `<x-gsmui:button>` |
| Directive spacing | Space after @ | `@if ($condition)` |
| Indentation | 4 spaces | Consistent nesting |
| Self-closing tags | When no content | `<x-gsmui:input />` |
| CSS classes | Tailwind utility | `class="flex items-center"` |
| Alpine directives | x-data, x-on | `x-data="{ open: false }"` |

# Testing Standards

## Test Naming Convention

```php
// Method: test_{method_name}_{scenario}_{expected_result}
public function test_login_with_valid_credentials_redirects_to_dashboard(): void
public function test_login_with_invalid_credentials_returns_401(): void
public function test_login_with_locked_account_returns_423(): void

// Or: it_{scenario}_{expected_result}
public function test_it_redirects_to_dashboard_on_successful_login(): void
public function test_it_returns_401_on_invalid_credentials(): void
```

## Test Structure (AAA Pattern)

```php
public function test_subscription_activation_grants_pro_access(): void
{
    // Arrange
    $user = User::factory()->create();
    $plan = Plan::factory()->pro()->create();

    // Act
    $this->actingAs($user)
         ->post('/subscriptions', ['plan' => $plan->slug]);

    // Assert
    $this->assertDatabaseHas('subscriptions', [
        'user_id' => $user->id,
        'plan_id' => $plan->id,
        'status' => 'active',
    ]);
    $this->assertTrue($user->fresh()->isPro());
}
```

## Test Categories

| Category | Purpose | Execution Speed | Count Target |
|----------|---------|----------------|-------------|
| Unit | Test individual classes | Fast (< 1ms) | 500+ |
| Feature | Test HTTP endpoints | Medium (< 100ms) | 200+ |
| Browser | Test user interactions | Slow (< 5s) | 50+ |
| Integration | Test service interactions | Medium (< 500ms) | 100+ |
| Business Rule | Test domain invariants | Medium (< 100ms) | 150+ |

# 13.400 Navigation — GsmUi Navigation Category Specification

## Overview

Navigation components enable users to move through the application, understand their location, and access different sections.

## Components

| Component | Status | Description |
|-----------|--------|-------------|
| [Navbar](./13.401-navbar.md) | Stable | Top application bar |
| [Sidebar](./13.402-sidebar.md) | Stable | Collapsible side navigation |
| [Tabs](./13.403-tabs.md) | Stable | Tabbed content panes |
| [Breadcrumb](./13.404-breadcrumb.md) | Stable | Hierarchical location trail |
| [Pagination](./13.405-pagination.md) | Stable | Page navigation controls |
| [Menu](./13.406-menu.md) | Stable | Context/action menus |
| [Tree](./13.407-tree.md) | Beta | Hierarchical navigation |
| [Steps](./13.408-steps.md) | Stable | Multi-step process indicator |
| [Dock](./13.409-dock.md) | Beta | Bottom/app bar (mobile) |
| [CommandPalette](./13.410-command-palette.md) | Beta | Keyboard-driven search/actions |

## Design Principles

### Navigation Hierarchy

```
Global (Navbar) → Section (Sidebar) → Local (Tabs/Breadcrumb) → Inline (Pagination/Steps)
```

### Mobile-First

- Navbar collapses to hamburger menu
- Sidebar becomes drawer/off-canvas
- Tabs become scrollable
- Dock for primary actions

### Keyboard Navigation

| Key | Action |
|-----|--------|
| `Tab` | Next focusable |
| `Shift+Tab` | Previous focusable |
| `Enter` / `Space` | Activate |
| `ArrowLeft/Right` | Horizontal (tabs, breadcrumb, pagination) |
| `ArrowUp/Down` | Vertical (menu, tree, sidebar) |
| `Home` / `End` | First/Last |
| `Escape` | Close dropdown/drawer |
| `Ctrl/Cmd+K` | Open Command Palette |

## Component Specifications

### 13.401 Navbar

**Top application bar**

```blade
<x-gsmui:navbar 
    :brand="[
        'href' => '/',
        'label' => 'GsmUi',
        'icon' => 'cube',
    ]"
    :links="[
        ['label' => 'Features', 'href' => '/features'],
        ['label' => 'Pricing', 'href' => '/pricing'],
        ['label' => 'Docs', 'href' => '/docs'],
    ]"
    :actions="[
        ['label' => 'Login', 'href' => '/login', 'variant' => 'ghost'],
        ['label' => 'Get Started', 'href' => '/signup', 'variant' => 'primary'],
    ]"
    :search="[
        'placeholder' => 'Search docs...',
        'action' => '/search',
    ]"
    sticky
    class="border-b"
/>
```

**Props:**
- `brand` - Brand object (href, label, icon)
- `links` - Navigation links array
- `actions` - Action buttons (right side)
- `search` - Search configuration
- `sticky` - `position: sticky; top: 0`
- `transparent` - Transparent background
- `border` - Bottom border
- `mobileBreakpoint` - Collapse breakpoint (default: `lg`)

**Responsive:**
- Desktop: Horizontal links
- Mobile: Hamburger → Drawer/Sheet

### 13.402 Sidebar

**Collapsible side navigation**

```blade
<x-gsmui:sidebar 
    :items="[
        ['label' => 'Dashboard', 'href' => '/', 'icon' => 'home'],
        ['label' => 'Projects', 'href' => '/projects', 'icon' => 'folder', 'badge' => 3],
        ['label' => 'Team', 'icon' => 'users', 'children' => [
            ['label' => 'Members', 'href' => '/team'],
            ['label' => 'Invite', 'href' => '/team/invite'],
        ]],
        ['label' => 'Settings', 'href' => '/settings', 'icon' => 'cog-6-tooth'],
    ]"
    :collapsed="$sidebarCollapsed"
    wire:model="sidebarCollapsed"
    class="border-r"
/>
```

**Item Structure:**
```php
[
    'label' => 'Dashboard',
    'href' => '/dashboard',
    'icon' => 'home',
    'badge' => 3,              // Notification count
    'badgeColor' => 'danger',  // Badge variant
    'children' => [...],       // Nested items
    'disabled' => false,
    'external' => false,       // target="_blank"
    'active' => false,         // Manual active state
]
```

**Props:**
- `items` - Navigation items array
- `collapsed` - Collapsed state (wire:model supported)
- `collapsible` - Allow collapse (default: true)
- `variant` - `default` | `bordered` | `filled`
- `width` - Expanded width (default: 16rem/256px)
- `collapsedWidth` - Collapsed width (default: 4rem/64px)

**Events:** `collapse-change` `{ collapsed: boolean }`

**Tabbed content panes**

```blade
<x-gsmui:tabs 
    wire:model="activeTab"
    variant="line"
    class="w-full"

    <x-gsmui:tabs.list>
        <x-gsmui:tabs.tab value="overview" icon="home">Overview</x-gsmui:tabs.tab>
        <x-gsmui:tabs.tab value="features" icon="star">Features</x-gsmui:tabs.tab>
        <x-gsmui:tabs.tab value="pricing" icon="currency-dollar">Pricing</x-gsmui:tabs.tab>
        <x-gsmui:tabs.tab value="docs" icon="book-open" disabled>Docs</x-gsmui:tabs.tab>
    </x-gsmui:tabs.list>
    
    <x-gsmui:tabs.panels>
        <x-gsmui:tabs.panel value="overview">Overview content</x-gsmui:tabs.panel>
        <x-gsmui:tabs.panel value="features">Features content</x-gsmui:tabs.panel>
        <x-gsmui:tabs.panel value="pricing">Pricing content</x-gsmui:tabs.panel>
    </x-gsmui:tabs.panels>

```

**Variants:**
| Variant | Indicator | Use Case |
|---------|-----------|----------|

| `enclosed` | Background pill | Secondary/filters |
| `soft` | Background highlight | Minimal |
| `pills` | Rounded pills | Compact spaces |

**Props:**
- `variant` - `line` | `enclosed` | `soft` | `pills`
- `orientation` - `horizontal` | `vertical`
- `activation` - `auto` | `manual` (keyboard activation)
- `lazy` - Lazy render panels (default: true)

**Slots:** `list`, `panels` (via sub-components)

### 13.404 Breadcrumb

**Hierarchical location trail**

```blade
<x-gsmui:breadcrumb 
    :items="[
        ['label' => 'Home', 'href' => '/'],
        ['label' => 'Products', 'href' => '/products'],
        ['label' => 'Category', 'href' => '/products/category'],
        ['label' => 'Product Name', 'current' => true],
    ]"
    separator="chevron-right"
    class="mb-6"
/>
```

**Props:**
- `items` - Breadcrumb items
- `separator` - Icon name (default: chevron-right)
- `maxItems` - Collapse after N items (default: 5)
- `truncate` - Truncate long labels

**Item Structure:**
```php
[
    'label' => 'Products',
    'href' => '/products',
    'icon' => 'cube',           // Optional leading icon
    'current' => false,         // Last item only
    'disabled' => false,
]
```

### 13.405 Pagination

**Page navigation controls**

```blade
<x-gsmui:pagination 
    :current-page="$posts->currentPage()"
    :last-page="$posts->lastPage()"
    :per-page="$posts->perPage()"
    :total="$posts->total()"
    wire:model="page"
    show-first-last
    show-page-numbers
    :boundary-links="2"
/>
```

**Props:**
- `currentPage` - Current page (1-indexed)
- `lastPage` - Total pages
- `perPage` - Items per page
- `total` - Total items
- `showFirstLast` - Show first/last buttons
- `showPageNumbers` - Show page number buttons
- `boundaryLinks` - Pages at start/end (default: 1)
- `siblingLinks` - Pages around current (default: 1)

**Sizes:** `sm` | `md` | `lg`
**Variants:** `default` | `simple` (prev/next only)

### 13.406 Menu

**Context/action menus**

```blade
<x-gsmui:menu>
    <x-slot name="trigger">
        <x-gsmui:button variant="ghost" icon="ellipsis-vertical" />
    </x-slot>
    
    <x-gsmui:menu.items>
        <x-gsmui:menu.item icon="pencil" wire:click="edit">Edit</x-gsmui:menu.item>
        <x-gsmui:menu.item icon="duplicate" wire:click="duplicate">Duplicate</x-gsmui:menu.item>
        <x-gsmui:menu.divider />
        <x-gsmui:menu.item icon="trash" variant="danger" wire:click="delete">Delete</x-gsmui:menu.item>
    </x-gsmui:menu.items>
</x-gsmui:menu>
```

**Sub-components:**
- `menu.trigger` - Trigger element
- `menu.items` - Items container
- `menu.item` - Individual item
- `menu.divider` - Separator
- `menu.group` - Grouped items with label
- `menu.submenu` - Nested menu

**Item Props:**
- `icon` - Leading icon
- `shortcut` - Keyboard shortcut (e.g., "⌘S")
- `variant` - `default` | `danger`
- `disabled` - Disable item
- `checked` - Show checkmark

### 13.407 Tree

**Hierarchical navigation tree**

```blade
<x-gsmui:tree 
    :items="$navigationTree"
    wire:model="expandedItems"
    :selected="selectedItem"
    @select="selectItem"
/>
```

**Item Structure:**
```php
[
    'id' => 'projects',
    'label' => 'Projects',
    'icon' => 'folder',
    'href' => '/projects',
    'children' => [
        ['id' => 'project-1', 'label' => 'Project Alpha', 'href' => '/projects/1'],
        ['id' => 'project-2', 'label' => 'Project Beta', 'href' => '/projects/2'],
    ],
    'expanded' => true,
    'selected' => false,
    'disabled' => false,
]
```

**Props:**
- `items` - Tree items array
- `expanded` - Expanded item IDs (wire:model)
- `selected` - Selected item ID
- `multiple` - Allow multiple selection
- `showIcons` - Show folder/file icons
- `lazy` - Lazy load children

**Events:** `select` `{ id, item }`, `expand` `{ id, expanded }`

**Variants:**
| Variant | Style | Use Case |
|---------|-------|----------|
| `numbered` | Circle with number | Sequential steps |

**Props:**
- `current` - Current step (1-indexed)
- `items` - Steps array
- `variant` - `numbered` | `icon` | `simple`
- `clickable` - Allow clicking steps
- `orientation` - `horizontal` | `vertical`
- `size` - `sm` | `md` | `lg`

### 13.410 CommandPalette

**Keyboard-driven search & actions**

```blade
<x-gsmui:command-palette 
    :sections="[
        ['title' => 'Navigate', 'items' => $navItems],
        ['title' => 'Actions', 'items' => $actionItems],
        ['title' => 'Recent', 'items' => $recentItems],
    ]"
    placeholder="Search or run command..."
    shortcut="k"
/>
```

**Item Structure:**
```php
[
    'label' => 'New Project',
    'description' => 'Create a new project',
    'icon' => 'plus',
    'shortcut' => '⌘N',
    'action' => 'new-project',        // Event name
    'href' => '/projects/new',        // Or navigation
    'group' => 'actions',             // Section grouping
    'keywords' => ['create', 'add'],  // Search keywords

```

**Props:**
- `sections` - Grouped items
- `placeholder` - Input placeholder
- `shortcut` - Keyboard shortcut (default: `k`)
- `emptyMessage` - No results message

**Events:** `select` `{ action, item }`, `close`

## Accessibility

### ARIA Patterns

```blade
{{-- Navbar --}}
<nav role="navigation" aria-label="Main navigation">
    <ul role="menubar">
        <li role="none"><a role="menuitem" href="/">Home</a></li>
    </ul>
</nav>

{{-- Tabs --}}
<div role="tablist" aria-label="Product tabs">
    <button role="tab" aria-selected="true" aria-controls="panel-1" id="tab-1">Tab 1</button>
</div>
<div role="tabpanel" id="panel-1" aria-labelledby="tab-1">Content</div>

{{-- Menu --}}
<div role="menu" aria-label="Actions">
    <div role="menuitem" tabindex="-1">Edit</div>
</div>

{{-- Breadcrumb --}}
<nav aria-label="Breadcrumb">
    <ol>
        <li><a href="/">Home</a></li>
        <li aria-current="page">Current</li>
    </ol>
</nav>

{{-- Pagination --}}
<nav aria-label="Pagination">
    <a aria-label="Page 1" href="?page=1">1</a>
    <span aria-current="page">2</span>
</nav>
```

### Focus Management

- Sidebar drawer: Trap focus, restore on close
- Command Palette: Trap focus, restore trigger on close
- Dropdown menus: Focus first item on open
- Tabs: Arrow keys move focus, Enter/Space activates (manual)

### Screen Reader

- Live region for pagination changes
- Command Palette: Announce result count
- Steps: Announce current step
- Tree: Announce expanded/collapsed state

### Command Palette Navigation

```blade
{{-- Command palette for quick navigation --}}
<div
    x-data="{
        open: false,
        search: '',
        results: [],
        selectedIndex: 0,
        commands: @js($commands),
        init() {
            window.addEventListener('keydown', (e) => {
                if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
                    e.preventDefault();
                    this.open = !this.open;
                }
            });
        },
        searchCommands() {
            if (!this.search) {
                this.results = this.commands;
            } else {
                const query = this.search.toLowerCase();
                this.results = this.commands.filter(cmd =>
                    cmd.label.toLowerCase().includes(query) ||
                    cmd.description?.toLowerCase().includes(query) ||
                    cmd.keywords?.some(k => k.toLowerCase().includes(query))
                );
            }
            this.selectedIndex = 0;
        },
        executeCommand(command) {
            if (command.action) {
                command.action();
            } else if (command.url) {
                window.location.href = command.url;
            } else if (command.component) {
                this.$wire.runCommand(command.id);
            }
            this.open = false;
        },
        handleKeydown(e) {
            if (e.key === 'ArrowDown') {
                e.preventDefault();
                this.selectedIndex = Math.min(this.selectedIndex + 1, this.results.length - 1);
            } else if (e.key === 'ArrowUp') {
                e.preventDefault();
                this.selectedIndex = Math.max(this.selectedIndex - 1, 0);
            } else if (e.key === 'Enter') {
                e.preventDefault();
                this.executeCommand(this.results[this.selectedIndex]);
            }
        }
    }"
    x-on:keydown.escape.window="open = false"
>
    {{-- Trigger button --}}
    <x-gsmui:button
        variant="ghost"
        x-on:click="open = true"
        class="flex items-center gap-2"
    >
        <x-gsmui:icon name="magnifying-glass" class="w-4 h-4" />
        <span class="text-sm text-zinc-500">Search...</span>
        <kbd class="hidden sm:inline-flex items-center px-2 py-0.5 text-xs text-zinc-500 bg-zinc-100 dark:bg-zinc-800 rounded">
            <span class="mr-1">⌘</span>K
        </kbd>
    </x-gsmui:button>

    {{-- Command palette modal --}}

            <div class="flex items-center gap-3 py-3">
                <x-gsmui:icon name="magnifying-glass" class="w-5 h-5 text-zinc-400" />
                <input
                    type="text"
                    placeholder="Type a command or search..."
                    x-model="search"
                    x-on:input="searchCommands()"
                    x-on:keydown="handleKeydown($event)"
                    class="flex-1 bg-transparent border-none focus:outline-none text-sm"
                    x-ref="searchInput"
                />
            </div>
        </div>

        {{-- Results --}}
        <div class="max-h-80 overflow-auto p-2">
            @if($results->count())
                @foreach($results as $index => $command)
                    <button
                        class="flex items-center gap-3 w-full px-3 py-2 text-sm rounded-lg text-left transition-colors
                            {{ $index === $selectedIndex ? 'bg-zinc-100 dark:bg-zinc-800' : 'hover:bg-zinc-50 dark:hover:bg-zinc-700' }}"
```

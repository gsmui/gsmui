# 13.900 Charts — GsmUi Charts Category Specification

## Overview

The Charts category provides data visualization components built on a lightweight, accessible charting library. All charts are responsive, themeable, and support server-side rendering.

## Components

| Component | Status | Description |
|-----------|--------|-------------|
| [LineChart](./13.901-line-chart.md) | Stable | Time series and trends |
| [AreaChart](./13.902-area-chart.md) | Stable | Cumulative values |
| [BarChart](./13.903-bar-chart.md) | Stable | Categorical comparisons |
| [PieChart](./13.904-pie-chart.md) | Stable | Part-to-whole |
| [DonutChart](./13.905-donut-chart.md) | Stable | Part-to-whole with center |
| [RadarChart](./13.906-radar-chart.md) | Beta | Multi-dimensional |
| [HeatmapChart](./13.907-heatmap-chart.md) | Beta | Density/intensity |
| [TreemapChart](./13.908-treemap-chart.md) | Beta | Hierarchical proportions |
| [Sparkline](./13.909-sparkline.md) | Stable | Inline mini charts |
| [Gauge](./13.910-gauge.md) | Stable | Single metric progress |

## Architecture

### Library Choice

**Chart.js v4** (or uCharts/ApexCharts) with:
- Canvas rendering (performant)
- Tree-shakeable
- TypeScript support
- No external dependencies
- Responsive by default

### PHP Component

```php
class LineChart extends BaseChartComponent
{
    public array $data = [];
    public array $options = [];
    public string $type = 'line';
    
    public function render(): View
    {
        return view('gsmui::components.charts.line-chart', [
            'chartId' => $this->id,
            'data' => $this->data,
            'options' => $this->getMergedOptions(),
        ]);
    }
}
```

## Component Specifications

### 13.901 LineChart

**Time series and trends**

```blade
<x-gsmui:line-chart
    :data="[
        'labels' => ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
        'datasets' => [
            ['label' => 'Revenue', 'data' => [12, 19, 15, 25, 22, 30], 'fill' => false],
            ['label' => 'Expenses', 'data' => [8, 12, 10, 18, 15, 20], 'fill' => false],
        ],
    ]"
    title="Monthly Revenue vs Expenses"
    :options="[
        'scales' => [
            'y' => ['beginAtZero' => true, 'title' => ['display' => true, 'text' => 'USD (thousands)']],
        ],
        'interaction' => ['mode' => 'index', 'intersect' => false],
    ]"
/>
```

**Specific Options:**
- `tension` - Curve tension (0 = straight, 0.4 = smooth)
- `stepped` - Stepped line (before, after, middle)
- `spanGaps` - Connect across null data
- `showLine` - Show/hide line (points only)

### 13.903 BarChart

**Props:**

### 13.910 Gauge

**Single metric progress**

```blade
<x-gsmui:gauge
    :value="78"
    :min="0"
    :max="100"
    :thresholds="[
        ['max' => 50, 'color' => 'var(--gsmui-color-danger)'],
```

**Props:**
- `value` - Current value
- `min` / `max` - Range
- `thresholds` - Color thresholds
- `label` - Metric name
- `prefix` / `suffix` - Value affixes

- `type` - `semi` (180°) | `circle` (360°) | `arch` (custom)
- `startAngle` / `endAngle` - Custom arc
- `thickness` - Ring thickness
- `showValue` - Display numeric value
- `valueFormatter` - Format function

### Data Preparation

```php
class RevenueChart extends BaseChartComponent
{
    public function mount(): void
    {
        $this->data = $this->prepareData();
    }
    
    protected function prepareData(): array
    {
        $revenues = Order::selectRaw('DATE(created_at) as date, SUM(total) as revenue')
            ->where('created_at', '>=', now()->subDays(30))
            ->groupBy('date')
            ->orderBy('date')
            ->get()
            ->keyBy('date');
        
        $labels = [];
        $data = [];
        
        for ($i = 29; $i >= 0; $i--) {
            $date = now()->subDays($i)->format('Y-m-d');
            $labels[] = now()->subDays($i)->format('M j');
            $data[] = $revenues[$date]->revenue ?? 0;
        }
        
        return [
            'labels' => $labels,
            'datasets' => [[
                'label' => 'Revenue',
                'data' => $data,
                'borderColor' => 'var(--gsmui-color-primary)',
                'fill' => false,
            ]],
        ];
    }
}
```

## Charts Deep Dive

### Chart.js Integration Architecture

The GsmUi Charts category is built on top of Chart.js v4 with a custom abstraction layer that provides:

1. **Automatic theme integration** with GsmUi's design tokens
2. **Livewire reactive updates** for server-side data changes
3. **Accessibility compliance** (WCAG 2.1 AA)
4. **Responsive behavior** with breakpoint-aware sizing
5. **Animation control** respecting `prefers-reduced-motion`

### Chart Base Class

```php
<?php

namespace GsmUi\Components\Charts;

use GsmUi\Components\BaseComponent;
use Illuminate\Support\Facades\View;

abstract class BaseChartComponent extends BaseComponent
{
    public array $data = [];
    public array $options = [];
    public string $type = 'line';
    public bool $responsive = true;
    public bool $maintainAspectRatio = true;
    public string $theme = 'auto';
    public array $colors = [];
    public ?string $title = null;
    public ?string $subtitle = null;
    public bool $legend = true;
    public string $legendPosition = 'top';
    public bool $tooltip = true;
    public bool $animation = true;
    public int $animationDuration = 750;
    public string $animationEasing = 'easeOutQuart';
    public array $plugins = [];

    protected function getMergedOptions(): array
    {
        $defaults = $this->getDefaultOptions();
        $themeOptions = $this->getThemeOptions();
        $customOptions = $this->options;

        return array_merge_recursive(
            $defaults,
            $themeOptions,
            $customOptions
        );
    }

    protected function getDefaultOptions(): array
    {
        return [
            'responsive' => $this->responsive,
            'maintainAspectRatio' => $this->maintainAspectRatio,
            'animation' => $this->animation ? [
                'duration' => $this->animationDuration,
                'easing' => $this->animationEasing,
            ] : false,
            'plugins' => [
                'title' => [
                    'display' => $this->title !== null,
                    'text' => $this->title,
                    'subtitle' => [
                        'display' => $this->subtitle !== null,
                        'text' => $this->subtitle,
                    ],
                ],
                'legend' => [
                    'display' => $this->legend,
                    'position' => $this->legendPosition,
                ],
                'tooltip' => [
                    'enabled' => $this->tooltip,
                ],
            ],
        ];
    }

    protected function getThemeOptions(): array
    {
        $isDark = $this->isDarkMode();

        return [
            'plugins' => [
                'legend' => [
                    'labels' => [
                        'color' => $isDark ? '#e5e7eb' : '#374151',
                    ],
                ],
                'tooltip' => [
                    'backgroundColor' => $isDark ? '#1f2937' : '#ffffff',
```

```php
    public static function fromTimeSeries($collection, string $dateField, string $valueField, string $format = 'M j'): array
    {
        $grouped = $collection->groupBy(function ($item) use ($dateField, $format) {
            return \Carbon\Carbon::parse($item->{$dateField})->format($format);
        });

        return [
            'labels' => $grouped->keys()->toArray(),
            'datasets' => [
                [
                    'data' => $grouped->map(fn($items) => $items->sum($valueField))->toArray(),
                ],
            ],
        ];
    }

    public static function fromMultiSeries($collection, string $labelField, array $seriesFields): array
    {
        $datasets = [];
        foreach ($seriesFields as $field => $config) {
            $datasets[] = [
                'label' => $config['label'] ?? $field,
                'data' => $collection->pluck($field)->toArray(),
                'borderColor' => $config['color'] ?? null,
                'backgroundColor' => $config['bgColor'] ?? null,
            ];
        }

        return [
            'labels' => $collection->pluck($labelField)->toArray(),
            'datasets' => $datasets,
        ];
    }

    public static function pivotForChart($collection, string $categoryField, string $seriesField, string $valueField): array
    {
        $categories = $collection->pluck($categoryField)->unique()->sort()->values();
        $series = $collection->pluck($seriesField)->unique()->values();

        $datasets = [];
        foreach ($series as $s) {
            $data = $categories->map(function ($cat) use ($collection, $categoryField, $seriesField, $valueField, $s) {
                return $collection
                    ->where($categoryField, $cat)
                    ->where($seriesField, $s)
                    ->sum($valueField);
            })->toArray();

            $datasets[] = [
                'label' => $s,
                'data' => $data,
            ];
        }

        return [
            'labels' => $categories->toArray(),
            'datasets' => $datasets,
        ];
    }
```

```php
<?php

namespace GsmUi\Components\Charts;

class ChartAccessibility
{
    public static function generateAriaLabel(array $data, string $chartType): string
    {
        $summary = self::generateSummary($data);
        $trend = self::generateTrend($data);

        return "{$chartType} chart. {$summary}. {$trend}";
    }

    private static function generateSummary(array $data): string
    {
        $labels = $data['labels'] ?? [];
        $datasets = $data['datasets'] ?? [];

        if (empty($datasets)) {
            return 'No data available';
        }

        $firstDataset = $datasets[0];
        $values = $firstDataset['data'] ?? [];

        if (empty($values)) {
            return 'No data available';
        }

        $min = min($values);
        $max = max($values);
        $avg = round(array_sum($values) / count($values));

        $firstLabel = $labels[0] ?? 'Start';
        $lastLabel = end($labels) ?? 'End';

        return "Range from {$min} to {$max}, average {$avg}. Data from {$firstLabel} to {$lastLabel}";
    }

    private static function generateTrend(array $data): string
    {
        $datasets = $data['datasets'] ?? [];
        if (empty($datasets)) return '';

        $values = $datasets[0]['data'] ?? [];
        if (count($values) < 2) return '';

        $first = $values[0];
        $last = end($values);
        $percentChange = (($last - $first) / $first) * 100;

        if ($percentChange > 5) {
            return 'Overall trend: increasing';
        } elseif ($percentChange < -5) {
            return 'Overall trend: decreasing';
        } else {
            return 'Overall trend: stable';
        }
    }

    public static function generateDataTable(array $data): array
    {
        $labels = $data['labels'] ?? [];
        $datasets = $data['datasets'] ?? [];

        $headers = ['Label'];
        foreach ($datasets as $dataset) {
            $headers[] = $dataset['label'] ?? 'Series';
        }

        $rows = [];
        foreach ($labels as $index => $label) {
            $row = [$label];
            foreach ($datasets as $dataset) {
                $row[] = $dataset['data'][$index] ?? '';
            }
            $rows[] = $row;
        }

        return [
            'headers' => $headers,
            'rows' => $rows,
        ];
    }
}
```

### Chart Performance Optimization

```php
<?php

namespace GsmUi\Components\Charts;

class ChartOptimizer
{
    public static function downsample(array $data, int $maxPoints = 200): array
    {
        $labels = $data['labels'] ?? [];
        $datasets = $data['datasets'] ?? [];

        if (count($labels) <= $maxPoints) {
            return $data;
        }

        $factor = ceil(count($labels) / $maxPoints);

        $newLabels = [];
        $newDatasets = array_fill_keys(array_keys($datasets), []);

        foreach ($labels as $index => $label) {
            if ($index % $factor === 0) {
                $newLabels[] = $label;
                foreach ($datasets as $dsIndex => $dataset) {
                    $newDatasets[$dsIndex][] = $dataset['data'][$index] ?? 0;
                }
            }
        }

        $result = ['labels' => $newLabels, 'datasets' => []];
        foreach ($datasets as $dsIndex => $dataset) {
            $result['datasets'][] = array_merge($dataset, ['data' => $newDatasets[$dsIndex]]);
        }

        return $result;
    }

    public static function getDecimationOptions(int $dataPoints): array
    {
        if ($dataPoints <= 200) {
            return ['plugins' => ['decimation' => ['enabled' => false]]];
        }

        return [
            'plugins' => [
                'decimation' => [
                    'enabled' => true,
                    'algorithm' => 'lttb',
                    'samples' => 200,
                    'threshold' => 200,
                ],
            ],
        ];
    }

    public static function getPerformanceOptions(int $dataPoints): array
    {
        $options = [];

        if ($dataPoints > 100) {
            $options['animation'] = false;
        }

        if ($dataPoints > 500) {
            $options['elements'] = [
                'point' => ['radius' => 0],
                'line' => ['borderWidth' => 1],
            ];
        }

        if ($dataPoints > 1000) {
            $options['sampling'] = 'nearest';
            $options['parsing'] = false;
        }

        return $options;
    }
```

```php
namespace App\Charts\Virtual;

class VirtualScroller
{
    private int $maxVisiblePoints = 50;

    public function getSimplifiedData(array $data, int $viewportWidth): array
    {
        $totalPoints = count($data['labels']);

        if ($totalPoints <= $this->maxVisiblePoints) {
            return $data;
        }

        $step = ceil($totalPoints / $this->maxVisiblePoints);
        $simplified = [
            'labels' => [],
            'datasets' => [],
        ];

        for ($i = 0; $i < $totalPoints; $i += $step) {
            $simplified['labels'][] = $data['labels'][$i];
            foreach ($data['datasets'] as $datasetIndex => $dataset) {
                $simplified['datasets'][$datasetIndex][] = $dataset[$i];
            }
        }

        return $simplified;
    }

    public function getWindowedData(array $data, int $start, int $end): array
    {
        return [
            'labels' => array_slice($data['labels'], $start, $end - $start),
            'datasets' => array_map(
                fn($dataset) => array_slice($dataset, $start, $end - $start),
                $data['datasets']
            ),
        ];
    }
}
```

## Chart Best Practices

### Do's

- Use `tabular-nums` for numeric axes that update rapidly
- Always provide accessible data tables for screen readers
- Throttle high-frequency data updates to prevent jank
- Use virtual scrolling for datasets exceeding 500 points
- Test charts at multiple viewport sizes
- Provide meaningful aria-labels for chart containers
- Use semantic colors (red for errors, green for success)
- Cache chart data to reduce server load

### Don'ts

- Don't use animations that can't be disabled
- Don't rely solely on color to convey information
- Don't render charts in hidden containers
- Don't load all data at once for large datasets
- Don't skip the data table fallback for accessibility
- Don't use more than 7 datasets on a single chart
- Don't render charts with zero data points
- Don't ignore mobile responsiveness

| Error | `#ef4444` | `#f87171` | Negative values |
| Neutral | `#6b7280` | `#9ca3af` | Reference lines |

### Color Application Rules

1. **Maximum 8 colors per chart** — Beyond this, use grouping or patterns
2. **Sequential colors** — Use color gradients for ordered data
3. **Diverging colors** — Use two-color gradients for data around a midpoint
4. **Categorical colors** — Use distinct hues for unordered categories
5. **Accessibility** — Ensure sufficient contrast ratios (4.5:1 minimum)

# 13.600 Feedback — GsmUi Feedback Category Specification

## Overview

The Feedback category contains components that communicate system status, progress, and results to users. These components provide visibility into system state without blocking user workflow.

## Components

| Component | Status | Description |
|-----------|--------|-------------|
| [Alert](./13.601-alert.md) | Stable | Persistent inline messages |
| [Toast](./13.602-toast.md) | Stable | Transient notifications |
| [Progress](./13.603-progress.md) | Stable | Determinate/indeterminate progress |
| [Spinner](./13.604-spinner.md) | Stable | Loading indicator |
| [Skeleton](./13.605-skeleton.md) | Stable | Content placeholders |
| [EmptyState](./13.606-empty-state.md) | Stable | Empty content illustrations |
| [StatusBadge](./13.607-status-badge.md) | Stable | Inline status indicators |
| [Notification](./13.608-notification.md) | Beta | System notifications center |

## Design Principles

### Feedback Timing

| Type | Duration | Dismissible | Use Case |
|------|----------|-------------|----------|
| Alert | Persistent | Yes | Errors, warnings, info |
| Toast | 4-8s | Yes | Success, confirmations |
| Progress | Until complete | No | Uploads, processing |
| Spinner | Until complete | No | Quick loads |
| Skeleton | Until content loads | No | Initial loads |
| Empty State | Persistent | N/A | No data |

### Severity Levels

| Severity | Color | Icon | Use Case |
|----------|-------|------|----------|
| `success` | Green | Check circle | Completed, confirmed |
| `info` | Blue | Info circle | Neutral information |
| `warning` | Amber | Exclamation | Attention needed |
| `danger` | Red | X circle | Errors, destructive |

## Shared API

### Common Props

```php
#[Prop(options: ['success', 'info', 'warning', 'danger'])]
public string $variant = 'info';

#[Prop(options: ['default', 'outline', 'soft', 'solid'])]
public string $style = 'default';

#[Prop]
public bool $dismissible = true;

#[Prop]
public ?string $title = null;

#[Prop]
public ?string $description = null;

#[Prop]
public ?string $icon = null;  // Auto-selected by variant if null

#[Prop]
public ?string $actionLabel = null;

#[Prop]
public ?string $actionHref = null;

#[Prop]
public ?callable $actionHandler = null;
```

### Style Variants

| Style | Background | Border | Text | Use Case |
|-------|------------|--------|------|----------|
| `default` | Subtle tint | Yes | Dark | Default |
| `outline` | Transparent | Yes | Normal | Subtle |
| `soft` | Tinted | No | Dark | Emphasized |
| `solid` | Full color | No | White | High contrast |

## Component Specifications

### 13.601 Alert

**Persistent inline message**

```blade
<x-gsmui:alert 
    variant="success" 
    style="soft"
    title="Changes saved"
    description="Your profile has been updated successfully."
    dismissible
    wire:dismiss="dismissAlert"
>
    <x-slot name="action">
        <x-gsmui:button variant="ghost" size="sm" wire:click="undo">Undo</x-gsmui:button>
    </x-slot>
</x-gsmui:alert>

<x-gsmui:alert 
    variant="danger" 
    style="outline"
    title="Payment failed"
    description="Your credit card was declined. Please update your payment method."
    :action-label="'Update payment method'"
    :action-href="'/billing'"
/>
```

**Props:**
- `variant` - `success` | `info` | `warning` | `danger`
- `style` - `default` | `outline` | `soft` | `solid`
- `title` - Bold headline
- `description` - Detailed message
- `icon` - Custom icon (auto if null)
- `dismissible` - Show close button
- `actionLabel` / `actionHref` / `actionHandler` - Call to action

**Slots:** `icon`, `title`, `description`, `action`, `default` (full content)

### 13.602 Toast

**Transient notification**

```blade
{{-- Via component --}}
<x-gsmui:toast 
    :visible="$showToast"
    variant="success"
    title="Saved"
    description="Changes have been saved."
    wire:dismiss="hideToast"
    duration="5000"
/>

{{-- Via global service (recommended) --}}
<button wire:click="$toast.success('Saved!', 'Changes saved.')">
    Save
</button>
```

**Global Service Usage:**
```php
// In Livewire component
$this->dispatch('toast', [
    'type' => 'success',
    'title' => 'Saved',
    'message' => 'Changes saved successfully.',
    'duration' => 5000,
]);

// Or use helper
toast()->success('Saved!', 'Changes saved.')->push();
```

**Toast Container (layout):**
```blade
<!-- In main layout -->
<x-gsmui:toast-container position="top-right" :max="5" />
```

**Positions:** `top-right`, `top-left`, `bottom-right`, `bottom-left`, `top-center`, `bottom-center`

**Props:**
- `visible` - Show/hide (wire:model)
- `duration` - Auto-dismiss ms (default: 5000)
- `pauseOnHover` - Pause timer on hover (default: true)
- `closeButton` - Show close button (default: true)
- `progressBar` - Show progress bar (default: true)

**Events:** `dismiss` `{ toastId }`

**Props:**

- `max` - Maximum value (default: 100)

- `label` - Label text
- `showValue` - Show percentage/value
- `size` - `xs` | `sm` | `md` | `lg`
- `variant` - Color variant
- `striped` - Striped animation


### 13.608 Notification

**System notification center**

```blade
<x-gsmui:notification-center
    :notifications="$notifications"
    wire:model="notificationPanelOpen"
    position="top-right"
    :max-visible="10"
    empty-title="No notifications"
    empty-description="You're all caught up!"
/>
```

**Notification Structure:**
```php
[
    'id' => 'notif-123',
    'type' => 'info',           // success, info, warning, danger
    'title' => 'New message',
    'message' => 'You have a new message from John',
    'time' => '2 hours ago',    // Relative time
    'read' => false,
    'action' => [               // Optional
        'label' => 'View',
        'href' => '/messages/456',
    ],
    'avatar' => 'user-avatar',  // Optional
    'group' => 'messages',      // For grouping
]
```

**Props:**
- `notifications` - Notification array
- `maxVisible` - Max shown before "view all"
- `position` - `top-right` | `top-left` | `bottom-right`
- `groupBy` - Group by `type`, `date`, `group`
- `showUnreadBadge` - Show count on trigger
- `emptyTitle` / `emptyDescription`

**Events:** `mark-read` `{ id }`, `dismiss` `{ id }`, `action` `{ id, action }`

## Toast Service Integration

### PHP Service

```php
// app/Services/ToastService.php
class ToastService
{
    public function success(string $title, string $message = '', int $duration = 5000): void
    {
        $this->push('success', $title, $message, $duration);
    }
    
    public function error(string $title, string $message = '', int $duration = 8000): void
    {
        $this->push('danger', $title, $message, $duration);
    }
    
    public function warning(string $title, string $message = '', int $duration = 6000): void
    {
        $this->push('warning', $title, $message, $duration);
    }
    
    public function info(string $title, string $message = '', int $duration = 5000): void
    {
        $this->push('info', $title, $message, $duration);
    }
    
    protected function push(string $type, string $title, string $message, int $duration): void
    {
        Livewire::dispatch('toast', [
            'id' => 'toast-' . uniqid(),
            'type' => $type,
            'title' => $title,
            'message' => $message,
            'duration' => $duration,
        ]);
    }
}
```

### Blade Directive

```blade
@toastScripts
<!-- Include in layout before </body> -->
```

### JavaScript Listener

```javascript
// resources/js/toast-listener.js
document.addEventListener('livewire:load', () => {
    Livewire.on('toast', (data) => {
        window.GsmuiToast?.show(data);
    });
});
```

```blade
    <!-- Alert content -->
</div>

{{-- Progress --}}

</progress>

{{-- Spinner --}}

    <span class="sr-only">Loading...</span>
</div>
```

### Keyboard

| Component | Keys |
|-----------|------|
| Toast | `Escape` - dismiss, `Tab` - focus action |
| Alert | `Tab` - focus action, `Escape` - dismiss |
| Progress | N/A (read-only) |
| Notification Center | `Tab` - navigate, `Enter` - open, `Escape` - close |

### Screen Reader

- Toast: Announced immediately via `aria-live="polite"`
- Alert: Announced immediately via `role="alert"`
- Progress: `aria-valuenow` updated, announced on change
- Skeleton: `aria-hidden="true"` (decorative)

### Toast Notification Queue

```blade
{{-- Toast notification queue with persistence --}}
<div
    x-data="{
        toasts: [],
        maxToasts: 5,
        defaultDuration: 5000,
        addToast(toast) {
            const id = Date.now();
            this.toasts.push({
                id,
                ...toast,
                duration: toast.duration || this.defaultDuration
            });

            // Persist to localStorage
            this.persistToasts();

            // Auto-remove
            if (toast.duration !== 0) {
                setTimeout(() => this.removeToast(id), toast.duration);
            }

            // Limit visible toasts
            if (this.toasts.length > this.maxToasts) {
                this.toasts.shift();
            }
        },
        removeToast(id) {
            this.toasts = this.toasts.filter(t => t.id !== id);
            this.persistToasts();
        },
        persistToasts() {
            localStorage.setItem('toasts', JSON.stringify(this.toasts));
        },
        restoreToasts() {
            const saved = localStorage.getItem('toasts');
            if (saved) {
                this.toasts = JSON.parse(saved);
                this.toasts.forEach(toast => {
                    if (toast.duration !== 0) {
                        setTimeout(() => this.removeToast(toast.id), toast.duration);
                    }
                });
            }
        },
        init() {
            this.restoreToasts();
            window.addEventListener('toast', (e) => this.addToast(e.detail));
        }
    }"
    class="fixed bottom-4 right-4 z-50 space-y-2"
>
    <template x-for="toast in toasts" :key="toast.id">
        <div
            x-show="true"
            x-transition:enter="transition ease-out duration-300"
            x-transition:enter-start="opacity-0 translate-y-2"
            x-transition:enter-end="opacity-100 translate-y-0"
            x-transition:leave="transition ease-in duration-200"
            x-transition:leave-start="opacity-100 translate-y-0"
            x-transition:leave-end="opacity-0 translate-y-2"
            class="flex items-start gap-3 p-4 bg-white dark:bg-zinc-800 rounded-lg shadow-lg border max-w-sm"
        >
            <div class="shrink-0 mt-0.5"
                :class="{
                    'text-green-500': toast.type === 'success',
                    'text-red-500': toast.type === 'error',
                    'text-yellow-500': toast.type === 'warning',
                    'text-blue-500': toast.type === 'info'
                }"
            >
                <template x-if="toast.type === 'success'">
                    <x-gsmui:icon name="check-circle" class="w-5 h-5" />
                </template>
                <template x-if="toast.type === 'error'">

</div>
```

### Progress Indicator with Steps

```blade
{{-- Multi-step progress indicator --}}
<div
    x-data="{
        currentStep: {{ $currentStep }},
        steps: @js($steps),
        get progress() {
            return ((this.currentStep - 1) / (this.steps.length - 1)) * 100;
        },
        isCompleted(step) {
            return step < this.currentStep;
        },
        isCurrent(step) {
            return step === this.currentStep;
        },
        isUpcoming(step) {
            return step > this.currentStep;
        }
    }"
>
    {{-- Progress bar --}}
    <div class="mb-8">
        <div class="flex items-center justify-between mb-2">
            <span class="text-sm font-medium">Step <span x-text="currentStep"></span> of <span x-text="steps.length"></span></span>
            <span class="text-sm text-zinc-500"><span x-text="Math.round(progress)"></span>% complete</span>
        </div>
        <div class="h-2 bg-zinc-200 dark:bg-zinc-700 rounded-full overflow-hidden">
            <div
                class="h-full bg-primary transition-all duration-500 ease-out"
                :style="`width: ${progress}%`"
            ></div>
        </div>
    </div>

    {{-- Step indicators --}}
    <div class="flex items-center justify-between">
        @foreach($steps as $index => $step)
            <div class="flex flex-col items-center">
                {{-- Circle --}}
                <div
                    class="w-10 h-10 rounded-full flex items-center justify-center text-sm font-medium transition-colors"
                    :class="{
                        'bg-primary text-white': isCompleted({{ $index + 1 }}),
                        'bg-primary text-white ring-4 ring-primary/20': isCurrent({{ $index + 1 }}),
                        'bg-zinc-200 dark:bg-zinc-700 text-zinc-500': isUpcoming({{ $index + 1 }})
                    }"
                >
                    @if(isCompleted({{ $index + 1 }}))
                        <x-gsmui:icon name="check" class="w-5 h-5" />
                    @else
                        {{ $index + 1 }}
                    @endif
                </div>

                {{-- Label --}}
                <span
                    class="mt-2 text-xs text-center max-w-[80px]"
                    :class="{
                        'text-primary font-medium': isCurrent({{ $index + 1 }}),
                        'text-zinc-600': isCompleted({{ $index + 1 }}),
                        'text-zinc-400': isUpcoming({{ $index + 1 }})
                    }"
                >
                    {{ $step->label }}
                </span>
            </div>

            {{-- Connector line --}}
            @if(!$loop->last)
                <div class="flex-1 h-0.5 mx-2 -mt-6"
                    :class="isCompleted({{ $index + 1 }}) ? 'bg-primary' : 'bg-zinc-200 dark:bg-zinc-700'"
                ></div>
            @endif
        @endforeach
    </div>
</div>
```

### Inline Validation Feedback

```blade
{{-- Inline validation with real-time feedback --}}
<div
    x-data="{
        value: '',
        status: 'idle',
        message: '',
        debounceTimer: null,
        async validate() {
            this.status = 'validating';
            clearTimeout(this.debounceTimer);
            this.debounceTimer = setTimeout(async () => {
                try {
                    const result = await $wire.validateField(this.value);
                    this.status = result.valid ? 'valid' : 'invalid';
                    this.message = result.message || '';
                } catch (e) {
                    this.status = 'invalid';
                    this.message = 'Validation failed';
                }
            }, 300);
        }
    }"
>
    <div class="relative">
        <input
            type="text"
            x-model="value"
            x-on:input="validate()"
            class="w-full px-4 py-2 pr-10 border rounded-lg transition-colors"
            :class="{
                'border-zinc-200 dark:border-zinc-700': status === 'idle',
                'border-zinc-300 dark:border-zinc-600': status === 'validating',
                'border-green-500 ring-2 ring-green-500/20': status === 'valid',
                'border-red-500 ring-2 ring-red-500/20': status === 'invalid'
            }"
        />
        <div class="absolute right-3 top-1/2 -translate-y-1/2">
            @if($status === 'validating')
                <div class="w-5 h-5 border-2 border-zinc-300 border-t-primary rounded-full animate-spin"></div>
            @elseif($status === 'valid')
                <x-gsmui:icon name="check-circle" class="w-5 h-5 text-green-500" />
            @elseif($status === 'invalid')
                <x-gsmui:icon name="x-circle" class="w-5 h-5 text-red-500" />
            @endif
        </div>
    </div>
    @if($message)
        <p class="mt-1 text-sm" :class="$status === 'valid' ? 'text-green-600' : 'text-red-600'">
            {{ $message }}
        </p>
    @endif
</div>
```

### Loading Overlay

```blade
{{-- Full-page loading overlay --}}
<div
    x-data="{
        loading: @entangle('loading'),
        progress: 0,
        message: '',
        init() {
            this.$watch('loading', (val) => {
                if (val) {
                    this.progress = 0;
                    this.simulateProgress();
                }
            });
        },
        simulateProgress() {
            const interval = setInterval(() => {
                if (this.progress < 90) {

                    clearInterval(interval);

            }, 200);
        }
    }"
```

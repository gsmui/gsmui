# 13.22 Versioning — GsmUi Versioning Specification

## Overview

GsmUi follows **Semantic Versioning 2.0.0** (SemVer) with additional conventions for component libraries. This document defines versioning policies, release procedures, and compatibility guarantees.

## Version Format

```
MAJOR.MINOR.PATCH[-PRERELEASE][+BUILD]
```

### Examples

| Version | Type | Description |
|---------|------|-------------|
| `1.0.0` | Stable | Production ready |
| `0.9.0` | Pre-release | Breaking changes allowed |
| `1.1.0` | Minor | New features, backward compatible |
| `1.0.1` | Patch | Bug fixes only |
| `2.0.0-rc.1` | Release candidate | Pre-release of major |
| `1.5.0-beta.3` | Beta | Pre-release of minor |
| `1.0.0+build.123` | Build metadata | CI build number |

## Version Categories

### Major (X.0.0) — Breaking Changes

**Triggers:**
- Removing or renaming public props, slots, events
- Changing component HTML structure (breaking CSS selectors)
- Removing components
- Changing default behavior significantly
- Changing CSS custom property names
- Removing PHP public methods
- Changing Livewire event names/payloads
- Changing ARIA roles/patterns

**Migration Path Required:**
- Automated codemod where possible
- Migration guide in CHANGELOG
- Deprecation period in previous minor (when feasible)

```php
// BREAKING: Renamed prop
// v1.x
public string $variant = 'primary';

// v2.x
public string $style = 'primary'; // Renamed

// Migration: codemod transforms `variant` -> `style`
```

### Minor (X.Y.0) — New Features (Backward Compatible)

**Triggers:**
- Adding new components
- Adding new props (with defaults)
- Adding new slots
- Adding new events
- Adding new variants/sizes/colors
- Adding new CSS custom properties
- Adding new PHP public methods
- Adding new Blade components
- Performance improvements
- New translations

**Guarantees:**
- Existing code continues to work
- No migration needed
- Can upgrade safely

```php
// NON-BREAKING: New optional prop
#[Prop(default: false)]
public bool $loading = false; // Added in v1.2.0
```

### Patch (X.Y.Z) — Bug Fixes (Backward Compatible)

**Triggers:**
- Fixing incorrect behavior
- Fixing accessibility issues
- Fixing CSS bugs (visual only)
- Fixing PHP warnings/errors
- Security patches
- Documentation fixes
- Test improvements

**Guarantees:**
- Zero risk upgrade
- No API changes
- No behavior changes (except bug fixes)

```php
// PATCH: Fix focus ring color
// Before
outline-color: var(--gsmui-color-blue-500);

// After (correct semantic token)
outline-color: var(--gsmui-focus-ring-color);
```

### Pre-releases

| Suffix | Stability | Use Case |
|--------|-----------|----------|
| `-alpha.N` | Internal/early | Early development, unstable |
| `-beta.N` | Feature complete | Public testing, APIs stable |
| `-rc.N` | Release candidate | Final validation, no new features |
| `-dev` | Development | Nightly/edge builds |

## Semantic Versioning Edge Cases

### Pre-release Version Handling

Pre-release versions follow SemVer rules with additional GsmUi conventions:

```text
1.0.0-alpha.1    Internal testing, API unstable
1.0.0-alpha.2    Internal testing, API may change
1.0.0-beta.1     Public testing, API stable but may have bugs
1.0.0-beta.2     Public testing, minor fixes
1.0.0-rc.1       Release candidate, no new features
1.0.0-rc.2       Release candidate, final fixes
1.0.0            Stable release
```

### Pre-release Upgrade Path

```php
// Pre-release version comparison
$version = '1.0.0-beta.2';

if (version_compare($version, '1.0.0-rc.1', '<')) {
    // Still in beta, expect potential breaking changes
    $this->enableBetaWarnings();
}

if (version_compare($version, '1.0.0', '<')) {
    // Pre-release, not recommended for production
    $this->showPreReleaseWarning();
}
```

### Build Metadata

Build metadata is ignored for version precedence but useful for debugging:

```text
1.0.0+build.123     CI build number
1.0.0+sha.abc123    Git commit hash
1.0.0+20260715      Date-based build
```

```php
// Extract build metadata
$version = '1.0.0+build.123';
$parts = explode('+', $version);
$coreVersion = $parts[0]; // 1.0.0
$buildMeta = $parts[1] ?? null; // build.123
```

|-------|-----------|------------------|-----------------|
| `stable` | Full SemVer | Only in major | Production |

## Backward Compatibility Rules

### What Constitutes a Breaking Change

| Change Type | Major | Minor | Patch |
|-------------|-------|-------|-------|
| Remove public prop | Yes | No | No |
| Rename public prop | Yes | No | No |
| Change prop default | Depends | Yes | No |
| Add required prop | Yes | No | No |
| Remove slot | Yes | No | No |
| Rename slot | Yes | No | No |
| Change HTML structure | Yes | No | No |
| Change CSS class names | Yes | No | No |
| Change event names | Yes | No | No |
| Change event payloads | Yes | Depends | No |
| Add new prop | No | Yes | No |
| Add new slot | No | Yes | No |
| Add new variant | No | Yes | No |
| Fix CSS bug | No | No | Yes |
| Fix accessibility | No | No | Yes |
| Update documentation | No | No | Yes |

### Default Value Changes

Changing a prop's default value is a minor change if it doesn't break existing usage:

```php
// v1.x: Default is 'md'
#[Prop(default: 'md')]
public string $size = 'md';

// v1.y: Default changed to 'lg' (minor change)
// Existing code using size="md" still works
// Code relying on default size will see visual change
#[Prop(default: 'lg')]
public string $size = 'lg';
```

### HTML Structure Changes

Changes to component HTML structure are always major:

```html
<!-- v1.x -->
<div class="gsmui-button">
    <span class="gsmui-button-label">Click me</span>
</div>

<!-- v2.x: Structure changed -->
<button class="gsmui-button">
    <span class="gsmui-button-content">Click me</span>
</button>
```

Users who styled `gsmui-button-label` would break. This requires a major version bump.

## Version Constraint Strategies

### Conservative Strategy

Use conservative constraints for maximum stability:

```json
{
    "require": {
        "gsmui/gsmui": "~1.5.0",
        "gsmui/gsmui-pro": "~1.5.0"
    }
}
```

This only allows patch updates within 1.5.x.

### Moderate Strategy

Allow minor updates for new features:

```json
{
    "require": {
        "gsmui/gsmui": "^1.5",
        "gsmui/gsmui-pro": "^1.5"
    }
}
```

This allows 1.5.x through 1.x.x but not 2.0.0.

### Aggressive Strategy

Always get latest features:

```json
{
    "require": {
        "gsmui/gsmui": "*",
        "gsmui/gsmui-pro": "*"
    }
}
```

Not recommended for production but useful for development.

### Recommended Strategy

```json
{
    "require": {
        "gsmui/gsmui": "^1.5",
        "gsmui/gsmui-pro": "^1.5"
    },
    "config": {
        "sort-packages": true
    }
}
```

```yaml
      - uses: actions/checkout@v4

          name: dist

    needs: build

      - uses: actions/checkout@v4

          php-version: '8.3'

      - name: Publish to Packagist

    runs-on: ubuntu-latest

      - uses: actions/checkout@v4
      - uses: actions/download-artifact@v4

          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## Version Migration Tools

### Automated Migration Scanner

```php
<?php

namespace GsmUi\Migration;

class VersionMigrationScanner
{
    public function scan(string $projectPath, string $fromVersion, string $toVersion): array
    {
        $issues = [];
        $rules = $this->getMigrationRules($fromVersion, $toVersion);

        foreach ($rules as $rule) {
            $matches = $rule->scan($projectPath);
            foreach ($matches as $match) {
                $issues[] = [
                    'rule' => $rule->getName(),
                    'file' => $match['file'],
                    'line' => $match['line'],
                    'message' => $rule->getMessage(),
                    'fix' => $rule->getFix(),
                    'codemod' => $rule->getCodemod(),
                ];
            }
        }

        return $issues;
    }

    protected function getMigrationRules(string $from, string $to): array
    {
        $rules = [];

        if (version_compare($to, '2.0.0', '>=') && version_compare($from, '2.0.0', '<')) {
            $rules[] = new ButtonVariantRule();
            $rules[] = new SelectEventsRule();
            $rules[] = new LegacyCardRule();
            $rules[] = new CssPrefixRule();
        }

        return $rules;
    }
}
```

### Migration Report Generator

```php
class MigrationReportGenerator
{
    public function generate(string $projectPath, string $fromVersion, string $toVersion): string
    {
        $scanner = new VersionMigrationScanner();
        $issues = $scanner->scan($projectPath, $fromVersion, $toVersion);

        $report = "# Migration Report: v{$fromVersion} → v{$toVersion}\n\n";
        $report .= "## Summary\n\n";
        $report .= "- **Total issues found:** " . count($issues) . "\n";
        $report .= "- **Auto-fixable:** " . count(array_filter($issues, fn($i) => $i['codemod'])) . "\n";
        $report .= "- **Manual fixes required:** " . count(array_filter($issues, fn($i) => !$i['codemod'])) . "\n\n";

        $report .= "## Issues\n\n";
        foreach ($issues as $issue) {
            $report .= "### {$issue['rule']}\n\n";
            $report .= "- **File:** {$issue['file']}:{$issue['line']}\n";
            $report .= "- **Message:** {$issue['message']}\n";
            $report .= "- **Fix:** {$issue['fix']}\n";
            if ($issue['codemod']) {
                $report .= "- **Codemod:** `gsmui-codemod migrate --only={$issue['codemod']}`\n";
            }
            $report .= "\n";
        }

        return $report;
    }
}
```

## Version Security Practices

### Security Patch Policy

| Severity | Response Time | Patch Type | Notification |
|----------|---------------|------------|--------------|
| Critical | 24 hours | Emergency patch | Email + security advisory |
| High | 72 hours | Patch release | Email + changelog |
| Medium | 1 week | Minor release | Changelog |
| Low | Next release | Patch/minor | Changelog |

### Security Version Support

All supported versions receive security patches:

```php
class SecurityVersionChecker
{
    public function getSupportedVersions(): array
    {
        return [
            '1.x' => ['min' => '1.5.0', 'max' => '1.12.99'],
            '2.x' => ['min' => '2.0.0', 'max' => '2.99.99'],
        ];
    }

    public function isVersionSupported(string $version): bool
    {
        foreach ($this->getSupportedVersions() as $range) {
            if (version_compare($version, $range['min'], '>=') &&
                version_compare($version, $range['max'], '<=')) {
                return true;
            }
        }
        return false;
    }

    public function getLatestSecurityPatch(string $majorVersion): ?string
    {
        // Query for latest security patch in major version
        return Cache::remember("security_patch:{$majorVersion}", 3600, function () use ($majorVersion) {
            return DB::table('security_patches')
                ->where('major_version', $majorVersion)
                ->orderByDesc('patched_at')
                ->value('version');
        });
    }
}
```

### Version Health Monitoring

```php
<?php

namespace App\Services\VersionMonitoring;

use App\Models\VersionHealth;

class VersionHealthMonitor
{
    public function recordHealth(string $version, array $metrics): void
    {
        VersionHealth::create([
            'version' => $version,
            'error_rate' => $metrics['error_rate'],
            'response_time' => $metrics['response_time'],
            'memory_usage' => $metrics['memory_usage'],
            'cpu_usage' => $metrics['cpu_usage'],
            'active_users' => $metrics['active_users'],
            'recorded_at' => now(),
        ]);
    }

    public function getHealthTrend(string $version, int $days = 7): array
    {
        return VersionHealth::where('version', $version)
            ->where('recorded_at', '>=', now()->subDays($days))
            ->orderBy('recorded_at')
            ->get()
            ->toArray();
    }

    public function detectRegressions(string $version): array
    {
        $current = VersionHealth::where('version', $version)
            ->latest()
            ->first();

        $previous = VersionHealth::where('version', $version)
            ->where('recorded_at', '<', $current->recorded_at)
            ->latest()
            ->first();

        if (!$previous) return [];

        $regressions = [];

        if ($current->error_rate > $previous->error_rate * 1.5) {
            $regressions[] = [
                'metric' => 'error_rate',
                'current' => $current->error_rate,
                'previous' => $previous->error_rate,
                'severity' => 'high',
            ];
        }

        if ($current->response_time > $previous->response_time * 1.2) {
            $regressions[] = [
                'metric' => 'response_time',
                'current' => $current->response_time,
                'previous' => $previous->response_time,
                'severity' => 'medium',
            ];
        }

        return $regressions;
    }
}
```

### Automated Rollback

```php
<?php

namespace App\Services\VersionRollback;

class AutomatedRollback
{
    public function shouldRollback(string $version): bool
    {
        $health = app(VersionHealthMonitor::class);
        $regressions = $health->detectRegressions($version);

        $highSeverity = collect($regressions)->where('severity', 'high')->count();

        return $highSeverity >= 2;
    }

    public function rollback(string $fromVersion, string $toVersion): bool
    {
        // 1. Notify team
        Notification::route('slack', config('gsmui.alerts_channel'))
            ->notify(new RollbackInitiatedNotification($fromVersion, $toVersion));

        // 2. Run rollback migration
        Artisan::call('gsmui:rollback', ['--to-version' => $toVersion]);

        // 3. Clear caches
        Artisan::call('cache:clear');
        Artisan::call('config:clear');
        Artisan::call('view:clear');

        // 4. Verify rollback
        $currentVersion = GsmUi::version();
        if ($currentVersion !== $toVersion) {
            Log::critical('Rollback failed', [
                'expected' => $toVersion,
                'actual' => $currentVersion,
            ]);
            return false;
        }

        // 5. Notify completion
        Notification::route('slack', config('gsmui.alerts_channel'))
            ->notify(new RollbackCompletedNotification($fromVersion, $toVersion));

        return true;
    }
}
```

### Rollback Strategy

```php
<?php

namespace App\Deployment;

class RollbackManager
{
    public function rollback(string $version): void
    {
        // 1. Verify rollback target exists
        $this->verifyTarget($version);

        // 2. Run database migrations (down)
        $this->rollbackMigrations();

        // 3. Deploy previous version assets
        $this->deployAssets($version);

        // 4. Clear caches
        $this->clearCaches();

        // 5. Restart services
        $this->restartServices();

        // 6. Verify rollback
        $this->verifyRollback($version);
    }

    protected function verifyTarget(string $version): void
    {
        if (!$this->versionExists($version)) {
            throw new VersionNotFoundException("Version {$version} not found");
        }
    }

    protected function rollbackMigrations(): void
    {
        Artisan::call('migrate:rollback');
    }

    protected function deployAssets(string $version): void
    {
        $this->git->checkout("v{$version}");
        $this->npm->run('build');
    }

    protected function clearCaches(): void
    {
        Artisan::call('cache:clear');
        Artisan::call('config:clear');
        Artisan::call('view:clear');
    }

    protected function restartServices(): void
    {
        Artisan::call('queue:restart');
        // Trigger production deployment restart
    }

    protected function verifyRollback(string $version): void
    {
        $current = config('app.version');
        if ($current !== $version) {
            throw new RollbackFailedException("Rollback to {$version} failed");
        }
    }
}
```

### Rollback Decision Tree

```text

    │   ├─ Yes → Immediate rollback
    │   └─ No → Continue investigation
    │
    ├─ Is it a performance regression?
    │   ├─ Yes → Check if hotfix possible
    │   │   ├─ Yes → Deploy hotfix
    │   │   └─ No → Rollback
    │   └─ No → Continue investigation
    │
    ├─ Is it a security vulnerability?
    │   ├─ Critical → Immediate rollback + security patch
    │   ├─ High → Rollback within 24 hours
    │   └─ Medium/Low → Patch in next release
    │
    └─ Is it a UI regression?
        ├─ Yes → Check user impact
        │   ├─ High → Rollback or hotfix
        │   └─ Low → Fix in next release
        └─ No → Investigate root cause
```

### Usage Analytics

```php
<?php

namespace App\Analytics;

class VersionAnalytics
{
    public function trackVersionUsage(string $version, array $features): void
    {
        DB::table('version_usage')->insert([
            'version' => $version,
            'features_used' => json_encode($features),
            'user_id' => auth()->id(),
            'project_id' => request()->header('X-Project-ID'),
            'created_at' => now(),
        ]);
    }

    public function getAdoptionRate(string $version): float
    {
        $total = DB::table('version_usage')->count();
        $specific = DB::table('version_usage')
            ->where('version', $version)
            ->count();

        return $total > 0 ? ($specific / $total) * 100 : 0;
    }

    public function getPopularFeatures(string $version): array
    {
        return DB::table('version_usage')
            ->where('version', $version)
            ->selectRaw('JSON_UNQUOTE(features_used) as features')
            ->get()
            ->pluck('features')
            ->flatMap(fn($f) => json_decode($f, true))
            ->countBy()
            ->sortDesc()
```

### Version Comparison Dashboard

```php
<?php

namespace App\Http\Controllers;

class VersionDashboardController extends Controller
{
    public function index(): View
    {
        return view('admin.versions.dashboard', [
            'currentVersion' => config('app.version'),
            'latestRelease' => $this->getLatestRelease(),
            'adoptionRates' => $this->getAdoptionRates(),
            'breakingChanges' => $this->getBreakingChanges(),
            'deprecationWarnings' => $this->getDeprecationWarnings(),
            'performanceMetrics' => $this->getPerformanceMetrics(),
        ]);
    }

    protected function getLatestRelease(): array
    {
        return Cache::remember('latest_release', 3600, function () {
            return [
                'version' => config('app.version'),
                'released_at' => now()->subDays(7),
                'changelog_url' => '/changelog',
                'migration_guide_url' => '/docs/migration',
            ];
        });
    }

    protected function getAdoptionRates(): array
    {
        return [
            'v2.x' => ['users' => 1250, 'percentage' => 15],
            'v3.x' => ['users' => 5800, 'percentage' => 55],
            'v4.x' => ['users' => 3500, 'percentage' => 30],
        ];
    }
}
```

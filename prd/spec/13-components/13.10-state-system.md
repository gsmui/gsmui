# 13.10 State System — GsmUi State Specification

## Overview

The GsmUi state system provides a consistent way to manage and style component states. States are represented as `data-*` attributes on the root element, enabling CSS-based styling without class toggling.

## Standard States

### State Definitions

| State | Attribute | CSS Selector | Description |
|-------|-----------|--------------|-------------|
| Default | (none) | `.component` | Normal state |
| Hover | `data-hover="true"` | `[data-hover="true"]` | Mouse over |
| Active/Pressed | `data-active="true"` | `[data-active="true"]` | Mouse down / pressed |
| Focus | `data-focus="true"` | `[data-focus="true"]` | Any focus |
| Focus Visible | `data-focus-visible="true"` | `[data-focus-visible="true"]` | Keyboard focus (visible) |
| Disabled | `data-disabled="true"` | `[data-disabled="true"]` | Non-interactive |
| Readonly | `data-readonly="true"` | `[data-readonly="true"]` | Non-editable, submits |
| Loading | `data-loading="true"` | `[data-loading="true"]` | Async operation |
| Invalid | `data-invalid="true"` | `[data-invalid="true"]` | Validation error |
| Required | `data-required="true"` | `[data-required="true"]` | Required field |
| Filled | `data-filled="true"` | `[data-filled="true"]` | Has value |
| Empty | `data-empty="true"` | `[data-empty="true"]` | No value |
| Open | `data-open="true"` | `[data-open="true"]` | Popover/dropdown open |
| Selected | `data-selected="true"` | `[data-selected="true"]` | Item selected |
| Checked | `data-checked="true"` | `[data-checked="true"]` | Checkbox/radio checked |
| Indeterminate | `data-indeterminate="true"` | `[data-indeterminate="true"]` | Mixed state |
| Expanded | `data-expanded="true"` | `[data-expanded="true"]` | Accordion/tree expanded |
| Dragging | `data-dragging="true"` | `[data-dragging="true"]` | Drag in progress |
| Drop Target | `data-drop-target="true"` | `[data-drop-target="true"]` | Valid drop zone |

// State mixin for Alpine.js
const StateMixin = {
    // Reactive states
    hovered: false,
    focused: false,
    active: false,
    focusVisible: false,
    
    // Initialize state listeners
    initState() {
        this.$watch('hovered', v => this.setAttribute('data-hover', v));
        this.$watch('focused', v => this.setAttribute('data-focus', v));
        this.$watch('active', v => this.setAttribute('data-active', v));
        this.$watch('focusVisible', v => this.setAttribute('data-focus-visible', v));
    },
    
    // Event handlers
    handleMouseEnter() { this.hovered = true; },
    handleMouseLeave() { this.hovered = false; this.active = false; },
    handleMouseDown() { this.active = true; },
    handleMouseUp() { this.active = false; },
    handleFocus() { this.focused = true; },
    handleBlur() { this.focused = false; this.focusVisible = false; },
    handleKeyDown(e) { 
        if (['Tab', 'Enter', 'Space', 'ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight'].includes(e.key)) {
            this.focusVisible = true;
        }
    },
    handleKeyUp() { this.focusVisible = false; },
    handleMouseDown() { this.focusVisible = false; },
};

// Vanilla JS state controller
class StateController {
    constructor(element) {
        this.el = element;
        this.states = new Set();
        this.bindEvents();
    }
    
    bindEvents() {
        // Hover
        this.el.addEventListener('mouseenter', () => this.setState('hover', true));
        this.el.addEventListener('mouseleave', () => this.setState('hover', false));
        
        // Active
        this.el.addEventListener('mousedown', () => this.setState('active', true));
        this.el.addEventListener('mouseup', () => this.setState('active', false));
        this.el.addEventListener('mouseleave', () => this.setState('active', false));
        
        // Focus
        this.el.addEventListener('focus', () => this.setState('focus', true));
        this.el.addEventListener('blur', () => this.setState('focus', false));
        
        // Focus visible (keyboard)
        this.el.addEventListener('keydown', (e) => {
            if (['Tab', 'Enter', 'Space', 'ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight'].includes(e.key)) {
                this.setState('focus-visible', true);
            }
        });
        this.el.addEventListener('keyup', () => this.setState('focus-visible', false));
        this.el.addEventListener('mousedown', () => this.setState('focus-visible', false));
    }
    
    setState(name, value) {
        const attr = `data-${name}`;
        if (value) {
            this.states.add(name);
            this.el.setAttribute(attr, 'true');
        } else {
            this.states.delete(name);
            this.el.setAttribute(attr, 'false');
        }
    }
    
    getState(name) {
        return this.states.has(name);
    }
}
```

## State Priority

When multiple states apply, priority determines styling:

1. **Disabled** (highest) - overrides all
2. **Loading** - overrides interactive states
3. **Invalid** - error styling
4. **Focus Visible** - keyboard focus ring
5. **Active/Pressed** - mouse down
6. **Hover** - mouse over
7. **Filled/Empty** - content state
8. **Selected/Checked** - selection state
9. **Open/Expanded** - panel state
10. **Default** (lowest)

```css
/* Priority implementation via specificity */
.component[data-disabled="true"] { /* wins */ }
.component[data-loading="true"] { /* wins over hover/active */ }
.component[data-invalid="true"] { /* wins over focus */ }
.component[data-focus-visible="true"] { /* wins over active/hover */ }
.component[data-active="true"] { /* wins over hover */ }
.component[data-hover="true"] { /* wins over default */ }
.component[data-filled="true"] { /* wins over empty */ }
.component[data-selected="true"] { /* wins over unselected */ }
.component[data-open="true"] { /* wins over closed */ }
.component { /* default */ }
```

## Form Validation States

```php
trait HasValidationState
{
    #[Prop]
    public bool $invalid = false;
    
    #[Prop]
    public ?string $errorMessage = null;
    
    #[Prop]
    public ?array $errors = null;
    
    public function getInvalidAttribute(): bool
    {
        if ($this->invalid) return true;
        if ($this->errors) return !empty($this->errors);
        if ($this->wireModel) {
            return $this->getWireErrorBag()->has($this->wireModel);
        }
        return false;
    }
    
    public function getErrorMessageAttribute(): ?string
    {
        if ($this->errorMessage) return $this->errorMessage;
        if ($this->errors) return $this->errors[0] ?? null;
        if ($this->wireModel) {
            return $this->getWireErrorBag()->first($this->wireModel);
        }
        return null;
    }
}

## Advanced State Patterns

### State Machine Implementation

```php
<?php

namespace GsmUi\State;

class StateMachine
{
    protected array $states = [];
    protected array $transitions = [];
    protected string $currentState;
    protected array $listeners = [];
    
    public function addState(string $name, array $config = []): self
    {
        $this->states[$name] = $config;
        return $this;
    }
    
    public function addTransition(string $from, string $event, string $to): self
    {
        $this->transitions[$from][$event] = $to;
        return $this;
    }
    
    public function on(string $state, callable $listener): self
    {
        $this->listeners[$state][] = $listener;
        return $this;
    }
    
    public function transition(string $event): void
    {
        if (!isset($this->transitions[$this->currentState][$event])) {
            throw new \InvalidArgumentException(
                "Invalid transition: {$this->currentState} + {$event}"
            );
        }
        
        $previousState = $this->currentState;
        $this->currentState = $this->transitions[$this->currentState][$event];
        
        $this->notifyListeners($previousState, $this->currentState, $event);
    }
    
    public function getCurrentState(): string
    {
        return $this->currentState;
    }
    
    public function can(string $event): bool
    {
        return isset($this->transitions[$this->currentState][$event]);
    }
    
    protected function notifyListeners(string $from, string $to, string $event): void
    {
        foreach ($this->listeners[$to] ?? [] as $listener) {
            $listener($from, $to, $event);
        }
    }
}
```

{

    {

        $this->addState('idle')
            ->addState('hover')

            ->addState('focus-visible')

            ->addTransition('idle', 'tab', 'focus-visible')
            ->addTransition('idle', 'disable', 'disabled')
            ->addTransition('idle', 'load', 'loading')
            ->addTransition('idle', 'invalidate', 'invalid')
            
            ->addTransition('hover', 'mouseleave', 'idle')
            ->addTransition('hover', 'mousedown', 'active')
            ->addTransition('hover', 'focus', 'focus')
            ->addTransition('hover', 'tab', 'focus-visible')
            ->addTransition('hover', 'disable', 'disabled')
            
            ->addTransition('active', 'mouseup', 'hover')
            ->addTransition('active', 'mouseleave', 'idle')
            ->addTransition('active', 'disable', 'disabled')
            
            ->addTransition('focus', 'blur', 'idle')
            ->addTransition('focus', 'mouseenter', 'hover')
            ->addTransition('focus', 'key', 'focus-visible')
            ->addTransition('focus', 'disable', 'disabled')
            
            ->addTransition('focus-visible', 'blur', 'idle')
            ->addTransition('focus-visible', 'mouseenter', 'hover')
            ->addTransition('focus-visible', 'mousedown', 'active')
            ->addTransition('focus-visible', 'disable', 'disabled')
            
            ->addTransition('disabled', 'enable', 'idle')
            ->addTransition('loading', 'loaded', 'idle')
            ->addTransition('loading', 'error', 'invalid')
            ->addTransition('invalid', 'validate', 'idle');
        
        // State listeners
        $this->on('disabled', function ($from, $to) {
            $this->notify('disabled-change', ['disabled' => true]);
        });
        
        $this->on('loading', function ($from, $to) {
            $this->notify('loading-change', ['loading' => true]);
        });
        
        $this->on('idle', function ($from, $to) {
            if ($from === 'disabled') {
                $this->notify('disabled-change', ['disabled' => false]);
            }
            if ($from === 'loading') {
                $this->notify('loading-change', ['loading' => false]);
            }
        });
    }
}

## State Observation

### MutationObserver Integration

```javascript
class StateObserver {
    constructor(element) {
        this.element = element;
        this.observer = new MutationObserver((mutations) => {
            this.handleMutations(mutations);
        });
        
        this.observer.observe(this.element, {
            attributes: true,
            attributeFilter: [
                'data-hover', 'data-active', 'data-focus', 'data-focus-visible',
                'data-disabled', 'data-readonly', 'data-loading', 'data-invalid',
                'data-required', 'data-filled', 'data-empty', 'data-open',
                'data-selected', 'data-checked', 'data-indeterminate',
                'data-expanded', 'data-dragging', 'data-drop-target',
            ],
            attributeOldValue: true,
        });
        
        this.stateCallbacks = new Map();
    }
    
    handleMutations(mutations) {
        for (const mutation of mutations) {
            if (mutation.type === 'attributes') {
                const attributeName = mutation.attributeName;
                const oldValue = mutation.oldValue;
                const newValue = this.element.getAttribute(attributeName);
                
                if (oldValue !== newValue) {
                    this.notifyStateChange(attributeName, oldValue, newValue);
                }
            }
        }
    }
    
    notifyStateChange(attribute, oldValue, newValue) {
        const stateName = attribute.replace('data-', '');
        const callbacks = this.stateCallbacks.get(stateName) || [];
        
        for (const callback of callbacks) {
            callback({
                state: stateName,
                oldValue: oldValue === 'true',
                newValue: newValue === 'true',
                element: this.element,
            });
        }
    }
    
    onStateChange(stateName, callback) {
        if (!this.stateCallbacks.has(stateName)) {
            this.stateCallbacks.set(stateName, []);
        }
        this.stateCallbacks.get(stateName).push(callback);
    }
    
    destroy() {
        this.observer.disconnect();
        this.stateCallbacks.clear();
    }
}
```

### State Change Events

```javascript
class StateEventEmitter {
    constructor(element) {
        this.element = element;
        this.setupEventListeners();
    }
    
    setupEventListeners() {
        // Hover
        this.element.addEventListener('mouseenter', () => {
            this.setState('hover', true);
            this.emit('state-change', { state: 'hover', value: true });
        });
        
        this.element.addEventListener('mouseleave', () => {
            this.setState('hover', false);
            this.setState('active', false);
            this.emit('state-change', { state: 'hover', value: false });
        });
        
        // Active
        this.element.addEventListener('mousedown', () => {
            this.setState('active', true);
            this.emit('state-change', { state: 'active', value: true });
        });
        
        this.element.addEventListener('mouseup', () => {
            this.setState('active', false);
            this.emit('state-change', { state: 'active', value: false });
        });
        
        // Focus
        this.element.addEventListener('focus', () => {
            this.setState('focus', true);
            this.emit('state-change', { state: 'focus', value: true });
        });
        
        this.element.addEventListener('blur', () => {
            this.setState('focus', false);
            this.setState('focus-visible', false);
            this.emit('state-change', { state: 'focus', value: false });
        });
        
        // Focus visible (keyboard)
        this.element.addEventListener('keydown', (e) => {
            if (this.isNavigationKey(e.key)) {
                this.setState('focus-visible', true);
                this.emit('state-change', { state: 'focus-visible', value: true });
            }
        });
        
        this.element.addEventListener('keyup', () => {
            this.setState('focus-visible', false);
            this.emit('state-change', { state: 'focus-visible', value: false });
        });
        
        this.element.addEventListener('mousedown', () => {
            this.setState('focus-visible', false);
        });
    }
    
    isNavigationKey(key) {
        return ['Tab', 'Enter', 'Space', 'ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight'].includes(key);
    }
    
    setState(name, value) {
        const attr = `data-${name}`;
        this.element.setAttribute(attr, value ? 'true' : 'false');
    }
    
    getState(name) {
        return this.element.getAttribute(`data-${name}`) === 'true';
    }
    
    emit(eventName, detail) {
        this.element.dispatchEvent(new CustomEvent(eventName, {
            detail: { ...detail, timestamp: Date.now() },
            bubbles: true,
            composed: true,
        }));
    }
}

## State Persistence

### localStorage Integration

```php
trait PersistsState
{
    public function getPersistableState(): array
    {
        return [
            'value' => $this->value ?? null,
            'open' => $this->open ?? false,
            'selected' => $this->selected ?? null,
            'expanded' => $this->expanded ?? false,
        ];
    }
    
    public function persistState(): void
    {
        $state = $this->getPersistableState();
        $this->dispatch('gsmui:persist', [
            'component' => $this->componentName(),
            'id' => $this->getId(),
            'state' => $state,
        ]);
    }
    
    public function restoreState(array $state): void
    {
        foreach ($state as $key => $value) {
            if (property_exists($this, $key)) {
                $this->$key = $value;
            }
        }
    }
}

    setupLivewireHooks() {
        if (typeof Livewire === 'undefined') return;
        
        Livewire.hook('message.sent', (message) => {
            if (message.update?.includes('gsmui:persist')) {
                this.save(message.component.id, message.data);
            }
        });
        
        Livewire.hook('morph.updated', ({ el }) => {
            const persistKey = el.getAttribute('data-gsmui-persist');
            if (persistKey) {
                this.restore(persistKey);
            }
        });
    }
    
    save(componentId, state) {
        const key = `${this.namespace}:${componentId}`;
        try {
            localStorage.setItem(key, JSON.stringify({
                state,
                timestamp: Date.now(),
            }));
        } catch (e) {
            console.warn('Failed to persist state:', e);
        }
    }
    
    restore(componentId) {
        const key = `${this.namespace}:${componentId}`;
        try {
            const data = localStorage.getItem(key);
            if (data) {
                const parsed = JSON.parse(data);
                // Check if state is not too old (24 hours)
                if (Date.now() - parsed.timestamp < 86400000) {
                    return parsed.state;
                }
                localStorage.removeItem(key);
            }
        } catch (e) {
            console.warn('Failed to restore state:', e);
        }
        return null;
    }
    
    clear(componentId) {
        const key = `${this.namespace}:${componentId}`;
        localStorage.removeItem(key);
    }
    
    clearAll() {
        Object.keys(localStorage)
            .filter(key => key.startsWith(`${this.namespace}:`))
            .forEach(key => localStorage.removeItem(key));
    }
}

class StateSync {
    constructor() {
        this.channel = new BroadcastChannel('gsmui-state');
        this.setupListeners();
    }
    
    setupListeners() {
        this.channel.onmessage = (event) => {
            const { component, state, value } = event.data;
            this.applyState(component, state, value);
        };
        
        window.addEventListener('storage', (event) => {
            if (event.key?.startsWith('gsmui:sync:')) {
                const data = JSON.parse(event.newValue);
                this.applyState(data.component, data.state, data.value);
            }
        });
    }
    
    broadcast(component, state, value) {
        this.channel.postMessage({ component, state, value });
        
        // Also persist for cross-tab sync
        localStorage.setItem(`gsmui:sync:${component}:${state}`, JSON.stringify({
            component,
            state,
            value,
            timestamp: Date.now(),
        }));
    }
    
    applyState(component, state, value) {
        const elements = document.querySelectorAll(`[data-gsmui-component="${component}"]`);
        elements.forEach(el => {
            el.setAttribute(`data-${state}`, value ? 'true' : 'false');
        });
    }

## State System Best Practices

### State Management Guidelines

#### Do's and Don'ts

#### Do

1. **Use data attributes for states** — Store state in `data-*` attributes for CSS access
2. **Keep states atomic** — Each state should represent a single boolean flag
3. **Use consistent naming** — Follow the established state naming convention
4. **Document state transitions** — Define valid state transitions
5. **Test state combinations** — Verify states work together correctly

#### Don't

1. **Don't use classes for states** — Use `data-*` attributes instead of `.is-active` classes
2. **Don't create circular dependencies** — States should not trigger each other
3. **Don't skip disabled checks** — Always check disabled state before interactions
4. **Don't forget reduced motion** — Respect `prefers-reduced-motion`
5. **Don't ignore accessibility** — States should be announced to screen readers

### PHP State Manager

```php
<?php

namespace GsmUi\State;

class StateManager
{
    protected array $states = [];
    protected array $listeners = [];
    protected array $history = [];
    protected int $maxHistory = 100;
    
    public function define(string $name, array $config = []): void
    {
        $this->states[$name] = array_merge([
            'default' => false,
            'transitions' => [],
            'guards' => [],
            'actions' => [],
        ], $config);
    }
    
    public function set(string $name, $value = true): void
    {
        if (!isset($this->states[$name])) {
            throw new \InvalidArgumentException("Unknown state: {$name}");
        }
        
        $oldValue = $this->states[$name]['value'] ?? $this->states[$name]['default'];
        
        if ($oldValue === $value) {
            return;
        }
        
        // Check guards
        if (!$this->passesGuards($name, $value, $oldValue)) {
            return;
        }
        
        // Record history
        $this->recordHistory($name, $oldValue, $value);
        
        // Set value
        $this->states[$name]['value'] = $value;
        
        // Execute actions
        $this->executeActions($name, $value, $oldValue);
        
        // Notify listeners
        $this->notifyListeners($name, $value, $oldValue);
    }
    
    public function get(string $name): mixed
    {
        if (!isset($this->states[$name])) {
            return null;
        }
        
        return $this->states[$name]['value'] ?? $this->states[$name]['default'];
    }
    
    public function toggle(string $name): void
    {
        $this->set($name, !$this->get($name));
    }
    
    public function on(string $name, callable $listener): void
    {
        $this->listeners[$name][] = $listener;
    }
    
    public function off(string $name, callable $listener): void
    {
        $this->listeners[$name] = array_filter(
            $this->listeners[$name],
            fn($l) => $l !== $listener
        );
    }
    
    protected function passesGuards(string $name, $newValue, $oldValue): bool
    {
        $guards = $this->states[$name]['guards'] ?? [];
        
        foreach ($guards as $guard) {
            if (!$guard($newValue, $oldValue)) {
                return false;
            }
        }
        
        return true;
    }
    
    protected function executeActions(string $name, $newValue, $oldValue): void
    {
        $actions = $this->states[$name]['actions'] ?? [];
        
        foreach ($actions as $action) {
            $action($newValue, $oldValue);
        }
    }
    
    protected function notifyListeners(string $name, $newValue, $oldValue): void
    {
        $listeners = $this->listeners[$name] ?? [];
        
        foreach ($listeners as $listener) {
            $listener($newValue, $oldValue);
        }
    }
    
    protected function recordHistory(string $name, $oldValue, $newValue): void
    {
        $this->history[] = [
            'state' => $name,
            'old' => $oldValue,
            'new' => $newValue,
            'timestamp' => microtime(true),
        ];
        
        if (count($this->history) > $this->maxHistory) {
            array_shift($this->history);
        }
    }
    
    public function getHistory(string $name = null): array
    {
        if ($name) {
            return array_filter($this->history, fn($h) => $h['state'] === $name);
        }
        
        return $this->history;
    }
    
    public function canTransition(string $name, $toValue): bool
    {
        $currentValue = $this->get($name);
        return $this->passesGuards($name, $toValue, $currentValue);
    }
    
    public function reset(): void
    {
        foreach ($this->states as $name => &$state) {
            $state['value'] = $state['default'];
        }
        
        $this->history = [];
    }
    
    public function getAll(): array
    {
        $result = [];
        
        foreach ($this->states as $name => $state) {
            $result[$name] = $state['value'] ?? $state['default'];
        }
        
        return $result;
    }
}
```

### JavaScript State Controller

```javascript
class StateController {
    constructor(element) {
        this.element = element;
        this.states = new Map();
        this.listeners = new Map();
        this.history = [];
        this.maxHistory = 100;
        
        this.setupMutationObserver();
    }
    
    setupMutationObserver() {
        this.observer = new MutationObserver((mutations) => {
            for (const mutation of mutations) {
                if (mutation.type === 'attributes' && mutation.attributeName.startsWith('data-')) {
                    const stateName = mutation.attributeName.replace('data-', '');
                    const newValue = mutation.oldValue !== this.element.getAttribute(mutation.attributeName);
                    
                    this.handleStateChange(stateName, newValue);
                }
            }
        });
        
        this.observer.observe(this.element, {
            attributes: true,
            attributeFilter: Array.from(this.states.keys()).map(s => `data-${s}`),
            attributeOldValue: true,
        });
    }
    
    define(name, options = {}) {
        this.states.set(name, {
            default: options.default || false,
            value: options.default || false,
            guards: options.guards || [],
            actions: options.actions || [],
        });
        
        // Set initial attribute
        this.element.setAttribute(`data-${name}`, this.get(name) ? 'true' : 'false');
    }
    
    set(name, value) {
        const state = this.states.get(name);
        
        if (!state) {
            throw new Error(`Unknown state: ${name}`);
        }
        
        const oldValue = state.value;
        
        if (oldValue === value) {
            return;
        }
        
        // Check guards
        if (!this.passesGuards(name, value, oldValue)) {
            return;
        }
        
        // Record history
        this.recordHistory(name, oldValue, value);
        
        // Set value
        state.value = value;
        
        // Update attribute
        this.element.setAttribute(`data-${name}`, value ? 'true' : 'false');
        
        // Execute actions
        this.executeActions(name, value, oldValue);
        
        // Notify listeners
        this.notifyListeners(name, value, oldValue);
    }
    
    get(name) {
        const state = this.states.get(name);
        return state ? state.value : null;
    }
    
    toggle(name) {
        this.set(name, !this.get(name));
    }
    
    on(name, listener) {
        if (!this.listeners.has(name)) {
            this.listeners.set(name, []);
        }
        this.listeners.get(name).push(listener);
    }
    
    off(name, listener) {
        const listeners = this.listeners.get(name) || [];
        this.listeners.set(name, listeners.filter(l => l !== listener));
    }
    
    passesGuards(name, newValue, oldValue) {
        const state = this.states.get(name);
        const guards = state?.guards || [];
        
        return guards.every(guard => guard(newValue, oldValue));
    }
    
    executeActions(name, newValue, oldValue) {
        const state = this.states.get(name);
        const actions = state?.actions || [];
        
        actions.forEach(action => action(newValue, oldValue));
    }
    
    notifyListeners(name, newValue, oldValue) {
        const listeners = this.listeners.get(name) || [];
        listeners.forEach(listener => listener(newValue, oldValue));
    }
    
    recordHistory(name, oldValue, newValue) {
        this.history.push({
            state: name,
            old: oldValue,
            new: newValue,
            timestamp: Date.now(),
        });
        
        if (this.history.length > this.maxHistory) {
            this.history.shift();
        }
    }
    
    getHistory(name) {
        if (name) {
            return this.history.filter(h => h.state === name);
        }
        return this.history;
    }
    
    canTransition(name, toValue) {
        const currentValue = this.get(name);
        return this.passesGuards(name, toValue, currentValue);
    }
    
    destroy() {
        this.observer?.disconnect();
        this.states.clear();
        this.listeners.clear();
        this.history = [];
    }
}

### State Testing Utilities

```javascript
class StateTestHelper {
    constructor(controller) {
        this.controller = controller;
        this.expectedTransitions = [];
        this.actualTransitions = [];
        
        this.setupTracking();
    }
    
    setupTracking() {
        const originalSet = this.controller.set.bind(this.controller);
        
        this.controller.set = (name, value) => {
            const oldValue = this.controller.get(name);
            this.actualTransitions.push({ name, oldValue, newValue: value });
            originalSet(name, value);
        };
    }
    
    expectTransition(name, from, to) {
        this.expectedTransitions.push({ name, from, to });
    }
    
    verify() {
        const results = [];
        
        for (const expected of this.expectedTransitions) {
            const actual = this.actualTransitions.find(
                t => t.name === expected.name &&
                     t.oldValue === expected.from &&
                     t.newValue === expected.to
            );
            
            results.push({
                expected,
                passed: !!actual,
                actual,
            });
        }
        
        return results;
    }
    
    reset() {
        this.expectedTransitions = [];
        this.actualTransitions = [];
    }
}

### Common State Patterns

#### Toggle Button

```blade
<button
    type="button"
    data-checked="{{ $checked ? 'true' : 'false' }}"
    aria-pressed="{{ $checked ? 'true' : 'false' }}"
    wire:click="toggle"
    class="gsmui-button {{ $checked ? 'bg-blue-600 text-white' : 'bg-zinc-100 text-zinc-900' }}"

    {{ $label }}
</button>
```

#### Expandable Section

```blade
<div data-expanded="{{ $expanded ? 'true' : 'false' }}">
    <button
        type="button"
        aria-expanded="{{ $expanded ? 'true' : 'false' }}"
        aria-controls="content-{{ $id }}"
        wire:click="toggle"
    >
        {{ $title }}
        <svg class="w-5 h-5 transition-transform {{ $expanded ? 'rotate-180' : '' }}">
            <path d="M5 15l7-7 7 7" />
        </svg>
    </button>
    
    <div
        id="content-{{ $id }}"
        role="region"
        class="overflow-hidden transition-all {{ $expanded ? 'max-h-screen opacity-100' : 'max-h-0 opacity-0' }}"
    >
        {{ $slot }}
    </div>
</div>
```

#### Multi-State Component

```blade
<div
    data-hover="{{ $hovered ? 'true' : 'false' }}"
    data-active="{{ $active ? 'true' : 'false' }}"
    data-focus="{{ $focused ? 'true' : 'false' }}"
    data-disabled="{{ $disabled ? 'true' : 'false' }}"
    data-loading="{{ $loading ? 'true' : 'false' }}"
    class="gsmui-component"
    @mouseenter="$set('hovered', true)"
    @mouseleave="$set('hovered', false); $set('active', false)"
    @mousedown="$set('active', true)"
    @mouseup="$set('active', false)"
    @focus="$set('focused', true)"
    @blur="$set('focused', false)"
>
    @if($loading)
        <span class="sr-only">Loading...</span>
        <svg class="animate-spin" aria-hidden="true">...</svg>
    @else
        {{ $slot }}
    @endif
</div>
```

### State Documentation Template

```markdown
## [Component Name] States

### Available States

| State | Attribute | Description |
|-------|-----------|-------------|
| Hover | `data-hover` | Mouse is over the component |
| Active | `data-active` | Mouse button is pressed |
| Focus | `data-focus` | Component has focus |
| Focus Visible | `data-focus-visible` | Component has keyboard focus |
| Disabled | `data-disabled` | Component is non-interactive |
| Loading | `data-loading` | Async operation in progress |
| Invalid | `data-invalid` | Validation error |

### State Styling

```css
.gsmui-component[data-hover="true"] {
    background-color: var(--hover-bg);
}

.gsmui-component[data-active="true"] {
    transform: scale(0.98);
}

.gsmui-component[data-disabled="true"] {
    opacity: 0.5;
    pointer-events: none;
}
```

### State Accessibility

- Disabled: Use `aria-disabled="true"` and `disabled` attribute
- Loading: Use `aria-busy="true"` and announce to screen readers
- Invalid: Use `aria-invalid="true"` and `aria-describedby` for error message
```

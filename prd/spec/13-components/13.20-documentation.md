# 13.20 Documentation — GsmUi Documentation Specification

## Overview

GsmUi documentation follows a **docs-as-code** approach with auto-generated reference docs from component metadata, supplemented by hand-crafted guides, examples, and API references. Documentation is built with the GsmUi Docs Engine and deployed as a static site.

### Labels

| Use | Don't Use |
|-----|-----------|
| `label="hex"` (format demo) | `label="Clearable"` (echoes section title) |
| `label="Email"` (meaningful) | `label="Brand"` (random filler) |
| No label (when obvious) | Label on every example |

### Previews vs Code Blocks

- **Previews**: Dressed up with `value="#0ea5e9"` for visual context
- **Code blocks**: Clean copy-paste targets with `wire:model="color"`
- They don't need to match

## Documentation Content Guidelines

### Writing Style

Follow these conventions when writing documentation:

1. **Use active voice** — "Click the button" not "The button should be clicked"
2. **Be direct** — "Use `wire:model`" not "You might want to use `wire:model`"
3. **Show, don't tell** — Provide code examples before explanations
4. **One concept per section** — Keep sections focused and scannable
5. **Use consistent terminology** — Always say "prop" not "property", "slot" not "content area"

### Code Examples

Every code example must:

- Be syntactically valid
- Include all necessary imports
- Work as a standalone example
- Be copy-pasteable without modification

```blade
{{-- GOOD: Complete, working example --}}
<x-gsmui:input 
    wire:model="email"
    type="email"
    label="Email address"
    placeholder="you@example.com"
    :required="true"
    :invalid="$errors->has('email')"
    :error-message="$errors->first('email')"
/>

{{-- BAD: Missing context, won't work standalone --}}
<x-gsmui:input wire:model="email" />
```

### Naming Conventions

| Element | Convention | Example |
|---------|------------|---------|
| Components | PascalCase | `Button`, `DatePicker` |
| Props | camelCase | `iconPosition`, `isDisabled` |
| Events | kebab-case | `value-change`, `open-change` |
| CSS classes | kebab-case | `gsmui-button`, `gsmui-input` |
| Blade components | kebab-case with prefix | `x-gsmui:button`, `x-gsmui:input` |

## Versioned Documentation

### Version Manager

```php
<?php

namespace GsmUi\Docs;

class VersionManager
{
    protected string $currentVersion;
    protected array $versions = [];
    protected string $docsPath;
    
    public function __construct(string $docsPath)
    {
        $this->docsPath = $docsPath;
        $this->loadVersions();
    }
    
    protected function loadVersions(): void
    {
        $versionsFile = "{$this->docsPath}/versions.json";
        
        if (file_exists($versionsFile)) {
            $this->versions = json_decode(file_get_contents($versionsFile), true);
        }
        
        $this->currentVersion = $this->versions['current'] ?? 'latest';
    }
    
    public function getVersions(): array
    {
        return $this->versions['available'] ?? ['latest'];
    }
    
    public function getCurrentVersion(): string
    {
        return $this->currentVersion;
    }
    
    public function setCurrentVersion(string $version): void
    {
        $this->currentVersion = $version;
    }
    
    public function getVersionPath(string $version = null): string
    {
        $version = $version ?? $this->currentVersion;
        
        if ($version === 'latest') {
            return $this->docsPath;
        }
        
        return "{$this->docsPath}/versions/{$version}";
    }
    
    public function getVersionsForDropdown(): array
    {
        $versions = $this->getVersions();
        $current = $this->getCurrentVersion();
        
        return array_map(function ($version) use ($current) {
            return [
                'version' => $version,
                'label' => $version === 'latest' ? 'Latest (v1.x)' : "v{$version}",
                'current' => $version === $current,
                'url' => $version === 'latest' ? '/' : "/v{$version}/",
            ];
        }, $versions);
    }
    
    public function deprecateVersion(string $version): void
    {
        if (isset($this->versions['deprecated'])) {
            $this->versions['deprecated'][] = $version;
        } else {
            $this->versions['deprecated'] = [$version];
        }
        
        $this->saveVersions();
    }
    
    protected function saveVersions(): void
    {
        $versionsFile = "{$this->docsPath}/versions.json";
        file_put_contents($versionsFile, json_encode($this->versions, JSON_PRETTY_PRINT));
    }
}
```

### Changelog Generation

```php
<?php

namespace GsmUi\Docs;

class ChangelogGenerator
{
    protected string $gitPath;
    
    public function __construct(string $gitPath = null)
    {
        $this->gitPath = $gitPath ?? base_path();
    }
    
    public function generate(string $fromTag, string $toTag = 'HEAD'): array
    {
        $commits = $this->getCommits($fromTag, $toTag);
        
        $changelog = [
            'features' => [],
            'fixes' => [],
            'breaking' => [],
            'other' => [],
        ];
        
        foreach ($commits as $commit) {
            $parsed = $this->parseCommit($commit);
            
            match ($parsed['type']) {
                'feat' => $changelog['features'][] = $parsed,
                'fix' => $changelog['fixes'][] = $parsed,
                'breaking' => $changelog['breaking'][] = $parsed,
                default => $changelog['other'][] = $parsed,
            };
        }
        
        return $changelog;
    }
    
    protected function getCommits(string $from, string $to): array
    {
        $command = sprintf(
            'git log %s..%s --pretty=format:"%%H|%%s|%%an|%%ai" %s',
            escapeshellarg($from),
            escapeshellarg($to),
            $this->gitPath
        );
        
        $output = shell_exec($command);
        
        return array_filter(explode("\n", $output));
    }
    
    protected function parseCommit(string $commit): array
    {
        [$hash, $message, $author, $date] = explode('|', $commit);
        
        preg_match('/^(\w+)(?:\((.+)\))?\s*[!]?:\s*(.+)$/', $message, $matches);
        
        return [
            'hash' => substr($hash, 0, 7),
            'type' => $matches[1] ?? 'other',
            'scope' => $matches[2] ?? null,
            'description' => $matches[3] ?? $message,
            'breaking' => str_contains($message, '!'),
            'author' => $author,

<?php

namespace GsmUi\Docs;

class ComponentDocGenerator
{
    protected array $components = [];
    protected string $outputPath;
    
    public function __construct(string $outputPath)
    {
        $this->outputPath = $outputPath;
        $this->loadComponents();
    }
    
    protected function loadComponents(): void
    {
        $componentsPath = resource_path('views/vendor/gsmui/components');
        
        $directories = glob($componentsPath . '/*', GLOB_ONLYDIR);
        
        foreach ($directories as $directory) {
            $name = basename($directory);
            $this->components[$name] = $this->parseComponent($directory);
        }
    }
    
    protected function parseComponent(string $path): array
    {
        $component = [
            'name' => basename($path),
            'props' => [],
            'slots' => [],
            'events' => [],
        ];
        
        // Parse component file
        $indexFile = "{$path}/index.blade.php";
        if (file_exists($indexFile)) {
            $content = file_get_contents($indexFile);
            
            // Extract props from @props directive
            preg_match('/@props\(\[(.*?)\]\)/s', $content, $propsMatch);
            if ($propsMatch[1]) {
                $component['props'] = $this->parseProps($propsMatch[1]);
            }
        }
        
        return $component;
    }
    
    protected function parseProps(string $propsString): array
    {
        $props = [];
        
        // Simple prop extraction
        preg_match_all('/\'(\w+)\'\s*=>\s*[\'"]([^\'"]*)[\'"]/', $propsString, $matches);
        
        foreach ($matches[1] as $index => $name) {
            $props[] = [
                'name' => $name,
                'default' => $matches[2][$index],
                'type' => 'string',
            ];
        }
        
        return $props;
    }
    
    public function generateAll(): void
    {
        foreach ($this->components as $name => $component) {
            $this->generateComponentDoc($name, $component);
        }
    }
    
    protected function generateComponentDoc(string $name, array $component): void
    {
        $content = $this->renderTemplate($component);
        
        $outputFile = "{$this->outputPath}/components/{$name}.md";
        file_put_contents($outputFile, $content);
    }
    
    protected function renderTemplate(array $component): string
    {
        $name = ucfirst($component['name']);
        
        $content = "---\n";
        $content .= "title: \"{$name}\"\n";
        $content .= "description: \"The {$name} component.\"\n";
        $content .= "component: \"{$component['name']}\"\n";
        $content .= "---\n\n";
        
        $content .= "# {$name}\n\n";
        $content .= "## Installation\n\n";
        $content .= "```bash\ncomposer require gsmui/gsmui-pro\n```\n\n";
        
        $content .= "## Usage\n\n";
        $content .= "```blade\n<x-gsmui:{$component['name']} />\n```\n\n";
        
        if (!empty($component['props'])) {
            $content .= "## Props\n\n";
            $content .= "| Prop | Type | Default | Description |\n";
            $content .= "|------|------|---------|-------------|\n";
            
            foreach ($component['props'] as $prop) {
                $content .= "| `{$prop['name']}` | {$prop['type']} | `{$prop['default']}` | |\n";
            }
            $content .= "\n";
        }
        
        return $content;
    }
}

### Documentation Quality Checker

```php
<?php

namespace GsmUi\Docs;

class DocQualityChecker
{
    protected array $issues = [];
    protected array $rules = [];
    
    public function __construct()
    {
        $this->setupRules();
    }
    
    protected function setupRules(): void
    {
        $this->rules = [
            'has_title' => fn($content) => str_contains($content, '# '),
            'has_installation' => fn($content) => str_contains($content, '## Installation'),
            'has_usage' => fn($content) => str_contains($content, '## Usage'),
            'has_examples' => fn($content) => str_contains($content, '```blade'),
            'has_props' => fn($content) => str_contains($content, '## Props') || !str_contains($content, 'Prop'),
            'no_todo' => fn($content) => !preg_match('/TODO|FIXME|HACK/i', $content),
            'no_lorem' => fn($content) => !preg_match('/lorem ipsum/i', $content),
            'no_placeholder_text' => fn($content) => !preg_match('/(foo|bar|baz|example\.com)/i', $content),
        ];
    }
    
    public function check(string $filePath): array
    {
        $content = file_get_contents($filePath);
        $this->issues = [];
        
        foreach ($this->rules as $rule => $callback) {
            if (!$callback($content)) {
                $this->issues[] = [
                    'file' => $filePath,
                    'rule' => $rule,
                    'message' => $this->getRuleMessage($rule),
                ];
            }
        }
        
        // Check for broken links
        $this->checkLinks($content, $filePath);
        
        // Check for code block formatting
        $this->checkCodeBlocks($content, $filePath);
        
        return $this->issues;
    }
    
    protected function checkLinks(string $content, string $filePath): void
    {
        preg_match_all('/\[([^\]]+)\]\(([^)]+)\)/', $content, $matches);
        
        foreach ($matches[2] as $index => $url) {
            if (str_starts_with($url, 'http')) {
                continue;
            }
            
            $linkPath = dirname($filePath) . '/' . $url;
            if (!file_exists($linkPath)) {
                $this->issues[] = [
                    'file' => $filePath,
                    'rule' => 'broken_link',
                    'message' => "Broken link: {$url}",
                ];
            }
        }
    }
    
    protected function checkCodeBlocks(string $content, string $filePath): void
    {
        $lines = explode("\n", $content);
        $inCodeBlock = false;
        $language = '';
        
        foreach ($lines as $lineNum => $line) {
            if (preg_match('/^```(\w*)$/', $line, $matches)) {
                if ($inCodeBlock) {
                    $inCodeBlock = false;
                } else {
                    $inCodeBlock = true;
                    $language = $matches[1];
                }
            }
        }
        
        if ($inCodeBlock) {
            $this->issues[] = [
                'file' => $filePath,
                'rule' => 'unclosed_code_block',
                'message' => 'Unclosed code block',
            ];
        }
    }
    
    protected function getRuleMessage(string $rule): string
    {
        return match ($rule) {
            'has_title' => 'Missing page title',
            'has_installation' => 'Missing installation section',
            'has_usage' => 'Missing usage section',
            'has_examples' => 'Missing code examples',
            'has_props' => 'Missing props documentation',
            'no_todo' => 'Contains TODO/FIXME comments',
            'no_lorem' => 'Contains lorem ipsum placeholder text',
            'no_placeholder_text' => 'Contains placeholder text (foo, bar, example.com)',
            default => 'Unknown rule',
        };
    }
    
    public function checkDirectory(string $directory): array
    {
        $allIssues = [];
        $files = glob($directory . '/**/*.md');
        
        foreach ($files as $file) {
            $issues = $this->check($file);
            $allIssues = array_merge($allIssues, $issues);
        }
        
        return $allIssues;
    }
}

<?php

namespace GsmUi\Docs;

class DocValidator
{
    protected array $issues = [];
    
    public function validateDirectory(string $directory): array
    {
        $this->issues = [];
        
        $files = glob($directory . '/**/*.md');
        
        foreach ($files as $file) {
            $this->validateFile($file);
        }
        
        return $this->issues;
    }
    
    protected function validateFile(string $file): void
    {
        $content = file_get_contents($file);
        $relativePath = str_replace(base_path() . '/', '', $file);
        
        // Check for required sections
        $requiredSections = ['# ', '## Installation', '## Usage'];
        
        foreach ($requiredSections as $section) {
            if (!str_contains($content, $section)) {
                $this->issues[] = [
                    'file' => $relativePath,
                    'type' => 'missing_section',
                    'message' => "Missing required section: {$section}",
                ];
            }
        }
        
        // Check for placeholder text
        $placeholders = ['TODO', 'FIXME', 'lorem ipsum', 'foo', 'bar', 'baz'];
        
        foreach ($placeholders as $placeholder) {
            if (stripos($content, $placeholder) !== false) {
                $this->issues[] = [
                    'file' => $relativePath,
                    'type' => 'placeholder_text',
                    'message' => "Contains placeholder text: {$placeholder}",
                ];
            }
        }
        
        // Check for broken internal links
        preg_match_all('/\[([^\]]+)\]\(([^)]+)\)/', $content, $matches);
        
        foreach ($matches[2] as $link) {
            if (str_starts_with($link, 'http')) {
                continue;
            }
            
            $targetPath = dirname($file) . '/' . $link;
            if (!file_exists($targetPath)) {
                $this->issues[] = [
                    'file' => $relativePath,
                    'type' => 'broken_link',
                    'message' => "Broken link: {$link}",
                ];
            }
        }
        
        // Check for code block formatting
        $codeBlocks = preg_match_all('/```(\w+)?/', $content, $matches);
        
        // Check for unclosed code blocks
        $openBlocks = substr_count($content, '```') % 2;
        if ($openBlocks !== 0) {
            $this->issues[] = [
                'file' => $relativePath,
                'type' => 'unclosed_code_block',
                'message' => 'Unclosed code block',
            ];
        }
    }
}

## Documentation Best Practices

### Writing Guidelines

#### Do's and Don'ts

#### Do

1. **Use active voice** — "Click the button" not "The button should be clicked"
2. **Be direct** — "Use `wire:model`" not "You might want to use `wire:model`"
3. **Show, don't tell** — Provide code examples before explanations
4. **One concept per section** — Keep sections focused and scannable
5. **Use consistent terminology** — Always say "prop" not "property"

#### Don't

1. **Don't use jargon** — Explain technical terms
2. **Don't assume knowledge** — Provide context for advanced topics
3. **Don't use vague language** — Be specific and precise
4. **Don't skip examples** — Always include working code examples
5. **Don't forget mobile** — Ensure docs work on all devices

class DocumentationEngine {
    constructor(options = {}) {
        this.options = {
            basePath: '/docs',
            componentsPath: '/docs/components',
            ...options,
        };
        
        this.cache = new Map();
    }
    
    async getComponentDocs(componentName) {
        if (this.cache.has(componentName)) {
            return this.cache.get(componentName);
        }
        
        const response = await fetch(`${this.options.componentsPath}/${componentName}.json`);
        const docs = await response.json();
        
        this.cache.set(componentName, docs);
        
        return docs;
    }
    
    async search(query) {
        const response = await fetch(`${this.options.basePath}/search?q=${encodeURIComponent(query)}`);
        return response.json();
    }
    
    clearCache() {
        this.cache.clear();
    }
}

                    </div>
                </div>
            </div>
        `;
        
        this.setupTabs();
        this.render();
    }

        const tabs = this.container.querySelectorAll('.playground-tab');
        
        tabs.forEach(tab => {
            tab.addEventListener('click', () => {
                tabs.forEach(t => t.classList.remove('active'));
                tab.classList.add('active');
                
                const content = tab.dataset.content;
                this.container.querySelectorAll('[data-content]').forEach(el => {
                    el.style.display = el.dataset.content === content ? 'block' : 'none';
                });
            });
        });
    }
    
    render() {
        const preview = this.container.querySelector('.playground-preview');
        const code = this.container.querySelector('.playground-code code');
        
        preview.innerHTML = this.options.code;
        code.textContent = this.options.code;
    }
    
    updateCode(code) {

class CodeBlock {

        this.container = container;
        this.options = {
            language: 'blade',
            code: '',
            showLineNumbers: false,
            ...options,
        };
        
        this.init();
    }
    
    init() {
        this.container.innerHTML = `
            <div class="code-block">
                <div class="code-header">
                    <span class="code-language">${this.options.language}</span>
                    <button class="code-copy">Copy</button>
                </div>
                <pre><code class="language-${this.options.language}">${this.escapeHtml(this.options.code)}</code></pre>
            </div>
        `;
        
        this.setupCopy();
    }
    
    setupCopy() {
        const button = this.container.querySelector('.code-copy');
        
        button.addEventListener('click', () => {
            navigator.clipboard.writeText(this.options.code);
            button.textContent = 'Copied!';
            setTimeout(() => {
                button.textContent = 'Copy';
            }, 2000);
        });
    }
    
    escapeHtml(text) {
        const div = document.createElement('div');
        div.textContent = text;
        return div.innerHTML;
    }
}

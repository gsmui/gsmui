# 13.05 Props System — GsmUi Props Specification

## Overview

The GsmUi props system provides a consistent, type-safe, and developer-friendly way to define component properties. It leverages PHP 8.1+ features (typed properties, enums, attributes) and integrates with Laravel's Blade component system.

## Prop Definition

### Using PHP Attributes (Recommended)

```php
<?php

namespace GsmUi\Components\Forms;

use GsmUi\Concerns\Props\Prop;
use GsmUi\Contracts\ComponentContract;
use Livewire\Component;

class Input extends Component implements ComponentContract
{
    #[Prop(
        type: 'string',
        default: 'text',
        description: 'Input type (text, email, password, etc.)',
        options: ['text', 'email', 'password', 'number', 'tel', 'url', 'search']
    )]
    public string $type = 'text';

    #[Prop(
        type: 'string',
        default: 'md',
        description: 'Input size',
        options: ['xs', 'sm', 'md', 'lg']
    )]
    public string $size = 'md';

    #[Prop(
        type: 'string?',
        default: null,
        description: 'Placeholder text'
    )]
    public ?string $placeholder = null;

    #[Prop(
        type: 'bool',
        default: false,
        description: 'Whether input is required'
    )]
    public bool $required = false;

    #[Prop(
        type: 'bool',
        default: false,
        description: 'Whether input is disabled'
    )]
    public bool $disabled = false;

    #[Prop(
        type: 'bool',
        default: false,
        description: 'Whether input has validation error'
    )]
    public bool $invalid = false;

    #[Prop(
        type: 'string?',
        default: null,
        description: 'Wire model for Livewire binding'
    )]
    public ?string $wireModel = null;

    // Computed props (not passed from parent)
    public string $id;
    public bool $focused = false;
}
```

### Prop Attribute Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `type` | `string` | Yes | PHP type hint (supports `?`, `[]`, `union`) |
| `default` | `mixed` | No | Default value |
| `description` | `string` | No | Human-readable description |
| `options` | `array` | No | Allowed values (for validation) |
| `required` | `bool` | No | Whether prop is required |
| `reactive` | `bool` | No | Whether prop triggers re-render |
| `livewire` | `bool` | No | Whether prop supports `wire:model` |

## Prop Merging & Precedence

### Precedence Order (Highest to Lowest)

1. **Explicit prop value** — `<x-gsmui:button variant="secondary">`
2. **Wire:model binding** — `wire:model="form.status"` (for value props)
3. **Global config** — `config('gsmui.defaults.button.variant')`
4. **Theme defaults** — Theme token `--gsmui-button-variant`
5. **Component default** — `public string $variant = 'primary'`

### Merging Logic

```php
trait HasProps
{
    public function resolveProp(string $name): mixed
    {
        // 1. Explicit attribute
        if ($this->attributes->has($name)) {
            return $this->attributes->get($name);
        }
        
        // 2. Wire model (for value props)
        if ($this->isWireModelProp($name) && $this->wireModel) {
            return $this->getWireModelValue();
        }
        
        // 3. Global config
        $configKey = "gsmui.defaults.{$this->componentName}.{$name}";
        if (config()->has($configKey)) {
            return config($configKey);
        }
        
        // 4. Theme token (CSS variable)
        $token = "--gsmui-{$this->componentName}-{$name}";
        if ($this->theme->hasToken($token)) {
            return $this->theme->getToken($token);
        }
        
        // 5. Component default
        return $this->getDefaultProp($name);
    }
}
```

## Responsive Props

Props can accept responsive arrays:

```php
#[Prop(type: 'string|array', default: 'md')]
public string|array $size = 'md';
```

Usage:
```blade
<!-- Single value -->
<x-gsmui:button size="lg" />

<!-- Responsive array -->
<x-gsmui:button :size="['sm', 'md:lg', 'xl:xl']" />
```

### Responsive Resolution

```php
trait ResolvesResponsiveProps
{
    public function resolveResponsiveProp(string|array $value, string $breakpoint = 'md'): string
    {
        if (is_string($value)) {
            return $value;
        }
        
        // Parse Tailwind-style responsive array
        $currentBreakpoint = $this->getCurrentBreakpoint();
        $resolved = $value[0] ?? 'md';
        
        foreach ($value as $item) {
            if (str_starts_with($item, "{$currentBreakpoint}:")) {
                $resolved = substr($item, strlen($currentBreakpoint) + 1);
                break;
            }
            if (!str_contains($item, ':')) {
                $resolved = $item;
            }
        }
        
        return $resolved;
    }
}
```

## Prop Validation

### Automatic Validation

```php
trait ValidatesProps
{
    public function validateProps(): void
    {
        $props = $this->getPropDefinitions();
        
        foreach ($props as $name => $definition) {
            $value = $this->$name ?? $definition->default;
            
            // Type validation
            if (!$this->validateType($value, $definition->type)) {
                throw new InvalidPropTypeException(
                    "Prop {$name} expects {$definition->type}, got " . gettype($value)
                );
            }
            
            // Options validation
            if ($definition->options && !in_array($value, $definition->options, true)) {
                throw new InvalidPropValueException(
                    "Prop {$name} must be one of: " . implode(', ', $definition->options)
                );
            }
            
            // Required validation
            if ($definition->required && $value === null) {
                throw new RequiredPropMissingException("Prop {$name} is required");
            }
        }
    }
}
```

## Prop Resolution Deep Dive

### Resolution Order

When a component receives a prop, it resolves the value in this order:

1. **Explicit prop value** — Highest priority
2. **Wire:model binding** — For value props
3. **Global config** — Application defaults
4. **Theme token** — CSS variable
5. **Component default** — Lowest priority

```php
trait ResolvesProps
{
    public function resolveProp(string $name): mixed
    {
        // 1. Explicit attribute
        if ($this->attributes->has($name)) {
            return $this->castProp(
                $name,
                $this->attributes->get($name)
            );
        }
        
        // 2. Wire model (for value props)
        if ($this->isWireModelProp($name) && $this->wireModel) {
            return $this->getWireModelValue();
        }
        
        // 3. Global config
        $configKey = "gsmui.defaults.{$this->componentName}.{$name}";
        if (config()->has($configKey)) {
            return $this->castProp($name, config($configKey));
        }
        
        // 4. Theme token (CSS variable)
        $token = "--gsmui-{$this->componentName}-{$name}";
        if ($this->theme && $this->theme->hasToken($token)) {
            return $this->castProp($name, $this->theme->getToken($token));
        }
        
        // 5. Component default
        return $this->getDefaultProp($name);
    }
}
```

### Prop Casting

Props are automatically cast to their declared type:

```php
trait CastsProps
{
    protected function castProp(string $name, mixed $value): mixed
    {
        $type = $this->getPropType($name);
        
        return match ($type) {
            'string' => (string) $value,
            'string?' => $value !== null ? (string) $value : null,
            'int' => (int) $value,
            'int?' => $value !== null ? (int) $value : null,
            'float' => (float) $value,
            'float?' => $value !== null ? (float) $value : null,
            'bool' => filter_var($value, FILTER_VALIDATE_BOOLEAN),
            'bool?' => $value !== null ? filter_var($value, FILTER_VALIDATE_BOOLEAN) : null,
            'array' => (array) $value,
            'array?' => $value !== null ? (array) $value : null,
            'object' => (object) $value,
            default => $value,
        };
    }
}
```

## Prop Validation Deep Dive

### Built-in Validation

```php
trait ValidatesProps
{
    public function validateProps(): void
    {
        $props = $this->getPropDefinitions();
        
        foreach ($props as $name => $definition) {
            $value = $this->$name ?? $definition->default;
            
            // Type validation
            if (!$this->validateType($value, $definition->type)) {
                throw new InvalidPropTypeException(
                    "Prop {$name} expects {$definition->type}, got " . gettype($value)
                );
            }
            
            // Options validation
            if ($definition->options && !in_array($value, $definition->options, true)) {
                throw new InvalidPropValueException(
                    "Prop {$name} must be one of: " . implode(', ', $definition->options)
                );
            }
            
            // Required validation
            if ($definition->required && $value === null) {
                throw new RequiredPropMissingException(
                    "Prop {$name} is required"
                );
            }
            
            // Min/Max validation
            if (is_string($value)) {
                if (isset($definition->min) && strlen($value) < $definition->min) {
                    throw new InvalidPropValueException(
                        "Prop {$name} must be at least {$definition->min} characters"
                    );
                }
                if (isset($definition->max) && strlen($value) > $definition->max) {
                    throw new InvalidPropValueException(
                        "Prop {$name} must be at most {$definition->max} characters"
                    );
                }
            }
            
            if (is_numeric($value)) {
                if (isset($definition->min) && $value < $definition->min) {
                    throw new InvalidPropValueException(
                        "Prop {$name} must be at least {$definition->min}"
                    );
                }
                if (isset($definition->max) && $value > $definition->max) {
                    throw new InvalidPropValueException(
                        "Prop {$name} must be at most {$definition->max}"
                    );
                }
            }
        }
    }
}
```

## Prop Transformation Deep Dive

### Built-in Transformers

```php
trait TransformsProps
{
    protected function transformProp(string $name, mixed $value): mixed
    {
        return match ($name) {
            'variant' => $this->transformVariant($value),
            'size' => $this->transformSize($value),
            'color' => $this->transformColor($value),
            default => $value,
        };
    }
    
    protected function transformVariant(mixed $value): string
    {
        return match (strtolower((string) $value)) {
            'main', 'brand', 'primary' => 'primary',
            'secondary', 'alt' => 'secondary',
            'outline', 'bordered' => 'outline',
            'ghost', 'plain', 'transparent' => 'ghost',
            'link', 'underline' => 'link',
            default => (string) $value,
        };
    }
    
    protected function transformSize(mixed $value): string
    {
        return match (strtolower((string) $value)) {
            'tiny', '2xs', 'xxs' => 'xs',
            'small', 'sm' => 'sm',
            'medium', 'md', 'default' => 'md',
            'large', 'lg' => 'lg',
            'huge', '2xl', 'xxl', 'xl' => 'xl',
            default => (string) $value,
        };
    }
    
    protected function transformColor(mixed $value): string
    {
        return match (strtolower((string) $value)) {
            'blue', 'primary', 'brand' => 'primary',
            'gray', 'grey', 'neutral', 'secondary' => 'secondary',
            'green', 'success', 'emerald' => 'success',
            'yellow', 'warning', 'amber' => 'warning',
            'red', 'danger', 'error' => 'danger',
            default => (string) $value,
        };

}
```

```php
class OptionsTransformer implements PropTransformer
```

### Responsive Resolution

```php
trait ResolvesResponsiveProps
{
    public function resolveResponsiveProp(string|array $value, string $breakpoint = 'md'): string
    {
        if (is_string($value)) {
            return $value;
        }
        
        $currentBreakpoint = $this->getCurrentBreakpoint();
        $resolved = $value[0] ?? 'md';
        
        foreach ($value as $item) {
            if (str_starts_with($item, "{$currentBreakpoint}:")) {
                $resolved = substr($item, strlen($currentBreakpoint) + 1);
                break;
            }
            if (!str_contains($item, ':')) {
                $resolved = $item;
            }
        }
        
        return $resolved;
    }
    
    protected function getCurrentBreakpoint(): string
    {
        // This would be determined server-side based on request
        // or client-side via JavaScript
        return config('gsmui.current_breakpoint', 'md');
    }
}
```

```php
trait DebuggableProps
{
    public function debugProps(): array
    {
        if (!config('gsmui.debug')) {
            return [];
        }
        
        return collect($this->getPropDefinitions())
            ->mapWithKeys(fn($definition, $name) => [
                $name => [
                    'value' => $this->$name,
                    'type' => $definition->type,
                    'default' => $definition->default,
                    'source' => $this->getPropSource($name),
                ],
            ])
            ->toArray();
    }
    
    protected function getPropSource(string $name): string
    {
        if ($this->attributes->has($name)) {
            return 'explicit';
        }
        if ($this->isWireModelProp($name)) {
            return 'wire:model';
        }
        if (config()->has("gsmui.defaults.{$this->componentName}.{$name}")) {
            return 'config';
        }
        return 'default';
    }
}
```

```php
trait CachesProps
{

    {
```

# 13.300 Layout — GsmUi Layout Category Specification

## Overview

Layout components provide structural building blocks for page composition. They handle spacing, alignment, and responsive behavior without imposing visual styling.

## Components

| Component | Status | Description |
|-----------|--------|-------------|
| [Container](./13.301-container.md) | Stable | Max-width centered wrapper |
| [Grid](./13.302-grid.md) | Stable | CSS Grid layout system |
| [Stack](./13.303-stack.md) | Stable | Vertical/horizontal spacing |
| [Flex](./13.304-flex.md) | Stable | Flexbox wrapper |
| [Card](./13.305-card.md) | Stable | Content container with elevation |
| [Panel](./13.306-panel.md) | Stable | Collapsible content section |
| [Section](./13.307-section.md) | Stable | Page section with spacing |
| [Divider](./13.308-divider.md) | Stable | Horizontal/vertical rule |
| [Spacer](./13.309-spacer.md) | Stable | Explicit spacing element |
| [ScrollArea](./13.310-scroll-area.md) | Beta | Custom styled scrollbars |

```blade
<x-gsmui:container size="lg" class="py-12">
    Page content
</x-gsmui:container>
```

**Sizes:**
| Size | Max-Width |
|------|-----------|

| `sm` | 24rem (384px) |
| `md` | 28rem (448px) |
| `lg` | 32rem (512px) |
| `xl` | 36rem (576px) |
| `2xl` | 42rem (672px) |
| `3xl` | 48rem (768px) |
| `4xl` | 56rem (896px) |
| `5xl` | 64rem (1024px) |
| `6xl` | 72rem (1152px) |
| `7xl` | 80rem (1280px) |
| `full` | 100% |

**Props:** `size`, `fluid` (adds padding), `class`

### 13.302 Grid

**CSS Grid layout**

```blade
<x-gsmui:grid 
    :cols="['1', 'md:2', 'lg:3', 'xl:4']"
    :gap="['4', 'md:6', 'lg:8']"
    :cols-start="1"
    :cols-end="auto"
>
    @foreach($items as $item)
        <x-gsmui:card>{{ $item }}</x-gsmui:card>
    @endforeach
</x-gsmui:grid>
```

**Props:**
- `cols` - Responsive column count (string or array)
- `gap` - Responsive gap (string or array)
- `colsStart` / `colsEnd` - Grid line placement
- `rows` - Responsive row count
- `flow` - `row` | `col` | `dense` | `row-dense` | `col-dense`
- `templateAreas` - Named grid areas

---

### 13.303 Stack

**Vertical/horizontal spacing between children**

```blade
<x-gsmui:stack direction="vertical" :space="6" class="w-full">
    <x-gsmui:input label="Name" />
    <x-gsmui:input label="Email" type="email" />
    <x-gsmui:button variant="primary">Submit</x-gsmui:button>
</x-gsmui:stack>

<x-gsmui:stack direction="horizontal" :space="3" class="items-center">
    <x-gsmui:avatar :src="$user->avatar" />
    <div>
        <p class="font-medium">{{ $user->name }}</p>
        <p class="text-sm text-zinc-500">{{ $user->email }}</p>
    </div>
</x-gsmui:stack>
```

**Props:**
- `direction` - `vertical` | `horizontal` (default: vertical)
- `space` - Space token (default: 4)
- `divider` - Show divider between items
- `wrap` - Allow wrapping (horizontal only)
- `align` - `start` | `center` | `end` | `stretch`
- `justify` - `start` | `center` | `end` | `between` | `around`

---

### 13.304 Flex

**Flexbox wrapper with alignment utilities**

```blade
<x-gsmui:flex 
    :gap="4" 
    align="center" 
    justify="between"
    wrap="true"
>
    <x-gsmui:button variant="ghost">Cancel</x-gsmui:button>
    <x-gsmui:button variant="primary">Save</x-gsmui:button>
</x-gsmui:flex>
```

**Props:**
- `direction` - `row` | `col` | `row-reverse` | `col-reverse`
- `gap` - Space token (default: 4)
- `align` - `start` | `center` | `end` | `stretch` | `baseline`
- `justify` - `start` | `center` | `end` | `between` | `around` | `evenly`
- `wrap` - `nowrap` | `wrap` | `wrap-reverse`
- `grow` / `shrink` / `basis` - Flex item props (on children via `x-gsmui:flex.item`)

---

### 13.305 Card

**Elevated content container**

```blade
<x-gsmui:card variant="elevated" padding="lg" class="w-full max-w-md">
    <x-slot name="header">
        <h3 class="text-lg font-semibold">Card Title</h3>
        <p class="text-sm text-zinc-500">Optional description</p>
    </x-slot>
    
    <p class="text-zinc-600 dark:text-zinc-400">Card content goes here.</p>
    
    <x-slot name="footer">
        <x-gsmui:flex justify="end" gap="2">
            <x-gsmui:button variant="ghost">Cancel</x-gsmui:button>
            <x-gsmui:button>Confirm</x-gsmui:button>
        </x-gsmui:flex>
    </x-slot>
</x-gsmui:card>
```

**Variants:**
| Variant | Border | Shadow | Background |
|---------|--------|--------|------------|
| `outlined` | Yes | None | Surface |
| `elevated` | No | `shadow-sm` | Surface |
| `filled` | No | None | Surface variant |
| `plain` | No | None | Transparent |

**Props:**
- `variant` - `outlined` | `elevated` | `filled` | `plain`
- `padding` - `none` | `sm` | `md` | `lg` | `xl`
- `interactive` - Hover/focus states
- `href` - Renders as link

**Slots:** `header`, `default`, `footer`, `image` (top media)

### 13.306 Panel

**Collapsible content section**

```blade
<x-gsmui:panel 
    title="Advanced Settings" 
    :open="false"
    icon="chevron-down"
```

**Props:**
- `title` - Panel header text
- `open` - Initial open state (default: false)
- `icon` - Chevron icon (default: chevron-down)
- `variant` - `default` | `bordered` | `filled`
- `disabled` - Prevent toggle

**Events:** `open-change` `{ open: boolean }`

### 13.310 ScrollArea

**Custom styled scrollbars**

```blade
<x-gsmui:scroll-area class="h-96 w-full">
    <x-gsmui:stack space="4">

        @endforeach
```

**Props:**
- `scrollbars` - `auto` | `always` | `hover` | `never`

```blade
/>

    :space="['4', 'md:6']"
    direction="['vertical', 'lg:horizontal']"
/>
```

### Accessibility

- [ ] Semantic HTML (`section`, `main`, `aside`, etc.)
- [ ] Panel: `aria-expanded`, `aria-controls`
- [ ] Card as link: `role="article"` or proper heading structure
- [ ] Focus visible on interactive elements

## Related Components

- **Navigation:** Sidebar uses Stack/Flex
- **Forms:** Field uses Stack
- **Data Display:** Table wrapper uses Container
- **Overlays:** Modal content uses ScrollArea

### Split View Layout

```blade
{{-- Split view with resizable panels --}}
<div
    x-data="{
        splitPosition: 50,
        isDragging: false,
        startDrag(e) {
            this.isDragging = true;
            const startX = e.clientX;
            const startSplit = this.splitPosition;
            const container = this.$el;

            const onMove = (e) => {
                const dx = e.clientX - startX;
                const newSplit = startSplit + (dx / container.offsetWidth * 100);
                this.splitPosition = Math.max(20, Math.min(80, newSplit));
            };

            const onUp = () => {
                this.isDragging = false;
                document.removeEventListener('mousemove', onMove);
                document.removeEventListener('mouseup', onUp);
            };

            document.addEventListener('mousemove', onMove);
            document.addEventListener('mouseup', onUp);
        }
    }"
    class="flex h-screen"
>

    <div class="overflow-auto" :style="`width: ${splitPosition}%`">
        <div class="p-4">
            {{ $leftPanel }}

    </div>
```

### Dashboard Widget Grid

```blade
{{-- Dashboard widget grid with drag-and-drop --}}
<div
    x-data="{
        widgets: @entangle('widgets'),
        draggedWidget: null,
        startDrag(widget) {
            this.draggedWidget = widget;
        },
        drop(target) {
            if (this.draggedWidget && this.draggedWidget.id !== target.id) {
                const fromIndex = this.widgets.findIndex(w => w.id === this.draggedWidget.id);
                const toIndex = this.widgets.findIndex(w => w.id === target.id);
                const [removed] = this.widgets.splice(fromIndex, 1);
                this.widgets.splice(toIndex, 0, removed);
                this.$wire.updateWidgetOrder(this.widgets.map(w => w.id));
            }
            this.draggedWidget = null;
        }
    }"
    class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6"
>
    @foreach($widgets as $widget)
        <div
            draggable="true"
            x-on:dragstart="startDrag(@js($widget))"
            x-on:dragover.prevent
            x-on:drop="drop(@js($widget))"
            class="cursor-move"
        >
            <x-gsmui:card>
                <div class="p-4">
                    <div class="flex items-center justify-between mb-4">
                        <x-gsmui:heading level="4">{{ $widget->title }}</x-gsmui:heading>
                        <x-gsmui:icon name="bars-3" class="text-zinc-400" />
                    </div>
                    @livewire($widget->component, $widget->props, key($widget->id))
                </div>
            </x-gsmui:card>
        </div>

</div>
```

# 13.800 Media — GsmUi Media Category Specification

## Overview

The Media category contains components for displaying rich media content: images, video, audio, code, and documents. These components handle loading states, responsiveness, and accessibility.

## Components

| Component | Status | Description |
|-----------|--------|-------------|
| [Image](./13.801-image.md) | Stable | Responsive images with lazy loading |
| [Gallery](./13.802-gallery.md) | Stable | Image grid with lightbox |
| [Carousel](./13.803-carousel.md) | Stable | Sliding image/content carousel |
| [Video](./13.804-video.md) | Stable | Video player with custom controls |
| [Audio](./13.805-audio.md) | Stable | Audio player with waveform |
| [CodeBlock](./13.806-code-block.md) | Stable | Syntax-highlighted code |
| [MarkdownViewer](./13.807-markdown-viewer.md) | Beta | Rendered markdown content |
| [DocumentViewer](./13.808-document-viewer.md) | Beta | PDF/Office document preview |
| [Avatar](./13.809-avatar.md) | Stable | User/image avatars (also in Data Display) |
| [Icon](./13.810-icon.md) | Stable | SVG icon system |

## Design Principles

### Loading States

```
1. Placeholder (skeleton/blur) → 2. Low-quality (LQIP) → 3. Full quality
```

### Responsive Images

```blade
<x-gsmui:image 
    src="/image.jpg"
    :srcset="[
        '320w' => '/image-320w.jpg',
        '640w' => '/image-640w.jpg',
        '1280w' => '/image-1280w.jpg',
    ]"
    sizes="(max-width: 640px) 100vw, (max-width: 1280px) 50vw, 33vw"
    alt="Description"
/>
```

### Aspect Ratios

| Ratio | Classes | Use Case |
|-------|---------|----------|
| `1/1` | `aspect-square` | Avatars, thumbnails |
| `4/3` | `aspect-video` | Standard photos |
| `16/9` | `aspect-w-16 aspect-h-9` | Videos, wide images |
| `21/9` | `aspect-w-21 aspect-h-9` | Cinematic |
| `3/2` | `aspect-w-3 aspect-h-2` | Classic photos |
| `auto` | None | Natural dimensions |

## Component Specifications

### 13.801 Image

**Responsive image with loading states**

```blade
<x-gsmui:image
    src="/hero.jpg"
    :srcset="[
        '320w' => '/hero-320w.jpg',
        '640w' => '/hero-640w.jpg',
        '1280w' => '/hero-1280w.jpg',
        '1920w' => '/hero-1920w.jpg',
    ]"
    sizes="(max-width: 640px) 100vw, (max-width: 1280px) 50vw, 33vw"
    alt="Mountain landscape at sunset"
    aspect-ratio="16/9"
    loading="lazy"
    placeholder="blur"
    :lqip="base64BlurDataUri"
    rounded="lg"
    class="w-full"
/>
```

**Props:**
- `src` - Primary image URL
- `srcset` - Responsive sources array
- `sizes` - Sizes attribute
- `alt` - Alt text (required)
- `aspectRatio` - Aspect ratio (auto, square, video, 4/3, 3/2, 16/9, 21/9, or custom)
- `loading` - `lazy` | `eager` | `auto`
- `placeholder` - `blur` | `color` | `skeleton` | `none`
- `lqip` - Low Quality Image Placeholder (base64)
- `placeholderColor` - Solid color placeholder
- `rounded` - Border radius
- `fit` - `cover` | `contain` | `fill` | `scale-down`
- `priority` - Preload (for above-fold images)

**Events:** `load`, `error`

### 13.802 Gallery

**Image grid with lightbox**

```blade
<x-gsmui:gallery
    :items="[
        ['src' => '/img1.jpg', 'alt' => 'Photo 1', 'caption' => 'Sunset'],
        ['src' => '/img2.jpg', 'alt' => 'Photo 2', 'caption' => 'Mountains'],
        ['src' => '/img3.jpg', 'alt' => 'Photo 3'],
    ]"
    :columns="['default' => 1, 'sm' => 2, 'lg' => 3, 'xl' => 4]"
    gap="3"
    aspect-ratio="4/3"
    lightbox
    lightbox-captions
/>
```

**Props:**
- `items` - Array of images
- `columns` - Responsive column count
- `gap` - Gap between images
- `aspectRatio` - Grid item aspect ratio
- `lightbox` - Enable lightbox (default: true)
- `lightboxCaptions` - Show captions in lightbox
- `lightboxCounter` - Show "1 of 5"
- `lightboxDownload` - Allow download
- `lightboxZoom` - Enable zoom
- `lazyLoad` - Lazy load images (default: true)

**Lightbox Features:**
- Keyboard navigation (arrows, escape)
- Swipe gestures (mobile)
- Zoom (pinch/wheel)
- Fullscreen
- Captions
- Counter

### 13.803 Carousel

**Sliding content carousel**

```blade
<x-gsmui:carousel
    :items="$slides"
    :autoplay="5000"
    :pause-on-hover="true"
    :show-indicators="true"
    :show-controls="true"
    :loop="true"
    transition="slide"
>
    <x-slot name="item" :item="$item">
        <x-gsmui:image :src="$item->image" alt="$item->title" aspect-ratio="16/9" />
        <div class="absolute bottom-0 left-0 right-0 p-4 bg-gradient-to-t from-black/80 to-transparent text-white">
            <h3 class="font-semibold">{{ $item->title }}</h3>
            <p class="text-sm opacity-90">{{ $item->description }}</p>
        </div>
    </x-slot>
</x-gsmui:carousel>
```

**Props:**
- `items` - Array of slide data
- `autoplay` - Autoplay interval ms (0 = disabled)
- `pauseOnHover` - Pause on hover
- `showIndicators` - Show dot indicators
- `showControls` - Show prev/next arrows
- `loop` - Infinite loop
- `transition` - `slide` | `fade` | `none`
- `transitionDuration` - Ms (default: 300)
- `align` - `start` | `center` | `end`
- `perView` - Slides per view (default: 1)
- `perViewMobile` - Slides on mobile

**Keyboard:**
- `ArrowLeft/Right` - Navigate
- `Home`/`End` - First/Last
- `Space` - Pause/play

- `quality` - Quality selector array
- `thumbnails` - VTT file for hover thumbnails

**Custom Controls:**

### 13.805 Audio

**Audio player with waveform**

```blade

    :sources="[
        ['src' => '/podcast.mp3', 'type' => 'audio/mpeg'],

    :show-waveform="true"
```

- `showTranscript` - Show transcript
- `transcript` - Array of `{ time, text, speaker }`
- `download` - Download button
- `speed` - Speed selector
- `skip` - Skip forward/back seconds
- `autoplay` - Auto play
- `loop` - Loop
- `preload` - Preload strategy

**Transcript Features:**
- Click to seek
- Auto-scroll to current time
- Speaker labels
- Search within transcript

## Accessibility

### Image
- `alt` required (empty for decorative)
- `loading="lazy"` for below-fold
- `decoding="async"` for performance

### Video/Audio
- `<track kind="captions">` for captions
- `<track kind="descriptions">` for audio descriptions
- Keyboard controls
- `aria-label` on custom controls

### CodeBlock
- `role="region"` `aria-label="Code block"`
- Copy button: `aria-label="Copy code"`
- Line numbers: `aria-hidden="true"`

### Carousel/Gallery
- `role="region"` `aria-roledescription="carousel"`
- `aria-label` for carousel
- `aria-roledescription="slide"` on items
- `aria-current="true"` on active
- Pause on hover/focus

## Performance Considerations

### Image Optimization

- Lazy loading by default
- LQIP (Low Quality Image Placeholder)
- Responsive srcset
- WebP/AVIF format support
- Priority loading for above-fold

### Video Optimization

- Poster image for fast initial load
- Metadata preload (not full video)
- Quality selector for bandwidth
- Thumbnail preview on hover

### Audio Optimization

- Metadata preload
- Waveform data precomputed
- Transcript lazy-loaded

### CodeBlock Optimization

- Syntax highlighting lazy-loaded
- Large code blocks use virtual scrolling
- Copy button uses clipboard API

### Bundle Size

- Image: ~2KB gzipped
- Gallery: ~4KB gzipped (includes lightbox)
- Carousel: ~3KB gzipped
- Video: ~5KB gzipped (includes controls)
- Audio: ~4KB gzipped (includes waveform)
- CodeBlock: ~8KB gzipped (includes Prism/Shiki)
- MarkdownViewer: ~6KB gzipped (includes parser)
- DocumentViewer: ~5KB gzipped (includes PDF.js)
- Icon: ~1KB gzipped
- Total category: ~38KB gzipped

### File Upload with Preview

```blade
{{-- File upload with preview and progress --}}
<div
    x-data="{
        files: [],
        uploading: false,
        progress: 0,
        dragover: false,
        addFiles(newFiles) {
            for (const file of newFiles) {
                this.files.push({
                    id: Date.now() + Math.random(),
                    file,
                    name: file.name,
                    size: this.formatSize(file.size),
                    type: file.type,
                    preview: this.getPreview(file),
                    status: 'pending',
                    progress: 0
                });
            }
        },
        getPreview(file) {
            if (file.type.startsWith('image/')) {
                return URL.createObjectURL(file);
            }
            return null;
        },
        formatSize(bytes) {
            if (bytes === 0) return '0 Bytes';
            const k = 1024;
            const sizes = ['Bytes', 'KB', 'MB', 'GB'];
            const i = Math.floor(Math.log(bytes) / Math.log(k));
            return parseFloat((bytes / Math.pow(k, i)).toFixed(2)) + ' ' + sizes[i];
        },
        removeFile(id) {
            this.files = this.files.filter(f => f.id !== id);
        },
        async uploadFiles() {
            this.uploading = true;
            this.progress = 0;

            for (const file of this.files) {
                if (file.status === 'success') continue;

                file.status = 'uploading';
                const formData = new FormData();
                formData.append('file', file.file);

                try {
                    const response = await fetch('/upload', {
                        method: 'POST',
                        body: formData,
                        headers: {
                            'X-CSRF-TOKEN': document.querySelector('meta[name=csrf-token]').content
                        }
                    });

                    if (response.ok) {
                        file.status = 'success';
                        file.progress = 100;
                    } else {
                        file.status = 'error';
                    }
                } catch (e) {
                    file.status = 'error';
                }

                this.progress = Math.round((this.files.filter(f => f.status === 'success').length / this.files.length) * 100);
            }

            this.uploading = false;
        }
    }"
    x-on:dragover.prevent="dragover = true"
    x-on:dragleave.prevent="dragover = false"
    x-on:drop.prevent="dragover = false; addFiles($event.dataTransfer.files)"
>
    {{-- Drop zone --}}
    <div
        class="border-2 border-dashed rounded-xl p-8 text-center transition-colors"
        :class="dragover ? 'border-primary bg-primary/5' : 'border-zinc-300 dark:border-zinc-700'"
    >
        <x-gsmui:icon name="arrow-up-tray" class="w-10 h-10 mx-auto text-zinc-400 mb-4" />
        <p class="text-sm text-zinc-600">
            <span class="font-medium text-primary">Click to upload</span> or drag and drop
        </p>
        <p class="text-xs text-zinc-500 mt-1">PNG, JPG, PDF up to 10MB</p>
        <input
            type="file"
            multiple
            class="absolute inset-0 w-full h-full opacity-0 cursor-pointer"
            x-on:change="addFiles($event.target.files)"
        />
    </div>

    {{-- File list --}}
    @if($files->count())
        <div class="mt-4 space-y-2">
            @foreach($files as $file)
                <div class="flex items-center gap-3 p-3 bg-zinc-50 dark:bg-zinc-800 rounded-lg">
                    {{-- Preview/Icon --}}
                    @if($file->preview)
                        <img src="{{ $file->preview }}" class="w-10 h-10 rounded object-cover" />
                    @else
                        <div class="w-10 h-10 bg-zinc-200 dark:bg-zinc-700 rounded flex items-center justify-center">
                            <x-gsmui:icon name="document" class="w-5 h-5 text-zinc-500" />
                        </div>
                    @endif

                    {{-- Info --}}
                    <div class="flex-1 min-w-0">
                        <p class="text-sm font-medium truncate">{{ $file->name }}</p>
                        <p class="text-xs text-zinc-500">{{ $file->size }}</p>
                    </div>

                    {{-- Status --}}
                    @if($file->status === 'uploading')
                        <div class="w-20">
                            <div class="h-1.5 bg-zinc-200 dark:bg-zinc-700 rounded-full overflow-hidden">
                                <div class="h-full bg-primary rounded-full" :style="`width: ${$file->progress}%`"></div>
                            </div>
                        </div>
                    @elseif($file->status === 'success')
                        <x-gsmui:icon name="check-circle" class="w-5 h-5 text-green-500" />
                    @elseif($file->status === 'error')
                        <x-gsmui:icon name="x-circle" class="w-5 h-5 text-red-500" />
```

### Image Cropper

```blade
{{-- Image cropper with aspect ratio --}}
<div
    x-data="{
        image: null,
        croppedImage: null,
        aspectRatio: 16/9,
        zoom: 1,
        rotation: 0,
        position: { x: 0, y: 0 },
        handleFile(e) {
            const file = e.target.files[0];
            if (file) {
                const reader = new FileReader();
                reader.onload = (e) => {
                    this.image = e.target.result;
                    this.reset();
                };
                reader.readAsDataURL(file);
            }
        },
        reset() {
            this.zoom = 1;
            this.rotation = 0;
            this.position = { x: 0, y: 0 };
        },
        async crop() {
            const canvas = document.createElement('canvas');
            const img = new Image();
            img.src = this.image;

            await new Promise(resolve => img.onload = resolve);

            const ctx = canvas.getContext('2d');
            const size = Math.min(img.width, img.height);
            canvas.width = size;
            canvas.height = size;

            ctx.drawImage(img, 0, 0, size, size);

            this.croppedImage = canvas.toDataURL('image/jpeg', 0.9);
            this.$wire.setCroppedImage(this.croppedImage);
        }
    }"
```

### Document Viewer

```blade

    x-data="{
        zoom: 100,
        rotation: 0,
        currentPage: 1,
        totalPages: {{ $totalPages }},
        fitToWidth: true,
        zoomIn() {
            this.zoom = Math.min(200, this.zoom + 25);
            this.fitToWidth = false;
        },
        zoomOut() {
            this.zoom = Math.max(25, this.zoom - 25);
            this.fitToWidth = false;
        },
        resetZoom() {
            this.zoom = 100;
            this.rotation = 0;
            this.fitToWidth = true;
        },
        rotate() {
            this.rotation = (this.rotation + 90) % 360;
        },
        prevPage() {
            if (this.currentPage > 1) this.currentPage--;
        },
        nextPage() {
            if (this.currentPage < this.totalPages) this.currentPage++;
```

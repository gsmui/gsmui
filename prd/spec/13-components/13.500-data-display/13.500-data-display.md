# 13.500 Data Display — GsmUi Data Display Category Specification

## Overview

The Data Display category contains components for presenting structured information. These components focus on readability, scannability, and efficient data presentation.

## Components

| Component | Status | Description |
|-----------|--------|-------------|
| [Table](./13.501-table.md) | Stable | Tabular data with sorting, filtering, pagination |
| [DataTable](./13.502-datatable.md) | Stable | Advanced table with virtualization, editing |
| [Badge](./13.503-badge.md) | Stable | Status labels and counts |
| [Avatar](./13.504-avatar.md) | Stable | User/entity representation |
| [Statistic](./13.505-statistic.md) | Stable | Key metrics with trends |
| [Timeline](./13.506-timeline.md) | Stable | Chronological event sequence |
| [Calendar](./13.507-calendar.md) | Stable | Monthly calendar view |
| [List](./13.508-list.md) | Stable | Structured item lists |
| [DescriptionList](./13.509-description-list.md) | Stable | Key-value pairs |
| [DataGrid](./13.510-data-grid.md) | Beta | Card-based data layout |

## Design Principles

### Information Hierarchy

```
Primary (largest, boldest)     → Statistic value, Table header
Secondary (medium)             → Labels, descriptions, timestamps
Tertiary (smallest, muted)     → Metadata, help text, counts
```

### Density Options

| Density | Row Height | Padding | Use Case |
|---------|------------|---------|----------|
| `comfortable` | 48px | 16px | Default, reading |
| `compact` | 40px | 12px | Data-heavy, scanning |
| `condensed` | 32px | 8px | Maximum data, admin |

### Alignment Rules

| Data Type | Alignment |
|-----------|-----------|
| Text | Left |
| Numbers | Right (tabular-nums) |
| Currency | Right (tabular-nums) |
| Dates | Right or Center |
| Boolean/Status | Center |
| Actions | Center or Right |

## Component Specifications

### 13.501 Table

**Basic tabular data**

```blade
<x-gsmui:table 
    :columns="[
        ['key' => 'name', 'label' => 'Name', 'sortable' => true],
        ['key' => 'email', 'label' => 'Email', 'sortable' => true],
        ['key' => 'role', 'label' => 'Role', 'width' => '120px'],
        ['key' => 'status', 'label' => 'Status', 'render' => fn($row) => $this->statusBadge($row)],
        ['key' => 'actions', 'label' => '', 'width' => '80px', 'align' => 'center'],
    ]"
    :rows="$users"
    :sort-by="$sortBy"
    :sort-direction="$sortDirection"
    wire:sort="setSort"
    density="comfortable"
    striped
    hoverable
>
    <x-slot name="actions" :row="$row">
        <x-gsmui:button variant="ghost" size="xs" icon="pencil" wire:click="edit({{ $row->id }})" />
    </x-slot>
</x-gsmui:table>
```

**Column Definition:**
```php
[
    'key' => 'name',              // Row property key
    'label' => 'Name',            // Header label
    'sortable' => true,           // Enable sorting
    'width' => '200px',           // Fixed width
    'minWidth' => '150px',        // Minimum width
    'align' => 'left',            // left|center|right
    'render' => fn($row) => ...,  // Custom render function
    'class' => 'font-medium',     // Cell classes
    'headerClass' => 'uppercase', // Header classes
]
```

**Features:**
- Server-side sort (via `wire:sort`)
- Client-side sort (if no wire:sort)
- Row click selection
- Keyboard navigation (Arrow keys)
- Sticky header option
- Column resizing (future)

### 13.502 DataTable

**Advanced table with virtualization**

```blade
<x-gsmui:datatable
    :columns="$columns"
    :rows="$users"
    :total="$total"
    :per-page="25"
    wire:model="tableState"
    density="compact"
    virtualized
    selectable
    :selected="$selectedIds"
    wire:select="selectRows"
    :filters="[
        ['key' => 'status', 'type' => 'select', 'options' => $statuses],
        ['key' => 'created_at', 'type' => 'dateRange'],
    ]"
    wire:filter="applyFilters"
    :bulk-actions="[
        ['label' => 'Delete', 'action' => 'bulkDelete', 'variant' => 'danger'],
        ['label' => 'Export', 'action' => 'bulkExport'],
    ]"
/>
```

**State Object:**
```php
$tableState = [
    'page' => 1,
    'perPage' => 25,
    'sortBy' => 'created_at',
    'sortDirection' => 'desc',
    'filters' => ['status' => 'active'],
    'search' => '',
    'selected' => [],
];
```

**Features:**
- Virtual scrolling (10k+ rows)
- Column resizing/reordering
- Row selection (single/multi)
- Bulk actions toolbar
- Column filtering
- Global search
- Export (CSV, JSON)
- Row expansion/detail view
- Inline editing
- Persisted state (localStorage)

### 13.503 Badge

**Status labels and counts**

```blade
<x-gsmui:badge variant="success">Active</x-gsmui:badge>
<x-gsmui:badge variant="warning" dot>Pending</x-gsmui:badge>
<x-gsmui:badge variant="danger" count="5" />
```

**Variants:**
| Variant | Style | Use Case |
|---------|-------|----------|
| `default` | Neutral | Generic |
| `primary` | Brand | Primary actions |
| `success` | Green | Positive status |
| `warning` | Amber | Attention needed |
| `danger` | Red | Critical/error |
| `info` | Blue | Informational |
| `outline` | Bordered | Subtle |

**Props:**
- `variant` - Visual style
- `size` - `xs` | `sm` | `md` | `lg`
- `dot` - Show status dot
- `count` - Show number badge
- `icon` - Leading icon
- `removable` - Show close button
- `href` - Render as link

**User/entity representation**

```blade
<x-gsmui:avatar

    status="online"

    <x-gsmui:avatar name="John Doe" />
    <x-gsmui:avatar name="Jane Smith" />
    <x-gsmui:avatar name="Bob Wilson" />
```

**Status:** `online` | `offline` | `busy` | `away` | `custom`

**Fallback:** Initials from name, colored background (deterministic from name hash)

```blade
<x-gsmui:statistic

    value="$127,432"
```

**Props:**

- `iconVariant` - Icon color variant
- `sparkline` - Array of numbers for mini chart

- `action` - Link/button for drill-down

### 13.507 Calendar

**Monthly calendar view**

```blade
<x-gsmui:calendar
    wire:model="selectedDate"
    :events="$events"
    :min-date="today()"
    :max-date="'+1 year'"
    first-day-of-week="1"
    show-week-numbers
    locale="en"
/>
```

**Event Structure:**
```php
[
    'date' => '2026-07-20',
    'endDate' => '2026-07-22',  // Multi-day
    'title' => 'Conference',
    'description' => 'Annual dev conference',
    'color' => '#3b82f6',
    'url' => '/events/123',
    'allDay' => true,
]
```

**Props:**
- `value` - Selected date(s)
- `events` - Event array
- `minDate`, `maxDate` - Date bounds
- `firstDayOfWeek` - 0 (Sun) or 1 (Mon)
- `showWeekNumbers`
- `locale` - Date locale
- `view` - `month` | `week` | `day`
- `range` - Select date range

### 13.508 List

**Structured item lists**

```blade
<x-gsmui:list
    :items="$notifications"
    density="comfortable"
    divide
>
    <x-slot name="item" :item="$item">
        <x-gsmui:list.item>
            <x-slot name="leading">
                <x-gsmui:avatar :name="$item->sender" size="sm" />
            </x-slot>
            
            <x-slot name="content">
                <p class="font-medium">{{ $item->sender }}</p>
                <p class="text-sm text-zinc-500">{{ $item->preview }}</p>
            </x-slot>
            
            <x-slot name="trailing">
                <span class="text-xs text-zinc-400">{{ $item->time }}</span>
                @if($item->unread)
                    <x-gsmui:badge variant="primary" size="xs" dot />
                @endif
            </x-slot>
        </x-gsmui:list.item>
    </x-slot>
</x-gsmui:list>
```

**Sub-components:**
- `list.item` - Individual item
- `list.item.leading` - Leading content (avatar, icon)
- `list.item.content` - Main content
- `list.item.trailing` - Trailing content (time, badge, actions)
- `list.divider` - Section divider
- `list.section` - Section with header

**Props:**
- `items` - Data array
- `density` - `comfortable` | `compact` | `condensed`
- `divide` - Show dividers
- `striped` - Alternate row colors
- `hoverable` - Hover highlight
- `selectable` - Row selection

### 13.509 DescriptionList

**Key-value pairs (definition list)**

```blade
<x-gsmui:description-list
    :items="[
        ['label' => 'Email', 'value' => 'john@example.com'],
        ['label' => 'Phone', 'value' => '(555) 123-4567', 'copyable' => true],
        ['label' => 'Address', 'value' => '123 Main St, City, State'],
        ['label' => 'Status', 'value' => 'Active', 'variant' => 'success'],
        ['label' => 'Last Login', 'value' => '2 hours ago'],

    layout="horizontal"
    label-width="160px"
/>
```

**Layouts:**
| Layout | Description |
|--------|-------------|
| `horizontal` | Label left, value right |
| `vertical` | Label above value |
| `grid` | CSS grid auto-fit |

**Props:**
- `items` - Array of key-value pairs
- `layout` - `horizontal` | `vertical` | `grid`
- `labelWidth` - Fixed label width (horizontal)
- `divide` - Show dividers
- `colon` - Append colon to labels

**Item Props:**
- `label` - Key
- `value` - Value (string or component)
- `variant` - Value color variant
- `copyable` - Copy to clipboard
- `href` - Make value a link

## Accessibility

### Table
- `<table>` with `<thead>`, `<tbody>`
- `<th scope="col">` for headers
- `aria-sort` on sortable headers
- `role="grid"` for interactive tables
- `aria-selected` on selectable rows

### Badge/Avatar
- Badge: `role="status"` for live counts
- Avatar: `alt=""` for decorative, `alt="Name"` for informative

### Timeline
- `<ol>` with `<li>` for events
- `aria-label="Timeline"` on container

### Calendar
- `<table role="grid">`
- `aria-selected` on selected date
- `aria-disabled` on disabled dates
- `aria-label` on navigation buttons

### List
- `<ul role="list">` or `<ol>`
- `role="listitem"` on items
- `aria-selected` on selectable

### Virtualization

- DataTable virtual scrolling for 10k+ rows
- Only render visible rows in viewport
- Smooth scrolling with buffer rows
- Dynamic row height support

### Lazy Loading

- Calendar events lazy-load per month
- DataTable data lazy-load per page
- DataGrid items lazy-load on scroll

- Table: ~3KB gzipped
- DataTable: ~8KB gzipped (includes virtualization)

- Calendar: ~5KB gzipped

### Virtual Scrolling Table

```blade
{{-- Virtual scrolling for large datasets --}}
<div
    x-data="{
        items: @entangle('items'),
        scrollTop: 0,
        itemHeight: 48,
        containerHeight: 600,
        get visibleItems() {
            const start = Math.floor(this.scrollTop / this.itemHeight);
            const count = Math.ceil(this.containerHeight / this.itemHeight) + 5;
            return this.items.slice(start, start + count).map((item, i) => ({
                ...item,
                index: start + i
            }));
        },
        get totalHeight() {
            return this.items.length * this.itemHeight;
        },
        get offsetY() {

            <div class="absolute inset-0" :style="`transform: translateY(${offsetY}px)`">
```

### Sortable Data Table

```blade
{{-- Data table with column sorting --}}
<div
    x-data="{
        sortColumn: '{{ $defaultSort }}',
        sortDirection: '{{ $defaultDirection }}',
        data: @entangle('data'),
        get sortedData() {
            return [...this.data].sort((a, b) => {
                const aVal = a[this.sortColumn];
                const bVal = b[this.sortColumn];
                const modifier = this.sortDirection === 'asc' ? 1 : -1;
                if (aVal < bVal) return -1 * modifier;
                if (aVal > bVal) return 1 * modifier;
                return 0;
            });
        },
        toggleSort(column) {
            if (this.sortColumn === column) {
                this.sortDirection = this.sortDirection === 'asc' ? 'desc' : 'asc';
            } else {
                this.sortColumn = column;
                this.sortDirection = 'asc';
            }
        }
    }"
>
    <table class="w-full">
        <thead>
            <tr class="border-b">
                @foreach($columns as $column)
                    <th
                        class="px-4 py-3 text-left text-sm font-medium text-zinc-600 cursor-pointer hover:bg-zinc-50"
                        x-on:click="toggleSort('{{ $column->key }}')"
                    >
                        <div class="flex items-center gap-2">
                            {{ $column->label }}
                            <div class="flex flex-col">
                                <x-gsmui:icon
                                    name="chevron-up"
                                    class="w-3 h-3"
                                    :class="sortColumn === '{{ $column->key }}' && sortDirection === 'asc' ? 'text-primary' : 'text-zinc-300'"
                                />
                                <x-gsmui:icon
                                    name="chevron-down"
                                    class="w-3 h-3 -mt-1"
                                    :class="sortColumn === '{{ $column->key }}' && sortDirection === 'desc' ? 'text-primary' : 'text-zinc-300'"
                                />
                            </div>
                        </div>
                    </th>
                @endforeach
            </tr>
        </thead>
        <tbody>
            <template x-for="row in sortedData" :key="row.id">
                <tr class="border-b hover:bg-zinc-50 dark:hover:bg-zinc-800">
                    @foreach($columns as $column)
                        <td class="px-4 py-3 text-sm" x-text="row['{{ $column->key }}']"></td>
                    @endforeach
                </tr>
            </template>
        </tbody>
    </table>
</div>
```

### Filterable Data Grid

```blade
{{-- Data grid with advanced filtering --}}
<div
    x-data="{
        filters: @entangle('filters'),
        data: @entangle('data'),
        get filteredData() {
            return this.data.filter(row => {
                return Object.entries(this.filters).every(([key, value]) => {
                    if (!value) return true;
                    const rowValue = String(row[key]).toLowerCase();
                    const filterValue = value.toLowerCase();
                    if (value.startsWith('>=')) return rowValue >= value.slice(2);
                    if (value.startsWith('<=')) return rowValue <= value.slice(2);
                    if (value.startsWith('!')) return rowValue !== value.slice(1);
                    if (value.startsWith('*') && value.endsWith('*')) return rowValue.includes(value.slice(1, -1));
                    if (value.endsWith('*')) return rowValue.startsWith(value.slice(0, -1));
                    if (value.startsWith('*')) return rowValue.endsWith(value.slice(1));
                    return rowValue === filterValue;
                });
            });
        }
    }"
>
    {{-- Filter inputs --}}
    <div class="flex flex-wrap gap-4 mb-4 p-4 bg-zinc-50 dark:bg-zinc-800 rounded-lg">
```

```blade
    x-data="{
```

```blade
        init() {
            this.$watch('selectedPoint', (point) => {
                if (point) {

                    canvas: null,
                    init() {
                        this.canvas = this.$el.querySelector('canvas');
                        this.drawChart();
                    },
                    drawChart() {
                        const ctx = this.canvas.getContext('2d');
                        const data = this.chartData;
                        const width = this.canvas.width;
                        const height = this.canvas.height;
                        const padding = 40;

                        ctx.clearRect(0, 0, width, height);

                        // Draw axes
                        ctx.strokeStyle = '#e5e7eb';
                        ctx.lineWidth = 1;
                        ctx.beginPath();
                        ctx.moveTo(padding, padding);
                        ctx.lineTo(padding, height - padding);
                        ctx.lineTo(width - padding, height - padding);
                        ctx.stroke();

                        // Draw line
                        ctx.strokeStyle = '#3b82f6';
                        ctx.lineWidth = 2;
                        ctx.beginPath();
                        data.forEach((point, i) => {
                            const x = padding + (i / (data.length - 1)) * (width - 2 * padding);
                            const y = height - padding - (point.value / Math.max(...data.map(d => d.value))) * (height - 2 * padding);
                            if (i === 0) ctx.moveTo(x, y);
                            else ctx.lineTo(x, y);
                        });
                        ctx.stroke();
                    }
```

```blade
{{-- Side-by-side data comparison --}}
<div
    x-data="{
        leftVersion: @entangle('leftVersion'),
        rightVersion: @entangle('rightVersion'),
        differences: [],
        init() {
            this.compare();
        },
        compare() {
            this.differences = [];
            const keys = [...new Set([...Object.keys(this.leftVersion), ...Object.keys(this.rightVersion)])];
            keys.forEach(key => {
                if (JSON.stringify(this.leftVersion[key]) !== JSON.stringify(this.rightVersion[key])) {
                    this.differences.push({
                        key,
                        left: this.leftVersion[key],
                        right: this.rightVersion[key]
                    });
                }
            });
        }
    }"
>
    <div class="grid grid-cols-2 gap-4">
        {{-- Left version --}}
        <div>
            <div class="flex items-center justify-between mb-4">
                <x-gsmui:heading level="3">Version A</x-gsmui:heading>
                <x-gsmui:badge variant="primary">Current</x-gsmui:badge>
            </div>
            <div class="border rounded-lg overflow-hidden">
                @foreach($leftVersion as $key => $value)
                    <div class="flex border-b last:border-b-0 {{ in_array($key, collect($differences)->pluck('key')->toArray()) ? 'bg-yellow-50 dark:bg-yellow-900/20' : '' }}">
                        <div class="w-1/3 px-4 py-2 text-sm font-medium bg-zinc-50 dark:bg-zinc-800">{{ $key }}</div>
                        <div class="w-2/3 px-4 py-2 text-sm">{{ $value }}</div>
                    </div>
                @endforeach
            </div>
        </div>

        {{-- Right version --}}
        <div>
            <div class="flex items-center justify-between mb-4">
                <x-gsmui:heading level="3">Version B</x-gsmui:heading>
                <x-gsmui:badge variant="secondary">Previous</x-gsmui:badge>
            </div>
            <div class="border rounded-lg overflow-hidden">
                @foreach($rightVersion as $key => $value)
                    <div class="flex border-b last:border-b-0 {{ in_array($key, collect($differences)->pluck('key')->toArray()) ? 'bg-yellow-50 dark:bg-yellow-900/20' : '' }}">
                        <div class="w-1/3 px-4 py-2 text-sm font-medium bg-zinc-50 dark:bg-zinc-800">{{ $key }}</div>
                        <div class="w-2/3 px-4 py-2 text-sm">{{ $value }}</div>
                    </div>
                @endforeach
            </div>
        </div>
    </div>

    {{-- Differences summary --}}
    @if($differences->count())
        <div class="mt-6 p-4 bg-yellow-50 dark:bg-yellow-900/20 rounded-lg">
            <x-gsmui:heading level="4" class="text-yellow-800 dark:text-yellow-200">
                {{ $differences->count() }} differences found
            </x-gsmui:heading>
            <ul class="mt-2 space-y-1 text-sm text-yellow-700 dark:text-yellow-300">
                @foreach($differences as $diff)
                    <li>• {{ $diff->key }}: "{{ $diff->left }}" → "{{ $diff->right }}"</li>
                @endforeach
            </ul>
        </div>
    @endif
</div>
```

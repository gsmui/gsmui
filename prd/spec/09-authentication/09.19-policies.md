# 09.19 — Policies

## Purpose

Define the authorization policies for GsmUi, covering resource-level access control for all major domain objects.

## Policy Overview

Policies provide resource-specific authorization logic. Each major entity has a corresponding policy.

## Policy List

| Policy | Entity | Location |
|---|---|---|
| `UserPolicy` | User | `app/Policies/UserPolicy.php` |

| Method | Purpose |
|---|---|
| `viewAny(User $user)` | Can list all entities |
| `view(User $user, Model $model)` | Can view specific entity |
| `create(User $user)` | Can create new entity |
| `update(User $user, Model $model)` | Can update entity |
| `delete(User $user, Model $model)` | Can delete entity |
| `restore(User $user, Model $model)` | Can restore soft-deleted entity |

## Policy Best Practices

1. Always check ownership first (`$model->user_id === $user->id`)
2. Fall back to role checks for admin operations
3. Never return `true` for destructive operations without checks
4. Use policy methods for resource-level authorization
5. Use gates for global abilities
6. Keep policies focused on one entity
7. Log authorization failures

## Policy Service Layer

### Policy Evaluation Service

```php
// app/Services/PolicyEvaluationService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Auth\Access\AuthorizationException;
use Illuminate\Support\Facades\Gate;

class PolicyEvaluationService
{
    /**
     * Check if user can perform action on model.
     */
    public function check(User $user, string $action, $model = null): bool
    {
        if ($model === null) {
            return Gate::forUser($user)->allows($action);
        }

        return Gate::forUser($user)->allows($action, $model);
    }

    /**
     * Authorize action or throw exception.
     */
    public function authorize(User $user, string $action, $model = null): void
    {
        if (! $this->check($user, $action, $model)) {
            throw new AuthorizationException(
                "Unauthorized: {$action} on " . class_basename($model ?? 'resource')
            );
        }
    }

    /**
     * Get all abilities for a user on a model.
     */
    public function getAbilities(User $user, $model): array
    {
        $abilities = [
            'viewAny',
            'view',
            'create',
            'update',
            'delete',
            'restore',
            'forceDelete',
        ];

        $results = [];
        foreach ($abilities as $ability) {
            $results[$ability] = Gate::forUser($user)->allows($ability, $model);
        }

        return $results;
    }

    /**
     * Batch check multiple abilities.
     */
    public function batchCheck(User $user, array $checks): array
    {
        $results = [];

        foreach ($checks as [$action, $model]) {
            $key = $action . ':' . ($model ? get_class($model) . ':' . $model->id : 'null');
            $results[$key] = $this->check($user, $action, $model);
        }

        return $results;
    }

    /**
     * Filter models by ability.
     */
    public function filterByAbility(User $user, string $ability, $models): \Illuminate\Support\Collection
    {
        return $models->filter(fn($model) => $this->check($user, $ability, $model));
    }
}
```

### Policy Cache Service

```php
// app/Services/PolicyCacheService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\Cache;

class PolicyCacheService
{
    /**
     * Cache key prefix for policy results.
     */
    protected string $prefix = 'policy:';

    /**
     * Get a cached policy evaluation result.
     */
    public function getCachedResult(User $user, string $action, $model): ?bool
    {
        $key = $this->buildKey($user, $action, $model);

        if (! Cache::has($key)) {
            return null;
        }

        return Cache::get($key);
    }

    /**
     * Store a policy evaluation result in cache.
     */
    public function cacheResult(User $user, string $action, $model, bool $result, int $ttl = 300): void
    {
        $key = $this->buildKey($user, $action, $model);
        Cache::put($key, $result, $ttl);
    }

    /**
     * Clear cached results for a user.
     */
    public function clearUserCache(User $user): void
    {
        Cache::tags(["policy:user:{$user->id}"])->flush();
    }

    /**
     * Clear cached results for a model.
     */
    public function clearModelCache($model): void
    {
        $key = get_class($model) . ':' . $model->id;
        Cache::tags(["policy:model:{$key}"])->flush();
    }

    /**
     * Build cache key for a policy check.
     */
    protected function buildKey(User $user, string $action, $model): string
    {
        $modelKey = $model
            ? get_class($model) . ':' . $model->id
            : 'null';

        return "{$this->prefix}{$user->id}:{$action}:{$modelKey}";
    }
}
```

## Policy Registration Service

```php
// app/Services/PolicyRegistrationService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\Gate;
use ReflectionClass;
use ReflectionMethod;

class PolicyRegistrationService
{
    /**
     * Register all policies from a directory.
     */
    public function registerPoliciesFromDirectory(string $directory): void
    {
        $files = glob($directory . '/*Policy.php');

        foreach ($files as $file) {
            $className = pathinfo($file, PATHINFO_FILENAME);
            $fullClass = $this->getNamespaceFromFile($file) . '\\' . $className;

            if (class_exists($fullClass)) {
                $this->registerPolicy($fullClass);
            }
        }
    }

    /**
     * Register a single policy.
     */
    public function registerPolicy(string $policyClass): void
    {
        $reflection = new ReflectionClass($policyClass);
        $beforeMethods = [];
        $afterMethods = [];

        foreach ($reflection->getMethods(ReflectionMethod::IS_PUBLIC) as $method) {
            $attributes = $method->getAttributes(\App\Attributes\BeforePolicy::class);
            if (! empty($attributes)) {
                $beforeMethods[] = $method->getName();
            }

            $attributes = $method->getAttributes(\App\Attributes\AfterPolicy::class);
            if (! empty($attributes)) {
                $afterMethods[] = $method->getName();
            }
        }

        // Store registration data for later use
        $this->registeredPolicies[$policyClass] = [
            'before_methods' => $beforeMethods,
            'after_methods' => $afterMethods,
        ];
    }

    /**
     * Get all registered policies.
     */
    public function getRegisteredPolicies(): array
    {
        return $this->registeredPolicies ?? [];
    }

    /**
     * Extract namespace from file.
     */
    protected function getNamespaceFromFile(string $file): string
    {
        $content = file_get_contents($file);
        preg_match('/namespace\s+(.+?);/', $content, $matches);
        return $matches[1] ?? '';
    }
}
```

```php
namespace App\Policies;

use App\Models\User;
use Laravel\Sanctum\PersonalAccessToken;

class ApiTokenPolicy
{
    public function viewAny(User $user): bool
    {
        return true; // Users can see their own tokens
    }

    public function view(User $user, PersonalAccessToken $token): bool
    {
        return $token->tokenable_type === User::class
            && $token->tokenable_id === $user->id;
    }

    public function create(User $user): bool
    {
        return $user->can('api.access');
    }

    public function delete(User $user, PersonalAccessToken $token): bool
    {
        return $this->view($user, $token);
    }

    public function update(User $user, PersonalAccessToken $token): bool
    {
        return $this->view($user, $token);
    }
}
```

## Policy Quick Reference

| Pattern | Code | Description |
|---|---|---|
| Check ability | `$user->can('update', $model)` | Check single ability |
| Check with gate | `Gate::allows('update', $model)` | Gate-based check |
| Authorize | `$this->authorize('update', $model)` | Throw if denied |
| Abort unless | `abort_unless($user->can('update', $model), 403)` | Abort if denied |
| Blade check | `@can('update', $model) ... @endcan` | Conditional UI |
| Before hook | `Gate::before(fn($u) => ...)` | Global bypass |
| After hook | `Gate::after(fn($u) => ...)` | Audit logging |
| Deny response | `Gate::denied()` | Custom denial |

## Policy Best Practices

1. Always check ownership first (`$model->user_id === $user->id`)
2. Fall back to role checks for admin operations
3. Never return `true` for destructive operations without checks
4. Use policy methods for resource-level authorization
5. Use gates for global abilities
6. Keep policies focused on one entity
7. Log authorization failures for audit
8. Cache policy results for frequently checked permissions
9. Test every policy method with different user roles
10. Use `authorize()` in controllers for clean 403 responses
11. Use `@can` Blade directives for conditional UI rendering
12. Keep policy logic simple and readable
13. Document custom policy methods in the class docblock
14. Use `Gate::before()` for super_admin bypass only
15. Use `Gate::after()` for audit logging only

## Policy Middleware

### PolicyMiddleware Implementation

```php
// app/Http/Middleware/AuthorizePolicy.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class AuthorizePolicy
{
    /**
     * Handle an incoming request.
     *
     * Usage: Route::middleware('policy:ThemePolicy,update,theme')
     */
    public function handle(Request $request, Closure $next, string $policy, string $ability, ?string $param = null): Response
    {
        $model = $param ? $request->route($param) : null;

        $policyClass = "App\\Policies\\{$policy}";

        if (! class_exists($policyClass)) {
            abort(500, "Policy class not found: {$policy}");
        }

        $user = $request->user();

        if (! $user) {
            abort(401, 'Authentication required.');
        }

        $policyInstance = app($policyClass);
        $method = 'before';

        if (method_exists($policyInstance, $ability)) {
            $result = $policyInstance->{$ability}($user, ...array_values($request->route()->parameters()));
        } else {
            abort(404, "Policy method not found: {$ability}");
        }

        if ($result === false) {
            if ($request->expectsJson()) {
                return response()->json(['message' => 'Unauthorized.'], 403);
            }
            abort(403, "Unauthorized: {$ability}");
        }

        return $next($request);
    }
}
```

```php
// app/Services/AuthorizationLogger.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\DB;

class AuthorizationLogger
{
    /**
     * Log an authorization check.
     */
    public function log(
        string $action,
        User $user,
        ?object $model,
        bool $granted,
        string $reason = '',
        array $context = []
    ): void {
        DB::table('authorization_log')->insert([
            'user_id' => $user->id,
            'action' => $action,
            'model_type' => $model ? get_class($model) : null,
            'model_id' => $model?->id,
            'granted' => $granted,
            'reason' => $reason,
            'context' => json_encode($context),
            'ip_address' => request()->ip(),
            'user_agent' => request()->userAgent(),
            'created_at' => now(),
        ]);
    }

    /**
     * Get authorization log for a user.
     */
    public function getUserLog(User $user, int $limit = 100): Collection
    {
        return DB::table('authorization_log')
            ->where('user_id', $user->id)
            ->orderBy('created_at', 'desc')
            ->limit($limit)
            ->get();
    }

    /**
     * Get authorization failure rate for a user.
     */
    public function getFailureRate(User $user, int $minutes = 60): float
    {
        $total = DB::table('authorization_log')
            ->where('user_id', $user->id)
            ->where('created_at', '>=', now()->subMinutes($minutes))
            ->count();

        $failures = DB::table('authorization_log')
            ->where('user_id', $user->id)
            ->where('granted', false)
            ->where('created_at', '>=', now()->subMinutes($minutes))
            ->count();

        return $total > 0 ? round(($failures / $total) * 100, 2) : 0;
    }

    /**
     * Get top denied abilities.
     */
    public function getTopDeniedAbilities(int $limit = 10): array
    {
        return DB::table('authorization_log')
            ->where('granted', false)
            ->select('action', DB::raw('count(*) as count'))
            ->groupBy('action')
            ->orderBy('count', 'desc')
            ->limit($limit)
            ->pluck('count', 'action')
            ->toArray();
    }
}
```

## Policy Documentation

### Policy Documentation Generator

```php
// app/Services/PolicyDocumentationGenerator.php

namespace App\Services;

use ReflectionClass;
use ReflectionMethod;

class PolicyDocumentationGenerator
{
    /**
     * Generate documentation for a policy class.
     */
    public function generate(string $policyClass): array
    {
        $reflection = new ReflectionClass($policyClass);
        $methods = $reflection->getMethods(ReflectionMethod::IS_PUBLIC);

        $documentation = [
            'class' => $policyClass,
            'entity' => $this->extractEntity($policyClass),
            'methods' => [],
        ];

        foreach ($methods as $method) {
            if (str_starts_with($method->getName(), '__')) {
                continue;
            }

            $parameters = $method->getParameters();
            $docComment = $method->getDocComment();

            $documentation['methods'][] = [
                'name' => $method->getName(),
                'parameters' => array_map(fn($p) => [
                    'name' => '$' . $p->getName(),
                    'type' => $p->getType() ? $p->getType()->getName() : 'mixed',
                    'optional' => $p->isOptional(),
                    'default' => $p->isOptional() ? $p->getDefaultValue() : null,
                ], $parameters),
                'return_type' => $method->getReturnType() ? $method->getReturnType()->getName() : 'mixed',
                'description' => $this->extractDescription($docComment),
            ];
        }

        return $documentation;
    }

    /**
     * Extract entity name from policy class name.
     */
    protected function extractEntity(string $policyClass): string
    {
        $classBasename = basename(str_replace('\\', '/', $policyClass), '.php');
        return str_replace('Policy', '', $classBasename);
    }

    /**
     * Extract description from doc comment.
     */
    protected function extractDescription(?string $docComment): string
    {
        if (! $docComment) {
            return '';
        }

        preg_match('/\/\*\*\s*\n\s*\*\s*(.+?)\n/', $docComment, $matches);
        return $matches[1] ?? '';
    }

    /**
     * Generate markdown documentation for all policies.
     */
    public function generateAll(): string
    {
        $policies = glob(app_path('Policies/*Policy.php'));
        $markdown = "# Policy Documentation\n\n";

        foreach ($policies as $policy) {
            $className = pathinfo($policy, PATHINFO_FILENAME);
            $fullClass = "App\\Policies\\{$className}";
            $docs = $this->generate($fullClass);

            $markdown .= "## {$docs['entity']} Policy\n\n";
            $markdown .= "| Method | Parameters | Return |\n";
            $markdown .= "|---|---|---|\n";

            foreach ($docs['methods'] as $method) {
                $params = implode(', ', array_map(fn($p) => $p['name'], $method['parameters']));
                $markdown .= "| `{$method['name']}` | `{$params}` | `{$method['return_type']}` |\n";
            }

            $markdown .= "\n";
        }

        return $markdown;
    }
}
```

```php
// tests/Traits/PolicyTestTrait.php

namespace Tests\Traits;

use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;

trait PolicyTestTrait
{
    use RefreshDatabase;

    /**
     * Create a user with a specific role.
     */
    protected function createUserWithRole(string $roleName): User
    {
        $user = User::factory()->create();
        $user->assignRole($roleName);
        return $user->fresh();
    }

    /**
     * Create multiple users with different roles.
     */
    protected function createRoleMatrix(): array
    {
        return [
            'guest' => null,
            'user' => $this->createUserWithRole('user'),
            'pro_user' => $this->createUserWithRole('pro_user'),
            'creator' => $this->createUserWithRole('creator'),
            'moderator' => $this->createUserWithRole('moderator'),
            'support' => $this->createUserWithRole('support'),
            'editor' => $this->createUserWithRole('editor'),
            'admin' => $this->createUserWithRole('admin'),
            'super_admin' => $this->createUserWithRole('super_admin'),
        ];
    }

    /**
     * Assert that a user can perform an action.
     */
    protected function assertUserCan(User $user, string $ability, $model = null): void
    {
        $this->assertTrue(
            $user->can($ability, $model),
            "Expected user to be able to '{$ability}' but was denied."
        );
    }

    /**
     * Assert that a user cannot perform an action.
     */
    protected function assertUserCannot(User $user, string $ability, $model = null): void
    {
        $this->assertFalse(
            $user->can($ability, $model),
            "Expected user to NOT be able to '{$ability}' but was granted."
        );
    }

    /**
     * Test a policy against all roles.
     */
    protected function testPolicyAgainstRoles(
        string $ability,
        $model,
        array $allowedRoles,
        array $deniedRoles
    ): void {
        foreach ($allowedRoles as $roleName) {
            $user = $this->createUserWithRole($roleName);
            $this->assertUserCan($user, $ability, $model);
        }

        foreach ($deniedRoles as $roleName) {
            if ($roleName === 'guest') {
                $user = User::factory()->create();
                // Simulate guest behavior
                $this->assertUserCannot($user, $ability, $model);
            } else {
                $user = $this->createUserWithRole($roleName);
                $this->assertUserCannot($user, $ability, $model);
            }
        }
    }
}
```

## Policy Quick Reference

| Operation | Code | Description |
|---|---|---|
| Check ability | `$user->can('update', $model)` | Check single ability |
| Check with gate | `Gate::allows('update', $model)` | Gate-based check |
| Authorize | `$this->authorize('update', $model)` | Throw if denied |
| Abort unless | `abort_unless($user->can('update', $model), 403)` | Abort if denied |
| Blade check | `@can('update', $model) ... @endcan` | Conditional UI |
| Before hook | `Gate::before(fn($u) => ...)` | Global bypass |
| After hook | `Gate::after(fn($u) => ...)` | Audit logging |
| Deny response | `Gate::denied()` | Custom denial |
| Get abilities | `$user->abilities()` | All user abilities |
| Check any | `$user->canAny(['update', 'delete'])` | Multiple checks |
| Filter models | `$models->filter(fn($m) => $user->can('view', $m))` | Filter collection |
| Policy for | `Gate::policyFor($model)` | Get policy instance |
| Before callback | `Gate::before(fn($u) => true)` | Global bypass |
| After callback | `Gate::after(fn($u) => null)` | Audit/logging |
| Deny callback | `Gate::denied(fn() => response(...))` | Custom denial |

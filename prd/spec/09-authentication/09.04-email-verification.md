# 09.04 — Email Verification

## Purpose

Define the email verification system that ensures users own the email address they register with. Unverified users cannot log in or access any authenticated features.

## Verification Flow

```text
User registers
    ↓
Verification email sent (signed URL, 60-min expiry)
    ↓
User clicks link → /verify-email/{id}/{hash}
    ↓
Email verified → redirect to dashboard
    ↓
User is now Active
```

```php
public function __invoke(Request $request): RedirectResponse
{
    $user = User::findOrFail($request->route('id'));

    if (! URL::hasValidSignature($request)) {
```

## Security Notes

* Verification URLs are signed and time-limited (60 minutes)
* Tokens are single-use
* Old tokens are invalidated when a new one is generated
* IP address is logged with verification events
* Suspicious patterns (multiple accounts, same IP) trigger manual review

## Polling for Verification

The verification page uses Livewire polling (`wire:poll.60s`) to automatically detect when the user has verified their email, providing a seamless experience without requiring a page refresh.

## Detailed Verification Architecture

### Verification Token Generation

The verification token is generated using Laravel's signed URL mechanism:

```php
// In User model (inherits from Authenticatable)
public function getEmailVerificationUrl(): string
{
    return URL::temporarySignedRoute(
        'verification.verify',
        now()->addMinutes(60),
        [
            'id' => $this->getKey(),
            'hash' => sha1($this->getEmailForVerification()),
        ]
    );
}
```

### Token Structure

The signed URL contains:
- **id** — User's primary key
- **hash** — SHA-1 hash of the user's email
- **expires** — Timestamp when the link expires
- **signature** — HMAC signature for URL integrity

```
https://gsmui.dev/verify-email/1/abc123...?expires=1234567890&signature=xyz789...
```

### Verification Handler Implementation

```php
// app/Http/Controllers/EmailVerificationController.php

class EmailVerificationController extends Controller
{
    public function __invoke(Request $request): RedirectResponse
    {
        $user = User::findOrFail($request->route('id'));

        // Validate the signed URL
        if (! URL::hasValidSignature($request)) {
            return redirect()->route('verification.notice')
                ->withErrors([
                    'email' => 'The verification link is invalid or has expired.',
                ]);
        }

        // Check if already verified
        if ($user->hasVerifiedEmail()) {
            return redirect()->intended('/dashboard')
                ->with('status', 'Your email is already verified.');
        }

        // Mark as verified
        $user->markEmailAsVerified();

        // Dispatch verification event
        event(new Verified($user));

        return redirect()->intended('/dashboard')
            ->with('status', 'Your email has been verified successfully.');
    }
}
```

### Security Considerations

1. **Token Expiration** — 60-minute TTL prevents stale links
2. **Single-Use** — Token is invalidated after use
3. **Signed URLs** — Prevents URL tampering
4. **Rate Limiting** — Prevents email flooding
5. **IP Logging** — Audit trail for verification attempts
6. **No User Enumeration** — Generic messages for invalid requests

### Verification Service

```php
// app/Services/EmailVerificationService.php

class EmailVerificationService
{
    public function sendVerificationEmail(User $user): void
    {
        $user->sendEmailVerificationNotification();

        activity()
            ->performedOn($user)
            ->withProperties([
                'ip' => request()->ip(),
            ])
            ->log('verification.email_sent');
    }

    public function verifyEmail(User $user): void
    {
        $user->markEmailAsVerified();

        event(new Verified($user));

        activity()
            ->performedOn($user)
            ->withProperties([
                'ip' => request()->ip(),
            ])
            ->log('verification.email_verified');
    }

    public function isVerificationRateLimited(User $user): bool
    {
        return RateLimiter::tooManyAttempts(
            'email-verification:' . $user->id,
            3
        );
    }

    public function getVerificationRateLimitTimeRemaining(User $user): int
    {
        return RateLimiter::availableIn('email-verification:' . $user->id);
    }
}
```

```php
// app/Http/Middleware/EnsureEmailIsVerified.php

class EnsureEmailIsVerified
{
    public function handle(Request $request, Closure $next, string $redirectToRoute = null)
    {
        if ($request->user() &&
            ! $request->user()->hasVerifiedEmail() &&
            ! $request->expectsJson()) {
            return $request->expectsJson()
                ? response()->json(['message' => 'Your email address is not verified.'], 403)
                : redirect()->route($redirectToRoute ?: 'verification.notice');
        }

        return $next($request);
    }
}
```

```php
// app/Jobs/SendVerificationEmailJob.php

class SendVerificationEmailJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        public User $user,
    ) {}

    public function handle(): void
    {
        $verificationUrl = URL::temporarySignedRoute(
            'verification.verify',
            now()->addMinutes(60),
            [
                'id' => $this->user->id,
                'hash' => sha1($this->user->email),
            ]
        );

        Mail::to($this->user->email)
            ->queue(new VerifyEmail($this->user, $verificationUrl));
    }
}
```

### Verification Queue Processing

```php
// app/Jobs/SendVerificationEmailJob.php

class SendVerificationEmailJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public int $tries = 3;
    public int $timeout = 30;
    public string $queue = 'emails';

    public function __construct(
        public User $user,
    ) {}

    public function handle(): void
    {
        $verificationUrl = URL::temporarySignedRoute(
            'verification.verify',
            now()->addMinutes(60),
            [
                'id' => $this->user->id,
                'hash' => sha1($this->user->email),
            ]
        );

        Mail::to($this->user->email)
            ->queue(new VerifyEmail($this->user, $verificationUrl));
    }

    public function failed(\Throwable $exception): void
    {
        Log::error('Verification email failed for user: ' . $this->user->id, [
            'exception' => $exception,
        ]);
    }
}
```

### Verification Livewire Component

```php
// app/Livewire/Auth/EmailVerificationPrompt.php

namespace App\Livewire\Auth;

use App\Models\User;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\RateLimiter;
use Livewire\Component;

class EmailVerificationPrompt extends Component
{
    public bool $isVerified = false;
    public bool $isResending = false;
    public string $status = '';
    public int $resendCooldown = 0;

    protected $listeners = [
        'email-verified' => 'handleEmailVerified',
    ];

    public function mount(): void
    {
        $this->isVerified = Auth::user()?->hasVerifiedEmail() ?? false;
    }

    public function poll(): void
    {
        $user = Auth::user();

        if ($user && ! $this->isVerified) {
            $this->isVerified = $user->fresh()->hasVerifiedEmail();

            if ($this->isVerified) {
                $this->dispatch('email-verified');
            }
        }
    }

    public function resend(): void
    {
        $user = Auth::user();

        if (! $user) {
            return;
        }

        $throttleKey = 'verification-email:' . $user->id;

        if (RateLimiter::tooManyAttempts($throttleKey, 1)) {
            $this->resendCooldown = RateLimiter::availableIn($throttleKey);
            $this->status = 'rate_limited';
            return;
        }

        $this->isResending = true;

        try {
            if ($user->hasVerifiedEmail()) {
                $this->status = 'already_verified';
                return;
            }

            $user->sendEmailVerificationNotification();

            RateLimiter::hit($throttleKey, 60);

            $this->status = 'email_sent';

            activity()
                ->performedOn($user)
                ->event('verification_email_resent')
                ->withProperties([
                    'ip' => request()->ip(),
                ])
                ->log('Verification email resent');
        } catch (\Exception $e) {
            $this->status = 'error';
        } finally {
            $this->isResending = false;
        }
    }

    public function handleEmailVerified(): void
    {
        $this->isVerified = true;
    }

    public function render()
    {
        return view('livewire.auth.email-verification-prompt');
    }
}
```

### Verification Livewire Component

```php
// app/Livewire/Auth/EmailVerificationPrompt.php

namespace App\Livewire\Auth;

use App\Models\User;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\RateLimiter;
use Livewire\Component;

class EmailVerificationPrompt extends Component
{
    public bool $isVerified = false;
    public bool $isResending = false;
    public string $status = '';
    public int $resendCooldown = 0;

    protected $listeners = [
        'email-verified' => 'handleEmailVerified',
    ];

    public function mount(): void
    {
        $this->isVerified = Auth::user()?->hasVerifiedEmail() ?? false;
    }

    public function poll(): void
    {
        $user = Auth::user();

        if ($user && ! $this->isVerified) {
            $this->isVerified = $user->fresh()->hasVerifiedEmail();

            if ($this->isVerified) {
                $this->dispatch('email-verified');
            }
        }
    }

    public function resend(): void
    {
        $user = Auth::user();

        if (! $user) {
            return;
        }

        $throttleKey = 'verification-email:' . $user->id;

        if (RateLimiter::tooManyAttempts($throttleKey, 1)) {
            $this->resendCooldown = RateLimiter::availableIn($throttleKey);
            $this->status = 'rate_limited';
            return;
        }

        $this->isResending = true;

        try {
            if ($user->hasVerifiedEmail()) {
                $this->status = 'already_verified';
                return;
            }

            $user->sendEmailVerificationNotification();

            RateLimiter::hit($throttleKey, 60);

            $this->status = 'email_sent';

            activity()
                ->performedOn($user)
                ->event('verification_email_resent')
                ->withProperties([
                    'ip' => request()->ip(),
                ])
                ->log('Verification email resent');
        } catch (\Exception $e) {
            $this->status = 'error';
        } finally {
            $this->isResending = false;
        }
    }

    public function handleEmailVerified(): void
    {
        $this->isVerified = true;
    }

    public function render()
    {
        return view('livewire.auth.email-verification-prompt');
    }
}
```

### Verification Job Retry Strategy

```php
// app/Jobs/SendVerificationEmailJob.php

class SendVerificationEmailJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public $tries = 3;
    public $timeout = 30;
    public $backoff = [60, 300, 900]; // 1min, 5min, 15min
    public $queue = 'emails';

    public function __construct(
        public User $user,
    ) {}

    public function handle(): void
    {
        $verificationUrl = URL::temporarySignedRoute(
            'verification.verify',
            now()->addMinutes(60),
            [
                'id' => $this->user->id,
                'hash' => sha1($this->user->email),
            ]
        );

        Mail::to($this->user->email)
            ->queue(new VerifyEmail($this->user, $verificationUrl));
    }

    public function failed(\Throwable $exception): void
    {
        Log::error('Verification email failed for user: ' . $this->user->id, [
            'exception' => $exception,
            'attempt' => $this->attempts(),
        ]);

        // Notify admin after all retries exhausted
        if ($this->attempts() >= $this->tries) {
            Notification::route('mail', config('admin.email'))
                ->notify(new VerificationEmailFailedNotification($this->user, $exception));
        }
    }
}
```

```php
// app/Services/VerificationMonitoringService.php

class VerificationMonitoringService
{
    public function getVerificationRate(int $days = 30): float
    {
        $total = User::where('created_at', '>=', now()->subDays($days))->count();
        $verified = User::where('created_at', '>=', now()->subDays($days))
            ->whereNotNull('email_verified_at')
            ->count();

        return $total > 0 ? round(($verified / $total) * 100, 2) : 0;
    }

    public function getAverageTimeToVerify(int $days = 30): float
    {
        return User::whereNotNull('email_verified_at')
            ->where('email_verified_at', '>=', now()->subDays($days))
            ->whereNotNull('created_at')
            ->avg(DB::raw('TIMESTAMPDIFF(MINUTE, created_at, email_verified_at)')) ?? 0;
    }

    public function getPendingVerificationsCount(): int
    {
        return User::whereNull('email_verified_at')
            ->where('created_at', '>=', now()->subDays(7))
            ->count();
    }

    public function getResendRate(int $days = 30): float
    {
        $requests = DB::table('activity_log')
            ->where('log_name', 'verification')
            ->where('event', 'verification_email_resent')
            ->where('created_at', '>=', now()->subDays($days))
            ->count();

        $total = User::where('created_at', '>=', now()->subDays($days))->count();

        return $total > 0 ? round(($requests / $total) * 100, 2) : 0;
    }

    public function getExpiredTokenRate(int $days = 30): float
    {
        $expired = DB::table('activity_log')
            ->where('log_name', 'verification')
            ->where('event', 'verification_expired')
            ->where('created_at', '>=', now()->subDays($days))
            ->count();

        $total = DB::table('activity_log')
            ->where('log_name', 'verification')
            ->whereIn('event', ['verification_verified', 'verification_expired'])
            ->where('created_at', '>=', now()->subDays($days))
            ->count();

        return $total > 0 ? round(($expired / $total) * 100, 2) : 0;
    }
}
```

### Verification Troubleshooting Guide

| Issue | Symptoms | Root Cause | Resolution |
|---|---|---|---|
| User never receives email | No email in inbox/spam | Email provider blocking | Check Mailgun/SES logs, verify domain reputation |
| Link shows "expired" immediately | Clicking link shows expired | Server time mismatch | Sync server time with NTP |
| "Invalid link" on valid link | Valid link rejected | URL encoding issue | Check nginx/apache proxy config |
| Verification not detected | Polling doesn't redirect | Session driver issue | Ensure session persists across requests |
| Rate limited incorrectly | Can't resend after 1 min | Redis connection issue | Check Redis connectivity |
| Multiple verifications | User clicks link multiple times | No idempotency | Add token consumed flag |
| Email goes to spam | Low delivery rate | Poor sender reputation | Warm up IP, setup DMARC/SPF/DKIM |
| Verification loop | Redirects back to verify page | Middleware order | Ensure 'verified' middleware runs after auth |

### Verification Security Hardening

```php
// app/Http/Middleware/VerifyEmailVerification.php

class VerifyEmailVerification
{
    public function handle(Request $request, Closure $next)
    {
        // Prevent user enumeration
        $user = User::where('email', $request->input('email'))->first();

        if (! $user) {
            // Always return success-like response
            return $next($request);
        }

        // Check if email is already verified
        if ($user->hasVerifiedEmail()) {
            return redirect()->intended('/dashboard')
                ->with('status', 'Your email is already verified.');
        }

        // Check verification token validity
        if ($request->hasValidSignature()) {
            // Check if token is for this user
            $tokenUser = User::find($request->route('id'));

            if (! $tokenUser || $tokenUser->email !== $request->input('email')) {
                return redirect()->route('verification.notice')
                    ->withErrors(['email' => 'Invalid verification link.']);
            }

            // Verify and mark as verified
            if (! $tokenUser->hasVerifiedEmail()) {
                $tokenUser->markEmailAsVerified();
                event(new Verified($tokenUser));
            }

            return redirect()->intended('/dashboard')
                ->with('status', 'Your email has been verified successfully.');
        }

        return redirect()->route('verification.notice')
            ->withErrors(['email' => 'The verification link is invalid or has expired.']);
    }
}
```

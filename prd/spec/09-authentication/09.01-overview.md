# 09.01 — Authentication Overview

## Purpose

This document defines the **complete Identity & Access Management (IAM)** architecture for GsmUi. Authentication is not a feature — it is the foundation of every interaction on the platform. Every request, every API call, every marketplace transaction, and every admin action flows through this system.

## Scope

GsmUi's authentication system must serve:

* Public visitors (registration, browsing)
* Registered users (dashboard, purchases, settings)
* Creators (theme/component publishing, revenue)
* API consumers (Sanctum tokens, MCP)
* Admins (user management, platform operations)
* Enterprise users (SSO, team accounts)
* CLI tools (token-based authentication)

## Identity Stack

| Layer | Technology | Purpose |
|---|---|---|
| Authentication | Laravel Fortify | Web login, registration, password reset |
| API Authentication | Laravel Sanctum | Token-based API access |
| Authorization | Laravel Policies | Resource-level access control |

## Security Principles

1. **Never store plain-text passwords.** Argon2id only.
2. **All sessions are Redis-backed** for instant revocation.
3. **Rate limiting on all auth endpoints** — login, registration, password reset.
4. **Email verification required** before any authenticated action.
5. **Password confirmation** required for sensitive operations (email change, 2FA setup, API token creation).
6. **Audit log every security-relevant event** — login, logout, password change, role change.
7. **CSRF protection** on all state-changing requests.
8. **Secure cookie flags** — HttpOnly, Secure, SameSite=Lax.

## Detailed Security Architecture

### Threat Model

GsmUi's authentication system must defend against the following attack vectors:

| Threat | Mitigation | Priority |
|---|---|---|
| Brute force login | Rate limiting + account lockout | Critical |
| Credential stuffing | Rate limiting + breach detection | Critical |
| Session hijacking | Secure cookies + session fixation prevention | Critical |
| CSRF attacks | CSRF tokens on all state-changing requests | Critical |
| XSS attacks | Content Security Policy + output encoding | High |
| Timing attacks | Constant-time hash comparisons | High |
| Email enumeration | Generic error messages | High |
| Password spraying | Per-account rate limiting | High |
| Man-in-the-middle | HTTPS enforcement + HSTS | High |
| Replay attacks | Nonce + timestamp validation | Medium |
| Token leakage | Short-lived tokens + secure storage | Medium |
| SQL injection | Parameterized queries + Eloquent ORM | Critical |

### Argon2id Configuration Deep Dive

Argon2id is the recommended hashing algorithm for GsmUi because it provides:

1. **Memory-hardness** — requires large amounts of memory, making GPU/ASIC attacks expensive
2. **Time-hardness** — configurable iteration count
3. **Side-channel resistance** — hybrid of Argon2i and Argon2d

```php
// Recommended Argon2id parameters
'MEMORY_COST' => 65536, // 64 MB
'TIME_COST' => 4,       // 4 iterations
'THREADS' => 3,         // 3 parallel threads
```

Performance considerations:
- On a standard server, hashing should take 100-300ms
- If hashing is too fast, increase memory cost
- If hashing is too slow, decrease time cost
- Benchmark on production hardware before deploying

### Session Management Deep Dive

Redis-backed sessions provide:

1. **Instant revocation** — delete key from Redis
2. **Expiration** — automatic TTL-based cleanup
3. **Atomic operations** — no race conditions
4. **Clustering support** — horizontal scaling

```php
// Redis session configuration
'redis' => [
    'connection' => 'session',
    'lock_table' => 'session_locks',
    'lottery' => [2, 100],
    'prefix' => 'gsmui_session:',
],
```

Session data structure in Redis:
```
gsmui_session:{session_id} → {
    "login_web": {user_id},
    "two_factor_verified": true,
    "password_confirmed_at": timestamp,
    "_token": csrf_token
}
```

### Rate Limiting Strategy

Rate limiting is applied at multiple levels:

#### Global Rate Limits
- 100 requests per minute per IP (all endpoints)
- 1000 requests per hour per authenticated user

#### Authentication-Specific Limits
- Login: 5 attempts per IP per minute
- Login: 5 attempts per email per minute
- Registration: 5 per IP per hour
- Password reset: 1 per email per minute
- Email verification resend: 1 per minute

#### Implementation

```php
// app/Providers/RouteServiceProvider.php

public function boot(): void
{
    RateLimiter::for('api', function (Request $request) {
        return Limit::perMinute(60)->by($request->user()?->id ?: $request->ip());
    });

    RateLimiter::for('login', function (Request $request) {
        return [
            Limit::perMinute(5)->by($request->ip()),
            Limit::perMinute(5)->by($request->input('email')),
        ];
    });

    RateLimiter::for('registration', function (Request $request) {
        return Limit::perHour(5)->by($request->ip());
    });

    RateLimiter::for('password-reset', function (Request $request) {
        return Limit::perMinute(1)->by($request->input('email'));
    });
}
```

### Input Validation Strategy

All authentication inputs are validated at multiple layers:

1. **Client-side** — Livewire real-time validation (UX)
2. **Server-side** — Fortify actions (security)
3. **Database** — Column constraints (data integrity)

```php
// Validation rules for login
'email' => ['required', 'email', 'max:255'],
'password' => ['required', 'string', 'min:1', 'max:255'],

// Validation rules for registration
'name' => ['required', 'string', 'max:255'],
'email' => ['required', 'string', 'email', 'max:255', 'unique:users'],
'password' => ['required', 'string', 'min:8', 'confirmed'],
'terms' => ['required', 'accepted'],
```

### Password Storage Rules

1. **Never** log plain-text passwords
2. **Never** store plain-text passwords
3. **Never** return plain-text passwords in API responses
4. **Never** include passwords in error messages
5. **Always** use Argon2id for hashing
6. **Always** use `Hash::make()` for hashing
7. **Always** use `Hash::check()` for verification
8. **Always** hash before database storage

### API Authentication Architecture

Sanctum provides two authentication methods:

#### SPA Authentication
- Cookie-based authentication
- Session stored in Redis
- CSRF protection enabled
- Same-site cookie policy enforced

#### Token Authentication
- Bearer token in Authorization header
- Token stored in `personal_access_tokens` table
- Scoped permissions per token
- Revocable via API or admin panel

```php
// Token creation
$token = $user->createToken('API Token', ['read:themes', 'write:themes']);

// Token usage
$token->plainTextToken; // "1|abc123..."

// API request
Authorization: Bearer 1|abc123...
```

// app/Services/AuthenticationService.php

class AuthenticationService
{
    public function __construct(
        protected SessionService $sessionService,
        protected TokenService $tokenService,
        protected ActivityService $activityService,
    ) {}

    public function login(Request $request, User $user, bool $remember = false): void
    {
        Auth::login($user, $remember);
        $request->session()->regenerate();

        $this->sessionService->storeMetadata($request, $user);
        $this->activityService->log('auth.login', $user, [
            'ip' => $request->ip(),
            'user_agent' => $request->userAgent(),
            'remember' => $remember,
        ]);
    }

    public function logout(Request $request): void
    {
        $user = $request->user();
        $sessionId = $request->session()->getId();

        Auth::logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();

        $this->activityService->log('auth.logout', $user, [
            'session_id' => $sessionId,
        ]);
    }

    public function register(array $data): User
    {
        $user = User::create([
            'name' => $data['name'],
            'email' => $data['email'],
            'password' => Hash::make($data['password']),
            'username' => $data['username'] ?? null,
        ]);

        $user->assignRole('user');
        event(new UserRegistered($user));

        return $user;
    }

    public function verifyEmail(User $user): void
    {
        $user->markEmailAsVerified();
        event(new EmailVerified($user));
    }

    public function requestPasswordReset(string $email): void
    {
        $status = Password::sendResetLink(['email' => $email]);
        if ($status !== Password::RESET_LINK_SENT) {
            throw new \Exception('Failed to send reset link.');
        }
    }

    public function resetPassword(array $data): void
    {
        $status = Password::reset($data, function (User $user, string $password) {
            $user->forceFill([
                'password' => Hash::make($password),
                'remember_token' => Str::random(60),
            ])->save();

            event(new PasswordReset($user));
        });

        if ($status !== Password::PASSWORD_RESET) {
            throw new \Exception('Failed to reset password.');
        }
    }
}

    {
        if (preg_match('/windows/i', $userAgent)) {

        }

            return 'macOS';
        }
        if (preg_match('/linux/i', $userAgent)) {
            return 'Linux';
        }
        if (preg_match('/android/i', $userAgent)) {
            return 'Android';
        }
        if (preg_match('/iphone|ipad/i', $userAgent)) {
            return 'iOS';
        }
        return 'Unknown';
    }

    public static function getCountryFromIp(string $ip): ?string
    {
        try {
            $reader = new \GeoIp2\Database\Reader(storage_path('app/geoip2/GeoLite2-Country.mmdb'));
            $record = $reader->country($ip);
            return $record->country->isoCode;
        } catch (\Exception $e) {
            return null;
        }
    }

    public static function getCityFromIp(string $ip): ?string
    {
        try {
            $reader = new \GeoIp2\Database\Reader(storage_path('app/geoip2/GeoLite2-City.mmdb'));
            $record = $reader->city($ip);
            return $record->city->name;
        } catch (\Exception $e) {
            return null;
        }
    }

    public static function isSuspiciousLogin(User $user, string $ip): bool
    {
        $recentLogins = $user->loginHistory()
            ->where('created_at', '>', now()->subDays(7))
            ->where('successful', true)
            ->get();

        if ($recentLogins->isEmpty()) {
            return false;
        }

        $countries = $recentLogins->pluck('country')->unique();
        $currentCountry = self::getCountryFromIp($ip);

        if ($currentCountry && ! $countries->contains($currentCountry)) {
            return true;
        }

        return false;
    }

    public static function getMaxConcurrentSessions(): int
    {
        return config('auth.max_concurrent_sessions', 10);
    }

    public static function enforceConcurrentSessionLimit(User $user): void
    {
        $sessionCount = $user->sessions()->count();

        if ($sessionCount > self::getMaxConcurrentSessions()) {
            $oldestSessions = $user->sessions()
                ->orderBy('last_activity', 'asc')
                ->limit($sessionCount - self::getMaxConcurrentSessions())
                ->get();

            foreach ($oldestSessions as $session) {
                $session->delete();
            }
        }
    }

## Authentication Service Layer

```php
// app/Services/AuthenticationService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Hash;
use Illuminate\Validation\ValidationException;

class AuthenticationService
{
    public function attemptLogin(string $email, string $password, bool $remember = false): bool
    {
        $user = User::where('email', $email)->first();

        if (! $user || ! Hash::check($password, $user->password)) {
            return false;
        }

        if (! $user->hasVerifiedEmail()) {
            throw ValidationException::withMessages([
                'email' => 'Please verify your email address before signing in.',
            ]);
        }

        if ($user->isSuspended()) {
            throw ValidationException::withMessages([
                'email' => 'Your account has been suspended. Please contact support.',
            ]);
        }

        if ($user->isDeactivated()) {
            throw ValidationException::withMessages([
                'email' => 'Your account has been deactivated.',
            ]);
        }

        Auth::login($user, $remember);

        $user->update([
            'last_login_at' => now(),
            'last_login_ip' => request()->ip(),
        ]);

        return true;
    }

    public function register(array $data): User
    {
        $user = User::create([
            'name' => $data['name'],
            'email' => $data['email'],
            'password' => Hash::make($data['password']),
            'email_verified_at' => null,
            'status' => 'pending',
        ]);

        $user->assignRole('user');

        $user->settings()->create([
            'theme' => 'system',
            'locale' => app()->getLocale(),
            'timezone' => config('app.timezone'),
        ]);

        return $user;
    }

    public function logout(): void
    {
        Auth::logout();
        request()->session()->invalidate();
        request()->session()->regenerateToken();
    }
}
```

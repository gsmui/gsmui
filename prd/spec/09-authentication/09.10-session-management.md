# 09.10 — Session Management

## Purpose

Define the session management system for GsmUi, including creation, storage, revocation, multi-device tracking, and security.

## Session Architecture

| Component | Technology |
|---|---|
| Storage | Redis |
| Driver | `redis` |
| Lifetime (default) | 120 minutes |
| Lifetime (remember me) | 30 days |
| Cookie | HTTP-only, Secure, SameSite=Lax |
| Encryption | Yes (APP_KEY) |

## Session Lifecycle

```text
Login
    ↓
Session created (Redis)
    ↓
Cookie set (HTTP-only, Secure)
    ↓
Activity extends session (rolling)
    ↓
Logout / Timeout / Revocation
    ↓
Session deleted from Redis
    ↓
Cookie invalidated
```

## Multi-Device Sessions

Each login creates a separate session. Users can view and revoke sessions.

## Session Revocation

```php
// Revoke single session
Auth::user()->sessions()
    ->where('id', $sessionId)
    ->delete();

// Revoke all sessions except current
Auth::user()->sessions()
    ->where('id', '!=', session()->getId())
    ->delete();

// Revoke all sessions (force logout everywhere)
Auth::user()->sessions()->delete();
```

## Session Events

| Event | Triggered When |
|---|---|
| `Login` | Successful login |
| `Logout` | User logs out |
| `FailedLogin` | Invalid credentials |
| `PasswordReset` | Password changed/reset |
| `OtherDeviceLogout` | Session revoked from another device |

## Security Features

| Feature | Implementation |
|---|---|
| Session fixation prevention | Regenerate session ID on login |
| Session hijacking | Secure cookie flags, IP validation |
| Concurrent sessions | Allow multiple, show in UI |
| Session timeout | 120 minutes inactive |
| Remember me | 30-day persistent cookie |
| Force logout | Revoke all sessions on password change |
| Activity tracking | Last activity timestamp in Redis |
| User agent logging | Store for session management UI |

## Redis Session Structure

```text
gsmui_session:{session_id}
    → serialized session data
    → TTL: 7200 seconds (120 minutes)

gsmui_user_sessions:{user_id}
    → Set of active session IDs
```

## Cleanup Jobs

| Job | Frequency | Purpose |
|---|---|---|
| `GarbageCollectSessions` | Daily | Remove expired sessions from Redis |
| `CleanupOldSessions` | Weekly | Remove sessions older than 30 days |

## Security Notes

* Sessions encrypted with APP_KEY
* Cookie flags: HttpOnly, Secure, SameSite=Lax
* Session ID regenerated on login (prevents fixation)
* IP address logged with each session
* User agent logged for device identification
* Last activity tracked for timeout
* Password change revokes all other sessions
* Account deactivation revokes all sessions
* Account suspension revokes all sessions

## Session Manager Service

```php
// app/Services/SessionManager.php

namespace App\Services;

use App\Models\User;
use App\Models\UserSession;
use Illuminate\Support\Collection;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Redis;

class SessionManager
{
    /**
     * Get all active sessions for a user.
     */
    public function getActiveSessions(User $user): Collection
    {
        $sessions = DB::table('sessions')
            ->where('user_id', $user->id)
            ->get();

        $currentSessionId = session()->getId();

        return $sessions->map(function ($session) use ($currentSessionId) {
            $data = unserialize($session->payload);

            return new UserSession([
                'id' => $session->id,
                'ip_address' => $session->ip_address,
                'user_agent' => $session->user_agent,
                'last_activity' => now()->subSeconds(
                    time() - $session->last_activity
                ),
                'is_current' => $session->id === $currentSessionId,
                'device_type' => $this->parseDeviceType($session->user_agent),
                'browser' => $this->parseBrowser($session->user_agent),
                'os' => $this->parseOS($session->user_agent),
                'location' => $this->getGeoLocation($session->ip_address),
            ]);
        });
    }

    /**
     * Get current session.
     */
    public function getCurrentSession(User $user): ?UserSession
    {
        return $this->getActiveSessions($user)
            ->firstWhere('is_current', true);
    }

    /**
     * Revoke a specific session.
     */
    public function revokeSession(User $user, string $sessionId): bool
    {
        $deleted = DB::table('sessions')
            ->where('user_id', $user->id)
            ->where('id', $sessionId)
            ->delete();

        if ($deleted) {
            event(new SessionRevoked($user, $sessionId));
        }

        return (bool) $deleted;
    }

    /**
     * Revoke all sessions except the current one.
     */
    public function revokeAllOtherSessions(User $user): int
    {
        $currentSessionId = session()->getId();

        $deleted = DB::table('sessions')
            ->where('user_id', $user->id)
            ->where('id', '!=', $currentSessionId)
            ->delete();

        if ($deleted > 0) {
            event(new AllOtherSessionsRevoked($user, $deleted));
        }

        return $deleted;
    }

    /**
     * Revoke all sessions for a user (force logout everywhere).
     */
    public function revokeAllSessions(User $user): int
    {
        $deleted = DB::table('sessions')
            ->where('user_id', $user->id)
            ->delete();

        event(new AllSessionsRevoked($user, $deleted));

        return $deleted;
    }

    /**
     * Revoke sessions older than a given number of days.
     */
    public function revokeStaleSessions(User $user, int $days = 30): int
    {
        $cutoff = now()->subDays($days)->timestamp;

        $deleted = DB::table('sessions')
            ->where('user_id', $user->id)
            ->where('last_activity', '<', $cutoff)
            ->delete();

        if ($deleted > 0) {
            event(new StaleSessionsRevoked($user, $deleted, $days));
        }

        return $deleted;
    }

    /**
     * Check if a session is still valid.
     */
    public function isSessionValid(string $sessionId): bool
    {
        return DB::table('sessions')
            ->where('id', $sessionId)
            ->where('last_activity', '>', now()->subMinutes(config('session.lifetime'))->timestamp)
            ->exists();
    }

    /**
     * Get session count for a user.
     */
    public function getSessionCount(User $user): int
    {
        return DB::table('sessions')
            ->where('user_id', $user->id)
            ->count();
    }

    /**
     * Get session activity summary.
     */
    public function getSessionActivitySummary(User $user): array
    {
        $sessions = $this->getActiveSessions($user);

        return [
            'total' => $sessions->count(),
            'current' => $sessions->where('is_current', true)->count(),
            'other' => $sessions->where('is_current', false)->count(),
            'devices' => $sessions->pluck('device_type')->unique()->count(),
            'browsers' => $sessions->pluck('browser')->unique()->count(),
            'ips' => $sessions->pluck('ip_address')->unique()->count(),
            'last_activity' => $sessions->max('last_activity'),
            'oldest_session' => $sessions->min('last_activity'),
        ];
    }

    /**
     * Parse device type from user agent string.
     */
    protected function parseDeviceType(string $userAgent): string
    {
        $agent = strtolower($userAgent);

        if (str_contains($agent, 'mobile') || str_contains($agent, 'android')) {
            return 'mobile';
        }

        if (str_contains($agent, 'tablet') || str_contains($agent, 'ipad')) {
            return 'tablet';
        }

        return 'desktop';
    }

    /**
     * Parse browser from user agent string.
     */
    protected function parseBrowser(string $userAgent): string
    {
        $agent = strtolower($userAgent);

        if (str_contains($agent, 'chrome') && ! str_contains($agent, 'edg')) {
            return 'Chrome';
        }
        if (str_contains($agent, 'firefox')) {
            return 'Firefox';
        }
        if (str_contains($agent, 'safari') && ! str_contains($agent, 'chrome')) {
            return 'Safari';
        }
        if (str_contains($agent, 'edg')) {
            return 'Edge';
        }
        if (str_contains($agent, 'opera') || str_contains($agent, 'opr')) {
            return 'Opera';
        }

        return 'Unknown';
    }

    /**
     * Parse operating system from user agent string.
     */
    protected function parseOS(string $userAgent): string
    {
        $agent = strtolower($userAgent);

        if (str_contains($agent, 'windows')) {
            return 'Windows';
        }
        if (str_contains($agent, 'mac os') || str_contains($agent, 'macos')) {
            return 'macOS';
        }
        if (str_contains($agent, 'linux')) {
            return 'Linux';
        }
        if (str_contains($agent, 'android')) {
            return 'Android';
        }
        if (str_contains($agent, 'iphone') || str_contains($agent, 'ipad')) {
            return 'iOS';
        }

        return 'Unknown';
    }

    /**
     * Get geo-location from IP address.
     */
    protected function getGeoLocation(string $ip): ?array
    {
        if (config('session.track_location', false)) {
            // Integration with geo-IP service
            return null;
        }

        return null;
    }
}
```

## User Session Model

```php
// app/Models/UserSession.php

namespace App\Models;

use Carbon\Carbon;
use Illuminate\Support\Facades\Request;

class UserSession
{
    public function __construct(
        public string $id,
        public string $ipAddress,
        public string $userAgent,
        public Carbon $lastActivity,
        public bool $isCurrent,
        public string $deviceType = 'desktop',
        public string $browser = 'Unknown',
        public string $os = 'Unknown',
        public ?array $location = null,
    ) {}

    public function toArray(): array
    {
        return [
            'id' => $this->id,
            'ip_address' => $this->ipAddress,
            'user_agent' => $this->userAgent,
            'last_activity' => $this->lastActivity->toISOString(),
            'is_current' => $this->isCurrent,
            'device_type' => $this->deviceType,
            'browser' => $this->browser,
            'os' => $this->os,
            'location' => $this->location,
        ];
    }

    public function getDeviceIcon(): string
    {
        return match($this->deviceType) {
            'mobile' => 'heroicon-o-device-phone-mobile',
            'tablet' => 'heroicon-o-device-tablet',
            default => 'heroicon-o-computer-desktop',
        };
    }

    public function getBrowserIcon(): string
    {
        return match($this->browser) {
            'Chrome' => 'heroicon-o-globe-alt',
            'Firefox' => 'heroicon-o-globe-alt',
            'Safari' => 'heroicon-o-globe-alt',
            'Edge' => 'heroicon-o-globe-alt',
            'Opera' => 'heroicon-o-globe-alt',
            default => 'heroicon-o-globe-alt',
        };
    }

    public function getFormattedLastActivity(): string
    {
        if ($this->lastActivity->diffInMinutes(now()) < 1) {
            return 'Active now';
        }

        if ($this->lastActivity->diffInMinutes(now()) < 60) {
            return $this->lastActivity->diffForHumans();
        }

        if ($this->lastActivity->isToday()) {
            return 'Today at ' . $this->lastActivity->format('g:i A');
        }

        if ($this->lastActivity->isYesterday()) {
            return 'Yesterday at ' . $this->lastActivity->format('g:i A');
        }

        return $this->lastActivity->format('M j, Y g:i A');
    }

    public function getLocationDisplay(): ?string
    {
        if (! $this->location) {
            return null;
        }

        return implode(', ', array_filter([
            $this->location['city'] ?? null,
            $this->location['region'] ?? null,
            $this->location['country'] ?? null,
        ]));
    }
}
```

### Session Management Livewire Component

```php
// app/Livewire/Settings/SessionManagement.php

namespace App\Livewire\Settings;

use App\Services\SessionManager;
use Illuminate\Support\Facades\Auth;
use Livewire\Component;

class SessionManagement extends Component
{
    public ?string $selectedSessionId = null;
    public bool $showRevokeAllModal = false;
    public bool $showRevokeModal = false;
    public array $sessions = [];
    public array $activitySummary = [];

    protected SessionManager $sessionManager;

    public function boot(): void
    {
        $this->sessionManager = app(SessionManager::class);
    }

    public function mount(): void
    {
        $this->loadSessions();
    }

    public function loadSessions(): void
    {
        $user = Auth::user();
        $this->sessions = $this->sessionManager->getActiveSessions($user)
            ->toArray();
        $this->activitySummary = $this->sessionManager->getSessionActivitySummary($user);
    }

    public function revokeSession(string $sessionId): void
    {
        $user = Auth::user();

        $this->sessionManager->revokeSession($user, $sessionId);

        $this->loadSessions();

        session()->flash('status', 'Session revoked successfully.');
    }

    public function revokeAllOtherSessions(): void
    {
        $user = Auth::user();

        $revokedCount = $this->sessionManager->revokeAllOtherSessions($user);

        $this->showRevokeAllModal = false;
        $this->loadSessions();

        session()->flash('status', "{$revokedCount} session(s) revoked successfully.");
    }

    public function revokeAllSessions(): void
    {
        $user = Auth::user();

        $this->sessionManager->revokeAllSessions($user);

        $this->showRevokeAllModal = false;

        // Redirect to login since all sessions are revoked
        return redirect()->route('login')
            ->with('status', 'All sessions have been revoked. Please log in again.');
    }

    public function confirmRevokeSession(string $sessionId): void
    {
        $this->selectedSessionId = $sessionId;
        $this->showRevokeModal = true;
    }

    public function confirmRevokeAll(): void
    {
        $this->showRevokeAllModal = true;
    }

    public function cancelRevoke(): void
    {
        $this->selectedSessionId = null;
        $this->showRevokeModal = false;
        $this->showRevokeAllModal = false;
    }

    public function getDeviceIcon(string $deviceType): string
    {
        return match($deviceType) {
            'mobile' => 'heroicon-o-device-phone-mobile',
            'tablet' => 'heroicon-o-device-tablet',
            default => 'heroicon-o-computer-desktop',
        };
    }

    public function render(): \Illuminate\View\View
    {
        return view('livewire.settings.session-management');
    }
}
```

```php
// app/Http/Middleware/DetectSessionHijacking.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class DetectSessionHijacking
{
    public function handle(Request $request, Closure $next)
    {
        $currentIp = $request->ip();
        $currentUserAgent = $request->userAgent();

        $sessionIp = session('ip_address');
        $sessionUserAgent = session('user_agent');

        if ($sessionIp && $sessionUserAgent) {
            if ($currentIp !== $sessionIp || $currentUserAgent !== $sessionUserAgent) {
                // Potential session hijacking
                \Log::warning('Potential session hijacking detected', [
                    'user_id' => auth()->id(),
                    'session_id' => session()->getId(),
                    'current_ip' => $currentIp,
                    'session_ip' => $sessionIp,
                    'current_ua' => $currentUserAgent,
                    'session_ua' => $sessionUserAgent,
                ]);

                // Optionally force logout
                if (config('session.hijacking_action') === 'logout') {
                    auth()->logout();
                    session()->invalidate();
                    session()->regenerateToken();

                    return redirect()->route('login')
                        ->withErrors(['session' => 'Session invalidated for security reasons.']);
                }
            }
        }

        // Store current request info
        session([
            'ip_address' => $currentIp,
            'user_agent' => $currentUserAgent,
        ]);

        return $next($request);
    }
}
```

```php
use Illuminate\Http\Request;

class EnforceSessionTimeout
{
    public function handle(Request $request, Closure $next)
    {
        $lastActivity = session('last_activity');
        $timeout = config('session.lifetime') * 60; // Convert to seconds

        if ($lastActivity && (now()->timestamp - $lastActivity) > $timeout) {

            session()->invalidate();
            session()->regenerateToken();

            return redirect()->route('login')
                ->withErrors(['session' => 'Your session has expired. Please log in again.']);
        }

        session(['last_activity' => now()->timestamp]);

        return $next($request);
    }
}
```

## Session Security Service

### Session Security Scanner

```php
// app/Services/SessionSecurityScanner.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\DB;

class SessionSecurityScanner
{
    /**
     * Check for suspicious session activity.
     */
    public function scan(User $user): array
    {
        $sessions = DB::table('sessions')
            ->where('user_id', $user->id)
            ->get();

        return [
            'total_sessions' => $sessions->count(),
            'suspicious_sessions' => $this->findSuspiciousSessions($sessions),
            'concurrent_locations' => $this->findConcurrentLocations($sessions),
            'old_sessions' => $this->findOldSessions($sessions),
            'recommendations' => $this->generateRecommendations($sessions),
        ];
    }

    protected function findSuspiciousSessions($sessions): array
    {
        return $sessions->filter(function ($session) {
            // Flag sessions with unusual user agents
            $suspiciousPatterns = ['curl', 'wget', 'python', 'bot', 'spider', 'crawler'];
            $userAgent = strtolower($session->user_agent ?? '');

            foreach ($suspiciousPatterns as $pattern) {
                if (str_contains($userAgent, $pattern)) {
                    return true;
                }
            }

            return false;
        })->map(fn($s) => [
            'id' => $s->id,
            'ip' => $s->ip_address,
            'user_agent' => $s->user_agent,
            'last_activity' => date('Y-m-d H:i:s', $s->last_activity),
        ])->toArray();
    }

    protected function findConcurrentLocations($sessions): array
    {
        $ipCounts = $sessions->groupBy('ip_address')
            ->filter(fn($group) => $group->count() > 1)
            ->map(fn($group) => $group->count());

        return $ipCounts->toArray();
    }

    protected function findOldSessions($sessions): array
    {
        $cutoff = now()->subDays(30)->timestamp;

        return $sessions->filter(fn($s) => $s->last_activity < $cutoff)
            ->map(fn($s) => [
                'id' => $s->id,
                'last_activity' => date('Y-m-d H:i:s', $s->last_activity),
            ])
            ->toArray();
    }

    protected function generateRecommendations($sessions): array
    {
        $recommendations = [];

        if ($sessions->count() > 10) {
            $recommendations[] = 'You have many active sessions. Consider revoking unused ones.';
        }

        $oldSessions = $this->findOldSessions($sessions);
        if (count($oldSessions) > 0) {
            $recommendations[] = count($oldSessions) . ' session(s) are older than 30 days.';
        }

        return $recommendations;
    }
}
```

```php
// app/Services/SessionExportService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\DB;

class SessionExportService
{
    public function export(User $user, string $format = 'json'): string
    {
        $sessions = DB::table('sessions')
            ->where('user_id', $user->id)
            ->get()
            ->map(fn($s) => [
                'id' => $s->id,
                'ip_address' => $s->ip_address,
                'user_agent' => $s->user_agent,
                'last_activity' => date('Y-m-d H:i:s', $s->last_activity),
                'is_current' => $s->id === session()->getId(),
            ]);

        $data = [
            'user' => $user->email,
            'exported_at' => now()->toIso8601String(),
            'current_session_id' => session()->getId(),
            'sessions' => $sessions->toArray(),
        ];

        return match($format) {
            'json' => json_encode($data, JSON_PRETTY_PRINT),
            'csv' => $this->toCsv($sessions->toArray()),
            default => json_encode($data, JSON_PRETTY_PRINT),
        };
    }

    protected function toCsv(array $sessions): string
    {
        $headers = ['Session ID', 'IP Address', 'User Agent', 'Last Activity', 'Current'];
        $csv = implode(',', $headers) . "\n";

        foreach ($sessions as $session) {
            $csv .= implode(',', array_map(
                fn($cell) => '"' . str_replace('"', '""', $cell) . '"',
                array_values($session)
            )) . "\n";
        }

        return $csv;
    }
}
```

## Session Notification Service

```php
// app/Services/SessionNotificationService.php

namespace App\Services;

use App\Models\User;
use App\Notifications\SessionRevokedNotification;
use App\Notifications\NewLoginNotification;
use App\Notifications\SuspiciousActivityNotification;

class SessionNotificationService
{
    /**
     * Notify user of new login.
     */
    public function notifyNewLogin(User $user, string $ipAddress, string $userAgent): void
    {
        $user->notify(new NewLoginNotification(
            ipAddress: $ipAddress,
            userAgent: $userAgent,
            deviceType: $this->parseDeviceType($userAgent),
            browser: $this->parseBrowser($userAgent),
            os: $this->parseOS($userAgent),
        ));
    }

    /**
     * Notify user of session revocation.
     */
    public function notifySessionRevoked(User $user, string $sessionId, string $reason): void
    {
        $user->notify(new SessionRevokedNotification(
            sessionId: $sessionId,
            reason: $reason,
        ));
    }

    /**
     * Notify user of suspicious activity.
     */
    public function notifySuspiciousActivity(User $user, string $ipAddress, string $reason): void
    {
        $user->notify(new SuspiciousActivityNotification(
            ipAddress: $ipAddress,
            reason: $reason,
        ));
    }

    protected function parseDeviceType(string $userAgent): string
    {
        $agent = strtolower($userAgent);

        if (str_contains($agent, 'mobile') || str_contains($agent, 'android')) {
            return 'mobile';
        }

        if (str_contains($agent, 'tablet') || str_contains($agent, 'ipad')) {
            return 'tablet';
        }

        return 'desktop';
    }

    protected function parseBrowser(string $userAgent): string
    {
        $agent = strtolower($userAgent);

        if (str_contains($agent, 'chrome') && ! str_contains($agent, 'edg')) {
            return 'Chrome';
        }
        if (str_contains($agent, 'firefox')) {
            return 'Firefox';
        }
        if (str_contains($agent, 'safari') && ! str_contains($agent, 'chrome')) {
            return 'Safari';
        }
        if (str_contains($agent, 'edg')) {
            return 'Edge';
        }
        if (str_contains($agent, 'opera') || str_contains($agent, 'opr')) {
            return 'Opera';
        }

        return 'Unknown';
    }

    protected function parseOS(string $userAgent): string
    {
        $agent = strtolower($userAgent);

        if (str_contains($agent, 'windows')) {
            return 'Windows';
        }
        if (str_contains($agent, 'mac os') || str_contains($agent, 'macos')) {
            return 'macOS';
        }
        if (str_contains($agent, 'linux')) {
            return 'Linux';
        }
        if (str_contains($agent, 'android')) {
            return 'Android';
        }
        if (str_contains($agent, 'iphone') || str_contains($agent, 'ipad')) {
            return 'iOS';
        }

        return 'Unknown';
    }
}
```

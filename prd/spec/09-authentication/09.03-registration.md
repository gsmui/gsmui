# 09.03 — Registration

## Purpose

Define the complete registration flow for GsmUi, including form requirements, validation, rate limiting, post-registration actions, and error handling.

## Registration Methods

### Email + Password (Primary)

The standard registration method for all users.

### Username + Password (Optional)

Alternative registration when username login is enabled in `config/fortify.php`.

### Social Login (Phase 2)

GitHub, Google, Microsoft OAuth registration. See 09.09-social-login.md.

## Registration Flow

```text
Visitor arrives at /register
    ↓
Fills registration form
    ↓
Client-side validation (Livewire)
    ↓
Server-side validation
    ↓
Rate limit check
    ↓
Create user record
    ↓
Assign default role (User)
    ↓
Send email verification
    ↓
Redirect to verification prompt
```

## Form Fields

| Field | Required | Validation | Notes |
|---|---|---|---|
| Name | Yes | `string|max:255` | Display name |
| Email | Yes | `email|unique:users` | Login identifier |
| Password | Yes | `min:8|confirmed` | Must match confirmation |
| Password Confirmation | Yes | `same:password` | Confirm password field |
| Username | Optional | `alpha_dash|unique:users|max:30` | If username login enabled |
| Terms Agreement | Yes | `accepted` | Must accept Terms of Service |

## Livewire Component

```php
// app/Livewire/Auth/Register.php

class Register extends Component
{
    public string $name = '';
    public string $email = '';
    public string $password = '';
    public string $password_confirmation = '';
    public ?string $username = null;
    public bool $terms = false;

    protected array $rules = [
        'name' => ['required', 'string', 'max:255'],
        'email' => ['required', 'email', 'max:255', 'unique:users'],
        'password' => ['required', 'string', 'min:8', 'confirmed'],
        'username' => ['nullable', 'string', 'alpha_dash', 'max:30', 'unique:users'],
        'terms' => ['accepted'],
    ];

    public function register(): void
    {
        $this->validate();

        // Rate limit: 5 per IP per hour
        RateLimiter::attempt(
            'registration:' . request()->ip(),
            5,
            fn() => $this->createUser()
        );

        // Redirect to verification prompt
        redirect()->route('verification.notice');
    }

    protected function createUser(): void
    {
        $user = User::create([
            'name' => $this->name,
            'email' => $this->email,
            'password' => Hash::make($this->password),
            'username' => $this->username,
        ]);

        $user->assignRole('user');

        event(new UserRegistered($user));

        Auth::login($user);
    }
}
```

## Rate Limiting

| Limit | Window | Action on Exceed |
|---|---|---|
| 5 registrations | Per IP per hour | Return 429, show "too many attempts" |
| 3 registrations | Per IP per 15 minutes | Return 429, show "slow down" |

```php
// Rate limiter configuration

RateLimiter::for('registration', function (Request $request) {
    return Limit::perMinute(5)->by($request->ip());
});
```

## Post-Registration Actions

1. **Email Verification:** Send verification email with signed URL (60-minute expiry)
2. **Default Role:** Assign `User` role via Spatie Permission
3. **User Settings:** Create default user settings record
4. **Activity Log:** Log `user.registered` event
5. **Welcome Email:** Send after email verification (not at registration)
6. **Session:** Auto-login after registration

## Detailed Registration Flow Analysis

### Pre-Registration Checks

Before the registration form is even displayed, several checks must be performed:

```php
// app/Http/Middleware/PreRegistrationChecks.php

public function handle(Request $request, Closure $next)
{
    // Check if registration is enabled
    if (! config('fortify.register')) {
        return redirect()->route('login')
            ->with('status', 'Registration is currently disabled.');
    }

    // Check if maintenance mode
    if (app()->isDownForMaintenance()) {
        return response()->view('errors.maintenance', [], 503);
    }

    // Check for IP-based restrictions
    if ($this->isIpBlocked($request->ip())) {
        return redirect()->route('login')
            ->withErrors(['email' => 'Registration is temporarily unavailable.']);
    }

    return $next($request);
}
```

### Password Strength Indicator

The registration form includes a real-time password strength indicator:

```php
// app/Livewire/Auth/Register.php

public function updatedPassword(): void
{
    $this->passwordStrength = $this->calculatePasswordStrength($this->password);
}

protected function calculatePasswordStrength(string $password): array
{
    $score = 0;

    if (strlen($password) >= 8) $score++;
    if (strlen($password) >= 12) $score++;
    if (preg_match('/[a-z]/', $password)) $score++;
    if (preg_match('/[A-Z]/', $password)) $score++;
    if (preg_match('/[0-9]/', $password)) $score++;
    if (preg_match('/[^a-zA-Z0-9]/', $password)) $score++;

    return [
        'score' => min($score, 4),
        'label' => match(true) {
            $score <= 1 => 'Weak',
            $score <= 2 => 'Fair',
            $score <= 3 => 'Good',
            default => 'Strong',
        },
        'color' => match(true) {
            $score <= 1 => 'red',
            $score <= 2 => 'orange',
            $score <= 3 => 'yellow',
            default => 'green',
        },
    ];
}
```

### Registration Event Handlers

```php
// app/Listeners/HandleUserRegistration.php

class HandleUserRegistration
{
    public function handle(UserRegistered $event): void
    {
        $user = $event->user;

        // 1. Send verification email
        $user->sendEmailVerificationNotification();

        // 2. Create default user settings
        UserSettings::create([
            'user_id' => $user->id,
            'theme' => 'system',
            'locale' => 'en',
            'notifications_enabled' => true,
            'marketing_emails' => false,
        ]);

        // 3. Initialize user stats
        UserStats::create([
            'user_id' => $user->id,
            'downloads' => 0,
            'purchases' => 0,
            'uploads' => 0,
        ]);

        // 4. Log activity
        activity()
            ->performedOn($user)
            ->withProperties([
                'ip' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ])
            ->log('user.registered');
    }
}
```

### Duplicate Registration Prevention

```php
// In Register Livewire component
public function register(): void
{
    $this->validate();

    // Double-check uniqueness before creating
    if (User::where('email', $this->email)->exists()) {
        $this->addError('email', 'An account with this email already exists.');
        return;
    }

    if ($this->username && User::where('username', $this->username)->exists()) {
        $this->addError('username', 'This username is already taken.');
        return;
    }

    RateLimiter::attempt(
        'registration:' . request()->ip(),
        5,
        fn() => $this->createUser()
    );
}
```

```php
class RegistrationException extends Exception
{
    public static function emailTaken(string $email): self

        return new self(

    {
        return new self(
            "Registration rate limited for IP: {$ip}"
        );
    }

    public static function validationFailed(array $errors): self

        return new self(
```

```php
class RegistrationTest extends TestCase
{
    public function test_user_can_register()
    {

            'password_confirmation' => 'password',

    {
        $response = $this->post('/register', [
            'name' => 'John Doe',
            'email' => 'john@example.com',
            'password' => 'password',
            'password_confirmation' => 'password',
        ]);

        $response->assertSessionHasErrors('terms');
    }

    public function test_registration_rate_limiting()
    {
        for ($i = 0; $i < 6; $i++) {
            $this->post('/register', [
                'name' => 'User ' . $i,

                'password' => 'password',
                'password_confirmation' => 'password',
                'terms' => true,
            ]);
        }

        $response = $this->post('/register', [
            'name' => 'User 6',
            'email' => 'user6@example.com',
            'password' => 'password',
            'password_confirmation' => 'password',
            'terms' => true,
        ]);

    }
```

### Registration Livewire Component

```php
// app/Livewire/Auth/RegisterForm.php

namespace App\Livewire\Auth;

use App\Events\UserRegistered;
use App\Models\User;
use Illuminate\Support\Facades\Hash;
use Livewire\Component;
use Illuminate\Validation\Rules\Password;

class RegisterForm extends Component
{
    public string $name = '';
    public string $email = '';
    public string $password = '';
    public string $password_confirmation = '';
    public bool $terms = false;
    public bool $agreedToPolicy = false;
    public bool $isSubmitting = false;
    public string $status = '';
    public array $passwordStrength = [];

    protected $listeners = [
        'socialRegistered' => 'handleSocialRegistration',
    ];

    public function updatedName(): void
    {
        $this->validateOnly('name', [
            'name' => ['required', 'string', 'max:255'],
        ]);
    }

    public function updatedEmail(): void
    {
        $this->validateOnly('email', [
            'email' => ['required', 'string', 'email', 'max:255', 'unique:users'],
        ]);
    }

    public function updatedPassword(): void
    {
        $this->validateOnly('password', [
            'password' => ['required', 'string', 'min:8', 'confirmed'],
        ]);

        $this->passwordStrength = $this->calculatePasswordStrength($this->password);
    }

    public function register(): void
    {
        $this->validate([
            'name' => ['required', 'string', 'max:255'],
            'email' => ['required', 'string', 'email', 'max:255', 'unique:users'],
            'password' => ['required', 'string', 'min:8', 'confirmed', Password::defaults()],
            'terms' => ['accepted'],
        ]);

        $this->isSubmitting = true;

        try {
            $user = User::create([
                'name' => $this->name,
                'email' => $this->email,
                'password' => Hash::make($this->password),
                'email_verified_at' => null,
                'status' => 'pending',
            ]);

            $user->assignRole('user');

            event(new UserRegistered($user));

            auth()->login($user);

            $this->status = 'success';
            $this->dispatch('registered', userId: $user->id);
        } catch (\Exception $e) {
            $this->status = 'error';
            $this->addError('registration', 'Registration failed. Please try again.');
        } finally {
            $this->isSubmitting = false;
        }
    }

    public function calculatePasswordStrength(string $password): array
    {
        $score = 0;
        $feedback = [];

        if (strlen($password) >= 8) $score++;
        if (strlen($password) >= 12) $score++;
        if (preg_match('/[A-Z]/', $password)) $score++;
        if (preg_match('/[a-z]/', $password)) $score++;
        if (preg_match('/[0-9]/', $password)) $score++;
        if (preg_match('/[^A-Za-z0-9]/', $password)) $score++;

        $labels = ['Very Weak', 'Weak', 'Fair', 'Good', 'Strong', 'Very Strong'];
        $colors = ['bg-red-500', 'bg-orange-500', 'bg-yellow-500', 'bg-lime-500', 'bg-green-500', 'bg-emerald-500'];

        return [
            'score' => min($score, 5),
            'label' => $labels[min($score, 5)],
            'color' => $colors[min($score, 5)],
            'percentage' => min($score * 20, 100),
            'feedback' => $feedback,
        ];
    }

    public function handleSocialRegistration($data): void
    {
        $this->status = 'success';
        $this->dispatch('registered', userId: $data['user_id']);
    }

    public function render()
    {
        return view('livewire.auth.register-form');
    }
}
```

```php
// app/Livewire/Auth/RegisterForm.php

namespace App\Livewire\Auth;

use App\Events\UserRegistered;
use App\Models\User;
use Illuminate\Support\Facades\Hash;
use Livewire\Component;
use Illuminate\Validation\Rules\Password;

class RegisterForm extends Component
{
    public string $name = '';
    public string $email = '';
    public string $password = '';
    public string $password_confirmation = '';
    public bool $terms = false;
    public bool $isSubmitting = false;
    public string $status = '';
    public array $passwordStrength = [];

    protected $listeners = [
        'socialRegistered' => 'handleSocialRegistration',
    ];

    public function updatedName(): void
    {
        $this->validateOnly('name', [
            'name' => ['required', 'string', 'max:255'],
        ]);
    }

    public function updatedEmail(): void
    {
        $this->validateOnly('email', [
            'email' => ['required', 'string', 'email', 'max:255', 'unique:users'],
        ]);
    }

    public function updatedPassword(): void
    {
        $this->validateOnly('password', [
            'password' => ['required', 'string', 'min:8', 'confirmed'],
        ]);

        $this->passwordStrength = $this->calculatePasswordStrength($this->password);
    }

    public function register(): void
    {
        $this->validate([
            'name' => ['required', 'string', 'max:255'],
            'email' => ['required', 'string', 'email', 'max:255', 'unique:users'],
            'password' => ['required', 'string', 'min:8', 'confirmed', Password::defaults()],
            'terms' => ['accepted'],
        ]);

        $this->isSubmitting = true;

        try {
            $user = User::create([
                'name' => $this->name,
                'email' => $this->email,
                'password' => Hash::make($this->password),
                'email_verified_at' => null,
                'status' => 'pending',
            ]);

            $user->assignRole('user');

            event(new UserRegistered($user));

            auth()->login($user);

            $this->status = 'success';
            $this->dispatch('registered', userId: $user->id);
        } catch (\Exception $e) {
            $this->status = 'error';
            $this->addError('registration', 'Registration failed. Please try again.');
        } finally {
            $this->isSubmitting = false;
        }
    }

    public function calculatePasswordStrength(string $password): array
    {
        $score = 0;
        if (strlen($password) >= 8) $score++;
        if (strlen($password) >= 12) $score++;
        if (preg_match('/[A-Z]/', $password)) $score++;
        if (preg_match('/[a-z]/', $password)) $score++;
        if (preg_match('/[0-9]/', $password)) $score++;
        if (preg_match('/[^A-Za-z0-9]/', $password)) $score++;

        $labels = ['Very Weak', 'Weak', 'Fair', 'Good', 'Strong', 'Very Strong'];
        $colors = ['bg-red-500', 'bg-orange-500', 'bg-yellow-500', 'bg-lime-500', 'bg-green-500', 'bg-emerald-500'];

        return [
            'score' => min($score, 5),
            'label' => $labels[min($score, 5)],
            'color' => $colors[min($score, 5)],
            'percentage' => min($score * 20, 100),
        ];
    }

    public function handleSocialRegistration($data): void
    {
        $this->status = 'success';
        $this->dispatch('registered', userId: $data['user_id']);
    }

    public function render()
    {
        return view('livewire.auth.register-form');
    }
}
```

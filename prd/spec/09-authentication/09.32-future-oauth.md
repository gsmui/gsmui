# 09.32 — Future OAuth

## Purpose

Define the future OAuth architecture for GsmUi, including OAuth2 provider capabilities, API authorization, and third-party integration patterns.

## Status: Phase 4 (Future)

OAuth provider capabilities are a Phase 4 feature.

## OAuth Features

### OAuth2 Provider

GsmUi as OAuth2 provider for third-party apps:

| Grant Type | Use Case | Status |
|---|---|---|
| Authorization Code | Web apps | Phase 4 |
| Client Credentials | Server-to-server | Phase 4 |
| PKCE | SPAs, mobile apps | Phase 4 |
| Refresh Token | Long-lived access | Phase 4 |

### OAuth2 Client

GsmUi as OAuth2 client for third-party services:

| Provider | Use Case | Status |
|---|---|---|
| GitHub | Social login | Phase 2 |
| Google | Social login | Phase 2 |
| Microsoft | Social login | Phase 3 |
| Stripe | Payment processing | Phase 1 |
| Paddle | Payment processing | Phase 1 |

## OAuth2 Provider Flow

```text
Third-party app requests authorization
    ↓
User authorizes app at GsmUi
    ↓
Authorization code returned
    ↓
App exchanges code for tokens
    ↓
App accesses GsmUi API with token
    ↓
GsmUi validates token and scope
```

```sql
    scopes TEXT NULL,
    revoked BOOLEAN DEFAULT FALSE,
    expires_at TIMESTAMP NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (client_id) REFERENCES oauth_clients(id) ON DELETE CASCADE
);

CREATE TABLE oauth_access_tokens (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT UNSIGNED NULL,
    client_id BIGINT UNSIGNED NOT NULL,
    name VARCHAR(255) NULL,
    scopes TEXT NULL,
    revoked BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    expires_at TIMESTAMP NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (client_id) REFERENCES oauth_clients(id) ON DELETE CASCADE
);

CREATE TABLE oauth_refresh_tokens (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    access_token_id BIGINT UNSIGNED NOT NULL,
    revoked BOOLEAN DEFAULT FALSE,
    expires_at TIMESTAMP NULL,
    FOREIGN KEY (access_token_id) REFERENCES oauth_access_tokens(id) ON DELETE CASCADE
);
```

## Security Notes

* Authorization codes are single-use and expire in 1 minute
* Access tokens expire in 15 minutes (configurable)
* Refresh tokens expire in 30 days
* All tokens can be revoked individually or all at once
* PKCE required for public clients
* Client authentication required for confidential clients
* Token introspection endpoint provided
* Token revocation endpoint provided
* CORS configured for authorized origins only

## Detailed OAuth2 Provider Implementation

### Provider Architecture

The OAuth2 provider follows Laravel Passport's architecture with custom extensions for GsmUi's multi-tenant and team-based authorization model.

```text
+-------------------+     +-------------------+     +-------------------+
|   Client App      | --> |   GsmUi Auth      | --> |   Token Service   |
|   (Third-party)   |     |   Server          |     |   (Passport)      |
+-------------------+     +-------------------+     +-------------------+
        |                        |                        |
        v                        v                        v
+-------------------+     +-------------------+     +-------------------+
|   Authorization   |     |   Consent         |     |   Token           |
|   Request         |     |   Screen          |     |   Response        |
+-------------------+     +-------------------+     +-------------------+
```

```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Database\Eloquent\Relations\HasOne;
use Illuminate\Support\Str;

class OAuthClient extends Model
{
    protected $fillable = [
        'user_id',
        'team_id',
        'name',
        'provider',
        'redirect_uris',
        'grant_types',
        'scopes',
        'personal_access_client',
        'password_client',
        'confidential',
        'revoked',
        'metadata',
    ];

    protected $casts = [
        'redirect_uris' => 'array',
        'grant_types' => 'array',
        'scopes' => 'array',
        'personal_access_client' => 'boolean',
        'password_client' => 'boolean',
        'confidential' => 'boolean',
        'revoked' => 'boolean',
        'metadata' => 'array',
    ];

    protected $hidden = [
        'secret',
    ];

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }

    public function team(): BelongsTo
    {
        return $this->belongsTo(Team::class);
    }

    public function accessTokens(): HasMany
    {
        return $this->hasMany(OAuthAccessToken::class, 'client_id');
    }

    public function authCodes(): HasMany
    {
        return $this->hasMany(OAuthAuthCode::class, 'client_id');
    }

    public function refreshTokens(): HasManyThrough
    {
        return $this->hasManyThrough(
            OAuthRefreshToken::class,
            OAuthAccessToken::class,
            'client_id',
            'access_token_id'
        );
    }

    public function personalAccessClient(): HasOne
    {
        return $this->hasOne(OAuthPersonalAccessClient::class);
    }

    public function generateSecret(): string
    {
        $secret = Str::random(48);
        $this->update(['secret' => hash('sha256', $secret)]);
        return $secret;
    }

    public function isConfidential(): bool
    {
        return $this->confidential;
    }

    public function supportsGrantType(string $grantType): bool
    {
        return in_array($grantType, $this->grant_types ?? []);
    }

    public function hasScope(string $scope): bool
    {
        if (empty($this->scopes)) {
            return true;
        }
        return in_array('*', $this->scopes) || in_array($scope, $this->scopes);
    }

    public function isRevoked(): bool
    {
        return $this->revoked;
    }

    public function revoke(): bool
    {
        $this->update(['revoked' => true]);
        $this->accessTokens()->update(['revoked' => true]);
        return true;
    }

    public function validateRedirectUri(string $uri): bool
    {
        foreach ($this->redirect_uris as $allowedUri) {
            if (Str::startsWith($uri, $allowedUri)) {
                return true;
            }
        }
        return false;
    }

    public function scope()
    {
        return $this->belongsTo(Team::class, 'team_id');
    }
}
```

```php
    protected $fillable = [
        'user_id',
```

```php
        'scopes',
        'revoked',
        'expires_at',
        'code',
        'code_challenge',

    public function verifyChallenge(string $codeVerifier): bool
    {
        if (!$this->code_challenge) {
            return true;
        }

        if ($this->code_challenge_method === 'S256') {
            return hash('sha256', $codeVerifier) === $this->code_challenge;
        }

        return $codeVerifier === $this->code_challenge;
    }

    public function revoke(): bool
    {
        return $this->update(['revoked' => true]);
    }
```

#### AuthorizationController

```php
// app/Http/Controllers/OAuth/AuthorizationController.php

namespace App\Http\Controllers\OAuth;

use App\Http\Controllers\Controller;
use App\Models\OAuthClient;
use App\Models\OAuthAuthCode;
use Illuminate\Http\Request;
use Illuminate\Support\Str;
use Carbon\Carbon;

class AuthorizationController extends Controller
{
    public function authorize(Request $request)
    {
        $request->validate([
            'client_id' => 'required|string',
            'redirect_uri' => 'required|url',
            'response_type' => 'required|in:code',
            'scope' => 'nullable|string',
            'state' => 'nullable|string',
            'code_challenge' => 'nullable|string',
            'code_challenge_method' => 'nullable|in:S256,plain',
        ]);

        $client = OAuthClient::where('provider', $request->client_id)
            ->where('revoked', false)
            ->firstOrFail();

        if (!$client->validateRedirectUri($request->redirect_uri)) {
            return redirect()->route('oauth.error', [
                'error' => 'invalid_redirect_uri',
                'error_description' => 'The redirect URI is not authorized.',
            ]);
        }

        if (!$client->supportsGrantType($request->response_type === 'code' ? 'authorization_code' : $request->response_type)) {
            return redirect()->route('oauth.error', [
                'error' => 'unsupported_response_type',
                'error_description' => 'The grant type is not supported.',
            ]);
        }

        $user = $request->user();

        $existingToken = $user->accessTokens()
            ->where('client_id', $client->id)
            ->where('revoked', false)
            ->first();

        if ($existingToken && !$request->has('prompt') || $request->input('prompt') !== 'consent') {
            return $this->issueAuthorizationCode($request, $client, $user);
        }

        return view('oauth.consent', [
            'client' => $client,
            'scopes' => $this->parseScopes($request->scope),
            'state' => $request->state,
            'codeChallenge' => $request->code_challenge,
            'codeChallengeMethod' => $request->code_challenge_method,
        ]);
    }

    public function approve(Request $request)
    {
        $request->validate([
            'client_id' => 'required|string',
            'redirect_uri' => 'required|url',
            'state' => 'nullable|string',
            'scopes' => 'required|array',
            'code_challenge' => 'nullable|string',
            'code_challenge_method' => 'nullable|in:S256,plain',
        ]);

        $client = OAuthClient::where('provider', $request->client_id)
            ->where('revoked', false)
            ->firstOrFail();

        $user = $request->user();

        return $this->issueAuthorizationCode($request, $client, $user, $request->scopes);
    }

    public function deny(Request $request)
    {
        $request->validate([
            'client_id' => 'required|string',
            'redirect_uri' => 'required|url',
            'state' => 'nullable|string',
        ]);

        return redirect()->buildAbsoluteUrl([
            'query' => [
                'error' => 'access_denied',
                'error_description' => 'The user denied the authorization request.',
                'state' => $request->state,
            ],
        ]);
    }

    protected function issueAuthorizationCode(
        Request $request,
        OAuthClient $client,
        $user,
        array $scopes = []
    ): \Illuminate\Http\RedirectResponse {
        $code = Str::random(40);

        OAuthAuthCode::create([
            'user_id' => $user->id,
            'client_id' => $client->id,
            'team_id' => $user->current_team_id,
            'scopes' => $scopes,
            'code' => hash('sha256', $code),
            'code_challenge' => $request->code_challenge,
            'code_challenge_method' => $request->code_challenge_method,
            'expires_at' => Carbon::now()->addMinutes(1),
        ]);

        return redirect()->buildAbsoluteUrl([
            'query' => array_filter([
                'code' => $code,
                'state' => $request->state,
            ]),
        ]);
    }

    protected function parseScopes(?string $scopeString): array
    {
        if (!$scopeString) {
            return ['*'];
        }
        return explode(' ', $scopeString);
    }
}
```

#### TokenController

```php
// app/Http/Controllers/OAuth/TokenController.php

namespace App\Http\Controllers\OAuth;

use App\Http\Controllers\Controller;
use App\Models\OAuthClient;
use App\Models\OAuthAccessToken;
use App\Models\OAuthRefreshToken;
use App\Models\OAuthAuthCode;
use App\Services\OAuth\TokenService;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Str;

class TokenController extends Controller
{
    public function __construct(
        protected TokenService $tokenService
    ) {}

    public function issueToken(Request $request): JsonResponse
    {
        $request->validate([
            'grant_type' => 'required|string',
            'client_id' => 'required|string',
            'client_secret' => 'nullable|string',
        ]);

        $client = $this->authenticateClient($request);

        if ($client->isRevoked()) {
            return response()->json([
                'error' => 'invalid_client',
                'error_description' => 'The client has been revoked.',
            ], 401);
        }

        return match ($request->grant_type) {
            'authorization_code' => $this->handleAuthorizationCodeGrant($request, $client),
            'refresh_token' => $this->handleRefreshTokenGrant($request, $client),
            'client_credentials' => $this->handleClientCredentialsGrant($request, $client),
            'personal_access' => $this->handlePersonalAccessTokenGrant($request, $client),
            default => response()->json([
                'error' => 'unsupported_grant_type',
                'error_description' => 'The grant type is not supported.',
            ], 400),
        };
    }

    protected function authenticateClient(Request $request): OAuthClient
    {
        $clientId = $request->client_id;
        $clientSecret = $request->client_secret;

        $client = OAuthClient::where('provider', $clientId)
            ->where('revoked', false)
            ->firstOrFail();

        if ($client->isConfidential()) {
            if (!$clientSecret || !hash_equals($client->secret, hash('sha256', $clientSecret))) {
                abort(401, 'Invalid client credentials.');
            }
        }

        return $client;
    }

    protected function handleAuthorizationCodeGrant(
        Request $request,
        OAuthClient $client
    ): JsonResponse {
        $request->validate([
            'code' => 'required|string',
            'redirect_uri' => 'required|url',
            'code_verifier' => 'nullable|string',
        ]);

        $authCode = OAuthAuthCode::where('client_id', $client->id)
            ->where('revoked', false)
            ->first();

        if (!$authCode || $authCode->isExpired()) {
            return response()->json([
                'error' => 'invalid_grant',
                'error_description' => 'The authorization code is invalid or expired.',
            ], 400);
        }

        if (!hash_equals($authCode->code, hash('sha256', $request->code))) {
            $authCode->revoke();
            return response()->json([
                'error' => 'invalid_grant',
                'error_description' => 'The authorization code is invalid.',
            ], 400);
        }

        if ($authCode->code_challenge && !$authCode->verifyChallenge($request->code_verifier)) {
            return response()->json([
                'error' => 'invalid_grant',
                'error_description' => 'The code verifier is invalid.',
            ], 400);
        }

        $authCode->revoke();

        $token = $this->tokenService->createAccessToken(
            $client,
            $authCode->user_id,
            $authCode->scopes,
            $authCode->team_id
        );

        $refreshToken = $this->tokenService->createRefreshToken($token);

        return response()->json([
            'access_token' => $token->token,
            'token_type' => 'Bearer',
            'expires_in' => $token->expires_at->diffInSeconds(now()),
            'refresh_token' => $refreshToken->token,
            'scope' => implode(' ', $authCode->scopes),
        ]);
    }

    protected function handleRefreshTokenGrant(
        Request $request,
        OAuthClient $client
    ): JsonResponse {
        $request->validate([
            'refresh_token' => 'required|string',
        ]);

        $refreshToken = OAuthRefreshToken::where('token', hash('sha256', $request->refresh_token))
            ->where('revoked', false)
            ->first();

        if (!$refreshToken || $refreshToken->isExpired()) {
            return response()->json([
                'error' => 'invalid_grant',
                'error_description' => 'The refresh token is invalid or expired.',
            ], 400);
        }

        $accessToken = $refreshToken->accessToken;

        if ($accessToken->client_id !== $client->id) {
            return response()->json([
                'error' => 'invalid_grant',
                'error_description' => 'The refresh token does not belong to this client.',
            ], 400);
        }

        $refreshToken->revoke();

        $newToken = $this->tokenService->createAccessToken(
            $client,
            $accessToken->user_id,
            $accessToken->scopes,
            $accessToken->team_id
        );

        $newRefreshToken = $this->tokenService->createRefreshToken($newToken);

        return response()->json([
            'access_token' => $newToken->token,
            'token_type' => 'Bearer',
            'expires_in' => $newToken->expires_at->diffInSeconds(now()),
            'refresh_token' => $newRefreshToken->token,
            'scope' => implode(' ', $accessToken->scopes),
        ]);
    }

    protected function handleClientCredentialsGrant(
        Request $request,
        OAuthClient $client
    ): JsonResponse {
        $request->validate([
            'scope' => 'nullable|string',
        ]);

        $scopes = $request->scope ? explode(' ', $request->scope) : ['*'];

        $token = $this->tokenService->createAccessToken(
            $client,
            null,
            $scopes,
            null
        );

        return response()->json([
            'access_token' => $token->token,
            'token_type' => 'Bearer',
            'expires_in' => $token->expires_at->diffInSeconds(now()),
            'scope' => implode(' ', $scopes),
        ]);
    }

    protected function handlePersonalAccessTokenGrant(
        Request $request,
        OAuthClient $client
    ): JsonResponse {
        $request->validate([
            'token' => 'required|string',
            'scope' => 'nullable|string',
        ]);

        $token = $this->tokenService->findPersonalAccessToken($request->token);

        if (!$token || $token->isRevoked()) {
            return response()->json([
                'error' => 'invalid_token',
                'error_description' => 'The personal access token is invalid.',
            ], 400);
        }

        $scopes = $request->scope ? explode(' ', $request->scope) : $token->scopes;

        return response()->json([
            'access_token' => $token->token,
            'token_type' => 'Bearer',
            'expires_in' => $token->expires_at->diffInSeconds(now()),
            'scope' => implode(' ', $scopes),
        ]);
    }
}
```

#### OAuthAuthenticateMiddleware

```php
// app/Http/Middleware/OAuthAuthenticateMiddleware.php

namespace App\Http\Middleware;

use App\Models\OAuthAccessToken;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class OAuthAuthenticateMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $token = $request->bearerToken();

        if (!$token) {
            return response()->json([
                'error' => 'invalid_token',
                'error_description' => 'The access token is missing.',
            ], 401);
        }

        $accessToken = OAuthAccessToken::where('token', hash('sha256', $token))
            ->where('revoked', false)
            ->first();

        if (!$accessToken || $accessToken->isExpired()) {
            return response()->json([
                'error' => 'invalid_token',
                'error_description' => 'The access token is invalid or expired.',
            ], 401);
        }

        $request->setUser($accessToken->user);
        $request->attributes->set('oauth_token', $accessToken);
        $request->attributes->set('oauth_scopes', $accessToken->scopes);

        return $next($request);
    }
```

```php
// app/Http/Middleware/OAuthScopeMiddleware.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class OAuthScopeMiddleware
{
    public function handle(Request $request, Closure $next, string ...$scopes): Response
    {
        $tokenScopes = $request->attributes->get('oauth_scopes', []);

        if (in_array('*', $tokenScopes)) {
            return $next($request);
        }

        foreach ($scopes as $requiredScope) {
            if (!in_array($requiredScope, $tokenScopes)) {
                return response()->json([
                    'error' => 'insufficient_scope',
                    'error_description' => 'The token does not have the required scope.',
                    'scope' => implode(' ', $scopes),
                ], 403);
            }
        }

        return $next($request);
    }
}
```

```php
// app/Services/OAuth/TokenService.php

namespace App\Services\OAuth;

use App\Models\OAuthClient;
use App\Models\OAuthAccessToken;
use App\Models\OAuthRefreshToken;
use App\Models\OAuthPersonalAccessClient;
use Illuminate\Support\Str;
use Carbon\Carbon;

class TokenService
{
    public function createAccessToken(
        OAuthClient $client,
        ?int $userId,
        array $scopes,
        ?int $teamId
    ): OAuthAccessToken {
        $token = Str::random(80);

        return OAuthAccessToken::create([
            'user_id' => $userId,
            'client_id' => $client->id,
            'team_id' => $teamId,
            'token' => hash('sha256', $token),
            'name' => null,
            'scopes' => $scopes,
            'revoked' => false,
            'created_at' => now(),
            'expires_at' => Carbon::now()->addMinutes(
                config('passport.access_token_expiration', 15)
            ),
        ])->forceFill(['token' => $token])->save();
    }

    public function createRefreshToken(OAuthAccessToken $accessToken): OAuthRefreshToken
    {
        $token = Str::random(100);

        return OAuthRefreshToken::create([
            'access_token_id' => $accessToken->id,
            'token' => hash('sha256', $token),
            'revoked' => false,
            'expires_at' => Carbon::now()->addDays(
                config('passport.refresh_token_expiration', 30)
            ),
        ])->forceFill(['token' => $token])->save();
    }

    public function createPersonalAccessToken(
        OAuthClient $client,
        int $userId,
        string $name,
        array $scopes,
        ?int $teamId
    ): OAuthAccessToken {
        $token = Str::random(80);

        $accessToken = OAuthAccessToken::create([
            'user_id' => $userId,
            'client_id' => $client->id,
            'team_id' => $teamId,
            'token' => hash('sha256', $token),
            'name' => $name,
            'scopes' => $scopes,
            'revoked' => false,
            'created_at' => now(),
            'expires_at' => null,
        ]);

        OAuthPersonalAccessClient::create([
            'user_id' => $userId,
            'client_id' => $client->id,
            'team_id' => $teamId,
        ]);

        return $accessToken->forceFill(['token' => $token])->save();
    }

    public function findPersonalAccessToken(string $token): ?OAuthAccessToken
    {
        return OAuthAccessToken::where('token', hash('sha256', $token))
            ->whereNull('expires_at')
            ->first();
    }

    public function revokeAccessToken(OAuthAccessToken $accessToken): bool
    {
        return $accessToken->revoke();
    }

    public function revokeRefreshToken(OAuthRefreshToken $refreshToken): bool
    {
        return $refreshToken->revoke();
    }

    public function revokeAllTokens(OAuthClient $client, ?int $userId): bool
    {
        $query = OAuthAccessToken::where('client_id', $client->id);

        if ($userId) {
            $query->where('user_id', $userId);
        }

        $query->update(['revoked' => true]);

        return true;
    }

    public function introspectToken(string $token): ?array
    {
        $accessToken = OAuthAccessToken::where('token', hash('sha256', $token))
            ->with('user', 'client')
            ->first();

        if (!$accessToken || $accessToken->isRevoked() || $accessToken->isExpired()) {
            return null;
        }

        return [
            'active' => true,
            'scope' => implode(' ', $accessToken->scopes),
            'client_id' => $accessToken->client->provider,
            'username' => $accessToken->user->email,
            'token_type' => 'Bearer',
            'exp' => $accessToken->expires_at->timestamp,
            'iat' => $accessToken->created_at->timestamp,
            'sub' => $accessToken->user_id,
            'aud' => $accessToken->client->provider,
            'iss' => config('app.url'),
        ];
    }
}
```

## OAuth Rate Limiting

```php
// app/Http/Middleware/OAuthRateLimitMiddleware.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\RateLimiter;
use Symfony\Component\HttpFoundation\Response;

class OAuthRateLimitMiddleware
{
    public function handle(Request $request, Closure $next, string $maxAttempts = '60', string $decayMinutes = '1'): Response
    {
        $key = $this->resolveRequestSignature($request);

        if (RateLimiter::tooManyAttempts($key, (int) $maxAttempts)) {
            $seconds = RateLimiter::availableIn($key);

            return response()->json([
                'error' => 'rate_limit_exceeded',
                'error_description' => 'Too many requests. Please try again later.',
                'retry_after' => $seconds,
            ], 429)->withHeaders([
                'Retry-After' => $seconds,
                'X-RateLimit-Limit' => $maxAttempts,
                'X-RateLimit-Remaining' => 0,
            ]);
        }

        RateLimiter::hit($key, (int) $decayMinutes * 60);

        $response = $next($request);

        return $response->withHeaders([
            'X-RateLimit-Limit' => $maxAttempts,
            'X-RateLimit-Remaining' => RateLimiter::remaining($key, (int) $maxAttempts),
        ]);
    }

    protected function resolveRequestSignature(Request $request): string
    {
        return $request->ip() . '|' . $request->input('client_id', '');
    }
}
```

### SPA Frontend Integration

```javascript
// resources/js/oauth.js

class OAuthClient {
    constructor(config) {
        this.clientId = config.clientId;
        this.redirectUri = config.redirectUri;
        this.authorizationEndpoint = config.authorizationEndpoint;
        this.tokenEndpoint = config.tokenEndpoint;
        this.scopes = config.scopes || ['*'];
    }

    async login() {
        const codeVerifier = this.generateCodeVerifier();
        const codeChallenge = await this.generateCodeChallenge(codeVerifier);
        const state = this.generateState();

        sessionStorage.setItem('oauth_state', state);
        sessionStorage.setItem('oauth_code_verifier', codeVerifier);

        const params = new URLSearchParams({
            client_id: this.clientId,
            redirect_uri: this.redirectUri,
            response_type: 'code',
            scope: this.scopes.join(' '),
            state: state,
            code_challenge: codeChallenge,
            code_challenge_method: 'S256',
        });

        window.location.href = `${this.authorizationEndpoint}?${params.toString()}`;
    }

    async handleCallback(code, state) {
        const storedState = sessionStorage.getItem('oauth_state');
        const codeVerifier = sessionStorage.getItem('oauth_code_verifier');

        if (state !== storedState) {
            throw new Error('Invalid state parameter');
        }

        const response = await fetch(this.tokenEndpoint, {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'Accept': 'application/json',
            },
            body: JSON.stringify({
                grant_type: 'authorization_code',
                client_id: this.clientId,
                code: code,
                redirect_uri: this.redirectUri,
                code_verifier: codeVerifier,
            }),
        });

        const data = await response.json();

        if (data.error) {
            throw new Error(data.error_description || data.error);
        }

        sessionStorage.removeItem('oauth_state');
        sessionStorage.removeItem('oauth_code_verifier');

        return data;
    }

    generateCodeVerifier() {
        const array = new Uint8Array(32);
        crypto.getRandomValues(array);
        return this.base64UrlEncode(array);
    }

    async generateCodeChallenge(codeVerifier) {
        const encoder = new TextEncoder();
        const data = encoder.encode(codeVerifier);
        const digest = await crypto.subtle.digest('SHA-256', data);
        return this.base64UrlEncode(new Uint8Array(digest));
    }

    base64UrlEncode(array) {
        return btoa(String.fromCharCode.apply(null, array))
            .replace(/\+/g, '-')
            .replace(/\//g, '_')
            .replace(/=/g, '');
    }

    generateState() {
        const array = new Uint8Array(16);
        crypto.getRandomValues(array);
        return this.base64UrlEncode(array);
    }
}

export default OAuthClient;
```

```php
use App\Http\Controllers\Controller;
```

```php
use App\Models\OAuthDeviceCode;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Str;

class DeviceAuthController extends Controller
{
    public function requestDeviceCode(Request $request): JsonResponse
    {
        $request->validate([
            'client_id' => 'required|string',
            'scope' => 'nullable|string',
        ]);

        $client = OAuthClient::where('provider', $request->client_id)
            ->where('revoked', false)
            ->firstOrFail();

        $deviceCode = Str::random(40);
        $userCode = strtoupper(Str::random(8));

        OAuthDeviceCode::create([
            'client_id' => $client->id,
            'device_code' => hash('sha256', $deviceCode),
            'user_code' => $userCode,
            'scope' => $request->scope ? explode(' ', $request->scope) : ['*'],
            'expires_at' => now()->addMinutes(10),
            'interval' => 5,
        ]);

        return response()->json([
            'device_code' => $deviceCode,
            'user_code' => $userCode,
            'verification_uri' => route('oauth.device.verify'),
            'verification_uri_complete' => route('oauth.device.verify', ['user_code' => $userCode]),
            'expires_in' => 600,
            'interval' => 5,
        ]);
    }

    public function pollToken(Request $request): JsonResponse
    {
        $request->validate([
            'device_code' => 'required|string',
            'client_id' => 'required|string',
        ]);

        $deviceCode = OAuthDeviceCode::where('device_code', hash('sha256', $request->device_code))
            ->where('revoked', false)
            ->first();

        if (!$deviceCode || $deviceCode->isExpired()) {
            return response()->json([
                'error' => 'expired_token',
                'error_description' => 'The device code has expired.',
            ], 400);
        }

        if ($deviceCode->isPending()) {
            return response()->json([
                'error' => 'authorization_pending',
                'error_description' => 'The authorization request is still pending.',
            ], 400)->withHeaders([
                'Retry-After' => $deviceCode->interval,
            ]);
        }

        if ($deviceCode->isDenied()) {
            return response()->json([
                'error' => 'access_denied',
                'error_description' => 'The authorization request was denied.',
            ], 400);
        }

        $client = $deviceCode->client;
        $token = $this->tokenService->createAccessToken(
            $client,
            $deviceCode->user_id,
            $deviceCode->scope,
            $deviceCode->team_id
        );

        $deviceCode->revoke();

        return response()->json([
            'access_token' => $token->token,
            'token_type' => 'Bearer',
            'expires_in' => $token->expires_at->diffInSeconds(now()),
            'scope' => implode(' ', $deviceCode->scope),
        ]);
    }
```

```php
namespace App\Http\Controllers\OAuth;

use App\Http\Controllers\Controller;
use Illuminate\Http\JsonResponse;
use Illuminate\Support\Facades\File;

class JwksController extends Controller
{
    public function index(): JsonResponse
    {
        $publicKey = config('oauth.passport.public_key');

        if (!$publicKey) {
            return response()->json(['keys' => []]);
        }

        $details = openssl_pkey_get_details(openssl_pkey_get_public($publicKey));

        return response()->json([
            'keys' => [
                [
                    'kty' => 'RSA',
                    'kid' => config('app.key', 'gsmui-key'),
                    'use' => 'sig',
                    'alg' => 'RS256',
                    'n' => $this->base64UrlEncode($details['rsa']['n']),
                    'e' => $this->base64UrlEncode($details['rsa']['e']),
                ],
            ],
        ]);
    }

    protected function base64UrlEncode(string $data): string
    {
        return rtrim(strtr(base64_encode($data), '+/', '-_'), '=');
    }
}
```

## OAuth Webhook Support

```php
// app/Services/OAuth/WebhookService.php

namespace App\Services\OAuth;

use App\Models\OAuthClient;
use App\Models\OAuthWebhook;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;

class WebhookService
{
    public function send(OAuthClient $client, string $event, array $payload): bool
    {
        $webhooks = OAuthWebhook::where('client_id', $client->id)
            ->where('active', true)
            ->whereJsonContains('events', $event)
            ->get();

        foreach ($webhooks as $webhook) {
            $this->dispatchWebhook($webhook, $event, $payload);
        }

        return true;
    }

    protected function dispatchWebhook(OAuthWebhook $webhook, string $event, array $payload): void
    {
        $body = [
            'event' => $event,
            'timestamp' => now()->toIso8601String(),
            'data' => $payload,
        ];

        $signature = $this->generateSignature($body, $webhook->secret);

        try {
            $response = Http::withHeaders([
                'Content-Type' => 'application/json',
                'X-Gsmui-Signature' => $signature,
                'X-Gsmui-Event' => $event,
                'X-Gsmui-Delivery' => $webhook->id . '-' . now()->timestamp,
            ])->timeout(30)->post($webhook->url, $body);

            $webhook->update([
                'last_status' => $response->status(),
                'last_attempt_at' => now(),
                'success_count' => $webhook->success_count + ($response->successful() ? 1 : 0),
                'failure_count' => $webhook->failure_count + ($response->failed() ? 1 : 0),
            ]);

            Log::channel('webhooks')->info('Webhook delivered', [
                'webhook_id' => $webhook->id,
                'event' => $event,
                'status' => $response->status(),
            ]);
        } catch (\Exception $e) {
            $webhook->update([
                'last_status' => 0,
                'last_attempt_at' => now(),
                'failure_count' => $webhook->failure_count + 1,
                'last_error' => $e->getMessage(),
            ]);

            Log::channel('webhooks')->error('Webhook delivery failed', [
                'webhook_id' => $webhook->id,
                'event' => $event,
                'error' => $e->getMessage(),
            ]);
        }
    }

    protected function generateSignature(array $payload, string $secret): string
    return hash_hmac('sha256', json_encode($payload), $secret);
    }
}
```

```php
// app/Services/OAuth/MetricsService.php

namespace App\Services\OAuth;

use App\Models\OAuthAccessToken;
use App\Models\OAuthClient;
use App\Models\OAuthAuthCode;
use Illuminate\Support\Facades\DB;
use Carbon\Carbon;

class MetricsService
{
    public function getAuthorizationMetrics(Carbon $startDate, Carbon $endDate): array
    {
        return [
            'total_authorizations' => OAuthAuthCode::whereBetween('created_at', [$startDate, $endDate])->count(),
            'successful_authorizations' => OAuthAuthCode::whereBetween('created_at', [$startDate, $endDate])->where('revoked', false)->count(),
            'denied_authorizations' => OAuthAuthCode::whereBetween('created_at', [$startDate, $endDate])->where('revoked', true)->count(),
            'unique_users' => OAuthAuthCode::whereBetween('created_at', [$startDate, $endDate])->distinct('user_id')->count('user_id'),
            'unique_clients' => OAuthAuthCode::whereBetween('created_at', [$startDate, $endDate])->distinct('client_id')->count('client_id'),
        ];
    }

    public function getTokenMetrics(Carbon $startDate, Carbon $endDate): array
    {
        return [
            'tokens_issued' => OAuthAccessToken::whereBetween('created_at', [$startDate, $endDate])->count(),
            'tokens_active' => OAuthAccessToken::where('revoked', false)->where('expires_at', '>', now())->count(),
            'tokens_revoked' => OAuthAccessToken::where('revoked', true)->whereBetween('updated_at', [$startDate, $endDate])->count(),
            'tokens_expired' => OAuthAccessToken::where('expires_at', '<=', now())->count(),
            'avg_token_lifetime' => $this->calculateAverageTokenLifetime($startDate, $endDate),
        ];
    }

    public function getClientMetrics(): array
    {
        return OAuthClient::withCount(['accessTokens as active_tokens_count' => function ($query) {
            $query->where('revoked', false)->where('expires_at', '>', now());
        }])->get()->toArray();
    }

    public function getTopClients(int $limit = 10): array
    {
        return OAuthClient::withCount('accessTokens')
            ->orderByDesc('access_tokens_count')
            ->limit($limit)
            ->get()
            ->toArray();
    }

    protected function calculateAverageTokenLifetime(Carbon $startDate, Carbon $endDate): float
    {
        $result = OAuthAccessToken::whereBetween('created_at', [$startDate, $endDate])
            ->whereNotNull('expires_at')
            ->selectRaw('AVG(TIMESTAMPDIFF(SECOND, created_at, expires_at)) as avg_lifetime')
            ->value('avg_lifetime');

        return $result ? round($result / 3600, 2) : 0;
    }
}
```

```php
// app/Services/OAuth/TokenBindingService.php

namespace App\Services\OAuth;

use App\Models\OAuthAccessToken;
use Illuminate\Support\Facades\Hash;

class TokenBindingService
{
    public function bindToken(OAuthAccessToken $token, string $fingerprint): void
    {
        $token->update([
            'metadata' => array_merge($token->metadata ?? [], [
                'binding_fingerprint' => hash('sha256', $fingerprint),
                'bound_at' => now()->toIso8601String(),
            ]),
        ]);
    }

    public function verifyBinding(OAuthAccessToken $token, string $fingerprint): bool
    {
        $metadata = $token->metadata ?? [];

        if (!isset($metadata['binding_fingerprint'])) {
            return true;
        }

        return hash_equals($metadata['binding_fingerprint'], hash('sha256', $fingerprint));
    }

    public function getTokenFingerprint(): string
    {
        return request()->ip() . '|' . request()->userAgent();
    }
}
```

```php
// app/Services/OAuth/PkceValidationService.php

namespace App\Services\OAuth;

use App\Models\OAuthAuthCode;

class PkceValidationService
{
    public function validate(OAuthAuthCode $authCode, ?string $codeVerifier): bool
    {
        if (!$authCode->code_challenge) {
            return true;
        }

        if (!$codeVerifier) {
            return false;
        }

        if (strlen($codeVerifier) < 43 || strlen($codeVerifier) > 128) {
            return false;
        }

        if ($authCode->code_challenge_method === 'S256') {
            $computedChallenge = rtrim(strtr(base64_encode(hash('sha256', $codeVerifier, true)), '+/', '-_'), '=');
            return hash_equals($authCode->code_challenge, $computedChallenge);
        }

        return hash_equals($authCode->code_challenge, $codeVerifier);
    }
}
```

### Token Rotation

```php
// app/Services/OAuth/TokenRotationService.php

namespace App\Services\OAuth;

use App\Models\OAuthAccessToken;
use App\Models\OAuthRefreshToken;

class TokenRotationService
{
    public function __construct(
        protected TokenService $tokenService
    ) {}

    public function rotateRefreshToken(OAuthRefreshToken $refreshToken): array
    {
        if ($refreshToken->isRevoked()) {
            throw new \App\Exceptions\OAuth\TokenRevokedException(
                'Refresh token has been revoked.'
            );
        }

        $accessToken = $refreshToken->accessToken;

        $newAccessToken = $this->tokenService->createAccessToken(
            $accessToken->client,
            $accessToken->user_id,
            $accessToken->scopes,
            $accessToken->team_id
        );

        $newRefreshToken = $this->tokenService->createRefreshToken($newAccessToken);

        $refreshToken->revoke();
        $accessToken->revoke();

        return [
            'access_token' => $newAccessToken,
            'refresh_token' => $newRefreshToken,
        ];
    }
}
```

```php
namespace App\Services\OAuth;

    {
        return OAuthAuthCode::where('user_id', $userId)
            ->with('client')
            ->orderByDesc('created_at')
            ->get()
            ->toArray();
    }
}
```

```php
namespace App\Livewire\OAuth;
```

* [ ] Set short expiration for authorization codes (1 minute)

* [ ] Use signed JWTs for access tokens
* [ ] Validate redirect URIs against registered URIs
* [ ] Implement rate limiting on token endpoints
* [ ] Log all OAuth events for audit
* [ ] Implement token binding for high-security clients

* [ ] Implement PKCE for SPA and mobile flows

* [ ] Use short-lived access tokens
* [ ] Implement refresh token rotation

* [ ] Monitor for suspicious activity

# 09.21 — Admin Authentication

## Purpose

Define the admin authentication system for GsmUi, including admin login, admin panel access, and admin-specific security features.

## Admin Authentication Flow

```text
Admin visits /admin/login
    ↓
Enters email + password
    ↓
Rate limit check (stricter than regular login)
    ↓
Credential verification
    ↓
Role check (admin or super_admin)
    ↓
2FA verification (if enabled)
    ↓
Session created (Redis)
    ↓
Admin audit log entry
    ↓
Redirect to /admin/dashboard
```

## Admin Login Requirements

| Requirement | Value |
|---|---|
| Role required | admin or super_admin |
| 2FA | Required for all admins |
| Session lifetime | 60 minutes |
| Password confirmation | Every 30 minutes for sensitive ops |
| Rate limiting | 3 attempts per minute |

## Admin Login Livewire

```php
// app/Livewire/Admin/Login.php

class Login extends Component
{
    public string $email = '';
    public string $password = '';

    protected array $rules = [
        'email' => ['required', 'email'],
        'password' => ['required', 'string'],
    ];

    public function login(): void
    {
        $this->validate();

        RateLimiter::attempt(
            'admin-login:' . request()->ip(),
            3,
            fn() => $this->attemptAdminLogin()
        );

        redirect()->intended('/admin/dashboard');
    }

    protected function attemptAdminLogin(): bool
    {
        $user = User::where('email', $this->email)->first();

        if (! $user || ! Hash::check($this->password, $user->password)) {
            Hash::make('dummy'); // Timing attack prevention
            return false;
        }

        if (! $user->hasRole(['admin', 'super_admin'])) {
            return false;
        }

        if ($user->isSuspended()) {
            return false;
        }

        Auth::login($user);

        // Log admin login
        activity('admin-auth')
            ->performedOn($user)
            ->withProperties([
                'ip' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ])
            ->log('Admin login successful');

        return true;
    }
}
```

## Admin Panel Middleware

```php
// app/Http/Middleware/AdminMiddleware.php

class AdminMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        if (! Auth::check()) {
            return redirect('/admin/login');
        }

        if (! Auth::user()->hasRole(['admin', 'super_admin'])) {
            abort(403, 'Unauthorized admin access.');
        }

        if (Auth::user()->isSuspended()) {
            Auth::logout();
            return redirect('/admin/login')
                ->with('error', 'Your admin account has been suspended.');
        }

        // Log admin panel access
        activity('admin-access')
            ->performedOn(Auth::user())
            ->log('Admin panel accessed');

        return $next($request);
    }
}
```

## Admin Two-Factor Authentication

### 2FA Enforcement

```php
// app/Livewire/Admin/TwoFactorSetup.php

namespace App\Livewire\Admin;

use Livewire\Component;
use Illuminate\Support\Facades\Auth;
use Laravel\Fortify\Actions\EnableTwoFactorAuthentication;
use Laravel\Fortify\Actions\GenerateTwoFactorAuthenticationSecret;
use PragmaRX\Google2FAQRCode\Exceptions\Exception;

class TwoFactorSetup extends Component
{
    public ?string $secret = null;
    public ?string $qrCodeUrl = null;
    public string $verificationCode = '';
    public bool $enabled = false;
    public bool $showCodes = false;
    public array $recoveryCodes = [];

    public function mount(): void
    {
        $user = Auth::user();

        if ($user->two_factor_secret) {
            $this->enabled = true;
            $this->recoveryCodes = json_decode($user->two_factor_recovery_codes, true) ?? [];
        }
    }

    public function enableTwoFactor(): void
    {
        $user = Auth::user();

        if (! $user->two_factor_secret) {
            $secret = app(GenerateTwoFactorAuthenticationSecret::class)->handle($user);
            $this->secret = $secret;
            $this->qrCodeUrl = $user->twoFactorQrCodeUrl();
        }

        $this->dispatch('show-setup-modal');
    }

    public function confirmTwoFactor(): void
    {
        $this->validate([
            'verificationCode' => ['required', 'string', 'size:6'],
        ]);

        $user = Auth::user();

        $result = app(EnableTwoFactorAuthentication::class)->handle(
            $user,
            $this->verificationCode
        );

        if ($result) {
            $this->enabled = true;
            $this->recoveryCodes = json_decode($user->two_factor_recovery_codes, true) ?? [];
            $this->showCodes = true;

            session()->flash('success', 'Two-factor authentication enabled successfully.');

            activity('admin-2fa')
                ->performedOn($user)
                ->log('Admin enabled 2FA');
        } else {
            $this->addError('verificationCode', 'Invalid verification code.');
        }
    }

    public function disableTwoFactor(): void
    {
        $user = Auth::user();
        $user->forceFill([
            'two_factor_secret' => null,
            'two_factor_recovery_codes' => null,
        ])->save();

        $this->enabled = false;
        $this->secret = null;
        $this->qrCodeUrl = null;
        $this->recoveryCodes = [];

        session()->flash('success', 'Two-factor authentication disabled.');

        activity('admin-2fa')
            ->performedOn($user)
            ->log('Admin disabled 2FA');
    }

    public function regenerateRecoveryCodes(): void
    {
        $user = Auth::user();
        $user->generateRecoveryCodes();

        $this->recoveryCodes = json_decode($user->two_factor_recovery_codes, true) ?? [];
        $this->showCodes = true;

        session()->flash('success', 'Recovery codes regenerated.');
    }

    public function render()
    {
        return view('livewire.admin.two-factor-setup');
    }
}
```

### 2FA Challenge Livewire Component

```php
// app/Livewire/Admin/TwoFactorChallenge.php

namespace App\Livewire\Admin;

use Livewire\Component;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\RateLimiter;
use Laravel\Fortify\Actions\ConfirmTwoFactorCode;

class TwoFactorChallenge extends Component
{
    public string $code = '';
    public bool $usingRecoveryCode = false;
    public string $recoveryCode = '';

    protected array $rules = [
        'code' => ['required', 'string', 'size:6'],
        'recoveryCode' => ['required_with:usingRecoveryCode', 'string'],
    ];

    public function challenge(): void
    {
        $this->validate();

        $user = Auth::user();
        $key = 'admin-2fa:' . $user->id;

        if (RateLimiter::tooManyAttempts($key, 5)) {
            $seconds = RateLimiter::availableIn($key);
            session()->flash('error', "Too many attempts. Please try again in {$seconds} seconds.");
            return;
        }

        if ($this->usingRecoveryCode) {
            $this->validate(['recoveryCode' => ['required', 'string']]);
            $valid = $user->validateRecoveryCode($this->recoveryCode);
        } else {
            $valid = app(ConfirmTwoFactorCode::class)->handle($user, $this->code);
        }

        if ($valid) {
            RateLimiter::clear($key);
            session(['admin_2fa_verified' => true]);
            session()->flash('success', 'Two-factor verification successful.');

            activity('admin-2fa')
                ->performedOn($user)
                ->log('Admin completed 2FA challenge');

            redirect()->intended('/admin/dashboard');
        } else {
            RateLimiter::hit($key, 60);
            $this->addError('code', 'Invalid verification code.');
        }
    }

    public function render()
    {
        return view('livewire.admin.two-factor-challenge');
    }
}
```

## Admin Password Confirmation

### Password Confirmation Middleware

```php
// app/Http/Middleware/AdminPasswordConfirm.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Symfony\Component\HttpFoundation\Response;

class AdminPasswordConfirm
{
    /**
     * Require password confirmation for sensitive admin operations.
     *
     * @param  int $minutes  How long confirmation is valid (default: 30)
     */
    public function handle(Request $request, Closure $next, int $minutes = 30): Response
    {
        if (Auth::guest()) {
            return redirect('/admin/login');
        }

        if (Auth::user()->hasRole('super_admin')) {
            return $next($request);
        }

        $confirmedAt = session('admin_password_confirmed_at');

        if (! $confirmedAt || now()->diffInMinutes($confirmedAt) > $minutes) {
            if ($request->expectsJson()) {
                return response()->json([
                    'message' => 'Password confirmation required.',
                    'confirm_url' => route('admin.password.confirm'),
                ], 423);
            }

            session()->put('url.intended', $request->url());
            return redirect()->route('admin.password.confirm');
        }

        return $next($request);
    }
}
```

## Admin Session Management

### Session Service

```php
// app/Services/AdminSessionService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Session;

class AdminSessionService
{
    /**
     * Create an admin session with tracking.
     */
    public function createAdminSession(User $user): void
    {
        Auth::login($user);

        DB::table('admin_sessions')->insert([
            'user_id' => $user->id,
            'session_id' => Session::getId(),
            'ip_address' => request()->ip(),
            'user_agent' => request()->userAgent(),
            'created_at' => now(),
            'last_activity_at' => now(),
        ]);

        activity('admin-session')
            ->performedOn($user)
            ->withProperties([
                'ip' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ])
            ->log('Admin session created');
    }

    /**
     * Validate admin session is still active.
     */
    public function validateSession(User $user): bool
    {
        $session = DB::table('admin_sessions')
            ->where('user_id', $user->id)
            ->where('session_id', Session::getId())
            ->where('is_revoked', false)
            ->first();

        if (! $session) {
            return false;
        }

        // Check session timeout (60 minutes)
        $lastActivity = now()->parse($session->last_activity_at);
        if ($lastActivity->diffInMinutes(now()) > 60) {
            $this->revokeSession($user, $session->id);
            return false;
        }

        // Update last activity
        DB::table('admin_sessions')
            ->where('id', $session->id)
            ->update(['last_activity_at' => now()]);

        return true;
    }

    /**
     * Revoke a specific admin session.
     */
    public function revokeSession(User $user, int $sessionId): void
    {
        DB::table('admin_sessions')
            ->where('id', $sessionId)
            ->where('user_id', $user->id)
            ->update([
                'is_revoked' => true,
                'revoked_at' => now(),
            ]);

        activity('admin-session')
            ->performedOn($user)
            ->log('Admin session revoked');
    }

    /**
     * Revoke all admin sessions except current.
     */
    public function revokeAllOtherSessions(User $user): void
    {
        $currentSessionId = Session::getId();

        DB::table('admin_sessions')
            ->where('user_id', $user->id)
            ->where('session_id', '!=', $currentSessionId)
            ->where('is_revoked', false)
            ->update([
                'is_revoked' => true,
                'revoked_at' => now(),
            ]);

        activity('admin-session')
            ->performedOn($user)
            ->log('All other admin sessions revoked');
    }

    /**
     * Get all active admin sessions for a user.
     */
    public function getActiveSessions(User $user): array
    {
        return DB::table('admin_sessions')
            ->where('user_id', $user->id)
            ->where('is_revoked', false)
            ->orderBy('last_activity_at', 'desc')
            ->get()
            ->map(fn($s) => (array) $s)
            ->toArray();
    }
}
```

## Admin IP Allowlisting

### IP Allowlist Middleware

```php
// app/Http/Middleware/AdminIpAllowlist.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Symfony\Component\HttpFoundation\Response;

class AdminIpAllowlist
{
    public function handle(Request $request, Closure $next): Response
    {
        $allowedIps = config('admin.ip_allowlist', []);

        if (empty($allowedIps)) {
            return $next($request);
        }

        $clientIp = $request->ip();

        if (! in_array($clientIp, $allowedIps)) {
            activity('admin-ip-blocked')
                ->performdOn(Auth::user())
                ->withProperties([
                    'ip' => $clientIp,
                    'attempted_url' => $request->url(),
                ])
                ->log("Admin access blocked from IP: {$clientIp}");

            abort(403, 'Access denied from your IP address.');
        }

        return $next($request);
    }
}
```

## Admin Password Policy

### Password Expiration Check

```php
// app/Services/AdminPasswordPolicyService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\Hash;

class AdminPasswordPolicyService
{
    /**
     * Check if admin password has expired.
     */
    public function isPasswordExpired(User $user): bool
    {
        $maxAgeDays = config('admin.password.max_age_days', 90);

        if (! $user->password_changed_at) {
            return true;
        }

        return $user->password_changed_at->addDays($maxAgeDays)->isPast();
    }

    /**
     * Check if password meets admin requirements.
     */
    public function validatePasswordStrength(string $password): array
    {
        $errors = [];
        $config = config('admin.password');

        if (strlen($password) < $config['min_length']) {
            $errors[] = "Password must be at least {$config['min_length']} characters.";
        }

        if ($config['require_uppercase'] && ! preg_match('/[A-Z]/', $password)) {
            $errors[] = 'Password must contain at least one uppercase letter.';
        }

        if ($config['require_lowercase'] && ! preg_match('/[a-z]/', $password)) {
            $errors[] = 'Password must contain at least one lowercase letter.';
        }

        if ($config['require_numbers'] && ! preg_match('/[0-9]/', $password)) {
            $errors[] = 'Password must contain at least one number.';
        }

        if ($config['require_symbols'] && ! preg_match('/[^A-Za-z0-9]/', $password)) {
            $errors[] = 'Password must contain at least one symbol.';
        }

        return $errors;
    }

    /**
     * Check if password was recently used.
     */
    public function isPasswordReused(User $user, string $newPassword): bool
    {
        $preventReuse = config('admin.password.prevent_reuse', 12);

        $recentPasswords = DB::table('password_history')
            ->where('user_id', $user->id)
            ->orderBy('created_at', 'desc')
            ->limit($preventReuse)
            ->pluck('password')
            ->toArray();

        foreach ($recentPasswords as $oldPassword) {
            if (Hash::check($newPassword, $oldPassword)) {
                return true;
            }
        }

        return false;
    }

    /**
     * Store password in history.
     */
    public function storePasswordHistory(User $user): void
    {
        DB::table('password_history')->insert([
            'user_id' => $user->id,
            'password' => $user->password,
            'created_at' => now(),
        ]);

        // Keep only last 24 entries
        $keepIds = DB::table('password_history')
            ->where('user_id', $user->id)
            ->orderBy('created_at', 'desc')
            ->limit(24)
            ->pluck('id');

        DB::table('password_history')
            ->where('user_id', $user->id)
            ->whereNotIn('id', $keepIds)
            ->delete();
    }
}
```

```php
// app/Livewire/Admin/Dashboard.php

namespace App\Livewire\Admin;

use Livewire\Component;
use App\Models\User;
use App\Models\Theme;
use App\Models\Order;
use App\Models\Subscription;
use Illuminate\Support\Facades\DB;

class Dashboard extends Component
{
    public array $stats = [];
    public array $recentActivity = [];
    public array $systemHealth = [];

    public function mount(): void
    {
        $this->loadStats();
        $this->loadRecentActivity();
        $this->loadSystemHealth();

    protected function loadStats(): void
    {
        $this->stats = [

            ->get()

            'queue_status' => $this->checkQueue(),

            'disk_usage' => $this->checkDiskUsage(),
            'php_version' => phpversion(),

    {
        try {

        } catch (\Exception) {
            return 'unavailable';
        }
    }

    protected function checkQueue(): string
    {
        try {
            $size = DB::table('jobs')->count();
            return $size > 1000 ? 'backlogged' : 'healthy';
        } catch (\Exception) {
            return 'unavailable';
        }
    }

    {
        try {
            DB::connection()->getPdo();
            return 'connected';
        } catch (\Exception) {
            return 'disconnected';
        }

    {
        $total = disk_total_space('/');
        $free = disk_free_space('/');
        $used = $total - $free;

        return [
            'total' => round($total / 1073741824, 2) . ' GB',
            'used' => round($used / 1073741824, 2) . ' GB',
            'free' => round($free / 1073741824, 2) . ' GB',
            'percentage' => round(($used / $total) * 100, 1) . '%',
```

```php
// app/Services/AdminSecurityMonitor.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Mail;

class AdminSecurityMonitor
{
    /**
     * Detect multiple failed login attempts from same IP.
     */
    public function detectBruteForce(string $ip, int $threshold = 10, int $windowMinutes = 15): bool
    {
        $attempts = DB::table('activity_log')
            ->where('log_name', 'admin-auth')
            ->where('description', 'Admin login failed')
            ->where('properties->ip', $ip)
            ->where('created_at', '>=', now()->subMinutes($windowMinutes))
            ->count();

        return $attempts >= $threshold;
    }

    /**
     * Detect login from new location.
     */
    public function detectNewLocation(User $user, string $currentIp): bool
    {
        $lastLogin = DB::table('activity_log')
            ->where('log_name', 'admin-auth')
            ->where('subject_type', User::class)
            ->where('subject_id', $user->id)
            ->where('description', 'Admin login successful')
            ->orderBy('created_at', 'desc')
            ->first();

        if (! $lastLogin) {
            return true;
        }

        $lastProperties = json_decode($lastLogin->properties, true);
        $lastIp = $lastProperties['ip'] ?? null;

        return $lastIp && $lastIp !== $currentIp;
    }

    /**
     * Detect rapid admin actions (possible automation).
     */
    public function detectRapidActions(User $user, int $threshold = 20, int $windowSeconds = 60): bool
    {
        $actions = DB::table('admin_activity_log')
            ->where('user_id', $user->id)
            ->where('created_at', '>=', now()->subSeconds($windowSeconds))
            ->count();

        return $actions >= $threshold;
    }

    /**
     * Detect privilege escalation attempts.
     */
    public function detectPrivilegeEscalation(User $user): bool
    {
        $recentRoleChanges = DB::table('activity_log')
            ->where('log_name', 'role-management')
            ->where('properties->assigned_by', $user->id)
            ->where('created_at', '>=', now()->subHours(24))
            ->count();

        return $recentRoleChanges >= 5;
    }

    /**
     * Send security alert to super admins.
     */
    public function sendSecurityAlert(string $alertType, array $context): void
    {
        $superAdmins = User::whereHas('roles', fn($q) => $q->where('name', 'super_admin'))->get();

        foreach ($superAdmins as $admin) {
            Mail::to($admin->email)->send(
                new \App\Mail\AdminSecurityAlertMail($alertType, $context)
            );
        }

        activity('admin-security')
            ->withProperties([
                'alert_type' => $alertType,
                'context' => $context,
            ])
            ->log("Security alert: {$alertType}");
    }

    /**
     * Get security summary for admin dashboard.
     */
    public function getSecuritySummary(): array
    {
        return [
            'failed_logins_24h' => DB::table('activity_log')
                ->where('log_name', 'admin-auth')
                ->where('description', 'Admin login failed')
                ->where('created_at', '>=', now()->subHours(24))
                ->count(),
            'successful_logins_24h' => DB::table('activity_log')
                ->where('log_name', 'admin-auth')
                ->where('description', 'Admin login successful')
                ->where('created_at', '>=', now()->subHours(24))
                ->count(),
            'active_admin_sessions' => DB::table('admin_sessions')
                ->where('is_revoked', false)
                ->count(),
            'sensitive_actions_24h' => DB::table('admin_activity_log')
                ->where('created_at', '>=', now()->subHours(24))
                ->count(),
            'locked_out_ips' => $this->getLockedOutIps(),
        ];
    }

    /**
     * Get IPs currently locked out.
     */
    protected function getLockedOutIps(): array
    {
        return DB::table('activity_log')
            ->where('log_name', 'admin-auth')
            ->where('description', 'Admin login failed')
            ->where('created_at', '>=', now()->subMinutes(15))
            ->select('properties->ip as ip', DB::raw('count(*) as attempts'))
            ->groupBy('properties->ip')
            ->having('attempts', '>=', 3)
            ->pluck('attempts', 'ip')
            ->toArray();
    }
}
```

### Admin Authentication Flow Diagram

```text
Full Admin Authentication Flow:

    User visits /admin/login
        |
        v
    Rate limit check (3/min per IP)
        | (if exceeded -> 429 Too Many Requests)
        v
    Credential validation
        | (email + password check)
        v
    Role verification
        | (must be admin or super_admin)
        | (if not -> generic "invalid credentials")
        v
    Suspended account check
        | (if suspended -> "account suspended" message)
        v
    Password validity check
        | (if expired -> redirect to password change)
        v
    Session creation
        | (Redis session with admin tracking)
        v
    2FA check
        | (if 2FA enabled -> redirect to challenge)
        v
    IP allowlist check
        | (if configured and IP not allowed -> 403)
        v
    Login audit log entry
        | (IP, user agent, timestamp, success)
        v
    Email notification
        | (if new location detected)
        v
    Redirect to /admin/dashboard
        |
        v
    Password confirmation check
        | (every 30 minutes for sensitive ops)
        v
    Admin panel accessible
```

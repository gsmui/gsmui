# 06.12 - Permissions

**Project:** GsmUi
**Domain:** Core Platform
**Version:** 1.0.0

---

# Purpose

This document defines the database schema for the Permissions domain. It covers global roles and permissions (Spatie Permission pattern), team-scoped custom roles, and polymorphic role/permission assignment to users, teams, and other models.

References: [06.01-design-principles.md](./06.01-design-principles.md) | [06.02-naming-conventions.md](./06.02-naming-conventions.md) | [06.03-common-columns.md](./06.03-common-columns.md) | [06.04-relationships.md](./06.04-relationships.md)

# 1. Roles (Global)

## Schema

```
id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
name        VARCHAR(255)       NOT NULL
guard_name  VARCHAR(255)       NOT NULL DEFAULT 'web'
created_at  DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3)
updated_at  DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3)
```

CHARSET = utf8mb4, COLLATE = utf8mb4_unicode_ci

## Indexes

| Index Name | Columns | Type |
|---|---|---|
| roles_pk | id | PRIMARY |
| roles_name_guard_name_unique | name, guard_name | UNIQUE |
| roles_guard_name_index | guard_name | INDEX |

## Constraints

- Composite unique: `(name, guard_name)` — a role name is unique within a guard.
- `guard_name` defaults to `'web'` for session-based authentication. API tokens use `'api'`.

## Soft Delete

Not applicable. Role definitions are configuration data, not user-editable content.

## Relationships

```
roles 1 ──* role_permissions
roles 1 ──* model_has_roles
roles 1 ──* user_roles
```

## Eloquent Model

```php
<?php

namespace App\Domains\Permissions\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;

class Role extends Model
{
    protected $fillable = [
        'name',
        'guard_name',
    ];

    public function permissions(): BelongsToMany
    {
        return $this->belongsToMany(Permission::class, 'role_permissions');
    }

    public function users(): BelongsToMany
    {
        return $this->belongsToMany(User::class, 'user_roles');
    }
}
```

# 3. Role Permissions (Pivot)

## Schema

```
id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
role_id     BIGINT UNSIGNED    NOT NULL
permission_id BIGINT UNSIGNED  NOT NULL
created_at  DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3)
```

CHARSET = utf8mb4, COLLATE = utf8mb4_unicode_ci

## Indexes

| Index Name | Columns | Type |
|---|---|---|
| role_permissions_pk | id | PRIMARY |
| role_permissions_role_id_permission_id_unique | role_id, permission_id | UNIQUE |
| role_permissions_role_id_index | role_id | INDEX |
| role_permissions_permission_id_index | permission_id | INDEX |

## Constraints

- Composite unique: `(role_id, permission_id)` — a permission cannot be assigned to the same role twice.
- `role_id` references `roles.id` with `ON DELETE CASCADE`.
- `permission_id` references `permissions.id` with `ON DELETE CASCADE`.

## Soft Delete

Not applicable. Pivot records have no independent existence.

## Relationships

```
role_permissions belongsTo roles
role_permissions belongsTo permissions
```

## Schema

```
id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
permission_id BIGINT UNSIGNED  NOT NULL
model_type  VARCHAR(255)       NOT NULL
model_id    BIGINT UNSIGNED    NOT NULL
created_at  DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3)
```

CHARSET = utf8mb4, COLLATE = utf8mb4_unicode_ci

## Indexes

| Index Name | Columns | Type |
|---|---|---|
| model_has_permissions_pk | id | PRIMARY |
| model_has_permissions_permission_id_model_type_model_id_unique | permission_id, model_type, model_id | UNIQUE |
| model_has_permissions_model_type_model_id_index | model_type, model_id | INDEX |

Not applicable. Pivot records have no independent existence.

| Table | Primary Key | Foreign Keys | Soft Delete | Notes |
|---|---|---|---|---|
| roles | id | — | No | Global roles, unique (name, guard_name) |
| permissions | id | — | No | Global permissions, unique (name, guard_name) |
| role_permissions | id | role_id → roles, permission_id → permissions | No | Pivot, unique (role_id, permission_id) |

# Relationship Diagram

```
users ──< user_roles >── roles ──< role_permissions >── permissions
                          │
teams ──< team_roles ─────┘
          │
          └──< team_role_permissions >── permissions

Any model (User, Team) ──< model_has_roles >── roles
Any model (User, Team) ──< model_has_permissions >── permissions
```

---

# Permission Resolution Order

When checking if a model has a permission, the application resolves in this order:

1. **Direct assignment** — `model_has_permissions` for the exact model
2. **Role assignment** — permissions granted via `model_has_roles` → `role_permissions`
3. **Team role assignment** — if the model is a team member, permissions from `team_roles` → `team_role_permissions`

Cache the resolved permission set per model to avoid repeated joins across these tables.

---

# Locked Decisions

- **Global roles and permissions** use the `roles`, `permissions`, `role_permissions`, and `user_roles` tables. No per-role permission tables.
- **Team roles** use `team_roles` and `team_role_permissions`. Default team roles are Owner/Admin/Member, but teams may define custom roles.
- **Polymorphic assignment** (`model_has_roles`, `model_has_permissions`) supports assigning roles/permissions to any model, not just users. Application layer restricts which models are eligible.
- **No per-table permissions** — all permission definitions live in the single `permissions` table. Team roles share the same permission namespace as global roles.

# 13. Role Hierarchy

## Hierarchy Levels

```
Level 0: system.admin        (Super Administrator)
Level 1: team.owner          (Team Owner)
Level 2: team.admin          (Team Administrator)
Level 3: team.member         (Team Member)
Level 4: team.viewer         (Team Viewer)
```

## Inheritance Rules

1. Higher-level roles implicitly include all permissions of lower-level roles.
2. A user cannot assign a role higher than their own level.
3. Team roles (levels 1-4) are scoped to a single team.
4. System roles (level 0) operate globally across all teams.

## Role Upgrade/Downgrade Constraints

```php
<?php

namespace App\Domains\Permissions\Actions;

use App\Domains\Permissions\Models\Role;

class RoleHierarchyValidator
{
    private const HIERARCHY = [
        'system.admin' => 0,
        'team.owner' => 1,
        'team.admin' => 2,
        'team.member' => 3,
        'team.viewer' => 4,
    ];

    public function canAssignRole(string $assignerRole, string $targetRole): bool
    {
        $assignerLevel = self::HIERARCHY[$assignerRole] ?? 99;
        $targetLevel = self::HIERARCHY[$targetRole] ?? 99;

        return $assignerLevel < $targetLevel;
    }

    public function getRoleLevel(string $role): int
    {
        return self::HIERARCHY[$role] ?? 99;
    }

    public function isHigherOrEqual(string $roleA, string $roleB): bool
    {
        return $this->getRoleLevel($roleA) <= $this->getRoleLevel($roleB);
    }
}
```

# 14. Team Permissions (Extended)

## Team Permission Resolution

When checking team-scoped permissions, the system resolves in this order:

1. **Direct team role** — `team_members.role` determines the base role.
2. **Team role permissions** — `team_roles` → `team_role_permissions` for custom roles.
3. **Global override** — `model_has_roles` or `model_has_permissions` with global scope can override team permissions.
4. **Explicit denial** — If any level explicitly denies a permission, it is denied regardless of higher-level grants.

## Team Permission Evaluation Flow

```
1. Fetch user's team_members record for the target team
2. Load team_role → team_role_permissions for the user's team role
3. Merge with any model_has_permissions direct assignments
4. Check for explicit deny entries
5. Return merged permission set
```

## Dynamic Permission Registration Service

```php
<?php

namespace App\Domains\Permissions\Services;

use App\Domains\Permissions\Models\Permission;

class PermissionRegistry
{
    private array $registered = [];

    public function register(string $domain, string $resource, array $actions): void
    {
        foreach ($actions as $action) {
            $name = "{$domain}.{$resource}.{$action}";
            $this->registered[$name] = [
                'domain' => $domain,
                'resource' => $resource,
                'action' => $action,
            ];
        }
    }

    public function sync(): void
    {
        foreach ($this->registered as $name => $meta) {
            Permission::updateOrCreate(
                ['name' => $name, 'guard_name' => 'web'],
                ['metadata' => $meta]
            );
        }

        $registeredNames = array_keys($this->registered);
        Permission::where('guard_name', 'web')
            ->whereNotIn('name', $registeredNames)
            ->delete();
    }

    public function getRegistered(): array
    {
        return $this->registered;
    }
}
```

# 17. Policy Definitions

## Base Policy Pattern

```php

namespace App\Domains\Permissions\Policies;

abstract class BasePolicy

    use HandlesAuthorization;

    protected string $permissionPrefix;

    {
        if ($user->hasRole('system.admin')) {
            return true;

    {
        return $user->hasPermission("{$this->permissionPrefix}.view");

    public function view(User $user, $model): bool
    {

    }

    public function create(User $user): bool
    {
        return $user->hasPermission("{$this->permissionPrefix}.create");
    }

    public function update(User $user, $model): bool
    {
        return $user->hasPermission("{$this->permissionPrefix}.edit");
    }

    public function delete(User $user, $model): bool
    {
        return $user->hasPermission("{$this->permissionPrefix}.delete");
    }
}
```

# 20. Permission Resolution Algorithm

## Full Resolution Flow

```
function hasPermission(user, permission, team = null):
    // 1. Super admin bypass
    if user.hasRole('system.admin'):
        return ALLOW

    // 2. Direct permission assignment
    direct = model_has_permissions.where(
        model_type = User,
        model_id = user.id,
        permission_id = permission.id
    )
    if direct.exists:
        return ALLOW

    // 3. Global role permissions
    userRoles = user_roles.where(user_id = user.id)
    for each role in userRoles:
        rolePerms = role_permissions.where(role_id = role.id)
        if rolePerms.contains(permission):
            return ALLOW

    // 4. Team-specific resolution
    if team is not null:
        membership = team_members.where(
            team_id = team.id,
            user_id = user.id
        )
        if membership.exists:
            teamRole = team_roles.where(id = membership.role_id)
            if teamRole is not null:
                teamPerms = team_role_permissions.where(team_role_id = teamRole.id)
                if teamPerms.contains(permission):
                    return ALLOW

    // 5. Explicit denial check
    if any level explicitly denies the permission:
        return DENY

    // 6. Default deny
    return DENY
```

## Cache Hit Rate Monitoring

```php
<?php

namespace App\Domains\Permissions\Services;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Log;

class PermissionCacheMonitor
{
    public function recordHit(string $key): void
    {
        $date = now()->format('Y-m-d');
        $hour = now()->format('H');
        Cache::increment("perm_cache_hits:{$date}:{$hour}");
        Cache::increment("perm_cache_hits:{$date}:total");
    }

    public function recordMiss(string $key): void
    {
        $date = now()->format('Y-m-d');
        $hour = now()->format('H');
        Cache::increment("perm_cache_misses:{$date}:{$hour}");
        Cache::increment("perm_cache_misses:{$date}:total");
    }

    public function getHitRate(string $date = null): float
    {
        $date = $date ?? now()->format('Y-m-d');
        $hits = Cache::get("perm_cache_hits:{$date}:total", 0);
        $misses = Cache::get("perm_cache_misses:{$date}:total", 0);
        $total = $hits + $misses;
        return $total > 0 ? round($hits / $total * 100, 2) : 0;
    }

    public function logDailyReport(): void
    {
        $hitRate = $this->getHitRate();
        Log::info('Permission cache daily report', [
            'date' => now()->format('Y-m-d'),
            'hit_rate' => $hitRate . '%',
        ]);
    }
}
```

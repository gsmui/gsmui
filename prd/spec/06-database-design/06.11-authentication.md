# 1. Password Reset Tokens

## Schema

```
id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
user_id     BIGINT UNSIGNED    NOT NULL
token       VARCHAR(255)       NOT NULL
expires_at  DATETIME(3)        NOT NULL
created_at  DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3)
updated_at  DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3)
```

CHARSET = utf8mb4, COLLATE = utf8mb4_unicode_ci

## Indexes

| Index Name | Columns | Type |
|---|---|---|
| password_reset_tokens_pk | id | PRIMARY |
| password_reset_tokens_token_unique | token | UNIQUE |
| password_reset_tokens_user_id_index | user_id | INDEX |

## Constraints

- `token` is unique for lookup during reset.
- `user_id` references `users.id` with `ON DELETE CASCADE`.

## Soft Delete

Not applicable. Token records are not soft-deleted.

## Relationships

# 2. Personal Access Tokens

## Schema

```
id                BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
tokenable_type    VARCHAR(255)       NOT NULL
tokenable_id      BIGINT UNSIGNED    NOT NULL
name              VARCHAR(255)       NOT NULL
token             VARCHAR(255)       NOT NULL
abilities         JSON               NULL
last_used_at      DATETIME(3)        NULL
expires_at        DATETIME(3)        NULL
created_at        DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3)
updated_at        DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3)
```

CHARSET = utf8mb4, COLLATE = utf8mb4_unicode_ci

## Indexes

| Index Name | Columns | Type |
|---|---|---|
| personal_access_tokens_pk | id | PRIMARY |
| personal_access_tokens_token_unique | token | UNIQUE |
| personal_access_tokens_tokenable_type_tokenable_id_index | tokenable_type, tokenable_id | INDEX |

## Constraints

- `token` is unique for API authentication.
- `tokenable_type` + `tokenable_id` is a polymorphic reference to `users` or `teams`. No database-level foreign key constraint. Application validates via `morphTo`.

## Soft Delete

Not applicable. Token records are not soft-deleted. Expired tokens remain for audit purposes.

## Relationships

```
personal_access_tokens morphTo tokenable (User | Team)
```

## Schema

```
id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
user_id     BIGINT UNSIGNED    NOT NULL
type        VARCHAR(100)       NOT NULL
secret      TEXT               NOT NULL
recovery_codes JSON            NULL

created_at  DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3)
updated_at  DATETIME(3)        NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3)
```

CHARSET = utf8mb4, COLLATE = utf8mb4_unicode_ci

## Indexes

| Index Name | Columns | Type |
|---|---|---|
| two_factor_auth_pk | id | PRIMARY |
| two_factor_auth_user_id_unique | user_id | UNIQUE |

## Constraints

- `user_id` is unique — one 2FA record per user.

## Soft Delete

Not applicable. 2FA records follow the user lifecycle.

## Relationships

```
two_factor_auth belongsTo users
```

# Table Summary

| Table | Primary Key | Foreign Keys | Soft Delete | Notes |
|---|---|---|---|---|
| password_reset_tokens | id | user_id → users | No | Unique token, expires_at required |
| personal_access_tokens | id | morphTo (tokenable) | No | Polymorphic, unique token, abilities JSON |
| sessions | id (string) | user_id → users (nullable) | No | Laravel session table, PK is string |
| login_attempts | id | — | No | Rate-limiting, no FK |
| email_verifications | id | user_id → users | No | Unique token |
| two_factor_auth | id | user_id → users | No | 1:1, secret encrypted |

---

# Security Considerations

1. **Token storage**: `personal_access_tokens.token` stores the plaintext token at creation for lookup. Laravel Sanctum hashes the token for display. Never expose the full token after creation.
2. **Secret encryption**: `two_factor_auth.secret` uses Laravel's `encrypted` cast. The application key must be rotated carefully — re-encryption of existing secrets is required.
3. **Session payload**: Laravel serializes session data into `sessions.payload`. Do not store unencrypted sensitive data in session.
4. **Rate limiting**: `login_attempts` tracks failed attempts per IP and email. Lockout is enforced at the application level.

```php
use Illuminate\Database\Eloquent\Relations\BelongsTo;

{
    protected $fillable = [
        'user_id', 'provider', 'provider_id', 'name',
        'email', 'avatar_url', 'token', 'refresh_token',
        'expires_at', 'scopes',
    ];

    protected $casts = [
        'token' => 'encrypted',
        'refresh_token' => 'encrypted',
        'expires_at' => 'datetime',
        'scopes' => 'array',
    ];

    protected $hidden = ['token', 'refresh_token'];

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }

    public function isExpired(): bool
    {
        return $this->expires_at && $this->expires_at->isPast();
    }

    public function hasScope(string $scope): bool
    {
        return in_array($scope, $this->scopes ?? []);
    }
}
```

## Passkey Registration Flow

```
1. Client calls POST /api/auth/passkeys/register/begin
2. Server generates WebAuthn challenge, stores in cache
3. Client receives challenge, prompts biometric/PIN
4. Authenticator creates key pair, signs challenge
5. Client sends signed assertion to POST /api/auth/passkeys/register/complete
6. Server verifies signature, stores public key and credential_id
7. Passkey record created in passkeys table
```

## Passkey Authentication Flow

```
1. Client calls POST /api/auth/passkeys/authenticate/begin
2. Server generates challenge, stores in cache
3. Client receives challenge, prompts biometric/PIN
4. Authenticator signs challenge with stored private key
5. Client sends signed assertion to POST /api/auth/passkeys/authenticate/complete
6. Server verifies signature against stored public key
7. Counter checked for replay attack prevention
8. Session created, user authenticated
```

# 12. Password Reset Tokens (Extended)

## Token Generation

```php
<?php

namespace App\Domains\Authentication\Services;

use App\Domains\Authentication\Models\PasswordResetToken;
use App\Domains\Users\Models\User;
use Illuminate\Support\Str;

class PasswordResetService
{
    public function generateToken(User $user): string
    {
        PasswordResetToken::where('user_id', $user->id)->delete();

        $token = Str::random(60);

        PasswordResetToken::create([
            'user_id' => $user->id,
            'token' => hash('sha256', $token),
            'expires_at' => now('UTC')->addHours(1),
        ]);

        return $token;
    }

    public function validateToken(string $token): ?User
    {
        $record = PasswordResetToken::where('token', hash('sha256', $token))
            ->where('expires_at', '>', now('UTC'))
            ->first();

        if (!$record) {
            return null;
        }

        return $record->user;
    }

    public function resetPassword(string $token, string $newPassword): bool
    {
        $user = $this->validateToken($token);

        if (!$user) {
            return false;
        }

        $user->update(['password' => bcrypt($newPassword)]);
        PasswordResetToken::where('user_id', $user->id)->delete();

        return true;
    }

    public function cleanupExpired(): int
    {
        return PasswordResetToken::where('expires_at', '<', now('UTC'))->delete();
    }
}
```

## Recovery Codes

```php
<?php

namespace App\Domains\Authentication\Services;

use App\Domains\Authentication\Models\TwoFactorAuth;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Str;

class TwoFactorRecoveryService
{
    public function generateRecoveryCodes(): array
    {
        $codes = [];
        for ($i = 0; $i < 10; $i++) {
            $codes[] = strtoupper(Str::random(4) . '-' . Str::random(4));
        }
        return $codes;
    }

    public function hashCodes(array $codes): array
    {
        return array_map(fn ($code) => Hash::make($code), $codes);
    }

    public function useRecoveryCode(TwoFactorAuth $auth, string $code): bool
    {
        $hashedCodes = $auth->recovery_codes ?? [];

        foreach ($hashedCodes as $index => $hashedCode) {
            if (Hash::check($code, $hashedCode)) {
                unset($hashedCodes[$index]);
                $auth->update(['recovery_codes' => array_values($hashedCodes)]);
                return true;
            }
        }

        return false;
    }

    public function regenerateRecoveryCodes(TwoFactorAuth $auth): array
    {
        $codes = $this->generateRecoveryCodes();
        $auth->update(['recovery_codes' => $this->hashCodes($codes)]);
        return $codes;
    }
}
```

## 2FA Verification Flow

```
1. User enters email + password
2. System validates credentials
3. If 2FA enabled:
   a. Return 2FA challenge page
   b. User enters TOTP code or recovery code
   c. System validates code against stored secret
   d. If valid, session marked as 2FA verified
4. If 2FA not enabled:
   a. Session created directly
```

## 2FA Setup Service

```php
<?php

namespace App\Domains\Authentication\Services;

use App\Domains\Authentication\Models\TwoFactorAuth;
use App\Domains\Users\Models\User;
use PragmaRX\Google2FA\Google2FA;

class TwoFactorSetupService
{
    private Google2FA $google2fa;

    public function __construct()
    {
        $this->google2fa = new Google2FA();
    }

    public function generateSecretKey(): string
    {
        return $this->google2fa->generateSecretKey();
    }

    public function getQrCodeUrl(User $user, string $secret): string
    {
        return $this->google2fa->getQRCodeUrl(
            config('app.name'),
            $user->email,
            $secret
        );
    }

    public function verifyCode(string $secret, string $code): bool
    {
        return $this->this->google2fa->verifyKey($secret, $code, 1);
    }

    public function enable2FA(User $user, string $secret, string $code): array
    {
        if (!$this->verifyCode($secret, $code)) {
            throw new \InvalidArgumentException('Invalid 2FA code.');
        }

        $recoveryService = app(TwoFactorRecoveryService::class);
        $recoveryCodes = $recoveryService->generateRecoveryCodes();

        TwoFactorAuth::updateOrCreate(
            ['user_id' => $user->id],
            [
                'type' => 'totp',
                'secret' => $secret,
                'recovery_codes' => $recoveryService->hashCodes($recoveryCodes),
                'confirmed_at' => now('UTC'),
            ]
        );

        return ['recovery_codes' => $recoveryCodes];
    }

    public function disable2FA(User $user): void
    {
        TwoFactorAuth::where('user_id', $user->id)->delete();
    }
}
```

# 15. Login Attempt Throttling (Extended)

## Throttling Configuration

| Limit | Window | Lockout Duration | Strategy |
|---|---|---|---|
| 5 failed attempts | 15 minutes | 15 minutes | Per email |
| 20 failed attempts | 1 hour | 1 hour | Per IP |
| 100 failed attempts | 24 hours | 24 hours | Per IP |

## Throttling Service

```php
<?php

namespace App\Domains\Authentication\Services;

use App\Domains\Authentication\Models\FailedLogin;
use App\Domains\Authentication\Models\LoginAttempt;

class ThrottlingService
{
    public function isEmailThrottled(string $email): bool
    {
        $recentFailures = FailedLogin::where('email', $email)
            ->where('successful', false)
            ->where('created_at', '>=', now('UTC')->subMinutes(15))
            ->count();

        return $recentFailures >= 5;
    }

    public function isIpThrottled(string $ipAddress): bool
    {
        $recentFailures = FailedLogin::where('ip_address', $ipAddress)
            ->where('successful', false)
            ->where('created_at', '>=', now('UTC')->subMinutes(60))
            ->count();

        return $recentFailures >= 20;
    }

    public function recordFailure(string $email, string $ipAddress, ?string $userAgent, string $reason): void
    {
        FailedLogin::create([
            'email' => $email,
            'ip_address' => $ipAddress,
            'user_agent' => $userAgent,
            'successful' => false,
            'failure_reason' => $reason,
        ]);
    }

    public function recordSuccess(string $email, string $ipAddress, ?string $userAgent): void
    {
        FailedLogin::create([
            'email' => $email,
            'ip_address' => $ipAddress,
            'user_agent' => $userAgent,
            'successful' => true,
        ]);
    }

    public function getRemainingAttempts(string $email): int
    {
        $recentFailures = FailedLogin::where('email', $email)
            ->where('successful', false)
            ->where('created_at', '>=', now('UTC')->subMinutes(15))
            ->count();

        return max(0, 5 - $recentFailures);
    }

    public function getLockoutDuration(string $email): ?int
    {
        $recentFailures = FailedLogin::where('email', $email)
            ->where('successful', false)
            ->where('created_at', '>=', now('UTC')->subMinutes(15))
            ->count();

        if ($recentFailures < 5) {
            return null;
        }

        $lastFailure = FailedLogin::where('email', $email)
            ->where('successful', false)
            ->latest()
            ->first();

        if (!$lastFailure) {
            return null;
        }

        $lockoutEnd = $lastFailure->created_at->addMinutes(15);
        $remaining = $lockoutEnd->diffInSeconds(now('UTC'));

        return $remaining > 0 ? $remaining : 0;
    }
}
```

```php
namespace App\Domains\Authentication\Services;

use App\Domains\Authentication\Models\AuthEventLog;
use App\Domains\Users\Models\User;

class AuthEventTracker
{
    public function track(string $event, ?User $user = null, ?Request $request = null, array $properties = []): AuthEventLog
    {
        return AuthEventLog::create([
            'user_id' => $user?->id,
            'event' => $event,
            'ip_address' => $request?->ip(),
            'user_agent' => $request?->userAgent(),
            'properties' => $properties,
        ]);
    }

    public function trackLogin(User $user, Request $request): AuthEventLog
    {
        return $this->track('login', $user, $request, [
            'method' => 'password',
            'device_name' => $this->parseDeviceName($request->userAgent()),
        ]);
    }

    public function trackLoginFailure(string $email, string $reason, Request $request): AuthEventLog
    {
        return $this->track('login_failed', null, $request, [
            'email' => $email,
            'reason' => $reason,
        ]);
    }

    public function trackLogout(User $user, Request $request): AuthEventLog
    {
        return $this->track('logout', $user, $request);
    }

    private function parseDeviceName(?string $userAgent): string
    {
        if (!$userAgent) {
            return 'Unknown Device';
        }

        if (str_contains($userAgent, 'Mac')) {
            return 'macOS';
        }
        if (str_contains($userAgent, 'Windows')) {
            return 'Windows';
        }
        if (str_contains($userAgent, 'Linux')) {
            return 'Linux';
        }
        if (str_contains($userAgent, 'iPhone') || str_contains($userAgent, 'iPad')) {
            return 'iOS';
        }
        if (str_contains($userAgent, 'Android')) {
            return 'Android';
        }

        return 'Unknown Device';
    }
```

# 17. Remember Token Handling

## Token Lifecycle

```
1. User checks "Remember Me" during login
2. System generates random 60-char token
3. Token hashed (bcrypt) and stored in users.remember_token
4. Token cookie set on client (expires in 5 years)
5. On subsequent visits, cookie token compared to stored hash
6. If match, user auto-authenticated
7. On logout, remember_token cleared
```

## Implementation

```php
<?php

namespace App\Domains\Authentication\Services;

use App\Domains\Users\Models\User;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Str;

class RememberTokenService
{
    public function generateToken(): string
    {
        return Str::random(60);
    }

    public function setToken(User $user): string
    {
        $token = $this->generateToken();
        $user->update(['remember_token' => Hash::make($token)]);
        return $token;
    }

    public function clearToken(User $user): void
    {
        $user->update(['remember_token' => null]);
    }

    public function validateToken(User $user, string $token): bool
    {
        if (!$user->remember_token) {
            return false;
        }

        return Hash::check($token, $user->remember_token);
    }
}
```

# 18. Security Considerations (Extended)

## Token Storage

- `personal_access_tokens.token` stores plaintext at creation for lookup
- Laravel Sanctum hashes the token for display
- Never expose the full token after creation

## Secret Encryption

- `two_factor_auth.secret` uses Laravel's `encrypted` cast
- Application key rotation requires re-encryption of existing secrets
- Backup encryption key recommended for disaster recovery

## Session Payload

- Laravel serializes session data into `sessions.payload`
- Do not store unencrypted sensitive data in session
- Use encrypted cookies for client-side data

## Rate Limiting

- `login_attempts` tracks failed attempts per IP and email
- Lockout enforced at application level
- Progressive lockout: 5 attempts / 15 min, 20 / 1 hour, 100 / 24 hours

## Password Policy

| Rule | Requirement |
|---|---|
| Minimum length | 8 characters |
| Maximum length | 255 characters |
| Complexity | At least 1 uppercase, 1 lowercase, 1 number |
| History | No reuse of last 5 passwords |
| Expiry | No forced expiry (optional per-role) |

## Brute Force Protection

| Layer | Mechanism | Scope |
|---|---|---|
| Layer 1 | Failed login counter | Per email |
| Layer 2 | IP rate limiting | Per IP |
| Layer 3 | CAPTCHA after 3 failures | Per session |
| Layer 4 | Account lockout | Per account |

## Session Security

| Setting | Value | Description |
|---|---|---|
| `encrypt` | `true` | Encrypt all session data |
| `http_only` | `true` | No JavaScript access to cookie |
| `secure` | `null` | Auto-detect HTTPS |
| `same_site` | `lax` | CSRF protection |
| `throttle` | `10` | Regenerate session ID every 10 requests |

# 06.81 - Snippets

**Project:** GsmUi
**Domain:** Playground - Snippets
**Version:** 1.0.0

---

# Purpose

This document defines the database schema for the Snippets sub-domain of Playground — reusable code fragments created by users and shared with the community. A snippet carries an optional category, a normalized many-to-many tag set, a configurable language, and privacy/feature flags. Copy and run events are recorded as analytics via `snippet_executions`, and snippets are discoverable through a fulltext `search_vector`. Standard timestamps (`created_at`, `updated_at`, and `deleted_at` where noted) follow 06.03.

# Tables

## snippets

**Purpose:** Reusable code snippets shared by the community or created by users.
**Business Rules:** Belongs to one user; optional `category_id`. `slug` unique; `language` enum defaults to `blade`. `status`: draft→published→archived. `is_public` (default true) controls visibility; `is_featured` is editorial. `copy_count` denormalized; `search_vector` fulltext. Soft-deletable.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | NO | AUTO_INCREMENT | PK |
| user_id | BIGINT UNSIGNED | NO | — | FK → users.id (author) |
| category_id | BIGINT UNSIGNED | YES | NULL | FK → snippet_categories.id |
| title | VARCHAR(255) | NO | — | Display title |
| slug | VARCHAR(255) | NO | — | URL-friendly identifier |
| description | TEXT | YES | NULL | Snippet description |
| code | LONGTEXT | NO | — | Snippet source |
| language | ENUM('blade','html','php','javascript','css') | NO | 'blade' | Syntax type |
| is_public | BOOLEAN | NO | true | Community visibility |
| is_featured | BOOLEAN | NO | false | Editorial highlight |
| copy_count | INT UNSIGNED | NO | 0 | Denormalized copy counter |
| status | ENUM('draft','published','archived') | NO | 'draft' | Publication state |
| search_vector | TEXT | YES | NULL | Fulltext search |

**Indexes:** `PRIMARY: id` · `UNIQUE: snippets_slug_unique (slug)` · `INDEX: snippets_user_id_index (user_id)` · `INDEX: snippets_category_id_index (category_id)` · `INDEX: snippets_is_public_index (is_public)` · `FULLTEXT: snippets_search_vector_fulltext (search_vector)`

**Relationships:** belongsTo User, SnippetCategory; hasMany SnippetExecution; belongsToMany Tag (via snippet_tag).

**Migration:**

```php

```

## snippet_executions

**Purpose:** Tracks snippet copy/run events for analytics.
**Business Rules:** References a snippet; `user_id` nullable (anonymous allowed). `action` enum copy/run/view; `ip_address` IPv6-safe. No soft deletes (immutable telemetry).

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | NO | AUTO_INCREMENT | PK |
| snippet_id | BIGINT UNSIGNED | NO | — | FK → snippets.id |
| user_id | BIGINT UNSIGNED | YES | NULL | FK → users.id |
| action | ENUM('copy','run','view') | NO | — | Event type |
| ip_address | VARCHAR(45) | NO | — | Actor IP (IPv6) |

**Indexes:** `PRIMARY: id` · `INDEX: snippet_executions_snippet_id_index (snippet_id)` · `INDEX: snippet_executions_user_id_index (user_id)` · `INDEX: snippet_executions_action_index (action)` · `INDEX: snippet_executions_created_at_index (created_at)`

**Relationships:** belongsTo Snippet, User (nullable).

# Cross-Domain Relationships

- **snippets → users**: authorship; cascade to snippets, tag pivots, executions on user delete.
- **snippets → snippet_categories**: optional grouping (`nullOnDelete`).
- **snippets ↔ snippet_tags (via snippet_tag)**: many-to-many; pivot cascades on either side.
- **snippets → snippet_executions**: one-to-many analytics; cascade on snippet delete, `user_id` nullable (`nullOnDelete`).

## Advanced Query Patterns

### Complex Snippet Analytics

```php
// Snippet engagement metrics
$engagement = Snippet::selectRaw('
    s.id,
    s.title,
    s.slug,
    s.language,
    s.copy_count,
    (SELECT COUNT(*) FROM snippet_executions WHERE snippet_id = s.id AND action = "run") as run_count,
    (SELECT COUNT(*) FROM snippet_executions WHERE snippet_id = s.id AND action = "view") as view_count,
    (s.copy_count * 0.7 + (SELECT COUNT(*) FROM snippet_executions WHERE snippet_id = s.id AND action = "run") * 0.3) as engagement_score,
    DATEDIFF(NOW(), s.created_at) as days_old,
    ROUND(s.copy_count / NULLIF(DATEDIFF(NOW(), s.created_at), 0), 2) as copies_per_day
')
->where('s.is_public', TRUE)
->where('s.status', 'published')
->orderByDesc('engagement_score')
->limit(20)
->get();

// Language popularity trend
$languageTrend = Snippet::selectRaw('
    language,
    DATE_FORMAT(created_at, "%Y-%m") as month,
    COUNT(*) as snippet_count,
    SUM(copy_count) as total_copies
')
->where('is_public', TRUE)
->where('created_at', '>=', now()->subMonths(6))
->groupBy('language', 'month')
->orderBy('month')
->get();

// Tag co-occurrence analysis
$tagCooccurrence = DB::select('
    SELECT
        t1.name as tag1,
        t2.name as tag2,
        COUNT(*) as cooccurrence_count
    FROM snippet_tag st1
    JOIN snippet_tags t1 ON st1.tag_id = t1.id
    JOIN snippet_tag st2 ON st1.snippet_id = st2.snippet_id AND st1.tag_id < st2.tag_id
    JOIN snippet_tags t2 ON st2.tag_id = t2.id
    GROUP BY t1.name, t2.name
    HAVING cooccurrence_count > 5
    ORDER BY cooccurrence_count DESC
    LIMIT 20
');
```

## Stored Procedures

### sp_create_snippet

```sql
DELIMITER //
CREATE PROCEDURE sp_create_snippet(
  IN p_user_id BIGINT,
  IN p_title VARCHAR(255),
  IN p_slug VARCHAR(255),
  IN p_description TEXT,
  IN p_code LONGTEXT,
  IN p_language VARCHAR(20),
  IN p_category_id BIGINT,
  IN p_is_public BOOLEAN,
  OUT p_snippet_id BIGINT,
  OUT p_status VARCHAR(50)
)
BEGIN
  DECLARE v_existing_slug INT;

  -- Check slug uniqueness
  SELECT COUNT(*) INTO v_existing_slug
  FROM snippets
  WHERE slug = p_slug AND deleted_at IS NULL;

  IF v_existing_slug > 0 THEN
    SET p_status = 'slug_taken';
  ELSE
    INSERT INTO snippets (
      user_id, category_id, title, slug, description, code, language,
      is_public, is_featured, copy_count, status, search_vector,
      created_at, updated_at
    ) VALUES (
      p_user_id, p_category_id, p_title, p_slug, p_description, p_code, p_language,
      p_is_public, FALSE, 0, 'draft', NULL, NOW(), NOW()
    );

    SET p_snippet_id = LAST_INSERT_ID();
    SET p_status = 'created';
  END IF;
END //
DELIMITER ;
```

### sp_copy_snippet

```sql
DELIMITER //
CREATE PROCEDURE sp_copy_snippet(
  IN p_snippet_id BIGINT,
  IN p_user_id BIGINT,
  IN p_ip_address VARCHAR(45),
  OUT p_code LONGTEXT,
  OUT p_status VARCHAR(50)
)
BEGIN
  DECLARE v_is_public BOOLEAN;
  DECLARE v_status VARCHAR(20);

  -- Check snippet exists and is accessible
  SELECT is_public, status INTO v_is_public, v_status
  FROM snippets WHERE id = p_snippet_id AND deleted_at IS NULL;

  IF v_status IS NULL THEN
    SET p_status = 'snippet_not_found';
  ELSEIF v_status != 'published' AND v_is_public = FALSE THEN
    SET p_status = 'not_accessible';
  ELSE
    -- Get code
    SELECT code INTO p_code FROM snippets WHERE id = p_snippet_id;

    -- Increment copy count atomically
    UPDATE snippets
    SET copy_count = copy_count + 1, updated_at = NOW()
    WHERE id = p_snippet_id;

    -- Log execution
    INSERT INTO snippet_executions (snippet_id, user_id, action, ip_address, created_at, updated_at)
    VALUES (p_snippet_id, p_user_id, 'copy', p_ip_address, NOW(), NOW());

    SET p_status = 'copied';
  END IF;
END //
DELIMITER ;
```

### sp_search_snippets

```sql
DELIMITER //
CREATE PROCEDURE sp_search_snippets(
  IN p_query TEXT,
  IN p_language VARCHAR(20),
  IN p_category_id BIGINT,
  IN p_limit INT,
  IN p_offset INT
)
BEGIN
  DECLARE v_query TEXT;

  -- Build search query
  SET v_query = CONCAT('%', p_query, '%');

  SELECT
    s.id,
    s.title,
    s.slug,
    s.description,
    s.language,
    s.copy_count,
    s.created_at,
    u.name AS user_name,
    sc.name AS category_name
  FROM snippets s
  JOIN users u ON s.user_id = u.id
  LEFT JOIN snippet_categories sc ON s.category_id = sc.id
  WHERE s.is_public = TRUE
    AND s.status = 'published'
    AND s.deleted_at IS NULL
    AND (p_query IS NULL OR s.title LIKE v_query OR s.description LIKE v_query)
    AND (p_language IS NULL OR s.language = p_language)
    AND (p_category_id IS NULL OR s.category_id = p_category_id)
  ORDER BY s.copy_count DESC
  LIMIT p_limit OFFSET p_offset;
END //
```

### trg_snippets_before_update

```sql
DELIMITER //
CREATE TRIGGER trg_snippets_before_update
BEFORE UPDATE ON snippets
FOR EACH ROW
BEGIN
  -- Validate slug format
  IF NEW.slug NOT REGEXP '^[a-z0-9-]+$' THEN
    SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'Slug must contain only lowercase letters, numbers, and hyphens';
  END IF;

  -- Ensure copy_count never goes negative
  IF NEW.copy_count < 0 THEN
    SET NEW.copy_count = 0;
  END IF;

  -- Auto-generate search_vector on content change
  IF NEW.title != OLD.title OR NEW.description != OLD.description OR NEW.code != OLD.code THEN
    SET NEW.search_vector = CONCAT_WS(' ', NEW.title, NEW.description, NEW.code);
  END IF;
END //
DELIMITER ;
```

```sql
      FROM snippets
```

## Data Migration Patterns

### Migrating from Legacy Snippet System

```php
// Step 1: Export legacy snippets
$legacySnippets = DB::connection('legacy')
    ->table('old_snippets')
    ->where('active', true)
    ->get();

// Step 2: Transform and import
foreach ($legacySnippets as $snippet) {
    $slug = Str::slug($snippet->title);
    $existingSlug = Snippet::where('slug', $slug)->count();
    if ($existingSlug > 0) {
        $slug = "{$slug}-{$existingSlug}";
    }

    Snippet::create([
        'user_id' => $snippet->user_id,
        'category_id' => $snippet->category_id,
        'title' => $snippet->title,
        'slug' => $slug,
        'description' => $snippet->description,
        'code' => $snippet->code,
        'language' => $snippet->language,
        'is_public' => $snippet->public,
        'status' => $snippet->published ? 'published' : 'draft',
        'copy_count' => $snippet->copies,
        'created_at' => $snippet->created_at,
        'updated_at' => now(),
    ]);
}

// Step 3: Migrate tags
$legacyTags = DB::connection('legacy')
    ->table('old_snippet_tags')
    ->get();

foreach ($legacyTags as $tag) {
    $snippet = Snippet::where('slug', Str::slug($tag->snippet_title))->first();
    $tagModel = SnippetTag::firstOrCreate(
        ['slug' => Str::slug($tag->name)],
        ['name' => $tag->name]
    );
    if ($snippet) {
        $snippet->tags()->attach($tagModel->id);
    }
}
```

### Tag Migration

```php
// Merge duplicate tags
$duplicateTags = SnippetTag::select('name')
    ->groupBy('name')
    ->havingRaw('COUNT(*) > 1')
    ->get();

foreach ($duplicateTags as $dup) {
    $tags = SnippetTag::where('name', $dup->name)->get();
    $keepTag = $tags->first();

    foreach ($tags->skip(1) as $removeTag) {
        // Move all snippet associations to the keep tag
        DB::table('snippet_tag')
            ->where('tag_id', $removeTag->id)
            ->update(['tag_id' => $keepTag->id]);

        // Remove duplicate tag
        $removeTag->delete();
    }
}
```

## Detailed Business Rules

### Snippet Lifecycle

**Snippet State Transitions:**
```
draft → published → archived
  ↑         ↓
  └─── unarchive (if archived)
```

**Creation Rules:**
- Any authenticated user can create a snippet
- `user_id` is set to the creating user's ID
- `slug` is auto-generated from `title` (lowercase, hyphenated, URL-safe)
- Slug uniqueness is enforced globally (not per-user)
- Default status is `draft`
- Default `is_public = true` — snippets are publicly visible by default
- `language` defaults to `blade`
- `code` field stores the snippet source code

**Publishing Rules:**
- Status transition: `draft` → `published`
- A snippet must have non-empty `code` before publishing
- Publishing fires `SnippetPublished` event
- Published snippets appear in the community snippet gallery
- URL pattern: `/snippets/{slug}`

**Archiving Rules:**
- Status transition: `published` → `archived`
- Archived snippets are hidden from gallery but accessible via direct URL
- Archived snippets are read-only (no code edits)
- Archiving fires `SnippetArchived` event

### Language Support

**Supported Languages:**
| Language | MIME Type | Syntax Highlighting |
|----------|-----------|-------------------|
| `blade` | text/x-blade | Yes |
| `html` | text/html | Yes |
| `php` | text/x-php | Yes |
| `javascript` | text/javascript | Yes |
| `css` | text/css | Yes |

**Language Rules:**
- Language is determined at creation time
- Language can be changed after creation (for drafts only)
- Published snippets cannot change language (would break syntax highlighting)
- Language affects syntax highlighting in the viewer

### Category System

**Category Rules:**
- Each snippet can belong to exactly one category (optional)
- Categories are flat (no parent-child hierarchy)
- Category assignment is optional — snippets can be uncategorized
- Categories are soft-deletable — deleting a category unassigns its snippets
- Category display order controlled by `sort_order`

**Default Categories:**
- "Layout" — flexbox, grid, responsive patterns
- "Animation" — transitions, GSAP, CSS animations
- "Form" — input, select, checkbox patterns
- "Data" — table, chart, API integration
- "Utility" — helper functions, mixins, variables

### Tag System

**Tag Rules:**
- Tags are a many-to-many relationship via `snippet_tag` pivot
- Tags are global (not per-user) — any user can apply existing tags
- New tags can be created inline during snippet creation
- Tag names are case-insensitive (stored lowercase)
- Maximum 10 tags per snippet (enforced at application layer)

**Tag Management:**
- Tags are created on first use
- Tags without any snippets are soft-deleted after 30 days
- Tag merging: admin can merge duplicate tags (updates pivot, soft-deletes source)

### Copy Count

**Copy Count Rules:**
- `copy_count` is incremented each time a user copies the snippet
- Copy is tracked via `snippet_executions` with `action = 'copy'`
- Count is atomic (`DB::raw('copy_count + 1')`)
- Count is denormalized — not real-time accurate but acceptable for display
- Used for "Most Copied" sorting in gallery

### Search Vector

**Search Indexing Rules:**
- `search_vector` is updated on snippet create/update
- Uses MySQL FULLTEXT index
- Searchable fields: title, description, code
- Weight: title (highest), description (medium), code (lowest)
- Search is global across all public snippets
- Filterable by: language, category, tags

## Category Management

### Category Creation

**Creation Flow:**
```
1. Admin creates category with name, slug, description
2. System normalizes slug (lowercase, hyphenated)
3. Slug uniqueness enforced
4. Category created with is_active = true, sort_order = 0
5. Category immediately available for assignment
```

**Category Deletion:**
- Categories are soft-deletable
- Deleting a category sets `category_id = NULL` on all associated snippets
- Deleted categories are hidden from category picker
- Deleted categories can be restored with their snippets

### Category Ordering

- `sort_order` controls display order in category picker and filter
- Lower numbers appear first
- Ties broken by `name` alphabetically
- Reordering is an admin action

---

## Tag Pivot Management

### Tag Assignment

**Assignment Rules:**
- Tags are assigned via the `snippet_tag` pivot table
- `(snippet_id, tag_id)` is unique — no duplicate assignments
- Pivot timestamps track when tags were assigned
- Tags can be added/removed at any time (for draft and published snippets)

### Tag Cleanup

**Orphaned Tag Rules:**
- A tag with zero snippets is considered orphaned
- Orphaned tags are soft-deleted after 30 days via scheduled command
- Soft-deleted tags are hidden from tag picker
- Tags can be restored if snippets are re-assigned

## Execution Tracking

### Event Types

| Action | Description | When Tracked |
|--------|-------------|-------------|
| `copy` | User copies snippet code | Copy button click |
| `run` | User runs snippet in playground | Run button click |
| `view` | User views snippet detail page | Page load (deduplicated per session) |

**Tracking Rules:**
- Every event is logged with `snippet_id`, `user_id` (nullable), `ip_address`
- `user_id` is NULL for anonymous views
- No soft deletes — events are immutable telemetry
- IP address is IPv6-safe (VARCHAR(45))
- User agent is logged for forensic analysis

### Deduplication

- **View deduplication:** Same user + same snippet = 1 view per 24 hours
- **Copy deduplication:** No deduplication — every copy is tracked
- **Run deduplication:** No deduplication — every run is tracked

## Security Considerations

### Code Safety

- Snippet code is rendered in a sandboxed iframe (same as Playground)
- Sandbox restrictions: no access to parent window, no cookies, no localStorage
- External scripts are blocked (only inline scripts allowed)
- Maximum code size: 50KB

### Spam Prevention

- **Rate limiting:** Max 5 snippets per user per hour
- **Content analysis:** Basic code analysis for malicious patterns
- **User reputation:** New accounts (< 7 days) require manual moderation
- **Duplicate detection:** Similar code across snippets flagged for review

### Abuse Prevention

- **Tag spam:** Max 10 tags per snippet; rate limit tag creation
- **Copy farming:** Multiple copies from same IP → flagged
- **View manipulation:** Deduplication prevents artificial view inflation

- On copy: invalidate popular cache
- On category change: invalidate categories cache

## Artisan Commands

### `snippets:cleanup-orphans`

**Purpose:** Remove orphaned tags and soft-deleted data.

**Schedule:** Daily at 03:00 UTC.

**Logic:**
```php
// Soft-delete tags with no snippets, older than 30 days
SnippetTag::whereDoesntHave('snippets')
    ->where('created_at', '<', now()->subDays(30))
    ->update(['deleted_at' => now()]);

// Force-delete soft-deleted snippets older than 90 days
Snippet::where('deleted_at', '<', now()->subDays(90))
    ->forceDelete();
```

### `snippets:rebuild-search`

**Purpose:** Rebuild search vectors for all snippets.

**Schedule:** Weekly on Sunday at 04:00 UTC.

**Logic:**

```php
Snippet::chunkById(200, function ($snippets) {

        $snippet->update([
            'search_vector' => DB::raw("CONCAT_WS(' ', '{$snippet->title}', '{$snippet->description}', '{$snippet->code}')")
        ]);
    }
});
```

### Retention Policies

| Table | Retention | Action |
|-------|-----------|--------|
| `snippets` | 90 days after soft delete | Force delete |
| `snippet_categories` | Indefinite | Soft-deleted retained |
| `snippet_tags` | 30 days without snippets | Soft-delete |
| `snippet_tag` | Cascades with snippet | Cascade delete |
| `snippet_executions` | Indefinite | Immutable telemetry |

### GDPR Compliance

- Snippets are personal data (code + user_id)
- User deletion: anonymize user_id on snippets; keep code for community value
- Execution history: anonymize user_id on snippet_executions
- Tag assignments: cascade-delete with snippet

### Copy Count Reconciliation

`copy_count` is denormalized from `snippet_executions`. The nightly
reconciliation job corrects drift:

```php
// snippets:sync-counters
Snippet::chunkById(500, function ($snippets) {
    $counts = SnippetExecution::whereIn('snippet_id', $snippets->pluck('id'))
        ->where('event_type', 'copy')
        ->selectRaw('snippet_id, COUNT(*) AS c')
        ->groupBy('snippet_id')
        ->pluck('c', 'snippet_id');

    foreach ($snippets as $snippet) {
        $snippet->updateQuietly(['copy_count' => $counts[$snippet->id] ?? 0]);
    }
});
```

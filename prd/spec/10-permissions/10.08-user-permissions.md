# 10.08 - User Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

Define the **complete permission set for the base authenticated User role** and the Pro User upgrade. Users are the foundation of the platform — they browse, purchase, configure their profile, and interact with the playground. This document covers what a standard user can and cannot do, and how Pro User permissions extend the base set.

The User role is assigned automatically upon registration. The Pro User role is assigned automatically when a user subscribes to a paid plan (see [10.17-billing-permissions.md](./10.17-billing-permissions.md) for billing integration).

## Role Progression

```text
Guest (unauthenticated)
    ↓ Register
User (base authenticated)
    ↓ Subscribe
Pro User (paid plan active)
    ↓ Apply + Approve
Creator (published content)
```

Each level inherits all permissions from the level below it. See [10.03-roles.md](./10.03-roles.md) for the complete role hierarchy.

### Marketplace Purchasing

| Permission | User | Pro User | Description |
|---|---|---|---|
| `marketplace.purchase` | ✅ | ✅ | Buy themes, components, templates |
| `marketplace.gift` | ❌ | ✅ | Gift a purchase to another user |
| `marketplace.view_cart` | ✅ | ✅ | View shopping cart |
| `marketplace.apply_coupon` | ✅ | ✅ | Apply discount codes |

**Purchase authorization flow:**

1. User clicks "Buy" on a marketplace listing
2. System checks `marketplace.purchase` permission
3. System verifies user has a valid payment method
4. Order is created with `pending` status
5. Payment is processed via billing provider
6. Order status updates to `completed`
7. License is issued to buyer
8. Creator is notified of sale
9. Analytics are updated

```php
// app/Services/MarketplacePurchaseService.php

public function purchase(User $buyer, MarketplaceListing $listing, ?string $couponCode = null): Order
{
    if (! $buyer->can('marketplace.purchase')) {
        throw new AuthorizationException('You do not have permission to make purchases.');
    }

    if (! $buyer->hasPaymentMethod()) {
        throw new PaymentRequiredException('Please add a payment method before purchasing.');
    }

    // Check for duplicate purchase
    if ($this->hasPurchased($buyer, $listing)) {
        throw new DuplicatePurchaseException('You have already purchased this item.');
    }

    $order = Order::create([
        'user_id' => $buyer->id,
        'listing_id' => $listing->id,
        'amount' => $this->calculateTotal($listing, $couponCode),
        'status' => 'pending',
    ]);

    // Process payment, issue license, notify creator
    $this->processPayment($order);
    $this->issueLicense($buyer, $listing);
    $this->notifyCreator($listing->user, $order);

    return $order;
}
```

```php
// app/Services/PlaygroundService.php

public function execute(User $user, string $code, string $language): PlaygroundResult
{
    $limits = $user->hasRole('pro_user')
        ? ['time' => 30, 'memory' => 256]
        : ['time' => 5, 'memory' => 64];

    // Check daily execution limit
    $todayCount = Cache::increment("playground:{$user->id}:" . date('Y-m-d'));
    $maxDaily = $user->hasRole('pro_user') ? 500 : 50;

    if ($todayCount > $maxDaily) {
        throw new QuotaExceededException('Daily execution limit reached.');
    }

    return $this->sandbox->run($code, $language, $limits);
}
```

## Pro User Upgrade

### Automatic Role Assignment

When a user subscribes to a paid plan, the Pro User role is assigned automatically via a billing webhook handler:

```php
// app/Listeners/AssignProRoleOnSubscription.php

namespace App\Listeners;

use App\Events\SubscriptionActivated;
use App\Models\User;

class AssignProRoleOnSubscription
{
    public function handle(SubscriptionActivated $event): void
    {
        $user = $event->subscription->user;

        if (! $user->hasRole('pro_user')) {
            $user->assignRole('pro_user');

            activity()
                ->causedBy($user)
                ->withProperties([
                    'action' => 'pro_role_assigned',
                    'plan' => $event->subscription->plan->name,
                ])
                ->log('pro_role_assigned');
        }
    }
}
```

### Automatic Role Removal

When a subscription is cancelled or expires, the Pro User role is removed and the User role remains:

```php
// app/Listeners/RemoveProRoleOnCancellation.php

namespace App\Listeners;

use App\Events\SubscriptionCancelled;
use App\Models\User;

class RemoveProRoleOnCancellation
{
    public function handle(SubscriptionCancelled $event): void
    {
        $user = $event->subscription->user;

        if ($user->hasRole('pro_user')) {
            $user->removeRole('pro_user');

            // Revoke any pro-only features
            $this->revokeProFeatures($user);

            activity()
                ->causedBy($user)
                ->withProperties([
                    'action' => 'pro_role_removed',
                    'reason' => $event->reason,
                ])
                ->log('pro_role_removed');
        }
    }

    protected function revokeProFeatures(User $user): void
    {
        // Revoke pro-only saved playground sessions beyond free limit
        // Revoke premium theme access
        // Revoke pro-only API tokens
    }
}
```

## API Token Permissions

Users can create personal API tokens for programmatic access. Token permissions are scoped to the user's role:

```php
$requestedPermissions = array_intersect($requestedPermissions, $validPermissions);
```

## Security Notes

* Users cannot escalate their own role via any client-side mechanism.
* All permission checks happen server-side in policies and gates.
* Pro User role is assigned/removed only via billing webhooks — never via client request.
* Ownership checks use database IDs, not user-supplied values.
* Rate limiting applies to all user-facing endpoints (see [09.28-rate-limiting.md](../09-authentication/09.28-rate-limiting.md)).
* Account deletion triggers a 30-day grace period before permanent removal.

#### Profile Management

```php
// app/Livewire/Dashboard/Profile.php

class Profile extends Component
{
    public string $name = '';
    public string $email = '';
    public ?string $bio = null;
    public ?string $avatarUrl = null;

    protected array $rules = [
        'name' => ['required', 'string', 'max:255'],
        'email' => ['required', 'email', 'max:255'],
        'bio' => ['nullable', 'string', 'max:500'],
    ];

    public function mount(): void
    {
        $user = auth()->user();
        $this->name = $user->name;
        $this->email = $user->email;
        $this->bio = $user->bio;
        $this->avatarUrl = $user->avatar_url;
    }

    public function update(): void
    {
        $this->authorize('users.update');
        $this->validate();

        $user = auth()->user();

        // Check if email changed
        if ($this->email !== $user->email) {
            $user->update([
                'name' => $this->name,
                'email' => $this->email,
                'email_verified_at' => null, // Require re-verification
                'bio' => $this->bio,
            ]);

            // Send verification email
            $user->sendEmailVerificationNotification();
            
            $this->dispatch('notify', type: 'info', message: 'Email changed. Please verify your new email.');
        } else {
            $user->update([
                'name' => $this->name,
                'bio' => $this->bio,
            ]);
        }

        $this->dispatch('notify', type: 'success', message: 'Profile updated.');
    }

    public function uploadAvatar(): void
    {
        $this->authorize('users.update');

        $this->validate([
            'avatar' => ['required', 'image', 'max:5120'], // 5MB max
        ]);

        $user = auth()->user();
        $path = $this->avatar->store('avatars', 'public');
        
        // Delete old avatar
        if ($user->avatar_url) {
            Storage::disk('public')->delete($user->avatar_url);
        }

        $user->update(['avatar_url' => $path]);
        
        $this->dispatch('notify', type: 'success', message: 'Avatar updated.');
    }
}
```

#### Security Settings

```php
// app/Livewire/Dashboard/Security.php

class Security extends Component
{
    public bool $twoFactorEnabled = false;
    public ?string $recoveryCodes = null;
    public Collection $sessions;

    public function mount(): void
    {
        $this->authorize('security.view');
        
        $user = auth()->user();
        $this->twoFactorEnabled = $user->two_factor_secret !== null;
        $this->sessions = $user->sessions;
    }

    public function enable2FA(): void
    {
        $this->authorize('security.enable_2fa');

        $user = auth()->user();
        
        // Generate secret
        $secret = app(TwoFactorAuthenticatable::class)->generateSecretKey();
        
        // Generate recovery codes
        $recoveryCodes = app(TwoFactorAuthenticatable::class)->generateRecoveryCodes();
        
        $user->update([
            'two_factor_secret' => encrypt($secret),
            'two_factor_recovery_codes' => encrypt(json_encode($recoveryCodes)),
        ]);

        $this->recoveryCodes = implode("\n", $recoveryCodes);
        $this->twoFactorEnabled = true;

        activity()
            ->causedBy($user)
            ->log('2fa_enabled');

        $this->dispatch('notify', type: 'success', message: 'Two-factor authentication enabled.');
    }

    public function disable2FA(): void
    {
        $this->authorize('security.disable_2fa');

        $user = auth()->user();
        
        $user->update([
            'two_factor_secret' => null,
            'two_factor_recovery_codes' => null,
        ]);

        $this->twoFactorEnabled = false;

        activity()
            ->causedBy($user)
            ->log('2fa_disabled');

        $this->dispatch('notify', type: 'success', message: 'Two-factor authentication disabled.');
    }

    public function revokeSession(string $sessionId): void
    {
        $this->authorize('security.revoke_session');

        $session = auth()->user()->sessions()->findOrFail($sessionId);
        $session->delete();

        activity()
            ->causedBy(auth()->user())
            ->withProperties(['session_id' => $sessionId])
            ->log('session_revoked');

        $this->dispatch('notify', type: 'success', message: 'Session revoked.');
    }

    public function revokeAllSessions(): void
    {
        $this->authorize('security.revoke_session');

        auth()->user()->sessions()->delete();

        activity()
            ->causedBy(auth()->user())
            ->log('all_sessions_revoked');

        $this->dispatch('notify', type: 'success', message: 'All sessions revoked.');
    }
}
```

```php
class DeleteUserAccount implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(private User $user) {}

    public function handle(): void
    {
        // Check if grace period has passed
        if ($this->user->deleted_at && $this->user->deleted_at->isFuture()) {
            return; // Still in grace period
        }

        // Soft-delete content
        $this->user->themes()->delete();
        $this->user->components()->delete();
        $this->user->templates()->delete();

        // Anonymize order data (keep for accounting)
        $this->user->orders()->update([
            'user_id' => null,
            'name' => 'Deleted User',
            'email' => 'deleted@anonymized.local',
        ]);

        // Delete files
        $this->deleteFiles();

        // Delete sessions
        $this->user->sessions()->delete();

        // Delete API tokens
        $this->user->tokens()->delete();

        // Delete notifications
        $this->user->notifications()->delete();

        // Finally delete the user
        $this->user->forceDelete();

        activity()
            ->withProperties(['user_id' => $this->user->id])
            ->log('user_permanently_deleted');
    }

    private function deleteFiles(): void
    {
        // Delete avatar
        if ($this->user->avatar_url) {
            Storage::disk('public')->delete($this->user->avatar_url);
        }

        // Delete playground sessions
        $this->user->playgroundSessions()->each(function ($session) {
            Storage::disk('private')->delete("playground/{$session->id}.json");
        });
    }
}
```

## User API Token Management

### Token Creation

```php
// app/Livewire/Dashboard/ApiTokens.php

class ApiTokens extends Component
{
    public string $name = '';
    public array $permissions = [];
    public int $maxTokens = 3; // Free user limit

    protected array $rules = [
        'name' => ['required', 'string', 'max:100'],
        'permissions' => ['required', 'array', 'min:1'],
    ];

    public function mount(): void
    {
        $this->authorize('security.api_tokens');
        
        // Pro users get more tokens
        if (auth()->user()->hasRole('pro_user')) {
            $this->maxTokens = 20;
        }
    }

    public function createToken(): void
    {
        $this->validate();

        $user = auth()->user();

        // Check token limit
        if ($user->tokens()->count() >= $this->maxTokens) {
            $this->dispatch('notify', type: 'error', message: "Maximum token limit reached ({$this->maxTokens}).");
            return;
        }

        // Validate requested permissions against user's permissions
        $validPermissions = $user->getAllPermissions()->pluck('name')->toArray();
        $requestedPermissions = array_intersect($this->permissions, $validPermissions);

        $token = $user->createToken($this->name, $requestedPermissions);

        activity()
            ->causedBy($user)
            ->withProperties(['token_name' => $this->name, 'permissions' => $requestedPermissions])
            ->log('api_token_created');

        $this->dispatch('notify', type: 'success', message: 'API token created. Copy it now, it won\'t be shown again.');
        $this->dispatch('showToken', $token->plainTextToken);
        
        $this->name = '';
        $this->permissions = [];
    }

    public function revokeToken(Token $token): void
    {
        $token->delete();

        activity()
            ->causedBy(auth()->user())
            ->withProperties(['token_name' => $token->name])
            ->log('api_token_revoked');

        $this->dispatch('notify', type: 'success', message: 'API token revoked.');
    }
}
```

```php
            ],

            'description' => 'Completed first marketplace purchase',
            'permissions' => [
                'reviews.create',
                'library.view',
                'downloads.manage',
            ],
        ],
    ];

    public function completeMilestone(User $user, string $milestone): array
    {
        if (! isset(self::MILESTONES[$milestone])) {
            throw new \InvalidArgumentException("Unknown milestone: {$milestone}");
        }

        $config = self::MILESTONES[$milestone];
        $newPermissions = [];

        foreach ($config['permissions'] as $permission) {
            if (! $user->hasPermissionTo($permission)) {
                $user->givePermissionTo($permission);
                $newPermissions[] = $permission;
            }
        }

        // Record milestone completion
        DB::table('user_milestones')->insert([
            'user_id' => $user->id,
            'milestone' => $milestone,
            'completed_at' => now(),
            'permissions_granted' => json_encode($newPermissions),
        ]);

        ActivityLog::milestoneCompleted($user, $milestone, $newPermissions);

        return $newPermissions;
    }

    public function getUserProgress(User $user): array
    {
        $completed = DB::table('user_milestones')
            ->where('user_id', $user->id)
            ->pluck('milestone')
            ->toArray();

        $milestones = [];
        foreach (self::MILESTONES as $name => $config) {
            $milestones[$name] = [
                'description' => $config['description'],
                'completed' => in_array($name, $completed),
                'permissions' => $config['permissions'],
            ];
        }

        return $milestones;
    }
}
```

```php
            'min_account_age_days' => 90,
            'max_daily_posts' => -1, // unlimited
            'max_daily_comments' => -1,
            'can_review' => true,
            'can_sell' => true,
        ],
        self::TIER_CHAMPION => [
            'min_reputation' => 1000,
            'min_account_age_days' => 180,
            'max_daily_posts' => -1,
            'max_daily_comments' => -1,
            'can_review' => true,
            'can_sell' => true,
        ],
    ];

    public function getCurrentTier(User $user): string
    {
        $reputation = $user->reputation_score ?? 0;
        $accountAge = $user->created_at->diffInDays(now());

        $currentTier = self::TIER_FREE;
        foreach (self::TIER_CONFIG as $tier => $config) {
            if ($reputation >= $config['min_reputation']
                && $accountAge >= $config['min_account_age_days']) {
                $currentTier = $tier;
            }
        }

        return $currentTier;
    }

    public function getTierConfig(string $tier): array
    {
        return self::TIER_CONFIG[$tier] ?? self::TIER_CONFIG[self::TIER_FREE];
    }

    public function checkRateLimit(User $user, string $action): bool
    {
        $tier = $this->getCurrentTier($user);
        $config = self::TIER_CONFIG[$tier];

        $limit = match ($action) {
            'post' => $config['max_daily_posts'],
            'comment' => $config['max_daily_comments'],
            default => -1,
        };

        if ($limit === -1) {
            return true; // unlimited
        }

        $todayCount = $this->getTodayCount($user, $action);
        return $todayCount < $limit;
    }

    protected function getTodayCount(User $user, string $action): int
    {
        $model = match ($action) {
            'post' => Post::class,
            'comment' => Comment::class,
            default => null,
        };

        if (! $model) {
            return 0;
        }

        return $model::where('user_id', $user->id)
            ->whereDate('created_at', today())
            ->count();
    }
}
```

```php
class PermissionChangedNotification extends Notification

        private array $addedPermissions,
        private array $removedPermissions,
        private string $reason
    ) {}

            'removed' => $this->removedPermissions,
            'reason' => $this->reason,
            'changed_at' => now()->toISOString(),
        ];
    }

    public function toMail(User $notifiable): MailMessage
    {
        $message = (new MailMessage)
            ->subject('Your Permissions Have Been Updated')
            ->line('Some of your permissions have changed.');

        if (! empty($this->addedPermissions)) {
            $message->line('**New permissions:**');
            foreach ($this->addedPermissions as $perm) {
                $message->line("- {$perm}");
            }
        }

        if (! empty($this->removedPermissions)) {
            $message->line('**Removed permissions:**');
            foreach ($this->removedPermissions as $perm) {
                $message->line("- {$perm}");
            }
        }

        $message->line("Reason: {$this->reason}");

        return $message;
    }
}
```

```php
                    $perm->permission_name,
                    $perm->expires_at

                DB::table('user_permission_expiry')
                    ->where('id', $perm->id)
                    ->update(['notified' => true]);
            }
        }

        $this->info("Notified {$expiringPerms->count()} users of expiring permissions.");
        return self::SUCCESS;
    }
}
```

## User Permission Caching

### User-Specific Cache Strategy

```php
// app/Services/UserPermissionCache.php

class UserPermissionCache
{
    private CacheRepository $cache;
    private int $ttl = 600;

    public function __construct(CacheRepository $cache)
    {
        $this->cache = $cache;
    }

    public function getUserPermissions(User $user): array
    {
        $cacheKey = "user:{$user->id}:permissions";

        return $this->cache->remember($cacheKey, $this->ttl, function () use ($user) {
            return $user->getPermissionsViaGroups()
                ->pluck('name')
                ->toArray();
        });
    }

    public function hasPermission(User $user, string $permission): bool
    {
        $permissions = $this->getUserPermissions($user);
        return in_array($permission, $permissions);
    }

    public function invalidate(User $user): void
    {
        $this->cache->forget("user:{$user->id}:permissions");
        $user->forgetCachedPermissions();
    }

    public function warmCache(User $user): void
    {
        $this->getUserPermissions($user); // populates cache
    }

    public function warmBatchCache(Collection $users): void
    {
        foreach ($users as $user) {
            $this->warmCache($user);
        }
    }
}
```

```php
class UserPermissionReport
{
    public function generateForUser(User $user): array

    public function generatePlatformSummary(): array
    {
        return [
            'total_users' => User::count(),
            'users_by_role' => $this->getUsersByRole(),
            'permission_distribution' => $this->getPermissionDistribution(),
            'tier_distribution' => $this->getTierDistribution(),
            'recent_changes' => $this->getRecentPermissionChanges(),
        ];
    }

    protected function getInheritedPermissions(User $user): array
    {
        return $user->roles
            ->flatMap(fn ($role) => $role->permissions)
            ->pluck('name')
            ->unique()
            ->toArray();
    }

    protected function getPermissionGroups(User $user): array
    {
        return $user->roles
            ->flatMap(fn ($role) => $role->permissions)
            ->pluck('group_id')
            ->unique()
            ->map(fn ($groupId) => PermissionGroup::find($groupId)?->name)
            ->filter()
            ->toArray();
    }

    protected function getRateLimits(User $user): array
    {
        $tier = app(UserPermissionTier::class)->getCurrentTier($user);
        return app(UserPermissionTier::class)->getTierConfig($tier);
    }

    protected function getUsersByRole(): array
    {
        return Role::withCount('users')
            ->get()
            ->pluck('users_count', 'name')
            ->toArray();
    }

    protected function getPermissionDistribution(): array
    {
        return Permission::withCount('users')
            ->get()
            ->pluck('users_count', 'name')
            ->toArray();
    }

    protected function getTierDistribution(): array
    {
        $tiers = [
            UserPermissionTier::TIER_FREE,
            UserPermissionTier::TIER_ACTIVE,
            UserPermissionTier::TIER_TRUSTED,
            UserPermissionTier::TIER_PRO,
            UserPermissionTier::TIER_CHAMPION,
        ];

        $tierService = app(UserPermissionTier::class);
        $distribution = [];

        foreach ($tiers as $tier) {
            $count = User::all()->filter(
                fn ($user) => $tierService->getCurrentTier($user) === $tier
            )->count();
            $distribution[$tier] = $count;
        }

        return $distribution;
    }

    protected function getRecentPermissionChanges(): array
    {
        return Activity::whereIn('description', [
            'role_assigned', 'role_removed',
            'permission_granted', 'permission_revoked',
        ])
        ->where('created_at', '>=', now()->subDays(7))
        ->with('causer', 'subject')
        ->orderByDesc('created_at')
        ->limit(20)
        ->get()
        ->toArray();
    }
```

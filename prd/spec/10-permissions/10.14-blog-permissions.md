# 10.14 — Blog Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines the complete authorization rules for the **Blog domain** in GsmUi. The blog serves as the platform's content marketing channel — product announcements, tutorials, creator spotlights, changelogs, and community stories. This specification governs who can create, edit, publish, feature, and delete blog posts, as well as who can moderate comments, manage categories, and control the editorial workflow.

The blog interacts with the [Documentation domain](./10.15-documentation-permissions.md), the [User permissions](./10.08-user-permissions.md), and the [Admin permissions](./10.07-admin-permissions.md).

## Scope

Blog permissions apply to:

* Blog post creation and editing
* Blog post publishing and editorial workflow
* Blog post featuring on the homepage
* Blog post deletion and archival
* Comment moderation
* Category and tag management
* Blog post SEO metadata management
* Blog post scheduling (future)

## Blog Post Lifecycle States

```text
draft
  ↓ (submit for review)
in_review
  ↓ (approve)
published
  ↓ (feature)
featured

in_review
  ↓ (reject)
rejected
  ↓ (author edits & resubmits)
in_review

published
  ↓ (unpublish)
unpublished
  ↓ (resubmit)
in_review
```

### State Transition Matrix

| From State | To State | Trigger | Permission Required |
|---|---|---|---|
| `draft` | `in_review` | Author submits | `blog.publish` (own) |
| `in_review` | `published` | Editor approves | `blog.publish` (editor+) |
| `in_review` | `rejected` | Editor rejects | `blog.publish` (editor+) |
| `in_review` | `draft` | Author withdraws | `blog.update` (own) |
| `rejected` | `in_review` | Author resubmits | `blog.publish` (own) |
| `published` | `featured` | Editor features | `blog.feature` (editor+) |
| `featured` | `published` | Editor unfeatures | `blog.feature` (editor+) |
| `published` | `unpublished` | Author/editor unpublishes | `blog.unpublish` (own or editor+) |
| `unpublished` | `in_review` | Author resubmits | `blog.publish` (own) |
| Any | `draft` | Author/editor deletes | `blog.delete` (own or editor+) |

## Comment Moderation

Comments on blog posts require moderation rules:

```text
Author:     moderate comments on own posts only
Editor:     moderate all comments across all posts
Admin:      moderate all comments + set global policies
Super Admin: moderate all + configure moderation settings
```

### Comment Moderation Policy

```php
class CommentPolicy
{
    public function moderate(User $user, Comment $comment): bool
    {
        // Admin and Super Admin can moderate any comment
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        // Editor can moderate any comment
        if ($user->hasRole('editor')) {
            return true;
        }

        // Author can moderate comments on their own posts
        return $user->id === $comment->post->user_id;
    }

    public function delete(User $user, Comment $comment): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        if ($user->hasRole('editor')) {
            return true;
        }

        // Author can delete comments on their own posts
        if ($user->id === $comment->post->user_id) {
            return true;
        }

        // User can delete their own comment
        return $user->id === $comment->user_id;
    }
}
```

## Policy Implementation

```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\BlogPost;
use Illuminate\Auth\Access\HandlesAuthorization;

class BlogPostPolicy
{
    use HandlesAuthorization;

    /**
     * Determine whether the user can view any blog posts.
     * Published posts are public.
     */
    public function viewAny(User $user): bool
    {
        return true;
    }

    /**
     * Determine whether the user can view the blog post.
     * Published/featured posts are public.
     * Draft/rejected posts are owner/editor/admin only.
     */
    public function view(User $user, BlogPost $post): bool
    {
        if (in_array($post->status, ['published', 'featured'])) {
            return true;
        }

        // draft/rejected/in_review — owner + editor + admin only
        return $user->id === $post->user_id
            || $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can create blog posts.
     * Requires 'author', 'editor', or 'admin' role.
     */
    public function create(User $user): bool
    {
        return $user->hasRole(['author', 'editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can update the blog post.
     * Owner can update own posts; editors/admins can update any.
     */
    public function update(User $user, BlogPost $post): bool
    {
        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $post->user_id;
    }

    /**
     * Determine whether the user can delete the blog post.
     * Owner can delete own posts; editors/admins can delete any.
     */
    public function delete(User $user, BlogPost $post): bool
    {
        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $post->user_id;
    }

    /**
     * Determine whether the user can publish the blog post.
     * Owner can submit own drafts; editors can publish any.
     */
    public function publish(User $user, BlogPost $post): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        if ($user->hasRole('editor')) {
            return true;
        }

        // Author can submit own draft for review
        return $user->id === $post->user_id
            && in_array($post->status, ['draft', 'rejected', 'unpublished']);
    }

    /**
     * Determine whether the user can unpublish the blog post.
     */
    public function unpublish(User $user, BlogPost $post): bool
    {
        if (! in_array($post->status, ['published', 'featured'])) {
            return false;
        }

        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $post->user_id;
    }

    /**
     * Determine whether the user can feature the blog post.
     */
    public function feature(User $user, BlogPost $post): bool
    {
        if ($post->status !== 'published') {
            return false;
        }

        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can manage categories.
     */
    public function manageCategories(User $user): bool
    {
        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can pin the blog post.
     */
    public function pin(User $user, BlogPost $post): bool
    {
        if ($post->status !== 'published' && $post->status !== 'featured') {
            return false;
        }

        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can view post analytics.
     */
    public function viewAnalytics(User $user, BlogPost $post): bool
    {
        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $post->user_id;
    }

    /**
     * Determine whether the user can schedule the post.
     */
    public function schedule(User $user, BlogPost $post): bool
    {
        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $post->user_id
            && in_array($post->status, ['draft', 'rejected']);
    }
}
```

## Controller Integration

```php
<?php

namespace App\Http\Controllers;

use App\Models\BlogPost;
use Illuminate\Http\Request;

class BlogPostController extends Controller
{
    public function __construct()
    {
        $this->authorizeResource(BlogPost::class, 'post');
    }

    public function index()
    {
        // viewAny — public blog listing
    }

    public function store(Request $request)
    {
        // create — requires 'author', 'editor', or 'admin' role

        $post = BlogPost::create([
            'user_id' => auth()->id(),
            'title' => $request->title,
            'slug' => $request->slug,
            'body' => $request->body,
            'status' => 'draft',
        ]);

        return redirect()->route('blog.edit', $post);
    }

    public function update(Request $request, BlogPost $post)
    {
        // update — owner, editor, or admin

        $post->update($request->validated());

        return back()->with('success', 'Post updated.');
    }

    public function submitForReview(BlogPost $post)
    {
        $this->authorize('publish', $post);

        $post->update(['status' => 'in_review']);

        activity()
            ->performedOn($post)
            ->event('blog.submitted_for_review')
            ->log('Blog post submitted for review');

        return back()->with('success', 'Post submitted for review.');
    }

    public function approve(BlogPost $post)
    {
        $this->authorize('feature', $post);

        $post->update([
            'status' => 'published',
            'published_at' => now(),
        ]);

        activity()
            ->performedOn($post)
            ->event('blog.approved')
            ->log('Blog post approved and published');

        return back()->with('success', 'Post published.');
    }

    public function reject(BlogPost $post, Request $request)
    {
        $this->authorize('publish', $post);

        $post->update([
            'status' => 'rejected',
            'rejection_reason' => $request->reason,
        ]);

        activity()
            ->performedOn($post)
            ->event('blog.rejected')
            ->withProperties(['reason' => $request->reason])
            ->log('Blog post rejected');

        return back()->with('success', 'Post rejected.');
    }

    public function destroy(BlogPost $post)
    {
        $this->authorize('delete', $post);

        $post->delete();

        return redirect()->route('blog.index');
    }
}
```

### SEO Scoring Service

```php
class BlogSeoScoringService
{
    public function score(BlogPost $post): array
    {
        $score = 0;
        $checks = [];

        // Meta title check
        $checks['meta_title'] = strlen($post->meta_title) > 0
            && strlen($post->meta_title) <= 60;
        if ($checks['meta_title']) $score += 20;

        // Meta description check
        $checks['meta_description'] = strlen($post->meta_description) > 0
            && strlen($post->meta_description) <= 160;
        if ($checks['meta_description']) $score += 20;

        // Slug check
        $checks['slug'] = ! empty($post->slug)
            && Str::contains($post->slug, '-');
        if ($checks['slug']) $score += 15;

        // Content length check
        $checks['content_length'] = str_word_count($post->body) >= 300;
        if ($checks['content_length']) $score += 15;

        // Heading structure
        $checks['headings'] = preg_match_all('/<h[2-6]/', $post->body) >= 2;
        if ($checks['headings']) $score += 10;

        // Image alt text
        $checks['images'] = ! preg_match('/<img(?![^>]*alt=)/', $post->body);
        if ($checks['images']) $score += 10;

        // Internal links
        $checks['links'] = preg_match_all('/<a\s+href="\/', $post->body) >= 1;
        if ($checks['links']) $score += 10;

        return [
            'score' => $score,
            'checks' => $checks,
            'grade' => $this->gradeFromScore($score),
        ];
    }

    private function gradeFromScore(int $score): string
    {
        return match(true) {
            $score >= 90 => 'A',
            $score >= 75 => 'B',
            $score >= 60 => 'C',
            $score >= 40 => 'D',
            default => 'F',
        };
    }
}
```

### Schedule Workflow

```text
Author/Editor sets scheduled_at timestamp
    ↓
Check: blog.schedule permission
    ↓
Validate scheduled_at is in the future
    ↓
Update post status to 'scheduled'
    ↓
Dispatch PublishScheduledPost job with delay
    ↓
Job runs at scheduled_at time
    ↓
Check: post still in 'scheduled' status
    ↓
Update status to 'published'
    ↓
Set published_at = now()
    ↓
Log activity
    ↓
Notify author of publication
```

### Schedule Job

```php
class PublishScheduledPost implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        private int $postId,
    ) {}

    public function handle(): void
    {
        $post = BlogPost::find($this->postId);

        if (! $post || $post->status !== 'scheduled') {
            return;
        }

        $post->update([
            'status' => 'published',
            'published_at' => now(),
        ]);

        activity()
            ->performedOn($post)
            ->event('blog.scheduled_published')
            ->log('Scheduled blog post published');

        Notification::send($post->user, new BlogPostPublishedNotification($post));
    }
}
```

### Revision Policy

```php
class BlogPostRevisionPolicy
{
    public function view(User $user, BlogPostRevision $revision): bool
    {
        $post = $revision->blogPost;

        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $post->user_id;
    }

    public function restore(User $user, BlogPostRevision $revision): bool
    {
        $post = $revision->blogPost;

        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $post->user_id
            && in_array($post->status, ['draft', 'rejected']);
    }

    public function compareRevisions(User $user, BlogPostRevision $rev1, BlogPostRevision $rev2): bool
    {
        return $this->view($user, $rev1) && $this->view($user, $rev2);
    }
}
```

### Analytics Aggregation Service

```php
class BlogAnalyticsService
{
    public function getPostStats(BlogPost $post, int $days = 30): array
    {
        return DB::table('blog_analytics')
            ->where('blog_post_id', $post->id)
            ->where('date', '>=', now()->subDays($days))
            ->select([
                DB::raw('SUM(views) as total_views'),
                DB::raw('SUM(unique_visitors) as total_unique'),
                DB::raw('AVG(time_on_page_seconds) as avg_time'),
                DB::raw('SUM(bounces) / SUM(views) * 100 as bounce_rate'),
            ])
            ->first();
    }

    public function getReferrerBreakdown(BlogPost $post, int $days = 30): Collection
    {
        return DB::table('blog_analytics')
            ->where('blog_post_id', $post->id)
            ->where('date', '>=', now()->subDays($days))
            ->groupBy('referrer_domain')
            ->orderByRaw('SUM(views) DESC')
            ->limit(10)
            ->get();
    }

    public function getEngagementTimeline(BlogPost $post): Collection
    {
        return DB::table('blog_analytics')
            ->where('blog_post_id', $post->id)
            ->orderBy('date')
            ->get();
    }
}
```

# 10.07 - Admin Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

Define the **complete permission set for platform administrators**. Admins have near-total access to the platform but are deliberately constrained from system-level operations reserved for Super Admin. This separation ensures that a compromised admin account cannot take down infrastructure or access sensitive system internals.

This document is the authoritative reference for what admin roles can and cannot do. Every admin route, API endpoint, and Blade conditional must reference this matrix.

## Admin Role Definitions

### Admin

The standard platform administrator. Handles user management, content oversight, marketplace operations, billing disputes, and day-to-day platform operations. Cannot access system infrastructure.

### Super Admin

The highest-privilege role on the platform. Inherits all Admin permissions plus system-level operations: health monitoring, log access, maintenance mode, backup management, and debug tools. Super Admin is the only role that cannot be self-assigned or self-modified.

**Guard rails:**

* Admins cannot delete roles or permissions to prevent accidental cascade failures.
* Admins cannot assign `super_admin` role to any user (including themselves).
* Role changes are audit-logged via Spatie Activity Log.

```php
// app/Policies/RolePolicy.php

public function delete(User $user, Role $role): bool
{
    // Only super admins can delete roles
    return $user->hasRole('super_admin');
}

public function assign(User $user, string $roleName): bool
{
    // Admins cannot assign super_admin
    if ($roleName === 'super_admin') {
        return $user->hasRole('super_admin');
    }

    return $user->hasRole(['admin', 'super_admin']);
}
```

**Refund policy:**

* Admins can process refunds within 30 days of purchase without approval.
* Refunds over 30 days require Super Admin approval.
* All refunds are audit-logged with reason codes.

```php
// app/Services/RefundService.php

public function processRefund(Order $order, User $admin, ?string $reason = null): Refund
{
    if (! $admin->can('orders.refund')) {
        throw new AuthorizationException('Insufficient permissions for refund.');
    }

    // Check if refund requires super admin approval
    if ($order->created_at->diffInDays(now()) > 30) {
        if (! $admin->hasRole('super_admin')) {
            throw new AuthorizationException(
                'Refunds after 30 days require Super Admin approval.'
            );
        }
    }

    $refund = Refund::create([
        'order_id' => $order->id,
        'admin_id' => $admin->id,
        'amount' => $order->total,
        'reason' => $reason,
        'status' => 'processing',
    ]);

    // Process via billing provider, revoke license, notify parties
    // ...

    return $refund;
}
```

### Custom Middleware: `role`

```php
// app/Http/Middleware/RoleMiddleware.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class RoleMiddleware
{
    public function handle(Request $request, Closure $next, string ...$roles)
    {
        if (! $request->user()) {
            return redirect()->route('login');
        }

        if (! $request->user()->hasRole($roles)) {
            abort(403, 'Unauthorized. Required role: ' . implode(' or ', $roles));
        }

        return $next($request);
    }
}

// bootstrap/app.php or Kernel.php
$router->aliasMiddleware('role', RoleMiddleware::class);
```

### User Management

```php
// app/Livewire/Admin/UserManager.php

class UserManager extends Component
{
    public string $search = '';
    public ?string $roleFilter = null;

    public function mount(): void
    {
        $this->authorize('users.view');
    }

    public function toggleRole(User $user, string $role): void
    {
        $this->authorize('roles.assign');

        // Prevent admin from assigning super_admin
        if ($role === 'super_admin' && ! auth()->user()->hasRole('super_admin')) {
            $this->dispatch('notify', type: 'error', message: 'Insufficient permissions.');
            return;
        }

        if ($user->hasRole($role)) {
            $user->removeRole($role);
        } else {
            $user->assignRole($role);
        }

        activity()
            ->performedOn($user)
            ->withProperties(['role' => $role, 'action' => 'toggle'])
            ->log('role_changed');
    }

    public function suspendUser(User $user): void
    {
        $this->authorize('users.suspend');
        $user->suspend();
        $this->dispatch('notify', type: 'success', message: "User {$user->name} suspended.");
    }

    public function deleteUser(User $user): void
    {
        $this->authorize('users.delete');

        // Prevent self-deletion
        if ($user->id === auth()->id()) {
            $this->dispatch('notify', type: 'error', message: 'Cannot delete your own account.');
            return;
        }

        $user->delete();
        $this->dispatch('notify', type: 'success', message: "User {$user->name} deleted.");
    }

    public function getResults()
    {
        return User::query()
            ->when($this->search, fn($q) => $q->where('name', 'like', "%{$this->search}%")
                ->orWhere('email', 'like', "%{$this->search}%"))
            ->when($this->roleFilter, fn($q) => $q->whereRole($this->roleFilter))
            ->orderBy('created_at', 'desc')
            ->paginate(20);
    }
}
```

## Security Constraints

### What Admins Cannot Do

1. **Assign `super_admin` role** — only super admins can do this.
2. **Delete roles or permissions** — prevents accidental cascade failures.
3. **Access system health, logs, or maintenance** — reserved for super admins.
4. **Rotate API keys or secrets** — prevents key theft by compromised admin.
5. **View sensitive user PII** (payment details, IPs) — super admin only.
6. **Impersonate users** — audit-heavy, super admin only.
7. **Self-modify role** — an admin cannot promote themselves to super admin.
8. **Access debug tools in production** — `access-debug` gate checks environment.

### Self-Protection Rules

```php
// Prevent admin from modifying their own role
public function update(User $admin, User $target): bool
{
    if ($admin->id === $target->id) {
        return false; // Cannot modify own account via admin panel
    }

    return $admin->hasRole(['admin', 'super_admin']);
}

// Prevent role escalation
public function assignRole(User $admin, User $target, string $role): bool
{
    if ($role === 'super_admin') {
        return $admin->hasRole('super_admin');
    }

    // Admin cannot assign roles they don't have
    if (! $admin->hasRole($role) && ! $admin->hasRole('super_admin')) {
        return false;
    }

    return true;
}
```

```php
        }

        // Prevent self-demotion
        if ($user->id === auth()->id() && in_array($role, ['admin', 'super_admin'])) {
            $this->dispatch('notify', type: 'error', message: 'Cannot modify your own role.');
            return;
        }

        if ($user->hasRole($role)) {
            $user->removeRole($role);
        } else {
            $user->assignRole($role);
        }

        activity()
            ->causedBy(auth()->user())
            ->performedOn($user)
            ->withProperties(['role' => $role, 'action' => 'toggle'])
            ->log('role_changed');

        $this->dispatch('notify', type: 'success', message: "Role {$role} updated for {$user->name}.");
    }

    public function suspendUser(User $user): void
    {
        $this->authorize('users.suspend');

        $user->suspend();
        
        activity()
            ->causedBy(auth()->user())
            ->performedOn($user)
            ->log('user_suspended');

        $this->dispatch('notify', type: 'success', message: "User {$user->name} suspended.");
    }

    public function deleteUser(User $user): void
    {
        $this->authorize('users.delete');

        // Prevent self-deletion
        if ($user->id === auth()->id()) {
            $this->dispatch('notify', type: 'error', message: 'Cannot delete your own account.');
            return;
        }

        // Prevent deleting last super admin
        if ($user->hasRole('super_admin') && User::role('super_admin')->count() <= 1) {
            $this->dispatch('notify', type: 'error', message: 'Cannot delete the last Super Admin.');
            return;
        }

        $user->delete();
        
        activity()
            ->causedBy(auth()->user())
            ->performedOn($user)
            ->log('user_deleted');

        $this->dispatch('notify', type: 'success', message: "User {$user->name} deleted.");
    }

    public function getResults()
    {
        return User::query()
            ->when($this->search, fn($q) => $q->where('name', 'like', "%{$this->search}%")
                ->orWhere('email', 'like', "%{$this->search}%"))
            ->when($this->roleFilter, fn($q) => $q->whereRole($this->roleFilter))
            ->when($this->statusFilter, fn($q) => match($this->statusFilter) {
                'active' => $q->whereNull('suspended_at'),
                'suspended' => $q->whereNotNull('suspended_at'),
                'verified' => $q->whereNotNull('email_verified_at'),
                'unverified' => $q->whereNull('email_verified_at'),
                default => $q,
            })
            ->orderBy('created_at', 'desc')
            ->paginate($this->perPage);
    }
}
```

## Admin Security Patterns

### Principle of Least Privilege

Admins should have only the permissions they need. Regular admins should not have system-level permissions.

```php
// Restricting admin permissions
class AdminPermissionGuard
{
    private array $adminRestrictedPermissions = [
        'system.health',
        'system.logs',
        'system.maintenance',
        'system.backup',
        'system.cache',
        'system.queue',
        'system.scheduler',
        'system.deploy',
        'system.database',
        'system.debug',
        'permissions.create',
        'permissions.update',
        'permissions.delete',
        'settings.manage',
    ];

    public function canAccess(User $user, string $permission): bool
    {
        if ($user->hasRole('super_admin')) {
            return true;
        }

        if ($user->hasRole('admin') && in_array($permission, $this->adminRestrictedPermissions)) {
            return false;
        }

        return $user->hasPermissionTo($permission);
    }
}
```

### Self-Protection Rules

Admins cannot modify their own role or access levels:

```php
// Self-protection middleware
class AdminSelfProtection
{
    public function handle(Request $request, Closure $next): Response
    {
        $user = $request->user();
        $target = $request->route('user');

        // Prevent self-role modification
        if ($target && $target->id === $user->id) {
            if ($request->isMethod('put') && $request->has('role')) {
                abort(403, 'Cannot modify your own role.');
            }
        }

        // Prevent self-deletion
        if ($target && $target->id === $user->id && $request->isMethod('delete')) {
            abort(403, 'Cannot delete your own account.');
        }

        return $next($request);
    }
}
```

```php
class ImpersonateUserAction

            ])

        auth()->login($target);

    {

            auth()->login(User::find($impersonatorId));
            session()->forget('impersonator_id');
            
            activity()
                ->withProperties(['action' => 'impersonation_ended'])
                ->log('impersonation_ended');
        }
    }
}
```

### Alert Rules for Admin Actions

Define automatic alerts when certain admin thresholds are exceeded:

```php
// app/Services/AdminAlertRules.php

class AdminAlertRules
{
    private const RULES = [
        'rapid_role_escalation' => [
            'description' => 'Multiple role assignments in short window',
            'threshold' => 5,
            'window_minutes' => 10,
            'severity' => 'high',
        ],
        'mass_user_deletion' => [
            'description' => 'Bulk user deletion detected',
            'threshold' => 10,
            'window_minutes' => 5,
            'severity' => 'critical',
        ],
        'permission_grant_spike' => [
            'description' => 'Unusual volume of direct permission grants',
            'threshold' => 20,
            'window_minutes' => 60,
            'severity' => 'medium',
        ],
        'off_hours_admin_activity' => [
            'description' => 'Admin action outside business hours',
            'severity' => 'low',
        ],
    ];

    public function evaluate(Activity $activity): array
    {
        $alerts = [];

        foreach (self::RULES as $ruleName => $rule) {
            if ($this->matchesRule($activity, $rule)) {
                $alerts[] = Alert::create([
                    'rule_name' => $ruleName,
                    'description' => $rule['description'],
                    'severity' => $rule['severity'],
                    'activity_id' => $activity->id,
                    'admin_id' => $activity->causer_id,
                    'status' => 'active',
                ]);
            }
        }

        return $alerts;
    }

    protected function matchesRule(Activity $activity, array $rule): bool
    {
        if (isset($rule['threshold'], $rule['window_minutes'])) {
            $count = Activity::where('description', $activity->description)
                ->where('causer_id', $activity->causer_id)
                ->where('created_at', '>=', now()->subMinutes($rule['window_minutes']))
                ->count();

            return $count >= $rule['threshold'];
        }

        return false;
    }
}
```

## Admin Self-Protection Rules

### Self-Demotion Prevention

```php
// app/Policies/AdminSelfProtectionPolicy.php

class AdminSelfProtectionPolicy
{
    public function assignRole(User $admin, User $target, string $role): bool
    {
        // Prevent self-role-change
        if ($admin->id === $target->id) {
            return false;
        }

        // Prevent assigning a role equal to or higher than your own
        $adminLevel = $this->getRoleLevel($admin);
        $targetRoleLevel = $this->getRoleLevelByName($role);

        if ($targetRoleLevel >= $adminLevel) {
            return false;
        }

        return true;
    }

    public function removeRole(User $admin, User $target, string $role): bool
    {
        if ($admin->id === $target->id) {
            return false;
        }

        return true;
    }

    protected function getRoleLevel(User $user): int
    {
        $highestRole = $user->roles->sortByDesc('hierarchy_level')->first();
        return $highestRole?->hierarchy_level ?? 0;
    }

    protected function getRoleLevelByName(string $roleName): int
    {
        $role = Role::where('name', $roleName)->first();
        return $role?->hierarchy_level ?? 0;
    }
}
```

```php
class AutoRoleAssignment
{
    private const RULES = [
        [
            'trigger' => 'user_registered',
            'condition' => 'email_ends_with(@company.com)',
            'role' => 'employee',
        ],
        [
            'trigger' => 'creator_profile_approved',
            'condition' => 'always',
            'role' => 'creator',
        ],
        [
            'trigger' => 'purchase_completed',
            'condition' => 'total_purchases >= 5',
            'role' => 'pro_user',
        ],
    ];

    public function evaluate(string $trigger, User $user): array
    {
        $assignedRoles = [];

        foreach (self::RULES as $rule) {
            if ($rule['trigger'] !== $trigger) {
                continue;
            }

            if ($this->evaluateCondition($rule['condition'], $user)) {
                $user->assignRole($rule['role']);
                $assignedRoles[] = $rule['role'];

                ActivityLog::autoRoleAssigned($user, $rule['role'], $rule['trigger']);
            }
        }

        return $assignedRoles;
    }

    protected function evaluateCondition(string $condition, User $user): bool
    {
        return match (true) {
            str_starts_with($condition, 'email_ends_with') => $this->checkEmailDomain($condition, $user),
            $condition === 'always' => true,
            str_starts_with($condition, 'total_purchases') => $this->checkPurchaseCount($condition, $user),
            default => false,
        };
    }
}
```

```php

class AdminMaintenanceCommand extends Command
{
    protected $signature = 'admin:maintenance';
    protected $description = 'Run scheduled admin maintenance tasks';

    public function handle(): int
    {
        $tasks = [

        return self::SUCCESS;
    }

    protected function expireIdleSessions(): bool
    {
        $timeout = config('admin-session.idle_timeout_minutes');
        $expired = DB::table('admin_sessions')
            ->where('last_activity', '<', now()->subMinutes($timeout))
            ->delete();

        $this->line("  Expired {$expired} idle sessions");
        return true;
    }

    protected function cleanupAuditLogs(): bool
    {
        $retentionDays = config('admin.audit_retention_days', 90);
        $deleted = DB::table('admin_audit_log')
            ->where('created_at', '<', now()->subDays($retentionDays))
            ->delete();

        $this->line("  Cleaned up {$deleted} old audit entries");
        return true;
    }

    protected function revokeStaleTokens(): bool
    {
        $staleDays = config('admin.stale_token_days', 30);
        $revoked = DB::table('personal_access_tokens')
            ->where('last_used_at', '<', now()->subDays($staleDays))
            ->delete();

        $this->line("  Revoked {$revoked} stale API tokens");
        return true;
    }

    protected function notifyDormantAdmins(): bool
    {
        $dormantDays = 30;
        $dormantAdmins = User::role(['admin', 'super_admin'])
            ->where('last_active_at', '<', now()->subDays($dormantDays))
            ->get();

        foreach ($dormantAdmins as $admin) {
            Notification::send($admin, new DormantAdminReminder());
        }

        $this->line("  Notified {$dormantAdmins->count()} dormant admins");
        return true;
    }

    protected function validateRoleIntegrity(): bool
    {
        $validator = app(PermissionGroupValidator::class);
        $issues = [];

        foreach (PermissionGroup::all() as $group) {
            $groupIssues = $validator->validate($group);
            $issues = array_merge($issues, $groupIssues);
        }

        if (! empty($issues)) {
            $this->warn("  Found " . count($issues) . " integrity issues:");
            foreach ($issues as $issue) {
                $this->warn("    - {$issue}");
            }
            return false;
        }

        $this->line("  All role integrity checks passed");
        return true;
    }
```

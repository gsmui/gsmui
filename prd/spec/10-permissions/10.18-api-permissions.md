# 10.18 — API Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines authorization rules for **API access** via Laravel Sanctum. API tokens have scoped permissions that mirror the web permissions but are independently managed. API authorization ensures that programmatic access respects the same security boundaries as the web interface, while providing fine-grained token scoping for third-party integrations, CI/CD pipelines, and personal automation.

API permissions are critical because they bypass browser-based CSRF protection and rely entirely on token-based authentication. A leaked token with excessive permissions can cause more damage than a compromised browser session.

## Scope

API permissions govern:

- Personal access token creation and management
- Team access token management
- Integration token management for third-party services
- Token permission scoping (fine-grained)
- API rate limiting by role
- Endpoint-level authorization
- Token revocation and lifecycle management

## API Token Types

### Personal Access Tokens

- Created by users for their own integrations
- Scoped to user's own permissions (cannot exceed user's role)
- Used for personal automation, scripts, and third-party app connections

### Team Access Tokens

- Created by team owners/admins for team-wide integrations
- Scoped to team-level permissions
- Used for CI/CD pipelines, team automation

### Integration Tokens

- Created by Admin for third-party marketplace integrations
- Can have cross-user permissions (e.g., reading public marketplace data)
- Used for marketplace partner APIs and webhooks

```php
    'my-integration-token',

// Token with all user permissions

    ['themes.view', 'components.create', 'components.update']
```

### Token Scope Validation

```php
class TokenScopeValidator
{
    public function validateScopes(User $user, array $requestedScopes): bool
    {
        $userPermissions = $user->getAllPermissions()->pluck('name')->toArray();

        foreach ($requestedScopes as $scope) {
            if ($scope === '*') {
                continue; // Wildcard handled separately
            }

            if (! in_array($scope, $userPermissions)) {
                return false; // Cannot grant permissions user doesn't have
            }
        }

        return true;
    }

    public function filterScopes(User $user, array $requestedScopes): array
    {
        $userPermissions = $user->getAllPermissions()->pluck('name')->toArray();

        return array_filter($requestedScopes, function ($scope) use ($userPermissions) {
            return $scope === '*' || in_array($scope, $userPermissions);
        });
    }
}
```

## API Rate Limits by Role

| Role | Requests/min | Burst | Daily Limit |
|---|---|---|---|
| Guest | 30 | 60 | 1,000 |
| User | 60 | 120 | 10,000 |
| Pro User | 120 | 240 | 50,000 |
| Creator | 180 | 360 | 100,000 |
| Admin | 300 | 600 | Unlimited |
| Super Admin | 500 | 1,000 | Unlimited |

### Rate Limit Implementation

```php
class ApiRateLimiter
{
    public function getRateLimit(User $user): array
    {
        $role = $this->getHighestRole($user);

        return self::LIMITS[$role] ?? self::LIMITS['guest'];
    }

    public function tooManyRequests(Request $request): bool
    {
        $user = $request->user();
        $limits = $this->getRateLimit($user);

        $key = 'api:rate:' . $user?->id ?? $request->ip();
        $current = Cache::get($key, 0);

        return $current >= $limits['per_minute'];
    }

    public function increment(Request $request): void
    {
        $user = $request->user();
        $key = 'api:rate:' . $user?->id ?? $request->ip();

        Cache::increment($key);
        Cache::put($key, Cache::get($key), 60); // 1-minute window
    }
}
```

## API Authorization Flow

```text
Request arrives with Bearer token
    ↓
Sanctum validates token
    ↓
Resolve user from token
    ↓
Check token scopes
    ↓
Rate limit check
    ↓
Route middleware checks required permissions
    ↓
Policy checks resource-level access
    ↓
Business service rules
    ↓
Response includes rate limit headers:
    X-RateLimit-Limit
    X-RateLimit-Remaining
    X-RateLimit-Reset
```

## API Response Authorization

```php
class ApiResponse
{
    public function authorized(mixed $data, int $statusCode = 200): JsonResponse
    {
        return response()->json([
            'data' => $data,
            'meta' => [
                'rate_limit' => [
                    'limit' => $this->rateLimit['per_minute'],
                    'remaining' => $this->rateLimit['per_minute'] - $this->currentUsage,
                    'reset' => $this->rateLimitReset,
                ],
            ],
        ], $statusCode);
    }

    public function forbidden(string $message = 'Unauthorized'): JsonResponse
    {
        return response()->json([
            'error' => 'forbidden',
            'message' => $message,
        ], 403);
    }

    public function rateLimited(): JsonResponse
    {
        return response()->json([
            'error' => 'rate_limited',
            'message' => 'Too many requests. Please slow down.',
        ], 429)->withHeaders([
            'X-RateLimit-Reset' => $this->rateLimitReset,
            'Retry-After' => $this->retryAfter,
        ]);
    }
}
```

## Security Considerations

### Token Security

| Measure | Implementation |
|---|---|
| Token hashing | Tokens stored as SHA-256 hashes |
| TLS only | All API traffic over HTTPS |
| Token rotation | Users can regenerate tokens |
| Scope enforcement | Middleware validates token scopes |
| IP whitelisting | Optional per-token IP restrictions |
| Expiry | Configurable TTL per token type |

### OAuth 2.0 Authorization Flow

```text
Third-party app redirects to /oauth/authorize
    ↓

App uses token for API access
```

## API Input Validation

Comprehensive input validation protects against malformed data and injection attacks.

### Validation Policy

```php
class ApiValidationPolicy
{
    public function validateRequest(string $endpoint, array $data, User $user): array
    {
        $rules = $this->getRulesForEndpoint($endpoint);
        $validator = Validator::make($data, $rules);

        if ($validator->fails()) {
            return [
                'valid' => false,
                'errors' => $validator->errors()->toArray(),
            ];
        }

        return ['valid' => true];
    }

    private function getRulesForEndpoint(string $endpoint): array
    {
        return match($endpoint) {
            'POST /api/themes' => [
                'name' => 'required|string|max:255',
                'description' => 'nullable|string|max:5000',
                'price' => 'nullable|numeric|min:0|max:999.99',
            ],
            'POST /api/components' => [
                'name' => 'required|string|max:255',
                'description' => 'nullable|string|max:5000',
            ],
            default => [],
        };
    }
}
```

### Security Audit Service

```php
class ApiSecurityAudit
{
    public function detectBruteForce(Request $request): bool
    {
        $ip = $request->ip();
        $key = "api:security:brute_force:{$ip}";

        $attempts = Cache::get($key, 0);

        if ($attempts >= 10) { // 10 failed attempts
            $this->alertAdmin('Brute force attempt', [
                'ip' => $ip,
                'attempts' => $attempts,
            ]);

            return true;
        }

        return false;
    }

    public function detectInjection(Request $request): bool
    {
        $payload = $request->all();
        $payloadString = json_encode($payload);

        $patterns = [
            '/\bUNION\b.*\bSELECT\b/i',
            '/\bINSERT\b.*\bINTO\b/i',
            '/\bDELETE\b.*\bFROM\b/i',
            '/<script\b[^>]*>/i',
            '/javascript:/i',
            '/on\w+\s*=/i',
        ];

        foreach ($patterns as $pattern) {
            if (preg_match($pattern, $payloadString)) {
                activity()
                    ->withProperties([
                        'ip' => $request->ip(),
                        'endpoint' => $request->path(),
                        'pattern' => $pattern,
                    ])
                    ->event('api.security.injection_attempt')
                    ->log('Potential injection attempt detected');

                return true;
            }
        }

        return false;
    }

    public function checkIpReputation(string $ip): bool
    {
        // Check against known malicious IP lists
        $maliciousRanges = Cache::get('api:security:malicious_ips', []);

        foreach ($maliciousRanges as $range) {
            if ($this->ipInRange($ip, $range)) {
                return false;
            }
        }

        return true;
    }
}
```

```php
    {
```

## API Response Envelope

All API responses follow a standard envelope format:

```json
{
    "status": "success",
    "data": {},
    "meta": {
        "request_id": "uuid",
        "timestamp": "ISO8601",
        "api_version": "v1"
    },
    "pagination": {
        "total": 100,
        "per_page": 20,
        "current_page": 1,
        "last_page": 5
    }
}
```

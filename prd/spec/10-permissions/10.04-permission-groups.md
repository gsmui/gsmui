# 10.04 — Permission Groups

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document catalogs every permission in the GsmUi platform, organized by domain into logical groups. Each group maps to a platform domain and contains all CRUD actions plus domain-specific operations. Permissions follow the `resource.action` naming convention defined in [10.01-overview.md](./10.01-overview.md).

See [10.03-roles.md](./10.03-roles.md) for which roles receive which permissions and [10.05-policies.md](./10.05-policies.md) for policy enforcement details.

## Naming Convention

All permissions follow the `resource.action` format:

```
<resource>.<action>
```

### Standard Actions

| Action | Purpose | Typical Roles |
|---|---|---|
| `view` | Read access to resource(s) | All authenticated |
| `create` | Create new resource | Creator, Admin |
| `update` | Modify existing resource | Owner, Admin |
| `delete` | Remove resource (soft or hard) | Owner, Admin |
| `publish` | Make resource public | Creator, Moderator, Admin |
| `feature` | Highlight/promote resource | Moderator, Admin |
| `export` | Download resource data | Admin |

### Domain-Specific Actions

Some domains have custom actions beyond standard CRUD:

| Domain | Action | Purpose |
|---|---|---|
| Themes | `install` | Install purchased theme |
| Templates | `install` | Install template to project |
| Marketplace | `purchase` | Buy marketplace item |
| Marketplace | `refund` | Process item refund |
| Orders | `cancel` | Cancel pending order |
| Orders | `refund` | Refund completed order |
| Licenses | `revoke` | Revoke active license |
| Playground | `execute` | Run code in playground |
| Playground | `share` | Share playground result |
| AI | `generate` | Generate AI content |
| AI | `configure` | Configure AI settings |
| MCP | `execute` | Execute MCP tool |
| MCP | `configure` | Configure MCP server |
| Settings | `manage` | System-wide settings |

## Permission Groups

### 1. Users

User management permissions. Controls who can view, create, update, and delete user accounts.

| Permission | Description | Assigned Roles |
|---|---|---|
| `users.view` | View user profiles and details | Support, Editor, Admin |
| `users.create` | Create new user accounts | Admin |
| `users.update` | Update user details (name, email, role) | Admin |
| `users.delete` | Delete or deactivate user accounts | Admin |
| `users.export` | Export user data (GDPR compliance) | Admin |

```php
// Policy: UserPolicy
public function view(User $user, User $target): bool
{
    return $user->id === $target->id || $user->hasPermissionTo('users.view');
}
```

Role management permissions. Controls who can create, modify, and assign roles.

| Permission | Description | Assigned Roles |

| `roles.update` | Modify role permissions | Admin |

```php
// Policy: RolePolicy
public function update(User $user, Role $role): bool
{
    // Cannot modify seeded roles
    if ($role->is_seeded) {
        return false;
    }
    
    return $user->hasPermissionTo('roles.update');
}
```

## Permission Naming Conventions (Detailed)

### Format Rules

All permissions follow the `resource.action` format with these rules:

1. **Lowercase only**: `themes.create` not `Themes.Create`
2. **Underscore for multi-word resources**: `marketplace_listings` not `marketplace-listings`
3. **Present tense actions**: `create` not `creating` or `created`
4. **No abbreviations**: `documentation` not `docs`
5. **No articles**: `view` not `view_the`

### Standard Actions Reference

|---|---|---|---|
| `view` | Read access | `themes.view` | List or single resource |

### Permission Conflict Detection

Some permissions should not be assigned together:

```php
// Permission conflict rules
$conflicts = [
    ['users.create', 'users.delete'], // Don't give both create and delete to same role
    ['settings.view', 'settings.manage'], // Separate view and manage
    ['system.health', 'system.maintenance'], // Health is read-only, maintenance is write
];
```

## Permission Group Versioning

### Schema Version Tracking

Each permission group is versioned to support schema evolution across deployments. When permissions are added, removed, or restructured, the version increments to allow migration scripts to target specific schema changes.

```php
// app/Models/PermissionGroup.php

class PermissionGroup extends Model
{
    protected $fillable = [
        'name',
        'slug',
        'description',
        'version',
        'schema_hash',
        'is_system',   // system groups cannot be deleted
        'is_active',
        'sort_order',
    ];

    protected $casts = [
        'version' => 'integer',
        'is_system' => 'boolean',
        'is_active' => 'boolean',
    ];

    /**
     * Compute a hash of the group's current permission set.
     * Used to detect drift between environments.
     */
    public function computeSchemaHash(): string
    {
        $permissions = $this->permissions()
            ->pluck('name')
            ->sort()
            ->values()
            ->toArray();

        return hash('sha256', json_encode($permissions));
    }

    /**
     * Check if this group has drifted from expected schema.
     */
    public function hasSchemaDrift(): bool
    {
        return $this->schema_hash !== $this->computeSchemaHash();
    }
}
```

### Schema Drift Detection

Run schema drift detection in CI to catch environment mismatches:

```php
// app/Console/Commands/CheckPermissionDrift.php

class CheckPermissionDrift extends Command
{
    protected $signature = 'permissions:check-drift';
    protected $description = 'Detect permission schema drift across environments';

    public function handle(): int

            $this->line("  Actual hash:   {$item['actual']}");
        }

}
```

### Cache Invalidation Patterns

Permission group cache must be invalidated when:

- A group is created, renamed, or deleted
- A user is assigned or removed from a role that references group permissions

```php
// app/Observers/PermissionGroupObserver.php

class PermissionGroupObserver
{
    public function saved(PermissionGroup $group): void
    {
        // Clear group-level cache
        Cache::forget("group:{$group->slug}:permissions");
        Cache::forget('permission_groups');

        // Clear affected user caches
        $affectedUserIds = DB::table('model_has_roles')
            ->join('role_has_permissions', 'model_has_roles.role_id', '=', 'role_has_permissions.role_id')

            if ($user) {

            }
        }
    }

    {
        Cache::forget("group:{$group->slug}:permissions");
```

### Cache Hit Rate Monitoring

Track cache performance to optimize TTL values and detect invalidation storms:

```php
// app/Services/PermissionCacheMetrics.php

class PermissionCacheMetrics
{
    private int $hits = 0;
    private int $misses = 0;

    public function recordHit(): void
    {
        $this->hits++;
        $this->reportIfNeeded();
    }

    public function recordMiss(): void
    {
        $this->misses++;
        $this->reportIfNeeded();
    }

    public function getHitRate(): float
    {
        $total = $this->hits + $this->misses;
        return $total > 0 ? round($this->hits / $total, 4) : 0.0;
    }

    protected function reportIfNeeded(): void
    {
        $total = $this->hits + $this->misses;
        if ($total % 1000 === 0 && $total > 0) {
            $rate = $this->getHitRate();
            if ($rate < 0.9) {
                Log::warning('Low permission cache hit rate', [
                    'hit_rate' => $rate,
                    'hits' => $this->hits,
                    'misses' => $this->misses,
                ]);
            }
        }
    }
}
```

## Permission Group Validation

### Runtime Validation

Validate permission group consistency at runtime to catch misconfigurations early:

```php
// app/Services/PermissionGroupValidator.php

class PermissionGroupValidator
{
    public function validate(PermissionGroup $group): array
    {
        $issues = [];

        // Check for empty groups
        if ($group->permissions()->count() === 0) {
            $issues[] = "Group '{$group->slug}' has no permissions assigned.";
        }

        // Check for duplicate permissions across groups
        $duplicates = $this->findDuplicatePermissions($group);
        if (! empty($duplicates)) {
            $issues[] = "Duplicate permissions found: " . implode(', ', $duplicates);
        }

        // Check naming convention
        if (! preg_match('/^[a-z][a-z0-9_]*$/', $group->slug)) {
            $issues[] = "Group slug '{$group->slug}' violates naming convention (lowercase, underscores only).";
        }

        // Check for orphaned permissions (permissions not in any group)
        $orphaned = $this->findOrphanedPermissions();
        if (! empty($orphaned)) {
            $issues[] = "Orphaned permissions: " . implode(', ', $orphaned);
        }

        return $issues;
    }

    protected function findDuplicatePermissions(PermissionGroup $group): array
    {
        return DB::table('permission_group_permissions')
            ->join('permissions', 'permission_group_permissions.permission_id', '=', 'permissions.id')
            ->select('permissions.name', DB::raw('COUNT(*) as cnt'))
            ->groupBy('permissions.name')
            ->having('cnt', '>', 1)
            ->pluck('permissions.name')
            ->toArray();
    }

    protected function findOrphanedPermissions(): array
    {
        return Permission::whereNotIn('id', function ($query) {
            $query->select('permission_id')->from('permission_group_permissions');
        })
        ->pluck('name')
        ->toArray();
    }
}
```

```php
                DB::raw('SUM(CASE WHEN result = 0 THEN 1 ELSE 0 END) as denied'),

                DB::raw('MAX(duration_ms) as max_duration'),
            )
            ->whereBetween('created_at', [$from, $to])
            ->groupBy('group_name')
            ->orderByDesc('total_checks')
            ->get();
    }

    public function getDeniedRate(string $groupName, Carbon $from, Carbon $to): float
    {
        $stats = DB::table('permission_check_log')
            ->select(
                DB::raw('COUNT(*) as total'),
                DB::raw('SUM(CASE WHEN result = 0 THEN 1 ELSE 0 END) as denied'),
            )
            ->where('group_name', $groupName)
            ->whereBetween('created_at', [$from, $to])
            ->first();

        return $stats->total > 0
            ? round($stats->denied / $stats->total, 4)
            : 0.0;
    }
}
```

### Removing a Group

When retiring a group, ensure no active permissions depend on it:

```php

return new class extends Migration

                ->whereIn('permission_id', $group->permissions->pluck('id'))
```

### Audit Logging for Group Changes

```php
// app/Observers/PermissionGroupAuditObserver.php

class PermissionGroupAuditObserver
{
    public function updated(PermissionGroup $group): void
    {
        $changes = $group->getChanges();

        ActivityLog::groupModified(
            $group,
            $changes,
            auth()->user()
        );

        // Alert on critical changes
        if (isset($changes['is_system']) && $changes['is_system'] === false) {
            $this->alertSystemGroupModified($group);
        }
    }

    public function deleted(PermissionGroup $group): void
    {
        ActivityLog::groupDeleted($group, auth()->user());

        if ($group->is_system) {
            $this->alertSystemGroupDeleted($group);
        }
    }

    protected function alertSystemGroupModified(PermissionGroup $group): void
    {
        Notification::send(
            User::role('super_admin')->get(),
            new SystemGroupModifiedAlert($group)
        );
    }

    protected function alertSystemGroupDeleted(PermissionGroup $group): void
    {
        Notification::send(
            User::role('super_admin')->get(),
            new SystemGroupDeletedAlert($group)
        );
    }
}
```

### Rate Limiting on Group Operations

```php
// app/Http/Middleware/RateLimitPermissionGroupOps.php

class RateLimitPermissionGroupOps
{
    public function handle($request, Closure $next): JsonResponse
    {
        $key = 'permission_group_ops:' . auth()->id();
        $maxAttempts = 10;
        $decayMinutes = 1;

        if (RateLimiter::tooManyAttempts($key, $maxAttempts)) {
            return response()->json([
                'message' => 'Too many permission group operations. Please try again later.',
            ], 429);
        }

        RateLimiter::hit($key, $decayMinutes * 60);

        return $next($request);
    }
}
```

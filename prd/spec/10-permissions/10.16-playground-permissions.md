# 10.16 — Playground Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines authorization rules for the **Playground domain**. The Playground is a sandboxed code execution environment that allows users to run code snippets, save sessions, share them publicly, and manage playground resources. Playground permissions enforce tier-based execution limits, session ownership, and resource quotas.

Playground authorization must balance openness (encouraging experimentation) with security (isolating execution, preventing abuse, and enforcing resource limits). Every code execution is sandboxed, every session is ownership-scoped, and every sharing action is gated by subscription tier.

## Scope

Playground permissions govern:

- Accessing the playground interface
- Executing code in sandboxed containers
- Saving playground sessions
- Sharing sessions publicly
- Deleting own sessions
- Managing playground templates (admin-only)
- Viewing others' shared sessions
- Execution resource limits per role

## Permission Definitions

| Permission | Description | User | Pro User | Creator | Admin |
|---|---|---|---|---|---|
| `playground.view` | Access playground interface | ✅ | ✅ | ✅ | ✅ |
| `playground.execute` | Run code in sandbox | ✅ (limited) | ✅ (full) | ✅ (full) | ✅ (full) |
| `playground.save` | Save playground session | ❌ | ✅ | ✅ | ✅ |
| `playground.share` | Share session publicly | ❌ | ✅ | ✅ | ✅ |
| `playground.delete` | Delete own session | ❌ | ✅ (own) | ✅ (own) | Any |
| `playground.manage_templates` | Manage playground templates | ❌ | ❌ | ❌ | ✅ |
| `playground.view_others` | View others' shared sessions | ❌ | ✅ | ✅ | ✅ |

```php
class PlaygroundResourceLimits
{
    private const LIMITS = [
        'user' => [
            'execution_time' => 5,
            'memory' => 64 * 1024 * 1024,
            'output_size' => 10 * 1024,
            'concurrent' => 1,
            'daily_executions' => 10,
            'storage_bytes' => 0,
            'max_sessions' => 0,
        ],
        'pro_user' => [
            'execution_time' => 30,
            'memory' => 256 * 1024 * 1024,
            'output_size' => 100 * 1024,
            'concurrent' => 3,
            'daily_executions' => -1, // unlimited
            'storage_bytes' => 50 * 1024 * 1024,
            'max_sessions' => 25,
        ],
        'creator' => [
            'execution_time' => 30,
            'memory' => 256 * 1024 * 1024,
            'output_size' => 100 * 1024,
            'concurrent' => 5,
            'daily_executions' => -1,
            'storage_bytes' => 100 * 1024 * 1024,
            'max_sessions' => 100,
        ],
        'admin' => [
            'execution_time' => 60,
            'memory' => 512 * 1024 * 1024,
            'output_size' => 1024 * 1024,
            'concurrent' => 10,
            'daily_executions' => -1,
            'storage_bytes' => 500 * 1024 * 1024,
            'max_sessions' => -1,
        ],
    ];

    public function getLimitsForUser(User $user): array
    {
        $role = $this->getHighestRole($user);

        return self::LIMITS[$role] ?? self::LIMITS['user'];
    }

    public function canExecute(User $user): bool
    {
        $limits = $this->getLimitsForUser($user);

        if ($limits['daily_executions'] === -1) {
            return true;
        }

        $todayCount = $this->getDailyExecutionCount($user);

        return $todayCount < $limits['daily_executions'];
    }
}
```

## Sandbox Security

All code execution occurs in isolated Docker containers with strict constraints:

### Container Isolation

| Constraint | Implementation |
|---|---|
| Process isolation | Separate container per execution |
| Network access | Disabled (except whitelisted APIs) |
| Filesystem | Read-only base + writable temp volume |
| Time limit | Enforced by container timeout |
| Memory limit | Enforced by Docker cgroup |
| CPU limit | 1 vCPU per execution |
| Syscalls | Seccomp profile restricting dangerous calls |
| User | Non-root (nobody:nogroup) |

### Language Support

| Language | Runtime | Max Execution Time |
|---|---|---|
| PHP | php-cli | Role-based |
| JavaScript | Node.js | Role-based |
| Python | python3 | Role-based |
| Bash | bash (restricted) | Role-based |

### Whitelisted APIs

Only the following external APIs are accessible from the sandbox:

| API | Purpose |
|---|---|
| `api.gsmui.test` | GsmUi platform API |
| `jsonplaceholder.typicode.com` | Demo data API |
| `httpbin.org` | HTTP testing API |

## Policy Implementation

```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\PlaygroundSession;
use App\Services\Playground\PlaygroundResourceLimits;
use Illuminate\Auth\Access\HandlesAuthorization;

class PlaygroundPolicy
{
    use HandlesAuthorization;

    public function __construct(
        private PlaygroundResourceLimits $resourceLimits,
    ) {}

    public function view(User $user): bool
    {
        return true; // All authenticated users can view
    }

    public function execute(User $user): bool
    {
        if (! $user->hasRole(['user', 'pro_user', 'creator', 'admin'])) {
            return false;
        }

        return $this->resourceLimits->canExecute($user);
    }

    public function save(User $user): bool
    {
        return $user->hasRole(['pro_user', 'creator', 'admin']);
    }

    public function share(User $user, PlaygroundSession $session): bool
    {
        if (! $user->hasRole(['pro_user', 'creator', 'admin'])) {
            return false;
        }

        return $user->id === $session->user_id;
    }

    public function delete(User $user, PlaygroundSession $session): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        return $user->id === $session->user_id
            && $user->hasRole(['pro_user', 'creator']);
    }

    public function manageTemplates(User $user): bool
    {
        return $user->hasRole('admin');
    }

    public function viewOthers(User $user): bool
    {
        return $user->hasRole(['pro_user', 'creator', 'admin']);
    }
}
```

## Rate Limiting

```php
class PlaygroundRateLimiter
{
    public function tooManyExecutions(User $user): bool
    {
        $limits = $this->resourceLimits->getLimitsForUser($user);

        // Check concurrent executions
        $concurrent = Cache::get("playground:concurrent:{$user->id}", 0);
        if ($concurrent >= $limits['concurrent']) {
            return true;
        }

        // Check daily executions (if limited)
        if ($limits['daily_executions'] !== -1) {
            $daily = Cache::get("playground:daily:{$user->id}", 0);
            if ($daily >= $limits['daily_executions']) {
                return true;
            }
        }

        return false;
    }

    public function incrementExecution(User $user): void
    {
        Cache::increment("playground:concurrent:{$user->id}");
        Cache::increment("playground:daily:{$user->id}");

        // Release concurrent count after execution
        Cache::decrement("playground:concurrent:{$user->id}", 120);
    }
}
```

## Playground Session Management

Session management governs the lifecycle of playground sessions from creation through archival. Sessions persist user code, output, and metadata.

### Session Lifecycle States

```text
created
  ↓ (execute code)
executing
  ↓ (execution complete)
completed
  ↓ (user saves)
saved
  ↓ (user shares)
shared
  ↓ (user deletes or auto-expire)
deleted
```

### Session State Transition Matrix

| From State | To State | Trigger | Permission Required |
|---|---|---|---|
| `created` | `executing` | User clicks run | `playground.execute` |
| `executing` | `completed` | Execution finishes | — |
| `completed` | `saved` | User saves session | `playground.save` |
| `saved` | `shared` | User shares session | `playground.share` |
| `shared` | `saved` | User unshares | `playground.update` (own) |
| `saved` | `deleted` | User deletes session | `playground.delete` (own) |
| Any | `deleted` | Admin force deletes | `playground.delete` (admin) |

### Session Service

```php
class PlaygroundSessionService
{
    public function createSession(User $user, string $language, string $code): PlaygroundSession
    {
        if (! $user->can('save')) {
            throw new AuthorizationException('Upgrade required to save sessions');
        }

        $limits = $this->resourceLimits->getLimitsForUser($user);

        $currentSessions = PlaygroundSession::where('user_id', $user->id)
            ->where('status', '!=', 'deleted')
            ->count();

        if ($limits['max_sessions'] !== -1 && $currentSessions >= $limits['max_sessions']) {
            throw new ReachedSessionLimitException('Session limit reached');
        }

        return PlaygroundSession::create([
            'user_id' => $user->id,
            'title' => 'Untitled Session',
            'language' => $language,
            'code' => $code,
            'status' => 'created',
        ]);
    }

    public function shareSession(User $user, PlaygroundSession $session): string
    {
        if (! $user->can('share', $session)) {
            throw new AuthorizationException('Cannot share this session');
        }

        $session->update([
            'is_shared' => true,
            'share_token' => Str::random(64),
        ]);

        activity()
            ->performedOn($session)
            ->event('playground.session.shared')
            ->log('Playground session shared publicly');

        return $session->share_token;
    }

    public function unshareSession(User $user, PlaygroundSession $session): void
    {
        if (! $user->can('update', $session)) {
            throw new AuthorizationException('Cannot update this session');
        }

        $session->update([
            'is_shared' => false,
            'share_token' => null,
        ]);
    }
}
```

## Playground Code Execution Engine

The execution engine manages sandboxed code execution with resource constraints and output capture.

### Execution Engine Architecture

```text
User submits code
    ↓
Validate language support
    ↓
Check execution permission
    ↓
Check rate limits
    ↓
Parse and validate code
    ↓
Allocate Docker container
    ↓
Set resource limits (time, memory, CPU)
    ↓
Execute code with timeout
    ↓
Capture stdout/stderr
    ↓
Measure resource usage
    ↓
Release container
    ↓
Store execution result
    ↓
Return output to user
```

### Execution Engine Service

```php
class PlaygroundExecutionEngine
{
    public function execute(
        User $user,
        string $language,
        string $code,
        ?int $timeoutSeconds = null,
    ): ExecutionResult {
        // Validate permission
        if (! $user->can('execute')) {
            throw new AuthorizationException('Execution permission required');
        }

        // Check rate limits
        if ($this->rateLimiter->tooManyExecutions($user)) {
            throw new RateLimitExceededException('Execution limit reached');
        }

        // Get resource limits
        $limits = $this->resourceLimits->getLimitsForUser($user);
        $timeout = $timeoutSeconds ?? $limits['execution_time'];

        // Allocate container
        $container = $this->containerManager->allocate([
            'image' => $this->getImageForLanguage($language),
            'memory_limit' => $limits['memory'],
            'cpu_limit' => '1',
            'timeout' => $timeout,
            'network' => 'none',
            'read_only_root' => true,
        ]);

        try {
            // Execute code
            $result = $container->exec($code, [
                'timeout' => $timeout,
                'max_output_size' => $limits['output_size'],
            ]);

            // Log execution
            $this->logExecution($user, $result);

            // Increment counters
            $this->rateLimiter->incrementExecution($user);

            return $result;
        } finally {
            // Always release container
            $container->destroy();
        }
    }

    private function getImageForLanguage(string $language): string
    {
        return match($language) {
            'php' => 'gsmui/playground-php:latest',
            'javascript' => 'gsmui/playground-node:latest',
            'python' => 'gsmui/playground-python:latest',
            'bash' => 'gsmui/playground-bash:latest',
            default => throw new InvalidArgumentException("Unsupported language: {$language}"),
        };
    }

    private function logExecution(User $user, ExecutionResult $result): void
    {
        PlaygroundExecutionLog::create([
            'user_id' => $user->id,
            'session_id' => $result->sessionId,
            'language' => $result->language,
            'code_hash' => hash('sha256', $result->code),
            'execution_time_ms' => $result->durationMs,
            'memory_used_bytes' => $result->memoryBytes,
            'output_size_bytes' => strlen($result->output),
            'status' => $result->status,
            'error_message' => $result->errorMessage,
        ]);
    }
}
```

## Playground Sharing and Collaboration

Sharing features allow users to share code sessions publicly and collaborate in real-time.

### Sharing Authorization

```php
class PlaygroundSharingPolicy
{
    public function shareSession(User $user, PlaygroundSession $session): bool
    {
        if (! $user->hasRole(['pro_user', 'creator', 'admin'])) {
            return false;
        }

        return $user->id === $session->user_id
            && $session->status === 'completed';
    }

    public function viewShared(User $user, string $shareToken): bool
    {
        $session = PlaygroundSession::where('share_token', $shareToken)
            ->where('is_shared', true)
            ->first();

        if (! $session) {
            return false;
        }

        // Owner can always view
        if ($user && $user->id === $session->user_id) {
            return true;
        }

        // Pro users and above can view shared sessions
        return $user && $user->hasRole(['pro_user', 'creator', 'admin']);
    }

    public function embedSession(User $user, PlaygroundSession $session): bool
    {
        return $session->is_shared
            || ($user && $user->id === $session->user_id);
    }

    public function forkSession(User $user, PlaygroundSession $session): bool
    {
        if (! $user->hasRole(['pro_user', 'creator', 'admin'])) {
            return false;
        }

        return $session->is_shared
            && $user->id !== $session->user_id;
    }
}
```

## Playground Security Audit

Security audit rules ensure all playground activities are logged and anomalies are detected.

### Security Audit Events

| Event | Severity | Action |
|---|---|---|
| Rate limit exceeded | Medium | Log + warn user |
| Container escape attempt | Critical | Log + alert admin + ban user |
| Malicious code detected | Critical | Log + alert admin + review |
| Excessive resource usage | High | Log + warn user |
| Unauthorized access attempt | High | Log + alert admin |
| Token abuse detected | Critical | Log + revoke token + ban user |
| Network policy violation | High | Log + alert admin |

### Security Audit Service

```php
class PlaygroundSecurityAudit
{
    public function detectAnomalies(User $user, ExecutionResult $result): void
    {
        // Check for container escape attempts
        if ($this->detectEscapeAttempt($result)) {
            $this->alertAdmin('Container escape attempt', [
                'user_id' => $user->id,
                'code_hash' => hash('sha256', $result->code),
            ]);

            activity()
                ->performedOn($user)
                ->event('playground.security.escape_attempt')
                ->log('Container escape attempt detected');
        }

        // Check for excessive resource usage
        if ($result->memoryBytes > 200 * 1024 * 1024) { // 200MB
            activity()
                ->performedOn($user)
                ->withProperties([
                    'memory_used' => $result->memoryBytes,
                ])
                ->event('playground.security.excessive_memory')
                ->log('Excessive memory usage detected');
        }

        // Check for suspicious code patterns
        if ($this->detectSuspiciousCode($result->code)) {
            activity()
                ->performedOn($user)
                ->event('playground.security.suspicious_code')
                ->log('Suspicious code pattern detected');
        }
    }

    private function detectEscapeAttempt(ExecutionResult $result): bool
    {
        $patterns = [
            '/proc/self',
            '/etc/passwd',
            'docker.sock',
            'mount',
            'chroot',
        ];

        foreach ($patterns as $pattern) {
            if (str_contains($result->output, $pattern)) {
                return true;
            }
        }

        return false;
    }
}
```

## Playground Quality Assurance

Quality assurance rules ensure the playground meets minimum standards.

### Quality Gates

| Gate | Requirement | Blocking |
|---|---|---|
| Code execution reliability | ≥ 99% success rate | Yes |
| Average response time | < 5 seconds | Yes |
| Error rate | < 1% | Yes |
| Uptime | ≥ 99.9% | Yes |
| Security scan | Zero critical findings | Yes |
| Accessibility audit | Score ≥ 90 | Yes |

### Quality Gate Service

```php
class PlaygroundQualityGate
{
    public function passAllGates(): array
    {
        return [
            'reliability' => $this->checkReliability(),
            'response_time' => $this->checkResponseTime(),
            'error_rate' => $this->checkErrorRate(),
            'uptime' => $this->checkUptime(),
            'security' => $this->checkSecurity(),
            'accessibility' => $this->checkAccessibility(),
        ];
    }

    public function canOperate(): bool
    {
        $gates = $this->passAllGates();

        return ! in_array(false, $gates);
    }

    private function checkReliability(): bool
    {
        $successRate = DB::table('playground_execution_logs')
            ->where('executed_at', '>=', now()->subDays(7))
            ->selectRaw('SUM(CASE WHEN status = "success" THEN 1 ELSE 0 END) / COUNT(*) * 100 as success_rate')
            ->value('success_rate');

        return $successRate >= 99;
    }

    private function checkResponseTime(): bool
    {
        $avgTime = DB::table('playground_execution_logs')
            ->where('executed_at', '>=', now()->subDays(7))
            ->avg('execution_time_ms');

        return $avgTime <= 5000;
    }
}
```

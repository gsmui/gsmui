# 10.20 — Team Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines authorization rules for **team-scoped permissions**. Teams allow multiple users to collaborate on themes, components, templates, and marketplace listings with role-based access within the team context. Team permissions layer on top of user-level permissions, adding an additional dimension of access control.

Team authorization introduces a third axis of permission resolution: user-level, role-level, and team-level. A user's effective permissions are the union of their personal permissions and their team-scoped permissions for the active team context.

**Status:** Planned for Phase 2. Team permissions are designed now for architectural consistency but are not yet implemented.

## Scope

Team permissions govern:

- Team creation, update, and deletion
- Team member invitation and removal
- Team role assignment (Owner, Admin, Member, Guest)
- Team-scoped resource access (themes, components, templates)
- Team billing management
- Team audit log access
- Cross-team permission isolation

## Team Roles

| Team Role | Description | Can Assign | Inherits |
|---|---|---|---|
| Owner | Full team control, billing, deletion | — | All team permissions |
| Admin | Manage members, settings, resources | Owner | Member permissions |
| Member | Basic team access, resource collaboration | Owner, Admin | Guest permissions |
| Guest | Limited read-only access | Owner, Admin | None |

## Permission Resolution

```text
User requests action on resource
    ↓
Resolve user-level permissions (Spatie)
    ↓
Resolve team-level permissions (if team context active)
    ↓
Union of user + team permissions
    ↓
Policy evaluation (resource-level checks)
    ↓
Business rule enforcement
    ↓
Decision: allow / deny
```

### Permission Resolver Implementation

```php
<?php

namespace App\Services\Permissions;

use App\Models\User;
use App\Models\Team;
use Spatie\Permission\PermissionRegistrar;

class TeamPermissionResolver
{
    public function __construct(
        private PermissionRegistrar $permissionRegistrar,
    ) {}

    public function resolveEffectivePermissions(User $user, ?Team $team): array
    {
        // Start with user-level permissions
        $userPermissions = $user->getAllPermissions()->pluck('name')->toArray();

        if (! $team) {
            return $userPermissions;
        }

        // Add team-scoped permissions
        $teamPermissions = $this->getTeamPermissions($user, $team);

        // Union of both
        return array_unique(array_merge($userPermissions, $teamPermissions));
    }

    public function getTeamPermissions(User $user, Team $team): array
    {
        $teamRole = $team->getUserRole($user);

        if (! $teamRole) {
            return []; // Not a team member
        }

        return $team->getPermissionsForRole($teamRole)
            ->pluck('name')
            ->toArray();
    }

    public function setTeamContext(?Team $team): void
    {
        $this->permissionRegistrar->setPermissionsTeamId(
            $team?->id
        );
    }
}
```

## Team Context Middleware

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Spatie\Permission\PermissionRegistrar;

class SetTeamContext
{
    public function __construct(
        private PermissionRegistrar $permissionRegistrar,
    ) {}

    public function handle(Request $request, Closure $next)
    {
        $team = $request->route('team');

        if ($team && $team->hasUser($request->user())) {
            $this->permissionRegistrar->setPermissionsTeamId($team->id);

            // Store team in request for downstream use
            request()->attributes->set('current_team', $team);
        }

        return $next($request);
    }
}
```

## Team Policy

```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\Team;
use Illuminate\Auth\Access\HandlesAuthorization;

class TeamPolicy
{
    use HandlesAuthorization;

    public function viewAny(User $user): bool
    {
        return true; // Users can see teams they belong to
    }

    public function view(User $user, Team $team): bool
    {
        return $team->hasUser($user);
    }

    public function create(User $user): bool
    {
        // Users can create teams if they have an active subscription
        return $user->hasRole(['pro_user', 'creator', 'admin']);
    }

    public function update(User $user, Team $team): bool
    {
        return $team->hasUser($user, ['owner', 'admin']);
    }

    public function delete(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id;
    }

    public function invite(User $user, Team $team): bool
    {
        return $team->hasUser($user, ['owner', 'admin']);
    }

    public function removeMember(User $user, Team $team, User $member): bool
    {
        // Owner can remove anyone
        if ($team->owner_id === $user->id) {
            return true;
        }

        // Admin can remove Members and Guests (not Owner or other Admins)
        if ($team->hasUser($user, ['admin'])) {
            $memberRole = $team->getUserRole($member);

            return in_array($memberRole, ['member', 'guest']);
        }

        return false;
    }

    public function manageRoles(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id;
    }

    public function manageBilling(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id;
    }

    public function viewAudit(User $user, Team $team): bool
    {
        return $team->hasUser($user, ['owner', 'admin']);
    }
}
```

### Invitation Policy

```php
class TeamInvitationPolicy
{
    public function create(User $user, Team $team): bool
    {
        return $team->hasUser($user, ['owner', 'admin']);
    }

    public function accept(User $user, TeamInvitation $invitation): bool
    {
        // Invitee must have verified email
        if (! $user->hasVerifiedEmail()) {
            return false;
        }

        // Check subscription requirement (if team requires pro)
        if ($invitation->team->requires_subscription) {
            return $user->hasRole(['pro_user', 'creator', 'admin']);
        }

        return true;
    }

    public function cancel(User $user, TeamInvitation $invitation): bool
    {
        return $user->id === $invitation->invited_by
            || $invitation->team->owner_id === $user->id;
    }
}
```

```php
        $teams = $this->user->teams;

    }

    {
        $this->authorize('create', Team::class);

            'name' => $request->name,
            'slug' => Str::slug($request->name),
            'owner_id' => $request->user()->id,
        ]);

        $team->addMember($request->user(), 'owner');

        return response()->json($team, 201);
    }

    public function update(UpdateTeamRequest $request, Team $team): JsonResponse
    {
        $this->authorize('update', $team);

        $team->update($request->validated());

        return response()->json($team);
    }

    public function destroy(Team $team): JsonResponse
    {
        $this->authorize('delete', $team);

        $team->delete();

        return response()->json(null, 204);
    }

    public function invite(InviteTeamMemberRequest $request, Team $team): JsonResponse
    {
        $this->authorize('invite', $team);

        $invitation = TeamInvitation::create([
            'team_id' => $team->id,
            'email' => $request->email,
            'role' => $request->role,
            'invited_by' => $request->user()->id,
            'token' => Str::random(64),
            'expires_at' => now()->addDays(7),
        ]);

        // Send invitation email
        Mail::to($request->email)->send(new TeamInvitationMail($invitation));

        return response()->json($invitation, 201);
    }

    public function removeMember(Team $team, User $member): JsonResponse
    {
        $this->authorize('removeMember', [$team, $member]);

        $team->removeMember($member);

        return response()->json(null, 204);
    }
}
```

## Team Permissions Deep Dive

### Team Role Hierarchy

The team role hierarchy is separate from the platform role hierarchy. A user can be a Super Admin on the platform but a Guest in a specific team:

| Team Role | Platform Equivalent | Inheritance | Special Rules |
|-----------|-------------------|-------------|---------------|
| Owner | Super Admin (team scope) | All team permissions | Cannot be removed, cannot downgrade self |
| Admin | Admin (team scope) | Member permissions | Cannot remove Owner, cannot promote to Owner |
| Member | User (team scope) | Guest permissions | Can edit own resources only |
| Guest | Guest (team scope) | None | Read-only access to team resources |

### Team Permission Resolution Algorithm

```php
<?php

namespace App\Services\Permissions;

use App\Models\User;
use App\Models\Team;

class TeamPermissionResolver
{
    public function resolve(User $user, ?Team $team, string $permission): bool
    {
        // Step 1: Check platform-level permissions first
        if ($this->hasPlatformPermission($user, $permission)) {
            return true;
        }

        // Step 2: If no team context, return false
        if (!$team) {
            return false;
        }

        // Step 3: Check if user is team member
        $teamRole = $team->getUserRole($user);
        if (!$teamRole) {
            return false; // Not a team member
        }

        // Step 4: Check team-level permissions
        $teamPermissions = $team->getPermissionsForRole($teamRole);
        if (in_array($permission, $teamPermissions)) {
            return true;
        }

        // Step 5: Check inherited permissions from lower roles
        $inheritedPermissions = $this->getInheritedTeamPermissions($teamRole);
        if (in_array($permission, $inheritedPermissions)) {
            return true;
        }

        // Step 6: Check resource ownership (for Own scope)
        return $this->checkResourceOwnership($user, $team, $permission);
    }

    protected function hasPlatformPermission(User $user, string $permission): bool
    {
        // Super Admins can access anything
        if ($user->hasRole('super_admin')) {
            return true;
        }

        // Check direct platform permission
        return $user->hasPermissionTo($permission);
    }

    protected function getInheritedTeamPermissions(string $role): array
    {
        $hierarchy = [
            'guest'   => [],
            'member'  => ['team.view', 'team.themes.view', 'team.components.view'],
            'admin'   => ['team.update', 'team.invite', 'team.remove_member', 'team.view_audit'],
            'owner'   => ['team.delete', 'team.manage_roles', 'team.billing'],
        ];

        return $hierarchy[$role] ?? [];
    }

    protected function checkResourceOwnership(User $user, Team $team, string $permission): bool
    {
        // Extract resource type from permission (e.g., 'team.themes.update' -> 'themes')
        $parts = explode('.', $permission);
        if (count($parts) < 3) return false;

        $resourceType = $parts[1];
        $action = $parts[2];

        // Only ownership checks apply for update/delete actions
        if (!in_array($action, ['update', 'delete'])) {
            return false;
        }

        // Check if user has a resource of this type in the team
        return $this->userOwnsTeamResource($user, $team, $resourceType);
    }

    protected function userOwnsTeamResource(User $user, Team $team, string $resourceType): bool
    {
        $modelClass = $this->getResourceModel($resourceType);
        if (!$modelClass) return false;

        return $modelClass::where('team_id', $team->id)
            ->where('created_by', $user->id)
            ->exists();
    }

    protected function getResourceModel(string $resourceType): ?string
    {
        $models = [
            'themes' => \App\Models\Theme::class,
            'components' => \App\Models\Component::class,
            'templates' => \App\Models\Template::class,
        ];

        return $models[$resourceType] ?? null;
    }
}
```

```text
    ↓
Email sent to invitee
    ↓
Invitee clicks link
    ↓
Check: invitee has verified email
    ↓

    ↓

    ↓
Check: invitation not already accepted
    ↓
Create team membership
    ↓
Assign team role and permissions
    ↓
Notify team owner
    ↓
Log membership creation
    ↓
Invitation status: accepted
```

```php
        'per_team_per_day' => 50,
        'per_user_per_hour' => 5,
        'per_user_per_day' => 20,
    ];

    public function canSendInvitation(User $sender, Team $team): bool
    {
        $teamHourKey = "team_invite:{$team->id}:hour";
        $teamDayKey = "team_invite:{$team->id}:day";
        $userHourKey = "team_invite:{$sender->id}:hour";
        $userDayKey = "team_invite:{$sender->id}:day";

        $teamHourCount = Cache::get($teamHourKey, 0);
        $teamDayCount = Cache::get($teamDayKey, 0);
        $userHourCount = Cache::get($userHourKey, 0);
        $userDayCount = Cache::get($userDayKey, 0);

        if ($teamHourCount >= self::LIMITS['per_team_per_hour']) {
            return false;
        }

        if ($teamDayCount >= self::LIMITS['per_team_per_day']) {
            return false;
        }

        if ($userHourCount >= self::LIMITS['per_user_per_hour']) {
            return false;
        }

        if ($userDayCount >= self::LIMITS['per_user_per_day']) {
            return false;
        }

        // Increment counters
        Cache::put($teamHourKey, $teamHourCount + 1, 3600);
        Cache::put($teamDayKey, $teamDayCount + 1, 86400);
        Cache::put($userHourKey, $userHourCount + 1, 3600);
        Cache::put($userDayKey, $userDayCount + 1, 86400);

        return true;
    }
```

#### Concurrent Editing

When multiple team members edit the same resource, implement conflict detection:

```php
<?php

namespace App\Services\TeamCollaboration;

use App\Models\User;
use App\Models\Team;
use App\Models\Resource;

class ConcurrentEditDetector
{
    public function checkForConflicts(Resource $resource, User $editor): ?ConflictInfo
    {
        // Check if another user is currently editing
        $activeEditors = $this->getActiveEditors($resource);

        if ($activeEditors->isEmpty()) {
            return null; // No conflict
        }

        // Filter out the current editor
        $otherEditors = $activeEditors->filter(fn($e) => $e->id !== $editor->id);

        if ($otherEditors->isEmpty()) {
            return null; // Only current editor
        }

        return new ConflictInfo(
            resource: $resource,
            conflictingEditors: $otherEditors,
            conflictStartedAt: $otherEditors->first()->editing_since,
            suggestedAction: $this->getSuggestedAction($resource, $editor, $otherEditors)
        );
    }

    public function startEditing(Resource $resource, User $user): void
    {
        // Create or update editing session
        DB::table('resource_editing_sessions')->updateOrInsert(
            [
                'resource_type' => get_class($resource),
                'resource_id' => $resource->id,
                'user_id' => $user->id,
            ],
            [
                'editing_since' => now(),
                'last_activity' => now(),
            ]
        );
    }

    public function stopEditing(Resource $resource, User $user): void
    {
        DB::table('resource_editing_sessions')
            ->where('resource_type', get_class($resource))
            ->where('resource_id', $resource->id)
            ->where('user_id', $user->id)
            ->delete();
    }

    protected function getActiveEditors(Resource $resource): Collection
    {
        return DB::table('resource_editing_sessions')
            ->where('resource_type', get_class($resource))
            ->where('resource_id', $resource->id)
            ->where('last_activity', '>=', now()->subMinutes(5))
            ->join('users', 'users.id', '=', 'resource_editing_sessions.user_id')
            ->get();
    }
}
```

```php
class TeamOwnerTransfer

    public function transfer(Team $team, User $currentOwner, User $newOwner): void
    {
        // Verify current owner
        if ($team->owner_id !== $currentOwner->id) {
            throw new \UnauthorizedException('Only the team owner can transfer ownership.');
        }

        // Verify new owner is team member
        if (!$team->hasUser($newOwner)) {
            throw new \InvalidArgumentException('New owner must be a team member.');
        }

        DB::transaction(function () use ($team, $currentOwner, $newOwner) {

            $team->update(['owner_id' => $newOwner->id]);

            // Update roles
            $team->removeMemberRole($currentOwner, 'owner');
            $team->addMemberRole($currentOwner, 'admin');
            $team->addMemberRole($newOwner, 'owner');

            TeamActivity::log('team.owner_transferred', $currentOwner, $team, null, [
                'previous_owner_id' => $currentOwner->id,
                'new_owner_id' => $newOwner->id,
            ]);
        });

        // Notify both parties
        $currentOwner->notify(new OwnershipTransferredNotification($team, $newOwner));
        $newOwner->notify(new OwnershipReceivedNotification($team, $currentOwner));
    }
```

```php
        ],
        'business' => [
            'max_members' => 25,
            'max_themes' => 100,
            'max_components' => 200,
            'max_templates' => 50,
            'storage_mb' => 2000,
        ],
        'enterprise' => [
            'max_members' => PHP_INT_MAX,
            'max_themes' => PHP_INT_MAX,
            'max_components' => PHP_INT_MAX,
            'max_templates' => PHP_INT_MAX,
            'storage_mb' => PHP_INT_MAX,
        ],
    ];

    public function checkLimit(Team $team, string $resource): array
    {
        $tier = $team->subscription?->tier ?? 'free';
        $limits = self::LIMITS[$tier] ?? self::LIMITS['free'];

        $currentCount = match ($resource) {
            'members' => $team->members()->count(),
            'themes' => $team->themes()->count(),
            'components' => $team->components()->count(),
            'templates' => $team->templates()->count(),
            default => 0,
        };

        $limit = $limits["max_{$resource}"] ?? 0;

        return [
            'tier' => $tier,
            'current' => $currentCount,
            'limit' => $limit,
            'remaining' => max(0, $limit - $currentCount),
            'exceeded' => $currentCount >= $limit,
        ];
    }
}
```

### Team Activity Webhooks

```php
<?php

namespace App\Services\TeamWebhooks;

use App\Models\Team;
use App\Models\TeamActivity;

class TeamWebhookService
{
    private const EVENTS = [
        'team.member_added',
        'team.member_removed',
        'team.member_role_changed',
        'team.theme_created',
        'team.theme_updated',
        'team.component_created',
        'team.billing_updated',
    ];

    public function dispatch(Team $team, string $event, array $payload): void
    {
        if (!in_array($event, self::EVENTS)) {
            return;
        }

        $webhooks = $team->webhooks()
            ->where('active', true)
            ->get();

        foreach ($webhooks as $webhook) {
            if ($this->shouldTrigger($webhook, $event)) {
                TeamWebhookJob::dispatch($webhook, $event, $payload)
                    ->onQueue('webhooks');
            }
        }
    }

    protected function shouldTrigger($webhook, string $event): bool
    {
        $subscribedEvents = json_decode($webhook->events, true) ?? [];
        return in_array('*', $subscribedEvents) || in_array($event, $subscribedEvents);
    }
}
```

### Team Performance Metrics

```php
<?php

namespace App\Services\TeamMetrics;

use App\Models\Team;
use Illuminate\Support\Facades\DB;

class TeamMetricsCollector
{
    public function collect(Team $team): array
    {
        return [
            'member_count' => $team->members()->count(),
            'active_members' => $team->members()
                ->where('last_active_at', '>=', now()->subDays(30))
                ->count(),
            'resource_count' => $this->getResourceCount($team),
            'activity_score' => $this->calculateActivityScore($team),
            'collaboration_score' => $this->calculateCollaborationScore($team),
            'growth_rate' => $this->calculateGrowthRate($team),
        ];
    }

    protected function getResourceCount(Team $team): int
    {
        return $team->themes()->count()
            + $team->components()->count()
            + $team->templates()->count();
    }

    protected function calculateActivityScore(Team $team): float
    {
        $activities = $team->activities()
            ->where('created_at', '>=', now()->subDays(30))
            ->count();

        $members = $team->members()->count();

        return $members > 0 ? round($activities / $members, 2) : 0;
    }

    protected function calculateCollaborationScore(Team $team): float
    {
        $collaborativeEdits = DB::table('resource_editing_sessions')
            ->where('team_id', $team->id)
            ->where('created_at', '>=', now()->subDays(30))
            ->select('resource_type', 'resource_id')
            ->distinct()
            ->count();

        return round($collaborativeEdits * 10, 2);
    }

    protected function calculateGrowthRate(Team $team): float
    {
        $currentMembers = $team->members()->count();
        $membersOneMonthAgo = $team->members()
            ->where('joined_at', '<', now()->subMonth())
            ->count();

        return $membersOneMonthAgo > 0
            ? round((($currentMembers - $membersOneMonthAgo) / $membersOneMonthAgo) * 100, 2)
            : 0;
    }
}
```

### Team Permission Sync Service

```php
<?php

namespace App\Services\TeamPermissions;

use App\Models\Team;
use App\Models\User;

class TeamPermissionSyncService
{
    public function syncUserPermissions(User $user, Team $team): void
    {
        $teamRole = $team->getUserRole($user);

        if (!$teamRole) {
            // User is not a team member, remove any cached team permissions
            cache()->forget("team_permissions:{$team->id}:{$user->id}");
            return;
        }

        $teamPermissions = $team->getPermissionsForRole($teamRole);

        // Store in cache for fast lookup
        cache()->put(
            "team_permissions:{$team->id}:{$user->id}",
            $teamPermissions,
            300
        );
    }

    public function syncAllTeamMembers(Team $team): void
    {
        $members = $team->members()->get();

        foreach ($members as $member) {
            $this->syncUserPermissions($member, $team);
        }
    }

    public function getUserEffectivePermissions(User $user, Team $team): array
    {
        // Get platform permissions
        $platformPermissions = $user->getAllPermissions()->pluck('name')->toArray();

        // Get team permissions from cache or database
        $teamPermissions = cache()->remember(
            "team_permissions:{$team->id}:{$user->id}",
            300,
            function () use ($user, $team) {
                $teamRole = $team->getUserRole($user);
                if (!$teamRole) {
                    return [];
                }
                return $team->getPermissionsForRole($teamRole)->toArray();
            }
        );

        // Return union of both
        return array_unique(array_merge($platformPermissions, $teamPermissions));
    }
}
```

### Team Permission Caching

| Cache Key | TTL | Description |
|-----------|-----|-------------|
| `team_permissions:{team_id}` | 300s | All team role permissions |
| `team_members:{team_id}` | 300s | Team member list |
| `team_user_role:{team_id}:{user_id}` | 300s | Specific user role in team |
| `team_effective:{team_id}:{user_id}` | 300s | Effective permissions for user |

### Cache Invalidation Rules

| Event | Cache to Invalidate |
|-------|---------------------|
| Team role created | `team_permissions:{team_id}` |
| Team role deleted | `team_permissions:{team_id}` |
| Role permissions updated | `team_permissions:{team_id}` |
| User assigned to team | `team_members:{team_id}`, `team_user_role:{team_id}:{user_id}` |
| User removed from team | `team_members:{team_id}`, `team_user_role:{team_id}:{user_id}` |
| User role changed | `team_user_role:{team_id}:{user_id}`, `team_effective:{team_id}:{user_id}` |
| Platform role changed | `team_effective:{team_id}:{user_id}` for all user's teams |

### Team Permission Best Practices

- Keep team roles separate from platform roles
- Use inheritance sparingly to avoid complex permission trees
- Cache aggressively but invalidate carefully
- Log all team permission changes for audit trail
- Test permission resolution with multiple team memberships

### Common Team Permission Scenarios

| Scenario | Resolution | Notes |
|----------|------------|-------|
| User is owner + has platform admin | Union of both | Platform admin overrides |
| User has team editor + platform user | Team editor wins for team resources | |
| User removed from team | Lose all team permissions | Platform permissions remain |
| Team deleted | All team permissions revoked | Member relationships removed |
| Role hierarchy conflict | Highest level wins | Within same permission scope |

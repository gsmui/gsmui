# Additional Index Definitions

## Covering Indexes

Covering indexes include all columns needed by a query, avoiding table lookups:

```sql
-- Component listing query (covers the most common listing query)
CREATE INDEX idx_components_listing_cover ON components
    (status, is_active, is_premium, category_id, created_at, name, slug, version, downloads_count, stars_count);

-- User dashboard query
CREATE INDEX idx_users_dashboard_cover ON users
    (id, name, email, avatar_url, subscription_status, downloads_this_month);

-- Blog post listing
CREATE INDEX idx_blog_posts_listing_cover ON blog_posts
    (is_published, published_at, title, slug, excerpt, featured_image_url, reading_time_minutes);

-- Order history
CREATE INDEX idx_orders_history_cover ON orders
    (user_id, status, created_at, order_number, total_cents, paid_at);
```

## Partial Indexes (MySQL 8.0 Functional Indexes)

```sql
-- Active components only
CREATE INDEX idx_components_active ON components
    ((CASE WHEN status = 'published' AND is_active = 1 THEN id END));

-- Unread notifications
CREATE INDEX idx_notifications_unread ON notifications
    ((CASE WHEN read_at IS NULL THEN id END));

-- Pending reviews
CREATE INDEX idx_components_pending_review ON components
    ((CASE WHEN status = 'pending_review' THEN id END));

-- Active subscriptions
CREATE INDEX idx_subscriptions_active ON subscriptions
    ((CASE WHEN status IN ('active', 'trialing') THEN id END));
```

# Database Sharding Strategy

## Shard Key Selection

| Table | Shard Key | Rationale | Shard Count |
|-------|-----------|-----------|-------------|
| activity_logs | user_id | Evenly distributed, query pattern aligned | 16 |
| analytics_events | user_id or session_id | High volume, append-only | 16 |
| page_views | user_id | High volume, append-only | 8 |
| downloads | user_id | Moderate volume, user-centric | 8 |
| notifications | notifiable_id | User-centric access pattern | 8 |

## Shard Routing

```php
// Shard routing logic
function getShardForUser(int $userId, int $shardCount = 16): int
{
    return $userId % $shardCount;
}

// Example: activity_logs sharding
$shard = getShardForUser($userId, 16);
$table = "activity_logs_shard_{$shard}";
```

## Cross-Shard Queries

| Query Type | Strategy | Performance |
|-----------|----------|-------------|
| User-specific data | Route to user's shard | Fast (single shard) |
| Aggregate across shards | Scatter-gather + merge | Slow (parallel queries) |
| Global search | Search index (Elasticsearch) | Fast (denormalized) |
| Analytics | Read replica + materialized views | Medium (batch processing) |

# Read Replica Configuration

## Replica Pool Management

```php
// config/database.php
'mysql' => [
    'read' => [
        'host' => [
            'replica-1' => 1,  // weight
            'replica-2' => 1,
            'replica-3' => 1,
        ],
    ],
    'write' => [
        'host' => ['primary'],
    ],
    'sticky' => true, // Use primary after write in same request
    'replica_separation_timeout' => 10, // Seconds to wait for replica
],
```

## Replication Monitoring

```sql
-- Check replication lag
SHOW SLAVE STATUS\G

-- Key metrics to monitor:
-- Seconds_Behind_Master: Replication lag in seconds
-- Slave_IO_Running: IO thread running
-- Slave_SQL_Running: SQL thread running
-- Last_Error: Last replication error

-- Alert thresholds:
-- Seconds_Behind_Master > 10: Warning
-- Seconds_Behind_Master > 60: Critical
-- Slave_IO_Running != Yes: Critical
-- Slave_SQL_Running != Yes: Critical
```

## Read After Write Consistency

```php
// Ensure consistency after writes
class DatabaseService
{
    public function writeAndRead(callable $write, callable $read): mixed
    {
        // Execute write on primary
        $result = $write();

        // Force subsequent reads to primary for this request
        DB::purge('mysql');

        // Execute read on primary (sticky session)
        return $read();
    }
}
```

# Database Monitoring Queries

## Slow Query Analysis

```sql
-- Find slow queries from slow query log
SELECT
    query_time,
    lock_time,
    rows_sent,
    rows_examined,
    LEFT(sql_text, 200) AS query_preview
FROM mysql.slow_log
WHERE query_time > 0.05  -- Queries taking more than 50ms
ORDER BY query_time DESC
LIMIT 20;

-- Analyze specific query
EXPLAIN ANALYZE
SELECT c.*, u.name AS author_name
FROM components c
JOIN users u ON u.id = c.author_id
WHERE c.status = 'published'
  AND c.is_active = 1
ORDER BY c.created_at DESC
LIMIT 20;
```

## Index Usage Analysis

```sql
-- Find unused indexes
SELECT
    object_schema,
    object_name,
    index_name
FROM performance_schema.table_io_waits_summary_by_index_usage
WHERE index_name IS NOT NULL
  AND count_star = 0
  AND object_schema = 'gsmui'
ORDER BY object_name;

-- Find missing indexes (queries doing full table scans)
SELECT
    digest_text,
    count_star,
    avg_timer_wait / 1000000000 AS avg_time_ms
FROM performance_schema.events_statements_summary_by_digest
WHERE no_index_used_count > 0
  AND digest_text LIKE 'SELECT%'
ORDER BY count_star DESC
LIMIT 20;
```

## Connection Analysis

```sql
-- Current connections by state
SELECT
    state,
    COUNT(*) AS connection_count

WHERE db = 'gsmui'

ORDER BY connection_count DESC;
```

# Database Backup Verification

## Backup Integrity Checks

```bash
#!/bin/bash
# scripts/verify-backup-integrity.sh

BACKUP_FILE=$1

# Check file exists and is not empty
if [ ! -s "$BACKUP_FILE" ]; then
    echo "ERROR: Backup file is empty or does not exist"
    exit 1
fi

# Check file is valid gzip
if ! gzip -t "$BACKUP_FILE" 2>/dev/null; then
    echo "ERROR: Backup file is corrupted (invalid gzip)"
    exit 1
fi

# Check SQL content
if ! zcat "$BACKUP_FILE" | head -5 | grep -q "MySQL dump"; then
    echo "ERROR: Backup file does not appear to be a MySQL dump"
    exit 1
fi

# Check for complete dump (end marker)
if ! zcat "$BACKUP_FILE" | tail -5 | grep -q "Dump completed"; then
    echo "WARNING: Backup may be incomplete (no dump completed marker)"
fi

# Verify table count
TABLE_COUNT=$(zcat "$BACKUP_FILE" | grep -c "CREATE TABLE")
echo "Tables found in backup: $TABLE_COUNT"

echo "Backup verification complete: $BACKUP_FILE"
```

## Point-in-Time Recovery Test

```bash
#!/bin/bash
# scripts/test-pitr.sh

echo "Starting Point-in-Time Recovery Test..."

# 1. Create test database from backup
echo "Step 1: Restoring backup to test database..."

# 2. Apply binlog events up to specific time
echo "Step 2: Applying binlog events..."
mysqlbinlog --stop-datetime="2026-01-15 10:30:00" \
    --database=gsmui_pitr_test \
    mysql-bin.000001 mysql-bin.000002 | \
    mysql -h test-host -u root -p"$ROOT_PASS" gsmui_pitr_test

# 3. Verify data integrity

    "SELECT COUNT(*) FROM gsmui_pitr_test.components")

# 4. Cleanup
echo "Step 4: Cleaning up test database..."
mysql -h test-host -u root -p"$ROOT_PASS" -e "DROP DATABASE gsmui_pitr_test"

echo "PITR test complete!"
```

# Database Migration Examples

## Adding a Column (Zero-Downtime)

```php
// database/migrations/2026_02_01_000001_add_avatar_url_to_users.php
return new class extends Migration
{
    public function up(): void
    {
        Schema::table('users', function (Blueprint $table) {
            $table->string('avatar_url', 500)->nullable()->after('email');
        });
    }

    public function down(): void
    {
        Schema::table('users', function (Blueprint $table) {
            $table->dropColumn('avatar_url');
        });
    }
};
```

## Adding an Index (Zero-Downtime)

```php
// database/migrations/2026_02_01_000002_add_index_to_components.php
return new class extends Migration
{
    public function up(): void
    {
        Schema::table('components', function (Blueprint $table) {
            $table->index(['status', 'is_active', 'created_at'], 'idx_components_status_active');
        });
    }

    public function down(): void
    {
        Schema::table('components', function (Blueprint $table) {
            $table->dropIndex('idx_components_status_active');
        });
    }
};
```

## Renaming a Column (Zero-Downtime, Multi-Step)

```php
// Step 1: Add new column
Schema::table('users', function (Blueprint $table) {
    $table->string('display_name', 255)->nullable()->after('name');
});

// Step 2: Copy data (async job)
// UpdateUsersDisplayNameJob: UPDATE users SET display_name = name WHERE display_name IS NULL

// Step 3: Deploy code that reads from both columns, writes to both
// (Dual-write phase)

// Step 4: Switch reads to new column only
// (Read-switch phase)

// Step 5: Drop old column (after verification)
Schema::table('users', function (Blueprint $table) {
    $table->dropColumn('name');
});
```

## Factory Convention

```php
// database/factories/ComponentFactory.php
class ComponentFactory extends Factory
{
    protected $model = Component::class;

    public function definition(): array
    {
        return [
            'name' => fake()->unique()->words(3, true),
            'slug' => fake()->unique()->slug(),
            'description' => fake()->sentence(),
            'author_id' => User::factory(),
            'category_id' => Category::factory(),
            'version' => '1.0.0',
            'status' => 'published',
            'is_active' => true,
            'is_approved' => true,
            'is_premium' => false,
            'downloads_count' => fake()->numberBetween(0, 1000),
            'stars_count' => fake()->numberBetween(0, 100),
            'license' => 'MIT',
            'published_at' => fake()->dateTimeBetween('-1 year', 'now'),
        ];
    }

    public function premium(): static
    {
        return $this->state(fn (array $attributes) => [
            'is_premium' => true,
            'price_cents' => fake()->randomElement([900, 1900, 2900, 4900]),
        ]);
    }

    public function draft(): static
    {
        return $this->state(fn (array $attributes) => [
            'status' => 'draft',
            'is_active' => false,
            'is_approved' => false,
            'published_at' => null,
        ]);
    }
}
```

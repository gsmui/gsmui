# 07.40 - User Dashboard

**Project:** GsmUi
**Architecture:** Dashboard Aggregation Services + Read-Through Cache
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `05.25-user-dashboard-architecture.md` (dashboard modules, data architecture, real-time updates). This document is the *implementation contract*: the `DashboardAggregator`, per-section aggregate services, the caching strategy for aggregates, and how moderation/billing outcomes are surfaced.

# Purpose

The User Dashboard aggregates data scattered across many domains — profile, subscriptions, downloads, AI usage, showcase projects, billing — into a handful of fast, coherent view models. The dashboard must render in one or two queries, not dozens, so aggregation happens in dedicated services that read through a short-TTL cache and recompute only on invalidation.

The `DashboardAggregator` composes four section services: `AccountSummaryService`, `UsageSummaryService`, `BillingSummaryService`, and `ActivitySummaryService`. Each returns a typed DTO; the aggregator merges them into a single `DashboardData` view model consumed by Livewire. Cache keys are tenant/user-scoped and invalidated by domain events (subscription changed, download recorded, AI usage recorded).

Goals:

- Dashboard loads in ≤ 2 primary reads via pre-aggregated DTOs.
- Aggregates cached per user with event-driven invalidation (no polling).
- Each section service is independently testable and reusable by the API (`07.21-api-architecture.md`).
- Sensitive billing/usage numbers are scoped to the authenticated user only.

## 1. Aggregator Service

`DashboardAggregator` is the single entry point the Livewire component calls. It pulls cached section DTOs (or computes them), merges, and returns `DashboardData`.

```php
namespace App\Domains\Dashboard\Services;

use App\Domains\Dashboard\DTOs\DashboardData;

final class DashboardAggregator
{
    public function __construct(
        private readonly AccountSummaryService $account,
        private readonly UsageSummaryService $usage,
        private readonly BillingSummaryService $billing,
        private readonly ActivitySummaryService $activity,
        private readonly \Illuminate\Contracts\Cache\Repository $cache,
    ) {}

    public function build(string $userId, string $tenantId): DashboardData
    {
        $key = "dashboard:{$userId}";

        return $this->cache->remember($key, 300, fn () => new DashboardData(
            account: $this->account->summary($userId),
            usage: $this->usage->summary($userId, $tenantId),
            billing: $this->billing->summary($userId),
            activity: $this->activity->recent($userId, limit: 10),
        ));
    }

    public function invalidate(string $userId): void
    {
        $this->cache->forget("dashboard:{$userId}");
    }
}
```

```php
namespace App\Domains\Dashboard\DTOs;

final readonly class DashboardData
{
    public function __construct(
        public \App\Domains\Dashboard\DTOs\AccountSummary $account,
        public \App\Domains\Dashboard\DTOs\UsageSummary $usage,
        public \App\Domains\Dashboard\DTOs\BillingSummary $billing,
        public \App\Domains\Dashboard\DTOs\ActivityItemCollection $activity,
    ) {}
}
```

## 2. Section: Account Summary

`AccountSummaryService` gathers profile completeness, connected accounts, and open security items. It reads the user aggregate and the `AuthService` state, never the request.

```php
namespace App\Domains\Dashboard\Services;

use App\Domains\Dashboard\DTOs\AccountSummary;

final class AccountSummaryService
{
    public function summary(string $userId): AccountSummary
    {
        $user = \App\Models\User::findOrFail($userId);

        return new AccountSummary(
            name: $user->name,
            email: $user->email,
            avatarUrl: $user->avatar_url,
            hasTwoFactor: $user->hasEnabledTwoFactorAuthentication(),
            connectedAccounts: $user->connectedAccounts()->count(),
            profileComplete: $this->completeness($user),
        );
    }

    private function completeness(\App\Models\User $user): int
    {
        $checks = [$user->name, $user->email, $user->avatar_url, $user->timezone];
        $done = count(array_filter($checks));

        return (int) round($done / count($checks) * 100);
    }
}
```

## 3. Section: Usage Summary

`UsageSummaryService` rolls up AI token spend, component downloads, and showcase views from their respective repositories. It reads the tenant's current month counter (maintained by `07.37-ai-engine.md` `UsageRecorder`) and the download log.

```php
namespace App\Domains\Dashboard\Services;

use App\Domains\Dashboard\DTOs\UsageSummary;

final class UsageSummaryService
{
    public function __construct(
        private readonly \App\Domains\Ai\Repositories\AiUsageRepository $aiUsage,
        private readonly \App\Domains\Components\Repositories\ComponentDownloadRepository $downloads,
    ) {}

    public function summary(string $userId, string $tenantId): UsageSummary
    {
        $month = now()->format('Y-m');

        return new UsageSummary(
            aiTokensMonth: $this->aiUsage->tokensForTenant($tenantId, $month),
            aiSpendUsdMonth: $this->aiUsage->spendForTenant($tenantId, $month),
            downloadsMonth: $this->downloads->countForUser($userId, $month),
            aiBudgetUsd: (float) config("tenants.{$tenantId}.ai_monthly_budget", 50.0),
        );
    }
}
```

## 4. Section: Billing Summary

`BillingSummaryService` composes the active subscription, current period, payment method, and recent invoices via the billing domain (Laravel Cashier / Stripe). It returns only non-sensitive fields.

```php
namespace App\Domains\Dashboard\Services;

use App\Domains\Dashboard\DTOs\BillingSummary;

final class BillingSummaryService
{
    public function summary(string $userId): BillingSummary
    {
        $user = \App\Models\User::findOrFail($userId);
        $subscription = $user->subscription('default');

        return new BillingSummary(
            plan: $subscription?->stripe_price ?? 'free',
            status: $subscription?->stripe_status ?? 'none',
            renewsAt: $subscription?->ends_at,
            cardBrand: $user->card_brand,
            cardLastFour: $user->card_last_four,
            invoices: $user->invoicesIncludingPending()->take(5)->map(
                fn ($i) => ['id' => $i->id, 'total' => $i->total(), 'date' => $i->date()->toDateString()]
            )->all(),
        );
    }
}
```

## 5. Section: Activity Summary

`ActivitySummaryService` returns the most recent, deduplicated activity (logins, downloads, publishes, moderation outcomes). Moderation rejections surface here as a neutral "update" entry without exposing internal notes.

```php
namespace App\Domains\Dashboard\Services;

use App\Domains\Dashboard\DTOs\ActivityItem;

final class ActivitySummaryService
{
    /** @return \App\Domains\Dashboard\DTOs\ActivityItem[] */
    public function recent(string $userId, int $limit = 10): array
    {
        return \App\Domains\Activity\Models\Activity::query()
            ->where('user_id', $userId)
            ->latest()
            ->limit($limit)
            ->get()
            ->map(fn ($a) => new ActivityItem(
                type: $a->type,
                message: $a->publicMessage(),
                at: $a->created_at,
            ))
            ->all();
    }
}
```

## 6. Caching & Invalidation

Aggregates live 5 minutes (300s). Invalidation is event-driven: any domain event that changes dashboard data forgets the user's cache key. This avoids polling and keeps the dashboard fresh within seconds of an action.

```php
// In a listener (or via EventServiceProvider mapping)
use App\Domains\Dashboard\Services\DashboardAggregator;

final class InvalidateDashboardOnSubscriptionChange
{
    public function __construct(private readonly DashboardAggregator $agg) {}

    public function handle(\App\Domains\Billing\Events\SubscriptionChanged $e): void
    {
        $this->agg->invalidate($e->userId);
    }
}
```

| Event | Invalidate |
| --- | --- |
| `SubscriptionChanged` | account + billing |
| `ComponentDownloaded` | usage |
| `AiCompletionRecorded` | usage |
| `ContentModerated` (owned) | activity |
| `ProfileUpdated` | account |

All invalidations collapse to `dashboard:{$userId}` for simplicity.

## 7. Request Flow

```text
Livewire Dashboard component
      │
DashboardAggregator::build(userId, tenantId)
      │
cache "dashboard:userId" (300s TTL)
      ├─ hit  ──► DashboardData
      └─ miss ──► (Account + Usage + Billing + Activity services)
                  │
                  └─► cache put ──► DashboardData
      │
Livewire binds DashboardData to view
      │
User action ──► domain event ──► cache forget ──► rebuild on next load
```

Usage:

```php
$data = app(\App\Domains\Dashboard\Services\DashboardAggregator::class)
    ->build(userId: auth()->id(), tenantId: tenant_id());

// $data->usage->aiSpendUsdMonth, $data->billing->plan, ...
```

### 8.3 Widget Registry

```php
namespace App\Domains\Dashboard\Services;

final class DashboardWidgetRegistry
{
    /** @var DashboardWidget[] */
    private array $widgets = [];

    public function register(DashboardWidget $widget): void
    {
        $this->widgets[$widget->name()] = $widget;
    }

    public function get(string $name): ?DashboardWidget
    {
        return $this->widgets[$name] ?? null;
    }

    /** @return DashboardWidget[] */
    public function all(): array
    {
        return $this->widgets;
    }

    /** @return DashboardWidget[] */
    public function enabledForUser(string $userId): array
    {
        $preferences = $this->userPreferences($userId);

        return array_filter($this->widgets, function (DashboardWidget $widget) use ($preferences) {
            return $preferences[$widget->name()] ?? $widget->defaultEnabled();
        });
    }

    private function userPreferences(string $userId): array
    {
        return cache()->remember("dashboard:prefs:{$userId}", 3600, function () use ($userId) {
            return \App\Domains\Dashboard\Models\DashboardPreference::where('user_id', $userId)
                ->pluck('enabled', 'widget_name')
                ->all();
        });
    }
}
```

### 8.4 Widget Preference Management

```php
namespace App\Domains\Dashboard\Services;

final class DashboardPreferenceService
{
    public function __construct(
        private readonly \App\Domains\Dashboard\Repositories\DashboardPreferenceRepository $prefs,
        private readonly DashboardAggregator $aggregator,
    ) {}

    public function updateWidget(string $userId, string $widgetName, bool $enabled): void
    {
        $this->prefs->updateOrCreate(
            ['user_id' => $userId, 'widget_name' => $widgetName],
            ['enabled' => $enabled]
        );

        // Invalidate dashboard cache
        $this->aggregator->invalidate($userId);

        // Clear preference cache
        cache()->forget("dashboard:prefs:{$userId}");
    }

    public function reorder(string $userId, array $widgetOrder): void
    {
        foreach ($widgetOrder as $position => $widgetName) {
            $this->prefs->updateOrCreate(
                ['user_id' => $userId, 'widget_name' => $widgetName],
                ['sort_order' => $position]
            );
        }

        cache()->forget("dashboard:prefs:{$userId}");
    }

    /** @return array<string, bool> */
    public function getAll(string $userId): array
    {
        return $this->prefs->where('user_id', $userId)
            ->pluck('enabled', 'widget_name')
            ->all();
    }
}
```

## 9. Real-Time Updates

The dashboard supports real-time updates via Livewire polling and WebSocket broadcasting.

### 9.1 Livewire Polling

```php
// In the Dashboard Livewire component
class Dashboard extends Component
{
    public $refreshInterval = 30; // seconds

    protected $listeners = [
        'dashboard:refresh' => '$refresh',
        'subscription:changed' => 'refreshBilling',
        'ai:usage:recorded' => 'refreshUsage',
        'content:moderated' => 'refreshActivity',
    ];

    public function pollingInterval(): int
    {
        return $this->refreshInterval;
    }

    public function refreshBilling(): void
    {
        $this->billing = app(BillingSummaryService::class)
            ->summary(auth()->id());
    }

    public function refreshUsage(): void
    {
        $this->usage = app(UsageSummaryService::class)
            ->summary(auth()->id(), tenant_id());
    }

    public function refreshActivity(): void
    {
        $this->activity = app(ActivitySummaryService::class)
            ->recent(auth()->id(), limit: 10);
    }
}
```

```php
namespace App\Domains\Dashboard\Services;

final class NotificationPreferenceService

        private readonly \App\Domains\Dashboard\Repositories\NotificationPreferenceRepository $prefs,

            'product' => $prefs->product,

        public bool $marketing,
```

## 11. Data Export (User-Side)

Users can export their own data (GDPR compliance):

```php
namespace App\Domains\Dashboard\Services;

final class UserDataExportService
{
    public function __construct(
        private readonly \App\Domains\Dashboard\Repositories\UserDataExportRepository $exports,
    ) {}

    public function requestExport(string $userId): \App\Domains\Dashboard\Models\UserDataExport
    {
        $export = $this->exports->create([
            'user_id' => $userId,
            'status' => 'pending',
            'requested_at' => now(),
        ]);

        // Dispatch async job to build the export
        \App\Domains\Dashboard\Jobs\BuildUserDataExport::dispatch($export->id);

        return $export;
    }

    public function buildExport(int $exportId): void
    {
        $export = $this->exports->find($exportId);
        $user = \App\Models\User::find($export->user_id);

        $data = [
            'profile' => $user->only(['id', 'name', 'email', 'created_at', 'updated_at']),
            'showcase_projects' => $user->showcaseProjects->toArray(),
            'blog_posts' => $user->posts->toArray(),
            'ai_conversations' => $user->aiConversations->toArray(),
            'downloads' => $user->componentDownloads->toArray(),
            'activity' => $user->activities->toArray(),
        ];

        $filename = "user-data-export-{$export->user_id}-" . now()->format('Y-m-d') . ".json";
        $path = storage_path("app/exports/{$filename}");

        file_put_contents($path, json_encode($data, JSON_PRETTY_PRINT));

        $export->update([
            'status' => 'completed',
            'file_path' => $path,
            'completed_at' => now(),
        ]);
    }

    public function download(int $exportId): \Symfony\Component\HttpFoundation\StreamedResponse
    {
        $export = $this->exports->find($exportId);

        if ($export->status !== 'completed') {
            throw new \App\Domains\Dashboard\Exceptions\ExportNotReadyException();
        }

        return response()->streamDownload(function () use ($export) {
            echo file_get_contents($export->file_path);
        }, basename($export->file_path));
    }
}
```

## 12. API Access Management

Users manage API tokens for programmatic access:

```php
namespace App\Domains\Dashboard\Services;

final class ApiTokenService
{
    public function __construct(
        private readonly \App\Domains\Dashboard\Repositories\ApiTokenRepository $tokens,
    ) {}

    public function create(string $userId, string $name, array $scopes, ?\DateTime $expiresAt = null): \App\Domains\Dashboard\Models\ApiToken
    {
        return $this->tokens->create([
            'user_id' => $userId,
            'name' => $name,
            'token' => hash('sha256', $plainToken = Str::random(40)),
            'token_last_four' => substr($plainToken, -4),
            'scopes' => $scopes,
            'expires_at' => $expiresAt,
            'created_at' => now(),
        ]);
    }

    public function list(string $userId): array
    {
        return $this->tokens->forUser($userId);
    }

    public function revoke(string $userId, int $tokenId): void
    {
        $token = $this->tokens->findForUser($tokenId, $userId);
        if (! $token) {
            throw new \App\Domains\Dashboard\Exceptions\ApiTokenNotFoundException();
        }

        $token->delete();
    }

    public function validate(string $plainToken): ?\App\Domains\Dashboard\Models\ApiToken
    {
        $hashed = hash('sha256', $plainToken);
        $token = $this->tokens->findByHash($hashed);

        if (! $token) return null;
        if ($token->expires_at && $token->expires_at->isPast()) return null;

        $token->update(['last_used_at' => now()]);
        return $token;
    }
}
```

## 13. Team Management

For team/organization accounts:

```php
namespace App\Domains\Dashboard\Services;

final class TeamManagementService
{
    public function __construct(
        private readonly \App\Domains\Dashboard\Repositories\TeamRepository $teams,
        private readonly \App\Domains\Dashboard\Repositories\TeamMemberRepository $members,
    ) {}

    public function create(string $ownerId, string $name): \App\Domains\Dashboard\Models\Team
    {
        $team = $this->teams->create([
            'name' => $name,
            'owner_id' => $ownerId,
            'created_at' => now(),
        ]);

        $this->members->create([
            'team_id' => $team->id,
            'user_id' => $ownerId,
            'role' => 'owner',
            'joined_at' => now(),
        ]);

        return $team;
    }

    public function invite(string $teamId, string $email, string $role): \App\Domains\Dashboard\Models\TeamInvitation
    {
        return $this->invitations->create([
            'team_id' => $teamId,
            'email' => $email,
            'role' => $role,
            'token' => Str::random(40),
            'expires_at' => now()->addDays(7),
        ]);
    }

    public function acceptInvitation(string $token, string $userId): void
    {
        $invitation = $this->invitations->where('token', $token)
            ->where('expires_at', '>', now())
            ->first();

        if (! $invitation) {
            throw new \App\Domains\Dashboard\Exceptions\InvalidInvitationException();
        }

        $this->members->create([
            'team_id' => $invitation->team_id,
            'user_id' => $userId,
            'role' => $invitation->role,
            'joined_at' => now(),
        ]);

        $invitation->delete();
    }

    public function removeMember(string $teamId, string $userId): void
    {
        $this->members->where('team_id', $teamId)->where('user_id', $userId)->delete();
    }

    public function changeRole(string $teamId, string $userId, string $newRole): void
    {
        $this->members->where('team_id', $teamId)->where('user_id', $userId)
            ->update(['role' => $newRole]);
    }

    public function members(string $teamId): array
    {
        return $this->members->forTeam($teamId);
    }
}
```

## 18. Performance Optimization

### 18.1 Lazy Loading

Widgets are loaded lazily to reduce initial page load:

```php
namespace App\Domains\Dashboard\Livewire;

class Dashboard extends Component
{
    public $loadedWidgets = [];
    public $pendingWidgets = [];

    public function mount(): void
    {
        $allWidgets = app(DashboardWidgetRegistry::class)->enabledForUser(auth()->id());

        // Load critical widgets immediately
        $critical = ['account', 'billing', 'usage'];
        foreach ($allWidgets as $widget) {
            if (in_array($widget->name(), $critical)) {
                $this->loadedWidgets[$widget->name()] = $widget->data(auth()->id(), tenant_id());
            } else {
                $this->pendingWidgets[] = $widget->name();
            }
        }
    }

    public function loadWidget(string $widgetName): void
    {
        $widget = app(DashboardWidgetRegistry::class)->get($widgetName);
        if ($widget) {
            $this->loadedWidgets[$widgetName] = $widget->data(auth()->id(), tenant_id());
            $this->pendingWidgets = array_diff($this->pendingWidgets, [$widgetName]);
        }
    }
}
```

## 22. Dashboard Security

### 22.1 Security Middleware

```php
namespace App\Domains\Dashboard\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class DashboardSecurityMiddleware
{
    public function handle(Request $request, Closure $next)
    {
        // Verify CSRF token for state-changing operations
        if ($request->isMethod('POST') || $request->isMethod('PUT') || $request->isMethod('DELETE')) {
            $this->verifyCsrf($request);
        }

        // Rate limit dashboard loads
        if (! rate_limiter()->attempt('dashboard:' . auth()->id(), 60)) {
            abort(429, 'Too many dashboard requests. Please wait.');
        }

        // Log dashboard access
        $this->logAccess($request);

        return $next($request);
    }

    private function verifyCsrf(Request $request): void
    {
        $token = $request->input('_token') ?? $request->header('X-CSRF-TOKEN');
        if (! hash_equals(csrf_token(), $token ?? '')) {
            abort(419, 'CSRF token mismatch.');
        }
    }

    private function logAccess(Request $request): void
    {
        \App\Domains\Activity\Models\Activity::create([
            'user_id' => auth()->id(),
            'type' => 'dashboard.access',
            'properties' => json_encode([
                'ip' => $request->ip(),
                'path' => $request->path(),
            ]),
            'created_at' => now(),
        ]);
    }
}
```

### 22.2 Data Isolation

| Rule | Enforcement |
| --- | --- |
| User can only see own data | Service queries filter by `user_id` |
| No cross-tenant data leakage | Tenant ID injected from auth context |
| Billing data requires auth | Billing service checks `auth()->id()` |
| API tokens scoped to user | Token queries include `user_id` |
| Admin data requires role | Middleware checks `hasRole('admin')` |

### 22.3 Session Security

```php
namespace App\Domains\Dashboard\Services;

final class DashboardSessionSecurity
{
    public function __construct(
        private readonly \Illuminate\Contracts\Session\Session $session,
    ) {}

    public function validateSession(): bool
    {
        $lastActivity = $this->session->get('dashboard_last_activity');
        $timeout = config('dashboard.session_timeout_minutes', 30);

        if ($lastActivity && now()->diffInMinutes($lastActivity) > $timeout) {
            $this->session->invalidate();
            $this->session->regenerateToken();
            return false;
        }

        $this->session->put('dashboard_last_activity', now());
        return true;
    }

    public function detectConcurrentSessions(): bool
    {
        $currentFingerprint = $this->session->get('fingerprint');
        $storedFingerprint = cache()->get("session:fingerprint:" . auth()->id());

        if ($storedFingerprint && $currentFingerprint !== $storedFingerprint) {
            return true; // Concurrent session detected
        }

        cache()->put("session:fingerprint:" . auth()->id(), $currentFingerprint, 3600);
        return false;
    }
}
```

```php
namespace App\Domains\Dashboard\Services;

final class DashboardPreferencesService
{
    public function __construct(
        private readonly \App\Domains\Dashboard\Repositories\DashboardPreferenceRepository $prefs,
        private readonly DashboardWidgetRegistry $widgets,
    ) {}

    public function export(string $userId): array
    {
        $userPrefs = $this->prefs->where('user_id', $userId)->get();

        return [
            'version' => '1.0',
            'exported_at' => now()->toIso8601String(),
            'widgets' => $userPrefs->pluck('enabled', 'widget_name')->all(),
            'layout' => $userPrefs->pluck('layout_config', 'widget_name')->all(),
            'theme' => $userPrefs->where('key', 'theme')->value ?? 'light',
            'refresh_interval' => $userPrefs->where('key', 'refresh_interval')->value ?? 30,
        ];
    }

    public function import(string $userId, array $data): void
    {
        if (($data['version'] ?? '') !== '1.0') {
            throw new \App\Domains\Dashboard\Exceptions\IncompatiblePreferencesVersionException();
        }

        foreach ($data['widgets'] ?? [] as $widgetName => $enabled) {
            $this->prefs->updateOrCreate(
                ['user_id' => $userId, 'widget_name' => $widgetName],
                ['enabled' => $enabled]
            );
        }

        foreach ($data['layout'] ?? [] as $widgetName => $config) {
            $this->prefs->updateOrCreate(
                ['user_id' => $userId, 'widget_name' => $widgetName],
                ['layout_config' => $config]
            );
        }

        if (isset($data['theme'])) {
            app(DashboardThemeService::class)->set($userId, $data['theme']);
        }

        if (isset($data['refresh_interval'])) {
            $this->prefs->updateOrCreate(
                ['user_id' => $userId, 'key' => 'refresh_interval'],
                ['value' => $data['refresh_interval']]
            );
        }
    }

    public function reset(string $userId): void
    {
        $this->prefs->where('user_id', $userId)->delete();

        // Apply defaults
        foreach ($this->widgets->all() as $widget) {
            if ($widget->defaultEnabled()) {
                $this->prefs->create([
                    'user_id' => $userId,
                    'widget_name' => $widget->name(),
                    'enabled' => true,
                ]);
            }
        }
    }
}
```

```php
namespace App\Domains\Dashboard\Services;

final class DashboardPerformanceService
{
    public function __construct(
        private readonly \Illuminate\Contracts\Cache\Repository $cache,
    ) {}

    public function recordLoad(string $userId, float $loadTimeMs, array $widgetTimes = []): void
    {
        $key = "dashboard:perf:" . now()->format('Y-m-d');
        $data = $this->cache->get($key, [
            'loads' => 0,
            'total_time' => 0,
            'widget_times' => [],
        ]);

        $data['loads']++;
        $data['total_time'] += $loadTimeMs;

        foreach ($widgetTimes as $widget => $time) {
            $data['widget_times'][$widget] = ($data['widget_times'][$widget] ?? 0) + $time;
        }

        $this->cache->put($key, $data, 86400);
    }

    public function todayStats(): DashboardPerformanceStats
    {
        $key = "dashboard:perf:" . now()->format('Y-m-d');
        $data = $this->cache->get($key, ['loads' => 0, 'total_time' => 0, 'widget_times' => []]);

        return new DashboardPerformanceStats(
            totalLoads: $data['loads'],
            avgLoadTimeMs: $data['loads'] > 0 ? round($data['total_time'] / $data['loads'], 2) : 0,
            widgetAvgTimes: array_map(fn ($total) => round($total / max($data['loads'], 1), 2), $data['widget_times']),
        );
    }

    public function weeklyTrend(): array
    {
        $trend = [];
        for ($i = 6; $i >= 0; $i--) {
            $date = now()->subDays($i)->format('Y-m-d');
            $data = cache()->get("dashboard:perf:{$date}", ['loads' => 0, 'total_time' => 0]);

            $trend[] = [
                'date' => $date,
                'loads' => $data['loads'],
                'avg_time_ms' => $data['loads'] > 0 ? round($data['total_time'] / $data['loads'], 2) : 0,
            ];
        }

        return $trend;
    }
}
```

### 33.1 Performance Metrics Collector

```php
namespace App\Domains\Dashboard\Services;

final class DashboardPerformanceCollector
{
    public function __construct(
        private readonly \App\Models\User $user,
    ) {}

    public function recordPageLoad(string $route, float $serverMs, float $clientMs): void
    {
        \App\Domains\Dashboard\Models\DashboardMetric::create([
            'user_id' => $this->user->id,
            'metric_type' => 'page_load',
            'route' => $route,
            'server_ms' => $serverMs,
            'client_ms' => $clientMs,
            'created_at' => now(),
        ]);
    }

    public function recordWidgetLoad(string $widget, float $loadTimeMs): void
    {
        \App\Domains\Dashboard\Models\DashboardMetric::create([
            'user_id' => $this->user->id,
            'metric_type' => 'widget_load',
            'widget' => $widget,
            'load_time_ms' => $loadTimeMs,
            'created_at' => now(),
        ]);
    }

    public function recordCacheHit(string $key, bool $hit): void
    {
        \App\Domains\Dashboard\Models\DashboardMetric::create([
            'user_id' => $this->user->id,
            'metric_type' => 'cache',
            'cache_key' => $key,
            'hit' => $hit,
            'created_at' => now(),
        ]);
    }

    public function summary(int $days = 7): array
    {
        $from = now()->subDays($days);

        $metrics = \App\Domains\Dashboard\Models\DashboardMetric::where('user_id', $this->user->id)
            ->where('created_at', '>=', $from)
            ->get();

        return [
            'avg_page_load_ms' => $metrics->where('metric_type', 'page_load')->avg('server_ms'),
            'avg_widget_load_ms' => $metrics->where('metric_type', 'widget_load')->avg('load_time_ms'),
            'cache_hit_rate' => $this->calculateCacheHitRate($metrics),
            'total_requests' => $metrics->count(),
            'slowest_routes' => $this->slowestRoutes($metrics),
        ];
    }

    private function calculateCacheHitRate(\Illuminate\Support\Collection $metrics): float
    {
        $cacheMetrics = $metrics->where('metric_type', 'cache');
        if ($cacheMetrics->isEmpty()) return 0;

        $hits = $cacheMetrics->where('hit', true)->count();
        return round($hits / $cacheMetrics->count() * 100, 2);
    }

    private function slowestRoutes(\Illuminate\Support\Collection $metrics): array
    {
        return $metrics->where('metric_type', 'page_load')
            ->groupBy('route')
            ->map(fn ($group) => $group->avg('server_ms'))
            ->sortDesc()
            ->take(5)
            ->toArray();
    }
}
```

```php
namespace App\Domains\Dashboard\Services;

final class DashboardGdprService
{
    public function __construct(
        private readonly \App\Domains\Dashboard\Repositories\ActivityRepository $activities,
    ) {}

    public function exportUserData(string $userId): array
    {
        $user = \App\Models\User::with([
            'snippets',
            'showcaseProjects',
            'blogPosts',
            'comments',
        ])->find($userId);

        return [
            'user' => [
                'id' => $user->id,
                'name' => $user->name,
                'email' => $user->email,
                'created_at' => $user->created_at,
                'settings' => $user->settings,
            ],
            'snippets' => $user->snippets->toArray(),
            'showcases' => $user->showcaseProjects->toArray(),
            'blog_posts' => $user->blogPosts->toArray(),
            'activities' => $this->activities->forUser($userId, 1000),
            'exported_at' => now()->toIso8601String(),
        ];
    }

    public function deleteUserData(string $userId): bool
    {
        $user = \App\Models\User::find($userId);
        if (! $user) return false;

        // Anonymize rather than hard delete to preserve data integrity
        $user->update([
            'name' => 'Deleted User',
            'email' => "deleted_{$userId}@deleted.invalid",
            'email_verified_at' => null,
            'settings' => [],
            'deleted_at' => now(),
        ]);

        $user->snippets()->update(['user_id' => null, 'status' => 'archived']);
        $user->showcaseProjects()->update(['user_id' => null, 'status' => 'archived']);

        return true;
    }

    public function anonymizeActivities(string $userId): int
    {
        return $this->activities->anonymizeForUser($userId);
    }

    public function getDataRetentionDays(): int
    {
        return (int) config('gsmui.dashboard.gdpr.retention_days', 365);
    }

    public function purgeOldData(): int
    {
        $cutoff = now()->subDays($this->getDataRetentionDays());

        return \App\Domains\Dashboard\Models\DashboardMetric::where('created_at', '<', $cutoff)->delete();
    }
}
```

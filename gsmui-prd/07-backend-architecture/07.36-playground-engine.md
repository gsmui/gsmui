# 07.36 - Playground Engine Service Interfaces

**Project:** GsmUi
**Architecture:** Sandboxed Execution + Snippet Storage
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.19-playground.md` for the playground overview, `07.33-component-engine.md` for the component renderer it drives, and `06.01-design-principles.md` §3 (soft-deletable `snippets`, `playground_projects`, `playground_snapshots`). This document specifies the **implementation contract** for the playground service layer: the `SnippetExecutor` (sandbox execution model), the `SnippetStorage` service, and the `ProjectExporter` (export to project). 

The playground lets developers compose GsmUi components live and preview the result. It must never execute untrusted code in the production process: there is **no `eval` of user snippets in production**. Instead, a snippet is a structured, validated description of components + props (the same shape the component renderer consumes), and "execution" means passing it through the trusted `ComponentRenderer`. Arbitrary PHP/JS authored by a user is rejected at the validation boundary; only the declared component graph is rendered, server-side, inside a sandboxed render context.

Snippets and projects are persisted (soft-deletable per §3) so users can save, fork, and share work. Export to a real Laravel project reuses the template/asset pipeline approach (`07.34-template-engine.md`) to emit drop-in files.

Goals:

- Define a `SnippetExecutor` that renders validated snippets without eval.
- Specify the server-side validation/sandbox boundary.
- Define `SnippetStorage` for save/fork/share.
- Define `ProjectExporter` for exporting a playground project to a project skeleton.

# 2. Snippet Model & Validation

A snippet is a declarative graph of `SnippetNode`s — each node references a **registered** component by name and a validated props array. The schema is the same `PropSchema` the component registry exposes (`07.33-component-engine.md`), so a node is only valid if its component exists and its props pass schema validation. Free-text code is not part of the model.

```php
namespace App\Domains\Playground\Data;

final readonly class SnippetNode
{
    public function __construct(
        public string $id,         // client-side stable id
        public string $component,  // must exist in ComponentRegistry
        public array $props = [],  // validated against component schema
        /** @var string[] child node ids (slot composition) */
        public array $children = [],
    ) {}
}

final readonly class Snippet
{
    /** @var SnippetNode[] */
    public array $nodes;
    public string $rootId;
}
```

# 3. The `SnippetExecutor` Contract (Sandbox)

`SnippetExecutor` is the sandbox. It validates the snippet against the registry, then renders each node through the trusted `ComponentRenderer` — no PHP/user-code evaluation. A production environment additionally rejects any node referencing a component not on the playground allow-list.

```php
namespace App\Domains\Playground\Contracts;

use App\Domains\Playground\Data\Snippet;
use App\Domains\Playground\Data\ExecutionResult;

interface SnippetExecutor
{
    /**
     * Validate + render a snippet to HTML. Never evaluates user code.
     * Throws ValidationException if a node references an unknown or
     * disallowed component, or props fail the component schema.
     */
    public function execute(Snippet $snippet): ExecutionResult;

    /** Validate only (used by the live editor before render). */
    public function validate(Snippet $snippet): ValidationReport;
}
```

```php
final class ExecutorManager implements SnippetExecutor
{
    public function execute(Snippet $snippet): ExecutionResult
    {
        $report = $this->validate($snippet);
        if ($report->hasErrors()) {
            throw new SnippetValidationException($report);
        }

        $html = '';
        foreach ($this->orderedNodes($snippet) as $node) {
            // Trusted render path — no eval, no user PHP/JS executed.
            $html .= $this->renderer
                ->render($node->component, $node->props)
                ->html;
        }

        return new ExecutionResult($html, $report);
    }

    public function validate(Snippet $snippet): ValidationReport
    {
        $errors = [];
        foreach ($snippet->nodes as $node) {
            if (! $this->registry->exists($node->component)) {
                $errors[$node->id] = 'unknown_component';
                continue;
            }
            if (! $this->allowList->allows($node->component)) {
                $errors[$node->id] = 'disallowed_component';
                continue;
            }
            $schema = $this->registry->schemaFor($node->component);
            $result = $schema?->validate($node->props);
            if ($result && $result->errors) {
                $errors[$node->id] = $result->errors;
            }
        }
        return new ValidationReport($errors);
    }
}
```

# 4. Why No `eval` in Production

| Concern | Rule |
| ------- | ---- |
| User-authored PHP | Never accepted as snippet input; rejected at the API boundary |
| User-authored JS | Sandboxed in the browser preview iframe; never runs server-side |
| Component graph | Rendered only via trusted `ComponentRenderer` |
| Unknown components | Rejected by `validate()` before any render |
| Allow-list | Production limits nodes to playground-safe components |

The executor is identical in dev and prod; the only difference is the allow-list strictness, controlled by config — the safety boundary is structural, not environmental.

# 9. Component Allow-List Management

The playground must restrict which components can be rendered. In production, a curated allow-list ensures only safe, tested components are available. In development, the allow-list is permissive for rapid iteration.

```php
namespace App\Domains\Playground\Services;

final class PlaygroundAllowList
{
    private array $cache = [];
    private ?array $list = null;

    public function __construct(
        private readonly \Illuminate\Contracts\Config\Repository $config,
    ) {}

    public function allows(string $component): bool
    {
        if (isset($this->cache[$component])) {
            return $this->cache[$component];
        }

        $result = in_array($component, $this->getList(), true);
        $this->cache[$component] = $result;

        return $result;
    }

    /** @return string[] */
    private function getList(): array
    {
        if ($this->list !== null) {
            return $this->list;
        }

        $env = $this->config->get('app.env', 'production');

        $this->list = $env === 'production'
            ? $this->config->get('playground.allow_list', [])
            : $this->loadAllRegistered();

        return $this->list;
    }

    private function loadAllRegistered(): array
    {
        return app(\App\Domains\Components\Contracts\ComponentRegistry::class)
            ->allNames();
    }
}
```

Configuration in `config/playground.php`:

```php
return [
    'allow_list' => [

        'radio', 'toggle', 'badge', 'alert', 'card',
```

# 10. Snippet Validation Rules (Detailed)

Validation is a multi-pass process: structural integrity, component existence, prop schema compliance, and depth/circularity checks. Every rule has a dedicated validator class that produces a `ValidationError` with a machine-readable code.

```php
namespace App\Domains\Playground\Validation;

interface SnippetValidator
{
    /** @return ValidationError[] */
    public function validate(Snippet $snippet): array;
}
```

### 10.1 Structural Validators

| Validator | Rule | Error Code |
| --- | --- | --- |
| `NodeCountValidator` | Total nodes ≤ `max_nodes_per_snippet` | `too_many_nodes` |
| `DepthValidator` | Tree depth ≤ `max_depth` | `excessive_depth` |
| `CircularReferenceValidator` | No node appears in its own descendant chain | `circular_reference` |
| `RootExistsValidator` | Exactly one root node, and it exists in the node list | `missing_root` |
| `OrphanValidator` | Every non-root node is reachable from root | `orphaned_node` |
| `IdUniquenessValidator` | All node IDs are unique within the snippet | `duplicate_id` |

```php
namespace App\Domains\Playground\Validation;

final class NodeCountValidator implements SnippetValidator
{
    public function __construct(
        private readonly int $maxNodes,
    ) {}

    public function validate(Snippet $snippet): array
    {
        if (count($snippet->nodes) > $this->maxNodes) {
            return [new ValidationError(
                code: 'too_many_nodes',
                message: "Snippet has " . count($snippet->nodes) . " nodes; maximum is {$this->maxNodes}.",
            )];
        }
        return [];
    }
}
```

### 10.2 Component Validators

| Validator | Rule | Error Code |
| --- | --- | --- |
| `ComponentExistsValidator` | Node's component name exists in the registry | `unknown_component` |
| `AllowListValidator` | Component is on the playground allow-list | `disallowed_component` |
| `SlotCompatibilityValidator` | Child nodes are compatible with parent's declared slots | `slot_mismatch` |

### 10.3 Prop Validators

| Validator | Rule | Error Code |
| --- | --- | --- |
| `PropSchemaValidator` | Each prop matches its schema type (string, int, bool, array, enum) | `invalid_prop_type` |
| `RequiredPropsValidator` | All required props are present | `missing_required_prop` |
| `PropSizeValidator` | Serialized props ≤ `max_props_bytes` | `props_too_large` |
| `EnumValidator` | Enum props have a valid value from the allowed set | `invalid_enum_value` |
| `UrlValidator` | URL-type props are valid URLs | `invalid_url` |
| `ColorValidator` | Color props are valid CSS colors | `invalid_color` |

```php
namespace App\Domains\Playground\Validation;

final class PropSchemaValidator implements SnippetValidator
{
    public function __construct(
        private readonly \App\Domains\Components\Contracts\ComponentRegistry $registry,
    ) {}

    public function validate(Snippet $snippet): array
    {
        $errors = [];
        foreach ($snippet->nodes as $node) {
            $schema = $this->registry->schemaFor($node->component);
            if ($schema === null) {
                continue; // caught by ComponentExistsValidator
            }
            $result = $schema->validate($node->props);
            if ($result->errors !== []) {
                $errors[] = new ValidationError(
                    code: 'invalid_prop_type',
                    message: "Node {$node->id} has invalid props: " . implode(', ', array_keys($result->errors)),
                    nodeId: $node->id,
                );
            }
        }
        return $errors;
    }
}
```

### 10.4 Validation Pipeline

All validators are composed into a pipeline that runs in order and collects all errors:

```php
namespace App\Domains\Playground\Services;

final class SnippetValidationPipeline
{
    /** @param SnippetValidator[] $validators */
    public function __construct(
        private readonly iterable $validators,
    ) {}

    public function validate(Snippet $snippet): ValidationReport
    {
        $errors = [];

        foreach ($this->validators as $validator) {
            $errors = array_merge($errors, $validator->validate($snippet));
        }

        return new ValidationReport($errors);
    }
}
```

The pipeline is registered in the service provider:

```php
$this->app->bind(SnippetValidationPipeline::class, function ($app) {
    return new SnippetValidationPipeline([
        new NodeCountValidator(config('playground.max_nodes_per_snippet', 50)),
        new DepthValidator(config('playground.max_depth', 10)),
        new CircularReferenceValidator(),
        new RootExistsValidator(),
        new OrphanValidator(),
        new IdUniquenessValidator(),
        new ComponentExistsValidator($app->make(ComponentRegistry::class)),
        new AllowListValidator($app->make(PlaygroundAllowList::class)),
        new SlotCompatibilityValidator($app->make(ComponentRegistry::class)),
        new PropSchemaValidator($app->make(ComponentRegistry::class)),
        new RequiredPropsValidator($app->make(ComponentRegistry::class)),
        new PropSizeValidator(config('playground.max_props_bytes', 4096)),
    ]);
});
```

# 11. Sandbox Security Model

The playground never executes user-authored code. The security model has three layers: input sanitization, render isolation, and output escaping.

### 11.1 Input Sanitization

Every snippet passes through a sanitization step before validation:

```php
namespace App\Domains\Playground\Services;

final class SnippetSanitizer
{
    public function sanitize(Snippet $snippet): Snippet
    {
        $sanitizedNodes = array_map(function (SnippetNode $node): SnippetNode {
            return new SnippetNode(
                id: $this->sanitizeId($node->id),
                component: $this->sanitizeComponentName($node->component),
                props: $this->sanitizeProps($node->props),
                children: array_map([$this, 'sanitizeId'], $node->children),
            );
        }, $snippet->nodes);

        return new Snippet(
            nodes: $sanitizedNodes,
            rootId: $this->sanitizeId($snippet->rootId),
        );
    }

    private function sanitizeId(string $id): string
    {
        return preg_replace('/[^a-zA-Z0-9_-]/', '', $id);
    }

    private function sanitizeComponentName(string $name): string
    {
        return preg_replace('/[^a-zA-Z0-9\-_]/', '', $name);
    }

    private function sanitizeProps(array $props): array
    {
        return array_map(function ($value) {
            if (is_string($value)) {
                return strip_tags($value);
            }
            if (is_array($value)) {
                return $this->sanitizeProps($value);
            }
            return $value;
        }, $props);
    }
}
```

### 11.2 Render Isolation

The component renderer operates in a sandboxed context:

- No access to `$_SERVER`, `$_GET`, `$_POST`, `$_COOKIE` superglobals
- No access to `file_*`, `exec`, `shell_*`, `proc_*`, `eval`, `assert` functions
- No access to database connections or queue workers
- No access to HTTP clients or network sockets
- Time-boxed execution (configurable, default 500ms)
- Memory-capped (configurable, default 64MB per render)

```php
namespace App\Domains\Playground\Services;

final class RenderSandbox
{
    public function render(string $component, array $props, int $timeoutMs = 500): string
    {
        $start = microtime(true);

        $html = $this->renderer->render($component, $props)->html;

        $elapsed = (microtime(true) - $start) * 1000;
        if ($elapsed > $timeoutMs) {
            throw new \App\Domains\Playground\Exceptions\RenderTimeoutException(
                "Render took {$elapsed}ms, exceeding {$timeoutMs}ms limit."
            );
        }

        return $html;
    }
}
```

### 11.3 Output Escaping

Rendered HTML is escaped for safe insertion into the preview iframe:

```php
namespace App\Domains\Playground\Services;

final class OutputEscaper
{
    /** Strip script tags and event handlers from rendered HTML */
    public function escape(string $html): string
    {
        $html = preg_replace('/<script\b[^<]*(?:(?!<\/script>)<[^<]*)*<\/script>/is', '', $html);
        $html = preg_replace('/\bon\w+\s*=\s*["\'][^"\']*["\']/i', '', $html);
        $html = preg_replace('/javascript\s*:/i', '', $html);
        $html = preg_replace('/data\s*:\s*text\/html/i', '', $html);

        return $html;
    }
}
```

# 12. Preview Iframe Isolation

The playground renders snippets inside a sandboxed `<iframe>` with strict security attributes:

```html
<iframe
    sandbox="allow-same-origin"
    srcdoc="<!DOCTYPE html>
        <html>
        <head>
            <meta charset='utf-8'>
            <meta http-equiv='Content-Security-Policy'
                content=\"default-src 'none'; style-src 'self' 'unsafe-inline'; img-src 'self' data:;\">
            <link rel='stylesheet' href='/dist/gsmui.css'>
        </head>
        <body>
            <div id='preview'>{{ RENDERED_HTML }}</div>
            <script src='/dist/gsmui.js'></script>
        </body>
        </html>"
    style="width: 100%; border: none; min-height: 200px;"
></iframe>
```

| Attribute | Purpose |
| --- | --- |
| `sandbox="allow-same-origin"` | Allows CSS/JS to run but prevents top-level navigation, form submission, and script execution from untrusted sources |
| `Content-Security-Policy` | Blocks external scripts, frames, and network requests |
| `style-src 'self' 'unsafe-inline'` | Only allows GsmUi's own styles and inline styles for component rendering |
| `img-src 'self' data:` | Only allows self-hosted images and inline data URIs (for SVG icons) |

The iframe communicates with the parent Livewire component via `postMessage`:

```javascript
// In the playground Livewire component's JS
window.addEventListener('message', (event) => {
    if (event.origin !== window.location.origin) return;

    const { type, payload } = event.data;

    if (type === 'gsmui:playground:resize') {
        // Resize iframe to match content height
        const iframe = document.getElementById('playground-preview');
        iframe.style.height = payload.height + 'px';
    }

    if (type === 'gsmui:playground:error') {
        Livewire.find(componentId).call('handlePreviewError', payload);
    }
});
```

# 13. Snippet Versioning and Migration

Snippets are versioned to support schema evolution as components change. Each snippet carries a `schema_version` that the executor checks before rendering.

```php
namespace App\Domains\Playground\Data;

final readonly class Snippet
{
    public function __construct(
        public string $rootId,
        /** @var SnippetNode[] */
        public array $nodes,
        public int $schemaVersion = 1,
        public ?string $name = null,
        public ?string $description = null,
    ) {}
}
```

Migration from version N to N+1:

```php
namespace App\Domains\Playground\Migrations;

interface SnippetMigration
{
    public function fromVersion(): int;
    public function toVersion(): int;
    public function migrate(Snippet $snippet): Snippet;
}
```

```php
namespace App\Domains\Playground\Migrations;

final class V1ToV2Migration implements SnippetMigration
{
    public function fromVersion(): int { return 1; }
    public function toVersion(): int { return 2; }

    public function migrate(Snippet $snippet): Snippet
    {
        $nodes = array_map(function (SnippetNode $node): SnippetNode {
            // Example: rename "button_label" prop to "label"
            $props = $node->props;
            if (isset($props['button_label'])) {
                $props['label'] = $props['button_label'];
                unset($props['button_label']);
            }
            return new SnippetNode(
                id: $node->id,
                component: $node->component,
                props: $props,
                children: $node->children,
            );
        }, $snippet->nodes);

        return new Snippet(
            rootId: $snippet->rootId,
            nodes: $nodes,
            schemaVersion: 2,
        );
    }
}
```

```php
namespace App\Domains\Playground\Services;

final class SnippetVersionManager
{
    /** @param SnippetMigration[] $migrations */
    public function __construct(
        private readonly iterable $migrations,
    ) {}

    public function upgrade(Snippet $snippet): Snippet
    {
        $current = $snippet->schemaVersion;
        $latest = $this->latestVersion();

        if ($current >= $latest) {
            return $snippet;
        }

        $sorted = collect($this->migrations)
            ->sortBy('toVersion')
            ->values();

        foreach ($sorted as $migration) {
            if ($migration->fromVersion() >= $current && $migration->toVersion() <= $latest) {
                $snippet = $migration->migrate($snippet);
                $current = $migration->toVersion();
            }
        }

        return $snippet;
    }

    private function latestVersion(): int
    {
        return collect($this->migrations)->max('toVersion');
    }
}
```

# 14. Performance Optimization

### 14.1 Render Caching

Frequently rendered component combinations are cached to avoid redundant computation:

```php
namespace App\Domains\Playground\Services;

final class RenderCache
{
    public function __construct(
        private readonly \Illuminate\Contracts\Cache\Repository $cache,
    ) {}

    public function remember(string $component, array $props, callable $render): string
    {
        $key = 'playground:render:' . md5($component . json_encode($props));

        return $this->cache->remember($key, 300, $render);
    }

    public function invalidateAll(): void
    {
        // Use tag-based clearing if using Redis/Memcached
        $this->cache->tags(['playground:render'])->flush();
    }
}
```

### 14.2 Lazy Component Loading

Large component trees are split into progressive chunks:

```php
namespace App\Domains\Playground\Services;

final class LazyRenderer
{
    public function renderIncremental(Snippet $snippet, int $batchSize = 10): \Generator
    {
        $nodes = $this->orderedNodes($snippet);

        foreach (array_chunk($nodes, $batchSize) as $batch) {
            $html = '';
            foreach ($batch as $node) {
                $html .= $this->renderer->render($node->component, $node->props)->html;
            }
            yield $html;
        }
    }
}
```

# 15. Error Handling and Recovery

The executor has a layered error handling strategy:

```php
namespace App\Domains\Playground\Exceptions;

class SnippetValidationException extends \RuntimeException
{
    public function __construct(
        public readonly ValidationReport $report,
    ) {
        parent::__construct('Snippet validation failed: ' . $report->summary());
    }
}

class RenderTimeoutException extends \RuntimeException {}
class SnippetNotFoundException extends \RuntimeException {}
class SnippetForkException extends \RuntimeException {}
class ExportFailedException extends \RuntimeException {}
```

The Livewire component catches and surfaces errors:

```php
public function execute()
{
    try {
        $result = app(SnippetExecutor::class)->execute(
            Snippet::fromEditorState($this->nodes)
        );
        $this->previewHtml = $result->html;
        $this->errors = [];
    } catch (SnippetValidationException $e) {
        $this->errors = $e->report->errors;
        $this->previewHtml = '';
    } catch (RenderTimeoutException $e) {
        $this->errors = [['code' => 'timeout', 'message' => $e->getMessage()]];
        $this->previewHtml = '';
    } catch (\Throwable $e) {
        report($e);
        $this->errors = [['code' => 'internal', 'message' => 'An unexpected error occurred.']];
        $this->previewHtml = '';
    }
}
```

Error response structure:

```php
namespace App\Domains\Playground\Data;

final readonly class ValidationError
```

```php
namespace App\Domains\Playground\Http\Controllers;

use App\Http\Controllers\Controller;
use Illuminate\Http\Request;
use Illuminate\Http\JsonResponse;

class PlaygroundApiController extends Controller
{
    public function validate(Request $request): JsonResponse
    {
        $snippet = Snippet::fromArray($request->validated());
        $report = app(\App\Domains\Playground\Contracts\SnippetExecutor::class)
            ->validate($snippet);

        return response()->json([
            'valid' => !$report->hasErrors(),
            'errors' => $report->errors,
        ]);

    {
        $snippet = Snippet::fromArray($request->validated());

        try {
            $result = app(\App\Domains\Playground\Contracts\SnippetExecutor::class)
                ->execute($snippet);

            return response()->json([
                'html' => $result->html,
                'errors' => $result->report->errors,
            ]);
        } catch (\Throwable $e) {
            return response()->json([
                'html' => '',
                'errors' => [['code' => 'execution_failed', 'message' => $e->getMessage()]],
            ], 422);
        }
    }

    public function export(Request $request): JsonResponse
    {
        $data = $request->validated();
        $snippet = Snippet::fromArray($data['snippet']);

        $project = app(\App\Domains\Playground\Contracts\ProjectExporter::class)
            ->export($snippet, [
                'name' => $data['name'],
                'author' => auth()->user()->name,
            ]);

        return response()->json([
            'files' => $project->files,
            'manifest' => $project->manifest,
        ]);
    }
}
```

# 17. Rate Limiting and Quotas

Playground usage is rate-limited per user and per tenant:

```php
namespace App\Domains\Playground\Services;

final class PlaygroundRateLimiter
{
    public function __construct(
        private readonly \Illuminate\Cache\RateLimiter $limiter,
    ) {}

    public function attempt(string $userId, string $action, int $maxAttempts, int $decayMinutes = 1): bool
    {
        $key = "playground:{$action}:{$userId}";
        return $this->limiter->attempt($key, $maxAttempts, function () {}, $decayMinutes);
    }

    public function remaining(string $userId, string $action, int $maxAttempts, int $decayMinutes = 1): int
    {
        $key = "playground:{$action}:{$userId}";
        return $this->limiter->remaining($key, $maxAttempts, $decayMinutes);
    }

    public function reset(string $userId, string $action): void
    {
        $this->limiter->clear("playground:{$action}:{$userId}");
    }
}
```

```php
    public function merge(SnippetNode $local, SnippetNode $remote): SnippetNode

        // Last-writer-wins at the prop level
```

### 20.1 Export Formats

| Format | Description | Use Case |
| --- | --- | --- |
| `json` | Raw snippet JSON | Backup, sharing, API |
| `blade` | Laravel Blade template | Drop-in into a Laravel project |
| `html` | Static HTML + CSS | Deployment to any hosting |
| `zip` | Archive of all project files | Full project download |

```php
namespace App\Domains\Playground\Services;

final class SnippetExporter
{
    public function toArray(Snippet $snippet): array
    {
        return [
            'schema_version' => $snippet->schemaVersion,
            'name' => $snippet->name,
            'description' => $snippet->description,
            'root_id' => $snippet->rootId,
            'nodes' => array_map(fn (SnippetNode $n) => [
                'id' => $n->id,
                'component' => $n->component,
                'props' => $n->props,
                'children' => $n->children,
            ], $snippet->nodes),
        ];
    }

    public function toBlade(Snippet $snippet): string
    {
        $lines = ['<x-gsmui:layout>', '    <div class="playground-export">'];
        foreach ($this->orderedNodes($snippet) as $node) {
            $propsStr = $this->propsToBlade($node->props);
            $lines[] = "        <x-gsmui:{$node->component} {$propsStr} />";
        }
        $lines[] = '    </div>';
        $lines[] = '</x-gsmui:layout>';
        return implode("\n", $lines);
    }

    public function toHtml(Snippet $snippet): string
    {
        $result = app(SnippetExecutor::class)->execute($snippet);
        return $this->wrapInLayout($result->html);
    }

    private function propsToBlade(array $props): string
    {
        return implode(' ', array_map(
            fn ($k, $v) => is_bool($v) ? ":{$k}=\"{$v ? 'true' : 'false'}\"" : ":{$k}=\"{$v}\"",
            array_keys($props),
            array_values($props)
        ));
    }

    private function wrapInLayout(string $html): string
    {
        return "<!DOCTYPE html>\n<html>\n<head><meta charset='utf-8'><link rel='stylesheet' href='/dist/gsmui.css'></head>\n<body>\n{$html}\n<script src='/dist/gsmui.js'></script>\n</body>\n</html>";
    }
}
```

# 22. Snippet Analytics and Usage Tracking

Usage analytics help understand which components are most popular and where users struggle:

```php
namespace App\Domains\Playground\Services;

final class PlaygroundAnalyticsService
{
    public function recordExecution(string $userId, Snippet $snippet, ExecutionResult $result): void
    {
        foreach ($snippet->nodes as $node) {
            \App\Domains\Playground\Models\ComponentUsageStat::create([
                'user_id' => $userId,
                'component' => $node->component,
                'snippet_id' => null, // anonymized
                'had_errors' => $result->report->hasErrors(),
            ]);
        }
    }

    public function topComponents(int $limit = 20): array
    {
        return \App\Domains\Playground\Models\ComponentUsageStat::query()
            ->selectRaw('component, count(*) as usage_count')
            ->where('created_at', '>=', now()->subDays(30))
            ->groupBy('component')
            ->orderByDesc('usage_count')
            ->limit($limit)
            ->pluck('usage_count', 'component')
            ->all();
    }

    public function errorRate(string $component, int $days = 30): float
    {
        $total = \App\Domains\Playground\Models\ComponentUsageStat::query()
            ->where('component', $component)
            ->where('created_at', '>=', now()->subDays($days))
            ->count();

        if ($total === 0) {
            return 0.0;
        }

        $errors = \App\Domains\Playground\Models\ComponentUsageStat::query()
            ->where('component', $component)
            ->where('had_errors', true)
            ->where('created_at', '>=', now()->subDays($days))
            ->count();

        return round($errors / $total * 100, 2);
    }
}
```

Analytics are displayed in the admin dashboard to help the team improve components with high error rates.

# 23. CDN and Asset Management for Previews

The playground preview iframe needs GsmUi's CSS and JS assets. These are served from the local `dist/` directory (per the CSP policy in `AGENTS.md`), never from a CDN.

```php
namespace App\Domains\Playground\Services;

final class PlaygroundAssetService
{
    public function __construct(
        private readonly \Illuminate\Filesystem\Filesystem $filesystem,
    ) {}

    public function cssPath(): string
    {
        return asset('vendor/gsmui/dist/gsmui.css');
    }

    public function jsPath(): string
    {
        return asset('vendor/gsmui/dist/gsmui.js');
    }

    public function manifest(): array
    {
        $path = public_path('vendor/gsmui/dist/manifest.json');
        if (! $this->filesystem->exists($path)) {
            return [];
        }
        return json_decode($this->filesystem->get($path), true) ?? [];
    }

    /** Versioned asset URLs for cache busting */
    public function versionedUrl(string $file): string
    {
        $manifest = $this->manifest();
        return asset('vendor/gsmui/dist/' . ($manifest[$file] ?? $file));
    }
}
```

```php
    public function save(string $userId, array $state): void
    {
        $this->session->put("playground:{$userId}:state", [
            'nodes' => $state['nodes'] ?? [],
            'selected_node' => $state['selected_node'] ?? null,
            'undo_stack' => $state['undo_stack'] ?? [],
            'redo_stack' => $state['redo_stack'] ?? [],
            'saved_at' => now()->toIso8601String(),
        ]);
    }

    public function load(string $userId): ?array
    {
        return $this->session->get("playground:{$userId}:state");
    }

    public function clear(string $userId): void
    {
        $this->session->forget("playground:{$userId}:state");
    }

    public function pushUndo(string $userId, array $snapshot): void
    {
        $state = $this->load($userId) ?? ['undo_stack' => [], 'redo_stack' => []];
        $state['undo_stack'][] = $snapshot;
        $state['undo_stack'] = array_slice($state['undo_stack'], -50); // Keep last 50 states
        $state['redo_stack'] = []; // Clear redo on new action
        $this->save($userId, $state);
    }

    public function undo(string $userId): ?array
    {
        $state = $this->load($userId);
        if (empty($state['undo_stack'])) return null;

        $current = $state['nodes'];
        $state['redo_stack'][] = $current;
        $state['nodes'] = array_pop($state['undo_stack']);
        $this->save($userId, $state);

        return $state['nodes'];
    }

    public function redo(string $userId): ?array
    {
        $state = $this->load($userId);
        if (empty($state['redo_stack'])) return null;

        $current = $state['nodes'];
        $state['undo_stack'][] = $current;
        $state['nodes'] = array_pop($state['redo_stack']);
        $this->save($userId, $state);

        return $state['nodes'];
    }
}
```

### 28.2 Auto-Save Service

```php
namespace App\Domains\Playground\Services;

final class PlaygroundAutoSave
{
    public function __construct(
        private readonly PlaygroundEditorState $state,
        private readonly SnippetStorage $storage,
    ) {}

    public function autoSave(string $userId, array $nodes, ?int $snippetId = null): ?int
    {
        $state = $this->state->load($userId);
        if (! $state || $state['nodes'] === $nodes) {
            return null; // No changes
        }

        if ($snippetId) {
            $this->storage->update($snippetId, $nodes);
            return $snippetId;
        }

        $snippet = $this->storage->autoSave($userId, $nodes);
        return $snippet?->id;
    }

    public function lastSavedAt(string $userId): ?\Carbon\Carbon
    {
        $state = $this->state->load($userId);
        return isset($state['saved_at']) ? \Carbon\Carbon::parse($state['saved_at']) : null;
    }
}
```

# 30. Playground Error Recovery Strategies

### 30.1 Component Fallback

When a component fails to render, the executor can fall back to a simpler version:

```php
namespace App\Domains\Playground\Services;

final class ComponentFallbackStrategy
{
    private const FALLBACKS = [
        'modal' => 'div',
        'dropdown' => 'div',
        'tooltip' => 'span',
        'popover' => 'div',
        'accordion' => 'div',
        'tabs' => 'div',
    ];

    public function fallbackComponent(string $component): ?string
    {
        return self::FALLBACKS[$component] ?? null;
    }

    public function renderWithFallback(string $component, array $props): string
    {
        try {
            return app(\App\Domains\Components\Contracts\ComponentRenderer::class)
                ->render($component, $props)->html;
        } catch (\Throwable $e) {
            $fallback = $this->fallbackComponent($component);
            if ($fallback) {
                return app(\App\Domains\Components\Contracts\ComponentRenderer::class)
                    ->render($fallback, ['content' => $props['label'] ?? $props['text'] ?? ''])->html;
            }
            throw $e;
        }
    }
}
```

### 30.2 Graceful Degradation

```php
namespace App\Domains\Playground\Services;

final class PlaygroundGracefulDegradation
{
    public function renderWithDegradation(Snippet $snippet): ExecutionResult
    {
        $report = app(SnippetExecutor::class)->validate($snippet);

        // Remove invalid nodes
        $validNodes = array_filter($snippet->nodes, function (SnippetNode $node) use ($report) {
            $nodeErrors = $report->forNode($node->id);
            return empty($nodeErrors);
        });

        if (empty($validNodes)) {
            return new ExecutionResult(
                html: '<div class="text-center text-zinc-500 p-8">No valid components to display.</div>',
                report: $report,
            );
        }

        // Render only valid nodes
        $html = '';
        foreach ($validNodes as $node) {
            try {
                $html .= app(\App\Domains\Components\Contracts\ComponentRenderer::class)
                    ->render($node->component, $node->props)->html;
            } catch (\Throwable $e) {
                $html .= "<div class=\"text-red-500 text-sm p-2\">Error rendering {$node->component}: " . e($e->getMessage()) . "</div>";
            }
        }

        return new ExecutionResult($html, $report);
    }
}
```

# 33. Playground Version Diff Viewer

### 33.1 Snippet Diff Service

```php
namespace App\Domains\Playground\Services;

final class SnippetDiffService
{
    public function diff(Snippet $old, Snippet $new): SnippetDiff
    {
        $oldNodes = array_column($old->nodes, null, 'id');
        $newNodes = array_column($new->nodes, null, 'id');

        $added = [];
        $removed = [];
        $modified = [];

        // Find added and modified
        foreach ($newNodes as $id => $node) {
            if (! isset($oldNodes[$id])) {
                $added[] = $node;
            } elseif ($oldNodes[$id]->props !== $node->props || $oldNodes[$id]->component !== $node->component) {
                $modified[] = [
                    'old' => $oldNodes[$id],
                    'new' => $node,
                    'changes' => $this->propChanges($oldNodes[$id]->props, $node->props),
                ];
            }
        }

        // Find removed
        foreach ($oldNodes as $id => $node) {
            if (! isset($newNodes[$id])) {
                $removed[] = $node;
            }
        }

        return new SnippetDiff(
            added: $added,
            removed: $removed,
            modified: $modified,
            identical: count($added) === 0 && count($removed) === 0 && count($modified) === 0,
        );
    }

    private function propChanges(array $old, array $new): array
    {
        $changes = [];
        $allKeys = array_unique(array_merge(array_keys($old), array_keys($new)));

        foreach ($allKeys as $key) {
            $oldVal = $old[$key] ?? null;
            $newVal = $new[$key] ?? null;

            if ($oldVal !== $newVal) {
                $changes[$key] = ['old' => $oldVal, 'new' => $newVal];
            }
        }

        return $changes;
    }
}

final readonly class SnippetDiff
{
    public function __construct(
        public array $added,
        public array $removed,
        public array $modified,
        public bool $identical,
    ) {}
}
```

# 34. Playground API Rate Limit Headers

### 34.1 Rate Limit Response Headers

```php
namespace App\Domains\Playground\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class PlaygroundRateLimitHeaders
{
    public function handle(Request $request, Closure $next)
    {
        $response = $next($request);

        $limiter = app(\App\Domains\Playground\Services\PlaygroundRateLimiter::class);
        $userId = auth()->id();
        $action = $this->resolveAction($request);

        $remaining = $limiter->remaining($userId, $action, 30);
        $resetAt = now()->addMinutes(1);

        $response->headers->set('X-RateLimit-Limit', '30');
        $response->headers->set('X-RateLimit-Remaining', (string) $remaining);
        $response->headers->set('X-RateLimit-Reset', $resetAt->timestamp);

        if ($remaining <= 0) {
            $response->headers->set('Retry-After', '60');
        }

        return $response;
    }

    private function resolveAction(Request $request): string
    {
        $path = $request->path();
        if (str_contains($path, 'validate')) return 'validate';
        if (str_contains($path, 'render')) return 'render';
        if (str_contains($path, 'export')) return 'export';
        return 'default';
    }
}
```

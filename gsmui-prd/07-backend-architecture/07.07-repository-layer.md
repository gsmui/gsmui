# 07.07 - Repository Layer

**Project:** GsmUi
**Architecture:** Repository Pattern + Domain-Driven Design
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.08-repositories.md` for the conceptual repository architecture. This document specifies the **implementation contract** — the concrete interfaces, abstract base classes, Eloquent implementations, criteria objects, and pagination structures that every GsmUi repository must follow.

The Repository Layer is the only persistence boundary in GsmUi. Services and Actions never touch Eloquent, the `DB` facade, or a model's query builder directly; they depend on a typed repository interface bound in a domain service provider. This isolates data-access details (table names, eager-load lists, query scopes, the eventual move to a different store) from business logic and makes repositories unit-testable with a swapped implementation.

Repositories are pure persistence adapters. They translate interface calls into Eloquent queries, apply the eager-loading and criteria that prevent N+1 queries, and return domain models or typed read models. They do **not** contain business rules, dispatch events, send notifications, or open transactions — those belong to the Service and Action layers (see `07.06-service-layer.md`, `07.08-action-layer.md`).

# 1. Directory Layout

Every domain owns a `Repositories/` folder split into `Contracts/` (interfaces) and `Eloquent/` (implementations). A shared `app/Repositories/` holds the generic base classes.

# 2. Read/Write Split

Repositories separate read operations from write operations at the method level (see `05.08-repositories.md` §"Read vs Write"). A single interface may expose both, but writes (`create`, `update`, `delete`, `restore`) are kept free of query complexity. Read-heavy workloads that span multiple tables or need projections should use a dedicated **Query Service** (`ComponentQueryService`) rather than growing the repository with reporting methods.

| Concern   | Methods                                                            |
| --------- | ------------------------------------------------------------------ |
| Read      | `find`, `findOrFail`, `all`, `paginate`, `search`, `exists`, `bySlug` |
| Write     | `create`, `update`, `delete`, `restore`, `forceDelete`             |

# 3. Base Repository Contract

All repositories extend a generic `BaseRepository` that provides the common CRUD surface. Domain interfaces extend it and add domain-specific finders.

```php
namespace App\Repositories;

use Illuminate\Database\Eloquent\Collection;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Contracts\Pagination\LengthAwarePaginator;

/**
 * @template TModel of Model
 */
abstract class BaseRepository
{
    /** @return class-string<TModel> */
    abstract protected function modelClass(): string;

    public function find(int $id): ?Model
    {
        return $this->query()->find($id);
    }

    public function findOrFail(int $id): Model
    {
        return $this->query()->findOrFail($id);
    }

    public function all(): Collection
    {
        return $this->query()->get();
    }

    public function paginate(int $perPage = 15): LengthAwarePaginator
    {
        return $this->query()->paginate($perPage);
    }

    public function create(array $data): Model
    {
        return $this->query()->create($data);
    }

    public function update(Model $model, array $data): Model
    {
        $model->update($data);
        return $model->fresh();
    }

    public function delete(Model $model): void
    {
        $model->delete();
    }

    protected function query()
    {
        return $this->modelClass()::query();
    }
}
```

# 4. Domain Repository Interface

The interface is what Services depend on. It declares domain finders and extends the base where convenient.

```php
namespace App\Domains\Components\Repositories\Contracts;

use App\Models\Component;
use Illuminate\Contracts\Pagination\LengthAwarePaginator;

interface ComponentRepositoryInterface
{
    public function findOrFail(int $id): Component;

    public function bySlug(string $slug): ?Component;

    public function paginatePublished(int $perPage = 15): LengthAwarePaginator;

    public function create(array $attributes): Component;

    public function update(Component $component, array $attributes): Component;

    public function delete(Component $component): void;
}
```

# 5. Eloquent Implementation

The concrete repository owns eager-loading decisions and query scopes. It extends `BaseRepository` only to reuse CRUD helpers, then implements the domain interface.

```php
namespace App\Domains\Components\Repositories\Eloquent;

use App\Domains\Components\Repositories\Contracts\ComponentRepositoryInterface;
use App\Models\Component;
use App\Repositories\BaseRepository;
use Illuminate\Contracts\Pagination\LengthAwarePaginator;

class ComponentRepository extends BaseRepository implements ComponentRepositoryInterface
{
    protected function modelClass(): string
    {
        return Component::class;
    }

    public function findOrFail(int $id): Component
    {
        return $this->query()
            ->with(['versions', 'category', 'examples'])
            ->findOrFail($id);
    }

    public function bySlug(string $slug): ?Component
    {
        return $this->query()
            ->with(['versions', 'category'])
            ->where('slug', $slug)
            ->first();
    }

    public function paginatePublished(int $perPage = 15): LengthAwarePaginator
    {
        return $this->query()
            ->with('category')
            ->where('status', 'published')
            ->latest()
            ->paginate($perPage);
    }
}
```

# 6. Criteria Pattern

Reusable query constraints are expressed as `Criteria` objects and applied before execution, keeping repository method signatures clean (see `05.08-repositories.md` §"Criteria Pattern (Optional)").

```php
namespace App\Repositories\Criteria;

use Illuminate\Database\Eloquent\Builder;

interface Criteria
{
    public function apply(Builder $query): Builder;
}

final class PublishedCriteria implements Criteria
{
    public function apply(Builder $query): Builder
    {
        return $query->where('status', 'published');
    }
}

// Usage inside a repository method:
public function matching(array $criteria): Collection
{
    $query = $this->query();
    foreach ($criteria as $criterion) {
        $query = $criterion->apply($query);
    }
    return $query->get();
}
```

# 7. Pagination Contract

All paginated repository methods return a standard `LengthAwarePaginator` so the presentation layer (Livewire, API resources) consumes one shape. For very large read models use `cursorPaginate()`; for simple "next/prev" views use `simplePaginate()`.

```php
namespace App\Repositories\Pagination;

final readonly class PageOptions
{
    public function __construct(
        public int $page = 1,
        public int $perPage = 15,
        public string $sort = 'created_at',
        public string $direction = 'desc',
    ) {}
}
```

# 8. Dependency Injection & Binding

Interfaces are bound to implementations in a per-domain service provider, never via the global `AppServiceProvider`. This keeps binding colocated with the domain.

```php
namespace App\Domains\Components\Providers;

use App\Domains\Components\Repositories\Contracts\ComponentRepositoryInterface;
use App\Domains\Components\Repositories\Eloquent\ComponentRepository;
use Illuminate\Support\ServiceProvider;

class ComponentServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->bind(
            ComponentRepositoryInterface::class,
            ComponentRepository::class
        );
    }
}
```

# 9. Service Provider Registration

Domain providers are loaded from `bootstrap/providers.php` (Laravel 13) or registered in the package's `ServiceProvider::register()` when the domain ships as a package. Order does not matter; bindings are resolved lazily.

```php
// bootstrap/providers.php
return [
    App\Domains\Components\Providers\ComponentServiceProvider::class,
    App\Domains\Themes\Providers\ThemeServiceProvider::class,
];
```

# 10. Usage From a Service

Services depend on the interface, never the concrete class. Repositories receive fully-validated data; they do not validate or authorize.

```php
namespace App\Domains\Components\Services;

use App\Domains\Components\Repositories\Contracts\ComponentRepositoryInterface;

class ComponentService
{
    public function __construct(
        private ComponentRepositoryInterface $components,
    ) {}

    public function getPublished(int $perPage = 15): LengthAwarePaginator
    {
        return $this->components->paginatePublished($perPage);
    }
}
```

# 11. Error Handling

Repositories throw **infrastructure** exceptions only. The base `ModelNotFoundException` (raised by `findOrFail`) is allowed to bubble; business exceptions (e.g. `ComponentAlreadyExistsException`) are thrown by Services after a repository `exists()` check.

| Situation            | Exception                          |
| -------------------- | --------------------------------- |
| Record missing       | `Illuminate\Database\Eloquent\ModelNotFoundException` |
| Constraint violation | `Illuminate\Database\QueryException` |
| Connection failure   | Laravel's `ConnectionException`   |

# 12. Testing Per Layer

Repository tests run against a real (test) database with migrations — never mocked queries.

- `ComponentRepositoryTest`: `findOrFail` returns model with eager loads, `paginatePublished` filters by status, `bySlug` is null when absent.
- Use `RefreshDatabase` and model factories from `07.48-models.md`.
- Verify N+1 absence via `DB::enableQueryLog()` assertions on list endpoints.

# 13. Repository Implementation Patterns

### 13.1 Query Builder Pattern

```php
// Repository methods use the query builder for complex queries
public function search(string $query, ?string $status = null): Collection
{
    $builder = $this->query()
        ->with(['category', 'author'])
        ->where(function ($q) use ($query) {
            $q->where('name', 'LIKE', "%{$query}%")
              ->orWhere('description', 'LIKE', "%{$query}%")
              ->orWhere('slug', 'LIKE', "%{$query}%");
        });

    if ($status) {
        $builder->where('status', $status);
    }

    return $builder->latest()->get();
}
```

### 13.2 Scope Pattern

```php
// Use Eloquent scopes for reusable query constraints
public function query()
{
    return $this->modelClass()::query();
}

// In the model
class Component extends Model
{
    public function scopePublished($query)
    {
        return $query->where('status', 'published');
    }

    public function scopeDraft($query)
    {
        return $query->where('status', 'draft');
    }

    public function scopeFeatured($query)
    {
        return $query->where('is_featured', true);
    }

    public function scopeByCategory($query, string $category)
    {
        return $query->whereHas('category', fn ($q) => $q->where('slug', $category));
    }
}

// Usage in repository
public function paginateFeatured(int $perPage = 15): LengthAwarePaginator
{
    return $this->query()
        ->published()
        ->featured()
        ->with('category')
        ->latest()
        ->paginate($perPage);
}
```

### 13.3 Aggregate Query Pattern

```php
// Repository methods for aggregate queries
public function countByStatus(ComponentStatus $status): int
{
    return $this->query()->where('status', $status)->count();
}

public function countByAuthor(int $authorId): int
{
    return $this->query()->where('author_id', $authorId)->count();
}

public function totalSize(): int
{
    return $this->query()->sum('file_size');
}

public function averageRating(): float
{
    return $this->query()->avg('rating');
}
```

# 14. Eager Loading Strategy

### 14.1 Eager Loading Rules

| Method | Eager loads | Reason |
| --- |---|---|
| `find()` | None (lightweight) | Caller decides relations |
| `findOrFail()` | Domain-specific defaults | Always need full context |
| `findBySlug()` | `['versions', 'category']` | Detail page needs these |
| `paginatePublished()` | `['category']` | List page needs category |
| `search()` | `['category', 'author']` | Search results need context |

### 14.2 Conditional Eager Loading

```php
public function findWithRelations(int $id, array $relations = []): ?Component
{
    $query = $this->query();

    if (! empty($relations)) {
        $query->with($relations);
    }

    return $query->find($id);
}

// Usage
$component = $this->components->findWithRelations(1, ['versions', 'examples', 'files']);
```

### 14.3 Preventing N+1 Queries

```php
// Test for N+1
/** @test */
public function paginate_published_does_not_have_n_plus_one(): void
{
    Component::factory()->count(5)->published()->create();

    DB::enableQueryLog();

    $components = $this->components->paginatePublished();

    // Load each component's category (would cause N+1 without eager loading)
    foreach ($components as $component) {
        $component->category->name;
    }

    $queries = DB::getQueryLog();

    // Should be 2 queries: one for components, one for categories
    $this->assertCount(2, $queries);

    DB::disableQueryLog();
}
```

# 16. Repository Performance Optimization

### 16.1 Index Strategy

| Column | Index type | When to add |
| --- |---|---|
| `slug` | Unique | Every model with URL-friendly slug |
| `status` | Regular | Filtered list queries |
| `author_id` | Regular | User-scoped queries |
| `created_at` | Regular | Chronological ordering |
| `category_id` | Regular | Category filtering |
| `published_at` | Regular | Published date filtering |

### 16.2 Query Optimization Patterns

```php
// Use select() for list views
public function listPublished(): Collection
{
    return $this->query()
        ->select(['id', 'name', 'slug', 'status', 'category_id'])
        ->published()
        ->latest()
        ->get();
}

// Use cursor() for large result processing
public function allPublishedSlugs(): Generator
{
    return $this->query()
        ->select(['id', 'slug'])
        ->published()
        ->cursor();
}

// Use chunk() for batch processing
public function processInBatches(callable $callback, int $batchSize = 500): void
{
    $this->query()
        ->published()
        ->chunk($batchSize, function ($components) use ($callback) {
            foreach ($components as $component) {
                $callback($component);
            }
        });
}
```

### 16.3 Connection Pool Usage

```php
// Use read replica for heavy read queries
public function paginatePublished(int $perPage = 15): LengthAwarePaginator
{
    return $this->query()
        ->onReadReplica() // Laravel 13 read/write splitting
        ->with('category')
        ->published()
        ->latest()
        ->paginate($perPage);
}
```

# 17. Repository Error Handling

### 17.1 Exception Types

| Exception | When | Example |
| --- |---|---|
| `ModelNotFoundException` | `findOrFail()` with missing record | `$this->query()->findOrFail(999)` |
| `QueryException` | Database constraint violation | Duplicate unique value |
| `ConnectionException` | Database connection failure | Connection timeout |

### 17.2 Error Handling Pattern

```php
// Repository throws infrastructure exceptions only
public function create(array $attributes): Component
{
    try {
        return $this->query()->create($attributes);
    } catch (\Illuminate\Database\QueryException $e) {
        if ($e->errorInfo[1] == 1062) { // Duplicate entry
            throw new DuplicateEntryException(
                'A component with this slug already exists',
                previous: $e
            );
        }
        throw $e;
    }
}
```

# 19. Repository Anti-Patterns

| Anti-pattern | Symptom | Fix |
| --- |---|---|
| Business logic in repository | Repository validates data, checks rules | Move logic to service |
| Transaction in repository | Repository opens DB transaction | Move transaction to action/service |
| Event dispatch in repository | Repository fires events | Move to service/action |
| Direct model query from service | Service calls Model::query() | Use repository |
| God repository | Repository has > 20 methods | Split into query services |
| Missing eager loading | N+1 queries on list pages | Add eager loading to repository |
| Raw SQL everywhere | Repository uses raw SQL | Use query builder + Eloquent |
| Cache in repository | Repository caches results | Move cache to service layer |
| Pagination in service | Service calls paginate() | Let repository handle pagination |
| Returning raw arrays | Repository returns arrays | Return typed models |

# 20. Repository Documentation Standards

### 20.1 Interface Documentation

```php
/**
 * Repository for managing UI components.
 *
 * Handles persistence, querying, and retrieval of Component aggregates.
 * This interface is the only persistence boundary for the Components domain.
 *
 * @see ComponentService
 * @see Component Eloquent model
 */
interface ComponentRepositoryInterface
{
    /**
     * Find a component by its ID.
     *
     * Returns null if no component with the given ID exists.
     * Does not include eager-loaded relations.
     *
     * @param int $id The component ID
     * @return Component|null The component or null
     */
    public function find(int $id): ?Component;

    /**
     * Find a component by its ID or throw an exception.
     *
     * Returns the component if found, otherwise throws ModelNotFoundException.
     * Includes eager-loaded relations.
     *
     * @param int $id The component ID
     * @return Component The component
     * @throws \Illuminate\Database\Eloquent\ModelNotFoundException If not found
     */
    public function findOrFail(int $id): Component;
}
```

### 22.1 Repository Method Catalog

| Method | Return type | Eager loads | Description |
| --- |---|---|---|
| `find(int $id)` | `?Model` | None | Find by primary key |

| Method | Eager loads | Reason |
| --- |---|---|

# 23. Repository Testing Patterns

### 23.1 Unit Test Pattern

```php
namespace Tests\Unit\Domains\Components\Repositories;

use App\Domains\Components\Models\Component;
use App\Domains\Components\Repositories\Eloquent\ComponentRepository;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

class ComponentRepositoryTest extends TestCase
{
    use RefreshDatabase;

    private ComponentRepository $repository;

    protected function setUp(): void
    {
        parent::setUp();
        $this->repository = new ComponentRepository();
    }

    /** @test */
    public function find_returns_model_when_exists(): void
    {
        $component = Component::factory()->create(['id' => 1]);

        $result = $this->repository->find(1);

        $this->assertNotNull($result);
        $this->assertEquals(1, $result->id);
    }

    /** @test */
    public function find_returns_null_when_not_exists(): void
    {
        $result = $this->repository->find(999);

        $this->assertNull($result);
    }

    /** @test */
    public function findOrFail_throws_when_not_exists(): void
    {
        $this->expectException(\Illuminate\Database\Eloquent\ModelNotFoundException::class);

        $this->repository->findOrFail(999);
    }

    /** @test */
    public function create_persists_to_database(): void
    {
        $data = [
            'name' => 'Button',
            'slug' => 'button',
            'description' => 'A button component',
            'author_id' => 1,
            'status' => 'draft',
        ];

        $component = $this->repository->create($data);

        $this->assertDatabaseHas('components', ['slug' => 'button']);
        $this->assertEquals('Button', $component->name);
    }

    /** @test */
    public function update_modifies_attributes(): void
    {
        $component = Component::factory()->create(['name' => 'Old Name']);

        $updated = $this->repository->update($component, ['name' => 'New Name']);

        $this->assertEquals('New Name', $updated->fresh()->name);
```

# 24. Repository Anti-Patterns Reference

| Anti-pattern | Symptom | Fix |
| --- |---|---|
| Business logic in repository | Repository validates data, checks rules | Move logic to service |
| Transaction in repository | Repository opens DB transaction | Move transaction to action/service |
| Event dispatch in repository | Repository fires events | Move to service/action |
| Direct model query from service | Service calls Model::query() | Use repository |
| God repository | Repository has > 20 methods | Split into query services |
| Missing eager loading | N+1 queries on list pages | Add eager loading to repository |
| Raw SQL everywhere | Repository uses raw SQL | Use query builder + Eloquent |
| Cache in repository | Repository caches results | Move cache to service layer |
| Pagination in service | Service calls paginate() | Let repository handle pagination |
| Returning raw arrays | Repository returns arrays | Return typed models |
| No soft delete handling | Hard delete when soft delete expected | Use SoftDeletes trait |
| Missing indexes | Slow queries on filtered columns | Add migration indexes |
| Select all columns | Loading full model when only ID needed | Use select(['id', 'slug']) |

```php
final class EloquentComponentRepository implements ComponentRepositoryInterface
{
    private array $criteria = [];

    public function pushCriteria(CriteriaInterface $criteria): static
    {
        $this->criteria[] = $criteria;
        return $this;
    }

    public function clearCriteria(): static
    {
        $this->criteria = [];
        return $this;
    }

    private function applyCriteria(Builder $builder): Builder
    {
        foreach ($this->criteria as $criteria) {

        }
        return $builder;
    }

    {
        return $this->applyCriteria(Component::query());
    }
}
```

### 25.3 Dynamic Query Builder

```php
namespace App\Domains\Components\Repositories;

final class ComponentQueryBuilder
{
    private Builder $builder;
    private array $conditions = [];
    private array $orders = [];
    private ?int $limit = null;
    private ?int $offset = null;
    private array $with = [];
    private array $select = [];

    public function __construct(Builder $builder)
    {
        $this->builder = $builder;
    }

    public function where(string $column, mixed $value): static
    {
        $this->conditions[] = fn ($q) => $q->where($column, $value);
        return $this;
    }

    public function whereIn(string $column, array $values): static
    {
        $this->conditions[] = fn ($q) => $q->whereIn($column, $values);
        return $this;
    }

    public function whereHas(
        string $relation,
        callable $callback,
    ): static {
        $this->conditions[] = fn ($q) => $q->whereHas($relation, $callback);
        return $this;
    }

    public function orderBy(
        string $column,
        string $direction = 'asc',
    ): static {
        $this->orders[] = [$column, $direction];
        return $this;
    }

    public function with(array $relations): static
    {
        $this->with = array_merge($this->with, $relations);
        return $this;
    }

    public function select(array $columns): static
    {
        $this->select = $columns;
        return $this;
    }

    public function limit(int $limit): static
    {
        $this->limit = $limit;
        return $this;
    }

    public function offset(int $offset): static
    {
        $this->offset = $offset;
        return $this;
    }

    public function get(): Collection
    {
        $query = clone $this->builder;

        foreach ($this->conditions as $condition) {
            $condition($query);
        }

        foreach ($this->orders as [$column, $direction]) {
            $query->orderBy($column, $direction);
        }

        if (!empty($this->with)) {
            $query->with($this->with);
        }

        if (!empty($this->select)) {
            $query->select($this->select);
        }

        if ($this->limit !== null) {
            $query->limit($this->limit);
        }

        if ($this->offset !== null) {
            $query->offset($this->offset);
        }

        return $query->get();
    }

    public function paginate(int $perPage = 20): LengthAwarePaginator
    {
        $query = clone $this->builder;

        foreach ($this->conditions as $condition) {
            $condition($query);
        }

        foreach ($this->orders as [$column, $direction]) {
            $query->orderBy($column, $direction);
        }

        if (!empty($this->with)) {
            $query->with($this->with);
        }

        return $query->paginate($perPage);
    }
}
```

## 26. Repository Caching Patterns

### 26.1 Cache-Aside Pattern

```php
final class CachedComponentRepository implements ComponentRepositoryInterface
{
    public function __construct(
        private EloquentComponentRepository $repository,
        private CacheService $cache,
    ) {}

    public function find(int $id): ?Component
    {
        $key = "components:{$id}";

        return $this->cache->remember(
            key: $key,
            ttl: now()->addMinutes(15),
            callback: fn () => $this->repository->find($id),
        );
    }

    public function findBySlug(string $slug): ?Component
    {
        $key = "components:slug:{$slug}";

        return $this->cache->remember(
            key: $key,
            ttl: now()->addMinutes(15),
            callback: fn () => $this->repository->findBySlug($slug),
        );
    }

    public function save(Component $component): Component
    {
        $result = $this->repository->save($component);

        // Invalidate cache
        $this->cache->forget("components:{$component->id()}");
        $this->cache->forget("components:slug:{$component->slug()}");
        $this->cache->forget("components:list:*");

        return $result;
    }

    public function delete(Component $component): bool
    {
        $result = $this->repository->delete($component);

        // Invalidate cache
        $this->cache->forget("components:{$component->id()}");
        $this->cache->forget("components:slug:{$component->slug()}");

        return $result;
    }
}
```

```php
namespace App\Shared\Repositories;

final class RepositoryFactory
{
    private array $repositories = [];
    private Container $container;

    public function __construct(Container $container)
    {
        $this->container = $container;
    }

    public function register(
        string $interface,
```

| Optimization | When | Impact |
|---|---|---|

### 31.2 Retry Strategy

```php
namespace App\Shared\Repositories;

use Illuminate\Database\ConnectionException;

abstract class RetryableRepository
{
    protected function withRetry(
        callable $operation,
        int $maxRetries = 3,
        int $delayMs = 100,
    ): mixed {
        $attempt = 0;

        while (true) {
            try {
                return $operation();
            } catch (ConnectionException $e) {
                $attempt++;

                if ($attempt >= $maxRetries) {
                    throw $e;
                }

                usleep($delayMs * 1000 * $attempt); // Exponential backoff
            }
        }
    }
}
```

```php
        return collect($this->components)
            ->first(fn ($c) => $c->slug() === $slug);
    }

    public function save(Component $component): Component
    {
        $id = $component->id() ?? $this->nextId++;
        $this->components[$id] = $component;
        return $component;
    }

    public function delete(Component $component): bool
    {
        unset($this->components[$component->id()]);
        return true;
    }

    public function all(): Collection
    {
        return collect($this->components);
    }

    public function count(): int
    {
        return count($this->components);
    }

    public function reset(): void
    {
        $this->components = [];
        $this->nextId = 1;
    }
}
```

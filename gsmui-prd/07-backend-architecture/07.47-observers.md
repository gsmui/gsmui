# 07.47 - Observers

**Project:** GsmUi
**Architecture:** Model Observers & Audit Hooks
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `06.01-design-principles.md` §5 (centralized audit logging mandate) and `06.111-activity-log.md` (the immutable `activity_logs` schema that observers write into). This document is the *implementation contract*: the observer-vs-event decision rule, an `ActivityLogObserver` base pattern, registration, and the audit-hook convention that complements the event-driven cross-domain flow (see `07.12-events.md`).

# Purpose

Model observers respond to Eloquent lifecycle events (`creating`, `created`, `updating`, `updated`, `deleting`, `deleted`) and perform side effects tied to persistence. They are the natural home for audit-log hooking, search index invalidation, media cleanup, and cache warming.

Observers complement events: use an observer for model-centric behavior (audit, cache, filesystem) and dispatch a domain event from inside the observer when multiple domains must react. This split keeps audit logging consistent and centralized (per `06.01` §5) while preserving loose cross-domain coupling.

---

## 1. Observers vs Events

| Concern | Observer | Event |
| --- | --- | --- |
| Tied to a specific model | Yes | No (generic) |
| Multiple listeners | No (one per event type) | Yes |
| Decoupled cross-domain | Weak | Strong |
| Audit logging | Ideal | Possible but noisy |
| Search index sync | Ideal | Possible |
| Notification dispatch | Possible but domain-coupled | Ideal |

**Rule:** if the behavior belongs to a single model, use an observer. If multiple domains must react, dispatch an event *from* the observer.

## 2. Observer Registration

Register in a dedicated `ObservingServiceProvider` (or `AppServiceProvider::boot()`). Registering per model keeps the mapping explicit and discoverable.

```php
namespace App\Providers;

use App\Domains\Components\Models\Component;
use App\Domains\Components\Observers\ComponentObserver;
use App\Domains\Themes\Models\Theme;
use App\Domains\Themes\Observers\ThemeObserver;
use Illuminate\Foundation\Support\Providers\EventServiceProvider as ServiceProvider;

final class ObservingServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Theme::observe(ThemeObserver::class);
        Component::observe(ComponentObserver::class);
    }
}
```

## 3. Standard Observer Structure

Observers are `final readonly` classes. They mutate only the model being saved (in `*ing` hooks) and perform side effects in `*ed` hooks. Heavy work is deferred to jobs or events, never run synchronously.

```php
declare(strict_types=1);

namespace App\Domains\Themes\Observers;

use App\Domains\Themes\Events\ThemeUpdated;
use App\Domains\Themes\Models\Theme;
use Illuminate\Support\Facades\Cache;

final readonly class ThemeObserver
{
    public function creating(Theme $theme): void
    {
        $theme->token ??= \App\Domains\Themes\ValueObjects\ThemeToken::generate();
    }

    public function created(Theme $theme): void
    {
        Cache::forget("themes:user:{$theme->user_id}:list");
    }

    public function updating(Theme $theme): void
    {
        if ($theme->isDirty('visibility')) {
            // pre-update validation/logic
        }
    }

    public function updated(Theme $theme): void
    {
        if ($theme->wasChanged('visibility')) {
            event(new ThemeUpdated(themeId: $theme->id, changedBy: auth()->id()));
        }
    }

    public function deleting(Theme $theme): void
    {
        if ($theme->components()->where('status', \App\Domains\Components\Enums\ComponentStatus::Published)->exists()) {
            throw new \App\Domains\Themes\Exceptions\ThemeNotEmptyException();
        }
    }

    public function deleted(Theme $theme): void
    {
        Cache::forget("theme:{$theme->id}");
        $theme->unsearchable();
    }
}
```

## 4. Audit-Log Hooking via Observers

Centralize audit logging in observers rather than scattering `activity()` calls through Actions. The `ActivityLogObserver` trait hooks the lifecycle and writes the immutable `activity_logs` row (schema in `06.111-activity-log.md`).

```php
declare(strict_types=1);

namespace App\Domains\Shared\Observers;

use App\Domains\Notifications\Models\ActivityLog;
use App\Domains\Shared\Models\User;
use Illuminate\Database\Eloquent\Model;

trait ActivityLogObserver
{
    public function created(Model $model): void
    {
        $this->log($model, 'created', null, $model->getAttributes());
    }

    public function updated(Model $model): void
    {
        $this->log($model, 'updated', $model->getOriginal(), $model->getChanges());
    }

    public function deleted(Model $model): void
    {
        $this->log($model, 'deleted', $model->getOriginal(), null);
    }

    private function log(Model $model, string $action, ?array $old, ?array $new): void
    {
        ActivityLog::create([
            'user_id'     => auth()->id() ?? User::system()->id,
            'action'      => $action,
            'entity_type' => $model::class,
            'entity_id'   => $model->getKey(),
            'old_values'  => $old,
            'new_values'  => $new,
            'ip_address'  => request()?->ip(),
            'user_agent'  => request()?->userAgent(),
            'occurred_at' => now(),
        ]);
    }
}
```

```php
// In a domain observer:
final readonly class ComponentObserver
```

## 8. Observer Conventions

1. One observer per model maximum. If it exceeds ~150 lines, split into focused private methods.
2. Observers return nothing and alter control flow only by throwing (e.g. `deleting` guard).
3. Heavy work (indexing, notifications, network) is deferred to jobs or events, never run synchronously in the observer.
4. Audit logging is centralized via the `ActivityLogObserver` trait, not duplicated in each observer.

## 10. Observer Lifecycle Event Reference

### 10.1 Complete Event Matrix

Every Eloquent model fires these lifecycle events. Observers can hook into any of them.

| Event | When | `$model` state | Common uses |
| --- | --- | --- | --- |
| `creating` | Before INSERT | Attributes set, no ID | Set UUIDs, compute slugs, default values |
| `created` | After INSERT | Has ID, persisted | Cache warming, search indexing, audit log |
| `updating` | Before UPDATE | Dirty attributes visible | Validation, computed field updates |
| `updated` | After UPDATE | Changes committed | Cache invalidation, event dispatch, audit log |
| `saving` | Before INSERT or UPDATE | Depends on context | Cross-cutting pre-persist logic |
| `saved` | After INSERT or UPDATE | Persisted | Post-persist side effects |
| `deleting` | Before DELETE | Still exists | Guard checks, cascade prep |
| `deleted` | After DELETE | Gone (soft or hard) | Cache cleanup, search removal, audit log |
| `restoring` | Before RESTORE (soft) | Soft-deleted | Pre-restore validation |
| `restored` | After RESTORE | Active again | Cache warming, index restoration |
| `forceDeleted` | After HARD DELETE | Gone permanently | Filesystem cleanup, permanent audit |

### 10.2 Event Ordering Within a Transaction

```text
INSERT flow:
  creating → saving → created → saved

UPDATE flow:
  updating → saving → updated → saved

DELETE flow:
  deleting → saving → deleted → saved

RESTORE flow:
  restoring → saving → restored → saved
```

All hooks run within the same database transaction. Throwing from any `*ing` hook rolls back the entire transaction.

## 11. Observer Base Class Pattern

### 11.1 Abstract Base Observer

Provide a shared base class that handles common cross-cutting concerns:

```php
declare(strict_types=1);

namespace App\Domains\Shared\Observers;

use Illuminate\Database\Eloquent\Model;

abstract class BaseObserver
{
    /**
     * Common pre-create logic: set UUIDs, compute timestamps,
     * apply defaults that depend on runtime context.
     */
    public function creating(Model $model): void
    {
        // Override in subclass as needed
    }

    /**
     * Common post-create logic: cache warming, search indexing.
     * Always runs in the "ed" hook so the model has an ID.
     */
    public function created(Model $model): void
    {
        // Override in subclass as needed
    }

    /**
     * Common pre-update logic: validate changes, compute fields.
     */
    public function updating(Model $model): void
    {
        // Override in subclass as needed
    }

    /**
     * Common post-update logic: cache invalidation, event dispatch.
     */
    public function updated(Model $model): void
    {
        // Override in subclass as needed
    }

    /**
     * Guard deletion: check for dependent records, enforce business rules.
     * Throw an exception to prevent deletion.
     */
    public function deleting(Model $model): void
    {
        // Override in subclass as needed
    }

    /**
     * Post-delete cleanup: cache eviction, search removal, filesystem cleanup.
     */
    public function deleted(Model $model): void
    {
        // Override in subclass as needed
    }

    /**
     * Helper: check if a specific attribute changed during an update.
     */
    protected function wasChanged(Model $model, string $attribute): bool
    {
        return $model->wasChanged($attribute);
    }

    /**
     * Helper: get the previous value of an attribute before update.
     */
    protected function original(Model $model, string $attribute): mixed
    {
        return $model->getOriginal($attribute);
    }

    /**
     * Helper: dispatch a domain event safely.
     */
    protected function dispatchEvent(object $event): void
    {
        event($event);
    }

    /**
     * Helper: forget a cache key with a standard pattern.
     */
    protected function forgetCache(string $key): void
    {
        \Illuminate\Support\Facades\Cache::forget($key);
    }
}
```

### 11.2 Usage Pattern

```php
final class ComponentObserver extends BaseObserver
{
    use ActivityLogObserver;

    public function creating(Component $component): void
    {
        parent::creating($component);

        $component->token ??= ComponentToken::generate();
        $component->status ??= ComponentStatus::Draft;
    }

    public function created(Component $component): void
    {
        parent::created($component);

        $this->forgetCache("components:user:{$component->author_id}:list");
        $this->forgetCache("components:category:{$component->category_id}:list");
    }

    public function updated(Component $component): void
    {
        parent::updated($component);

        if ($this->wasChanged($component, 'status')) {
            $this->forgetCache("component:{$component->id}:status");
            $this->dispatchEvent(new ComponentStatusChanged(
                componentId: $component->id,
                oldStatus: $this->original($component, 'status'),
                newStatus: $component->status,
            ));
        }
    }

    public function deleted(Component $component): void
    {
        parent::deleted($component);

        $this->forgetCache("component:{$component->id}");
        $component->unsearchable();
    }
}
```

### 12.2 Tagged Audit Logging

Tags allow filtering audit logs by category:

```php
trait ActivityLogObserver
{
    public function created(Model $model): void
    {
        $this->log($model, 'created', null, $model->getAttributes(), ['creation']);
    }

    public function updated(Model $model): void
    {
        $tags = $this->inferTags($model);
        $this->log($model, 'updated', $model->getOriginal(), $model->getChanges(), $tags);
    }

    private function inferTags(Model $model): array
    {
        $tags = [];

        // Tag financial changes
        if ($model->isDirty(['amount', 'total', 'price', 'cost'])) {
            $tags[] = 'financial';
        }

        // Tag status changes
        if ($model->isDirty('status')) {
            $tags[] = 'status';
        }

        // Tag permission changes
        if ($model->isDirty(['role', 'permissions', 'is_admin'])) {
            $tags[] = 'permissions';
        }

        // Tag security-sensitive changes
        if ($model->isDirty(['password', 'email', 'api_key'])) {
            $tags[] = 'security';
        }

        return $tags;
    }

    private function log(Model $model, string $action, ?array $old, ?array $new, array $tags = []): void
    {
        ActivityLog::create([
            'user_id' => auth()->id() ?? User::system()->id,
            'action' => $action,
            'entity_type' => $model::class,
            'entity_id' => $model->getKey(),
            'old_values' => $this->redactSensitive($old),
            'new_values' => $this->redactSensitive($new),
            'ip_address' => request()?->ip(),
            'user_agent' => request()?->userAgent(),
            'request_url' => request()?->url(),
            'request_method' => request()?->method(),
            'occurred_at' => now(),
            'tags' => $tags,
            'metadata' => $this->buildMetadata($model),
        ]);
    }

    private function redactSensitive(?array $values): ?array
    {
        if ($values === null) return null;

        $redacted = ['password', 'api_key', 'secret', 'token', 'ssn', 'credit_card'];

        return collect($values)->mapWithKeys(function ($value, $key) use ($redacted) {
            $val = in_array(strtolower($key), $redacted) ? '[REDACTED]' : $value;
            return [$key => $val];
        })->toArray();
    }

    private function buildMetadata(Model $model): array
    {
        return [
            'model_table' => $model->getTable(),
            'model_key' => $model->getKey(),
            'connection' => $model->getConnectionName(),
        ];
    }
}
```

### 12.3 Audit Log Query Helpers

```php
namespace App\Domains\Notifications\Services;

final class AuditLogService
{
    public function forEntity(string $type, int $id): Collection
    {
        return ActivityLog::where('entity_type', $type)
            ->where('entity_id', $id)
            ->orderByDesc('occurred_at')
            ->get();
    }

    public function forUser(int $userId, ?DateTimeInterface $from = null, ?DateTimeInterface $to = null): Collection
    {
        return ActivityLog::where('user_id', $userId)
            ->when($from, fn ($q) => $q->where('occurred_at', '>=', $from))
            ->when($to, fn ($q) => $q->where('occurred_at', '<=', $to))
            ->orderByDesc('occurred_at')
            ->get();
    }

    public function byTag(string $tag, int $limit = 100): Collection
    {
        return ActivityLog::where('tags', 'like', "%\"{$tag}\"%")
            ->orderByDesc('occurred_at')
            ->limit($limit)
            ->get();
    }

    public function recentChanges(int $minutes = 60): Collection
    {
        return ActivityLog::where('occurred_at', '>=', now()->subMinutes($minutes))
            ->orderByDesc('occurred_at')
            ->get();
    }

    public function export(string $type, int $id, string $format = 'csv'): string
    {
        $logs = $this->forEntity($type, $id);

        if ($format === 'csv') {
            return $this->toCsv($logs);
        }

        return json_encode($logs->toArray(), JSON_PRETTY_PRINT);
    }

    private function toCsv(Collection $logs): string
    {
        $header = 'Timestamp,User,Action,Entity,Old Values,New Values,IP,Tags';
        $rows = $logs->map(fn ($log) => implode(',', [
            $log->occurred_at->toIso8601String(),
            $log->user?->name ?? 'System',
            $log->action,
            "{$log->entity_type}:{$log->entity_id}",
            json_encode($log->old_values),
            json_encode($log->new_values),
            $log->ip_address,
            implode(';', $log->tags ?? []),
        ]));

        return $header . "\n" . $rows->implode("\n");
    }
}
```

## 13. Observer Error Handling

### 13.1 Error Propagation Rules

| Hook type | Error behavior | Transaction |
| --- | --- | --- |
| `creating` | Exception → abort, rollback | Rolled back |
| `created` | Exception → logged, does NOT rollback created model | Model committed |
| `updating` | Exception → abort, rollback | Rolled back |
| `updated` | Exception → logged, does NOT rollback update | Model committed |
| `deleting` | Exception → abort, rollback | Rolled back |
| `deleted` | Exception → logged, does NOT rollback deletion | Model deleted |

### 13.2 Safe Side Effects in `*ed` Hooks

```php
public function updated(Model $model): void
{
    try {
        $this->invalidateCache($model);
    } catch (\Throwable $e) {
        // Cache failure should not break the model update
        report($e);
    }

    try {
        $this->syncSearchIndex($model);
    } catch (\Throwable $e) {
        // Search sync failure should not break the model update
        report($e);
    }
}
```

### 13.3 Deferred Side Effects via Jobs

For expensive side effects, dispatch jobs from the observer:

```php
public function updated(Model $model): void
{
    if ($model->wasChanged('content')) {
        // Dispatch search reindex — not critical path
        SyncSearchIndex::dispatch($model::class, $model->id)
            ->onQueue('search');
    }

    if ($model->wasChanged('status')) {
        // Notify relevant parties
        NotifyStatusChange::dispatch($model::class, $model->id, $model->getOriginal('status'))
            ->onQueue('mail');
    }
}
```

## 14. Observer Composition & Traits

### 14.1 Reusable Observer Traits

Small, focused traits provide cross-cutting observer behavior:

```php
// Traits for common observer patterns
trait CacheInvalidationObserver
{
    private function invalidateCacheFor(Model $model, string ...$patterns): void
    {
        foreach ($patterns as $pattern) {
            $key = str_replace('{id}', $model->getKey(), $pattern);
            Cache::forget($key);
        }
    }
}

trait SearchIndexObserver
{
    private function indexModel(Model $model): void
    {
        if (method_exists($model, 'toSearchableArray')) {
            dispatch(fn () => $model->searchable())
                ->onQueue('search');
        }
    }

    private function removeModelIndex(Model $model): void
    {
        if (method_exists($model, 'unsearchable')) {
            dispatch(fn () => $model->unsearchable())
                ->onQueue('search');
        }
    }
}

trait FileCleanupObserver
{
    private function deleteModelFiles(Model $model, string $disk, string $pathAttribute): void
    {
        $path = $model->{$pathAttribute};
        if ($path && Storage::disk($disk)->exists($path)) {
            Storage::disk($disk)->delete($path);
        }
    }
}
```

### 14.2 Combining Traits in Observers

```php
final class MediaObserver
{
    use ActivityLogObserver;
    use CacheInvalidationObserver;
    use FileCleanupObserver;

    public function created(Media $media): void
    {
        $this->invalidateCacheFor($media, "media:user:{$media->user_id}:list");
    }

    public function deleted(Media $media): void
    {
        $this->deleteModelFiles($media, 'media', 'path');
        $this->invalidateCacheFor($media, "media:{$media->id}");
    }
}
```

## 19. Observer Middleware Pattern

### 19.1 Conditional Observer Execution

Sometimes observers should only run under certain conditions (e.g., skip audit logging for system users, skip cache invalidation in tests):

```php
namespace App\Domains\Shared\Observers;

trait ConditionalObserver
{
    private array $conditions = [];

    public function when(string $condition, callable $callback): void
    {
        $this->conditions[$condition] = $callback;
    }

    private function shouldExecute(string $condition): bool
    {
        if (!isset($this->conditions[$condition])) {
            return true; // Default: execute
        }

        return $this->conditions[$condition]();
    }
}

// Usage in observer:
final class ComponentObserver
{
    use ActivityLogObserver;
    use ConditionalObserver;

    public function __construct()
    {
        // Skip audit logging for system user
        $this->when('skip_audit', fn () => auth()->id() === User::SYSTEM_ID);
    }

    public function created(Component $component): void
    {
        if (!$this->shouldExecute('skip_audit')) {
            return;
        }

        $this->log($component, 'created', null, $component->getAttributes());
    }
}
```

## 21. Observer Event Aggregation

### 21.1 Batching Side Effects

Instead of dispatching a job per model change, batch them:

```php
namespace App\Domains\Shared\Observers;

final class BatchObserver
{
    private static array $pendingJobs = [];

    public function updated(Model $model): void
    {
        if ($model->wasChanged('status')) {
            self::$pendingJobs[] = [
                'model' => $model::class,
                'id' => $model->getKey(),
                'old_status' => $model->getOriginal('status'),
                'new_status' => $model->status,
            ];
        }
    }

    public static function flush(): void
    {
        if (!empty(self::$pendingJobs)) {
            BatchNotifyStatusChange::dispatch(self::$pendingJobs)->onQueue('mail');
            self::$pendingJobs = [];
        }
    }
}

// In a middleware or after response:
app()->terminating(function () {
    BatchObserver::flush();
});
```

## 28. Observer Error Recovery

### 28.1 Retry Logic for Side Effects

```php
namespace App\Domains\Shared\Observers;

trait RetryableObserver
{
    private function retrySideEffect(callable $callback, int $maxAttempts = 3): void
    {
        $attempt = 0;

        while ($attempt < $maxAttempts) {
            try {
                $callback();
                return;
            } catch (\Throwable $e) {
                $attempt++;

                if ($attempt >= $maxAttempts) {
                    report($e);
                    return;
                }

                usleep(100_000 * $attempt); // 100ms, 200ms, 300ms
            }
        }
    }
}

// Usage:
final class ReliableObserver
{
    use RetryableObserver;

    public function created(Component $component): void
    {
        $this->retrySideEffect(function () use ($component) {
            Cache::forget("components:list");
        });
    }
}
```

### 28.2 Circuit Breaker Pattern

Stop retrying when external services are down:

```php
namespace App\Domains\Shared\Observers;

trait CircuitBreakerObserver
{
    private static array $circuitState = [];

    private function circuitBreak(string $service, callable $callback, int $threshold = 5): void
    {
        $key = "circuit:{$service}";

        if (Cache::get("{$key}:open", false)) {
            return; // Circuit is open — skip
        }

        try {
            $callback();
        } catch (\Throwable $e) {
            $failures = Cache::increment("{$key}:failures") ?? 1;
            Cache::put("{$key}:failures", $failures, 300);

            if ($failures >= $threshold) {
                Cache::put("{$key}:open", true, 60); // Open circuit for 60s
                Log::warning("Circuit breaker opened for {$service}", [
                    'failures' => $failures,
                ]);
            }

            report($e);
        }
    }
}
```

## 31. Observer Security Considerations

### 31.1 Authorization in Observers

Observers should not perform authorization checks — that belongs in controllers and actions. However, some observers need to verify the acting user:

```php
            'entity_type' => $model::class,
            'entity_id' => $model->getKey(),
            'ip_address' => request()?->ip(),

}
```

### 31.2 Preventing Observer Abuse

```php
final class AbusePreventionObserver
{
    private static int $maxChangesPerMinute = 30;

    public function updated(Model $model): void
    {
        $key = "observer:rate:" . $model::class . ":" . $model->getKey();
        $count = Cache::increment($key);

        if ($count === 1) {
            Cache::put($key, 1, 60); // 1 minute window
        }

        if ($count > self::$maxChangesPerMinute) {
            Log::warning('Observer rate limit exceeded', [
                'model' => $model::class,
                'id' => $model->getKey(),
                'changes' => $count,
            ]);

            // Don't throw — just skip the side effect
            return;
        }

        $this->performSideEffect($model);
    }
}
```

### 31.3 Data Privacy in Audit Logs

```php
trait ActivityLogObserver
{
    private function redactPII(array $values): array
    {
        $piiFields = ['email', 'phone', 'address', 'ssn', 'credit_card'];

        return collect($values)->mapWithKeys(function ($value, $key) use ($piiFields) {
            $val = in_array(strtolower($key), $piiFields)
                ? $this->redactValue($value)
                : $value;
            return [$key => $val];
        })->toArray();
    }

    private function redactValue(mixed $value): string
    {
        if (is_string($value) && strlen($value) > 4) {
            return substr($value, 0, 2) . str_repeat('*', strlen($value) - 4) . substr($value, -2);
        }
        return '***';
    }
}
```

| `retrieved` | Loaded from DB | All attributes | Hydration logging | N/A (post-load) |
| `creating` | Not yet saved | Attributes set | Set UUIDs, defaults | Throws → rollback |
| `created` | Persisted, has ID | All attributes | Cache warming, search | Logged, no rollback |
| `saving` | Not yet saved/updated | Current attributes | Cross-cutting pre-save | Throws → rollback |
| `saved` | Persisted | All attributes | Post-save side effects | Logged, no rollback |
| `updating` | Not yet updated | Dirty attributes visible | Validation, computed fields | Throws → rollback |
| `updated` | Updated, persisted | Changed attributes | Cache invalidation, events | Logged, no rollback |
| `deleting` | Not yet deleted | All attributes | Guard checks, cascade prep | Throws → rollback |
| `deleted` | Deleted (soft/hard) | All attributes | Cache cleanup, search removal | Logged, no rollback |
| `restoring` | Not yet restored | Soft-deleted attributes | Pre-restore validation | Throws → rollback |
| `restored` | Restored, active | All attributes | Cache warming, index restore | Logged, no rollback |
| `forceDeleted` | Permanently gone | All attributes | Filesystem cleanup | Logged, no rollback |

### 33.2 Hook Execution Order

```text
INSERT:
  creating → saving → created → saved

UPDATE:
  updating → saving → updated → saved

DELETE:
  deleting → saving → deleted → saved

RESTORE:
  restoring → saving → restored → saved

FORCE DELETE:
  forceDeleted (no saving/saved hooks)
```

### 33.3 Transaction Behavior

```text
All hooks run within the same database transaction.

*ing hooks (creating, updating, deleting):
  - Throwing an exception rolls back the entire transaction
  - Model is NOT persisted/updated/deleted

*ed hooks (created, updated, deleted):
  - Throwing an exception does NOT rollback the model change
  - Exception is logged and reported, but model change is committed
  - This is intentional: side effects should not break persistence
```

```php
namespace App\Domains\Themes\Observers;

use App\Domains\Themes\Events\ThemeUpdated;

        // Pre-update validation or computed field logic
    }
```

### 34.2 ComponentObserver

```php
declare(strict_types=1);

namespace App\Domains\Components\Observers;

use App\Domains\Components\Models\Component;
use App\Domains\Components\Events\ComponentStatusChanged;
use App\Domains\Shared\Observers\ActivityLogObserver;
use Illuminate\Support\Facades\Cache;

final readonly class ComponentObserver
{
    use ActivityLogObserver;

    public function creating(Component $component): void
    {
        $component->token ??= \App\Domains\Components\ValueObjects\ComponentToken::generate();
        $component->status ??= \App\Domains\Components\Enums\ComponentStatus::Draft;
    }

    public function created(Component $component): void
    {
        Cache::forget("components:user:{$component->author_id}:list");
        Cache::forget("components:category:{$component->category_id}:list");
    }

    public function updated(Component $component): void
    {
        if ($component->wasChanged('status')) {
            Cache::forget("component:{$component->id}:status");
            event(new ComponentStatusChanged(
                componentId: $component->id,
                oldStatus: $component->getOriginal('status'),
                newStatus: $component->status,
            ));
        }

        if ($component->wasChanged('category_id')) {
            $oldCategoryId = $component->getOriginal('category_id');
            $newCategoryId = $component->category_id;

            if ($oldCategoryId) {
                Cache::forget("components:category:{$oldCategoryId}:list");
            }
            if ($newCategoryId) {
                Cache::forget("components:category:{$newCategoryId}:list");
            }
        }
    }

    public function deleted(Component $component): void
    {
        Cache::forget("component:{$component->id}");
        Cache::forget("component:{$component->id}:status");
        Cache::forget("components:user:{$component->author_id}:list");
        Cache::forget("components:category:{$component->category_id}:list");
        $component->unsearchable();
    }
}
```

```php
    public function forceDeleted(Media $media): void
    {
        if ($media->path && Storage::disk($media->disk)->exists($media->path)) {

        if ($media->thumbnails) {
            foreach ($media->thumbnails as $thumbnail) {
                if (Storage::disk($media->disk)->exists($thumbnail)) {
                    Storage::disk($media->disk)->delete($thumbnail);
                }
            }
        }
    }
}
```

### 35.2 Observer Profiling

```php
trait ProfiledObserver
{
    private array $timings = [];

    protected function startTimer(string $label): void
    {
        $this->timings[$label] = microtime(true);
    }

    protected function endTimer(string $label): float
    {
        $elapsed = microtime(true) - ($this->timings[$label] ?? microtime(true));

        if ($elapsed > 0.1) {
            Log::warning("Slow observer operation", [
                'label' => $label,
                'elapsed_ms' => round($elapsed * 1000, 2),
                'model' => static::class,
            ]);
        }

        return $elapsed;
    }
}
```

## 36. Observer Conventions Summary

1. One observer per model maximum.
2. Observers return nothing; alter control flow only by throwing.
3. Heavy work is deferred to jobs or events.
4. Audit logging via `ActivityLogObserver` trait.
5. Cache invalidation follows `{entity}:{id}` pattern.
6. Side effects in `*ed` hooks are wrapped in try-catch.
7. Sensitive data is redacted before audit logging.
8. Financial and security changes are tagged.
9. Event dispatch uses domain events.
10. Testing covers side effects, events, guards, audit, errors.
11. Use `ConditionalObserver` for skip logic.
12. Batch side effects when possible.
13. Profile observer execution for slow operations.
14. Register observers in explicit order.
15. Document observer side effects and cache keys.

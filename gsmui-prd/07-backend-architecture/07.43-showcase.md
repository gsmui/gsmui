# 07.43 - Showcase

**Project:** GsmUi
**Architecture:** Submission + Review + Voting Services
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `05.28-showcase-platform.md` (submission, display, moderation, categories, social). This document is the *implementation contract*: the `SubmissionService`, the review workflow (reusing `07.39-admin-platform.md` `ModerationService`), the `VotingService`, and featured-curation logic.

# Purpose

The Showcase Platform lets users submit community projects built with GsmUi and browse them in a curated, votable gallery. It is the most socially-driven domain, so it leans hard on two existing services rather than reinventing them: content moderation reuses the `ModerationService` state machine (`07.39-admin-platform.md`), and aggregation/render patterns follow the dashboard and blog services. What is unique here is submission intake, duplicate detection, voting integrity, and featured curation.

`SubmissionService` owns intake + duplicate checks; `ReviewService` is a thin facade over `ModerationService` for the approve/reject/flag transitions; `VotingService` records one weighted vote per user with idempotency; `CurationService` selects featured projects by a rank score. All writes go through repositories and emit events for analytics (`07.44-analytics.md`).

Goals:

- Submission intake is spam-resistant: duplicate/similar-title detection before persistence.
- Review reuses the single moderation state machine — no second approval path.
- One vote per user per project; votes are immutable tallies, not mutable counters prone to races.
- Featured projects are computed by a transparent rank, not hand-set flags alone.

## 1. Submission Service

`SubmissionService` validates intake, runs duplicate detection against existing approved projects (title/URL similarity), and persists a `ShowcaseProject` in `pending` moderation state. It never approves — that is `ReviewService`'s job.

```php
namespace App\Domains\Showcase\Services;

use App\Domains\Showcase\DTOs\SubmissionData;
use App\Domains\Showcase\Enums\ModerationStatus;

final class SubmissionService
{
    public function __construct(
        private readonly \App\Domains\Showcase\Repositories\ShowcaseRepository $projects,
        private readonly \App\Domains\Showcase\Services\DuplicateDetector $dupes,
    ) {}

    public function submit(SubmissionData $data, string $userId): \App\Domains\Showcase\Models\ShowcaseProject
    {
        if ($this->dupes->looksDuplicate($data->title, $data->demoUrl, $data->sourceUrl)) {
            throw new \App\Domains\Showcase\Exceptions\DuplicateSubmissionException();
        }

        return $this->projects->create([
            'title' => $data->title,
            'slug' => \Illuminate\Support\Str::slug($data->title),
            'description' => $data->description,
            'author_id' => $userId,
            'author_name' => $data->authorName,
            'screenshots' => $data->screenshots,
            'demo_url' => $data->demoUrl,
            'source_url' => $data->sourceUrl,
            'category_id' => $data->categoryId,
            'moderation_status' => ModerationStatus::Pending,
            'created_at' => now(),
        ]);
    }
}
```

Duplicate detection uses a cheap normalized similarity on title + URL host:

```php
namespace App\Domains\Showcase\Services;

final class DuplicateDetector
{
    public function looksDuplicate(string $title, ?string $demo, ?string $source): bool
    {
        $existing = \App\Domains\Showcase\Models\ShowcaseProject::query()
            ->where('moderation_status', '!=', 'rejected')
            ->get(['title', 'demo_url', 'source_url']);

        foreach ($existing as $e) {
            if (similar_text(strtolower($title), strtolower($e->title), $p) && $p > 85) {
                return true;
            }
            if ($demo && parse_url($demo, PHP_URL_HOST) === parse_url($e->demo_url ?? '', PHP_URL_HOST)) {
                return true;
            }
        }

        return false;
    }
}
```

Usage:

```php
$project = app(\App\Domains\Showcase\Services\SubmissionService::class)->submit(
    SubmissionData::from($request->validated()),
    userId: auth()->id()
);
// project is now in "pending" — awaiting review
```

## 2. Review Service (over ModerationService)

`ReviewService` is a domain-friendly wrapper that adapts a `ShowcaseProject` to the `Moderatable` contract and delegates to `ModerationService`. This guarantees the showcase review path is identical to blog-comment moderation.

```php
namespace App\Domains\Showcase\Services;

use App\Domains\Admin\Enums\ModerationStatus;
use App\Domains\Admin\Services\ModerationService;
use App\Domains\Showcase\Models\ShowcaseProject;

final class ReviewService
{
    public function __construct(
        private readonly ModerationService $moderation,
        private readonly \App\Domains\Showcase\Repositories\ShowcaseRepository $projects,
    ) {}

    public function approve(int $id): void
    {
        $this->moderation->decide($this->projects->find($id), ModerationStatus::Approved);
    }

    public function reject(int $id, string $reason): void
    {
        $this->moderation->decide($this->projects->find($id), ModerationStatus::Rejected, reason: $reason);
    }

    public function flag(int $id): void
    {
        $this->moderation->decide($this->projects->find($id), ModerationStatus::Flagged);
    }
}
```

Because `ShowcaseProject` implements `Moderatable`, the transition validation, RBAC check, audit log, and `ContentModerated` event all come for free from `07.39-admin-platform.md`.

## 3. Voting Service

`VotingService` records one vote per user per project in a `showcase_votes` table (immutable rows), and derives `likes_count` from a counted view or a maintained counter. Idempotency prevents double-voting; "un-vote" deletes the row and recomputes.

```php
namespace App\Domains\Showcase\Services;

final class VotingService
{
    public function __construct(
        private readonly \App\Domains\Showcase\Repositories\VoteRepository $votes,
    ) {}

    public function vote(int $projectId, string $userId): void
    {
        if ($this->votes->exists($projectId, $userId)) {
            throw new \App\Domains\Showcase\Exceptions\AlreadyVotedException();
        }

        $this->votes->create([
            'project_id' => $projectId,
            'user_id' => $userId,
            'created_at' => now(),
        ]);

        $this->recount($projectId);
    }

    public function unvote(int $projectId, string $userId): void
    {
        $this->votes->deleteFor($projectId, $userId);
        $this->recount($projectId);
    }

    private function recount(int $projectId): void
    {
        $count = $this->votes->countFor($projectId);
        \App\Domains\Showcase\Models\ShowcaseProject::where('id', $projectId)
            ->update(['likes_count' => $count]);
    }
}
```

| Rule | Enforcement |
| --- | --- |
| One vote per user/project | Unique `(project_id, user_id)` + `exists()` guard |
| No self-vote inflation | Caller checks `$project->author_id !== $userId` |
| Recount atomic | Single `update` after row write |

## 4. Curation Service (Featured)

`CurationService` computes the featured set from a transparent rank: recency, votes, views, and category diversity. It returns a stable list for the homepage rail and the `/showcase/featured` page. Manual "pinned" projects are merged on top.

```php
namespace App\Domains\Showcase\Services;

use App\Domains\Showcase\Enums\ModerationStatus;

final class CurationService
{
    public function featured(int $limit = 6): array
    {
        $pinned = \App\Domains\Showcase\Models\ShowcaseProject::query()
            ->where('is_pinned', true)
            ->where('moderation_status', ModerationStatus::Approved)
            ->get();

        $ranked = \App\Domains\Showcase\Models\ShowcaseProject::query()
            ->where('moderation_status', ModerationStatus::Approved)
            ->where('is_pinned', false)
            ->get()
            ->map(fn ($p) => $p->setAttribute('rank', $this->score($p)))
            ->sortByDesc('rank')
            ->take($limit - $pinned->count());

        return $pinned->concat($ranked)->values()->all();
    }

    private function score(\App\Domains\Showcase\Models\ShowcaseProject $p): float
    {
        $ageDays = now()->diffInDays($p->published_at ?? $p->created_at);
        $recency = 1 / (1 + $ageDays / 30);            // decays over ~30d
        $popularity = ($p->likes_count * 1.0) + ($p->views_count * 0.1);

        return $recency * 0.4 + min($popularity / 100, 1) * 0.6;
    }
}
```

## 5. Display & Events

```text
User submits ──► SubmissionService (dup check) ──► pending project
      │
Admin/MCP ──► ReviewService ──► ModerationService::decide
      │                                 └─► ContentModerated event
      │                                        ├─► approved → public gallery
      │                                        └─► rejected → hidden
      │
Visitor ──► VotingService::vote ──► showcase_votes (immutable)
      │
CurationService::featured ──► homepage rail + /showcase/featured
      │
Analytics (07.44) consumes votes/views/moderation events
```

Views are tracked via a lightweight `ViewService` (increment + dedupe by user/IP per day) so `views_count` feeds curation without write amplification.

### 8.1 Screenshot Upload Service

```php
namespace App\Domains\Showcase\Services;

final class ScreenshotService
{
    private const MAX_SCREENSHOTS = 10;
    private const MAX_SIZE_MB = 5;
    private const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'image/webp'];

    public function __construct(
        private readonly \App\Domains\Showcase\Repositories\ScreenshotRepository $screenshots,
    ) {}

    public function upload(int $projectId, \Illuminate\Http\UploadedFile $file, int $order = 0): \App\Domains\Showcase\Models\Screenshot
    {
        $this->validateFile($file);
        $this->checkLimit($projectId);

        $path = $file->store("showcase/{$projectId}", 'public');

        // Generate thumbnails
        $thumbPath = $this->generateThumbnail($path);

        return $this->screenshots->create([
            'project_id' => $projectId,
            'path' => $path,
            'thumbnail_path' => $thumbPath,
            'original_name' => $file->getClientOriginalName(),
            'size' => $file->getSize(),
            'mime_type' => $file->getMimeType(),
            'order' => $order,
            'created_at' => now(),
        ]);
    }

    public function uploadBatch(int $projectId, array $files): array
    {
        $results = [];
        foreach ($files as $index => $file) {
            $results[] = $this->upload($projectId, $file, $index);
        }
        return $results;
    }

    public function reorder(int $projectId, array $orderedIds): void
    {
        foreach ($orderedIds as $position => $id) {
            $this->screenshots->where('id', $id)->where('project_id', $projectId)
                ->update(['order' => $position]);
        }
    }

    public function delete(int $screenshotId): void
    {
        $screenshot = $this->screenshots->find($screenshotId);
        Storage::disk('public')->delete($screenshot->path);
        Storage::disk('public')->delete($screenshot->thumbnail_path);
        $screenshot->delete();
    }

    /** @return \App\Domains\Showcase\Models\Screenshot[] */
    public function forProject(int $projectId): array
    {
        return $this->screenshots->forProject($projectId);
    }

    private function validateFile(\Illuminate\Http\UploadedFile $file): void
    {
        $maxSize = self::MAX_SIZE_MB * 1024 * 1024;
        if ($file->getSize() > $maxSize) {
            throw new \App\Domains\Showcase\Exceptions\FileTooLargeException(self::MAX_SIZE_MB);
        }
        if (! in_array($file->getMimeType(), self::ALLOWED_TYPES)) {
            throw new \App\Domains\Showcase\Exceptions\UnsupportedFileTypeException($file->getMimeType());
        }
    }

    private function checkLimit(int $projectId): void
    {
        $count = $this->screenshots->countForProject($projectId);
        if ($count >= self::MAX_SCREENSHOTS) {
            throw new \App\Domains\Showcase\Exceptions\TooManyScreenshotsException(self::MAX_SCREENSHOTS);
        }
    }

    private function generateThumbnail(string $path): string
    {
        // Generate 400x300 thumbnail
        $thumbPath = str_replace('showcase/', 'showcase/thumbs/', $path);
        // Image processing logic here
        return $thumbPath;
    }
}
```

## 9. Demo Integration

### 9.1 Demo Link Validation

```php
namespace App\Domains\Showcase\Services;

final class DemoValidator
{
    private const ALLOWED_HOSTS = [
        'vercel.app',
        'netlify.app',
        'github.io',
        'gitlab.io',
        'herokuapp.com',
        'railway.app',
        'render.com',
        'fly.dev',
        'pages.dev',
    ];

    public function validate(string $url): DemoValidationResult
    {
        $parsed = parse_url($url);

        if (! $parsed || ! isset($parsed['host'])) {
            return new DemoValidationResult(false, 'Invalid URL');
        }

        // Check for localhost (blocked in production)
        if (in_array($parsed['host'], ['localhost', '127.0.0.1', '0.0.0.0'])) {
            if (app()->environment('production')) {
                return new DemoValidationResult(false, 'Localhost URLs are not allowed in production');
            }
        }

        // Check HTTPS
        if (($parsed['scheme'] ?? '') !== 'https') {
            return new DemoValidationResult(false, 'Demo URL must use HTTPS');
        }

        // Check against known hosting platforms or allow custom domains
        $isKnownPlatform = false;
        foreach (self::ALLOWED_HOSTS as $host) {
            if (str_ends_with($parsed['host'], $host)) {
                $isKnownPlatform = true;
                break;
            }
        }

        return new DemoValidationResult(true, null, $isKnownPlatform);
    }
}

final readonly class DemoValidationResult
{
    public function __construct(
        public bool $valid,
        public ?string $error = null,
        public bool $isKnownPlatform = false,
    ) {}
}
```

```php
namespace App\Domains\Showcase\Services;

final class DemoHealthChecker
{
    public function check(string $url): DemoHealthResult
    {
        try {
            $response = Http::timeout(10)->get($url);

            return new DemoHealthResult(
                reachable: $response->successful(),
                statusCode: $response->status(),
                loadTimeMs: $response->transferStats?->getTransferTime() * 1000 ?? 0,
                sslValid: str_starts_with($url, 'https://'),
            );
        } catch (\Throwable $e) {
            return new DemoHealthResult(
                reachable: false,
                error: $e->getMessage(),
            );
        }
    }

    /** @return array<int, DemoHealthResult> */
    public function checkAll(): array
    {
        $projects = \App\Domains\Showcase\Models\ShowcaseProject::query()
            ->whereNotNull('demo_url')
            ->where('moderation_status', 'approved')
            ->get();

        $results = [];
        foreach ($projects as $project) {
            $results[$project->id] = $this->check($project->demo_url);
        }

        return $results;
    }
}

{
    public function __construct(
        public bool $reachable,
        public ?int $statusCode = null,
        public float $loadTimeMs = 0,
        public bool $sslValid = false,
        public ?string $error = null,
    ) {}
}
```

## 10. Source Code Linking

### 10.1 Source Repository Service

```php
namespace App\Domains\Showcase\Services;

final class SourceRepositoryService
{
    public function __construct(
        private readonly \App\Domains\Showcase\Repositories\SourceRepositoryRepository $repos,
    ) {}

    public function connect(int $projectId, string $url): \App\Domains\Showcase\Models\SourceRepository
    {
        $parsed = parse_url($url);
        $provider = $this->detectProvider($parsed['host'] ?? '');

        if (! $provider) {
            throw new \App\Domains\Showcase\Exceptions\UnsupportedGitProviderException();
        }

        $metadata = $this->fetchMetadata($url, $provider);

        return $this->repos->create([
            'project_id' => $projectId,
            'url' => $url,
            'provider' => $provider,
            'owner' => $metadata['owner'] ?? null,
            'repo' => $metadata['repo'] ?? null,
            'stars' => $metadata['stars'] ?? 0,
            'forks' => $metadata['forks'] ?? 0,
            'language' => $metadata['language'] ?? null,
            'license' => $metadata['license'] ?? null,
            'last_synced_at' => now(),
        ]);
    }

    public function syncMetadata(int $projectId): void
    {
        $repo = $this->repos->forProject($projectId);
        if (! $repo) return;

        $metadata = $this->fetchMetadata($repo->url, $repo->provider);
        $repo->update([
            'stars' => $metadata['stars'] ?? $repo->stars,
            'forks' => $metadata['forks'] ?? $repo->forks,
            'language' => $metadata['language'] ?? $repo->language,
            'license' => $metadata['license'] ?? $repo->license,
            'last_synced_at' => now(),
        ]);
    }

    private function detectProvider(string $host): ?string
    {
        return match (true) {
            str_contains($host, 'github.com') => 'github',
            str_contains($host, 'gitlab.com') => 'gitlab',
            str_contains($host, 'bitbucket.org') => 'bitbucket',
            default => null,
        };
    }

    private function fetchMetadata(string $url, string $provider): array
    {
        // Fetch repository metadata from provider API
        return match ($provider) {
            'github' => $this->fetchGithubMetadata($url),
            'gitlab' => $this->fetchGitlabMetadata($url),
            'bitbucket' => $this->fetchBitbucketMetadata($url),
            default => [],
        };
    }

    private function fetchGithubMetadata(string $url): array
    {
        // GitHub API call
        return ['stars' => 0, 'forks' => 0, 'language' => null, 'license' => null];
    }

    private function fetchGitlabMetadata(string $url): array
    {
        return [];
    }

    private function fetchBitbucketMetadata(string $url): array
    {
        return [];
    }
}
```

```php
    }

    private function computeDiff(?string $a, ?string $b): string
    {
        if ($a === null || $b === null) return '';
        // Simple diff computation
        return $b;
    }
}
```

```php
namespace App\Domains\Showcase\Services;

final class ProjectCollaboratorService

    public function __construct(

        $this->collaborators->create([
            'project_id' => $invitation->project_id,
            'user_id' => $userId,
```

```php
namespace App\Domains\Showcase\Services;

final class AchievementService
{
    private const ACHIEVEMENTS = [

        'five_submissions' => ['name' => 'Prolific Creator', 'description' => 'Submit 5 projects', 'icon' => 'fire'],
        'ten_submissions' => ['name' => 'Showcase Veteran', 'description' => 'Submit 10 projects', 'icon' => 'trophy'],
        'first_approved' => ['name' => 'Published', 'description' => 'Get your first project approved', 'icon' => 'check'],
        'featured_project' => ['name' => 'Featured', 'description' => 'Get a project featured', 'icon' => 'star'],
        'hundred_votes' => ['name' => 'Community Favorite', 'description' => 'Receive 100 votes across projects', 'icon' => 'heart'],
        'fifty_stars' => ['name' => 'Open Source Star', 'description' => 'Receive 50 GitHub stars', 'icon' => 'github'],
        'helpful_reviewer' => ['name' => 'Helpful Reviewer', 'description' => 'Review 10 projects', 'icon' => 'eye'],
    ];

    public function __construct(
        private readonly \App\Domains\Showcase\Repositories\AchievementRepository $achievements,
    ) {}

    public function checkAndAward(string $userId): array
    {
        $awarded = [];

        foreach (self::ACHIEVEMENTS as $key => $config) {
            if ($this->hasAchievement($userId, $key)) continue;
            if ($this->meetsCriteria($userId, $key)) {
                $this->award($userId, $key);
                $awarded[] = $config;
            }
        }

        return $awarded;
    }

    public function award(string $userId, string $achievementKey): void
    {
        $this->achievements->create([
            'user_id' => $userId,
            'achievement_key' => $achievementKey,
            'awarded_at' => now(),
        ]);

        \App\Domains\Showcase\Events\AchievementAwarded::dispatch($userId, $achievementKey);
    }

    public function hasAchievement(string $userId, string $achievementKey): bool
    {
        return $this->achievements->where('user_id', $userId)
            ->where('achievement_key', $achievementKey)
            ->exists();
    }

    /** @return array<string, array> */
    public function forUser(string $userId): array
    {
        $awarded = $this->achievements->where('user_id', $userId)->pluck('achievement_key')->all();

        return array_map(function ($key) use ($awarded) {
            return [
                ...self::ACHIEVEMENTS[$key],
                'key' => $key,
                'awarded' => in_array($key, $awarded),
                'awarded_at' => in_array($key, $awarded)
                    ? $this->achievements->where('user_id', $userId)->where('achievement_key', $key)->first()?->awarded_at
                    : null,
            ];
        }, array_keys(self::ACHIEVEMENTS));
    }

    private function meetsCriteria(string $userId, string $achievementKey): bool
    {
        return match ($achievementKey) {
            'first_submission' => \App\Domains\Showcase\Models\ShowcaseProject::where('author_id', $userId)->exists(),
            'five_submissions' => \App\Domains\Showcase\Models\ShowcaseProject::where('author_id', $userId)->count() >= 5,
            'ten_submissions' => \App\Domains\Showcase\Models\ShowcaseProject::where('author_id', $userId)->count() >= 10,
            'first_approved' => \App\Domains\Showcase\Models\ShowcaseProject::where('author_id', $userId)->where('moderation_status', 'approved')->exists(),
            'featured_project' => \App\Domains\Showcase\Models\ShowcaseProject::where('author_id', $userId)->where('is_featured', true)->exists(),
            'hundred_votes' => \App\Domains\Showcase\Models\ShowcaseProject::where('author_id', $userId)->sum('likes_count') >= 100,
            default => false,
        };
    }
}
```

```php
namespace App\Domains\Showcase\Services;

final class ShowcaseSearchService
{
    public function __construct(
        private readonly \MeiliSearch\Laravel\Indexes\MeiliSearchIndex $index,
    ) {}

    public function search(string $query, array $filters = []): SearchResult
    {
        $searchOptions = [
            'filter' => $this->buildFilters($filters),
            'sort' => $filters['sort'] ?? 'relevance',
            'limit' => $filters['limit'] ?? 20,
            'offset' => $filters['offset'] ?? 0,
        ];

        $results = $this->index->search($query, $searchOptions);

        return new SearchResult(
            hits: $results['hits'],
            totalHits: $results['nbHits'],
            processingTimeMs: $results['processingTimeMs'],
            query: $query,
        );
    }

    public function facets(): array
    {
        return $this->index->search('', [
            'facets' => ['category', 'tags', 'author', 'moderation_status'],
            'limit' => 0,
        ]);
    }

    private function buildFilters(array $filters): array
    {
        $filterParts = [];

        if (isset($filters['category'])) {
            $filterParts[] = "category = '{$filters['category']}'";
        }
        if (isset($filters['author'])) {
            $filterParts[] = "author_id = '{$filters['author']}'";
        }
        if (isset($filters['min_votes'])) {
            $filterParts[] = "likes_count >= {$filters['min_votes']}";
        }
        if (isset($filters['date_from'])) {
            $filterParts[] = "created_at >= '{$filters['date_from']}'";
        }

        return $filterParts;
    }

    public function indexProject(int $projectId): void
    {
        $project = \App\Domains\Showcase\Models\ShowcaseProject::with(['category', 'tags', 'author'])->find($projectId);

        $this->index->addDocuments([[
            'id' => $project->id,
            'title' => $project->title,
            'description' => $project->description,
            'category' => $project->category?->name,
            'tags' => $project->tags->pluck('name')->all(),
            'author_id' => $project->author_id,
            'author_name' => $project->author_name,
            'likes_count' => $project->likes_count,
            'views_count' => $project->views_count,
            'moderation_status' => $project->moderation_status,
            'created_at' => $project->created_at->timestamp,
        ]]);
    }

    public function removeProject(int $projectId): void
    {
        $this->index->deleteDocument($projectId);
    }
}

final readonly class SearchResult
{
    public function __construct(
        public array $hits,
        public int $totalHits,
        public int $processingTimeMs,
        public string $query,
    ) {}
}
```

```php
final class ShowcaseGuidelinesService

    private const REQUIREMENTS = [
        'title' => [
            'min_length' => 5,
            'max_length' => 100,
            'required' => true,
        ],
        'description' => [
            'min_length' => 50,
            'max_length' => 2000,

        ],
        'url' => [
            'required' => true,
            'valid_url' => true,
        ],
        'screenshots' => [

            'max_count' => 10,
            'required' => true,

            'required' => true,
            'allowed_values' => ['application', 'library', 'tool', 'documentation', 'other'],
        ],
    ];

    /** @return array<string, array> */
    public function requirements(): array
    {
        return self::REQUIREMENTS;
    }

    public function validate(array $data): array
    {
        $errors = [];

        foreach (self::REQUIREMENTS as $field => $rules) {
            if ($rules['required'] && empty($data[$field])) {
                $errors[$field] = "{$field} is required.";
                continue;
            }

            if (isset($data[$field]) && isset($rules['min_length']) && strlen($data[$field]) < $rules['min_length']) {
                $errors[$field] = "{$field} must be at least {$rules['min_length']} characters.";
            }

            if (isset($data[$field]) && isset($rules['max_length']) && strlen($data[$field]) > $rules['max_length']) {
                $errors[$field] = "{$field} must not exceed {$rules['max_length']} characters.";
            }

            if (isset($data[$field]) && ($rules['valid_url'] ?? false) && ! filter_var($data[$field], FILTER_VALIDATE_URL)) {
                $errors[$field] = "{$field} must be a valid URL.";
            }
        }

        return $errors;
    }

    public function submissionChecklist(): array
    {
        return [
            'Project has a descriptive title',

            'Working demo URL is provided',
```

# 29. Showcase Featured Rotation Service

### 29.1 Featured Selection Algorithm

```php
namespace App\Domains\Showcase\Services;

final class ShowcaseFeaturedRotationService
{
    public function __construct(
        private readonly CurationService $curation,
    ) {}

    public function autoFeature(int $count = 6): array
    {
        $candidates = \App\Domains\Showcase\Models\ShowcaseProject::where('status', 'approved')
            ->where('is_featured', false)
            ->where('approved_at', '>=', now()->subDays(30))
            ->with('author')
            ->get();

        $scored = $candidates->map(fn ($project) => [
            'project' => $project,
            'score' => $this->scoreCandidate($project),
        ])->sortByDesc('score')->take($count);

        $featured = [];
        foreach ($scored as $item) {
            $item['project']->update(['is_featured' => true, 'featured_at' => now()]);
            $featured[] = $item['project'];
        }

        return $featured;
    }

    public function rotate(): void
    {
        // Remove featured status from projects featured > 14 days ago
        \App\Domains\Showcase\Models\ShowcaseProject::where('is_featured', true)
            ->where('featured_at', '<', now()->subDays(14))
            ->update(['is_featured' => false, 'featured_at' => null]);

        // Auto-feature new candidates
        $this->autoFeature(3);
    }

    private function scoreCandidate($project): float
    {
        $score = 0;

        // Recency bonus
        $daysSinceApproval = now()->diffInDays($project->approved_at);
        $score += max(0, 30 - $daysSinceApproval);

        // View count bonus
        $score += min(20, $project->views_count / 10);

        // Like ratio
        $totalEngagement = $project->likes_count + $project->bookmarks_count + $project->comments_count;
        $score += min(15, $totalEngagement * 2);

        // Has screenshot bonus
        if ($project->screenshots()->count() >= 1) $score += 10;

        // Has demo URL
        if (! empty($project->demo_url)) $score += 5;

        // Author reputation
        if ($project->author) {
            $authorProjects = \App\Domains\Showcase\Models\ShowcaseProject::where('user_id', $project->author->id)
                ->where('status', 'approved')
                ->count();
            $score += min(10, $authorProjects * 2);
        }

        return $score;
    }
}
```

```php
            $query->where('created_at', '>=', $this->periodStart($period));

            ->map(fn ($project) => [

            ->take($limit)
            ->values()
            ->toArray();

    {
        $projects = $user->projects_count ?? 0;

    }

            + ($project->views_count * 0.1)
            + ($project->bookmarks_count * 2)
            + ($project->comments_count * 1.5)
            + ($recencyFactor * 20);
    }

        return match ($period) {
            'week' => now()->subWeek(),
            'month' => now()->subMonth(),
            'year' => now()->subYear(),
            default => now()->subYears(10),
        };
```

```php
namespace App\Domains\Showcase\Services;

final class ShowcaseTrendingService
{
    public function trending(int $limit = 10): array
    {
        $projects = \App\Domains\Showcase\Models\ShowcaseProject::where('status', 'approved')
            ->where('created_at', '>=', now()->subDays(14))
            ->with('author')
            ->get();

        $scored = $projects->map(function ($project) {
            return [
                'project' => $project,
                'trending_score' => $this->calculateTrendingScore($project),
            ];
        })->sortByDesc('trending_score');

        return $scored->take($limit)->values()->toArray();
    }

    private function calculateTrendingScore($project): float
    {
        $ageHours = max(1, now()->diffInHours($project->created_at));

        $likesPerHour = $project->likes_count / $ageHours;
        $viewsPerHour = $project->views_count / $ageHours;
        $commentsPerHour = $project->comments_count / $ageHours;
        $bookmarksPerHour = $project->bookmarks_count / $ageHours;

        $velocityScore = ($likesPerHour * 10)
            + ($viewsPerHour * 1)
            + ($commentsPerHour * 5)
            + ($bookmarksPerHour * 3);

        $recencyMultiplier = max(0.1, 1 - ($ageHours / 336)); // 14 days = 336 hours

        $baseScore = $project->likes_count * 3
            + $project->views_count * 0.5
            + $project->comments_count * 2
            + $project->bookmarks_count * 1.5;

        return ($velocityScore * 5 * $recencyMultiplier) + ($baseScore * 0.3);
    }

    public function refreshTrending(): void
    {
        cache()->tags(['showcase:trending'])->put(
            'daily',
            $this->trending(20),
            now()->addHours(6)
        );
    }
}
```

```php
    {
        $response = ['success' => true];
```

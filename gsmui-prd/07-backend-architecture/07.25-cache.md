# 07.25 - Cache

**Project:** GsmUi
**Architecture:** Redis Cache Layer
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.12-cache.md` for the conceptual cache strategy, key conventions, TTL policy, and invalidation triggers. This document specifies the **implementation contract** — the concrete Redis store configuration, cache-tag taxonomy, the repository cache-decorator pattern, and the event-driven invalidation mechanics that realize that strategy.

Caching in GsmUi is an optimization layer only; the database remains the source of truth. The application must remain fully functional when Redis is unavailable — cache misses degrade to database reads, never to errors. Repositories own the cache-decorator boundary: read-heavy methods are wrapped so callers (Services, Livewire, API resources) never decide caching themselves. Invalidation is event-driven: domain events (`05.10-events.md`) trigger tag flushes, keeping caches consistent without scattered `forget()` calls.

This document covers store setup, the decorator implementation, tag-based grouped invalidation, TTL resolution, and the resilience/fallback rules.

---

# 1. Store Configuration

The primary cache store is Redis. Local/test environments may fall back to `array` or `file`. Configuration lives in `config/cache.php` and is driven by `.env`.

```php
// config/cache.php (excerpt)
'default' => env('CACHE_DRIVER', 'redis'),

'stores' => [
    'redis' => [
        'driver'     => 'redis',
        'connection' => 'cache',          // dedicated Redis DB, not the session/queue DB
        'lock_connection' => 'default',
    ],
    'array' => [
        'driver' => 'array',
        'serialize' => false,
    ],
],
```

```env
CACHE_DRIVER=redis
REDIS_CACHE_DB=1
REDIS_HOST=redis
REDIS_PASSWORD=null
REDIS_PORT=6379
```

> Use a **dedicated Redis database** for cache (`REDIS_CACHE_DB=1`) separate from sessions and queues, so that a `flushdb` during debugging never wipes session state. See `05.12-cache.md` §Cache Storage.

# 2. Cache Key & Tag Taxonomy

Keys follow the `gsmui:{domain}:{resource}:{identifier}` convention from `05.12-cache.md`. Tags group keys for bulk invalidation.

```php
final class CacheKeys
{
    public const string COMPONENTS = 'gsmui:components:list';
    public const string COMPONENT  = 'gsmui:components:%d';   // sprintf with id
    public const string THEMES     = 'gsmui:themes:list';
    public const string DOCS_NAV   = 'gsmui:docs:%s:nav';    // sprintf with version

    public static function component(int $id): string
    {
        return sprintf(self::COMPONENT, $id);
    }
}

final class CacheTags
{
    public const string COMPONENTS = 'components';
    public const string THEMES     = 'themes';
    public const string DOCS       = 'documentation';
    public const string MARKETPLACE = 'marketplace';
    public const string BLOG       = 'blog';
}
```

# 3. Repository Cache-Decorator

Repositories expose a clean interface (`07.07-repository-layer.md`). Caching is added by **decorating** the repository, never by embedding `Cache::remember` inside the Eloquent implementation. This keeps the base repository testable against a real DB and lets caching be toggled per environment.

```php
namespace App\Domains\Components\Repositories\Cache;

use App\Domains\Components\Repositories\Contracts\ComponentRepositoryInterface;
use Illuminate\Cache\Repository as Cache;
use Illuminate\Contracts\Pagination\LengthAwarePaginator;

final class CachedComponentRepository implements ComponentRepositoryInterface
{
    public function __construct(
        private ComponentRepositoryInterface $repository,
        private Cache $cache,
    ) {}

    public function findOrFail(int $id): \App\Models\Component
    {
        return $this->cache->tags(CacheTags::COMPONENTS)->remember(
            CacheKeys::component($id),
            now()->addHour(),
            fn () => $this->repository->findOrFail($id),
        );
    }

    public function bySlug(string $slug): ?\App\Models\Component
    {
        return $this->cache->tags(CacheTags::COMPONENTS)->remember(
            "gsmui:components:slug:{$slug}",
            now()->addHour(),
            fn () => $this->repository->bySlug($slug),
        );
    }

    public function paginatePublished(int $perPage = 15): LengthAwarePaginator
    {
        // List endpoints use a short TTL and a versioned key so invalidation is cheap.
        return $this->cache->tags(CacheTags::COMPONENTS)->remember(
            "gsmui:components:published:{$perPage}",
            now()->addMinutes(30),
            fn () => $this->repository->paginatePublished($perPage),
        );
    }

    // Writes bypass the cache and delegate directly; invalidation handled by listener.
    public function create(array $attributes): \App\Models\Component
    {
        return $this->repository->create($attributes);
    }

    public function update(\App\Models\Component $component, array $attributes): \App\Models\Component
    {
        return $this->repository->update($component, $attributes);
    }

    public function delete(\App\Models\Component $component): void
    {
        $this->repository->delete($component);
    }
}
```

Binding (per-domain service provider, see `07.07-repository-layer.md` §8):

```php
public function register(): void
{
    $this->app->bind(ComponentRepositoryInterface::class, function ($app) {
        $base = $app->make(Eloquent\ComponentRepository::class);

        if (config('cache.default') === 'redis') {
            return new CachedComponentRepository($base, $app->make('cache.store'));
        }

        return $base; // no caching in array/file dev mode
    });
}
```

# 4. Invalidation Strategy

Writes do **not** call `forget()` inline. Instead, domain events (`07.12-events.md`) are consumed by a synchronous listener that flushes the relevant tag. This centralizes invalidation and survives multiple write paths (API, admin, marketplace).

```php
// app/Domains/Components/Listeners/InvalidateComponentCache.php
namespace App\Domains\Components\Listeners;

use App\Domains\Components\Events\ComponentPublished;
use App\Domains\Components\Events\ComponentUpdated;
use App\Domains\Components\Events\ComponentDeleted;
use Illuminate\Cache\Repository as Cache;
use Illuminate\Contracts\Queue\ShouldQueue;

final class InvalidateComponentCache // synchronous on purpose: must run even on rollback-free writes
{
    public function __construct(private Cache $cache) {}

    public function handle(ComponentPublished|ComponentUpdated|ComponentDeleted $event): void
    {
        $this->cache->tags(CacheTags::COMPONENTS)->flush();
    }
}
```

Tag-flush mapping (excerpt from `05.12-cache.md` §Cache Invalidation):

| Event | Tag flushed | Warming |
| --- | --- | --- |
| `ComponentPublished`, `ComponentUpdated`, `ComponentDeleted` | `components` | warm `gsmui:components:list` |
| `ThemePublished`, `ThemeGenerated` | `themes` | warm `gsmui:themes:list` |
| `DocumentationReleased` | `documentation` | warm `gsmui:docs:v1:nav` |

> Do **not** cache writes, auth state, permissions, CSRF tokens, or in-progress orders — see `05.12-cache.md` §Do NOT Cache.

# 5. TTL Resolution

TTLs are resolved from a central policy so they can be tuned without touching call sites. Defaults match `05.12-cache.md` §TTL Policy.

```php
final class CacheTtl
{
    public const array DEFAULTS = [
        CacheTags::COMPONENTS  => 3600,   // 1 hour
        CacheTags::THEMES      => 21600,  // 6 hours
        CacheTags::DOCS        => 86400,  // 24 hours
        CacheTags::MARKETPLACE => 1800,   // 30 minutes
        CacheTags::BLOG        => 3600,   // 1 hour
    ];

    public static function for(string $tag): int
    {
        return self::DEFAULTS[$tag] ?? 300;
    }
}
```

# 6. Locks for Critical Workflows

Critical single-flight workflows use Redis locks (see `05.12-cache.md` §Locks) to prevent duplicate generation (theme build, license generation, reindex).

```php
use Illuminate\Support\Facades\Cache;

$lock = Cache::lock("theme:generate:{$themeId}", 30);

try {
    if (! $lock->get()) {
        return; // another worker is generating
    }
    // ... generate theme assets
} finally {
    $lock->release();
}
```

# 7. Resilience & Fallback

| Scenario | Behavior |
| --- | --- |
| Redis unavailable | `Cache::remember` throws `ConnectionException`; catch at decorator and call `$this->repository` directly |
| Cache miss | Degrade to DB read, repopulate on next call |
| Tag flush failure | Log + continue; stale keys expire via TTL |

```php
public function findOrFail(int $id): \App\Models\Component
{
    try {
        return $this->cache->tags(CacheTags::COMPONENTS)
            ->remember(CacheKeys::component($id), now()->addHour(),
                fn () => $this->repository->findOrFail($id));
    } catch (\Throwable $e) {
        report($e);                 // Redis down — degrade gracefully
        return $this->repository->findOrFail($id);
    }
}
```

The application must remain functional without cache (`05.12-cache.md` §Error Handling).

# 9. Cache Warming

## 9.1 Cache Warmer Service

```php
<?php

declare(strict_types=1);

namespace App\Domains\Shared\Services;

use App\Domains\Components\Models\Component;
use App\Domains\Themes\Models\Theme;
use App\Domains\Documentation\Models\DocPage;
use Illuminate\Support\Facades\Cache;

final class CacheWarmerService
{
    public function warmComponents(): void
    {
        // Warm the published components list
        $components = Component::where('status', 'published')
            ->orderByDesc('updated_at')
            ->limit(100)
            ->get();

        Cache::tags(CacheTags::COMPONENTS)->remember(
            CacheKeys::COMPONENTS,
            now()->addMinutes(30),
            fn () => $components
        );

        // Warm individual component pages
        foreach ($components as $component) {
            Cache::tags(CacheTags::COMPONENTS)->remember(
                CacheKeys::component($component->id),
                now()->addHour(),
                fn () => $component->load(['user', 'tags', 'media'])
            );
        }
    }

    public function warmThemes(): void
    {
        $themes = Theme::where('status', 'published')
            ->orderByDesc('updated_at')
            ->limit(100)
            ->get();

        Cache::tags(CacheTags::THEMES)->remember(
            CacheKeys::THEMES,
            now()->addMinutes(30),
            fn () => $themes
        );

        foreach ($themes as $theme) {
            Cache::tags(CacheTags::THEMES)->remember(
                "gsmui:themes:{$theme->id}",
                now()->addHour(),
                fn () => $theme->load(['user', 'tags', 'media'])
            );
        }
    }

    public function warmDocs(): void
    {
        $versions = DocPage::distinct()->pluck('version');

        foreach ($versions as $version) {
            $nav = DocPage::where('version', $version)
                ->where('is_draft', false)
                ->orderBy('section')
                ->orderBy('order')
                ->get(['id', 'title', 'slug', 'section', 'order']);

            Cache::tags(CacheTags::DOCS)->remember(
                sprintf(CacheKeys::DOCS_NAV, $version),
                now()->addDay(),
                fn () => $nav
            );
        }
    }

    public function warmAll(): void
    {
        $this->warmComponents();
        $this->warmThemes();
        $this->warmDocs();
    }
}
```

# 10. Cache Decorator Pattern

## 10.1 Repository Cache Decorator

```php
<?php

declare(strict_types=1);

namespace App\Domains\Themes\Repositories\Cache;

use App\Domains\Themes\Models\Theme;
use App\Domains\Themes\Repositories\Contracts\ThemeRepositoryInterface;
use App\Domains\Shared\Services\CacheKeys;
use App\Domains\Shared\Services\CacheTags;
use App\Domains\Shared\Services\CacheTtl;
use Illuminate\Cache\Repository as Cache;
use Illuminate\Contracts\Pagination\LengthAwarePaginator;

final class CachedThemeRepository implements ThemeRepositoryInterface
{
    public function __construct(
        private ThemeRepositoryInterface $repository,
        private Cache $cache,
    ) {}

    public function findOrFail(int $id): Theme
    {
        return $this->cached("theme:{$id}", function () use ($id) {
            return $this->repository->findOrFail($id);
        }, CacheTags::THEMES);
    }

    public function bySlug(string $slug): ?Theme
    {
        return $this->cached("theme:slug:{$slug}", function () use ($slug) {
            return $this->repository->bySlug($slug);
        }, CacheTags::THEMES);
    }

    public function paginatePublished(int $perPage = 15): LengthAwarePaginator
    {
        return $this->cached("themes:published:{$perPage}", function () use ($perPage) {
            return $this->repository->paginatePublished($perPage);
        }, CacheTags::THEMES, 1800);
    }

    public function findByCategory(string $category, int $perPage = 15): LengthAwarePaginator
    {
        return $this->cached("themes:category:{$category}:{$perPage}", function () use ($category, $perPage) {
            return $this->repository->findByCategory($category, $perPage);
        }, CacheTags::THEMES, 1800);
    }

    public function create(array $attributes): Theme
    {
        return $this->repository->create($attributes);
    }

    public function update(Theme $theme, array $attributes): Theme
    {
        return $this->repository->update($theme, $attributes);
    }

    public function delete(Theme $theme): void
    {
        $this->repository->delete($theme);
    }

    private function cached(string $key, callable $callback, string $tag, ?int $ttl = null): mixed
    {
        $ttl = $ttl ?? CacheTtl::for($tag);

        try {
            return $this->cache->tags($tag)->remember(
                "gsmui:{$key}",
                now()->addSeconds($ttl),
                $callback
            );
        } catch (\Throwable $e) {
            report($e);
            return $callback();
        }
    }
}
```

# 12. Cache Lock Service

```php
<?php

declare(strict_types=1);

namespace App\Domains\Shared\Services;

use Illuminate\Support\Facades\Cache;

final class CacheLockService
{
    public function __construct(
        private int $defaultTimeout = 30,
    ) {}

    public function acquire(string $name, ?callable $callback = null): ?bool
    {
        $lock = Cache::lock("gsmui:lock:{$name}", $this->defaultTimeout);

        if (! $lock->get()) {
            return false;
        }

        if ($callback) {
            try {
                $result = $callback();
                $lock->release();
                return $result;
            } catch (\Throwable $e) {
                $lock->release();
                throw $e;
            }
        }

        return true;
    }

    public function release(string $name): void
    {
        Cache::lock("gsmui:lock:{$name}")->forceRelease();
    }

    public function block(string $name, int $seconds, callable $callback): mixed
    {
        return Cache::lock("gsmui:lock:{$name}", $seconds)->block($seconds, $callback);
    }
}
```

Usage:

```php
final class ThemeGenerationService
{
    public function generate(Theme $theme): void
    {
        $lockService = app(CacheLockService::class);

        if (! $lockService->acquire("theme:generate:{$theme->id}")) {
            return; // another worker is generating
        }

        try {
            // ... generate theme assets
        } finally {
            $lockService->release("theme:generate:{$theme->id}");
        }
    }
}
```

# 13. Cache Middleware

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Cache;
use Symfony\Component\HttpFoundation\Response;

final class CacheResponse
{
    public function __construct(
        private int $ttl = 300,
        private ?string $tag = null,
    ) {}

    public function handle(Request $request, Closure $next, ?int $ttl = null, ?string $tag = null): Response
    {
        $ttl = $ttl ?? $this->ttl;
        $tag = $tag ?? $this->tag;

        $cacheKey = $this->buildCacheKey($request);

        if ($cached = Cache::tags([$tag])->get($cacheKey)) {
            return response()->json($cached)->header('X-Cache', 'HIT');
        }

        $response = $next($request);

        if ($response->getStatusCode() === 200 && $request->isMethod('GET')) {
            $data = json_decode($response->getContent(), true);

            Cache::tags([$tag])->remember(
                $cacheKey,
                now()->addSeconds($ttl),
                fn () => $data
            );
        }

        return $response->header('X-Cache', 'MISS');
    }

    private function buildCacheKey(Request $request): string
    {
        return md5($request->fullUrl());
    }
}
```

# 14. Cache Statistics Service

```php
<?php

declare(strict_types=1);

namespace App\Domains\Shared\Services;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\DB;

final class CacheStatisticsService
{
    public function getStats(): array
    {
        return [
            'redis' => $this->getRedisStats(),
            'tags' => $this->getTagStats(),
            'hit_rate' => $this->getHitRate(),
        ];
    }

    private function getRedisStats(): array
    {
        try {
            $redis = Cache::store('redis')->getStore()->getRedis();
            $info = $redis->info('stats');

            return [
                'hits' => $info['keyspace_hits'] ?? 0,
                'misses' => $info['keyspace_misses'] ?? 0,
                'hit_rate' => $this->calculateHitRate(
                    $info['keyspace_hits'] ?? 0,
                    $info['keyspace_misses'] ?? 0
                ),
                'memory_used' => $redis->info('memory')['used_memory_human'] ?? 'N/A',
                'connected_clients' => $redis->info('clients')['connected_clients'] ?? 0,
            ];
        } catch (\Throwable $e) {
            return ['error' => 'Redis unavailable'];
        }
    }

    private function getTagStats(): array
    {
        $tags = [
            CacheTags::COMPONENTS,
            CacheTags::THEMES,
            CacheTags::DOCS,
            CacheTags::MARKETPLACE,
            CacheTags::BLOG,
        ];

        $stats = [];
        foreach ($tags as $tag) {
            $stats[$tag] = [
                'ttl' => CacheTtl::for($tag),
                'key_count' => $this->countKeysByTag($tag),
            ];
        }

        return $stats;
    }

    private function getHitRate(): float
    {
        $stats = $this->getRedisStats();
        return $stats['hit_rate'] ?? 0;
    }

    private function calculateHitRate(int $hits, int $misses): float
    {
        $total = $hits + $misses;
        return $total > 0 ? round(($hits / $total) * 100, 2) : 0;
    }

    private function countKeysByTag(string $tag): int
    {
        try {
            $redis = Cache::store('redis')->getStore()->getRedis();
            $keys = $redis->keys("*:tag:{$tag}:*");
            return count($keys);
        } catch (\Throwable $e) {
            return 0;
        }
    }
}
```

## 15.2 Integration Tests

```php
<?php

declare(strict_types=1);

namespace Tests\Integration\Cache;

use App\Domains\Components\Models\Component;
use App\Domains\Shared\Services\CacheKeys;
use App\Domains\Shared\Services\CacheTags;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Illuminate\Support\Facades\Cache;
use Tests\TestCase;

final class CacheInvalidationTest extends TestCase
{
    use RefreshDatabase;

    public function test_component_update_invalidates_cache(): void
    {
        $component = Component::factory()->published()->create();

        // Populate cache
        Cache::tags(CacheTags::COMPONENTS)->remember(
            CacheKeys::component($component->id),
            now()->addHour(),
            fn () => $component
        );

        $this->assertNotNull(Cache::tags(CacheTags::COMPONENTS)->get(CacheKeys::component($component->id)));

        // Update component triggers event which flushes cache
        $component->update(['name' => 'Updated']);

        // Simulate event listener
        Cache::tags(CacheTags::COMPONENTS)->flush();
```

# 26. Cache Resilience Patterns

## 26.1 Graceful Degradation

```php
trait CacheResilient
{
    protected function cacheRemember(string $tag, string $key, int $ttl, callable $callback): mixed
    {
        try {
            return Cache::tags($tag)->remember($key, $ttl, $callback);
        } catch (\Illuminate\Redis\ConnectionException $e) {
            report($e);
            return $callback();
        } catch (\Predis\PredisException $e) {
            report($e);
            return $callback();
        }
    }

    protected function cacheFlush(string $tag): void
    {
        try {
            Cache::tags($tag)->flush();
        } catch (\Throwable $e) {
            report($e);
        }
    }
}
```

## 26.2 Circuit Breaker

```php
<?php

declare(strict_types=1);

namespace App\Domains\Shared\Services;

use Illuminate\Support\Facades\Cache;

final class CacheCircuitBreaker
{
    private int $failureThreshold = 5;
    private int $recoveryTime = 60;

    public function isOpen(): bool
    {
        $failures = Cache::get('cache:circuit_breaker:failures', 0);
        $lastFailure = Cache::get('cache:circuit_breaker:last_failure');

        if ($failures >= $this->failureThreshold) {
            if ($lastFailure && now()->timestamp - $lastFailure < $this->recoveryTime) {
                return true;
            }
            // Half-open: allow one attempt
            Cache::put('cache:circuit_breaker:failures', $failures - 1, now()->addSeconds($this->recoveryTime));
        }

        return false;
    }

    public function recordFailure(): void
    {
        Cache::increment('cache:circuit_breaker:failures');
        Cache::put('cache:circuit_breaker:last_failure', now()->timestamp, now()->addSeconds($this->recoveryTime));
    }

    public function reset(): void
    {
        Cache::forget('cache:circuit_breaker:failures');
        Cache::forget('cache:circuit_breaker:last_failure');
    }
}
```

```php
    public function isHealthy(): bool
    {
        try {
            $testKey = 'gsmui:health:' . Str::random(8);
            $testValue = Str::random(32);

            Cache::put($testKey, $testValue, 10);

            $retrieved = Cache::get($testKey);

        $healthy = $this->isHealthy();

        $latencyMs = round((microtime(true) - $startTime) * 1000, 2);

        return [
            'status' => $healthy ? 'healthy' : 'degraded',
            'latency_ms' => $latencyMs,
            'driver' => config('cache.default'),
            'timestamp' => now()->toIso8601String(),
```

# 41. Cache Best Practices

1. **Never cache writes, auth state, permissions, CSRF tokens, or in-progress orders.**
2. **Always use tags for grouped invalidation** — never key-based deletion for lists.
3. **TTLs must be short enough to avoid stale data** but long enough to reduce DB load.
4. **Cache misses must degrade to DB reads**, never to errors.
5. **Use distributed locks for critical single-flight workflows** (theme generation, license creation).
6. **Warm caches after invalidation** to avoid cold-start stampedes.
7. **Monitor Redis memory** in production — tag-based caching can grow unbounded.
8. **Use a dedicated Redis DB for cache** separate from sessions and queues.
9. **Test cache behavior in CI** with array driver and Redis integration tests.
10. **Document all cache keys and invalidation rules** for team visibility.

# 07.34 - Template Engine

**Project:** GsmUi
**Architecture:** Template Compilation + Asset Pipeline
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

> See also: `05.29-template-engine.md` for the conceptual template architecture, and `06.40-templates.md` (`templates`, `template_assets`) + `06.41-template-assets.md` for the persistence schema. This document specifies the **implementation contract** — the `TemplateRenderer` service, the template-compilation and asset-pipeline steps, and DI binding. It does NOT re-spec the schema.

Templates are pre-built, multi-component page/layout scaffolds (landing pages, dashboards, admin screens) composed from registered GsmUi components (`07.33-component-engine.md`). The Template Engine compiles a template's block tree into a rendered Blade/Livewire page, resolves and bundles its asset references through the asset pipeline, and applies the active theme (`07.32-theme-engine.md`). Templates are distributed through the Marketplace (`07.31-marketplace.md`) as a `templates` product type.

The goals of this contract are:

- Expose one `TemplateRenderer` that turns a `Template` + context into rendered HTML.
- Compile a template's block tree by delegating each block to `ComponentRenderer` (`07.33`).
- Resolve and version assets (CSS/JS/media) through an `AssetPipeline` without blocking requests.
- Keep compilation pure; persistence and cache invalidation live in the calling action/job.
- Apply theme tokens at render time so a template re-themes without recompilation.

## 2. The `TemplateRenderer` Contract

`TemplateRenderer` compiles a template's block tree into HTML. It depends on `ComponentRenderer` (`07.33`) for each block and `AssetPipeline` for asset resolution.

```php
namespace App\Domains\Templates\Contracts;

use App\Domains\Templates\Data\RenderedTemplate;
use App\Domains\Templates\Data\TemplateContext;
use App\Domains\Templates\Models\Template;

interface TemplateRenderer
{
    /**
     * Compile a template into rendered HTML for the given context
     * (theme id, locale, preview flags). Pure: returns RenderedTemplate.
     */
    public function render(Template $template, TemplateContext $context): RenderedTemplate;

    /** Render a single block node (delegates to ComponentRenderer). */
    public function renderBlock(array $block): string;
}
```

---

## 3. The `AssetPipeline` Contract

`AssetPipeline` resolves a template's asset references, versions them, and returns the URLs to inject. Asset compilation (bundling/minification) runs in the queued `CompileTemplateAssets` job.

```php
namespace App\Domains\Templates\Contracts;

interface AssetPipeline
{
    /** Resolve asset references → versioned, cache-busted URLs. */
    public function resolve(Template $template): array;

    /** Queue bundling/minification of a template's assets. */
    public function compile(Template $template): void;
}
```

## 4. Example Service: Template Renderer Manager

The manager walks the template's block tree, renders each block via the Component Engine, collects assets through the pipeline, and returns a `RenderedTemplate`. Theme tokens are injected by the theme view composer (`07.32`).

```php
namespace App\Domains\Templates\Services;

use App\Domains\Components\Contracts\ComponentRenderer;
use App\Domains\Templates\Contracts\{TemplateRenderer, AssetPipeline};
use App\Domains\Templates\Data\RenderedTemplate;
use App\Domains\Templates\Data\TemplateContext;
use App\Domains\Templates\Models\Template;
use App\Domains\Templates\Support\BlockCompiler;

final class TemplateRendererManager implements TemplateRenderer
{
    public function __construct(
        private ComponentRenderer $components,
        private AssetPipeline $assets,
        private BlockCompiler $blocks,
    ) {}

    public function render(Template $template, TemplateContext $context): RenderedTemplate
    {
        $html = '';
        foreach ($this->blocks->tree($template) as $block) {
            $html .= $this->renderBlock($block);
        }

        return new RenderedTemplate(
            html: $html,
            assets: $this->assets->resolve($template),
            themeId: $context->themeId,
        );
    }

    public function renderBlock(array $block): string
    {
        // Each block declares a component name + props; delegate to the
        // Component Engine rather than rendering Blade directly.
        return $this->components
            ->renderNamed($block['component'], $block['props'] ?? [])
            ->html;
    }
}
```

## 5. Compilation Pipeline (Async)

Asset bundling/minification and the published `compiled_html` snapshot run in a queued job so publish never blocks. The action opens the transaction; the job produces artifacts on `templates` (`06.40-templates.md`).

```text
PublishTemplateAction::run(template)
        │  DB::transaction
        ├─ set status = published
        ├─ dispatchAfterCommit(TemplatePublished)
        ▼
CompileTemplateAssets job
        │
        ├─ app(AssetPipeline::class)->compile(template)
        ├─ app(TemplateRenderer::class)->render(template, context)
        ├─ persist compiled_html + asset manifest
        └─ cache rendered template
```

---

## 6. Theme Re-application

Because theme tokens are injected at render time, switching a template's theme does not require recompilation of the block tree — only a fresh `render()` with a different `TemplateContext.themeId`. The cached `compiled_html` is invalidated when the template or its theme changes.

```php
$rendered = app(TemplateRenderer::class)->render($template, new TemplateContext(
    themeId: $request->theme_id,
    preview: true,
));
```

## 8. Reuse Rules

A template service MAY:

- Compile block trees by delegating to `ComponentRenderer` (`07.33`).
- Resolve/version assets via `AssetPipeline`; cache rendered output.
- Apply the active theme at render time via the theme composer (`07.32`).

A template service MUST NOT:

- Re-implement component rendering (always delegate to `07.33`).
- Hard-code theme values (use `--gsm-*` tokens).
- Execute arbitrary user Blade (that is the playground sandbox, `07.36`).

| Concern | Owner |
| --- | --- |
| Per-block render | `ComponentRenderer` (`07.33`) |
| Theme tokens | `ThemeCompiler` (`07.32`) |
| Distribution | Marketplace `templates` type (`07.31`) |
| Live editing | Playground (`07.36`) |

# 11. Template Inheritance

## 11.1 Layout Inheritance

Templates can extend parent layouts, inheriting their structure and overriding specific blocks.

```php
final class TemplateInheritanceResolver
{
    public function resolve(Template $template): Template
    {
        if (!$template->parent_id) {
            return $template;
        }

        $parent = Template::findOrFail($template->parent_id);

        // Merge parent blocks with child overrides
        $parentBlocks = $this->getBlockTree($parent);
        $childBlocks = $this->getBlockTree($template);

        $mergedBlocks = $this->mergeBlocks($parentBlocks, $childBlocks);

        $template->setBlockTree($mergedBlocks);

        return $template;
    }

    private function mergeBlocks(array $parent, array $child): array
    {
        $merged = $parent;

        foreach ($child as $key => $block) {
            if (isset($merged[$key]) && $block['type'] === $merged[$key]['type']) {
                // Same block type — merge props
                $merged[$key]['props'] = array_merge($merged[$key]['props'], $block['props']);
            } else {
                // New or different block — add/replace
                $merged[$key] = $block;
            }
        }

        return $merged;
    }
}
```

## 11.2 Template Slots

Templates define named slots that child templates can override.

```php
final class TemplateSlotManager
```

## 12.2 Asset Processing Pipeline

```php
final class AssetProcessor
{
    public function process(string $content, string $type): string
    {
        return match ($type) {
            'css' => $this->processCss($content),
            'js' => $this->processJs($content),
            'image' => $this->processImage($content),
            'svg' => $this->processSvg($content),
            default => $content,
        };
    }

    private function processCss(string $css): string
    {
        // Minify
        $css = (new CssMinifier())->minify($css);

        // Autoprefix
        $css = (new Autoprefixer())->process($css);

        return $css;
    }

    private function processJs(string $js): string
    {
        // Minify
        $js = (new JavaScriptMinifier())->minify($js);

        // Bundle dependencies
        $js = (new JavaScriptBundler())->bundle($js);

        return $js;
    }
}
```

## 12.3 Asset Versioning

```php
final class AssetVersioner
{
    public function version(string $path): string
    {
        $hash = md5_file(storage_path("app/public/{$path}"));

        return "{$path}?v={$hash}";
    }

    public function manifest(Template $template): array
    {
        $assets = $template->assets;

        return array_map(function ($asset) {
            return [
                'original' => $asset['path'],
                'versioned' => $this->version($asset['path']),
                'size' => $asset['size'],
                'type' => $asset['type'],
            ];
        }, $assets);
    }
}
```

# 13. Template Compilation Deep Dive

## 13.1 Compilation Steps

```text
Template compilation pipeline:
1. Parse template JSON (block tree + metadata)
2. Resolve inheritance chain
3. Merge blocks from parent templates
4. Validate block schemas
5. Resolve component references
6. Compile each block via ComponentRenderer
7. Assemble rendered blocks into page HTML
8. Resolve and inject assets
9. Apply theme tokens
10. Cache compiled output
```

## 13.2 Block Tree Walker

```php
final class BlockTreeWalker
{
    public function walk(array $blocks, callable $visitor): array
    {
        $result = [];

        foreach ($blocks as $key => $block) {
            $visited = $visitor($block, $key);

            if ($visited !== null) {
                $result[$key] = $visited;
            }

            // Recurse into nested blocks
            if (isset($block['children'])) {
                $result[$key]['children'] = $this->walk($block['children'], $visitor);
            }
        }

        return $result;
    }
}
```

## 13.3 Compiled Template Cache

```php
final class TemplateCacheManager
{
    public function get(string $templateId, string $themeId): ?string
    {
        return Cache::get("template:compiled:{$templateId}:{$themeId}");
    }

    public function set(string $templateId, string $themeId, string $html): void
    {
        Cache::put(
            "template:compiled:{$templateId}:{$themeId}",
            $html,
            now()->addMinutes(config('templates.cache_ttl', 60))
        );
    }

    public function invalidate(string $templateId): void
    {
        $keys = Cache::tags(["template:{$templateId}"])->getKeys();
        Cache::tags(["template:{$templateId}"])->flush();
    }

    public function invalidateAll(): void
    {
        Cache::tags(['templates'])->flush();
    }
}
```

# 17. Template Livewire Components

## 17.1 Template Editor

```php
// app/Livewire/TemplateEditor.php
final class TemplateEditor extends Component
{
    public ?Template $template = null;
    public array $blockTree = [];
    public ?string $selectedBlock = null;
    public bool $isDirty = false;

    public function mount(?int $templateId = null): void
    {
        if ($templateId) {
            $this->template = Template::find($templateId);
            $this->blockTree = $this->template->block_tree;
        } else {
            $this->template = null;
            $this->blockTree = $this->getDefaultBlockTree();
        }
    }

    public function addBlock(string $type, int $position): void
    {
        $block = $this->createBlock($type);
        array_splice($this->blockTree, $position, 0, [$block]);
        $this->isDirty = true;
    }

    public function removeBlock(string $blockId): void
    {
        $this->blockTree = $this->removeBlockById($this->blockTree, $blockId);
        $this->isDirty = true;
    }

    public function moveBlock(string $blockId, int $newPosition): void
    {
        $block = $this->findBlockById($this->blockTree, $blockId);
        $this->blockTree = $this->removeBlockById($this->blockTree, $blockId);
        array_splice($this->blockTree, $newPosition, 0, [$block]);
        $this->isDirty = true;
    }

    public function updateBlockProps(string $blockId, array $props): void
    {
        $this->updateBlockById($this->blockTree, $blockId, $props);
        $this->isDirty = true;
    }

    public function save(): void
    {
        if (!$this->template) {
            $this->template = Template::create([
                'author_id' => auth()->id(),
                'name' => 'Untitled Template',
                'slug' => Str::slug('Untitled Template'),
                'type' => 'landing',
                'block_tree' => $this->blockTree,
                'status' => 'draft',
            ]);
        } else {
            $this->template->update(['block_tree' => $this->blockTree]);
        }

        $this->isDirty = false;

        // Trigger compilation
        CompileTemplateAssets::dispatch($this->template);

        $this->dispatch('template-saved', templateId: $this->template->id);
    }

    public function render(): View
    {
        return view('livewire.template-editor', [
            'blockTypes' => BlockSchema::SCHEMA,
            'preview' => $this->getPreview(),
        ]);
    }
}
```

```php
final class TemplateCommands extends Command
{
    protected $signature = 'gsmui:template {action} {name?}';
    protected $description = 'Manage GsmUi templates';

    public function handle(): int
    {
        return match ($this->argument('action')) {
            'list' => $this->list(),
            'info' => $this->info(),
            'compile' => $this->compile(),
            'preview' => $this->preview(),
            'export' => $this->export(),
            default => $this->error('Unknown action'),
        };
    }

    private function list(): int
    {
        $templates = Template::with('author')->get();

        $this->table(
            ['Name', 'Type', 'Status', 'Author'],
            $templates->map(fn ($t) => [
                $t->name, $t->type, $t->status, $t->author->name,
            ])
        );

        return self::SUCCESS;
    }

    private function compile(): int
    {
        $name = $this->argument('name');
        $template = Template::where('slug', $name)->firstOrFail();

        $compiled = app(TemplateRenderer::class)->render($template, new TemplateContext(
            themeId: Theme::where('is_active', true)->first()?->id,
        ));

        Storage::disk('local')->put(
            "templates/compiled/{$template->slug}.html",
            $compiled->html
        );

        $this->info("Template '{$template->slug}' compiled successfully.");
        return self::SUCCESS;
    }

    private function export(): int
    {
        $name = $this->argument('name');
        $template = Template::where('slug', $name)->firstOrFail();

        $export = app(TemplateExportService::class)->export($template, 'zip');

        $path = storage_path("app/exports/{$template->slug}.zip");
        file_put_contents($path, $export);

        $this->info("Template exported to: {$path}");
        return self::SUCCESS;
    }
```

```php
final class BlockValidator
{
    public function validate(array $blockTree): ValidationResult
    {
        $errors = [];

        foreach ($blockTree as $block) {
            // Validate block type
            if (!isset(BlockSchema::SCHEMA[$block['type']])) {
                $errors[] = "Unknown block type: {$block['type']}";
                continue;
            }

            // Validate required props
            $schema = BlockSchema::SCHEMA[$block['type']];
            foreach ($schema['required'] as $prop) {
                if (!isset($block['props'][$prop])) {
                    $errors[] = "Missing required prop '{$prop}' for block type '{$block['type']}'";
                }
            }

            // Validate nested blocks
            if (isset($block['children'])) {
                $nestedResult = $this->validate($block['children']);
                $errors = array_merge($errors, $nestedResult->errors);
            }
        }

        return new ValidationResult(
            valid: empty($errors),
            errors: $errors
        );
    }
}
```

```php
final class TemplateTranslationService
{
    public function translate(Template $template, string $locale): Template
    {
        $translations = TemplateTranslation::where('template_id', $template->id)
            ->where('locale', $locale)
            ->first();

        if (!$translations) {
            return $template;
        }

        // Apply translations to block tree
        $blockTree = $this->applyTranslations($template->block_tree, $translations->data);

        $clone = $template->replicate();
        $clone->block_tree = $blockTree;

        return $clone;
    }

    private function applyTranslations(array $blockTree, array $translations): array
    {
        foreach ($blockTree as &$block) {
            if (isset($translations[$block['id']])) {
                $block['props'] = array_merge(
                    $block['props'],
                    $translations[$block['id']]
                );
            }

            if (isset($block['children'])) {
                $block['children'] = $this->applyTranslations($block['children'], $translations);
            }
        }

        return $blockTree;
    }
}
```

## 38.2 Asset Compiler

```php
final class TemplateAssetCompiler
{
    public function compile(string $templateId): array
    {
        $template = Template::find($templateId);

        if (!$template) {
            throw new \InvalidArgumentException("Template {$templateId} not found");
        }

        $assets = [
            'css' => $this->compileCss($template),
            'js' => $this->compileJs($template),
            'svg' => $this->compileSvg($template),
        ];

        // Hash for cache busting
        $hash = md5(serialize($assets));

        // Store compiled assets
        $this->storeCompiled($templateId, $assets, $hash);

        return [
            'css_url' => "/assets/templates/{$templateId}/{$hash}.css",
            'js_url' => "/assets/templates/{$templateId}/{$hash}.js",
            'svg_url' => "/assets/templates/{$templateId}/{$hash}.svg",
            'hash' => $hash,
        ];
    }

    private function compileCss(Template $template): string
    {
        $css = '';

        // Include base styles
        $css .= $this->getBaseStyles();

        // Include template-specific styles
        $css .= $template->css ?? '';

        // Include block styles
        foreach ($template->blocks as $block) {
            $css .= $block->css ?? '';
        }

        return $css;
    }

    private function compileJs(Template $template): string
    {
        $js = '';

        // Include base scripts
        $js .= $this->getBaseScripts();

        // Include template-specific scripts
        $js .= $template->js ?? '';

        // Include block scripts
        foreach ($template->blocks as $block) {
            $js .= $block->js ?? '';
        }

        return $js;
    }
}
```

```php
final class TemplateContentSanitizer
{
    private array $allowedTags = [
        'p', 'br', 'strong', 'em', 'code', 'pre', 'a', 'img',
        'ul', 'ol', 'li', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6',

    {

        return $purifier->purify($html);

    public function sanitizeSvg(string $svg): string
    {

        $svg = preg_replace('/<script\b[^>]*(?:\/>|<\/script>)/is', '', $svg);

        // Remove event handlers
        $svg = preg_replace('/\son\w+\s*=\s*["\'][^"\']*["\']/i', '', $svg);

        // Remove javascript: URLs
        $svg = preg_replace('/href\s*=\s*["\']javascript:[^"\']*["\']/i', '', $svg);

        // Remove data: URLs (except images)
        $svg = preg_replace('/(?:href|src)\s*=\s*["\']data:(?!image)[^"\']*["\']/i', '', $svg);

        return $svg;
    }

        $config = \HTMLPurifier_Config::createDefault();

        $config->set('AutoFormat.RemoveEmpty', true);

        return $config;
    }
}
```

**Project:** GsmUi

# Purpose

Email is a primary channel for transactional and marketing communication in GsmUi — subscription confirmations, invoices, password resets, product updates, and welcome emails. This document specifies the *implementation contract*: concrete `Mailable` classes, Markdown-based mailables for consistent theming, queueing discipline, and the preview/testing approach. Mailables are produced by the `mail` notification channel (`07.27-notifications.md`) and by direct dispatches from Services/Actions (`07.06-service-layer.md`, `07.08-action-layer.md`).

> See also: `07.27-notifications.md` (mail channel), `07.49-queues.md` (mail queue mapping), `07.54-logging.md` (PII redaction in mail logs).

# 2. Mailable Class Contract

Every mailable is `final`, `implements ShouldQueue` (so sending never blocks a request), and declares its envelope, content, and attachments.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Mail\Mailables;

use App\Domains\Billing\Models\Subscription;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Address;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;

final class SubscriptionRenewed extends Mailable implements ShouldQueue
{
    use Queueable;

    public function __construct(
        public readonly Subscription $subscription,
    ) {}

    public function envelope(): Envelope
    {
        return new Envelope(
            from: new Address('billing@gsmui.dev', 'GsmUi Billing'),
            subject: 'Your subscription has renewed',
        );
    }

    public function content(): Content
    {
        return new Content(
            markdown: 'emails.subscription-renewed',
            with: [
                'plan'   => $this->subscription->plan_name,
                'renewedAt' => $this->subscription->renewed_at,
            ],
        );
    }
}
```

# 4. Queueing Discipline

All mailables implement `ShouldQueue` and run on a dedicated `emails` queue so a mail-provider outage never stalls web requests (`07.49-queues.md`).

```php
// config/queue.php — mail uses its own connection/queue
'emails' => [
    'connection' => 'redis',
    'queue'      => 'emails',
],
```

```php
// Dispatch from a service/action:
Mail::to($user->email)->queue(new SubscriptionRenewed($subscription));

// Or later (scheduled digest) — see 07.50-scheduler.md:
Mail::to($user->email)->later($sendAt, new WeeklyDigest($user));
```

```php
                Subscription::first()

            default => abort(404),
        };

```

Tests use `Mail::fake()` and assert both dispatch and rendered content:

```php
final class SubscriptionRenewedTest extends TestCase
{
    public function test_sends_to_subscriber(): void
    {
        Mail::fake();
        $subscription = Subscription::factory()->create();

        Mail::to($subscription->user->email)
            ->queue(new SubscriptionRenewed($subscription));

        Mail::assertQueued(SubscriptionRenewed::class, function ($mail) use ($subscription) {
            return $mail->hasTo($subscription->user->email)
                && $mail->subscription->is($subscription);
        });
    }

    public function test_renders_markdown(): void
    {
        $mail = new SubscriptionRenewed(Subscription::factory()->create());
        $mail->assertSeeInHtml('renewed');
    }
}
```

## 8.4 Mailable Class Example — InvoiceReady

```php
<?php

declare(strict_types=1);

namespace App\Domains\Mail\Mailables;

use App\Domains\Billing\Models\Invoice;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Address;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;
use Illuminate\Mail\Mailables\Attachment;

final class InvoiceReady extends Mailable implements ShouldQueue
{
    use Queueable;

    public function __construct(
        public readonly Invoice $invoice,
    ) {
        $this->onQueue('emails');
        $this->tries = 3;
        $this->backoff = [30, 120, 600];
    }

    public function envelope(): Envelope
    {
        return new Envelope(
            from: new Address('billing@gsmui.dev', 'GsmUi Billing'),
            subject: "Invoice #{$this->invoice->number} is ready",
            tags: ['billing', 'invoice'],
        );
    }

    public function content(): Content
    {
        return new Content(
            markdown: 'emails.invoice-ready',
            with: [
                'invoiceNumber' => $this->invoice->number,
                'amount' => $this->invoice->formatted_total,
                'currency' => $this->invoice->currency,
                'dueDate' => $this->invoice->due_date?->format('M j, Y'),
                'items' => $this->invoice->line_items,
                'downloadUrl' => route('invoices.download', $this->invoice),
            ],
        );
    }

    public function attachments(): array
    {
        return [
            Attachment::fromContent(
                $this->generatePdf(),
                "invoice-{$this->invoice->number}.pdf"
            )->mime('application/pdf'),
        ];
    }

    private function generatePdf(): string
    {
        return app(PdfGenerator::class)->generate($this->invoice);
    }
}
```

# 10. Attachment Handling

Attachments are managed through Laravel's `Attachment` value objects. GsmUi restricts attachment types and sizes to prevent abuse and ensure compatibility across email clients.

## 10.1 Allowed Attachment Types

| MIME Type | Extension | Max Size | Use Case |
| --- | --- | --- | --- |
| `application/pdf` | `.pdf` | 5 MB | Invoices, receipts |
| `image/png` | `.png` | 2 MB | Report charts, badges |
| `image/jpeg` | `.jpg` | 2 MB | Report charts, badges |
| `text/csv` | `.csv` | 1 MB | Export data |
| `application/zip` | `.zip` | 10 MB | Product bundles |

## 10.2 Attachment Generation

Large attachments (reports, exports) are generated by queued jobs and stored on S3 before being attached to the mailable. The mailable receives a pre-signed URL or disk path.

```php
final class GenerateMonthlyReportJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function handle(): void
    {
        $report = app(ReportService::class)->generateMonthly(
            vendorId: $this->vendorId,
            month: $this->month,
        );

        $path = Storage::disk('s3')->put(
            "reports/{$this->vendorId}/{$this->month}.pdf",
            $report->pdfContent()
        );

        Mail::to($this->vendor->email)
            ->queue(new MonthlyReport($report, $path));
    }
}
```

## 10.3 Virus Scanning

All uploaded attachments pass through a virus scan before being queued. The scan happens in the Action layer (`07.08-action-layer.md`) before the Mailable is dispatched.

```php
final class ScanAttachmentAction
{
    public function execute(string $diskPath): ScanResult
    {
        $scanner = app(VirusScanner::class);

        return $scanner->scan(
            Storage::disk('local')->path($diskPath)
        );
    }
}
```

# 12. Email Rendering Pipeline

## 12.1 Theme Integration

All email templates consume CSS variables from the active theme (`07.32-theme-engine.md`). Email-safe CSS is generated separately from web CSS because email clients have limited CSS support.

```php
final class EmailThemeCompiler
{
    public function compileForEmail(array $tokens): string
    {
        $emailTokens = $this->filterEmailSafeTokens($tokens);

        $css = ':root {';
        foreach ($emailTokens as $path => $value) {
            $var = '--gsm-email-' . str_replace('.', '-', $path);
            $css .= "{$var}: {$value}; ";
        }
        $css .= '}';

        return $this->inlineCss($css); // email clients require inlined CSS
    }

    private function filterEmailSafeTokens(array $tokens): array
    {
        $allowedGroups = ['color', 'radius', 'font', 'spacing'];

        return array_filter(
            $tokens,
            fn ($key) => in_array(explode('.', $key)[0], $allowedGroups),
            ARRAY_FILTER_USE_KEY
        );
    }

    private function function inlineCss(string $css): string
    {
        return app(HtmlInliner::class)->convert($css);
    }
}
```

## 12.2 Dark Mode Support

Email templates include `@media (prefers-color-scheme: dark)` overrides in a `<style>` block. The dark-mode token set is compiled from `mode: dark` tokens.


# 13. Email Deliverability

## 13.1 SPF / DKIM / DMARC Configuration

GsmUi configures email authentication to maximize deliverability and prevent spoofing.

| Record | Value | TTL |
| --- | --- | --- |
| SPF | `v=spf1 include:amazonses.com ~all` | 3600 |
| DKIM | Provided by SES/SendGrid | 3600 |
| DMARC | `v=DMARC1; p=quarantine; rua=mailto:dmarc@gsmui.dev` | 3600 |

## 13.2 Bounce & Complaint Handling

Bounces and complaints are handled by the mail provider's webhook integration. GsmUi processes these webhooks to update user subscription status and suppress future sends.

```php
final class BounceHandler
{
    public function handle(BounceEvent $event): void
    {
        $email = $event->email;
        $type = $event->type; // 'hard' | 'soft'

        if ($type === 'hard') {
            // Suppress permanently
            SuppressedEmail::create([
                'email' => $email,
                'reason' => 'hard_bounce',
                'suppressed_at' => now(),
            ]);

            // Disable user account if primary email bounces
            $user = User::where('email', $email)->first();
            if ($user) {
                $user->update(['email_bounced' => true]);
            }
        }
    }
}
```

```php
final class ClickTracker
{
    public function wrap(string $originalUrl, string $mailId, string $recipientEmail): string
    {
        $token = Str::random(32);

        EmailClick::create([
            'mail_id' => $mailId,

            'clicked_at' => now(),
            'user_agent' => request()->userAgent(),

        return redirect($click->url);
    }
}
```

## 17.2 Batch Sending

Large email batches (newsletter, announcement) use Laravel's `Bus::batch()` for chunked processing and failure tracking.

```php
final class SendBatchMarketingEmail
{
    public function handle(Mailable $mailable, Collection $recipients): void
    {
        $chunks = $recipients->chunk(500);

        $batch = Bus::batch($chunks->map(function ($chunk) use ($mailable) {
            return new SendMarketingEmailBatch($mailable, $chunk);
        }))
        ->then(function (Batch $batch) {
            Log::info("Marketing batch {$batch->id} completed");
        })
        ->catch(function (Batch $batch, Throwable $e) {
            Log::error("Marketing batch {$batch->id} failed: {$e->getMessage()}");
        })
        ->finally(function (Batch $batch) {
            // Update batch statistics
            MarketingBatchStats::create([
                'batch_id' => $batch->id,
                'total' => $batch->totalJobs,
                'completed' => $batch->processedJobs(),
                'failed' => $batch->failedJobs,
            ]);
        })
        ->onConnection('redis')
        ->onQueue('marketing');

        Bus::batch($batch)->dispatch();
    }
}
```

## 17.3 Throttled Sending

Marketing emails are throttled to respect provider rate limits and maintain sender reputation.

```php
final class ThrottledMarketingDispatcher
{
    public function dispatch(Mailable $mailable, Collection $recipients): void
    {
        $recipients->each(function ($recipient) use ($mailable) {
            dispatch(function () use ($mailable, $recipient) {
                Mail::to($recipient)->queue($mailable);
            })->onQueue('marketing')
              ->delay(now()->addSeconds(1)); // 1 email per second per worker
        });
    }
}
```

# 18. Security Considerations

- `List-Unsubscribe` header for marketing emails

# 23. Email Template Versioning

Email templates are versioned alongside the application codebase. Each template version is tracked to ensure that emails already queued continue to render correctly even after a template update.

## 23.1 Version Tracking

```php
// Each mailable declares its template version
final class SubscriptionRenewed extends Mailable implements ShouldQueue
{
    const TEMPLATE_VERSION = '1.2.0';

    public function content(): Content
    {
        return new Content(
            markdown: $this->resolveTemplateVersion('emails.subscription-renewed'),
            with: [/* ... */],
        );
    }

    private function resolveTemplateVersion(string $template): string
    {
        $versioned = "{$template}.v" . str_replace('.', '_', self::TEMPLATE_VERSION);

        return View::exists($versioned) ? $versioned : $template;
    }
}
```

## 23.2 Template Rollback

If a newly deployed template causes rendering issues, the system can roll back to the previous version without redeploying code.

```php
final class RollbackEmailTemplateAction
{
    public function execute(string $templateName, string $targetVersion): void
    {
        $templatePath = resource_path("views/emails/{$templateName}");

        // Copy the old version back to the active path
        $archived = Storage::disk('email-templates')
            ->get("archived/{$templateName}/v{$targetVersion}.blade.php");

        File::put("{$templatePath}.blade.php", $archived);

        // Invalidate any compiled view cache
        Artisan::call('view:clear');
    }
}
```

# 24. Email Queue Health Monitoring

## 24.1 Health Check Command

```php
final class MailQueueHealthCheck extends Command
{
    protected $signature = 'mail:health-check';

    public function handle(): int
    {
        $queues = ['emails', 'marketing', 'digests'];
        $issues = [];

        foreach ($queues as $queue) {
            $depth = Queue::size($queue);
            $failed = $this->getFailedJobCount($queue);
            $avgProcessingTime = $this->getAvgProcessingTime($queue);

            if ($depth > 1000) {
                $issues[] = "Queue '{$queue}' has {$depth} pending jobs";
            }

            if ($failed > 50) {
                $issues[] = "Queue '{$queue}' has {$failed} failed jobs";
            }

            if ($avgProcessingTime > 60) {
                $issues[] = "Queue '{$queue}' avg processing time is {$avgProcessingTime}s";
            }

            $this->info("  {$queue}: depth={$depth}, failed={$failed}, avg_time={$avgProcessingTime}s");
        }

        if (!empty($issues)) {
            $this->error('Mail queue health issues detected:');
            foreach ($issues as $issue) {
                $this->error("  - {$issue}");
            }

            app(AlertService::class)->warning(
                'Mail queue health issues',
                ['issues' => $issues]
            );

            return self::FAILURE;
        }

        $this->info('All mail queues healthy.');
        return self::SUCCESS;
    }
}
```

# 26. Mail Provider Failover

GsmUi supports automatic failover between mail providers when the primary provider is unavailable.

## 26.1 Failover Configuration

```php
// config/mail.php
'failover' => [
    'enabled' => true,
    'providers' => ['ses', 'sendgrid', 'postmark'],
    'health_check_interval' => 60, // seconds
    'circuit_breaker' => [
        'threshold' => 5, // failures before switching
        'reset_timeout' => 300, // seconds before retrying primary
    ],
],
```

## 26.2 Circuit Breaker

```php
final class MailFailoverService
{
    public function send(Mailable $mailable, array $recipients): TransportResult
    {
        $providers = config('mail.failover.providers');

        foreach ($providers as $provider) {
            if ($this->circuitBreaker($provider)->isOpen()) {
                continue; // skip this provider
            }

            try {
                $transport = $this->resolveTransport($provider);
                $result = $transport->send($mailable, $recipients);

                $this->circuitBreaker($provider)->recordSuccess();
                return $result;

            } catch (TransportException $e) {
                $this->circuitBreaker($provider)->recordFailure();
                Log::warning("Mail provider {$provider} failed", [
                    'error' => $e->getMessage(),
                ]);
            }
        }

        // All providers failed — queue for retry
        MailFailedJob::dispatch($mailable, $recipients);
        throw new MailDeliveryException('All mail providers failed');
    }
}
```

# 27. Email Compliance & Legal

## 27.1 CAN-SPAM Compliance

- Identification as an advertisement

## 27.2 GDPR Compliance

- Users can export their email history
- Users can request deletion of all email data

## 27.3 CCPA Compliance

- "Do Not Sell My Personal Information" link in marketing emails
- Email data is included in user data export requests
- Email deletion requests are honored within 30 days

## 27.4 Compliance Monitoring

```php
final class EmailComplianceCheck extends Command
{
    public function handle(): int
    {
        $issues = [];

        // Check unsubscribe link presence
        $marketingTemplates = $this->getMarketingTemplates();
        foreach ($marketingTemplates as $template) {
            $html = $this->renderTemplate($template);
            if (!str_contains($html, 'unsubscribe')) {
                $issues[] = "Template {$template} missing unsubscribe link";
            }
            if (!str_contains($html, 'List-Unsubscribe')) {
                $issues[] = "Template {$template} missing List-Unsubscribe header";
            }
        }

        // Check physical address presence
        foreach ($marketingTemplates as $template) {
            $html = $this->renderTemplate($template);
            if (!str_contains($html, config('company.address'))) {
                $issues[] = "Template {$template} missing physical address";
            }
        }

        if (!empty($issues)) {
            $this->error('Compliance issues found:');
            foreach ($issues as $issue) {
                $this->error("  - {$issue}");
            }
            return self::FAILURE;
        }

        $this->info('All compliance checks passed.');
        return self::SUCCESS;
    }
}
```

# 28. Email Template Asset Management

## 28.1 Inline Images

Email images are base64-encoded inline or uploaded to a CDN with cache-busting hashes. External images are forbidden in production emails to prevent tracking pixels from untrusted sources.

```php
final class EmailImageManager
{
    public function inline(string $imagePath): string
    {
        $contents = Storage::disk('public')->get($imagePath);
        $mimeType = mime_content_type(Storage::disk('public')->path($imagePath));

        return "data:{$mimeType};base64," . base64_encode($contents);
    }

    public function cdnUrl(string $imagePath): string
    {
        $hash = md5(Storage::disk('public')->get($imagePath));

        return config('app.cdn_url') . "/emails/{$imagePath}?v={$hash}";
    }
}
```

## 28.2 Font Handling

Email templates do NOT use custom web fonts because most email clients (especially Outlook and Gmail) do not support them. Templates use system font stacks.

```css
/* Email-safe font stack */
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
```

# 30. Email Performance Optimization

## 30.1 Template Compilation Caching

Compiled Blade templates are cached to avoid re-parsing on every send. The cache is invalidated when templates are updated.

```php
// Cache compiled email templates
Cache::remember(
    "email-template:{$templateName}:{$templateVersion}",
    now()->addHours(24),
    fn () => view($templateName, $data)->render()
);
```

## 30.2 Connection Pooling

For high-volume sends, mail transport connections are pooled to reduce TCP/TLS handshake overhead.

```php
final class PooledSesTransport implements MailTransport
{
    private ?SesClient $client = null;

    public function getClient(): SesClient
    {
        if ($this->client === null) {
            $this->client = new SesClient([
                'region' => config('services.ses.region'),
                'version' => 'latest',
                'credentials' => config('services.ses.credentials'),
            ]);
        }

        return $this->client;
    }
}
```

## 30.3 Batch Insert for Tracking

Email tracking events (opens, clicks) are batched to reduce database writes.

```php
final class TrackingEventBuffer
{
    private array $buffer = [];
    private int $flushThreshold = 100;

    public function record(string $type, string $mailId, string $recipientHash): void
    {
        $this->buffer[] = [
            'type' => $type,
            'mail_id' => $mailId,
            'recipient_hash' => $recipientHash,
            'created_at' => now(),
        ];

        if (count($this->buffer) >= $this->flushThreshold) {
            $this->flush();
        }
    }

    public function flush(): void
    {
        if (empty($this->buffer)) {
            return;
        }

        DB::table('email_tracking_events')->insert($this->buffer);
        $this->buffer = [];
    }
}
```

| --- | --- | --- |

| Database failure | 15 minutes | Restore from latest backup |

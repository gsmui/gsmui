# 07.26 - Storage

**Project:** GsmUi
**Architecture:** Spatie Media Library
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

GsmUi persists user-uploaded and system-generated binary assets — component thumbnails, theme previews, template exports, avatar images, blog covers, and marketplace media — through **Spatie Media Library**. Media Library attaches files to Eloquent models via a polymorphic `media` table and produces derived conversions (resized thumbnails, optimized webp) without bespoke upload controllers.

This document specifies the *implementation contract*: disk configuration (public vs private), the `InteractsWithMedia` model contract, conversion definitions, responsive-image generation, and the access-control rules that decide which disk a file lands on. The conceptual asset flows (CDN, transformations) are intentionally out of scope here — see `05.12-cache.md` for the related static-asset caching notes.

> See also: `07.48-models.md` (model conventions), `07.23-authorization.md` (private media access), `06.110-notifications.md` (no overlap — separate domain).

---

# 1. Disk Configuration

Disks are declared in `config/filesystems.php`. GsmUi uses three logical disks:

- `public` — CDN-backed, world-readable assets (thumbnails, previews, avatars).
- `private` — non-public user uploads and license artifacts, served via a signed stream route.
- `local` — ephemeral processing scratch (not persisted long-term).

```php
// config/filesystems.php (excerpt)
'disks' => [
    'public' => [
        'driver'     => 'local',
        'root'       => storage_path('app/public'),
        'url'        => env('APP_URL') . '/storage',
        'visibility' => 'public',
    ],
    'private' => [
        'driver'     => 'local',
        'root'       => storage_path('app/private'),
        'visibility' => 'private',
    ],
    's3' => [
        'driver' => 's3',
        'key'    => env('AWS_ACCESS_KEY_ID'),
        'secret' => env('AWS_SECRET_ACCESS_KEY'),
        'bucket' => env('AWS_BUCKET'),
        'region' => env('AWS_DEFAULT_REGION'),
        'visibility' => 'public',
    ],
],
```

Media Library's default disk and path generator are configured in `config/media-library.php`:

```php
// config/media-library.php (excerpt)
'disk_name' => env('MEDIA_DISK', 'public'),
'path_generator' => \App\Domains\Media\PathGenerators\DomainPathGenerator::class,
```

# 2. Model Contract (`InteractsWithMedia`)

Any model that owns media implements `Spatie\MediaLibrary\HasMedia` and uses `InteractsWithMedia`. Conversions are declared in `registerMediaConversions()`.

```php
<?php

declare(strict_types=1);

namespace App\Domains\Components\Models;

use App\Models\Component;
use Spatie\MediaLibrary\HasMedia;
use Spatie\MediaLibrary\InteractsWithMedia;
use Spatie\MediaLibrary\MediaCollections\Models\Media;
use Illuminate\Database\Eloquent\Model;

final class Component extends Model implements HasMedia
{
    use InteractsWithMedia;

    public function registerMediaConversions(?Media $media = null): void
    {
        $this->addMediaConversion('thumb')
            ->width(300)
            ->height(200)
            ->sharpen(10)
            ->nonQueued(); // small conversions run inline

        $this->addMediaConversion('preview')
            ->width(1200)
            ->format('webp')
            ->queued();    // heavy conversions run on the queue
    }

    public function registerMediaCollections(): void
    {
        $this->addMediaCollection('screenshots')
            ->acceptsMimeTypes(['image/jpeg', 'image/png', 'image/webp'])
            ->singleFile(false);

        $this->addMediaCollection('cover')
            ->singleFile();
    }
}
```

# 3. Private vs Public Media

Public assets (previews, thumbnails) live on the `public` disk and are referenced by URL. Private assets (source downloads, license files, draft uploads) live on the `private` disk and are **never** referenced by a direct path — they are streamed through an authorized route.

```php
// Attaching to the correct disk:
$model->addMediaFromRequest('source')
    ->toMediaCollection('source-files', 'private'); // private disk

$model->addMediaFromRequest('cover')
    ->toMediaCollection('cover', 'public');         // public disk

// Public URL (safe to expose):
$url = $model->getFirstMediaUrl('cover', 'thumb');

// Private streaming route (authorized — see 07.23-authorization.md):
Route::get('media/{media}', MediaDownloadController::class)
    ->middleware(['auth', 'can:download,media']);
```

Access enforcement for private media:

```php
final class MediaDownloadController
{
    public function __invoke(Media $media, Request $request): Response
    {
        abort_unless($media->disk === 'private', 404);
        abort_unless($request->user()?->can('download', $media), 403);

        return response()->file($media->getPath());
    }
}
```

# 4. Responsive Images

For gallery-heavy models, register responsive conversions so Media Library generates multiple widths and serves `srcset`.

```php
$this->addMediaConversion('responsive')
    ->withResponsiveImages()
    ->format('webp');
```

Render in Blade with the `->img()` helper provided by the package:

```blade
{!! $component->getFirstMedia('screenshots')?->img('responsive', ['class' => 'rounded-lg']) !!}
```

# 5. Upload Pipeline

Uploads never bypass Media Library. A Livewire/API upload action validates the file, then delegates to the model:

```php
final class UploadComponentScreenshotAction
{
    public function execute(Component $component, UploadedFile $file): Media
    {
        return $component->addMedia($file)
            ->usingName($file->getClientOriginalName())
            ->toMediaCollection('screenshots', 'public');
    }
}
```

Conversions flagged `->queued()` are processed by Horizon (`07.49-queues.md`); the model is returned immediately with `hasGeneratedConversion()` false until ready.

# 6. Cleanup & Deletion

Deleting a model cascades its media (`Media` is soft-aware via the model's `delete()`). For hard-removal of orphaned files, run the package command in a scheduled task (`07.50-scheduler.md`):

```bash
php artisan media-library:clean
```

# 8. Media Upload Service

## 8.1 Upload Action

```php
<?php

declare(strict_types=1);

namespace App\Domains\Media\Actions;

use App\Domains\Media\Events\MediaUploaded;
use App\Domains\Shared\Exceptions\FileUploadException;
use Illuminate\Http\UploadedFile;
use Illuminate\Support\Facades\Storage;
use Spatie\MediaLibrary\MediaCollections\Models\Media;

final class UploadMediaAction
{
    private const MAX_FILE_SIZE = 10 * 1024 * 1024; // 10MB
    private const ALLOWED_MIMES = [
        'image/jpeg',
        'image/png',
        'image/webp',
        'image/gif',
        'application/pdf',
        'application/zip',
    ];

    public function execute(
        \Illuminate\Database\Eloquent\Model $model,
        UploadedFile $file,
        string $collection = 'default',
        string $disk = 'public',
    ): Media {
        $this->validateFile($file);

        $media = $model->addMedia($file)
            ->usingName($file->getClientOriginalName())
            ->withCustomProperties([
                'uploaded_by' => auth()->id(),
                'original_name' => $file->getClientOriginalName(),
                'mime_type' => $file->getMimeType(),
            ])
            ->toMediaCollection($collection, $disk);

        event(new MediaUploaded($media));

        return $media;
    }

    public function executeFromRequest(
        \Illuminate\Database\Eloquent\Model $model,
        string $inputName,
        string $collection = 'default',
        string $disk = 'public',
    ): ?Media {
        if (! request()->hasFile($inputName)) {
            return null;
        }

        return $this->execute(
            $model,
            request()->file($inputName),
            $collection,
            $disk,
        );
    }

    public function executeMultiple(
        \Illuminate\Database\Eloquent\Model $model,
        array $files,
        string $collection = 'default',
        string $disk = 'public',
    ): array {
        $media = [];

        foreach ($files as $file) {
            if ($file instanceof UploadedFile) {
                $media[] = $this->execute($model, $file, $collection, $disk);
            }
        }

        return $media;
    }

    private function validateFile(UploadedFile $file): void
    {
        if ($file->getSize() > self::MAX_FILE_SIZE) {
            throw FileUploadException::fileTooLarge($file->getClientOriginalName(), self::MAX_FILE_SIZE);
        }

        if (! in_array($file->getMimeType(), self::ALLOWED_MIMES)) {
            throw FileUploadException::invalidMimeType(
                $file->getClientOriginalName(),
                $file->getMimeType(),
                self::ALLOWED_MIMES,
            );
        }
    }
}
```

# 9. Media Controller

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers;

use App\Domains\Media\Actions\UploadMediaAction;
use App\Http\Requests\UploadMediaRequest;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Http\Response;
use Spatie\MediaLibrary\MediaCollections\Models\Media;

final class MediaController extends Controller
{
    public function store(UploadMediaRequest $request, UploadMediaAction $action): JsonResponse
    {
        $modelType = $request->input('model_type', 'App\\Models\\User');
        $modelId = $request->input('model_id', $request->user()->id);
        $collection = $request->input('collection', 'default');

        $model = $modelType::findOrFail($modelId);

        abort_unless($request->user()->can('update', $model), 403);

        $media = $action->execute(
            model: $model,
            file: $request->file('file'),
            collection: $collection,
            disk: $request->input('disk', 'public'),
        );

        return response()->json([
            'data' => [
                'id' => $media->id,
                'name' => $media->name,
                'url' => $media->getUrl(),
                'thumb_url' => $media->getTemporaryUrl(now()->addMinutes(30), 'thumb'),
                'size' => $media->size,
                'mime_type' => $media->mime_type,
            ],
        ], 201);
    }

    public function destroy(Media $media): JsonResponse
    {
        $model = $media->mediable;

        abort_unless($request->user()->can('update', $model), 403);

        $media->delete();

        return response()->json(['message' => 'Media deleted.']);
    }

    public function reorder(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'collection' => ['required', 'string'],
            'model_type' => ['required', 'string'],
            'model_id' => ['required', 'integer'],
            'order' => ['required', 'array'],
            'order.*' => ['integer', 'exists:media,id'],
        ]);

        $model = $validated['model_type']::findOrFail($validated['model_id']);

        abort_unless($request->user()->can('update', $model), 403);

        foreach ($validated['order'] as $position => $mediaId) {
            \DB::table('media')
                ->where('id', $mediaId)
                ->update(['order_column' => $position]);
        }

        return response()->json(['message' => 'Order updated.']);
    }
}
```

# 10. Private Media Streaming

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Http\Response;
use Spatie\MediaLibrary\MediaCollections\Models\Media;

final class MediaDownloadController extends Controller
{
    public function __invoke(Media $media, Request $request): Response
    {
        abort_unless($media->disk === 'private', 404);

        abort_unless(
            $request->user()?->can('download', $media),
            403,
            'You do not have permission to download this file.'
        );

        // Log the download
        \DB::table('media_downloads')->insert([
            'media_id' => $media->id,
            'user_id' => $request->user()->id,
            'ip' => $request->ip(),
            'user_agent' => $request->userAgent(),
            'created_at' => now(),
        ]);

        return response()->file($media->getPath(), [
            'Content-Type' => $media->mime_type,
            'Content-Disposition' => 'attachment; filename="' . $media->file_name . '"',
        ]);
    }
}
```

# 11. Media Conversion Jobs

```php
<?php

declare(strict_types=1);

namespace App\Domains\Media\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Spatie\MediaLibrary\MediaCollections\Models\Media;

final class GenerateMediaConversionsJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public int $tries = 3;
    public int $timeout = 120;

    public function __construct(
        public Media $media,
    ) {}

    public function handle(): void
    {
        $this->media->refresh();

        // Generate all registered conversions
        $this->media->generateConversions();
    }

    public function failed(\Throwable $exception): void
    {
        \Log::error('Media conversion failed', [
            'media_id' => $this->media->id,
            'error' => $exception->getMessage(),
        ]);
    }
}
```

```php
            ->orWhereNull('mediable_id')

        }
```

# 13. Media Path Generator

```php
<?php

declare(strict_types=1);

namespace App\Domains\Media\PathGenerators;

use Spatie\MediaLibrary\PathGenerators\PathGenerator;

final class DomainPathGenerator implements PathGenerator
{
    public function getPath(\Spatie\MediaLibrary\MediaCollections\Models\Media $media): string
    {
        return $this->getBasePath($media) . '/' . $media->id;
    }

    public function getPathForConversions(\Spatie\MediaLibrary\MediaCollections\Models\Media $media): string
    {
        return $this->getBasePath($media) . '/' . $media->id . '/conversions';
    }

    public function getPathForResponsiveImages(\Spatie\MediaLibrary\MediaCollections\Models\Media $media): string
    {
        return $this->getBasePath($media) . '/' . $media->id . '/responsive';
    }

    private function getBasePath(\Spatie\MediaLibrary\MediaCollections\Models\Media $media): string
    {
        $type = class_basename($media->mediable_type ?? 'unknown');

        return strtolower($type);
    }
}
```

# 15. Storage Service Provider

```php
<?php

declare(strict_types=1);

namespace App\Providers;

use App\Domains\Media\Actions\UploadMediaAction;
use App\Domains\Media\PathGenerators\DomainPathGenerator;
use Illuminate\Support\ServiceProvider;
use Spatie\MediaLibrary\PathGenerators\PathGenerator;

final class MediaServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton(UploadMediaAction::class);
        $this->app->bind(PathGenerator::class, DomainPathGenerator::class);
    }

    public function boot(): void
    {
        $this->configureMediaLibrary();
    }

    private function configureMediaLibrary(): void
    {
        // Ensure storage links exist
        if (! is_dir(storage_path('app/public'))) {
            \Artisan::call('storage:link');
        }
    }
}
```

# 19. Storage Health Check

```php
<?php

declare(strict_types=1);

namespace App\Domains\Media\Services;

use Illuminate\Support\Facades\Storage;

final class StorageHealthService
{
    public function isHealthy(): array
    {
        $disks = ['public', 'private', 'local'];
        $results = [];

        foreach ($disks as $disk) {
            try {
                $testFile = '__health_check_' . Str::random(8);
                $testContent = 'ok';

                Storage::disk($disk)->put($testFile, $testContent);
                $read = Storage::disk($disk)->get($testFile);
                Storage::disk($disk)->delete($testFile);

                $results[$disk] = $read === $testContent ? 'healthy' : 'read_mismatch';
            } catch (\Throwable $e) {
                $results[$disk] = 'error: ' . $e->getMessage();
            }
        }

        return $results;
    }
}
```

# 21. Image Processing Pipeline

## 21.1 Conversion Definitions

```php
<?php

declare(strict_types=1);

namespace App\Domains\Media\Conversions;

use Spatie\MediaLibrary\Conversions\Conversion;
use Spatie\MediaLibrary\Conversions\ConversionCollection;

final class ImageConversions
{
    public static function forComponent(): ConversionCollection
    {
        $conversions = new ConversionCollection();

        $conversions->add(
            Conversion::create('thumb')
                ->width(300)
                ->height(200)
                ->sharpen(10)
                ->nonQueued()
        );

        $conversions->add(
            Conversion::create('medium')
                ->width(600)
                ->height(400)
                ->sharpen(5)
                ->nonQueued()
        );

        $conversions->add(
            Conversion::create('preview')
```

```php
<?php

declare(strict_types=1);

namespace App\Domains\Media\Services;

use Spatie\MediaLibrary\MediaCollections\Models\Media;

final class ResponsiveImageService
{
    private const BREAKPOINTS = [
        'mobile' => 480,
        'tablet' => 768,
        'desktop' => 1200,
        'wide' => 1920,
    ];

    public function getSrcSet(Media $media, string $conversion = 'default'): string
    {
        $srcSet = [];

        foreach (self::BREAKPOINTS as $name => $width) {
            $url = $media->getTemporaryUrl(now()->addMinutes(30), $conversion, [
                'w' => $width,
            ]);

            $srcSet[] = "{$url} {$width}w";
        }

        return implode(', ', $srcSet);
    }

    public function getSizes(): string
    {
        return '(max-width: 480px) 100vw, (max-width: 768px) 50vw, 33vw';
    }

    public function getResponsiveUrls(Media $media, string $conversion = 'default'): array
    {
        $urls = [];

        foreach (self::BREAKPOINTS as $name => $width) {
            $urls[$name] = $media->getTemporaryUrl(now()->addMinutes(30), $conversion, [
                'w' => $width,
            ]);
        }

        return $urls;
    }

    public function generateResponsiveImages(Media $media): void
    {
        foreach (self::BREAKPOINTS as $name => $width) {
            $media->addMediaConversion("responsive-{$name}")
                ->width($width)
                ->format('webp')
                ->quality(80)
                ->queued();
        }
    }
}
```

# 30. Storage Health Check

```php
<?php

declare(strict_types=1);

namespace App\Domains\Media\Services;

use Illuminate\Support\Facades\Storage;

final class StorageHealthService
{
    public function checkAll(): array
    {
        $disks = ['public', 'private'];
        $results = [];

        foreach ($disks as $disk) {
            $results[$disk] = $this->checkDisk($disk);
        }

        return $results;
    }

    public function checkDisk(string $disk): array
    {
        try {
            $testFile = '__health_' . Str::random(8);
            Storage::disk($disk)->put($testFile, 'test');
            $content = Storage::disk($disk)->get($testFile);
            Storage::disk($disk)->delete($testFile);

            return [
                'status' => 'healthy',
                'read_write' => $content === 'test',
            ];
        } catch (\Throwable $e) {
            return [
                'status' => 'error',
                'message' => $e->getMessage(),
            ];
        }
    }

    public function getDiskUsage(string $disk): array
    {
        $files = Storage::disk($disk)->allFiles();
        $totalSize = 0;

        foreach ($files as $file) {
            $totalSize += Storage::disk($disk)->size($file);
        }

        return [
            'file_count' => count($files),
            'total_size_bytes' => $totalSize,
            'total_size_human' => round($totalSize / 1024 / 1024, 2) . ' MB',
        ];
    }
}
```

# 33. Storage Best Practices

1. **Never store user-uploaded files outside Media Library** — always use `addMedia()`.
2. **Use `singleFile()` for collections that should only have one file** (avatars, covers).
3. **Queue heavy conversions** (`->queued()`) — inline conversions block the request.
4. **Validate files before upload** — check MIME type, size, and dimensions.
5. **Use signed routes for private media** — never expose direct file paths.
6. **Clean up orphaned media** with a scheduled task (`media-library:clean`).
7. **Monitor disk usage** — set alerts when storage exceeds thresholds.
8. **Use responsive images** for gallery-heavy pages.
9. **Store metadata** in `custom_properties` for audit trails.
10. **Test with `Storage::fake()`** to avoid writing to real disks in tests.

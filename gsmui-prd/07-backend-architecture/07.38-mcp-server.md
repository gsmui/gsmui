# 07.38 - MCP Server

**Project:** GsmUi
**Architecture:** Model Context Protocol (MCP) Server
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `05.23-mcp-architecture.md` for the MCP transport/protocol overview and `06.131-mcp.md` for the servers/tools/parameters/tool-calls/sessions schema. This document is the **implementation contract** — the `McpTool` adapter interface, the tool registry/dispatcher, the session service, and the idempotency contract enforced on every tool call via `idempotency_key`.

# Purpose

The MCP Server exposes GsmUi capabilities to AI assistants through a standardized protocol (JSON-RPC over HTTP, with WebSocket/SSE transports — see `05.23-mcp-architecture.md`). It is a thin, secure bridge: each exposed capability is a registered `McpTool` adapter that receives validated arguments, performs its work through the normal domain services (never touching models directly — see `07.06-service-layer.md`), and returns a structured result. Tools never run arbitrary code; they are explicit, audited adapters.

Idempotency is the core safety property. Every tool invocation carries an `idempotency_key` (schema `mcp_tool_calls.idempotency_key` in `06.131-mcp.md`). A repeated key returns the original result instead of re-executing the tool, guaranteeing exactly-once side effects even under AI-assistant retries. Sessions (`mcp_sessions`) bind an assistant connection to a user and server for the connection lifetime.

Goals:

- Define the `McpTool` adapter interface (input schema, invocation, result).
- Define the `McpToolRegistry` that maps tool names to adapters and validates arguments.
- Define the `McpSessionService` that issues and validates session tokens.
- Specify the idempotency contract and the `McpToolCall` recording flow.

# 1. The `McpTool` Adapter Interface

A tool is an explicit adapter that wraps a domain use case. It declares its input schema (so the registry can validate before dispatch) and returns a serializable result array. Tools MUST delegate to Actions/Services, never to repositories or models directly.

```php
namespace App\Domains\Mcp\Contracts;

use App\Domains\Mcp\Data\McpToolResult;

interface McpTool
{
    /** Stable tool name as advertised to MCP clients (e.g. "list_components"). */
    public function name(): string;

    /** Human description for MCP client discovery. */
    public function description(): string;

    /** JSON-schema-shaped input definition (name => [type, required, default]). */
    public function inputSchema(): array;

    /**
     * Execute the tool. $args are already validated against inputSchema().
     * Returns a serializable result; MUST be safe to call repeatedly under
     * the same idempotency key.
     */
    public function invoke(array $args, McpContext $context): McpToolResult;
}
```

The `McpContext` carries the authenticated session/user — never trust client-supplied identity:

```php
namespace App\Domains\Mcp\Data;

final readonly class McpContext
{
    public function __construct(
        public int $userId,
        public int $serverId,
        public string $sessionToken,
    ) {}
}
```

# 3. Tool Registry & Argument Validation

The `McpToolRegistry` resolves a tool by name and validates incoming arguments against the tool's `inputSchema()` before invoking it. Unknown or disabled tools are rejected with a protocol error.

```php
namespace App\Domains\Mcp\Services;

use App\Domains\Mcp\Contracts\McpTool;
use App\Domains\Mcp\Exceptions\{ToolNotFoundException, InvalidToolArgumentsException};

final class McpToolRegistry
{
    /** @param iterable<McpTool> $tools */
    public function __construct(private iterable $tools) {}

    public function resolve(string $name): McpTool
    {
        foreach ($this->tools as $tool) {
            if ($tool->name() === $name) {
                return $tool;
            }
        }
        throw new ToolNotFoundException($name);
    }

    /** Apply defaults and coerce types; throw on missing required args. */
    public function validate(McpTool $tool, array $raw): array
    {
        $schema = $tool->inputSchema();
        $out = [];

        foreach ($schema as $key => $def) {
            if (array_key_exists($key, $raw)) {
                $out[$key] = $this->coerce($def['type'], $raw[$key]);
            } elseif ($def['required'] ?? false) {
                throw new InvalidToolArgumentsException("Missing required argument: {$key}");
            } else {
                $out[$key] = $def['default'] ?? null;
            }
        }
        return $out;
    }

    private function coerce(string $type, mixed $value): mixed
    {
        return match ($type) {
            'integer' => (int) $value,
            'boolean' => filter_var($value, FILTER_VALIDATE_BOOLEAN),
            'string'  => (string) $value,
            default   => $value,
        };
    }
}
```

Register every tool adapter in the MCP module's service provider (per `07.06-service-layer.md` §5):

```php
$this->app->tag([ListComponentsTool::class, GetComponentTool::class], 'mcp.tools');
$this->app->bind(McpToolRegistry::class,
    fn ($app) => new McpToolRegistry($app->tagged('mcp.tools')));
```

# 4. The `McpDispatcher` & Idempotency Contract

Every tool call flows through the dispatcher, which enforces idempotency against `mcp_tool_calls.idempotency_key` (schema `06.131-mcp.md`). On a duplicate key it returns the persisted result instead of re-invoking the adapter. Status transitions follow `pending → running → completed|failed`.

```php
namespace App\Domains\Mcp\Services;

use App\Domains\Mcp\Contracts\McpTool;
use App\Domains\Mcp\Data\McpContext;
use App\Domains\Mcp\Models\McpToolCall;

final class McpDispatcher
{
    public function __construct(
        private McpToolRegistry $registry,
        private McpToolCallRepository $calls,
    ) {}

    public function dispatch(string $toolName, array $rawArgs, string $idempotencyKey, McpContext $ctx): array
    {
        // Idempotency: return prior result if the key already completed.
        if ($prior = $this->calls->findCompleted($idempotencyKey)) {
            return $prior->result;
        }

        $tool = $this->registry->resolve($toolName);
        $args = $this->registry->validate($tool, $rawArgs);

        $call = $this->calls->create([
            'server_id'       => $ctx->serverId,
            'tool_id'         => $this->calls->toolIdFor($toolName),
            'user_id'         => $ctx->userId,
            'arguments'       => $args,
            'idempotency_key' => $idempotencyKey,
            'status'          => 'running',
        ]);

        try {
            $result = $tool->invoke($args, $ctx)->toArray();
            $this->calls->complete($call, $result);
            return $result;
        } catch (\Throwable $e) {
            $this->calls->fail($call, $e->getMessage());
            throw $e;
        }
    }
}
```

Idempotency semantics:

| Scenario | Behavior |
| --- | --- |
| First call with key `K` | Executes tool, stores result under `K`. |
| Retry with same key `K`, completed | Returns stored result; tool NOT re-run. |
| Retry with same key `K`, failed | Re-executes (key not marked completed). |
| Key omitted | Treated as non-idempotent; new row each call. |

# 5. Session Service

`McpSessionService` issues signed session tokens, validates them on each request, and expires them (`mcp_sessions.expires_at`). It scopes every tool call to the authenticated user/server pair.

```php
namespace App\Domains\Mcp\Services;

use App\Domains\Mcp\Data\McpContext;
use App\Domains\Mcp\Exceptions\InvalidMcpSessionException;
use App\Domains\Mcp\Models\McpSession;

final class McpSessionService
{
    public function start(int $userId, int $serverId, int $ttlMinutes = 60): McpSession
    {
        return McpSession::create([
            'user_id'       => $userId,
            'server_id'     => $serverId,
            'session_token' => \Str::random(40),
            'expires_at'    => now()->addMinutes($ttlMinutes),
        ]);
    }

    public function resolve(string $token): McpContext
    {
        $session = McpSession::where('session_token', $token)
            ->where('expires_at', '>', now())
            ->first();

        if (! $session) {
            throw new InvalidMcpSessionException($token);
        }

        return new McpContext(
            userId: $session->user_id,
            serverId: $session->server_id,
            sessionToken: $session->session_token,
        );
    }
}
```

# 6. Security Model

- Scoped permissions: a tool only runs if the resolved `McpContext->userId` passes the tool's policy (see `07.15-policies.md`).
- Rate limiting: wrap `McpDispatcher::dispatch` in the rate-limiter used across the API (`07.21-api-architecture.md`).
- Audit logging: every `McpToolCall` is persisted; write operations also trigger domain events (`07.12-events.md`) after commit.
- No arbitrary code: tools are a fixed, registered set — never dynamically evaluated.

# 7. Testing

- `McpToolRegistryTest`: resolves a known tool; throws `ToolNotFoundException` for unknown; applies defaults; coerces types; rejects missing required.
- `McpDispatcherTest`: first call executes and stores; same `idempotency_key` returns stored result without re-invoking (spy on tool); failed call transitions to `failed` with message.
- `McpSessionServiceTest`: `start` creates unexpired session; `resolve` succeeds before expiry and throws after.

# 7. Tool Discovery Protocol

AI assistants discover available tools through a structured introspection endpoint. The MCP server exposes tool metadata so clients can dynamically build their tool-use strategies.

### 7.1 Discovery Endpoint

```php
namespace App\Domains\Mcp\Http\Controllers;

use App\Http\Controllers\Controller;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;

class McpDiscoveryController extends Controller
{
    public function tools(Request $request): JsonResponse
    {
        $context = app(\App\Domains\Mcp\Services\McpSessionService::class)
            ->resolve($request->header('X-Mcp-Session-Token'));

        $registry = app(\App\Domains\Mcp\Services\McpToolRegistry::class);

        $tools = collect($registry->allTools())
            ->filter(fn ($tool) => $this->canAccess($tool, $context))
            ->map(fn ($tool) => [
                'name' => $tool->name(),
                'description' => $tool->description(),
                'input_schema' => $tool->inputSchema(),
            ])
            ->values()
            ->all();

        return response()->json([
            'tools' => $tools,
            'server_version' => config('mcp.server_version', '1.0.0'),
            'protocol_version' => '2024-11-05',
        ]);
    }

    private function canAccess(\App\Domains\Mcp\Contracts\McpTool $tool, \App\Domains\Mcp\Data\McpContext $context): bool
    {
        try {
            app(\App\Domains\Admin\Services\AuthService::class)
                ->authorize($tool->requiredAbility(), null);
            return true;
        } catch (\Throwable) {
            return false;
        }
    }
}
```

### 7.3 Capability Negotiation

Clients declare their capabilities during session initialization:

```php
namespace App\Domains\Mcp\Services;

final class McpCapabilityNegotiator
{
    private const SUPPORTED_CAPABILITIES = [
        'tools' => true,
        'resources' => true,
        'prompts' => false,
        'sampling' => false,
        'logging' => true,
    ];

    public function negotiate(array $clientCapabilities): array
    {
        $serverCapabilities = [];
        foreach (self::SUPPORTED_CAPABILITIES as $cap => $supported) {
            if ($supported && ($clientCapabilities[$cap] ?? false)) {
                $serverCapabilities[$cap] = true;
            }
        }

        return $serverCapabilities;
    }
}
```

# 8. Resource Management

MCP resources expose read-only data that AI assistants can query (not just tools that perform actions).

### 8.1 Resource Interface

```php
namespace App\Domains\Mcp\Contracts;

interface McpResource
{
    /** URI-style resource identifier, e.g. "gsmui://components/button" */

    /** Human-readable name */

    /** MIME type of the resource content */
    public function mimeType(): string;

    /** Fetch the resource content */
    public function read(array $params): McpResourceContent;

final readonly class McpResourceContent
{
    public function __construct(
        public string $mimeType,
        public string $content,
    ) {}
}
```

### 8.2 Example Resources

| URI Pattern | Description | MIME Type |
| --- | --- | --- |
| `gsmui://components` | Full component registry | `application/json` |
| `gsmui://components/{name}` | Single component schema | `application/json` |
| `gsmui://themes/current` | Current theme configuration | `application/json` |
| `gsmui://docs/{topic}` | Documentation page | `text/markdown` |
| `gsmui://snippets/{id}` | Saved snippet | `application/json` |

```php
namespace App\Domains\Mcp\Resources;

final class ComponentResource implements \App\Domains\Mcp\Contracts\McpResource
{
    public function __construct(
        private readonly string $componentName,
    ) {}

    public function uri(): string
    {
        return "gsmui://components/{$this->componentName}";
    }

    public function name(): string
    {
        return "Component: {$this->componentName}";
    }

    public function mimeType(): string
    {
        return 'application/json';
    }

    public function read(array $params): \App\Domains\Mcp\Data\McpResourceContent
    {
        $schema = app(\App\Domains\Components\Contracts\ComponentRegistry::class)
            ->schemaFor($this->componentName);

        return new \App\Domains\Mcp\Data\McpResourceContent(
            mimeType: $this->mimeType(),
            content: json_encode($schema?->toArray() ?? []),
        );
    }
}
```

### 8.3 Resource Registry

```php
namespace App\Domains\Mcp\Services;

final class McpResourceRegistry
{
    /** @var McpResource[] */
    private array $resources = [];

    public function register(McpResource $resource): void
    {
        $this->resources[$resource->uri()] = $resource;
    }

    public function resolve(string $uri): ?McpResource
    {
        return $this->resources[$uri] ?? null;
    }

    /** @return McpResource[] */
    public function all(): array
    {
        return $this->resources;
    }

    /** Match a URI pattern against registered resources */
    public function match(string $pattern): array
    {
        $results = [];
        foreach ($this->resources as $uri => $resource) {
            if (fnmatch($pattern, $uri)) {
                $results[] = $resource;
            }
        }
        return $results;
    }
}
```

# 9. Session Lifecycle (Detailed)

### 9.1 Session States

```text
created → active → expired
              ↓
           terminated
```

| State | Description | Transition |
| --- | --- | --- |
| `created` | Token issued, not yet used | First request → `active` |
| `active` | Valid, in-use session | TTL expires → `expired`; explicit logout → `terminated` |
| `expired` | Past `expires_at` | Terminal; new session required |
| `terminated` | Explicitly closed by client or admin | Terminal |

### 9.3 Session Cleanup

A scheduled job cleans up expired sessions:

```php
namespace App\Domains\Mcp\Jobs;

use App\Domains\Mcp\Models\McpSession;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;

final class CleanupExpiredSessions implements ShouldQueue
{
    use Queueable;

    public function handle(): void
    {
        $expired = McpSession::where('expires_at', '<', now())
            ->where('status', 'active')
            ->get();

        foreach ($expired as $session) {
            $session->update(['status' => 'expired']);
            \App\Domains\Mcp\Events\McpSessionExpired::dispatch($session->id);
        }
    }
}
```

```php

```

# 10. Error Codes and Handling

### 10.1 MCP Protocol Error Codes

| Code | Name | Description |
| --- | --- | --- |
| `-32600` | Invalid Request | Malformed JSON-RPC |
| `-32601` | Method Not Found | Unknown tool or resource |
| `-32602` | Invalid Params | Tool arguments fail validation |
| `-32603` | Internal Error | Server-side failure |
| `-32000` | Tool Not Found | Requested tool doesn't exist |
| `-32001` | Tool Disabled | Tool is disabled by configuration |
| `-32002` | Unauthorized | User lacks permission |
| `-32003` | Rate Limited | Too many requests |
| `-32004` | Session Expired | Session token is invalid or expired |
| `-32005` | Idempotency Conflict | Key reused with different arguments |

### 10.2 Error Response Builder

```php
namespace App\Domains\Mcp\Services;

final class McpErrorBuilder
{
    public function toolNotFound(string $name): array
    {
        return $this->error(-32000, "Tool '{$name}' not found");
    }

    public function invalidParams(string $detail): array
    {
        return $this->error(-32602, $detail);
    }

    public function unauthorized(string $ability): array
    {
        return $this->error(-32002, "Missing ability: {$ability}");
    }

    public function rateLimited(): array
    {
        return $this->error(-32003, 'Rate limit exceeded. Retry after backoff.');
    }

    public function sessionExpired(): array
    {
        return $this->error(-32004, 'Session expired. Obtain a new session token.');
    }

    public function idempotencyConflict(string $key, array $expectedArgs): array
    {
        return $this->error(-32005, "Idempotency key '{$key}' was used with different arguments.");
    }

    public function internal(string $message): array
    {
        return $this->error(-32603, $message);
    }

    private function error(int $code, string $message): array
    {
        return [
            'jsonrpc' => '2.0',
            'error' => [
                'code' => $code,
                'message' => $message,
            ],
        ];
    }
}
```

### 10.3 Exception-to-Error Mapping

```php
namespace App\Domains\Mcp\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class McpErrorMiddleware
{
    public function handle(Request $request, Closure $next)
    {
        try {
            return $next($request);
        } catch (\App\Domains\Mcp\Exceptions\ToolNotFoundException $e) {
            return response()->json(
                app(\App\Domains\Mcp\Services\McpErrorBuilder::class)->toolNotFound($e->getMessage()),
                200 // JSON-RPC errors are always 200
            );
        } catch (\App\Domains\Mcp\Exceptions\InvalidToolArgumentsException $e) {
            return response()->json(
                app(\App\Domains\Mcp\Services\McpErrorBuilder::class)->invalidParams($e->getMessage()),
                200
            );
        } catch (\App\Domains\Mcp\Exceptions\InvalidMcpSessionException $e) {
            return response()->json(
                app(\App\Domains\Mcp\Services\McpErrorBuilder::class)->sessionExpired(),
                200
            );
        } catch (\Throwable $e) {
            report($e);
            return response()->json(
                app(\App\Domains\Mcp\Services\McpErrorBuilder::class)->internal('An unexpected error occurred'),
                200
            );
        }
    }
}
```

# 11. Authentication Flows

### 11.1 API Key Authentication

```php
namespace App\Domains\Mcp\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class McpApiKeyAuth
{
    public function handle(Request $request, Closure $next)
    {
        $apiKey = $request->header('X-Mcp-Api-Key');

        if (! $apiKey) {
            return response()->json(['error' => 'Missing API key'], 401);
        }

        $server = \App\Domains\Mcp\Models\McpServer::where('api_key', $apiKey)->first();

        if (! $server || ! $server->is_active) {
            return response()->json(['error' => 'Invalid API key'], 401);
        }

        $request->merge(['_mcp_server' => $server]);

        return $next($request);
    }
}
```

# 12. Tool Composition Patterns

Tools can be composed to create higher-level workflows:

### 12.1 Sequential Tool Chains

```php
namespace App\Domains\Mcp\Services;

final class McpToolChain
{
    /** @param string[] $toolNames Tools to run in order */
    public function execute(array $toolNames, array $initialArgs, McpContext $context): array
    {
        $results = [];
        $currentArgs = $initialArgs;

        foreach ($toolNames as $toolName) {
            $dispatcher = app(\App\Domains\Mcp\Services\McpDispatcher::class);
            $result = $dispatcher->dispatch(
                $toolName,
                $currentArgs,
                Str::uuid()->toString(),
                $context
            );
            $results[] = ['tool' => $toolName, 'result' => $result];

            // Pass output as input to the next tool
            $currentArgs = $result;
        }

        return $results;
    }
}
```

### 12.2 Parallel Tool Execution

```php
namespace App\Domains\Mcp\Services;

final class McpParallelExecutor
{
    /** Execute multiple independent tools concurrently */
    public function execute(array $toolCalls, McpContext $context): array
    {
        $futures = [];

        foreach ($toolCalls as $call) {
            $futures[] = function () use ($call, $context) {
                $dispatcher = app(\App\Domains\Mcp\Services\McpDispatcher::class);
                return [
                    'tool' => $call['name'],
                    'result' => $dispatcher->dispatch(
                        $call['name'],
                        $call['arguments'],
                        $call['idempotency_key'] ?? Str::uuid()->toString(),
                        $context
                    ),
                ];
            };
        }

        // Execute all in parallel using Laravel's parallel helper
        return \Illuminate\Support\Parallel::run($futures);
    }
}
```

# 13. Batch Operations

For efficiency, the MCP server supports batching multiple tool calls in a single request:

```php
namespace App\Domains\Mcp\Http\Controllers;

class McpBatchController extends Controller
{
    public function handle(Request $request): JsonResponse
    {
        $batch = $request->input('batch', []);
        $context = $this->resolveContext($request);

        $results = [];
        foreach ($batch as $index => $call) {
            try {
                $dispatcher = app(\App\Domains\Mcp\Services\McpDispatcher::class);
                $result = $dispatcher->dispatch(
                    $call['tool'],
                    $call['arguments'] ?? [],
                    $call['idempotency_key'] ?? Str::uuid()->toString(),
                    $context
                );
                $results[$index] = ['success' => true, 'result' => $result];
            } catch (\Throwable $e) {
                $results[$index] = ['success' => false, 'error' => $e->getMessage()];
            }
        }

        return response()->json(['results' => $results]);
    }
}
```

Batch limits:

| Limit | Value | Purpose |
| --- | --- | --- |
| Max batch size | 10 | Prevent abuse |
| Max total execution time | 30 seconds | Timeout protection |

# 14. Subscription Management for MCP

MCP server access is managed per-server with usage quotas:

```php
namespace App\Domains\Mcp\Services;

final class McpSubscriptionService
{
    public function __construct(
        private readonly \App\Domains\Mcp\Repositories\McpServerRepository $servers,
    ) {}

    public function canInvoke(int $serverId, string $toolName): bool
    {
        $server = $this->servers->find($serverId);

        if (! $server || ! $server->is_active) {
            return false;
        }

        $quota = $this->remainingQuota($serverId);
        if ($quota <= 0) {
            return false;
        }

        return true;
    }

    public function remainingQuota(int $serverId): int
    {
        $server = $this->servers->find($serverId);
        $month = now()->format('Y-m');

        $used = \App\Domains\Mcp\Models\McpToolCall::query()
            ->where('server_id', $serverId)
            ->whereMonth('created_at', $month)
            ->count();

        return max(0, ($server->monthly_quota ?? 10000) - $used);
    }

    public function recordUsage(int $serverId): void
    {
        // Increment usage counter (atomic via Redis or DB)
        $key = "mcp:usage:{$serverId}:" . now()->format('Y-m');
        \Illuminate\Support\Facades\Cache::increment($key);
    }
}
```

# 15. Tool Versioning

Tools are versioned to support backward compatibility:

```php
namespace App\Domains\Mcp\Contracts;

interface McpTool
{
    // ... existing methods ...

    /** Semantic version of this tool */
    public function version(): string;

```

Version compatibility rules:

| Scenario | Behavior |
| --- | --- |
| Client requests tool v1.x, server has v1.y | Compatible; use v1.y |
| Client requests tool v1.x, server has v2.x | Incompatible; return error with migration hint |
| Client doesn't specify version | Use latest available version |

```php
namespace App\Domains\Mcp\Services;

final class McpToolVersionResolver
{
    public function resolve(string $toolName, ?string $requestedVersion): \App\Domains\Mcp\Contracts\McpTool
    {
        $tool = app(\App\Domains\Mcp\Services\McpToolRegistry::class)->resolve($toolName);

        if ($requestedVersion === null) {
            return $tool; // latest
        }

        $serverVersion = $tool->version();
        if ($this->isCompatible($requestedVersion, $serverVersion)) {
            return $tool;
        }

        throw new \App\Domains\Mcp\Exceptions\IncompatibleToolVersionException(
            $toolName,
            $requestedVersion,
            $serverVersion
        );
    }

    private function isCompatible(string $requested, string $available): bool
    {
        $requestedParts = explode('.', $requested);
        $availableParts = explode('.', $available);

        // Major version must match
        return ($requestedParts[0] ?? 0) === ($availableParts[0] ?? 0);
    }
}
```

Example streaming tool:

```php
namespace App\Domains\Mcp\Tools;

final class SearchComponentsTool implements \App\Domains\Mcp\Contracts\McpStreamingTool
{
    public function __construct(
        private readonly \App\Domains\Components\Contracts\ComponentServiceContract $components,
    ) {}

    public function name(): string { return 'search_components'; }
    public function description(): string { return 'Search components with streaming results.'; }

    public function inputSchema(): array
    {
        return [
            'query' => ['type' => 'string', 'required' => true],
            'limit' => ['type' => 'integer', 'required' => false, 'default' => 50],
        ];
    }

    public function invoke(array $args, McpContext $context): \App\Domains\Mcp\Data\McpToolResult
    {
        $results = iterator_to_array($this->invokeStream($args, $context));
        return new \App\Domains\Mcp\Data\McpToolResult(data: ['components' => $results]);
    }

    public function invokeStream(array $args, McpContext $context): \Generator
    {
        $query = $args['query'];
        $limit = $args['limit'];
        $offset = 0;
        $batchSize = 10;

        while ($offset < $limit) {
            $batch = $this->components->search(
                query: $query,
                offset: $offset,
                limit: $batchSize,
                userId: $context->userId,
            );

            foreach ($batch as $component) {
                yield $component->toArray();
            }

            if (count($batch) < $batchSize) break;
            $offset += $batchSize;
        }
    }
}
```

```php
namespace App\Domains\Mcp\Middleware;

final class McpRateLimitMiddleware implements \App\Domains\Mcp\Contracts\McpToolMiddleware
```

### 22.2 Middleware Pipeline

```php
namespace App\Domains\Mcp\Services;

final class McpToolMiddlewarePipeline
{
    /** @param McpToolMiddleware[] $middlewares */
    public function __construct(
        private readonly iterable $middlewares,
    ) {}

    public function run(string $toolName, array $args, McpContext $context, callable $operation): mixed
    {
        // Before middleware
        foreach ($this->middlewares as $middleware) {
            $args = $middleware->before($toolName, $args, $context);
        }

        // Execute tool
        $result = $operation($args);

        // After middleware (reverse order)
        foreach (array_reverse(iterator_to_array($this->middlewares)) as $middleware) {
            $result = $middleware->after($toolName, $args, $context, $result);
        }

        return $result;
    }
}
```

```php
            ->where('created_at', '>=', $from);

        return new ToolMetrics(
            toolName: $toolName,
            totalCalls: (clone $calls)->count(),
            successfulCalls: (clone $calls)->where('status', 'completed')->count(),

            p99LatencyMs: $this->percentileLatency($toolName, 99, $days),
        );
    }

    private function avgLatency(string $date): float
    {
        return \App\Domains\Mcp\Models\McpToolCall::whereDate('created_at', $date)
            ->avg('latency_ms') ?? 0;
    }

    private function topTools(string $date, int $limit = 10): array
    {
        return \App\Domains\Mcp\Models\McpToolCall::whereDate('created_at', $date)
            ->selectRaw('tool_name, count(*) as calls')
            ->groupBy('tool_name')
            ->orderByDesc('calls')
            ->limit($limit)
            ->pluck('calls', 'tool_name')
            ->all();
    }

    private function errorRate(string $date): float
    {
        $total = \App\Domains\Mcp\Models\McpToolCall::whereDate('created_at', $date)->count();
        if ($total === 0) return 0;

        $failed = \App\Domains\Mcp\Models\McpToolCall::whereDate('created_at', $date)
            ->where('status', 'failed')->count();

        return round($failed / $total * 100, 2);
    }

    private function percentileLatency(string $toolName, int $percentile, int $days): float
    {
        $latencies = \App\Domains\Mcp\Models\McpToolCall::where('tool_name', $toolName)
            ->where('created_at', '>=', now()->subDays($days))
            ->pluck('latency_ms')
            ->sort()
            ->values();

        if ($latencies->isEmpty()) return 0;

        $index = (int) ceil($percentile / 100 * $latencies->count()) - 1;
        return $latencies->get(max(0, $index));
    }
```

```php
                message: $json['error']['message'],
                code: $json['error']['code'],
            );
        }

        return $json['result'] ?? $json;
    }
}
```

### 25.2 JavaScript Client SDK

```javascript
class McpJsClient {
    constructor(baseUrl, apiKey) {
        this.baseUrl = baseUrl;
        this.apiKey = apiKey;
        this.sessionToken = null;
    }

    async connect() {
        const response = await fetch(`${this.baseUrl}/mcp/session/start`, {
            method: 'POST',
            headers: { 'X-Mcp-Api-Key': this.apiKey }
        });
        const data = await response.json();
        this.sessionToken = data.session_token;
    }

    async tools() {
        return this._request('GET', '/mcp/tools');
    }

    async call(tool, args = {}, idempotencyKey = crypto.randomUUID()) {
        return this._request('POST', '/mcp/tools/call', {
            tool,
            arguments: args,
            idempotency_key: idempotencyKey
        });
    }

    async resources() {
        return this._request('GET', '/mcp/resources');
    }

    async readResource(uri) {
        return this._request('GET', '/mcp/resources/read', { uri });
    }

    async batch(calls) {
        return this._request('POST', '/mcp/batch', { batch: calls });
    }

    async disconnect() {
        await this._request('POST', '/mcp/session/terminate');
    }

    async _request(method, path, data = {}) {
        const options = {
            method,
            headers: {
                'X-Mcp-Api-Key': this.apiKey,
                'X-Mcp-Session-Token': this.sessionToken || '',
                'Content-Type': 'application/json'
            }
        };

        if (method !== 'GET') {
            options.body = JSON.stringify(data);
        }

        const response = await fetch(`${this.baseUrl}${path}`, options);
        const json = await response.json();

        if (json.error) {
            throw new Error(`MCP Error ${json.error.code}: ${json.error.message}`);
        }

        return json.result || json;
    }
}

export default McpJsClient;
```

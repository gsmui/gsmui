# 07.37 - AI Engine

**Project:** GsmUi
**Architecture:** AI Provider Adapter
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `05.22-ai-architecture.md` for the AI feature overview (component/theme/doc generation, providers, prompt management) and `06.130-ai.md` for the conversation/message/template/provider-config/usage-log schema. This document is the **implementation contract** — the `AiProvider` adapter interface, the prompt-template renderer, the streaming transport, and the `AiEngine` service that wires providers together with usage logging and fallback.

# Purpose

The AI Engine is the single integration seam between GsmUi and external LLM providers (OpenAI, Anthropic, Google). It hides provider SDKs behind a uniform `AiProvider` contract so the rest of the platform depends only on the abstraction, never on a vendor namespace. This makes the active provider swappable per user (via `ai_provider_configs`) and globally, and makes adding a new provider a matter of implementing one interface plus a service-provider binding.

The engine is deliberately thin: it owns prompt assembly, request dispatch, streaming, and usage recording. It does NOT own conversation state, message persistence, or business decisions about *what* to generate — those live in the domain services that call it (see `07.06-service-layer.md`). All persisted AI data follows the schema in `06.130-ai.md`; this file specifies only the service contracts.

Goals:

- Define the `AiProvider` adapter interface (chat, stream, embed) with a provider-agnostic message shape.
- Define the `PromptTemplateRenderer` for `{{var}}` substitution over the `ai_prompt_templates` rows.
- Specify streaming as a PHP `Generator` so Livewire components can flush tokens incrementally.
- Record every call as an immutable `AiUsageLog` (see `06.130-ai.md`) and resolve the active provider per request.

# 1. Provider Abstraction

Every provider implements `AiProvider`. The interface is vendor-neutral: it accepts a list of `AiMessage` turns (role + content) and returns either a full completion or a token stream. Provider-specific config arrives as a plain `array` of settings (temperature, max_tokens, etc.) sourced from `AiProviderConfig.settings`.

```php
namespace App\Domains\Ai\Contracts;

use App\Domains\Ai\Data\AiMessage;
use App\Domains\Ai\Data\AiCompletion;
use App\Domains\Ai\Exceptions\AiProviderException;

interface AiProvider
{
    /** Human/stable provider identifier, e.g. "openai", "anthropic". */
    public function name(): string;

    /** Non-streaming single completion. */
    public function complete(array $messages, array $options = []): AiCompletion;

    /**
     * Streaming completion. Yields incremental content chunks
     * (strings) and returns the final AiCompletion on close.
     *
     * @return \Generator<int, string, null, AiCompletion>
     */
    public function stream(array $messages, array $options = []): \Generator;

    /** Token usage estimate for a payload (used for pre-flight quota checks). */
    public function estimateTokens(array $messages): int;
}
```

The `AiMessage` and `AiCompletion` value carriers are immutable and serializable (no model instances, per `07.12-events.md` §3):

```php
namespace App\Domains\Ai\Data;

final readonly class AiMessage
{
    public function __construct(
        public string $role,    // 'user' | 'assistant' | 'system'
        public string $content,
    ) {}
}

final readonly class AiCompletion
{
    public function __construct(
        public string $content,
        public int $promptTokens,
        public int $completionTokens,
        public string $model,
    ) {}
}
```

# 3. Prompt Template Renderer

`ai_prompt_templates` rows carry a `prompt` body with `{{var}}` placeholders and a `variables` JSON of definitions. The renderer substitutes caller-supplied values, validates required variables, and returns the assembled system/user prompt.

```php
namespace App\Domains\Ai\Contracts;

interface PromptTemplateRenderer
{
    /** Render a template body with provided variables, throwing on missing required ones. */
    public function render(string $template, array $variables): string;
}
```

```php
namespace App\Domains\Ai\Services;

use App\Domains\Ai\Contracts\PromptTemplateRenderer;
use App\Domains\Ai\Exceptions\MissingTemplateVariableException;

final class BladePromptRenderer implements PromptTemplateRenderer
{
    public function render(string $template, array $variables): string
    {
        $missing = [];
        $out = preg_replace_callback('/{{\s*(\w+)\s*}}/', function (array $m) use ($variables, &$missing): string {
            if (! array_key_exists($m[1], $variables)) {
                $missing[] = $m[1];
                return '';
            }
            return (string) $variables[$m[1]];
        }, $template);

        if ($missing !== []) {
            throw new MissingTemplateVariableException($missing);
        }

        return $out;
    }
}
```

# 4. Streaming Usage

Streaming returns a `Generator` so a Livewire component can flush tokens to the browser as they arrive. The engine wraps the provider stream, aggregates the final completion, and records usage once the stream closes.

```php
namespace App\Domains\Ai\Services;

use App\Domains\Ai\Contracts\AiProvider;

final class AiEngine
{
    public function __construct(private AiProvider $provider) {}

    /**
     * Yield content chunks to the caller; invoke $onComplete with the
     * final AiCompletion so the caller can persist the message + usage log.
     *
     * @return \Generator<int, string, null, void>
     */
    public function streamConversation(array $messages, array $options, callable $onComplete): \Generator
    {
        $stream = $this->provider->stream($messages, $options);

        foreach ($stream as $chunk) {
            yield $chunk;
        }

        $completion = $stream->getReturn(); // final AiCompletion
        $onComplete($completion);
    }
}
```

Livewire consumption (thin — the component stays a thin adapter, see `07.19-livewire-architecture.md`):

```php
public function ask(): void
{
    $messages = $this->conversation->toAiMessages();

    foreach ($this->engine->streamConversation($messages, [], fn ($c) => $this->persist($c)) as $token) {
        $this->partial .= $token;
        $this->stream(to: 'ai:token', content: $token);
    }
}
```

# 5. Usage Recording & Fallback

Every completion — streamed or not — produces an immutable `AiUsageLog` (schema in `06.130-ai.md`, no soft deletes). The engine writes the log after the call returns. Provider fallback (primary → secondary) is resolved by `AiProviderResolver`, which reads the active `ai_provider_configs` row for the user (or the global default) and constructs the matching adapter.

```php
namespace App\Domains\Ai\Services;

use App\Domains\Ai\Data\AiCompletion;

final class AiUsageRecorder
{
    public function record(int $userId, ?int $conversationId, AiCompletion $c, string $provider): void
    {
        \App\Domains\Ai\Models\AiUsageLog::create([
            'user_id'          => $userId,
            'conversation_id'  => $conversationId,
            'provider'         => $provider,
            'model'            => $c->model,
            'tokens_prompt'    => $c->promptTokens,
            'tokens_completion'=> $c->completionTokens,
            'cost'             => $this->costCents($provider, $c),
        ]);
    }

    private function costCents(string $provider, AiCompletion $c): int
    {
        // lookup provider pricing table; precision in minor units per 06.130
        return (int) (($c->promptTokens + $c->completionTokens) * 0.0001 * 100);
    }
}
```

The resolver binds the active provider into the container so domain services receive `AiProvider` without knowing which vendor is live:

```php
$this->app->bind(AiProvider::class, fn () => $this->app
    ->make(AiProviderResolver::class)
    ->resolveForUser(auth()->id()));
```

# 7. Provider Configuration Details

Every provider stores its configuration in `ai_provider_configs` (schema `06.130-ai.md`). The resolver constructs the matching adapter from these settings.

```php
namespace App\Domains\Ai\Services;

final class AiProviderResolver
{
    public function __construct(
        private readonly \App\Domains\Ai\Repositories\AiProviderConfigRepository $configs,
    ) {}

    public function resolveForUser(?int $userId): \App\Domains\Ai\Contracts\AiProvider
    {
        $config = $userId
            ? $this->configs->forUser($userId) ?? $this->configs->globalDefault()
            : $this->configs->globalDefault();

        if (! $config) {
            throw new \App\Domains\Ai\Exceptions\NoAiProviderConfiguredException();
        }

        return $this->buildProvider($config);
    }

    private function buildProvider(\App\Domains\Ai\Models\AiProviderConfig $config): \App\Domains\Ai\Contracts\AiProvider
    {
        return match ($config->provider) {
            'openai' => new \App\Domains\Ai\Providers\OpenAiProvider(
                apiKey: $config->settings['api_key'],
                model: $config->settings['model'] ?? 'gpt-4o',
            ),
            'anthropic' => new \App\Domains\Ai\Providers\AnthropicProvider(
                apiKey: $config->settings['api_key'],
                model: $config->settings['model'] ?? 'claude-sonnet-4-20250514',
            ),
            'google' => new \App\Domains\Ai\Providers\GoogleProvider(
                apiKey: $config->settings['api_key'],
                model: $config->settings['model'] ?? 'gemini-2.0-flash',
            ),
            default => throw new \App\Domains\Ai\Exceptions\UnknownProviderException($config->provider),
        };
    }
}
```

namespace App\Domains\Ai\Services;

final class AiProviderHealthMonitor
{
    public function __construct(
        private readonly \App\Domains\Ai\Repositories\AiProviderConfigRepository $configs,
    ) {}

    /** @return array<string, AiHealthCheckResult> */
    public function checkAll(): array
    {
        $results = [];
        foreach ($this->configs->allActive() as $config) {
            $provider = app(\App\Domains\Ai\Services\AiProviderResolver::class)
                ->resolveForUser(null); // global default
            $start = microtime(true);
            try {
                $result = $provider->healthCheck();
                $latency = (int) ((microtime(true) - $start) * 1000);
                $results[$config->provider] = new AiHealthCheckResult(
                    healthy: $result->healthy,
                    error: $result->error,
                    latencyMs: $latency,
                );
            } catch (\Throwable $e) {
                $results[$config->provider] = new AiHealthCheckResult(
                    healthy: false,
                    error: $e->getMessage(),
                );
            }
        }
        return $results;
    }
}

# 8. Token Counting Strategies

Accurate token counting is essential for quota management and cost estimation. Different providers have different tokenization schemes, so the engine uses provider-specific counters when available and falls back to estimation.

```php
namespace App\Domains\Ai\Services;

final class TokenCounter
{
    private const CHARS_PER_TOKEN_ESTIMATE = 4;

    public function countForProvider(string $provider, array $messages): int
    {
        return match ($provider) {
            'openai' => $this->countOpenAi($messages),
            'anthropic' => $this->countAnthropic($messages),
            default => $this->estimate($messages),
        };
    }

    private function countOpenAi(array $messages): int
    {
        // OpenAI uses tiktoken; approximation: ~4 chars per token
        // For production, use the tiktoken PHP binding
        return $this->estimate($messages);
    }

    private function countAnthropic() messages: int)
    {
        // Anthropic uses a similar tokenizer; approximation
        return $this->estimate($messages);
    }

    private function estimate(array $messages): int
    {
        $totalChars = array_sum(array_map(
            fn (AiMessage $m) => mb_strlen($m->content),
            $messages
        ));

        // Add overhead for role tokens (roughly 4 tokens per message)
        $overhead = count($messages) * 4;

        return (int) ceil($totalChars / self::CHARS_PER_TOKEN_ESTIMATE) + $overhead;
    }

    /** Pre-flight quota check: can this user afford this request? */
    public function canAfford(int $userId, array $messages, string $provider): bool
    {
        $tokens = $this->countForProvider($provider, $messages);
        $remaining = app(\App\Domains\Ai\Repositories\AiUsageRepository::class)
            ->remainingQuota($userId, now()->format('Y-m'));

        return $tokens <= $remaining;
    }
}
```

# 9. Prompt Engineering Patterns

### 9.1 System Prompt Composition

System prompts are assembled from templates with variable injection:

```php
namespace App\Domains\Ai\Services;

final class PromptComposer
{
    public function __construct(
        private readonly PromptTemplateRenderer $renderer,
        private readonly \App\Domains\Ai\Repositories\AiPromptTemplateRepository $templates,
    ) {}

    public function composeSystemPrompt(string $templateKey, array $variables): string
    {
        $template = $this->templates->findByKey($templateKey);
        if (! $template) {
            throw new \App\Domains\Ai\Exceptions\PromptTemplateNotFoundException($templateKey);
        }

        return $this->renderer->render($template->prompt, $variables);
    }

    /** Compose a full conversation with system prompt + user messages */
    public function composeConversation(
        string $systemTemplateKey,
        array $systemVars,
        array $userMessages,
    ): array {
        $systemPrompt = $this->composeSystemPrompt($systemTemplateKey, $systemVars);

        $messages = [new AiMessage(role: 'system', content: $systemPrompt)];

        foreach ($userMessages as $msg) {
            $messages[] = is_string($msg)
                ? new AiMessage(role: 'user', content: $msg)
                : $msg;
        }

        return $messages;
    }
}
```

### 9.3 Few-Shot Prompting

For high-quality output, the engine injects few-shot examples:

```php
namespace App\Domains\Ai\Services;

final class FewShotProvider
{
    private const EXAMPLES_DIR = resource_path('ai/few-shot');

    public function injectExamples(string $prompt, string $task, int $count = 3): string
    {
        $examples = $this->loadExamples($task, $count);
        if ($examples === []) {
            return $prompt;
        }

        $exampleBlock = "Here are some examples:\n\n";
        foreach ($examples as $i => $example) {
            $exampleBlock .= "Example " . ($i + 1) . ":\n";
            $exampleBlock .= "Input: {$example['input']}\n";
            $exampleBlock .= "Output: {$example['output']}\n\n";
        }

        return $exampleBlock . $prompt;
    }

    private function loadExamples(string $task, int $limit): array
    {
        $path = self::EXAMPLES_DIR . "/{$task}.json";
        if (! file_exists($path)) {
            return [];
        }
        $all = json_decode(file_get_contents($path), true) ?? [];
        return array_slice($all, 0, $limit);
    }
}
```

# 10. Streaming Protocols

### 10.1 Server-Sent Events (SSE)

For browser clients that don't support WebSocket, the engine falls back to SSE:

```php
namespace App\Domains\Ai\Http\Controllers;

use App\Http\Controllers\Controller;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\StreamedResponse;

class AiStreamController extends Controller
{
    public function stream(Request $request): StreamedResponse
    {
        $messages = $request->input('messages');
        $conversationId = $request->input('conversation_id');

        return new StreamedResponse(function () use ($messages, $conversationId) {
            $engine = app(\App\Domains\Ai\Services\AiEngine::class);

            echo "event: start\ndata: {\"conversation_id\": \"{$conversationId}\"}\n\n";
            ob_flush();
            flush();

            foreach ($engine->streamConversation($messages, [], function ($completion) use ($conversationId) {
                // Persist the full response
                app(\App\Domains\Ai\Services\AiUsageRecorder::class)->record(
                    userId: auth()->id(),
                    conversationId: $conversationId,
                    c: $completion,
                    provider: $completion->model,
                );
            }) as $token) {
                $escapedToken = json_encode($token);
                echo "event: token\ndata: {$escapedToken}\n\n";
                ob_flush();
                flush();
            }

            echo "event: done\ndata: {}\n\n";
            ob_flush();
            flush();
        }, 200, [
            'Content-Type' => 'text/event-stream',
            'Cache-Control' => 'no-cache',
            'X-Accel-Buffering' => 'no',
        ]);
    }
}
```

### 11.2 Retry Strategy

The engine implements exponential backoff with jitter:

```php
namespace App\Domains\Ai\Services;

final class AiRetryStrategy
{
    private const MAX_RETRIES = 3;
    private const BASE_DELAY_MS = 500;

    public function retryWithBackoff(callable $operation, string $provider): mixed
    {
        $lastException = null;

        for ($attempt = 0; $attempt <= self::MAX_RETRIES; $attempt++) {
            try {
                return $operation();
            } catch (AiRateLimitException $e) {
                $lastException = $e;
                if ($attempt < self::MAX_RETRIES) {
                    $delay = self::BASE_DELAY_MS * (2 ** $attempt);
                    $jitter = random_int(0, (int) ($delay * 0.1));
                    usleep(($delay + $jitter) * 1000);
                }
            } catch (AiProviderException $e) {
                if ($e->statusCode >= 500 && $attempt < self::MAX_RETRIES) {
                    $lastException = $e;
                    $delay = self::BASE_DELAY_MS * (2 ** $attempt);
                    usleep($delay * 1000);
                } else {
                    throw $e;
                }
            }
        }

        throw $lastException;
    }
}
```

| Status Code | Retryable | Strategy |
| --- | --- | --- |
| 429 (Rate Limit) | Yes | Exponential backoff with jitter |
| 500 (Server Error) | Yes | Exponential backoff |
| 502 (Bad Gateway) | Yes | Exponential backoff |
| 503 (Service Unavailable) | Yes | Exponential backoff |
| 401 (Unauthorized) | No | Throw immediately |
| 400 (Bad Request) | No | Throw immediately |
| 408 (Timeout) | Yes | One retry, then throw |

# 12. Cost Optimization

### 12.1 Model Selection by Task

Different tasks use different models based on cost/quality tradeoffs:

```php
namespace App\Domains\Ai\Services;

final class ModelRouter
{
    private const TASK_MODEL_MAP = [
        'component.generate' => 'gpt-4o',          // high quality needed
        'component.document' => 'claude-sonnet-4-20250514', // good at documentation
        'snippet.explain' => 'gemini-2.0-flash',  // fast, cheap
        'code.review' => 'gpt-4o',                // high quality needed
        'theme.generate' => 'gpt-4o',             // creative task
        'quick.question' => 'gemini-2.0-flash',   // fast response
    ];

    public function modelForTask(string $task): string
    {
        return self::TASK_MODEL_MAP[$task] ?? config('ai.default_model', 'gpt-4o');
    }

    public function costEstimate(string $task, int $promptTokens, int $completionTokens): float
    {
        $model = $this->modelForTask($task);
        $pricing = config("ai.pricing.{$model}", ['prompt' => 0.005, 'completion' => 0.015]);

        return ($promptTokens * $pricing['prompt'] + $completionTokens * $pricing['completion']) / 1000;
    }
}
```

### 12.3 Budget Management

```php
namespace App\Domains\Ai\Services;

final class AiBudgetManager
{
    public function __construct(
        private readonly \App\Domains\Ai\Repositories\AiUsageRepository $usage,
    ) {}

    public function remainingBudget(int $userId, string $month): float
    {
        $spent = $this->usage->spendForUser($userId, $month);
        $budget = $this->monthlyBudget($userId);

        return max(0, $budget - $spent);
    }

    public function isOverBudget(int $userId, string $month): bool
    {
        return $this->remainingBudget($userId, $month) <= 0;
    }

    private function monthlyBudget(int $userId): float
    {
        $user = \App\Models\User::find($userId);
        $plan = $user?->subscription('default')?->stripe_price;

        return match ($plan) {
            'pro' => 100.00,
            'team' => 500.00,
            'enterprise' => 2000.00,
            default => 10.00,
        };
    }
}

### 13.2 Context Window Management

LLMs have context limits. The engine truncates old messages while preserving the system prompt:

```php
namespace App\Domains\Ai\Services;

final class ContextWindowManager
{
    public function __construct(
        private readonly TokenCounter $tokenCounter,
    ) {}

    public function fitToWindow(
        array $messages,
        int $maxTokens,
        string $provider,
    ): array {
        $systemMessages = array_filter($messages, fn ($m) => $m->role === 'system');
        $conversationMessages = array_filter($messages, fn ($m) => $m->role !== 'system');

        $systemTokens = $this->tokenCounter->countForProvider($provider, $systemMessages);
        $availableForConversation = $maxTokens - $systemTokens - 100; // 100 token buffer

        $total = 0;
        $fitted = [];
        $conversationMessages = array_reverse($conversationMessages);

        foreach ($conversationMessages as $msg) {
            $msgTokens = $this->tokenCounter->countForProvider($provider, [$msg]);
            if ($total + $msgTokens > $availableForConversation) {
                break;
            }
            $total += $msgTokens;
            $fitted[] = $msg;
        }

        return array_merge($systemMessages, array_reverse($fitted));
    }
}

# 19. Fallback Chains

```php
namespace App\Domains\Ai\Services;

final class AiFallbackChain
{
    private array $providers;

    public function __construct()
    {
        $this->providers = config('ai.fallback_chain', ['openai', 'anthropic', 'google']);
    }

    public function execute(array $messages, array $options, callable $operation): mixed
    {
        $lastException = null;

        foreach ($this->providers as $providerName) {
            try {
                $provider = app(\App\Domains\Ai\Services\AiProviderResolver::class)
                    ->resolveForProvider($providerName);

                return $operation($provider);
            } catch (\Throwable $e) {
                $lastException = $e;
                \Illuminate\Support\Facades\Log::warning("AI provider {$providerName} failed, trying next", [
                    'error' => $e->getMessage(),
                ]);
            }
        }

        throw $lastException ?? new \App\Domains\Ai\Exceptions\NoAiProviderConfiguredException();
    }
}

```php
namespace App\Domains\Ai\Services;

final class StreamingBuffer
{
    private string $buffer = '';
    private int $bufferSize = 0;
    private const MAX_BUFFER_SIZE = 65536; // 64KB

    public function append(string $chunk): void
    {
        $this->buffer .= $chunk;
        $this->bufferSize += mb_strlen($chunk);

        if ($this->bufferSize >= self::MAX_BUFFER_SIZE) {
            $this->flush();
        }
    }

    public function flush(): string
    {
        $content = $this->buffer;
        $this->buffer = '';
        $this->bufferSize = 0;
        return $content;
    }

    public function remaining(): string
    {
        return $this->buffer;
    }
}

        ]);

# 26. AI Model Routing Strategy (Advanced)

### 26.1 Task Complexity Detection

The engine automatically detects task complexity and routes to the optimal model:

```php
namespace App\Domains\Ai\Services;

final class TaskComplexityAnalyzer
{
    private const COMPLEXITY_SIGNALS = [
        'code_generation' => 'high',
        'architecture_design' => 'high',
        'bug_analysis' => 'high',
        'refactoring' => 'high',
        'component_generation' => 'medium',
        'documentation' => 'medium',
        'theme_generation' => 'medium',
        'quick_question' => 'low',
        'simple_edit' => 'low',
        'formatting' => 'low',
    ];

    public function analyze(string $taskType, string $input): string
    {
        $baseComplexity = self::COMPLEXITY_SIGNALS[$taskType] ?? 'medium';

        // Adjust based on input characteristics
        $inputLength = mb_strlen($input);
        if ($inputLength > 5000) {
            $baseComplexity = $this->upgradeComplexity($baseComplexity);
        }

        // Check for code blocks (indicates technical task)
        if (preg_match('/```[\s\S]*```/', $input)) {
            $baseComplexity = $this->upgradeComplexity($baseComplexity);
        }

        // Check for multiple requirements
        $requirementCount = substr_count($input, "\n") + 1;
        if ($requirementCount > 5) {
            $baseComplexity = $this->upgradeComplexity($baseComplexity);
        }

        return $baseComplexity;
    }

    private function upgradeComplexity(string $current): string
    {
        return match ($current) {
            'low' => 'medium',
            'medium' => 'high',
            default => 'high',
        };
    }
}

        $result = $this->engine->provider()->complete($summaryPrompt, [
            'max_tokens' => 500,
            'temperature' => 0.3,
        ]);

        // Store summary as a system message
        $this->conversation->addMessage($conversationId, 'system', "[Summary]\n{$result->content}");

        // Trim old messages
        $this->trimOldMessages($conversationId, 20);

        return $result->content;
    }

    private function formatForSummary(array $messages): string
    {
        return implode("\n\n", array_map(function ($msg) {
            $role = $msg->role === 'user' ? 'User' : 'Assistant';
            return "{$role}: {$msg->content}";
        }, $messages));
    }

    private function trimOldMessages(int $conversationId, int $keepCount): void
    {
        $messages = $this->conversation->getHistory($conversationId, 100);
        if (count($messages) <= $keepCount) return;

        $toRemove = array_slice($messages, 0, count($messages) - $keepCount);
        foreach ($toRemove as $msg) {
            // Remove old messages (keep summary)
            if (! str_starts_with($msg->content, '[Summary]')) {
                $msg->delete();
            }
        }
    }
}

# 29. AI Response Quality Scoring

### 29.1 Quality Metrics

```php
namespace App\Domains\Ai\Services;

final class AiQualityScorer
{
    public function score(string $input, string $output, string $taskType): QualityScore
    {
        $scores = [];

        // Relevance score
        $scores['relevance'] = $this->scoreRelevance($input, $output);

        // Completeness score
        $scores['completeness'] = $this->scoreCompleteness($input, $output, $taskType);

        // Coherence score
        $scores['coherence'] = $this->scoreCoherence($output);

        // Format compliance
        $scores['format'] = $this->scoreFormat($output, $taskType);

        // Code quality (for code tasks)
        if (in_array($taskType, ['code_generation', 'bug_analysis', 'refactoring'])) {
            $scores['code_quality'] = $this->scoreCodeQuality($output);
        }

        $overall = array_sum($scores) / count($scores);

        return new QualityScore(
            overall: round($overall, 2),
            breakdown: $scores,
        );
    }

    private function scoreRelevance(string $input, string $output): float
    {
        // Simple keyword overlap scoring
        $inputWords = array_unique(str_word_count(strtolower($input), 1));
        $outputWords = array_unique(str_word_count(strtolower($output), 1));

        $intersection = array_intersect($inputWords, $outputWords);
        $union = array_unique(array_merge($inputWords, $outputWords));

        return count($union) > 0 ? round(count($intersection) / count($union), 2) : 0;
    }

    private function scoreCompleteness(string $input, string $output, string $taskType): float
    {
        // Check if output addresses all parts of the input
        $requirements = $this->extractRequirements($input);
        if (empty($requirements)) return 1.0;

        $addressed = 0;
        foreach ($requirements as $req) {
            if (stripos($output, $req) !== false || $this->semanticallyMatches($req, $output)) {
                $addressed++;
            }
        }

        return round($addressed / count($requirements), 2);
    }

    private function scoreCoherence(string $output): float
    {
        // Check for logical flow and consistency
        $sentences = preg_split('/[.!?]+/', $output);
        $score = 1.0;

        // Penalize very short or very long responses
        $wordCount = str_word_count($output);
        if ($wordCount < 10) $score -= 0.3;
        if ($wordCount > 2000) $score -= 0.2;

        // Check for repetition
        $uniqueWords = array_unique(str_word_count(strtolower($output), 1));
        $repetition = 1 - (count($uniqueWords) / max($wordCount, 1));
        if ($repetition > 0.5) $score -= 0.3;

        return max(0, round($score, 2));
    }

    private function scoreFormat(string $output, string $taskType): float
    {
        $score = 1.0;

        // Check markdown formatting for documentation tasks
        if ($taskType === 'documentation') {
            if (! preg_match('/^#+\s/m', $output)) $score -= 0.2;
            if (! preg_match('/```/', $output)) $score -= 0.1;
        }

        // Check code block formatting for code tasks
        if (in_array($taskType, ['code_generation', 'bug_analysis'])) {
            if (! preg_match('/```/', $output)) $score -= 0.3;
        }

        return max(0, round($score, 2));
    }

    private function scoreCodeQuality(string $output): float
    {
        $score = 1.0;

        // Extract code blocks
        preg_match_all('/```(\w+)?\n([\s\S]*?)```/', $output, $matches);

        foreach ($matches[2] as $code) {
            // Check for common issues
            if (preg_match('/(TODO|FIXME|HACK|XXX)/', $code)) $score -= 0.1;
            if (preg_match('/eval\s*\(/', $code)) $score -= 0.3;
            if (preg_match('/(exec|shell_exec|system)\s*\(/', $code)) $score -= 0.2;
            if (substr_count($code, "\n") > 100) $score -= 0.1; // Very long code
        }

        return max(0, round($score, 2));
    }

    private function extractRequirements(string $input): array
    {
        $requirements = [];

        // Look for numbered lists
        if (preg_match_all('/^\s*\d+[\.\)]\s*(.+)/m', $input, $matches)) {
            $requirements = array_merge($requirements, $matches[1]);
        }

        // Look for bullet points
        if (preg_match_all('/^\s*[-*]\s*(.+)/m', $input, $matches)) {
            $requirements = array_merge($requirements, $matches[1]);
        }

        return array_slice($requirements, 0, 10);
    }

    private function semanticallyMatches(string $requirement, string $output): bool
    {
        // Simple word-based matching
        $reqWords = array_unique(str_word_count(strtolower($requirement), 1));
        $outWords = array_unique(str_word_count(strtolower($output), 1));

        $overlap = count(array_intersect($reqWords, $outWords));
        return $overlap >= count($reqWords) * 0.5;
    }
}

final readonly class QualityScore
{
    public function __construct(
        public float $overall,
        public array $breakdown,
    ) {}
}

# 30. AI Error Recovery

### 30.1 Graceful Degradation

When the primary AI provider fails, the engine degrades gracefully:

```php
namespace App\Domains\Ai\Services;

final class AiGracefulDegradation
{
    public function __construct(
        private readonly AiFallbackChain $fallback,
        private readonly AiResponseCache $cache,
    ) {}

    public function executeWithFallback(array $messages, array $options, string $taskType): AiCompletion
    {
        // Try primary provider
        try {
            return $this->executePrimary($messages, $options);
        } catch (\Throwable $e) {
            \Illuminate\Support\Facades\Log::warning("AI primary provider failed", [
                'error' => $e->getMessage(),
                'task' => $taskType,
            ]);
        }

        // Try fallback providers
        try {
            return $this->fallback->execute($messages, $options, function ($provider) use ($messages, $options) {
                return $provider->complete($messages, $options);
            });
        } catch (\Throwable $e) {
            \Illuminate\Support\Facades\Log::error("AI fallback providers failed", [
                'error' => $e->getMessage(),
            ]);
        }

        // Try cached response
        $cached = $this->cache->remember(
            $this->cache->cacheKey($messages, $options),
            fn () => null
        );

        if ($cached) {
            return $cached;
        }

        // Return a helpful error message
        return new AiCompletion(
            content: "I'm sorry, I'm currently experiencing technical difficulties. Please try again later or contact support.",
            promptTokens: 0,
            completionTokens: 0,
            model: 'fallback',
        );
    }

    private function executePrimary(array $messages, array $options): AiCompletion
    {
        $provider = app(AiProviderResolver::class)->resolveForUser(auth()->id());
        return $provider->complete($messages, $options);
    }
}

# 07.42 - Blog

**Project:** GsmUi
**Architecture:** Blog Content Service + Feed Generation
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `05.27-blog-engine.md` (post management, categories/tags, RSS/feeds, SEO). This document is the *implementation contract*: the `BlogService`, the scheduling/publishing workflow, RSS/Atom/JSON feed generation, and category/tag management. Blog posts reuse the CMS block + revision primitives (`07.41-cms.md`).

# Purpose

The Blog Engine is the CMS's richest content type: posts support draft/scheduled/published states, hierarchical categories, free tags, and three feed formats (RSS 2.0, Atom, JSON Feed). Posts are authored with the same block model as pages, so rendering, revisions, and SEO are shared. The differences are scheduling, taxonomy, and feeds — all owned by `BlogService`.

`BlogService` composes the CMS `ContentService` for block/revision storage and adds: scheduled publishing via the scheduler (`07.50-scheduler.md`), taxonomy assignment through `TaxonomyService`, and feed rendering through `FeedService`. Posts are indexed into Meilisearch via Scout (`07.xx-search`); published posts sync automatically on the `PostPublished` event.

Goals:

- Scheduled posts publish exactly once via a due-job, not by request-time checks.
- Categories are hierarchical; tags are flat — both resolved through one `TaxonomyService`.
- Feeds are generated from a single source method, serialized to RSS/Atom/JSON.
- Publishing emits `PostPublished` so Scout + full-page cache update without polling.

## 1. Blog Service

`BlogService` wraps CMS primitives and adds blog-specific state (scheduling, author, taxonomy). It reuses `ContentService::create` semantics but stores posts in the `posts` table with a `published_at` and `publish_state`.

```php
namespace App\Domains\Blog\Services;

use App\Domains\Blog\DTOs\PostData;
use App\Domains\Blog\Enums\PublishState;
use App\Domains\Blog\Events\PostPublished;

final class BlogService
{
    public function __construct(
        private readonly \App\Domains\Cms\Services\ContentService $cms,
        private readonly \App\Domains\Blog\Services\TaxonomyService $taxonomy,
        private readonly \App\Domains\Blog\Repositories\PostRepository $posts,
    ) {}

    public function draft(PostData $data): \App\Domains\Blog\Models\Post
    {
        $post = $this->posts->create($data->metaOnly()); // title, slug, excerpt, author
        $this->cms->saveBlocks($post, $data->blocks);     // revision snapshot

        if ($data->categoryIds || $data->tagIds) {
            $this->taxonomy->assign($post, $data->categoryIds, $data->tagIds);
        }

        return $post;
    }

    public function schedule(string $slug, \Illuminate\Support\Carbon $at): void
    {
        $post = $this->posts->findBySlug($slug);
        $post->published_at = $at;
        $post->publish_state = PublishState::Scheduled;
        $post->saveQuietly();

        \App\Domains\Blog\Jobs\PublishScheduledPost::dispatch($post->id)->delay($at);
    }

    public function publishNow(string $slug): void
    {
        $post = $this->posts->findBySlug($slug);
        $post->publish_state = PublishState::Published;
        $post->published_at = $post->published_at ?? now();
        $post->saveQuietly();

        PostPublished::dispatch($post->slug);
    }
}
```

Usage:

```php
$post = app(\App\Domains\Blog\Services\BlogService::class)->draft(PostData::from([
    'title' => 'Introducing GsmUi 2.15',
    'slug' => 'introducing-gsmui-2-15',
    'excerpt' => 'What is new in this release.',
    'blocks' => [['type' => 'rich_text', 'content' => '<p>...</p>']],
    'categoryIds' => [3], 'tagIds' => [7, 9],
]));

app(\App\Domains\Blog\Services\BlogService::class)
    ->schedule($post->slug, Carbon::parse('2026-08-01 09:00'));
```

## 2. Taxonomy Service

`TaxonomyService` manages hierarchical categories and flat tags, attaching them to a post through pivot tables. It resolves the category breadcrumb for breadcrumbs/SEO and de-duplicates tags on assignment.

```php
namespace App\Domains\Blog\Services;

final class TaxonomyService
{
    public function assign(\App\Domains\Blog\Models\Post $post, array $categoryIds, array $tagIds): void
    {
        $post->categories()->sync($categoryIds);
        $post->tags()->sync(array_unique($tagIds));
    }

    /** @return string[] breadcrumb from root → leaf */
    public function breadcrumb(int $categoryId): array
    {
        $chain = [];
        $node = \App\Domains\Blog\Models\Category::find($categoryId);

        while ($node) {
            array_unshift($chain, $node->name);
            $node = $node->parent;
        }

        return $chain;
    }

    /** @return array<int, int> tag id → usage count (for tag cloud) */
    public function tagCloud(int $limit = 30): array
    {
        return \App\Domains\Blog\Models\Tag::withCount('posts')
            ->orderByDesc('posts_count')->limit($limit)
            ->pluck('posts_count', 'id')->all();
    }
}
```

## 3. Scheduled Publishing Job

Scheduling dispatches a delayed job (`07.49-queues.md`) so publishing is crash-safe and idempotent. The job re-checks state to avoid double-publish if the post was published manually first.

```php
namespace App\Domains\Blog\Jobs;

use App\Domains\Blog\Models\Post;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;

final class PublishScheduledPost implements ShouldQueue
{
    use Queueable, InteractsWithQueue, SerializesModels;

    public function __construct(public int $postId) {}

    public function handle(): void
    {
        $post = Post::find($this->postId);
        if (! $post || $post->publish_state === \App\Domains\Blog\Enums\PublishState::Published) {
            return; // already handled
        }

        $post->publish_state = \App\Domains\Blog\Enums\PublishState::Published;
        $post->saveQuietly();

        \App\Domains\Blog\Events\PostPublished::dispatch($post->slug);
    }
}
```

## 4. Feed Service

`FeedService` renders one normalized post list into RSS 2.0, Atom, or JSON Feed. The source query is shared; only serialization differs. Feeds are cached for the `feed_ttl` and busted on `PostPublished`.

```php
namespace App\Domains\Blog\Services;

use App\Domains\Blog\Enums\FeedFormat;

final class FeedService
{
    public function __construct(
        private readonly \App\Domains\Blog\Repositories\PostRepository $posts,
        private readonly \Illuminate\Contracts\Cache\Repository $cache,
    ) {}

    public function render(FeedFormat $format, int $limit = 20): string
    {
        return $this->cache->remember("feed:{$format->value}", 600, function () use ($format, $limit): string {
            $items = $this->posts->published()->latest('published_at')->limit($limit)->get();

            return match ($format) {
                FeedFormat::Rss  => $this->rss($items),
                FeedFormat::Atom => $this->atom($items),
                FeedFormat::Json => $this->json($items),
            };
        });
    }

    private function rss($items): string
    {
        $entries = $items->map(fn ($p) => "<item><title>{$p->title}</title>"
            . "<link>" . route('blog.show', $p->slug) . "</link>"
            . "<pubDate>{$p->published_at->toRfc822String()}</pubDate></item>")->implode("\n");

        return "<?xml version=\"1.0\"?><rss version=\"2.0\"><channel>{$entries}</channel></rss>";
    }

    private function atom($items): string { /* Atom 1.0 serialization */ return ''; }
    private function json($items): string { return json_encode(['items' => $items]); }
}
```

| Format | Content-Type | Route |
| --- | --- | --- |
| RSS 2.0 | `application/rss+xml` | `GET /blog/feed/rss` |
| Atom | `application/atom+xml` | `GET /blog/feed/atom` |
| JSON Feed | `application/feed+json` | `GET /blog/feed/json` |

## 5. SEO & Search Sync

On `PostPublished`, a listener purges the post's full-page cache, pushes the post to Meilisearch (Scout `Searchable`), and regenerates the sitemap. Categories/tags also get their own indexable pages.

```php
use App\Domains\Blog\Events\PostPublished;

final class SyncPostOnPublish
{
    public function handle(PostPublished $e): void
    {
        $post = \App\Domains\Blog\Models\Post::where('slug', $e->slug)->firstOrFail();
        $post->searchable();                       // Scout → Meilisearch
        \Illuminate\Support\Facades\Cache::forget("page:blog:{$post->slug}");
        \App\Domains\Seo\Services\SitemapService::regenerate();
    }
}
```

## 6. Request Flow

```text
Editor ──► BlogService::draft
              ├─ CMS ContentService (blocks + revision)
              ├─ TaxonomyService (categories/tags)
              └─ posts row (publish_state = draft)
      │
BlogService::schedule ──► PublishScheduledPost (delayed job)
      │                        │
      │                   PostPublished event
      │                        ├─ Scout index
      │                        ├─ cache purge
      │                        └─ sitemap regen
      │
GET /blog/feed/rss ──► FeedService::render(Rss) ──► cached XML
```

```php
    {

    }
```

```php
            if ($rules['required'] && ($value === null || $value === '')) {
                $errors[] = "{$field} is required for {$format->value} format";
```

## 8. Comment System

### 8.1 Comment Service

```php
namespace App\Domains\Blog\Services;

final class CommentService
{
    public function __construct(
        private readonly \App\Domains\Blog\Repositories\CommentRepository $comments,
        private readonly \App\Domains\Admin\Services\ModerationService $moderation,
    ) {}

    public function add(int $postId, string $userId, string $body, ?int $parentId = null): \App\Domains\Blog\Models\Comment
    {
        $post = \App\Domains\Blog\Models\Post::findOrFail($postId);

        if (! $post->comments_enabled) {
            throw new \App\Domains\Blog\Exceptions\CommentsDisabledException();
        }

        return $this->comments->create([
            'post_id' => $postId,
            'user_id' => $userId,
            'parent_id' => $parentId,
            'body' => $body,
            'status' => 'pending', // requires moderation
            'created_at' => now(),
        ]);
    }

    public function approve(int $commentId): void
    {
        $comment = $this->comments->find($commentId);
        $this->moderation->decide($comment, \App\Domains\Admin\Enums\ModerationStatus::Approved);
    }

    public function reject(int $commentId, string $reason): void
    {
        $comment = $this->comments->find($commentId);
        $this->moderation->decide($comment, \App\Domains\Admin\Enums\ModerationStatus::Rejected, $reason);
    }

    /** @return \App\Domains\Blog\Models\Comment[] */
    public function forPost(int $postId, string $status = 'approved'): array
    {
        return $this->comments->forPost($postId, $status);
    }

    public function count(int $postId): int
    {
        return $this->comments->countForPost($postId, 'approved');
    }

    public function threaded(int $postId): array
    {
        $comments = $this->forPost($postId);
        return $this->buildThread($comments);
    }

    private function buildThread(array $comments, int $parentId = null): array
    {
        $thread = [];
        foreach ($comments as $comment) {
            if ($comment->parent_id === $parentId) {
                $comment->replies = $this->buildThread($comments, $comment->id);
                $thread[] = $comment;
            }
        }
        return $thread;
    }
}
```

### 8.3 Comment Spam Detection

```php
namespace App\Domains\Blog\Services;

final class CommentSpamDetector
{
    public function isSpam(string $body, string $userId): SpamCheckResult
    {
        $score = 0;
        $reasons = [];

        // Check for excessive links
        $linkCount = preg_match_all('/https?:\/\//i', $body);
        if ($linkCount > 3) {
            $score += 30;
            $reasons[] = 'excessive_links';
        }

        // Check for ALL CAPS
        if (mb_strlen($body) > 20 && preg_match('/^[A-Z\s!?]{20,}$/', $body)) {
            $score += 20;
            $reasons[] = 'all_caps';
        }

        // Check for repeated characters
        if (preg_match('/(.)\1{4,}/', $body)) {
            $score += 25;
            $reasons[] = 'repeated_characters';
        }

        // Check user's comment history
        $userCommentCount = app(\App\Domains\Blog\Repositories\CommentRepository::class)
            ->countForUser($userId);
        if ($userCommentCount === 0) {
            $score += 10;
            $reasons[] = 'first_comment';
        }

        return new SpamCheckResult(
            isSpam: $score >= 50,
            score: $score,
            reasons: $reasons,
        );
    }
}

final readonly class SpamCheckResult
{
    public function __construct(
        public bool $isSpam,
        public int $score,
        public array $reasons,
    ) {}
}
```

```php
        foreach ($activeSubscribers as $subscriber) {
            \App\Domains\Blog\Jobs\SendNewsletterEmail::dispatch($subscriber, $post)
                ->onQueue('emails');
        }
    }

    public function stats(): array
    {
        return [
            'total' => $this->subscribers->count(),
            'active' => $this->subscribers->active()->count(),
            'unsubscribed' => $this->subscribers->whereNotNull('unsubscribed_at')->count(),
        ];
    }
}
```

## 11. Related Posts

### 11.1 Related Posts Algorithm

```php
namespace App\Domains\Blog\Services;

final class RelatedPostsService
{
    public function __construct(
        private readonly \App\Domains\Blog\Repositories\PostRepository $posts,
    ) {}

    /** @return \App\Domains\Blog\Models\Post[] */
    public function forPost(int $postId, int $limit = 5): array
    {
        $post = $this->posts->find($postId);

        // Score based on shared categories, tags, and content similarity
        $candidates = $this->posts->published()
            ->where('id', '!=', $postId)
            ->get();

        $scored = $candidates->map(function ($candidate) use ($post) {
            $score = 0;

            // Shared categories (weight: 3)
            $sharedCategories = $post->categories->pluck('id')
                ->intersect($candidate->categories->pluck('id'))
                ->count();
            $score += $sharedCategories * 3;

            // Shared tags (weight: 2)
            $sharedTags = $post->tags->pluck('id')
                ->intersect($candidate->tags->pluck('id'))
                ->count();
            $score += $sharedTags * 2;

            // Same author (weight: 1)
            if ($post->author_id === $candidate->author_id) {
                $score += 1;
            }

            // Recency bonus (weight: 0.5)
            $daysDiff = abs($post->created_at->diffInDays($candidate->created_at));
            if ($daysDiff < 30) {
                $score += 0.5;
            }

            return ['post' => $candidate, 'score' => $score];
        });

        return $scored->sortByDesc('score')->take($limit)->pluck('post')->all();
    }
}
```

## 12. Reading Time Estimation

### 12.1 Reading Time Calculator

```php
namespace App\Domains\Blog\Services;

final class ReadingTimeService
{
    private const WORDS_PER_MINUTE = 238; // Average reading speed
    private const IMAGES_SECONDS = 12; // Average time per image
    private const CODE_BLOCK_SECONDS = 30; // Average time per code block

    public function estimate(int $postId): ReadingTime
    {
        $post = \App\Domains\Blog\Models\Post::findOrFail($postId);
        $content = $post->renderedContent();

        $wordCount = str_word_count(strip_tags($content));
        $imageCount = substr_count($content, '<img');
        $codeBlockCount = substr_count($content, '<pre');

        $textMinutes = $wordCount / self::WORDS_PER_MINUTE;
        $imageMinutes = ($imageCount * self::IMAGES_SECONDS) / 60;
        $codeMinutes = ($codeBlockCount * self::CODE_BLOCK_SECONDS) / 60;

        $totalMinutes = (int) ceil($textMinutes + $imageMinutes + $codeMinutes);

        return new ReadingTime(
            minutes: max(1, $totalMinutes),
            wordCount: $wordCount,
            imageCount: $imageCount,
            codeBlockCount: $codeBlockCount,
        );
    }
}

final readonly class ReadingTime
{
    public function __construct(
        public int $minutes,
        public int $wordCount,
        public int $imageCount,
        public int $codeBlockCount,
    ) {}

    public function display(): string
    {
        return "{$this->minutes} min read";
    }
}
```

```php
            'slug' => $slug,

    public function addToSeries(int $seriesId, int $postId, int $position): void

            'series_id' => $seriesId,
            'post_id' => $postId,
            'position' => $position,
        ]);
    }

            ->where('series_id', $seriesId)
            ->where('post_id', $postId)
            ->delete();
    }

    /** @return \App\Domains\Blog\Models\Post[] */
    public function posts(int $seriesId): array
    {
        return $this->seriesPosts()
            ->where('series_id', $seriesId)
            ->orderBy('position')
            ->with('post')
            ->get()
            ->pluck('post')
            ->all();
    }

    public function nextPost(int $seriesId, int $currentPostId): ?\App\Domains\Blog\Models\Post
    {
        $posts = $this->posts($seriesId);
        $currentIndex = array_search($currentPostId, array_column($posts, 'id'));

        if ($currentIndex === false || $currentIndex >= count($posts) - 1) {
            return null;
        }

        return $posts[$currentIndex + 1];
    }

    public function previousPost(int $seriesId, int $currentPostId): ?\App\Domains\Blog\Models\Post
    {
        $posts = $this->posts($seriesId);
        $currentIndex = array_search($currentPostId, array_column($posts, 'id'));

        if ($currentIndex === false || $currentIndex <= 0) {
            return null;
        }

        return $posts[$currentIndex - 1];
    }

    {
        return \App\Domains\Blog\Models\SeriesPost::query();
```

```php
final class BlogRevisionService
{
    public function __construct(
        private readonly \App\Domains\Cms\Services\RevisionService $cmsRevisions,
    ) {}

    public function snapshot(\App\Domains\Blog\Models\Post $post, array $blocks, ?string $note = null): \App\Domains\Cms\Models\PageRevision
    {
        return $this->cmsRevisions->snapshot($post, $blocks, $note);
    }

    public function history(\App\Domains\Blog\Models\Post $post): array
    {
        return $this->cmsRevisions->history($post);
    }

    public function restore(\App\Domains\Blog\Models\Post $post, int $revisionId): void
    {
        $this->cmsRevisions->restore($post, $revisionId);
    }

    public function diff(\App\Domains\Blog\Models\Post $post, int $revisionA, int $revisionB): array
    {
        $revA = $this->cmsRevisions->find($post, $revisionA);
        $revB = $this->cmsRevisions->find($post, $revisionB);

        return $this->computeDiff($revA->blocks, $revB->blocks);
    }

    private function computeDiff(array $blocksA, array $blocksB): array
    {
        $diff = [];
        $max = max(count($blocksA), count($blocksB));

        for ($i = 0; $i < $max; $i++) {
            $a = $blocksA[$i] ?? null;
            $b = $blocksB[$i] ?? null;

            if ($a === null) {
                $diff[] = ['type' => 'added', 'block' => $b];
            } elseif ($b === null) {
                $diff[] = ['type' => 'removed', 'block' => $a];
            } elseif ($a !== $b) {
                $diff[] = ['type' => 'changed', 'from' => $a, 'to' => $b];
            }
        }

        return $diff;
    }
}
```

```php
                'value' => mb_strlen($seo->metaDescription),
            ],
            'featured_image' => [
                'label' => 'Featured image set',
                'passed' => ! empty($post->featured_image),
            ],
            'excerpt' => [
                'label' => 'Excerpt exists',
                'passed' => ! empty($post->excerpt),
            ],
            'slug_length' => [
                'label' => 'Slug length (3-50 chars)',
                'passed' => mb_strlen($post->slug) >= 3 && mb_strlen($post->slug) <= 50,
                'value' => mb_strlen($post->slug),
            ],
            'categories' => [
                'label' => 'Has categories',
                'passed' => $post->categories->count() > 0,
            ],
            'tags' => [
                'label' => 'Has tags',
                'passed' => $post->tags->count() > 0,
            ],
            'headings_structure' => [
                'label' => 'Has at least one H2 heading',
                'passed' => str_contains($post->renderedContent(), '<h2'),
            ],
            'internal_links' => [
                'label' => 'Has internal links',
                'passed' => preg_match_all('/href="[^"]*' . config('app.url') . '[^"]*"/', $post->renderedContent()) > 0,
            ],

        $passed = count(array_filter($checks, fn ($c) => $c['passed']));
        $total = count($checks);

        return new SeoChecklist(
            postId: $postId,
            checks: $checks,
            score: (int) round($passed / $total * 100),
        );
    }
```

# 27. Blog Reading Time Calculator

### 27.1 Reading Time Service

```php
namespace App\Domains\Blog\Services;

final class BlogReadingTimeService
{
    private const WORDS_PER_MINUTE = 200;
    private const IMAGE_PENALTY_SECONDS = 12;

    public function calculate(string $markdown, int $imageCount = 0): int
    {
        $wordCount = str_word_count(strip_tags($markdown));
        $readingTimeMinutes = ceil($wordCount / self::WORDS_PER_MINUTE);

        $imageSeconds = $imageCount * self::IMAGE_PENALTY_SECONDS;
        $readingTimeMinutes += ceil($imageSeconds / 60);

        return max(1, (int) $readingTimeMinutes);
    }

    public function format(int $minutes): string
    {
        if ($minutes < 1) return 'Less than 1 min';
        if ($minutes === 1) return '1 min read';
        return "{$minutes} min read";
    }
}
```

### 27.2 Post Excerpt Generator

```php
namespace App\Domains\Blog\Services;

final class BlogExcerptGenerator
{
    private const DEFAULT_LENGTH = 160;

    public function generate(string $markdown, int $maxLength = self::DEFAULT_LENGTH): string
    {
        $plain = strip_tags($markdown);
        $plain = preg_replace('/\s+/', ' ', $plain);
        $plain = trim($plain);

        if (strlen($plain) <= $maxLength) {
            return $plain;
        }

        $truncated = substr($plain, 0, $maxLength);
        $lastSpace = strrpos($truncated, ' ');

        if ($lastSpace !== false) {
            $truncated = substr($truncated, 0, $lastSpace);
        }

        return $truncated . '...';
    }

    public function fromBlocks(array $blocks, int $maxLength = self::DEFAULT_LENGTH): string
    {
        $text = '';

        foreach ($blocks as $block) {
            if ($block['type'] === 'paragraph' && isset($block['data']['content'])) {
                $text .= $block['data']['content'] . ' ';
            }
            if (strlen(strip_tags($text)) >= $maxLength) {
                break;
            }
        }

        return $this->generate($text, $maxLength);
    }
}
```

# 28. Blog RSS Feed Generator

### 28.1 RSS/Atom Feed Service

```php
namespace App\Domains\Blog\Services;

final class BlogFeedGenerator
{
    public function __construct(
        private readonly \App\Domains\Blog\Repositories\BlogPostRepository $posts,
    ) {}

    public function rss(int $limit = 20): string
    {
        $posts = $this->posts->where('status', 'published')
            ->orderByDesc('published_at')
            ->limit($limit)
            ->get();

        $xml = new \SimpleXMLElement('<?xml version="1.0" encoding="UTF-8"?>' .
            '<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom" xmlns:content="http://purl.org/rss/1.0/modules/content/"></rss>');

        $channel = $xml->addChild('channel');
        $channel->addChild('title', config('app.name') . ' Blog');
        $channel->addChild('link', url('/blog'));
        $channel->addChild('description', 'Latest posts from the ' . config('app.name') . ' blog');
        $channel->addChild('language', config('app.locale', 'en'));
        $channel->addChild('lastBuildDate', now()->toRfc2822String());

        foreach ($posts as $post) {
            $item = $channel->addChild('item');
            $item->addChild('title', htmlspecialchars($post->title));
            $item->addChild('link', url("/blog/{$post->slug}"));
            $item->addChild('guid', url("/blog/{$post->slug}"));
            $item->addChild('pubDate', $post->published_at->toRfc2822String());
            $item->addChild('description', htmlspecialchars($post->excerpt ?? ''));

            if ($post->author) {
                $item->addChild('author', htmlspecialchars($post->author->name));
            }

            if ($post->tags) {
                foreach ($post->tags as $tag) {
                    $item->addChild('category', htmlspecialchars($tag->name));
                }
            }

            $encoded = $item->addChild('content:encoded', '', 'http://purl.org/rss/1.0/modules/content/');
            $encoded[0] = $this->renderBlocks($post->blocks);
        }

        return $xml->asXML();
    }

    public function atom(int $limit = 20): string
    {
        $posts = $this->posts->where('status', 'published')
            ->orderByDesc('published_at')
            ->limit($limit)
            ->get();

        $xml = new \SimpleXMLElement('<?xml version="1.0" encoding="UTF-8"?>' .
            '<feed xmlns="http://www.w3.org/2005/Atom"></feed>');

        $xml->addChild('title', config('app.name') . ' Blog');
        $xml->addChild('link', url('/blog'))->addAttribute('rel', 'alternate');
        $xml->addChild('link', url('/blog/feed.atom'))->addAttribute('rel', 'self');
        $xml->addChild('id', url('/blog'));
        $xml->addChild('updated', now()->toIso8601String());

        $author = $xml->addChild('author');
        $author->addChild('name', config('app.name'));

        foreach ($posts as $post) {
            $entry = $xml->addChild('entry');
            $entry->addChild('title', htmlspecialchars($post->title));
            $entry->addChild('link', url("/blog/{$post->slug}"))->addAttribute('rel', 'alternate');
            $entry->addChild('id', url("/blog/{$post->slug}"));
            $entry->addChild('published', $post->published_at->toIso8601String());
            $entry->addChild('updated', $post->updated_at->toIso8601String());
            $entry->addChild('summary', htmlspecialchars($post->excerpt ?? ''));
            $entry->addChild('content', $this->renderBlocks($post->blocks))->addAttribute('type', 'html');

            if ($post->author) {
                $authorEntry = $entry->addChild('author');
                $authorEntry->addChild('name', htmlspecialchars($post->author->name));
            }
        }

        return $xml->asXML();
    }

    public function jsonFeed(int $limit = 20): string
    {
        $posts = $this->posts->where('status', 'published')
            ->orderByDesc('published_at')
            ->limit($limit)
            ->get();

        $feed = [
            'version' => 'https://jsonfeed.org/version/1',
            'title' => config('app.name') . ' Blog',
            'home_page_url' => url('/blog'),
            'feed_url' => url('/blog/feed.json'),
            'items' => $posts->map(fn ($post) => [
                'id' => url("/blog/{$post->slug}"),
                'url' => url("/blog/{$post->slug}"),
                'title' => $post->title,
                'content_html' => $this->renderBlocks($post->blocks),
                'summary' => $post->excerpt,
                'date_published' => $post->published_at->toIso8601String(),
                'date_modified' => $post->updated_at->toIso8601String(),
                'author' => $post->author ? ['name' => $post->author->name] : null,
                'tags' => $post->tags->pluck('name')->toArray(),
            ])->toArray(),
        ];

        return json_encode($feed, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
    }

    private function renderBlocks(array $blocks): string
    {
        $html = '';
        foreach ($blocks as $block) {
            switch ($block['type']) {
                case 'paragraph':
                    $html .= '<p>' . e($block['data']['content'] ?? '') . '</p>';
                    break;
                case 'heading':
                    $level = $block['data']['level'] ?? 2;
                    $html .= "<h{$level}>" . e($block['data']['content'] ?? '') . "</h{$level}>";
                    break;
                case 'code':
                    $html .= '<pre><code>' . e($block['data']['code'] ?? '') . '</code></pre>';
                    break;
                case 'image':
                    $src = e($block['data']['src'] ?? '');
                    $alt = e($block['data']['alt'] ?? '');
                    $html .= "<img src=\"{$src}\" alt=\"{$alt}\" />";
                    break;
            }
        }
        return $html;
    }
}
```

### 29.1 Series Management

```php
namespace App\Domains\Blog\Services;

final class BlogSeriesService
{
    public function create(string $name, string $description, ?string $slug = null): \App\Domains\Blog\Models\BlogSeries
    {
        return \App\Domains\Blog\Models\BlogSeries::create([
            'name' => $name,
            'slug' => $slug ?: $this->generateSlug($name),
            'description' => $description,
            'posts_count' => 0,
        ]);
    }

    public function addToSeries(string $seriesId, string $postId, int $order): void
    {
        $post = \App\Models\BlogPost::findOrFail($postId);
        $post->update([
            'series_id' => $seriesId,
            'series_order' => $order,
        ]);

        $series = \App\Domains\Blog\Models\BlogSeries::findOrFail($seriesId);
        $series->update(['posts_count' => $series->posts()->count()]);
    }

    public function removeFromSeries(string $postId): void
    {
        $post = \App\Models\BlogPost::findOrFail($postId);
        $seriesId = $post->series_id;
        $post->update(['series_id' => null, 'series_order' => null]);

        if ($seriesId) {
            $series = \App\Domains\Blog\Models\BlogSeries::findOrFail($seriesId);
            $series->update(['posts_count' => $series->posts()->count()]);
        }
    }

    public function nextInSeries(string $postId): ?\App\Models\BlogPost
    {
        $post = \App\Models\BlogPost::findOrFail($postId);

        if (! $post->series_id) return null;

        return \App\Models\BlogPost::where('series_id', $post->series_id)
            ->where('series_order', '>', $post->series_order)
            ->orderBy('series_order')
            ->first();
    }

    public function previousInSeries(string $postId): ?\App\Models\BlogPost
    {
        $post = \App\Models\BlogPost::findOrFail($postId);

        if (! $post->series_id) return null;

        return \App\Models\BlogPost::where('series_id', $post->series_id)
            ->where('series_order', '<', $post->series_order)
            ->orderByDesc('series_order')
            ->first();
    }

    public function getSeriesWithPosts(string $seriesId): \App\Domains\Blog\Models\BlogSeries
    {
        return \App\Domains\Blog\Models\BlogSeries::with(['posts' => function ($q) {
            $q->orderBy('series_order');
        }])->findOrFail($seriesId);
    }

    private function generateSlug(string $name): string
    {
        return strtolower(trim(preg_replace('/[^A-Za-z0-9-]+/', '-', $name), '-'));
    }
}
```

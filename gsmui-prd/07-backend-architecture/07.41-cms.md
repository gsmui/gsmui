# 07.41 - CMS

**Project:** GsmUi
**Architecture:** Content Service + Revisions + Blocks
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

> See also: `05.26-cms-architecture.md` (content types, data model, rendering). This document is the *implementation contract*: the `ContentService`, the revision/block persistence model, menu management, and the publish/unpublish workflow used by the admin UI.

# Purpose

The CMS manages static pages, blog posts, and navigation menus. Content is authored as a tree of **blocks** (heading, rich text, image, component embed) rather than one monolithic HTML column, which lets the same content render in the web frontend, the editor preview, and (potentially) export formats. Every save creates an immutable **revision**; publishing simply points the live pointer at a revision. This makes "undo" and "preview a past version" first-class, not an afterthought.

The `ContentService` owns create/update/publish for the `Page` and `Menu` entities; block composition is handled by `BlockService`, and revision history by `RevisionService`. Posts use a parallel `PostService` (`07.42-blog.md`) that reuses these same block/revision primitives. All writes go through repositories; all transitions emit events for the cache/Sitemap/SEO layers.

Goals:

- Blocks are the unit of content; pages are ordered block lists.
- Every mutation yields a revision; publishing swaps a pointer, never rewrites history.
- Menus are a separate aggregate with their own tree storage and cache.
- Publishes are event-driven so sitemap/SEO/full-page cache update automatically.

## 1. Content Service

`ContentService` is the write path for pages. It validates the slug, composes blocks through `BlockService`, snapshots a revision, and (on publish) updates the live pointer. It never renders HTML itself.

```php
namespace App\Domains\Cms\Services;

use App\Domains\Cms\DTOs\PageData;
use App\Domains\Cms\Enums\PublishState;
use App\Domains\Cms\Events\PagePublished;

final class ContentService
{
    public function __construct(
        private readonly \App\Domains\Cms\Repositories\PageRepository $pages,
        private readonly \App\Domains\Cms\Services\BlockService $blocks,
        private readonly \App\Domains\Cms\Services\RevisionService $revisions,
    ) {}

    public function create(PageData $data): \App\Domains\Cms\Models\Page
    {
        if ($this->pages->slugExists($data->slug)) {
            throw new \App\Domains\Cms\Exceptions\SlugTakenException($data->slug);
        }

        return $this->transaction(function () use ($data): \App\Domains\Cms\Models\Page {
            $page = $this->pages->create($data->metaOnly());

            $revision = $this->revisions->snapshot($page, $this->blocks->compose($data->blocks));
            $page->draft_revision_id = $revision->id;
            $page->saveQuietly();

            return $page;
        });
    }

    public function publish(string $slug, ?int $revisionId = null): void
    {
        $page = $this->pages->findBySlug($slug);
        $revision = $revisionId
            ? $this->revisions->find($page, $revisionId)
            : $this->revisions->latest($page);

        $page->live_revision_id = $revision->id;
        $page->publish_state = PublishState::Published;
        $page->published_at = $page->published_at ?? now();
        $page->saveQuietly();

        PagePublished::dispatch($page->slug, $revision->id);
    }
}
```

Helper used by callers:

```php
$page = app(\App\Domains\Cms\Services\ContentService::class)->create(PageData::from([
    'title' => 'Pricing',
    'slug' => 'pricing',
    'meta_title' => 'Pricing — GsmUi',
    'blocks' => [
        ['type' => 'heading', 'content' => 'Plans'],
        ['type' => 'rich_text', 'content' => '<p>Choose a plan...</p>'],
    ],
]));

app(\App\Domains\Cms\Services\ContentService::class)->publish($page->slug);
```

## 2. Block Service

Blocks are stored as an ordered JSON column on the revision (`blocks` is an array of `BlockData`). `BlockService` validates each block against its type schema and composes the list; it does not persist — the `RevisionService` owns storage.

```php
namespace App\Domains\Cms\Services;

use App\Domains\Cms\DTOs\BlockData;

final class BlockService
{
    /** @param array<int, array{type: string, content: mixed}> $raw */
    public function compose(array $raw): array
    {
        return array_values(array_map(function (array $b, int $i): BlockData {
            $block = BlockData::from($b);
            if (! $block->isValid()) {
                throw new \App\Domains\Cms\Exceptions\InvalidBlockException($block->type, $i);
            }

            return $block;
        }, $raw, array_keys($raw)));
    }

    /** Render blocks to HTML for the frontend (called by the view layer, not the service). */
    public function render(array $blocks): string
    {
        return implode("\n", array_map(
            fn (BlockData $b) => $b->toHtml(),
            array_map(BlockData::from(...), $blocks)
        ));
    }
}
```

```php
namespace App\Domains\Cms\DTOs;

final readonly class BlockData
{
    public function __construct(
        public string $type,
        public mixed $content,
        public int $order = 0,
    ) {}

    public static function from(array $b): self
    {
        return new self($b['type'], $b['content'], (int) ($b['order'] ?? 0));
    }

    public function isValid(): bool
    {
        return in_array($this->type, ['heading', 'rich_text', 'image', 'component_embed', 'quote'], true);
    }

    public function toHtml(): string { /* per-type render */ return (string) $this->content; }
}
```

## 3. Revision Service

Every save snapshots the composed blocks into an immutable `PageRevision`. The live/draft pointers on `Page` reference revisions; nothing is ever overwritten. `RevisionService` also powers "restore" (clone an old revision as a new one) and "diff" (compare two revisions).

```php
namespace App\Domains\Cms\Services;

use App\Domains\Cms\Models\Page;

final class RevisionService
{
    public function __construct(
        private readonly \App\Domains\Cms\Repositories\PageRevisionRepository $revisions,
    ) {}

    public function snapshot(Page $page, array $blocks, ?string $note = null): \App\Domains\Cms\Models\PageRevision
    {
        return $this->revisions->create([
            'page_id' => $page->id,
            'blocks' => $blocks,
            'note' => $note,
            'created_by' => auth()->id(),
            'created_at' => now(),
        ]);
    }

    public function restore(Page $page, int $revisionId): void
    {
        $old = $this->revisions->find($page, $revisionId);
        $copy = $this->snapshot($page, $old->blocks, note: "Restored from #$revisionId");
        $page->draft_revision_id = $copy->id;
        $page->saveQuietly();
    }

    /** @return \App\Domains\Cms\Models\PageRevision[] */
    public function history(Page $page): array
    {
        return $this->revisions->forPage($page);
    }
}
```

| Field | Meaning |
| --- | --- |
| `page_id` | Owning page |
| `blocks` | Immutable composed block tree (JSON) |
| `note` | Editor's note for this revision |
| `created_by` | Staff user id |

## 4. Menu Service

Menus are a separate aggregate (`Menu`) storing a nested `items` JSON tree. `MenuService` rebuilds the tree from a flat ordered input and caches the resolved hierarchy for the frontend nav. The primary menu is referenced by slug `primary`.

```php
namespace App\Domains\Cms\Services;

use App\Domains\Cms\DTOs\MenuItemData;

final class MenuService
{
    public function __construct(
        private readonly \App\Domains\Cms\Repositories\MenuRepository $menus,
        private readonly \Illuminate\Contracts\Cache\Repository $cache,
    ) {}

    /** @param MenuItemData[] $items flat, ordered, with parent_id */
    public function save(string $name, array $items, bool $primary = false): \App\Domains\Cms\Models\Menu
    {
        $tree = $this->buildTree($items);

        $menu = $this->menus->upsert($name, ['items' => $tree, 'is_primary' => $primary]);
        $this->cache->forget("menu:" . ($primary ? 'primary' : $menu->id));

        return $menu;
    }

    public function resolve(string $key): array
    {
        return $this->cache->remember("menu:$key", 3600, fn () =>
            $this->menus->findByKey($key)?->items ?? []);
    }

    /** @param MenuItemData[] $items */
    private function buildTree(array $items): array { /* nest by parent_id */ return $items; }
}
```

## 5. Publish Workflow & Events

```text
Editor (Livewire)
      │
ContentService::create / update
      ├─ BlockService::compose (validate)
      ├─ RevisionService::snapshot (immutable)
      └─ page.draft_revision_id = revision
      │
ContentService::publish
      ├─ page.live_revision_id = revision
      ├─ publish_state = published
      └─ PagePublished event
            │
            ├─► Full-page cache purge
            ├─► Sitemap regen
            └─► Search (Scout) sync
```

Unpublish simply flips `publish_state` to `draft` and clears the live pointer; the revision history is preserved.

Usage:

```php
app(\App\Domains\Cms\Services\ContentService::class)
    ->publish('pricing', revisionId: 42); // publish a specific past revision
```

### 6.2 Block Validation by Type

```php
namespace App\Domains\Cms\Services;

final class BlockValidator
{
    public function __construct(
        private readonly BlockTypeRegistry $registry,
    ) {}

    public function validate(string $type, array $content): BlockValidationResult
    {
        $schema = $this->registry->schema($type);
        if (! $schema) {
            return new BlockValidationResult(false, ['Unknown block type: ' . $type]);
        }

        $errors = [];
        foreach ($schema as $field => $rules) {
            $value = $content[$field] ?? null;

            if ($rules['required'] && ($value === null || $value === '')) {
                $errors[] = "{$field} is required";
                continue;
            }

            if ($value === null) continue;

            if (isset($rules['max_length']) && mb_strlen($value) > $rules['max_length']) {
                $errors[] = "{$field} exceeds maximum length of {$rules['max_length']}";
            }

            if (isset($rules['min']) && $value < $rules['min']) {
                $errors[] = "{$field} must be at least {$rules['min']}";
            }

            if (isset($rules['max']) && $value > $rules['max']) {
                $errors[] = "{$field} must be at most {$rules['max']}";
            }

            if (isset($rules['values']) && ! in_array($value, $rules['values'])) {
                $errors[] = "{$field} must be one of: " . implode(', ', $rules['values']);
            }
        }

        return new BlockValidationResult(empty($errors), $errors);
    }
}

final readonly class BlockValidationResult
{
    public function __construct(
        public bool $valid,
        public array $errors,
    ) {}
}
```

## 7. Media Management

### 7.1 Media Upload Service

```php
namespace App\Domains\Cms\Services;

final class MediaService
{
    public function __construct(
        private readonly \App\Domains\Cms\Repositories\MediaRepository $media,
        private readonly \Illuminate\Filesystem\Filesystem $filesystem,
    ) {}

    public function upload(\Illuminate\Http\UploadedFile $file, string $userId): \App\Domains\Cms\Models\Media
    {
        $this->validateFile($file);

        $path = $file->store('media', 'public');
        $hash = hash_file('sha256', $file->getRealPath());

        return $this->media->create([
            'user_id' => $userId,
            'filename' => $file->getClientOriginalName(),
            'path' => $path,
            'mime_type' => $file->getMimeType(),
            'size' => $file->getSize(),
            'hash' => $hash,
            'alt_text' => '',
            'caption' => '',
            'created_at' => now(),
        ]);
    }

    public function uploadBatch(array $files, string $userId): array
    {
        return array_map(fn ($file) => $this->upload($file, $userId), $files);
    }

    private function validateFile(\Illuminate\Http\UploadedFile $file): void
    {
        $maxSize = config('cms.media.max_file_size_mb', 10) * 1024 * 1024;
        $allowedTypes = config('cms.media.allowed_types', ['image/jpeg', 'image/png', 'image/gif', 'image/webp', 'image/svg+xml']);

        if ($file->getSize() > $maxSize) {
            throw new \App\Domains\Cms\Exceptions\FileTooLargeException($maxSize);
        }

        if (! in_array($file->getMimeType(), $allowedTypes)) {
            throw new \App\Domains\Cms\Exceptions\UnsupportedFileTypeException($file->getMimeType());
        }
    }

    public function list(string $userId, int $page = 1, int $perPage = 20): array
    {
        return $this->media->forUser($userId, $page, $perPage);
    }

    public function delete(int $mediaId, string $userId): void
    {
        $media = $this->media->findForUser($mediaId, $userId);
        $this->filesystem->delete(storage_path('app/' . $media->path));
        $media->delete();
    }

    public function updateMetadata(int $mediaId, string $userId, array $data): void
    {
        $media = $this->media->findForUser($mediaId, $userId);
        $media->update($data);
    }
}
```

final class SeoService

                'canonical_url' => $data['canonical_url'] ?? null,
                'robots' => $data['robots'] ?? 'index,follow',
                'schema_markup' => $data['schema_markup'] ?? null,
            ]
        );

    public function generateAutoSeo(string $title, string $description): array
    {
        return [
            'meta_title' => mb_substr($title, 0, 60),
            'meta_description' => mb_substr($description, 0, 160),
            'og_title' => $title,
            'og_description' => mb_substr($description, 0, 200),
            'twitter_card' => 'summary_large_image',
            'robots' => 'index,follow',
        ];

        return new SeoMetadata(

            metaDescription: config('app.description', ''),
            ogTitle: config('app.name'),
            ogDescription: config('app.description', ''),
            ogImage: null,
            twitterCard: 'summary',
            canonicalUrl: url($slug),
            robots: 'index,follow',
            schemaMarkup: null,

}

    public function submitForReview(string $slug): void
    {
        $page = app(\App\Domains\Cms\Repositories\PageRepository::class)->findBySlug($slug);

        if ($page->publish_state !== PublishState::Draft) {
            throw new \App\Domains\Cms\Exceptions\InvalidWorkflowTransitionException(
                $page->publish_state->value,
                'review'
            );
        }

        $page->update(['publish_state' => PublishState::Review]);
        \App\Domains\Cms\Events\PageSubmittedForReview::dispatch($slug);
    }

    public function approveForPublish(string $slug, int $approverId): void
    {
        $page = app(\App\Domains\Cms\Repositories\PageRepository::class)->findBySlug($slug);

        if ($page->publish_state !== PublishState::Review) {
            throw new \App\Domains\Cms\Exceptions\InvalidWorkflowTransitionException(
                $page->publish_state->value,
                'approved'
            );
        }

        $page->update([
            'publish_state' => PublishState::Approved,
            'approved_by' => $approverId,
            'approved_at' => now(),
        ]);

        \App\Domains\Cms\Events\PageApprovedForPublish::dispatch($slug, $approverId);
    }

    public function schedulePublish(string $slug, \Illuminate\Support\Carbon $at): void
    {
        $page = app(\App\Domains\Cms\Repositories\PageRepository::class)->findBySlug($slug);

        $page->update([
            'publish_state' => PublishState::Scheduled,
            'scheduled_at' => $at,
        ]);

        \App\Domains\Cms\Jobs\PublishScheduledPage::dispatch($page->id)->delay($at);
    }
}
```

### 9.2 Workflow States

```text
draft → review → approved → published
  ↑        ↓         ↓
  │     rejected   scheduled
  │        ↓         ↓
  └──── revision   published (at scheduled time)
```

| State | Description | Allowed Actions |
| --- | --- | --- |
| `draft` | Work in progress | Edit, submit for review |
| `review` | Submitted for approval | Approve, reject, edit |
| `approved` | Ready to publish | Publish, schedule |
| `scheduled` | Scheduled for future publish | Cancel schedule |
| `published` | Live on the site | Unpublish, edit (creates new draft) |
| `rejected` | Not approved | Edit, resubmit |

    public function getMissing(string $locale): array
    {

        $translated = $this->translations->keysForLocale($locale);

    }

    {
        return $this->translations->allForLocale($locale);
    }

    {
        $count = 0;
        foreach ($translations as $key => $value) {
            $this->set($key, $locale, $value);
            $count++;
        }
        return $count;
    }

```php
namespace App\Domains\Cms\Services;

final class CmsAccessService
{
    public function canView(string $userId, string $slug): bool
    {
        $page = app(\App\Domains\Cms\Repositories\PageRepository::class)->findBySlug($slug);

        if ($page->is_public) return true;

        return $this->hasAccess($userId, $page->access_level, $page->access_roles);

    public function canEdit(string $userId, string $slug): bool
    {
        $page = app(\App\Domains\Cms\Repositories\PageRepository::class)->findBySlug($slug);

        if ($page->author_id === $userId) return true;

        return auth()->user()->can('pages.edit');
    }

    public function canPublish(string $userId): bool
    {
        return auth()->user()->can('pages.publish');
    }

    public function canDelete(string $userId): bool
    {
        return auth()->user()->can('pages.delete');
    }

    private function hasAccess(string $userId, string $level, ?array $roles): bool
    {
        return match ($level) {
            'public' => true,
            'authenticated' => auth()->check(),
            'role' => $roles ? auth()->user()->hasAnyRole($roles) : false,
            'admin' => auth()->user()->hasRole('admin'),
            default => false,
        };
    }
}

final class PublishScheduledPage implements ShouldQueue
{
    use Queueable;

    public function __construct(public int $pageId) {}

    public function handle(): void
    {
        $page = Page::find($this->pageId);

            'publish_state' => PublishState::Published,
            'published_at' => now(),
        ]);

        PagePublished::dispatch($page->slug, $revision->id);
    }
}

namespace App\Domains\Cms\Services;

final class CmsPublishScheduler
{
    public function __construct(
        private readonly \App\Domains\Cms\Repositories\CmsPageRepository $pages,
        private readonly \App\Domains\Cms\Repositories\CmsPostRepository $posts,
        private readonly \App\Domains\Cms\Services\CmsPublishWorkflow $workflow,
    ) {}

    public function publishDueItems(): int
    {
        $count = 0;

        $count += $this->publishDuePages();
        $count += $this->publishDuePosts();

        return $count;
    }

    private function publishDuePages(): int
    {
        $due = $this->pages->where('status', 'scheduled')
            ->where('published_at', '<=', now())
            ->get();

        foreach ($due as $page) {
            $this->workflow->publish($page);
        }

        return $due->count();
    }

    private function publishDuePosts(): int
    {
        $due = $this->posts->where('status', 'scheduled')
            ->where('published_at', '<=', now())
            ->get();

        foreach ($due as $post) {
            $this->workflow->publish($post);
        }

        return $due->count();
    }
}

# 29. CMS Content Import Service

### 29.1 Markdown Import

```php
namespace App\Domains\Cms\Services\Import;

final class MarkdownImporter
{
    public function import(string $markdown, array $metadata = []): array
    {
        $parsed = $this->parseMarkdown($markdown);

        return [
            'title' => $metadata['title'] ?? $parsed['title'] ?? 'Untitled',
            'slug' => $metadata['slug'] ?? $this->generateSlug($parsed['title'] ?? 'untitled'),
            'blocks' => $this->convertToBlocks($parsed['body']),
            'seo' => [
                'meta_title' => $parsed['title'] ?? null,
                'meta_description' => $parsed['excerpt'] ?? null,
            ],
            'tags' => $metadata['tags'] ?? [],
        ];
    }

    private function parseMarkdown(string $markdown): array
    {
        $lines = explode("\n", $markdown);
        $title = null;
        $excerpt = null;
        $body = '';
        $inFrontMatter = false;
        $frontMatter = [];

        foreach ($lines as $line) {
            if ($line === '---' && ! $inFrontMatter && empty($frontMatter)) {
                $inFrontMatter = true;
                continue;
            }

            if ($line === '---' && $inFrontMatter) {
                $inFrontMatter = false;
                $title = $frontMatter['title'] ?? null;
                $excerpt = $frontMatter['excerpt'] ?? null;
                continue;
            }

            if ($inFrontMatter) {
                if (preg_match('/^(\w+):\s*(.+)$/', $line, $matches)) {
                    $frontMatter[$matches[1]] = $matches[2];
                }
                continue;
            }

            if (! $title && preg_match('/^#\s+(.+)$/', $line, $matches)) {
                $title = $matches[1];
                continue;
            }

            $body .= $line . "\n";
        }

        return ['title' => $title, 'excerpt' => $excerpt, 'body' => trim($body)];
    }

    /** @return array<int, array> */
    private function convertToBlocks(string $markdown): array
    {
        $blocks = [];
        $paragraphs = preg_split('/\n\s*\n/', $markdown);

        foreach ($paragraphs as $paragraph) {
            $paragraph = trim($paragraph);
            if (empty($paragraph)) continue;

            if (preg_match('/^#{1,6}\s+(.+)$/', $paragraph, $matches)) {
                $level = strlen($matches[0]) - strlen(rtrim($matches[0]));
                $blocks[] = ['type' => 'heading', 'data' => ['level' => $level, 'content' => $matches[1]]];
            } elseif (preg_match('/^```(\w+)?/', $paragraph, $matches)) {
                $language = $matches[1] ?? null;
                $code = preg_replace('/^```\w*\n?/', '', $paragraph);
                $code = preg_replace('/\n?```$/', '', $code);
                $blocks[] = ['type' => 'code', 'data' => ['language' => $language, 'code' => $code]];
            } elseif (preg_match('/^[-*]\s+(.+)$/', $paragraph)) {
                $items = preg_split('/\n[-*]\s+/', $paragraph);
                $items = array_filter($items);
                $blocks[] = ['type' => 'list', 'data' => ['style' => 'bullet', 'items' => array_values($items)]];
            } else {
                $blocks[] = ['type' => 'paragraph', 'data' => ['content' => $paragraph]];
            }
        }

        return $blocks;
    }

    private function generateSlug(string $title): string
    {
        return strtolower(trim(preg_replace('/[^A-Za-z0-9-]+/', '-', $title), '-'));
    }
}

namespace App\Domains\Cms\Services;

final class CmsCacheWarmer
{
    public function __construct(
        private readonly \App\Domains\Cms\Repositories\CmsPageRepository $pages,
        private readonly \App\Domains\Cms\Repositories\CmsPostRepository $posts,
    ) {}

    public function warmAll(): array
    {
        $results = [
            'pages' => $this->warmPages(),
            'posts' => $this->warmPosts(),
            'menus' => $this->warmMenus(),
            'routes' => $this->warmRoutes(),
        ];

        return $results;
    }

    public function warmPage(string $slug): void
    {
        $page = $this->pages->findBySlug($slug);
        if ($page) {
            cache()->tags(["cms:page:{$slug}"])->put(
                'rendered',
                $page->toRenderable(),
                now()->addHours(24)
            );
        }
    }

    private function warmPages(): int
    {
        $pages = $this->pages->where('status', 'published')->get();
        foreach ($pages as $page) {
            cache()->tags(["cms:page:{$page->slug}"])->put(
                'rendered',
                $page->toRenderable(),
                now()->addHours(24)
            );
        }
        return $pages->count();
    }

    private function warmPosts(): int
    {
        $posts = $this->posts->where('status', 'published')
            ->orderByDesc('published_at')
            ->limit(50)
            ->get();

        foreach ($posts as $post) {
            cache()->tags(["cms:post:{$post->slug}"])->put(
                'rendered',
                $post->toRenderable(),
                now()->addHours(12)
            );
        }
        return $posts->count();
    }

    private function warmMenus(): int
    {
        $menus = \App\Domains\Cms\Models\CmsMenu::with('items')->get();
        foreach ($menus as $menu) {
            cache()->tags(["cms:menu:{$menu->handle}"])->put(
                'tree',
                $menu->toTree(),
                now()->addHours(24)
            );
        }
        return $menus->count();
    }

    private function warmRoutes(): int
    {
        $routes = $this->pages->where('status', 'published')
            ->pluck('slug')
            ->toArray();
        cache()->tags(['cms:routes'])->put('slugs', $routes, now()->addHours(24));
        return count($routes);
    }
}

# 31. CMS SEO Analysis Service

### 31.1 SEO Scorer

```php
namespace App\Domains\Cms\Services;

final class CmsSeoScorer
{
    public function score(array $seoData, array $blocks): SeoScore
    {
        $checks = [];
        $total = 0;
        $max = 0;

        // Meta title check
        $titleScore = $this->scoreTitle($seoData['meta_title'] ?? null);
        $checks['title'] = $titleScore;
        $total += $titleScore['score'];
        $max += $titleScore['max'];

        // Meta description check
        $descScore = $this->scoreDescription($seoData['meta_description'] ?? null);
        $checks['description'] = $descScore;
        $total += $descScore['score'];
        $max += $descScore['max'];

        // Heading structure
        $headingScore = $this->scoreHeadings($blocks);
        $checks['headings'] = $headingScore;
        $total += $headingScore['score'];
        $max += $headingScore['max'];

        // Keyword density
        $keywordScore = $this->scoreKeyword($seoData['meta_title'] ?? '', $blocks);
        $checks['keyword'] = $keywordScore;
        $total += $keywordScore['score'];
        $max += $keywordScore['max'];

        // Image alt text
        $imageScore = $this->scoreImages($blocks);
        $checks['images'] = $imageScore;
        $total += $imageScore['score'];
        $max += $imageScore['max'];

        return new SeoScore(
            total: $total,
            max: $max,
            percentage: $max > 0 ? round($total / $max * 100) : 0,
            checks: $checks,
            grade: $this->calculateGrade($total, $max),
        );
    }

    private function scoreTitle(?string $title): array
    {
        $score = 0;
        $max = 20;

        if ($title && strlen($title) > 0) $score += 5;
        if ($title && strlen($title) >= 30 && strlen($title) <= 60) $score += 10;
        if ($title && strlen($title) < 30) $score += 3;
        if ($title && strlen($title) > 60) $score += 3;

        return ['score' => $score, 'max' => $max, 'message' => $this->titleMessage($title)];
    }

    private function titleMessage(?string $title): string
    {
        if (! $title) return 'No meta title set.';
        if (strlen($title) < 30) return 'Title is too short. Aim for 30-60 characters.';
        if (strlen($title) > 60) return 'Title is too long. Keep it under 60 characters.';
        return 'Title length looks good.';
    }

    private function scoreDescription(?string $description): array
    {
        $score = 0;
        $max = 20;

        if ($description && strlen($description) > 0) $score += 5;
        if ($description && strlen($description) >= 120 && strlen($description) <= 160) $score += 10;
        if ($description && strlen($description) < 120) $score += 3;
        if ($description && strlen($description) > 160) $score += 3;

        return ['score' => $score, 'max' => $max];
    }

    private function scoreHeadings(array $blocks): array
    {
        $score = 0;
        $max = 20;

        $headings = array_filter($blocks, fn ($b) => $b['type'] === 'heading');
        $h1Count = count(array_filter($headings, fn ($h) => ($h['data']['level'] ?? 0) === 1));

        if ($h1Count === 1) $score += 10;
        if (count($headings) >= 2) $score += 5;
        if (count($headings) >= 4) $score += 5;

        return ['score' => $score, 'max' => $max];
    }

    private function scoreKeyword(string $keyword, array $blocks): array
    {
        $score = 0;
        $max = 20;

        if (empty($keyword)) return ['score' => 0, 'max' => $max];

        $content = '';
        foreach ($blocks as $block) {
            if (isset($block['data']['content'])) {
                $content .= ' ' . $block['data']['content'];
            }
        }

        $count = substr_count(strtolower($content), strtolower($keyword));
        $wordCount = str_word_count($content);
        $density = $wordCount > 0 ? ($count / $wordCount) * 100 : 0;

        if ($density >= 0.5 && $density <= 2.5) $score += 15;
        elseif ($density > 0 && $density < 0.5) $score += 8;
        elseif ($density > 2.5) $score += 5;

        if ($count >= 1) $score += 5;

        return ['score' => $score, 'max' => $max, 'keyword_count' => $count, 'density' => round($density, 2)];
    }

    private function scoreImages(array $blocks): array
    {
        $score = 0;
        $max = 20;

        $images = array_filter($blocks, fn ($b) => $b['type'] === 'image');
        if (empty($images)) return ['score' => 10, 'max' => $max, 'message' => 'No images found.'];

        $withAlt = count(array_filter($images, fn ($img) => ! empty($img['data']['alt'])));
        $total = count($images);

        $score = (int) round(($withAlt / $total) * 20);

        return ['score' => $score, 'max' => $max, 'with_alt' => $withAlt, 'total' => $total];
    }

    private function calculateGrade(int $score, int $max): string
    {
        $pct = $max > 0 ? ($score / $max) * 100 : 0;
        if ($pct >= 90) return 'A';
        if ($pct >= 75) return 'B';
        if ($pct >= 60) return 'C';
        if ($pct >= 40) return 'D';
        return 'F';
    }
}

final readonly class SeoScore
{
    public function __construct(
        public int $total,
        public int $max,
        public int $percentage,
        public array $checks,
        public string $grade,
    ) {}
}

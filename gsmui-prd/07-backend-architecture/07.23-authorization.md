# 07.23 - Authorization

**Project:** GsmUi
**Architecture:** Spatie Laravel-Permission RBAC + Team Scoping
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

Once a user is authenticated (`07.22-authentication.md`), GsmUi authorizes actions through **Spatie Laravel-Permission**. The model combines flat *roles* (e.g. `admin`, `author`, `subscriber`) with fine-grained *permissions* (e.g. `themes.publish`, `components.delete`), and supports *team scoping* so a user's role can differ per team/tenant. Authorization is enforced at three layers: Policies (`07.15-policies.md`), Gates (`07.16-gates.md`), and middleware on routes.

This document specifies the *implementation mechanics*: model trait setup, role/permission seeding, team-scoped checks, middleware, and how services query permission without leaking auth logic. The conceptual RBAC overview is in `05.15-security.md`.

> See also: 07.22-authentication.md (identity), 07.15-policies.md (resource policies), 07.16-gates.md (ad-hoc gates), 05.15-security.md (security model).

---

# 1. Model Setup

The `User` model uses Spatie's `HasRoles` trait. Team scoping is enabled with `HasPermissions` + the `team_id` foreign key.

```php
<?php

declare(strict_types=1);

namespace App\Models;

use Illuminate\Foundation\Auth\User as Authenticatable;
use Spatie\Permission\Traits\HasRoles;

final class User extends Authenticatable
{
    use HasRoles;

    protected $guard_name = 'web'; // shared with sanctum guard via same provider

    // Team scoping: permissions are scoped to team_id when set
    protected ?string $teamsKey = 'team_id';
}
```

Publish Spatie's migrations (creates `roles`, `permissions`, `model_has_roles`, `model_has_permissions`, `role_has_permissions`) and configure the `teams` flag in `config/permission.php`.

# 2. Role & Permission Definition

Define permissions as constants and seed roles. Permissions are grouped by resource verb.

```php
// app/Domains/Shared/Enums/Permission.php
final class Permission
{
    public const string THEMES_PUBLISH = 'themes.publish';
    public const string COMPONENTS_DELETE = 'components.delete';
    public const string MARKETPLACE_SELL = 'marketplace.sell';
    public const string ADMIN_PANEL = 'admin.panel';
}
```

Seed (idempotent — uses `findOrCreate`):

```php
use Spatie\Permission\Models\Role;
use Spatie\Permission\Models\Permission;

final class RolesAndPermissionsSeeder extends \Database\Seeders\Seeder
{
    public function run(): void
    {
        $admin = Role::findOrCreate('admin');
        $author = Role::findOrCreate('author');
        $subscriber = Role::findOrCreate('subscriber');

        Permission::findOrCreate(Permission::THEMES_PUBLISH)->assignRole($author);
        Permission::findOrCreate(Permission::COMPONENTS_DELETE)->assignRole($admin);
        Permission::findOrCreate(Permission::ADMIN_PANEL)->assignRole($admin);

        $subscriber->givePermissionTo(Permission::MARKETPLACE_SELL);
    }
}
```

# 3. Assignment in Services

Services and Actions assign roles through Spatie, never inside controllers. Example from an `InviteToTeamAction`:

```php
public function execute(User $user, Team $team, string $roleName): void
{
    $user->assignRole($roleName);          // scoped to current team if teams enabled
    // or with explicit team:
    // $user->assignRole($roleName, $team->id);
}
```

# 4. Checks

| Scope | API | Where |
| ----- | --- | ----- |
| Global permission | `$user->can('themes.publish')` | anywhere |
| Role check | `$user->hasRole('admin')` | services |
| Team-scoped | `$user->hasRole('author', $team->id)` | multi-tenant |
| Any of many | `$user->hasAnyPermission([...])` | gates |
| Blade/Livewire | `@can('themes.publish')` / `$this->authorize()` | views |

Service-side guard example:

```php
public function publish(Theme $theme, User $user): void
{
    if (! $user->can(Permission::THEMES_PUBLISH)) {
        throw new \App\Domains\Shared\Exceptions\InsufficientPermissionsException(
            'Missing themes.publish'
        );
    }
    // ...publish logic
}
```

# 5. Middleware

Route-level enforcement uses Spatie's middleware (registered in `bootstrap/app.php` or `app/Http/Kernel.php`):

```php
use Spatie\Permission\Middleware\RoleMiddleware;
use Spatie\Permission\Middleware\PermissionMiddleware;

// Laravel 13 alias registration
$middleware->alias([
    'role' => RoleMiddleware::class,
    'permission' => PermissionMiddleware::class,
]);
```

Applied on routes:

```php
Route::middleware(['auth:sanctum', 'permission:' . Permission::ADMIN_PANEL])
    ->group(fn () => Route::get('admin', AdminController::class));
```

For resource operations, prefer Policies (`07.15-policies.md`) via `authorizeResource()` in the controller (see `07.21-api-architecture.md` §6). Use gates (`07.16-gates.md`) only for cross-cutting, non-resource abilities.

# 6. Team Scoping Model

```text
User
  │
  ├── role: author   (team: Acme)   → can themes.publish within Acme
  ├── role: admin    (team: global) → can components.delete anywhere
  │
Team (tenant)
  │
Permissions resolved against (user, team_id)
```

When teams are enabled, `setPermissionsTeamId($teamId)` scopes all subsequent checks to that team. Always set the team context early in the request (e.g. in a middleware bound to the route's `{team}` parameter).

# 8. Policy Implementations

## 8.1 Component Policy

```php
<?php

declare(strict_types=1);

namespace App\Domains\Components\Policies;

use App\Domains\Components\Models\Component;
use App\Domains\Shared\Enums\Permission;
use App\Models\User;

final class ComponentPolicy
{
    public function viewAny(User $user): bool
    {
        return true; // all authenticated users can browse
    }

    public function view(User $user, Component $component): bool
    {
        if ($component->visibility === 'public') {
            return true;
        }

        if ($component->visibility === 'team') {
            return $user->teams()->where('teams.id', $component->team_id)->exists();
        }

        return $user->id === $component->user_id || $user->hasRole('admin');
    }

    public function create(User $user): bool
    {
        return $user->hasRole(['admin', 'author'])
            || $user->hasPermissionTo(Permission::COMPONENTS_CREATE);
    }

    public function update(User $user, Component $component): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        return $user->id === $component->user_id
            && $component->status !== 'archived';
    }

    public function delete(User $user, Component $component): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        return $user->id === $component->user_id
            && $component->downloads < 10;
    }

    public function publish(User $user, Component $component): bool
    {
        return $user->id === $component->user_id
            && $component->status === 'draft'
            && $user->hasRole(['admin', 'author']);
    }

    public function archive(User $user, Component $component): bool
    {
        return ($user->id === $component->user_id || $user->hasRole('admin'))
            && $component->status !== 'archived';
    }

    public function transfer(User $user, Component $component): bool
    {
        return $user->id === $component->user_id && $user->hasRole('admin');
    }

    public function forceDelete(User $user, Component $component): bool
    {
        return $user->hasRole('admin');
    }

    public function restore(User $user, Component $component): bool
    {
        return $user->hasRole('admin');
    }
}
```

```php
namespace App\Domains\Themes\Policies;

use App\Domains\Themes\Models\Theme;
use App\Models\User;

final class ThemePolicy
{
    public function viewAny(User $user): bool
    {
        return true;
    }

    public function view(User $user, Theme $theme): bool
    {
        if ($theme->visibility === 'public') {
            return true;
        }

        if ($theme->visibility === 'team') {
            return $user->teams()->where('teams.id', $theme->team_id)->exists();
        }

        return $user->id === $theme->user_id || $user->hasRole('admin');
    }

    public function create(User $user): bool
    {
        return $user->hasRole(['admin', 'author']);
    }

    public function update(User $user, Theme $theme): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        return $user->id === $theme->user_id && $theme->status !== 'archived';
    }

    public function delete(User $user, Theme $theme): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        return $user->id === $theme->user_id && $theme->sales_count === 0;
    }

    public function publish(User $user, Theme $theme): bool
    {
        return $user->id === $theme->user_id
            && in_array($theme->status, ['draft', 'revision'])
            && $user->hasRole(['admin', 'author']);
    }

    public function download(User $user, Theme $theme): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        if ($theme->base_price === 0) {
            return true;
        }

        return $user->hasPurchased($theme);
    }

    public function manageVersions(User $user, Theme $theme): bool
    {
        return ($user->id === $theme->user_id || $user->hasRole('admin'))
            && $theme->status !== 'archived';
    }
}
```

## 8.3 Product (Marketplace) Policy

```php
<?php

declare(strict_types=1);

namespace App\Domains\Marketplace\Policies;

use App\Domains\Marketplace\Models\Product;
use App\Models\User;

final class ProductPolicy
{
    public function viewAny(User $user): bool
    {
        return true;
    }

    public function view(User $user, Product $product): bool
    {
        if ($product->status === 'published') {
            return true;
        }

        return $user->id === $product->user_id || $user->hasRole('admin');
    }

    public function create(User $user): bool
    {
        return $user->hasRole(['admin', 'author'])
            && $user->hasPermissionTo('marketplace.sell');
    }

    public function update(User $user, Product $product): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        return $user->id === $product->user_id
            && $product->sales_count === 0;
    }

    public function delete(User $user, Product $product): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        return $user->id === $product->user_id
            && $product->sales_count === 0
            && $product->status !== 'published';
    }

    public function purchase(User $user, Product $product): bool
    {
        return $product->status === 'published'
            && $user->id !== $product->user_id
            && ! $user->hasPurchased($product);
    }

    public function review(User $user, Product $product): bool
    {
        return $product->status === 'published'
            && $user->hasPurchased($product)
            && ! $user->hasReviewed($product);
    }

    public function manage(User $user): bool
    {
        return $user->hasRole('admin')
            || $user->hasPermissionTo('marketplace.manage');
    }
}
```

## 8.4 Team Policy

```php
<?php

declare(strict_types=1);

namespace App\Domains\Teams\Policies;

use App\Domains\Teams\Models\Team;
use App\Models\User;

final class TeamPolicy
{
    public function viewAny(User $user): bool
    {
        return true;
    }

    public function view(User $user, Team $team): bool
    {
        return $team->visibility === 'public'
            || $team->members()->where('users.id', $user->id)->exists()
            || $user->hasRole('admin');
    }

    public function create(User $user): bool
    {
        $maxTeams = config('gsmui.teams.max_per_user', 5);
        return $user->ownedTeams()->count() < $maxTeams;
    }

    public function update(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id;
    }

    public function delete(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id;
    }

    public function invite(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id
            || $team->members()->where('users.id', $user->id)
                ->wherePivot('role', 'admin')->exists();
    }

    public function removeMember(User $user, Team $team, User $member): bool
    {
        if ($user->hasRole('admin')) {
            return true;
        }

        if ($user->id === $member->id) {
            return true; // user can leave
        }

        return $team->owner_id === $user->id
            || $team->members()->where('users.id', $user->id)
                ->wherePivot('role', 'admin')->exists();
    }

    public function changeRole(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id;
    }
}
```

# 9. Gate Definitions

```php
<?php

declare(strict_types=1);

namespace App\Providers;

use App\Models\User;
use Illuminate\Foundation\Support\Providers\AuthServiceProvider;
use Illuminate\Support\Facades\Gate;

final class AuthServiceProvider extends AuthServiceProvider
{
    public function boot(): void
    {
        $this->registerPolicies();

        // ── Cross-Cutting Gates ──────────────────────────────
        Gate::define('admin-panel', fn (User $user) =>
            $user->hasPermissionTo('admin.panel')
        );

        Gate::define('manage-marketplace', fn (User $user) =>
            $user->hasRole('admin') || $user->hasPermissionTo('marketplace.manage')
        );

        Gate::define('manage-docs', fn (User $user) =>
            $user->hasRole('admin') || $user->hasPermissionTo('docs.manage')
        );

        Gate::define('manage-users', fn (User $user) =>
            $user->hasRole('admin')
        );

        Gate::define('view-analytics', fn (User $user) =>
            $user->hasRole('admin') || $user->hasPermissionTo('analytics.view')
        );

        Gate::define('export-data', fn (User $user) =>
            $user->hasRole('admin') || $user->hasPermissionTo('data.export')
        );

        // ── Team Gates ───────────────────────────────────────
        Gate::define('team-owner', fn (User $user, $team) =>
            $user->id === $team->owner_id
        );

        Gate::define('team-admin', fn (User $user, $team) =>
            $user->id === $team->owner_id
            || $team->members()->where('users.id', $user->id)
                ->wherePivot('role', 'admin')->exists()
        );

        // ── Super Admin Bypass ───────────────────────────────
        Gate::before(function (User $user) {
            if ($user->hasRole('super-admin')) {
                return true;
            }
        });

        // ── After Hook (Logging) ─────────────────────────────
        Gate::after(function (User $user, $ability, $result, $arguments) {
            if ($result === false && config('app.debug')) {
                \Log::debug('Gate denied', [
                    'user' => $user->id,
                    'ability' => $ability,
                    'arguments' => array_keys($arguments),
                ]);
            }
        });
    }
}
```

## 10.2 Custom Team Context Middleware

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Spatie\Permission\PermissionRegistrar;
use Symfony\Component\HttpFoundation\Response;

final class SetTeamContext
{
    public function handle(Request $request, Closure $next): Response
    {
        $teamId = $request->route('team')?->id
            ?? $request->user()?->current_team_id;

        if ($teamId) {
            app(PermissionRegistrar::class)->setPermissionsTeamId($teamId);
        }

        $response = $next($request);

        // Reset to default after request
        if ($teamId) {
            app(PermissionRegistrar::class)->setPermissionsTeamId(1);
        }

        return $response;
    }
}
```

## 10.3 Custom Ability Middleware

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

final class EnsureTeamMembership
{
    public function handle(Request $request, Closure $next, string $role = 'member'): Response
    {
        $user = $request->user();
        $team = $request->route('team');

        if (! $user || ! $team) {
            abort(403);
        }

        $hasRole = $team->members()
            ->where('users.id', $user->id)
            ->wherePivot('role', $role)
            ->exists();

        if (! $hasRole) {
            abort(403, "You must be a {$role} of this team.");
        }

        return $next($request);
    }
}
```

# 11. Role & Permission Seeders

## 11.1 Complete Seeder

```php
<?php

declare(strict_types=1);

namespace Database\Seeders;

use App\Domains\Shared\Enums\Permission;
use Illuminate\Database\Seeder;
use Spatie\Permission\Models\Role;
use Spatie\Permission\Models\Permission;

final class RolesAndPermissionsSeeder extends Seeder
{
    public function run(): void
    {
        // Reset cached roles and permissions
        app()[\Spatie\Permission\PermissionRegistrar::class]->forgetCachedPermissions();

        // ── Create Permissions ─────────────────────────────
        $permissions = [
            Permission::THEMES_PUBLISH,
            Permission::THEMES_MANAGE,
            Permission::COMPONENTS_CREATE,
            Permission::COMPONENTS_DELETE,
            Permission::COMPONENTS_PUBLISH,
            Permission::MARKETPLACE_SELL,
            Permission::MARKETPLACE_MANAGE,
            Permission::ADMIN_PANEL,
            Permission::ADMIN_USERS,
            Permission::DOCS_MANAGE,
            Permission::ANALYTICS_VIEW,
            Permission::DATA_EXPORT,
            Permission::COMMENTS_MODERATE,
            Permission::REPORTS_VIEW,
        ];

        foreach ($permissions as $perm) {
            Permission::findOrCreate($perm);
        }

        // ── Create Roles ───────────────────────────────────
        $superAdmin = Role::findOrCreate('super-admin');
        $admin = Role::findOrCreate('admin');
        $author = Role::findOrCreate('author');
        $subscriber = Role::findOrCreate('subscriber');
        $viewer = Role::findOrCreate('viewer');

        // ── Assign Permissions to Roles ─────────────────────
        // Super Admin: everything
        $superAdmin->givePermissionTo(Permission::all());

        // Admin: all except super-admin specific
        $admin->givePermissionTo([
            Permission::ADMIN_PANEL,
            Permission::ADMIN_USERS,
            Permission::THEMES_MANAGE,
            Permission::THEMES_PUBLISH,
            Permission::COMPONENTS_CREATE,
            Permission::COMPONENTS_DELETE,
            Permission::COMPONENTS_PUBLISH,
            Permission::MARKETPLACE_MANAGE,
            Permission::DOCS_MANAGE,
            Permission::ANALYTICS_VIEW,
            Permission::COMMENTS_MODERATE,
            Permission::REPORTS_VIEW,
        ]);

        // Author: create and publish
        $author->givePermissionTo([
            Permission::THEMES_PUBLISH,
            Permission::COMPONENTS_CREATE,
            Permission::COMPONENTS_PUBLISH,
            Permission::MARKETPLACE_SELL,
        ]);

        // Subscriber: sell on marketplace
        $subscriber->givePermissionTo([
            Permission::MARKETPLACE_SELL,
        ]);

        // Viewer: read-only
        $viewer->givePermissionTo([]);
    }
}
```

# 12. Service Layer Authorization

## 12.1 Authorization in Services

```php
<?php

declare(strict_types=1);

namespace App\Domains\Components\Services;

use App\Domains\Components\Models\Component;
use App\Domains\Shared\Exceptions\InsufficientPermissionsException;
use App\Models\User;

final class ComponentAuthorizationService
{
    public function ensureCanCreate(User $user): void
    {
        if (! $user->can('create', Component::class)) {
            throw InsufficientPermissionsException::forAction('create component');
        }
    }

    public function ensureCanUpdate(User $user, Component $component): void
    {
        if (! $user->can('update', $component)) {
            throw InsufficientPermissionsException::forAction('update component');
        }
    }

    public function ensureCanDelete(User $user, Component $component): void
    {
        if (! $user->can('delete', $component)) {
            throw InsufficientPermissionsException::forAction('delete component');
        }
    }

    public function ensureCanPublish(User $user, Component $component): void
    {
        if (! $user->can('publish', $component)) {
            throw InsufficientPermissionsException::forAction('publish component');
        }
    }

    public function ensureCanView(User $user, Component $component): void
    {
        if (! $user->can('view', $component)) {
            throw InsufficientPermissionsException::forAction('view component');
        }
    }

    public function ensureAdmin(User $user): void
    {
        if (! $user->hasRole('admin')) {
            throw InsufficientPermissionsException::forAction('admin access');
        }
    }

    public function ensureTeamMember(User $user, int $teamId, string $role = 'member'): void
    {
        $isMember = $user->teams()
            ->where('teams.id', $teamId)
            ->wherePivot('role', $role)
            ->exists();

        if (! $isMember) {
            throw InsufficientPermissionsException::forAction("team {$role} access");
        }
    }
}
```

## 12.2 InsufficientPermissionsException

```php
<?php

declare(strict_types=1);

namespace App\Domains\Shared\Exceptions;

use Symfony\Component\HttpKernel\Exception\HttpException;

final class InsufficientPermissionsException extends HttpException
{
    public static function forAction(string $action): self
    {
        return new self(
            403,
            "You do not have permission to {$action}.",
            null,
            [],
            0
        );
    }

    public static function forTeam(string $role, int $teamId): self
    {
        return new self(
            403,
            "You must be a {$role} of team #{$teamId} to perform this action.",
            null,
            [],
            0
        );
    }
}
```

# 14. Authorization Testing Patterns

## 14.1 Policy Tests

```php
<?php

declare(strict_types=1);

namespace Tests\Authorization;

use App\Domains\Components\Models\Component;
use App\Domains\Components\Policies\ComponentPolicy;
use App\Models\User;
use Tests\TestCase;
use Illuminate\Foundation\Testing\RefreshDatabase;

final class ComponentPolicyTest extends TestCase
{
    use RefreshDatabase;

    private ComponentPolicy $policy;

    protected function setUp(): void
    {
        parent::setUp();
        $this->policy = new ComponentPolicy();
    }

    public function test_admin_can_do_anything(): void
    {
        $admin = User::factory()->create()->assignRole('admin');
        $component = Component::factory()->create();

        $this->assertTrue($this->policy->update($admin, $component));
        $this->assertTrue($this->policy->delete($admin, $component));
        $this->assertTrue($this->policy->publish($admin, $component));
    }
```

# 20. Authorization in Livewire

```php
<?php

declare(strict_types=1);

namespace App\Http\Livewire\Components;

use App\Domains\Components\Models\Component;
use App\Domains\Shared\Exceptions\InsufficientPermissionsException;
use Livewire\Component;

abstract class BaseComponent extends Component
{
    public function authorize(string $ability, $model = null): void
    {
        $user = auth()->user();

        if (! $user) {
            throw InsufficientPermissionsException::forAction('unauthenticated access');
        }

        if ($model && ! $user->can($ability, $model)) {
            throw InsufficientPermissionsException::forAction("{$ability} on " . class_basename($model));
        }

        if (! $model && ! $user->can($ability)) {
            throw InsufficientPermissionsException::forAction($ability);
        }
    }
}
```

# 24. Authorization Service Provider

```php
<?php

declare(strict_types=1);

namespace App\Providers;

use App\Domains\Auth\Listeners\LogPermissionDenied;
use App\Domains\Auth\Events\PermissionDenied;
use Illuminate\Foundation\Support\Providers\AuthServiceProvider;
use Illuminate\Support\Facades\Gate;
use Spatie\Permission\PermissionRegistrar;

final class AuthorizationServiceProvider extends AuthServiceProvider
{
    public function boot(): void
    {
        $this->registerPolicies();
        $this->registerGates();
        $this->registerEventListeners();
    }

    private function registerPolicies(): void
    {
        // Policies are auto-discovered in App\Domains\*\Policies
        // No manual registration needed with Laravel auto-discovery
    }

    private function registerGates(): void
    {
        Gate::before(function ($user) {
            if ($user->hasRole('super-admin')) {
                return true;
            }
        });

        Gate::after(function ($user, $ability, $result, $arguments) {
            if ($result === false) {
                event(new PermissionDenied($user, $ability, $arguments['model'] ?? null));
            }
        });
    }

    private function registerEventListeners(): void
    {
        $this->app->make(\Illuminate\Contracts\Events\Dispatcher::class)
            ->listen(PermissionDenied::class, LogPermissionDenied::class);
    }
}
```

```php
                    'message' => 'You do not have permission to perform this action.',

                ], 403);
            }

            abort(403);
        });
```

# 33. Role Hierarchy Pattern

Implement role hierarchy where higher roles inherit lower role permissions:

```php
<?php

declare(strict_types=1);

namespace App\Domains\Auth\Services;

final class RoleHierarchyService
{
    private const array HIERARCHY = [
        'super-admin' => ['admin', 'author', 'subscriber', 'viewer'],
        'admin' => ['author', 'subscriber', 'viewer'],
        'author' => ['subscriber', 'viewer'],
        'subscriber' => ['viewer'],
        'viewer' => [],
    ];

    public function inheritsRole(string $assignedRole, string $requiredRole): bool
    {
        if ($assignedRole === $requiredRole) {
            return true;
        }

        return in_array($requiredRole, self::HIERARCHY[$assignedRole] ?? []);
    }

    public function getInheritedPermissions(string $role): array
    {
        $permissions = [];
        $roles = array_merge([$role], self::HIERARCHY[$role] ?? []);

        foreach ($roles as $r) {
            $roleModel = \Spatie\Permission\Models\Role::where('name', $r)->first();
            if ($roleModel) {
                $permissions = array_merge($permissions, $roleModel->getAllPermissions()->pluck('name')->toArray());
            }
        }

        return array_unique($permissions);
    }

    public function canAccess(string $assignedRole, string $minimumRole): bool
    {
        return $this->inheritsRole($assignedRole, $minimumRole);
    }
}
```

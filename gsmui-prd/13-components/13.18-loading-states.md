# 13.18 Loading States — GsmUi Loading State Specification

## Overview

Consistent loading state patterns across all GsmUi components. Loading states communicate async operations without blocking the UI, following the principle: **show immediate feedback, then progressive enhancement**.

## Loading State Types

| Type | Use Case | Component Examples |
|------|----------|-------------------|
| **Inline Spinner** | Button actions, form submits | Button, Submit |
| **Overlay Spinner** | Full component replacement | Table, Card, Modal |
| **Skeleton** | Content placeholders | List, Card, Table, Avatar |
| **Progress Bar** | Known duration operations | Upload, Import, Multi-step |
| **Indeterminate** | Unknown duration | Search, Load more |
| **Shimmer** | Text/content loading | Typography, Statistic |

## Component Loading Patterns

### 1. Button Loading

```blade
<x-gsmui:button :loading="$saving" wire:click="save">
    Save
</x-gsmui:button>
```

```php
public function render(): View

        'spinnerPosition' => $this->iconPosition === 'right' ? 'left' : 'right',
    ]);
}
```

```php
public function save(): void
{
    $this->saving = true;
    
    try {
        $this->validate();
        User::create($this->form);
        $this->dispatch('saved');
        $this->reset('form');

    } finally {
        $this->saving = false;
    }
}
```

## Offline Support

### Persist State

```php
trait PersistsState
{
    public function persistState(): void
    {
        $this->dispatch('persist:state', [
            'component' => $this->componentName(),
            'state' => $this->getPersistableState(),
        ]);
    }
    
    public function restoreState(array $state): void
    {
        foreach ($state as $key => $value) {
            if (property_exists($this, $key)) {
                $this->$key = $value;
            }
        }
    }
    
    protected function getPersistableState(): array
    {
        return [
            'value' => $this->value,
            'open' => $this->open ?? false,
            // ... other state
        ];
    }
}
```

```javascript
// Auto-save to localStorage
document.addEventListener('livewire:load', () => {
    Livewire.hook('message.sent', (message) => {
        if (message.type === 'persist:state') {
            localStorage.setItem(`gsmui:${message.payload.component}`, JSON.stringify(message.payload.state));
        }

    Livewire.hook('initial-page-load', () => {
        document.querySelectorAll('[data-gsmui-persist]').forEach(el => {

            const saved = localStorage.getItem(`gsmui:${key}`);

            }
        });
    });
```

## Advanced Loading Patterns

### Streaming Loading States

```php
<?php

namespace GsmUi\Loading;

class StreamingLoader
{
    protected $stream;
    protected array $buffer = [];
    protected int $bufferSize = 10;
    
    public function __construct($stream = null)
    {
        $this->stream = $stream;
    }
    
    public function stream(callable $callback): void
    {
        $this->startStream();
        
        $callback(function ($chunk) {
            $this->buffer[] = $chunk;
            
            if (count($this->buffer) >= $this->bufferSize) {
                $this->flushBuffer();
            }
        });
        
        $this->flushBuffer();
        $this->endStream();
    }
    
    protected function startStream(): void
    {
        header('Content-Type: text/event-stream');
        header('Cache-Control: no-cache');
        header('Connection: keep-alive');
        header('X-Accel-Buffering: no');
    }
    
    protected function flushBuffer(): void
    {
        if (empty($this->buffer)) {
            return;
        }
        
        $data = json_encode($this->buffer);
        echo "data: {$data}\n\n";
        ob_flush();
        flush();
        
        $this->buffer = [];
    }
    
    protected function endStream(): void
    {
        echo "data: [DONE]\n\n";
        ob_flush();
        flush();
    }
    
    public function sendProgress(int $current, int $total, string $message = ''): void
    {
        $progress = [
            'type' => 'progress',
            'current' => $current,
            'total' => $total,
            'percentage' => round(($current / $total) * 100),
            'message' => $message,
        ];
        
        echo "data: " . json_encode($progress) . "\n\n";
        ob_flush();
        flush();
    }
    
    public function sendChunk(string $content): void
    {
        $chunk = [
            'type' => 'chunk',
            'content' => $content,
        ];
        
        echo "data: " . json_encode($chunk) . "\n\n";
        ob_flush();
        flush();
    }
    
    public function sendComplete(mixed $result = null): void
    {
        $complete = [
            'type' => 'complete',
            'result' => $result,
        ];
        
        echo "data: " . json_encode($complete) . "\n\n";
        ob_flush();
        flush();
    }
    
    public function sendError(string $message): void
    {
        $error = [
            'type' => 'error',
            'message' => $message,
        ];
        
        echo "data: " . json_encode($error) . "\n\n";
        ob_flush();
        flush();
    }
}
```

### Progress Tracker

```php
<?php

namespace GsmUi\Loading;

class ProgressTracker
{
    protected string $id;
    protected int $total;
    protected int $current = 0;
    protected string $status = 'pending';
    protected string $message = '';
    protected array $steps = [];
    protected \Closure $onProgress;
    protected \Closure $onComplete;
    protected \Closure $onError;
    
    public function __construct(string $id, int $total)
    {
        $this->id = $id;
        $this->total = $total;
    }
    
    public function setTotal(int $total): self
    {
        $this->total = $total;
        return $this;
    }
    
    public function increment(int $amount = 1): self
    {
        $this->current = min($this->current + $amount, $this->total);
        $this->notify();
        return $this;
    }
    
    public function setProgress(int $current): self
    {
        $this->current = min(max($current, 0), $this->total);
        $this->notify();
        return $this;
    }
    
    public function setMessage(string $message): self
    {
        $this->message = $message;
        return $this;
    }
    
    public function addStep(string $name, callable $callback): self
    {
        $this->steps[] = [
            'name' => $name,
            'callback' => $callback,
            'status' => 'pending',
        ];
        return $this;
    }
    
    public function start(): self
    {
        $this->status = 'running';
        $this->executeSteps();
        return $this;
    }
    
    protected function executeSteps(): void
    {
        foreach ($this->steps as &$step) {
            try {
                $step['status'] = 'running';
                $step['callback']($this);
                $step['status'] = 'completed';
                $this->increment();
            } catch (\Exception $e) {
                $step['status'] = 'failed';
                $this->status = 'failed';
                $this->message = $e->getMessage();
                $this->notifyError($e);
                return;
            }
        }
        
        $this->status = 'completed';
        $this->notifyComplete();
    }
    
    public function onProgress(\Closure $callback): self
    {
        $this->onProgress = $callback;
        return $this;
    }
    
    public function onComplete(\Closure $callback): self
    {
        $this->onComplete = $callback;
        return $this;
    }
    
    public function onError(\Closure $callback): self
    {
        $this->onError = $callback;
        return $this;
    }
    
    protected function notify(): void
    {
        if ($this->onProgress) {
            ($this->onProgress)($this->getProgress());
        }
    }
    
    protected function notifyComplete(): void
    {
        if ($this->onComplete) {
            ($this->onComplete)($this->getProgress());
        }
    }
    
    protected function notifyError(\Exception $e): void
    {
        if ($this->onError) {
            ($this->onError)($this->getProgress(), $e);
        }
    }
    
    public function getProgress(): array
    {
        return [
            'id' => $this->id,
            'current' => $this->current,
            'total' => $this->total,
            'percentage' => round(($this->current / $this->total) * 100),
            'status' => $this->status,
            'message' => $this->message,
            'steps' => array_map(fn($s) => [
                'name' => $s['name'],
                'status' => $s['status'],
            ], $this->steps),
        ];
    }
    
    public function getPercentage(): int
    {
        return round(($this->current / $this->total) * 100);
    }
    
    public function isComplete(): bool
```

## Loading States Best Practices

### Loading State Guidelines

#### Do's and Don'ts

#### Do

1. **Show immediate feedback** — Display loading state as soon as possible
2. **Use skeleton screens** — Better perceived performance than spinners
3. **Provide progress feedback** — Show progress for known-duration tasks
4. **Announce loading states** — Use ARIA for screen readers
5. **Respect reduced motion** — Disable animations when requested

#### Don't

1. **Don't block the UI** — Allow users to cancel long operations
2. **Don't show loading for fast operations** — Only show for >300ms
3. **Don't use generic messages** — Be specific about what's loading
4. **Don't forget error states** — Handle loading failures gracefully
5. **Don't stack loading indicators** — One loading state at a time

### Loading Pattern Selection

| Duration | Pattern | Example |
|----------|---------|---------|
| <100ms | No indicator | Button click |
| 100-300ms | Subtle indicator | Input validation |
| 300ms-1s | Inline spinner | Form submit |
| 1-3s | Progress bar | File upload |
| >3s | Full page skeleton | Page load |

### Loading UX Guidelines

1. **Set expectations** — Tell users how long it will take
2. **Allow cancellation** — Provide cancel button for long operations
3. **Show progress** — For operations with known duration
4. **Preserve context** — Don't lose user's work during loading
5. **Handle errors gracefully** — Show clear error messages

### Progress Tracker

```javascript
class ProgressTracker {
    constructor(options = {}) {
        this.options = {
            total: 100,
            current: 0,
            ...options,
        };
        
        this.listeners = [];
    }
    
    setProgress(current) {
        this.options.current = Math.min(Math.max(current, 0), this.options.total);
        this.notifyListeners();
    }
    
    increment(amount = 1) {
        this.setProgress(this.options.current + amount);
    }
    
    getPercentage() {
        return Math.round((this.options.current / this.options.total) * 100);
    }
    
    isComplete() {
        return this.options.current >= this.options.total;
    }
    
    onComplete(callback) {
        this.listeners.push({
            type: 'complete',
            callback,
        });
    }
    
    onProgress(callback) {
        this.listeners.push({
            type: 'progress',
            callback,
        });
    }
    
    notifyListeners() {
        this.listeners.forEach(listener => {
            if (listener.type === 'progress') {
                listener.callback(this.getPercentage(), this.options.current, this.options.total);
            } else if (listener.type === 'complete' && this.isComplete()) {
                listener.callback();
            }
        });
    }
    
    reset() {
        this.setProgress(0);
    }
}
```

```javascript
class SkeletonLoader {
    constructor(container, options = {}) {
        this.container = container;
        this.options = {
            rows: 5,
            columns: 3,
            animated: true,
            ...options,
        };
    }
    
    show() {
        const skeleton = this.createSkeleton();
        this.container.innerHTML = '';
        this.container.appendChild(skeleton);
    }
    
    hide() {
        this.container.innerHTML = '';
    }
    
    createSkeleton() {
        const wrapper = document.createElement('div');
        wrapper.className = 'gsmui-skeleton-wrapper';
        wrapper.setAttribute('role', 'status');
        wrapper.setAttribute('aria-label', 'Loading');
        
        for (let i = 0; i < this.options.rows; i++) {
            const row = document.createElement('div');
            row.className = 'gsmui-skeleton-row';
            
            for (let j = 0; j < this.options.columns; j++) {
                const cell = document.createElement('div');
                cell.className = 'gsmui-skeleton-cell';
                
                if (this.options.animated) {
                    cell.classList.add('animate-pulse');
                }
                
                row.appendChild(cell);
            }
            
            wrapper.appendChild(row);
        }
        
        return wrapper;
    }
}
```

```javascript
        const displayMessage = message || this.options.message;
        
        if (this.options.showSpinner) {
            this.element.innerHTML = `
                <span class="inline-flex items-center gap-2">
                    <svg class="animate-spin h-4 w-4" viewBox="0 0 24 24" fill="none">
                        <circle class="opacity-25" cx="12" cy="12" r="10" stroke="currentColor" stroke-width="4"></circle>
                        <path class="opacity-75" fill="currentColor" d="M4 12a8 8 0 018-8V0C5.373 0 0 5.373 0 12h4zm2 5.291A7.962 7.962 0 014 12H0c0 3.042 1.135 5.824 3 7.938l3-2.647z"></path>
                    </svg>
                    <span>${displayMessage}</span>
                </span>
            `;
        } else {
            this.element.textContent = displayMessage;
        }
        
        this.element.setAttribute('aria-busy', 'true');
    }
    
    hide() {
        this.element.innerHTML = this.originalContent;
        this.element.removeAttribute('aria-busy');
    }
}
```

### Overlay Loading Indicator

```javascript
class OverlayLoadingIndicator {
    constructor(element, options = {}) {
        this.element = element;
        this.options = {
            message: 'Loading...',
            backdrop: true,
            spinner: true,
            ...options;
        };
        
        this.overlay = null;
    }
    
    show(message = null) {
        const displayMessage = message || this.options.message;
        
        this.overlay = document.createElement('div');
        this.overlay.className = 'gsmui-loading-overlay';
        this.overlay.setAttribute('role', 'status');
        this.overlay.setAttribute('aria-label', displayMessage);
        
        let content = '';
        
        if (this.options.backdrop) {
            content += '<div class="gsmui-loading-backdrop"></div>';
        }
        
        content += '<div class="gsmui-loading-content">';
        
        if (this.options.spinner) {
            content += `
                <svg class="animate-spin h-8 w-8 text-blue-600" viewBox="0 0 24 24" fill="none">
                    <circle class="opacity-25" cx="12" cy="12" r="10" stroke="currentColor" stroke-width="4"></circle>
                    <path class="opacity-75" fill="currentColor" d="M4 12a8 8 0 018-8V0C5.373 0 0 5.373 0 12h4zm2 5.291A7.962 7.962 0 014 12H0c0 3.042 1.135 5.824 3 7.938l3-2.647z"></path>
                </svg>
            `;
        }
        
        content += `<span class="gsmui-loading-message">${displayMessage}</span>`;
        content += '</div>';
        
        this.overlay.innerHTML = content;
        this.element.style.position = 'relative';
        this.element.appendChild(this.overlay);
    }
    
    hide() {
        if (this.overlay) {
            this.overlay.remove();
            this.overlay = null;
        }
    }
}
```

## Loading States Quick Reference

### Loading Pattern Decision Tree

```
Is the operation instant (<100ms)?
├── Yes → No loading indicator
└── No → Is it <300ms?
    ├── Yes → Subtle indicator (button state change)
    └── No → Is the duration known?
        ├── Yes → Progress bar
        └── No → Is it <1s?
            ├── Yes → Inline spinner
            └── No → Skeleton screen + spinner
```

### Loading Accessibility Checklist

- [ ] Loading states announced to screen readers
- [ ] `aria-busy="true"` added during loading
- [ ] `aria-live` regions used for status updates
- [ ] Progress bars have `role="progressbar"`
- [ ] Skeleton loaders have `role="status"`
- [ ] Reduced motion preferences respected
- [ ] Error states handled gracefully

### Loading Performance Guidelines

1. **Debounce fast operations** — Don't show loading for <100ms
2. **Use skeleton screens** — Better perceived performance
3. **Optimize animations** — Use GPU-accelerated properties
4. **Cache results** — Reduce redundant loading states
5. **Lazy load** — Load non-critical content on demand

### Loading Timeout Behavior

```javascript
// Show spinner only after 200ms delay
const debounceMs = 200;
const timeoutMs = 1000;
let timeout;

// Start
timeout = setTimeout(() => {
    loading = true;
}, debounceMs);

// Cancel if done quickly
clearTimeout(timeout);
loading = false;

// Fallback for stuck states
if (loading) {
    setTimeout(() => {
        loading = false;
        showError('Request timed out');
    }, timeoutMs);
}
```

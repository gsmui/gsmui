# 13.700 Overlays — GsmUi Overlays Category Specification

## Overview

The Overlays category contains components that appear above the main content, requiring user attention or interaction. These components manage focus trapping, portal rendering, and proper stacking context.

## Components

| Component | Status | Description |
|-----------|--------|-------------|
| [Modal](./13.701-modal.md) | Stable | Dialog requiring immediate attention |
| [Drawer](./13.702-drawer.md) | Stable | Slide-out panel from edge |
| [Popover](./13.703-popover.md) | Stable | Floating content anchored to trigger |
| [Tooltip](./13.704-tooltip.md) | Stable | Hover/focus text hints |
| [Dropdown](./13.705-dropdown.md) | Stable | Action/menu dropdown |
| [ContextMenu](./13.706-context-menu.md) | Stable | Right-click context menu |
| [HoverCard](./13.707-hover-card.md) | Beta | Rich hover preview |
| [Toast](./13.708-toast.md) | Stable | Transient notifications (also in Feedback) |

## Design Principles

### Stacking Context (z-index)

```css
--gsmui-z-dropdown: 100;        /* Dropdown, Select, Combobox */
--gsmui-z-sticky: 200;          /* Sticky headers */
--gsmui-z-fixed: 300;           /* Fixed headers, toolbars */
--gsmui-z-modal-backdrop: 400;  /* Modal backdrop */
--gsmui-z-modal: 500;           /* Modal dialog */
--gsmui-z-popover: 600;         /* Popover, Tooltip, Dropdown */
--gsmui-z-tooltip: 700;         /* Tooltip (above popover) */
--gsmui-z-toast: 800;           /* Toast notifications */
--gsmui-z-command-palette: 900; /* Command palette */
```

### Portal Rendering

All overlays render via **Teleport/Livewire Portal** to `body` or `#gsmui-portal` to escape stacking context constraints.

```blade
<!-- Automatic portal via component -->
<x-gsmui:modal :open="$showModal">
    Content renders in portal
</x-gsmui:modal>

<!-- Manual portal target -->
<div id="gsmui-portal"></div>
```

### Focus Management

| Component | Focus Trap | Restore Focus | Initial Focus |
|-----------|------------|---------------|---------------|
| Modal | Yes | Yes | First focusable / autofocus |
| Drawer | Yes | Yes | First focusable / autofocus |
| Popover | No | Yes | First focusable |
| Dropdown | No | Yes | First focusable |
| Tooltip | No | No | N/A |
| ContextMenu | No | Yes | First item |
| HoverCard | No | No | N/A |

### Close Behaviors

| Trigger | Modal | Drawer | Popover | Dropdown | Tooltip | ContextMenu |
|---------|-------|--------|---------|----------|---------|-------------|
| Escape | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Backdrop click | ✓ | ✓ | ✓ | ✓ | - | ✓ |
| Outside click | - | - | ✓ | ✓ | - | ✓ |
| Tab out | Trapped | Trapped | Close | Close | - | Close |
| Trigger click | - | - | Toggle | Toggle | - | - |

## Shared API

### Common Props

```php
#[Prop]
public bool $open = false;

#[Prop]
public bool $persistent = false;  // Prevent close on escape/backdrop

#[Prop]
public string $placement = 'bottom';  // Popover/Tooltip/Dropdown

#[Prop(options: ['top', 'bottom', 'left', 'right', 'center'])]
public string $position = 'center';  // Modal/Drawer

#[Prop]
public bool $modal = true;  // Drawer: modal backdrop

#[Prop]
public bool $trapFocus = true;

#[Prop]
public bool $restoreFocus = true;

#[Prop]
public ?string $container = null;  // Portal target selector

#[Prop]
public int $zIndex = null;  // Override default

#[Prop]
public ?Closure $onClose = null;

#[Prop]
public ?Closure $onOpen = null;

#[Prop]
public array $transition = ['enter' => 'ease-out', 'leave' => 'ease-in'];
```

### Common Slots

```blade
{{-- Modal/Drawer --}}

<x-slot name="footer">Actions</x-slot>
```

## Component Specifications

### 13.701 Modal

**Focused dialog requiring immediate attention**

```blade
<x-gsmui:modal 
    wire:model="showModal"
    title="Confirm Delete"
    description="This action cannot be undone."
    size="md"
    :persistent="false"
>
    <p>Are you sure you want to delete this item?</p>
    
    <x-slot name="footer">
        <x-gsmui:flex justify="end" gap="3">
            <x-gsmui:button variant="ghost" wire:click="$set('showModal', false)">Cancel</x-gsmui:button>
            <x-gsmui:button variant="danger" wire:click="confirmDelete">Delete</x-gsmui:button>
        </x-gsmui:flex>
    </x-slot>
</x-gsmui:modal>
```

**Sizes:**
| Size | Max Width | Use Case |
|------|-----------|----------|
| `xs` | 20rem (320px) | Simple confirm |
| `sm` | 24rem (384px) | Forms |
| `md` | 32rem (512px) | **Default** |
| `lg` | 48rem (768px) | Complex forms |
| `xl` | 64rem (1024px) | Full-width content |
| `full` | 100vw | Mobile fullscreen |

**Props:**
- `title` - Dialog title
- `description` - Accessible description
- `size` - Size variant
- `centered` - Vertical center (default: true)
- `scrollable` - Scroll body if tall (default: true)
- `closeButton` - Show close button (default: true)
- `persistent` - Prevent close on escape/backdrop

**Events:** `open`, `close`, `before-close` (can prevent)

**Fullscreen (Mobile):**
```blade
<x-gsmui:modal 
    wire:model="showModal"
    :fullscreen="$breakpoint === 'mobile'"
>
```

**Props:**

### 13.703 Popover

**Floating content anchored to trigger**

```blade
<x-gsmui:popover 
    wire:model="showPopover"
    placement="bottom"
    trigger="click"
>
    <x-slot name="trigger">
        <x-gsmui:button variant="outline">Options</x-gsmui:button>
    </x-slot>
    
    <x-slot name="content">
        <x-gsmui:menu>
            <x-gsmui:menu.item wire:click="edit">Edit</x-gsmui:menu.item>
            <x-gsmui:menu.item wire:click="delete" variant="danger">Delete</x-gsmui:menu.item>
        </x-gsmui:menu>
    </x-slot>
</x-gsmui:popover>
```

**Placements:**
```
top, top-start, top-end
bottom, bottom-start, bottom-end
left, left-start, left-end
right, right-start, right-end
```

**Triggers:** `click` | `hover` | `focus` | `context-menu`

**Props:**
- `placement` - Anchor position
- `trigger` - Activation method
- `offset` - Distance from trigger (default: 8px)
- `flip` - Auto-flip if no space (default: true)
- `shift` - Shift to stay in view (default: true)
- `arrow` - Show arrow indicator (default: true)
- `closeOnSelect` - Close on item click (default: true)

**Props:**

- `offset` - Distance from target (default: 6px)
- `interactive` - Allow hover on tooltip (default: false)

**Variants:** `default` (dark), `light`, `styled` (custom)

### Focus Management

```javascript
// Modal focus trap
function trapFocus(element) {
    const focusable = element.querySelectorAll(
        'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
    );
    const first = focusable[0];
    const last = focusable[focusable.length - 1];
    
    element.addEventListener('keydown', (e) => {
        if (e.key !== 'Tab') return;
        
        if (e.shiftKey && document.activeElement === first) {
            e.preventDefault();
            last.focus();
        } else if (!e.shiftKey && document.activeElement === last) {
            e.preventDefault();
            first.focus();
        }
    });
    
    first?.focus();
}
```

### Keyboard Navigation

| Component | Keys |
|-----------|------|
| Modal | `Tab`/`Shift+Tab` (trapped), `Escape` (close) |
| Drawer | Same as Modal |
| Popover | `Tab` (close), `Escape` (close), `Arrow` (if menu inside) |
| Dropdown | `ArrowUp/Down` (navigate), `Enter`/`Space` (select), `Escape` (close), `Tab` (close) |
| Tooltip | N/A (no focus) |
| ContextMenu | `ArrowUp/Down`, `Enter`/`Space`, `Escape`, `Tab` (close) |
| HoverCard | N/A (hover only) |

## Focus Management

### Focus Trap

```javascript
function trapFocus(element) {
    const focusable = element.querySelectorAll(
        'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
    );
    const first = focusable[0];
    const last = focusable[focusable.length - 1];
    
    element.addEventListener('keydown', (e) => {
        if (e.key !== 'Tab') return;
        
        if (e.shiftKey && document.activeElement === first) {
            e.preventDefault();
            last.focus();
        } else if (!e.shiftKey && document.activeElement === last) {
            e.preventDefault();
            first.focus();
        }
    });
    
    first?.focus();
}
```

### Focus Restore

```javascript
// Save trigger element before opening
const triggerElement = document.activeElement;

// On close, restore focus
function restoreFocus() {
    triggerElement?.focus();
}
```

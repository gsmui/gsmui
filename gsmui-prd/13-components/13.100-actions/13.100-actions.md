# 13.100 Actions — GsmUi Actions Category Specification

## Overview

The Actions category contains components for user interactions and call-to-action elements. These are the primary interface elements users click, tap, or activate to perform actions.

## Components

| Component | Status | Description |
|-----------|--------|-------------|
| [Button](./13.101-button.md) | Stable | Primary action trigger with multiple variants |
| [IconButton](./13.102-icon-button.md) | Stable | Icon-only button for compact actions |
| [Link](./13.103-link.md) | Stable | Styled anchor for navigation |
| [SplitButton](./13.104-split-button.md) | Stable | Button with attached dropdown menu |
| [DropdownButton](./13.105-dropdown-button.md) | Stable | Button that opens a dropdown menu |
| [FloatingActionButton](./13.106-floating-action-button.md) | Beta | Prominent circular action button |
| [ToggleButton](./13.107-toggle-button.md) | Beta | Button that toggles between states |

## Design Principles

### Visual Hierarchy

```
Primary (1 per view)     → High emphasis, brand color
Secondary (2-3 per view) → Medium emphasis, neutral
Tertiary (unlimited)     → Low emphasis, ghost/link
```

### Spacing & Alignment

- Buttons in groups: `gap-2` (8px)
- Button + Input: `gap-2` (8px)
- Full-width on mobile (< 640px) for primary actions
- Icon + text: `gap-2` (8px) internal spacing

### States Priority

1. **Disabled** (highest) - Non-interactive
2. **Loading** - Async operation
3. **Active/Pressed** - Mouse down
4. **Focus Visible** - Keyboard focus
5. **Hover** - Mouse over
6. **Default** - Rest state

## Shared API

### Common Props

```php
// All action components share these props
#[Prop(options: ['primary', 'secondary', 'outline', 'ghost', 'link'])]
public string $variant = 'primary';

#[Prop(options: ['xs', 'sm', 'md', 'lg', 'xl'])]
public string $size = 'md';

#[Prop(options: ['primary', 'secondary', 'success', 'warning', 'danger'])]
public string $color = 'primary';

#[Prop]
public bool $disabled = false;

#[Prop]
public bool $loading = false;

#[Prop]
public ?string $icon = null;

#[Prop(options: ['left', 'right'])]
public string $iconPosition = 'left';

#[Prop]
public bool $fullWidth = false;
```

### Common Slots

```blade
{{-- Default slot for label/content --}}
{{ $slot }}

{{-- Optional icon slot --}}
<x-slot name="icon">
    <x-gsmui:icon name="plus" />
</x-slot>

{{-- Loading state override --}}
<x-slot name="loading">
    <x-gsmui:icon name="arrow-path" class="animate-spin" />
</x-slot>
```

### Common Events

```javascript
// All action components emit these events
click: { originalEvent, componentId }
focus: { originalEvent }
blur: { originalEvent }
keydown: { originalEvent }
```

## Component Specifications

### 13.101 Button

**Primary action component**

```blade
<x-gsmui:button 
    variant="primary" 
    size="md"
    icon="plus"
    wire:click="save"
>
    Save Changes
</x-gsmui:button>
```

**Variants:**
- `primary` - Brand color, high emphasis
- `secondary` - Neutral, medium emphasis  
- `outline` - Bordered, transparent bg
- `ghost` - No border, transparent bg
- `link` - Text link appearance

**Sizes:** `xs`, `sm`, `md`, `lg`, `xl`

**States:** `disabled`, `loading`, `active`, `focus-visible`

---

### 13.102 IconButton

**Compact icon-only action**

```blade
<x-gsmui:icon-button 
    icon="cog-6-tooth" 
    variant="ghost"
    size="md"
    aria-label="Settings"
    wire:click="openSettings"
/>
```

**Variants:** Same as Button, defaults to `ghost`
**Sizes:** `xs` (24px), `sm` (32px), `md` (40px), `lg` (48px), `xl` (56px)
**Accessibility:** Requires `aria-label` or `aria-labelledby`

---

### 13.103 Link

**Styled navigation link**

```blade
<x-gsmui:link 
    href="/settings"
    variant="primary"
    icon="arrow-right"
    icon-position="right"
>
    View Settings
</x-gsmui:link>
```

**Variants:** `primary`, `secondary`, `ghost`, `link` (default)
**Props:** `href`, `target`, `rel`, `replace` (Turbo/Inertia)

---

### 13.104 SplitButton

**Primary action + dropdown**

```blade
<x-gsmui:split-button 
    label="Export"
    variant="primary"
    :items="[
        ['label' => 'PDF', 'action' => 'exportPdf'],
        ['label' => 'CSV', 'action' => 'exportCsv'],
        ['divider' => true],
        ['label' => 'Print', 'action' => 'print'],
    ]"
/>
```

**Props:**
- `label` - Primary button text
- `items` - Dropdown menu items
- `placement` - `bottom`, `bottom-start`, `bottom-end`, `top`, etc.

---

### 13.105 DropdownButton

**Button that opens dropdown (no primary action)**

```blade
<x-gsmui:dropdown-button 
    label="Actions"
    variant="outline"
    :items="$menuItems"
    placement="bottom-end"
/>
```

---

### 13.106 FloatingActionButton

**Prominent circular action (Material Design FAB)**

```blade
<x-gsmui:fab 
    icon="plus"
    variant="primary"
    position="bottom-right"
    :actions="[
        ['icon' => 'pencil', 'label' => 'Edit', 'action' => 'edit'],
        ['icon' => 'trash', 'label' => 'Delete', 'action' => 'delete', 'variant' => 'danger'],
    ]"
/>
```

**Positions:** `bottom-right`, `bottom-left`, `top-right`, `top-left`
**Extended FAB:** Includes label text next to icon

---

### 13.107 ToggleButton

**Button with pressed/unpressed state**

```blade
<x-gsmui:toggle-button 
    :pressed="$isBold"
    icon="bold"
    wire:click="toggleBold"
    aria-label="Bold"
/>
```

**Props:**
- `pressed` - Boolean toggle state
- `toggle` - Auto-toggle on click (default: true)

| `ArrowUp` | Previous menu item |

## Accessibility

### ARIA Attributes

```blade
{{-- Button --}}
<button 
    role="button" 
    tabindex="0"
    aria-disabled="{{ $disabled ? 'true' : 'false' }}"
    aria-busy="{{ $loading ? 'true' : 'false' }}"
    aria-pressed="{{ $pressed ?? 'false' }}"
>
```

### Focus Management

- Focus ring: `focus-visible:outline-2 focus-visible:outline-[-webkit-focus-ring-color]`
- Focus trapped in open dropdowns
- Focus returns to trigger on dropdown close

### Screen Reader

- Loading state: `aria-busy="true"` + "Loading..." announcement
- Disabled: `aria-disabled="true"` (not `disabled` on non-native elements)
- Toggle: `aria-pressed` announces state changes

#### Blade Usage Examples

```blade

{{-- With tooltip --}}
<x-gsmui:icon-button 
    icon="trash" 
    aria-label="Delete" 
    tooltip="Delete item"
    variant="danger"
    wire:click="delete({{ $item->id }})"
/>

{{-- Icon button group --}}
<x-gsmui:button-group>
    <x-gsmui:icon-button icon="bold" aria-label="Bold" />
    <x-gsmui:icon-button icon="italic" aria-label="Italic" />
    <x-gsmui:icon-button icon="underline" aria-label="Underline" />
</x-gsmui:button-group>

{{-- Loading state --}}
<x-gsmui:icon-button 
    icon="arrow-path" 
    :loading="$refreshing" 
    aria-label="Refresh"
    wire:click="refresh"
/>
```

#### Accessibility Requirements

- `aria-label` or `aria-labelledby` is **required** for all icon buttons
- Icon buttons must have visible focus indicator (`focus-visible:outline-2 focus-visible:outline-[-webkit-focus-ring-color]`)
- Loading state must set `aria-busy="true"` and `aria-label="Loading, [original label]"`
- Disabled state must set `aria-disabled="true"` (not native `disabled` for non-form elements)

## Performance Considerations

### Lazy Loading

- Icons should be loaded via the Icon component with lazy loading support
- FAB speed dial actions should be lazy-rendered when opened
- Split button dropdown items should use `x-show` with `x-cloak` for initial hide

### Bundle Size

- Base button component: ~2KB gzipped
- IconButton: ~1.5KB gzipped (shares Button core)
- SplitButton: ~4KB gzipped (includes Dropdown/Menu)
- FAB: ~3KB gzipped (includes speed dial)
- Total category: ~12KB gzipped

### Animation Performance

- Button transitions: `150ms ease-in-out` (duration < 200ms for perceived responsiveness)
- Dropdown open/close: `200ms ease-out` with `opacity` and `transform` only (GPU accelerated)
- FAB entrance: `300ms cubic-bezier(0.34, 1.56, 0.64, 1)` (spring-like)
- Loading spinner: CSS animation (no JS overhead)

### Undo/Redo Pattern

```blade
{{-- Undo/Redo action management --}}
<div
    x-data="{
        history: [],
        historyIndex: -1,
        pushState(state) {
            this.history = this.history.slice(0, this.historyIndex + 1);
            this.history.push(JSON.parse(JSON.stringify(state)));
            this.historyIndex++;
        },
        undo() {
            if (this.historyIndex > 0) {
                this.historyIndex--;
                this.$wire.restoreState(this.history[this.historyIndex]);
            }
        },
        redo() {
            if (this.historyIndex < this.history.length - 1) {
                this.historyIndex++;
                this.$wire.restoreState(this.history[this.historyIndex]);
            }
        }
    }"
    x-init="$watch('items', val => pushState(val))"
>
    {{-- Undo/Redo buttons --}}
    <div class="flex gap-2 mb-4">
        <x-gsmui:button
            variant="ghost"
            icon="arrow-uturn-left"
            x-on:click="undo()"
            x-bind:disabled="historyIndex <= 0"
        />
        <x-gsmui:button
            variant="ghost"
            icon="arrow-uturn-right"
            x-on:click="redo()"
            x-bind:disabled="historyIndex >= history.length - 1"
        />
    </div>
</div>
```

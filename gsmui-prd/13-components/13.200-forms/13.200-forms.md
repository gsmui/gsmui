# 13.200 Forms — GsmUi Forms Category Specification

## Overview

The Forms category contains all form input components. Every component supports `wire:model` for Livewire two-way binding, native HTML form submission, and comprehensive validation integration.

## Design Principles

### Form Field Anatomy

```
┌─────────────────────────────────────┐
│ Label (required marker)             │
├─────────────────────────────────────┤
│ [Prefix] Input/Control [Suffix]     │  ← Main interaction area
├─────────────────────────────────────┤
│ Description / Help text             │
├─────────────────────────────────────┤
│ Error message (when invalid)        │
└─────────────────────────────────────┘
```

### Spacing System

| Element | Spacing |
|---------|---------|
| Label → Input | `mt-1.5` (6px) |
| Input → Description | `mt-1.5` (6px) |
| Input → Error | `mt-1.5` (6px) |
| Field → Field (vertical) | `space-y-4` (16px) |
| Field → Field (inline) | `gap-4` (16px) |
| Prefix/Suffix → Input | `0` (touching) |

### Visual States (Priority Order)

1. **Disabled** - `opacity-50 cursor-not-allowed`
2. **Invalid** - `border-red-500 focus:ring-red-500`
3. **Focus** - `focus-visible:outline-2 focus-visible:outline-[-webkit-focus-ring-color]`
4. **Hover** - `border-zinc-400 dark:border-zinc-500`
5. **Filled** - Label floats up (if applicable)
6. **Default** - Base styles

```javascript

```

```blade

{{-- With validation --}}
```

## Component Specifications

### 13.201 Input

**Single-line text input**

```blade
<x-gsmui:input
    type="email"
    wire:model="form.email"
    label="Email"
    placeholder="you@example.com"
    prefix="@"
    :invalid="$errors->has('email')"
    :error-message="$errors->first('email')"
/>
```

**Props:**
- `type`: `text`, `email`, `password`, `number`, `tel`, `url`, `search`, `date`, `time`, `datetime-local`, `month`, `week`, `color`
- `placeholder`
- `minlength`, `maxlength`
- `min`, `max`, `step` (for number/date)
- `pattern`
- `autocomplete`
- `inputmode`: `text`, `decimal`, `numeric`, `tel`, `search`, `email`, `url`
- `autofocus`

**Variants:** `outline` (default), `filled`, `underlined`, `flushed`

---

### 13.202 Textarea

**Multi-line text input**

```blade
<x-gsmui:textarea
    wire:model="form.bio"
    label="Bio"
    placeholder="Tell us about yourself..."
    rows="4"
    :maxlength="500"
    show-character-count
/>
```

**Props:**
- `rows` (default: 4)
- `cols`
- `maxlength`
- `showCharacterCount` - Shows "X/500" counter
- `resize`: `none`, `vertical`, `horizontal`, `both`

---

### 13.203 Select

**Dropdown selection (single/multiple)**

```blade
<x-gsmui:select
    wire:model="form.category"
    :options="$categories"
    option-value="id"
    option-label="name"
    placeholder="Select category"
    searchable
    clearable
    label="Category"
/>
```

**Props:**
- `options` - Array of objects or simple values
- `optionValue` - Key for value (default: 'value')
- `optionLabel` - Key for label (default: 'label')
- `optionGroup` - Key for optgroup children (default: 'children')
- `multiple`
- `searchable`
- `clearable`
- `allowCustom` - Allow free-text entry
- `maxSelected` - Limit for multiple
- `placeholder`

**Keyboard:**
- `Enter`/`Space` - Open/Select
- `ArrowUp/Down` - Navigate
- `Type` - Filter (searchable)
- `Escape` - Close
- `Backspace` - Remove last (multiple)

---

### 13.204 Combobox

**Searchable select with custom input**

```blade
<x-gsmui:combobox
    wire:model="form.user"
    :options="$users"
    option-value="id"
    option-label="name"
    placeholder="Search users..."
    :get-option-label="fn($user) => $user->name . ' (' . $user->email . ')'"
/>
```

**Difference from Select:** Allows typing to filter, shows custom "no results" slot, supports async loading.

---

### 13.205 Autocomplete

**Input with suggestion dropdown**

```blade
<x-gsmui:autocomplete
    wire:model="form.tags"
    :suggestions="$availableTags"
    multiple
    placeholder="Add tags..."
    :min-chars="2"
    :debounce="150"
/>
```

**Props:**
- `suggestions` - Array of strings or objects
- `multiple` - Chip-style multiple selection
- `minChars` - Minimum chars to trigger (default: 1)
- `debounce` - Search debounce ms (default: 150)
- `maxSuggestions` - Limit results (default: 10)

## Validation Integration

### Laravel Validation

```php
// Controller
$request->validate([
    'email' => 'required|email|unique:users',
    'password' => 'required|min:8|confirmed',
    'dob' => 'required|date|before:-18 years',
    'attachments.*' => 'file|max:5120|mimes:jpg,png,pdf',
]);
```

### Component Error Display

```blade
<x-gsmui:input
    wire:model="form.email"
    :invalid="$errors->has('email')"
    :error-message="$errors->first('email')"
/>

{{-- Or use field wrapper --}}
<x-gsmui:field 
    :errors="$errors" 
    name="email" 
    label="Email"
>
    <x-gsmui:input wire:model="form.email" />
</x-gsmui:field>
```

### Real-time Validation

```blade
<x-gsmui:input
    wire:model.live="form.email"
    :invalid="$errors->has('email')"
    :error-message="$errors->first('email')"
/>
```

```php
// Component trait
public function updatedFormEmail($value)
{
    $this->validateOnly('form.email');
}
```

## Accessibility

### Required ARIA

| Component | Role | Required ARIA |
|-----------|------|---------------|
| Input | `textbox` | `aria-label`/`aria-labelledby`, `aria-describedby`, `aria-invalid`, `aria-required` |
| Textarea | `textbox` | Same as input |
| Select | `combobox` | `aria-haspopup="listbox"`, `aria-expanded`, `aria-controls`, `aria-activedescendant` |
| Checkbox | `checkbox` | `aria-checked`, `aria-describedby` |
| Radio | `radio` | `aria-checked`, `aria-describedby` |
| Switch | `switch` | `aria-checked`, `aria-describedby` |
| Slider | `slider` | `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, `aria-orientation` |
| Range | `slider` | Same + `aria-valuetext` |

### Keyboard Patterns

```typescript
// Input, Textarea
Tab → Next field
Shift+Tab → Previous field

// Select, Combobox
Enter/Space → Open dropdown
ArrowUp/Down → Navigate options
Type → Filter (combobox)
Escape → Close
Enter → Select
Tab → Close + next field

// Checkbox/Radio
Space → Toggle
Tab → Next field (not next option!)

// Slider
ArrowLeft/Right → Decrease/Increase
Home/End → Min/Max
PageUp/PageDown → Large step

// Date Picker
Enter → Open calendar
Arrow keys → Navigate days
PageUp/Down → Month
Ctrl+PageUp/Down → Year
Escape → Close
```

#### Props Table

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `mask` | `string` | **required** | Mask pattern |
| `value` | `?string` | `null` | Current value |
| `placeholder` | `?string` | `null` | Placeholder text |
| `showMask` | `bool` | `false` | Show mask template |
| `formatOnBlur` | `bool` | `false` | Apply mask on blur |
| `definitions` | `array` | `[]` | Custom mask tokens |
| `label` | `?string` | `null` | Field label |
| `disabled` | `bool` | `false` | Prevents interaction |
| `invalid` | `bool` | `false` | Error state |
| `wireModel` | `?string` | `null` | Livewire model binding |

#### Mask Characters

| Character | Description | Example |
|-----------|-------------|---------|
| `9` | Numeric (0-9) | `(999) 999-9999` |
| `a` | Alphabetic (a-z, A-Z) | `aaa-9999` |
| `*` | Alphanumeric | `***-****` |
| `\` | Escape next character | `\(999\)` |

### Server-side Validation

```php
// In Livewire component
public function updatedFormEmail($value)
{
    $this->validateOnly('form.email', [
        'form.email' => 'required|email|unique:users',
    ]);
}

public function save()
{
    $this->validate([
        'form.name' => 'required|string|max:255',
        'form.email' => 'required|email|unique:users,email,' . $this->user->id,
        'form.password' => 'required|min:8|confirmed',
    ]);

    // Save logic...
}
```

### Custom Validation Rules

```php
// Custom rule
class NoSpacesRule implements ValidationRule
{
    public function validate(string $attribute, mixed $value, Closure $fail): void
    {
        if (str_contains($value, ' ')) {
            $fail('The :attribute must not contain spaces.');
        }
    }
}

// Usage
$this->validate([
    'form.username' => ['required', new NoSpacesRule()],
]);
```

### Lazy Loading

- Combobox/Autocomplete options should be lazy-loaded
- Date picker calendar should lazy-load month data
- Color picker swatches should be rendered on demand

- ColorPicker: ~7KB gzipped (includes canvas)
- Rich Editor: ~15KB gzipped (includes TipTap)
- Total category: ~50KB gzipped (with lazy loading)

## Design Principles

### Progressive Enhancement

All advanced components work without JavaScript (server-rendered) and enhance with client-side interactivity.

### Composition over Configuration

```blade
<!-- Compose from primitives -->
<x-gsmui:kanban>
    <x-slot name="columns">
        <x-gsmui:kanban.column id="backlog" label="Backlog" :max-items="10">
            <x-slot name="header">
                <x-gsmui:badge count="{{ $backlogCount }}" />
            </x-slot>
        </x-gsmui:kanban.column>
    </x-slot>
    
    <x-slot name="card" :card="$card">
        <x-gsmui:card class="h-full">
            <x-gsmui:avatar :src="$card->assignee->avatar" size="xs" />
            <h4>{{ $card->title }}</h4>
            <x-gsmui:badge variant="{{ $card->priority }}">{{ $card->priority }}</x-gsmui:badge>
        </x-gsmui:card>
    </x-slot>
</x-gsmui:kanban>
```

### Server-Side State

```php
// Livewire handles all state
class KanbanBoard extends Component
{
    public array $columns = [];
    
    public function updateCardPosition(string $cardId, string $columnId, int $position): void
    {
        $this->dispatch('kanban:card-moved', [
            'cardId' => $cardId,
            'columnId' => $columnId,
            'position' => $position,
        ]);
    }
}
```

- Card cover images

- Custom fields
- Swimlanes (by assignee, label, etc.)
- Keyboard navigation
- Touch support
- Column scrolling
- Board-level search/filter

**Events:** `card-moved`, `card-clicked`, `card-created`, `column-added`, `column-reordered`

**Visual query/filter builder**

```blade
<x-gsmui:query-builder
    wire:model="query"
    :fields="$availableFields"
    :operators="$operators"
    :combinators="['and', 'or', 'not']"
    :default-combinator="'and'"
```

**Field Definition:**
```php

    'name' => 'email',
    'label' => 'Email',
    'type' => 'string',  // string, number, boolean, date, datetime, select, multiselect

    'validation' => 'email',
```

**Operators by Type:**
| Type | Operators |
|------|-----------|
| string | =, !=, contains, not_contains, starts_with, ends_with, in, not_in, is_null, is_not_null, is_empty, is_not_empty |
| number | =, !=, >, >=, <, <=, between, not_between, is_null, is_not_null |
| boolean | =, !=, is_null, is_not_null |
| date | =, !=, >, >=, <, <=, between, not_between, is_null, is_not_null, today, this_week, this_month, this_year |
| datetime | Same as date + time operators |
| select | =, !=, in, not_in, is_null, is_not_null |
| multiselect | contains, not_contains, in, not_in |

**Output:** JSON query object (convertible to SQL, Eloquent, Elasticsearch, MongoDB)

## Shared Architecture

### Livewire Integration

```php
abstract class AdvancedComponent extends Component
{
    use InteractsWithAdvancedState;
    
    public array $state = [];
    
    public function mount(array $initial = []): void
    {
        $this->state = array_merge($this->defaultState(), $initial);
    }
    
    protected function defaultState(): array
    {
        return [];
    }
    
    public function getState(string $key, mixed $default = null): mixed
    {
        return data_get($this->state, $key, $default);
    }
    
    public function setState(string $key, mixed $value): void
    {
        data_set($this->state, $key, $value);
        $this->dispatch('state-changed', key: $key, value: $value);
    }
    
    public function dispatchBrowserEvent(string $event, array $payload = []): void
    {
        $this->dispatch('browser:' . $event, $payload);
    }
}
```

### JavaScript Bridge

```javascript
// Advanced component base class
class GsmuiAdvancedComponent {
    constructor(element) {
        this.element = element;
        this.state = {};
        this.listeners = new Map();
        this.init();
    }
    
    init() {
        this.bindLivewire();
        this.bindEvents();
        this.restoreState();
    }
    
    bindLivewire() {
        if (window.Livewire) {
            Livewire.on('state-changed', ({ key, value }) => {
                this.setState(key, value);
            });
        }
    }
    
    emit(event, payload) {
        this.element.dispatchEvent(new CustomEvent(`gsmui:${event}`, { detail: payload }));
        
        if (window.Livewire) {
            Livewire.dispatch(event, payload);
        }
    }
    
    on(event, handler) {
        this.element.addEventListener(`gsmui:${event}`, (e) => handler(e.detail));
    }
}
```

## Virtual Scrolling

### Implementation for Large Datasets

GsmUi advanced components support virtual scrolling for datasets exceeding 10,000 rows. The virtualization engine renders only the visible viewport plus a configurable overscan buffer, reducing DOM nodes from 100k+ to ~50.

### Core Virtual Scroller

```javascript
class GsmuiVirtualScroller {
    constructor(element, options = {}) {
        this.element = element;
        this.itemHeight = options.itemHeight || 40;
        this.overscan = options.overscan || 5;
        this.buffer = document.createElement('div');
        this.viewport = element.querySelector('[data-viewport]') || element;
        this.items = options.items || [];
        this.renderItem = options.renderItem || (() => '');
        this.sentinel = document.createElement('div');
        this.sentinel.style.height = '1px';
        this.viewport.appendChild(this.sentinel);
        this.scrollTop = 0;
        this.visibleStart = 0;
        this.visibleEnd = 0;
        this.renderedRange = { start: -1, end: -1 };
        this.init();
    }

    init() {
        this.viewport.style.overflow = 'auto';
        this.viewport.style.position = 'relative';
        this.viewport.addEventListener('scroll', this.onScroll.bind(this), { passive: true });
        this.render();
    }

    onScroll() {
        this.scrollTop = this.viewport.scrollTop;
        requestAnimationFrame(() => this.render());
    }

    getVisibleRange() {
        const start = Math.floor(this.scrollTop / this.itemHeight);
        const visibleCount = Math.ceil(this.viewport.clientHeight / this.itemHeight);
        const end = start + visibleCount;
        return {
            start: Math.max(0, start - this.overscan),
            end: Math.min(this.items.length - 1, end + this.overscan),
        };
    }

    render() {
        const range = this.getVisibleRange();
        if (range.start === this.renderedRange.start && range.end === this.renderedRange.end) {
            return;
        }
        this.renderedRange = range;
        this.viewport.style.height = `${this.items.length * this.itemHeight}px`;
        const fragment = document.createDocumentFragment();
        for (let i = range.start; i <= range.end; i++) {
            const row = document.createElement('div');
            row.style.position = 'absolute';
            row.style.top = `${i * this.itemHeight}px`;
            row.style.height = `${this.itemHeight}px`;
            row.style.width = '100%';
            row.innerHTML = this.renderItem(this.items[i], i);
            fragment.appendChild(row);
        }
        this.viewport.innerHTML = '';
        this.viewport.appendChild(fragment);
        this.viewport.appendChild(this.sentinel);
    }

    setItems(items) {
        this.items = items;
        this.renderedRange = { start: -1, end: -1 };
        this.render();
    }

    scrollToIndex(index) {
        this.viewport.scrollTop = index * this.itemHeight;
    }

    destroy() {
        this.viewport.removeEventListener('scroll', this.onScroll);
    }
}
```

```javascript
class GsmuiColumnVirtualizer {
    constructor(container, options = {}) {

        const start = Math.floor(this.scrollLeft / this.columnWidth);
        const count = Math.ceil(viewportWidth / this.columnWidth);
        const end = start + count;
        return {

            end: Math.min(this.columns.length - 1, end + this.overscan),
        };
    }

        const range = this.getVisibleColumns();
        const visible = this.columns.slice(range.start, range.end + 1);
        return visible;
    }
```

```javascript
class GsmuiBidirectionalScroller extends GsmuiVirtualScroller {
    constructor(element, options) {
        super(element, options);
        this.loadingTop = false;
        this.loadingBottom = false;
        this.onLoadTop = options.onLoadTop || null;
        this.onLoadBottom = options.onLoadBottom || null;
        this.topSentinel = document.createElement('div');
        this.topSentinel.style.height = '1px';
        this.intersectionObserver = new IntersectionObserver(this.onIntersection.bind(this), {
            root: this.viewport,
            threshold: 0.1,
        });
    }

    prependItems(newItems) {
        this.loadingTop = true;
        const prevScrollHeight = this.viewport.scrollHeight;
        this.items = [...newItems, ...this.items];
        this.render();
        this.viewport.scrollTop = this.viewport.scrollHeight - prevScrollHeight;
        this.loadingTop = false;
    }

    appendItems(newItems) {
        this.loadingBottom = true;
        this.items = [...this.items, ...newItems];
        this.render();
        this.loadingBottom = false;
    }

    onIntersection(entries) {
        entries.forEach(entry => {
            if (entry.target === this.topSentinel && entry.isIntersecting && this.onLoadTop) {
                this.onLoadTop();
            }
        });
    }

    destroy() {
        super.destroy();
        this.intersectionObserver.disconnect();
    }
}
```

## Drag and Drop

### Sortable Integration

GsmUi provides a unified drag-and-drop API built on top of native HTML5 Drag and Drop with SortableJS as an optional enhancement for touch support.

### Core Drag and Drop Manager

```javascript
class GsmuiDragManager {
    constructor(options = {}) {
        this.dragElement = null;
        this.dropTargets = new Map();
        this.ghostElement = null;
        this.offsetX = 0;
        this.offsetY = 0;
        this.animation = options.animation !== false;
        this.group = options.group || null;
        this.sortable = null;
        this.init();
    }

    init() {
        document.addEventListener('dragstart', this.onDragStart.bind(this));
        document.addEventListener('dragover', this.onDragOver.bind(this));
        document.addEventListener('dragenter', this.onDragEnter.bind(this));
        document.addEventListener('dragleave', this.onDragLeave.bind(this));
        document.addEventListener('drop', this.onDrop.bind(this));
        document.addEventListener('dragend', this.onDragEnd.bind(this));
    }

    registerDraggable(element, config = {}) {
        element.setAttribute('draggable', 'true');
        element._gsmuiDragConfig = config;
        element.addEventListener('dragstart', (e) => {
            this.dragElement = element;
            e.dataTransfer.effectAllowed = config.effect || 'move';
            e.dataTransfer.setData('text/plain', config.id || '');
            if (config.onDragStart) config.onDragStart(e, element);
        });
    }

    registerDropTarget(element, config = {}) {
        this.dropTargets.set(element, config);
        element._gsmuiDropConfig = config;
    }

    onDragStart(e) {
        if (!this.dragElement) return;
        this.dragElement.classList.add('gsmui-dragging');
        document.body.classList.add('gsmui-drag-active');
        this.createGhost(e);
    }

    createGhost(e) {
        if (!this.animation) return;
        this.ghostElement = this.dragElement.cloneNode(true);
        this.ghostElement.classList.add('gsmui-drag-ghost');
        this.ghostElement.style.position = 'fixed';
        this.ghostElement.style.pointerEvents = 'none';
        this.ghostElement.style.zIndex = '9999';
        this.ghostElement.style.opacity = '0.8';
        this.ghostElement.style.width = `${this.dragElement.offsetWidth}px`;
        document.body.appendChild(this.ghostElement);
    }

    onDragOver(e) {
        e.preventDefault();
        e.dataTransfer.dropEffect = e.dataTransfer.effectAllowed || 'move';
        if (this.ghostElement) {
            this.ghostElement.style.left = `${e.clientX}px`;
            this.ghostElement.style.top = `${e.clientY}px`;
        }
    }

    onDragEnter(e) {
        const target = e.currentTarget;
        target.classList.add('gsmui-drag-over');
        const config = this.dropTargets.get(target);
        if (config?.onDragEnter) config.onDragEnter(e, target, this.dragElement);
    }

    onDragLeave(e) {
        const target = e.currentTarget;
        target.classList.remove('gsmui-drag-over');
        const config = this.dropTargets.get(target);
        if (config?.onDragLeave) config.onDragLeave(e, target, this.dragElement);
    }

    onDrop(e) {
        e.preventDefault();
        const target = e.currentTarget;
        target.classList.remove('gsmui-drag-over');
        const config = this.dropTargets.get(target);
        if (config?.onDrop) {
            config.onDrop(e, target, this.dragElement);
        }
    }

    onDragEnd(e) {
        if (this.dragElement) {
            this.dragElement.classList.remove('gsmui-dragging');
        }
        document.body.classList.remove('gsmui-drag-active');
        this.dropTargets.forEach((config, target) => {
            target.classList.remove('gsmui-drag-over');
            if (config.onDragEnd) config.onDragEnd(e, target, this.dragElement);
        });
        if (this.ghostElement) {
            this.ghostElement.remove();
            this.ghostElement = null;
        }
        this.dragElement = null;
    }

    destroy() {
        document.removeEventListener('dragstart', this.onDragStart);
        document.removeEventListener('dragover', this.onDragOver);
        document.removeEventListener('dragenter', this.onDragEnter);
        document.removeEventListener('dragleave', this.onDragLeave);
        document.removeEventListener('drop', this.onDrop);
        document.removeEventListener('dragend', this.onDragEnd);
    }
}
```

### Kanban Drag and Drop

```javascript
class GsmuiKanbanDrag {
    constructor(boardElement, options = {}) {
        this.board = boardElement;
        this.columns = new Map();
        this.cardElement = null;
        this.sourceColumn = null;
        this.placeholder = null;
        this.onCardMoved = options.onCardMoved || null;
        this.onColumnReordered = options.onColumnReordered || null;
        this.wipLimits = new Map();
        this.init();
    }

    init() {
        this.board.querySelectorAll('[data-kanban-column]').forEach(col => {
            const columnId = col.dataset.columnId;
            const maxItems = parseInt(col.dataset.maxItems) || Infinity;
            this.columns.set(columnId, col);
            this.wipLimits.set(columnId, maxItems);
            this.setupColumnDropZone(col);
            this.setupCards(col);
        });
        this.setupColumnDrag();
    }

    setupColumnDropZone(column) {
        column.addEventListener('dragover', (e) => {
            e.preventDefault();
            const afterElement = this.getDragAfterElement(column, e.clientY);
            const draggable = document.querySelector('.gsmui-dragging');
            if (!draggable) return;
            if (afterElement == null) {
                column.appendChild(this.placeholder || draggable);
            } else {
                column.insertBefore(this.placeholder || draggable, afterElement);
            }
        });

        column.addEventListener('drop', (e) => {
            e.preventDefault();
            const cardId = e.dataTransfer.getData('text/plain');
            const columnId = column.dataset.columnId;
            const currentCount = column.querySelectorAll('[data-kanban-card]').length;
            const maxItems = this.wipLimits.get(columnId);
            if (currentCount >= maxItems) {
                this.showWipLimitWarning(column, maxItems);
                return;
            }
            this.onCardMoved?.({ cardId, columnId, position: this.getPosition(column) });
        });
    }

    setupCards(column) {
        column.querySelectorAll('[data-kanban-card]').forEach(card => {
            card.setAttribute('draggable', 'true');
            card.addEventListener('dragstart', (e) => {
                this.cardElement = card;
                this.sourceColumn = column;
                card.classList.add('gsmui-dragging');
                e.dataTransfer.setData('text/plain', card.dataset.cardId);
                e.dataTransfer.effectAllowed = 'move';
            });
            card.addEventListener('dragend', () => {
                card.classList.remove('gsmui-dragging');
                this.cardElement = null;
                this.sourceColumn = null;
            });
        });
    }

    setupColumnDrag() {
        this.board.querySelectorAll('[data-kanban-column-header]').forEach(header => {
            header.setAttribute('draggable', 'true');
            header.addEventListener('dragstart', (e) => {
                e.dataTransfer.setData('text/column', header.dataset.columnId);
                e.dataTransfer.effectAllowed = 'move';
            });
        });
    }

    getDragAfterElement(column, y) {
        const draggableElements = [...column.querySelectorAll('[data-kanban-card]:not(.gsmui-dragging)')];
        return draggableElements.reduce((closest, child) => {
            const box = child.getBoundingClientRect();
            const offset = y - box.top - box.height / 2;
            if (offset < 0 && offset > closest.offset) {
                return { offset, element: child };
            }
            return closest;
        }, { offset: Number.NEGATIVE_INFINITY }).element;
    }

    getPosition(column) {
        if (!this.cardElement) return 0;
        const cards = [...column.querySelectorAll('[data-kanban-card]')];
        return cards.indexOf(this.cardElement);
    }

    showWipLimitWarning(column, maxItems) {
        const warning = document.createElement('div');
        warning.className = 'gsmui-wip-warning';
        warning.textContent = `WIP limit reached (${maxItems})`;
        warning.style.cssText = 'position:absolute;top:50%;left:50%;transform:translate(-50%,-50%);background:#ef4444;color:white;padding:8px 16px;border-radius:8px;z-index:100;';
        column.style.position = 'relative';
        column.appendChild(warning);
        setTimeout(() => warning.remove(), 2000);
    }

    destroy() {
        this.columns.clear();
        this.wipLimits.clear();
    }
}
```

```javascript
class GsmuiRichEditor {
    constructor(element, options = {}) {
        this.element = element;
        this.toolbar = element.querySelector('[data-editor-toolbar]');
        this.content = element.querySelector('[data-editor-content]');

        this.editor = null;

    }

    async init() {
        const { Editor } = await import('@tiptap/core');
        const { StarterKit } = await import('@tiptap/starter-kit');
        const { Placeholder } = await import('@tiptap/extension-placeholder');
        const { TextAlign } = await import('@tiptap/extension-text-align');

        const { TaskList } = await import('@tiptap/extension-task-list');

        const { Highlight } = await import('@tiptap/extension-highlight');
        const { Underline } = await import('@tiptap/extension-underline');

        this.editor = new Editor({
            element: this.content,
            editable: !this.readonly,
            extensions: [
                StarterKit.configure({
                    heading: { levels: [1, 2, 3, 4] },
                }),
                Placeholder.configure({ placeholder: this.placeholder }),
                TextAlign.configure({ types: ['heading', 'paragraph'] }),
                Link.configure({ openOnClick: false }),
                Image.configure({ inline: true }),
                Table.configure({ resizable: true }),
                TableRow,
                TableCell,
                TableHeader,
                CodeBlock,
                TaskList,
                TaskItem.configure({ nested: true }),
                Highlight,
                Underline,
                ...this.extension,
            ],
            content: this.element.querySelector('[data-editor-initial-content]')?.innerHTML || '',
            onUpdate: ({ editor }) => {
                this.onUpdate?.(editor.getHTML(), editor.getJSON());
            },
            onBlur: ({ editor }) => {
                this.onChange?.(editor.getHTML(), editor.getJSON());
            },
        });
        this.initToolbar();
    }

    initToolbar() {
        if (!this.toolbar) return;
        this.toolbar.querySelectorAll('[data-editor-command]').forEach(btn => {
            btn.addEventListener('click', (e) => {
                e.preventDefault();
                const command = btn.dataset.editorCommand;
                const value = btn.dataset.editorValue || null;
                this.executeCommand(command, value);
            });
        });
        this.toolbar.querySelectorAll('[data-editor-input]').forEach(input => {
            input.addEventListener('change', () => {
                const command = input.dataset.editorInput;
                this.executeCommand(command, input.value);
            });
        });
        this.updateToolbarState();
    }

    executeCommand(command, value) {
        if (!this.editor) return;
        switch (command) {
            case 'bold': this.editor.chain().focus().toggleBold().run(); break;
            case 'italic': this.editor.chain().focus().toggleItalic().run(); break;
            case 'underline': this.editor.chain().focus().toggleUnderline().run(); break;
            case 'strike': this.editor.chain().focus().toggleStrike().run(); break;
            case 'code': this.editor.chain().focus().toggleCode().run(); break;
            case 'heading': this.editor.chain().focus().toggleHeading({ level: parseInt(value) }).run(); break;
            case 'bulletList': this.editor.chain().focus().toggleBulletList().run(); break;
            case 'orderedList': this.editor.chain().focus().toggleOrderedList().run(); break;
            case 'taskList': this.editor.chain().focus().toggleTaskList().run(); break;
            case 'blockquote': this.editor.chain().focus().toggleBlockquote().run(); break;
            case 'codeBlock': this.editor.chain().focus().toggleCodeBlock().run(); break;
            case 'horizontalRule': this.editor.chain().focus().setHorizontalRule().run(); break;
            case 'undo': this.editor.chain().focus().undo().run(); break;
            case 'redo': this.editor.chain().focus().redo().run(); break;
            case 'link': this.setLink(value); break;
            case 'align': this.editor.chain().focus().setTextAlign(value).run(); break;
            case 'highlight': this.editor.chain().focus().toggleHighlight().run(); break;
            default: this.editor.chain().focus().run(command); break;
        }
        this.updateToolbarState();
    }

    setLink(url) {
        if (url === null) {
            this.editor.chain().focus().unsetLink().run();
            return;
        }
        this.editor.chain().focus().extendMarkRange('link').setLink({ href: url }).run();
    }

    updateToolbarState() {
        if (!this.toolbar || !this.editor) return;
        this.toolbar.querySelectorAll('[data-editor-command]').forEach(btn => {
            const command = btn.dataset.editorCommand;
            let isActive = false;
            switch (command) {
                case 'bold': isActive = this.editor.isActive('bold'); break;
                case 'italic': isActive = this.editor.isActive('italic'); break;
                case 'underline': isActive = this.editor.isActive('underline'); break;
                case 'strike': isActive = this.editor.isActive('strike'); break;
                case 'heading': isActive = this.editor.isActive('heading', { level: parseInt(btn.dataset.editorValue) }); break;
                case 'bulletList': isActive = this.editor.isActive('bulletList'); break;
                case 'orderedList': isActive = this.editor.isActive('orderedList'); break;
                case 'taskList': isActive = this.editor.isActive('taskList'); break;
                case 'blockquote': isActive = this.editor.isActive('blockquote'); break;
                case 'codeBlock': isActive = this.editor.isActive('codeBlock'); break;
                case 'highlight': isActive = this.editor.isActive('highlight'); break;
            }
            btn.classList.toggle('gsmui-editor-active', isActive);
            btn.setAttribute('aria-pressed', isActive.toString());
        });
    }

    getHTML() { return this.editor?.getHTML() || ''; }
    getJSON() { return this.editor?.getJSON() || null; }
    getText() { return this.editor?.getText() || ''; }
    setContent(html) { this.editor?.commands.setContent(html); }
    focus() { this.editor?.commands.focus(); }
    destroy() { this.editor?.destroy(); }
}
```

```javascript
class GsmuiTreeSitterHighlighter {
    constructor() {
        this.languages = new Map();
        this.parser = null;
    }

    async init() {
        const Parser = await import('web-tree-sitter');
        this.parser = new Parser.default();
        await this.parser.init();
        return this;
    }

    async loadLanguage(name, wasmUrl) {
        const Language = await import('web-tree-sitter');
        const lang = await Language.Language.load(wasmUrl);
        this.parser.setLanguage(lang);
        this.languages.set(name, lang);
        return lang;
    }

    highlight(code, language) {
        const tree = this.parser.parse(code);
        const nodes = [];
        this.walkTree(tree.rootNode, nodes, 0);
        return this.renderHighlightedNodes(nodes, code);
    }

    walkTree(node, nodes, depth) {
        if (node.childCount === 0) {
            nodes.push({
                type: node.nodeType,
                text: node.text,
                start: node.startPosition,
                end: node.endPosition,
                depth,
            });
        } else {
            for (let i = 0; i < node.childCount; i++) {
                this.walkTree(node.children[i], nodes, depth + 1);
            }
        }
    }

    renderHighlightedNodes(nodes, code) {
        let html = '';
        let lastIndex = 0;
        nodes.forEach(node => {
            const offset = code.indexOf(node.text, lastIndex);
            if (offset > lastIndex) {
                html += code.slice(lastIndex, offset);
            }
            const cls = `gsmui-ts-${node.type}`;
            html += `<span class="${cls}">${this.escapeHtml(node.text)}</span>`;
            lastIndex = offset + node.text.length;
        });
        if (lastIndex < code.length) {
            html += code.slice(lastIndex);
        }
        return html;
    }

    escapeHtml(str) {
        return str.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');
    }
}
```

```javascript
class GsmuiMarkdownEditor {
    constructor(element, options = {}) {
        this.element = element;
        this.textarea = element.querySelector('textarea');
        this.preview = element.querySelector('[data-md-preview]');
        this.toolbar = element.querySelector('[data-md-toolbar]');
        this.splitMode = options.splitMode ?? true;
        this.previewDebounce = options.previewDebounce || 300;
        this.onUpdate = options.onUpdate || null;
        this.onChange = options.onChange || null;
        this.marked = null;
        this.editor = null;
        this.debounceTimer = null;
        this.init();
    }

    async init() {
        const { marked } = await import('marked');
        const { gfm } = await import('marked-gfm');
        this.marked = marked;
        this.marked.use(gfm());
        this.marked.use({
            breaks: true,
            gfm: true,
            headerIds: true,
            mangle: false,
        });
        this.renderPreview();
        this.initToolbar();
        this.initKeyboardShortcuts();
        this.textarea?.addEventListener('input', this.onInput.bind(this));
    }

    onInput() {
        clearTimeout(this.debounceTimer);
        this.debounceTimer = setTimeout(() => {
            this.renderPreview();
            this.onUpdate?.(this.textarea.value);
        }, this.previewDebounce);
    }

    renderPreview() {
        if (!this.preview || !this.textarea) return;
        const html = this.marked.parse(this.textarea.value);
        this.preview.innerHTML = html;
        this.preview.querySelectorAll('pre code').forEach(block => {
            if (window.Prism) {
                window.Prism.highlightElement(block);
            }
        });
    }

    insertMarkdown(syntax, placeholder = '') {
        const start = this.textarea.selectionStart;
        const end = this.textarea.selectionEnd;
        const selected = this.textarea.value.substring(start, end);
        const text = selected || placeholder;
        let replacement;
        switch (syntax) {
            case 'bold': replacement = `**${text}**`; break;
            case 'italic': replacement = `*${text}*`; break;
            case 'strikethrough': replacement = `~~${text}~~`; break;
            case 'code': replacement = selected.includes('\n') ? `\`\`\`\n${text}\n\`\`\`` : `\`${text}\``; break;
            case 'link': replacement = `[${text}](url)`; break;
            case 'image': replacement = `![${text}](url)`; break;
            case 'heading1': replacement = `# ${text}`; break;
            case 'heading2': replacement = `## ${text}`; break;
            case 'heading3': replacement = `### ${text}`; break;
            case 'ul': replacement = `- ${text}`; break;
            case 'ol': replacement = `1. ${text}`; break;
            case 'task': replacement = `- [ ] ${text}`; break;
            case 'quote': replacement = `> ${text}`; break;
            case 'hr': replacement = `---\n`; break;
            case 'table': replacement = `| Header | Header |\n|--------|--------|\n| Cell   | Cell   |`; break;
            default: replacement = text;
        }
        this.textarea.setRangeText(replacement, start, end, 'select');
        this.textarea.focus();
        this.onInput();
    }

    initToolbar() {
        if (!this.toolbar) return;
        this.toolbar.querySelectorAll('[data-md-action]').forEach(btn => {
            btn.addEventListener('click', (e) => {
                e.preventDefault();
                const action = btn.dataset.mdAction;
                if (action === 'toggle-preview') {
                    this.togglePreview();
                } else {
                    this.insertMarkdown(action, btn.dataset.mdPlaceholder || '');
                }
            });
        });
    }

    initKeyboardShortcuts() {
        this.textarea?.addEventListener('keydown', (e) => {
            if (e.ctrlKey || e.metaKey) {
                switch (e.key) {
                    case 'b': e.preventDefault(); this.insertMarkdown('bold'); break;
                    case 'i': e.preventDefault(); this.insertMarkdown('italic'); break;
                    case 'k': e.preventDefault(); this.insertMarkdown('link'); break;
                    case 'e': e.preventDefault(); this.insertMarkdown('code'); break;
                }
            }
            if (e.key === 'Tab') {
                e.preventDefault();
                this.textarea.setRangeText('    ', this.textarea.selectionStart, this.textarea.selectionEnd, 'end');
            }
        });
    }

    togglePreview() {
        this.element.classList.toggle('gsmui-md-preview-hidden');
    }

    getValue() { return this.textarea?.value || ''; }
    setValue(md) { if (this.textarea) { this.textarea.value = md; this.onInput(); } }
    destroy() { clearTimeout(this.debounceTimer); }
}
```

```javascript
class GsmuiCanvas {
    constructor(canvasElement, options = {}) {
        this.canvas = canvasElement;
        this.ctx = canvasElement.getContext('2d');
        this.dpr = window.devicePixelRatio || 1;
        this.width = options.width || canvasElement.width;
        this.height = options.height || canvasElement.height;
        this.backgroundColor = options.backgroundColor || 'transparent';
        this.autoResize = options.autoResize ?? true;
        this.animationFrame = null;
        this.layers = [];
        this.interactive = options.interactive ?? false;
        this.hitRegions = [];
        this.init();
    }

    init() {
        this.resize();
        if (this.autoResize) {
            this.resizeObserver = new ResizeObserver(() => this.resize());
            this.resizeObserver.observe(this.canvas.parentElement);
        }
        if (this.interactive) {
            this.canvas.addEventListener('mousemove', this.onMouseMove.bind(this));
            this.canvas.addEventListener('click', this.onClick.bind(this));
            this.canvas.style.cursor = 'default';
        }
    }

    resize() {
        const rect = this.canvas.parentElement.getBoundingClientRect();
        this.width = rect.width;
        this.height = rect.height;
        this.canvas.width = this.width * this.dpr;
        this.canvas.height = this.height * this.dpr;
        this.canvas.style.width = `${this.width}px`;
        this.canvas.style.height = `${this.height}px`;
        this.ctx.scale(this.dpr, this.dpr);
        this.render();
    }

    clear() {
        this.ctx.clearRect(0, 0, this.width, this.height);
        if (this.backgroundColor !== 'transparent') {
            this.ctx.fillStyle = this.backgroundColor;
            this.ctx.fillRect(0, 0, this.width, this.height);
        }
    }

    render() {
        this.clear();
        this.hitRegions = [];
        this.layers.forEach(layer => {
            this.ctx.save();
            layer.render(this.ctx, this.width, this.height);
            if (layer.hitRegions) {
                this.hitRegions.push(...layer.hitRegions);
            }
            this.ctx.restore();
        });
    }

    addLayer(layer) {
        this.layers.push(layer);
        this.render();
    }

    removeLayer(layer) {
        this.layers = this.layers.filter(l => l !== layer);
        this.render();
    }

    onMouseMove(e) {
        const rect = this.canvas.getBoundingClientRect();
        const x = e.clientX - rect.left;
        const y = e.clientY - rect.top;
        let cursor = 'default';
        for (const region of this.hitRegions) {
            if (this.pointInRegion(x, y, region)) {
                cursor = region.cursor || 'pointer';
                if (region.onHover) region.onHover(x, y);
                break;
            }
        }
        this.canvas.style.cursor = cursor;
    }

    onClick(e) {
        const rect = this.canvas.getBoundingClientRect();
        const x = e.clientX - rect.left;
        const y = e.clientY - rect.top;
        for (const region of this.hitRegions) {
            if (this.pointInRegion(x, y, region)) {
                region.onClick?.(x, y, region.data);
                break;
            }
        }
    }

    pointInRegion(x, y, region) {
        const r = region.bounds;
        return x >= r.x && x <= r.x + r.width && y >= r.y && y <= r.y + r.height;
    }

    exportImage(format = 'png', quality = 1) {
        return this.canvas.toDataURL(`image/${format}`, quality);
    }

    exportBlob(format = 'png', quality = 1) {
        return new Promise(resolve => this.canvas.toBlob(resolve, `image/${format}`, quality));
    }

    destroy() {
        if (this.resizeObserver) this.resizeObserver.disconnect();
        cancelAnimationFrame(this.animationFrame);
    }
}
```

```javascript
class GsmuiChartLayer {
    constructor(data, options = {}) {
        this.data = data;
        this.type = options.type || 'line';

    }

    render(ctx, width, height) {
        const chartWidth = width - this.padding.left - this.padding.right;
        const chartHeight = height - this.padding.top - this.padding.bottom;
        const max = Math.max(...this.data.map(d => d.value));
        const min = Math.min(0, Math.min(...this.data.map(d => d.value)));
        const range = max - min || 1;

        if (this.showGrid) this.renderGrid(ctx, chartWidth, chartHeight);
        if (this.showLabels) this.renderLabels(ctx, chartWidth, chartHeight, this.data);

        ctx.beginPath();
        ctx.strokeStyle = this.colors[0];
        ctx.lineWidth = 2;
        ctx.lineJoin = 'round';

        this.data.forEach((point, i) => {
            const x = this.padding.left + (i / (this.data.length - 1)) * chartWidth;
            const y = this.padding.top + chartHeight - ((point.value - min) / range) * chartHeight;
            if (i === 0) ctx.moveTo(x, y);
            else ctx.lineTo(x, y);

            this.hitRegions.push({
                bounds: { x: x - 10, y: y - 10, width: 20, height: 20 },
                cursor: 'pointer',
                data: point,
            });
        });
        ctx.stroke();

        this.data.forEach((point, i) => {
            const x = this.padding.left + (i / (this.data.length - 1)) * chartWidth;
            const y = this.padding.top + chartHeight - ((point.value - min) / range) * chartHeight;
            ctx.beginPath();
            ctx.arc(x, y, 4, 0, Math.PI * 2);
            ctx.fillStyle = this.colors[0];
            ctx.fill();
            ctx.strokeStyle = '#ffffff';
            ctx.lineWidth = 2;
            ctx.stroke();
        });

            }
        });
    }
```

```javascript
class GsmuiWebGL {
    constructor(canvasElement, options = {}) {
        this.canvas = canvasElement;
        this.gl = canvasElement.getContext('webgl2', options.contextAttributes || {
            alpha: true,
            antialias: true,
            premultipliedAlpha: false,
        }) || canvasElement.getContext('webgl', options.contextAttributes || {
            alpha: true,
            antialias: true,
        });
        if (!this.gl) {
            throw new Error('GsmUi: WebGL is not supported in this browser.');
        }
        this.programs = new Map();
        this.buffers = new Map();
        this.textures = new Map();
        this.onRender = options.onRender || null;
        this.animationFrame = null;
        this.running = false;
        this.init();
    }

    init() {
        const gl = this.gl;
        gl.enable(gl.BLEND);
        gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA);
        gl.clearColor(0, 0, 0, 0);
    }

    createProgram(name, vertexSource, fragmentSource) {
        const gl = this.gl;
        const vertexShader = this.compileShader(gl.VERTEX_SHADER, vertexSource);
        const fragmentShader = this.compileShader(gl.FRAGMENT_SHADER, fragmentSource);
        const program = gl.createProgram();
        gl.attachShader(program, vertexShader);
        gl.attachShader(program, fragmentShader);
        gl.linkProgram(program);
        if (!gl.getProgramParameter(program, gl.LINK_STATUS)) {
            throw new Error(`GsmUi: Program ${name} link failed: ${gl.getProgramInfoLog(program)}`);
        }
        this.programs.set(name, program);
        return program;
    }

    compileShader(type, source) {
        const gl = this.gl;
        const shader = gl.createShader(type);
        gl.shaderSource(shader, source);
        gl.compileShader(shader);
        if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
            throw new Error(`GsmUi: Shader compile failed: ${gl.getShaderInfoLog(shader)}`);
        }
        return shader;
    }

    createBuffer(name, data, type = this.gl.ARRAY_BUFFER) {
        const gl = this.gl;
        const buffer = gl.createBuffer();
        gl.bindBuffer(type, buffer);
        gl.bufferData(type, new Float32Array(data), gl.STATIC_DRAW);
        this.buffers.set(name, buffer);
        return buffer;
    }

    createTexture(name, source) {
        const gl = this.gl;
        const texture = gl.createTexture();
        gl.bindTexture(gl.TEXTURE_2D, texture);
        gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
        gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
        gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR);
        gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, 1, 1, 0, gl.RGBA, gl.UNSIGNED_BYTE, source);
        this.textures.set(name, texture);
        return texture;
    }

    start() {
        if (this.running) return;
        this.running = true;
        const loop = (time) => {
            if (!this.running) return;
            this.onRender?.(this.gl, time);
            this.animationFrame = requestAnimationFrame(loop);
        };
        this.animationFrame = requestAnimationFrame(loop);
    }

    stop() {
        this.running = false;
        if (this.animationFrame) cancelAnimationFrame(this.animationFrame);
    }

    resize(width, height) {
        const dpr = window.devicePixelRatio || 1;
        this.canvas.width = width * dpr;
        this.canvas.height = height * dpr;
        this.canvas.style.width = `${width}px`;
        this.canvas.style.height = `${height}px`;
        this.gl.viewport(0, 0, this.canvas.width, this.canvas.height);
    }

    destroy() {
```

## Web Workers

### Off-Thread Processing

GsmUi leverages Web Workers for CPU-intensive tasks like data processing, sorting, filtering, and CSV/JSON parsing without blocking the main thread.

### Worker Manager

```javascript
class GsmuiWorkerManager {
    constructor() {
        this.workers = new Map();
        this.taskQueue = new Map();
        this.workerUrl = null;
    }

    async init() {
        const workerCode = `
            self.onmessage = async (e) => {
                const { taskId, type, payload } = e.data;
                try {
                    let result;
                    switch (type) {
                        case 'sort':
                            result = handleSort(payload);
                            break;
                        case 'filter':
                            result = handleFilter(payload);
                            break;
                        case 'parse-csv':
                            result = handleParseCSV(payload);
                            break;
                        case 'parse-json':
                            result = handleParseJSON(payload);
                            break;
                        case 'aggregate':
                            result = handleAggregate(payload);
                            break;
                        case 'search':
                            result = handleSearch(payload);
                            break;
                        case 'custom':
                            result = eval('(' + payload.fn + ')')(...payload.args);
                            break;
                        default:
                            throw new Error('Unknown task type: ' + type);
                    }
                    self.postMessage({ taskId, success: true, result });
                } catch (error) {
                    self.postMessage({ taskId, success: false, error: error.message });
                }
            };

            function handleSort({ data, field, direction, type }) {
                return data.sort((a, b) => {
                    let valA = a[field];
                    let valB = b[field];
                    if (type === 'number') { valA = Number(valA); valB = Number(valB); }
                    if (type === 'date') { valA = new Date(valA).getTime(); valB = new Date(valB).getTime(); }
                    if (valA < valB) return direction === 'asc' ? -1 : 1;
                    if (valA > valB) return direction === 'asc' ? 1 : -1;
                    return 0;
                });
            }

            function handleFilter({ data, filters }) {
                return data.filter(row => {
                    return filters.every(({ field, operator, value }) => {
                        const cellValue = row[field];
                        switch (operator) {
                            case '=': case '==': return cellValue == value;
                            case '!=': case '!==': return cellValue != value;
                            case '>': return cellValue > value;
                            case '>=': return cellValue >= value;
                            case '<': return cellValue < value;
                            case '<=': return cellValue <= value;
                            case 'contains': return String(cellValue).toLowerCase().includes(String(value).toLowerCase());
                            case 'starts_with': return String(cellValue).toLowerCase().startsWith(String(value).toLowerCase());
                            case 'ends_with': return String(cellValue).toLowerCase().endsWith(String(value).toLowerCase());
                            case 'in': return Array.isArray(value) && value.includes(cellValue);
                            case 'not_in': return Array.isArray(value) && !value.includes(cellValue);
                            case 'is_null': return cellValue === null || cellValue === undefined;
                            case 'is_not_null': return cellValue !== null && cellValue !== undefined;
                            default: return true;
                        }
                    });
                });
            }

            function handleParseCSV({ text, delimiter = ',', hasHeader = true }) {
                const lines = text.split('\\n').filter(l => l.trim());
                if (lines.length === 0) return { headers: [], rows: [] };
                const parseRow = (line) => {
                    const result = [];
                    let current = '';
                    let inQuotes = false;
                    for (let i = 0; i < line.length; i++) {
                        const ch = line[i];
                        if (ch === '"') { inQuotes = !inQuotes; }
                        else if (ch === delimiter && !inQuotes) { result.push(current.trim()); current = ''; }
                        else { current += ch; }
                    }
                    result.push(current.trim());
                    return result;
                };
                if (hasHeader) {
                    const headers = parseRow(lines[0]);
                    const rows = lines.slice(1).map(line => {
                        const values = parseRow(line);
                        const obj = {};
                        headers.forEach((h, i) => { obj[h] = values[i] || ''; });
                        return obj;
                    });
                    return { headers, rows };
                }
                return { headers: [], rows: lines.map(l => parseRow(l)) };
            }

            function handleParseJSON({ text }) {
                return JSON.parse(text);
            }

            function handleAggregate({ data, field, fn }) {
                const values = data.map(r => Number(r[field])).filter(v => !isNaN(v));
                switch (fn) {
                    case 'sum': return values.reduce((a, b) => a + b, 0);
                    case 'avg': return values.length ? values.reduce((a, b) => a + b, 0) / values.length : 0;
                    case 'min': return Math.min(...values);
                    case 'max': return Math.max(...values);
                    case 'count': return values.length;
                    case 'countDistinct': return new Set(values).size;
                    default: return 0;
                }
            }

            function handleSearch({ data, query, fields }) {
                const lowerQuery = query.toLowerCase();
                return data.filter(row =>
                    fields.some(field => String(row[field] || '').toLowerCase().includes(lowerQuery))
                );
            }
        `;
        const blob = new Blob([workerCode], { type: 'application/javascript' });
        this.workerUrl = URL.createObjectURL(blob);
    }

    createWorker() {
        const worker = new Worker(this.workerUrl);
        return worker;
    }

    runTask(type, payload) {
        return new Promise((resolve, reject) => {
            const taskId = `task-${Date.now()}-${Math.random().toString(36).substr(2, 6)}`;
            const worker = this.createWorker();
            this.workers.set(taskId, worker);
            const timeout = setTimeout(() => {
                worker.terminate();
                this.workers.delete(taskId);
                reject(new Error(`GsmUi Worker: Task ${taskId} timed out after 30s`));
            }, 30000);
            worker.onmessage = (e) => {
                clearTimeout(timeout);
                worker.terminate();
                this.workers.delete(taskId);
                if (e.data.success) resolve(e.data.result);
                else reject(new Error(e.data.error));
            };
            worker.onerror = (e) => {
                clearTimeout(timeout);
                worker.terminate();
                this.workers.delete(taskId);
                reject(e);
            };
            worker.postMessage({ taskId, type, payload });
        });
    }

    terminateAll() {
        this.workers.forEach(w => w.terminate());
        this.workers.clear();
        if (this.workerUrl) URL.revokeObjectURL(this.workerUrl);
    }
}
```

```javascript
class GsmuiWasmLoader {
    constructor() {
        this.modules = new Map();
        this.instances = new Map();
    }

    async load(name, wasmUrl, imports = {}) {
        if (this.instances.has(name)) {
            return this.instances.get(name);
        }
        let wasmBinary;
        if (typeof WebAssembly.instantiateStreaming === 'function') {
            const response = await fetch(wasmUrl);
            const { instance } = await WebAssembly.instantiateStreaming(response, imports);
            this.instances.set(name, instance);
            return instance;
        }
        const response = await fetch(wasmUrl);
        wasmBinary = await response.arrayBuffer();
        const { instance } = await WebAssembly.instantiate(wasmBinary, imports);
        this.instances.set(name, instance);
        return instance;
    }

    get(name) {
        return this.instances.get(name);
    }

    has(name) {
        return this.instances.has(name);
    }
}
```

### WASM Image Processor

```javascript
class GsmuiWasmImageProcessor {
    constructor(wasmLoader) {
        this.loader = wasmLoader;
        this.instance = null;
    }

    async init() {
        this.instance = await this.loader.load('image-processor', '/vendor/gsmui/wasm/image-processor.wasm', {
            env: {
                memory: new WebAssembly.Memory({ initial: 256, maximum: 512 }),
            },
        });
        return this;
    }

    async resize(imageData, width, height) {
        const { data, width: srcWidth, height: srcHeight } = imageData;
        const inputPtr = this.instance.exports.malloc(data.length);
        const HEAP = new Uint8Array(this.instance.exports.memory.buffer);
        HEAP.set(new Uint8Array(data.buffer), inputPtr);
        const outputPtr = this.instance.exports.resize(inputPtr, srcWidth, srcHeight, width, height);
        const outputSize = width * height * 4;
        const output = new Uint8Array(this.instance.exports.memory.buffer, outputPtr, outputSize).slice();
        this.instance.exports.free(inputPtr);
        this.instance.exports.free(outputPtr);
        return new ImageData(new Uint8ClampedArray(output.buffer), width, height);
    }

    async applyFilter(imageData, filterType) {
        const { data, width, height } = imageData;
        const inputPtr = this.instance.exports.malloc(data.length);
        const HEAP = new Uint8Array(this.instance.exports.memory.buffer);
        HEAP.set(new Uint8Array(data.buffer), inputPtr);
        const filterId = { grayscale: 0, sepia: 1, invert: 2, blur: 3, sharpen: 4 }[filterType] || 0;
        this.instance.exports.applyFilter(inputPtr, width, height, filterId);
        const output = new Uint8Array(this.instance.exports.memory.buffer, inputPtr, data.length).slice();
        this.instance.exports.free(inputPtr);
        return new ImageData(new Uint8ClampedArray(output.buffer), width, height);
    }

    async generatePDF(pages, options = {}) {
        const jsonStr = JSON.stringify({ pages, options });
        const encoder = new TextEncoder();
        const bytes = encoder.encode(jsonStr);
        const inputPtr = this.instance.exports.malloc(bytes.length);
        const HEAP = new Uint8Array(this.instance.exports.memory.buffer);
        HEAP.set(bytes, inputPtr);
        const resultPtr = this.instance.exports.generatePDF(inputPtr, bytes.length);
        const resultLen = this.instance.exports.getResultLength();
        const result = new Uint8Array(this.instance.exports.memory.buffer, resultPtr, resultLen).slice();
        this.instance.exports.free(inputPtr);
        this.instance.exports.free(resultPtr);
        return new Blob([result], { type: 'application/pdf' });
    }
}
```

## Component Lazy Loading

### Deferred Initialization

Advanced components can be deferred until they enter the viewport or until the page is interactive:

```javascript
class GsmuiLazyLoader {
    constructor() {
        this.pendingComponents = new Map();
        this.observer = null;
        this.init();
    }

    init() {
        this.observer = new IntersectionObserver((entries) => {
            entries.forEach(entry => {
                if (entry.isIntersecting) {
                    const el = entry.target;
                    const componentName = el.dataset.gsmuiLazy;
                    if (componentName && this.pendingComponents.has(componentName)) {
                        const factory = this.pendingComponents.get(componentName);
                        factory(el);
                        this.pendingComponents.delete(componentName);
                        this.observer.unobserve(el);
                    }
                }
            });
        }, { rootMargin: '200px' });
    }

    register(componentName, factory) {
        this.pendingComponents.set(componentName, factory);
        document.querySelectorAll(`[data-gsmui-lazy="${componentName}"]`).forEach(el => {
            this.observer.observe(el);
        });
    }

    destroy() {
        this.observer?.disconnect();
        this.pendingComponents.clear();
    }
}
```

### Built-in Metrics

```javascript
class GsmuiPerformanceMonitor {
    constructor() {
        this.metrics = new Map();
        this.marks = new Map();
    }

    mark(name) {
        this.marks.set(name, performance.now());
    }

    measure(name, startMark, endMark) {
        const start = this.marks.get(startMark) || 0;
        const end = this.marks.get(endMark) || performance.now();
        const duration = end - start;
        this.metrics.set(name, duration);
        return duration;
    }

    getMetric(name) {
        return this.metrics.get(name);
    }

    getAllMetrics() {
        return Object.fromEntries(this.metrics);
    }

    report() {
        const metrics = this.getAllMetrics();
        console.table(metrics);
        if (navigator.sendBeacon) {
            navigator.sendBeacon('/api/gsmui/metrics', JSON.stringify({
                url: window.location.href,
                metrics,
                timestamp: Date.now(),
            }));
        }
    }

    observeComponentRender(componentName) {
        const startTime = performance.now();
        return {
            finish: () => {
                const duration = performance.now() - startTime;
                this.metrics.set(`render:${componentName}`, duration);
                if (duration > 16) {
                    console.warn(`GsmUi: ${componentName} render took ${duration.toFixed(2)}ms (exceeded 16ms frame budget)`);
                }
            },
        };
    }
}

window.GsmuiMetrics = new GsmuiPerformanceMonitor();
```

# 13.13 Events System — GsmUi Events Specification

## Overview

The GsmUi event system provides a consistent way for components to communicate state changes, user interactions, and lifecycle events. It supports both DOM events (for JavaScript integration) and Livewire events (for server-side reactivity).

## Event Types

### 1. DOM Events (CustomEvent)

Components dispatch standard `CustomEvent` instances for JavaScript consumers.

```javascript
// Component dispatches
this.dispatchEvent(new CustomEvent('value-change', {
    detail: { value: this.value, previousValue: oldValue },
    bubbles: true,
    composed: true, // Crosses shadow DOM boundary
}));

// Consumer listens
element.addEventListener('value-change', (e) => {
    console.log(e.detail.value);
});
```

### 2. Livewire Events

Components emit events via Livewire's event system for server-side handling.

```php
// In component
$this->dispatch('value-changed', value: $this->value, previous: $oldValue);

// In parent Livewire component
#[On('value-changed')]
public function handleValueChanged($value, $previous) {
    // Server-side logic
}
```

### 3. Alpine.js Events

For lightweight client-side interactivity.

```blade
<div x-data="{ open: false }" 
     @click.outside="open = false"
     @keydown.escape.window="open = false">
     
    <button @click="open = !open" 
            @click.away="open = false"
            aria-expanded="{{ $open ? 'true' : 'false' }}">
        Toggle
    </button>
    
    <div x-show="open" x-transition>
        Content
    </div>
</div>
```

## Standard Event Names

### Value Events

| Event | Detail | When |
|-------|--------|------|
| `input` | `{ value }` | Value changes (live, on keystroke) |
| `change` | `{ value, previousValue }` | Value committed (blur, enter, selection) |
| `update:modelValue` | `{ value }` | Vue-compatible model update |

### State Events

| Event | Detail | When |
|-------|--------|------|
| `open-change` | `{ open: boolean }` | Popover/dropdown/modal opens/closes |
| `focus-change` | `{ focused: boolean }` | Component gains/loses focus |
| `hover-change` | `{ hovered: boolean }` | Mouse enters/leaves |
| `active-change` | `{ active: boolean }` | Mouse down/up |
| `disabled-change` | `{ disabled: boolean }` | Disabled state changes |
| `loading-change` | `{ loading: boolean }` | Loading state changes |
| `invalid-change` | `{ invalid: boolean, errors: string[] }` | Validation state changes |

### Selection Events

| Event | Detail | When |
|-------|--------|------|
| `select` | `{ value, label, item }` | Option selected |
| `deselect` | `{ value, label, item }` | Option deselected |
| `selection-change` | `{ values: [], items: [] }` | Multi-select changes |

### Navigation Events

| Event | Detail | When |
|-------|--------|------|
| `navigate` | `{ href, target }` | Link/button navigation |
| `tab-change` | `{ tabId, index }` | Tab activated |
| `step-change` | `{ step, index, direction }` | Stepper navigation |

### Lifecycle Events

| Event | Detail | When |
|-------|--------|------|
| `mount` | `{ component }` | Component mounted in DOM |
| `unmount` | `{ component }` | Component removed from DOM |
| `hydrate` | `{ component }` | Livewire component hydrated |
| `dehydrate` | `{ component }` | Livewire component dehydrated |

### Form Events

| Event | Detail | When |
|-------|--------|------|
| `submit` | `{ formData, submitter }` | Form submitted |
| `reset` | `{ }` | Form reset |
| `validate` | `{ valid: boolean, errors: [] }` | Validation run |
| `file-select` | `{ files: FileList }` | Files selected |
| `file-remove` | `{ file, index }` | File removed from upload |

## Event Payload Standards

### Base Payload Interface

```typescript
interface BaseEventDetail {
    component: string;        // Component name (e.g., "button", "select")
    componentId: string;      // Unique instance ID
    timestamp: number;        // Unix timestamp
}

interface ValueEventDetail extends BaseEventDetail {
    value: any;
    previousValue?: any;
}

interface StateEventDetail extends BaseEventDetail {
    state: string;
    enabled: boolean;
}

interface SelectionEventDetail extends BaseEventDetail {
    value: any;
    label: string;
    item: any;
    multiple: boolean;
}
```

## Component Event Implementation

### PHP (Livewire Component)

```php
trait EmitsEvents
{
    protected array $eventPrefix = '';
    
    protected function dispatchEvent(string $event, array $payload = []): void
    {
        $fullEvent = $this->eventPrefix . $event;
        
        $detail = array_merge([
            'component' => $this->componentName(),
            'componentId' => $this->getId(),
            'timestamp' => time() * 1000,
        ], $payload);
        
        // Dispatch to Livewire
        $this->dispatch($fullEvent, ...$detail);
        
        // Dispatch to browser (via Alpine bridge)
        $this->dispatchBrowserEvent($fullEvent, $detail);
    }
    
    protected function dispatchBrowserEvent(string $event, array $detail): void
    {
        $this->dispatch('browser:event', [
            'event' => $event,
            'detail' => $detail,
        ]);
    }
}

// Usage in component
class Select extends Component
{
    use EmitsEvents;
    
    protected string $eventPrefix = 'select:';
    
    public function open(): void
    {
        $this->open = true;
        $this->dispatchEvent('open-change', ['open' => true]);
    }
    
    public function selectOption($value): void
    {
        $previous = $this->value;
        $this->value = $value;
        
        $this->dispatchEvent('select', [
            'value' => $value,
            'label' => $this->getOptionLabel($value),
            'item' => $this->getOption($value),
            'multiple' => $this->multiple,
        ]);
        
        $this->dispatchEvent('change', [
            'value' => $value,
            'previousValue' => $previous,
        ]);
        
        $this->dispatchEvent('update:modelValue', ['value' => $value]);
    }
}
```

### JavaScript (Vanilla Component)

```javascript
class GsmuiComponent extends HTMLElement {
    #eventTarget = new EventTarget();
    
    // Public API for adding listeners
    addEventListener(type, listener, options) {
        return this.#eventTarget.addEventListener(type, listener, options);
    }
    
    removeEventListener(type, listener, options) {
        return this.#eventTarget.removeEventListener(type, listener, options);
    }
    
    #dispatch(eventName, detail = {}) {
        const event = new CustomEvent(eventName, {
            detail: {
                component: this.componentName,
                componentId: this.id || this.getAttribute('id') || this.generateId(),
                timestamp: Date.now(),
                ...detail,
            },
            bubbles: true,
            composed: true,
        });
        
        this.dispatchEvent(event);
        
        // Also dispatch on internal target for programmatic listeners
        this.#eventTarget.dispatchEvent(event);
        
        return event;
    }
    
    // Convenience methods
    #emitValueChange(value, previousValue) {
        this.#dispatch('input', { value });
        this.#dispatch('change', { value, previousValue });
    }
    
    #emitStateChange(state, enabled) {
        this.#dispatch(`${state}-change`, { [state]: enabled });
    }
}

// Usage
class Select extends GsmuiComponent {
    set open(value) {
        const changed = this._open !== value;
        this._open = value;
        this.setAttribute('open', value ? '' : null);
        
        if (changed) {
            this.#emitStateChange('open', value);
        }
    }
    
    selectOption(option) {
        const previous = this.value;
        this.value = option.value;
        
        this.#dispatch('select', {
            value: option.value,
            label: option.label,
            item: option,
            multiple: this.multiple,
        });
        
        this.#emitValueChange(this.value, previous);
    }
}
```

## Event Handling Patterns

### 1. Parent-Child Communication (Livewire)

```php
// Parent component
class Form extends Component
{
    #[On('select:change')]
    public function handleSelectChange($value, $previousValue, $componentId) {
        $this->formData[$componentId] = $value;
    }
    
    #[On('input:change')]
    public function handleInputChange($value, $previousValue, $componentId) {
        $this->validateOnly($componentId);
    }
}
```

### 2. Cross-Component (Alpine.js)

```blade
<div x-data="form()" x-init="
    @on('select:change', (e) => {
        formData[e.detail.componentId] = e.detail.value;
    })
    @on('input:change', (e) => {
        validateField(e.detail.componentId);
    })
">
    <x-gsmui:select id="country" wire:model="form.country" />
```

### 3. Global Event Bus (JavaScript)

```javascript
// Global event bus for cross-component communication
const GsmuiEvents = {
    bus: new EventTarget(),
    
    emit(event, detail) {
        this.bus.dispatchEvent(new CustomEvent(`gsmui:${event}`, {
            detail: { ...detail, timestamp: Date.now() },
            bubbles: true,
        }));
    },
    
    on(event, handler) {
        this.bus.addEventListener(`gsmui:${event}`, handler);
    },
    
    off(event, handler) {
        this.bus.removeEventListener(`gsmui:${event}`, handler);
    },
};

// Component integration
class Select extends GsmuiComponent {
    selectOption(option) {
        // Local event
        this.#dispatch('select', { value: option.value });
        
        // Global event
        GsmuiEvents.emit('select:change', {
            componentId: this.id,
            value: option.value,
            component: 'select',
        });
    }
}

// Consumer
GsmuiEvents.on('select:change', (e) => {
    analytics.track('select_changed', e.detail);
});
```

## Advanced Event Patterns

### Event Middleware

```php
<?php

namespace GsmUi\Events;

class EventMiddleware
{
    protected array $middlewares = [];
    
    public function use(string $name, callable $middleware): void
    {
        $this->middlewares[$name][] = $middleware;
    }
    
    public function handle(string $eventName, array $payload, callable $next): array
    {
        $middlewares = $this->middlewares[$eventName] ?? $this->middlewares['*'] ?? [];
        
        $pipeline = new Pipeline($middlewares);
        
        return $pipeline->through($payload, function ($payload) use ($next) {
            return $next($payload);
        });
    }
    
    public function getMiddleware(string $eventName): array
    {
        return $this->middlewares[$eventName] ?? [];
    }
}

class Pipeline
{
    protected array $pipes = [];
    
    public function __construct(array $pipes = [])
    {
        $this->pipes = $pipes;
    }
    
    public function through(array $payload, callable $destination): array
    {
        $pipeline = array_reduce(
            array_reverse($this->pipes),
            function ($next, $pipe) {
                return function ($payload) use ($next, $pipe) {
                    return $pipe($payload, $next);
                };
            },
            function ($payload) use ($destination) {
                return $destination($payload);
            }
        );
        
        return $pipeline($payload);
    }
}
```

### Event Debouncer

```php
<?php

namespace GsmUi\Events;

class EventDebouncer
{
    protected array $debounceTimers = [];
    protected int $defaultDelay = 300;
    
    public function debounce(string $key, callable $callback, int $delay = null): void
    {
        $delay = $delay ?? $this->defaultDelay;
        
        if (isset($this->debounceTimers[$key])) {
            timer_cancel($this->debounceTimers[$key]);
        }
        
        $this->debounceTimers[$key] = timer($delay / 1000, function () use ($callback) {
            $callback();
            unset($this->debounceTimers[$key]);
        });
    }
    
    public function throttle(string $key, callable $callback, int $delay = null): void
    {
        $delay = $delay ?? $this->defaultDelay;
        
        if (isset($this->debounceTimers[$key])) {
            return;
        }
        
        $callback();
        
        $this->debounceTimers[$key] = timer($delay / 1000, function () use ($key) {
            unset($this->debounceTimers[$key]);
        });
    }
    
    public function cancel(string $key): void
    {
        if (isset($this->debounceTimers[$key])) {
            timer_cancel($this->debounceTimers[$key]);
            unset($this->debounceTimers[$key]);
        }
    }
    
    public function cancelAll(): void
    {
        foreach ($this->debounceTimers as $key => $timer) {
            timer_cancel($timer);
        }
        $this->debounceTimers = [];
    }
}
```

### Event Batcher

```php
<?php

namespace GsmUi\Events;

class EventBatcher
{
    protected array $buffer = [];
    protected int $batchSize = 10;
    protected int $flushInterval = 100;
    protected ?Timer $timer = null;
    
    public function __construct(int $batchSize = 10, int $flushInterval = 100)
    {
        $this->batchSize = $batchSize;
        $this->flushInterval = $flushInterval;
    }
    
    public function push(string $event, array $payload): void
    {
        $this->buffer[] = [
            'event' => $event,
            'payload' => $payload,
            'timestamp' => microtime(true),
        ];
        
        if (count($this->buffer) >= $this->batchSize) {
            $this->flush();
        } elseif ($this->timer === null) {
            $this->timer = timer($this->flushInterval / 1000, function () {
                $this->flush();
            });
        }
    }
    
    public function flush(): void
    {
        if (empty($this->buffer)) {
            return;
        }
        
        $events = $this->buffer;
        $this->buffer = [];
        
        if ($this->timer) {
            timer_cancel($this->timer);
            $this->timer = null;
        }
        
        $this->dispatchBatch($events);
    }
    
    protected function dispatchBatch(array $events): void
    {
        // Group by event type
        $grouped = [];
        foreach ($events as $event) {
            $grouped[$event['event']][] = $event['payload'];
        }
        
        // Dispatch each event type with all payloads
        foreach ($grouped as $event => $payloads) {
            $this->dispatch("gsmui:batch:{$event}", [
                'events' => $payloads,
                'count' => count($payloads),
            ]);
        }
    }
    
    protected function dispatch(string $event, array $data): void
    {
        // Dispatch via Livewire or browser event
    }
}
```

## Event Validation

### Schema Validation

```php
<?php

namespace GsmUi\Events;

class EventValidator
{
    protected array $schemas = [];
    
    public function register(string $event, array $schema): void
    {
        $this->schemas[$event] = $schema;
    }
    
    public function validate(string $event, array $payload): ValidationResult
    {
        if (!isset($this->schemas[$event])) {
            return new ValidationResult(true);
        }
        
        $errors = [];
        $schema = $this->schemas[$event];
        
        foreach ($schema['required'] ?? [] as $field) {
            if (!array_key_exists($field, $payload)) {
                $errors[] = "Missing required field: {$field}";
            }
        }
        
        foreach ($payload as $key => $value) {
            if (!isset($schema['properties'][$key])) {
                continue;
            }
            
            $fieldSchema = $schema['properties'][$key];
            
            if (isset($fieldSchema['type']) && gettype($value) !== $fieldSchema['type']) {
                $errors[] = "Invalid type for {$key}: expected {$fieldSchema['type']}, got " . gettype($value);
            }
            
            if (isset($fieldSchema['enum']) && !in_array($value, $fieldSchema['enum'])) {
                $errors[] = "Invalid value for {$key}: must be one of " . implode(', ', $fieldSchema['enum']);
            }
            
            if (isset($fieldSchema['min']) && $value < $fieldSchema['min']) {
                $errors[] = "Value for {$key} must be at least {$fieldSchema['min']}";
            }
            
            if (isset($fieldSchema['max']) && $value > $fieldSchema['max']) {
                $errors[] = "Value for {$key} must be at most {$fieldSchema['max']}";
            }
        }
        
        return new ValidationResult(
            empty($errors),
            $errors
        );
    }
}
```

### Event Sanitizer

```php
<?php

namespace GsmUi\Events;

class EventSanitizer
{
    protected array $sanitizers = [];
    
    public function register(string $event, array $sanitizers): void
    {
        $this->sanitizers[$event] = $sanitizers;
    }
    
    public function sanitize(string $event, array $payload): array
    {
        if (!isset($this->sanitizers[$event])) {
            return $payload;
        }
        
        $sanitized = $payload;
        
        foreach ($this->sanitizers[$event] as $field => $rules) {
            if (!array_key_exists($field, $sanitized)) {
                continue;
            }
            
            foreach ((array) $rules as $rule) {
                $sanitized[$field] = $this->applyRule($sanitized[$field], $rule);
            }
        }
        
        return $sanitized;
    }
    
    protected function applyRule(mixed $value, string $rule): mixed
    {
        return match ($rule) {
            'trim' => is_string($value) ? trim($value) : $value,
            'lowercase' => is_string($value) ? strtolower($value) : $value,
            'uppercase' => is_string($value) ? strtoupper($value) : $value,
            'int' => (int) $value,
            'float' => (float) $value,
            'bool' => (bool) $value,
            'strip_tags' => is_string($value) ? strip_tags($value) : $value,
            'escape' => is_string($value) ? htmlspecialchars($value, ENT_QUOTES, 'UTF-8') : $value,
            default => $value,
        };
    }
}
```

## Event Queue

### Livewire Event Queue

```php
<?php

namespace GsmUi\Events;

class EventQueue
{
    protected array $queue = [];
    protected int $maxSize = 100;
    protected bool $processing = false;
    
    public function push(string $event, array $payload): void
    {
        if (count($this->queue) >= $this->maxSize) {
            array_shift($this->queue);
        }
        
        $this->queue[] = [
            'event' => $event,
            'payload' => $payload,
            'timestamp' => microtime(true),
            'id' => uniqid(),
        ];
        
        if (!$this->processing) {
            $this->process();
        }
    }
    
    public function pop(): ?array
    {
        return array_shift($this->queue);
    }
    
    public function peek(): ?array
    {
        return $this->queue[0] ?? null;
    }
    
    public function size(): int
    {
        return count($this->queue);
    }
    
    public function clear(): void
    {
        $this->queue = [];
    }
    
    protected function process(): void
    {
        $this->processing = true;
        
        while (!empty($this->queue)) {
            $item = $this->queue[0];
            
            $age = microtime(true) - $item['timestamp'];
            
            // Skip old events (> 5 seconds)
            if ($age > 5) {
                array_shift($this->queue);
                continue;
            }
            
            // Process event
            $this->dispatch($item['event'], $item['payload']);
            array_shift($this->queue);
        }
        
        $this->processing = false;
    }
    
    protected function dispatch(string $event, array $payload): void
    {
        // Dispatch to Livewire
    }
}
```

## Event Replay

### Event Recorder

```php
<?php

namespace GsmUi\Events;

class EventRecorder
{
    protected array $recordings = [];
    protected bool $recording = false;
    
    public function start(): void
    {
        $this->recording = true;
        $this->recordings = [];
    }
    
    public function stop(): void
    {
        $this->recording = false;
    }
    
    public function record(string $event, array $payload): void
    {
        if (!$this->recording) {
            return;
        }
        
        $this->recordings[] = [
            'event' => $event,
            'payload' => $payload,
            'timestamp' => microtime(true),
        ];
    }
    
    public function getRecordings(): array
    {
        return $this->recordings;
    }
    
    public function export(): string
    {
        return json_encode($this->recordings, JSON_PRETTY_PRINT);
    }
    
    public function import(string $json): void
    {
        $this->recordings = json_decode($json, true) ?? [];
    }
    
    public function replay(callable $replayCallback): void
    {
        $startTime = $this->recordings[0]['timestamp'] ?? 0;
        
        foreach ($this->recordings as $recording) {
            $delay = ($recording['timestamp'] - $startTime) * 1000;
            
            timer($delay / 1000, function () use ($recording, $replayCallback) {
                $replayCallback($recording['event'], $recording['payload']);
            });
        }
    }
}
```

### Event Tracker

```php
<?php

namespace GsmUi\Events;

class EventTracker
{
    protected array $events = [];
    protected array $metrics = [];
    
    public function track(string $event, array $payload = []): void
    {
        $this->events[] = [
            'event' => $event,
            'payload' => $payload,
            'timestamp' => microtime(true),
        ];
        
        $this->updateMetrics($event);
    }
    
    protected function updateMetrics(string $event): void
    {
        if (!isset($this->metrics[$event])) {
            $this->metrics[$event] = [
                'count' => 0,
                'first_seen' => microtime(true),
                'last_seen' => microtime(true),
            ];
        }
        
        $this->metrics[$event]['count']++;
        $this->metrics[$event]['last_seen'] = microtime(true);
    }
    
    public function getMetrics(): array
    {
        return $this->metrics;
    }
    
    public function getEventCount(string $event): int
    {
        return $this->metrics[$event]['count'] ?? 0;
    }
    
    public function getEventsSince(float $timestamp): array
    {
        return array_filter($this->events, function ($event) use ($timestamp) {
            return $event['timestamp'] >= $timestamp;
        });
    }
    
    public function clear(): void
    {
        $this->events = [];
        $this->metrics = [];
    }
    
    public function export(): array
    {
        return [
            'events' => $this->events,
            'metrics' => $this->metrics,
        ];
    }
}
```

```javascript
    }
    
    setupListener() {
        document.addEventListener('gsmui:*', (e) => {
            this.track(e.type, {
                detail: e.detail,
                target: e.target.tagName,
                timestamp: Date.now(),
            });
        });
    }
    
    track(event, data) {
        this.events.push({ event, data });
        this.updateMetrics(event);
    }
    
    updateMetrics(event) {
        if (!this.metrics[event]) {
            this.metrics[event] = {
                count: 0,
                firstSeen: Date.now(),
                lastSeen: Date.now(),
                targets: new Set(),
            };
        }
        
        const metric = this.metrics[event];
        metric.count++;
        metric.lastSeen = Date.now();
    }
    
    getTopEvents(limit = 10) {
        return Object.entries(this.metrics)
            .sort(([, a], [, b]) => b.count - a.count)
            .slice(0, limit)
            .map(([event, metric]) => ({
                event,
                count: metric.count,
                firstSeen: metric.firstSeen,
                lastSeen: metric.lastSeen,
            }));
    }
    
    getEventsPerMinute() {
        const now = Date.now();
        const oneMinuteAgo = now - 60000;
        
        return this.events.filter(e => e.data.timestamp > oneMinuteAgo).length;
    }
    
    clear() {
        this.events = [];
        this.metrics = {};
    }
}
```

## Event System Best Practices

### Event Usage Guidelines

#### Do's and Don'ts

#### Do

1. **Use semantic event names** — `change`, `select`, `submit`
2. **Include relevant detail** — Provide context in event payload
3. **Bubble events** — Allow parent components to listen
4. **Document events** — Add to component documentation
5. **Test event emission** — Verify events fire correctly

#### Don't

1. **Don't use generic names** — Avoid `update`, `change` without context
2. **Don't include sensitive data** — Never put secrets in event detail
3. **Don't forget cleanup** — Remove event listeners when done
4. **Don't block the main thread** — Keep event handlers fast
5. **Don't assume event order** — Events may fire in any order

### Event Naming Conventions

| Pattern | Example | Use Case |
|---------|---------|----------|
| `{noun}` | `click`, `submit` | Native events |
| `{noun}-change` | `value-change`, `open-change` | State changes |
| `{verb}` | `select`, `deselect` | Actions |
| `update:modelValue` | `update:modelValue` | Vue-compatible |
| `wire:model` | `wire:model` | Livewire binding |

```javascript
// Debounce rapid events
function debounce(fn, delay) {
    let timeoutId;
    return function (...args) {
        clearTimeout(timeoutId);
        timeoutId = setTimeout(() => fn.apply(this, args), delay);
```

```javascript
// Throttle rapid events
function throttle(fn, limit) {
```

### Event Dispatcher

```php
<?php

namespace GsmUi\Events;

class EventDispatcher
{
    protected array $listeners = [];
    protected array $wildcardListeners = [];
    protected array $events = [];
    
    public function listen(string $event, callable $listener): void
    {
        if ($event === '*') {
            $this->wildcardListeners[] = $listener;
        } else {
            $this->listeners[$event][] = $listener;
        }
    }
    
    public function dispatch(string $event, array $payload = []): void
    {
        $this->events[] = [
            'name' => $event,
            'payload' => $payload,
            'timestamp' => microtime(true),
        ];
        
        // Notify specific listeners
        foreach ($this->listeners[$event] ?? [] as $listener) {
            $listener(...array_values($payload));
        }
        
        // Notify wildcard listeners
        foreach ($this->wildcardListeners as $listener) {
            $listener($event, $payload);
        }
    }
    
    public function forget(string $event): void
    {
        unset($this->listeners[$event]);
    }
    
    public function forgetAll(): void
    {
        $this->listeners = [];
        $this->wildcardListeners = [];
    }
    
    public function getListeners(string $event): array
    {
        return $this->listeners[$event] ?? [];
    }
    
    public function hasListeners(string $event): bool
    {
        return !empty($this->listeners[$event]);
    }
    
    public function getEvents(): array
    {
        return $this->events;
    }
}
```

### Event Bus

```javascript
class EventBus {
    constructor() {
        this.listeners = new Map();
        this.wildcardListeners = [];
        this.history = [];
        this.maxHistory = 100;
    }
    
    on(event, callback) {
        if (!this.listeners.has(event)) {
            this.listeners.set(event, []);
        }
        this.listeners.get(event).push(callback);
        
        return () => this.off(event, callback);
    }
    
    off(event, callback) {
        const listeners = this.listeners.get(event) || [];
        this.listeners.set(
            event,
            listeners.filter(cb => cb !== callback)
        );
    }
    
    emit(event, data = {}) {
        const payload = {
            event,
            data,
            timestamp: Date.now(),
        };
        
        // Record history
        this.history.push(payload);
        if (this.history.length > this.maxHistory) {
            this.history.shift();
        }
        
        // Notify specific listeners
        const listeners = this.listeners.get(event) || [];
        listeners.forEach(callback => {
            try {
                callback(data);
            } catch (error) {
                console.error(`Error in event listener for "${event}":`, error);
            }
        });
        
        // Notify wildcard listeners
        this.wildcardListeners.forEach(callback => {
            try {
                callback(event, data);
            } catch (error) {
                console.error('Error in wildcard event listener:', error);
            }
        });
    }
    
    once(event, callback) {
        const wrapper = (data) => {
            callback(data);
            this.off(event, wrapper);
        };
        return this.on(event, wrapper);
    }
    
    onAny(callback) {
        this.wildcardListeners.push(callback);
        
        return () => {
            this.wildcardListeners = this.wildcardListeners.filter(cb => cb !== callback);
        };
    }
    
    getHistory(event = null) {
        if (event) {
            return this.history.filter(h => h.event === event);
        }
        return this.history;
    }
    
    clearHistory() {
        this.history = [];
    }
    
    removeAllListeners() {
        this.listeners.clear();
        this.wildcardListeners = [];
    }
}
```

### Event Middleware

```javascript
class EventMiddleware {
    constructor() {
        this.middlewares = new Map();
    }
    
    use(event, middleware) {
        if (!this.middlewares.has(event)) {
            this.middlewares.set(event, []);
        }
        this.middlewares.get(event).push(middleware);
    }
    
    async process(event, data, next) {
        const middlewares = this.middlewares.get(event) || [];
        const globalMiddlewares = this.middlewares.get('*') || [];
        
        const allMiddlewares = [...globalMiddlewares, ...middlewares];
        
        let index = 0;
        
        const execute = async () => {
            if (index >= allMiddlewares.length) {
                return next(data);
            }
            
            const middleware = allMiddlewares[index++];
            return middleware(data, execute);
        };
        
        return execute();
    }
    
    remove(event, middleware) {
        const middlewares = this.middlewares.get(event) || [];
        this.middlewares.set(
            event,
            middlewares.filter(m => m !== middleware)
        );
    }
    
    clear() {
        this.middlewares.clear();
    }
}
```

### Event Validation

```javascript
class EventValidator {
    constructor() {
        this.schemas = new Map();
    }
    
    register(event, schema) {
        this.schemas.set(event, schema);
    }
    
    validate(event, data) {
        const schema = this.schemas.get(event);
        
        if (!schema) {
            return { valid: true, errors: [] };
        }
        
        const errors = [];
        
        // Check required fields
        if (schema.required) {
            for (const field of schema.required) {
                if (!(field in data)) {
                    errors.push(`Missing required field: ${field}`);
                }
            }
        }
        
        // Check types
        if (schema.properties) {
            for (const [field, rules] of Object.entries(schema.properties)) {
                if (field in data) {
                    if (rules.type && typeof data[field] !== rules.type) {
                        errors.push(`Invalid type for ${field}: expected ${rules.type}`);
                    }
                    
                    if (rules.enum && !rules.enum.includes(data[field])) {
                        errors.push(`Invalid value for ${field}: must be one of ${rules.enum.join(', ')}`);
                    }
                    
                    if (rules.min !== undefined && data[field] < rules.min) {
                        errors.push(`Value for ${field} must be at least ${rules.min}`);
                    }
                    
                    if (rules.max !== undefined && data[field] > rules.max) {
                        errors.push(`Value for ${field} must be at most ${rules.max}`);
                    }
                }
            }
        }
        
        return {
            valid: errors.length === 0,
            errors,
        };
    }
    
    clear() {
        this.schemas.clear();
    }
}
```

# 13.06 Slots System — GsmUi Slots Specification

## Overview

The GsmUi slots system provides a consistent, flexible way to compose component content. It extends Laravel's native Blade slots with GsmUi-specific conventions for accessibility, theming, and component composition.

## Slot Types

### 1. Default Slot (Main Content)

```blade
<x-gsmui:card>
    This is the default slot content
</x-gsmui:card>
```

In component:
```blade
<div class="card">
    {{ $slot ?? '' }}
</div>
```

### 2. Named Slots

```blade
<x-gsmui:card>
    <x-slot name="header">
        <h2>Card Title</h2>
    </x-slot>
    
    <x-slot name="footer">
        <x-gsmui:button>Action</x-gsmui:button>
    </x-slot>
    
    Main content here
</x-gsmui:card>
```

### 3. Scoped Slots (Data Passing)

```blade
<x-gsmui:table :rows="$users">
    <x-slot name="row" :row="$row">
        <td>{{ $row->name }}</td>
        <td>{{ $row->email }}</td>
    </x-slot>
</x-gsmui:table>
```

In component:
```blade
@foreach($rows as $row)
    <tr>
        {{ $slot->render('row', ['row' => $row]) }}
    </tr>
@endforeach
```

### 4. Slot Components (Anonymous Components)

```blade
<x-gsmui:select>
    <x-gsmui:select.trigger>
        Select an option
    </x-gsmui:select.trigger>
    
    <x-gsmui:select.content>
        <x-gsmui:select.option value="1">Option 1</x-gsmui:select.option>
        <x-gsmui:select.option value="2">Option 2</x-gsmui:select.option>
    </x-gsmui:select.content>
</x-gsmui:select>
```

## Standard Slot Names

| Slot | Purpose | Components |
|------|---------|------------|
| `default` | Main content | All |
| `label` | Accessible label | Form inputs, Field |
| `description` | Help text | Form inputs, Field |
| `icon` | Leading/trailing icon | Button, Input, Select |
| `prefix` | Prefix content | Input, Textarea |
| `suffix` | Suffix content | Input, Textarea |
| `actions` | Action buttons | Select, DatePicker, ComboBox |
| `trigger` | Trigger element | Popover, Dropdown, Tooltip |
| `content` | Popover/content panel | Popover, Dropdown, Modal |
| `header` | Header section | Card, Modal, Drawer, Panel |
| `footer` | Footer section | Card, Modal, Drawer, Panel |
| `before` | Before main content | List, Table |
| `after` | After main content | List, Table |
| `empty` | Empty state | Table, Select, List |
| `loading` | Loading state | Table, List, DataDisplay |
| `error` | Error state | Form, Input |

## Slot Attributes

### Slot Props

```blade
<x-gsmui:select>
    <x-slot name="option" :option="$option" :selected="$selected">
        {{ $option->label }}
    </x-slot>
</x-gsmui:select>
```

In component template:
```blade
@foreach($options as $option)
    <x-gsmui:select.option 
        :value="$option->value"
        :selected="$option->value === $selected"
    >
        {{ $slot->render('option', ['option' => $option, 'selected' => $option->value === $selected]) }}
    </x-gsmui:select.option>
@endforeach
```

### Slot Fallbacks

```blade
{{-- In component --}}
<div class="content">
    {{ $slot->render('custom', ['item' => $item]) ?? $item->name }}
</div>
```

## Required vs Optional Slots

```php
class Component extends BaseComponent
{
    // Define required slots
    protected array $requiredSlots = ['trigger', 'content'];
    
    // Define optional slots with defaults
    protected array $optionalSlots = [
        'header' => null,
        'footer' => null,
        'empty' => 'No results found',
    ];
    
    public function mount(): void
    {
        $this->validateSlots();
    }
    
    protected function validateSlots(): void
    {
        foreach ($this->requiredSlots as $slot) {
            if (!$this->hasSlot($slot)) {
                throw new RequiredSlotMissingException(
                    "Slot '{$slot}' is required for {$this->componentName}"
                );
            }
        }
    }
}
```

## Slot Composition Patterns

### 1. Compound Components (Parent + Children)

```blade
<!-- Parent: resources/views/components/forms/select/index.blade.php -->
<x-gsmui:select.trigger {{ $triggerAttributes }}>
    {{ $slot->render('trigger') ?? $placeholder }}
</x-gsmui:select.trigger>

<x-gsmui:select.content {{ $contentAttributes }}>
    {{ $slot->render('content') }}
</x-gsmui:select.content>
```

```blade
<!-- Child: resources/views/components/forms/select/Trigger.blade.php -->
@props(['value', 'placeholder', 'open', 'disabled', 'attributes'])

<button 
    {{ $attributes->merge([
        'type' => 'button',
        'aria-haspopup' => 'listbox',
        'aria-expanded' => $open ? 'true' : 'false',
        'aria-controls' => $contentId,
    ]) }}
    class="select-trigger"
>
    {{ $slot ?? $placeholder }}
    <x-gsmui:icon :name="$open ? 'chevron-up' : 'chevron-down'" class="w-4 h-4 ml-2" />
</button>
```

### 2. Slot Injection via Parent

```blade
<!-- Parent component -->
<x-gsmui:dropdown>
    <x-slot name="trigger">
        <x-gsmui:button variant="outline">Open Menu</x-gsmui:button>
    </x-slot>
    
    <x-slot name="content">
        <x-gsmui:menu>
            <x-gsmui:menu.item>Item 1</x-gsmui:menu.item>
            <x-gsmui:menu.item>Item 2</x-gsmui:menu.item>
        </x-gsmui:menu>
    </x-slot>
</x-gsmui:dropdown>
```

### 3. Dynamic Slots

```blade
<x-gsmui:tabs :tabs="$tabs">
    @foreach($tabs as $tab)
        <x-slot:name="tab-{{ $tab->id }}">
            {{ $tab->content }}
        </x-slot>
    @endforeach
</x-gsmui:tabs>
```

## Accessibility & Slots

### Label Slot Pattern

```blade
<x-gsmui:input>
    <x-slot name="label">
        <label for="{{ $id }}">Email Address</label>
    </x-slot>
    
    <x-slot name="description">
        We'll never share your email.
    </x-slot>
</x-gsmui:input>
```

Component template:
```blade
<div class="field">
    {{-- Label --}}
    @if($hasLabelSlot || $label)
        <label 
            for="{{ $id }}" 
            class="block text-sm font-medium text-zinc-700 dark:text-zinc-300"
        >
            {{ $slot->render('label') ?? $label }}
            @if($required)
                <span class="text-red-500 ml-1" aria-hidden="true">*</span>
            @endif
        </label>
    @endif
    
    {{-- Input --}}
    <input 
        id="{{ $id }}"
        aria-describedby="{{ $hasDescriptionSlot ? $id . '-description' : '' }}"
        {{ $attributes->merge(['class' => 'input-classes']) }}
    />
    
    {{-- Description --}}
    @if($hasDescriptionSlot || $description)
        <p id="{{ $id }}-description" class="mt-1 text-sm text-zinc-500 dark:text-zinc-400">
            {{ $slot->render('description') ?? $description }}
        </p>
    @endif
    
    {{-- Error --}}
    @if($invalid)
        <p id="{{ $id }}-error" class="mt-1 text-sm text-red-600 dark:text-red-400" role="alert">
            {{ $errorMessage }}
        </p>
    @endif
</div>
```

## Slot Utilities

### Gsmui::slot() Helper

```php
// In component class
public function renderSlot(string $name, array $data = [], string $fallback = ''): string
{
    if ($this->hasSlot($name)) {
        return $this->slot($name)->render($data);
    }
    return $fallback;
}

// Usage in template
{{ $this->renderSlot('icon', ['open' => $this->open], '<default-icon />') }}
```

### Slot Merging

```blade
{{-- Merge multiple slots --}}
<div class="actions">
    {{ $slot->render('actions-start') }}
    {{ $slot->render('actions') }}
    {{ $slot->render('actions-end') }}
</div>
```

## Slot Deep Dive

### Default Slot

The default slot is the main content area of a component.

```blade
<x-gsmui:card>
    This is the default slot content.
</x-gsmui:card>
```

**Rendering:**

```blade
<div class="card">
    {{ $slot }}
</div>
```

**With fallback:**

```blade
<div class="card">
    {{ $slot ?? 'No content provided' }}
</div>
```

### Named Slots

Named slots allow inserting content into specific locations.

```blade
<x-gsmui:card>
    <x-slot name="header">
        <h2>Card Title</h2>
    </x-slot>
    
    Main content here
    
    <x-slot name="footer">
        <x-gsmui:button>Action</x-gsmui:button>
    </x-slot>
</x-gsmui:card>
```

**Rendering:**

```blade
<div class="card">
    @if(isset($header))
        <div class="card-header">
            {{ $header }}
        </div>
    @endif
    
    <div class="card-body">
        {{ $slot }}
    </div>
    
    @if(isset($footer))
        <div class="card-footer">
            {{ $footer }}
        </div>
    @endif
</div>
```

### Scoped Slots

Scoped slots pass data back to the parent for rendering.

```blade
<x-gsmui:list :items="$users">
    <x-slot name="item" :item="$item" :index="$index">
        <div class="flex items-center gap-3">
            <x-gsmui:avatar :src="$item->avatar" />
            <span>{{ $item->name }}</span>
        </div>
    </x-slot>
</x-gsmui:list>
```

**Rendering:**

```blade
<ul class="list">
    @foreach($items as $index => $item)
        <li>
            {{ $slot->render('item', ['item' => $item, 'index' => $index]) }}
        </li>
    @endforeach
</ul>
```

### Slot Components

Complex components use sub-components as slots.

```blade
<x-gsmui:select>
    <x-gsmui:select.trigger>
        <x-gsmui:select.value :value="$selected" />
    </x-gsmui:select.trigger>
    
    <x-gsmui:select.content>
        <x-gsmui:select.search />
        <x-gsmui:select.list>
            @foreach($options as $option)
                <x-gsmui:select.option :value="$option->value">
                    {{ $option->label }}
                </x-gsmui:select.option>
            @endforeach
        </x-gsmui:select.list>
    </x-gsmui:select.content>
</x-gsmui:select>
```

## Slot Patterns Deep Dive

### Pattern 1: Layout Slots

For structural content like headers, footers, sidebars.

```blade

    <x-slot name="trigger">
        <x-gsmui:button>Open Modal</x-gsmui:button>
    </x-slot>
    
    <x-slot name="header">
        <h2>Modal Title</h2>
        <x-gsmui:button icon="x" @click="close" />
    </x-slot>
    
    <x-slot name="default">
        <p>Modal content</p>
    </x-slot>
    
    <x-slot name="footer">
        <x-gsmui:button variant="ghost">Cancel</x-gsmui:button>
        <x-gsmui:button variant="primary">Save</x-gsmui:button>
    </x-slot>
</x-gsmui:modal>
```

### Pattern 2: Item Slots

For rendering lists of items.

```blade
<x-gsmui:table :rows="$users">
    <x-slot name="header">
        <tr>
            <x-gsmui:table.th>Name</x-gsmui:table.th>
            <x-gsmui:table.th>Email</x-gsmui:table.th>
            <x-gsmui:table.th>Actions</x-gsmui:table.th>

    </x-slot>
    
    <x-slot name="row" :row="$user">
        <x-gsmui:table.td>{{ $user->name }}</x-gsmui:table.td>
        <x-gsmui:table.td>{{ $user->email }}</x-gsmui:table.td>

        </x-gsmui:table.td>
    </x-slot>

```

### Pattern 3: Empty/Loading/Error Slots

For state-specific content.

```blade
<x-gsmui:list :items="$items">
    <x-slot name="empty">
        <div class="text-center py-12">
            <x-gsmui:icon name="inbox" class="w-12 h-12 mx-auto text-zinc-400" />
            <p class="mt-4 text-zinc-500">No items found</p>
        </div>
    </x-slot>
    
    <x-slot name="loading">
        <div class="space-y-4">
            @for($i = 0; $i < 5; $i++)
                <x-gsmui:skeleton class="h-12" />
            @endfor
        </div>
    </x-slot>
    
    <x-slot name="error">
        <div class="text-center py-12">
            <x-gsmui:icon name="alert-circle" class="w-12 h-12 mx-auto text-red-500" />
            <p class="mt-4 text-red-600">Failed to load items</p>
            <x-gsmui:button class="mt-4">Retry</x-gsmui:button>
        </div>
    </x-slot>
    
    <x-slot name="item" :item="$item">
        {{ $item->name }}
    </x-slot>
</x-gsmui:list>
```

### Pattern 4: Action Slots

For action buttons and menus.

```blade
<x-gsmui:card>
    <x-slot name="header">
        <div class="flex items-center justify-between">
            <h2>Card Title</h2>
            <x-gsmui:dropdown>
                <x-slot name="trigger">
                    <x-gsmui:button icon="dots-vertical" />
                </x-slot>
                <x-slot name="content">
                    <x-gsmui:menu>

```

### Pattern 5: Prefix/Suffix Slots

For input decorations.

```blade
<x-gsmui:input wire:model="email">
    <x-slot name="prefix">
        <x-gsmui:icon name="mail" class="w-4 h-4 text-zinc-400" />
    </x-slot>
    <x-slot name="suffix">
        @if($email)
            <x-gsmui:button icon="check" size="xs" color="success" />
        @endif
    </x-slot>
    <x-slot name="label">Email Address</x-slot>
    <x-slot name="description">We'll never share your email.</x-slot>
</x-gsmui:input>
```

### Rendering with Data

```blade
{{-- Pass data to slot --}}

@foreach($items as $index => $item)
```

```blade
{{-- Check if slot is provided --}}
@if(isset($header))
    <div class="header">{{ $header }}</div>

{{-- Check with slot helper --}}

    <div class="header">{{ $slot->render('header') }}</div>
@endif
```


## Slot Performance

### Lazy Slot Rendering

For expensive slot content, use lazy rendering:

```blade
@if(isset($expensiveSlot) && $shouldRender)
    {{ $expensiveSlot }}
@endif
```

### Slot Caching

```php
trait CachesSlots
{
    protected array $slotCache = [];
    
    public function renderSlot(string $name, array $data = []): string
    {
        $cacheKey = md5($name . json_encode($data));
        
        if (isset($this->slotCache[$cacheKey])) {
            return $this->slotCache[$cacheKey];
        }
        
        $rendered = $this->slot($name)->render($data);
        $this->slotCache[$cacheKey] = $rendered;
        
        return $rendered;
    }
}
```

## Slot Performance Optimization

### Slot Caching

```php
trait CachesSlots
{
    protected array $slotCache = [];
    
    public function cachedSlot(string $name, array $data = []): string
    {
        $key = md5($name . json_encode($data));
        
        if (!isset($this->slotCache[$key])) {
            $this->slotCache[$key] = $this->slot($name)->render($data);
        }
        
        return $this->slotCache[$key];
    }
}
```

# 13.08 Size System — GsmUi Size Specification

## Overview

The GsmUi size system provides a consistent, scalable sizing framework for all components. Sizes are defined as design tokens and map to CSS custom properties for themeability.

## Size Scale

## Standard Size Enum

```php
<?php

namespace GsmUi\Enums;

enum Size: string
{
    case Xs = 'xs';
    case Sm = 'sm';
    case Md = 'md';
    case Lg = 'lg';
    case Xl = 'xl';
    
    public function height(): string
    {
        return match ($this) {
            self::Xs => 'var(--gsmui-size-xs)',
            self::Sm => 'var(--gsmui-size-sm)',
            self::Md => 'var(--gsmui-size-md)',
            self::Lg => 'var(--gsmui-size-lg)',
            self::Xl => 'var(--gsmui-size-xl)',
        };
    }
    
    public function paddingX(): string
    {
        return match ($this) {
            self::Xs => 'var(--gsmui-space-2)',  /* 8px */
            self::Sm => 'var(--gsmui-space-3)',  /* 12px */
            self::Md => 'var(--gsmui-space-4)',  /* 16px */
            self::Lg => 'var(--gsmui-space-5)',  /* 20px */
            self::Xl => 'var(--gsmui-space-6)',  /* 24px */
        };
    }
    
    public function paddingY(): string
    {
        return match ($this) {
            self::Xs => 'var(--gsmui-space-1)',  /* 4px */
            self::Sm => 'var(--gsmui-space-1)',  /* 4px */
            self::Md => 'var(--gsmui-space-2)',  /* 8px */
            self::Lg => 'var(--gsmui-space-2)',  /* 8px */
            self::Xl => 'var(--gsmui-space-3)',  /* 12px */
        };

    public function fontSize(): string
    {
        return match ($this) {
            self::Xs => 'var(--gsmui-text-xs)',
            self::Sm => 'var(--gsmui-text-sm)',
            self::Md => 'var(--gsmui-text-sm)',
            self::Lg => 'var(--gsmui-text-base)',
            self::Xl => 'var(--gsmui-text-lg)',

        return match ($this) {
            self::Xs => 'var(--gsmui-radius-md)',

            self::Xl => 'var(--gsmui-space-6)',  /* 24px */

    {
        return match ($this) {
            self::Xs => 'var(--gsmui-space-1)',

            self::Md => 'var(--gsmui-space-2)',
            self::Lg => 'var(--gsmui-space-2)',
            self::Xl => 'var(--gsmui-space-3)',
        };
    }
}
```

## Size Prop in Components

```php
#[Prop(
    type: 'string',
    default: 'md',
    options: ['xs', 'sm', 'md', 'lg', 'xl'],
    description: 'Component size'
)]
public string $size = 'md';

public function sizeClasses(): string
{
    $size = Size::tryFrom($this->size) ?? Size::Md;
    
    return "h-[{$size->height()}] px-[{$size->paddingX()}] py-[{$size->paddingY()}] 
            text-[{$size->fontSize()}] rounded-[{$size->borderRadius()}] 
            gap-[{$size->gap()}]";
}
```

## Responsive Sizes

Components accept responsive size arrays:

```blade
<!-- Single size -->
<x-gsmui:button size="lg" />

<!-- Responsive -->
<x-gsmui:button :size="['sm', 'md:lg', 'xl:xl']" />
```

```php
trait ResolvesResponsiveSize
{
    public function resolveSize(): Size
    {
        $size = $this->size;
        
        if (is_array($size)) {
            $breakpoint = $this->getCurrentBreakpoint(); // sm, md, lg, xl, 2xl
            $resolved = $size[0] ?? 'md';
            
            foreach ($size as $item) {
                if (str_starts_with($item, "{$breakpoint}:")) {
                    $resolved = substr($item, strlen($breakpoint) + 1);
                    break;
                }
                if (!str_contains($item, ':')) {
                    $resolved = $item;
                }
            }
            
            $size = $resolved;
        }
        
        return Size::tryFrom($size) ?? Size::Md;
    }
}
```

## Size Deep Dive

### Size Resolution

Sizes are resolved in this order:

1. **Explicit size prop** — Highest priority
2. **Responsive array** — Breakpoint-based
3. **Global config** — Application defaults
4. **Theme token** — CSS variable
5. **Component default** — Lowest priority

```php
trait ResolvesSize
{
    protected function resolveSize(): Size
    {
        $size = $this->size;
        
        // Handle responsive array
        if (is_array($size)) {
            $size = $this->resolveResponsiveSize($size);
        }
        
        // 1. Explicit prop (already resolved)
        // 2. Global config
        if (!isset($size)) {
            $configKey = "gsmui.defaults.{$this->componentName}.size";
            if (config()->has($configKey)) {
                $size = config($configKey);
            }
        }
        
        // 3. Theme token
        if (!isset($size)) {
            $token = "--gsmui-{$this->componentName}-size";
            if ($this->theme && $this->theme->hasToken($token)) {
                $size = $this->theme->getToken($token);
            }
        }
        
        // 4. Component default
        return Size::tryFrom($size ?? 'md') ?? Size::Md;
    }
    
    protected function resolveResponsiveSize(array $sizes): string
    {
        $breakpoint = $this->getCurrentBreakpoint();
        $resolved = $sizes[0] ?? 'md';
        
        foreach ($sizes as $item) {
            if (str_starts_with($item, "{$breakpoint}:")) {
                $resolved = substr($item, strlen($breakpoint) + 1);
                break;
            }
            if (!str_contains($item, ':')) {
                $resolved = $item;
            }
        }
        
        return $resolved;
    }
}
```

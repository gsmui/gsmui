# 13.23 Deprecation Policy — GsmUi Deprecation Specification

## Overview

This document defines the formal deprecation policy for GsmUi components, props, slots, events, CSS tokens, and APIs. The goal is to provide clear migration paths while maintaining ecosystem stability.

## Deprecation Lifecycle

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  Stable     │───►│  Deprecated │───►│  Legacy     │───►│  Removed    │
│  (Current)  │    │  (Warning)  │    │  (Supported)│    │  (Next Major)│
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
     │                   │                   │                   │
     ▼                   ▼                   ▼                   ▼
  Feature           Announce in        Supported with     Delete code,
  works             minor release      warnings only      docs, tests
```

### Timeline

| Phase | Duration | Trigger | Actions |
|-------|----------|---------|---------|
| **Stable** | Indefinite | Release | Normal development |
| **Deprecated** | ≥ 1 minor cycle | Decision | Add warnings, docs, codemod |
| **Legacy** | Until next major | Next minor | Maintain, no new features |
| **Removed** | Next major | Major release | Delete entirely |

## Deprecation Categories

### 1. Component Deprecation

```yaml
# component.yaml
name: legacy-card
version: 1.2.0
status: deprecated
deprecation:
  since: "1.3.0"
  reason: "Replaced by Card component with variant system"
  replacement: "card"
  removalVersion: "2.0.0"
```

**Implementation:**

```php
class LegacyCard extends BaseComponent
{
    public function mount(): void
    {
        trigger_deprecation(
            'gsmui/gsmui-pro',
            '1.3.0',
            'The "legacy-card" component is deprecated. Use "card" component instead.',
            'https://gsmui.dev/docs/migration/legacy-card'
        );
        
        parent::mount();
    }
}
```

### 2. Prop Deprecation

```php
/**
 * @deprecated Since v1.5.0. Use `style` instead. Will be removed in v2.0.0.
 */
#[Prop(default: 'primary')]
public string $variant = 'primary';

public function updatedVariant($value): void
{
    $this->emitDeprecationWarning('variant', 'style');
    $this->style = $value;
}

protected function emitDeprecationWarning(string $oldProp, string $newProp): void
{
    if (app()->environment('local', 'testing')) {
        trigger_deprecation(
            'gsmui/gsmui-pro',
            '1.5.0',
            sprintf(
                'Prop "%s" is deprecated. Use "%s" instead. See migration guide: https://gsmui.dev/docs/migration/props#%s',
                $oldProp, $newProp, $oldProp
            )
        );
    }
}
```

### 3. Slot Deprecation

```php
public function getSlotContent(string $name): ?string
{
    $deprecatedSlots = [
        'left-icon' => 'icon (with iconPosition="left")',
        'right-icon' => 'icon (with iconPosition="right")',
    ];
    
    if (isset($deprecatedSlots[$name])) {
        $this->emitDeprecationWarning("slot '$name'", $deprecatedSlots[$name]);
    }
    
    return parent::getSlotContent($name);
}
```

### 4. Event Deprecation

```php
protected function dispatchEvent(string $event, array $payload = []): void
{
    $deprecatedEvents = [
        'select' => 'change',
        'open' => 'open-change',
        'close' => 'open-change',
    ];
    
    if (isset($deprecatedEvents[$event])) {
        $this->emitDeprecationWarning("event '$event'", $deprecatedEvents[$event]);
    }
    
    parent::dispatchEvent($event, $payload);
}
```

### 5. CSS Token Deprecation

```css
/* Deprecated token - will be removed in v2.0 */
@deprecated "Use --gsmui-btn-bg-primary instead";
--gsmui-btn-primary-bg: var(--gsmui-color-primary);

/* Replacement */
--gsmui-btn-bg-primary: var(--gsmui-color-primary);
```

```php
// Theme compiler adds deprecation comments
class ThemeCompiler
{
    protected array $deprecatedTokens = [
        '--gsmui-btn-primary-bg' => '--gsmui-btn-bg-primary',
        '--gsmui-input-border-color' => '--gsmui-input-border',
    ];
    
    public function compile(array $theme): string
    {
        $css = parent::compile($theme);
        
        foreach ($this->deprecatedTokens as $old => $new) {
            $css = str_replace(
                $old . ':',
                "@deprecated \"Use $new instead\";\n$old:",
                $css
            );
        }
        
        return $css;
    }
}
```

### 6. PHP Method Deprecation

```php
/**
 * @deprecated Since v1.4.0. Use the $value property directly.
 */
public function getValue(): mixed
{
    trigger_deprecation(
        'gsmui/gsmui-pro',
        '1.4.0',
        'Method getValue() is deprecated. Use the $value property directly.'
    );
    
    return $this->value;
}
```

### Browser Console Warnings

```javascript
// gsmui-deprecation.js
class DeprecationTracker {
    constructor() {
        this.warned = new Set();
    }
    
    warn(component, feature, replacement, url) {
        const key = `${component}:${feature}`;
        if (this.warned.has(key)) return;
        this.warned.add(key);
        
        console.warn(
            `%c[GsmUi Deprecation]%c ${component}: "${feature}" is deprecated. ` +
            `Use "${replacement}" instead.\n%c${url}`,
            'color: #f59e0b; font-weight: bold;',
            'color: inherit;',
            'color: #6b7280; font-size: 0.875rem;'
        );
    }
}

window.GsmuiDeprecation = new DeprecationTracker();

// Usage in component
if (process.env.NODE_ENV !== 'production') {
    window.GsmuiDeprecation.warn('Button', 'variant prop', 'style prop', 'https://gsmui.dev/docs/migration/button');
}

## Select: Event Renames

| Old Event | New Event | Payload Change |
|-----------|-----------|----------------|
| `select` | `change` | Standardized to `{value, previousValue}` |
| `open` | `open-change` | `{open: true}` → `{open: true}` |
| `close` | `open-change` | `{open: false}` → `{open: false}` |

### Update Listeners

```php
// Before
#[On('select:select')]
public function handleSelect($value) { }

// After
#[On('select:change')]
public function handleChange($value, $previousValue) { }
```

## Deprecation Lifecycle in Detail

### Phase 1: Stable (Active Development)

During the stable phase, a feature is actively developed and maintained. Bug fixes are applied as patch releases, and new capabilities are added as minor releases. No deprecation warnings are emitted, and the feature is considered production-ready.

**Characteristics:**
- Full test coverage maintained
- Documentation kept up to date
- Performance optimizations applied
- Security patches delivered promptly
- Community feedback incorporated

**Duration:** Indefinite until deprecation decision is made.

### Phase 2: Deprecated (Warning Period)

When a feature is marked as deprecated, it enters a warning period where:
- Deprecation warnings are emitted in development environments
- Documentation is updated to indicate the deprecation
- An automated codemod is provided where possible
- The feature continues to work identically to the stable phase
- No new features or improvements are added

**Characteristics:**
- Deprecation warning in `trigger_deprecation()` or `@deprecated` PHPDoc
- Migration guide published in documentation
- Codemod tool available for automated migration
- Feature flagged for monitoring usage decline
- Changelog entry documents the deprecation

**Duration:** Minimum one minor release cycle (typically 1-3 months).

### Phase 3: Legacy (Supported with Warnings)

After the deprecation period, the feature enters legacy status:
- The feature still works but is frozen
- Deprecation warnings are emitted in all environments
- No bug fixes unless critical security issues
- Documentation is marked as legacy
- Community support is limited

**Characteristics:**
- Code is marked with `@legacy` annotations
- Warning messages include removal timeline
- Performance may degrade slightly as optimizations focus elsewhere
- Security patches still applied for critical vulnerabilities

**Duration:** Until the next major version release.

### Phase 4: Removed (Deleted)

In the next major version, deprecated features are completely removed:
- Code is deleted from the codebase
- Documentation is removed
- Tests are removed
- Migration guides remain available
- Codemods may still be available for migration

**Characteristics:**
- Zero code remnants
- Clean API surface
- No backward compatibility concerns
- Migration path fully documented

## Deprecation Decision Framework

### When to Deprecate

A feature should be deprecated when:

| Criterion | Threshold | Measurement |
|-----------|-----------|-------------|
| Usage decline | < 5% of users | Telemetry data |
| Better alternative exists | Superior API design | Architecture review |
| Security concerns | Unfixable vulnerability | Security audit |
| Performance issues | Cannot be optimized | Benchmark analysis |
| Maintenance burden | > 2x maintenance cost | Developer time tracking |
| Community consensus | > 70% approval | RFC process |

## Codemod Development Guide

### Creating a Codemod

Codemods automate the migration from deprecated APIs to their replacements. Each codemod is a PHP class that parses and transforms source code.

```php
<?php

namespace GsmUi\Codemod;

use PhpParser\Node;
use PhpParser\NodeTraverser;
use PhpParser\NodeVisitorAbstract;
use PhpParser\ParserFactory;

class ButtonVariantToStyleCodemod extends Codemod
{
    protected string $description = 'Renames the "variant" prop to "style" in Button components';

    public function transform(string $code): string
    {
        $parser = (new ParserFactory)->create(ParserFactory::PREFER_PHP7);
        $stmts = $parser->parse($code);

        $traverser = new NodeTraverser();
        $traverser->addVisitor(new class extends NodeVisitorAbstract {
            public function enterNode(Node $node): ?Node
            {
                if ($this->isBladeComponent($node, 'x-gsmui:button')) {
                    $this->renameAttribute($node, 'variant', 'style');
                }
                return $node;
            }
        });

        $stmts = $traverser->traverse($stmts);
        return $this->prettyPrint($stmts);
    }

    protected function isBladeComponent(Node $node, string $componentName): bool
    {
        // Implementation for Blade component detection
        return $node instanceof Node\Expr\FuncCall
            && $node->name instanceof Node\Name
            && $node->name->toString() === $componentName;
    }

    protected function renameAttribute(Node $node, string $oldName, string $newName): void
    {
        // Implementation for attribute renaming
        foreach ($node->args as $arg) {
            if ($arg->name && $arg->name->toString() === $oldName) {
                $arg->name = new Node\Identifier($newName);
            }
        }
    }
}
```

### Codemod Testing

```php
<?php

namespace Tests\Unit\Codemods;

use Tests\TestCase;
use GsmUi\Codemod\ButtonVariantToStyleCodemod;

class ButtonVariantToStyleCodemodTest extends TestCase
{
    private ButtonVariantToStyleCodemod $codemod;

    protected function setUp(): void
    {
        parent::setUp();
        $this->codemod = new ButtonVariantToStyleCodemod();
    }

    public function test_renames_variant_to_style(): void
    {
        $input = '<x-gsmui:button variant="primary">Save</x-gsmui:button>';
        $expected = '<x-gsmui:button style="primary">Save</x-gsmui:button>';

        $result = $this->codemod->transform($input);

        $this->assertEquals($expected, $result);
    }

    public function test_preserves_other_attributes(): void
    {
        $input = '<x-gsmui:button variant="primary" size="lg" disabled>Save</x-gsmui:button>';
        $expected = '<x-gsmui:button style="primary" size="lg" disabled>Save</x-gsmui:button>';

        $result = $this->codemod->transform($input);

        $this->assertEquals($expected, $result);
    }

    public function test_handles_multiple_buttons(): void
    {
        $input = <<<'BLADE'
        <x-gsmui:button variant="primary">Save</x-gsmui:button>
        <x-gsmui:button variant="secondary">Cancel</x-gsmui:button>
        BLADE;

        $expected = <<<'BLADE'
        <x-gsmui:button style="primary">Save</x-gsmui:button>
        <x-gsmui:button style="secondary">Cancel</x-gsmui:button>
        BLADE;

        $result = $this->codemod->transform($input);

        $this->assertEquals($expected, $result);
    }

    public function test_skips_non_button_components(): void
    {
        $input = '<x-gsmui:input variant="outline">Name</x-gsmui:input>';
        $expected = $input;

        $result = $this->codemod->transform($input);

        $this->assertEquals($expected, $result);
    }

    public function test_handles_dynamic_expressions(): void
    {
        $input = '<x-gsmui:button :variant="$type">Save</x-gsmui:button>';
        $expected = '<x-gsmui:button :style="$type">Save</x-gsmui:button>';

        $result = $this->codemod->transform($input);

        $this->assertEquals($expected, $result);
    }
}
```

## Deprecation Tracking System

### Database Schema for Deprecations

```sql
CREATE TABLE component_deprecations (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    component_name VARCHAR(100) NOT NULL,
    feature_type ENUM('component', 'prop', 'slot', 'event', 'css_token', 'method') NOT NULL,
    feature_name VARCHAR(100) NOT NULL,
    deprecated_since VARCHAR(20) NOT NULL,
    removal_version VARCHAR(20) NOT NULL,
    replacement VARCHAR(255) NULL,
    migration_guide_url VARCHAR(500) NULL,
    codemod_available BOOLEAN DEFAULT FALSE,
    usage_count INT UNSIGNED DEFAULT 0,
    affected_users INT UNSIGNED DEFAULT 0,
    status ENUM('proposed', 'approved', 'deprecated', 'legacy', 'removed') DEFAULT 'proposed',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_component (component_name),
    INDEX idx_status (status),
    INDEX idx_removal_version (removal_version)
);

CREATE TABLE deprecation_usage_log (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    deprecation_id BIGINT UNSIGNED NOT NULL,
    user_id BIGINT UNSIGNED NULL,
    usage_context TEXT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (deprecation_id) REFERENCES component_deprecations(id) ON DELETE CASCADE,
    INDEX idx_deprecation (deprecation_id),
    INDEX idx_created (created_at)
);
```

### Deprecation Reporting Dashboard

```php
<?php

namespace App\Http\Controllers\Admin;

use App\Models\ComponentDeprecation;
use Illuminate\Http\Request;
use Illuminate\View\View;

class DeprecationReportController extends Controller
{
    public function index(Request $request): View
    {
        $deprecations = ComponentDeprecation::query()
            ->withCount('usageLogs')
            ->when($request->status, fn($q, $s) => $q->where('status', $s))
            ->when($request->component, fn($q, $c) => $q->where('component_name', $c))
            ->orderByDesc('deprecated_since')
            ->paginate(20);

        $stats = [
            'total' => ComponentDeprecation::count(),
            'deprecated' => ComponentDeprecation::where('status', 'deprecated')->count(),
            'legacy' => ComponentDeprecation::where('status', 'legacy')->count(),
            'removed' => ComponentDeprecation::where('status', 'removed')->count(),
            'total_usage' => ComponentDeprecation::sum('usage_count'),
            'affected_users' => ComponentDeprecation::sum('affected_users'),
        ];

        return view('admin.deprecations.index', compact('deprecations', 'stats'));
    }

    public function show(ComponentDeprecation $deprecation): View
    {
        $usageOverTime = $deprecation->usageLogs()
            ->selectRaw('DATE(created_at) as date, COUNT(*) as count')
            ->groupBy('date')
            ->orderBy('date')
            ->get();

        $recentUsers = $deprecation->usageLogs()
            ->with('user')
            ->latest()
            ->limit(50)
            ->get();

        return view('admin.deprecations.show', compact('deprecation', 'usageOverTime', 'recentUsers'));
    }
}
```

## Emergency Deprecation Process

### Security-Related Deprecations

For security vulnerabilities, a shortened deprecation timeline is used:

```php
class EmergencyDeprecationHandler
{
    public function handleSecurityDeprecation(
        string $component,
        string $feature,
        string $vulnerability,
        string $patchVersion
    ): void {
        // 1. Immediately emit deprecation warnings in all environments
        config(['gsmui.deprecation_warnings_always' => true]);

        // 2. Log the security deprecation
        Log::critical('Emergency deprecation activated', [
            'component' => $component,
            'feature' => $feature,
            'vulnerability' => $vulnerability,
            'patch_version' => $patchVersion,
        ]);

        // 3. Send urgent notification to all users
        $affectedUsers = $this->findAffectedUsers($component, $feature);
        foreach ($affectedUsers as $user) {
            Mail::to($user->email)->send(new SecurityDeprecationNotice(
                $component, $feature, $vulnerability, $patchVersion
            ));
        }

        // 4. Update deprecation record
        ComponentDeprecation::where('component_name', $component)
            ->where('feature_name', $feature)
            ->update([
                'status' => 'deprecated',
                'deprecated_since' => $patchVersion,
                'emergency' => true,
            ]);
    }
}
```

| Phase | Duration | Actions |
|-------|----------|---------|
| **Immediate** | 0-24 hours | Patch released, warnings activated, notifications sent |
| **Urgent** | 1-7 days | Support team briefed, documentation updated |
| **Legacy** | 1-4 weeks | Feature frozen, migration assistance offered |
| **Removed** | Next patch/major | Feature removed from codebase |

### Deprecation Health Score

Calculate an overall deprecation health score:

```php
class DeprecationHealthCalculator
{
    public function calculate(): array
    {
        $deprecations = ComponentDeprecation::where('status', '!=', 'removed')->get();

        $score = 100;
        $penalties = [];

        // Penalty for old deprecations still in use
        foreach ($deprecations as $dep) {
            if ($dep->status === 'deprecated' && $dep->usage_count > 0) {
                $ageInMonths = Carbon::parse($dep->deprecated_since)->diffInMonths(now());
                if ($ageInMonths > 6) {
                    $penalty = min(10, $ageInMonths * 2);
                    $score -= $penalty;
                    $penalties[] = [
                        'feature' => "{$dep->component_name}.{$dep->feature_name}",
                        'penalty' => $penalty,
                        'reason' => "Deprecated for {$ageInMonths} months with {$dep->usage_count} usages",
                    ];
                }
            }
        }

        // Penalty for missing codemods
        $deprecatedWithoutCodemod = $deprecations->where('codemod_available', false)->count();
        if ($deprecatedWithoutCodemod > 3) {
            $penalty = $deprecatedWithoutCodemod * 2;
            $score -= $penalty;
            $penalties[] = [
                'feature' => 'Multiple features',
                'penalty' => $penalty,
                'reason' => "{$deprecatedWithoutCodemod} deprecations without codemods",
            ];
        }

        return [
            'score' => max(0, $score),
            'grade' => $this->getGrade($score),
            'penalties' => $penalties,
            'recommendations' => $this->getRecommendations($deprecations),
        ];
    }

    protected function getGrade(int $score): string
    {
        return match (true) {
            $score >= 90 => 'A',
            $score >= 80 => 'B',
            $score >= 70 => 'C',
            $score >= 60 => 'D',
            default => 'F',
        };
    }
}

### Automated Deprecation Detection

```php
<?php

namespace App\Deprecation;

class DeprecationDetector
{
    private array $deprecatedMethods = [];
    private array $deprecatedProps = [];
    private array $deprecatedEvents = [];

    public function scan(): array
    {
        $violations = [];

        // Scan Blade templates for deprecated patterns
        $templates = $this->getBladeTemplates();
        foreach ($templates as $template) {
            $violations = array_merge(
                $violations,
                $this->scanTemplate($template)
            );
        }

        // Scan JavaScript for deprecated API usage
        $jsFiles = $this->getJavaScriptFiles();
        foreach ($jsFiles as $file) {
            $violations = array_merge(
                $violations,
                $this->scanJavaScript($file)
            );
        }

        return $violations;
    }

    protected function scanTemplate(string $template): array
    {
        $violations = [];
        $content = file_get_contents($template);

        foreach ($this->deprecatedProps as $prop => $replacement) {
            if (str_contains($content, $prop)) {
                $violations[] = [
                    'file' => $template,
                    'type' => 'prop',
                    'deprecated' => $prop,
                    'replacement' => $replacement,
                    'severity' => 'warning',
                ];
            }
        }

        return $violations;
    }
}

## Deprecation Exceptions Process

### Exception Request Form

```php
<?php

namespace App\Deprecation;

class ExceptionRequest
{
    public string $feature;
    public string $reason;
    public string $impact;
    public string $requestor;
    public string $organization;
    public int $estimatedUsers;
    public string $proposedTimeline;

    public function __construct(array $data)
    {
        $this->feature = $data['feature'];
        $this->reason = $data['reason'];
        $this->impact = $data['impact'];
        $this->requestor = $data['requestor'];
        $this->organization = $data['organization'];
        $this->estimatedUsers = $data['estimated_users'];
        $this->proposedTimeline = $data['proposed_timeline'];
    }

    public function submit(): bool
    {
        // Validate request
        if (!$this->validate()) {
            return false;
        }

        // Store request
        DB::table('deprecation_exceptions')->insert([
            'feature' => $this->feature,
            'reason' => $this->reason,
            'impact' => $this->impact,
            'requestor' => $this->requestor,
            'organization' => $this->organization,
            'estimated_users' => $this->estimatedUsers,
            'proposed_timeline' => $this->proposedTimeline,
            'status' => 'pending',
            'created_at' => now(),
        ]);

        // Notify maintainers
        $this->notifyMaintainers();

        return true;
    }

    protected function validate(): bool
    {
        return !empty($this->feature)
            && !empty($this->reason)
            && !empty($this->impact)
            && $this->estimatedUsers > 0;
    }
}
```

### Exception Approval Workflow

```text
Exception Request Submitted
    │
    ├─ Is the request complete?
    │   ├─ No → Request additional information
    │   └─ Yes → Continue review
    │
    ├─ Is the impact significant?
    │   ├─ Yes → Full team review required
    │   └─ No → Maintainer review sufficient
    │
    ├─ Is the reason valid?
    │   ├─ Yes → Approve with conditions
    │   └─ No → Deny with explanation
    │
    └─ What conditions apply?
        ├─ Extended timeline → Document new removal date
        ├─ Specific version → Document which version
        └─ Partial support → Document what is supported
```

## Deprecation Metrics and Reporting

### Monthly Report

```php
<?php

namespace App\Reports;

class DeprecationMonthlyReport
{
    public function generate(): array
    {
        return [
            'summary' => $this->getSummary(),
            'deprecations' => $this->getDeprecationDetails(),
            'migrations' => $this->getMigrationStats(),
            'support' => $this->getSupportStats(),
            'recommendations' => $this->getRecommendations(),
        ];
    }

    protected function getSummary(): array
    {
        return [
            'total_deprecations' => Deprecation::count(),
            'active_deprecations' => Deprecation::where('status', 'active')->count(),
            'removed_features' => Deprecation::where('status', 'removed')->count(),
            'average_adoption_rate' => $this->calculateAverageAdoption(),
            'upcoming_removals' => $this->getUpcomingRemovalsCount(),
        ];
    }

    protected function getRecommendations(): array
    {
        $recommendations = [];

        $lowAdoption = $this->getLowAdoptionDeprecations();
        foreach ($lowAdoption as $deprecation) {
            $recommendations[] = [
                'type' => 'communication',
                'feature' => $deprecation->feature,
                'action' => 'Increase migration communication',
                'priority' => 'high',
            ];
        }

        return $recommendations;
    }
}
```

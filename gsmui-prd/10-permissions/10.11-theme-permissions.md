# 10.11 — Theme Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines the complete authorization rules for the **Theme domain** in GsmUi. Themes are the visual skins applied to projects. Creators build, publish, and sell themes through the marketplace. This specification governs who can create, edit, publish, feature, export, clone, and delete themes — and enforces ownership, moderation workflows, and marketplace lifecycle constraints.

Authorization for themes interacts directly with the [Marketplace domain](./10.10-marketplace-permissions.md), the [Creator permissions](./10.09-creator-permissions.md), and the general [Policy framework](./10.05-policies.md).

## Scope

Theme permissions apply to:

* Theme creation and editing
* Theme publishing and approval workflow
* Theme featuring on the homepage
* Theme exporting as installable packages
* Theme cloning as templates
* Theme deletion and archival
* Theme marketplace listing interactions
* Theme asset management (screenshots, previews, source files)

## Theme Lifecycle States

```text
draft
  ↓ (submit for review)
pending_review
  ↓ (approve)
published
  ↓ (feature)
featured

pending_review
  ↓ (reject)
rejected
  ↓ (owner edits & resubmits)
pending_review

published
  ↓ (unpublish by owner or admin)
unpublished
  ↓ (resubmit)
pending_review
```

### State Transition Matrix

| From State | To State | Trigger | Permission Required |
|---|---|---|---|
| `draft` | `pending_review` | Owner submits | `themes.publish` (own) |
| `pending_review` | `published` | Moderator approves | `themes.publish` (moderator+) |
| `pending_review` | `rejected` | Moderator rejects | `themes.publish` (moderator+) |
| `pending_review` | `draft` | Owner withdraws | `themes.update` (own) |
| `rejected` | `pending_review` | Owner resubmits | `themes.publish` (own) |
| `published` | `featured` | Admin features | `themes.feature` (admin+) |
| `featured` | `published` | Admin unfeatures | `themes.feature` (admin+) |
| `published` | `unpublished` | Owner/admin unpublishes | `themes.unpublish` (own or admin) |
| `unpublished` | `pending_review` | Owner resubmits | `themes.publish` (own) |
| Any | `draft` | Owner deletes | `themes.delete` (own) |

## Ownership Rules

### Creator Ownership

A theme's `user_id` field determines ownership. Ownership grants:

* Full edit rights on the theme while in `draft` or `rejected` state
* Ability to submit for review
* Ability to withdraw from review
* Ability to unpublish a published theme
* Revenue share from marketplace sales (see [10.10-marketplace-permissions.md](./10.10-marketplace-permissions.md))

### Ownership Transfer

Ownership can be transferred in these scenarios:

* **Gift:** Creator gifts theme to another creator (admin approval required)
* **Acquisition:** Theme is purchased outright (admin-mediated)
* **Account merger:** Two accounts are merged (admin action)
* **Death/disability:** Successor designated in creator settings

```php
// Ownership transfer must be logged
Theme::withoutTimestamps(function () use ($theme, $newOwnerId) {
    $oldUserId = $theme->user_id;
    $theme->user_id = $newOwnerId;
    $theme->save();

    activity()
        ->performedOn($theme)
        ->withProperties([
            'old_user_id' => $oldUserId,
            'new_user_id' => $newOwnerId,
        ])
        ->event('theme.ownership_transferred')
        ->log('Theme ownership transferred');
});
```

### Collaborative Themes (Future)

Future team-based ownership:

* Multiple creators can collaborate on a single theme
* Permissions are scoped to team membership
* See [10.20-team-permissions.md](./10.20-team-permissions.md) for team permission architecture

## Authorization Rules by State

### Draft Theme

```text
Owner:     edit metadata, upload assets, preview, submit for review, delete
Other:     (no access — private draft)
Moderator: (no access)
Admin:     view, delete (enforcement only)
```

**Enforcement:**

```php
// Draft themes are only visible to owner and admins
public function view(User $user, Theme $theme): bool
{
    if ($theme->status === 'draft') {
        return $user->id === $theme->user_id
            || $user->hasRole(['admin', 'super_admin']);
    }

    return true; // published/rejected themes are public
}
```

### Pending Review

```text
Owner:     view, withdraw (revert to draft)
Other:     view (read-only preview)
Moderator: view, approve, reject
Admin:     view, approve, reject, delete
```

**Enforcement:**

```php
public function update(User $user, Theme $theme): bool
{
    if ($theme->status !== 'draft' && $theme->status !== 'rejected') {
        return false; // Cannot edit while in review or published
    }

    return $user->id === $theme->user_id;
}

public function publish(User $user, Theme $theme): bool
{
    if ($user->hasRole(['admin', 'super_admin'])) {
        return true;
    }

    if ($user->hasRole('moderator') && $theme->status === 'pending_review') {
        return true;
    }

    // Owner can submit draft/rejected theme for review
    return $user->id === $theme->user_id
        && in_array($theme->status, ['draft', 'rejected']);
}
```

### Published Theme

```text
Owner:     view, update metadata (non-breaking), unpublish, view sales
Other:     view (public marketplace)
Moderator: view
Admin:     view, feature, unfeature, unpublish, delete
```

**Enforcement:**

```php
public function unpublish(User $user, Theme $theme): bool
{
    if ($theme->status !== 'published' && $theme->status !== 'featured') {
        return false;
    }

    if ($user->hasRole(['admin', 'super_admin'])) {
        return true;
    }

    return $user->id === $theme->user_id;
}

public function feature(User $user, Theme $theme): bool
{
    if ($theme->status !== 'published') {
        return false;
    }

    return $user->hasRole(['admin', 'super_admin']);
}
```

### Rejected Theme

```text
Owner:     view (with rejection reason), edit, resubmit
Other:     (no access to rejected theme)
Moderator: view (audit trail)
Admin:     view, delete
```

## Policy Implementation

```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\Theme;
use Illuminate\Auth\Access\HandlesAuthorization;

class ThemePolicy
{
    use HandlesAuthorization;

    /**
     * Determine whether the user can view any themes.
     * Public browsing — all users and guests can view published themes.
     */
    public function viewAny(User $user): bool
    {
        return true;
    }

    /**
     * Determine whether the user can view the theme.
     * Published and featured themes are public.
     * Draft and rejected themes are owner/admin only.
     */
    public function view(User $user, Theme $theme): bool
    {
        if (in_array($theme->status, ['published', 'featured'])) {
            return true;
        }

        if ($theme->status === 'pending_review') {
            return $user->id === $theme->user_id
                || $user->hasRole(['moderator', 'admin', 'super_admin']);
        }

        // draft or rejected — owner + admin only
        return $user->id === $theme->user_id
            || $user->hasRole(['admin', 'super_admin']);
    }

    /**
     * Determine whether the user can create themes.
     * Requires 'creator' or 'admin' role.
     */
    public function create(User $user): bool
    {
        return $user->hasRole(['creator', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can update the theme.
     * Only owner can update, and only in draft/rejected state.
     */
    public function update(User $user, Theme $theme): bool
    {
        if (! in_array($theme->status, ['draft', 'rejected'])) {
            return false;
        }

        return $user->id === $theme->user_id;
    }

    /**
     * Determine whether the user can delete the theme.
     * Owner can delete own themes; admins can delete any.
     */
    public function delete(User $user, Theme $theme): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $theme->user_id;
    }

    /**
     * Determine whether the user can publish/submit for review.
     * Owner submits drafts for review; moderators/admins approve.
     */
    public function publish(User $user, Theme $theme): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        if ($user->hasRole('moderator') && $theme->status === 'pending_review') {
            return true;
        }

        // Owner submitting draft/rejected for review
        if ($user->id === $theme->user_id && in_array($theme->status, ['draft', 'rejected'])) {
            return true;
        }

        return false;
    }

    /**
     * Determine whether the user can unpublish a theme.
     */
    public function unpublish(User $user, Theme $theme): bool
    {
        if (! in_array($theme->status, ['published', 'featured'])) {
            return false;
        }

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $theme->user_id;
    }

    /**
     * Determine whether the user can feature a theme.
     */
    public function feature(User $user, Theme $theme): bool
    {
        if ($theme->status !== 'published') {
            return false;
        }

        return $user->hasRole(['admin', 'super_admin']);
    }

    /**
     * Determine whether the user can export a theme.
     */
    public function export(User $user, Theme $theme): bool
    {
        if ($theme->status !== 'published') {
            return false;
        }

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $theme->user_id;
    }

    /**
     * Determine whether the user can clone a theme.
     */
    public function clone(User $user, Theme $theme): bool
    {
        if ($theme->status !== 'published') {
            return false;
        }

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $theme->user_id;
    }

    /**
     * Determine whether the user can view sales data.
     */
    public function viewSales(User $user, Theme $theme): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $theme->user_id;
    }

    /**
     * Determine whether the user can manage pricing.
     */
    public function managePricing(User $user, Theme $theme): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $theme->user_id
            && in_array($theme->status, ['draft', 'rejected', 'unpublished']);
    }
}
```

## Controller Integration

```php
<?php

namespace App\Http\Controllers;

use App\Models\Theme;
use Illuminate\Http\Request;

class ThemeController extends Controller
{
    public function __construct()
    {
        $this->authorizeResource(Theme::class, 'theme');
    }

    public function index()
    {
        // viewAny — all published themes
    }

    public function store(Request $request)
    {
        // create — requires 'creator' or 'admin' role

        $theme = Theme::create([
            'user_id' => auth()->id(),
            'name' => $request->name,
            'slug' => $request->slug,
            'status' => 'draft',
        ]);

        return redirect()->route('themes.edit', $theme);
    }

    public function update(Request $request, Theme $theme)
    {
        // update — owner only, draft/rejected state only

        $theme->update($request->validated());

        return back()->with('success', 'Theme updated.');
    }

    public function submitForReview(Theme $theme)
    {
        $this->authorize('publish', $theme);

        $theme->update(['status' => 'pending_review']);

        activity()
            ->performedOn($theme)
            ->event('theme.submitted_for_review')
            ->log('Theme submitted for review');

        return back()->with('success', 'Theme submitted for review.');
    }

    public function approve(Theme $theme)
    {
        $this->authorize('publish', $theme);

        $theme->update(['status' => 'published', 'published_at' => now()]);

        activity()
            ->performedOn($theme)
            ->event('theme.approved')
            ->log('Theme approved and published');

        return back()->with('success', 'Theme approved.');
    }

    public function reject(Theme $theme, Request $request)
    {
        $this->authorize('publish', $theme);

        $theme->update([
            'status' => 'rejected',
            'rejection_reason' => $request->reason,
        ]);

        activity()
            ->performedOn($theme)
            ->event('theme.rejected')
            ->withProperties(['reason' => $request->reason])
            ->log('Theme rejected');

        return back()->with('success', 'Theme rejected.');
    }

    public function destroy(Theme $theme)
    {
        $this->authorize('delete', $theme);

        $theme->delete();

        return redirect()->route('themes.index');
    }
}
```

## Theme Asset Management

Theme assets include screenshots, source files, and preview images. Access to these assets follows strict ownership and visibility rules.

### Asset Types and Access Rules

| Asset Type | Visibility | Max Size | Allowed Formats |
|---|---|---|---|
| Screenshots | Public (published), Private (draft) | 5MB each | PNG, JPG, WebP |
| Source files | Owner + Admin only | 50MB total | ZIP, TAR.GZ |
| Preview images | Public (published), Private (draft) | 2MB each | PNG, JPG, WebP |
| Thumbnail | Public | 500KB | PNG, JPG, WebP |

### Asset Upload Authorization

## Theme Export Authorization

Theme exports create installable packages from published themes. The export process is asynchronous and generates a downloadable ZIP archive.

### Export Workflow

```text
Owner/Admin requests export
    ↓
Check: themes.export permission
    ↓
Verify theme is in 'published' or 'featured' state
    ↓
Dispatch export job to queue
    ↓
Job: Compile theme source files
    ↓
Job: Generate package manifest (version, dependencies)
    ↓
Job: Create ZIP archive
    ↓
Job: Store archive in storage
    ↓
Notify owner/admin of export completion
    ↓
Provide download link (time-limited)
```

### Export Policy

```php
class ThemeExportPolicy
{
    public function export(User $user, Theme $theme): bool
    {
        if (! in_array($theme->status, ['published', 'featured'])) {
            return false;
        }

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $theme->user_id;
    }

    public function downloadExport(User $user, ThemeExport $export): bool
    {
        $theme = $export->theme;

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $theme->user_id;
    }

    public function cancelExport(User $user, ThemeExport $export): bool
    {
        if ($export->status !== 'pending') {
            return false;
        }

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $export->theme->user_id;
    }
}
```

### Export Job Implementation

```php
class ExportThemeJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        private Theme $theme,
        private User $user,
    ) {}

    public function handle(): void
    {
        $archivePath = Storage::disk('local')->path(
            "theme-exports/{$this->theme->id}/{$this->theme->slug}-{$this->theme->version}.zip"
        );

        // Collect theme source files
        $files = $this->theme->assets()
            ->where('type', 'source')
            ->get();

        // Generate package manifest
        $manifest = [
            'name' => $this->theme->name,
            'version' => $this->theme->version,
            'author' => $this->user->name,
            'description' => $this->theme->description,
            'dependencies' => $this->theme->dependencies ?? [],
        ];

        // Create ZIP archive
        $zip = new \ZipArchive();
        $zip->open($archivePath, \ZipArchive::CREATE | \ZipArchive::OVERWRITE);

        $zip->addFromString('manifest.json', json_encode($manifest, JSON_PRETTY_PRINT));

        foreach ($files as $file) {
            $zip->addFile(
                Storage::disk('local')->path($file->path),
                "source/{$file->filename}"
            );
        }

        $zip->close();

        // Store export record
        $export = ThemeExport::create([
            'theme_id' => $this->theme->id,
            'user_id' => $this->user->id,
            'path' => $archivePath,
            'version' => $this->theme->version,
            'status' => 'completed',
            'file_size' => filesize($archivePath),
        ]);

        // Notify owner
        Notification::send($this->user, new ThemeExportReadyNotification($export));
    }
}
```

## Theme Cloning Authorization

Cloning creates a new theme based on an existing published theme. The clone is a new draft under the cloner's ownership.

### Clone Workflow

```text
User requests clone
    ↓
Check: themes.clone permission
    ↓
Verify source theme is 'published' or 'featured'
    ↓
Verify user is NOT the source owner (use edit instead)
    ↓
Create new theme record under cloner's user_id
    ↓
Copy metadata (name, description, screenshot thumbnails)
    ↓
Set status to 'draft'
    ↓
Set original_theme_id to source theme
    ↓
Log clone activity
    ↓
Redirect to edit page of cloned theme
```

### Clone Policy

```php
class ThemeClonePolicy
{
    public function clone(User $user, Theme $theme): bool
    {
        if (! in_array($theme->status, ['published', 'featured'])) {
            return false;
        }

        // Cannot clone your own theme
        if ($user->id === $theme->user_id) {
            return false;
        }

        return true;
    }
}
```

### Clone Service

```php
class ThemeCloner
{
    public function clone(Theme $original, User $cloner): Theme
    {
        $clone = $original->replicate();
        $clone->user_id = $cloner->id;
        $clone->original_theme_id = $original->id;
        $clone->name = $original->name . ' (Clone)';
        $clone->slug = Str::slug($clone->name) . '-' . Str::random(5);
        $clone->status = 'draft';
        $clone->version = '1.0.0';
        $clone->price = null;
        $clone->published_at = null;
        $clone->featured_at = null;
        $clone->save();

        // Copy screenshots as references (not files)
        foreach ($original->assets()->where('type', 'screenshot')->get() as $asset) {
            $cloneAsset = $asset->replicate();
            $cloneAsset->theme_id = $clone->id;
            $cloneAsset->user_id = $cloner->id;
            $cloneAsset->save();
        }
```

```php
            ->where('date', '>=', now()->subDays($days))

            ->select([

                DB::raw('SUM(views) as total_views'),

                DB::raw('SUM(revenue_cents) / 100 as total_revenue'),

            ->where('theme_id', $theme->id)
            ->sum('downloads');

            return 0.0;
        }

        return round(($downloads / $views) * 100, 2);
```

### ACL Resolution

```php
class ThemeAclResolver
{
    public function resolve(User $user, Theme $theme, string $permission): bool
    {
        // Check role-based permission first
        if ($user->can($permission, $theme)) {
            return true;
        }

        // Check explicit ACL grant
        $acl = ThemeAcl::where('theme_id', $theme->id)
            ->where('user_id', $user->id)
            ->where('permission', $permission)
            ->where(function ($q) {
                $q->whereNull('expires_at')
                  ->orWhere('expires_at', '>', now());
            })
            ->first();

        return $acl !== null;
    }
}
```

```php
{
    public function checkBudget(Theme $theme, array $metrics): void
    {
        $budgets = Cache::get('theme:performance:budgets', [
            'fcp_ms' => 1500,
            'lcp_ms' => 2500,
            'cls' => 0.15,
            'tbt_ms' => 300,
        ]);

        $violations = [];

        foreach ($budgets as $metric => $threshold) {
            if (isset($metrics[$metric]) && $metrics[$metric] > $threshold) {

                    'metric' => $metric,
                    'value' => $metrics[$metric],

            Notification::send($theme->user, new ThemePerformanceWarningNotification($theme, $violations));

            activity()
                ->performedOn($theme)
                ->withProperties(['violations' => $violations])
                ->event('theme.performance.budget_exceeded')
```

# 10.05 — Policies

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines every Policy class in the GsmUi platform. Each aggregate root (model) has a dedicated Policy that enforces authorization for CRUD operations. Policies are the primary enforcement mechanism for resource-level access control — they combine permission checks with ownership verification and business constraints.

See [10.02-rbac-architecture.md](./10.02-rbac-architecture.md) for how policies integrate with the RBAC system and [10.03-roles.md](./10.03-roles.md) for role definitions.

## Policy Architecture

```text
User requests action on Model
    ↓
Controller / Livewire calls authorize()
    ↓
Laravel resolves Policy class
    ↓
Policy method checks:
  1. Permission (does user have the required permission?)
  2. Ownership (does user own this resource?)
  3. Business rules (domain constraints)
    ↓
Returns true (allow) or false (deny)
```

## Policy Method Contract

Every policy implements these standard methods:

| Method | Purpose | Typical Check |
|---|---|---|
| `viewAny(User $user)` | Can user list all resources? | Permission check only |
| `view(User $user, Model $model)` | Can user view this specific resource? | Permission + ownership |
| `create(User $user)` | Can user create a new resource? | Permission check only |
| `update(User $user, Model $model)` | Can user update this resource? | Permission + ownership |
| `delete(User $user, Model $model)` | Can user delete this resource? | Permission + ownership |
| `restore(User $user, Model $model)` | Can user restore soft-deleted resource? | Permission + ownership |
| `forceDelete(User $user, Model $model)` | Can user permanently delete? | Permission (admin only) |

## Ownership Pattern

The most common authorization pattern in GsmUi. Resources are owned by the creating user. Owners can manage their own resources; non-owners need explicit permission.

```php
public function update(User $user, Theme $theme): bool
{
    return $user->id === $theme->user_id || $user->hasPermissionTo('themes.update');
}

public function delete(User $user, Theme $theme): bool
{
    return $user->id === $theme->user_id || $user->hasPermissionTo('themes.delete');
}
```

## Policy List

### UserPolicy

Controls access to user accounts and profiles.

| Method | Rule | Reference |
|---|---|---|
| `viewAny` | `users.view` permission | Admin, Support |
| `view` | Owner or `users.view` | Own profile or admin |
| `create` | `users.create` | Admin only |
| `update` | Owner (limited fields) or `users.update` | Own profile or admin |
| `delete` | `users.delete` | Admin only |
| `restore` | `users.delete` | Admin only |
| `forceDelete` | `users.delete` | Super Admin only |

```php
// app/Policies/UserPolicy.php
class UserPolicy
{
    use HandlesAuthorization;

    public function viewAny(User $user): bool
    {
        return $user->hasPermissionTo('users.view');
    }

    public function view(User $user, User $target): bool
    {
        return $user->id === $target->id || $user->hasPermissionTo('users.view');
    }

    public function create(User $user): bool
    {
        return $user->hasPermissionTo('users.create');
    }

    public function update(User $user, User $target): bool
    {
        if ($user->id === $target->id) {
            // Owners can update limited fields
            return true;
        }

        return $user->hasPermissionTo('users.update');
    }

    public function delete(User $user, User $target): bool
    {
        // Cannot delete yourself
        if ($user->id === $target->id) {
            return false;
        }

        return $user->hasPermissionTo('users.delete');
    }
}
```

### RolePolicy

Controls access to role management.

| Method | Rule | Reference |
|---|---|---|
| `viewAny` | `roles.view` | Admin |
| `view` | `roles.view` | Admin |
| `create` | `roles.create` | Admin |
| `update` | `roles.update` + not seeded | Admin |
| `delete` | `roles.delete` + not seeded + not last | Admin |

```php
// app/Policies/RolePolicy.php
class RolePolicy
{
    use HandlesAuthorization;

    public function update(User $user, Role $role): bool
    {
        // Cannot modify seeded roles (user, admin, etc.)
        if ($role->is_seeded) {
            return false;
        }

        return $user->hasPermissionTo('roles.update');
    }

    public function delete(User $user, Role $role): bool
    {
        // Cannot delete seeded roles
        if ($role->is_seeded) {
            return false;
        }

        // Cannot delete if it's the last role of its level
        if ($role->users()->count() > 0) {
            return false;
        }

        return $user->hasPermissionTo('roles.delete');
    }
}
```

### ThemePolicy

Controls access to themes. Uses the ownership pattern.

| Method | Rule | Reference |
|---|---|---|
| `viewAny` | `themes.view` | All authenticated |
| `view` | Published (any) or owner (draft) | Public for published |
| `create` | `themes.create` | Creator, Admin |
| `update` | Owner or `themes.update` | Creator (own), Admin |
| `delete` | Owner or `themes.delete` | Creator (own), Admin |
| `publish` | Owner + `themes.publish` or moderator/admin | Creator, Moderator, Admin |
| `feature` | `themes.feature` | Moderator, Admin |

```php
// app/Policies/ThemePolicy.php
class ThemePolicy
{
    use HandlesAuthorization;

    public function viewAny(User $user): bool
    {
        return $user->hasPermissionTo('themes.view');
    }

    public function view(User $user, Theme $theme): bool
    {
        // Published themes are publicly viewable
        if ($theme->status === 'published') {
            return true;
        }

        // Draft themes are only viewable by owner
        return $user->id === $theme->user_id;
    }

    public function create(User $user): bool
    {
        return $user->hasPermissionTo('themes.create');
    }

    public function update(User $user, Theme $theme): bool
    {
        return $user->id === $theme->user_id || $user->hasPermissionTo('themes.update');
    }

    public function delete(User $user, Theme $theme): bool
    {
        return $user->id === $theme->user_id || $user->hasPermissionTo('themes.delete');
    }

    public function publish(User $user, Theme $theme): bool
    {
        // Owner with publish permission
        if ($user->id === $theme->user_id && $user->hasPermissionTo('themes.publish')) {
            return true;
        }

        // Moderator or admin can publish any theme
        return $user->hasRole(['moderator', 'admin']);
    }

    public function feature(User $user, Theme $theme): bool
    {
        return $user->hasPermissionTo('themes.feature');
    }
}
```

### OrderPolicy

Controls access to orders.

| Method | Rule | Reference |
|---|---|---|
| `viewAny` | `orders.view` | Support, Admin |
| `view` | Owner or `orders.view` | Own orders or Support/Admin |
| `create` | Authenticated user | Any authenticated user |
| `update` | Owner + pending status | Owner (pending only) |
| `cancel` | Owner + pending or `orders.cancel` | Owner (pending) or Support/Admin |
| `refund` | `orders.refund` | Support (with approval), Admin |

```php
// app/Policies/OrderPolicy.php
class OrderPolicy
{
    use HandlesAuthorization;

    public function view(User $user, Order $order): bool
    {
        return $user->id === $order->user_id || $user->hasPermissionTo('orders.view');
    }

    public function cancel(User $user, Order $order): bool
    {
        // Owner can cancel pending orders
        if ($user->id === $order->user_id && $order->status === 'pending') {
            return true;
        }

        return $user->hasPermissionTo('orders.cancel');
    }

    public function refund(User $user, Order $order): bool
    {
        // Cannot refund own order
        if ($user->id === $order->user_id) {
            return false;
        }

        return $user->hasPermissionTo('orders.refund');
    }
}
```

## Registration

Policies are registered via auto-discovery in Laravel. Place policy classes in `app/Policies/` and Laravel automatically maps them to models.

```php
// app/Providers/AuthServiceProvider.php (if manual registration needed)
class AuthServiceProvider extends ServiceProvider
{
    protected $policies = [
        User::class => UserPolicy::class,
        Theme::class => ThemePolicy::class,
        Component::class => ComponentPolicy::class,
        Template::class => TemplatePolicy::class,
        Order::class => OrderPolicy::class,
        License::class => LicensePolicy::class,
        Subscription::class => SubscriptionPolicy::class,
        BlogPost::class => BlogPostPolicy::class,
        Documentation::class => DocumentationPolicy::class,
        Playground::class => PlaygroundPolicy::class,
        AiInteraction::class => AiInteractionPolicy::class,
        McpServer::class => McpServerPolicy::class,
        Setting::class => SettingPolicy::class,
        AuditLog::class => AuditLogPolicy::class,
    ];

    public function boot(): void
    {
        Gate::policy(User::class, UserPolicy::class);
    }
}

## Before/After Hooks

### Before Hook (Super Admin Bypass)

```php
// In any policy
public function before(User $user, string $ability): ?bool
{
    // Super Admin bypasses all policy checks
    if ($user->hasRole('super_admin')) {
        return true;
    }

    return null; // Continue to normal method
}
```

### After Hook (Audit Logging)

```php
// In any policy
public function after(User $user, string $ability, bool $result): void
{
    // Log authorization decisions for audit trail
    activity()
        ->performedOn($user)
        ->withProperties([
            'ability' => $ability,
            'result' => $result,
        ])
        ->log("Authorization check: {$ability}");
}
```

## Controller Usage

```php
// app/Http/Controllers/ThemeController.php
class ThemeController extends Controller
{
    public function index(): View
    {
        $this->authorize('viewAny', Theme::class);
        
        $themes = Theme::where('status', 'published')->get();
        
        return view('themes.index', compact('themes'));
    }

    public function show(Theme $theme): View
    {
        $this->authorize('view', $theme);
        
        return view('themes.show', compact('theme'));
    }

    public function update(ThemeUpdateRequest $request, Theme $theme): RedirectResponse
    {
        $this->authorize('update', $theme);
        
        $theme->update($request->validated());
        
        return redirect()->route('themes.show', $theme);
    }

    public function destroy(Theme $theme): RedirectResponse
    {
        $this->authorize('delete', $theme);
        
        $theme->delete();
        
        return redirect()->route('themes.index');
    }

    public function publish(Theme $theme): RedirectResponse
    {
        $this->authorize('publish', $theme);
        
        $theme->update(['status' => 'published']);
        
        return redirect()->route('themes.show', $theme);
    }
}

## Advanced Policy Patterns

### Policy Composition via Traits

```php
// app/Policies/Concerns/HasOwnership.php

namespace App\Policies\Concerns;

use App\Models\User;
use Illuminate\Database\Eloquent\Model;

trait HasOwnership
{
    protected function isOwner(User $user, Model $model): bool
    {
        return $user->id === ($model->user_id ?? null);
    }

    protected function isOwnerOrAdmin(User $user, Model $model): bool
    {
        return $this->isOwner($user, $model)
            || $user->hasRole(['admin', 'super_admin']);
    }

    protected function isOwnerOrHasPermission(User $user, Model $model, string $permission): bool
    {
        return $this->isOwner($user, $model)
            || $user->hasPermissionTo($permission);
    }
}
```

```php
// app/Policies/Concerns/HasSubscriptionChecks.php

namespace App\Policies\Concerns;

use App\Models\User;

trait HasSubscriptionChecks
{
    protected function hasMinimumPlan(User $user, string $minimumPlan): bool
    {
        $hierarchy = ['free' => 0, 'pro' => 1, 'creator' => 2, 'enterprise' => 3];
        $currentLevel = $hierarchy[$user->subscription?->plan ?? 'free'] ?? 0;
        $requiredLevel = $hierarchy[$minimumPlan] ?? 0;
        return $currentLevel >= $requiredLevel;
    }

    protected function withinProjectLimit(User $user): bool
    {
        $tier = $user->subscription?->plan ?? 'free';
        $maxProjects = config("subscriptions.{$tier}.max_projects", 1);
        $currentProjects = $user->projects()->count();
        return $maxProjects === -1 || $currentProjects < $maxProjects;
    }

    protected function withinApiLimit(User $user): bool
    {
        $tier = $user->subscription?->plan ?? 'free';
        $limit = config("subscriptions.{$tier}.api_calls_per_month", 0);
        $used = cache()->get("api_calls:{$user->id}:" . now()->format('Y-m'), 0);
        return $limit === -1 || $used < $limit;
    }
}
```

```php
// app/Policies/Concerns/HasAuditTrail.php

namespace App\Policies\Concerns;

use App\Models\User;
use Illuminate\Database\Eloquent\Model;

trait HasAuditTrail
{
    protected function logAuthorizationResult(
        User $user,
        string $ability,
        Model $model,
        bool $result,
    ): void {
        activity()
            ->performedOn($model)
            ->causedBy($user)
            ->withProperties([
                'ability' => $ability,
                'result' => $result,
                'policy' => static::class,
                'ip' => request()->ip(),
                'user_agent' => Str::limit(request()->userAgent(), 200),
            ])
            ->event($result ? 'policy_allowed' : 'policy_denied')
            ->log("Policy {$result ? 'allowed' : 'denied'}: {$ability}");
    }
}
```

### Composed Policy Example

```php
// app/Policies/ThemePolicy.php

use App\Policies\Concerns\HasOwnership;
use App\Policies\Concerns\HasStatusChecks;
use App\Policies\Concerns\HasAuditTrail;

class ThemePolicy
{
    use HandlesAuthorization, HasOwnership, HasStatusChecks, HasAuditTrail;

    protected const PERMISSION_PREFIX = 'themes';

    public function before(User $user, string $ability): ?bool
    {
        if ($user->hasRole('super_admin')) {
            return true;
        }
        return null;
    }

    public function viewAny(User $user): bool
    {
        return $user->hasPermissionTo(self::PERMISSION_PREFIX . '.view');
    }

    public function view(User $user, Theme $theme): bool
    {
        if ($this->isPublished($theme)) {
            return true;
        }
        return $this->isOwnerOrAdmin($user, $theme);
    }

    public function create(User $user): bool
    {
        return $user->hasPermissionTo(self::PERMISSION_PREFIX . '.create');
    }

    public function update(User $user, Theme $theme): bool
    {
        if (! $this->isEditable($theme)) {
            return false;
        }
        return $this->isOwnerOrHasPermission(
            $user, $theme, self::PERMISSION_PREFIX . '.update'
        );
    }

    public function delete(User $user, Theme $theme): bool
    {
        return $this->isOwnerOrHasPermission(
            $user, $theme, self::PERMISSION_PREFIX . '.delete'
        );
    }

    public function publish(User $user, Theme $theme): bool
    {
        if ($user->hasRole(['moderator', 'admin'])) {
            return true;
        }
        return $this->isOwner($user, $theme)
            && $user->hasPermissionTo(self::PERMISSION_PREFIX . '.publish')
            && $this->isEditable($theme);
    }

    public function feature(User $user, Theme $theme): bool
    {
        return $user->hasPermissionTo(self::PERMISSION_PREFIX . '.feature');
    }
}
```

## Policy Inheritance

In some cases, policies can inherit behavior from a base policy to reduce code duplication.

### Base Resource Policy

```php
// app/Policies/BaseResourcePolicy.php

namespace App\Policies;

use App\Models\User;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Auth\Access\HandlesAuthorization;

abstract class BaseResourcePolicy
{
    use HandlesAuthorization;

    abstract protected function permissionPrefix(): string;

    protected function ownerKey(): string
    {
        return 'user_id';
    }

    public function before(User $user, string $ability): ?bool
    {
        if ($user->hasRole('super_admin')) {
            return true;
        }
        return null;
    }

    public function viewAny(User $user): bool
    {
        return $user->hasPermissionTo($this->permissionPrefix() . '.view');
    }

    public function view(User $user, Model $model): bool
    {
        if (in_array($model->status ?? '', ['published', 'featured'])) {
            return true;
        }
        return $this->isOwner($user, $model)
            || $user->hasPermissionTo($this->permissionPrefix() . '.view');
    }

    public function create(User $user): bool
    {
        return $user->hasPermissionTo($this->permissionPrefix() . '.create');
    }

    public function update(User $user, Model $model): bool
    {
        return $this->isOwner($user, $model)
            || $user->hasPermissionTo($this->permissionPrefix() . '.update');
    }

    public function delete(User $user, Model $model): bool
    {
        return $this->isOwner($user, $model)
            || $user->hasPermissionTo($this->permissionPrefix() . '.delete');
    }

    protected function isOwner(User $user, Model $model): bool
    {
        return $user->id === $model->{$this->ownerKey()};
    }
}
```

## Policy Testing: Advanced Patterns

### Testing Policy Interactions

```php
// tests/Feature/Policies/PolicyInteractionTest.php

namespace Tests\Feature\Policies;

use App\Models\Theme;
use App\Models\User;
use Tests\TestCase;

class PolicyInteractionTest extends TestCase
{
    use \Illuminate\Foundation\Testing\RefreshDatabase;

    public function test_delegated_permission_grants_policy_access(): void
    {
        $owner = User::factory()->create();
        $delegated = User::factory()->create();
        $theme = Theme::factory()->create(['user_id' => $owner->id, 'status' => 'draft']);

        // Delegate permission
        $delegation = \App\Models\PermissionDelegation::create([
            'organization_id' => $owner->current_organization_id,
            'delegated_to_id' => $delegated->id,
            'delegated_by_id' => $owner->id,
            'permission' => 'themes.update',
        ]);

        // Delegated user can update
        $this->assertTrue($delegated->can('update', $theme));
    }

    public function test_team_sharing_grants_policy_access(): void
    {
        $owner = User::factory()->create();
        $teamMember = User::factory()->create();
        $team = \App\Models\Team::factory()->create();
        $theme = Theme::factory()->create(['user_id' => $owner->id, 'status' => 'draft']);

        // Add team member

### Pattern 3: Role Hierarchy Check

```php
protected function userAtOrAboveRole(User $user, string $minimumRole): bool
{
    $hierarchy = [
        'user' => 1,
        'creator' => 2,
        'moderator' => 3,
        'admin' => 4,
        'super_admin' => 5,
    ];

    $userLevel = 0;
    foreach ($user->roles as $role) {
        if (isset($hierarchy[$role->name])) {
            $userLevel = max($userLevel, $hierarchy[$role->name]);
        }
    }

    return $userLevel >= ($hierarchy[$minimumRole] ?? 0);
}
```

### Pattern 4: Rate-Limited Actions

```php
protected function withinQuota(User $user, string $action, int $limit): bool
{
    $key = "quota:{$user->id}:{$action}:" . now()->format('Y-m');
    $current = cache()->get($key, 0);
    return $current < $limit;
}

protected function incrementQuota(User $user, string $action): void
{
    $key = "quota:{$user->id}:{$action}:" . now()->format('Y-m');
    cache()->increment($key);
}

public function create(User $user): bool
{
    $limits = ['free' => 1, 'pro' => 10, 'creator' => 50, 'enterprise' => -1];
    $tier = $user->subscription?->plan ?? 'free';
    $limit = $limits[$tier] ?? 1;
    if ($limit === -1) {
        return true;
    }
    return $this->withinQuota($user, 'theme_create', $limit);
}

### Multi-Level Policy Resolver

```php
// app/Services/NestedPolicyResolver.php

namespace App\Services;

use App\Models\User;
use Illuminate\Database\Eloquent\Model;

class NestedPolicyResolver
{
    public function canAccess(
        User $user,
        Model $resource,
        string $ability,
    ): bool {
        $ancestors = $this->getAncestorChain($resource);

        foreach ($ancestors as $ancestor) {
            if (! $user->can($ability, $ancestor)) {
                return false;
            }
        }

        return $user->can($ability, $resource);
    }

    protected function getAncestorChain(Model $resource): array
    {
        $ancestors = [];
        $current = $resource;

        while (method_exists($current, 'parent') && $current->parent) {
            $current = $current->parent;
            $ancestors[] = $current;
        }

        return array_reverse($ancestors);
    }

    public function canAccessAnyAncestor(
        User $user,
        Model $resource,
        string $ability,
    ): bool {
        $ancestors = $this->getAncestorChain($resource);

        foreach ($ancestors as $ancestor) {
            if ($user->can($ability, $ancestor)) {
                return true;
            }
        }

        return false;
    }

    public function getClosestAccessibleAncestor(
        User $user,
        Model $resource,
        string $ability,
    ): ?Model {
        $ancestors = $this->getAncestorChain($resource);

        foreach ($ancestors as $ancestor) {
            if ($user->can($ability, $ancestor)) {
                return $ancestor;
            }
        }

        return null;
    }
}

# Appendix A. Policy Implementation Checklist

When implementing a new policy for a GsmUI model, follow this checklist to ensure consistency and completeness.

## Design Phase

- [ ] Identify the model or aggregate root the policy governs
- [ ] Define ownership pattern: `user_id` for single-user ownership, `team_id` for team-scoped, `organization_id` for org-wide
- [ ] List all standard CRUD abilities: `viewAny`, `view`, `create`, `update`, `delete`, `restore`, `forceDelete`
- [ ] List custom abilities specific to the model (e.g., `publish`, `feature`, `archive`, `assign`, `export`)
- [ ] Map each ability to required permissions from the permission system
- [ ] Define status-gating rules: which statuses block `update`, which allow `publish`
- [ ] Document role requirements for each ability (owner, moderator, admin, super_admin)

## Implementation Phase

- [ ] Create policy class in `app/Policies/` (or domain-specific path)
- [ ] Implement `before()` hook for super_admin bypass
- [ ] Implement `viewAny()` with permission check
- [ ] Implement `view()` with ownership check or public status check
- [ ] Implement `create()` with permission check
- [ ] Implement `update()` with ownership + permission + status check
- [ ] Implement `delete()` with ownership + permission + status check
- [ ] Implement `restore()` if soft-delete is used
- [ ] Implement `forceDelete()` with hard-delete guard
- [ ] Implement custom abilities (`publish`, `feature`, `assign`, etc.)
- [ ] Add `after()` hook for audit logging if required
- [ ] Use `HasOwnership` trait for consistent ownership checks
- [ ] Use `HasStatusChecks` trait for status-gating logic

## Testing Phase

- [ ] Test owner can view, update, delete own resources
- [ ] Test non-owner cannot view draft/unpublished resources
- [ ] Test admin can update any resource regardless of ownership
- [ ] Test moderator can publish/feature/unpublish
- [ ] Test status blocks update even for owner (e.g., archived items)
- [ ] Test super_admin bypasses all checks
- [ ] Test custom abilities with and without permissions
- [ ] Test `restore` and `forceDelete` with proper guards
- [ ] Run performance benchmarks (target: < 2ms per check)

## Integration Phase

- [ ] Register in AuthServiceProvider (if manual registration is used)
- [ ] Add `@can` / `@cannot` directives in Blade templates
- [ ] Add `$this->authorize()` calls in Livewire components
- [ ] Add `middleware.can` in route definitions
- [ ] Verify API endpoint authorization returns 403 with proper JSON
- [ ] Test error responses in both web and API contexts

## Policy Change Detection

When policies change, dependent systems (caches, audit logs, tests) must be aware. This service tracks the current policy version.

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\File;

class PolicyVersionTracker
{
    protected const CACHE_KEY = 'policy_version_current';
    protected const PREV_KEY = 'policy_version_previous';

    public function getCurrentVersion(): string
    {
        return Cache::remember(self::CACHE_KEY, 3600, function () {
            $policies = glob(app_path('Policies/*.php'));
            $hash = md5(implode('', array_map('file_get_contents', $policies)));
            return $hash;
        });
    }

    public function hasChanged(): bool
    {
        $stored = Cache::get(self::PREV_KEY);
        $current = $this->getCurrentVersion();
        return $stored !== null && $stored !== $current;
    }

    public function recordVersion(): void
    {
        $current = $this->getCurrentVersion();
        Cache::put(self::PREV_KEY, $current, 86400 * 30);
        Cache::put(self::CACHE_KEY, $current, 3600);
    }
}

## Policy Migration Service

Use this service when role or permission structures change between releases.

```php
<?php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;

class PolicyMigrationService
{
    public function migrateRolePermissions(string $fromRole, string $toRole): int
    {
        return DB::transaction(function () use ($fromRole, $toRole) {
            $users = User::whereHas('roles', fn ($q) => $q->where('name', $fromRole))->get();

            foreach ($users as $user) {
                $user->removeRole($fromRole);
                $user->assignRole($toRole);
            }

            Log::info("Policy migration: {$fromRole} -> {$toRole}", ['count' => $users->count()]);
            return $users->count();
        });
    }

    public function addPermissionToRole(string $roleName, array $permissions): void
    {
        $role = \App\Models\Role::where('name', $roleName)->first();
        if ($role) {
            $existing = $role->permissions->pluck('name')->toArray();
            $role->syncPermissions(array_unique(array_merge($existing, $permissions)));
        }
    }

    public function removePermissionFromRole(string $roleName, array $permissions): void
    {
        $role = \App\Models\Role::where('name', $roleName)->first();
        if ($role) {
            $remaining = array_diff($role->permissions->pluck('name')->toArray(), $permissions);
            $role->syncPermissions(array_values($remaining));
        }
    }

    public function bulkAssignRole(array $userIds, string $roleName): int
    {
        $count = 0;
        foreach ($userIds as $userId) {
            $user = User::find($userId);
            if ($user && !$user->hasRole($roleName)) {
                $user->assignRole($roleName);
                $count++;
            }
        }
        return $count;
    }
}

    private const WINDOW = 300; // 5 minutes

    public function recordViolation(User $user, string $ability, $model, string $reason): void
    {
        $violation = [
            'user_id' => $user->id,
            'email' => $user->email,
            'ability' => $ability,

            'model_id' => $model->id ?? null,

            'user_agent' => request()->userAgent(),
            'path' => request()->path(),
            'method' => request()->method(),
            'timestamp' => now('UTC')->toISOString(),
        ];

        Log::warning('Policy violation detected', $violation);
        $this->checkForSuspiciousPattern($user, $ability);

            'violation_count' => $count,
            'window_seconds' => self::WINDOW,

                $stats[$policy]['denied_count'] += $data['denied_count'] ?? 0;
            }

                ? round($data['total_ms'] / $data['total_checks'], 2)
                : 0;
            $data['denial_rate'] = $data['total_checks'] > 0

                'has_before' => in_array('before', $methods),
                'has_after' => in_array('after', $methods),
                'standard_methods' => array_intersect($methods, $standardMethods),
                'custom_methods' => array_diff($methods, array_merge($standardMethods, ['before', 'after'])),
                'standard_count' => count(array_intersect($methods, $standardMethods)),
                'custom_count' => count(array_diff($methods, array_merge($standardMethods, ['before', 'after']))),
            ];
        }

        return $report;
    }

    public function getCoveragePercentage(): float
    {
        $report = $this->generate();
        $totalStandard = 0;
        $testedStandard = 0;

        foreach ($report as $policy) {
            $totalStandard += count($policy['standard_methods']);
            $testClass = str_replace('\\Policies\\', '\\Tests\\Feature\\Policies\\', $policy['class']) . 'Test';
            if (class_exists($testClass)) {
                $testMethods = get_class_methods($testClass);
                $testedStandard += count(array_intersect(
                    $testMethods,
                    $policy['standard_methods']
                ));
            }
        }

        return $totalStandard > 0 ? round($testedStandard / $totalStandard * 100, 2) : 0;
    }

    private function getPolicyClasses(): array
    {
        $policies = [];
        $policyPath = app_path('Policies');

        if (!is_dir($policyPath)) {
            return [];
        }

        foreach (glob("{$policyPath}/*.php") as $file) {
            $className = 'App\\Policies\\' . pathinfo($file, PATHINFO_FILENAME);
            if (class_exists($className)) {
                $policies[] = $className;
            }
        }

        return $policies;
    }
}

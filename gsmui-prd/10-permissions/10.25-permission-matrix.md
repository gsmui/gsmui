**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

## Purpose

This document is the **single source of truth** for authorization across the entire GsmUi platform. It provides a complete reference matrix showing every permission and which roles have access. Use this document when implementing policies (see [10.05-policies.md](./10.05-policies.md)), gates (see [10.06-gates.md](./10.06-gates.md)), or debugging authorization issues.

## Legend

| Symbol | Meaning |
|---|---|
| ✅ | Full access |
| Own | Access only to own resources |
| Pending | Can submit for approval |
| Purchased | Must have purchased the resource |
| Any | Access to any resource |
| ❌ | No access |

## Role Hierarchy

```text
Guest           (unauthenticated visitor)
    ↓
User            (registered, email verified)
    ↓
Pro User        (active paid subscription)
    ↓
Creator         (published themes/components/templates)
    ↓
Moderator       (content moderation, review management)
    ↓
Support         (customer support, order management)
    ↓
Editor          (documentation, blog, CMS management)
    ↓
Admin           (full platform administration)
    ↓
Super Admin     (system-level administration, admin management)
```

Higher roles inherit all permissions of lower roles. An Admin automatically has all permissions of Editor, Support, Moderator, Creator, Pro User, and User.

## Permission Matrix Deep Dive

### Understanding Permission Resolution

When a user attempts an action, the permission resolution process follows these steps:

1. **Authentication Check**: Is the user authenticated?
2. **Role Resolution**: What roles does the user have?
3. **Permission Check**: Does the user (or any of their roles) have the required permission?
4. **Policy Evaluation**: Does the policy allow this specific resource/action combination?
5. **Business Rule Enforcement**: Are there additional business constraints?

```php
// Example permission resolution flow
class PermissionResolver
{
    public function resolve(User $user, string $permission, $resource = null): bool
    {
        // Step 1: Authentication
        if (!$user) {
            return false;
        }

        // Step 2: Direct permission check
        if ($user->hasPermissionTo($permission)) {
            // Step 4: Policy check (if resource provided)
            if ($resource) {
                return $user->can(class_basename($resource) . '.' . $this->getAction($permission), $resource);
            }
            return true;
        }

        // Step 3: Role inheritance check
        foreach ($user->roles as $role) {
            if ($role->hasPermissionTo($permission)) {
                return true;
            }
        }

        return false;
    }
}
```

### Permission Scope Definitions

| Scope | Meaning | Implementation |
|-------|---------|----------------|
| ✅ | Full access to all resources of this type | `$user->hasPermissionTo('resource.action')` |
| Own | Access only to resources the user owns | `$resource->user_id === $user->id` |
| Pending | Can submit for approval but cannot publish directly | `$user->can('resource.publish', $resource)` returns true only for draft/pending status |
| Purchased | Must have purchased the resource to access | `Order::where('user_id', $user->id)->where('resource_id', $resource->id)->exists()` |
| Any | Can access any resource (admin override) | `$user->hasAnyRole(['admin', 'super_admin'])` |
| ❌ | No access | Default deny |

### Permission Migration Guide

When permissions change between versions:

```php
// Example: Splitting a permission
public function up(): void
{
    // Create new permissions
    Permission::create(['name' => 'marketplace.browse', 'guard_name' => 'web']);
    Permission::create(['name' => 'marketplace.search', 'guard_name' => 'web']);

    // Migrate users from old permission
    $oldPermission = Permission::where('name', 'marketplace.view')->first();
    $browsePermission = Permission::where('name', 'marketplace.browse')->first();
    $searchPermission = Permission::where('name', 'marketplace.search')->first();

    if ($oldPermission) {
        // Copy role assignments
        foreach ($oldPermission->roles as $role) {
            $role->givePermissionTo([$browsePermission, $searchPermission]);
        }

        // Remove old permission
        $oldPermission->delete();
    }
}

public function down(): void
{
    // Reverse migration
    $browsePermission = Permission::where('name', 'marketplace.browse')->first();
    $searchPermission = Permission::where('name', 'marketplace.search')->first();
    $oldPermission = Permission::create(['name' => 'marketplace.view', 'guard_name' => 'web']);

    if ($browsePermission && $searchPermission) {
        $roles = $browsePermission->roles->merge($searchPermission->roles)->unique();
        foreach ($roles as $role) {
            $role->givePermissionTo($oldPermission);
        }

        $browsePermission->delete();
        $searchPermission->delete();
    }
}
```

### Permission Change Impact Analysis

When adding or modifying permissions, analyze the impact:

```php
<?php

namespace App\Services\Permissions;

class PermissionImpactAnalyzer
{
    public function analyzeChange(string $type, string $permission, array $options = []): array
    {
        return match ($type) {
            'add' => $this->analyzeAddition($permission, $options),
            'remove' => $this->analyzeRemoval($permission, $options),
            'modify' => $this->analyzeModification($permission, $options),
            default => ['error' => 'Unknown change type'],
        };
    }

    protected function analyzeAddition(string $permission, array $options): array
    {
        $affectedRoles = $options['roles'] ?? [];
        $affectedUsers = User::role($affectedRoles)->count();

        return [
            'type' => 'addition',
            'permission' => $permission,
            'affected_roles' => $affectedRoles,
            'affected_users' => $affectedUsers,
            'requires_migration' => false,
            'requires_cache_clear' => true,
            'estimated_impact' => $affectedUsers > 1000 ? 'high' : 'low',
        ];
    }

    protected function analyzeRemoval(string $permission, array $options): array
    {
        $currentHolders = DB::table('model_has_permissions')
            ->join('permissions', 'permissions.id', '=', 'model_has_permissions.permission_id')
            ->where('permissions.name', $permission)
            ->count();

        return [
            'type' => 'removal',
            'permission' => $permission,
            'current_holders' => $currentHolders,
            'requires_migration' => $currentHolders > 0,
            'requires_cache_clear' => true,
            'estimated_impact' => $currentHolders > 100 ? 'high' : 'low',
            'migration_path' => $options['migration_path'] ?? null,
        ];
    }

    protected function analyzeModification(string $permission, array $options): array
    {
        $currentRoles = DB::table('role_has_permissions')
            ->join('permissions', 'permissions.id', '=', 'role_has_permissions.permission_id')
            ->where('permissions.name', $permission)
            ->join('roles', 'roles.id', '=', 'role_has_permissions.role_id')
            ->pluck('roles.name')
            ->toArray();

        return [
            'type' => 'modification',
            'permission' => $permission,
            'current_roles' => $currentRoles,
            'proposed_roles' => $options['roles'] ?? $currentRoles,
            'requires_cache_clear' => true,
            'breaking_change' => $this->isBreakingChange($currentRoles, $options['roles'] ?? []),
        ];
    }

    protected function isBreakingChange(array $current, array $proposed): bool
    {
        $removed = array_diff($current, $proposed);
        return !empty($removed);
    }
}
```

```php
namespace App\Services\Permissions;

class PermissionHealthChecker
{
    public function check(): array
    {
        $issues = [];

        // Check for orphaned permissions
        $orphaned = DB::table('permissions')
            ->whereNotIn('id', function ($query) {
                $query->select('permission_id')->from('role_has_permissions');
            })
            ->get();

        if ($orphaned->isNotEmpty()) {
            $issues[] = [
                'type' => 'orphaned_permissions',
                'severity' => 'warning',
                'count' => $orphaned->count(),
                'message' => "{$orphaned->count()} permissions are not assigned to any role",
            ];
        }

        // Check for roles with no users
        $emptyRoles = Role::whereDoesntHave('users')->get();

        if ($emptyRoles->isNotEmpty()) {
            $issues[] = [
                'type' => 'empty_roles',
                'severity' => 'info',
                'count' => $emptyRoles->count(),
                'roles' => $emptyRoles->pluck('name')->toArray(),
            ];
        }

        // Check for duplicate permissions
        $duplicates = DB::table('permissions')
            ->select('name', DB::raw('COUNT(*) as count'))
            ->groupBy('name')
            ->having('count', '>', 1)
            ->get();

        if ($duplicates->isNotEmpty()) {
            $issues[] = [
                'type' => 'duplicate_permissions',
                'severity' => 'critical',
                'count' => $duplicates->count(),
                'message' => "{$duplicates->count()} duplicate permission names found",
            ];
        }

        return [
            'healthy' => empty($issues) || !collect($issues)->contains('severity', 'critical'),
            'issues' => $issues,
            'checked_at' => now()->toISOString(),
        ];
    }
```

### Permission Cache Strategy

```php
<?php

namespace App\Services\Permissions;

use Illuminate\Support\Facades\Cache;
use App\Models\User;

class PermissionCacheManager
{
    private const PREFIX = 'perm:';
    private const TTL = 300;

    public function getUserPermissions(User $user): array
    {
        $key = self::PREFIX . "user:{$user->id}";

        return Cache::remember($key, self::TTL, function () use ($user) {
            return $user->getAllPermissions()->pluck('name')->toArray();
        });
    }

    public function hasPermission(User $user, string $permission): bool
    {
        $permissions = $this->getUserPermissions($user);
        return in_array($permission, $permissions);
    }

    public function invalidateUser(User $user): void
    {
        Cache::forget(self::PREFIX . "user:{$user->id}");
    }

    public function invalidateRole(string $roleName): void
    {
```

## Permission Conflict Resolution

When multiple permission rules conflict, use this resolution order:

1. **Explicit Deny** — Always takes precedence over allow
2. **Ownership Check** — "Own" scope overrides "All" scope for the resource owner
3. **Role Hierarchy** — Higher role permissions override lower role permissions
4. **Feature Flags** — Feature flag settings can override permission grants
5. **Subscription Status** — Subscription-gated permissions are checked last

### Conflict Resolution Matrix

| Conflict Type | Resolution | Example |
|---------------|------------|---------|
| Deny vs Allow | Deny wins | `users.delete` denied by role vs allowed by feature flag → Denied |
| Own vs Any | Own wins for owner | `themes.update` own vs any → Owner gets own scope |
| Role vs Role | Higher role wins | `admin` vs `user` for `settings.manage` → Admin gets it |
| Feature vs Role | Checked independently | `pro_ui` feature vs `user` role → Both must pass |
| Subscription vs Role | Subscription gates | Premium content requires `is_pro` AND permission |

## Permission Caching Strategy

### Cache Invalidation Rules

| Event | Cache Action | Scope |
|-------|--------------|-------|
| User role changed | Invalidate user cache | Single user |
| Role permissions changed | Invalidate all users with that role | Role-wide |
| Permission created/deleted | Flush all permission caches | Global |
| User assigned to role | Invalidate user cache | Single user |
| User removed from role | Invalidate user cache | Single user |
| Subscription status changed | Invalidate user subscription cache | Single user |

### Cache Key Structure

```text
perm:user:{user_id}          → Array of permission names (TTL: 300s)
perm:roles:{user_id}         → Array of role names (TTL: 300s)
perm:role:{role_name}        → Array of permission names (TTL: 600s)
perm:has:{user_id}:{perm}    → Boolean (TTL: 300s)
perm:all                     → All permission names (TTL: 3600s)
```

### Performance Monitoring

```php
<?php

namespace App\Services\Permissions;

use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Log;

class PermissionPerformanceMonitor
{
    private array $metrics = [];

    public function trackPermissionCheck(string $permission, float $duration, bool $result): void
    {
        $this->metrics[] = [
            'permission' => $permission,
            'duration' => $duration,
            'result' => $result,
            'timestamp' => microtime(true),
        ];

        if ($duration > 50) {
            Log::warning('Slow permission check', [
                'permission' => $permission,
                'duration_ms' => round($duration, 2),
            ]);
        }
    }

    public function getMetrics(): array
    {
        return [
            'total_checks' => count($this->metrics),
            'average_duration' => $this->calculateAverageDuration(),
            'slow_checks' => $this->getSlowChecks(),
            'denial_rate' => $this->calculateDenialRate(),
            'permission_breakdown' => $this->getPermissionBreakdown(),
        ];
    }

    protected function calculateAverageDuration(): float
    {
        if (empty($this->metrics)) return 0;

        $total = array_sum(array_column($this->metrics', 'duration'));
        return $total / count($this->metrics);
    }

    protected function getSlowChecks(): array
    {
        return array_filter($this->metrics, fn($m) => $m['duration'] > 50);
    }

    protected function calculateDenialRate(): float
    {
        if (empty($this->metrics')) return 0;

        $denials = count(array_filter($this->metrics, fn($m) => !$m['result']));
        return ($denials / count($this->metrics)) * 100;
    }
}
```

# 10.21 - Enterprise Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines the **enterprise authorization layer** for GsmUi: organization-scoped permissions, delegated administration, resource sharing across teams, and temporary permission grants. Enterprise permissions extend the base RBAC system defined in [10.02-rbac-architecture.md](./10.02-rbac-architecture.md) with multi-tenant isolation and fine-grained delegation controls.

Enterprise customers operate within an **organization** that owns one or more **teams**. Permissions cascade from organization level to team level to user level. An organization owner can delegate specific administrative capabilities to admins without granting full platform access.

## Enterprise Roles

### Role Hierarchy

```text
Organization Owner
  ├── Organization Admin
  │     ├── Team Owner
  │     │     ├── Team Admin
  │     │     │     └── Team Member
  │     │     └── Team Member
  │     └── Team Member
  └── Organization Member
        └── Team Member
```

### Role Definitions

| Role | Scope | Description | Assignable By |
|---|---|---|---|
| Organization Owner | Organization | Full control over org and all teams | System (creation) |
| Organization Admin | Organization | Manage org settings, teams, and billing | Org Owner |
| Organization Member | Organization | Access to assigned teams | Org Owner, Org Admin |
| Team Owner | Team | Full control within team | Org Owner, Org Admin |
| Team Admin | Team | Manage team members and resources | Team Owner, Org Admin |
| Team Member | Team | Basic team access | Team Owner, Team Admin |

## Delegated Administration

Organization owners can delegate specific permissions to admins without granting full access. Delegated permissions are tracked with expiry dates and audit trails.

### Delegation Model

```php
// app/Models/PermissionDelegation.php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class PermissionDelegation extends Model
{
    protected $fillable = [
        'organization_id',
        'delegated_to_id',
        'delegated_by_id',
        'permission',
        'scope',
        'scope_id',
        'expires_at',
        'revoked_at',
        'reason',
    ];

    protected $casts = [
        'expires_at' => 'datetime',
        'revoked_at' => 'datetime',
    ];

    public function organization(): BelongsTo
    {
        return $this->belongsTo(Organization::class);
    }

    public function delegatedTo(): BelongsTo
    {
        return $this->belongsTo(User::class, 'delegated_to_id');
    }

    public function delegatedBy(): BelongsTo
    {
        return $this->belongsTo(User::class, 'delegated_by_id');
    }

    public function isExpired(): bool
    {
        return $this->expires_at && $this->expires_at->isPast();
    }

    public function isRevoked(): bool
    {
        return $this->revoked_at !== null;
    }

    public function isActive(): bool
    {
        return ! $this->isExpired() && ! $this->isRevoked();
    }
}
```

### Delegation Implementation

```php
// app/Services/DelegationService.php

namespace App\Services;

use App\Models\Organization;
use App\Models\PermissionDelegation;
use App\Models\User;
use Carbon\Carbon;
use Spatie\Permission\Models\Permission;

class DelegationService
{
    public function delegate(
        Organization $organization,
        User $delegatedTo,
        User $delegatedBy,
        string $permission,
        ?string $scope = null,
        ?int $scopeId = null,
        ?Carbon $expiresAt = null,
        ?string $reason = null,
    ): PermissionDelegation {
        // Verify the delegator has the permission
        if (! $delegatedBy->hasPermissionTo($permission)) {
            throw new \InvalidArgumentException(
                "User {$delegatedBy->id} does not have permission to delegate: {$permission}"
            );
        }

        // Verify the delegate is a member of the organization
        if (! $this->isOrganizationMember($organization, $delegatedTo)) {
            throw new \InvalidArgumentException(
                "User {$delegatedTo->id} is not a member of organization {$organization->id}"
            );
        }

        // Create the delegation
        $delegation = PermissionDelegation::create([
            'organization_id' => $organization->id,
            'delegated_to_id' => $delegatedTo->id,
            'delegated_by_id' => $delegatedBy->id,
            'permission' => $permission,
            'scope' => $scope,
            'scope_id' => $scopeId,
            'expires_at' => $expiresAt,
            'reason' => $reason,
        ]);

        // Grant the permission to the user
        $delegatedTo->givePermissionTo($permission);

        // Log the delegation
        activity()
            ->performedOn($organization)
            ->causedBy($delegatedBy)
            ->withProperties([
                'delegated_to' => $delegatedTo->id,
                'permission' => $permission,
                'scope' => $scope,
                'expires_at' => $expiresAt?->toIso8601String(),
            ])
            ->event('permission_delegated')
            ->log('Permission delegated');

        return $delegation;
    }

    public function revoke(PermissionDelegation $delegation, User $revokedBy): void
    {
        $delegation->update(['revoked_at' => now()]);

        // Remove the permission if no other active delegation grants it
        $user = $delegation->delegatedTo;
        $otherDelegations = PermissionDelegation::where('delegated_to_id', $user->id)
            ->where('permission', $delegation->permission)
            ->whereNull('revoked_at')
            ->where('id', '!=', $delegation->id)
            ->get();

        if ($otherDelegations->isEmpty()) {
            $user->revokePermissionTo($delegation->permission);
        }

        activity()
            ->performedOn($delegation->organization)
            ->causedBy($revokedBy)
            ->withProperties([
                'delegation_id' => $delegation->id,
                'permission' => $delegation->permission,
                'delegated_to' => $delegation->delegated_to_id,
            ])
            ->event('permission_delegation_revoked')
            ->log('Permission delegation revoked');
    }

    public function cleanupExpired(): int
    {
        $expired = PermissionDelegation::where('expires_at', '<', now())
            ->whereNull('revoked_at')
            ->get();

        foreach ($expired as $delegation) {
            $this->revoke($delegation, $delegation->delegatedBy);
        }

        return $expired->count();
    }

    protected function isOrganizationMember(Organization $organization, User $user): bool
    {
        return $organization->members()
            ->where('user_id', $user->id)
            ->exists();
    }
}
```

### Delegated Permission Check

```php
// app/Services/EnterprisePermissionResolver.php

namespace App\Services;

use App\Models\User;
use App\Models\Organization;
use App\Models\Team;

class EnterprisePermissionResolver
{
    public function hasPermission(
        User $user,
        string $permission,
        ?Organization $organization = null,
        ?Team $team = null,
    ): bool {
        // 1. Check direct permission
        if ($user->hasPermissionTo($permission)) {
            return true;
        }

        // 2. Check role-based permission
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        // 3. Check organization-level permission
        if ($organization) {
            if ($this->hasOrganizationPermission($user, $organization, $permission)) {
                return true;
            }
        }

        // 4. Check team-level permission
        if ($team) {
            if ($this->hasTeamPermission($user, $team, $permission)) {
                return true;
            }
        }

        // 5. Check delegated permission
        if ($this->hasDelegatedPermission($user, $permission, $organization)) {
            return true;
        }

        return false;
    }

    protected function hasOrganizationPermission(
        User $user,
        Organization $organization,
        string $permission,
    ): bool {
        $membership = $organization->members()
            ->where('user_id', $user->id)
            ->first();

        if (! $membership) {
            return false;
        }

        // Check organization-scoped roles
        return $user->hasPermissionTo($permission);
    }

    protected function hasTeamPermission(
        User $user,
        Team $team,
        string $permission,
    ): bool {
        $membership = $team->members()
            ->where('user_id', $user->id)
            ->first();

        if (! $membership) {
            return false;
        }

        // Set team context and check permission
        app()[\Spatie\Permission\PermissionRegistrar::class]
            ->setPermissionsTeamId($team->id);

        return $user->hasPermissionTo($permission);
    }

    protected function hasDelegatedPermission(
        User $user,
        string $permission,
        ?Organization $organization,
    ): bool {
        $query = \App\Models\PermissionDelegation::where('delegated_to_id', $user->id)
            ->where('permission', $permission)
            ->whereNull('revoked_at')
            ->where(function ($q) {
                $q->whereNull('expires_at')
                    ->orWhere('expires_at', '>', now());
            });

        if ($organization) {
            $query->where('organization_id', $organization->id);
        }

        return $query->exists();
    }
}
```

### Access Levels

| Access Level | Description |
|---|---|
| `read` | View the resource |
| `comment` | View and add comments |
| `edit` | View, comment, and edit |
| `admin` | Full control including sharing |

### Sharing Implementation

```php
// app/Services/ResourceSharingService.php

namespace App\Services;

use App\Models\Team;
use App\Models\TeamResource;
use Illuminate\Database\Eloquent\Model;

class ResourceSharingService
{
    public function share(
        Model $resource,
        Team $targetTeam,
        Team $sourceTeam,
        User $sharedBy,
        string $accessLevel = 'read',
    ): TeamResource {
        // Verify source team has the resource
        if (! $this->teamHasResource($sourceTeam, $resource)) {
            throw new \InvalidArgumentException(
                "Source team {$sourceTeam->id} does not have access to this resource"
            );
        }

        // Verify both teams are in the same organization
        if ($sourceTeam->organization_id !== $targetTeam->organization_id) {
            throw new \InvalidArgumentException(
                'Can only share resources within the same organization'
            );
        }

        // Check if already shared
        $existing = TeamResource::where('team_id', $targetTeam->id)
            ->where('resource_type', get_class($resource))
            ->where('resource_id', $resource->id)
            ->first();

        if ($existing) {
            // Update access level to most permissive
            if ($this->accessLevelRank($accessLevel) > $this->accessLevelRank($existing->access_level)) {
                $existing->update(['access_level' => $accessLevel]);
            }
            return $existing->refresh();
        }

        $teamResource = TeamResource::create([
            'team_id' => $targetTeam->id,
            'resource_type' => get_class($resource),
            'resource_id' => $resource->id,
            'shared_by' => $sharedBy->id,
            'shared_at' => now(),
            'access_level' => $accessLevel,
        ]);

        activity()
            ->performedOn($resource)
            ->causedBy($sharedBy)
            ->withProperties([
                'target_team_id' => $targetTeam->id,
                'source_team_id' => $sourceTeam->id,
                'access_level' => $accessLevel,
            ])
            ->event('resource_shared')
            ->log('Resource shared across teams');

        return $teamResource;
    }

    public function revokeShare(
        Model $resource,
        Team $team,
        User $revokedBy,
    ): bool {
        $deleted = TeamResource::where('team_id', $team->id)
            ->where('resource_type', get_class($resource))
            ->where('resource_id', $resource->id)
            ->delete();

        if ($deleted) {
            activity()
                ->performedOn($resource)
                ->causedBy($revokedBy)
                ->withProperties([
                    'team_id' => $team->id,
                ])
                ->event('resource_share_revoked')
                ->log('Resource share revoked');
        }

        return $deleted > 0;
    }

    public function getResourceAccess(Model $resource, Team $team): ?string
    {
        $share = TeamResource::where('team_id', $team->id)
            ->where('resource_type', get_class($resource))
            ->where('resource_id', $resource->id)
            ->first();

        return $share?->access_level;
    }

    protected function teamHasResource(Team $team, Model $resource): bool
    {
        return TeamResource::where('team_id', $team->id)
            ->where('resource_type', get_class($resource))
            ->where('resource_id', $resource->id)
            ->exists()
            || $resource->team_id === $team->id;
    }

    protected function accessLevelRank(string $level): int
    {
        return match ($level) {
            'read' => 1,
            'comment' => 2,
            'edit' => 3,
            'admin' => 4,
            default => 0,
        };
    }
}
```

### Granting Temporary Permissions

```php
// app/Services/TemporaryPermissionService.php

namespace App\Services;

use App\Models\TemporaryPermission;
use App\Models\User;
use Carbon\Carbon;

class TemporaryPermissionService
{
    public function grant(
        User $user,
        string $permission,
        User $grantedBy,
        Carbon $expiresAt,
        ?string $reason = null,
        ?array $context = null,
    ): TemporaryPermission {
        // Verify the granter has the permission
        if (! $grantedBy->hasPermissionTo($permission)) {
            throw new \InvalidArgumentException(
                "User {$grantedBy->id} cannot grant permission: {$permission}"
            );
        }

        // Check for existing active temporary permission
        $existing = TemporaryPermission::where('user_id', $user->id)
            ->where('permission', $permission)
            ->whereNull('revoked_at')
            ->where('expires_at', '>', now())
            ->first();

        if ($existing) {
            // Extend the existing permission
            if ($expiresAt->gt($existing->expires_at)) {
                $existing->update(['expires_at' => $expiresAt]);
            }
            return $existing->refresh();
        }

        // Create the temporary permission
        $tempPermission = TemporaryPermission::create([
            'user_id' => $user->id,
            'permission' => $permission,
            'granted_by' => $grantedBy->id,
            'expires_at' => $expiresAt,
            'reason' => $reason,
            'context' => $context,
        ]);

        // Grant the permission via Spatie
        $user->givePermissionTo($permission);

        activity()
            ->performedOn($user)
            ->causedBy($grantedBy)
            ->withProperties([
                'permission' => $permission,
                'expires_at' => $expiresAt->toIso8601String(),
                'reason' => $reason,
            ])
            ->event('temporary_permission_granted')
            ->log('Temporary permission granted');

        return $tempPermission;
    }

    public function revoke(TemporaryPermission $tempPermission, User $revokedBy): void
    {
        $tempPermission->update(['revoked_at' => now()]);

        // Check if any other active temporary permission grants the same permission
        $otherGrants = TemporaryPermission::where('user_id', $tempPermission->user_id)
            ->where('permission', $tempPermission->permission)
            ->whereNull('revoked_at')
            ->where('expires_at', '>', now())
            ->where('id', '!=', $tempPermission->id)
            ->exists();

        if (! $otherGrants) {
            $tempPermission->user->revokePermissionTo($tempPermission->permission);
        }

        activity()
            ->performedOn($tempPermission->user)
            ->causedBy($revokedBy)
            ->withProperties([
                'permission' => $tempPermission->permission,
                'temporary_permission_id' => $tempPermission->id,
            ])
            ->event('temporary_permission_revoked')
            ->log('Temporary permission revoked');
    }

    public function cleanupExpired(): int
    {
        $expired = TemporaryPermission::where('expires_at', '<', now())
            ->whereNull('revoked_at')
            ->get();

        foreach ($expired as $tempPermission) {
            $tempPermission->update(['revoked_at' => now()]);

            // Check if any other active grant exists
            $otherGrants = TemporaryPermission::where('user_id', $tempPermission->user_id)
                ->where('permission', $tempPermission->permission)
                ->whereNull('revoked_at')
                ->where('expires_at', '>', now())
                ->where('id', '!=', $tempPermission->id)
                ->exists();

            if (! $otherGrants) {
                $tempPermission->user->revokePermissionTo($tempPermission->permission);
            }
        }

        return $expired->count();
    }

    public function checkAndIncludeTemporary(User $user, string $permission): bool
    {
        // Check standard permission
        if ($user->hasPermissionTo($permission)) {
            return true;
        }

        // Check temporary permission
        return TemporaryPermission::where('user_id', $user->id)
            ->where('permission', $permission)
            ->whereNull('revoked_at')
            ->where('expires_at', '>', now())
            ->exists();
    }
}
```

## Permission Inheritance

Permissions cascade through the organization hierarchy:

```text
Organization level
  └── Team level
        └── User level
```

### Inheritance Rules

1. **Organization permissions apply to all teams** unless overridden at team level
2. **Team permissions are additive** — a user gets the union of org and team permissions
3. **Direct user permissions** override both org and team permissions
4. **Delegated permissions** are additive and scoped to the delegation
5. **Temporary permissions** are additive and time-limited

### Inheritance Implementation

```php
// app/Services/PermissionInheritanceResolver.php

namespace App\Services;

use App\Models\User;
use App\Models\Organization;
use App\Models\Team;

class PermissionInheritanceResolver
{
    public function resolvePermissions(
        User $user,
        ?Organization $organization = null,
        ?Team $team = null,
    ): array {
        $permissions = [];

        // 1. Start with direct user permissions
        $directPermissions = $user->getAllPermissions()->pluck('name')->toArray();
        $permissions = array_merge($permissions, $directPermissions);

        // 2. Add organization-level permissions
        if ($organization) {
            $orgPermissions = $this->getOrganizationPermissions($user, $organization);
            $permissions = array_merge($permissions, $orgPermissions);
        }

        // 3. Add team-level permissions (most specific)
        if ($team) {
            $teamPermissions = $this->getTeamPermissions($user, $team);
            $permissions = array_merge($permissions, $teamPermissions);
        }

        // 4. Add delegated permissions
        $delegatedPermissions = $this->getDelegatedPermissions($user, $organization);
        $permissions = array_merge($permissions, $delegatedPermissions);

        // 5. Add temporary permissions
        $temporaryPermissions = $this->getTemporaryPermissions($user);
        $permissions = array_merge($permissions, $temporaryPermissions);

        // Deduplicate
        return array_unique($permissions);
    }

    protected function getOrganizationPermissions(User $user, Organization $organization): array
    {
        $membership = $organization->members()
            ->where('user_id', $user->id)
            ->first();

        if (! $membership) {
            return [];
        }

        // Get role-based permissions for this organization
        return $user->getAllPermissions()->pluck('name')->toArray();
    }

    protected function getTeamPermissions(User $user, Team $team): array
    {
        $membership = $team->members()
            ->where('user_id', $user->id)
            ->first();

        if (! $membership) {
            return [];
        }

        // Set team context
        app()[\Spatie\Permission\PermissionRegistrar::class]
            ->setPermissionsTeamId($team->id);

        return $user->getAllPermissions()->pluck('name')->toArray();
    }

    protected function getDelegatedPermissions(User $user, ?Organization $organization): array
    {
        $query = \App\Models\PermissionDelegation::where('delegated_to_id', $user->id)
            ->whereNull('revoked_at')
            ->where(function ($q) {
                $q->whereNull('expires_at')
                    ->orWhere('expires_at', '>', now());
            });

        if ($organization) {
            $query->where('organization_id', $organization->id);
        }

        return $query->pluck('permission')->toArray();
    }

    protected function getTemporaryPermissions(User $user): array
    {
        return \App\Models\TemporaryPermission::where('user_id', $user->id)
            ->whereNull('revoked_at')
            ->where('expires_at', '>', now())
            ->pluck('permission')
            ->toArray();
    }
}
```

### SSO Authentication Flow

```text
User attempts login with corporate email
    ↓
GsmUi checks if email domain matches an SSO configuration
    ↓
Redirects to Identity Provider (IdP) SSO URL
    ↓
User authenticates with corporate credentials
    ↓
IdP sends SAML assertion / OIDC token back to GsmUi
    ↓
GsmUi validates the assertion/token
    ↓
Maps attributes (email, name, groups) to GsmUi user
    ↓
If auto_provision_users is true:
    → Create user if not exists
    → Assign default_role
    → Create organization membership
    ↓
Create session and redirect to dashboard
```

### SSO Service Implementation

```php
// app/Services/SsoService.php

namespace App\Services;

use App\Models\SsoConfiguration;
use App\Models\User;
use App\Models\Organization;
use Illuminate\Support\Facades\Http;
use InvalidArgumentException;

class SsoService
{
    public function findConfigurationByEmail(string $email): ?SsoConfiguration
    {
        $domain = strtolower(substr(strrchr($email, '@'), 1));

        return SsoConfiguration::where('is_active', true)
            ->whereJsonContains('allowed_domains', $domain)
            ->first();
    }

    public function handleSamlCallback(
        SsoConfiguration $config,
        array $assertionData,
    ): User {
        $email = $this->extractEmail($config, $assertionData);
        $name = $this->extractName($config, $assertionData);
        $groups = $this->extractGroups($config, $assertionData);

        if (! $email) {
            throw new InvalidArgumentException('Could not extract email from SAML assertion');
        }

        $user = User::where('email', $email)->first();

        if (! $user && $config->auto_provision_users) {
            $user = $this->provisionUser($config, $email, $name);
        }

        if (! $user) {
            throw new InvalidArgumentException('No user found for email: ' . $email);
        }

        $this->syncGroupRoles($config, $user, $groups);

        activity()
            ->performedOn($user)
            ->withProperties([
                'provider' => $config->provider_name,
                'method' => 'saml',
            ])
            ->event('sso_login')
            ->log('SSO login completed');

        return $user;
    }

    public function handleOidcCallback(
        SsoConfiguration $config,
        array $tokenData,
    ): User {
        $email = $tokenData['email'] ?? null;
        $name = $tokenData['name'] ?? $tokenData['preferred_username'] ?? null;

        if (! $email) {
            throw new InvalidArgumentException('No email in OIDC token');
        }

        $user = User::where('email', $email)->first();

        if (! $user && $config->auto_provision_users) {
            $user = $this->provisionUser($config, $email, $name);
        }

        if (! $user) {
            throw new InvalidArgumentException('No user found for email: ' . $email);
        }

        return $user;
    }

    protected function provisionUser(
        SsoConfiguration $config,
        string $email,
        ?string $name,
    ): User {
        $user = User::create([
            'name' => $name ?? $email,
            'email' => $email,
            'email_verified_at' => now(),
            'password' => null,
            'is_sso_user' => true,
        ]);

        // Create organization membership
        $config->organization->members()->create([
            'user_id' => $user->id,
            'role' => $config->default_role ?? 'member',
            'joined_at' => now(),
            'source' => 'sso',
        ]);

        activity()
            ->performedOn($user)
            ->withProperties([
                'organization_id' => $config->organization_id,
                'provider' => $config->provider_name,
            ])
            ->event('sso_user_provisioned')
            ->log('User provisioned via SSO');

        return $user;
    }

    protected function syncGroupRoles(
        SsoConfiguration $config,
        User $user,
        array $groups,
    ): void {
        $mapping = $config->attribute_mapping['group_roles'] ?? [];

        foreach ($mapping as $group => $role) {
            if (in_array($group, $groups)) {
                $user->assignRole($role);
            }
        }
    }

    protected function extractEmail(SsoConfiguration $config, array $data): ?string
    {
        $field = $config->attribute_mapping['email'] ?? 'email';
        return $data[$field] ?? null;
    }

    protected function extractName(SsoConfiguration $config, array $data): ?string
    {
        $field = $config->attribute_mapping['name'] ?? 'name';
        return $data[$field] ?? null;
    }

    protected function extractGroups(SsoConfiguration $config, array $data): array
    {
        $field = $config->attribute_mapping['groups'] ?? 'groups';
        return $data[$field] ?? [];
    }
}
```

### LDAP Sync Service

```php
// app/Services/LdapSyncService.php

namespace App\Services;

use App\Models\LdapConfiguration;
use App\Models\User;
use App\Models\Organization;
use App\Models\LdapSyncLog;
use Illuminate\Support\Facades\Log;

class LdapSyncService
{
    protected LdapConfiguration $config;
    protected array $syncResults = [
        'created' => 0,
        'updated' => 0,
        'deactivated' => 0,
        'errors' => [],
    ];

    public function __construct(protected LdapSyncLog $syncLog) {}

    public function sync(LdapConfiguration $config): LdapSyncLog
    {
        $this->config = $config;
        $this->syncResults = ['created' => 0, 'updated' => 0, 'deactivated' => 0, 'errors' => []];

        $log = LdapSyncLog::create([
            'ldap_configuration_id' => $config->id,
            'organization_id' => $config->organization_id,
            'started_at' => now(),
            'status' => 'running',
        ]);

        try {
            $connection = $this->connect();
            $users = $this->fetchUsers($connection);
            $groups = $this->fetchGroups($connection);

            foreach ($users as $userData) {
                $this->syncUser($userData, $groups);
            }

            $this->deactivateMissingUsers($users);

            $log->update([
                'status' => 'completed',
                'completed_at' => now(),
                'users_synced' => count($users),
                'users_created' => $this->syncResults['created'],
                'users_updated' => $this->syncResults['updated'],
                'users_deactivated' => $this->syncResults['deactivated'],
                'errors' => $this->syncResults['errors'],
            ]);
        } catch (\Exception $e) {
            $log->update([
                'status' => 'failed',
                'completed_at' => now(),
                'error_message' => $e->getMessage(),
            ]);

            Log::error('LDAP sync failed', [
                'config_id' => $config->id,
                'error' => $e->getMessage(),
            ]);
        }

        return $log;
    }

    protected function connect()
    {
        $protocol = $this->config->ssl_enabled ? 'ldaps' : 'ldap';
        $host = "{$protocol}://{$this->config->host}:{$this->config->port}";

        $connection = ldap_connect($host);

        if ($this->config->tls_enabled) {
            ldap_start_tls($connection);
        }

        ldap_set_option($connection, LDAP_OPT_PROTOCOL_VERSION, 3);
        ldap_set_option($connection, LDAP_OPT_REFERRALS, 0);

        $bind = ldap_bind(
            $connection,
            $this->config->bind_dn,
            $this->config->bind_password,
        );

        if (! $bind) {
            throw new \RuntimeException('LDAP bind failed');
        }

        return $connection;
    }

    protected function fetchUsers($connection): array
    {
        $filter = $this->config->user_filter ?? '(objectClass=person)';
        $baseDn = $this->config->base_dn;

        $attributes = [
            $this->config->attribute_mapping['email'] ?? 'mail',
            $this->config->attribute_mapping['name'] ?? 'cn',
            $this->config->attribute_mapping['first_name'] ?? 'givenName',
            $this->config->attribute_mapping['last_name'] ?? 'sn',
            $this->config->attribute_mapping['groups'] ?? 'memberOf',
            $this->config->attribute_mapping['uid'] ?? 'uid',
        ];

        $search = ldap_search($connection, $baseDn, $filter, $attributes);
        $entries = ldap_get_entries($connection, $search);

        $users = [];
        for ($i = 0; $i < $entries['count']; $i++) {
            $entry = $entries[$i];
            $mapping = $this->config->attribute_mapping;

            $users[] = [
                'uid' => $entry[$mapping['uid'] ?? 'uid'][0] ?? null,
                'email' => $entry[$mapping['email'] ?? 'mail'][0] ?? null,
                'name' => $entry[$mapping['name'] ?? 'cn'][0] ?? null,
                'first_name' => $entry[$mapping['first_name'] ?? 'givenName'][0] ?? null,
                'last_name' => $entry[$mapping['last_name'] ?? 'sn'][0] ?? null,
                'groups' => $this->extractLdapGroups(
                    $entry[$mapping['groups'] ?? 'memberOf'] ?? []
                ),
            ];
        }

        return $users;
    }

    protected function fetchGroups($connection): array
    {
        $filter = $this->config->group_filter ?? '(objectClass=group)';
        $groupDn = $this->config->group_dn ?? $this->config->base_dn;

        $search = ldap_search($connection, $groupDn, $filter, ['cn', 'member']);
        $entries = ldap_get_entries($connection, $search);

        $groups = [];
        for ($i = 0; $i < $entries['count']; $i++) {
            $entry = $entries[$i];
            $groups[$entry['cn'][0]] = $entry['member'] ?? [];
        }

        return $groups;
    }

    protected function syncUser(array $ldapUser, array $groups): void
    {
        if (! $ldapUser['email']) {
            $this->syncResults['errors'][] = 'Missing email for LDAP user: ' . ($ldapUser['uid'] ?? 'unknown');
            return;
        }

        $user = User::where('email', $ldapUser['email'])->first();

        if ($user) {
            $user->update([
                'name' => $ldapUser['name'] ?? $user->name,
                'first_name' => $ldapUser['first_name'] ?? $user->first_name,
                'last_name' => $ldapUser['last_name'] ?? $user->last_name,
                'ldap_uid' => $ldapUser['uid'],
                'last_ldap_sync' => now(),
            ]);
            $this->syncResults['updated']++;
        } else {
            $user = User::create([
                'name' => $ldapUser['name'] ?? $ldapUser['email'],
                'email' => $ldapUser['email'],
                'first_name' => $ldapUser['first_name'],
                'last_name' => $ldapUser['last_name'],
                'email_verified_at' => now(),
                'is_ldap_user' => true,
                'ldap_uid' => $ldapUser['uid'],
                'last_ldap_sync' => now(),
            ]);

            $this->config->organization->members()->create([
                'user_id' => $user->id,
                'role' => 'member',
                'joined_at' => now(),
                'source' => 'ldap',
            ]);

            $this->syncResults['created']++;
        }

        // Sync group-based roles
        $this->syncLdapGroupRoles($user, $ldapUser['groups']);
    }

    protected function deactivateMissingUsers(array $currentLdapUsers): void
    {
        $currentEmails = array_column($currentLdapUsers, 'email');

        User::where('is_ldap_user', true)
            ->whereNotIn('email', $currentEmails)
            ->update(['is_active' => false]);

        $this->syncResults['deactivated'] = User::where('is_ldap_user', true)
            ->whereNotIn('email', $currentEmails)
            ->where('is_active', false)
            ->count();
    }

    protected function syncLdapGroupRoles(User $user, array $groups): void
    {
        $roleMapping = $this->config->attribute_mapping['group_roles'] ?? [];

        foreach ($groups as $group) {
            if (isset($roleMapping[$group])) {
                $user->assignRole($roleMapping[$group]);
            }
        }
    }

    protected function extractLdapGroups(array $memberOf): array
    {
        $groups = [];
        foreach ($memberOf as $dn) {
            preg_match('/CN=([^,]+)/', $dn, $matches);
            if (isset($matches[1])) {
                $groups[] = $matches[1];
            }
        }
        return $groups;
    }
}
```

### SCIM Provisioning Service

```php
// app/Services/ScimProvisioningService.php

namespace App\Services;

use App\Models\ScimConfiguration;
use App\Models\User;
use App\Models\Organization;

class ScimProvisioningService
{
    public function provisionUser(
        ScimConfiguration $config,
        array $scimData,
    ): User {
        $email = $scimData['emails'][0]['value'] ?? null;
        $name = $scimData['name']['givenName'] ?? ''
            . ' ' . ($scimData['name']['familyName'] ?? '');

        $user = User::where('email', $email)->first();

        if (! $user) {
            $user = User::create([
                'name' => trim($name),
                'email' => $email,
                'email_verified_at' => now(),
                'is_scim_user' => true,
                'password' => null,
            ]);
        }

        // Add to organization
        $existingMembership = $config->organization->members()
            ->where('user_id', $user->id)
            ->first();

        if (! $existingMembership) {
            $config->organization->members()->create([
                'user_id' => $user->id,
                'role' => 'member',
                'joined_at' => now(),
                'source' => 'scim',
            ]);
        }

        // Sync groups to roles
        if (isset($scimData['groups'])) {
            $this->syncGroupsToRoles($config, $user, $scimData['groups']);
        }

        activity()
            ->performedOn($user)
            ->withProperties([
                'organization_id' => $config->organization_id,
                'method' => 'scim',
            ])
            ->event('scim_user_provisioned')
            ->log('User provisioned via SCIM');

        return $user;
    }

    public function updateUser(
        ScimConfiguration $config,
        User $user,
        array $scimData,
    ): User {
        $name = trim(
            ($scimData['name']['givenName'] ?? '') . ' ' .
            ($scimData['name']['familyName'] ?? '')
        );

        $user->update([
            'name' => $name ?: $user->name,
        ]);

        if (isset($scimData['groups'])) {
            $this->syncGroupsToRoles($config, $user, $scimData['groups']);
        }

        activity()
            ->performedOn($user)
            ->withProperties([
                'organization_id' => $config->organization_id,
                'method' => 'scim',
            ])
            ->event('scim_user_updated')
            ->log('User updated via SCIM');

        return $user->refresh();
    }

    public function deprovisionUser(
        ScimConfiguration $config,
        User $user,
    ): void {
        match ($config->deprovision_action ?? 'deactivate') {
            'deactivate' => $user->update(['is_active' => false]),
            'delete' => $user->delete(),
            default => null,
        };

        $config->organization->members()
            ->where('user_id', $user->id)
            ->update(['removed_at' => now()]);

        activity()
            ->performedOn($user)
            ->withProperties([
                'organization_id' => $config->organization_id,
                'action' => $config->deprovision_action,
                'method' => 'scim',
            ])
            ->event('scim_user_deprovisioned')
            ->log('User deprovisioned via SCIM');
    }

    public function toScimUser(User $user, ScimConfiguration $config): array
    {
        $nameParts = explode(' ', $user->name, 2);

        return [
            'schemas' => ['urn:ietf:params:scim:schemas:core:2.0:User'],
            'id' => (string) $user->id,
            'externalId' => (string) $user->id,
            'userName' => $user->email,
            'name' => [
                'givenName' => $nameParts[0] ?? '',
                'familyName' => $nameParts[1] ?? '',
            ],
            'emails' => [
                ['value' => $user->email, 'primary' => true],
            ],
            'active' => $user->is_active ?? true,
            'groups' => $user->roles->map(fn ($role) => [
                'value' => (string) $role->id,
                '$ref' => route('api.scim.groups.show', $role->id),
                'display' => $role->name,
            ])->toArray(),
        ];
    }

    public function toScimGroup($role, ScimConfiguration $config): array
    {
        return [
            'schemas' => ['urn:ietf:params:scim:schemas:core:2.0:Group'],
            'id' => (string) $role->id,
            'displayName' => $role->name,
            'members' => $role->users->map(fn ($user) => [
                'value' => (string) $user->id,
                '$ref' => route('api.scim.users.show', $user->id),
                'display' => $user->name,
            ])->toArray(),
        ];
    }

    protected function syncGroupsToRoles(
        ScimConfiguration $config,
        User $user,
        array $groups,
    ): void {
        $roleMapping = $config->schema_extensions['group_role_mapping'] ?? [];

        foreach ($groups as $group) {
            $groupName = $group['display'] ?? $group['value'] ?? null;

            if ($groupName && isset($roleMapping[$groupName])) {
                $user->assignRole($roleMapping[$groupName]);
            }
        }
    }
}
```

```php
namespace App\Services;

use App\Models\RoleTemplate;
use App\Models\Role;
use App\Models\DynamicPermission;
use App\Models\User;
use App\Models\Organization;
use InvalidArgumentException;

class RoleBuilderService
{
    public function createTemplate(

        string $description,
        array $permissionNames,
        ?User $createdBy = null,
        ?Organization $organization = null,
        string $category = 'custom',
    ): RoleTemplate {
        $template = RoleTemplate::create([
            'name' => $name,

            'category' => $category,

                ->causedBy($createdBy)

                ->log('Role template created');
        }

        return $template->load(['permissions', 'staticPermissions']);
    }

    public function applyTemplate(
        RoleTemplate $template,
        User $appliedBy,
    ): Role {
        $roleName = strtolower(str_replace(' ', '_', $template->name));

        $role = Role::create([
            'name' => $roleName,
            'description' => $template->description,
            'organization_id' => $template->organization_id,
            'is_system' => false,
        ]);

        // Grant dynamic permissions
        foreach ($template->permissions as $permission) {
            $role->givePermissionTo($permission);
        }

        // Grant static permissions
        foreach ($template->staticPermissions as $permission) {
            $role->givePermissionTo($permission->name);
        }

        $template->derivedRoles()->attach($role->id);

        activity()
            ->performedOn($role)
            ->causedBy($appliedBy)
            ->withProperties([
                'template_id' => $template->id,
                'template_name' => $template->name,
            ])
            ->event('role_created_from_template')
            ->log('Role created from template');

        return $role;
    }

    public function syncPermissionsToTemplate(
        RoleTemplate $template,
        array $permissionNames,
    ): RoleTemplate {
        $dynamicIds = [];
        $staticIds = [];

        foreach ($permissionNames as $name) {
            $dynamic = DynamicPermission::where('name', $name)->first();
            if ($dynamic) {
                $dynamicIds[] = $dynamic->id;
                continue;
            }

            $static = \Spatie\Permission\Models\Permission::where('name', $name)->first();
            if ($static) {
                $staticIds[] = $static->id;
                continue;
            }
        }

        $template->permissions()->sync($dynamicIds);
        $template->staticPermissions()->sync($staticIds);

        return $template->load(['permissions', 'staticPermissions']);
    }

    public function getTemplateSuggestions(
        Organization $organization,
        User $user,
    ): array {
        $existingRoles = $user->roles->pluck('name')->toArray();
        $existingPermissions = $user->getAllPermissions()->pluck('name')->toArray();

        $templates = RoleTemplate::where(function ($q) use ($organization) {
            $q->where('organization_id', $organization->id)
                ->orWhere('is_public', true);
        })->get();

        return $templates->map(function ($template) use ($existingPermissions) {
            $templatePermissions = $template->permissions->pluck('name')
                ->merge($template->staticPermissions->pluck('name'))
                ->toArray();

            $overlap = count(array_intersect($existingPermissions, $templatePermissions));
            $total = count($templatePermissions);

            return [
                'template' => $template,
                'overlap_percentage' => $total > 0 ? round(($overlap / $total) * 100) : 0,
                'missing_permissions' => array_diff($templatePermissions, $existingPermissions),
            ];
        })->sortByDesc('overlap_percentage')->values()->toArray();
    }
}
```

## Extended Permission Inheritance

Beyond the basic hierarchy described earlier, enterprise permission inheritance supports complex scenarios including cross-team inheritance, conditional inheritance, and permission conflict resolution.

### Conditional Inheritance Rules

```php
// app/Services/ConditionalInheritanceResolver.php

namespace App\Services;

use App\Models\User;
use App\Models\Organization;
use App\Models\Team;

class ConditionalInheritanceResolver
{
    /**
     * Resolve permissions with conditional rules.
     *
     * Conditions can be:
     * - Time-based: permissions active during specific hours/days
     * - IP-based: permissions restricted to certain IP ranges
     * - Location-based: permissions restricted to geographic locations
     * - Context-based: permissions active only in specific contexts
     */
    public function resolveWithConditions(
        User $user,
        ?Organization $organization = null,
        ?Team $team = null,
        ?array $context = null,
    ): array {
        $basePermissions = $this->resolveBasePermissions($user, $organization, $team);

        if (! $context) {
            return $basePermissions;
        }

        $conditionalPermissions = $this->getConditionalPermissions($user, $organization);
        $allowed = [];

        foreach ($conditionalPermissions as $permission) {
            if ($this->conditionsMet($permission, $context)) {
                $allowed[] = $permission['name'];
            }
        }

        return array_unique(array_merge($basePermissions, $allowed));
    }

    protected function resolveBasePermissions(
        User $user,
        ?Organization $organization,
        ?Team $team,
    ): array {
        $permissions = $user->getAllPermissions()->pluck('name')->toArray();

        if ($team) {
            app()->make(\Spatie\Permission\PermissionRegistrar::class)
                ->setPermissionsTeamId($team->id);
            $permissions = array_merge(
                $permissions,
                $user->getAllPermissions()->pluck('name')->toArray()
            );
        }

        return array_unique($permissions);
    }

    protected function getConditionalPermissions(
        User $user,
        ?Organization $organization,
    ): array {
        return \App\Models\ConditionalPermission::where('user_id', $user->id)
            ->when($organization, fn ($q) => $q->where('organization_id', $organization->id))
            ->where('is_active', true)
            ->where(function ($q) {
                $q->whereNull('expires_at')
                    ->orWhere('expires_at', '>', now());
            })
            ->get()
            ->toArray();
    }

    protected function conditionsMet(array $permission, array $context): bool
    {
        $conditions = $permission['conditions'] ?? [];

        foreach ($conditions as $type => $value) {
            switch ($type) {
                case 'time_range':
                    if (! $this->checkTimeRange($value)) {
                        return false;
                    }
                    break;
                case 'ip_whitelist':
                    if (! $this->checkIpWhitelist($value, $context['ip'] ?? null)) {
                        return false;
                    }
                    break;
                case 'required_headers':
                    if (! $this->checkRequiredHeaders($value, $context['headers'] ?? [])) {
                        return false;
                    }
                    break;
            }
        }

        return true;
    }

    protected function checkTimeRange(array $range): bool
    {
        $now = now();
        $start = $range['start'] ?? null;
        $end = $range['end'] ?? null;
        $days = $range['days'] ?? null;

        if ($days && ! in_array($now->isoDayOfWeek, $days)) {
            return false;
        }

        if ($start && $now->lt(Carbon::parse($start))) {
            return false;
        }

        if ($end && $now->gt(Carbon::parse($end))) {
            return false;
        }

        return true;
    }

    protected function checkIpWhitelist(array $ips, ?string $currentIp): bool
    {
        if (! $currentIp) {
            return false;
        }

        foreach ($ips as $allowedIp) {
            if (str_contains($allowedIp, '/')) {
                // CIDR notation
                if ($this->ipInCidr($currentIp, $allowedIp)) {
                    return true;
                }
            } elseif ($currentIp === $allowedIp) {
                return true;
            }
        }

        return false;
    }

    protected function checkRequiredHeaders(array $required, array $actual): bool
    {
        foreach ($required as $key => $value) {
            if (! isset($actual[$key]) || $actual[$key] !== $value) {
                return false;
            }
        }
        return true;
    }

    protected function ipInCidr(string $ip, string $cidr): bool
    {
        [$subnet, $mask] = explode('/', $cidr);
        return (ip2long($ip) & ~((1 << (32 - $mask)) - 1)) === ip2long($subnet);
    }
}
```

### Permission Conflict Resolution

```php
// app/Services/PermissionConflictResolver.php

namespace App\Services;

use App\Models\User;

class PermissionConflictResolver
{
    /**
     * Resolve conflicts when the same permission is granted through multiple paths
     * with different constraints or conditions.
     */
    public function resolveConflicts(array $permissionSources): array
    {
        $grouped = [];

        foreach ($permissionSources as $source) {
            $name = $source['permission'];
            $grouped[$name][] = $source;
        }

        $resolved = [];

        foreach ($grouped as $permissionName => $sources) {
            if (count($sources) === 1) {
                $resolved[$permissionName] = $sources[0];
                continue;
            }

            // Most permissive wins
            $resolved[$permissionName] = $this->mostPermissive($sources);
        }

        return $resolved;
    }

    protected function mostPermissive(array $sources): array
    {
        return collect($sources)
            ->sortByDesc(function ($source) {
                return match ($source['source_type'] ?? 'direct') {
                    'super_admin' => 100,
                    'direct' => 90,
                    'delegation' => 80,
                    'role' => 70,
                    'team' => 60,
                    'organization' => 50,
                    'conditional' => 40,
                    'temporary' => 30,
                    default => 0,
                };
            })
            ->first();
    }
}
```

### Audit Chain Service

```php
// app/Services/AuditChainService.php

namespace App\Services;

use App\Models\TamperProofAuditLog;
use App\Models\Organization;
use Spatie\Activitylog\Models\Activity;

class AuditChainService
{
    public function appendEntry(
        Organization $organization,
        Activity $activity,
    ): TamperProofAuditLog {
        $lastEntry = TamperProofAuditLog::where('organization_id', $organization->id)
            ->latest('sequence_number')
            ->first();

        $sequenceNumber = $lastEntry ? $lastEntry->sequence_number + 1 : 1;
        $previousHash = $lastEntry?->current_hash ?? '0';

        $blockData = [
            'activity_id' => $activity->id,
            'event' => $activity->event,
            'description' => $activity->description,
            'causer_id' => $activity->causer_id,
            'subject_type' => $activity->subject_type,
            'subject_id' => $activity->subject_id,
            'properties' => $activity->properties->toArray(),
            'created_at' => $activity->created_at->toIso8601String(),
        ];

        $currentHash = hash('sha256', json_encode([
            $previousHash,
            $activity->id,
            $sequenceNumber,
            json_encode($blockData),
        ]));

        return TamperProofAuditLog::create([
            'audit_entry_id' => $activity->id,
            'organization_id' => $organization->id,
            'previous_hash' => $previousHash,
            'current_hash' => $currentHash,
            'checksum' => hash('crc32b', $currentHash),
            'sequence_number' => $sequenceNumber,
            'block_data' => $blockData,
        ]);
    }

    public function verifyChain(Organization $organization): array
    {
        $entries = TamperProofAuditLog::where('organization_id', $organization->id)
            ->orderBy('sequence_number')
            ->get();

        $broken = [];
        $previousHash = null;

        foreach ($entries as $entry) {
            if ($previousHash && $entry->previous_hash !== $previousHash) {
                $broken[] = [
                    'sequence' => $entry->sequence_number,
                    'expected_previous' => $previousHash,
                    'actual_previous' => $entry->previous_hash,
                ];
            }

            if (! $entry->verifyIntegrity()) {
                $broken[] = [
                    'sequence' => $entry->sequence_number,
                    'error' => 'hash_mismatch',
                ];
            }

            $previousHash = $entry->current_hash;
        }

        return [
            'total_entries' => $entries->count(),
            'is_valid' => empty($broken),
            'broken_entries' => $broken,
        ];
    }

    public function getForensicReport(
        Organization $organization,
        \Carbon\Carbon $start,
        \Carbon\Carbon $end,
    ): array {
        $entries = TamperProofAuditLog::where('organization_id', $organization->id)
            ->whereHas('auditEntry', function ($q) use ($start, $end) {
                $q->whereBetween('created_at', [$start, $end]);
            })
            ->with('auditEntry')
            ->orderBy('sequence_number')
            ->get();

        $chainValid = $this->verifyChain($organization);

        return [
            'period' => [
                'start' => $start->toIso8601String(),
                'end' => $end->toIso8601String(),
            ],
            'total_entries' => $entries->count(),
            'chain_integrity' => $chainValid,
            'entries' => $entries->map(fn ($entry) => [
                'sequence' => $entry->sequence_number,
                'event' => $entry->auditEntry?->event,
                'description' => $entry->auditEntry?->description,
                'hash' => $entry->current_hash,
                'verified' => $entry->verifyIntegrity(),
            ])->toArray(),
        ];
    }
```

```php
// app/Services/ComplianceService.php

namespace App\Services;

use App\Models\ComplianceConfiguration;
use App\Models\Organization;
use App\Models\OrganizationMember;

class ComplianceService
{
    public function checkCompliance(
        Organization $organization,
        string $framework,
    ): array {
        $config = ComplianceConfiguration::where('organization_id', $organization->id)
            ->where('framework', $framework)
            ->where('is_active', true)
            ->first();

        if (! $config) {
            return ['status' => 'not_configured'];
        }

        return match ($framework) {
            'soc2' => $this->checkSoc2($organization, $config),
            'gdpr' => $this->checkGdpr($organization, $config),
            'hipaa' => $this->checkHipaa($organization, $config),
            'iso27001' => $this->checkIso27001($organization, $config),
            default => ['status' => 'unknown_framework'],
        };
    }

    protected function checkSoc2(
        Organization $organization,
        ComplianceConfiguration $config,
    ): array {
        $issues = [];

        // Check audit logging is enabled
        if (! $this->isAuditLoggingEnabled($organization)) {
            $issues[] = [
                'control' => 'CC7.2',
                'description' => 'Audit logging must be enabled',
                'severity' => 'high',
            ];
        }

        // Check MFA is enforced
        if (! $this->isMfaEnforced($organization)) {
            $issues[] = [
                'control' => 'CC6.1',
                'description' => 'Multi-factor authentication must be enforced',
                'severity' => 'high',
            ];
        }

        // Check access reviews are current
        if (! $this->accessReviewsCurrent($organization)) {
            $issues[] = [
                'control' => 'CC6.3',
                'description' => 'Access reviews must be conducted quarterly',
                'severity' => 'medium',
            ];
        }

        // Check separation of duties
        if (! $this->separationOfDuties($organization)) {
            $issues[] = [
                'control' => 'CC5.2',
                'description' => 'Separation of duties must be enforced',
                'severity' => 'medium',
            ];
        }

        // Check session management
        if (! $this->sessionManagementCompliant($organization)) {
            $issues[] = [
                'control' => 'CC6.1',
                'description' => 'Session timeout must be configured',
                'severity' => 'low',
            ];
        }

        return [
            'framework' => 'soc2',
            'status' => empty($issues) ? 'compliant' : 'non_compliant',
            'checked_at' => now()->toIso8601String(),
            'issues' => $issues,
            'controls_checked' => 5,
            'controls_passed' => 5 - count($issues),
        ];
    }

    protected function checkGdpr(
        Organization $organization,
        ComplianceConfiguration $config,
    ): array {
        $issues = [];

        // Check data retention policies
        if (! $this->dataRetentionConfigured($organization)) {
            $issues[] = [
                'article' => 'Article 5(1)(e)',
                'description' => 'Data retention policies must be configured',
                'severity' => 'high',
            ];
        }

        // Check consent tracking
        if (! $this->consentTrackingEnabled($organization)) {
            $issues[] = [
                'article' => 'Article 7',
                'description' => 'Consent tracking must be enabled',
                'severity' => 'high',
            ];
        }

        // Check right to erasure capability
        if (! $this->rightToErasureEnabled($organization)) {
            $issues[] = [
                'article' => 'Article 17',
                'description' => 'Right to erasure (data deletion) must be supported',
                'severity' => 'high',
            ];
        }

        // Check data processing agreements
        if (! $this->dpasConfigured($organization)) {
            $issues[] = [
                'article' => 'Article 28',
                'description' => 'Data processing agreements must be in place',
                'severity' => 'medium',
            ];
        }

        return [
            'framework' => 'gdpr',
            'status' => empty($issues) ? 'compliant' : 'non_compliant',
            'checked_at' => now()->toIso8601String(),
            'issues' => $issues,
        ];
    }

    protected function checkHipaa(
        Organization $organization,
        ComplianceConfiguration $config,
    ): array {
        $issues = [];

        // Check encryption at rest
        if (! $this->encryptionAtRestEnabled($organization)) {
            $issues[] = [
                'rule' => '§164.312(a)(2)(iv)',
                'description' => 'Encryption at rest is required for PHI',
                'severity' => 'critical',
            ];
        }

        // Check access controls
        if (! $this->accessControlsCompliant($organization)) {
            $issues[] = [
                'rule' => '§164.312(a)(1)',
                'description' => 'Access controls must follow least privilege principle',
                'severity' => 'high',
            ];
        }

        // Check audit controls
        if (! $this->auditControlsEnabled($organization)) {
            $issues[] = [
                'rule' => '§164.312(b)',
                'description' => 'Audit controls must record access to PHI',
                'severity' => 'high',
            ];
        }

        return [
            'framework' => 'hipaa',
            'status' => empty($issues) ? 'compliant' : 'non_compliant',

    protected function checkIso27001(
```

### ABAC Evaluation Engine

```php
// app/Services/AbacEvaluationEngine.php

namespace App\Services;

use App\Models\AbacPolicy;
use App\Models\User;

class AbacEvaluationEngine
{
    public function evaluate(
        User $user,
        string $resourceType,
        string $action,
        ?array $resourceAttributes = null,
        ?array $environmentAttributes = null,
    ): bool {
        $policies = AbacPolicy::where('organization_id', $user->current_organization_id)
            ->where('resource_type', $resourceType)
            ->where('action', $action)
            ->where('is_active', true)
            ->orderByDesc('priority')
            ->get();

        foreach ($policies as $policy) {
            $matches = $this->evaluatePolicy(
                $policy,
                $user,
                $resourceAttributes ?? [],
                $environmentAttributes ?? [],
            );

            if ($matches) {
                return $policy->effect === 'allow';
            }
        }

        return false;
    }

    protected function evaluatePolicy(
        AbacPolicy $policy,
        User $user,
        array $resourceAttributes,
        array $environmentAttributes,
    ): bool {
        $conditions = $policy->conditions;

        foreach ($conditions as $condition) {
            if (! $this->evaluateCondition($condition, $user, $resourceAttributes, $environmentAttributes)) {
                return false;
            }
        }

        return true;
    }

    protected function evaluateCondition(
        array $condition,
        User $user,
        array $resourceAttributes,
        array $environmentAttributes,
    ): bool {
        $attributeType = $condition['type']; // user, resource, environment
        $attributeKey = $condition['attribute'];
        $operator = $condition['operator'];
        $expectedValue = $condition['value'];

        $actualValue = match ($attributeType) {
            'user' => $user->{$attributeKey} ?? $user->getAttributeValue($attributeKey),
            'resource' => $resourceAttributes[$attributeKey] ?? null,
            'environment' => $environmentAttributes[$attributeKey] ?? null,
            default => null,
        };

        return match ($operator) {
            'equals' => $actualValue == $expectedValue,
            'not_equals' => $actualValue != $expectedValue,
            'in' => in_array($actualValue, (array) $expectedValue),
            'not_in' => ! in_array($actualValue, (array) $expectedValue),
            'gt' => $actualValue > $expectedValue,
            'gte' => $actualValue >= $expectedValue,
            'lt' => $actualValue < $expectedValue,
            'lte' => $actualValue <= $expectedValue,
            'contains' => str_contains((string) $actualValue, (string) $expectedValue),
            'starts_with' => str_starts_with((string) $actualValue, (string) $expectedValue),
            'regex' => preg_match((string) $expectedValue, (string) $actualValue) > 0,
            default => false,
        };
    }
}
```

### Risk-Based Authentication

```php
// app/Services/RiskBasedAuthService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Http\Request;

class RiskBasedAuthService
{
    public const RISK_LEVELS = [
        'low' => ['actions' => 'allow', 'mfa' => false],
        'medium' => ['actions' => 'allow', 'mfa' => true],
        'high' => ['actions' => 'require_approval', 'mfa' => true],
        'critical' => ['actions' => 'block', 'mfa' => true],
    ];

    public function assessRisk(Request $request, User $user): array
    {
        $riskFactors = [];
        $score = 0;

        // IP reputation check
        $ipRisk = $this->checkIpReputation($request->ip());
        $score += $ipRisk['score'];
        $riskFactors[] = $ipRisk;

        // Geolocation check
        $geoRisk = $this->checkGeolocation($request->ip(), $user);
        $score += $geoRisk['score'];
        $riskFactors[] = $geoRisk;

        // Device fingerprint check
        $deviceRisk = $this->checkDeviceFingerprint($request, $user);
        $score += $deviceRisk['score'];
        $riskFactors[] = $deviceRisk;

        // Time-based risk
        $timeRisk = $this->checkTimeRisk($user);
        $score += $timeRisk['score'];
        $riskFactors[] = $timeRisk;

        // Velocity check (too many actions in short time)
        $velocityRisk = $this->checkVelocity($user);
        $score += $velocityRisk['score'];
        $riskFactors[] = $velocityRisk;

        $riskLevel = match (true) {
            $score >= 80 => 'critical',
            $score >= 60 => 'high',
            $score >= 30 => 'medium',
            default => 'low',
        };

        return [
            'risk_level' => $riskLevel,
            'score' => $score,
            'factors' => $riskFactors,
            'recommendation' => self::RISK_LEVELS[$riskLevel],
        ];
    }

    protected function checkIpReputation(?string $ip): array
    {
        if (! $ip) {
            return ['factor' => 'ip_reputation', 'score' => 20, 'detail' => 'unknown_ip'];
        }

        // Check if IP is in known bad ranges
        $isTorExit = $this->isTorExitNode($ip);
        $isVpn = $this->isKnownVpn($ip);
        $isDatacenter = $this->isDatacenter($ip);

        $score = 0;
        if ($isTorExit) {
            $score += 40;
        }
        if ($isVpn) {
            $score += 15;
        }
        if ($isDatacenter) {
            $score += 20;
        }

        return [
            'factor' => 'ip_reputation',
            'score' => $score,
            'detail' => [
                'tor' => $isTorExit,
                'vpn' => $isVpn,
                'datacenter' => $isDatacenter,
            ],
        ];
    }

    protected function checkGeolocation(?string $ip, User $user): array
    {
        $lastLoginCountry = $user->settings['last_login_country'] ?? null;
        $currentCountry = $this->getCountryFromIp($ip);

        if ($lastLoginCountry && $currentCountry && $lastLoginCountry !== $currentCountry) {
            $timeSinceLastLogin = $user->last_login_at
                ? now()->diffInHours($user->last_login_at)
                : 999;

            // Impossible travel detection
            if ($timeSinceLastLogin < 2) {
                return [
                    'factor' => 'geolocation',
                    'score' => 50,
                    'detail' => 'impossible_travel',
                ];
            }

            return [
                'factor' => 'geolocation',
                'score' => 25,
                'detail' => 'country_changed',
            ];
        }

        return ['factor' => 'geolocation', 'score' => 0, 'detail' => 'normal'];
    }

    protected function checkDeviceFingerprint(Request $request, User $user): array
    {
        $currentFingerprint = $this->generateFingerprint($request);
        $knownDevices = $user->settings['known_devices'] ?? [];

        if (! in_array($currentFingerprint, $knownDevices)) {
            return [
                'factor' => 'device',
                'score' => 20,
                'detail' => 'unknown_device',
            ];
        }

        return ['factor' => 'device', 'score' => 0, 'detail' => 'known_device'];
    }

    protected function checkTimeRisk(User $user): array
    {
        $hour = now()->hour;

        // Unusual login hours (midnight to 5am)
        if ($hour >= 0 && $hour < 5) {
            $usualHours = $user->settings['usual_login_hours'] ?? [8, 20];

            if ($hour < ($usualHours[0] ?? 8) || $hour > ($usualHours[1] ?? 20)) {
                return [
                    'factor' => 'time',
                    'score' => 15,
                    'detail' => 'unusual_hour',
                ];
            }
        }

        return ['factor' => 'time', 'score' => 0, 'detail' => 'normal_hour'];
    }

    protected function checkVelocity(User $user): array
    {
        $recentActions = cache()->get("user_actions:{$user->id}", []);

        if (count($recentActions) > 50) {
            return [
                'factor' => 'velocity',
                'score' => 30,
                'detail' => 'high_velocity',
            ];
        }

        return ['factor' => 'velocity', 'score' => 0, 'detail' => 'normal_velocity'];
    }

    protected function isTorExitNode(string $ip): bool
    {
        return cache()->remember("tor_check:{$ip}", 3600, function () use ($ip) {
            // Check against Tor exit node list
            return false;
        });
    }

    protected function isKnownVpn(string $ip): bool
    {
        return cache()->remember("vpn_check:{$ip}", 3600, function () use ($ip) {
            return false;
        });
    }

    protected function isDatacenter(string $ip): bool
    {
        return cache()->remember("dc_check:{$ip}", 3600, function () use ($ip) {
            return false;
        });
    }

    protected function getCountryFromIp(?string $ip): ?string
    {
        return cache()->remember("geo:{$ip}", 86400, function () use ($ip) {
            return null;
        });
    }

    protected function generateFingerprint(Request $request): string
    {
        $ua = $request->userAgent();
        $accept = $request->header('Accept-Language');
        $encoding = $request->header('Accept-Encoding');

        return hash('sha256', "{$ua}|{$accept}|{$encoding}");
    }
}
```

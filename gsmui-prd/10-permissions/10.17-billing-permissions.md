# 10.17 — Billing Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines authorization rules for the **Billing domain**. Billing permissions govern subscription management, invoice access, payment processing, refund handling, and coupon management. Billing authorization is tightly coupled with role assignment — subscription status directly controls Pro User role assignment and feature access.

Billing is one of the most security-sensitive domains. Unauthorized access to billing data, payment methods, or refund capabilities can cause financial loss and legal liability. Every billing action is logged, and sensitive operations require elevated permissions.

## Scope

Billing permissions govern:

- Viewing own billing information
- Managing subscription settings
- Viewing/downloading invoices
- Exporting invoice data
- Processing refunds
- Managing coupon codes
- Managing all subscriptions (admin)
- Accessing billing analytics (admin)

## Permission Definitions

| Permission | Description | User | Pro User | Creator | Support | Admin | Super Admin |
|---|---|---|---|---|---|---|---|
| `billing.view` | View own billing info | ✅ | ✅ | ✅ | ❌ | ✅ | ✅ |
| `billing.manage` | Manage billing settings | ❌ | ✅ (own) | ✅ (own) | ❌ | ✅ | ✅ |
| `billing.view_all` | View all users' billing | ❌ | ❌ | ❌ | ✅ | ✅ | ✅ |

## Subscription Authorization Flow

```text
User subscribes
    ↓
Check billing.manage permission
    ↓
Create subscription via Stripe
    ↓
Webhook: subscription.created
    ↓
Assign Pro User role
    ↓
Activate premium features
    ↓
Log role assignment (audit trail)
```

### Subscription Lifecycle

| Event | Role Change | Feature Impact |
|---|---|---|
| Subscription created | Assign `pro_user` | Full access to premium features |
| Subscription renewed | No change | Continued access |
| Subscription past_due | No change (grace period) | Warning banner shown |
| Subscription cancelled | No change until period end | Countdown shown |
| Subscription expired | Remove `pro_user` | Revert to User permissions |
| Subscription refunded | Remove `pro_user` | Revert + audit log |

### Subscription Policy

```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\Subscription;
use Illuminate\Auth\Access\HandlesAuthorization;

class SubscriptionPolicy
{
    use HandlesAuthorization;

    public function view(User $user, Subscription $subscription): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        if ($user->hasRole('support')) {
            return true; // Support can view for ticket resolution
        }

        return $user->id === $subscription->user_id;
    }

    public function update(User $user, Subscription $subscription): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $subscription->user_id
            && $subscription->is_active;
    }

    public function cancel(User $user, Subscription $subscription): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $subscription->user_id
            && $subscription->is_active
            && ! $subscription->is_cancelled;
    }

    public function forceCancel(User $user, Subscription $subscription): bool
    {
        return $user->hasRole('admin');
    }
}
```

## Refund Authorization

Refund authorization follows a tiered approval model:

```text
Support requests refund
    ↓
Check: billing.refund permission
    ↓
Check: Refund amount
    ↓
≤ $50 → Auto-approve → Process refund
    ↓
> $50 → Queue for Admin approval
    ↓
Admin reviews → Approve/Deny
    ↓
Process refund (if approved)
    ↓
Notify Creator of refund
    ↓
Log refund in audit trail
```

### Refund Policy

```php
class RefundPolicy
{
    public function create(User $user): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->hasRole('support');
    }

    public function approve(User $user, Refund $refund): bool
    {
        if ($refund->amount > 50_00) { // $50.00 in cents
            return $user->hasRole(['admin', 'super_admin']);
        }

        // Support can approve their own refunds under $50
        return $user->hasRole('support')
            && $refund->requested_by === $user->id;
    }

    public function process(User $user, Refund $refund): bool
    {
        return $refund->is_approved
            && $user->hasRole(['admin', 'super_admin']);
    }
}
```

### Refund Limits

| Role | Max Refund (Auto-Approve) | Approval Required |
|---|---|---|
| Support | $50 | Over $50 requires Admin |
| Admin | Unlimited | None |
| Super Admin | Unlimited | None |

## Role Assignment via Billing Webhooks

```php
class SubscriptionWebhookHandler
{
    public function handleCreated(Subscription $subscription): void
    {
        $user = $subscription->user;
        $user->assignRole('pro_user');

        activity()
            ->performedOn($user)
            ->withProperties([
                'subscription_id' => $subscription->id,
                'plan' => $subscription->plan,
                'role_assigned' => 'pro_user',
            ])
            ->log('pro_user.role.assigned');
    }

    public function handleExpired(Subscription $subscription): void
    {
        $user = $subscription->user;
        $user->removeRole('pro_user');

        activity()
            ->performedOn($user)
            ->withProperties([
                'subscription_id' => $subscription->id,
                'role_removed' => 'pro_user',
            ])
            ->log('pro_user.role.removed');
    }

    public function handleCancelled(Subscription $subscription): void
    {
        // Do NOT remove role immediately — active until period end
        $subscription->update([
            'cancelled_at' => now(),
            'ends_at' => $subscription->current_period_end,
        ]);

        activity()
            ->performedOn($subscription->user)
            ->withProperties([
                'subscription_id' => $subscription->id,
                'ends_at' => $subscription->ends_at,
            ])
            ->log('subscription.cancelled');
    }
}
```

## Billing Authorization Middleware

```php
class EnsureBillingAccess
{
    public function handle(Request $request, Closure $next, ?string $scope = null)
    {
        $user = $request->user();

        if (! $user) {
            return redirect()->route('login');
        }

        return match ($scope) {
            'manage' => Gate::authorize('billing.manage')
                ? $next($request)
                : abort(403),
            'view_all' => Gate::authorize('billing.view_all')
                ? $next($request)
                : abort(403),
            'refund' => Gate::authorize('billing.refund')
                ? $next($request)
                : abort(403),
            default => $next($request),
        };
    }
}
```

### Analytics Service

```php
class BillingAnalyticsService
{
    public function calculateMrr(): float
    {
        return DB::table('subscriptions')
            ->where('stripe_status', 'active')
            ->sum('monthly_amount') / 100;
    }

    public function calculateChurn(int $months = 3): float
    {
        $startOfMonth = now()->subMonths($months)->startOfMonth();
        $endOfMonth = now()->startOfMonth();

        $startCount = Subscription::where('created_at', '<', $startOfMonth)
            ->where('stripe_status', 'active')
            ->count();

        $cancelled = Subscription::whereBetween('cancelled_at', [$startOfMonth, $endOfMonth])
            ->count();

        if ($startCount === 0) {
            return 0;
        }

        return round(($cancelled / $startCount) * 100, 2);
    }

    public function calculateLtv(): float
    {
        $arpu = DB::table('subscriptions')
            ->where('stripe_status', 'active')
            ->avg('monthly_amount') / 100;

        $churnRate = $this->calculateChurn(12) / 100;

        if ($churnRate === 0) {
            return $arpu * 12; // Assume 12-month max
        }

        return round($arpu / $churnRate, 2);
    }
}
```

### Security Audit Service

```php
class BillingSecurityAudit
{
    public function detectFraudulentActivity(User $user, array $paymentData): void
    {
        // Check for multiple failed payments
        $recentFailures = PaymentLog::where('user_id', $user->id)
            ->where('status', 'failed')
            ->where('created_at', '>', now()->subHours(24))
            ->count();

        if ($recentFailures >= 3) {
            $this->alertAdmin('Multiple failed payments', [
                'user_id' => $user->id,
                'failure_count' => $recentFailures,
            ]);
        }

        // Check for unusual payment patterns
        $recentPayments = PaymentLog::where('user_id', $user->id)
            ->where('created_at', '>', now()->subHours(1))
            ->count();

        if ($recentPayments >= 5) {
            $this->alertAdmin('Unusual payment pattern', [
                'user_id' => $user->id,
                'payment_count' => $recentPayments,
            ]);
        }

        // Check for geographic anomalies
        $currentIp = request()->ip();
        $lastPaymentIp = PaymentLog::where('user_id', $user->id)
            ->latest()
            ->value('ip_address');

        if ($lastPaymentIp && $currentIp !== $lastPaymentIp) {
            activity()
                ->performedOn($user)
                ->withProperties([
                    'old_ip' => $lastPaymentIp,
                    'new_ip' => $currentIp,
                ])
                ->event('billing.security.ip_change')
                ->log('IP address changed between payments');
        }
    }
}
```

### Exchange Rate Service

```php
class ExchangeRateService
{
    public function convert(float $amount, string $fromCurrency, string $toCurrency): float
    {
        if ($fromCurrency === $toCurrency) {
            return $amount;
        }

        $fromRate = $this->getRate($fromCurrency);
        $toRate = $this->getRate($toCurrency);

        return round($amount * ($toRate / $fromRate), 2);
    }

    private function getRate(string $currency): float
    {
        return DB::table('billing_currencies')
            ->where('code', $currency)
            ->value('exchange_rate') ?? 1.0;
    }
}
```

### Quality Gate Service

```php
class BillingQualityGate
{
    public function passAllGates(): array
    {
        return [
            'payment_success' => $this->checkPaymentSuccess(),
            'invoice_accuracy' => $this->checkInvoiceAccuracy(),
            'tax_accuracy' => $this->checkTaxAccuracy(),
            'webhook_delivery' => $this->checkWebhookDelivery(),
            'refund_processing' => $this->checkRefundProcessing(),
            'subscription_sync' => $this->checkSubscriptionSync(),
        ];
    }

    public function canOperate(): bool
    {
        $gates = $this->passAllGates();

        return ! in_array(false, $gates);
    }

    private function checkPaymentSuccess(): bool
    {
        $successRate = DB::table('invoices')
            ->where('created_at', '>=', now()->subDays(30))
            ->selectRaw('SUM(CASE WHEN status = "paid" THEN 1 ELSE 0 END) / COUNT(*) * 100 as success_rate')
            ->value('success_rate');

        return $successRate >= 99;
    }
}
```

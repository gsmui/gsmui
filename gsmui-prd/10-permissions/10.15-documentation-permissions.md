# 10.15 — Documentation Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines the complete authorization rules for the **Documentation domain** in GsmUi. Documentation is the knowledge backbone of the platform — API references, component guides, theme tutorials, getting-started walkthroughs, and changelogs. This specification governs who can create, edit, publish, reorder, version, and organize documentation pages, and enforces editorial workflows, version isolation, and category management.

Documentation interacts with the [Blog domain](./10.14-blog-permissions.md), the [Admin permissions](./10.07-admin-permissions.md), and the [User permissions](./10.08-user-permissions.md).

## Scope

Documentation permissions apply to:

* Documentation page creation and editing
* Documentation page publishing and editorial workflow
* Documentation page reordering (drag-and-drop hierarchy)
* Documentation version management (v1, v2, v3, etc.)
* Documentation category management (nestable categories)
* Documentation page archiving and deletion
* Documentation search index management
* Documentation analytics (page views, engagement)

## Documentation Version Management

Version management is restricted to admins. This prevents accidental version splits and ensures versioned content is consistent.

### Version Lifecycle

```text
Active version (v1)
  ↓ (admin creates new version)
Draft version (v2) — independent copy
  ↓ (editors work within v2)
v2 becomes Active
  ↓
v1 becomes Legacy (archived, read-only)
```

### Version Isolation Rules

* Each version has its own category tree and pages
* Editing within a version does not affect other versions
* Published versions are read-only (no edits without creating a new version)
* Only admins can create new versions
* Only admins can archive old versions

```php
class DocumentationVersionPolicy
{
    public function create(User $user): bool
    {
        return $user->hasRole(['admin', 'super_admin']);
    }

    public function update(User $user, DocumentationVersion $version): bool
    {
        // Can only edit draft versions
        if ($version->status !== 'draft') {
            return false;
        }

        return $user->hasRole(['admin', 'super_admin']);
    }

    public function archive(User $user, DocumentationVersion $version): bool
    {
        return $user->hasRole(['admin', 'super_admin']);
    }

    public function activate(User $user, DocumentationVersion $version): bool
    {
        return $user->hasRole(['admin', 'super_admin']);
    }
}
```

## Page Reordering Authorization

Page reordering changes the sort order of pages within a category. This is restricted to editors and above because it affects the public navigation structure.

```php
public function reorder(User $user): bool
{
    return $user->hasRole(['editor', 'admin', 'super_admin']);
}
```

### Reorder Request

```php
class ReorderDocumentationPagesRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'category_id' => ['required', 'exists:documentation_categories,id'],
            'pages' => ['required', 'array'],
            'pages.*.id' => ['required', 'exists:documentation_pages,id'],
            'pages.*.sort_order' => ['required', 'integer', 'min:0'],
        ];
    }

    public function authorize(): bool
    {
        return $this->user()->can('reorder', DocumentationPage::class);
    }
}
```

## Category Management

Categories organize documentation pages into a hierarchical tree. Category management is restricted to editors and above.

### Category CRUD Authorization

```php
class DocumentationCategoryPolicy
{
    public function create(User $user): bool
    {
        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    public function update(User $user, DocumentationCategory $category): bool
    {
        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    public function delete(User $user, DocumentationCategory $category): bool
    {
        // Cannot delete categories with pages
        if ($category->pages()->count() > 0) {
            return false;
        }

        // Cannot delete categories with child categories
        if ($category->children()->count() > 0) {
            return false;
        }

        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }
}
```

### Category Constraints

| Rule | Enforcement |
|---|---|
| Cannot delete category with pages | Policy check + DB constraint |
| Cannot delete category with children | Policy check + tree validation |
| Maximum nesting depth: 3 levels | Validation rule |
| Category name must be unique within parent | Unique composite index |
| Sort order must be unique within parent | Unique composite index |

## Policy Implementation

```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\DocumentationPage;
use Illuminate\Auth\Access\HandlesAuthorization;

class DocumentationPolicy
{
    use HandlesAuthorization;

    /**
     * Determine whether the user can view any documentation pages.
     * Published pages are public.
     */
    public function viewAny(User $user): bool
    {
        return true;
    }

    /**
     * Determine whether the user can view the documentation page.
     * Published pages are public.
     * Draft pages are owner/editor/admin only.
     */
    public function view(User $user, DocumentationPage $page): bool
    {
        if ($page->status === 'published') {
            return true;
        }

        // draft — owner + editor + admin only
        return $user->id === $page->user_id
            || $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can create documentation pages.
     * Requires 'author', 'editor', or 'admin' role.
     */
    public function create(User $user): bool
    {
        return $user->hasRole(['author', 'editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can update the documentation page.
     * Owner can update own pages; editors/admins can update any.
     */
    public function update(User $user, DocumentationPage $page): bool
    {
        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $page->user_id;
    }

    /**
     * Determine whether the user can delete the documentation page.
     * Owner can delete own pages; editors/admins can delete any.
     */
    public function delete(User $user, DocumentationPage $page): bool
    {
        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $page->user_id;
    }

    /**
     * Determine whether the user can publish the documentation page.
     */
    public function publish(User $user, DocumentationPage $page): bool
    {
        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        // Author can submit own draft for review
        return $user->id === $page->user_id
            && in_array($page->status, ['draft', 'rejected']);
    }

    /**
     * Determine whether the user can reorder documentation pages.
     */
    public function reorder(User $user): bool
    {
        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can manage documentation versions.
     */
    public function manageVersions(User $user): bool
    {
        return $user->hasRole(['admin', 'super_admin']);
    }

    /**
     * Determine whether the user can manage documentation categories.
     */
    public function manageCategories(User $user): bool
    {
        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can archive a page.
     */
    public function archive(User $user, DocumentationPage $page): bool
    {
        return $user->hasRole(['editor', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can view page analytics.
     */
    public function viewAnalytics(User $user, DocumentationPage $page): bool
    {
        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $page->user_id;
    }

    /**
     * Determine whether the user can rebuild the search index.
     */
    public function manageSearch(User $user): bool
    {
        return $user->hasRole(['admin', 'super_admin']);
    }
}
```

## Controller Integration

```php
<?php

namespace App\Http\Controllers;

use App\Models\DocumentationPage;
use App\Models\DocumentationVersion;
use Illuminate\Http\Request;

class DocumentationController extends Controller
{
    public function __construct()
    {
        $this->authorizeResource(DocumentationPage::class, 'page');
    }

    public function index()
    {
        // viewAny — public documentation listing
    }

    public function store(Request $request)
    {
        // create — requires 'author', 'editor', or 'admin' role

        $page = DocumentationPage::create([
            'user_id' => auth()->id(),
            'version_id' => $request->version_id,
            'category_id' => $request->category_id,
            'title' => $request->title,
            'slug' => $request->slug,
            'body' => $request->body,
            'status' => 'draft',
        ]);

        return redirect()->route('documentation.edit', $page);
    }

    public function update(Request $request, DocumentationPage $page)
    {
        // update — owner, editor, or admin

        $page->update($request->validated());

        return back()->with('success', 'Page updated.');
    }

    public function reorder(Request $request)
    {
        $this->authorize('reorder', DocumentationPage::class);

        foreach ($request->pages as $index => $item) {
            DocumentationPage::where('id', $item['id'])
                ->update(['sort_order' => $index]);
        }

        return back()->with('success', 'Pages reordered.');
    }

    public function destroy(DocumentationPage $page)
    {
        $this->authorize('delete', $page);

        $page->delete();

        return redirect()->route('documentation.index');
    }
}

class DocumentationVersionController extends Controller
{
    public function store(Request $request)
    {
        $this->authorize('manageVersions', DocumentationPage::class);

        $version = DocumentationVersion::create([
            'number' => $request->number,
            'name' => $request->name,
            'status' => 'draft',
        ]);

        return redirect()->route('documentation.versions.edit', $version);
    }

    public function activate(DocumentationVersion $version)
    {
        $this->authorize('manageVersions', DocumentationPage::class);

        // Archive current active version
        DocumentationVersion::where('status', 'active')
            ->update(['status' => 'archived']);

        $version->update(['status' => 'active']);

        return back()->with('success', 'Version activated.');
    }
}
```

## Documentation Page Revisions

Every documentation page edit creates a revision record for audit and rollback purposes. Revision management follows a structured workflow.

### Revision Policy

```php
class DocumentationRevisionPolicy
{
    public function view(User $user, DocumentationPageRevision $revision): bool
    {
        $page = $revision->documentationPage;

        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $page->user_id;
    }

    public function restore(User $user, DocumentationPageRevision $revision): bool
    {
        $page = $revision->documentationPage;

        if ($user->hasRole(['editor', 'admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $page->user_id
            && in_array($page->status, ['draft', 'rejected']);
    }

    public function compareRevisions(User $user, DocumentationPageRevision $rev1, DocumentationPageRevision $rev2): bool
    {
        return $this->view($user, $rev1) && $this->view($user, $rev2);
    }

    public function deleteRevision(User $user, DocumentationPageRevision $revision): bool
    {
        return $user->hasRole(['admin', 'super_admin']);
    }
}
```

### Search Index Service

```php
class DocumentationSearchIndexService
{
    public function rebuildFull(): void
    {
        $pages = DocumentationPage::where('status', 'published')->get();

        foreach ($pages as $page) {
            $this->indexPage($page);
        }

        activity()
            ->withProperties(['page_count' => $pages->count()])
            ->event('documentation.search_rebuilt')
            ->log('Documentation search index rebuilt');
    }

    public function indexPage(DocumentationPage $page): void
    {
        Search::index('documentation')->add([
            'id' => $page->id,
            'title' => $page->title,
            'body' => strip_tags($page->body),
            'version' => $page->version->number,
            'category' => $page->category?->name,
            'url' => route('documentation.show', $page->slug),
        ]);
    }

    public function removePage(DocumentationPage $page): void
    {
        Search::index('documentation')->remove($page->id);
    }
}
```

## Documentation Quality Assurance

Quality gates ensure documentation meets minimum standards before publication.

### Quality Gates

| Gate | Requirement | Blocks Publication |
|---|---|---|
| Spelling check | Zero spelling errors | Yes |
| Link validation | All links resolve | Yes |
| Image validation | All images have alt text | Yes |
| Heading structure | At least one H2 heading | Yes |
| Code examples | Code blocks have language tags | No |
| Minimum length | ≥ 100 words | Yes |
| Readability score | Flesch-Kincaid ≥ 60 | No |

### Quality Gate Service

```php
class DocumentationQualityGate
{
    public function passAllGates(DocumentationPage $page): array
    {
        return [
            'spelling' => $this->checkSpelling($page),
            'links' => $this->checkLinks($page),
            'images' => $this->checkImages($page),
            'headings' => $this->checkHeadings($page),
            'code_blocks' => $this->checkCodeBlocks($page),
            'length' => $this->checkLength($page),
            'readability' => $this->checkReadability($page),
        ];
    }

    public function canPublish(DocumentationPage $page): bool
    {
        $gates = $this->passAllGates($page);

        $requiredGates = ['spelling', 'links', 'images', 'headings', 'length'];

        foreach ($requiredGates as $gate) {
            if (isset($gates[$gate]) && $gates[$gate] === false) {
                return false;
            }
        }

        return true;
    }
}
```

### ACL Resolution

```php
class DocumentationAclResolver
{
    public function resolve(User $user, DocumentationPage $page, string $permission): bool
    {
        if ($user->can($permission, $page)) {
            return true;
        }

        $acl = DocumentationAcl::where('page_id', $page->id)
            ->where('user_id', $user->id)
            ->where('permission', $permission)
            ->where(function ($q) {
                $q->whereNull('expires_at')
                  ->orWhere('expires_at', '>', now());
            })
            ->first();

        return $acl !== null;
    }
}
```

### ACL Resolution

```php
class DocumentationAclResolver
{
    public function resolve(User $user, DocumentationPage $page, string $permission): bool
    {
        // Check role-based permission first
        if ($user->can($permission, $page)) {
            return true;
        }

        // Check page-level ACL
        $acl = DocumentationAcl::where('page_id', $page->id)
            ->where('user_id', $user->id)
            ->where('permission', $permission)
            ->where(function ($q) {
                $q->whereNull('expires_at')
                  ->orWhere('expires_at', '>', now());
            })
            ->first();

        if ($acl) {
            return true;
        }

        // Check category-level ACL
        if ($page->category_id) {
            $categoryAcl = DocumentationAcl::where('category_id', $page->category_id)
                ->where('user_id', $user->id)
                ->where('permission', $permission)
                ->where(function ($q) {
                    $q->whereNull('expires_at')
                      ->orWhere('expires_at', '>', now());
                })
                ->first();

            return $categoryAcl !== null;
        }

        return false;
    }
}
```

# 10.13 — Template Permissions

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines the complete authorization rules for the **Template domain** in GsmUi. Templates are complete project starters — pre-built scaffolding that users install into their own projects to get a working foundation. Unlike themes (visual skins) or components (individual UI elements), templates include directory structures, configuration files, starter code, and wired-up dependencies. This specification governs who can create, edit, publish, install, clone, and bundle templates, and enforces ownership, marketplace workflows, and project slot limits.

Templates interact with the [Theme domain](./10.11-theme-permissions.md), the [Component domain](./10.12-component-permissions.md), and the [Marketplace domain](./10.10-marketplace-permissions.md).

## Scope

Template permissions apply to:

* Template creation and editing (scaffolding, config, starter code)
* Template publishing and approval workflow
* Template installation into user projects
* Template cloning as basis for new templates
* Template bundling with themes
* Template deletion and archival
* Template marketplace listing interactions
* Template dependency resolution (components, themes, packages)

## Template Lifecycle States

```text
draft
  ↓ (submit for review)
pending_review
  ↓ (approve)
published
  ↓ (feature)
featured

pending_review
  ↓ (reject)
rejected
  ↓ (owner edits & resubmits)
pending_review

published
  ↓ (unpublish)
unpublished
  ↓ (resubmit)
pending_review
```

### State Transition Matrix

| From State | To State | Trigger | Permission Required |
|---|---|---|---|
| `draft` | `pending_review` | Owner submits | `templates.publish` (own) |
| `pending_review` | `published` | Moderator approves | `templates.publish` (moderator+) |
| `pending_review` | `rejected` | Moderator rejects | `templates.publish` (moderator+) |
| `pending_review` | `draft` | Owner withdraws | `templates.update` (own) |
| `rejected` | `pending_review` | Owner resubmits | `templates.publish` (own) |
| `published` | `featured` | Admin features | `templates.feature` (admin+) |
| `featured` | `published` | Admin unfeatures | `templates.feature` (admin+) |
| `published` | `unpublished` | Owner/admin unpublishes | `templates.unpublish` (own or admin) |
| `unpublished` | `pending_review` | Owner resubmits | `templates.publish` (own) |
| Any | `draft` | Owner deletes | `templates.delete` (own) |

## Template vs Theme Distinction

| Aspect | Template | Theme |
|---|---|---|
| Purpose | Complete project starter | Visual skin for existing project |
| Contents | Directory structure, config, code, dependencies | Colors, typography, layout, assets |
| Installation | Scaffolds a new project or extends existing | Applied to an existing project |
| Can be installed | Yes (creates new project) | No (modifies existing project) |
| Price model | One-time purchase or included in subscription | One-time purchase or included in subscription |
| Dependencies | May include themes and components | May include components |
| Post-install | User owns and modifies freely | User can customize within theme constraints |

## Template Installation Authorization

Installation is the most complex authorization flow in the Template domain. It involves:

1. **Permission check** — Does the user have `templates.install`?
2. **Purchase verification** — Has the user purchased the template (or is it free)?
3. **Project slot check** — Does the user's subscription tier allow another project?
4. **Dependency check** — Are all template dependencies (components, themes) available?
5. **Installation execution** — Scaffold the project files
6. **Event logging** — Log the installation for audit and analytics

### Installation Flow

```text
User clicks "Install Template"
    ↓
Check: Is user authenticated?
    → No: Redirect to login
    ↓
Check: Has user purchased template (or is it free)?
    → No: Redirect to purchase page
    ↓
Check: User's subscription tier has available project slots?
    → No: Show upgrade prompt
    ↓
Check: All template dependencies are resolvable?
    → No: Show dependency error
    ↓
Execute installation (queue job)
    → Scaffold project files
    → Install dependencies (npm/composer)
    → Create project record
    → Assign project ownership
    ↓
Log installation event
    ↓
Redirect to new project
```

### Installation Authorization Code

```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\Template;
use Illuminate\Auth\Access\HandlesAuthorization;

class TemplatePolicy
{
    use HandlesAuthorization;

    /**
     * Determine whether the user can install the template.
     * Must own (purchase) the template and have available project slots.
     */
    public function install(User $user, Template $template): bool
    {
        // Must be authenticated and verified
        if (! $user->hasVerifiedEmail()) {
            return false;
        }

        // Published templates can be installed
        if (! in_array($template->status, ['published', 'featured'])) {
            return false;
        }

        // Free templates — any verified user can install
        if ($template->price === 0 || $template->price === null) {
            return $this->hasAvailableSlots($user);
        }

        // Paid templates — must have purchased
        $hasPurchased = $user->purchases()
            ->where('purchasable_type', Template::class)
            ->where('purchasable_id', $template->id)
            ->where('status', 'completed')
            ->exists();

        if (! $hasPurchased) {
            return false;
        }

        return $this->hasAvailableSlots($user);
    }

    /**
     * Check if user has available project slots based on subscription tier.
     */
    protected function hasAvailableSlots(User $user): bool
    {
        $tier = $user->subscription?->tier ?? 'free';
        $maxProjects = config("subscriptions.{$tier}.max_projects", 1);
        $currentProjects = $user->projects()->count();

        return $currentProjects < $maxProjects;
    }
}
```

## Policy Implementation

```php
<?php

namespace App\Policies;

use App\Models\User;
use App\Models\Template;
use Illuminate\Auth\Access\HandlesAuthorization;

class TemplatePolicy
{
    use HandlesAuthorization;

    /**
     * Determine whether the user can view any templates.
     * Public browsing.
     */
    public function viewAny(User $user): bool
    {
        return true;
    }

    /**
     * Determine whether the user can view the template.
     * Published templates are public.
     * Draft/rejected templates are owner/admin only.
     */
    public function view(User $user, Template $template): bool
    {
        if (in_array($template->status, ['published', 'featured'])) {
            return true;
        }

        if ($template->status === 'pending_review') {
            return $user->id === $template->user_id
                || $user->hasRole(['moderator', 'admin', 'super_admin']);
        }

        return $user->id === $template->user_id
            || $user->hasRole(['admin', 'super_admin']);
    }

    /**
     * Determine whether the user can create templates.
     * Requires 'creator' or 'admin' role.
     */
    public function create(User $user): bool
    {
        return $user->hasRole(['creator', 'admin', 'super_admin']);
    }

    /**
     * Determine whether the user can update the template.
     * Only owner, only in draft/rejected state.
     */
    public function update(User $user, Template $template): bool
    {
        if (! in_array($template->status, ['draft', 'rejected'])) {
            return false;
        }

        return $user->id === $template->user_id;
    }

    /**
     * Determine whether the user can delete the template.
     * Owner or admin.
     */
    public function delete(User $user, Template $template): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $template->user_id;
    }

    /**
     * Determine whether the user can publish/submit for review.
     */
    public function publish(User $user, Template $template): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        if ($user->hasRole('moderator') && $template->status === 'pending_review') {
            return true;
        }

        return $user->id === $template->user_id
            && in_array($template->status, ['draft', 'rejected']);
    }

    /**
     * Determine whether the user can unpublish the template.
     */
    public function unpublish(User $user, Template $template): bool
    {
        if (! in_array($template->status, ['published', 'featured'])) {
            return false;
        }

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $template->user_id;
    }

    /**
     * Determine whether the user can install the template.
     * Must have purchased (or it's free) and have available project slots.
     */
    public function install(User $user, Template $template): bool
    {
        if (! $user->hasVerifiedEmail()) {
            return false;
        }

        if (! in_array($template->status, ['published', 'featured'])) {
            return false;
        }

        if ($template->price > 0) {
            $hasPurchased = $user->purchases()
                ->where('purchasable_type', Template::class)
                ->where('purchasable_id', $template->id)
                ->where('status', 'completed')
                ->exists();

            if (! $hasPurchased) {
                return false;
            }
        }

        return $this->hasAvailableSlots($user);
    }

    /**
     * Determine whether the user can clone the template.
     */
    public function clone(User $user, Template $template): bool
    {
        if (! in_array($template->status, ['published', 'featured'])) {
            return false;
        }

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $template->user_id;
    }

    /**
     * Determine whether the user can bundle the template with a theme.
     */
    public function bundle(User $user, Template $template, $theme = null): bool
    {
        if ($theme === null) {
            return false;
        }

        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $template->user_id
            && $user->id === $theme->user_id
            && $template->status === 'published'
            && in_array($theme->status, ['draft', 'rejected']);
    }

    /**
     * Determine whether the user can view analytics.
     */
    public function viewAnalytics(User $user, Template $template): bool
    {
        if ($user->hasRole(['admin', 'super_admin'])) {
            return true;
        }

        return $user->id === $template->user_id;
    }

    /**
     * Check if user has available project slots.
     */
    protected function hasAvailableSlots(User $user): bool
    {
        $tier = $user->subscription?->tier ?? 'free';
        $maxProjects = config("subscriptions.{$tier}.max_projects", 1);
        $currentProjects = $user->projects()->count();

        if ($maxProjects === -1) {
            return true; // unlimited
        }

        return $currentProjects < $maxProjects;
    }
}
```

## Controller Integration

```php
<?php

namespace App\Http\Controllers;

use App\Models\Template;
use App\Services\TemplateInstallerService;
use Illuminate\Http\Request;

class TemplateController extends Controller
{
    public function __construct(
        protected TemplateInstallerService $installer
    ) {
        $this->authorizeResource(Template::class, 'template');
    }

    public function index()
    {
        // viewAny — public template marketplace
    }

    public function store(Request $request)
    {
        // create — requires 'creator' or 'admin' role

        $template = Template::create([
            'user_id' => auth()->id(),
            'name' => $request->name,
            'slug' => $request->slug,
            'description' => $request->description,
            'price' => $request->price ?? 0,
            'status' => 'draft',
        ]);

        return redirect()->route('templates.edit', $template);
    }

    public function install(Template $template)
    {
        $this->authorize('install', $template);

        $project = $this->installer->install(
            template: $template,
            user: auth()->user()
        );

        activity()
            ->performedOn($template)
            ->withProperties([
                'project_id' => $project->id,
                'user_id' => auth()->id(),
            ])
            ->event('template.installed')
            ->log('Template installed');

        return redirect()->route('projects.show', $project);
    }

    public function destroy(Template $template)
    {
        $this->authorize('delete', $template);

        $template->delete();

        return redirect()->route('templates.index');
    }
}
```

## Template Ownership

Templates follow an ownership model where the creating user holds primary control. Ownership grants full lifecycle management rights.

### Ownership Rules

| Rule | Description |
|---|---|
| Creator is owner | The user who creates a template is its owner |
| Ownership is permanent | Cannot be transferred without explicit action |
| Owner can always edit | In draft/rejected state only |
| Owner can unpublish | Published templates can be withdrawn |
| Owner receives revenue | Marketplace earnings go to the owner |
| Owner manages versions | Version tags are controlled by the owner |
| Admin override | Admins can manage any template regardless of ownership |

### Ownership Transfer Model

```php
// app/Models/TemplateOwnershipTransfer.php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class TemplateOwnershipTransfer extends Model
{
    protected $fillable = [
        'template_id',
        'from_user_id',
        'to_user_id',
        'status', // pending, accepted, rejected, expired
        'reason',
        'expires_at',
        'accepted_at',
        'created_by',
    ];

    protected $casts = [
        'expires_at' => 'datetime',
        'accepted_at' => 'datetime',
    ];

    public function template()
    {
        return $this->belongsTo(Template::class);
    }

    public function fromUser()
    {
        return $this->belongsTo(User::class, 'from_user_id');
    }

    public function toUser()
    {
        return $this->belongsTo(User::class, 'to_user_id');
    }

    public function isExpired(): bool
    {
        return $this->expires_at && $this->expires_at->isPast();
    }

    public function isActive(): bool
    {
        return $this->status === 'pending' && ! $this->isExpired();
    }
}
```

### Ownership Transfer Service

```php
// app/Services/TemplateOwnershipService.php

namespace App\Services;

use App\Models\Template;
use App\Models\TemplateOwnershipTransfer;
use App\Models\User;

class TemplateOwnershipService
{
    public function initiateTransfer(
        Template $template,
        User $fromUser,
        User $toUser,
        ?string $reason = null,
    ): TemplateOwnershipTransfer {
        if ($template->user_id !== $fromUser->id) {
            throw new \InvalidArgumentException('Only the template owner can initiate a transfer');
        }

        if ($fromUser->id === $toUser->id) {
            throw new \InvalidArgumentException('Cannot transfer to yourself');
        }

        // Cancel any existing pending transfers
        TemplateOwnershipTransfer::where('template_id', $template->id)
            ->where('status', 'pending')
            ->update(['status' => 'cancelled']);

        $transfer = TemplateOwnershipTransfer::create([
            'template_id' => $template->id,
            'from_user_id' => $fromUser->id,
            'to_user_id' => $toUser->id,
            'status' => 'pending',
            'reason' => $reason,
            'expires_at' => now()->addDays(7),
            'created_by' => $fromUser->id,
        ]);

        activity()
            ->performedOn($template)
            ->causedBy($fromUser)
            ->withProperties([
                'transfer_id' => $transfer->id,
                'to_user_id' => $toUser->id,
            ])
            ->event('template_transfer_initiated')
            ->log('Template ownership transfer initiated');

        return $transfer;
    }

    public function acceptTransfer(
        TemplateOwnershipTransfer $transfer,
        User $acceptingUser,
    ): Template {
        if ($transfer->to_user_id !== $acceptingUser->id) {
            throw new \InvalidArgumentException('Only the designated recipient can accept');
        }

        if (! $transfer->isActive()) {
            throw new \InvalidArgumentException('Transfer is no longer active');
        }

        $template = $transfer->template;

        DB::beginTransaction();

        try {
            $template->update(['user_id' => $acceptingUser->id]);

            $transfer->update([
                'status' => 'accepted',
                'accepted_at' => now(),
            ]);

            activity()
                ->performedOn($template)
                ->causedBy($acceptingUser)
                ->withProperties([
                    'transfer_id' => $transfer->id,
                    'from_user_id' => $transfer->from_user_id,
                ])
                ->event('template_transfer_completed')
                ->log('Template ownership transferred');

            DB::commit();

            return $template->refresh();
        } catch (\Exception $e) {
            DB::rollBack();
            throw $e;
        }
    }

    public function rejectTransfer(
        TemplateOwnershipTransfer $transfer,
        User $rejectingUser,
    ): void {
        if ($transfer->to_user_id !== $rejectingUser->id) {
            throw new \InvalidArgumentException('Only the designated recipient can reject');
        }

        $transfer->update(['status' => 'rejected']);

        activity()
            ->performedOn($transfer->template)
            ->causedBy($rejectingUser)
            ->event('template_transfer_rejected')
            ->log('Template ownership transfer rejected');
    }
}
```

### Team Sharing Service

```php
// app/Services/TeamTemplateShareService.php

namespace App\Services;

use App\Models\Team;
use App\Models\Template;
use App\Models\TeamTemplateShare;
use App\Models\User;

class TeamTemplateShareService
{
    public function share(
        Template $template,
        Team $team,
        User $sharedBy,
        string $accessLevel = 'view',
        ?\Carbon\Carbon $expiresAt = null,
    ): TeamTemplateShare {
        // Verify the sharer has admin access to the template
        if ($sharedBy->id !== $template->user_id
            && ! $sharedBy->hasRole(['admin', 'super_admin'])) {
            throw new \InvalidArgumentException('Only template owner or admin can share');
        }

        // Verify the sharer is a member of the team
        if (! $team->members()->where('user_id', $sharedBy->id)->exists()) {
            throw new \InvalidArgumentException('You must be a team member to share');
        }

        $existing = TeamTemplateShare::where('team_id', $team->id)
            ->where('template_id', $template->id)
            ->whereNull('revoked_at')
            ->first();

        if ($existing) {
            // Upgrade access level if needed
            $levels = ['view' => 1, 'edit' => 2, 'admin' => 3];
            if ($levels[$accessLevel] > $levels[$existing->access_level]) {
                $existing->update(['access_level' => $accessLevel]);
            }
            return $existing->refresh();
        }

        $share = TeamTemplateShare::create([
            'team_id' => $team->id,
            'template_id' => $template->id,
            'shared_by' => $sharedBy->id,
            'access_level' => $accessLevel,
            'shared_at' => now(),
            'expires_at' => $expiresAt,
        ]);

        activity()
            ->performedOn($template)
            ->causedBy($sharedBy)
            ->withProperties([
                'team_id' => $team->id,
                'access_level' => $accessLevel,
            ])
            ->event('template_shared_with_team')
            ->log('Template shared with team');

        return $share;
    }

    public function revokeShare(
        Template $template,
        Team $team,
        User $revokedBy,
    ): bool {
        $deleted = TeamTemplateShare::where('team_id', $team->id)
            ->where('template_id', $template->id)
            ->whereNull('revoked_at')
            ->update(['revoked_at' => now()]);

        if ($deleted > 0) {
            activity()
                ->performedOn($template)
                ->causedBy($revokedBy)
                ->withProperties(['team_id' => $team->id])
                ->event('template_share_revoked')
                ->log('Template share revoked');
        }

        return $deleted > 0;
    }

    public function canTeamMemberEdit(Template $template, User $user): bool
    {
        $teamId = $user->current_team_id;

        if (! $teamId) {
            return false;
        }

        return TeamTemplateShare::where('team_id', $teamId)
            ->where('template_id', $template->id)
            ->where('access_level', 'edit')
            ->whereNull('revoked_at')
            ->where(function ($q) {
                $q->whereNull('expires_at')
                    ->orWhere('expires_at', '>', now());
            })
            ->exists();
    }

    public function getSharedTemplates(Team $team): \Illuminate\Support\Collection
    {
        return Template::whereHas('teamShares', function ($q) use ($team) {
            $q->where('team_id', $team->id)
                ->whereNull('revoked_at')
                ->where(function ($q2) {
                    $q2->whereNull('expires_at')
                        ->orWhere('expires_at', '>', now());
                });
        })->get();
    }
}
```

```php
    public function updatePrice(
        MarketplaceListing $listing,
        User $owner,
        float $newPrice,
    ): MarketplaceListing {
        if ($listing->user_id !== $owner->id && ! $owner->hasRole('admin')) {
            throw new \InvalidArgumentException('Unauthorized');
        }

        $oldPrice = $listing->price;
        $listing->update(['price' => $newPrice]);

        activity()
            ->performedOn($listing)
            ->causedBy($owner)
            ->withProperties([
                'old_price' => $oldPrice,
                'new_price' => $newPrice,
            ])
            ->event('listing_price_changed')
            ->log('Marketplace listing price changed');

        return $listing->refresh();
    }

    public function featureListing(
        MarketplaceListing $listing,
        User $admin,
    ): MarketplaceListing {
        if (! $admin->hasRole(['admin', 'super_admin'])) {
            throw new \InvalidArgumentException('Only admins can feature listings');
        }

        $listing->update(['is_featured' => true]);

        activity()
            ->performedOn($listing)
            ->causedBy($admin)
            ->event('listing_featured')
            ->log('Marketplace listing featured');

    public function getEarnings(MarketplaceListing $listing, User $owner): array

            throw new \InvalidArgumentException('Only owner can view earnings');

        $totalRevenue = $listing->sales()->sum('amount');
        $platformFee = $totalRevenue * (config('marketplace.platform_fee_percent', 20) / 100);
        $netEarnings = $totalRevenue - $platformFee;

        return [
            'total_sales' => $totalSales,
            'total_revenue' => round($totalRevenue, 2),
            'platform_fee' => round($platformFee, 2),
            'net_earnings' => round($netEarnings, 2),
            'currency' => 'USD',
        ];
    }
```

```php
    public function purchase(

                'license_id' => $license->id,

    public function canUseForProject(
        TemplateLicense $license,
        string $projectType,
    ): bool {
        $config = config("template-licenses.licenses.{$license->license_type}");

        if (! in_array($projectType, $config['allowed_uses'] ?? [])) {
            return false;
        }

        if ($config['max_projects'] === -1) {
            return true;
        }

        $currentProjects = TemplateLicenseUsage::where('license_id', $license->id)
            ->distinct('project_id')
            ->count('project_id');

        return $currentProjects < $config['max_projects'];
    }

    public function activateLicense(
        TemplateLicense $license,

    ): TemplateLicenseUsage {

            'license_id' => $license->id,
            'project_type' => $projectType,
            'activated_at' => now(),
        ]);
    }

        TemplateLicense $license,
        User $revokedBy,
    ): void {
```

```php
// app/Services/TemplateUsageService.php

namespace App\Services;

use App\Models\Template;
use App\Models\TemplateUsageMetric;
use App\Models\User;
use Carbon\Carbon;

class TemplateUsageService
{
    public function record(
        Template $template,
        string $metricType,
        ?User $user = null,
        ?int $projectId = null,
        ?array $metadata = null,
    ): TemplateUsageMetric {
        return TemplateUsageMetric::create([
            'template_id' => $template->id,
            'metric_type' => $metricType,
            'user_id' => $user?->id,
            'project_id' => $projectId,
            'metadata' => $metadata,
            'recorded_at' => now(),
        ]);
    }

    public function getSummary(Template $template, int $days = 30): array
    {
        $start = Carbon::now()->subDays($days);

        $metrics = TemplateUsageMetric::where('template_id', $template->id)
            ->where('recorded_at', '>=', $start)
            ->select('metric_type', \DB::raw('COUNT(*) as count'))
            ->groupBy('metric_type')
            ->get()
            ->pluck('count', 'metric_type')
            ->toArray();

        $dailyInstalls = TemplateUsageMetric::where('template_id', $template->id)
            ->where('metric_type', 'install')
            ->where('recorded_at', '>=', $start)
            ->select(
                \DB::raw('DATE(recorded_at) as date'),
                \DB::raw('COUNT(*) as count')
            )
            ->groupBy('date')
            ->get()
            ->pluck('count', 'date')
            ->toArray();

        return [
            'period_days' => $days,
            'total_views' => $metrics['view'] ?? 0,
            'total_installs' => $metrics['install'] ?? 0,
            'total_clones' => $metrics['clone'] ?? 0,
            'total_updates' => $metrics['update'] ?? 0,
            'total_uninstalls' => $metrics['uninstall'] ?? 0,
            'install_rate' => ($metrics['view'] ?? 0) > 0
                ? round(($metrics['install'] ?? 0) / ($metrics['view'] ?? 1) * 100, 2)
                : 0,
            'daily_installs' => $dailyInstalls,
            'unique_installers' => TemplateUsageMetric::where('template_id', $template->id)
                ->where('metric_type', 'install')
                ->where('recorded_at', '>=', $start)
                ->distinct('user_id')
                ->count('user_id'),
        ];
    }

    public function getLeaderboard(string $metricType = 'install', int $days = 30, int $limit = 10): array
    {
        $start = Carbon::now()->subDays($days);

        return TemplateUsageMetric::where('metric_type', $metricType)
            ->where('recorded_at', '>=', $start)
            ->select('template_id', \DB::raw('COUNT(*) as count'))
            ->groupBy('template_id')
            ->orderByDesc('count')
            ->limit($limit)
            ->get()
            ->map(fn ($item) => [
                'template_id' => $item->template_id,
                'count' => $item->count,
                'template' => Template::find($item->template_id)?->only(['id', 'name', 'slug']),
            ])
            ->toArray();
    }

    public function getUserHistory(User $user, int $limit = 50): array
    {
        return TemplateUsageMetric::where('user_id', $user->id)
            ->orderByDesc('recorded_at')
            ->limit($limit)
            ->with('template:id,name,slug')
            ->get()
            ->toArray();
    }
}
```

### Version Management Service

```php
// app/Services/TemplateVersionService.php

namespace App\Services;

use App\Models\Template;
use App\Models\TemplateVersion;
use App\Models\User;

class TemplateVersionService
{
    public function createVersion(
        Template $template,
        User $creator,
        string $versionTag,
        string $filePath,
        ?string $changelog = null,
    ): TemplateVersion {
        if ($template->user_id !== $creator->id && ! $creator->hasRole('admin')) {
            throw new \InvalidArgumentException('Only template owner can create versions');
        }

        // Determine next version number
        $latestVersion = TemplateVersion::where('template_id', $template->id)
            ->orderByDesc('version_number')
            ->first();

        $nextNumber = $latestVersion ? $latestVersion->version_number + 1 : 1;

        // Mark previous latest as not latest
        if ($latestVersion) {
            $latestVersion->update(['is_latest' => false]);
        }

        $version = TemplateVersion::create([
            'template_id' => $template->id,
            'version_number' => $nextNumber,
            'version_tag' => $versionTag,
            'changelog' => $changelog,
            'file_path' => $filePath,
            'file_size' => filesize($filePath),
            'file_hash' => hash_file('sha256', $filePath),
            'created_by' => $creator->id,
            'status' => 'published',
            'is_latest' => true,
            'published_at' => now(),
        ]);

        // Update template version
        $template->update(['version' => $versionTag]);

        activity()
            ->performedOn($template)
            ->causedBy($creator)
            ->withProperties([
                'version_id' => $version->id,
                'version_tag' => $versionTag,
                'changelog' => $changelog,
            ])
            ->event('template_version_created')
            ->log("Template version {$versionTag} created");

        return $version;
    }

    public function rollbackVersion(
        Template $template,
        TemplateVersion $targetVersion,
        User $admin,
    ): TemplateVersion {
        if (! $admin->hasRole(['admin', 'super_admin']) && $template->user_id !== $admin->id) {
            throw new \InvalidArgumentException('Unauthorized');
        }

        // Create a new version based on the target
        $newVersion = $this->createVersion(
            template: $template,
            creator: $admin,
            versionTag: $targetVersion->version_tag . '-rollback',
            filePath: $targetVersion->file_path,
            changelog: "Rollback to version {$targetVersion->version_tag}",
        );

        activity()
            ->performedOn($template)
            ->causedBy($admin)
            ->withProperties([
                'rolled_back_to' => $targetVersion->id,
                'new_version_id' => $newVersion->id,
            ])
            ->event('template_version_rollback')
            ->log("Template rolled back to version {$targetVersion->version_tag}");

        return $newVersion;
    }

    public function deprecateVersion(
        TemplateVersion $version,
        User $deprecator,
    ): void {
        if ($version->is_latest) {
            throw new \InvalidArgumentException('Cannot deprecate the latest version');
        }

        $version->update([
            'status' => 'deprecated',
            'deprecated_at' => now(),
        ]);

        activity()
            ->performedOn($version->template)
            ->causedBy($deprecator)
            ->withProperties(['version_id' => $version->id])
            ->event('template_version_deprecated')
            ->log("Template version {$version->version_tag} deprecated");
    }

    public function getVersionHistory(Template $template): array
    {
        return TemplateVersion::where('template_id', $template->id)
            ->orderByDesc('version_number')
            ->with('createdBy:id,name')
            ->get()
            ->toArray();
    }

    public function canDownloadVersion(
        TemplateVersion $version,
        User $user,
    ): bool {
        // Admin or owner can always download
        if ($user->hasRole('admin') || $template->user_id === $user->id) {
            return true;
        }

        // Purchasers can download any published version
        return $user->purchases()
            ->where('purchasable_type', Template::class)
            ->where('purchasable_id', $version->template_id)
            ->where('status', 'completed')
            ->exists();
    }
}
```

## Template Marketplace Workflow

The marketplace listing process has specific authorization requirements that differ from standard template publishing.

### Marketplace Approval Flow

```text
Template published
  ↓
Owner creates marketplace listing
  ↓
Listing goes through automated checks:
  → Template quality score > threshold
  → No copyright violations detected
  → Template documentation complete
  → Screenshots provided
  ↓
If automated checks pass:
  → Listing is auto-approved
  → Template appears in marketplace
If automated checks fail:
  → Listing enters manual review queue
  ↓
Manual review by moderator:
  → Approve: Listing goes live
  → Reject: Owner receives feedback and can resubmit
```

### Marketplace Permission Enforcement

```php
// app/Policies/MarketplaceListingPolicy.php

namespace App\Policies;

use App\Models\MarketplaceListing;
use App\Models\User;
use Illuminate\Auth\Access\HandlesAuthorization;

class MarketplaceListingPolicy
{
    use HandlesAuthorization;

    public function before(User $user, string $ability): ?bool
    {
        if ($user->hasRole('super_admin')) {
            return true;
        }
        return null;
    }

    public function viewAny(User $user): bool
    {
        return true; // Marketplace is public
    }

    public function view(User $user, MarketplaceListing $listing): bool
    {
        return $listing->status === 'active'
            || $user->id === $listing->user_id
            || $user->hasRole(['admin', 'moderator']);
    }

    public function create(User $user, Template $template): bool
    {
        // Must be the template owner
        if ($template->user_id !== $user->id) {
            return false;
        }

        // Template must be published
        if (! in_array($template->status, ['published', 'featured'])) {
            return false;
        }

        // Must have marketplace permission
        return $user->hasPermissionTo('marketplace.list_template');
    }

    public function update(User $user, MarketplaceListing $listing): bool
    {
        return $user->id === $listing->user_id
            || $user->hasRole('admin');
    }

    public function delete(User $user, MarketplaceListing $listing): bool
    {
        return $user->id === $listing->user_id
            || $user->hasRole('admin');
    }

    public function setPrice(User $user, MarketplaceListing $listing): bool
    {
        if ($user->id !== $listing->user_id) {
            return false;
        }

        // Must be a verified seller for paid templates
        return $user->is_verified_seller
            || $user->hasRole('admin');
    }

    public function runPromotion(User $user, MarketplaceListing $listing): bool
    {
        return $user->id === $listing->user_id
            && $user->hasPermissionTo('marketplace.run_promotion');
    }

    public function viewEarnings(User $user, MarketplaceListing $listing): bool
    {
        return $user->id === $listing->user_id;
    }

    public function withdrawEarnings(User $user, MarketplaceListing $listing): bool
    {
        if ($user->id !== $listing->user_id) {
            return false;
        }

        $minimumBalance = config('marketplace.minimum_withdrawal', 50);
        $earnings = $listing->getEarningsForUser($user);

        return $earnings >= $minimumBalance;
    }

    public function feature(User $user, MarketplaceListing $listing): bool
    {
        return $user->hasRole(['admin', 'super_admin']);
    }

    public function respondToReview(User $user, MarketplaceListing $listing): bool
    {
        return $user->id === $listing->user_id;
    }
}
```

## Template Dependency Resolution

Templates may depend on other templates, components, or themes. Dependency resolution requires specific permissions.

### Dependency Resolution Permissions

| Action | Permission Required | Description |
|---|---|---|
| View dependencies | `templates.view` | See what a template depends on |
| Add dependency | `templates.update` (owner) | Add a new dependency |
| Remove dependency | `templates.update` (owner) | Remove a dependency |
| Resolve dependencies | `templates.install` | Resolve before installation |
| Verify dependencies | `templates.view` | Check dependency availability |

### Dependency Resolution Service

```php
// app/Services/TemplateDependencyResolver.php

namespace App\Services;

use App\Models\Template;
use App\Models\TemplateDependency;
use App\Models\User;

class TemplateDependencyResolver
{
    /**
     * Resolve all dependencies for a template installation.
     */
    public function resolve(Template $template, User $user): array
    {
        $dependencies = $template->dependencies()->get();
        $resolved = [];
        $unresolved = [];
        $missing = [];

        foreach ($dependencies as $dep) {
            $result = $this->resolveDependency($dep, $user);

            if ($result['resolved']) {
                $resolved[] = $result;
            } else {
                $unresolved[] = $result;
                $missing[] = $dep;
            }
        }

        return [
            'all_resolved' => empty($unresolved),
            'resolved' => $resolved,
            'unresolved' => $unresolved,
            'missing' => $missing,
            'total_dependencies' => $dependencies->count(),
            'resolved_count' => count($resolved),
        ];
    }

    protected function resolveDependency(TemplateDependency $dep, User $user): array
    {
        return match ($dep->dependency_type) {
            'component' => $this->resolveComponent($dep, $user),
            'theme' => $this->resolveTheme($dep, $user),
            'package' => $this->resolvePackage($dep, $user),
            'template' => $this->resolveTemplate($dep, $user),
            default => ['resolved' => false, 'type' => $dep->dependency_type, 'error' => 'Unknown type'],
        };
    }

    protected function resolveComponent(TemplateDependency $dep, User $user): array
    {
        $component = \App\Models\Component::find($dep->dependency_id);

        if (! $component) {
            return ['resolved' => false, 'type' => 'component', 'error' => 'Component not found'];
        }

        if (! in_array($component->status, ['published', 'featured'])) {
            return ['resolved' => false, 'type' => 'component', 'error' => 'Component not published'];
        }

        return [
            'resolved' => true,
            'type' => 'component',
            'id' => $component->id,
            'name' => $component->name,
            'version' => $component->version,
        ];
    }

    protected function resolveTheme(TemplateDependency $dep, User $user): array
    {
        $theme = \App\Models\Theme::find($dep->dependency_id);

        if (! $theme) {
            return ['resolved' => false, 'type' => 'theme', 'error' => 'Theme not found'];
        }

        if (! in_array($theme->status, ['published', 'featured'])) {
            return ['resolved' => false, 'type' => 'theme', 'error' => 'Theme not published'];
        }

        return [
            'resolved' => true,
            'type' => 'theme',
            'id' => $theme->id,
            'name' => $theme->name,
            'version' => $theme->version,
        ];
    }

    protected function resolvePackage(TemplateDependency $dep, User $user): array
    {
        // Package resolution checks composer/npm registry
        return [
            'resolved' => true,
            'type' => 'package',
            'package_name' => $dep->package_name,
            'version_constraint' => $dep->version_constraint,
        ];
    }

    protected function resolveTemplate(TemplateDependency $dep, User $user): array
    {
        $template = Template::find($dep->dependency_id);

        if (! $template) {
            return ['resolved' => false, 'type' => 'template', 'error' => 'Template not found'];
        }

        if (! in_array($template->status, ['published', 'featured'])) {
            return ['resolved' => false, 'type' => 'template', 'error' => 'Template not published'];
        }

        // Check if user has purchased the dependency
        if ($template->price > 0) {
            $purchased = $user->purchases()
                ->where('purchasable_type', Template::class)
                ->where('purchasable_id', $template->id)
                ->where('status', 'completed')
                ->exists();

            if (! $purchased) {
                return [
                    'resolved' => false,
                    'type' => 'template',
                    'error' => 'Template not purchased',
                    'purchase_required' => true,
                    'purchase_url' => "/marketplace/templates/{$template->slug}",
                ];
            }
        }

        return [
            'resolved' => true,
            'type' => 'template',
            'id' => $template->id,
            'name' => $template->name,
            'version' => $template->version,
        ];
    }
}
```

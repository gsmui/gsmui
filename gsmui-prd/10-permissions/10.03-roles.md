# 10.03 — Roles

**Project:** GsmUi
**Domain:** Authorization & RBAC
**Version:** 1.0.0

---

## Purpose

This document defines every role in the GsmUi platform, their hierarchy, the permissions each role grants, and the rules governing role assignment and revocation. Roles are the primary mechanism for grouping permissions — they represent organizational functions, not individual capabilities.

See [10.01-overview.md](./10.01-overview.md) for the authorization overview and [10.02-rbac-architecture.md](./10.02-rbac-architecture.md) for the technical architecture.

## Role Hierarchy

```text
Super Admin
  └── Admin
        └── Editor
              └── Support
                    └── Moderator
                          └── Creator
                                └── Pro User
                                      └── User
                                            └── Guest
```

Each higher role inherits all permissions of the roles below it. The hierarchy is enforced via Spatie Permission's `role_has_roles` table (parent-child relationships).

### Hierarchy Levels

| Level | Role | Can Manage |
|---|---|---|
| 0 | Guest | Nothing |
| 1 | User | Own profile only |
| 2 | Pro User | Own profile + premium features |
| 3 | Creator | Own themes/components + marketplace |
| 4 | Moderator | Content moderation + creator permissions |
| 5 | Support | Order/support + moderator permissions |
| 6 | Editor | Content editing + support permissions |
| 7 | Admin | Full platform + editor permissions |
| 8 | Super Admin | System + admin management |

### Pro User (Level 2)

User with an active paid subscription. Inherits all User permissions.

| Capability | Allowed | Notes |
|---|---|---|
| All User permissions | Yes | Inherited |
| Access premium themes | Yes | Pro-only marketplace items |

```php

// When subscription expires

```

## Role Assignment Rules

### Automatic Assignment

| Trigger | Role | Handler |
|---|---|---|
| User registration + email verification | User | Fortify observer |
| Subscription activated | Pro User | Billing webhook |
| Subscription expired/cancelled | Remove Pro User | Billing webhook |
| First theme published | Creator (optional) | Theme observer |

### Manual Assignment

| Assigner | Can Assign | Can Revoke |
|---|---|---|
| Super Admin | All roles | All roles |
| Admin | User, Pro User, Creator, Moderator, Support, Editor | User, Pro User, Creator, Moderator, Support, Editor |
| Moderator | None | None |
| Support | None | None |
| Creator | None | None |
| Pro User | None | None |
| User | None | None |

### Assignment Constraints

1. **Super Admin cannot be demoted** by anyone other than another Super Admin.
2. **At least one Super Admin** must exist at all times. System prevents removing the last Super Admin.
3. **At least one Admin** must exist. System prevents removing the last Admin.
4. **Pro User role is automatic** — managed by billing, not manual assignment.
5. **Creator role requires approval** — either self-declaration with review, or direct admin assignment.
6. **Role changes are logged** — every assignment and revocation is recorded in the audit log.

## Database Schema

```sql
-- Roles table (Spatie Permission)
CREATE TABLE roles (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(125) NOT NULL,
    guard_name VARCHAR(125) NOT NULL DEFAULT 'web',
    level INT UNSIGNED DEFAULT 0,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    UNIQUE KEY unique_roles (name, guard_name)
);

-- Role hierarchy (parent-child)
CREATE TABLE role_has_roles (
    role_id BIGINT UNSIGNED NOT NULL,
    parent_role_id BIGINT UNSIGNED NOT NULL,
    PRIMARY KEY (role_id, parent_role_id),
    FOREIGN KEY (role_id) REFERENCES roles(id) ON DELETE CASCADE,
    FOREIGN KEY (parent_role_id) REFERENCES roles(id) ON DELETE CASCADE
);

-- User-role assignments
CREATE TABLE model_has_roles (
    role_id BIGINT UNSIGNED NOT NULL,
    model_type VARCHAR(255) NOT NULL,
    model_id BIGINT UNSIGNED NOT NULL,
    PRIMARY KEY (role_id, model_id, model_type),
    FOREIGN KEY (role_id) REFERENCES roles(id) ON DELETE CASCADE,
    INDEX model_has_roles_model_id_index (model_id, model_type)
);
```

## Seeding

```php
// database/seeders/RoleSeeder.php
class RoleSeeder extends Seeder
{
    public function run(): void
    {
        $roles = [
            ['name' => 'user', 'level' => 1],
            ['name' => 'pro_user', 'level' => 2],
            ['name' => 'creator', 'level' => 3],
            ['name' => 'moderator', 'level' => 4],
            ['name' => 'support', 'level' => 5],
            ['name' => 'editor', 'level' => 6],
            ['name' => 'admin', 'level' => 7],
            ['name' => 'super_admin', 'level' => 8],
        ];

        foreach ($roles as $role) {
            Role::create($role);
        }

        // Set up hierarchy
        $superAdmin = Role::findByName('super_admin');
        $admin = Role::findByName('admin');
        $editor = Role::findByName('editor');
        $support = Role::findByName('support');
        $moderator = Role::findByName('moderator');
        $creator = Role::findByName('creator');
        $proUser = Role::findByName('pro_user');
        $user = Role::findByName('user');

        $superAdmin->addChildRole($admin);
        $admin->addChildRole($editor);
        $editor->addChildRole($support);
        $support->addChildRole($moderator);
        $moderator->addChildRole($creator);
        $creator->addChildRole($proUser);
        $proUser->addChildRole($user);
    }
}
```

## Model Integration

```php
// app/Models/User.php
use Spatie\Permission\Traits\HasRoles;

class User extends Authenticatable
{
    use HasRoles;

    // Cache permissions per user
    protected $cacheDriver = 'redis';

    // Check multiple roles at once
    public function isContentManager(): bool
    {
        return $this->hasAnyRole(['admin', 'editor', 'moderator']);
    }

    // Check if user can manage a specific resource
    public function canManageTheme(Theme $theme): bool
    {
        return $this->hasPermissionTo('themes.update') 
            && $theme->user_id === $this->id;
    }
}
```

## Edge Cases

* **User with multiple roles:** The union of all permissions from all assigned roles applies. If a user is both `creator` and `moderator`, they get permissions from both.
* **Role revocation while active session:** The user's cached permissions are cleared immediately. Existing sessions continue until the next permission check.
* **Pro User role auto-removal:** When a subscription expires, the billing webhook removes the `pro_user` role. The user reverts to `user` level permissions.
* **Creator role auto-removal:** When all of a creator's published items are removed, the creator role is flagged for review but not automatically removed.
* **Admin demotion:** Only Super Admin can demote an Admin. The Admin cannot demote themselves.
* **Last Super Admin protection:** The system prevents removing the last Super Admin account to maintain platform access.

## Role Lifecycle Management

### Role Creation

New roles are created via the admin panel or database seeder. Custom roles must follow naming conventions and cannot conflict with seeded roles.

```php
// Creating a custom role
Role::create([
    'name' => 'content_reviewer',
    'guard_name' => 'web',
    'level' => 4, // Between moderator and support
]);
```

### Role Modification

Seeded roles (user, pro_user, creator, moderator, support, editor, admin, super_admin) cannot be modified by admins. Custom roles can be modified by admins.

```php
// RolePolicy
public function update(User $user, Role $role): bool
{
    // Seeded roles are immutable
    if ($role->is_seeded) {
        return false;
    }
    
    return $user->hasPermissionTo('roles.update');
}
```

### Role Deletion

Only Super Admin can delete roles. Deleting a role revokes it from all users who hold it.

```php
// Role deletion with cascade
public function delete(User $user, Role $role): bool
{
    if (! $user->hasRole('super_admin')) {
        return false;
    }

    // Prevent deletion of roles with users
    if ($role->users()->count() > 0) {
        throw new \Exception('Cannot delete role with active users.');
    }

    $role->delete();
    Permission::forgetCache();
    
    return true;
}
```

### Role Archiving

Instead of deletion, roles can be archived to preserve audit history:

```php
// Archive role instead of deleting
$role->update(['archived' => true, 'archived_at' => now()]);
$role->users()->detach(); // Remove from all users
```

### Assignment Validation

```php
// Validating role assignment
class AssignRoleAction
{
    public function execute(User $assigner, User $target, string $roleName): void
    {
        // Check assigner has permission
        if (! $assigner->hasPermissionTo('roles.assign')) {
            throw new AuthorizationException('Insufficient permissions.');
        }

        // Prevent self-assignment of elevated roles
        if ($assigner->id === $target->id && in_array($roleName, ['admin', 'super_admin'])) {
            throw new AuthorizationException('Cannot self-assign elevated roles.');
        }

        // Prevent assigning super_admin
        if ($roleName === 'super_admin' && ! $assigner->hasRole('super_admin')) {
            throw new AuthorizationException('Only Super Admin can assign Super Admin role.');
        }

        // Prevent assigning roles the assigner doesn't have
        if (! $assigner->hasRole($roleName) && ! $assigner->hasRole('super_admin')) {
            throw new AuthorizationException('Cannot assign roles you do not possess.');
        }

        // Check target doesn't already have role
        if ($target->hasRole($roleName)) {
            throw new ValidationException('User already has this role.');
        }

        // Assign role
        $target->assignRole($roleName);
        Permission::forgetCache();

        // Audit log
        activity()
            ->causedBy($assigner)
            ->performedOn($target)
            ->withProperties(['role' => $roleName])
            ->log('role_assigned');
    }
}
```

## Role Conflict Resolution

### Multiple Role Scenarios

When a user holds multiple roles, permissions are unioned. However, some role combinations may create conflicts:

| Conflict | Resolution |
|---|---|
| Admin + Creator | Admin permissions take precedence |
| Moderator + Creator | Both sets apply, ownership checks still apply |
| Support + Editor | Both sets apply independently |
| Super Admin + any | Super Admin bypass applies |

### Role Exclusivity Rules

Some roles are mutually exclusive:

```php
// Preventing exclusive role combinations
class RoleAssignmentValidator
{
    private array $exclusiveRoles = [
        ['admin', 'creator'], // Admin should not also be creator
        ['super_admin', 'creator'], // Super Admin should not be creator
    ];

    public function validate(User $user, string $newRole): void
    {
        foreach ($this->exclusiveRoles as $group) {
            if (in_array($newRole, $group)) {
                $existing = array_intersect($user->roles->pluck('name')->toArray(), $group);
                if (count($existing) > 0) {
                    throw new ValidationException(
                        "Role {$newRole} is mutually exclusive with: " . implode(', ', $existing)
                    );
                }
            }
        }
    }
}
```

## Role Migration Strategies

### From Boolean Flags

If your existing system uses boolean flags like `is_admin`, `is_moderator`, migrate to roles:

```php
// Migration script
class MigrateBooleanFlagsToRoles extends Migration
{
    public function up(): void
    {
        // Create roles
        Role::create(['name' => 'admin', 'level' => 7]);
        Role::create(['name' => 'moderator', 'level' => 4]);
        Role::create(['name' => 'creator', 'level' => 3]);

        // Migrate users
        User::where('is_admin', true)->each(function ($user) {
            $user->assignRole('admin');
        });

        User::where('is_moderator', true)->each(function ($user) {
            $user->assignRole('moderator');
        });

        User::where('is_creator', true)->each(function ($user) {
            $user->assignRole('creator');
        });

        // Remove boolean columns
        Schema::table('users', function (Blueprint $table) {
            $table->dropColumn(['is_admin', 'is_moderator', 'is_creator']);
        });
    }
}
```

### From String-Based Roles

If your system uses a `role` string column:

```php
// Migration from string-based roles
class MigrateStringRoles extends Migration
{
    public function up(): void
    {
        $roleMap = [
            'admin' => 'admin',
            'moderator' => 'moderator',
            'creator' => 'creator',
            'user' => 'user',
        ];

        User::all()->each(function ($user) use ($roleMap) {
            $roleName = $roleMap[$user->role] ?? 'user';
            $user->assignRole($roleName);
        });

        Schema::table('users', function (Blueprint $table) {
            $table->dropColumn('role');
        });
    }
}
```

```php
class RoleStatistics
```

### Role Health Checks

```php
// Automated role health checks
class RoleHealthCheck
{
    public function check(): array
    {
        $issues = [];

        // Check for users with no roles
        $rolelessUsers = User::whereDoesntHave('roles')->count();
        if ($rolelessUsers > 0) {
            $issues[] = "{$rolelessUsers} users have no assigned role";
        }

        // Check for orphaned role assignments
        $orphaned = DB::table('model_has_roles')
            ->whereNotIn('model_id', User::pluck('id'))
            ->count();
        if ($orphaned > 0) {
            $issues[] = "{$orphaned} orphaned role assignments found";
        }

        // Check for role hierarchy consistency
        $circular = $this->detectCircularHierarchy();
        if ($circular) {
            $issues[] = "Circular role hierarchy detected";
        }
```

## Role Best Practices

### Naming Conventions

- Use lowercase with underscores: `content_reviewer`, `super_admin`
- Avoid abbreviations: `moderator` not `mod`
- Use descriptive names: `billing_manager` not `billing`

### Permission Assignment

- Assign permissions to roles, not directly to users
- Use the principle of least privilege
- Document why each permission is assigned
- Review permissions quarterly

### Role Hierarchy

- Keep hierarchy shallow (max 10 levels)
- Document inheritance relationships
- Test hierarchy changes thoroughly
- Monitor for circular references

### Security

- Log all role changes
- Alert on elevated role assignments
- Prevent self-assignment of admin roles
- Require approval for sensitive role changes

### Role Service Layer

```php
// app/Services/RoleService.php

class RoleService
{
    public function __construct(
        private PermissionRegistrar $permissionRegistrar,
        private AuditLogger $auditLogger
    ) {}

    public function assignRole(User $assigner, User $target, string $roleName, ?string $reason = null): void
    {
        // Validate assignment
        $this->validateAssignment($assigner, $target, $roleName);

        // Perform assignment
        $target->assignRole($roleName);

        // Clear cache
        $this->permissionRegistrar->forgetCache();

        // Log assignment
        $this->auditLogger->logRoleAssignment($assigner, $target, $roleName, $reason);

        // Record in history
        $this->recordAssignment($target, $roleName, 'assigned', $assigner->id, $reason);

        // Dispatch event
        event(new RoleAssigned($target, $roleName, $assigner));
    }

    public function revokeRole(User $revoker, User $target, string $roleName, ?string $reason = null): void
    {
        // Validate revocation
        $this->validateRevocation($revoker, $target, $roleName);

        // Perform revocation
        $target->removeRole($roleName);

        // Clear cache
        $this->permissionRegistrar->forgetCache();

        // Log revocation
        $this->auditLogger->logRoleRevocation($revoker, $target, $roleName, $reason);

        // Record in history
        $this->recordAssignment($target, $roleName, 'revoked', $revoker->id, $reason);

        // Dispatch event
        event(new RoleRevoked($target, $roleName, $revoker));
    }

    public function syncRoles(User $syncer, User $target, array $roleNames): void
    {
        $oldRoles = $target->roles->pluck('name')->toArray();

        $target->syncRoles($roleNames);

        $newRoles = $target->fresh()->roles->pluck('name')->toArray();

        $added = array_diff($newRoles, $oldRoles);
        $removed = array_diff($oldRoles, $newRoles);

        foreach ($added as $role) {
            $this->auditLogger->logRoleAssignment($syncer, $target, $role);
            $this->recordAssignment($target, $role, 'assigned', $syncer->id);
        }

        foreach ($removed as $role) {
            $this->auditLogger->logRoleRevocation($syncer, $target, $role);
            $this->recordAssignment($target, $role, 'revoked', $syncer->id);
        }

        $this->permissionRegistrar->forgetCache();

        event(new RolesSynced($target, $oldRoles, $newRoles));
    }

    protected function validateAssignment(User $assigner, User $target, string $roleName): void
    {
        // Check assigner has permission
        if (! $assigner->hasPermissionTo('roles.assign')) {
            throw new AuthorizationException('Insufficient permissions to assign roles.');
        }

        // Check role exists
        if (! Role::where('name', $roleName)->exists()) {
            throw new ModelNotFoundException("Role '{$roleName}' not found.");
        }

        // Prevent self-assignment of elevated roles
        if ($assigner->id === $target->id && in_array($roleName, ['admin', 'super_admin'])) {
            throw new AuthorizationException('Cannot self-assign elevated roles.');
        }

        // Prevent assigning super_admin
        if ($roleName === 'super_admin' && ! $assigner->hasRole('super_admin')) {
            throw new AuthorizationException('Only Super Admin can assign Super Admin role.');
        }

        // Prevent assigning roles the assigner doesn't have
        if (! $assigner->hasRole($roleName) && ! $assigner->hasRole('super_admin')) {
            throw new AuthorizationException('Cannot assign roles you do not possess.');
        }

        // Check target doesn't already have role
        if ($target->hasRole($roleName)) {
            throw new ValidationException('User already has this role.');
        }

        // Check role user limit
        $role = Role::where('name', $roleName)->first();
        if ($role->max_users && $role->users()->count() >= $role->max_users) {
            throw new ValidationException('Role has reached maximum user limit.');
        }
    }

    protected function validateRevocation(User $revoker, User $target, string $roleName): void
    {
        // Check revoker has permission
        if (! $revoker->hasPermissionTo('roles.revoke')) {
            throw new AuthorizationException('Insufficient permissions to revoke roles.');
        }

        // Check target has the role
        if (! $target->hasRole($roleName)) {
            throw new ValidationException('User does not have this role.');
        }

        // Prevent revoking super_admin from non-super-admin
        if ($roleName === 'super_admin' && ! $revoker->hasRole('super_admin')) {
            throw new AuthorizationException('Only Super Admin can revoke Super Admin role.');
        }

        // Prevent revoking last super_admin
        if ($roleName === 'super_admin' && User::role('super_admin')->count() <= 1) {
            throw new ValidationException('Cannot revoke the last Super Admin role.');
        }

        // Prevent revoking last admin
        if ($roleName === 'admin' && User::role('admin')->count() <= 1) {
            throw new ValidationException('Cannot revoke the last Admin role.');
        }
    }

    protected function recordAssignment(User $user, string $roleName, string $action, ?int $assignedBy, ?string $reason = null): void
    {
        DB::table('role_assignment_history')->insert([
            'user_id' => $user->id,
            'role_id' => Role::where('name', $roleName)->first()->id,
            'action' => $action,
            'assigned_by' => $assignedBy,
            'reason' => $reason,
            'created_at' => now(),
        ]);
    }
}
```

## Role Lifecycle Management

### Role State Transitions

Roles follow a defined state machine that governs their lifecycle from creation through retirement. Understanding these transitions is critical for maintaining authorization integrity.

```
draft → active → archived
         ↓
      suspended → active (reactivation)
         ↓
      deleted (soft delete)
```

#### State Definitions

| State | Description | Permissions Active | Users Assigned |
|---|---|---|---|
| `draft` | Role created but not yet deployed | No | No |
| `active` | Role in production use | Yes | Yes |
| `archived` | Role retired, no new assignments | Yes (existing) | Yes (existing) |
| `suspended` | Role temporarily disabled | No | Yes (frozen) |
| `deleted` | Role permanently removed | No | No |

#### Transition Rules

```php
// app/Services/RoleLifecycleManager.php

class RoleLifecycleManager
{
    /**
     * Allowed state transitions.
     */
    private const TRANSITIONS = [
        'draft'     => ['active'],
        'active'    => ['archived', 'suspended'],
        'suspended' => ['active', 'deleted'],
        'archived'  => ['active', 'deleted'],
        'deleted'   => [],
    ];

    public function transition(Role $role, string $targetState): void
    {
        $currentState = $role->status ?? 'active';

        if (! in_array($targetState, self::TRANSITIONS[$currentState] ?? [])) {
            throw new InvalidRoleStateException(
                "Cannot transition role from [{$currentState}] to [{$targetState}]"
            );
        }

        $role->update(['status' => $targetState]);
        $this->handleTransitionSideEffects($role, $currentState, $targetState);
    }

    protected function handleTransitionSideEffects(
        Role $role,
        string $from,
        string $to
    ): void {
        match ($to) {
            'active' => $this->onActivate($role, $from),
            'suspended' => $this->onSuspend($role),
            'archived' => $this->onArchive($role),
            'deleted' => $this->onDelete($role),
            default => null,
        };
    }

    protected function onActivate(Role $role, string $from): void
    {
        if ($from === 'suspended') {
            // Clear cached permissions for all affected users
            $this->clearPermissionCacheForRole($role);
        }

        ActivityLog::roleActivated($role);
    }

    protected function onSuspend(Role $role): void
    {
        // Freeze permission checks — users retain role but cannot use its permissions
        $role->update(['permissions_frozen' => true]);
        $this->clearPermissionCacheForRole($role);

        ActivityLog::roleSuspended($role);
    }

    protected function onArchive(Role $role): void
    {
        $role->update(['archived_at' => now()]);
        ActivityLog::roleArchived($role);
    }

    protected function onDelete(Role $role): void
    {
        $this->clearPermissionCacheForRole($role);
        ActivityLog::roleDeleted($role);
    }

    protected function clearPermissionCacheForRole(Role $role): void
    {
        $users = User::role($role->name)->get();
        foreach ($users as $user) {
            $user->forgetCachedPermissions();
        }
    }
}
```

```php
class RoleComparator
{
    public function compare(Role $roleA, Role $roleB): array
    {
        $permsA = $roleA->permissions->pluck('name')->sort()->values();
        $permsB = $roleB->permissions->pluck('name')->sort()->values();

        return [
            'only_in_a' => $permsA->diff($permsB)->values()->toArray(),
            'only_in_b' => $permsB->diff($permsA)->values()->toArray(),
            'shared' => $permsA->intersect($permsB)->values()->toArray(),
            'similarity_score' => $this->calculateSimilarity($permsA, $permsB),
        ];
    }

    protected function calculateSimilarity($permsA, $permsB): float
    {
        if ($permsA->isEmpty() && $permsB->isEmpty()) {
            return 1.0;
        }

        $intersection = $permsA->intersect($permsB)->count();
        $union = $permsA->concat($permsB)->unique()->count();

        return round($intersection / $union, 2);
    }
}
```

### Hierarchical Permission Resolution

When checking permissions, the system walks up the inheritance chain:

```php
// app/Services/HierarchicalRoleResolver.php

class HierarchicalRoleResolver
{
    /**
     * Get all roles including inherited ones for a user.
     */
    public function getAllInheritedRoles(User $user): Collection
    {
        $directRoles = $user->roles;
        $allRoles = $directRoles->keyBy('name');

        foreach ($directRoles as $role) {
            $inherited = $this->resolveInheritedRoles($role);
            foreach ($inherited as $inheritedRole) {
                $allRoles->put($inheritedRole->name, $inheritedRole);
            }
        }

        return $allRoles->values();
    }

    protected function resolveInheritedRoles(Role $role, array $visited = []): Collection
    {
        if (in_array($role->name, $visited)) {
            return collect(); // prevent infinite loops
        }

        $visited[] = $role->name;
        $inherited = collect();

        $parentRoles = DB::table('role_inherits_roles')
            ->where('inherits_role_id', $role->id)
            ->pluck('role_id');

        $parents = Role::whereIn('id', $parentRoles)->get();

        foreach ($parents as $parent) {
            $inherited->push($parent);
            $inherited = $inherited->concat(
                $this->resolveInheritedRoles($parent, $visited)
            );
        }

        return $inherited->unique('name');
    }
}
```

### Circular Reference Detection

Prevent infinite loops in role inheritance:

```php
// app/Services/CircularReferenceDetector.php

class CircularReferenceDetector
{
    /**
     * Detect circular references in role inheritance.
     *
     * @throws CircularReferenceException
     */
    public function detect(Role $role, string $newParentName): void
    {
        $visited = [$role->name];
        $queue = [$newParentName];

        while (! empty($queue)) {
            $current = array_shift($queue);

            if (in_array($current, $visited)) {
                throw new CircularReferenceException(
                    "Circular reference detected: {$role->name} → {$current}"
                );
            }

            $visited[] = $current;

            $children = DB::table('role_inherits_roles')
                ->where('role_id', $this->getRoleId($current))
                ->pluck('inherits_role_id');

            foreach ($children as $childId) {
                $child = Role::find($childId);
                if ($child) {
                    $queue[] = $child->name;
                }
            }
        }
    }

    protected function getRoleId(string $name): int
    {
        return Role::where('name', $name)->firstOrFail()->id;
    }
}
```

```php
// app/Services/RoleExporter.php

class RoleExporter
{
    public function export(string $format = 'php'): string
    {
        $roles = Role::with('permissions')->get();

        $data = $roles->map(function (Role $role) {
            return [
                'name' => $role->name,
                'guard_name' => $role->guard_name,
                'description' => $role->description ?? '',
                'permissions' => $role->permissions->pluck('name')->toArray(),
                'hierarchy' => $this->getInheritance($role),
            ];
        });

        return match ($format) {
            'php' => $this->exportAsPhp($data),
            'json' => $data->toJson(JSON_PRETTY_PRINT),
            'yaml' => $this->exportAsYaml($data),
            default => throw new \InvalidArgumentException("Unsupported format: {$format}"),
        };
    }

    protected function getInheritance(Role $role): array
    {
        return DB::table('role_inherits_roles')
            ->where('role_id', $role->id)
            ->join('roles', 'roles.id', '=', 'inherits_role_id')
            ->pluck('roles.name')
            ->toArray();
    }

    protected function exportAsPhp(Collection $data): string
    {
        $export = "<?php\n\nreturn [\n";
        foreach ($data as $role) {
            $export .= "    '{$role['name']}' => [\n";
            $export .= "        'description' => '{$role['description']}',\n";
            $export .= "        'permissions' => " . var_export($role['permissions'], true) . ",\n";
            if (! empty($role['hierarchy'])) {
                $export .= "        'inherits' => " . var_export($role['hierarchy'], true) . ",\n";
            }
            $export .= "    ],\n";
        }
        $export .= "];\n";
        return $export;
    }
}
```

### Import Role Configuration

Import roles from an exported configuration file:

```php
// app/Services/RoleImporter.php

class RoleImporter
{
    public function importFromFile(string $path): array
    {
        $extension = pathinfo($path, PATHINFO_EXTENSION);

        $data = match ($extension) {
            'php' => require $path,
            'json' => json_decode(file_get_contents($path), true),
            default => throw new \InvalidArgumentException("Unsupported format: {$extension}"),
        };

        return $this->import($data);
    }

    public function import(array $data): array
    {
        $results = ['created' => 0, 'updated' => 0, 'errors' => []];

        DB::transaction(function () use ($data, &$results) {
            foreach ($data as $roleName => $config) {
                try {
                    $role = Role::firstOrCreate(
                        ['name' => $roleName, 'guard_name' => 'web'],
                        ['description' => $config['description'] ?? '']
                    );

                    // Sync permissions
                    $permissionNames = $config['permissions'] ?? [];
                    $permissions = Permission::whereIn('name', $permissionNames)->get();
                    $role->syncPermissions($permissions);

                    // Sync inheritance
                    if (! empty($config['inherits'])) {
                        $this->syncInheritance($role, $config['inherits']);
                    }

                    $results[$role->wasRecentlyCreated ? 'created' : 'updated']++;
                } catch (\Exception $e) {
                    $results['errors'][] = "{$roleName}: {$e->getMessage()}";
                }
            }
        });

        return $results;
    }

    protected function syncInheritance(Role $role, array $parentNames): void
    {
        $parentIds = Role::whereIn('name', $parentNames)->pluck('id')->toArray();

        DB::table('role_inherits_roles')
            ->where('role_id', $role->id)
            ->delete();

        foreach ($parentIds as $parentId) {
            DB::table('role_inherits_roles')->insert([
                'role_id' => $role->id,
                'inherits_role_id' => $parentId,
                'created_at' => now(),
                'updated_at' => now(),
            ]);
        }
    }
}
```

## Role Conflict Resolution

### Permission Conflicts

When two roles grant conflicting permissions, the system uses a resolution strategy:

```php
// app/Services/PermissionConflictResolver.php

class PermissionConflictResolver
{
    /**
     * Resolution strategies.
     */
    private const STRATEGIES = [
        'deny_wins' => 'explicit_deny_overrides_grant',
        'grant_wins' => 'grant_overrides_explicit_deny',
        'most_privileged' => 'higher_role_wins',
    ];

    public function resolve(User $user, string $permission, string $strategy = 'most_privileged'): bool
    {
        return match ($strategy) {
            'deny_wins' => $this->denyWinsResolution($user, $permission),
            'grant_wins' => $this->grantWinsResolution($user, $permission),
            'most_privileged' => $this->mostPrivilegedResolution($user, $permission),
            default => $user->hasPermissionTo($permission),
        };
    }

    protected function denyWinsResolution(User $user, string $permission): bool
    {
        // Check if any role explicitly denies this permission
        $denied = DB::table('permission_denies')
            ->where('user_id', $user->id)
            ->where('permission_name', $permission)
            ->exists();

        if ($denied) {
            return false;
        }

        return $user->hasPermissionTo($permission);
    }

    protected function grantWinsResolution(User $user, string $permission): bool
    {
        return $user->hasPermissionTo($permission);
    }

    protected function mostPrivilegedResolution(User $user, string $permission): bool
    {
        $roleHierarchy = app(HierarchicalRoleResolver::class);
        $allRoles = $roleHierarchy->getAllInheritedRoles($user);

        // Sort by hierarchy level (highest first)
        $sorted = $allRoles->sortByDesc(function ($role) {
            return $this->getHierarchyLevel($role);
        });

        // First role's verdict wins
        foreach ($sorted as $role) {
            if ($role->permissions->contains('name', $permission)) {
                return true;
            }
        }

        return false;
    }

    protected function getHierarchyLevel(Role $role): int
    {
        return match ($role->name) {
            'super_admin' => 100,
            'admin' => 80,
            'moderator' => 60,
            'editor' => 40,
            'viewer' => 20,
            default => 10,
        };
    }
}
```

## Role Audit and Compliance

### Compliance Report Generation

Generate compliance reports showing role assignments and permission coverage:

```php
// app/Services/ComplianceReporter.php

class ComplianceReporter
{
    public function generateReport(Carbon $from, Carbon $to): array
    {
        return [
            'period' => "{$from->toDateString()} to {$to->toDateString()}",
            'role_summary' => $this->getRoleSummary(),
            'permission_usage' => $this->getPermissionUsage($from, $to),
            'escalation_log' => $this->getEscalationLog($from, $to),
            'dormant_roles' => $this->getDormantRoles(),
            'excessive_permissions' => $this->getExcessivePermissions(),
        ];
    }

    protected function getRoleSummary(): array
    {
        return Role::withCount('users')
            ->get()
            ->map(fn ($role) => [
                'name' => $role->name,
                'user_count' => $role->users_count,
                'permission_count' => $role->permissions()->count(),
            ])
            ->toArray();
    }

    protected function getPermissionUsage(Carbon $from, Carbon $to): array
    {
        return Activity::where('description', 'permission_checked')
            ->whereBetween('created_at', [$from, $to])
            ->selectRaw('properties->>"$.permission" as permission, COUNT(*) as checks')
            ->groupBy('permission')
            ->orderByDesc('checks')
            ->get()
            ->toArray();
    }

    protected function getEscalationLog(Carbon $from, Carbon $to): array
    {
        return Activity::where('description', 'role_assigned')
            ->whereBetween('created_at', [$from, $to])
            ->with('causer', 'subject')
            ->orderByDesc('created_at')
            ->get()
            ->toArray();
    }

    protected function getDormantRoles(): array
    {
        return Role::withCount(['users' => function ($q) {
            $q->where('last_active_at', '>=', now()->subDays(90));
        }])
        ->having('users_count', '=', 0)
        ->get()
        ->map(fn ($role) => [
            'name' => $role->name,
            'total_users' => $role->users()->count(),
            'active_users' => $role->users_count,
        ])
        ->toArray();
    }

    protected function getExcessivePermissions(): array
    {
        return User::withCount('roles')
            ->withCount('directPermissions')
            ->having('roles_count', '>', 3)
            ->orHaving('direct_permissions_count', '>', 5)
            ->get()
            ->map(fn ($user) => [
                'id' => $user->id,
                'name' => $user->name,
                'roles' => $user->roles->pluck('name'),
                'direct_permissions' => $user->directPermissions->count(),
            ])
            ->toArray();
    }
}
```

### Automated Compliance Checks

Run scheduled compliance checks to detect anomalies:

```php
// app/Console/Commands/ComplianceCheckCommand.php

class ComplianceCheckCommand extends Command
{
    protected $signature = 'permissions:compliance-check';
    protected $description = 'Run automated compliance checks on role assignments';

    public function handle(ComplianceReporter $reporter): int
    {
        $issues = [];

        // Check 1: Users with super_admin role that shouldn't have it
        $unauthorizedSuperAdmins = User::role('super_admin')
            ->whereNotIn('id', config('permissions.authorized_super_admin_ids', []))
            ->get();

        if ($unauthorizedSuperAdmins->isNotEmpty()) {
            $issues[] = "Unauthorized super_admin accounts: " .
                $unauthorizedSuperAdmins->pluck('email')->implode(', ');
        }

        // Check 2: Roles with more permissions than super_admin
        $superAdminPermCount = Role::where('name', 'super_admin')
            ->first()?->permissions()->count() ?? 0;

        $overprivilegedRoles = Role::withCount('permissions')
            ->where('permissions_count', '>', $superAdminPermCount)
            ->get();

        if ($overprivilegedRoles->isNotEmpty()) {
            $issues[] = "Roles exceeding super_admin permissions: " .
                $overprivilegedRoles->pluck('name')->implode(', ');
        }

        // Check 3: Dormant roles (no users in 90 days)
        $dormantRoles = Role::withCount(['users' => function ($q) {
            $q->where('last_active_at', '>=', now()->subDays(90));
        }])
        ->having('users_count', '=', 0)
        ->get();

        if ($dormantRoles->isNotEmpty()) {
            $issues[] = "Dormant roles (90+ days): " .
                $dormantRoles->pluck('name')->implode(', ');
        }

        // Report
        if (empty($issues)) {
            $this->info('All compliance checks passed.');
            return self::SUCCESS;
        }

        foreach ($issues as $issue) {
            $this->warn("⚠ {$issue}");
        }

        // Notify admins
        Notification::send(
            User::role('super_admin')->get(),
            new ComplianceIssueNotification($issues)
        );

        return self::FAILURE;
    }
}
```

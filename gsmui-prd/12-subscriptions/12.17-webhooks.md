## Purpose

Define how payment provider webhooks are received, validated, processed, and reconciled. Webhooks are the primary mechanism for keeping subscription state synchronized with payment providers.

## Webhook Architecture

```text
Payment Provider Event
    ↓
HTTP POST /webhooks/{provider}
    ↓
Signature Verification
    ↓
Webhook Parsing (provider-specific)
    ↓
Normalized WebhookEvent
    ↓
Event Dispatcher
    ↓
Listeners (state transitions, notifications, logging)
```

## Webhook Verification

```php
class WebhookVerifier
{
    public function verify(string $provider, Request $request): bool
    {
        return match ($provider) {
            'stripe' => $this->verifyStripe($request),
            'paddle' => $this->verifyPaddle($request),
            'lemon-squeezy' => $this->verifyLemonSqueezy($request),
            default => throw new UnknownProviderException($provider),
        };
    }

    protected function verifyStripe(Request $request): bool
    {
        $payload = $request->getContent();
        $sigHeader = $request->header('Stripe-Signature');
        $secret = config('billing.providers.stripe.webhook_secret');

        try {
            \Stripe\Webhook::constructEvent($payload, $sigHeader, $secret);
            return true;
        } catch (\UnexpectedValueException|\Stripe\Exception\SignatureVerificationException) {
            return false;
        }
    }
}
```

### Invoice Paid

```php
class InvoicePaidHandler
{
    public function handle(WebhookEvent $event): void
    {
        $subscriptionId = $event->payload['data']['object']['subscription'];
        $subscription = $this->findSubscription($event->provider, $subscriptionId);

        if (!$subscription) {
            return; // Webhook arrived before subscription created
        }

        if ($subscription->status === 'past_due') {
            // Recovered from grace period
            $subscription->status = 'active';
            $subscription->save();

            app(EntitlementService::class)->synchronize($subscription);
            SubscriptionPaymentRecovered::dispatch($subscription);
        }

        // Log renewal
        $subscription->statusHistories()->create([
            'from_status' => $subscription->status,
            'to_status' => 'active',
            'reason' => 'Invoice paid',
        ]);

        SubscriptionRenewed::dispatch($subscription);
    }
}
```

## Idempotency

```php
class IdempotencyMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $idempotencyKey = $request->header('Idempotency-Key')
            ?? $request->input('id')
            ?? md5($request->getContent());

        $processed = Cache::get("webhook_processed:{$idempotencyKey}");

        if ($processed) {
            return response()->json(['status' => 'already_processed'], 200);
        }

        $response = $next($request);

        Cache::put("webhook_processed:{$idempotencyKey}", true, 3600);

        return $response;
    }
}
```

## Webhook Processing Pipeline

### Pipeline Stages

The webhook processing pipeline consists of multiple stages that ensure reliable, idempotent, and auditable processing of incoming webhook events.

```text
Stage 1: Receipt
    ↓
    HTTP request received
    Raw payload captured
    Provider identified
    ↓
Stage 2: Verification
    ↓
    Signature validation
    Payload integrity check
    Timestamp validation (replay protection)
    ↓
Stage 3: Parsing
    ↓
    Provider-specific extraction
    Normalized WebhookEvent creation
    Event type classification
    ↓
Stage 4: Idempotency Check
    ↓
    Deduplication key lookup
    Cache/database check
    Duplicate detection
    ↓
Stage 5: Dispatch
    ↓
    Event bus dispatch
    Listener resolution
    Queue assignment
    ↓
Stage 6: Processing
    ↓
    Business logic execution
    State transitions
    Side effects
    ↓
Stage 7: Response
    ↓
    HTTP 200 response
    Logging
    Monitoring
```

### Pipeline Implementation

```php
class WebhookProcessingPipeline
{
    public function __construct(
        private WebhookVerifier $verifier,
        private WebhookParser $parser,
        private WebhookIdempotencyChecker $idempotency,
        private WebhookLogger $logger,
    ) {}

    public function process(string $provider, Request $request): Response
    {
        $startTime = microtime(true);

        try {
            // Stage 1: Receipt
            $this->logger->logReceived($provider, $request);

            // Stage 2: Verification
            if (!$this->verifier->verify($provider, $request)) {
                $this->logger->logVerificationFailed($provider, $request);
                return response()->json(['error' => 'Invalid signature'], 400);
            }

            // Stage 3: Parsing
            $event = $this->parser->parse($provider, $request);

            if ($event->type === WebhookEventType::Unknown) {
                $this->logger->logUnhandled($provider, $event);
                return response()->json(['status' => 'unhandled_event_type'], 200);
            }

            // Stage 4: Idempotency Check
            if ($this->idempotency->isDuplicate($event)) {
                $this->logger->logDuplicate($provider, $event);
                return response()->json(['status' => 'already_processed'], 200);
            }

            // Stage 5: Dispatch
            $this->dispatchEvent($event);

            // Stage 6: Response
            $elapsed = (microtime(true) - $startTime) * 1000;
            $this->logger->logProcessed($provider, $event, $elapsed);

            return response()->json(['status' => 'processed'], 200);
        } catch (Exception $e) {
            $this->logger->logError($provider, $e, $request);
            throw $e;
        }
    }

    private function dispatchEvent(WebhookEvent $event): void
    {
        $handlerClass = $this->resolveHandler($event->type);

        if ($handlerClass) {
            $handler = app($handlerClass);
            $handler->handle($event);
        }
    }

    private function resolveHandler(WebhookEventType $type): ?string
    {
        return match ($type) {
            WebhookEventType::InvoicePaid => InvoicePaidHandler::class,
            WebhookEventType::InvoicePaymentFailed => InvoicePaymentFailedHandler::class,
            WebhookEventType::SubscriptionCreated => SubscriptionCreatedHandler::class,
            WebhookEventType::SubscriptionUpdated => SubscriptionUpdatedHandler::class,
            WebhookEventType::SubscriptionDeleted => SubscriptionDeletedHandler::class,
            WebhookEventType::SubscriptionPaused => SubscriptionPausedHandler::class,
            WebhookEventType::SubscriptionResumed => SubscriptionResumedHandler::class,
            WebhookEventType::PaymentMethodAttached => PaymentMethodAttachedHandler::class,
            WebhookEventType::PaymentMethodDetached => PaymentMethodDetachedHandler::class,
            WebhookEventType::CustomerUpdated => CustomerUpdatedHandler::class,
            WebhookEventType::CustomerDeleted => CustomerDeletedHandler::class,
            default => null,
        };
    }
}
```

### Subscription Created Handler

```php
class SubscriptionCreatedHandler
{
    public function handle(WebhookEvent $event): void
    {
        $providerSubscriptionId = $event->payload['data']['object']['id'];
        $customerId = $event->payload['data']['object']['customer'];

        // Find or create user from customer ID
        $user = $this->resolveUser($event->provider, $customerId);

        if (!$user) {
            Log::warning("Cannot resolve user for customer: {$customerId}");
            return;
        }

        // Find matching plan
        $plan = $this->resolvePlan($event);

        if (!$plan) {
            Log::warning("Cannot resolve plan for subscription: {$providerSubscriptionId}");
            return;
        }

        // Create or update subscription
        $idColumn = "{$event->provider}_id";
        $subscription = Subscription::updateOrCreate(
            [$idColumn => $providerSubscriptionId],
            [
                'user_id' => $user->id,
                'plan_id' => $plan->id,
                'status' => 'active',
                'quantity' => $event->payload['data']['object']['items']['data'][0]['quantity'] ?? 1,
                'current_period_start' => Carbon::createFromTimestamp(
                    $event->payload['data']['object']['current_period_start']
                ),
                'current_period_end' => Carbon::createFromTimestamp(
                    $event->payload['data']['object']['current_period_end']
                ),
                'trial_ends_at' => isset($event->payload['data']['object']['trial_end'])
                    ? Carbon::createFromTimestamp($event->payload['data']['object']['trial_end'])
                    : null,
            ]
        );

        // Handle trial
        if ($subscription->trial_ends_at && $subscription->trial_ends_at->isFuture()) {
            $subscription->update(['status' => 'trialing']);
        }

        // Synchronize entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // Log status history
        $subscription->statusHistories()->create([
            'from_status' => null,
            'to_status' => $subscription->status,
            'reason' => 'Webhook: subscription created',
        ]);

        SubscriptionCreated::dispatch($subscription);
    }

    private function resolveUser(string $provider, string $customerId): ?User
    {
        return match ($provider) {
            'stripe' => User::where('stripe_id', $customerId)->first(),
            'paddle' => User::where('paddle_id', $customerId)->first(),
            'lemon-squeezy' => User::where('lemon_squeezy_id', $customerId)->first(),
            default => null,
        };
    }

    private function resolvePlan(WebhookEvent $event): ?Plan
    {
        $priceId = $event->payload['data']['object']['items']['data'][0]['price']['id'] ?? null;

        if (!$priceId) {
            return null;
        }

        $priceColumn = "{$event->provider}_price_id";

        return Plan::where($priceColumn, $priceId)->first();
    }
}
```

### Subscription Updated Handler

```php
class SubscriptionUpdatedHandler
{
    public function handle(WebhookEvent $event): void
    {
        $providerSubscriptionId = $event->payload['data']['object']['id'];
        $subscription = $this->findSubscription($event->provider, $providerSubscriptionId);

        if (!$subscription) {
            return;
        }

        $oldStatus = $subscription->status;
        $newStatus = $this->mapProviderStatus($event->payload['data']['object']['status']);

        // Update subscription fields
        $subscription->update([
            'status' => $newStatus,
            'quantity' => $event->payload['data']['object']['items']['data'][0]['quantity'] ?? $subscription->quantity,
            'current_period_start' => Carbon::createFromTimestamp(
                $event->payload['data']['object']['current_period_start']
            ),
            'current_period_end' => Carbon::createFromTimestamp(
                $event->payload['data']['object']['current_period_end']
            ),
            'trial_ends_at' => isset($event->payload['data']['object']['trial_end'])
                ? Carbon::createFromTimestamp($event->payload['data']['object']['trial_end'])
                : null,
        ]);

        // Log status change if different
        if ($oldStatus !== $newStatus) {
            $subscription->statusHistories()->create([
                'from_status' => $oldStatus,
                'to_status' => $newStatus,
                'reason' => 'Webhook: subscription updated',
            ]);

            // Handle status-specific side effects
            match ($newStatus) {
                'active' => $this->handleActivated($subscription, $oldStatus),
                'past_due' => $this->handlePastDue($subscription),
                'canceled' => $this->handleCanceled($subscription),
                'trialing' => $this->handleTrialing($subscription),
                default => null,
            };
        }

        // Check for plan change
        $this->handlePlanChange($event, $subscription);

        // Check for quantity change
        $this->handleQuantityChange($event, $subscription);

        SubscriptionUpdated::dispatch($subscription, $oldStatus);
    }

    private function mapProviderStatus(string $providerStatus): string
    {
        return match ($providerStatus) {
            'active' => 'active',
            'past_due' => 'past_due',
            'unpaid' => 'unpaid',
            'canceled' => 'canceled',
            'incomplete' => 'incomplete',
            'incomplete_expired' => 'incomplete_expired',
            'trialing' => 'trialing',
            'paused' => 'paused',
            default => 'unknown',
        };
    }

    private function handleActivated(Subscription $subscription, string $oldStatus): void
    {
        // Synchronize entitlements if coming from past_due or trial
        if (in_array($oldStatus, ['past_due', 'trialing', 'incomplete'])) {
            app(EntitlementService::class)->synchronize($subscription);
            SubscriptionPaymentRecovered::dispatch($subscription);
        }
    }

    private function handlePastDue(Subscription $subscription): void
    {
        app(GracePeriodRetrySchedule::class)->schedule($subscription);
        SubscriptionPastDue::dispatch($subscription);
    }

    private function handleCanceled(Subscription $subscription): void
    {
        app(EntitlementService::class)->invalidate($subscription->billable);
        SubscriptionCanceled::dispatch($subscription);
    }

    private function handleTrialing(Subscription $subscription): void
    {
        TrialStarted::dispatch($subscription);
    }

    private function handlePlanChange(WebhookEvent $event, Subscription $subscription): void
    {
        $newPriceId = $event->payload['data']['object']['items']['data'][0]['price']['id'] ?? null;

        if (!$newPriceId) {
            return;
        }

        $priceColumn = "{$event->provider}_price_id";
        $newPlan = Plan::where($priceColumn, $newPriceId)->first();

        if ($newPlan && $newPlan->id !== $subscription->plan_id) {
            $oldPlan = $subscription->plan;
            $subscription->update(['plan_id' => $newPlan->id]);

            PlanChanged::dispatch($subscription, $oldPlan, $newPlan);
        }
    }

    private function handleQuantityChange(WebhookEvent $event, Subscription $subscription): void
    {
        $newQuantity = $event->payload['data']['object']['items']['data'][0]['quantity'] ?? null;

        if ($newQuantity && $newQuantity !== $subscription->quantity) {
            $oldQuantity = $subscription->quantity;
            $subscription->update(['quantity' => $newQuantity]);

            QuantityChanged::dispatch($subscription, $oldQuantity, $newQuantity);
        }
    }

    private function findSubscription(string $provider, string $providerSubscriptionId): ?Subscription
    {
        $idColumn = "{$provider}_id";

        return Subscription::where($idColumn, $providerSubscriptionId)->first();
    }
}
```

```php
class PaymentMethodAttachedHandler
{
    public function handle(WebhookEvent $event): void
    {
        $paymentMethodId = $event->payload['data']['object']['id'];
        $customerId = $event->payload['data']['object']['customer'];

        $user = $this->resolveUser($event->provider, $customerId);

            'stripe' => User::where('stripe_id', $customerId)->first(),
            'paddle' => User::where('paddle_id', $customerId)->first(),
            default => null,
        };
    }

    private function extractPaymentMethodDetails(array $object): array
    {
        return [
            'type' => $object['type'] ?? 'card',
            'brand' => $object['card']['brand'] ?? null,
            'last_four' => $object['card']['last4'] ?? null,
            'exp_month' => $object['card']['exp_month'] ?? null,
            'exp_year' => $object['card']['exp_year'] ?? null,
            'is_default' => false,
        ];
    }
}
```

```php
    public function handle(WebhookEvent $event): void
    {
        $customerId = $event->payload['data']['object']['id'];
        $user = $this->resolveUser($event->provider, $customerId);

        if (!$user) {
            return;
        }

        // Cancel all active subscriptions
        $user->subscriptions()
            ->whereIn('status', ['active', 'trialing'])
            ->each(function ($subscription) {
                $subscription->update([
                    'status' => 'canceled',
                    'canceled_at' => now(),
                    'cancellation_reason' => 'customer_deleted_at_provider',
                ]);

                app(EntitlementService::class)->invalidate($subscription->billable);

                SubscriptionCanceled::dispatch($subscription, 'customer_deleted_at_provider');
            });

        // Clear provider ID
        $providerColumn = "{$event->provider}_id";
        $user->update([$providerColumn => null]);

        CustomerDeleted::dispatch($user);
    }

    private function resolveUser(string $provider, string $customerId): ?User
    {
        return match ($provider) {
            'stripe' => User::where('stripe_id', $customerId)->first(),
            'paddle' => User::where('paddle_id', $customerId)->first(),
            default => null,
        };
    }
}
```

### Stripe Signature Verification

```php
class StripeWebhookVerifier
{
    public function verify(Request $request): bool
    {
        $payload = $request->getContent();
        $sigHeader = $request->header('Stripe-Signature');
        $secret = config('billing.providers.stripe.webhook_secret');

        if (!$sigHeader || !$secret) {
            return false;
        }

        try {
            $event = \Stripe\Webhook::constructEvent(
                $payload,
                $sigHeader,
                $secret
            );
            return true;
        } catch (\UnexpectedValueException $e) {
            Log::warning('Stripe webhook: Invalid payload', [
                'error' => $e->getMessage(),
            ]);
            return false;
        } catch (\Stripe\Exception\SignatureVerificationException $e) {
            Log::warning('Stripe webhook: Invalid signature', [
                'error' => $e->getMessage(),
            ]);
            return false;
        }
    }

    public function verifyTimestamp(Request $request, int $tolerance = 300): bool
    {
        $sigHeader = $request->header('Stripe-Signature');

        if (!$sigHeader) {
            return false;
        }

        $timestamp = $this->extractTimestamp($sigHeader);

        if (!$timestamp) {
            return false;
        }

        $now = time();

        return abs($now - $timestamp) <= $tolerance;
    }

    private function extractTimestamp(string $sigHeader): ?int
    {
        $elements = explode(',', $sigHeader);

        foreach ($elements as $element) {
            $parts = explode('=', $element);
            if ($parts[0] === 't') {
                return (int) $parts[1];
            }
        }

        return null;
    }
}
```

### Paddle Verification

```php
class PaddleWebhookVerifier
{
    public function verify(Request $request): bool
    {
        $payload = $request->json()->all();
        $signature = $request->header('Paddle-Signature');
        $publicKey = config('billing.providers.paddle.public_key');

        if (!$signature || !$publicKey) {
            return false;
        }

        // Paddle v2 uses JWT for webhook verification
        $parts = explode(':', $signature);

        if (count($parts) !== 3) {
            return false;
        }

        [$header, $body, $signatureHash] = $parts;

        // Verify signature
        $expectedHash = hash_hmac('sha256', "{$header}.{$body}", $publicKey);

        return hash_equals($expectedHash, $signatureHash);
    }
}
```

```php
class WebhookIdempotencyChecker

    {
        $key = $this->buildKey($event);

        $this->cache->forget($key);
    }

    private function buildKey(WebhookEvent $event): string
    {
```

## Webhook Retry System

### Retry Strategy

```php
class WebhookRetryStrategy
{
    private const DELAYS = [
        1 => 60,          // 1 minute
        2 => 300,         // 5 minutes
        3 => 1800,        // 30 minutes
        4 => 7200,        // 2 hours
        5 => 86400,       // 24 hours
    ];

    public function getDelayForAttempt(int $attempt): int
    {
        return self::DELAYS[$attempt] ?? 86400;
    }

    public function shouldRetry(int $attempt, string $error): bool
    {
        if ($attempt >= count(self::DELAYS)) {
            return false;
        }

        // Don't retry on permanent errors
        $permanentErrors = [
            'invalid_signature',
            'customer_not_found',
            'subscription_not_found',
        ];

        foreach ($permanentErrors as $permanentError) {
            if (str_contains($error, $permanentError)) {
                return false;
            }
        }

        return true;
    }

    public function getMaxAttempts(): int
    {
        return count(self::DELAYS);
    }
}
```

### Retry Processor Command

```php
class ProcessWebhookRetriesCommand extends Command
{
    protected $signature = 'webhooks:process-retries';
    protected $description = 'Process pending webhook retries';

    public function handle(): int
    {
        $pendingRetries = WebhookRetryQueue::where('status', 'pending')
            ->where('next_attempt_at', '<=', now())
            ->where('attempt', '<', 5)
            ->orderBy('next_attempt_at')
            ->limit(50)
            ->get();

        $processed = 0;

        foreach ($pendingRetries as $retry) {
            $retry->update(['status' => 'processing']);

            try {
                $pipeline = app(WebhookProcessingPipeline::class);
                $request = Request::create(
                    route('webhooks.' . $retry->provider),
                    'POST',
                    $retry->payload,
                    [],
                    [],
                    $this->buildServerVars($retry->headers)
                );

                $pipeline->process($retry->provider, $request);

                $retry->update([
                    'status' => 'completed',
                    'processed_at' => now(),
                ]);

                $processed++;
            } catch (Exception $e) {
                $retry->increment('attempt');
                $retry->update([
                    'status' => 'pending',
                    'last_attempt_at' => now(),
                    'last_error' => $e->getMessage(),
                    'next_attempt_at' => now()->addSeconds(
                        app(WebhookRetryStrategy::class)->getDelayForAttempt($retry->attempt)
                    ),
                ]);

                Log::warning("Webhook retry failed", [
                    'id' => $retry->id,
                    'attempt' => $retry->attempt,
                    'error' => $e->getMessage(),
                ]);
            }
        }

        $this->info("Processed {$processed} webhook retries.");

        return Command::SUCCESS;
    }

    private function buildServerVars(array $headers): array
    {
        $serverVars = [];
        foreach ($headers as $key => $value) {
            $serverVars['HTTP_' . strtoupper(str_replace('-', '_', $key))] = $value;
        }
        return $serverVars;
    }
}
```

```php
class WebhookHealthService
{
    public function getHealthMetrics(string $provider, int $hours = 24): array
    {
        $since = now()->subHours($hours);

        $logs = WebhookLog::where('provider', $provider)
            ->where('received_at', '>=', $since)
            ->get();

        $total = $logs->count();
        $processed = $logs->where('status', 'processed')->count();
        $failed = $logs->where('status', 'failed')->count();
        $pending = $logs->where('status', 'received')->count();

        return [
            'provider' => $provider,
            'period_hours' => $hours,
            'total_received' => $total,
            'processed' => $processed,
            'failed' => $failed,
            'pending' => $pending,
            'success_rate' => $total > 0 ? round(($processed / $total) * 100, 2) : 0,
            'failure_rate' => $total > 0 ? round(($failed / $total) * 100, 2) : 0,
            'avg_processing_time_ms' => $logs->where('processing_time_ms')
                ->avg('processing_time_ms'),
            'p95_processing_time_ms' => $logs->where('processing_time_ms')
                ->pluck('processing_time_ms')
                ->sort()
                ->nth((int) ceil($logs->count() * 0.95) - 1) ?? 0,
            'event_type_breakdown' => $logs->groupBy('event_type')
                ->map(fn ($group) => [
                    'count' => $group->count(),
                    'success_rate' => round(
                        ($group->where('status', 'processed')->count() / $group->count()) * 100,
                        2
                    ),
                ]),
        ];
    }

    public function getFailureAnalysis(string $provider, int $hours = 24): array
    {
        $since = now()->subHours($hours);

        $failures = WebhookLog::where('provider', $provider)
            ->where('status', 'failed')
            ->where('received_at', '>=', $since)
            ->get();

        return [
            'total_failures' => $failures->count(),
            'unique_errors' => $failures->pluck('error')->unique()->values(),
            'errors_by_type' => $failures->groupBy('event_type')
                ->map(fn ($group) => $group->pluck('error')->unique()->values()),
            'failures_over_time' => $failures->groupBy(
                fn ($log) => $log->received_at->format('Y-m-d H:00')
            )->map(fn ($group) => $group->count()),
        ];
    }

    public function getUnhandledEvents(string $provider, int $hours = 24): array
    {
        $since = now()->subHours($hours);

        return WebhookLog::where('provider', $provider)
            ->where('status', 'failed')
            ->where('error', 'like', '%unhandled_event_type%')
            ->where('received_at', '>=', $since)
            ->groupBy('event_type')
            ->select('event_type', DB::raw('count(*) as count'))
            ->get()
            ->toArray();
    }
}
```

### Outbound Webhook Sender

```php
class OutboundWebhookSender
{
    public function send(OutboundWebhook $webhook, string $eventType, array $payload): void
    {
        if (!$webhook->is_active) {
            return;
        }

        if (!$webhook->listensTo($eventType)) {
            return;
        }

        $body = [
            'event' => $eventType,
            'timestamp' => now()->toISOString(),
            'data' => $payload,
        ];

        $signature = hash_hmac('sha256', json_encode($body), $webhook->secret);

        try {
            $response = Http::withHeaders([
                'Content-Type' => 'application/json',
                'X-Webhook-Signature' => "sha256={$signature}",
                'X-Webhook-Event' => $eventType,
                'X-Webhook-Delivery' => Str::uuid(),
            ])->timeout(10)->post($webhook->url, $body);

            $webhook->update(['last_triggered_at' => now()]);

            OutboundWebhookLog::create([
                'outbound_webhook_id' => $webhook->id,
                'event_type' => $eventType,
                'status' => $response->successful() ? 'delivered' : 'failed',
                'response_code' => $response->status(),
                'response_body' => $response->body(),
                'payload' => $body,
            ]);

            if (!$response->successful()) {
                $webhook->increment('failure_count');
            } else {
                $webhook->update(['failure_count' => 0]);
            }
        } catch (Exception $e) {
            $webhook->increment('failure_count');

            OutboundWebhookLog::create([
                'outbound_webhook_id' => $webhook->id,
                'event_type' => $eventType,
                'status' => 'failed',
                'error' => $e->getMessage(),
                'payload' => $body,
            ]);

            // Disable webhook after too many failures
            if ($webhook->failure_count >= 10) {
                $webhook->update(['is_active' => false]);
            }
        }
    }

    public function sendToAll(string $eventType, array $payload): void
    {
        $webhooks = OutboundWebhook::where('is_active', true)
            ->get()
            ->filter(fn ($w) => $w->listensTo($eventType));

        foreach ($webhooks as $webhook) {
            $this->send($webhook, $eventType, $payload);
        }
    }
}
```

## Webhook Security Best Practices

### Security Checklist

| Measure | Implementation | Status |
|---|---|---|
| Signature verification | HMAC-SHA256 on all incoming webhooks | Required |
| Timestamp validation | Reject webhooks older than 5 minutes | Required |
| IP allowlisting | Stripe: `103.21.244.0/22`, `103.22.200.0/22`, etc. | Recommended |
| Replay protection | Idempotency key + timestamp check | Required |
| Payload size limits | Max 1MB per webhook payload | Required |
| Rate limiting | 100 requests/minute per provider | Recommended |
| HTTPS only | Reject HTTP webhook URLs | Required |
| Secret rotation | Rotate webhook secrets quarterly | Recommended |
| Audit logging | Log all webhook activity | Required |
| Error monitoring | Alert on sustained failure rates | Required |

### Security Middleware

```php
class WebhookSecurityMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        // Reject non-HTTPS in production
        if (app()->environment('production') && !$request->secure()) {
            return response()->json(['error' => 'HTTPS required'], 403);
        }

        // Reject oversized payloads
        if ($request->getContent() && strlen($request->getContent()) > 1048576) {
            return response()->json(['error' => 'Payload too large'], 413);
        }

        // Rate limiting
        $rateLimitKey = 'webhook:' . $request->ip();
        if (Cache::increment($rateLimitKey) > 100) {
            return response()->json(['error' => 'Rate limit exceeded'], 429);
        }

        return $next($request);
    }
}
```

# 12.18 — Events

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

---

## Purpose

Define all domain events dispatched by the subscription system, their payloads, and their listeners. Events are the backbone of asynchronous subscription processing — they decouple subscription operations from their side effects.

## Event Architecture

```text
Subscription Operation
    ↓
Domain Event Dispatched
    ↓
Event Bus (Laravel Events)
    ↓
Listeners (queued or sync)
    ├── Entitlement Synchronization
    ├── Notification Dispatch
    ├── Audit Trail Logging
    ├── Permission Sync
    └── Webhook Outbound
```

## Event Catalog

### Subscription Lifecycle Events

| Event | Dispatched When | Payload |
|---|---|---|
| `SubscriptionCreated` | Subscription created | subscription, plan, user |
| `TrialStarted` | Trial begins | subscription, trial_end |
| `SubscriptionConverted` | Trial → Active (paid) | subscription |
| `SubscriptionRenewed` | Successful renewal | subscription, invoice |
| `SubscriptionCanceled` | Subscription canceled | subscription, reason |
| `SubscriptionResumed` | Canceled → Active (resume) | subscription |
| `SubscriptionExpired` | Period end reached | subscription |
| `SubscriptionPaused` | Subscription paused (admin) | subscription, reason |
| `SubscriptionUnpaid` | Grace expired, unpaid | subscription |

### Payment Events

| Event | Dispatched When | Payload |
|---|---|---|
| `PaymentSucceeded` | Payment processed | subscription, receipt |
| `PaymentFailed` | Payment charge failed | subscription, error |
| `PaymentActionRequired` | 3DS / additional auth | subscription, intent |
| `PaymentRecovered` | Payment retry succeeded | subscription |
| `PaymentMethodUpdated` | User changed payment method | user, method |

### Entitlement Events

| Event | Dispatched When | Payload |
|---|---|---|
| `EntitlementsUpdated` | Entitlements recalculated | subscription, entitlements |
| `EntitlementGranted` | Admin grants entitlement | grantee, grant |
| `EntitlementRevoked` | Admin revokes entitlement | grantee, grant |
| `EntitlementExpired` | Grant expiration reached | grantee, grant_key |

### Plan Events

| Event | Dispatched When | Payload |
|---|---|---|
| `PlanCreated` | New plan created | plan |
| `PlanUpdated` | Plan details changed | plan, changes |
| `PlanArchived` | Plan set to inactive | plan |
| `PlanPriceChanged` | Price updated | plan, old_price, new_price |

### Team & Seat Events

| Event | Dispatched When | Payload |
|---|---|---|
| `TeamSubscriptionCreated` | Team subscribes | team, subscription |
| `TeamSubscriptionCanceled` | Team subscription canceled | team |
| `SeatAssigned` | Seat given to user | seat, user |
| `SeatInvited` | Invitation sent | seat, email |
| `SeatReclaimed` | Seat removed from user | seat |
| `SeatTransferred` | Seat moved to new user | seat, old_user, new_user |
| `SeatsPurchased` | Additional seats bought | team, quantity |

### Webhook Events

| Event | Dispatched When | Payload |
|---|---|---|
| `WebhookReceived` | Provider webhook arrives | provider, event_type |
| `WebhookProcessed` | Webhook handled | provider, event_type, status |
| `WebhookFailed` | Webhook processing error | provider, event_type, error |

```php
class SynchronizeEntitlements implements ShouldQueue
{
    public function handle(SubscriptionCreated|SubscriptionConverted|SubscriptionResumed $event): void
    {
        app(EntitlementService::class)->synchronize($event->subscription);
    }

```

### AssignProRole

```php
class AssignProRole
{
    public function handle(SubscriptionCreated $event): void
    {
        $user = $event->subscription->user;

        if (!$user->hasRole('pro_user')) {
            $user->assignRole('pro_user');
        }
    }
}
```

### RemoveProRole

```php
class RemoveProRole
{
    public function handle(SubscriptionExpired|SubscriptionCanceled $event): void
    {
        $user = $event->subscription->user;

        // Only remove if no other active subscription
        if (!$user->subscriptions()->where('status', 'active')->exists()) {
            $user->removeRole('pro_user');
        }
    }
}
```

### NotifyCanceled (with Save Offer)

```php
class NotifyCanceled
{
    public function handle(SubscriptionCanceled $event): void
    {
        $user = $event->subscription->user;
        $saveOffer = app(SaveOffer::class)->eligible($event->subscription);

        if ($saveOffer) {
            $user->notify(new SaveOfferNotification($event->subscription, $saveOffer));
        } else {
            $user->notify(new SubscriptionCanceledNotification($event->subscription));
        }
    }
}
```

## Event Testing

```php
class SubscriptionEventTest extends TestCase
{
    public function test_cancel_dispatches_event(): void
    {
        Event::fake();

        $subscription = Subscription::factory()->active()->create();
        $subscription->cancel();

        Event::assertDispatched(SubscriptionCanceled::class, function ($event) use ($subscription) {
            return $event->subscription->id === $subscription->id;
        });
    }

    public function test_cancel_triggers_listeners(): void
    {
        Event::fake();

        $subscription = Subscription::factory()->active()->create();
        $subscription->cancel();

        Event::assertDispatched(SubscriptionCanceled::class);
        Event::assertListening(
            SubscriptionCanceled::class,
            InvalidateEntitlements::class
        );
        Event::assertListening(
            SubscriptionCanceled::class,
            NotifyCanceled::class
        );
    }
}
```

### LogSubscriptionActivity

```php
class LogSubscriptionActivity implements ShouldQueue
{
    public function handle(SubscriptionCreated|SubscriptionConverted|SubscriptionRenewed|SubscriptionCanceled|SubscriptionResumed|SubscriptionExpired $event): void
    {
        $subscription = $event->subscription;

        activity()
            ->performedOn($subscription)
            ->causedBy($subscription->user)
            ->withProperties([
                'plan' => $subscription->plan->slug,
                'status' => $subscription->status,
                'event_class' => get_class($event),
            ])
            ->log("subscription." . strtolower(class_basename($event)));
    }
}
```

## Event Priority & Ordering

### Priority Configuration

Some events must be processed before others. For example, entitlement synchronization should happen before notifications that reference entitlement state.

```php
class EventPriorityRegistry
{
    private const PRIORITIES = [
        // High priority - state changes
        SubscriptionCreated::class => 100,
        SubscriptionConverted::class => 100,
        SubscriptionRenewed::class => 100,
        SubscriptionCanceled::class => 100,
        SubscriptionExpired::class => 100,
        SubscriptionPaused::class => 100,
        SubscriptionResumed::class => 100,
        SubscriptionPastDue::class => 100,
        SubscriptionUnpaid::class => 100,

        // Medium priority - entitlements
        EntitlementsUpdated::class => 80,
        EntitlementGranted::class => 80,
        EntitlementRevoked::class => 80,
        EntitlementExpired::class => 80,

        // Normal priority - payments
        PaymentSucceeded::class => 60,
        PaymentFailed::class => 60,
        PaymentRecovered::class => 60,
        PaymentActionRequired::class => 60,

        // Low priority - notifications
        TrialStarted::class => 40,
        PaymentMethodUpdated::class => 40,
        PlanCreated::class => 40,
        PlanUpdated::class => 40,
    ];

    public static function getPriority(string $eventClass): int
    {
        return self::PRIORITIES[$eventClass] ?? 50;
    }

    public static function sortByPriority(array $events): array
    {
        usort($events, fn ($a, $b) =>
            self::getPriority(get_class($b)) <=> self::getPriority(get_class($a))
        );

        return $events;
    }
}
```

### Event Ordering Middleware

```php
class EventOrderingMiddleware
{
    public function handle(object $event, Closure $next): void
    {
        $priority = EventPriorityRegistry::getPriority(get_class($event));

        // Store event in priority queue
        $queueKey = "event_queue:priority:{$priority}";
        Cache::push($queueKey, serialize($event));

        // Process events in priority order
        $this->processPriorityQueue();

        $next($event);
    }

    private function processPriorityQueue(): void
    {
        for ($p = 100; $p >= 0; $p -= 20) {
            $queueKey = "event_queue:priority:{$p}";

            while ($event = Cache::pop($queueKey)) {
                $event = unserialize($event);
                // Event already dispatched, this is just for ordering
            }
        }
    }
}
```

## Event Batching

### Batch Processing

For high-throughput scenarios, events can be batched to reduce database writes and API calls.

```php
class EventBatchProcessor
{
    private array $batch = [];
    private int $batchSize;
    private int $flushInterval;

    public function __construct(
        int $batchSize = 100,
        int $flushInterval = 60,
    ) {
        $this->batchSize = $batchSize;
        $this->flushInterval = $flushInterval;
    }

    public function addEvent(object $event): void
    {
        $this->batch[] = [
            'event_class' => get_class($event),
            'payload' => serialize($event),
            'created_at' => now(),
        ];

        if (count($this->batch) >= $this->batchSize) {
            $this->flush();
        }
    }

    public function flush(): void
    {
        if (empty($this->batch)) {
            return;
        }

        DB::table('event_batch')->insert($this->batch);

        $this->batch = [];
    }

    public function processBatch(): void
    {
        $events = DB::table('event_batch')
            ->where('created_at', '<', now()->subSeconds($this->flushInterval))
            ->orderBy('created_at')
            ->limit($this->batchSize)
            ->get();

        foreach ($events as $record) {
            $event = unserialize($record->payload);
            event($event);
        }

        // Delete processed events
        DB::table('event_batch')
            ->where('created_at', '<', now()->subSeconds($this->flushInterval))
            ->delete();
    }
}
```

```php
class EventExportService
{
    public function exportEvents(
        Carbon $from,
        Carbon $to,
        ?string $eventType = null,

    ): string {
        $query = Activity::whereBetween('created_at', [$from, $to]);

        return match ($format) {

                $event->id,

                $event->subject_type,
                $event->subject_id,
                $event->causer_id ?? 'System',
                json_encode($event->properties),
                $event->created_at->toISOString(),
            ]) . "\n";
        }

        return $csv;
    }

    private function exportJson($events): string
    {
        return $events->map(fn ($event) => [
            'id' => $event->id,
            'event' => $event->event,
            'subject' => [
                'type' => $event->subject_type,
                'id' => $event->subject_id,
            ],
            'causer' => $event->causer_id,
```

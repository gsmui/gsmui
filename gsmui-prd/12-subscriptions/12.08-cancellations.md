# 12.08 — Cancellations

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

---

## Purpose

Define subscription cancellation flows — when cancellations take effect, how access is managed during the remainder period, and what happens at expiry.

## Cancellation Architecture

```text
User requests cancellation
    ↓
Confirmation step
    ↓
Cancellation reason survey
    ↓
[ optional: save offer / discount ]
    ↓
Cancel at period end (default)
    OR
Cancel immediately (admin only)
    ↓
Subscription status → Canceled
    ↓
Access continues until period end
    ↓
[ period end ]
    ↓
Status → Expired
Entitlements revoked
```

## Cancellation Flow

### Standard Cancellation

```php
public function cancel(Subscription $subscription, string $reason = null): void
{
    // Prevent double cancellation
    if ($subscription->canceled()) {
        throw new AlreadyCanceledException();
    }

    // Must not be in terminal state
    if ($subscription->status === 'expired' || $subscription->status === 'unpaid') {
        throw new InvalidStateException('Cannot cancel terminal subscription');
    }

    $subscription->status = SubscriptionStatus::Canceled;
    $subscription->cancel_at_period_end = true;
    $subscription->canceled_at = now();
    $subscription->ends_at = $subscription->period()->end;
    $subscription->save();

    // Record reason
    if ($reason) {
        $subscription->metadata = array_merge($subscription->metadata ?? [], [
            'cancel_reason' => $reason,
        ]);
        $subscription->save();
    }

    // Log transition
    $subscription->statusHistories()->create([
        'from_status' => $subscription->status,
        'to_status' => SubscriptionStatus::Canceled,
        'changed_by' => auth()->id(),
        'reason' => $reason,
    ]);

    // Schedule entitlement revocation
    RevokeEntitlementsJob::dispatch($subscription)
        ->delay($subscription->ends_at);

    // Dispatch event
    SubscriptionCanceled::dispatch($subscription);

    // Notify
    $subscription->user->notify(new SubscriptionCanceledNotification($subscription));
}
```

```text

    ↑                                    ↑
```

## Resume During Canceled Period

Users can resume their subscription at any time before the period ends:

```php
public function resume(Subscription $subscription): void
{
    if (!$subscription->canceled() || $subscription->ends_at->isPast()) {
        throw new CannotResumeException();
    }

    $subscription->status = SubscriptionStatus::Active;
    $subscription->cancel_at_period_end = false;
    $subscription->canceled_at = null;
    $subscription->ends_at = null;
    $subscription->save();

    // Re-sync entitlements
    app(EntitlementService::class)->synchronize($subscription);

    // Cancel scheduled revocation
    // (RevokeEntitlementsJob will check status before acting)

    SubscriptionResumed::dispatch($subscription);
}
```

## Immediate Cancellation

Admin-only cancellation that revokes access immediately:

```php
public function cancelImmediately(Subscription $subscription, string $reason): void
{
    // Only admins can force immediate cancellation
    throw_unless(auth()->user()->isAdmin(), AuthorizationException::class);

    $subscription->status = SubscriptionStatus::Canceled;
    $subscription->canceled_at = now();
    $subscription->ends_at = now(); // Immediate
    $subscription->save();

    // Revoke entitlements now (not scheduled)
    app(EntitlementService::class)->invalidate($subscription);

    // Issue refund if applicable
    $this->billing->issueProratedRefund($subscription);

    SubscriptionImmediatelyCanceled::dispatch($subscription, $reason);
}
```

## Detailed Cancellation Flows

### Self-Service Cancellation (User-Initiated)

The primary cancellation flow where a user decides to cancel their subscription from the billing dashboard.

```text
User Navigation:
1. User navigates to Settings → Billing
2. Clicks "Cancel Subscription" link
3. System presents cancellation survey
4. User selects reason and provides feedback
5. System presents save offer (if eligible)
6. User confirms cancellation
7. Subscription marked as canceled
8. Access continues until period end
9. Confirmation email sent
10. Dashboard banner updated
```

```php
class SelfServiceCancellation
{
    public function initiate(User $user): CancellationContext
    {
        $subscription = $user->activeSubscription();

        if (!$subscription) {
            throw new NoActiveSubscriptionException();
        }

        // Check if already canceled
        if ($subscription->status === SubscriptionStatus::Canceled) {
            throw new AlreadyCanceledException('Subscription is already canceled');
        }

        // Check for scheduled downgrade (must cancel that first)
        if (isset($subscription->metadata['scheduled_plan_id'])) {
            throw new ScheduledChangeExistsException(
                'You have a scheduled plan change. Please cancel that first.'
            );
        }

        // Build cancellation context with save offers
        $context = new CancellationContext(
            subscription: $subscription,
            saveOffers: app(SaveOfferService::class)->getOffers($subscription),
            featuresToLose: $this->getFeaturesToLose($subscription),
            periodEndDate: $subscription->period_end,
            daysRemaining: now()->diffInDays($subscription->period_end),
        );

        return $context;
    }

    protected function getFeaturesToLose(Subscription $subscription): array
    {
        $currentFeatures = $subscription->plan->features ?? [];
        $freeFeatures = Plan::where('slug', 'free')->first()->features ?? [];

        return array_diff($currentFeatures, $freeFeatures);
    }
}
```

### Save Offer System

```php
class SaveOfferService
{
    public function getOffers(Subscription $subscription): array
    {
        $offers = [];

        // Offer 1: Discount for price-sensitive users
        if ($this->isPriceSensitive($subscription)) {
            $offers[] = new SaveOffer(
                type: 'discount',
                value: 30, // 30% off for 3 months
                duration: 3,
                message: 'Get 30% off for the next 3 months',
                eligible: true,
                conditions: [
                    'new_price' => $subscription->plan->price * 0.7,
                    'expires_at' => now()->addDays(7)->toDateTimeString(),
                ],
            );
        }

        // Offer 2: Trial extension for trial users
        if ($subscription->onTrial()) {
            $offers[] = new SaveOffer(
                type: 'trial_extension',
                value: 14, // 14 days
                duration: 14,
                message: 'Extend your trial by 14 days',
                eligible: true,
            );
        }

        // Offer 3: Plan pause for infrequent users
        if ($this->isInfrequentUser($subscription)) {
            $offers[] = new SaveOffer(
                type: 'pause',
                value: 30, // 30 days
                duration: 30,
                message: 'Pause your subscription for up to 30 days',
                eligible: true,
            );
        }

        // Offer 4: Downgrade to lower tier
        $lowerPlan = $this->getLowerPlan($subscription);
        if ($lowerPlan) {
            $offers[] = new SaveOffer(
                type: 'downgrade',
                value: $lowerPlan->id,
                message: "Downgrade to {$lowerPlan->name} for $${$lowerPlan->formattedPrice}/month",
                eligible: true,
                metadata: ['target_plan_id' => $lowerPlan->id],
            );
        }

        return array_filter($offers, fn ($offer) => $offer->eligible);
    }

    protected function isPriceSensitive(Subscription $subscription): bool
    {
        // Check if user has previously used a discount or coupon
        return $subscription->user->coupons()->count() > 0
            || $subscription->metadata['discount_applied'] ?? false;
    }

    protected function isInfrequentUser(Subscription $subscription): bool
    {
        // Check login activity over the past 30 days
        $loginCount = $subscription->user->activities()
            ->where('type', 'login')
            ->where('created_at', '>=', now()->subDays(30))
            ->count();

        return $loginCount < 5; // Less than 5 logins in 30 days
    }

    protected function getLowerPlan(Subscription $subscription): ?Plan
    {
        return Plan::where('is_active', true)
            ->where('sort_order', '<', $subscription->plan->sort_order)
            ->orderBy('sort_order', 'desc')
            ->first();
    }
}
```

### Accepting Save Offers

```php
class AcceptSaveOffer
{
    public function acceptDiscount(Subscription $subscription, SaveOffer $offer): void
    {
        // Apply 30% discount for 3 months
        $discountedPrice = $subscription->plan->price * 0.7;

        // Create discount record
        SubscriptionDiscount::create([
            'subscription_id' => $subscription->id,
            'type' => 'save_offer',
            'percentage' => 30,
            'expires_at' => now()->addMonths(3),
            'reason' => 'Accepted save offer during cancellation flow',
        ]);

        // Update Stripe subscription with discount
        $this->billing->applyDiscount(
            $subscription,
            'save_offer_30_percent',
            $offer->duration
        );

        // Cancel the pending cancellation
        $subscription->status = SubscriptionStatus::Active;
        $subscription->cancel_at_period_end = false;
        $subscription->canceled_at = null;
        $subscription->ends_at = null;
        $subscription->save();

        SaveOfferAccepted::dispatch($subscription, $offer);

        $subscription->user->notify(new SaveOfferAcceptedNotification($subscription, $offer));
    }

    public function acceptPause(Subscription $subscription, SaveOffer $offer): void
    {
        // Pause subscription for up to 30 days
        $subscription->status = SubscriptionStatus::Paused;
        $subscription->paused_at = now();
        $subscription->resumes_at = now()->addDays($offer->value);
        $subscription->save();

        // Suspend billing
        $this->billing->pauseSubscription($subscription);

        // Entitlements remain active during pause
        app(EntitlementService::class)->synchronize($subscription);

        SaveOfferAccepted::dispatch($subscription, $offer);
    }

    public function acceptDowngrade(Subscription $subscription, SaveOffer $offer): void
    {
        $targetPlan = Plan::find($offer->metadata['target_plan_id']);

        // Downgrade immediately
        $subscription->plan_id = $targetPlan->id;
        $subscription->save();

        // Synchronize entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // Cancel pending cancellation
        $subscription->cancel_at_period_end = false;
        $subscription->canceled_at = null;
        $subscription->ends_at = null;
        $subscription->save();

        SaveOfferAccepted::dispatch($subscription, $offer);
    }
}
```

### State Transitions

```php
enum SubscriptionStatus: string
{
    case Active = 'active';
    case PastDue = 'past_due';
    case Canceled = 'Canceled';
    case Expired = 'expired';
    case Unpaid = 'unpaid';
    case Paused = 'paused';

    public function canTransitionTo(self $newStatus): bool
    {
        return match ($this) {
            self::Active => in_array($newStatus, [
                self::PastDue,
                self::Canceled,
                self::Paused,
            ]),
            self::PastDue => in_array($newStatus, [
                self::Active,
                self::Unpaid,
                self::Canceled,
            ]),
            self::Canceled => in_array($newStatus, [
                self::Active, // Resume
                self::Expired,
            ]),
            self::Expired => in_array($newStatus, [
                self::Active, // Re-subscribe
            ]),
            self::Unpaid => in_array($newStatus, [
                self::Active,
                self::Canceled,
            ]),
            self::Paused => in_array($newStatus, [
                self::Active,
                self::Canceled,
            ]),
        };
    }
}
```

```php
class CancellationAccessManager
{
    public function getAccessLevel(Subscription $subscription, string $feature): AccessLevel
    {
        if ($subscription->status === SubscriptionStatus::Canceled) {

                };

                'team_workspace' => AccessLevel::Revoked,
                'support' => AccessLevel::Community,
                default => AccessLevel::Revoked,
            };
        }

        return AccessLevel::Full;
    }
```

## Resume Flow

### Resume During Canceled Period

```php
class ResumeSubscription
{
    public function resume(Subscription $subscription): void
    {
        if (!$subscription->canceled()) {
            throw new CannotResumeException('Subscription is not canceled');
        }

        if ($subscription->ends_at->isPast()) {
            throw new CannotResumeException('Subscription has already expired');
        }

        // Restore active status
        $subscription->status = SubscriptionStatus::Active;
        $subscription->cancel_at_period_end = false;
        $subscription->canceled_at = null;
        $subscription->ends_at = null;
        $subscription->save();

        // Re-sync entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // Cancel scheduled revocation jobs
        // Jobs will check status before executing

        // Log the resume
        $subscription->statusHistories()->create([
            'from_status' => SubscriptionStatus::Canceled,
            'to_status' => SubscriptionStatus::Active,
            'changed_by' => auth()->id(),
            'reason' => 'User resumed subscription',
        ]);

        SubscriptionResumed::dispatch($subscription);

        $subscription->user->notify(new SubscriptionResumedNotification($subscription));
    }
}
```

### Resume After Expiry

If a user wants to subscribe again after their subscription has expired, they can create a new subscription:

```php
class Resubscribe
{
    public function resubscribe(User $user, Plan $plan): Subscription
    {
        // Check for any existing subscription
        $existingSubscription = $user->subscriptions()
            ->whereIn('status', [
                SubscriptionStatus::Active,
                SubscriptionStatus::Canceled,
            ])
            ->first();

        if ($existingSubscription && $existingSubscription->isActive()) {
            throw new AlreadySubscribedException();
        }

        // Create new subscription
        $subscription = Subscription::create([
            'user_id' => $user->id,
            'plan_id' => $plan->id,
            'status' => SubscriptionStatus::Active,
            'period_start' => now(),
            'period_end' => $plan->getNextBillingDate(now()),
            'metadata' => [
                'resubscribed_from' => $existingSubscription?->id,
                'resubscribed_at' => now()->toDateTimeString(),
            ],
        ]);

        // Process payment
        $this->billing->createSubscription($user, $plan);

        // Synchronize entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // Restore any archived data
        if ($existingSubscription) {
            $this->restoreArchivedData($user, $existingSubscription);
        }

        SubscriptionCreated::dispatch($subscription);

        return $subscription;
    }

    protected function restoreArchivedData(User $user, Subscription $oldSubscription): void
    {
        // Restore team workspace (if applicable)
        if ($oldSubscription->plan->hasFeature('team.workspace')) {
            $workspace = TeamWorkspace::where('subscription_id', $oldSubscription->id)
                ->withTrashed()
                ->first();

            if ($workspace) {
                $workspace->restore();
            }
        }

        // Restore saved playground projects
        PlaygroundProject::where('user_id', $user->id)
            ->where('archived', true)
            ->update(['archived' => false]);
    }
}
```

## Admin Cancellation Operations

### Admin Panel Cancellation

```php
class AdminCancellationService
{
    public function cancelWithRefund(
        Subscription $subscription,
        string $reason,
        RefundType $refundType = RefundType::None
    ): void {
        throw_unless(auth()->user()->isAdmin(), AuthorizationException::class);

        // Process refund if applicable
        $refundAmount = match ($refundType) {
            RefundType::Full => $subscription->plan->price,
            RefundType::Prorated => $this->calculateProratedRefund($subscription),
            RefundType::None => 0,
        };

        if ($refundAmount > 0) {
            $this->billing->refund($subscription, $refundAmount, [
                'reason' => $reason,
                'admin_id' => auth()->id(),
            ]);
        }

        // Cancel subscription
        $subscription->status = SubscriptionStatus::Canceled;
        $subscription->canceled_at = now();
        $subscription->ends_at = now(); // Immediate for admin cancellation
        $subscription->metadata = array_merge($subscription->metadata ?? [], [
            'admin_cancellation' => true,
            'admin_id' => auth()->id(),
            'cancellation_reason' => $reason,
            'refund_type' => $refundType->value,
            'refund_amount' => $refundAmount,
        ]);
        $subscription->save();

        // Immediate entitlement revocation
        app(EntitlementService::class)->invalidate($subscription);

        // Log admin action
        AdminAction::log('subscription.admin_cancel', [
            'subscription_id' => $subscription->id,
            'reason' => $reason,
            'refund_type' => $refundType->value,
            'refund_amount' => $refundAmount,
        ]);

        SubscriptionImmediatelyCanceled::dispatch($subscription, $reason);

        $subscription->user->notify(new AdminCanceledNotification($subscription, $reason, $refundAmount));
    }

    protected function calculateProratedRefund(Subscription $subscription): int
    {
        $daysElapsed = $subscription->period_start->diffInDays(now());
        $daysTotal = $subscription->period_start->diffInDays($subscription->period_end);
        $dailyRate = $subscription->plan->price / $daysTotal;
        $daysRemaining = $daysTotal - $daysElapsed;

        return (int) round($dailyRate * $daysRemaining);
    }
}
```

### Bulk Cancellation

```php
class BulkCancellationService
{
    public function cancelBatch(array $subscriptionIds, string $reason): BulkCancellationResult
    {
        $results = [
            'succeeded' => [],
            'failed' => [],
        ];

        foreach ($subscriptionIds as $subscriptionId) {
            try {
                $subscription = Subscription::findOrFail($subscriptionId);

                $this->cancelWithRefund(
                    $subscription,
                    $reason,
                    RefundType::Prorated
                );

                $results['succeeded'][] = $subscriptionId;
            } catch (\Exception $e) {
                $results['failed'][] = [
                    'subscription_id' => $subscriptionId,
                    'error' => $e->getMessage(),
                ];
            }
        }

        // Log bulk action
        AdminAction::log('subscription.bulk_cancel', [
            'subscription_ids' => $subscriptionIds,
            'reason' => $reason,
            'results' => $results,
        ]);

        return new BulkCancellationResult($results);
    }
}
```

```php
        ]);
    }

    public function getCancellationRate(string $period = 'month'): float
    {
        $startOfMonth = now()->startOfMonth();
        $endOfMonth = now()->endOfMonth();

        $activeAtStart = Subscription::where('status', SubscriptionStatus::Active)
            ->where('created_at', '<', $startOfMonth)
            ->count();

        $canceledDuring = Subscription::where('status', SubscriptionStatus::Canceled)
            ->where('canceled_at', '>=', $startOfMonth)
            ->where('canceled_at', '<', $endOfMonth)
            ->count();

        return $activeAtStart > 0 ? $canceledDuring / $activeAtStart : 0;
    }

    public function getChurnReasonBreakdown(string $period = 'month'): array
    {
        return Subscription::where('status', SubscriptionStatus::Canceled)
            ->where('canceled_at', '>=', now()->sub($period))
            ->selectRaw("metadata->>'$.cancel_reason' as reason, count(*) as count")
            ->groupBy('reason')
            ->get()
            ->pluck('count', 'reason')
            ->toArray();
    }

    public function getSaveRate(string $period = 'month'): float
    {
        $presented = SaveOffer::where('presented_at', '>=', now()->sub($period))->count();
        $accepted = SaveOffer::where('accepted_at', '>=', now()->sub($period))->count();

        return $presented > 0 ? $accepted / $presented : 0;
    }

    public function getReactivationRate(string $period = 'month'): float
    {
        $canceled = Subscription::where('status', SubscriptionStatus::Canceled)
            ->where('canceled_at', '>=', now()->sub($period))
            ->count();

        $reactivated = Subscription::where('status', SubscriptionStatus::Active)
            ->where('metadata->$', 'like', '%"resubscribed_from"%')
            ->where('updated_at', '>=', now()->sub($period))
            ->count();

        return $canceled > 0 ? $reactivated / $canceled : 0;
    }

    public function getWinBackRate(string $period = '90days'): float
    {
        $expired = Subscription::where('status', SubscriptionStatus::Expired)
            ->where('ends_at', '>=', now()->sub(90, 'day'))
            ->count();

        $resubscribed = Subscription::where('status', SubscriptionStatus::Active)
            ->where('metadata->$', 'like', '%"resubscribed_from"%')
            ->where('updated_at', '>=', now()->sub(90, 'day'))
            ->count();

        return $expired > 0 ? $resubscribed / $expired : 0;
    }
}
```

```php
class PreventCancellationMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $user = $request->user();

        if (!$user) {
            return $next($request);
        }

        $subscription = $user->activeSubscription();

        if ($subscription && $subscription->status === SubscriptionStatus::Canceled) {
            if ($request->expectsJson()) {
                return response()->json([
                    'error' => 'Subscription canceled',
                    'message' => 'Your subscription has been canceled. Please resubscribe to continue.',
                    'resubscribe_url' => '/billing',
                ], 403);
            }

            return redirect('/billing')
                ->with('error', 'Your subscription has been canceled. Please resubscribe to continue.');
        }

        return $next($request);
    }
}
```

### Cancellation Hooks

```php
// app/Hooks/CancellationHook.php
class CancellationHook
{
    public function beforeCancel(Subscription $subscription): void
    {
        // Check for active team members
        if ($subscription->plan->hasFeature('team.workspace')) {
            $team = $subscription->billable;
            if ($team && $team->members()->count() > 1) {
                throw new CannotCancelTeamWithMembersException(
                    'Please remove all team members before canceling'
                );
            }
        }

        // Check for active projects
        $activeProjects = Project::where('user_id', $subscription->user_id)
            ->where('status', 'active')
            ->count();

        if ($activeProjects > 0) {
            throw new HasActiveProjectsException(
                "You have {$activeProjects} active projects. Please archive or transfer them first."
            );
        }
    }

    public function afterCancel(Subscription $subscription): void
    {
        // Archive team workspace
        if ($subscription->plan->hasFeature('team.workspace')) {
            $team = $subscription->billable;
            if ($team) {
                $team->workspace->archive();
            }
        }

        // Revoke all API keys
        ApiKey::where('user_id', $subscription->user_id)
            ->where('revoked_at', null)
            ->update(['revoked_at' => now()]);

        // Disconnect MCP connections
        McpConnection::where('user_id', $subscription->user_id)
            ->where('status', 'active')
            ->update(['status' => 'disconnected']);
    }

    public function beforeResume(Subscription $subscription): void
    {
        // Check if subscription is within resume window
        if ($subscription->ends_at->isPast()) {
            throw new CannotResumeExpiredException(
                'Subscription has expired. Please create a new subscription.'
            );
        }
    }

    public function afterResume(Subscription $subscription): void
    {
        // Restore team workspace
        if ($subscription->plan->hasFeature('team.workspace')) {
            $team = $subscription->billable;
            if ($team && $team->workspace) {
                $team->workspace->restore();
            }
        }

        // Reconnect MCP connections
        McpConnection::where('user_id', $subscription->user_id)
            ->where('status', 'disconnected')
            ->update(['status' => 'active']);
    }
}
```

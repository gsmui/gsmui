# 12.05 — Trials

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

---

## Purpose

Define trial period management — how trials start, how they are tracked, how they convert to paid subscriptions, and how they expire. Trials are the primary conversion mechanism for the platform.

## Trial Architecture

```text
User subscribes to plan with trial
    ↓
Payment method collected (no charge)
    ↓
Subscription enters Trialing state
    ↓
14-day countdown begins
    ↓
[end of trial]
    ↓
Payment method charged
    ↓
Success → Active
Failure → Past Due (grace period)
```

## Trial Eligibility

### Eligibility Rules

1. **One trial per plan type per user lifetime.** A user who tried Pro cannot trial Pro again. They can trial Team (different tier).

2. **One trial per billing entity.** If a user was on a team subscription trial, their individual trial eligibility is unaffected.

3. **Trial reset on admin grant.** Admins can reset trial eligibility for support purposes.

4. **Trial not available on Free plan.** Free is always free — no trial needed.

```php
class TrialEligibility
{
    public function canTrial(User $user, Plan $plan): bool
    {
        if ($plan->trial_days === 0) {
            return false; // Plan doesn't offer trial
        }

        if ($plan->isFree()) {
            return false;
        }

        $usedTrial = Subscription::where('user_id', $user->id)
            ->where('plan_id', $plan->id)
            ->whereNotNull('trial_ends_at')
            ->exists();

        return !$usedTrial;
    }
}
```

## Starting a Trial

### Flow

```text
1. User selects plan with trial
2. User enters payment method
3. Platform creates subscription with:
   - status = 'trialing'
   - trial_ends_at = now() + plan.trial_days
4. Entitlements resolved for full plan access
5. User immediately has full plan features
6. Trial started event dispatched
7. Trial expiry scheduled (job)
```

### Implementation

```php
class TrialService
{
    public function start(User $user, Plan $plan, string $paymentMethodId): Subscription
    {
        if (!$this->eligibility->canTrial($user, $plan)) {
            throw new TrialNotAvailableException('Trial not available');
        }

        $subscription = $user->subscriptions()->create([
            'plan_id' => $plan->id,
            'status' => SubscriptionStatus::Trialing,
            'trial_ends_at' => now()->addDays($plan->trial_days),
            'quantity' => 1,
        ]);

        // Attach payment method to provider
        $this->billing->attachPaymentMethod($user, $paymentMethodId);

        // Schedule trial expiry
        ExpireTrialJob::dispatch($subscription)
            ->delay($subscription->trial_ends_at);

        // Synchronize entitlements
        app(EntitlementService::class)->synchronize($subscription);

        TrialStarted::dispatch($subscription);

        return $subscription;
    }
}
```

## Trial Conversion (Trialing → Active)

### Automatic Conversion

**Trigger:** Trial period ends, payment method is charged

**Rules:**
- Payment method must be valid
- If charge succeeds → status becomes Active
- If charge fails → status becomes Past Due (not canceled)

```php
public function convert(Subscription $subscription): void
{
    if ($subscription->status !== SubscriptionStatus::Trialing) {
        throw new InvalidStateException('Subscription is not trialing');
    }

    try {
        $this->billing->charge($subscription);
        $this->stateMachine->transition($subscription, SubscriptionStatus::Active);
        SubscriptionConverted::dispatch($subscription);
    } catch (PaymentFailedException $e) {
        $this->stateMachine->transition($subscription, SubscriptionStatus::PastDue);
        PaymentActionRequired::dispatch($subscription, $e);
    }
}
```

### Manual Conversion (User Initiated)

Users can convert before trial end by clicking "Upgrade Now" or "Start Paid Plan":

```php
public function convertEarly(Subscription $subscription): void
{
    // Same as automatic, but user-initiated
    // Remaining trial days are forfeited (no proration)
    $this->convert($subscription);
}
```

## Trial Expiry (Trialing → Past Due)

**Trigger:** Trial period ends, payment method charge fails or no payment method

```php
// app/Jobs/ExpireTrialJob.php
class ExpireTrialJob implements ShouldQueue
{
    public function handle(): void
    {
        if ($this->subscription->status !== SubscriptionStatus::Trialing) {
            return; // Already converted or modified
        }

        try {
            $this->trialService->convert($this->subscription);
        } catch (PaymentFailedException) {
            $this->stateMachine->transition(
                $this->subscription,
                SubscriptionStatus::PastDue
            );
        }
    }
}
```

# Trial Eligibility Rules

## Rule 1: One Trial Per Plan Per User

A user can only trial each plan once in their lifetime. If they trial Pro, they cannot trial Pro again. They can trial Team (different tier).

```php
class TrialEligibilityChecker
{
    public function canTrial(User $user, Plan $plan): TrialEligibilityResult
    {
        // Check if plan offers trial
        if ($plan->trial_days === 0) {
            return TrialEligibilityResult::denied(
                reason: 'Plan does not offer a trial',
            );
        }

        // Check if user already trialed this plan
        $usedTrial = Subscription::where('user_id', $user->id)
            ->where('plan_id', $plan->id)
            ->whereNotNull('trial_ends_at')
            ->exists();

        if ($usedTrial) {
            return TrialEligibilityResult::denied(
                reason: 'Trial already used for this plan',
            );
        }

        // Check if user has active subscription
        $hasActive = Subscription::where('user_id', $user->id)
            ->whereIn('status', ['active', 'trialing'])
            ->exists();

        if ($hasActive) {
            return TrialEligibilityResult::denied(
                reason: 'User already has an active subscription',
            );
        }

        // Check if user has payment method (if required)
        if (config('subscriptions.trials.require_payment_method')) {
            $hasPaymentMethod = $user->hasPaymentMethod();

            if (!$hasPaymentMethod) {
                return TrialEligibilityResult::denied(
                    reason: 'Payment method required to start trial',
                );
            }
        }

        return TrialEligibilityResult::allowed();
    }
}
```

## Rule 2: One Trial Per Billing Entity

If a user was on a team subscription trial, their individual trial eligibility is unaffected.

```php
public function canTrialIndividually(User $user, Plan $plan): bool
{
    // Team trial doesn't affect individual trial
    $teamTrial = Subscription::where('user_id', $user->id)
        ->whereHas('plan', fn($q) => $q->where('slug', 'team'))
        ->whereNotNull('trial_ends_at')
        ->exists();

    if ($teamTrial) {
        // Still check individual plan trial
        return $this->canTrial($user, $plan)->allowed();
    }

    return $this->canTrial($user, $plan)->allowed();
}
```

## Rule 3: Admin Reset

Admins can reset trial eligibility for support purposes.

```php
class AdminTrialResetter
{
    public function reset(User $user, Plan $plan, string $reason): void
    {
        // Remove existing trial record
        Subscription::where('user_id', $user->id)
            ->where('plan_id', $plan->id)
            ->whereNotNull('trial_ends_at')
            ->delete();

        // Log reset
        activity('trial')
            ->performedOn($user)
            ->withProperties([
                'plan_id' => $plan->id,
                'reason' => $reason,
                'admin_id' => auth()->id(),
            ])
            ->log('Trial eligibility reset');

        TrialEligibilityReset::dispatch($user, $plan);
    }
}
```

## Rule 4: Free Plan Exclusion

The Free plan never has trials — it's always free.

```php
public function isTrialApplicable(Plan $plan): bool
{
    return $plan->trial_days > 0 && !$plan->isFree();
}
```

# Starting a Trial

## Complete Flow

```text
1. User selects plan with trial option
2. System checks trial eligibility
3. User enters payment method
4. System validates payment method with provider
5. Subscription created with:
   - status = 'trialing'
   - trial_starts_at = now()
   - trial_ends_at = now + plan.trial_days
   - current_period_start = now()
   - current_period_end = now + plan.trial_days
6. Entitlements resolved for full plan access
7. Usage meters initialized for trial period
8. Trial started event dispatched
9. Welcome email sent
10. Trial expiry job scheduled
```

## Implementation

```php
class TrialStarter
{
    public function start(User $user, Plan $plan, string $paymentMethodId): TrialResult
    {
        // 1. Check eligibility
        $eligibility = app(TrialEligibilityChecker::class)->canTrial($user, $plan);

        if (!$eligibility->allowed()) {
            return TrialResult::denied($eligibility->reason());
        }

        // 2. Attach payment method
        $this->billing->attachPaymentMethod($user, $paymentMethodId);

        // 3. Create subscription
        $subscription = $user->subscriptions()->create([
            'plan_id' => $plan->id,
            'status' => 'trialing',
            'trial_starts_at' => now(),
            'trial_ends_at' => now()->addDays($plan->trial_days),
            'current_period_start' => now(),
            'current_period_end' => now()->addDays($plan->trial_days),
            'quantity' => 1,
            'metadata' => [
                'created_via' => 'trial',
                'payment_method_id' => $paymentMethodId,
            ],
        ]);

        // 4. Sync entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // 5. Initialize usage meters
        app(UsageMeterService::class)->initialize($subscription);

        // 6. Schedule expiry
        ExpireTrialJob::dispatch($subscription)
            ->delay($subscription->trial_ends_at);

        // 7. Send notifications
        TrialStartedMail::to($user)->send();
        TrialWelcomeNotification::send($user, $subscription);

        // 8. Dispatch events
        TrialStarted::dispatch($subscription);

        return TrialResult::success($subscription);
    }
}
```

## Trial Usage Tracking

```php
class TrialUsageTracker
{
    public function track(Subscription $subscription, string $metric, int $quantity = 1): void
    {
        // Track usage during trial
        SubscriptionUsageRecord::create([
            'subscription_id' => $subscription->id,
            'metric' => $metric,
            'quantity' => $quantity,
            'recorded_at' => now(),
        ]);

        // Check if approaching limits
        $limit = $subscription->plan->getLimit($metric);
        $used = $this->usageForPeriod($subscription, $metric);

        if ($limit && $used >= $limit * 0.8) {
            // 80% of limit reached — notify user
            TrialUsageWarning::dispatch($subscription, $metric, $used, $limit);
        }
    }

    public function usageForPeriod(Subscription $subscription, string $metric): int
    {
        return SubscriptionUsageRecord::where('subscription_id', $subscription->id)
            ->where('metric', $metric)
            ->where('recorded_at', '>=', $subscription->trial_starts_at)
            ->sum('quantity');
    }
}
```

# Trial Conversion

## Automatic Conversion

When the trial period ends, the system attempts to charge the payment method.

### Conversion Flow

```text
Trial period ends
    ↓
ExpireTrialJob fires
    ↓
System attempts to charge payment method
    ↓
If charge succeeds:
    status → 'active'
    current_period_start = trial_ends_at
    current_period_end = now + plan.interval
    Send confirmation email
    Dispatch SubscriptionConverted event
    ↓
If charge fails:
    status → 'past_due'
    Grace period starts
    Send payment failed email
    Schedule retry jobs
```

### Conversion Implementation

```php
class TrialConverter
{
    public function convert(Subscription $subscription): ConversionResult
    {
        if ($subscription->status !== 'trialing') {
            throw new InvalidStateException('Subscription is not trialing');
        }

        // Check if trial has actually ended
        if ($subscription->trial_ends_at->isFuture()) {
            throw new TrialNotExpiredException('Trial has not ended yet');
        }

        try {
            // Attempt to charge
            $this->billing->charge($subscription);

            // Calculate new period
            $interval = $subscription->plan->interval;
            $periodEnd = match ($interval) {
                'monthly' => now()->addMonth(),
                'yearly' => now()->addYear(),
                default => now()->addMonth(),
            };

            // Update subscription
            $subscription->update([
                'status' => 'active',
                'current_period_start' => $subscription->trial_ends_at,
                'current_period_end' => $periodEnd,
                'trial_ends_at' => null,
            ]);

            // Audit trail
            $subscription->statusHistories()->create([
                'from_status' => 'trialing',
                'to_status' => 'active',
                'changed_by' => null,
                'reason' => 'Trial converted to paid',
            ]);

            // Sync entitlements
            app(EntitlementService::class)->synchronize($subscription);

            // Dispatch event
            TrialConverted::dispatch($subscription);

            // Send email
            TrialConvertedMail::to($subscription->user)->send();

            return ConversionResult::success($subscription);

        } catch (PaymentFailedException $e) {
            // Transition to past due
            app(SubscriptionStateMachine::class)->transitionToPastDue($subscription);

            return ConversionResult::failed($e);
        }
    }
}
```

# Trial Expiry

## ExpireTrialJob

```php
class ExpireTrialJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        public Subscription $subscription,
    ) {}

    public function handle(): void
    {
        // Reload fresh model
        $this->subscription = $this->subscription->fresh();

        // Check if still trialing
        if ($this->subscription->status !== 'trialing') {
            return; // Already converted or modified
        }

        // Check if trial has actually ended
        if ($this->subscription->trial_ends_at->isFuture()) {
            return; // Trial hasn't ended yet
        }

        // Attempt conversion
        $result = app(TrialConverter::class)->convert($this->subscription);

        if (!$result->success()) {
            // Conversion failed — trial expired without payment
            TrialExpired::dispatch($this->subscription);
        }
    }

    public function failed(\Throwable $exception): void
    {
        // Log failure
        Log::error('ExpireTrialJob failed', [
            'subscription_id' => $this->subscription->id,
            'error' => $exception->getMessage(),
        ]);

        // Notify admin
        AdminNotification::send(
            'Trial expiry job failed',
            [
                'subscription_id' => $this->subscription->id,
                'error' => $exception->getMessage(),
            ]
        );
    }
}
```

## Trial Expiry Without Payment

If the user has no payment method or the charge fails and grace period expires:

```text
Trial ends
    ↓
No payment method → status = 'past_due'
    ↓
Grace period (3 days)
    ↓
If still no payment → status = 'expired'
    ↓
All trial access revoked
    ↓
Trial expired email sent
    ↓
Win-back email sequence starts
```

## Admin Trial Manager

```php
class AdminTrialManager
{
    public function resetTrial(User $user, Plan $plan, string $reason): void
    {
        // Remove existing trial record
        Subscription::where('user_id', $user->id)
            ->where('plan_id', $plan->id)
            ->whereNotNull('trial_ends_at')
            ->delete();

        // Log action
        activity('trial')
            ->performedOn($user)
            ->withProperties([
                'plan_id' => $plan->id,
                'reason' => $reason,
                'admin_id' => auth()->id(),
            ])
            ->log('Trial eligibility reset');

        TrialEligibilityReset::dispatch($user, $plan);
    }

    public function extendTrial(Subscription $subscription, int $days, string $reason): void
    {
        $subscription->update([
            'trial_ends_at' => $subscription->trial_ends_at->addDays($days),
            'current_period_end' => $subscription->trial_ends_at->addDays($days),
        ]);

        // Reschedule expiry job
        ExpireTrialJob::where('subscription_id', $subscription->id)->cancel();
        ExpireTrialJob::dispatch($subscription)
            ->delay($subscription->trial_ends_at);

        // Log action
        activity('trial')
            ->performedOn($subscription)
            ->withProperties([
                'days_added' => $days,
                'reason' => $reason,
                'admin_id' => auth()->id(),
            ])
            ->log('Trial extended');

        TrialExtended::dispatch($subscription, $days);
    }

    public function skipTrial(User $user, Plan $plan): Subscription
    {
        // Create subscription directly as active
        $subscription = $user->subscriptions()->create([
            'plan_id' => $plan->id,
            'status' => 'active',
            'current_period_start' => now(),
            'current_period_end' => match ($plan->interval) {
                'monthly' => now()->addMonth(),
                'yearly' => now()->addYear(),
                default => now()->addMonth(),
            },
            'quantity' => 1,
            'metadata' => [
                'created_via' => 'admin_skip_trial',
                'admin_id' => auth()->id(),
            ],
        ]);

        // Sync entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // Log action
        activity('trial')
            ->performedOn($user)
            ->withProperties([
                'plan_id' => $plan->id,
                'admin_id' => auth()->id(),
            ])
            ->log('Trial skipped');

        return $subscription;
    }

    public function forceConvert(Subscription $subscription): void
    {
        if ($subscription->status !== 'trialing') {
            throw new InvalidStateException('Subscription is not trialing');
        }

        // Convert immediately
        app(TrialConverter::class)->convert($subscription);

        // Log action
        activity('trial')
            ->performedOn($subscription)
            ->withProperties([
                'admin_id' => auth()->id(),
            ])
            ->log('Trial force converted');
    }
}
```

```php
class TrialAnalytics
{
    public function conversionRate(string $period = '30d'): float
    {
        $start = Carbon::now()->subPeriod(1);
        $end = Now();

        $started = Subscription::where('status', 'trialing')
            ->where('created_at', '>=', $start)
            ->where('created_at', '<', $end)
            ->count();

        $converted = Subscription::where('status', 'active')
            ->whereNotNull('trial_ends_at')
            ->where('created_at', '>=', $start)
            ->where('created_at', '<', $end)
            ->count();

        return $started > 0 ? ($converted / $started) * 100 : 0;
    }

    public function avgTimeToConversion(): float
    {
        return Subscription::where('status', 'active')
            ->whereNotNull('trial_ends_at')
            ->where('created_at', '>=', now()->subDays(90))
            ->get()
            ->avg(function ($sub) {
                return $sub->created_at->diffInDays($sub->trial_ends_at);
            });
    }

    public function churnRate(string $period = '30d'): float
    {
        $start = Carbon::now()->subPeriod(1);

        $started = Subscription::where('created_at', '>=', $start)
            ->whereNotNull('trial_ends_at')
            ->count();

        $churned = Subscription::where('created_at', '>=', $start)
            ->whereNotNull('trial_ends_at')
            ->where('status', 'expired')
            ->count();

        return $started > 0 ? ($churned / $started) * 100 : 0;
    }

    public function planConversionBreakdown(): array
    {
        return Plan::where('trial_days', '>', 0)
            ->withCount(['subscriptions as total_trials' => function ($q) {
                $q->whereNotNull('trial_ends_at');
            }])
            ->withCount(['subscriptions as converted' => function ($q) {
                $q->where('status', 'active')
                    ->whereNotNull('trial_ends_at');
            }])
            ->get()
            ->map(fn($plan) => [
                'plan' => $plan->name,
                'total_trials' => $plan->total_trials,
                'converted' => $plan->converted,
                'conversion_rate' => $plan->total_trials > 0
                    ? ($plan->converted / $plan->total_trials) * 100
                    : 0,
            ])
            ->toArray();
    }
```

```php
class TrialAnalyticsService
{
    public function getDashboardMetrics(string $period = '30d'): array
    {

        return [
            'summary' => $this->getSummary($start),
            'conversion_funnel' => $this->getConversionFunnel($start),

            'cohort_analysis' => $this->getCohortAnalysis($start),

    protected function getSummary(Carbon $start): array
    {
        $trialsStarted = Subscription::where('trial_starts_at', '>=', $start)->count();
        $trialsConverted = Subscription::where('trial_starts_at', '>=', $start)
            ->where('status', 'active')
            ->whereNotNull('trial_ends_at')
            ->count();
        $trialsExpired = Subscription::where('trial_starts_at', '>=', $start)
            ->where('status', 'expired')
            ->count();

        return [
            'trials_started' => $trialsStarted,
            'trials_converted' => $trialsConverted,
            'trials_expired' => $trialsExpired,
            'conversion_rate' => $trialsStarted > 0
                ? round(($trialsConverted / $trialsStarted) * 100, 1)
                : 0,
            'churn_rate' => $trialsStarted > 0
                ? round(($trialsExpired / $trialsStarted) * 100, 1)
                : 0,
        ];
    }

    protected function getConversionFunnel(Carbon $start): array
    {
        $totalTrials = Subscription::where('trial_starts_at', '>=', $start)->count();
        $enteredPayment = Subscription::where('trial_starts_at', '>=', $start)
            ->whereNotNull('metadata->payment_method_id')
            ->count();
        $completedTrial = Subscription::where('trial_starts_at', '>=', $start)
            ->where('status', 'active')
            ->count();

        return [
            'total_trials' => $totalTrials,
            'entered_payment' => $enteredPayment,
            'completed_trial' => $completedTrial,
            'payment_entry_rate' => $totalTrials > 0
                ? round(($enteredPayment / $totalTrials) * 100, 1)
                : 0,
            'completion_rate' => $enteredPayment > 0
                ? round(($completedTrial / $enteredPayment) * 100, 1)
                : 0,
        ];
    }

    protected function getPlanBreakdown(Carbon $start): array
    {
        return Plan::where('trial_days', '>', 0)
            ->withCount(['subscriptions as total_trials' => function ($q) use ($start) {
                $q->where('trial_starts_at', '>=', $start);
            }])
            ->withCount(['subscriptions as converted' => function ($q) use ($start) {
                $q->where('trial_starts_at', '>=', $start)
                  ->where('status', 'active');
            }])
            ->get()
            ->map(fn($plan) => [
                'plan' => $plan->name,
                'total_trials' => $plan->total_trials,
                'converted' => $plan->converted,
                'conversion_rate' => $plan->total_trials > 0
                    ? round(($plan->converted / $plan->total_trials) * 100, 1)
                    : 0,
            ])
            ->toArray();
    }

    protected function getDailyTrend(Carbon $start): array
    {
        return Subscription::where('trial_starts_at', '>=', $start)
            ->selectRaw('DATE(trial_starts_at) as date, COUNT(*) as count')
            ->groupBy('date')
            ->orderBy('date')
            ->get()
            ->toArray();
    }
```

## Cohort Analysis

```php
class TrialCohortAnalyzer
{
    public function analyze(Carbon $cohortStart, Carbon $cohortEnd): array
    {
        $trials = Subscription::where('trial_starts_at', '>=', $cohortStart)
            ->where('trial_starts_at', '<', $cohortEnd)
            ->get();

        $cohorts = [];
        foreach (range(0, 30) as $day) {
            $converted = $trials->filter(fn($t) =>
                $t->status === 'active' &&
                $t->trial_ends_at &&
                $t->trial_ends_at->diffInDays($t->trial_starts_at) <= $day
            )->count();

            $cohorts[$day] = [
                'day' => $day,
                'converted' => $converted,
                'rate' => $trials->count() > 0
                    ? round(($converted / $trials->count()) * 100, 1)
                    : 0,
            ];
        }

        return $cohorts;
    }
}
```

```php
class TrialExperimentService
{
    public function assignVariant(User $user, TrialExperiment $experiment): int
    {
        $hash = md5($user->id . $experiment->name);
        $bucket = hexdec(substr($hash, 0, 8)) / 0xFFFFFFFF;

        return $bucket < $experiment->trafficSplit
            ? $experiment->controlDays
            : $experiment->variantDays;
    }

    public function trackConversion(User $user, TrialExperiment $experiment, int $trialDays): void
    {
        TrialExperimentConversion::create([
            'experiment_name' => $experiment->name,
            'user_id' => $user->id,
            'trial_days' => $trialDays,
            'converted_at' => now(),
        ]);
    }

    public function results(TrialExperiment $experiment): array
    {
        $conversions = TrialExperimentConversion::where('experiment_name', $experiment->name)
            ->get()
            ->groupBy('trial_days');

        return [
            'control' => [
                'trial_days' => $experiment->controlDays,
                'conversions' => $conversions->get($experiment->controlDays, collect())->count(),
            ],
            'variant' => [
                'trial_days' => $experiment->variantDays,
                'conversions' => $conversions->get($experiment->variantDays, collect())->count(),
            ],
        ];
    }
}
```

```php
class TrialConversionOptimizer
{
    public function getOptimizationSuggestions(User $user): array
    {
        $subscription = $user->activeSubscription();

        if (!$subscription || $subscription->status !== 'trialing') {
            return [];
        }

        $daysRemaining = $subscription->trial_ends_at->diffInDays(now());
        $usage = $this->getUserUsage($user);
        $engagement = $this->getEngagementScore($user);

        $suggestions = [];

        if ($daysRemaining <= 3 && $engagement < 0.3) {
            $suggestions[] = [
                'type' => 'low_engagement',
                'action' => 'send_reengagement_email',
                'priority' => 'high',
            ];
        }

        if ($daysRemaining <= 2 && !$usage->hasUsedPremiumFeatures()) {
            $suggestions[] = [
                'type' => 'feature_not_used',
                'action' => 'send_feature_highlight',
                'priority' => 'high',
            ];
        }

        if ($daysRemaining === 1) {
            $suggestions[] = [
                'type' => 'trial_ending',
                'action' => 'send_final_reminder',
                'priority' => 'critical',
            ];
        }

        return $suggestions;
    }

    protected function getUserUsage(User $user): TrialUsage
    {
        return new TrialUsage(
            componentsUsed = $user->usageRecords()->where('metric', 'component.view')->count(),
            themesUsed = $user->usageRecords()->where('metric', 'theme.view')->count(),
            aiCreditsUsed = $user->usageRecords()->where('metric', 'ai.chat')->sum('quantity'),
            downloadsCount = $user->usageRecords()->where('metric', 'download')->count(),
        );
    }

    protected function getEngagementScore(User $user): float
    {
        $actions = $user->activity()->where('created_at', '>=', now()->subDays(7))->count();
        return min(1.0, $actions / 50); // Normalize to 0-1
    }
}
```

## Trial Analytics Dashboard

### Metrics Panel

| Metric | Calculation | Period |
|---|---|---|
| Total trial starts | COUNT(subscriptions WHERE status=trialing AND created_at) | This week/month |
| Trial conversion rate | COUNT(converted) / COUNT(started) | Rolling 30 days |
| Average time to convert | AVG(DATEDIFF(converted_at, created_at)) | Rolling 30 days |
| Trial churn rate | COUNT(expired) / COUNT(started) | Rolling 30 days |
| Revenue from trials | SUM(first_payment WHERE trial_converted) | This month |
| Average trial revenue | SUM(first_payment) / COUNT(converted) | This month |

## Trial Quick Reference

| Status | Description | Access Level |
|---|---|---|
| Active | Currently in trial | Full |
| Extended | Extended by admin | Full |
| Expired | Trial period ended | None |
| Converted | Upgraded to paid | Full |

## Trial Configuration

| Setting | Default | Range |
|---|---|---|
| Trial duration | 14 days | 3-30 days |
| Payment required | No | Yes/No |
| Feature access | Full | Full/Limited |
| Email reminders | Yes | Yes/No |
| Max extensions | 1 | 0-5 |
| Trial per plan | Yes | Yes/No |
- Trial auto-converts to paid if payment method is on file

## Purpose

Define seat management for team and enterprise subscriptions — how seats are allocated, assigned, invited, transferred, and reclaimed.

## Seat Architecture

```text
Team Subscription
    ↓
Seat Pool (total = base + purchased add-ons)
    ↓
Assigned Seats (currently occupied)
    ↓
Available Seats (unassigned or pending)
    ↓
Pending Invitations (sent, not yet accepted)
```

```php
public function assignSeat(Team $team, User $user, string $role = 'member'): Seat
{
    // Check availability
    if ($team->availableSeats() <= 0) {
        throw new NoSeatsAvailableException('No seats available');
    }

    // Check if already a member
    if ($team->members()->where('user_id', $user->id)->exists()) {
        throw new UserAlreadyMemberException('User is already a team member');
    }

    $seat = Seat::create([
        'subscription_id' => $team->subscription->id,
        'team_id' => $team->id,
        'user_id' => $user->id,
        'email' => $user->email,
        'status' => 'assigned',
        'role' => $role,
        'assigned_at' => now(),
    ]);

    // Attach to team
    $team->members()->attach($user->id, ['role' => $role]);

    // Synchronize entitlements
    app(EntitlementService::class)->invalidate($user);

    SeatAssigned::dispatch($seat);

    return $seat;
}
```

## Detailed Seat Lifecycle

### Complete State Machine

The seat lifecycle is governed by a formal state machine that ensures data integrity and prevents invalid transitions. Every transition is logged, audited, and triggers appropriate side effects.

```text
                    ┌─────────────┐
                    │  CREATED    │
                    │ (provisioned)│
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
       ┌──────────┐  ┌──────────┐  ┌──────────┐
       │ AVAILABLE │  │ INVITED  │  │ ASSIGNED │
       │ (idle)    │  │ (pending)│  │ (active) │
       └─────┬────┘  └─────┬────┘  └─────┬────┘
             │             │             │
             │        ┌────┼────┐   ┌────┼────┐
             │        ▼    ▼    ▼   ▼    ▼    ▼
             │   ┌─────┐┌────┐┌───┐┌───┐┌────┐┌─────┐
             │   │ACPT ││EXPR││REV││TRN││RECL││SUSP │
             │   └─────┘└────┘└───┘└───┘└────┘└─────┘
             │        │    │        │    │
             ▼        ▼    ▼        ▼    ▼
       ┌─────────────────────────────────────┐
       │           TERMINAL STATES           │
       │  (available, expired, cancelled)    │
       └─────────────────────────────────────┘
```

### State Definitions

| State | Description | Duration | Exit Actions |
|---|---|---|---|
| `created` | Seat row exists but not yet provisioned | Instant | Provision to available or invited |
| `available` | Seat exists in pool, no user assigned | Indefinite | Assign, invite, or delete |
| `invited` | Invitation sent, awaiting acceptance | 7 days default | Accept, expire, or revoke |
| `assigned` | User actively occupies seat | Until reclaimed | Transfer, reclaim, or suspend |
| `pending_transfer` | Transfer initiated, awaiting new user confirmation | 48 hours | Complete transfer or cancel |
| `suspended` | Temporarily disabled (billing issue, etc.) | Until resolved | Reinforce or reclaim |
| `expired` | Invitation expired without acceptance | Terminal | Delete or re-invite |
| `cancelled` | Seat removed from pool (downgrade) | Terminal | None |

### Transition Rules

```php
class SeatTransition
{
    private const TRANSITIONS = [
        'created'    => ['available', 'invited'],
        'available'  => ['assigned', 'invited', 'cancelled'],
        'invited'    => ['assigned', 'expired', 'available', 'cancelled'],
        'assigned'   => ['available', 'pending_transfer', 'suspended'],
        'pending_transfer' => ['assigned', 'available', 'cancelled'],
        'suspended'  => ['assigned', 'available', 'cancelled'],
        'expired'    => ['available', 'cancelled'],
        'cancelled'  => [],
    ];

    public function canTransition(string $from, string $to): bool
    {
        return in_array($to, self::TRANSITIONS[$from] ?? []);
    }

    public function transition(Seat $seat, string $to, ?User $actor = null): void
    {
        if (!$this->canTransition($seat->status, $to)) {
            throw new InvalidSeatTransitionException(
                "Cannot transition from {$seat->status} to {$to}"
            );
        }

        $from = $seat->status;

        $seat->update(['status' => $to]);

        SeatTransitioned::dispatch($seat, $from, $to, $actor);

        $this->logTransition($seat, $from, $to, $actor);
    }

    private function logTransition(Seat $seat, string $from, string $to, ?User $actor): void
    {
        SeatAuditLog::create([
            'seat_id' => $seat->id,
            'team_id' => $seat->team_id,
            'from_status' => $from,
            'to_status' => $to,
            'actor_id' => $actor?->id,
            'metadata' => [
                'ip_address' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ],
        ]);
    }
}
```

## Invitation System

### Sending Invitations

```php
class SeatInvitationService
{
    public function sendInvitation(
        Seat $seat,
        string $email,
        User $invitedBy,
        string $role = 'member'
    ): SeatInvitation {
        if ($seat->status !== 'available') {
            throw new SeatNotAvailableForInvitationException();
        }

        $existing = SeatInvitation::where('team_id', $seat->team_id)
            ->where('email', $email)
            ->whereNull('accepted_at')
            ->where('expires_at', '>', now())
            ->first();

        if ($existing) {
            throw new InvitationAlreadyPendingException(
                'An invitation is already pending for this email'
            );
        }

        if ($seat->team->members()->where('email', $email)->exists()) {
            throw new UserAlreadyTeamMemberException();
        }

        $invitation = SeatInvitation::create([
            'seat_id' => $seat->id,
            'team_id' => $seat->team_id,
            'invited_by' => $invitedBy->id,
            'email' => $email,
            'token' => Str::random(64),
            'role' => $role,
            'sent_at' => now(),
            'expires_at' => now()->addDays(
                config('seats.invitation_expiry_days', 7)
            ),
        ]);

        $seat->update([
            'status' => 'invited',
            'email' => $email,
            'invited_at' => now(),
            'invitation_expires_at' => $invitation->expires_at,
            'invitation_token' => $invitation->token,
        ]);

        Mail::to($email)->send(new SeatInvitationEmail(
            team: $seat->team,
            invitation: $invitation,
            invitedBy: $invitedBy,
        ));

        SeatInvitationSent::dispatch($invitation);

        return $invitation;
    }

    public function acceptInvitation(string $token, User $user): Seat
    {
        $invitation = SeatInvitation::where('token', $token)
            ->whereNull('accepted_at')
            ->where('expires_at', '>', now())
            ->firstOrFail();

        if ($invitation->email !== $user->email) {
            throw new InvitationEmailMismatchException();
        }

        $team = $invitation->team;
        if ($team->availableSeats() <= 0) {
            throw new NoSeatsAvailableException();
        }

        $invitation->update(['accepted_at' => now()]);

        $seat = $invitation->seat;
        $seat->update([
            'user_id' => $user->id,
            'status' => 'assigned',
            'role' => $invitation->role,
            'assigned_at' => now(),
        ]);

        $team->members()->attach($user->id, ['role' => $invitation->role]);

        app(EntitlementService::class)->invalidate($user);

        SeatInvitationAccepted::dispatch($invitation, $seat);

        return $seat;
    }

    public function revokeInvitation(SeatInvitation $invitation, User $revokedBy): void
    {
        if ($invitation->accepted_at) {
            throw new InvitationAlreadyAcceptedException();
        }

        $invitation->delete();

        $seat = $invitation->seat;
        $seat->update([
            'status' => 'available',
            'email' => null,
            'invited_at' => null,
            'invitation_expires_at' => null,
            'invitation_token' => null,
        ]);

        SeatInvitationRevoked::dispatch($invitation);
    }

    public function resendInvitation(SeatInvitation $invitation, User $resendedBy): void
    {
        if ($invitation->accepted_at) {
            throw new InvitationAlreadyAcceptedException();
        }

        if ($invitation->expires_at->isPast()) {
            throw new InvitationExpiredException();
        }

        $invitation->update([
            'resend_count' => $invitation->resend_count + 1,
            'last_reminder_at' => now(),
        ]);

        Mail::to($invitation->email)->send(new SeatInvitationReminderEmail(
            team: $invitation->team,
            invitation: $invitation,
        ));

        SeatInvitationResent::dispatch($invitation);
    }
}
```

### Invitation Expiration Handling

```php
class ExpireSeatInvitationsCommand extends Command
{
    protected $signature = 'seats:expire-invitations';
    protected $description = 'Expire pending seat invitations past their expiry date';

    public function handle(): int
    {
        $expiredInvitations = SeatInvitation::whereNull('accepted_at')
            ->where('expires_at', '<', now())
            ->get();

        foreach ($expiredInvitations as $invitation) {
            DB::transaction(function () use ($invitation) {
                $invitation->update(['status' => 'expired']);

                $seat = $invitation->seat;
                if ($seat->status === 'invited') {
                    $seat->update([
                        'status' => 'available',
                        'email' => null,
                        'invited_at' => null,
                        'invitation_expires_at' => null,
                        'invitation_token' => null,
                    ]);
                }

                SeatInvitationExpired::dispatch($invitation);
            });
        }

        $this->info("Expired {$expiredInvitations->count()} invitations.");

        return Command::SUCCESS;
    }
}
```

## Seat Transfer System

### Transfer Workflow

```php
class SeatTransferService
{
    public function initiateTransfer(
        Seat $seat,
        string $newUserEmail,
        User $initiatedBy
    ): SeatTransfer {
        if (!$initiatedBy->can('manageSeats', $seat->team)) {
            throw new UnauthorizedSeatTransferException();
        }

        if ($seat->status !== 'assigned') {
            throw new SeatNotTransferableException();
        }

        $existingUser = User::where('email', $newUserEmail)->first();
        if ($existingUser && $seat->team->members()->where('user_id', $existingUser->id)->exists()) {
            throw new UserAlreadyTeamMemberException();
        }

        $transfer = SeatTransfer::create([
            'seat_id' => $seat->id,
            'team_id' => $seat->team_id,
            'from_user_id' => $seat->user_id,
            'to_email' => $newUserEmail,
            'initiated_by' => $initiatedBy->id,
            'status' => 'pending',
            'token' => Str::random(64),
            'expires_at' => now()->addHours(48),
        ]);

        $seat->update(['status' => 'pending_transfer']);

        Mail::to($newUserEmail)->send(new SeatTransferEmail(
            team: $seat->team,
            transfer: $transfer,
            initiatedBy: $initiatedBy,
        ));

        SeatTransferInitiated::dispatch($transfer);

        return $transfer;
    }

    public function completeTransfer(string $token, User $newUser): Seat
    {
        $transfer = SeatTransfer::where('token', $token)
            ->where('status', 'pending')
            ->where('expires_at', '>', now())
            ->firstOrFail();

        if ($transfer->to_email !== $newUser->email) {
            throw new TransferEmailMismatchException();
        }

        $seat = $transfer->seat;

        DB::transaction(function () use ($seat, $transfer, $newUser) {
            $seat->team->members()->detach($seat->user_id);

            app(EntitlementService::class)->invalidate(
                User::find($seat->from_user_id)
            );

            $seat->update([
                'user_id' => $newUser->id,
                'email' => $newUser->email,
                'status' => 'assigned',
                'transferred_at' => now(),
            ]);

            $seat->team->members()->attach($newUser->id, ['role' => $seat->role]);

            app(EntitlementService::class)->invalidate($newUser);

            $transfer->update([
                'status' => 'completed',
                'completed_at' => now(),
                'to_user_id' => $newUser->id,
            ]);
        });

        SeatTransferCompleted::dispatch($transfer);

        return $seat->fresh();
    }

    public function cancelTransfer(SeatTransfer $transfer, User $cancelledBy): void
    {
        if ($transfer->status !== 'pending') {
            throw new TransferNotCancellableException();
        }

        $transfer->update(['status' => 'cancelled']);

        $seat = $transfer->seat;
        if ($seat->status === 'pending_transfer') {
            $seat->update(['status' => 'assigned']);
        }

        SeatTransferCancelled::dispatch($transfer);
    }
}
```

### Add-on Seat Purchasing

```php
class SeatBillingService
{
    public function purchaseAdditionalSeats(
        Team $team,
        int $quantity,
        ?string $paymentMethodId = null
    ): SeatPurchase {
        $pricePerSeat = $this->getSeatPrice($team);
        $totalAmount = $quantity * $pricePerSeat;

        $subscriptionItem = $this->stripe->subscriptionItems()->create([
            'subscription' => $team->subscription->stripe_id,
            'price_data' => [
                'currency' => 'usd',
                'unit_amount' => $pricePerSeat,
                'recurring' => ['interval' => 'month'],
                'product_data' => [
                    'name' => "Additional Seat ({$team->name})",
                ],
            ],
            'quantity' => $quantity,
        ]);

        $team->increment('purchased_seats', $quantity);

        $purchase = SeatPurchase::create([
            'team_id' => $team->id,
            'subscription_id' => $team->subscription_id,
            'quantity' => $quantity,
            'price_per_seat' => $pricePerSeat,
            'total_amount' => $totalAmount,
            'stripe_subscription_item_id' => $subscriptionItem->id,
            'status' => 'active',
        ]);

        $this->provisionSeats($team, $quantity);

        SeatsPurchased::dispatch($team, $quantity, $purchase);

        return $purchase;
    }

    public function removeAdditionalSeats(Team $team, int $quantity): void
    {
        $currentPurchased = $team->purchased_seats;

        if ($quantity > $currentPurchased) {
            throw new CannotRemoveMoreSeatsThanPurchasedException();
        }

        $currentMembers = $team->members()->count();
        $baseSeats = $team->plan->base_seats;
        $availableAfterRemoval = $baseSeats + ($currentPurchased - $quantity);

        if ($currentMembers > $availableAfterRemoval) {
            throw new RemovingSeatsWouldExceedLimitException();
        }

        $seatItem = $this->getSeatSubscriptionItem($team);
        if ($seatItem) {
            $this->stripe->subscriptionItems()->update($seatItem->id, [
                'quantity' => $seatItem->quantity - $quantity,
            ]);
        }

        $team->decrement('purchased_seats', $quantity);

        $this->reclaimExcessSeats($team, $quantity);

        SeatsRemoved::dispatch($team, $quantity);
    }

    public function calculateSeatRefund(Team $team, int $quantity): int
    {
        $pricePerSeat = $this->getSeatPrice($team);
        $daysRemaining = now()->daysInMonth - now()->day;
        $dailyRate = $pricePerSeat / now()->daysInMonth;

        return (int) ($quantity * $dailyRate * $daysRemaining);
    }

    private function getSeatPrice(Team $team): int
    {
        return $team->subscription->plan->additional_seat_price ?? 1000;
    }

    private function provisionSeats(Team $team, int $quantity): void
    {
        for ($i = 0; $i < $quantity; $i++) {
            Seat::create([
                'subscription_id' => $team->subscription_id,
                'team_id' => $team->id,
                'status' => 'available',
                'role' => 'member',
            ]);
        }
    }

    private function reclaimExcessSeats(Team $team, int $quantity): void
    {
        Seat::where('team_id', $team->id)
            ->where('status', 'available')
            ->limit($quantity)
            ->delete();
    }
}
```

### Seat Usage Metering

```php
class SeatUsageMeteringService
{
    public function calculateUsage(Team $team): SeatUsage
    {
        $totalSeats = $team->base_seats + $team->purchased_seats;
        $assignedSeats = $team->seats()->where('status', 'assigned')->count();
        $invitedSeats = $team->seats()->where('status', 'invited')->count();
        $availableSeats = $totalSeats - $assignedSeats - $invitedSeats;

        return new SeatUsage(
            team: $team,
            totalSeats: $totalSeats,
            assignedSeats: $assignedSeats,
            invitedSeats: $invitedSeats,
            availableSeats: max(0, $availableSeats),
            utilizationRate: $totalSeats > 0 ? ($assignedSeats / $totalSeats) * 100 : 0,
            monthlyCost: $this->calculateMonthlyCost($team, $assignedSeats),
        );
    }

    private function calculateMonthlyCost(Team $team, int $assignedSeats): int
    {
        $baseCost = $team->plan->price;
        $additionalSeats = max(0, $assignedSeats - $team->plan->base_seats);
        $additionalCost = $additionalSeats * ($team->plan->additional_seat_price ?? 1000);

        return $baseCost + $additionalCost;
    }

    public function generateUsageReport(Team $team): array
    {
        $usage = $this->calculateUsage($team);

        return [
            'team_id' => $team->id,
            'team_name' => $team->name,
            'plan' => $team->plan->name,
            'period' => now()->format('Y-m'),
            'seats' => [
                'total' => $usage->totalSeats,
                'assigned' => $usage->assignedSeats,
                'invited' => $usage->invitedSeats,
                'available' => $usage->availableSeats,
                'utilization_rate' => round($usage->utilizationRate, 2),
            ],
            'billing' => [
                'base_cost' => $team->plan->price,
                'additional_seat_cost' => $usage->additionalSeatsCost ?? 0,
                'total_monthly_cost' => $usage->monthlyCost,
            ],
            'generated_at' => now()->toISOString(),
        ];
    }
}
```

### Role-Based Access Control

```php
class SeatPolicy
{
    public function viewAny(User $user, Team $team): bool
    {
        return $team->members()->where('user_id', $user->id)->exists();
    }

    public function view(User $user, Seat $seat): bool
    {
        return $seat->team->members()->where('user_id', $user->id)->exists();
    }

    public function create(User $user, Team $team): bool
    {
        return $team->members()
            ->where('user_id', $user->id)
            ->whereIn('role', ['owner', 'admin'])
            ->exists();
    }

    public function invite(User $user, Team $team): bool
    {
        return $team->members()
            ->where('user_id', $user->id)
            ->whereIn('role', ['owner', 'admin'])
            ->exists();
    }

    public function assign(User $user, Team $team): bool
    {
        return $team->members()
            ->where('user_id', $user->id)
            ->whereIn('role', ['owner', 'admin'])
            ->exists();
    }

    public function reclaim(User $user, Seat $seat): bool
    {
        if ($seat->team->owner_id === $user->id) {
            return true;
        }

        if ($seat->team->members()
            ->where('user_id', $user->id)
            ->where('role', 'admin')
            ->exists()
            && $seat->role === 'member'
        ) {
            return true;
        }

        return false;
    }

    public function transfer(User $user, Seat $seat): bool
    {
        return $this->reclaim($user, $seat);
    }

    public function purchaseAdditional(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id;
    }

    public function removeAdditional(User $user, Team $team): bool
    {
        return $team->owner_id === $user->id;
    }

    public function updateRole(User $user, Seat $seat): bool
    {
        if ($seat->team->owner_id === $user->id) {
            return true;
        }

        return $seat->team->members()
            ->where('user_id', $user->id)
            ->where('role', 'admin')
            ->exists() && $seat->role !== 'owner';
    }
}
```

### Reminder Command

```php
class SendSeatRemindersCommand extends Command
{
    protected $signature = 'seats:send-reminders';
    protected $description = 'Send reminder emails for seat invitations expiring soon';

    public function handle(): int
    {
        $reminderDays = config('seats.notifications.reminder_days_before_expiry', 2);
        $expiringAt = now()->addDays($reminderDays);

        $invitations = SeatInvitation::whereNull('accepted_at')
            ->where('expires_at', '<=', $expiringAt)
            ->where('expires_at', '>', now())
            ->where('last_reminder_at', '<', now()->subDay())
            ->get();

        foreach ($invitations as $invitation) {
            Mail::to($invitation->email)->send(new SeatInvitationReminderEmail(
                team: $invitation->team,
                invitation: $invitation,
                daysRemaining: now()->diffInDays($invitation->expires_at),
            ));

            $invitation->update(['last_reminder_at' => now()]);
        }

        $this->info("Sent {$invitations->count()} reminders.");

        return Command::SUCCESS;
    }
}
```

## Performance Considerations

### Caching Strategy

```php
class SeatCacheService
{
    private const CACHE_PREFIX = 'team:';
    private const CACHE_TTL = 300; // 5 minutes

    public function getAvailableSeatsCount(Team $team): int
    {
        $cacheKey = self::CACHE_PREFIX . "{$team->id}:seats:available";

        return Cache::remember($cacheKey, self::CACHE_TTL, function () use ($team) {
            return $team->seats()->where('status', 'available')->count();
        });
    }

    public function getTotalSeatsCount(Team $team): int
    {
        $cacheKey = self::CACHE_PREFIX . "{$team->id}:seats:total";

        return Cache::remember($cacheKey, self::CACHE_TTL, function () use ($team) {
            return $team->base_seats + $team->purchased_seats;
        });
    }

    public function invalidateSeatCache(Team $team): void
    {
        Cache::forget(self::CACHE_PREFIX . "{$team->id}:seats:available");
        Cache::forget(self::CACHE_PREFIX . "{$team->id}:seats:total");
        Cache::forget(self::CACHE_PREFIX . "{$team->id}:seats:usage");
    }

    public function getSeatUsage(Team $team): ?array
    {
        $cacheKey = self::CACHE_PREFIX . "{$team->id}:seats:usage";

        return Cache::remember($cacheKey, self::CACHE_TTL, function () use ($team) {
            return app(SeatUsageMeteringService::class)->generateUsageReport($team);
        });
    }
}
```

# 12.09 — Grace Periods

**Project:** GsmUi
**Domain:** Subscription Management
**Version:** 1.0.0

---

## Purpose

Define the grace period mechanism that protects users from immediate access loss when payment fails. Grace periods balance revenue collection with user experience — users retain access during the grace window while the system works to resolve payment issues.

## Grace Period Architecture

```text
Payment Fails
    ↓
Active → Past Due
    ↓
Grace Period Begins (3 days)
    ↓
Day 1: Full access, retry payment
Day 2: Full access, retry payment
Day 3: Full access, final retry
    ↓
Payment Resolved ──────────── Grace Expires
    ↓                              ↓
Past Due → Active             Past Due → Unpaid
Entitlements maintained       Entitlements revoked
```

## Grace Period Rules

### Duration

Default grace period is **3 calendar days**. Configurable per environment via `config/subscriptions.php`:

```php
return [
    'grace_period_days' => env('SUBSCRIPTION_GRACE_DAYS', 3),
];
```

### Access During Grace

During the grace period, the user retains **full access** to all plan features. The subscription is treated as Active for entitlement resolution purposes.

```php
public function hasAccessDuringGrace(Subscription $subscription): bool
{
    if ($subscription->status !== SubscriptionStatus::PastDue) {
        return false;
    }

    $graceEnd = $subscription->updated_at->addDays(
        config('subscriptions.grace_period_days')
    );

    return now()->lt($graceEnd);
}
```

### Multiple Grace Periods

A user can enter the grace period multiple times (each renewal failure starts a new grace period). There is no lifetime limit, but repeated failures after 3+ grace periods may trigger an admin review.

## Grace Period Flow

### Start of Grace Period

```text
Active → Past Due
    ↓
1. Subscription status updated
2. Grace period start logged in status_histories
3. First payment retry scheduled (immediate)
4. Entitlements maintained (no change)
5. User notified: "Payment failed"
6. Dashboard shows warning banner
7. Email sent: "Action required: update payment method"
```

### Grace Period Expiry

```php
// app/Jobs/ExpireGracePeriodJob.php
class ExpireGracePeriodJob implements ShouldQueue
{
    public function handle(): void
    {
        if ($this->subscription->status !== SubscriptionStatus::PastDue) {
            return; // Payment was resolved, no action needed
        }

        // All retries exhausted
        $this->subscription->status = SubscriptionStatus::Unpaid;
        $this->subscription->save();

        // Revoke entitlements
        app(EntitlementService::class)->invalidate($this->subscription);

        // Log transition
        $this->subscription->statusHistories()->create([
            'from_status' => SubscriptionStatus::PastDue,
            'to_status' => SubscriptionStatus::Unpaid,
            'changed_by' => null,
            'reason' => 'Grace period expired',
        ]);

        // Notify user
        $this->subscription->user->notify(
            new SubscriptionSuspendedNotification($this->subscription)
        );

        SubscriptionGracePeriodExpired::dispatch($this->subscription);
    }
}
```

## Payment Method Update During Grace

Users can update their payment method during the grace period to resolve the issue:

```php
class GracePeriodPaymentResolver
{
    public function updatePaymentMethod(Subscription $subscription, string $paymentMethodId): void

            $subscription->user,
            $paymentMethodId

            SubscriptionPaymentRecovered::dispatch($subscription);
        } catch (PaymentFailedException) {
            // Charge still failing — keep in grace period
            // Notify user of specific failure reason
        }
    }
}
```

## Entitlement Behavior During Grace

```php
// EntitlementService checks grace period
class EntitlementService
{
    public function resolve(Billable $billable): Collection
    {
        $subscription = $billable->activeSubscription();

        if (!$subscription) {
            return collect([]);
        }

        // During grace period, treat as active
        if ($subscription->status === 'past_due' && $this->gracePeriod->hasAccessDuringGrace($subscription)) {
            return $this->resolveForActive($subscription);
        }

        // Normal resolution
        return $this->resolveInternal($subscription);
    }
}
```

## Detailed Grace Period Scenarios

### Scenario: First Payment Failure

When a user's payment method fails for the first time during renewal, the grace period begins.

```text
Timeline:
Day 0: Payment attempt fails
Day 0: Subscription status → Past Due
Day 0: First retry attempted immediately
Day 0: Email sent: "Payment failed - update payment method"
Day 0: Dashboard warning banner displayed
Day 1: Second retry attempted
Day 1: Email sent: "Second payment attempt failed"
Day 2: Third retry attempted (final)
Day 2: Email sent: "Final notice - update payment method"
Day 3: Grace period expires
Day 3: Subscription status → Unpaid
Day 3: Entitlements revoked
Day 3: Email sent: "Subscription suspended"
```

```php
class FirstPaymentFailureHandler
{
    public function handle(Subscription $subscription): void
    {
        // Transition to Past Due
        $subscription->status = SubscriptionStatus::PastDue;
        $subscription->save();

        // Log the transition
        $subscription->statusHistories()->create([
            'from_status' => SubscriptionStatus::Active,
            'to_status' => SubscriptionStatus::PastDue,
            'changed_by' => null,
            'reason' => 'Payment failed',
        ]);

        // Schedule retry attempts
        $this->scheduleRetries($subscription);

        // Schedule grace period expiration
        ExpireGracePeriodJob::dispatch($subscription)
            ->delay(now()->addDays(config('subscriptions.grace_period_days')));

        // Send initial notification
        $subscription->user->notify(new PaymentFailedNotification($subscription));

        // Create in-app alert
        InAppAlert::create([
            'user_id' => $subscription->user_id,
            'type' => 'payment_failed',
            'title' => 'Payment Failed',
            'message' => 'Your payment method was declined. Please update your payment method to avoid service interruption.',
            'action_url' => '/billing/payment-method',
            'action_label' => 'Update Payment Method',
            'priority' => 'high',
            'dismissable' => false,
        ]);

        PaymentFailed::dispatch($subscription);
    }

    protected function scheduleRetries(Subscription $subscription): void
    {
        // Retry 1: Immediate
        ProcessRenewalJob::dispatch($subscription);

        // Retry 2: 24 hours later
        ProcessRenewalJob::dispatch($subscription)
            ->delay(now()->addHours(24))
            ->onQueue('billing');

        // Retry 3: 48 hours later (final attempt)
        ProcessRenewalJob::dispatch($subscription)
            ->delay(now()->addHours(48))
            ->onQueue('billing');
    }
}
```

### Scenario: Payment Method Updated During Grace

When a user updates their payment method during the grace period, the system immediately retries the payment.

```text
Timeline:
Day 0: Payment fails, grace period begins
Day 1: User updates payment method
Day 1: System retries payment with new method
Day 1: Payment succeeds
Day 1: Subscription status → Active
Day 1: Entitlements synchronized
Day 1: Email sent: "Payment successful"
Day 1: Dashboard warning removed
```

```php
class GracePeriodPaymentResolver
{
    public function updatePaymentMethod(Subscription $subscription, string $paymentMethodId): void
    {
        // Attach new payment method to customer
        $this->billing->updatePaymentMethod(
            $subscription->user,
            $paymentMethodId
        );

        // Immediately retry payment
        try {
            $result = $this->billing->retryCharge($subscription);

            if ($result->succeeded) {
                // Payment successful - restore subscription
                $this->restoreSubscription($subscription);
            } else {
                // Payment still failing
                $this->handleRetryFailure($subscription, $result->error);
            }
        } catch (PaymentFailedException $e) {
            // Payment still failing
            $this->handleRetryFailure($subscription, $e->getMessage());
        }
    }

    protected function restoreSubscription(Subscription $subscription): void
    {
        $subscription->status = SubscriptionStatus::Active;
        $subscription->save();

        // Log the restoration
        $subscription->statusHistories()->create([
            'from_status' => SubscriptionStatus::PastDue,
            'to_status' => SubscriptionStatus::Active,
            'changed_by' => $subscription->user_id,
            'reason' => 'Payment method updated, charge succeeded',
        ]);

        // Re-sync entitlements
        app(EntitlementService::class)->synchronize($subscription);

        // Remove any pending grace expiry jobs
        // Jobs will check status before executing

        // Send confirmation
        $subscription->user->notify(new PaymentRecoveredNotification($subscription));

        // Remove in-app alert
        InAppAlert::where('user_id', $subscription->user_id)
            ->where('type', 'payment_failed')
            ->delete();

        PaymentRecovered::dispatch($subscription);
    }

    protected function handleRetryFailure(Subscription $subscription, string $error): void
    {
        // Notify user of specific failure
        $subscription->user->notify(new PaymentRetryFailedNotification(
            $subscription,
            $error
        ));

        // Update in-app alert with specific error
        InAppAlert::where('user_id', $subscription->user_id)
            ->where('type', 'payment_failed')
            ->update([
                'message' => "Payment failed: {$error}. Please update your payment method.",
            ]);
    }
}
```

### Scenario: Multiple Grace Periods

Users can enter the grace period multiple times. Each failure starts a new grace period.

```php
class MultipleGracePeriodTracker
{
    public function getGracePeriodHistory(Subscription $subscription): array
    {
        return $subscription->statusHistories()
            ->where(function ($q) {
                $q->where('to_status', SubscriptionStatus::PastDue)
                  ->orWhere('from_status', SubscriptionStatus::PastDue);
            })
            ->orderBy('created_at', 'desc')
            ->get()
            ->map(fn ($history) => [
                'type' => $history->to_status === SubscriptionStatus::PastDue ? 'start' : 'end',
                'date' => $history->created_at,
                'reason' => $history->reason,
            ])
            ->toArray();
    }

    public function getGracePeriodCount(Subscription $subscription): int
    {
        return $subscription->statusHistories()
            ->where('to_status', SubscriptionStatus::PastDue)
            ->count();
    }

    public function shouldTriggerAdminReview(Subscription $subscription): bool
    {
        // Trigger review after 3+ grace periods in 90 days
        $recentGracePeriods = $subscription->statusHistories()
            ->where('to_status', SubscriptionStatus::PastDue)
            ->where('created_at', '>=', now()->subDays(90))
            ->count();

        return $recentGracePeriods >= 3;
    }
}
```

## Grace Period Access Control

### Entitlement Resolution During Grace

```php
class GracePeriodEntitlementResolver
{
    public function resolve(Billable $billable): Collection
    {
        $subscription = $billable->activeSubscription();

        if (!$subscription) {
            return collect([]);
        }

        // During grace period, treat as active
        if ($subscription->status === SubscriptionStatus::PastDue) {
            $gracePeriod = app(GracePeriodService::class);

            if ($gracePeriod->hasAccessDuringGrace($subscription)) {
                // Full access during grace
                return $this->resolveForActive($subscription);
            }
        }

        // Normal resolution
        return $this->resolveInternal($subscription);
    }

    public function hasAccessDuringGrace(Subscription $subscription): bool
    {
        if ($subscription->status !== SubscriptionStatus::PastDue) {
            return false;
        }

        $graceEnd = $subscription->updated_at->addDays(
            config('subscriptions.grace_period_days')
        );

        return now()->lt($graceEnd);
    }
}
```

## Admin Grace Period Management

### Extend Grace Period

```php
class AdminGracePeriodManager
{
    public function extendGracePeriod(Subscription $subscription, int $additionalDays, string $reason): void
    {
        throw_unless(auth()->user()->isAdmin(), AuthorizationException::class);

        // Update the grace period end
        $subscription->metadata = array_merge($subscription->metadata ?? [], [
            'grace_period_extended' => true,
            'original_grace_end' => $subscription->updated_at->addDays(
                config('subscriptions.grace_period_days')
            )->toDateTimeString(),
            'extended_grace_end' => $subscription->updated_at->addDays(
                config('subscriptions.grace_period_days') + $additionalDays
            )->toDateTimeString(),
            'extension_reason' => $reason,
            'extended_by' => auth()->id(),
        ]);
        $subscription->save();

        // Reschedule grace expiry
        $newGraceEnd = $subscription->updated_at->addDays(
            config('subscriptions.grace_period_days') + $additionalDays
        );

        // Cancel existing grace expiry job
        // Schedule new one
        ExpireGracePeriodJob::dispatch($subscription)
            ->delay($newGraceEnd);

        // Log admin action
        AdminAction::log('subscription.extend_grace', [
            'subscription_id' => $subscription->id,
            'additional_days' => $additionalDays,
            'reason' => $reason,
        ]);

        // Notify user
        $subscription->user->notify(new GracePeriodExtendedNotification(
            $subscription,
            $additionalDays,
            $reason
        ));
    }

    public function endGracePeriodEarly(Subscription $subscription, string $reason): void
    {
        throw_unless(auth()->user()->isAdmin(), AuthorizationException::class);

        // Immediately transition to Unpaid
        $subscription->status = SubscriptionStatus::Unpaid;
        $subscription->save();

        // Revoke entitlements
        app(EntitlementService::class)->invalidate($subscription);

        // Log transition
        $subscription->statusHistories()->create([
            'from_status' => SubscriptionStatus::PastDue,
            'to_status' => SubscriptionStatus::Unpaid,
            'changed_by' => auth()->id(),
            'reason' => "Grace period ended early: {$reason}",
        ]);

        // Log admin action
        AdminAction::log('subscription.end_grace_early', [
            'subscription_id' => $subscription->id,
            'reason' => $reason,
        ]);

        // Notify user
        $subscription->user->notify(new GracePeriodEndedEarlyNotification(
            $subscription,
            $reason
        ));
    }

    public function resetRetryCounter(Subscription $subscription): void
    {
        throw_unless(auth()->user()->isAdmin(), AuthorizationException::class);

        // Reset retry metadata
        $metadata = $subscription->metadata ?? [];
        unset($metadata['retry_count'], $metadata['last_retry_at']);
        $subscription->metadata = $metadata;
        $subscription->save();

        // Schedule new retries
        $this->scheduleRetries($subscription);

        // Log admin action
        AdminAction::log('subscription.reset_retries', [
            'subscription_id' => $subscription->id,
        ]);
    }
}
```

## Grace Period Analytics

### Metrics

```php
class GracePeriodAnalytics
{
    public function getRecoveryRate(string $period = 'month'): float
    {
        $enteredGrace = Subscription::where('status', SubscriptionStatus::PastDue)
            ->where('updated_at', '>=', now()->sub($period))
            ->count();

        $recovered = Subscription::where('status', SubscriptionStatus::Active)
            ->where('metadata->$', 'like', '%"recovered_from_grace"%')
            ->where('updated_at', '>=', now()->sub($period))
            ->count();

        return $enteredGrace > 0 ? $recovered / $enteredGrace : 0;
    }

    public function getExpirationRate(string $period = 'month'): float
    {
        $enteredGrace = Subscription::where('status', SubscriptionStatus::PastDue)
            ->where('updated_at', '>=', now()->sub($period))
            ->count();

        $expired = Subscription::where('status', SubscriptionStatus::Unpaid)
            ->where('updated_at', '>=', now()->sub($period))
            ->count();

        return $enteredGrace > 0 ? $expired / $enteredGrace : 0;
    }

    public function getAverageGracePeriodDuration(string $period = 'month'): float
    {
        $expired = Subscription::where('status', SubscriptionStatus::Unpaid)
            ->where('updated_at', '>=', now()->sub($period))
            ->get();

        if ($expired->isEmpty()) {
            return 0;
        }

        $totalDays = $expired->sum(function ($sub) {
            return $sub->updated_at->diffInHours($sub->created_at) / 24;
        });

        return $totalDays / $expired->count();
    }

    public function getPaymentMethodUpdateRate(string $period = 'month'): float
    {
        $enteredGrace = Subscription::where('status', SubscriptionStatus::PastDue)
            ->where('updated_at', '>=', now()->sub($period))
            ->count();

        $updatedPayment = Subscription::where('status', SubscriptionStatus::PastDue)
            ->whereHas('user', function ($q) {
                $q->whereHas('paymentMethods', function ($q) {
                    $q->where('created_at', '>=', now()->subDays(3));
                });
            })
            ->where('updated_at', '>=', now()->sub($period))
            ->count();

        return $enteredGrace > 0 ? $updatedPayment / $enteredGrace : 0;
    }
}
```

## Grace Period Testing

### Test Cases

```php
class GracePeriodTest extends TestCase
{
    public function test_grace_period_begins_on_payment_failure(): void
    {
        $user = User::factory()->create();
        $subscription = Subscription::factory()->create([
            'user_id' => $user->id,
            'status' => SubscriptionStatus::Active,
        ]);

        app(PaymentFailureHandler::class)->handle($subscription);

        $subscription->refresh();

        $this->assertEquals(SubscriptionStatus::PastDue, $subscription->status);
    }
```

### Recovery Strategy Interface

```php
interface GracePeriodRecoveryStrategy
{
    public function canRecover(Subscription $subscription): bool;
    public function recover(Subscription $subscription): bool;
    public function getName(): string;
}
```

### Payment Method Update Strategy

```php
class PaymentMethodUpdateRecovery implements GracePeriodRecoveryStrategy
{
    public function canRecover(Subscription $subscription): bool
    {
        // Check if user has other payment methods available
        $paymentMethods = $this->billing->getPaymentMethods($subscription->user);

        return $paymentMethods->count() > 1;
    }

    public function recover(Subscription $subscription): bool
    {
        // Try each payment method
        $paymentMethods = $this->billing->getPaymentMethods($subscription->user);

        foreach ($paymentMethods as $paymentMethod) {
            try {
                $this->billing->retryCharge($subscription, $paymentMethod->id);

                $subscription->status = SubscriptionStatus::Active;
                $subscription->save();

                return true;
            } catch (PaymentFailedException) {
                continue;
            }
        }

        return false;
    }

    public function getName(): string
    {
        return 'payment_method_update';
    }
}
```

### Downgrade Strategy

```php
class DowngradeRecovery implements GracePeriodRecoveryStrategy
{
    public function canRecover(Subscription $subscription): bool
    {
        // Can downgrade to free plan
        return $subscription->plan->slug !== 'free';
    }

    public function recover(Subscription $subscription): bool
    {
        $freePlan = Plan::where('slug', 'free')->first();

        if (!$freePlan) {
            return false;
        }

        // Downgrade to free plan
        $subscription->plan_id = $freePlan->id;
        $subscription->status = SubscriptionStatus::Active;
        $subscription->save();

        // Synchronize entitlements
        app(EntitlementService::class)->synchronize($subscription);

        return true;
    }

    public function getName(): string
    {
        return 'downgrade_to_free';
    }
}
```

### Recovery Strategy Manager

```php
class GracePeriodRecoveryManager
{
    protected array $strategies = [];

    public function __construct()
    {
        $this->strategies = [
            new RetryChargeRecovery(),
            new PaymentMethodUpdateRecovery(),
            new DowngradeRecovery(),
        ];
    }

    public function attemptRecovery(Subscription $subscription): ?string
    {
        foreach ($this->strategies as $strategy) {
            if ($strategy->canRecover($subscription)) {
                $recovered = $strategy->recover($subscription);

                if ($recovered) {
                    return $strategy->getName();
                }
            }
        }

        return null;
    }

    public function getAvailableStrategies(Subscription $subscription): array
    {
        return array_filter(
            $this->strategies,
            fn ($strategy) => $strategy->canRecover($subscription)
        );
    }
}
```

## Grace Period Monitoring

### Monitoring Service

```php
class GracePeriodMonitoring
{
    public function getMetrics(): array
    {
        return [
            'active_grace_periods' => $this->getActiveGracePeriodsCount(),
            'average_grace_duration' => $this->getAverageGraceDuration(),
            'recovery_rate_24h' => $this->getRecoveryRate(24),
            'recovery_rate_7d' => $this->getRecoveryRate(168),
            'recovery_rate_30d' => $this->getRecoveryRate(720),
            'top_failure_reasons' => $this->getTopFailureReasons(),
            'revenue_at_risk' => $this->getRevenueAtRisk(),
        ];
    }

    protected function getActiveGracePeriodsCount(): int
    {
        return Subscription::where('status', SubscriptionStatus::PastDue)
            ->where('updated_at', '>=', now()->subDays(config('subscriptions.grace_period_days')))
            ->count();
    }

    protected function getAverageGraceDuration(): float
    {
        return Subscription::where('status', SubscriptionStatus::Unpaid)
            ->where('updated_at', '>=', now()->subDays(30))
            ->avg(fn ($sub) => $sub->updated_at->diffInHours($sub->created_at)) ?? 0;
    }

    protected function getRecoveryRate(int $hours): float
    {
        $enteredGrace = Subscription::where('status', SubscriptionStatus::PastDue)
            ->where('updated_at', '>=', now()->subHours($hours))
            ->count();

        $recovered = Subscription::where('status', SubscriptionStatus::Active)
            ->where('metadata->$', 'like', '%"recovered_from_grace"%')
            ->where('updated_at', '>=', now()->subHours($hours))
            ->count();

        return $enteredGrace > 0 ? $recovered / $enteredGrace : 0;
    }

    protected function getTopFailureReasons(): array
    {
        return PaymentFailure::where('created_at', '>=', now()->subDays(30))
            ->select('failure_reason')
            ->selectRaw('count(*) as count')
            ->groupBy('failure_reason')
            ->orderByDesc('count')
            ->limit(5)
            ->get()
            ->pluck('count', 'failure_reason')
            ->toArray();
    }

    protected function getRevenueAtRisk(): int
    {
        return Subscription::where('status', SubscriptionStatus::PastDue)
            ->where('updated_at', '>=', now()->subDays(config('subscriptions.grace_period_days')))
            ->sum('plan.price');
    }
}
```

### Export Service

```php
class GracePeriodExport
{
    public function export(string $period = 'month'): StreamedResponse
    {
        $data = $this->getExportData($period);

        $headers = [
            'Content-Type' => 'text/csv',
            'Content-Disposition' => 'attachment; filename="grace-periods-' . $period . '.csv"',
        ];

        return StreamedResponse::make(function () use ($data) {
            $handle = fopen('php://output', 'w');

            // Header
            fputcsv($handle, [
                'ID',
                'Subscription ID',
                'User Email',
                'Plan',
                'Started At',
                'Ends At',
                'Resolved At',
                'Resolution',
                'Retry Count',
                'Days in Grace',
            ]);

            // Data
            foreach ($data as $row) {
                fputcsv($handle, [
                    $row->id,
                    $row->subscription_id,
                    $row->subscription->user->email,
                    $row->subscription->plan->name,
                    $row->started_at->format('Y-m-d H:i:s'),
                    $row->ends_at->format('Y-m-d H:i:s'),
                    $row->resolved_at?->format('Y-m-d H:i:s'),
                    $row->resolution,
                    $row->retry_count,
                    $row->started_at->diffInDays($row->resolved_at ?? now()),
                ]);
            }

            fclose($handle);
        }, 200, $headers);
    }

    protected function getExportData(string $period): Collection
    {
        return GracePeriod::with('subscription.plan', 'subscription.user')
            ->where('started_at', '>=', now()->sub($period))
            ->orderBy('started_at', 'desc')
            ->get();
    }
}
```

## Grace Period API

### API Endpoints

```php
// routes/api.php
Route::middleware('auth:sanctum')->group(function () {
    // Get grace period status
    Route::get('/subscription/grace-period', function (Request $request) {
        $subscription = $request->user()->activeSubscription();

        if (!$subscription || $subscription->status !== SubscriptionStatus::PastDue) {
            return response()->json([
                'in_grace_period' => false,
            ]);
        }

        $graceService = app(GracePeriodService::class);
        $graceEnd = $graceService->gracePeriodEndsAt($subscription);

        return response()->json([
            'in_grace_period' => true,
            'grace_started_at' => $subscription->updated_at->toIso8601String(),
            'grace_ends_at' => $graceEnd->toIso8601String(),
            'days_remaining' => max(0, now()->diffInDays($graceEnd)),
            'has_access' => $graceService->hasAccessDuringGrace($subscription),
        ]);
    });

    // Get available recovery strategies
    Route::get('/subscription/grace-period/recovery-strategies', function (Request $request) {
        $subscription = $request->user()->activeSubscription();

        $strategies = app(GracePeriodRecoveryManager::class)
            ->getAvailableStrategies($subscription);

        return response()->json([
            'strategies' => array_map(fn ($s) => [
                'name' => $s->getName(),
                'can_recover' => $s->canRecover($subscription),
            ], $strategies),
        ]);
    });

    // Get grace period history
    Route::get('/subscription/grace-period/history', function (Request $request) {
        $history = GracePeriod::whereHas('subscription', function ($q) use ($request) {
            $q->where('user_id', $request->user()->id);
        })
        ->orderBy('started_at', 'desc')
        ->limit(10)
        ->get();

        return response()->json([
            'history' => $history->map(fn ($gp) => [
                'id' => $gp->id,
                'started_at' => $gp->started_at->toIso8601String(),
                'ends_at' => $gp->ends_at->toIso8601String(),
                'resolved_at' => $gp->resolved_at?->toIso8601String(),
                'resolution' => $gp->resolution,
                'retry_count' => $gp->retry_count,
            ]),
        ]);
    });
});
```

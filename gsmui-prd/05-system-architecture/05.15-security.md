# 05.15 - Security Architecture

**Project:** GsmUi
**Architecture:** Defense in Depth
**Framework:** Laravel 13 + Livewire 4
**Version:** 1.0.0

---

# Purpose

Security is a foundational concern for GsmUi. Every layer—from infrastructure and authentication to business logic and user interfaces—must be designed to protect user data, platform integrity, and commercial assets.

This document defines the security architecture, standards, and operational controls applied throughout the platform.

---

# Security Objectives

The platform must provide:

* Strong authentication
* Fine-grained authorization
* Secure session management
* Secure API access
* Data encryption
* Secure file handling
* Audit logging
* Abuse prevention
* Secure development practices
* Compliance-ready architecture

---

# Security Principles

## Defense in Depth

Apply multiple independent security controls across:

* Network
* Infrastructure
* Application
* Database
* Storage
* User interface

No single failure should expose critical resources.

---

## Least Privilege

Every user, service, and process receives only the permissions required for its responsibilities.

---

## Secure by Default

Features should default to the safest configuration.

Examples:

* HTTPS required
* Email verification enabled
* CSRF protection enabled
* Authorization required
* Secure cookies
* Minimal permissions

# Security Architecture Deep Dive

## Threat Model

GsmUi faces the following primary threat categories.

| Threat Category | Examples | Impact |
|-----------------|----------|--------|
| Authentication Attacks | Brute force, credential stuffing, session hijacking | Account takeover |
| Authorization Attacks | Privilege escalation, IDOR, mass assignment | Data breach |
| Injection Attacks | SQL injection, XSS, Blade injection | Code execution |
| Data Exposure | PII leaks, API key exposure, debug info leaks | Privacy violation |
| Infrastructure Attacks | DDoS, man-in-the-middle, Redis compromise | Service disruption |
| Supply Chain Attacks | Malicious packages, dependency vulnerabilities | Code compromise |
| Social Engineering | Phishing, impersonation | Account compromise |
| Business Logic Attacks | Race conditions, price manipulation, coupon abuse | Financial loss |

## Authentication Deep Dive

### Registration Flow

```text id="sauth01"
Email + Password
   │
   ▼
Rate Limit Check (5/hour)
   │
   ▼
Password Validation (12+ chars, complexity)
   │
   ▼
Email Uniqueness Check
   │
   ▼
Create User (Argon2id hash)
   │
   ▼
Send Verification Email
   │
   ▼
Create Session
   │
   ▼
Log Registration Event
```

### Login Flow

```text id="sauth02"
Email + Password
   │
   ▼
Rate Limit Check (5/min per IP, 10/min per email)
   │
   ▼
Find User by Email
   │
   ▼
Verify Password (Argon2id)
   │
   ├── Fail → Increment Attempts → Lock After 5 Failures
   │
   └── Success → Check Email Verified
       │
       ├── Not Verified → Resend Verification
       │
       └── Verified → Check 2FA Enabled
           │
           ├── Yes → Prompt TOTP Code
           │
           └── No → Create Session → Regenerate ID → Log Success
```

### Password Hashing

Algorithm: Argon2id

Configuration:

```php id="sauth03"
'hashing' => [
    'driver' => 'argon2id',
    'memory' => 256,    // 256 MB
    'threads' => 3,     // 3 threads
    'time' => 4,        // 4 iterations
],
```

Why Argon2id:

* Memory-hard (resistant to GPU attacks)
* Time-hard (resistant to ASIC attacks)
* Winner of Password Hashing Competition
* Recommended by OWASP

## Two-Factor Authentication

### TOTP Setup Flow

```text id="sauth04"
User Enables 2FA
   │
   ▼
Generate Secret (32 bytes, base32 encoded)
   │
   ▼
Generate QR Code (otpauth:// URI)
   │
   ▼
User Scans with Authenticator App
   │
   ▼
User Enters Verification Code
   │
   ▼
Verify Code Against Secret
   │
   ├── Fail → Reject, Allow Retry
   │
   └── Success → Store Encrypted Secret
       │
       ▼
       Generate 10 Recovery Codes
       │
       ▼
       Display Recovery Codes (one-time use)
       │
       ▼
       Enable 2FA on Account
```

### TOTP Verification

```php id="sauth05"
class TotpVerifier
{
    public function verify(User $user, string $code): bool
    {
        $secret = decrypt($user->two_factor_secret);

        $google2fa = new Google2FA();

        return $google2fa->verifyKey($secret, $code, 1); // 1 window tolerance
    }
}
```

### Recovery Codes

```text id="sauth06"
Each user receives 10 recovery codes.

Format: XXXX-XXXX-XXXX

Storage: Encrypted in database

Usage: One-time use, mark as used after consumption

Backup: User should store codes securely offline
```

### Policy Implementation

```php id="spolicy01"
class ComponentPolicy
{
    public function viewAny(User $user): bool
    {
        return true; // Public
    }

    public function view(User $user, Component $component): bool
    {
        if ($component->isPublished()) {
            return true;
        }

        return $user->id === $component->author_id
            || $user->hasRole('admin');
    }

    public function create(User $user): bool
    {
        return $user->hasAnyRole(['contributor', 'admin', 'super_admin']);
    }

    public function update(User $user, Component $component): bool
    {
        return $user->id === $component->author_id
            || $user->hasRole('admin');
    }

    public function delete(User $user, Component $component): bool
    {
        return $user->id === $component->author_id
            || $user->hasRole('admin');
    }

    public function publish(User $user, Component $component): bool
    {
        return $user->hasAnyRole(['admin', 'super_admin']);
    }
}
```

## Rate Limiting Deep Dive

### Implementation

```php id="srate01"
class RateServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        RateLimiter::for('login', function (Request $request) {
            return Limit::perMinute(5)->by($request->ip());
        });

        RateLimiter::for('register', function (Request $request) {
            return Limit::perHour(5)->by($request->ip());
        });

        RateLimiter::for('password-reset', function (Request $request) {
            return Limit::perHour(5)->by($request->email);
        });

        RateLimiter::for('api', function (Request $request) {
            return Limit::perMinute(120)->by(
                $request->user()?->id ?: $request->ip()
            );
        });

        RateLimiter::for('search', function (Request $request) {
            return Limit::perMinute(30)->by($request->ip());
        });
    }
}
```

### Rate Limit Response

```json id="srate02"
}
```

## Incident Response Plan

### Severity Levels

| Level | Description | Response Time |
|-------|-------------|---------------|
| P0 - Critical | Data breach, system compromise | Immediate |
| P1 - High | Authentication bypass, privilege escalation | 1 hour |
| P2 - Medium | Vulnerability with exploit potential | 4 hours |
| P3 - Low | Minor vulnerability, no known exploit | 24 hours |

### Response Steps

```text id="sinc01"
Detect
   │
   ▼
Assess Severity
   │
   ├── P0/P1 → Immediate Containment
   │
   └── P2/P3 → Scheduled Response
   │
   ▼
Contain
   │
   ├── Revoke compromised credentials
   ├── Block malicious IPs
   └── Isolate affected systems
   │
   ▼
Investigate
   │
   ├── Review audit logs
   ├── Analyze attack vector
   └── Assess data exposure
   │
   ▼
Recover
   │
   ├── Restore from clean backups
   ├── Rotate all secrets
   └── Verify system integrity
   │
   ▼
Communicate
   │
   ├── Notify affected users
   ├── Report to authorities (if required)
   └── Publish incident report
   │
   ▼
Improve
   │
   ├── Add missing controls
   ├── Update runbooks
   └── Conduct postmortem
```

# Performance

Security controls must not degrade user experience. Performance targets with security enabled:

| Metric | Target | Security Control Impact |
|--------|--------|------------------------|
| Login Response Time | < 500ms | Includes password hashing (Argon2id) |
| 2FA Verification | < 300ms | TOTP validation overhead |
| API Token Validation | < 50ms | Sanctum token lookup via cache |
| Rate Limit Check | < 10ms | Redis-based rate limiter |
| Session Validation | < 20ms | Encrypted cookie + Redis session store |
| CSRF Token Verification | < 5ms | Laravel middleware overhead |
| File Upload Validation | < 200ms | MIME type, size, and extension checks |
| Audit Log Write | < 30ms | Async logging via queue for non-critical actions |

Security performance optimizations:

* **Argon2id tuning**: Configure memory cost, time cost, and threads to balance security and speed (target: 256MB, 4 iterations, 3 threads)
* **Token caching**: Cache Sanctum token lookups to reduce database queries
* **Rate limit caching**: Use Redis for rate limiting instead of database
* **Session store**: Redis-backed sessions for fast read/write
* **CSRF token caching**: Leverage Laravel's built-in CSRF token caching
* **Lazy policy evaluation**: Load policies only when authorization is actually checked

### Sanitization Middleware

```php id="ssanit02"
class SanitizeInputMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $request->merge($this->sanitize($request->all()));
        return $next($request);
    }

    private function sanitize(array $data): array
    {
        return array_map(function ($value) {
            if (is_string($value)) {
                $value = strip_tags($value);
                $value = trim($value);
                $value = preg_replace('/\s+/', ' ', $value);
            }
            return $value;
        }, $data);
    }
}
```

### Anomaly Detection

```php id="smon02"
class AnomalyDetector
{
    public function detect(User $user, string $action): ?string
    {
        // Check for unusual IP
        $lastIp = Cache::get("user:{$user->id}:last_ip");
        if ($lastIp && $lastIp !== request()->ip()) {
            return 'unusual_ip';
        }

        // Check for unusual time
        $usualHours = Cache::get("user:{$user->id}:usual_hours", []);
        $currentHour = now()->hour;
        if (!empty($usualHours) && !in_array($currentHour, $usualHours)) {
            return 'unusual_time';
        }

        return null;
    }
}
```

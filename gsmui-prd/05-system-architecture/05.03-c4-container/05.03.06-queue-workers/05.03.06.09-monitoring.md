# Purpose

This document describes the monitoring, alerting, health checks, and SLIs/SLOs for the GsmUi queue workers container. Effective monitoring ensures that queue processing remains reliable, performant, and observable in production.

---

# Responsibilities

Monitoring is responsible for:

* Tracking queue depth and throughput
* Monitoring worker health and utilization
* Alerting on failure patterns
* Measuring SLIs and SLOs
* Collecting runtime metrics
* Detecting anomalies
* Supporting incident response

# SLIs (Service Level Indicators)

SLIs are the quantitative measurements of service health:

| SLI | Definition | Target |
|-----|-----------|--------|
| Job Throughput | Jobs processed per minute | >100 |
| Job Latency | P95 processing time | <30s |
| Job Success Rate | Successful jobs / total jobs | >99% |
| Queue Availability | Time queue accepts jobs | 99.9% |
| Worker Availability | Workers processing jobs | 99.5% |

---

# SLOs (Service Level Objectives)

SLOs define the acceptable thresholds for each SLI:

| SLO | SLI | Target |
|-----|-----|--------|
| Processing SLO | Job Latency | P95 < 30s for 99% of jobs |
| Reliability SLO | Job Success Rate | >99% over 30-day window |
| Availability SLO | Queue Availability | 99.9% monthly uptime |
| Worker SLO | Worker Availability | 99.5% monthly uptime |

SLO violations trigger alerts and incident response.

```php
// app/Http/Controllers/HealthController.php

public function queue(): JsonResponse
{
    $horizonStatus = Artisan::call('horizon:status');
    $queueLength = Redis::llen('queues:high');
    $failedJobs = DB::table('failed_jobs')->count();

    return response()->json([
        'horizon' => $horizonStatus === 0,
        'queue_depth' => $queueLength,
        'failed_jobs' => $failedJobs,
        'status' => $horizonStatus === 0 && $queueLength < 500 ? 'healthy' : 'degraded',
    ]);
}
```

# Incident Response

When SLOs are violated:

1. **Detect** — Alert fires from monitoring
2. **Acknowledge** — On-call engineer acknowledges
3. **Investigate** — Check Horizon dashboard, logs, Redis status
4. **Mitigate** — Scale workers, pause problematic queues, clear backlogs
5. **Resolve** — Fix root cause (code fix, infrastructure, etc.)
6. **Review** — Post-incident review and action items

# Anomaly Detection

Anomaly detection identifies unusual patterns:

| Pattern | Anomaly | Action |
|---------|---------|--------|
| Sudden queue spike | Queue depth >3x normal | Scale workers immediately |
| Failure rate spike | >20% failure rate | Investigate and pause affected queue |
| Worker count drop | >50% workers down | Restart Horizon |
| Redis latency increase | P99 >50ms | Scale Redis or investigate |

Anomaly detection rules:

```php
// Queue depth anomaly
if ($currentDepth > $baselineDepth * 3) {
    Alert::queueDepthSpike($currentDepth);
    Horizon::scaleWorkers('high', 10);
}

// Failure rate anomaly
if ($failureRate > 0.20) {
    Alert::failureRateSpike($failureRate);
    Queue::pause('media');
}
```

# Advanced Monitoring

## Prometheus Integration

### Exporting Metrics

```php
// app/Metrics/QueueMetrics.php
class QueueMetrics
{
    private Counter $jobsProcessed;
    private Histogram $jobDuration;
    private Gauge $queueDepth;
    private Gauge $workerCount;
    private Counter $jobsFailed;

    public function __construct()
    {
        $this->jobsProcessed = new Counter(
            'gsmui_queue_jobs_processed_total',
            'Total number of jobs processed',
            ['queue', 'status']
        );

        $this->jobDuration = new Histogram(
            'gsmui_queue_job_duration_seconds',
            'Job processing duration in seconds',
            ['queue'],
            [0.1, 0.5, 1, 5, 10, 30, 60, 120, 300, 600]
        );

        $this->queueDepth = new Gauge(
            'gsmui_queue_depth',
            'Current queue depth',
            ['queue']
        );

        $this->workerCount = new Gauge(
            'gsmui_queue_workers_active',
            'Number of active workers',
            ['queue']
        );

        $this->jobsFailed = new Counter(
            'gsmui_queue_jobs_failed_total',
            'Total number of failed jobs',
            ['queue', 'exception']
        );
    }

    public function recordJobProcessed(string $queue, string $status, float $duration): void
    {
        $this->jobsProcessed->inc(['queue' => $queue, 'status' => $status]);
        $this->jobDuration->observe(['queue' => $queue], $duration);
    }

    public function setQueueDepth(string $queue, int $depth): void
    {
        $this->queueDepth->set(['queue' => $queue], $depth);
    }

    public function setWorkerCount(string $queue, int $count): void
    {
        $this->workerCount->set(['queue' => $queue], $count);
    }

    public function recordJobFailed(string $queue, string $exception): void
    {
        $this->jobsFailed->inc(['queue' => $queue, 'exception' => $exception]);
    }
}
```

## Distributed Tracing

### OpenTelemetry Integration

```php
use OpenTelemetry\API\Trace\TracerInterface;
use OpenTelemetry\API\Trace\SpanKind;

class ProcessMedia implements ShouldQueue
{
    public function __construct(
        private TracerInterface $tracer,
    ) {}

    public function handle(): void
    {
        $span = $this->tracer->spanBuilder('ProcessMedia')
            ->setSpanKind(SpanKind::CONSUMER)
            ->setAttribute('queue', 'media')
            ->setAttribute('job', self::class)
            ->setAttribute('file_id', $this->fileId)
            ->startSpan();

        $scope = $span->activate();

        try {
            $this->processor->convert($this->file);
            $span->setStatus(StatusCode::OK);
        } catch (\Exception $e) {
            $span->setStatus(StatusCode::ERROR, $e->getMessage());
            $span->recordException($e);
            throw $e;
        } finally {
            $span->end();
            $scope->detach();
        }
    }
}
```

### Trace Context Propagation

```php
class DispatchWithTrace
{
    public function dispatchJob($job): PendingDispatch
    {
        $traceContext = $this->tracer->spanBuilder('DispatchJob')
            ->setAttribute('job', get_class($job))
            ->startSpan();

        // Inject trace context into job payload
        $traceId = $traceContext->getContext()->getTraceId();
        $spanId = $traceContext->getContext()->getSpanId();

        $job->traceId = $traceId;
        $job->parentSpanId = $spanId;

        $traceContext->end();

        return $job->dispatch();
    }
}
```

## Custom Health Checks

```php
class QueueHealthCheck
{
    public function check(): array
    {
        $checks = [];

        // Check Horizon status
        $horizonStatus = Artisan::call('horizon:status');
        $checks['horizon'] = [
            'status' => $horizonStatus === 0 ? 'healthy' : 'unhealthy',
            'message' => $horizonStatus === 0 ? 'Horizon is running' : 'Horizon is not running',
        ];

        // Check queue depths
        foreach (['high', 'default', 'mail', 'media'] as $queue) {
            $depth = Redis::llen("queues:{$queue}");
            $checks["queue.{$queue}"] = [
                'status' => $depth < 1000 ? 'healthy' : ($depth < 5000 ? 'degraded' : 'unhealthy'),
                'depth' => $depth,
                'message' => "Queue {$queue} has {$depth} pending jobs",
            ];
        }

        // Check failed jobs
        $failedCount = DB::table('failed_jobs')
            ->where('failed_at', '>', now()->subHours(24))
            ->count();
        
        $checks['failed_jobs'] = [
            'status' => $failedCount < 50 ? 'healthy' : ($failedCount < 200 ? 'degraded' : 'unhealthy'),
            'count_24h' => $failedCount,
            'message' => "{$failedCount} failed jobs in the last 24 hours",
        ];

        // Check Redis latency
        $start = microtime(true);
        Redis::ping();
        $latency = (microtime(true) - $start) * 1000;
        
        $checks['redis_latency'] = [
            'status' => $latency < 10 ? 'healthy' : ($latency < 50 ? 'degraded' : 'unhealthy'),
            'latency_ms' => round($latency, 2),
            'message' => "Redis latency is {$latency}ms",
        ];

        return $checks;
    }
}
```

```php
class QueueHealthCheck
{
    public function check(): array
    {
        $checks = [];

        // Check Horizon status
        $horizonStatus = Artisan::call('horizon:status');
        $checks['horizon'] = [
            'status' => $horizonStatus === 0 ? 'healthy' : 'unhealthy',
            'message' => $horizonStatus === 0 ? 'Horizon is running' : 'Horizon is not running',
        ];

        // Check queue depths
        foreach (['high', 'default', 'mail', 'media'] as $queue) {
            $depth = Redis::llen("queues:{$queue}");
            $checks["queue.{$queue}"] = [
                'status' => $depth < 1000 ? 'healthy' : ($depth < 5000 ? 'degraded' : 'unhealthy'),
                'depth' => $depth,
                'message' => "Queue {$queue} has {$depth} pending jobs",
            ];
        }

        // Check failed jobs
        $failedCount = DB::table('failed_jobs')
            ->where('failed_at', '>', now()->subHours(24))
            ->count();
        
        $checks['failed_jobs'] = [
            'status' => $failedCount < 50 ? 'healthy' : ($failedCount < 200 ? 'degraded' : 'unhealthy'),
            'count_24h' => $failedCount,
            'message' => "{$failedCount} failed jobs in the last 24 hours",
        ];

        // Check Redis latency
        $start = microtime(true);
        Redis::ping();
        $latency = (microtime(true) - $start) * 1000;
        
        $checks['redis_latency'] = [
            'status' => $latency < 10 ? 'healthy' : ($latency < 50 ? 'degraded' : 'unhealthy'),
            'latency_ms' => round($latency, 2),
            'message' => "Redis latency is {$latency}ms",
        ];

        return $checks;
    }
}
```

```php
class PrometheusExporter
{
    private Counter $jobsProcessed;
    private Histogram $jobDuration;
    private Gauge $queueDepth;
    private Gauge $workerCount;
    private Counter $jobsFailed;

    public function __construct()
    {
        $this->jobsProcessed = new Counter(
            'gsmui_queue_jobs_processed_total',
            'Total number of jobs processed',
            ['queue', 'status']
        );

        $this->jobDuration = new Histogram(
            'gsmui_queue_job_duration_seconds',
            'Job processing duration in seconds',
            ['queue'],
            [0.1, 0.5, 1, 5, 10, 30, 60, 120, 300, 600]
        );

        $this->queueDepth = new Gauge(
            'gsmui_queue_depth',
            'Current queue depth',
            ['queue']
        );

        $this->workerCount = new Gauge(
            'gsmui_queue_workers_active',
            'Number of active workers',
            ['queue']
        );

        $this->jobsFailed = new Counter(
            'gsmui_queue_jobs_failed_total',
            'Total number of failed jobs',
            ['queue', 'exception']
        );
    }

    public function export(): string
    {
        $lines = [];
        
        // Queue depth
        foreach (['high', 'default', 'mail', 'media', 'search', 'exports', 'analytics', 'backups'] as $queue) {
            $depth = Redis::llen("queues:{$queue}");
            $lines[] = "gsmui_queue_depth{queue=\"{$queue}\"} {$depth}";
        }

        // Jobs processed
        $metrics = $this->getJobMetrics();
        foreach ($metrics as $metric) {
            $lines[] = "gsmui_queue_jobs_processed_total{queue=\"{$metric['queue']}\",status=\"{$metric['status']}\"} {$metric['count']}";
        }

        // Worker count
        $workers = $this->getWorkerCounts();
        foreach ($workers as $queue => $count) {
            $lines[] = "gsmui_queue_workers_active{queue=\"{$queue}\"} {$count}";
        }

        return implode("\n", $lines) . "\n";
    }
}
```

```php
use OpenTelemetry\API\Trace\TracerInterface;
use OpenTelemetry\API\Trace\SpanKind;

class ProcessMedia implements ShouldQueue
{
    public function __construct(
        private TracerInterface $tracer,
    ) {}

    public function handle(): void
    {
        $span = $this->tracer->spanBuilder('ProcessMedia')
            ->setSpanKind(SpanKind::CONSUMER)
            ->setAttribute('queue', 'media')
            ->setAttribute('job', self::class)
            ->setAttribute('file_id', $this->fileId)
            ->startSpan();

        $scope = $span->activate();

        try {
            $this->processor->convert($this->file);
            $span->setStatus(StatusCode::OK);
        } catch (\Exception $e) {
            $span->setStatus(StatusCode::ERROR, $e->getMessage());
            $span->recordException($e);
            throw $e;
        } finally {
            $span->end();
            $scope->detach();
        }
    }
}
```

# Data Flow

Monitoring and observability data flows from every layer of the GsmUi platform into a centralized collection pipeline.

## Telemetry Pipeline

`
Application Layer
    │
    ├── Laravel Telescope (dev) ──> Local DB
    │
    ├── Custom Metrics ──> StatsD/Prometheus
    │       ├── Request count, latency, status codes
    │       ├── Database query count, duration
    │       ├── Cache hit/miss ratios
    │       └── Queue job count, processing time
    │
    └── Structured Logs ──> Log Aggregator (ELK/Loki)
            ├── Request logs (method, path, status, duration)
            ├── Error logs (exception, stack trace, context)
            ├── Audit logs (actor, action, target)
            └── Business logs (events, milestones)

Infrastructure Layer
    │
    ├── Server Metrics ──> Node Exporter ──> Prometheus
    │       ├── CPU usage, memory, disk I/O
    │       ├── Network throughput
    │       └── Process count, file descriptors
    │
    ├── Database Metrics ──> mysqld_exporter ──> Prometheus
    │       ├── Query throughput, slow queries
    │       ├── Replication lag, connection count
    │       └── InnoDB buffer pool, lock waits
    │
    └── Cache Metrics ──> Redis Exporter ──> Prometheus
            ├── Hit/miss ratio, eviction count
            ├── Memory usage, key count
            └── Connected clients, commands/sec
`

## Alert Flow

`
Metric Threshold Breach
    │
    ├── Alert Manager evaluates rules
    │
    ├── Routing based on severity
    │       ├── Critical ──> PagerDuty ──> On-call engineer
    │       ├── Warning ──> Slack #ops-alerts
    │       └── Info ──> Dashboard only
    │
    └── Notification includes
            ├── Metric name and current value
            ├── Threshold and duration
            ├── Affected service/component
            └── Runbook link
`

# Security

Monitoring systems access sensitive data and must be secured to prevent information leakage and unauthorized access.

## Data Sanitization

| Data Type | Sanitization Rule | Storage |
|-----------|-------------------|---------|
| User passwords | Never logged | N/A |
| API tokens | Masked in logs (	ok_****) | N/A |
| Payment data | Never logged (PCI compliance) | N/A |
| Session tokens | Hashed before logging | Log aggregator |
| IP addresses | Retained 30 days, then purged | Log aggregator |
| User emails | Masked in non-auth logs | Log aggregator |

## Access Control

| System | Access | Authentication |
|--------|--------|---------------|
| Prometheus | Admin only | Basic auth + IP whitelist |
| Grafana | Admin + ops team | SSO with MFA |
| Log aggregator | Admin + devs | Role-based access |
| PagerDuty | On-call engineers | SSO |
| Telescope | Local dev only | Laravel auth |

## Log Security

- Logs are transmitted over TLS to the aggregation service.
- Log storage is encrypted at rest (AES-256).
- Retention policies enforce automatic purging of sensitive data.
- Audit logs are immutable once written (append-only).

## Monitoring the Monitoring

- UptimeRobot or similar monitors the monitoring stack itself.
- If the monitoring system fails, an external alert triggers.
- Health check endpoints expose monitoring system status.

# Conclusion

The GsmUi monitoring and observability stack provides comprehensive visibility into platform health across application, infrastructure, and business layers. Structured logs, metrics, and traces flow through a centralized pipeline into dashboards and alerting systems.

Key architectural decisions:

1. **Three pillars of observability**: Logs, metrics, and traces are collected independently but correlated through request IDs and timestamps.
2. **Severity-based routing**: Critical alerts reach on-call engineers via PagerDuty; warnings go to Slack; info stays on dashboards.
3. **Security-conscious logging**: PII is sanitized, tokens are masked, and log storage is encrypted at rest.
4. **Self-monitoring**: The monitoring system itself is monitored by external services to prevent blind spots.

Future improvements will add distributed tracing, ML-based anomaly detection, and predictive scaling to transform reactive monitoring into proactive platform management.

# Risk

Monitoring and observability carry specific risks that could compromise platform reliability or security if not properly managed.

## Risk Register

| Risk ID | Risk Description | Probability | Impact | Mitigation | Owner |
|---------|-----------------|-------------|--------|------------|-------|
| MON-001 | Monitoring system itself goes down creating blind spots | Low | Critical | External uptime monitor (UptimeRobot) with independent alerting | DevOps |
| MON-002 | Alert fatigue from too many false positives | Medium | High | Tune thresholds monthly; require 3 consecutive breaches before alerting | Platform Lead |
| MON-003 | Sensitive data leaked through logs | Medium | Critical | Automated PII scrubbing; log review audits quarterly | Security |
| MON-004 | Log storage costs exceed budget | Medium | Medium | Implement tiered retention; compress logs older than 7 days | DevOps |
| MON-005 | Dashboard performance degrades with high cardinality metrics | Medium | Medium | Limit unique tag values; aggregate before storage | Backend |
| MON-006 | Alert routing failure (PagerDuty/Slack down) | Low | High | Secondary email alerting fallback; SMS for critical alerts | DevOps |
| MON-007 | Prometheus data loss during server failure | Low | High | Prometheus remote write to durable storage; 15-day local retention | DevOps |
| MON-008 | Team does not respond to alerts due to alert exhaustion | Medium | High | Rotate on-call weekly; enforce acknowledgment SLAs | Engineering Manager |

## Risk Response Strategies

### Avoid
- Never store raw user data in log messages; always hash or mask before emission.
- Never expose monitoring endpoints (Prometheus, Grafana) to the public internet.

### Mitigate
- Implement alert deduplication to reduce noise from cascading failures.
- Use log sampling at 10% rate for debug-level logs in production.
- Set hard budget caps on cloud logging services with automated alerts at 80%.

### Transfer
- Use PagerDuty for incident management to leverage their escalation and scheduling infrastructure.
- Use cloud-provider monitoring (CloudWatch) as a backup for infrastructure metrics.

### Accept
- Accept that monitoring adds 1-2% overhead to application performance as a necessary cost.
- Accept that some historical metrics may be lost during catastrophic monitoring infrastructure failure.

# Distributed Tracing

## Trace Context Propagation

```php
<?php

namespace App\Monitoring\Tracing;

use Illuminate\Support\Facades\Request;

class TraceContext
{
    private string $traceId;
    private string $spanId;
    private ?string $parentSpanId;
    private array $tags = [];
    private array $baggage = [];

    public function __construct(
        ?string $traceId = null,
        ?string $spanId = null,
        ?string $parentSpanId = null
    ) {
        $this->traceId = $traceId ?? $this->generateId();
        $this->spanId = $spanId ?? $this->generateId();
        $this->parentSpanId = $parentSpanId;
    }

    public static function fromHeaders(): self
    {
        $traceparent = Request::header('traceparent', '');

        if (preg_match('/00-([a-f0-9]{32})-([a-f0-9]{16})-([a-f0-9]{2})/', $traceparent, $matches)) {
            return new self(
                traceId: $matches[1],
                parentSpanId: $matches[2]
            );
        }

        return new self();
    }

    public function toHeaders(): array
    {
        return [
            'traceparent' => sprintf(
                '00-%s-%s-01',
                $this->traceId,
                $this->spanId
            ),
        ];
    }

    public function createChildSpan(string $name): Span
    {
        return new Span(
            traceId: $this->traceId,
            spanId: $this->generateId(),
            parentSpanId: $this->spanId,
            name: $name,
            startTime: microtime(true)
        );
    }

    public function addTag(string $key, string $value): void
    {
        $this->tags[$key] = $value;
    }

    public function addBaggage(string $key, string $value): void
    {
        $this->baggage[$key] = $value;
    }

    public function getTraceId(): string
    {
        return $this->traceId;
    }

    public function getSpanId(): string
    {
        return $this->spanId;
    }

    private function generateId(): string
    {
        return bin2hex(random_bytes(16));
    }
}
```

## Span Implementation

```php
<?php

namespace App\Monitoring\Tracing;

class Span
{
    private string $traceId;
    private string $spanId;
    private ?string $parentSpanId;
    private string $name;
    private float $startTime;
    private ?float $endTime = null;
    private string $status = 'ok';
    private array $tags = [];
    private array $events = [];
    private ?string $statusMessage = null;

    public function __construct(
        string $traceId,
        string $spanId,
        ?string $parentSpanId,
        string $name,
        float $startTime
    ) {
        $this->traceId = $traceId;
        $this->spanId = $spanId;
        $this->parentSpanId = $parentSpanId;
        $this->name = $name;
        $this->startTime = $startTime;
    }

    public function setTag(string $key, mixed $value): self
    {
        $this->tags[$key] = $value;
        return $this;
    }

    public function addEvent(string $name, array $attributes = []): self
    {
        $this->events[] = [
            'name' => $name,
            'timestamp' => microtime(true),
            'attributes' => $attributes,
        ];
        return $this;
    }

    public function setError(string $message): self
    {
        $this->status = 'error';
        $this->statusMessage = $message;
        return $this;
    }

    public function finish(): void
    {
        $this->endTime = microtime(true);
    }

    public function getDurationMs(): float
    {
        $end = $this->endTime ?? microtime(true);
        return ($end - $this->startTime) * 1000;
    }

    public function toArray(): array
    {
        return [
            'trace_id' => $this->traceId,
            'span_id' => $this->spanId,
            'parent_span_id' => $this->parentSpanId,
            'name' => $this->name,
            'start_time' => date('c', (int) $this->startTime),
            'end_time' => $this->endTime ? date('c', (int) $this->endTime) : null,
            'duration_ms' => $this->getDurationMs(),
            'status' => $this->status,
            'status_message' => $this->statusMessage,
            'tags' => $this->tags,
            'events' => $this->events,
        ];
    }
}
```

# Prometheus Metrics

## Custom Metrics Registration

```php
<?php

namespace App\Monitoring\Metrics;

use Prometheus\CollectorRegistry;
use Prometheus\Storage\Redis;

class MetricsCollector
{
    private CollectorRegistry $registry;

    public function __construct()
    {
        $adapter = Redis::connection(config('metrics.redis_connection'));
        $this->registry = new CollectorRegistry($adapter);
    }

    public function recordHttpRequest(string $method, string $route, int $statusCode, float $duration): void
    {
        $this->registry->registerHistogram(
            'gsmui_http_request_duration_seconds',
            'HTTP request duration in seconds',
            ['method', 'route', 'status_code'],
            [0.01, 0.05, 0.1, 0.25, 0.5, 1.0, 2.5, 5.0, 10.0]
        )->observe($duration / 1000, [$method, $route, (string) $statusCode]);

        $this->registry->registerCounter(
            'gsmui_http_requests_total',
            'Total HTTP requests',
            ['method', 'route', 'status_code']
        )->inc([$method, $route, (string) $statusCode]);
    }

    public function recordDatabaseQuery(string $query, float $duration, string $connection): void
    {
        $this->registry->registerHistogram(
            'gsmui_db_query_duration_seconds',
            'Database query duration in seconds',
            ['connection'],
            [0.001, 0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1.0]
        )->observe($duration / 1000, [$connection]);

        $this->registry->registerCounter(
            'gsmui_db_queries_total',
            'Total database queries',
            ['connection']
        )->inc([$connection]);
    }

    public function recordQueueJob(string $job, string $status, float $duration): void
    {
        $this->registry->registerHistogram(
            'gsmui_queue_job_duration_seconds',
            'Queue job duration in seconds',
            ['job', 'status'],
            [0.1, 0.5, 1.0, 5.0, 10.0, 30.0, 60.0, 120.0]
        )->observe($duration, [$job, $status]);

        $this->registry->registerCounter(
            'gsmui_queue_jobs_total',
            'Total queue jobs processed',
            ['job', 'status']
        )->inc([$job, $status]);
    }

    public function recordCacheOperation(string $operation, bool $hit, string $store): void
    {
        $this->registry->registerCounter(
            'gsmui_cache_operations_total',
            'Total cache operations',
            ['operation', 'hit', 'store']
        )->inc([$operation, $hit ? 'true' : 'false', $store]);
    }

    public function recordActiveUsers(int $count, string $period): void
    {
        $this->registry->registerGauge(
            'gsmui_active_users',
            'Active user count',
            ['period']
        )->set($count, [$period]);
    }

    public function recordRevenue(float $amount, string $period): void
    {
        $this->registry->registerGauge(
            'gsmui_revenue_total',
            'Total revenue',
            ['period']
        )->set($amount, [$period]);
    }

    public function recordError(string $type, string $context): void
    {
        $this->registry->registerCounter(
            'gsmui_errors_total',
            'Total errors',
            ['type', 'context']
        )->inc([$type, $context]);
    }

    public function gauge(string $name, float $value, array $labels = []): void
    {
        $this->registry->getOrRegisterGauge(
            $name,
            $name . ' gauge',
            array_keys($labels)
        )->set($value, array_values($labels));
    }

    public function counter(string $name, array $labels = []): void
    {
        $this->registry->getOrRegisterCounter(
            $name,
            $name . ' counter',
            array_keys($labels)
        )->inc(array_values($labels));
    }

    public function getMetrics(): string
    {
        return $this->registry->renderMetrics();
    }
}
```

# Incident Response

## Incident Severity Levels

| Severity | Description | Response Time | Escalation |
|----------|-------------|--------------|------------|
| SEV-1 | Complete platform outage | < 5 minutes | Immediate page to on-call + management |
| SEV-2 | Major feature unavailable | < 15 minutes | Page to on-call engineer |
| SEV-3 | Degraded performance | < 30 minutes | Slack notification, next business day |
| SEV-4 | Minor issue, workaround exists | < 4 hours | Ticket created, normal priority |
| SEV-5 | Cosmetic or low-impact | < 24 hours | Backlog |

## Incident Response Runbook

```text
1. DETECT
   - Alert fires (automated)
   - User reports issue (support ticket)
   - Monitoring dashboard shows anomaly

2. TRIAGE
   - Acknowledge alert in PagerDuty
   - Check severity level
   - Assess blast radius (which services affected)
   - Open incident channel in Slack

3. COMMUNICATE
   - Post initial status in incident channel
   - Update status page if user-facing
   - Notify stakeholders for SEV-1/SEV-2

4. INVESTIGATE
   - Check recent deployments (last 24h)
   - Review error logs and metrics
   - Identify root cause hypothesis
   - Test hypothesis in staging if safe

5. MITIGATE
   - If deploy-related: rollback
   - If infrastructure: scale/restart/fix
   - If code bug: hotfix or feature flag
   - If external: enable circuit breaker/fallback

6. RESOLVE
   - Verify mitigation worked
   - Confirm metrics returned to normal
   - Update status page to resolved
   - Close incident channel

7. REVIEW
   - Write post-mortem within 48 hours
   - Identify action items
   - Create tickets for follow-up work
   - Share learnings with team
```

```php
<?php

namespace App\Monitoring\Synthetic;

use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;

class UptimeMonitor
{
    private array $checks = [
        ['name' => 'Homepage', 'url' => 'https://gsmui.com', 'expected_status' => 200, 'timeout' => 10],
        ['name' => 'API Health', 'url' => 'https://api.gsmui.com/health', 'expected_status' => 200, 'timeout' => 5],
        ['name' => 'Login Page', 'url' => 'https://gsmui.com/login', 'expected_status' => 200, 'timeout' => 10],
        ['name' => 'Component List', 'url' => 'https://gsmui.com/components', 'expected_status' => 200, 'timeout' => 15],
        ['name' => 'Analytics Ingest', 'url' => 'https://analytics.gsmui.com/v1/health', 'expected_status' => 200, 'timeout' => 5],
    ];

    public function runChecks(): array
    {
        $results = [];

        foreach ($this->checks as $check) {
            $result = $this->runCheck($check);
            $results[] = $result;

            if (!$result['healthy']) {
                $this->alert($check, $result);
            }
        }

        return $results;
    }

    private function runCheck(array $check): array
    {
        $start = microtime(true);

        try {
            $response = Http::timeout($check['timeout'])
                ->withoutVerifying()
                ->get($check['url']);

            $duration = (microtime(true) - $start) * 1000;

            return [
                'name' => $check['name'],
                'url' => $check['url'],
                'healthy' => $response->status() === $check['expected_status'],
                'status_code' => $response->status(),
                'response_time_ms' => $duration,
                'checked_at' => now()->toIso8601String(),
            ];
        } catch (\Throwable $e) {
            $duration = (microtime(true) - $start) * 1000;

            return [
                'name' => $check['name'],
                'url' => $check['url'],
                'healthy' => false,
                'status_code' => 0,
                'response_time_ms' => $duration,
                'error' => $e->getMessage(),
                'checked_at' => now()->toIso8601String(),
            ];
        }
    }

    private function alert(array $check, array $result): void
    {
        Log::channel('slack')->critical("Uptime check failed: {$check['name']}", [
            'url' => $check['url'],
            'status_code' => $result['status_code'],
            'error' => $result['error'] ?? null,
            'response_time_ms' => $result['response_time_ms'],
        ]);
    }
}
```

## Client-Side Performance Tracking

```javascript
// GsmUi RUM - Real User Monitoring
(function() {
    'use strict';

    const GsmuiRUM = {
        config: {
            endpoint: '/api/rum/collect',
            sampleRate: 0.1,
            sessionTimeout: 30 * 60 * 1000,
            maxEvents: 100,
        },
        
        events: [],
        sessionStart: Date.now(),

        init(config) {
            Object.assign(this.config, config);
            this.setupPerformanceObserver();
            this.setupErrorTracking();
            this.setupNavigationTiming();
            this.trackSession();
        },

        setupPerformanceObserver() {
            if (!('PerformanceObserver' in window)) return;

            const observer = new PerformanceObserver((list) => {
                for (const entry of list.getEntries()) {
                    if (entry.entryType === 'largest-contentful-paint') {
                        this.track('lcp', {
                            value: entry.startTime,
                            element: entry.element?.tagName,
                        });
                    }
                    if (entry.entryType === 'first-input') {
                        this.track('fid', {
                            value: entry.processingStart - entry.startTime,
                        });
                    }
                    if (entry.entryType === 'layout-shift') {
                        this.track('cls', {
                            value: entry.value,
                            hadRecentInput: entry.hadRecentInput,
                        });
                    }
                }
            });

            try {
                observer.observe({ type: 'largest-contentful-paint', buffered: true });
                observer.observe({ type: 'first-input', buffered: true });
                observer.observe({ type: 'layout-shift', buffered: true });
            } catch (e) {
                // Browser doesnt support these entry types
            }
        },

        setupErrorTracking() {
            window.addEventListener('error', (event) => {
                this.track('javascript_error', {
                    message: event.message,
                    filename: event.filename,
                    lineno: event.lineno,
                    stack: event.error?.stack?.substring(0, 500),
                });
            });

            window.addEventListener('unhandledrejection', (event) => {
                this.track('unhandled_rejection', {
                    reason: String(event.reason).substring(0, 500),
                });
            });
        },

        setupNavigationTiming() {
            window.addEventListener('load', () => {
                setTimeout(() => {
                    const timing = performance.getEntriesByType('navigation')[0];
                    if (!timing) return;

                    this.track('page_load', {
                        dns: timing.domainLookupEnd - timing.domainLookupStart,
                        tcp: timing.connectEnd - timing.connectStart,
                        ttfb: timing.responseStart - timing.requestStart,
                        download: timing.responseEnd - timing.responseStart,
                        dom_interactive: timing.domInteractive - timing.navigationStart,
                        dom_complete: timing.domComplete - timing.navigationStart,
                        load_event: timing.loadEventEnd - timing.loadEventStart,
                        total: timing.loadEventEnd - timing.navigationStart,
                        transfer_size: timing.transferSize,
                    });
                }, 0);
            });
        },

        trackSession() {
            const sessionId = this.getCookie('gsmui_rum_session');
            if (!sessionId || (Date.now() - parseInt(this.getCookie('gsmui_rum_session_time') || '0')) > this.config.sessionTimeout) {
                this.setCookie('gsmui_rum_session', this.generateId(), this.config.sessionTimeout / 1000);
                this.setCookie('gsmui_rum_session_time', Date.now(), this.config.sessionTimeout / 1000);
                this.track('session_start', {});
            }
        },

        track(name, data = {}) {
            if (Math.random() > this.config.sampleRate) return;

            this.events.push({
                name,
                data,
                timestamp: Date.now(),
                url: window.location.href,
                userAgent: navigator.userAgent,
                viewport: {
                    width: window.innerWidth,
                    height: window.innerHeight,
                },
            });

            if (this.events.length >= this.config.maxEvents) {
                this.flush();
            }
        },

        flush() {
            if (this.events.length === 0) return;

            const payload = {
                events: [...this.events],
                session_id: this.getCookie('gsmui_rum_session'),
            };

            this.events = [];

            if (navigator.sendBeacon) {
                navigator.sendBeacon(this.config.endpoint, JSON.stringify(payload));
            } else {
                fetch(this.config.endpoint, {
                    method: 'POST',
                    body: JSON.stringify(payload),
                    headers: { 'Content-Type': 'application/json' },
                    keepalive: true,
                });
            }
        },

        getCookie(name) {
            const match = document.cookie.match(new RegExp('(^| )' + name + '=([^;]+)'));
            return match ? match[2] : null;
        },

        setCookie(name, value, maxAge) {
            document.cookie = `${name}=${value}; Max-Age=${maxAge}; Path=/; SameSite=Lax`;
        },

        generateId() {
            return 'rum_' + Date.now().toString(36) + Math.random().toString(36).substring(2);
        },
    };

    window.GsmuiRUM = GsmuiRUM;
    GsmuiRUM.init();
})();
```

# Capacity Planning

## Traffic Forecasting

```php
<?php

namespace App\Monitoring\Capacity;

use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Cache;

class CapacityPlanner
{
    public function forecastTraffic(string $metric, int $daysAhead = 30): array
    {
        $historical = $this->getHistoricalData($metric, 90);

        if (count($historical) < 30) {
            return ['error' => 'Insufficient historical data'];
        }

        $trend = $this->calculateTrend($historical);
        $seasonality = $this->calculateSeasonality($historical);
        $current = end($historical)['value'];

        $forecast = [];

        for ($i = 1; $i <= $daysAhead; $i++) {
            $date = now()->addDays($i);
            $dayOfWeek = $date->dayOfWeek;
            $seasonalFactor = $seasonality[$dayOfWeek] ?? 1.0;
            $trendFactor = 1 + ($trend * $i);

            $forecast[] = [
                'date' => $date->format('Y-m-d'),
                'predicted' => round($current * $trendFactor * $seasonalFactor, 2),
                'lower_bound' => round($current * $trendFactor * $seasonalFactor * 0.8, 2),
                'upper_bound' => round($current * $trendFactor * $seasonalFactor * 1.2, 2),
            ];
        }

        return [
            'metric' => $metric,
            'current_value' => $current,
            'trend_per_day' => $trend,
            'forecast' => $forecast,
        ];
    }

    public function getCapacityRecommendations(): array
    {
        $recommendations = [];

        $cpuForecast = $this->forecastTraffic('cpu_usage', 30);
        if (isset($cpuForecast['forecast'])) {
            $maxPredicted = max(array_column($cpuForecast['forecast'], 'predicted'));
            if ($maxPredicted > 80) {
                $recommendations[] = [
                    'resource' => 'CPU',
                    'current_usage' => $cpuForecast['current_value'],
                    'predicted_usage' => $maxPredicted,
                    'recommendation' => 'Scale up compute instances',
                    'priority' => $maxPredicted > 90 ? 'critical' : 'warning',
                ];
            }
        }

        $memoryForecast = $this->forecastTraffic('memory_usage', 30);
        if (isset($memoryForecast['forecast'])) {
            $maxPredicted = max(array_column($memoryForecast['forecast'], 'predicted'));
            if ($maxPredicted > 85) {
                $recommendations[] = [
                    'resource' => 'Memory',
                    'current_usage' => $memoryForecast['current_value'],
                    'predicted_usage' => $maxPredicted,
                    'recommendation' => 'Increase memory allocation',
                    'priority' => $maxPredicted > 95 ? 'critical' : 'warning',
                ];
            }
        }

        return $recommendations;
    }

    private function getHistoricalData(string $metric, int $days): array
    {
        return DB::table('daily_metrics')
            ->where('metric_name', $metric)
            ->where('date', '>=', now()->subDays($days))
            ->orderBy('date')
            ->get()
            ->map(fn($row) => ['date' => $row->date, 'value' => $row->value])
            ->toArray();
    }

    private function calculateTrend(array $data): float
    {
        $n = count($data);
        if ($n < 2) return 0;

        $sumX = $sumY = $sumXY = $sumX2 = 0;

        foreach ($data as $i => $point) {
            $sumX += $i;
            $sumY += $point['value'];
            $sumXY += $i * $point['value'];
            $sumX2 += $i * $i;
        }

        $slope = ($n * $sumXY - $sumX * $sumY) / ($n * $sumX2 - $sumX * $sumX);
        $avg = $sumY / $n;

        return $avg > 0 ? $slope / $avg : 0;
    }

    private function calculateSeasonality(array $data): array
    {
        $dayTotals = array_fill(0, 7, 0);
        $dayCounts = array_fill(0, 7, 0);

        foreach ($data as $point) {
            $dayOfWeek = date('w', strtotime($point['date']));
            $dayTotals[$dayOfWeek] += $point['value'];
            $dayCounts[$dayOfWeek]++;
        }

        $dayAverages = [];
        foreach ($dayTotals as $day => $total) {
            $dayAverages[$day] = $dayCounts[$day] > 0 ? $total / $dayCounts[$day] : 1;
        }

        $overallAverage = array_sum($dayAverages) / 7;

        $seasonality = [];
        foreach ($dayAverages as $day => $avg) {
            $seasonality[$day] = $overallAverage > 0 ? $avg / $overallAverage : 1;
        }

        return $seasonality;
    }
}
```

```php
        return DB::table('oncall_schedules')
            ->where('start_date', '<=', $endOfWeek)
            ->where('end_date', '>=', $startOfWeek)
            ->orderBy('start_date')
            ->get()
            ->toArray();
    }

    public function rotate(): void
    {
        $current = $this->getCurrentOnCall();

        if (!$current) return;

        DB::table('oncall_schedules')->where('id', $current->id)->update(['end_date' => now()]);

        $nextEngineer = $this->getNextEngineer($current->engineer_id);

        DB::table('oncall_schedules')->insert([
            'engineer_id' => $nextEngineer->id,
            'start_date' => now(),
            'end_date' => now()->addWeek(),
            'created_at' => now(),
        ]);

        Cache::forget('oncall:current');
    }

    public function escalate(string $incidentId, string $reason): void
    {
        $current = $this->getCurrentOnCall();

        if (!$current) return;

        $escalationLevel = DB::table('oncall_escalations')
            ->where('schedule_id', $current->id)
            ->where('incident_id', $incidentId)
            ->max('escalation_level') + 1;

        DB::table('oncall_escalations')->insert([
            'schedule_id' => $current->id,
            'incident_id' => $incidentId,
            'escalation_level' => $escalationLevel,
            'reason' => $reason,
            'escalated_at' => now(),
        ]);
    }

    private function getNextEngineer(int $currentEngineerId): object
    {
        $allEngineers = DB::table('users')
            ->where('is_oncall_eligible', true)
            ->orderBy('id')
            ->get();

        $currentIndex = $allEngineers->search(fn($e) => $e->id === $currentEngineerId);
        $nextIndex = ($currentIndex + 1) % $allEngineers->count();

        return $allEngineers[$nextIndex];
    }
}
```

# Advanced Alert Routing

## Multi-Channel Alert Routing

The alert routing system supports escalation chains, quiet hours, and per-team notification preferences.

```php
<?php

namespace App\Monitoring\Alerting;

use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Notification;

class AlertRouter
{
    private array $severityConfig = [
        'critical' => [
            'channels' => ['pagerduty', 'slack', 'email', 'sms'],
            'escalation_delay_minutes' => 5,
            'acknowledgment_timeout_minutes' => 15,
            'auto_escalate_after_minutes' => 30,
        ],
        'warning' => [
            'channels' => ['slack', 'email'],
            'escalation_delay_minutes' => 15,
            'acknowledgment_timeout_minutes' => 60,
            'auto_escalate_after_minutes' => 120,
        ],
        'info' => [
            'channels' => ['slack'],
            'escalation_delay_minutes' => 60,
            'acknowledgment_timeout_minutes' => null,
            'auto_escalate_after_minutes' => null,
        ],
    ];

    public function routeAlert(Alert $alert): array
    {
        $config = $this->severityConfig[$alert->severity] ?? $this->severityConfig['info'];

        if ($this->isInQuietHours($alert)) {
            $this->queueForQuietHours($alert, $config);
            return ['status' => 'queued', 'reason' => 'quiet_hours'];
        }

        $recipients = $this->getRecipients($alert);
        $notifications = [];

        foreach ($config['channels'] as $channel) {
            $channelRecipients = $this->filterRecipientsForChannel($recipients, $channel);

            foreach ($channelRecipients as $recipient) {
                $notification = $this->sendNotification($alert, $channel, $recipient);
                $notifications[] = $notification;
            }
        }

        $this->scheduleEscalation($alert, $config);

        return [
            'status' => 'sent',
            'notifications' => $notifications,
            'recipients' => count($recipients),
        ];
    }

    public function acknowledgeAlert(string $alertId, string $userId): bool
    {
        return DB::table('alerts')
            ->where('id', $alertId)
            ->where('status', 'active')
            ->update([
                'acknowledged_by' => $userId,
                'acknowledged_at' => now(),
                'status' => 'acknowledged',
            ]) > 0;
    }

    public function resolveAlert(string $alertId, string $resolution): bool
    {
        return DB::table('alerts')
            ->where('id', $alertId)
            ->update([
                'resolved_at' => now(),
                'resolution' => $resolution,
                'status' => 'resolved',
            ]) > 0;
    }

    private function isInQuietHours(Alert $alert): bool
    {
        $quietStart = (int) config('monitoring.quiet_hours.start', 22);
        $quietEnd = (int) config('monitoring.quiet_hours.end', 7);
        $currentHour = (int) now()->format('H');

        if ($quietStart > $quietEnd) {
            return $currentHour >= $quietStart || $currentHour < $quietEnd;
        }

        return $currentHour >= $quietStart && $currentHour < $quietEnd;
    }

    private function queueForQuietHours(Alert $alert, array $config): void
    {
        DB::table('alert_queue')->insert([
            'alert_id' => $alert->id,
            'severity' => $alert->severity,
            'config' => json_encode($config),
            'queued_at' => now(),
            'deliver_after' => $this->getNextQuietHoursEnd(),
        ]);
    }

    private function getNextQuietHoursEnd(): \Carbon\Carbon
    {
        $quietEnd = (int) config('monitoring.quiet_hours.end', 7);
        $nextEnd = now()->copy()->startOfDay()->addHours($quietEnd);

        if ($nextEnd->isPast()) {
            $nextEnd->addDay();
        }

        return $nextEnd;
    }

    private function getRecipients(Alert $alert): array
    {
        $teamRecipients = DB::table('team_members')
            ->where('team_id', $alert->team_id)
            ->where('receives_alerts', true)
            ->get();

        $onCall = DB::table('oncall_schedules')
            ->where('start_date', '<=', now())
            ->where('end_date', '>=', now())
            ->first();

        $recipients = [];

        foreach ($teamRecipients as $member) {
            $recipients[] = [
                'user_id' => $member->user_id,
                'channels' => json_decode($member->notification_channels, true),
                'role' => $member->role,
            ];
        }

        if ($onCall) {
            $recipients[] = [
                'user_id' => $onCall->engineer_id,
                'channels' => ['pagerduty', 'sms', 'slack'],
                'role' => 'oncall',
            ];
        }

        return $recipients;
    }

    private function filterRecipientsForChannel(array $recipients, string $channel): array
    {
        return array_filter($recipients, function ($recipient) use ($channel) {
            return in_array($channel, $recipient['channels'] ?? []);
        });
    }

    private function sendNotification(Alert $alert, string $channel, array $recipient): array
    {
        $notificationClass = match ($channel) {
            'pagerduty' => PagerDutyNotification::class,
            'slack' => SlackAlertNotification::class,
            'email' => EmailAlertNotification::class,
            'sms' => SmsAlertNotification::class,
        };

        Notification::send(
            \App\Models\User::find($recipient['user_id']),
            new $notificationClass($alert)
        );

        DB::table('alert_notifications')->insert([
            'alert_id' => $alert->id,
            'channel' => $channel,
            'recipient_id' => $recipient['user_id'],
            'sent_at' => now(),
        ]);

        return [
            'channel' => $channel,
            'recipient_id' => $recipient['user_id'],
            'sent_at' => now()->toIso8601String(),
        ];
    }

    private function scheduleEscalation(Alert $alert, array $config): void
    {
        if (!$config['auto_escalate_after_minutes']) {
            return;
        }

        DB::table('alert_escalations')->insert([
            'alert_id' => $alert->id,
            'escalation_level' => 1,
            'scheduled_for' => now()->addMinutes($config['auto_escalate_after_minutes']),
            'status' => 'pending',
        ]);
    }
}
```

```php
        ]);

            ->orderBy('start_time')
            ->get();

        return response()->json([
            'status' => 'ok',
            'data' => $windows,
        ]);
    }

                ->whereDate('resolved_at', today())
                ->count(),
            'by_severity' => [
                'critical' => Alert::where('status', 'active')->where('severity', 'critical')->count(),
                'warning' => Alert::where('status', 'active')->where('severity', 'warning')->count(),
                'info' => Alert::where('status', 'active')->where('severity', 'info')->count(),
            ],
            'mttr_minutes' => $this->calculateMTTR(),
        ];
    }

    private function calculateMTTR(): float
    {
        $resolved = Alert::where('status', 'resolved')
            ->where('resolved_at', '>=', now()->subDays(7))
            ->get();

        if ($resolved->isEmpty()) {
            return 0;
        }

        $totalMinutes = $resolved->sum(function ($alert) {
            return $alert->created_at->diffInMinutes($alert->resolved_at);
        });

        return round($totalMinutes / $resolved->count(), 1);
    }
}
```

```php
            'queue' => $this->getQueueSummary($period),

        ];

        $healthy = !in_array(false, array_column($checks, 'healthy'));

            'memory_used_mb' => cache()->get("metrics:cache:memory:used", 0),
            'evictions' => cache()->get("metrics:cache:evictions:{$period}", 0),

    }

            'processing' => cache()->get("metrics:queue:processing", 0),
            'failed' => cache()->get("metrics:queue:failed:{$period}", 0),
            'avg_processing_ms' => cache()->get("metrics:queue:avg_time:{$period}", 0),
        ];
    }

    private function getErrorSummary(string $period): array
    {
        return [
            'total_4xx' => cache()->get("metrics:errors:4xx:{$period}", 0),
            'total_5xx' => cache()->get("metrics:errors:5xx:{$period}", 0),
            'uncaught_exceptions' => cache()->get("metrics:errors:exceptions:{$period}", 0),
            'unique_error_types' => cache()->get("metrics:errors:unique:{$period}", 0),
        ];
    }

    private function checkDatabase(): array
    {
        try {
            \Illuminate\Support\Facades\DB::select('SELECT 1');
            return ['healthy' => true, 'message' => 'Connected'];
        } catch (\Throwable $e) {
            return ['healthy' => false, 'message' => $e->getMessage()];
        }
    }

    private function checkCache(): array
    {
        try {
            \Illuminate\Support\Facades\Cache::put('_health_check', 'ok', 10);
            $value = \Illuminate\Support\Facades\Cache::get('_health_check');
            return ['healthy' => $value === 'ok', 'message' => $value === 'ok' ? 'Operational' : 'Read mismatch'];
        } catch (\Throwable $e) {
            return ['healthy' => false, 'message' => $e->getMessage()];
        }
    }

    private function checkQueue(): array
    {
        try {
            $size = \Illuminate\Support\Facades\Queue::size();
            return ['healthy' => $size < 1000, 'message' => "{$size} pending jobs"];
        } catch (\Throwable $e) {
            return ['healthy' => false, 'message' => $e->getMessage()];
        }
    }

    private function checkStorage(): array
    {
        $free = disk_free_space('/');
        $total = disk_total_space('/');
        $usedPercent = (($total - $free) / $total) * 100;

        return [
            'healthy' => $usedPercent < 90,
            'message' => round($usedPercent, 1) . '% used',
        ];
    }
}
```

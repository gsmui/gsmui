# Architecture Overview

The Admin Platform provides a unified interface for platform administration, including user management, content moderation, financial operations, and system monitoring. It is built as a set of Livewire components organized into domain modules, each with its own service layer, repository, and data models.

The architecture follows a strict separation of concerns: Blade templates handle presentation, Livewire components manage state and interaction, services encapsulate business logic, and repositories abstract data access. This layering enables independent testing and evolution of each concern without affecting others.

The admin panel is accessible only through authenticated routes protected by authorization middleware. All admin routes are grouped under the `/admin` prefix with dedicated middleware that verifies administrative privileges before any component is instantiated.

# Authorization Model

## Role-Based Access Control

The RBAC system defines roles with associated permissions. Permissions follow the `module.action` naming convention:

```php
'users.view'      // View user list and details
'users.edit'      // Edit user profiles
'users.delete'    // Delete user accounts
'content.approve' // Approve content submissions
'billing.manage'  // Manage subscriptions and orders
'system.settings' // Modify platform settings
```

## Permission Hierarchy

Roles inherit permissions from parent roles. A `super_admin` role has all permissions, while a `content_editor` role has only content-related permissions. Individual user permissions can override role defaults for exceptional cases.

## Authorization Enforcement

Authorization is checked at multiple layers:

1. **Route Middleware**: Verifies admin role before component instantiation
2. **Component Mount**: Checks specific component access
3. **Method-Level**: Sensitive operations verify individual permissions
4. **Service Layer**: Business logic validates authorization
5. **Repository Layer**: Query scopes filter data by permission

# Design Patterns

## Service Layer Pattern

Each domain module has a service class that encapsulates business logic. Services are injected through Laravel's service container and are responsible for orchestrating operations across multiple repositories.

```php
class UserService
{
    public function __construct(
        private UserRepository $users,
        private ActivityLogger $logger,
        private EventDispatcher $events,
    ) {}

    public function suspendUser(User $user, string $reason): void
    {
        $user->update(['status' => 'suspended']);
        $this->logger->log('user.suspended', $user, compact('reason'));
        $this->events->dispatch(new UserSuspended($user, $reason));
    }
}
```

## Repository Pattern

Repository classes abstract data access, providing a consistent interface for queries regardless of the underlying data source. This enables testing with in-memory repositories and future migration to different data stores.

## Policy Pattern

Laravel Policies handle authorization logic for model operations. Each model has a corresponding policy that defines which users can perform which actions.

```php
class UserPolicy
{
    public function edit(User $admin, User $target): bool
    {
        return $admin->hasPermissionTo('users.edit');
    }
}
```

## Event-Driven Audit Logging

Every administrative action dispatches an event that is captured by the audit logging listener. This decouples audit logging from business logic and ensures consistent capture across all modules.

# Performance Considerations

## Caching Strategy

- Dashboard metrics cached for 60 seconds with automatic invalidation
- Role and permission matrices cached for the session duration
- User list filter options cached for 5 minutes
- Report data cached for 15 minutes with background refresh

## Database Optimization

- All list queries use indexed columns for filtering and sorting
- Eager loading prevents N+1 queries on relationship data
- Cursor-based pagination for large datasets
- Read replicas for analytics queries

## Frontend Performance

- Livewire partial rendering updates only changed DOM elements
- Alpine.js handles client-side interactivity without full page reloads
- Asset compilation through Vite with code splitting
- Lazy loading for images and non-critical components

## Queue Processing

Heavy operations dispatch to queued jobs:
- Report generation
- Bulk exports
- Data migrations
- Email notifications
- Audit log processing

- **Package vulnerability**: Emergency patching, dependency audit, security disclosure

### Content Workflow State Machine

```php
// app/Services/ContentWorkflow.php
class ContentWorkflow
{
    private const TRANSITIONS = [
        'draft' => ['submit', 'delete'],
        'submitted' => ['approve', 'reject', 'request_revision'],
        'under_review' => ['approve', 'reject', 'request_revision'],
        'approved' => ['publish', 'reject'],
        'published' => ['unpublish', 'archive'],
        'rejected' => ['resubmit'],
        'revision' => ['submit'],
        'archived' => ['restore'],
    ];

    public function canTransition(Content $content, string $action): bool
    {
        $current = $content->status;
        return in_array($action, self::TRANSITIONS[$current] ?? []);
    }

    public function transition(Content $content, string $action, User $actor): void
    {
        if (!$this->canTransition($content, $action)) {
            throw new InvalidTransitionException(
                "Cannot {$action} content in {$content->status} state"
            );
        }

        $content->update(['status' => $this->getNextState($content->status, $action)]);

        event(new ContentStatusChanged($content, $action, $actor));
    }

    private function getNextState(string $current, string $action): string
    {
        $map = [
            'submit' => 'submitted',
            'approve' => 'approved',
            'reject' => 'rejected',
            'request_revision' => 'revision',
            'publish' => 'published',
            'unpublish' => 'draft',
            'archive' => 'archived',
            'resubmit' => 'submitted',
            'restore' => 'draft',
            'delete' => 'deleted',
        ];

        return $map[$action] ?? $current;
    }
}
```

```php
class ContentApproval extends Component
{
    public string $filter = 'submitted';
    public ?int $reviewingId = null;
    public string $reviewNotes = '';

    public function getQueueProperty(): Collection
    {
        return Content::query()
            ->where('status', $this->filter)
            ->with(['author', 'category'])
            ->latest()
            ->get();
    }

    public function startReview(int $contentId): void
    {
        $this->authorize('content.approve');
        $this->reviewingId = $contentId;
        $this->reviewNotes = '';
    }

    public function approve(): void
    {
        $this->authorize('content.approve');

        $content = Content::findOrFail($this->reviewingId);
        $workflow = app(ContentWorkflow::class);
        $workflow->transition($content, 'approve', auth()->user());

        $this->dispatch('content.approved', $content->id);
        $this->reviewingId = null;
    }

    public function reject(): void
    {
        $this->authorize('content.approve');

        $content = Content::findOrFail($this->reviewingId);
        $workflow = app(ContentWorkflow::class);
        $workflow->transition($content, 'reject', auth()->user());

        $content->update(['rejection_reason' => $this->reviewNotes]);

        $this->dispatch('content.rejected', $content->id);
        $this->reviewingId = null;
    }

    public function render(): View
    {
        return view('livewire.admin.content.content-approval', [
            'queue' => $this->queue,
        ]);
    }
}
```

### Subscription Management Service

```php
// app/Services/SubscriptionService.php
class SubscriptionService
{
    public function __construct(
        private StripeClient $stripe,
        private UserRepository $users,
        private ActivityLogger $logger,
    ) {}

    public function upgrade(User $user, Plan $newPlan): Subscription
    {
        $current = $user->subscription;

        if (!$current) {
            return $this->create($user, $newPlan);
        }

        // Calculate proration
        $proration = $this->calculateProration($current, $newPlan);

        // Update in Stripe
        $this->stripe->subscriptions->update($current->stripe_id, [
            'items' => [
                ['id' => $current->stripe_item_id, 'deleted' => true],
                ['price' => $newPlan->stripe_price_id],
            ],
            'proration_behavior' => 'create_prorations',
        ]);

        // Update local record
        $current->update([
            'plan_id' => $newPlan->id,
            'stripe_price_id' => $newPlan->stripe_price_id,
        ]);

        // Log the change
        $this->logger->log('subscription.upgraded', $user, [
            'old_plan' => $current->plan->name,
            'new_plan' => $newPlan->name,
            'proration_amount' => $proration,
        ]);

        event(new SubscriptionUpgraded($current, $newPlan, $proration));

        return $current->fresh();
    }

    public function cancel(User $user, bool $immediate = false): void
    {
        $subscription = $user->subscription;

        if (!$subscription) {
            throw new SubscriptionNotFoundException();
        }

        $this->stripe->subscriptions->update($subscription->stripe_id, [
            'cancel_at_period_end' => !$immediate,
        ]);

        if ($immediate) {
            $this->stripe->subscriptions->cancel($subscription->stripe_id);
            $subscription->update(['status' => 'canceled']);
        } else {
            $subscription->update(['cancel_at_period_end' => true]);
        }

        $this->logger->log('subscription.canceled', $user, [
            'immediate' => $immediate,
            'reason' => $user->cancellation_reason,
        ]);

        event(new SubscriptionCanceled($subscription, $immediate));
    }

    private function calculateProration(Subscription $current, Plan $newPlan): int
    {
        $now = now();
        $periodStart = Carbon::parse($current->current_period_start);
        $periodEnd = Carbon::parse($current->current_period_end);

        $daysRemaining = $now->diffInDays($periodEnd);
        $totalDays = $periodStart->diffInDays($periodEnd);

        $dailyOldPrice = $current->plan->price / $totalDays;
        $dailyNewPrice = $newPlan->price / $totalDays;

        return (int) round(($dailyNewPrice - $dailyOldPrice) * $daysRemaining);
    }
}
```

```php
                DB::raw('DATE(paid_at) as date'),
                DB::raw('SUM(total) as revenue'),
                DB::raw('COUNT(*) as order_count'),
                DB::raw('AVG(total) as avg_order_value')

            ->whereBetween('paid_at', [$start, $end])
            ->where('status', 'completed')
            ->groupBy(DB::raw('DATE(paid_at)'))
            ->orderBy('date')
            ->get();

    public function getMrr(): float
    {
        return DB::table('subscriptions')
            ->join('plans', 'plans.id', '=', 'subscriptions.plan_id')
            ->where('subscriptions.status', 'active')
            ->sum('plans.price') / 100;
    }

    public function getChurnRate(Carbon $start, Carbon $end): float
    {
        $startingSubs = DB::table('subscriptions')
            ->where('created_at', '<', $start)
            ->count();

        $canceled = DB::table('subscriptions')
            ->where('canceled_at', '>=', $start)
            ->where('canceled_at', '<', $end)
            ->count();

        return $startingSubs > 0 ? ($canceled / $startingSubs) * 100 : 0;
    }

    public function getRevenueByPlan(): Collection
    {
        return DB::table('subscriptions')
            ->join('plans', 'plans.id', '=', 'subscriptions.plan_id')
            ->where('subscriptions.status', 'active')
            ->select('plans.name', DB::raw('COUNT(*) as subscribers'), DB::raw('SUM(plans.price) as mrr'))
            ->groupBy('plans.name')
            ->get();
```

```php
    public function __construct(private CacheRepository $cache) {}

    public function isEnabled(string $flag, ?User $user = null): bool
    {
        $cacheKey = "feature_flag:{$flag}";

        return $this->cache->remember($cacheKey, 300, function () use ($flag, $user) {
            $feature = FeatureFlag::where('key', $flag)->first();

            if (!$feature || !$feature->enabled) {
                return false;
            }

            // Check gradual rollout
            if ($feature->rollout_percentage < 100 && $user) {

            }

            // Check user-specific overrides
            if ($user && in_array($user->id, $feature->included_users ?? [])) {
                return true;
            }

            if ($user && in_array($user->id, $feature->excluded_users ?? [])) {
                return false;
            }

            return true;
        });
    }

            ['key' => $flag],
            ['enabled' => true, 'rollout_percentage' => $rolloutPercentage]

        $this->cache->forget("feature_flag:{$flag}");
    }

    {
        FeatureFlag::where('key', $flag)->update(['enabled' => false]);
```

```php
// app/Services/TwoFactorAuthentication.php
class TwoFactorAuthentication
{
    public function generateSecret(User $user): array
    {
        $secret = $this->generateRandomSecret();

        $user->update([
            'two_factor_secret' => Crypt::encrypt($secret),
            'two_factor_enabled' => false,
        ]);

        return [
            'secret' => $secret,
            'qr_code' => $this->getQrCodeUrl($user, $secret),
            'recovery_codes' => $this->generateRecoveryCodes($user),
        ];
    }

    public function verify(User $user, string $code): bool
    {
        $secret = Crypt::decrypt($user->two_factor_secret);

        return TOTP::create($secret)->verify($code, now()->subSeconds(30));
    }

    public function enable(User $user, string $code): void
    {
        if (!$this->verify($user, $code)) {
            throw new Invalid2FACodeException();
        }

        $user->update(['two_factor_enabled' => true]);
    }

    public function verifyRecoveryCode(User $user, string $code): bool
    {
        $codes = $user->recovery_codes ?? [];
        $hashedCode = hash('sha256', $code);

        if (in_array($hashedCode, $codes)) {
            $codes = array_filter($codes, fn($c) => $c !== $hashedCode);
            $user->update(['recovery_codes' => array_values($codes)]);
            return true;
        }

        return false;
    }
}
```

## Notification Service

```php
// app/Services/AdminNotificationService.php
class AdminNotificationService
{
    public function send(string $type, array $data, string $priority = 'medium'): void
    {
        $admins = User::where('is_admin', true)->get();

        foreach ($admins as $admin) {
            if ($this->shouldNotify($admin, $type, $priority)) {
                $notification = match ($priority) {
                    'critical' => CriticalAdminNotification::class,
                    'high' => HighPriorityAdminNotification::class,
                    default => AdminNotification::class,
                };

                $notification::to($admin)->create($type, $data);
            }
        }
    }

    private function shouldNotify(User $admin, string $type, string $priority): bool
    {
        // Critical notifications always go through
        if ($priority === 'critical') return true;

        // Check admin notification preferences
        $preferences = $admin->notification_preferences ?? [];

        return $preferences[$type] ?? true;
    }
}
```

## Audit Middleware

```php
// app/Http/Middleware/AuditMiddleware.php
class AuditMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $response = $next($request);

        if ($request->isMethodUnsafe() && $response->getStatusCode() < 400) {
            $this->logRequest($request, $response);
        }

        return $response;
    }

    private function logRequest(Request $request, Response $response): void
    {
        AuditLog::create([
            'actor_id' => auth()->id(),
            'actor_type' => get_class(auth()->user()),
            'action' => $this->mapMethodToAction($request->method()),
            'subject_type' => $this->guessSubjectType($request),
            'subject_id' => $request->route('id'),
            'properties' => [
                'method' => $request->method(),
                'path' => $request->path(),
                'status' => $response->getStatusCode(),
                'input' => $this->sanitizeInput($request->all()),
            ],
        ]);
    }

    private function mapMethodToAction(string $method): string
    {
        return match ($method) {
            'POST' => 'create',
            'PUT', 'PATCH' => 'update',
            'DELETE' => 'delete',
            default => 'read',
        };
    }

    private function sanitizeInput(array $input): array
    {
        $sensitive = ['password', 'password_confirmation', 'token', 'secret'];

        return collect($input)
            ->mapWithKeys(fn($value, $key) => [
                $key => in_array($key, $sensitive) ? '[REDACTED]' : $value,
            ])
            ->toArray();
    }
}
```

# Admin Health Monitoring

## Health Check Endpoints

```php
// app/Http/Controllers/Admin/HealthController.php
class HealthController extends Controller
{
    public function check(): JsonResponse
    {
        $checks = [
            'database' => $this->checkDatabase(),
            'cache' => $this->checkCache(),
            'queue' => $this->checkQueue(),
            'storage' => $this->checkStorage(),
            'external_services' => $this->checkExternalServices(),
        ];

        $healthy = !in_array(false, array_column($checks, 'healthy'));

        return response()->json([
            'status' => $healthy ? 'healthy' : 'degraded',
            'checks' => $checks,
            'timestamp' => now()->toIso8601String(),
        ], $healthy ? 200 : 503);
    }

    private function checkDatabase(): array
    {
        try {
            DB::connection()->getPdo();
            return ['healthy' => true, 'latency_ms' => $this->measureQueryTime(fn() => DB::select('SELECT 1'))];
        } catch (\Exception $e) {
            return ['healthy' => false, 'error' => $e->getMessage()];
        }
    }

    private function checkCache(): array
    {
        try {
            Cache::put('health_check', true, 10);
            $value = Cache::get('health_check');
            return ['healthy' => $value === true];
        } catch (\Exception $e) {
            return ['healthy' => false, 'error' => $e->getMessage()];
        }
    }

    private function checkQueue(): array
    {
        try {
            $size = Queue::size();
            return [
                'healthy' => $size < 1000,
                'queue_size' => $size,
            ];
        } catch (\Exception $e) {
            return ['healthy' => false, 'error' => $e->getMessage()];
        }
    }

    private function checkStorage(): array
    {
        $free = disk_free_space(storage_path());
        $total = disk_total_space(storage_path());
        $percentUsed = (($total - $free) / $total) * 100;

        return [
            'healthy' => $percentUsed < 90,
            'percent_used' => round($percentUsed, 2),
            'free_gb' => round($free / 1024 / 1024 / 1024, 2),
        ];
    }

    private function checkExternalServices(): array
    {
        $services = [
            'stripe' => config('services.stripe.secret'),
            'postmark' => config('services.postmark.token'),
        ];

        $results = [];

        foreach ($services as $name => $key) {
            $results[$name] = ['healthy' => !empty($key)];
        }

        return $results;
    }
}
```

```php
// app/Services/AdminExportService.php
class AdminExportService
{
    public function exportUsers(array $filters, string $format = 'csv'): string
    {
        $users = User::query()
            ->applyFilters($filters)
            ->with(['subscription.plan', 'orders'])
            ->get();

        return match ($format) {
            'csv' => $this->exportCsv($users, [
                'id', 'name', 'email', 'status', 'created_at',
                'subscription_status', 'total_orders', 'total_spent',
            ]),
            'json' => $users->toJson(JSON_PRETTY_PRINT),
            'xlsx' => $this->exportExcel($users),
            default => throw new \InvalidArgumentException("Unsupported format: {$format}"),
        };
    }

    private function exportCsv(Collection $data, array $columns): string
    {
        $callback = function () use ($data, $columns) {
            $handle = fopen('php://output', 'w');

            // Header
            fputcsv($handle, $columns);

            // Rows
            foreach ($data as $row) {
                $values = array_map(fn($col) => data_get($row, $col), $columns);
                fputcsv($handle, $values);
            }

            fclose($handle);
        };

        return $callback();
    }

    public function scheduleExport(string $type, array $filters, string $format, User $user): void
    {
        $job = new ExportDataJob($type, $filters, $format, $user);
        dispatch($job);

        ExportStartedNotification::to($user)->queue($type);
    }
}
```

```php
// app/Console/Commands/AdminScheduledTasks.php
class AdminScheduledTasks extends Command
{
    protected $signature = 'admin:scheduled-tasks';

    public function handle(): void
    {
        // Daily tasks
        $this->dailyTasks();

        // Weekly tasks
        if (now()->dayOfWeek === Carbon::MONDAY) {
            $this->weeklyTasks();
        }

        // Monthly tasks
        if (now()->day === 1) {
            $this->monthlyTasks();
        }
    }

    private function dailyTasks(): void
    {
        // Clean up expired sessions
        Session::where('last_activity', '<', now()->subDays(7))->delete();

        // Archive old audit logs
        AuditLog::where('created_at', '<', now()->subMonths(6))
            ->chunkById(1000, fn($logs) => $logs->each->delete());

        // Check for suspicious activity
        app(SecurityMonitoringService::class)->runDailyChecks();

        // Generate daily report
        app(AdminReportService::class)->generateDailyReport();
    }

    private function weeklyTasks(): void
    {
        // Revoke expired tokens
        API_token::where('expires_at', '<', now())->delete();

        // Clean up abandoned carts
        CheckoutSession::where('status', 'active')
            ->where('created_at', '<', now()->subDays(7))
            ->update(['status' => 'expired']);

        // Generate weekly summary
        app(AdminReportService::class)->generateWeeklyReport();
    }

    private function monthlyTasks(): void
    {
        // Archive old data
        $this->archiveOldData();

        // Recalculate statistics
        app(RevenueService::class)->recalculateMonthlyStats();

        // Generate monthly report
        app(AdminReportService::class)->generateMonthlyReport();
    }
}
```

# Purpose

AI-powered theme generation allows users to create custom themes by describing their desired design. The system uses large language models to interpret natural language descriptions and generate complete, production-ready theme configurations including color palettes, typography, spacing, and component styles.

---

# Architecture Overview

The Theme Generator AI is a hybrid architecture combining server-side AI model integration with client-side preview and editing. The generation pipeline processes user input through multiple stages: natural language understanding, design token generation, CSS variable creation, and visual preview rendering.

The system is designed with a clear separation between the AI generation layer and the theme application layer. The AI produces structured design tokens that the theme engine interprets and applies to the Gsmui component library. This separation allows the AI model to be swapped or upgraded without affecting the theme application system.

The architecture supports both text-based and image-based inputs. Text descriptions are processed through prompt engineering that converts natural language to structured design specifications. Image uploads are analyzed for color palettes, patterns, and style characteristics using computer vision models.

## Prompt Engineering

### System Prompt

```text
You are an expert UI designer creating design systems for web applications.
Given a description, generate a complete theme with:

1. Color palette (primary, secondary, accent, neutral, semantic)
2. Typography (font families, sizes, weights, line heights)
3. Spacing scale (consistent unit-based system)
4. Border radius (consistent scale)
5. Shadows (elevation system)
6. Component-specific styles (buttons, inputs, cards)

Rules:
- Ensure WCAG AA contrast ratios (4.5:1 for normal text, 3:1 for large text)
- Use harmonious color relationships (complementary, analogous, triadic)
- Maintain consistent spacing using a 4px or 8px grid
- Provide semantic color variants (success, warning, danger)
- Consider dark mode compatibility
```

```php
    public function getTemplate(string $name): ?array

    }

    public function render(string $name, array $variables): array
    {
        $template = $this->getTemplate($name);
        if (!$template) {
            throw new TemplateNotFoundException($name);
        }

        return [
            'system' => $this->interpolate($template['system'], $variables),
            'user' => $this->interpolate($template['user'], $variables),
        ];
    }

    protected function interpolate(string $template, array $variables): string
    {
        return preg_replace_callback('/\{(\w+)\}/', function ($matches) use ($variables) {
            return $variables[$matches[1]] ?? $matches[0];
        }, $template);
    }
}
```

### Image Analysis Engine

```php
class ImageAnalysisEngine
{
    public function analyzeImage(string $imagePath): ImageAnalysis
    {
        $image = imagecreatefromstring(Storage::get($imagePath));

        $colors = $this->extractDominantColors($image, 5);
        $brightness = $this->calculateBrightness($image);
        $contrast = $this->calculateContrast($image);
        $saturation = $this->calculateSaturation($image);
        $temperature = $this->calculateTemperature($image);

        imagedestroy($image);

        return new ImageAnalysis(
            colors: $colors,
            brightness: $brightness,
            contrast: $contrast,
            saturation: $saturation,
            temperature: $temperature,
            is_dark: $brightness < 128,
            style: $this->inferStyle($brightness, $contrast, $saturation),
        );
    }

    protected function extractDominantColors($image, int $count): array
    {
        $width = imagesx($image);
        $height = imagesy($image);
        $colors = [];

        for ($y = 0; $y < $height; $y += 10) {
            for ($x = 0; $x < $width; $x += 10) {
                $rgb = imagecolorat($image, $x, $y);
                $r = ($rgb >> 16) & 0xFF;
                $g = ($rgb >> 8) & 0xFF;
                $b = $rgb & 0xFF;

                // Quantize to reduce color space
                $r = round($r / 32) * 32;
                $g = round($g / 32) * 32;
                $b = round($b / 32) * 32;

                $key = "{$r},{$g},{$b}";
                $colors[$key] = ($colors[$key] ?? 0) + 1;
            }
        }

        arsort($colors);

        return array_slice(array_keys($colors), 0, $count, true);
    }

    protected function inferStyle(float $brightness, float $contrast, float $saturation): string
    {
        if ($brightness < 80 && $contrast > 150) return 'dark-modern';
        if ($brightness > 200 && $saturation < 50) return 'minimal-light';
        if ($saturation > 150) return 'vibrant';
        if ($contrast < 80) return 'muted';
        return 'balanced';
    }
}
```

## Theme Validation Engine

### WCAG Compliance Checker

```php
class WcagComplianceChecker
{
    public function check(DesignTokens $tokens): WcagReport
    {
        $issues = [];
        $checks = 0;
        $passed = 0;

        // Check text contrast
        $textColors = ['text', 'text-secondary', 'text-muted'];
        $bgColors = ['bg', 'bg-secondary', 'bg-tertiary'];

        foreach ($textColors as $textColor) {
            foreach ($bgColors as $bgColor) {
                if (isset($tokens->colors[$textColor]) && isset($tokens->colors[$bgColor])) {
                    $checks++;
                    $ratio = $this->calculateContrastRatio(
                        $tokens->colors[$textColor],
                        $tokens->colors[$bgColor]
                    );

                    if ($ratio < 4.5) {
                        $issues[] = new WcagIssue(
                            'contrast',
                            'AA',
                            "{$textColor} on {$bgColor}: ratio {$ratio}:1 (minimum 4.5:1)",
                            'high'
                        );
                    } else {
                        $passed++;
                    }
                }
            }
        }

        // Check focus states
        if (empty($tokens->focus)) {
            $issues[] = new WcagIssue(
                'focus-visible',
                'AA',
                'No focus-visible styles defined',
                'high'
            );
        } else {
            $checks++;
            $passed++;
        }

        // Check color independence
        $checks++;
        if ($this->reliesOnlyOnColor($tokens)) {
            $issues[] = new WcagIssue(
                'color-independence',
                'AA',
                'Information conveyed through color alone',
                'medium'
            );
        } else {
            $passed++;
        }

        return new WcagReport(
            level: 'AA',
            total_checks: $checks,
            passed: $passed,
            issues: $issues,
            score: $checks > 0 ? round(($passed / $checks) * 100) : 0,
            is_compliant: empty($issues),
        );
    }

    public function calculateContrastRatio(string $color1, string $color2): float
    {
        $l1 = $this->getRelativeLuminance($color1);
        $l2 = $this->getRelativeLuminance($color2);

        $lighter = max($l1, $l2);
        $darker = min($l1, $l2);

        return ($lighter + 0.05) / ($darker + 0.05);
    }

    protected function getRelativeLuminance(string $hex): float
    {
        $rgb = $this->hexToRgb($hex);

        $r = $this->linearize($rgb['r'] / 255);
        $g = $this->linearize($rgb['g'] / 255);
        $b = $this->linearize($rgb['b'] / 255);

        return 0.2126 * $r + 0.7152 * $g + 0.0722 * $b;
    }

    protected function linearize(float $value): float
    {
        return $value <= 0.03928
            ? $value / 12.92
            : pow(($value + 0.055) / 1.055, 2.4);
    }

    protected function hexToRgb(string $hex): array
    {
        $hex = ltrim($hex, '#');
        return [
            'r' => hexdec(substr($hex, 0, 2)),
            'g' => hexdec(substr($hex, 2, 2)),
            'b' => hexdec(substr($hex, 4, 2)),
        ];
    }
}
```

```php
class ThemeExporter
{
    public function exportToTailwind(DesignTokens $tokens): string
    {
        $config = [
            'theme' => [
                'extend' => [
                    'colors' => $this->buildTailwindColors($tokens->colors),
                    'fontFamily' => $this->buildTailwindFonts($tokens->typography),
                    'fontSize' => $tokens->typography['fontSize'] ?? [],
                    'fontWeight' => $tokens->typography['fontWeight'] ?? [],
                    'borderRadius' => $tokens->borderRadius ?? [],
                    'boxShadow' => $tokens->shadows ?? [],
                    'spacing' => $this->buildSpacingScale($tokens->spacing),
                ],
            ],
        ];

        return "module.exports = " . var_export($config, true) . ";\n";
    }

    public function exportToCss(DesignTokens $tokens): string
    {
        $css = ":root {\n";

        // Colors
        foreach ($tokens->colors as $name => $value) {
            if (is_array($value)) {
                foreach ($value as $shade => $hex) {
                    $css .= "  --color-{$name}-{$shade}: {$hex};\n";
                }
            } else {
                $css .= "  --color-{$name}: {$value};\n";
            }
        }

        // Typography
        foreach ($tokens->typography as $property => $value) {
            if (is_array($value)) {
                foreach ($value as $key => $val) {
                    $css .= "  --font-{$property}-{$key}: {$val};\n";
                }
            }
        }

        // Spacing
        foreach ($tokens->spacing as $key => $value) {
            $css .= "  --spacing-{$key}: {$value};\n";
        }

        // Border radius
        foreach ($tokens->borderRadius as $key => $value) {
            $css .= "  --radius-{$key}: {$value};\n";
        }

        // Shadows
        foreach ($tokens->shadows as $key => $value) {
            $css .= "  --shadow-{$key}: {$value};\n";
        }

        $css .= "}\n";

        return $css;
    }

    public function exportToJson(DesignTokens $tokens): string
    {
        return json_encode($tokens->toArray(), JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES);
    }
}
```

```php
        return $published;
    }

    {
        $previewGenerator = app(ThemePreviewGenerator::class);

            'light' => $previewGenerator->generate($theme, 'light'),

            $path = Storage::disk('media')->put("themes/previews/{$published->id}/{$type}.png", $image);
            $published->previews[$type] = Storage::url($path);
        }

        $published->save();
    }
}
```

```php
class ColorHarmonyEngine
{
    public function generatePalette(string $baseColor, string $harmony): array
    {
        $hsl = $this->hexToHsl($baseColor);

        return match($harmony) {
            'complementary' => $this->complementary($hsl),
            'analogous' => $this->analogous($hsl),
            'triadic' => $this->triadic($hsl),
            'split-complementary' => $this->splitComplementary($hsl),
            'tetradic' => $this->tetradic($hsl),
            default => $this->monochromatic($hsl),
        };
    }

    protected function complementary(array $hsl): array
    {
        return [
            $this->hslToHex($hsl),
```

```php
class TypographyScaleGenerator
{
    public function generate(string $baseSize, string $scale): array
    {
        $ratios = [
            'minor-second' => 1.067,
            'major-second' => 1.125,
            'minor-third' => 1.2,
            'major-third' => 1.25,
            'perfect-fourth' => 1.333,
            'augmented-fourth' => 1.414,
            'perfect-fifth' => 1.5,
            'golden-ratio' => 1.618,
        ];

        $ratio = $ratios[$scale] ?? 1.25;
        $base = $this->parseSize($baseSize);

        $scale = [];
        $sizes = ['xs', 'sm', 'base', 'lg', 'xl', '2xl', '3xl', '4xl', '5xl'];

        foreach ($sizes as $index => $name) {
            $exponent = $index - 2; // base is at index 2
            $size = $base * pow($ratio, $exponent);
            $scale[$name] = round($size / 16, 4) . 'rem';
        }

        return $scale;
    }

    protected function parseSize(string $size): float
    {
        if (str_ends_with($size, 'rem')) {
            return (float) str_replace('rem', '', $size) * 16;
        }
        if (str_ends_with($size, 'px')) {
            return (float) str_replace('px', '', $size);
        }
        return (float) $size;
    }
```

```php
class StyleTransferEngine
{
    public function transfer(DesignTokens $source, DesignTokens $target, float $strength = 0.5): DesignTokens
    {
        $result = new DesignTokens();

        // Transfer colors with blending
        $result->colors = $this->blendColors($source->colors, $target->colors, $strength);

        // Transfer typography
        $result->typography = $this->blendTypography($source->typography, $target->typography, $strength);

        // Transfer spacing
        $result->spacing = $this->blendSpacing($source->spacing, $target->spacing, $strength);

        // Transfer border radius
        $result->borderRadius = $this->blendBorderRadius($source->borderRadius, $target->borderRadius, $strength);

        // Transfer shadows
        $result->shadows = $this->blendShadows($source->shadows, $target->shadows, $strength);

        return $result;
    }

    protected function blendColors(array $source, array $target, float $strength): array
    {
        $result = [];

        foreach ($target as $name => $value) {
            if (is_array($value)) {
                // Color scale (e.g., primary.50, primary.100, etc.)
                $result[$name] = [];
                foreach ($value as $shade => $hex) {
                    $sourceHex = $source[$name][$shade] ?? $hex;
                    $result[$name][$shade] = $this->blendHex($sourceHex, $hex, $strength);
                }
            } else {
                $sourceHex = $source[$name] ?? $hex;
                $result[$name] = $this->blendHex($sourceHex, $value, $strength);
            }
        }

        return $result;
    }

    protected function blendHex(string $source, string $target, float $strength): string
    {
        $sourceRgb = $this->hexToRgb($source);
        $targetRgb = $this->hexToRgb($target);

        $r = (int) round($sourceRgb['r'] * (1 - $strength) + $targetRgb['r'] * $strength);
        $g = (int) round($sourceRgb['g'] * (1 - $strength) + $targetRgb['g'] * $strength);
        $b = (int) round($sourceRgb['b'] * (1 - $strength) + $targetRgb['b'] * $strength);

        return sprintf('#%02x%02x%02x', $r, $g, $b);
    }
}
```

```php
        foreach ($dark->colors as $name => &$value) {

    {

                $hsl = $this->hexToHsl($value);
                $hsl[1] = min(50, $hsl[1] * 0.5); // Reduce saturation
                $hsl[2] = max(70, $hsl[2] * 1.3); // Increase lightness
                $value = $this->hslToHex($hsl);
            }
        }

        return $pastel;
    }
```

```php
class ThemeQualityMetrics
{
    public function calculate(Theme $theme): QualityMetrics
    {
        $tokens = $theme->getTokens();

        return new QualityMetrics([
            'color_harmony' => $this->scoreColorHarmony($tokens->colors),
            'typography_consistency' => $this->scoreTypographyConsistency($tokens->typography),
            'spacing_scale' => $this->scoreSpacingScale($tokens->spacing),
            'contrast_compliance' => $this->scoreContrastCompliance($tokens),
            'component_coverage' => $this->scoreComponentCoverage($tokens),
            'overall_score' => $this->calculateOverallScore($tokens),
        ]);
    }

    protected function scoreColorHarmony(array $colors): float
    {
        if (empty($colors)) return 0;

        $scores = [];
        foreach ($colors as $name => $value) {
            if (is_string($value) && str_starts_with($name, 'primary')) {
                // Check if colors follow harmonious relationships
                $scores[] = $this->evaluateColorRelationship($colors);
            }
        }

        return !empty($scores) ? array_sum($scores) / count($scores) : 50;
    }

    protected function scoreTypographyConsistency(array $typography): float
    {
        $score = 0;

        // Check font family consistency
        if (isset($typography['fontFamily'])) {
            $families = array_values($typography['fontFamily']);
            $uniqueFamilies = count(array_unique($families));
            $score += max(0, 100 - ($uniqueFamilies * 20));
        }

        // Check size scale
        if (isset($typography['fontSize'])) {
            $sizes = array_map('floatval', $typography['fontSize']);
            $ratios = [];
            for ($i = 1; $i < count($sizes); $i++) {
                $ratios[] = $sizes[$i] / $sizes[$i - 1];
            }
            $consistentRatios = count(array_unique(array_map('round', $ratios))) <= 2;
            $score += $consistentRatios ? 50 : 20;
        }

        return min(100, $score);
    }

    protected function scoreSpacingScale(array $spacing): float
    {
        if (empty($spacing)) return 0;

        $values = array_values($spacing);
        $ratios = [];

        for ($i = 1; $i < count($values); $i++) {
            $prev = (float) str_replace(['rem', 'px'], '', $values[$i - 1]);
            $curr = (float) str_replace(['rem', 'px'], '', $values[$i]);
            if ($prev > 0) {
                $ratios[] = $curr / $prev;
            }
        }

        if (empty($ratios)) return 50;

        // Check if ratios are consistent (within 0.1 of each other)
        $avgRatio = array_sum($ratios) / count($ratios);
        $deviations = array_map(fn($r) => abs($r - $avgRatio), $ratios);
        $maxDeviation = max($deviations);

        return max(0, 100 - ($maxDeviation * 100));
    }
}
```

```php
class ThemeComparator
{
    public function compare(Theme $theme1, Theme $theme2): ComparisonReport
    {
        $tokens1 = $theme1->getTokens();
        $tokens2 = $theme2->getTokens();

        return new ComparisonReport([
            'color_difference' => $this->compareColors($tokens1->colors, $tokens2->colors),
            'typography_difference' => $this->compareTypography($tokens1->typography, $tokens2->typography),
            'spacing_difference' => $this->compareSpacing($tokens1->spacing, $tokens2->spacing),
            'overall_similarity' => $this->calculateSimilarity($tokens1, $tokens2),
        ]);
    }

    protected function compareColors(array $colors1, array $colors2): array
    {
        $diff = [];

        foreach ($colors1 as $name => $value) {
            if (isset($colors2[$name])) {
                if (is_string($value) && is_string($colors2[$name])) {
                    $diff[$name] = $this->colorDistance($value, $colors2[$name]);
                }
            } else {
                $diff[$name] = ['status' => 'missing_in_theme2'];
            }
        }

        foreach ($colors2 as $name => $value) {
            if (!isset($colors1[$name])) {
                $diff[$name] = ['status' => 'missing_in_theme1'];
            }
        }

        return $diff;
    }

    protected function colorDistance(string $hex1, string $hex2): float
    {
        $rgb1 = $this->hexToRgb($hex1);
        $rgb2 = $this->hexToRgb($hex2);

        // Euclidean distance in RGB space
        return sqrt(
            pow($rgb1['r'] - $rgb2['r'], 2) +
            pow($rgb1['g'] - $rgb2['g'], 2) +
            pow($rgb1['b'] - $rgb2['b'], 2)
        );
    }
}
```

```php
        return new AccessibilityReport(
            theme_id: $theme->id,
            total_checks: $this->totalChecks,
            passed: $this->totalChecks - count($issues),
            issues: $issues,
            wcag_level: $this->determineWcagLevel($issues),
            score: $this->calculateScore($issues),
        );
    }

    protected function checkColorContrast(DesignTokens $tokens): array
    {
        $issues = [];
        $textColors = ['text', 'text-secondary'];
        $bgColors = ['bg', 'bg-secondary'];

        foreach ($textColors as $textColor) {
            foreach ($bgColors as $bgColor) {
                if (isset($tokens->colors[$textColor]) && isset($tokens->colors[$bgColor])) {
                    $ratio = $this->getContrastRatio(
                        $tokens->colors[$textColor],
                        $tokens->colors[$bgColor]
                    );

                    if ($ratio < 4.5) {
                        $issues[] = new AccessibilityIssue(
                            'contrast',
                            "Low contrast between {$textColor} and {$bgColor}: {$ratio}:1",
                            'high'
                        );
                    }
                }
            }
        }

        return $issues;
    }
}
```

```php
        try {

            foreach ($fallbackModels as $model) {
                try {
                    return $this->generateWithModel($model, $prompt, $options);
                } catch (\Exception $e) {

                }
            }

            throw new AllModelsFailedException('All AI models failed to generate theme');
        }

    {
        $provider = $this->models[$model]['provider'];

            'openai' => $this->generateWithOpenAi($prompt, $options),
            'anthropic' => $this->generateWithAnthropic($prompt, $options),
            'google' => $this->generateWithGoogle($prompt, $options),
        };
```

```php
class ThemeQualityScorer
{
    public function score(DesignTokens $tokens): QualityReport
    {
        $scores = [
            'color_harmony' => $this->scoreColorHarmony($tokens->colors),
            'typography' => $this->scoreTypography($tokens->typography),
            'spacing' => $this->scoreSpacing($tokens->spacing),
            'contrast' => $this->scoreContrast($tokens),
            'consistency' => $this->scoreConsistency($tokens),
        ];

        $weightedScore = ($scores['color_harmony'] * 0.25) +
                         ($scores['typography'] * 0.25) +
                         ($scores['spacing'] * 0.2) +
                         ($scores['contrast'] * 0.2) +
                         ($scores['consistency'] * 0.1);

        return new QualityReport(
            total_score: $weightedScore,
            category_scores: $scores,
            grade: $this->getGrade($weightedScore),
            suggestions: $this->generateSuggestions($tokens, $scores),
        );
    }

    protected function scoreColorHarmony(array $colors): float
    {
        if (empty($colors)) return 0;

        $primaryColor = $colors['primary'] ?? null;
        if (!$primaryColor) return 50;

        $harmonyScore = 0;

        // Check if colors are from the same family
        $primaryHsl = $this->hexToHsl(is_array($primaryColor) ? $primaryColor['500'] ?? reset($primaryColor) : $primaryColor);

        foreach ($colors as $name => $value) {
            if (is_array($value)) {
                foreach ($value as $shade => $hex) {
                    $hsl = $this->hexToHsl($hex);
                    $hueDifference = abs($primaryHsl[0] - $hsl[0]);
                    if ($hueDifference < 30 || $hueDifference > 330) {
                        $harmonyScore += 2;
                    }
                }
            }
        }

        return min(100, $harmonyScore);
    }

    protected function getGrade(float $score): string
    {
        return match(true) {
            $score >= 90 => 'A+',
            $score >= 80 => 'A',
            $score >= 70 => 'B',
            $score >= 60 => 'C',
            $score >= 50 => 'D',
            default => 'F',
        };
    }
}
```

```php
class ThemeReviewManager
{
    public function addReview(Theme $theme, User $user, array $data): ThemeReview
    {
        $existing = ThemeReview::where('theme_id', $theme->id)
            ->where('user_id', $user->id)
            ->first();

        if ($existing) {
            throw new AlreadyReviewedException();
        }

        $review = ThemeReview::create([
            'theme_id' => $theme->id,
            'user_id' => $user->id,
            'rating' => $data['rating'],
            'title' => $data['title'] ?? null,
            'content' => $data['content'] ?? null,
        ]);

        $this->updateThemeRating($theme);

        return $review;
    }

    protected function updateThemeRating(Theme $theme): void
    {
        $stats = ThemeReview::where('theme_id', $theme->id)
            ->selectRaw('AVG(rating) as avg_rating, COUNT(*) as count')
            ->first();

        $theme->update([
            'rating' => round($stats->avg_rating, 1),
            'rating_count' => $stats->count,
        ]);
    }
}
```

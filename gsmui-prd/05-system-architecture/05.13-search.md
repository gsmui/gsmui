# Purpose

Search is a core feature of GsmUi. Developers should be able to locate any component, documentation page, template, theme, blog article, or showcase project within milliseconds.

The search architecture provides:

* Full-text search
* Autocomplete
* Faceted filtering
* Ranking
* Typo tolerance
* Version-aware documentation
* Incremental indexing
* Near real-time updates

## Query Sanitization

Remove potentially dangerous or useless input.

Rules:

* Strip HTML tags
* Remove special characters (keep alphanumeric, spaces, hyphens)
* Trim whitespace
* Limit query length (max 200 characters)
* Remove null bytes
* Normalize Unicode

```php id="ssanit01"
function sanitizeQuery(string $query): string
{
    $query = strip_tags($query);
    $query = preg_replace('/[^\w\s\-]/', '', $query);
    $query = trim($query);
    $query = mb_substr($query, 0, 200);
    $query = mb_strtolower($query, 'UTF-8');

    return $query;
}
```

## Reindexing Strategies

### Full Reindex

Rebuild entire index from scratch.

When to use:

* Schema changes
* Ranking rule changes
* Data corruption
* Major version upgrades

```bash id="sreidx01"
php artisan scout:import "App\Models\Component"
php artisan scout:import "App\Models\DocumentationPage"
php artisan scout:import "App\Models\Theme"
```

### Incremental Reindex

Update only changed records.

Triggered by:

* Model created
* Model updated
* Model deleted

```php id="sreidx02"
// Automatic via Scout
class Component extends Model
{
    use Searchable;

    public function toSearchableArray(): array
    {
        return [
            'id' => $this->id,
            'title' => $this->name,
            'description' => $this->description,
            'category' => $this->category->name,
            'popularity' => $this->popularity_score,
            'downloads' => $this->download_count,
        ];
    }
}
```

### Partial Reindex

Update specific fields only.

```php id="sreidx03"
$client->index('gsmui_components')->updateDocuments([
    [
        'id' => 42,
        'downloads' => 1500,
        'popularity' => 85,
    ]
]);
```

## Search Performance Optimization

### Query Optimization

| Technique | Description | Impact |
|-----------|-------------|--------|
| Field weighting | Prioritize title matches | +20% relevance |
| Stop words | Remove noise | -30% index size |
| Prefix search | Faster autocomplete | -50% response time |
| Typo tolerance | Handle errors | +40% recall |
| Pagination | Limit result sets | Consistent latency |

### Index Optimization

| Technique | Description | Impact |
|-----------|-------------|--------|
| Attribute ordering | Most searchable first | Faster queries |
| Filtered search | Pre-filter large indexes | -60% query time |
| Sort optimization | Indexed sort attributes | Avoid in-memory sort |
| Facet caching | Cache facet counts | -80% facet time |

### Infrastructure Optimization

| Technique | Description | Impact |
|-----------|-------------|--------|
| Dedicated instance | No resource contention | Consistent latency |
| Memory allocation | Sufficient RAM for index | Avoid disk swaps |
| Connection pooling | Reuse connections | -20% overhead |
| Query caching | Cache frequent queries | -90% repeat query time |

class SearchDocumentValidator
{
    public function validateComponent(array $document): bool
    {
        return isset($document['id'])
            && isset($document['title'])
            && isset($document['type'])
            && is_string($document['title'])
            && strlen($document['title']) > 0
            && strlen($document['title']) <= 500;

## Search Error Handling

### Degraded Mode

When Meilisearch is unavailable.

```text id="serr01"
Meilisearch Down
   │
   ▼
Log Error
   │
   ▼
Enable MySQL Fallback
   │
   ▼
Use LIKE Queries
   │
   ▼
Serve Results (Reduced Relevance)
   │
   ▼
Notify Admin
   │
   ▼
Retry Connection (Backoff)
```

### Common Errors

| Error | Cause | Response |
|-------|-------|----------|
| Connection refused | Meilisearch down | Fallback to MySQL |
| Timeout | Query too complex | Simplify query, retry |
| Index not found | Missing index | Create index, reindex |
| Rate limited | Too many queries | Queue requests |
| Invalid query | Malformed input | Sanitize and retry |

## Query Operations

| Operation | Description | Example |
|-----------|-------------|---------|
| Exact match | Match exact term | title = "Button" |
| Prefix match | Match prefix | title = "But*" |
| Fuzzy match | Allow typos | title = "Boton~1" |
| Boolean AND | All terms must match | title AND category |
| Boolean OR | Any term matches | title OR description |
| Range query | Value in range | downloads > 100 |
| Faceted filter | Filter by facet | category = "Forms" |
| Wildcard | Match any character | title = "butt*" |
| Phrase match | Exact phrase | title = "button component" |
| Exclude | Negate term | NOT category = "archived" |

## Ranking Operations

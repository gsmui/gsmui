# Data Flow

Backup and disaster recovery data flows follow the same path as production data but in reverse—restoring from storage to database and application state.

## Backup Data Flow

`
Production Database (MySQL Primary)
    │
    ├── Daily Full Backup (mysqldump)
    │       └── Compressed archive ──> S3 Standard (30-day retention)
    │
    ├── Transaction Log Backups (every 5 min)
    │       └── Binary log shipping ──> S3 Standard (24-hour retention)
    │
    └── Incremental Backups (hourly)
            └── Changed pages only ──> S3 Standard (7-day retention)

File Storage
    │
    ├── User Uploads ──> S3 Cross-Region Replication
    ├── Component Assets ──> S3 Cross-Region Replication
    └── Documentation Assets ──> S3 Cross-Region Replication

Configuration
    │
    ├── .env files ──> Encrypted vault (HashiCorp Vault / AWS Secrets Manager)
    ├── Migrations ──> Git repository (version controlled)
    └── Seed data ──> Git repository (version controlled)
`

## Recovery Data Flow

`
Disaster Declared
    │
    ├── Step 1: Assess scope
    │       └── Which services affected? Which data lost?
    │
    ├── Step 2: Restore database
    │       ├── Download latest full backup from S3
    │       ├── Apply transaction logs up to point of failure
    │       └── Verify data integrity (checksums, row counts)
    │
    ├── Step 3: Restore files
    │       ├── Sync from S3 cross-region replica
    │       └── Verify file integrity (checksums)
    │
    ├── Step 4: Restore configuration
    │       ├── Decrypt environment variables
    │       └── Apply migration state
    │
    ├── Step 5: Bring services online
    │       ├── Start web servers
    │       ├── Start queue workers
    │       ├── Start cache (Redis)
    │       └── Verify health checks
    │
    └── Step 6: Validate
            ├── Run smoke tests
            ├── Check data integrity
            └── Monitor for errors
`

# Conclusion

The GsmUi backup and disaster recovery strategy ensures business continuity through a multi-layered approach: daily full backups, 5-minute transaction log shipping, cross-region file replication, and encrypted configuration vaults.

Key architectural decisions:

1. **30-day retention with point-in-time recovery**: Transaction logs enable restoration to any point within the last 24 hours; full backups provide weekly checkpoints for the full 30-day window.
2. **RTO of 1 hour, RPO of 5 minutes**: Critical services can be restored within one hour; data loss is limited to at most 5 minutes of transactions.
3. **Encrypted backups with Vault-managed keys**: All backup data is encrypted at rest and in transit, with keys managed through HashiCorp Vault.
4. **Regular DR drills**: Monthly restore tests validate that backups are viable and recovery procedures work as documented.

The system balances recovery capability against cost by using tiered storage (S3 Standard for 30 days, S3 Glacier for long-term) and automated verification to catch backup corruption before it is needed.

# Risk

Disaster recovery carries inherent risks that could result in data loss, extended downtime, or compliance violations.

## Risk Register

| Risk ID | Risk Description | Probability | Impact | Mitigation | Owner |
|---------|-----------------|-------------|--------|------------|-------|
| DR-001 | Backup corruption discovered only during restore | Low | Critical | Automated checksum verification after every backup; monthly restore tests | DevOps |
| DR-002 | Transaction log gap creates unrecoverable window | Low | Critical | Monitor log shipping lag; alert if gap exceeds 10 minutes | DBA |
| DR-003 | S3 cross-region replication fails silently | Medium | High | Daily replication health check; alert on replica age > 1 hour | DevOps |
| DR-004 | DR drill takes longer than RTO target | Medium | High | Run quarterly drills; refine procedures based on drill results | Platform Lead |
| DR-005 | Encryption key unavailable during restore | Low | Critical | Store Vault unseal keys in separate geographic locations | Security |
| DR-006 | Backup storage costs spiral due to data growth | Medium | Medium | Implement lifecycle policies; compress backups; review monthly | Finance |
| DR-007 | Restore from backup reveals data integrity issues | Low | Critical | Verify checksums and row counts before declaring restore complete | DBA |
| DR-008 | Team unfamiliar with DR procedures during real incident | Medium | High | Quarterly drills with rotated team leads; documented runbooks | Engineering Manager |

## Risk Response Strategies

### Avoid
- Never store backup credentials in the same region as backup data.
- Never skip transaction log backups; maintain continuous shipping.

### Mitigate
- Implement automated backup verification with checksum and row-count validation.
- Run DR drills in isolated environments that mirror production exactly.
- Maintain runbooks with step-by-step procedures for every restore scenario.

### Transfer
- Use AWS S3 with Cross-Region Replication for durable, managed backup storage.
- Use HashiCorp Vault for encryption key management with geographic distribution.

### Accept
- Accept that restoring from a backup 24+ hours old may result in some data loss beyond the 5-minute RPO for file-level changes.
- Accept that a full DR restore may require manual DNS propagation time (up to 15 minutes).

# Backup Automation

## Automated Backup Pipeline

The backup system runs on a fully automated pipeline that handles daily full backups, hourly incremental backups, and continuous transaction log shipping. No manual intervention is required for normal operations.

```php
<?php

namespace App\Backup\Pipeline;

use App\Backup\Models\BackupJob;
use App\Backup\Models\BackupSet;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\File;
use Illuminate\Support\Facades\Storage;

class BackupPipeline
{
    private string $tempPath;
    private string $archivePath;

    public function __construct()
    {
        $this->tempPath = storage_path('app/backups/temp');
        $this->archivePath = storage_path('app/backups/archives');

        $this->ensureDirectories();
    }

    public function runFullBackup(): BackupSet
    {
        $job = BackupJob::create([
            'type' => 'full',
            'status' => 'running',
            'started_at' => now(),
        ]);

        try {
            $dumpPath = $this->dumpDatabase();
            $filesPath = $this->backupFiles();
            $configPath = $this->backupConfig();

            $archivePath = $this->createArchive([
                'database' => $dumpPath,
                'files' => $filesPath,
                'config' => $configPath,
            ]);

            $checksum = hash_file('sha256', $archivePath);
            $size = filesize($archivePath);

            $storagePath = $this->uploadToStorage($archivePath, 'full');

            $backupSet = BackupSet::create([
                'job_id' => $job->id,
                'type' => 'full',
                'storage_path' => $storagePath,
                'checksum' => $checksum,
                'size_bytes' => $size,
                'completed_at' => now(),
            ]);

            $job->update([
                'status' => 'completed',
                'completed_at' => now(),
                'backup_set_id' => $backupSet->id,
            ]);

            $this->cleanup();

            return $backupSet;
        } catch (\Throwable $e) {
            $job->update([
                'status' => 'failed',
                'error_message' => $e->getMessage(),
                'completed_at' => now(),
            ]);

            throw $e;
        }
    }

    public function runIncrementalBackup(): BackupSet
    {
        $job = BackupJob::create([
            'type' => 'incremental',
            'status' => 'running',
            'started_at' => now(),
        ]);

        try {
            $lastBackup = BackupSet::where('type', 'full')
                ->latest('completed_at')
                ->first();

            $changedData = $this->getChangedDataSince(
                $lastBackup?->completed_at ?? now()->subDay()
            );

            $dumpPath = $this->dumpChangedData($changedData);

            $archivePath = $this->createArchive([
                'incremental' => $dumpPath,
            ]);

            $checksum = hash_file('sha256', $archivePath);
            $size = filesize($archivePath);

            $storagePath = $this->uploadToStorage($archivePath, 'incremental');

            $backupSet = BackupSet::create([
                'job_id' => $job->id,
                'type' => 'incremental',
                'parent_backup_id' => $lastBackup?->id,
                'storage_path' => $storagePath,
                'checksum' => $checksum,
                'size_bytes' => $size,
                'completed_at' => now(),
            ]);

            $job->update([
                'status' => 'completed',
                'completed_at' => now(),
                'backup_set_id' => $backupSet->id,
            ]);

            $this->cleanup();

            return $backupSet;
        } catch (\Throwable $e) {
            $job->update([
                'status' => 'failed',
                'error_message' => $e->getMessage(),
                'completed_at' => now(),
            ]);

            throw $e;
        }
    }

    public function shipTransactionLogs(): void
    {
        $binlogDir = config('database.connections.mysql.binary_log_dir', '/var/lib/mysql');

        if (!is_dir($binlogDir)) {
            return;
        }

        $lastPosition = cache()->get('backup:binlog:position', 0);

        $logFiles = collect(File::files($binlogDir))
            ->filter(fn($file) => str_starts_with($file->getFilename(), 'mysql-bin'))
            ->sortBy('filename');

        foreach ($logFiles as $logFile) {
            $logPath = $logFile->getRealPath();
            $logSize = $logFile->getSize();

            if ($logSize === 0) {
                continue;
            }

            $storagePath = "transaction-logs/{$logFile->getFilename()}";
            $contents = file_get_contents($logPath);

            Storage::disk('backups')->put($storagePath, $contents);

            cache()->put('backup:binlog:position', $logSize, now()->addHours(24));
        }
    }

    private function dumpDatabase(): string
    {
        $outputPath = "{$this->tempPath}/database_" . date('Y-m-d_His') . ".sql";

        $command = sprintf(
            'mysqldump --host=%s --user=%s --password=%s --single-transaction --routines --triggers --events %s > %s 2>&1',
            escapeshellarg(config('database.connections.mysql.host')),
            escapeshellarg(config('database.connections.mysql.username')),
            escapeshellarg(config('database.connections.mysql.password')),
            escapeshellarg(config('database.connections.mysql.database')),
            escapeshellarg($outputPath)
        );

        exec($command, $output, $returnCode);

        if ($returnCode !== 0) {
            throw new \RuntimeException("Database dump failed: " . implode("\n", $output));
        }

        return $outputPath;
    }

    private function backupFiles(): string
    {
        $outputPath = "{$this->tempPath}/files_" . date('Y-m-d_His') . ".tar.gz";

        $directories = [
            'public/uploads',
            'storage/app/public',
            'resources/views',
        ];

        $existingDirs = array_filter(
            array_map(fn($dir) => base_path($dir), $directories),
            'is_dir'
        );

        if (empty($existingDirs)) {
            file_put_contents($outputPath, '');
            return $outputPath;
        }

        $command = sprintf(
            'tar -czf %s -C %s %s 2>&1',
            escapeshellarg($outputPath),
            escapeshellarg(base_path()),
            implode(' ', array_map(fn($dir) => escapeshellarg(basename($dir)), $existingDirs))
        );

        exec($command, $output, $returnCode);

        if ($returnCode !== 0) {
            throw new \RuntimeException("File backup failed: " . implode("\n", $output));
        }

        return $outputPath;
    }

    private function backupConfig(): string
    {
        $outputPath = "{$this->tempPath}/config_" . date('Y-m-d_His') . ".tar.gz";

        $configFiles = [
            '.env',
            'config/gsmui.php',
            'config/gsmui-pro.php',
            'composer.json',
            'package.json',
        ];

        $existingFiles = array_filter(
            array_map(fn($file) => base_path($file), $configFiles),
            'file_exists'
        );

        if (empty($existingFiles)) {
            file_put_contents($outputPath, '');
            return $outputPath;
        }

        $command = sprintf(
            'tar -czf %s -C %s %s 2>&1',
            escapeshellarg($outputPath),
            escapeshellarg(base_path()),
            implode(' ', array_map(fn($file) => escapeshellarg(basename($file)), $existingFiles))
        );

        exec($command, $output, $returnCode);

        if ($returnCode !== 0) {
            throw new \RuntimeException("Config backup failed: " . implode("\n", $output));
        }

        return $outputPath;
    }

    private function createArchive(array $parts): string
    {
        $archiveName = "backup_" . date('Y-m-d_His') . ".tar.gz";
        $archivePath = "{$this->archivePath}/{$archiveName}";

        $command = sprintf(
            'tar -czf %s -C %s %s 2>&1',
            escapeshellarg($archivePath),
            escapeshellarg($this->tempPath),
            implode(' ', array_map(fn($file) => escapeshellarg(basename($file)), $parts))
        );

        exec($command, $output, $returnCode);

        if ($returnCode !== 0) {
            throw new \RuntimeException("Archive creation failed: " . implode("\n", $output));
        }

        return $archivePath;
    }

    private function uploadToStorage(string $archivePath, string $type): string
    {
        $filename = basename($archivePath);
        $storagePath = "{$type}/{$filename}";

        $contents = file_get_contents($archivePath);
        Storage::disk('backups')->put($storagePath, $contents);

        return $storagePath;
    }

    private function getChangedDataSince(\Carbon\Carbon $since): array
    {
        $tables = DB::select('SHOW TABLES');
        $dbName = DB::getDatabaseName();
        $changed = [];

        foreach ($tables as $table) {
            $tableName = $table->{"Tables_in_{$dbName}"} ?? reset($table);

            if ($this->tableHasTimestamp($tableName)) {
                $lastModified = DB::table($tableName)
                    ->max('updated_at');

                if ($lastModified && $lastModified->greaterThan($since)) {
                    $changed[] = $tableName;
                }
            }
        }

        return $changed;
    }

    private function dumpChangedData(array $tables): string
    {
        $outputPath = "{$this->tempPath}/incremental_" . date('Y-m-d_His') . ".sql";

        $dump = "-- Incremental Backup\n";
        $dump .= "-- Date: " . date('Y-m-d H:i:s') . "\n\n";

        foreach ($tables as $tableName) {
            $dump .= "-- Table: {$tableName}\n";
            $rows = DB::table($tableName)->get();

            foreach ($rows as $row) {
                $values = array_map(function ($value) {
                    if (is_null($value)) return 'NULL';
                    if (is_bool($value)) return $value ? '1' : '0';
                    return "'" . addslashes($value) . "'";
                }, (array) $row);

                $dump .= "REPLACE INTO `{$tableName}` VALUES (" . implode(', ', $values) . ");\n";
            }

            $dump .= "\n";
        }

        file_put_contents($outputPath, $dump);

        return $outputPath;
    }

    private function tableHasTimestamp(string $tableName): bool
    {
        $columns = DB::select("SHOW COLUMNS FROM `{$tableName}`");
        return collect($columns)->contains('Field', 'updated_at');
    }

    private function ensureDirectories(): void
    {
        foreach ([$this->tempPath, $this->archivePath] as $path) {
            if (!is_dir($path)) {
                mkdir($path, 0755, true);
            }
        }
    }

    private function cleanup(): void
    {
        $files = File::files($this->tempPath);
        foreach ($files as $file) {
            if ($file->getMTime() < now()->subHours(24)->timestamp) {
                File::delete($file->getRealPath());
            }
        }
    }
}
```

# Restore Procedures

## Point-in-Time Recovery

```php
<?php

namespace App\Backup\Recovery;

use App\Backup\Models\BackupSet;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\File;
use Illuminate\Support\Facades\Storage;

class PointInTimeRecovery
{
    private string $tempPath;

    public function __construct()
    {
        $this->tempPath = storage_path('app/backups/restore_temp');

        if (!is_dir($this->tempPath)) {
            mkdir($this->tempPath, 0755, true);
        }
    }

    public function restoreToPointInTime(\Carbon\Carbon $targetTime): array
    {
        $steps = [];
        $startTime = microtime(true);

        $steps[] = $this->validateRestorePoint($targetTime);

        $fullBackup = $this->findFullBackupBefore($targetTime);
        $steps[] = ['step' => 'Find full backup', 'result' => $fullBackup ? 'found' : 'not_found'];

        if (!$fullBackup) {
            throw new \RuntimeException("No full backup found before {$targetTime->toIso8601String()}");
        }

        $steps[] = $this->restoreFromBackup($fullBackup);

        $incrementalBackups = $this->findIncrementalBackupsBetween($fullBackup, $targetTime);
        foreach ($incrementalBackups as $incremental) {
            $steps[] = $this->restoreFromBackup($incremental);
        }

        $transactionLogs = $this->findTransactionLogsBetween($fullBackup, $targetTime);
        foreach ($transactionLogs as $log) {
            $steps[] = $this->applyTransactionLog($log);
        }

        $steps[] = $this->verifyIntegrity();

        $duration = microtime(true) - $startTime;

        return [
            'target_time' => $targetTime->toIso8601String(),
            'full_backup' => $fullBackup->storage_path,
            'incremental_backups' => count($incrementalBackups),
            'transaction_logs' => count($transactionLogs),
            'steps' => $steps,
            'duration_seconds' => round($duration, 2),
            'status' => 'completed',
        ];
    }

    public function restoreFromBackupSet(BackupSet $backupSet): array
    {
        $startTime = microtime(true);

        $archivePath = $this->downloadBackup($backupSet);

        $this->verifyChecksum($archivePath, $backupSet->checksum);

        $extractedPath = $this->extractArchive($archivePath);

        $this->restoreDatabase("{$extractedPath}/database.sql");
        $this->restoreFiles("{$extractedPath}/files");

        $this->cleanup($extractedPath, $archivePath);

        $duration = microtime(true) - $startTime;

        return [
            'backup_id' => $backupSet->id,
            'type' => $backupSet->type,
            'duration_seconds' => round($duration, 2),
            'status' => 'completed',
        ];
    }

    private function validateRestorePoint(\Carbon\Carbon $targetTime): array
    {
        $latestBackup = BackupSet::latest('completed_at')->first();

        if (!$latestBackup) {
            throw new \RuntimeException("No backups available for restore");
        }

        if ($targetTime->greaterThan(now())) {
            throw new \InvalidArgumentException("Cannot restore to a future time");
        }

        if ($targetTime->lessThan($latestBackup->completed_at->subDays(30))) {
            throw new \InvalidArgumentException("Restore point is beyond 30-day retention");
        }

        return ['step' => 'Validate restore point', 'result' => 'valid'];
    }

    private function findFullBackupBefore(\Carbon\Carbon $time): ?BackupSet
    {
        return BackupSet::where('type', 'full')
            ->where('completed_at', '<=', $time)
            ->latest('completed_at')
            ->first();
    }

    private function findIncrementalBackupsBetween(BackupSet $after, \Carbon\Carbon $before): \Illuminate\Support\Collection
    {
        return BackupSet::where('type', 'incremental')
            ->where('parent_backup_id', $after->id)
            ->where('completed_at', '>', $after->completed_at)
            ->where('completed_at', '<=', $before)
            ->orderBy('completed_at')
            ->get();
    }

    private function findTransactionLogsBetween(BackupSet $after, \Carbon\Carbon $before): array
    {
        $logDir = storage_path('app/backups/transaction-logs');

        if (!is_dir($logDir)) {
            return [];
        }

        return collect(File::files($logDir))
            ->filter(fn($file) => $file->getMTime() > $after->completed_at->timestamp
                && $file->getMTime() <= $before->timestamp)
            ->sortBy('filename')
            ->toArray();
    }

    private function restoreFromBackup(BackupSet $backupSet): array
    {
        $archivePath = $this->downloadBackup($backupSet);
        $extractedPath = $this->extractArchive($archivePath);

        if (file_exists("{$extractedPath}/database.sql")) {
            $this->restoreDatabase("{$extractedPath}/database.sql");
        }

        if (is_dir("{$extractedPath}/files")) {
            $this->restoreFiles("{$extractedPath}/files");
        }

        $this->cleanup($extractedPath, $archivePath);

        return ['step' => "Restore from {$backupSet->type} backup", 'result' => 'success'];
    }

    private function applyTransactionLog(string $logPath): array
    {
        $command = sprintf(
            'mysql --host=%s --user=%s --password=%s %s < %s 2>&1',
            escapeshellarg(config('database.connections.mysql.host')),
            escapeshellarg(config('database.connections.mysql.username')),
            escapeshellarg(config('database.connections.mysql.password')),
            escapeshellarg(config('database.connections.mysql.database')),
            escapeshellarg($logPath)
        );

        exec($command, $output, $returnCode);

        if ($returnCode !== 0) {
            throw new \RuntimeException("Transaction log apply failed: " . implode("\n", $output));
        }

        return ['step' => 'Apply transaction log', 'result' => 'success'];
    }

    private function downloadBackup(BackupSet $backupSet): string
    {
        $filename = basename($backupSet->storage_path);
        $localPath = "{$this->tempPath}/{$filename}";

        $contents = Storage::disk('backups')->get($backupSet->storage_path);
        file_put_contents($localPath, $contents);

        return $localPath;
    }

    private function verifyChecksum(string $path, string $expectedChecksum): void
    {
        $actualChecksum = hash_file('sha256', $path);

        if ($actualChecksum !== $expectedChecksum) {
            throw new \RuntimeException("Checksum mismatch: expected {$expectedChecksum}, got {$actualChecksum}");
        }
    }

    private function extractArchive(string $archivePath): string
    {
        $extractPath = "{$this->tempPath}/extracted_" . time();

        if (!is_dir($extractPath)) {
            mkdir($extractPath, 0755, true);
        }

        $command = sprintf(
            'tar -xzf %s -C %s 2>&1',
            escapeshellarg($archivePath),
            escapeshellarg($extractPath)
        );

        exec($command, $output, $returnCode);

        if ($returnCode !== 0) {
            throw new \RuntimeException("Archive extraction failed: " . implode("\n", $output));
        }

        return $extractPath;
    }

    private function restoreDatabase(string $sqlPath): void
    {
        $command = sprintf(
            'mysql --host=%s --user=%s --password=%s %s < %s 2>&1',
            escapeshellarg(config('database.connections.mysql.host')),
            escapeshellarg(config('database.connections.mysql.username')),
            escapeshellarg(config('database.connections.mysql.password')),
            escapeshellarg(config('database.connections.mysql.database')),
            escapeshellarg($sqlPath)
        );

        exec($command, $output, $returnCode);

        if ($returnCode !== 0) {
            throw new \RuntimeException("Database restore failed: " . implode("\n", $output));
        }
    }

    private function restoreFiles(string $filesPath): void
    {
        $mapping = [
            'uploads' => 'public/uploads',
            'storage-public' => 'storage/app/public',
            'views-custom' => 'resources/views',
        ];

        foreach ($mapping as $archiveDir => $appDir) {
            $sourceDir = "{$filesPath}/{$archiveDir}";
            $destDir = base_path($appDir);

            if (is_dir($sourceDir)) {
                $command = sprintf(
                    'cp -r %s/* %s/ 2>&1',
                    escapeshellarg($sourceDir),
                    escapeshellarg($destDir)
                );

                exec($command, $output, $returnCode);

                if ($returnCode !== 0) {
                    throw new \RuntimeException("File restore failed for {$appDir}: " . implode("\n", $output));
                }
            }
        }
    }

    private function verifyIntegrity(): array
    {
        $checks = [];

        try {
            DB::select('SELECT 1');
            $checks['database'] = 'ok';
        } catch (\Throwable $e) {
            $checks['database'] = 'failed: ' . $e->getMessage();
        }

        $requiredDirs = ['public/uploads', 'storage/app/public'];
        foreach ($requiredDirs as $dir) {
            $checks["dir_{$dir}"] = is_dir(base_path($dir)) ? 'ok' : 'missing';
        }

        return ['step' => 'Verify integrity', 'result' => $checks];
    }

    private function cleanup(string $extractPath, string $archivePath): void
    {
        if (is_dir($extractPath)) {
            File::deleteDirectory($extractPath);
        }

        if (file_exists($archivePath)) {
            File::delete($archivePath);
        }
    }
```

```php
<?php

namespace App\Backup\Verification;

use App\Backup\Models\BackupSet;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\File;
use Illuminate\Support\Facades\Storage;

class BackupVerifier
{
    public function verify(BackupSet $backupSet): array
    {
        $results = [
            'backup_id' => $backupSet->id,
            'checks' => [],
            'passed' => true,
            'verified_at' => now()->toIso8601String(),
        ];

        $results['checks'][] = $this->verifyFileExists($backupSet);
        $results['checks'][] = $this->verifyChecksum($backupSet);
        $results['checks'][] = $this->verifyFileSize($backupSet);
        $results['checks'][] = $this->verifyExtractable($backupSet);

        if ($backupSet->type === 'full') {
            $results['checks'][] = $this->verifyDatabaseDump($backupSet);
        }

        $results['passed'] = !in_array(false, array_column($results['checks'], 'passed'));

        $backupSet->update([
            'verification_status' => $results['passed'] ? 'verified' : 'failed',
            'verification_result' => $results,
            'verified_at' => now(),
        ]);

        return $results;
    }

    private function verifyFileExists(BackupSet $backupSet): array
    {
        $exists = Storage::disk('backups')->exists($backupSet->storage_path);

        return [
            'check' => 'file_exists',
            'passed' => $exists,
            'message' => $exists ? 'Backup file exists' : 'Backup file missing',
        ];
    }

    private function verifyChecksum(BackupSet $backupSet): array
    {
        $tempPath = storage_path("app/backups/verify_{$backupSet->id}.tmp");

        try {
            $contents = Storage::disk('backups')->get($backupSet->storage_path);
            file_put_contents($tempPath, $contents);

            $actualChecksum = hash_file('sha256', $tempPath);
            $passed = $actualChecksum === $backupSet->checksum;

            return [
                'check' => 'checksum',
                'passed' => $passed,
                'expected' => $backupSet->checksum,
                'actual' => $actualChecksum,
                'message' => $passed ? 'Checksum matches' : 'Checksum mismatch',
            ];
        } finally {
            if (file_exists($tempPath)) {
                File::delete($tempPath);
            }
        }
    }

    private function verifyFileSize(BackupSet $backupSet): array
    {
        $size = Storage::disk('backups')->size($backupSet->storage_path);
        $passed = $size > 0 && abs($size - $backupSet->size_bytes) < ($backupSet->size_bytes * 0.01);

        return [
            'check' => 'file_size',
            'passed' => $passed,
            'expected_bytes' => $backupSet->size_bytes,
            'actual_bytes' => $size,
            'message' => $passed ? 'File size matches' : 'File size mismatch',
        ];
    }

    private function verifyExtractable(BackupSet $backupSet): array
    {
        $tempPath = storage_path("app/backups/verify_extract_{$backupSet->id}");

        try {
            $contents = Storage::disk('backups')->get($backupSet->storage_path);
            $archivePath = "{$tempPath}.tar.gz";
            file_put_contents($archivePath, $contents);

            if (!is_dir($tempPath)) {
                mkdir($tempPath, 0755, true);
            }

            $command = sprintf(
                'tar -xzf %s -C %s 2>&1',
                escapeshellarg($archivePath),
                escapeshellarg($tempPath)
            );

            exec($command, $output, $returnCode);
            $passed = $returnCode === 0;

            return [
                'check' => 'extractable',
                'passed' => $passed,
                'message' => $passed ? 'Archive extracts successfully' : 'Extraction failed: ' . implode("\n", $output),
            ];
        } finally {
            if (is_dir($tempPath)) {
                File::deleteDirectory($tempPath);
            }
        }
    }

    private function verifyDatabaseDump(BackupSet $backupSet): array
    {
        $tempPath = storage_path("app/backups/verify_db_{$backupSet->id}.sql");

        try {
            $contents = Storage::disk('backups')->get($backupSet->storage_path);
            $archivePath = "{$tempPath}.tar.gz";
            file_put_contents($archivePath, $contents);

            $extractDir = "{$tempPath}_extracted";
            if (!is_dir($extractDir)) {
                mkdir($extractDir, 0755, true);
            }

            $command = sprintf(
                'tar -xzf %s -C %s 2>&1',
                escapeshellarg($archivePath),
                escapeshellarg($extractDir)
            );

            exec($command, $output, $returnCode);

            if ($returnCode !== 0) {
                return [
                    'check' => 'database_dump',
                    'passed' => false,
                    'message' => 'Could not extract for DB verification',
                ];
            }

            $sqlFiles = glob("{$extractDir}/*.sql");
            $hasSql = !empty($sqlFiles);

            return [
                'check' => 'database_dump',
                'passed' => $hasSql,
                'message' => $hasSql ? 'Database dump found in archive' : 'No database dump in archive',
            ];
        } finally {
            foreach (glob("{$tempPath}*") as $path) {
                if (is_dir($path)) {
                    File::deleteDirectory($path);
                } else {
                    File::delete($path);
                }
            }
        }
    }

    public function verifyAllRecent(int $hours = 24): array
    {
        $backups = BackupSet::where('completed_at', '>=', now()->subHours($hours))
            ->get();

        $results = [];

        foreach ($backups as $backup) {
            $results[] = $this->verify($backup);
        }

        return [
            'total' => $backups->count(),
            'passed' => count(array_filter($results, fn($r) => $r['passed'])),
            'failed' => count(array_filter($results, fn($r) => !$r['passed'])),
            'results' => $results,
        ];
    }
}
```

```php
<?php

namespace App\Backup\Replication;

use Aws\S3\S3Client;
use Aws\Exception\AwsException;

class CrossRegionReplication
{
    private S3Client $sourceClient;
    private S3Client $replicaClient;
    private string $sourceBucket;
    private string $replicaBucket;
    private string $replicaRegion;

    public function __construct()
    {
        $this->sourceClient = new S3Client([
            'version' => 'latest',
            'region' => config('backup.s3.region'),
            'credentials' => [
                'key' => config('backup.s3.key'),
                'secret' => config('backup.s3.secret'),
            ],
        ]);

        $this->replicaClient = new S3Client([
            'version' => 'latest',
            'region' => config('backup.s3.replica_region'),
            'credentials' => [
                'key' => config('backup.s3.key'),
                'secret' => config('backup.s3.secret'),
            ],
        ]);

        $this->sourceBucket = config('backup.s3.bucket');
        $this->replicaBucket = config('backup.s3.replica_bucket');
        $this->replicaRegion = config('backup.s3.replica_region');
    }

    public function replicateFile(string $key): bool
    {
        try {
            $result = $this->sourceClient->copyObject([
                'Bucket' => $this->replicaBucket,
                'Key' => $key,
                'CopySource' => "{$this->sourceBucket}/{$key}",
                'StorageClass' => 'STANDARD_IA',
                'MetadataDirective' => 'COPY',
            ]);

            return true;
        } catch (AwsException $e) {
            \Illuminate\Support\Facades\Log::error("Replication failed for {$key}", [
                'error' => $e->getMessage(),
            ]);

            return false;
        }
    }

    public function replicateAll(string $prefix = ''): array
    {
        $results = [
            'replicated' => 0,
            'failed' => 0,
            'skipped' => 0,
            'details' => [],
        ];

        $iterator = $this->sourceClient->getIterator('ListObjectsV2', [
            'Bucket' => $this->sourceBucket,
            'Prefix' => $prefix,
        ]);

        foreach ($iterator as $object) {
            $key = $object['Key'];

            $exists = $this->objectExists($this->replicaBucket, $key);

            if ($exists) {
                $results['skipped']++;
                continue;
            }

            $success = $this->replicateFile($key);

            if ($success) {
                $results['replicated']++;
                $results['details'][] = ['key' => $key, 'status' => 'replicated'];
            } else {
                $results['failed']++;
                $results['details'][] = ['key' => $key, 'status' => 'failed'];
            }
        }

        return $results;
    }

    public function verifyReplication(string $key): array
    {
        $sourceExists = $this->objectExists($this->sourceBucket, $key);
        $replicaExists = $this->objectExists($this->replicaBucket, $key);

        $sourceSize = $sourceExists ? $this->getObjectSize($this->sourceBucket, $key) : 0;
        $replicaSize = $replicaExists ? $this->getObjectSize($this->replicaBucket, $key) : 0;

        return [
            'key' => $key,
            'source_exists' => $sourceExists,
            'replica_exists' => $replicaExists,
            'source_size' => $sourceSize,
            'replica_size' => $replicaSize,
            'size_match' => $sourceSize === $replicaSize,
            'replicated' => $sourceExists && $replicaExists && $sourceSize === $replicaSize,
        ];
    }

    public function getReplicationStatus(): array
    {
        $sourceObjects = $this->listObjects($this->sourceBucket);
        $replicaObjects = $this->listObjects($this->replicaBucket);

        $sourceKeys = array_column($sourceObjects, 'Key');
        $replicaKeys = array_column($replicaObjects, 'Key');

        $missing = array_diff($sourceKeys, $replicaKeys);
        $extra = array_diff($replicaKeys, $sourceKeys);

        return [
            'source_count' => count($sourceObjects),
            'replica_count' => count($replicaObjects),
            'missing_in_replica' => count($missing),
            'extra_in_replica' => count($extra),
            'missing_keys' => array_values($missing),
            'replication_health' => count($missing) === 0 ? 'healthy' : 'degraded',
        ];
    }

    private function objectExists(string $bucket, string $key): bool
    {
        try {
            $this->replicaClient->headObject([
                'Bucket' => $bucket,
                'Key' => $key,
            ]);
            return true;
        } catch (AwsException $e) {
            if ($e->getStatusCode() === 404) {
                return false;
            }
            throw $e;
        }
    }

    private function getObjectSize(string $bucket, string $key): int
    {
        try {
            $result = $this->replicaClient->headObject([
                'Bucket' => $bucket,
                'Key' => $key,
            ]);
            return $result['ContentLength'];
        } catch (AwsException $e) {
            return 0;
        }
    }

    private function listObjects(string $bucket): array
    {
        $objects = [];

        $iterator = $this->replicaClient->getIterator('ListObjectsV2', [
            'Bucket' => $bucket,
        ]);

        foreach ($iterator as $object) {
            $objects[] = $object;
        }

        return $objects;
    }
}
```

# Advanced Alert Routing

## Multi-Channel Alert Routing

The alert routing system supports escalation chains, quiet hours, and per-team notification preferences.

```php
<?php

namespace App\Monitoring\Alerting;

use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Notification;

class AlertRouter
{
    private array $severityConfig = [
        'critical' => [
            'channels' => ['pagerduty', 'slack', 'email', 'sms'],
            'escalation_delay_minutes' => 5,
            'acknowledgment_timeout_minutes' => 15,
            'auto_escalate_after_minutes' => 30,
        ],
        'warning' => [
            'channels' => ['slack', 'email'],
            'escalation_delay_minutes' => 15,
            'acknowledgment_timeout_minutes' => 60,
            'auto_escalate_after_minutes' => 120,
        ],
        'info' => [
            'channels' => ['slack'],
            'escalation_delay_minutes' => 60,
            'acknowledgment_timeout_minutes' => null,
            'auto_escalate_after_minutes' => null,
        ],
    ];

    public function routeAlert(Alert $alert): array
    {
        $config = $this->severityConfig[$alert->severity] ?? $this->severityConfig['info'];

        if ($this->isInQuietHours($alert)) {
            $this->queueForQuietHours($alert, $config);
            return ['status' => 'queued', 'reason' => 'quiet_hours'];
        }

        $recipients = $this->getRecipients($alert);
        $notifications = [];

        foreach ($config['channels'] as $channel) {
            $channelRecipients = $this->filterRecipientsForChannel($recipients, $channel);

            foreach ($channelRecipients as $recipient) {
                $notification = $this->sendNotification($alert, $channel, $recipient);
                $notifications[] = $notification;
            }
        }

        $this->scheduleEscalation($alert, $config);

        return [
            'status' => 'sent',
            'notifications' => $notifications,
            'recipients' => count($recipients),
        ];
    }

    public function acknowledgeAlert(string $alertId, string $userId): bool
    {
        return DB::table('alerts')
            ->where('id', $alertId)
            ->where('status', 'active')
            ->update([
                'acknowledged_by' => $userId,
                'acknowledged_at' => now(),
                'status' => 'acknowledged',
            ]) > 0;
    }

    public function resolveAlert(string $alertId, string $resolution): bool
    {
        return DB::table('alerts')
            ->where('id', $alertId)
            ->update([
                'resolved_at' => now(),
                'resolution' => $resolution,
                'status' => 'resolved',
            ]) > 0;
    }

    private function isInQuietHours(Alert $alert): bool
    {
        $quietStart = (int) config('monitoring.quiet_hours.start', 22);
        $quietEnd = (int) config('monitoring.quiet_hours.end', 7);
        $currentHour = (int) now()->format('H');

        if ($quietStart > $quietEnd) {
            return $currentHour >= $quietStart || $currentHour < $quietEnd;
        }

        return $currentHour >= $quietStart && $currentHour < $quietEnd;
    }

    private function queueForQuietHours(Alert $alert, array $config): void
    {
        DB::table('alert_queue')->insert([
            'alert_id' => $alert->id,
            'severity' => $alert->severity,
            'config' => json_encode($config),
            'queued_at' => now(),
            'deliver_after' => $this->getNextQuietHoursEnd(),
        ]);
    }

    private function getNextQuietHoursEnd(): \Carbon\Carbon
    {
        $quietEnd = (int) config('monitoring.quiet_hours.end', 7);
        $nextEnd = now()->copy()->startOfDay()->addHours($quietEnd);

        if ($nextEnd->isPast()) {
            $nextEnd->addDay();
        }

        return $nextEnd;
    }

    private function getRecipients(Alert $alert): array
    {
        $teamRecipients = DB::table('team_members')
            ->where('team_id', $alert->team_id)
            ->where('receives_alerts', true)
            ->get();

        $onCall = DB::table('oncall_schedules')
            ->where('start_date', '<=', now())
            ->where('end_date', '>=', now())
            ->first();

        $recipients = [];

        foreach ($teamRecipients as $member) {
            $recipients[] = [
                'user_id' => $member->user_id,
                'channels' => json_decode($member->notification_channels, true),
                'role' => $member->role,
            ];
        }

        if ($onCall) {
            $recipients[] = [
                'user_id' => $onCall->engineer_id,
                'channels' => ['pagerduty', 'sms', 'slack'],
                'role' => 'oncall',
            ];
        }

        return $recipients;
    }

    private function filterRecipientsForChannel(array $recipients, string $channel): array
    {
        return array_filter($recipients, function ($recipient) use ($channel) {
            return in_array($channel, $recipient['channels'] ?? []);
        });
    }

    private function sendNotification(Alert $alert, string $channel, array $recipient): array
    {
        $notificationClass = match ($channel) {
            'pagerduty' => PagerDutyNotification::class,
            'slack' => SlackAlertNotification::class,
            'email' => EmailAlertNotification::class,
            'sms' => SmsAlertNotification::class,
        };

        Notification::send(
            \App\Models\User::find($recipient['user_id']),
            new $notificationClass($alert)
        );

        DB::table('alert_notifications')->insert([
            'alert_id' => $alert->id,
            'channel' => $channel,
            'recipient_id' => $recipient['user_id'],
            'sent_at' => now(),
        ]);

        return [
            'channel' => $channel,
            'recipient_id' => $recipient['user_id'],
            'sent_at' => now()->toIso8601String(),
        ];
    }

    private function scheduleEscalation(Alert $alert, array $config): void
    {
        if (!$config['auto_escalate_after_minutes']) {
            return;
        }

        DB::table('alert_escalations')->insert([
            'alert_id' => $alert->id,
            'escalation_level' => 1,
            'scheduled_for' => now()->addMinutes($config['auto_escalate_after_minutes']),
            'status' => 'pending',
        ]);
    }
}
```

```php
<?php

namespace App\Monitoring\Http\Controllers;

use App\Monitoring\Models\Alert;
use App\Monitoring\Models\MaintenanceWindow;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Routing\Controller;

class AlertDashboardController extends Controller
{
    public function index(Request $request): JsonResponse
    {
        $status = $request->input('status', 'active');
        $severity = $request->input('severity');
        $teamId = $request->input('team_id');

        $query = Alert::query()
            ->when($status, fn($q) => $q->where('status', $status))
            ->when($severity, fn($q) => $q->where('severity', $severity))
            ->when($teamId, fn($q) => $q->where('team_id', $teamId));

        $alerts = $query->orderBy('created_at', 'desc')
            ->paginate(25);

        return response()->json([
            'status' => 'ok',
            'data' => $alerts,
            'summary' => $this->getAlertSummary(),
        ]);
    }

    public function show(Alert $alert): JsonResponse
    {
        $alert->load(['notifications', 'escalations', 'acknowledger']);

        return response()->json([
            'status' => 'ok',
            'data' => $alert,
        ]);
    }

    public function acknowledge(Request $request, Alert $alert): JsonResponse
    {
        $alert->update([
            'acknowledged_by' => $request->user()->id,
            'acknowledged_at' => now(),
            'status' => 'acknowledged',
        ]);

        return response()->json([
            'status' => 'ok',
            'message' => 'Alert acknowledged',
        ]);
    }

    public function resolve(Request $request, Alert $alert): JsonResponse
    {
        $request->validate([
            'resolution' => 'required|string|max:500',
        ]);

        $alert->update([
            'resolved_by' => $request->user()->id,
            'resolved_at' => now(),
            'resolution' => $request->input('resolution'),
            'status' => 'resolved',
        ]);

        return response()->json([
            'status' => 'ok',
            'message' => 'Alert resolved',
        ]);
    }

    public function maintenance(Request $request): JsonResponse
    {
        $windows = MaintenanceWindow::query()
            ->where('end_time', '>=', now())
            ->orderBy('start_time')
            ->get();

        return response()->json([
            'status' => 'ok',
            'data' => $windows,
        ]);
    }

    public function createMaintenance(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'title' => 'required|string|max:200',
            'description' => 'sometimes|string|max:1000',
            'start_time' => 'required|date|after:now',
            'end_time' => 'required|date|after:start_time',
            'affected_services' => 'required|array',
            'notify_users' => 'sometimes|boolean',
        ]);

        $window = MaintenanceWindow::create($validated);

        return response()->json([
            'status' => 'ok',
            'data' => $window,
        ], 201);
    }

    private function getAlertSummary(): array
    {
        return [
            'active' => Alert::where('status', 'active')->count(),
            'acknowledged' => Alert::where('status', 'acknowledged')->count(),
            'resolved_today' => Alert::where('status', 'resolved')
                ->whereDate('resolved_at', today())
                ->count(),
            'by_severity' => [
                'critical' => Alert::where('status', 'active')->where('severity', 'critical')->count(),
                'warning' => Alert::where('status', 'active')->where('severity', 'warning')->count(),
                'info' => Alert::where('status', 'active')->where('severity', 'info')->count(),
            ],
            'mttr_minutes' => $this->calculateMTTR(),
        ];
    }

    private function calculateMTTR(): float
    {
        $resolved = Alert::where('status', 'resolved')
            ->where('resolved_at', '>=', now()->subDays(7))
            ->get();

        if ($resolved->isEmpty()) {
            return 0;
        }

        $totalMinutes = $resolved->sum(function ($alert) {
            return $alert->created_at->diffInMinutes($alert->resolved_at);
        });

        return round($totalMinutes / $resolved->count(), 1);
    }
}
```

```php
<?php

namespace App\Monitoring\Http\Controllers;

use App\Monitoring\Metrics\MetricsCollector;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Routing\Controller;

class MetricsController extends Controller
{
    public function __construct(
        private MetricsCollector $metrics
    ) {}

    public function prometheus(): \Symfony\Component\HttpFoundation\Response
    {
        $metricsOutput = $this->metrics->getMetrics();

        return response($metricsOutput, 200, [
            'Content-Type' => 'text/plain; version=0.0.4; charset=utf-8',
        ]);
    }

    public function summary(Request $request): JsonResponse
    {
        $period = $request->input('period', '1h');

        $summary = [
            'period' => $period,
            'http' => $this->getHttpSummary($period),
            'database' => $this->getDatabaseSummary($period),
            'cache' => $this->getCacheSummary($period),
            'queue' => $this->getQueueSummary($period),
            'errors' => $this->getErrorSummary($period),
        ];

        return response()->json([
            'status' => 'ok',
            'data' => $summary,
        ]);
    }

    public function customMetrics(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'name' => 'required|string',
            'value' => 'required|numeric',
            'labels' => 'sometimes|array',
            'type' => 'required|in:counter,gauge,histogram',
        ]);

        $this->metrics->counter($validated['name'], $validated['labels'] ?? []);

        return response()->json([
            'status' => 'ok',
            'message' => 'Metric recorded',
        ]);
    }

    public function health(): JsonResponse
    {
        $checks = [
            'database' => $this->checkDatabase(),
            'cache' => $this->checkCache(),
            'queue' => $this->checkQueue(),
            'storage' => $this->checkStorage(),
        ];

        $healthy = !in_array(false, array_column($checks, 'healthy'));

        return response()->json([
            'status' => $healthy ? 'ok' : 'degraded',
            'checks' => $checks,
            'timestamp' => now()->toIso8601String(),
        ], $healthy ? 200 : 503);
    }

    private function getHttpSummary(string $period): array
    {
        return [
            'total_requests' => cache()->get("metrics:http:total:{$period}", 0),
            'avg_response_ms' => cache()->get("metrics:http:avg_response:{$period}", 0),
            'p95_response_ms' => cache()->get("metrics:http:p95_response:{$period}", 0),
            'p99_response_ms' => cache()->get("metrics:http:p99_response:{$period}", 0),
            'error_rate' => cache()->get("metrics:http:error_rate:{$period}", 0),
        ];
    }

    private function getDatabaseSummary(string $period): array
    {
        return [
            'total_queries' => cache()->get("metrics:db:total:{$period}", 0),
            'avg_query_ms' => cache()->get("metrics:db:avg_time:{$period}", 0),
            'slow_queries' => cache()->get("metrics:db:slow:{$period}", 0),
            'connections_active' => cache()->get("metrics:db:connections:active", 0),
        ];
    }

    private function getCacheSummary(string $period): array
    {
        return [
            'hit_rate' => cache()->get("metrics:cache:hit_rate:{$period}", 0),
            'total_operations' => cache()->get("metrics:cache:total:{$period}", 0),
            'memory_used_mb' => cache()->get("metrics:cache:memory:used", 0),
            'evictions' => cache()->get("metrics:cache:evictions:{$period}", 0),
        ];
    }

    private function getQueueSummary(string $period): array
    {
        return [
            'pending' => cache()->get("metrics:queue:pending", 0),
            'processing' => cache()->get("metrics:queue:processing", 0),
            'failed' => cache()->get("metrics:queue:failed:{$period}", 0),
            'avg_processing_ms' => cache()->get("metrics:queue:avg_time:{$period}", 0),
        ];
    }

    private function getErrorSummary(string $period): array
    {
        return [
            'total_4xx' => cache()->get("metrics:errors:4xx:{$period}", 0),
            'total_5xx' => cache()->get("metrics:errors:5xx:{$period}", 0),
            'uncaught_exceptions' => cache()->get("metrics:errors:exceptions:{$period}", 0),
            'unique_error_types' => cache()->get("metrics:errors:unique:{$period}", 0),
        ];
    }

    private function checkDatabase(): array
    {
        try {
            \Illuminate\Support\Facades\DB::select('SELECT 1');
            return ['healthy' => true, 'message' => 'Connected'];
        } catch (\Throwable $e) {
            return ['healthy' => false, 'message' => $e->getMessage()];
        }
    }

    private function checkCache(): array
    {
        try {
            \Illuminate\Support\Facades\Cache::put('_health_check', 'ok', 10);
            $value = \Illuminate\Support\Facades\Cache::get('_health_check');
            return ['healthy' => $value === 'ok', 'message' => $value === 'ok' ? 'Operational' : 'Read mismatch'];
        } catch (\Throwable $e) {
            return ['healthy' => false, 'message' => $e->getMessage()];
        }
    }

    private function checkQueue(): array
    {
        try {
            $size = \Illuminate\Support\Facades\Queue::size();
            return ['healthy' => $size < 1000, 'message' => "{$size} pending jobs"];
        } catch (\Throwable $e) {
            return ['healthy' => false, 'message' => $e->getMessage()];
        }
    }

    private function checkStorage(): array
    {
        $free = disk_free_space('/');
        $total = disk_total_space('/');
        $usedPercent = (($total - $free) / $total) * 100;

        return [
            'healthy' => $usedPercent < 90,
            'message' => round($usedPercent, 1) . '% used',
        ];
    }
}
```

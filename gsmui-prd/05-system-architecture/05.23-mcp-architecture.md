# Purpose

MCP (Model Context Protocol) architecture enables AI assistants to interact with the GsmUi platform through a standardized protocol.

## Tool Categories

### Component Discovery Tools

#### `list_components`
- **Purpose**: List all available components
- **Input**: `{ category?: string, limit?: number, offset?: number }`
- **Output**: `{ components: Component[], total: number }`
- **Permissions**: `read:components`
- **Rate Limit**: 100/hour

#### `get_component`
- **Purpose**: Get detailed component information
- **Input**: `{ component_id: string }`
- **Output**: `{ component: ComponentDetails }`
- **Permissions**: `read:components`
- **Rate Limit**: 200/hour

#### `search_components`
- **Purpose**: Search components by query
- **Input**: `{ query: string, filters?: ComponentFilters }`
- **Output**: `{ results: Component[], total: number }`
- **Permissions**: `read:components`
- **Rate Limit**: 100/hour

### Documentation Tools

#### `search_docs`
- **Purpose**: Search documentation
- **Input**: `{ query: string, section?: string }`
- **Output**: `{ results: DocResult[] }`
- **Permissions**: `read:docs`
- **Rate Limit**: 200/hour

#### `get_doc_page`
- **Purpose**: Get specific documentation page
- **Input**: `{ page_id: string }`
- **Output**: `{ page: DocPage }`
- **Permissions**: `read:docs`
- **Rate Limit**: 200/hour

### Generation Tools

#### `generate_component`
- **Purpose**: Generate new component from description
- **Input**: `{ description: string, framework?: string }`
- **Output**: `{ component: GeneratedComponent }`
- **Permissions**: `write:components`
- **Rate Limit**: 50/hour

#### `generate_theme`
- **Purpose**: Generate theme from description
- **Input**: `{ description: string, base_theme?: string }`
- **Output**: `{ theme: GeneratedTheme }`
- **Permissions**: `write:themes`
- **Rate Limit**: 20/hour

#### `generate_page`
- **Purpose**: Generate page layout
- **Input**: `{ description: string, components?: string[] }`
- **Output**: `{ page: GeneratedPage }`
- **Permissions**: `write:pages`
- **Rate Limit**: 20/hour

### Query Tools

#### `get_user_info`
- **Purpose**: Get current user context
- **Input**: `{}`
- **Output**: `{ user: UserInfo }`
- **Permissions**: `read:user`
- **Rate Limit**: 100/hour

#### `get_subscription`
- **Purpose**: Get subscription status
- **Input**: `{}`
- **Output**: `{ subscription: SubscriptionInfo }`
- **Permissions**: `read:subscription`
- **Rate Limit**: 100/hour

## Protocol Details

### JSON-RPC 2.0 Format

#### Request
```json
{
  "jsonrpc": "2.0",
  "id": "request-123",
  "method": "tools/call",
  "params": {
    "name": "get_component",
    "arguments": {
      "component_id": "button-primary"
    }
  }
}
```

#### Response
```json
{
  "jsonrpc": "2.0",
  "id": "request-123",
  "result": {
    "content": [
      {
        "type": "text",
        "text": "Component details..."
      }
    ]
  }
}
```

#### Error
```json
{
  "jsonrpc": "2.0",
  "id": "request-123",
  "error": {
    "code": -32600,
    "message": "Invalid request",
    "data": {
      "details": "Component not found"
    }
  }
}
```

## Transport Layer

### HTTP/HTTPS Transport

```text
Client → HTTP POST → MCP Server → Process → JSON Response

Endpoint: /mcp/v1
Method: POST
Content-Type: application/json
Authorization: Bearer <token>
```

### WebSocket Transport

```text
Client → WebSocket → MCP Server → Process → WebSocket Response

Endpoint: /mcp/v1/ws
Protocol: mcp-v1
Heartbeat: 30s
```

### SSE Transport (Fallback)

```text
Client → GET → MCP Server → SSE Stream → Events

Endpoint: /mcp/v1/events
Event Types: message, error, complete
```

## Authentication & Authorization

### Authentication Methods

#### API Key
```text
Header: X-API-Key: <api_key>
Validation: Check against database
Expiration: Never (revocable)
```

#### JWT Token
```text
Header: Authorization: Bearer <jwt_token>
Validation: Verify signature & expiration
Refresh: Automatic with refresh token
```

#### Session-Based
```text
Cookie: mcp_session=<session_id>
Validation: Check session store
Expiration: 24 hours
```

### Authorization Model

```text
User → Role → Permissions → Tool Access

Roles:
- Free: Basic tools, limited usage
- Pro: All tools, higher limits
- Enterprise: Custom tools, unlimited
```

# Risk

## Risk Register

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| AI API rate limits | High | High | Multi-provider fallback, caching, prompt optimization |
| AI hallucination in generated code | High | Critical | Output validation, sandboxed preview, user review step |
| API cost overrun | Medium | High | Per-user quotas, cost monitoring, spending alerts |
| Protocol breaking changes | Low | Medium | Versioned API, backward compatibility layer |
| Security breach via tool execution | Low | Critical | Scoped permissions, input sanitization, audit logging |
| Latency issues with AI calls | Medium | Medium | Response streaming, progressive rendering, timeout handling |

## Contingency Plans

- **AI API outage**: Fall back to cached responses for discovery tools; queue generation requests
- **Cost spike**: Temporarily reduce free-tier tool limits; enable aggressive caching
- **Security incident**: Revoke all API keys; enable emergency read-only mode; notify affected users
- **Protocol incompatibility**: Maintain versioned endpoints; provide migration guides

## Risk Monitoring

- Daily cost tracking against budget thresholds
- Weekly AI output quality sampling
- Monthly security audit of tool permissions
- Quarterly protocol compatibility testing

# MCP Client SDK

## JavaScript SDK

```javascript
// @gsmui/mcp-client
import { McpClient } from '@gsmui/mcp-client';

const client = new McpClient({
  baseUrl: 'https://mcp.gsmui.dev',
  apiKey: 'gsmui_xxx',
  timeout: 30000,
  retries: 3,
});

// List components
const components = await client.call('list_components', {
  category: 'form',
  limit: 25,
});

// Get component details
const button = await client.call('get_component', {
  component_id: 'button-primary',
  include_code: true,
});

// Generate component
const generated = await client.call('generate_component', {
  description: 'A date range picker with presets',
  framework: 'livewire',
  style: 'standard',
});

// Stream generation (for long operations)
const stream = await client.stream('generate_page', {
  description: 'Dashboard with charts and tables',
});

for await (const chunk of stream) {
  console.log(chunk.type, chunk.content);
}
```

# MCP Security Architecture

## Authentication Flow

```text
Client Request
    |
    v
API Key Validation
    |
    +-- Invalid → 401 Unauthorized
    |
    v
JWT Token Verification
    |
    +-- Expired → 401 Token Expired
    +-- Invalid → 401 Invalid Token
    |
    v
Permission Check
    |
    +-- Insufficient → 403 Forbidden
    |
    v
Rate Limit Check
    |
    +-- Exceeded → 429 Too Many Requests
    |
    v
Input Validation
    |
    +-- Invalid → 400 Bad Request
    |
    v
Tool Execution
    |
    v
Audit Log Entry
    |
    v
Response
```

## Rate Limiting Implementation

```php
// RateLimitMiddleware.php
class McpRateLimitMiddleware
{
    public function handle(Request $request, Closure $next)
    {
        $user = $request->user();
        $tool = $request->input('params.name');
        $limit = $this->getLimit($user, $tool);

        $key = "mcp:rate:{$user->id}:{$tool}";
        $current = Cache::get($key, 0);

        if ($current >= $limit['attempts']) {
            return response()->json([
                'jsonrpc' => '2.0',
                'error' => [
                    'code' => -32600,
                    'message' => 'Rate limit exceeded',
                    'data' => [
                        'retry_after' => Cache::ttl($key),
                    ],
                ],
            ], 429);
        }

        Cache::increment($key);
        Cache::put($key, $current + 1, $limit['decay_minutes'] * 60);

        $response = $next($request);

        // Add rate limit headers
        $response->headers->set('X-RateLimit-Limit', $limit['attempts']);
        $response->headers->set('X-RateLimit-Remaining', $limit['attempts'] - $current - 1);
        $response->headers->set('X-RateLimit-Reset', now()->addMinutes($limit['decay_minutes'])->timestamp);

        return $response;
    }

    private function getLimit(User $user, string $tool): array
    {
        $tier = $user->subscription?->plan?->tier ?? 'free';
        $limits = config("mcp.rate_limit.limits");

        return match($tool) {
            'generate_component', 'generate_theme', 'generate_page' => $limits['generate'] ?? $limits['default'],
            default => $limits[$tier] ?? $limits['default'],
        };
    }
}
```

```text

    |

    +-- Input Validation Error → Return detailed error with suggestions
```

# MCP Versioning Strategy

## API Versioning

```text
/mcp/v1/           → Current stable version
/mcp/v2/           → Next version (beta)
/mcp/compat/       → Backward compatibility layer
```

## Version Negotiation

```text
Client Request
    |
    v
Check Accept-Version Header
    |
    +-- Not specified → Use latest stable version
    |
    +-- v1 → Route to v1 handler
    +-- v2 → Route to v2 handler (if available)
    |
    v
Response with MCP-Version Header
```

## Backward Compatibility

- **Breaking changes**: New version endpoint required
- **Non-breaking changes**: Additive changes in current version
- **Deprecated features**: 6-month deprecation notice
- **Migration guides**: Provided for each version upgrade

```yaml
  - title: Requests per Second
    type: graph
    query: rate(mcp_requests_total[5m])

  - title: Tool Execution Time
    type: heatmap
    query: histogram_quantile(0.95, rate(mcp_tool_duration_seconds_bucket[5m]))

  - title: AI API Costs
    type: graph
    query: sum(mcp_ai_tokens_total) * 0.00003

  - title: Error Rate
    type: stat
    query: sum(rate(mcp_errors_total[5m])) / sum(rate(mcp_requests_total[5m]))
```

## Alerting Rules

```yaml
# High error rate
- alert: McpHighErrorRate
  expr: sum(rate(mcp_errors_total[5m])) / sum(rate(mcp_requests_total[5m])) > 0.05
  for: 5m
  labels:
    severity: warning

# High latency
- alert: McpHighLatency
  expr: histogram_quantile(0.95, rate(mcp_tool_duration_seconds_bucket[5m])) > 2

    severity: warning

  for: 1h

    severity: warning
```

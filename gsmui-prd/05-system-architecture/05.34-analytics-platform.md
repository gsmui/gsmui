# Purpose

The Analytics Platform provides insights into platform usage, user behavior, and business metrics. It collects, processes, and visualizes data to support decision-making and platform optimization.

---

# Architecture Overview

The analytics platform is a pipeline architecture that collects events from multiple sources, processes them through a series of transformations, stores them in a data warehouse, and visualizes them through dashboards and reports.

The system is designed for both real-time operational metrics and historical business analytics. Real-time metrics use streaming processing for immediate availability, while historical analytics use batch processing for complex aggregations.

The architecture separates data collection from analysis, enabling independent scaling and evolution of each concern. Data collection is lightweight and non-blocking to avoid impacting application performance, while analysis can be compute-intensive without affecting user-facing operations.

# Risk Assessment

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| Event volume exceeds storage capacity | Medium | High | Tiered storage; archival policies; sampling for high-volume events |
| GDPR violation from improper data collection | Low | Critical | Consent gate before tracking; anonymization pipeline; DPO review |
| Real-time dashboard latency under load | Medium | Medium | Pre-aggregated materialized views; read replicas; CDN-cached widgets |
| Data loss from pipeline failures | Low | High | Event replay from write-ahead log; dead letter queue; monitoring |
| Inaccurate metrics from duplicate events | High | Medium | Client-side deduplication; server-side idempotency keys |
| Privacy backlash from users | Low | High | Transparent opt-out; clear privacy policy; data minimization |
| ML model drift in predictive analytics | Medium | Low | Regular retraining; performance monitoring; manual override |
| Cross-team data access disputes | Medium | Low | Role-based access; data governance policy; audit logging |

## Contingency Plans

- **Pipeline Failure**: Fall back to batch processing; alert on-call team
- **Storage Overflow**: Auto-archive events older than 90 days; increase storage
- **Privacy Incident**: Immediate tracking pause; incident response team activation

## Event Versioning

Events are versioned to support schema evolution without breaking downstream consumers.

```text
Schema Evolution Rules:
    1. New optional fields may be added in any minor version
    2. Existing fields must never be removed or renamed
    3. Field types must never change
    4. Major version bump required for breaking changes
    5. Deprecated fields must be marked with sunset date
    6. Consumers must ignore unknown fields gracefully
```

### Version Compatibility Matrix

| Schema Version | Producers | Consumers | Sunset Date |
|---------------|-----------|-----------|-------------|
| v1.0 | All current producers | All current consumers | N/A |
| v1.1 | New producers | v1.0 + v1.1 consumers | N/A |
| v2.0 | v2.0+ producers | v2.0+ consumers | 2027-01-01 |

### Event Collector Service

```php
<?php

namespace App\Analytics\Services;

use App\Analytics\Models\AnalyticsEvent;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\DB;

class EventCollector
{
    private int $batchSize = 50;
    private int $flushInterval = 30;

    public function track(
        string $type,
        array $properties = [],
        ?int $userId = null,
        ?string $sessionId = null,
    ): void {
        if (!$this->shouldTrack($type)) {
            return;
        }

        $event = [
            'event_id' => (string) \Illuminate\Support\Str::uuid(),
            'event_type' => $type,
            'timestamp' => now()->toIso8601String(),
            'user_id' => $userId ?? auth()->id(),
            'session_id' => $sessionId ?? session()->getId(),
            'properties' => $this->sanitizeProperties($properties),
            'context' => $this->captureContext(),
            'consent' => $this->getConsentState(),
        ];

        $this->queueEvent($event);
    }

    private function shouldTrack(string $type): bool
    {
        if (!config('analytics.enabled', true)) {
            return false;
        }

        $user = auth()->user();
        if ($user && !$user->consentAnalytics()) {
            return false;
        }

        $sampleRate = config("analytics.sampling.{$type}", 1.0);
        return mt_rand(0, 10000) / 10000 <= $sampleRate;
    }

    private function sanitizeProperties(array $properties): array
    {
        $sensitiveKeys = ['password', 'token', 'secret', 'credit_card', 'ssn'];

        foreach ($sensitiveKeys as $key) {
            if (isset($properties[$key])) {
                unset($properties[$key]);
            }
        }

        return $properties;
    }

    private function captureContext(): array
    {
        return [
            'app' => [
                'version' => config('app.version'),
                'environment' => config('app.env'),
                'region' => config('app.region', 'us-east-1'),
            ],
            'device' => [
                'user_agent' => request()->userAgent(),
                'ip_hash' => hash('sha256', request()->ip()),
                'language' => request()->header('Accept-Language'),
            ],
            'page' => [
                'url' => request()->fullUrl(),
                'path' => request()->path(),
                'referrer' => request()->header('Referer'),
            ],
        ];
    }

    private function getConsentState(): array
    {
        $user = auth()->user();

        return [
            'analytics' => $user?->consentAnalytics() ?? false,
            'marketing' => $user?->consentMarketing() ?? false,
            'timestamp' => now()->toIso8601String(),
        ];
    }

    private function queueEvent(array $event): void
    {
        Cache::tags(['analytics-queue'])->add(
            'event_queue',
            collect(),
            now()->addHour()
        );

        $queue = Cache::tags(['analytics-queue'])->get('event_queue', collect());
        $queue->push($event);

        if ($queue->count() >= $this->batchSize) {
            $this->flushQueue($queue);
        } else {
            Cache::tags(['analytics-queue'])->put('event_queue', $queue, now()->addMinutes(5));
        }
    }

    private function flushQueue(?collect $queue = null): void
    {
        $queue = $queue ?? Cache::tags(['analytics-queue'])->pull('event_queue', collect());

        if ($queue->isEmpty()) {
            return;
        }

        DB::table('analytics_events')->insert($queue->toArray());

        Cache::tags(['analytics-queue'])->forget('event_queue');
    }
}
```

# Data Warehouse Schema

## ClickHouse Schema (Recommended for High Volume)

```sql
-- Raw events table (append-only, partitioned by day)
CREATE TABLE analytics_events (
    event_id UUID,
    event_type LowCardinality(String),
    event_version LowCardinality(String),
    timestamp DateTime64(3, 'UTC'),
    user_id Nullable(UInt64),
    session_id String,
    anonymous_id Nullable(String),
    context String, -- JSON serialized
    properties String, -- JSON serialized
    consent String, -- JSON serialized
    created_at DateTime64(3, 'UTC')
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(timestamp)
ORDER BY (event_type, timestamp, user_id)
TTL timestamp + INTERVAL 2 YEAR;

-- Daily metrics rollup
CREATE TABLE daily_metrics (
    date Date,
    metric_name LowCardinality(String),
    dimension LowCardinality(String),
    dimension_value String,
    value Float64,
    count UInt64,
    updated_at DateTime64(3, 'UTC')
) ENGINE = SummingMergeTree()
PARTITION BY toYYYYMM(date)
ORDER BY (date, metric_name, dimension, dimension_value);

-- Hourly metrics rollup
CREATE TABLE hourly_metrics (
    hour DateTime,
    metric_name LowCardinality(String),
    dimension LowCardinality(String),
    dimension_value String,
    value Float64,
    count UInt64,
    updated_at DateTime64(3, 'UTC')
) ENGINE = SummingMergeTree()
PARTITION BY toYYYYMM(hour)
ORDER BY (hour, metric_name, dimension, dimension_value);

-- User sessions table
CREATE TABLE user_sessions (
    session_id String,
    user_id Nullable(UInt64),
    started_at DateTime64(3, 'UTC'),
    ended_at Nullable(DateTime64(3, 'UTC')),
    duration_seconds Nullable(UInt32),
    page_views UInt16,
    interactions UInt16,
    device_type LowCardinality(String),
    browser LowCardinality(String),
    os LowCardinality(String),
    country LowCardinality(String),
    referrer_domain Nullable(String),
    utm_source Nullable(String),
    utm_medium Nullable(String),
    utm_campaign Nullable(String)
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(started_at)
ORDER BY (started_at, user_id);
```

# Processing Pipeline

## Stream Processing (Real-Time)

Real-time metrics are processed using Laravel's queue system with dedicated workers for analytics processing.

### Stream Processor

```php
<?php

namespace App\Analytics\Processing;

use App\Analytics\Models\HourlyMetric;
use App\Analytics\Models\DailyMetric;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Cache;

class StreamProcessor
{
    private array $realTimeMetrics = [
        'page.views' => ['dimension' => 'path', 'aggregation' => 'count'],
        'component.downloads' => ['dimension' => 'component_slug', 'aggregation' => 'count'],
        'api.requests' => ['dimension' => 'endpoint', 'aggregation' => 'count'],
        'errors.count' => ['dimension' => 'error_type', 'aggregation' => 'count'],
        'session.duration' => ['dimension' => 'device_type', 'aggregation' => 'avg'],
    ];

    public function process(array $event): void
    {
        $metricName = $event['event_type'];

        if (!isset($this->realTimeMetrics[$metricName])) {
            return;
        }

        $config = $this->realTimeMetrics[$metricName];
        $dimension = $this->extractDimension($event, $config['dimension']);
        $value = $this->extractValue($event, $config['aggregation']);

        $this->updateHourlyMetric($metricName, $dimension, $value);
        $this->updateDailyMetric($metricName, $dimension, $value);
        $this->updateRealTimeCache($metricName, $dimension, $value);
    }

    private function extractDimension(array $event, string $dimensionPath): string
    {
        $parts = explode('.', $dimensionPath);
        $value = $event;

        foreach ($parts as $part) {
            $value = $value[$part] ?? 'unknown';
        }

        return (string) $value;
    }

    private function extractValue(array $event, string $aggregation): float
    {
        return match ($aggregation) {
            'count' => 1.0,
            'sum' => (float) ($event['properties']['amount'] ?? 0),
            'avg' => (float) ($event['properties']['duration'] ?? 0),
            'min' => (float) ($event['properties']['value'] ?? 0),
            'max' => (float) ($event['properties']['value'] ?? 0),
            default => 1.0,
        };
    }

    private function updateHourlyMetric(string $name, string $dimension, float $value): void
    {
        $hour = now()->startOfHour();

        DB::table('hourly_metrics')->updateOrInsert(
            [
                'hour' => $hour,
                'metric_name' => $name,
                'dimension' => 'all',
                'dimension_value' => $dimension,
            ],
            [
                'value' => DB::raw("value + {$value}"),
                'count' => DB::raw('count + 1'),
                'updated_at' => now(),
            ]
        );
    }

    private function updateDailyMetric(string $name, string $dimension, float $value): void
    {
        $date = now()->startOfDay();

        DB::table('daily_metrics')->updateOrInsert(
            [
                'date' => $date,
                'metric_name' => $name,
                'dimension' => 'all',
                'dimension_value' => $dimension,
            ],
            [
                'value' => DB::raw("value + {$value}"),
                'count' => DB::raw('count + 1'),
                'updated_at' => now(),
            ]
        );
    }

    private function updateRealTimeCache(string $name, string $dimension, float $value): void
    {
        $key = "analytics:realtime:{$name}:{$dimension}";
        $windowKey = "analytics:realtime:{$name}:{$dimension}:window";

        Cache::increment($key, $value);
        Cache::put($windowKey, now()->timestamp, 3600);
    }
}
```

## Batch Processing (Historical)

Batch jobs run on a schedule to compute daily aggregations, cohort analyses, and complex metrics.

### Daily Aggregation Job

```php
<?php

namespace App\Analytics\Jobs;

use App\Analytics\Models\DailyMetric;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Support\Facades\DB;

class ComputeDailyAggregations implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public string $queue = 'analytics-batch';

    public function handle(): void
    {
        $yesterday = now()->subDay()->startOfDay();

        $this->computeActiveUsers($yesterday);
        $this->computeSessionMetrics($yesterday);
        $this->computeComponentMetrics($yesterday);
        $this->computeRevenueMetrics($yesterday);
        $this->computeErrorMetrics($yesterday);
    }

    private function computeActiveUsers(\Carbon\Carbon $date): void
    {
        $metrics = DB::table('analytics_events')
            ->whereDate('timestamp', $date)
            ->whereNotNull('user_id')
            ->selectRaw('
                COUNT(DISTINCT user_id) as dau,
                COUNT(DISTINCT CASE WHEN context->"$.device.type" = "mobile" THEN user_id END) as mobile_users,
                COUNT(DISTINCT CASE WHEN context->"$.device.type" = "desktop" THEN user_id END) as desktop_users
            ')
            ->first();

        DailyMetric::updateOrCreate(
            [
                'date' => $date,
                'metric_name' => 'active_users',
                'dimension' => 'platform',
                'dimension_value' => 'all',
            ],
            ['value' => $metrics->dau, 'count' => $metrics->dau]
        );
    }

    private function computeSessionMetrics(\Carbon\Carbon $date): void
    {
        $metrics = DB::table('user_sessions')
            ->whereDate('started_at', $date)
            ->selectRaw('
                COUNT(*) as total_sessions,
                AVG(duration_seconds) as avg_duration,
                AVG(page_views) as avg_page_views,
                COUNT(CASE WHEN duration_seconds < 10 THEN 1 END) as bounced_sessions
            ')
            ->first();

        $bounceRate = $metrics->total_sessions > 0
            ? ($metrics->bounced_sessions / $metrics->total_sessions) * 100
            : 0;

        DailyMetric::updateOrCreate(
            [
                'date' => $date,
                'metric_name' => 'session.bounce_rate',
                'dimension' => 'platform',
                'dimension_value' => 'all',
            ],
            ['value' => $bounceRate, 'count' => $metrics->total_sessions]
        );
    }

    private function computeComponentMetrics(\Carbon\Carbon $date): void
    {
        $downloads = DB::table('analytics_events')
            ->whereDate('timestamp', $date)
            ->where('event_type', 'component.downloaded')
            ->selectRaw('
                properties->"$." as slug,
                COUNT(*) as download_count,
                SUM(CAST(properties->"$.file_size_bytes" AS UNSIGNED)) as total_bytes
            ')
            ->groupBy('slug')
            ->get();

        foreach ($downloads as $download) {
            DailyMetric::updateOrCreate(
                [
                    'date' => $date,
                    'metric_name' => 'component.downloads',
                    'dimension' => 'component',
                    'dimension_value' => $download->slug,
                ],
                ['value' => $download->download_count, 'count' => $download->download_count]
            );
        }
    }

    private function computeRevenueMetrics(\Carbon\Carbon $date): void
    {
        $revenue = DB::table('commerce_events')
            ->whereDate('created_at', $date)
            ->where('event_type', 'commerce.purchase.completed')
            ->selectRaw('
                SUM(CAST(properties->"$.amount" AS DECIMAL(10,2))) as total_revenue,
                COUNT(*) as transaction_count,
                AVG(CAST(properties->"$.amount" AS DECIMAL(10,2))) as avg_order_value
            ')
            ->first();

        DailyMetric::updateOrCreate(
            [
                'date' => $date,
                'metric_name' => 'revenue.total',
                'dimension' => 'platform',
                'dimension_value' => 'all',
            ],
            ['value' => $revenue->total_revenue ?? 0, 'count' => $revenue->transaction_count ?? 0]
        );
    }

    private function computeErrorMetrics(\Carbon\Carbon $date): void
    {
        $errors = DB::table('analytics_events')
            ->whereDate('timestamp', $date)
            ->where('event_type', 'platform.error.occurred')
            ->selectRaw('
                properties->"$.error_type" as error_type,
                COUNT(*) as error_count
            ')
            ->groupBy('error_type')
            ->get();

        foreach ($errors as $error) {
            DailyMetric::updateOrCreate(
                [
                    'date' => $date,
                    'metric_name' => 'errors.by_type',
                    'dimension' => 'error_type',
                    'dimension_value' => $error->error_type,
                ],
                ['value' => $error->error_count, 'count' => $error->error_count]
            );
        }
    }
}
```

### Cohort Analysis Job

```php
<?php

namespace App\Analytics\Jobs;

use App\Analytics\Models\Cohort;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Support\Facades\DB;

class ComputeCohortAnalysis implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public string $queue = 'analytics-batch';

    public function handle(): void
    {
        $cohorts = Cohort::where('status', 'active')->get();

        foreach ($cohorts as $cohort) {
            $this->computeRetention($cohort);
            $this->computeLTV($cohort);
            $this->computeChurnRate($cohort);
        }
    }

    private function computeRetention(Cohort $cohort): void
    {
        $registrationDate = $cohort->registration_date;
        $userIds = DB::table('users')
            ->whereDate('created_at', $registrationDate)
            ->pluck('id');

        $totalUsers = $userIds->count();

        if ($totalUsers === 0) {
            return;
        }

        $periods = [1, 3, 7, 14, 30, 60, 90];

        foreach ($periods as $days) {
            $checkDate = $registrationDate->addDays($days);

            $activeUsers = DB::table('analytics_events')
                ->whereIn('user_id', $userIds)
                ->whereDate('timestamp', $checkDate)
                ->distinct('user_id')
                ->count('user_id');

            $retentionRate = ($activeUsers / $totalUsers) * 100;

            DB::table('cohort_metrics')->updateOrInsert(
                [
                    'cohort_id' => $cohort->id,
                    'metric_name' => 'retention',
                    'period_days' => $days,
                ],
                [
                    'value' => $retentionRate,
                    'sample_size' => $totalUsers,
                    'computed_at' => now(),
                ]
            );
        }
    }

    private function computeLTV(Cohort $cohort): void
    {
        $registrationDate = $cohort->registration_date;
        $userIds = DB::table('users')
            ->whereDate('created_at', $registrationDate)
            ->pluck('id');

        $totalRevenue = DB::table('commerce_events')
            ->whereIn('user_id', $userIds)
            ->where('event_type', 'commerce.purchase.completed')
            ->sum(DB::raw('CAST(properties->"$.amount" AS DECIMAL(10,2))'));

        $ltv = $userIds->count() > 0
            ? $totalRevenue / $userIds->count()
            : 0;

        DB::table('cohort_metrics')->updateOrInsert(
            [
                'cohort_id' => $cohort->id,
                'metric_name' => 'ltv',
                'period_days' => now()->diffInDays($registrationDate),
            ],
            [
                'value' => $ltv,
                'sample_size' => $userIds->count(),
                'computed_at' => now(),
            ]
        );
    }

    private function computeChurnRate(Cohort $cohort): void
    {
        $registrationDate = $cohort->registration_date;
        $totalUsers = DB::table('users')
            ->whereDate('created_at', $registrationDate)
            ->count();

        if ($totalUsers === 0) {
            return;
        }

        $churnedUsers = DB::table('users')
            ->whereDate('created_at', $registrationDate)
            ->whereNotNull('churned_at')
            ->where('churned_at', '<=', now())
            ->count();

        $churnRate = ($churnedUsers / $totalUsers) * 100;

        DB::table('cohort_metrics')->updateOrInsert(
            [
                'cohort_id' => $cohort->id,
                'metric_name' => 'churn_rate',
                'period_days' => now()->diffInDays($registrationDate),
            ],
            [
                'value' => $churnRate,
                'sample_size' => $totalUsers,
                'computed_at' => now(),
            ]
        );
    }
}
```

```php
<?php

namespace App\Analytics\Http\Controllers;

use App\Analytics\Services\EventCollector;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Routing\Controller;
use Illuminate\Support\Facades\Validator;

class EventController extends Controller
{
    public function __construct(
        private EventCollector $collector
    ) {}

    public function store(Request $request): JsonResponse
    {
        $validator = Validator::make($request->all(), [
            'events' => 'required|array|max:50',
            'events.*.event_type' => 'required|string|max:100',
            'events.*.timestamp' => 'required|date',
            'events.*.properties' => 'sometimes|array',
            'events.*.context' => 'sometimes|array',
        ]);

        if ($validator->fails()) {
            return response()->json([
                'error' => 'validation_failed',
                'message' => 'Invalid event data',
                'details' => $validator->errors(),
            ], 422);
        }

        $events = $request->input('events');
        $processed = 0;
        $failed = 0;

        foreach ($events as $event) {
            try {
                $this->collector->track(
                    type: $event['event_type'],
                    properties: $event['properties'] ?? [],
                    userId: $request->user()?->id,
                    sessionId: $request->input('session_id'),
                );
                $processed++;
            } catch (\Throwable $e) {
                $failed++;
                report($e);
            }
        }

        return response()->json([
            'status' => 'ok',
            'processed' => $processed,
            'failed' => $failed,
        ]);
    }
}
```

### Funnel Analysis Service

```php
<?php

namespace App\Analytics\Services;

use App\Analytics\Models\Funnel;
use Illuminate\Support\Facades\DB;

class FunnelAnalysisService
{
    public function analyze(Funnel $funnel, string $range = '30d'): array
    {
        $steps = $funnel->steps;
        $startDate = $this->parseRange($range);

        $stepResults = [];
        $previousStepUsers = null;

        foreach ($steps as $index => $step) {
            $query = DB::table('analytics_events')
                ->where('event_type', $step['event'])
                ->where('timestamp', '>=', $startDate);

            if ($previousStepUsers !== null) {
                $query->whereIn('user_id', $previousStepUsers);
            }

            $userIds = $query->distinct('user_id')
                ->pluck('user_id')
                ->toArray();

            $stepResults[] = [
                'step' => $index + 1,
                'label' => $step['label'],
                'event' => $step['event'],
                'users' => count($userIds),
                'conversion_rate' => $previousStepUsers !== null
                    ? (count($userIds) / count($previousStepUsers)) * 100
                    : 100,
            ];

            $previousStepUsers = $userIds;
        }

        $totalUsers = $stepResults[0]['users'] ?? 0;
        $finalUsers = end($stepResults)['users'] ?? 0;

        return [
            'funnel' => $funnel->toArray(),
            'steps' => $stepResults,
            'overall_conversion' => $totalUsers > 0
                ? ($finalUsers / $totalUsers) * 100
                : 0,
            'period' => $range,
            'computed_at' => now()->toIso8601String(),
        ];
    }

    private function parseRange(string $range): \Carbon\Carbon
    {
        return match ($range) {
            '1h' => now()->subHour(),
            '24h' => now()->subDay(),
            '7d' => now()->subDays(7),
            '30d' => now()->subDays(30),
            '90d' => now()->subDays(90),
            default => now()->subDays(30),
        };
    }
}
```

### Experiment Service

```php
<?php

namespace App\Analytics\Services;

use App\Analytics\Models\Experiment;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Cookie;

class ExperimentService
{
    public function getVariant(Experiment $experiment): ?string
    {
        if (!$experiment->isActive()) {
            return null;
        }

        $userId = auth()->id();
        $sessionId = session()->getId();

        $assignmentKey = "experiment:{$experiment->slug}:user:{$userId}";
        $existing = Cache::get($assignmentKey);

        if ($existing) {
            return $existing;
        }

        if (!$this->matchesTargeting($experiment)) {
            return null;
        }

        $variant = $this->assignVariant($experiment);

        Cache::put($assignmentKey, $variant, $experiment->end_date);

        $this->trackExposure($experiment, $variant);

        return $variant;
    }

    private function matchesTargeting(Experiment $experiment): bool
    {
        $rules = $experiment->targeting_rules;

        if (empty($rules)) {
            return true;
        }

        foreach ($rules as $rule) {
            if (!$this->evaluateRule($rule)) {
                return false;
            }
        }

        return true;
    }

    private function evaluateRule(array $rule): bool
    {
        $user = auth()->user();

        return match ($rule['type']) {
            'percentage' => mt_rand(1, 100) <= $rule['value'],
            'user_segment' => in_array($user?->segment, $rule['segments']),
            'country' => in_array($user?->country, $rule['countries']),
            'plan' => $user?->plan === $rule['plan'],
            default => true,
        };
    }

    private function assignVariant(Experiment $experiment): string
    {
        $variants = $experiment->variants;
        $totalWeight = array_sum(array_column($variants, 'weight'));

        $random = mt_rand(0, $totalWeight);
        $cumulative = 0;

        foreach ($variants as $variant) {
            $cumulative += $variant['weight'];
            if ($random <= $cumulative) {
                return $variant['name'];
            }
        }

        return $variants[0]['name'];
    }

    private function trackExposure(Experiment $experiment, string $variant): void
    {
        event('experiment.exposed', [
            'experiment_slug' => $experiment->slug,
            'variant' => $variant,
            'user_id' => auth()->id(),
            'session_id' => session()->getId(),
        ]);
    }
}
```

### Export Job

```php
<?php

namespace App\Analytics\Jobs;

use App\Analytics\Services\AnalyticsQueryService;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Support\Facades\Storage;

class ExportAnalyticsData implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public int $timeout = 300;

    public function __construct(
        public readonly string $exportId,
        public readonly string $type,
        public readonly array $filters,
        public readonly string $format,
    ) {}

    public function handle(AnalyticsQueryService $query): void
    {
        cache()->put("export:{$this->exportId}:status", 'processing', 3600);

        $data = match ($this->type) {
            'events' => $query->getEvents($this->filters),
            'users' => $query->getUserMetrics($this->filters),
            'revenue' => $query->getRevenueMetrics($this->filters),
            default => throw new \InvalidArgumentException("Unknown export type: {$this->type}"),
        };

        $filename = "exports/{$this->exportId}.{$this->format}";
        $content = $this->format === 'csv'
            ? $this->toCsv($data)
            : $this->toJson($data);

        Storage::disk('exports')->put($filename, $content);

        $url = Storage::disk('exports')->temporaryUrl(
            $filename,
            now()->addHours(24)
        );

        cache()->put("export:{$this->exportId}:status", 'completed', 3600);
        cache()->put("export:{$this->exportId}:url", $url, 3600);
    }

    private function toCsv(array $data): string
    {
        if (empty($data)) {
            return '';
        }

        $headers = array_keys($data[0]);
        $lines[] = implode(',', $headers);

        foreach ($data as $row) {
            $lines[] = implode(',', array_map(fn($v) => '"' . str_replace('"', '""', $v) . '"', array_values($row)));
        }

        return implode("\n", $lines);
    }

    private function toJson(array $data): string
    {
        return json_encode($data, JSON_PRETTY_PRINT);
    }
}
```

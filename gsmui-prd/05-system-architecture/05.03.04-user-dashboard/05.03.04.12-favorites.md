# Conclusion

Favorites is the fastest way for GsmUi users to access their most-used components, templates, and themes. Unlike Saved Components (which supports organized collections), Favorites is a flat, quick-access list — the "starred" items of the GsmUi ecosystem. This page must be instant to load, effortless to manage, and deeply integrated into every component, template, and theme detail page across the platform.

# Performance

| Metric | Target | Strategy |
|--------|--------|----------|
| Toggle response | < 100ms | Optimistic UI, server-side async |
| Favorites list load | < 200ms | Eager-loaded, Redis-cached count |
| Sync broadcast | < 1s | Lightweight payload (item_id + type) |
| Count badge update | < 200ms | Cached count, incremented client-side |
| Search within favorites | < 100ms | Client-side filter for < 200 items |

**Caching:**
- Favorites count: Redis counter per user, incremented/decremented on toggle
- Favorites list: 5-minute cache per user, invalidated on toggle
- Favorite status: Cached in localStorage for instant toggle UI

|----------|--------|-------------|

| GET /api/favorites/check/{type}/{id} | GET | Check if item is favorited |

# Events

| Event | Trigger | Handler |
|-------|---------|---------|
| Favorited | Item added to favorites | Increment count, broadcast sync |
| Unfavorited | Item removed from favorites | Decrement count, broadcast sync |
| FavoritesSynced | Cross-device sync received | Merge states, notify UI |
| FavoritesImported | Bulk import from JSON | Batch insert, rebuild count |
| FavoriteLimitApproaching | User has 450+ favorites | Show soft warning |
| FavoriteItemRemoved | Favorited item deleted from platform | Mark as "removed" in favorites list |

# Database

| Table | Key Columns | Purpose |
|-------|------------|---------|
| avorites | id, user_id, 	ype, item_id, created_at | Favorite records |
| avorite_counts | user_id, 	ype, count | Cached counts per type |

**Schema:**
`php
Schema::create('favorites', function (Blueprint ) {
    ->id();
    ->foreignId('user_id')->constrained()->cascadeOnDelete();
    ->string('type'); // component, template, theme
    ->string('item_id');
    ->timestamp('created_at')->useCurrent();
    ->unique(['user_id', 'type', 'item_id']);
});
`

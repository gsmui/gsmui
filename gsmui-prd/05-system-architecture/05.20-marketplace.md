# 05.20 - Marketplace Architecture

**Project:** GsmUi
**Architecture:** Digital Marketplace Platform
**Framework:** Laravel 13 + Livewire 4 + Laravel Sanctum + Spatie Media Library
**Version:** 1.0.0

---

# Purpose

The Marketplace is the commercial platform of GsmUi. It enables creators and the GsmUi team to publish, sell, license, and distribute digital products while providing customers with a seamless purchasing and download experience.

The marketplace supports:

* UI Components
* Templates
* Themes
* Icons
* Charts
* Plugins
* MCP Tools
* AI Skills
* Code Snippets
* Asset Packs
* Future Extensions

---

# Objectives

The Marketplace should:

* Support free and paid products
* Handle subscriptions and one-time purchases
* Manage digital licenses
* Deliver secure downloads
* Support creator publishing
* Handle reviews and ratings
* Support coupons and promotions
* Integrate with billing
* Track analytics
* Scale to thousands of products

# Queue Architecture

## Queue Names

| Queue | Purpose | Workers | Priority |
|-------|---------|---------|----------|
| `marketplace-critical` | License generation, payment processing | 2 | High |
| `marketplace-default` | Product indexing, notifications | 2 | Normal |
| `marketplace-downloads` | Package generation, file processing | 1 | Normal |
| `marketplace-moderation` | Content review, abuse detection | 1 | Low |
| `marketplace-analytics` | Metrics aggregation, reporting | 1 | Low |

## Job Definitions

### Critical Jobs

```php
class GenerateLicense implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public string $queue = 'marketplace-critical';
    public int $tries = 3;
    public int $timeout = 30;

    public function handle(
        OrderItem $item,
        LicenseService $licenseService,
    ): void {
        $licenseService->generateForOrderItem($item);
    }
}

class ProcessPayment implements ShouldQueue
```

## Coupon Validation

```php
class CouponValidator
{
    public function validate(
        Coupon $coupon,
        User $user,
        Cart $cart,
    ): ValidationResult {
        // Check if coupon is active
        if (!$coupon->is_active) {
            return ValidationResult::failed('Coupon is inactive');
        }

        // Check expiration
        if ($coupon->expires_at && $coupon->expires_at->isPast()) {
            return ValidationResult::failed('Coupon has expired');
        }

        // Check start date
        if ($coupon->starts_at && $coupon->starts_at->isFuture()) {
            return ValidationResult::failed('Coupon is not yet active');
        }

        // Check usage limits
        if ($coupon->max_uses && $coupon->used_count >= $coupon->max_uses) {
            return ValidationResult::failed('Coupon usage limit reached');
        }

        // Check per-user limit
        if ($coupon->per_user_limit) {
            $userUsage = $this->getUserUsageCount($coupon, $user);
            if ($userUsage >= $coupon->per_user_limit) {
                return ValidationResult::failed('You have reached the usage limit for this coupon');
            }
        }

        // Check minimum order amount
        if ($coupon->min_order_amount && $cart->subtotal < $coupon->min_order_amount) {
            return ValidationResult::failed("Minimum order amount is {$coupon->min_order_amount}");
        }

        // Check product restrictions
        if ($coupon->applicable_product_ids) {
            $validItems = $cart->items->filter(fn ($item) =>
                in_array($item->product_id, $coupon->applicable_product_ids)
            );
            if ($validItems->isEmpty()) {
                return ValidationResult::failed('Coupon is not applicable to items in your cart');
            }
        }

        return ValidationResult::passed();
    }
}
```

| Marketplace piracy (sharing downloaded themes/components) | High | High | Encrypted packages with license-bound decryption. Watermark exported files. Periodic license validation checks. |

| Tax compliance across jurisdictions | High | Medium | Use Stripe Tax for automatic tax calculation. Support VAT/GST invoicing. Consult tax advisor for multi-region compliance. |
| Product quality complaints damage marketplace reputation | Medium | High | Require automated quality checks (a11y, linting, tests) before publication. Moderation review for new creators. Quality badge program. |
| Subscription billing errors cause revenue leakage | Medium | High | Stripe webhook monitoring. Automated reconciliation between Stripe and platform database. Manual review for edge cases. |
| Download service abuse (bulk downloading) | Low | Medium | Rate-limit downloads per license. Signed URLs with short TTL. Anomaly detection for unusual download patterns. |
| Creator payout disputes | Medium | Medium | Transparent earnings dashboard. Detailed transaction history. Automated payout reconciliation with manual review for disputes. |

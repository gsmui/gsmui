# 05.14 - API Architecture

**Project:** GsmUi
**Architecture:** REST API + Service-Oriented Backend
**Framework:** Laravel 13 + Laravel Sanctum
**Version:** 1.0.0

---

# Purpose

Although GsmUi is primarily a Livewire application, every core business capability should be accessible through a stable API.

The API enables:

* Mobile applications
* MCP integrations
* CLI tools
* Third-party integrations
* Automation
* Future GraphQL support
* Internal frontend consumption

The API is **service-first**, meaning controllers delegate all business logic to the Application Layer (Actions & Services).

---

# Goals

The API must be:

* RESTful
* Versioned
* Secure
* Fast
* Consistent
* Well documented
* Testable
* Extensible

## Request Validation Strategy

### Layer 1: Content-Type Check

```php id="apival01"
class ValidateContentType
{
    public function handle(Request $request, Closure $next)
    {
        if ($request->isMethod('POST') || $request->isMethod('PUT')) {
            $request->validate([
                'Content-Type' => 'required|in:application/json',
            ]);
        }

        return $next($request);
    }
}
```

### Layer 2: Form Request Validation

```php id="apival02"
class StoreComponentRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'name' => ['required', 'string', 'max:255'],
            'slug' => ['required', 'string', 'max:255', 'unique:components'],
            'description' => ['required', 'string', 'max:2000'],
            'category_id' => ['required', 'exists:categories,id'],
            'is_free' => ['boolean'],
            'is_featured' => ['boolean'],
        ];
    }

    public function messages(): array
    {
        return [
            'name.required' => 'Component name is required.',
            'slug.unique' => 'A component with this slug already exists.',
        ];
    }
}
```

### Layer 3: Action-Level Validation

```php id="apival03"
class CreateComponentAction
{
    public function execute(CreateComponentData $data): Component
    {
        // Business validation beyond form request
        if ($this->service->existsByName($data->name)) {
            throw new DuplicateComponentException($data->name);
        }

        return $this->service->create($data);
    }
}
```

```text id="apipage02"

  "meta": {
```

### Cursor Implementation

```php id="apipage03"
class CursorPagination
{
    public function paginate($query, string $cursor, int $limit): array
    {
        $decoded = json_decode(base64_decode($cursor), true);

        $items = $query
            ->where('id', '>', $decoded['id'])
            ->orderBy('id', 'asc')
            ->limit($limit + 1)
            ->get();

        $hasMore = $items->count() > $limit;
        $items = $items->take($limit);

        return [
            'data' => $items,
            'meta' => [
                'next_cursor' => $hasMore
                    ? base64_encode(json_encode(['id' => $items->last()->id]))
                    : null,
                'has_more' => $hasMore,
            ],
        ];
    }
}
```

## Rate Limiting Deep Dive

### Rate Limit Configuration

```php id="apirate01"
class RateServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        RateLimiter::for('api', function (Request $request) {

                $request->user()?->id ?: $request->ip()

            return Limit::perMinute(30)->by($request->ip());

}
```

### Signature Verification

```php id="apwh03"
class WebhookSignature
{
    public function verify(string $payload, string $signature, string $secret): bool
    {
        $expected = hash_hmac('sha256', $payload, $secret);

        return hash_equals($expected, $signature);
    }
}
```

### Retry Policy

| Attempt | Delay | Max Attempts |
|---------|-------|--------------|
| 1 | Immediate | 1 |
| 2 | 1 minute | 2 |
| 3 | 5 minutes | 3 |
| 4 | 30 minutes | 4 |
| 5 | 2 hours | 5 |
| 6 | 8 hours | 6 |
| 7 | 24 hours | 7 |

After 7 failed attempts, the webhook is disabled and the owner is notified.

### Input Sanitization

```php id="apisan01"
class SanitizeInput
{
    public function sanitize(array $data): array
    {
        return array_map(function ($value) {
            if (is_string($value)) {
                $value = strip_tags($value);
                $value = trim($value);
                $value = e($value);
            }
            return $value;
        }, $data);
    }
}
```

## API Error Taxonomy

### Client Errors (4xx)

| Error Code | Message | Resolution |
|------------|---------|------------|
| bad_request | Malformed request body | Check JSON syntax |
| unauthorized | Missing or invalid token | Authenticate first |
| forbidden | Insufficient permissions | Upgrade role |
| not_found | Resource doesn't exist | Check resource ID |
| validation_failed | Invalid input data | Check error details |
| conflict | Resource state conflict | Refresh and retry |
| rate_limited | Too many requests | Wait and retry |
| unsupported_media | Wrong content type | Use application/json |

### Server Errors (5xx)

| Error Code | Message | Action |
|------------|---------|--------|
| internal_error | Unexpected server error | Log, alert team |
| service_unavailable | Dependency failure | Retry, fallback |
| gateway_timeout | Upstream timeout | Retry with backoff |

## API Controller Implementation

### Standard Controller Structure

```php id="apictl01"
class ComponentController extends Controller
{
    public function __construct(
        private ListComponentsAction $listAction,
        private GetComponentAction $getAction,
        private CreateComponentAction $createAction,
        private UpdateComponentAction $updateAction,
        private DeleteComponentAction $deleteAction,
    ) {}

    public function index(ListComponentsRequest $request): ComponentCollection
    {
        return $this->listAction->execute(
            ListComponentsData::fromRequest($request)
        );
    }

    public function show(Component $component): ComponentResource
    {
        return $this->getAction->execute($component);
    }

    public function store(StoreComponentRequest $request): ComponentResource
    {
        return $this->createAction->execute(
            CreateComponentData::fromRequest($request)
        );
    }

    public function update(
        UpdateComponentRequest $request,
        Component $component
    ): ComponentResource {
        return $this->updateAction->execute(
            $component,
            UpdateComponentData::fromRequest($request)
        );
    }

    public function destroy(Component $component): Response
    {
        $this->deleteAction->execute($component);

        return response()->noContent();
    }
}
```

## API Webhook Implementation

### Webhook Service

```php id="apiwh01"
class WebhookService
{
    public function dispatch(string $event, array $data): void
    {
        $subscriptions = WebhookSubscription::whereJsonContains(
            'events',
            $event
        )->get();

        foreach ($subscriptions as $subscription) {
            WebhookDeliveryJob::dispatch($subscription, $event, $data);
        }
    }
}
```

### Delivery Job

```php id="apiwh02"
class WebhookDeliveryJob implements ShouldQueue
{
    public int $tries = 7;
    public int $backoff = [60, 300, 900, 1800, 3600, 7200, 14400];

    public function handle(
        WebhookSubscription $subscription,
        string $event,
        array $data
    ): void {
        $payload = json_encode([
            'event' => $event,
            'timestamp' => now()->toIso8601String(),
            'data' => $data,
        ]);

        $signature = hash_hmac('sha256', $payload, $subscription->secret);

        $response = Http::withHeaders([
            'Content-Type' => 'application/json',
            'X-GsmUi-Signature' => "sha256={$signature}",
            'X-GsmUi-Event' => $event,
        ])->timeout(30)->post($subscription->url, $payload);

        if ($response->failed()) {
            throw new WebhookDeliveryFailedException();
        }

        WebhookDelivery::create([
            'subscription_id' => $subscription->id,
            'event' => $event,
            'payload' => $payload,
            'response_code' => $response->status(),
        ]);
    }
}
```

## API Error Recovery

### Retry Strategy

```php id="apiretry01"
class ApiRetryStrategy
{
    public function shouldRetry(\Exception $e, int $attempt): bool
    {
        if ($attempt >= 3) {
            return false;
        }

        return in_array($e->getCode(), [429, 500, 502, 503, 504]);
    }

    public function getRetryDelay(int $attempt): int
    {
        return $attempt * 1000; // 1s, 2s, 3s
    }
}
```

### Circuit Breaker

```text id="apiretry02"
Closed (Normal)
   |
   v (failures exceed threshold)
   |
Open (Failing)
   |
   v (timeout expires)
   |
Half-Open (Testing)
   |
   +-- Success -> Closed
   +-- Failure -> Open
```

## API Best Practices

### Design Principles

| Principle | Description |
|-----------|-------------|
| Consistent naming | Same conventions across all endpoints |
| Predictable URLs | RESTful resource hierarchy |
| Standard methods | GET, POST, PUT, PATCH, DELETE |
| Proper status codes | Meaningful HTTP responses |
| Pagination | Always paginate collections |
| Filtering | Support query parameters |
| Sorting | Support sort parameters |
| Field selection | Allow sparse fieldsets |
| Versioning | URI-based versioning |
| Documentation | OpenAPI spec for every endpoint |

### Security Checklist

- [ ] HTTPS enforced
- [ ] Authentication on all non-public endpoints
- [ ] Authorization checks in policies
- [ ] Input validation via Form Requests
- [ ] Output escaping via API Resources
- [ ] Rate limiting configured
- [ ] CORS properly configured
- [ ] Secrets not in source control
- [ ] Audit logging for sensitive operations
- [ ] Webhook signatures verified

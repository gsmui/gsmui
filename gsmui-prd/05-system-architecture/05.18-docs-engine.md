# 05.18 - Documentation Engine Architecture

**Project:** GsmUi
**Architecture:** Documentation Platform + Knowledge Engine
**Framework:** Laravel 13 + Livewire 4 + Markdown + Blade + GsmUi Components
**Version:** 1.0.0

---

# Purpose

The Documentation Engine is one of the most valuable parts of GsmUi. It is not just a collection of Markdown files—it is a structured knowledge platform that powers:

* Component documentation
* Framework guides
* Installation guides
* Tutorials
* Theme documentation
* API documentation
* Playground examples
* Search
* AI Assistant
* MCP Server
* Versioned documentation

Every piece of documentation should be reusable, searchable, versioned, and automatically generated where possible.

---

# Goals

The Documentation Engine should:

* Support Markdown and MDX-style enhancements
* Generate documentation from component metadata
* Support versioning
* Support multilingual content (future)
* Include interactive examples
* Integrate with Playground
* Power AI and MCP
* Provide excellent SEO

### Breadcrumb Generation

```php id="dnav03"
class BreadcrumbGenerator
{
    public function generate(string $slug): array
    {
        $segments = explode('/', $slug);
        $breadcrumbs = [];
        $path = '';

        foreach ($segments as $segment) {
            $path .= '/' . $segment;
            $page = $this->findPage($path);

            $breadcrumbs[] = [
                'title' => $page->title ?? ucfirst($segment),
                'url' => $path,
                'active' => $path === $slug,
            ];
        }

        return $breadcrumbs;
    }
}
```

### Version Differences

```php id="dver03"
class VersionComparator
{
    public function diff(string $fromVersion, string $toVersion): array
    {
        $fromPages = $this->getPages($fromVersion);
        $toPages = $this->getPages($toVersion);

        return [
            'added' => $toPages->diffKeys($fromPages),
            'removed' => $fromPages->diffKeys($toPages),
            'modified' => $this->findModified($fromPages, $toPages),
        ];
    }
}
```

```php id="dai01"
class DocsAiService
{
    public function answer(string $question): array
    {
        $results = $this->searchService->search($question, [
            'limit' => 5,
            'type' => 'documentation',

        $context = collect($results)
```

```php id="dwork02"
class DocumentationScheduler
{
    public function handle(): void
    {
        Page::where('status', 'scheduled')
            ->where('publish_at', '<=', now())
            ->each(function ($page) {
                $page->update(['status' => 'published']);
                $this->searchService->index($page);
                $this->cacheService->invalidate('docs');
```

### Previous/Next Navigation

```php id="dnav05"
class NavigationLinks
{
    public function getLinks(string $slug, string $version): array
    {
        $pages = Page::where('version', $version)
            ->orderBy('category')
            ->orderBy('order')
            ->get();

        $currentIndex = $pages->search(fn($p) => $p->slug === $slug);

        return [
            'previous' => $pages->get($currentIndex - 1),
            'next' => $pages->get($currentIndex + 1),
        ];
    }
}
```

```php id="dai04"
class DocsCodeGenerator
{
    public function generateComponent(string $name, array $props): string
    {
        $metadata = $this->registry->get($name);

        $blade = "<x-gsm-{$name}";
        foreach ($props as $key => $value) {
            if (is_bool($value)) {
                $blade .= $value ? " {$key}" : "";
            } else {
                $blade .= " {$key}=\"{$value}\"";
            }
        }
        $blade .= " />";

        return $blade;
    }

    public function generatePage(array $sections): string
    {
        $html = '';

        foreach ($sections as $section) {
            $html .= match ($section['type']) {
                'heading' => "<h{$section['level']}>{$section['text']}</h{$section['level']}>",
                'paragraph' => "<p>{$section['text']}</p>",
                'code' => "<pre><code>{$section['code']}</code></pre>",
                'component' => $this->generateComponent($section['name'], $section['props']),
                default => '',
            };
        }

        return $html;
    }
}
```

```php id="dtest02"
class LinkChecker
{
    public function check(Page $page): array
    {
        $links = $this->extractLinks($page->content);
        $broken = [];

        foreach ($links as $link) {
            if (str_starts_with($link, '/')) {
                // Internal link
                $exists = Page::where('slug', ltrim($link, '/'))->exists();
                if (!$exists) {
                    $broken[] = $link;
                }
            } elseif (str_starts_with($link, 'http')) {
                // External link
                $response = Http::head($link);
                if ($response->failed()) {
                    $broken[] = $link;
                }
            }
        }

        return $broken;
    }
}
```

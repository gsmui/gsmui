### Payment State Machine

```text
State: active
    |
    +-- [payment_succeeded] --> active
    |       +-- Reset payment_retry_count
    |       +-- Update last_payment_at
    |       +-- Update next_billing_at
    |       +-- Generate invoice
    |       +-- Send receipt email
    |
    +-- [payment_failed] --> past_due
    |       +-- Increment payment_retry_count
    |       +-- Set payment_failed_at
    |       +-- Send failure notification
    |       +-- Schedule retry (if < 3 retries)
    |
    +-- [all_retries_failed] --> grace_period
    |       +-- Send grace period notification
    |       +-- Schedule grace period expiry (3 days)
    |
    +-- [grace_period_expired] --> inactive
    |       +-- Downgrade to free tier
    |       +-- Revoke Pro features
    |       +-- Send downgrade notification
    |
    +-- [user_cancels] --> cancelled
    |       +-- Set cancel_at_period_end = true
    |       +-- Access until period end
    |       +-- Send cancellation confirmation
    |
    +-- [period_end] (if cancelled) --> inactive
            +-- Revoke access
            +-- Send final notification
```

### Download State Machine

```text
User requests download
    |
    +-- Check: Is user authenticated?
    |   +-- No --> 401 Unauthorized
    |   +-- Yes --> Continue
    |
    +-- Check: Is component approved?
    |   +-- No --> 404 Not Found
    |   +-- Yes --> Continue
    |
    +-- Check: Is component premium?
    |   +-- Yes --> Check: User has premium access?
    |   |   +-- No --> 403 Forbidden (upgrade prompt)
    |   |   +-- Yes --> Continue
    |   +-- No --> Continue
    |
    +-- Check: Has user exceeded monthly limit?
    |   +-- Yes --> 429 Too Many Requests (upgrade prompt)
    |   +-- No --> Continue
    |
    +-- Check: Has user exceeded burst limit?
    |   +-- Yes --> 429 Too Many Requests (try again in N seconds)
    |   +-- No --> Continue
    |
    +-- Record download
    |   +-- Insert into downloads table
    |   +-- Increment downloads_this_month
    |   +-- Increment component downloads_count
    |
    +-- Check: Has user reached 80% of limit?
    |   +-- Yes --> Send warning notification
    |   +-- No --> Continue
    |
    +-- Generate download URL
    |   +-- Create signed S3 URL (expires in 5 minutes)
    |   +-- Return download URL to user
```

### Discount Calculation

```text
Discount Calculation Flow
    |
    +-- Base price = product price
    |
    +-- Apply coupon discount
    |   +-- Percentage: discount = base * (coupon_value / 100)
    |   +-- Fixed amount: discount = coupon_value
    |   +-- Free trial: discount = base (full discount)
    |
    +-- Apply minimum order check
    |   +-- If (base - discount) < minimum_order --> Coupon invalid
    |
    +-- Calculate tax
    |   +-- Tax = (base - discount) * tax_rate
    |   +-- Tax rate determined by user location
    |
    +-- Final total = base - discount + tax
    |
    +-- Validate: final_total >= 0
```

# Component Endpoints (Detailed)

## List Components

```
GET /v1/components
```

**Query Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| page | int | 1 | Page number |
| per_page | int | 20 | Items per page (max: 100) |
| category | string | null | Filter by category slug |
| search | string | null | Full-text search query |
| sort | string | created_at | Sort field: name, created_at, downloads_count, stars_count |
| order | string | desc | Sort direction: asc, desc |
| is_premium | bool | null | Filter by premium status |
| author | string | null | Filter by author slug |
| tags | string | null | Comma-separated tag slugs |
| laravel_version | string | null | Filter by Laravel version compatibility |

## Download Component

```
POST /v1/components/{slug}/download
Authorization: Bearer {token}
```

**Request Body:**

```json
{
    "version": "2.1.0"
}
```

**Response (200 OK):**

```json
{
    "data": {
        "download_url": "https://cdn.gsmui.com/components/datatable/2.1.0/gsmui-datatable.zip",

        "version": "2.1.0",
        "file_size_bytes": 45056,
```

# Webhook Endpoints

```

Authorization: Bearer {token}
```

**Request Body:**

```json
{
    "url": "https://example.com/webhooks/gsmui",
    "events": ["component.downloaded", "subscription.activated", "order.paid"]
```

**Response (201 Created):**

```json
{
    "data": {
        "id": 1,
```

```json
    "id": "evt_abc123",
```

## Webhook Events

| Event | Description | Payload |
|-------|-------------|---------|
| component.downloaded | Component downloaded | Component, user, version |
| component.approved | Component approved for listing | Component |
| component.rejected | Component rejected | Component, reason |
| subscription.activated | Subscription started | Subscription, plan |
| subscription.cancelled | Subscription cancelled | Subscription |
| subscription.payment_failed | Payment failed | Subscription, error |
| order.paid | Order paid | Order, items |
| order.refunded | Order refunded | Order, refund amount |
| showcase.project_approved | Showcase project approved | Project |
| user.registered | New user registered | User |

# API Response Standards

## Success Response Format

```json
{
    "data": {},
    "meta": {},
    "links": {}
}
```

## Error Response Format

```json
{
    "error": {
        "code": "validation_error",
        "message": "The given data failed to pass validation.",
        "details": [
            {
                "field": "email",
                "message": "The email has already been taken."
            }
        ]
    }
}
```

## Error Codes

| Code | HTTP Status | Description |
|------|------------|-------------|
| unauthorized | 401 | Authentication required |
| forbidden | 403 | Insufficient permissions |
| not_found | 404 | Resource not found |
| validation_error | 422 | Request validation failed |
| rate_limit_exceeded | 429 | Too many requests |
| server_error | 500 | Internal server error |
| service_unavailable | 503 | Service temporarily unavailable |
| download_limit_exceeded | 429 | Monthly download limit reached |
| trial_already_used | 403 | Free trial already used |
| payment_required | 402 | Subscription required |
| component_not_approved | 403 | Component not yet approved |
| order_already_paid | 409 | Order already processed |

## Pagination Format

```json
{
    "data": [],
    "meta": {
        "current_page": 1,
        "per_page": 20,
        "total": 156,
        "last_page": 8
    },
    "links": {
        "first": "https://api.gsmui.com/v1/resource?page=1",
        "last": "https://api.gsmui.com/v1/resource?page=8",
        "prev": null,
        "next": "https://api.gsmui.com/v1/resource?page=2"
    }
}
```

## Sort Format

Append `?sort=field&order=desc` to any list endpoint:

```
GET /v1/components?sort=downloads_count&order=desc
GET /v1/blog?sort=published_at&order=desc
GET /v1/showcase?sort=likes_count&order=desc
```

## Filter Format

Use `filter[field]=value` query parameters:

```
GET /v1/components?filter[category]=data-display&filter[is_premium]=true
GET /v1/users?filter[status]=active&filter[role]=pro
GET /v1/orders?filter[status]=paid&filter[paid_at][from]=2026-01-01
```

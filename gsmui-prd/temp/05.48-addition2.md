# Policy Rules Summary

## UserPolicy

| Method | Allowed When |
|--------|-------------|
| viewAny | User is admin |
| view | User is viewing self OR is admin |
| create | Always (registration) |
| update | User is updating self OR is admin |
| delete | User is deleting self OR is admin |
| suspend | User is admin |
| ban | User is admin |

## ComponentPolicy

| Method | Allowed When |
|--------|-------------|
| viewAny | Always (public listing) |
| view | Component is published OR user is author OR user is admin |
| create | User is authenticated |
| update | User is author OR is admin |
| delete | User is author OR is admin |
| submit | User is author AND component is in draft |
| approve | User is admin |
| reject | User is admin |
| download | Component is published AND user has access |

## SubscriptionPolicy

| Method | Allowed When |
|--------|-------------|
| viewAny | User is viewing own subscriptions |
| view | User is owner OR is admin |
| create | User is authenticated AND eligible |
| cancel | User is owner AND subscription is active |
| changePlan | User is owner AND subscription is active |
| refund | User is owner AND within refund window |

## OrderPolicy

| Method | Allowed When |
|--------|-------------|
| viewAny | User is viewing own orders |
| view | User is owner OR is admin |
| create | User is authenticated |
| refund | User is owner OR is admin AND within refund window |
| cancel | User is owner AND order is pending |

## BlogPostPolicy

| Method | Allowed When |
|--------|-------------|
| viewAny | Always (public listing) |
| view | Post is published OR user is author OR user is admin |
| create | User is authenticated AND has publish permission |
| update | User is author OR is admin |
| delete | User is author OR is admin |
| publish | User is author AND has publish permission OR is admin |

## ShowcaseProjectPolicy

| Method | Allowed When |
|--------|-------------|
| viewAny | Project is approved OR user is owner OR user is admin |
| view | Project is approved OR user is owner OR user is admin |
| create | User is authenticated |
| update | User is owner |
| delete | User is owner OR is admin |
| approve | User is admin |

## CouponPolicy

| Method | Allowed When |
|--------|-------------|
| viewAny | User is admin |
| view | User is admin |
| create | User is admin |
| update | User is admin |
| delete | User is admin |
| apply | Coupon is valid AND user meets conditions |

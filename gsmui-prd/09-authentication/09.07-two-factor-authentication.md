# 09.07 — Two-Factor Authentication

## Purpose

Define the Two-Factor Authentication (2FA) system for GsmUi using TOTP (Time-based One-Time Password) and recovery codes.

## 2FA Flow

### Setup Flow

```text
User goes to Settings → Security → Two-Factor Authentication
    ↓
Clicks "Enable Two-Factor Authentication"
    ↓
Confirms password (password.confirm middleware)
    ↓
System generates TOTP secret
    ↓
Displays QR code + manual entry key
    ↓
User scans QR code with authenticator app
    ↓
User enters 6-digit code to verify
    ↓
System verifies code against secret
    ↓
System generates 8 recovery codes
    ↓
User saves recovery codes
    ↓
2FA is enabled
```

### Login with 2FA

```text
User enters email + password
    ↓
Credentials verified
    ↓
Check if 2FA is enabled
    ↓
If enabled → redirect to /two-factor-challenge
    ↓
User enters TOTP code OR recovery code
    ↓
Code verified
    ↓
Session fully authenticated
    ↓
Redirect to dashboard
```

## Livewire Components

### Two-Factor Setup

```php
// app/Livewire/Settings/TwoFactorSetup.php

class TwoFactorSetup extends Component
{
    public ?string $qrCodeSvg = null;
    public ?string $secret = null;
    public ?string $recoveryCodes = null;
    public string $code = '';
    public bool $enabled = false;
    public bool $showingRecoveryCodes = false;

    public function mount(): void
    {
        $user = Auth::user();
        $this->enabled = $user->hasTwoFactorEnabled();

        if ($this->enabled) {
            $this->recoveryCodes = decrypt($user->two_factor_recovery_codes);
        }
    }

    public function enable(): void
    {
        $user = Auth::user();
        $this->secret = $user->createTwoFactorAuthenticator()->generateSecretKey();
        $this->qrCodeSvg = $user->createTwoFactorAuthenticator()
            ->QRCodeUri($user->email, 'GsmUi', $this->secret);
    }

    public function confirm(): void
    {
        $user = Auth::user();

        $this->validate([
            'code' => ['required', 'string', 'size:6'],
        ]);

        $google2fa = app('pragmarx.google2fa');
        if (! $google2fa->verifyKey($this->secret, $this->code)) {
            $this->addError('code', 'The provided code is invalid.');
            return;
        }

        $recoveryCodes = $user->generateRecoveryCodes();

        $user->forceFill([
            'two_factor_secret' => encrypt($this->secret),
            'two_factor_recovery_codes' => encrypt($recoveryCodes),
            'two_factor_confirmed_at' => now(),
        ])->save();

        $this->enabled = true;
        $this->recoveryCodes = $recoveryCodes;
        $this->showingRecoveryCodes = true;

        event(new TwoFactorEnabled($user));
    }

    public function disable(): void
    {
        $user = Auth::user();

        $user->forceFill([
            'two_factor_secret' => null,
            'two_factor_recovery_codes' => null,
            'two_factor_confirmed_at' => null,
        ])->save();

        $this->enabled = false;
        $this->qrCodeSvg = null;
        $this->secret = null;
        $this->recoveryCodes = null;

        event(new TwoFactorDisabled($user));
    }
}
```

### Two-Factor Challenge (Login)

```php
// app/Livewire/Auth/TwoFactorChallenge.php

class TwoFactorChallenge extends Component
{
    public string $code = '';
    public string $recoveryCode = '';
    public bool $usingRecoveryCode = false;

    protected array $rules = [
        'code' => ['required_without:recoveryCode', 'string', 'size:6'],
        'recoveryCode' => ['required_without:code', 'string'],
    ];

    public function challenge(): void
    {
        $this->validate();

        $user = Auth::user();

        if ($this->usingRecoveryCode) {
            $this->verifyRecoveryCode($user);
        } else {
            $this->verifyTotpCode($user);
        }

        session(['two_factor_verified' => true]);

        redirect()->intended('/dashboard');
    }

    protected function verifyTotpCode(User $user): void
    {
        $google2fa = app('pragmarx.google2fa');

        if (! $google2fa->verifyKey(
            decrypt($user->two_factor_secret),
            $this->code
        )) {
            $this->addError('code', 'The provided code is invalid.');
            return;
        }
    }

    protected function verifyRecoveryCode(User $user): void
    {
        $recoveryCodes = decrypt($user->two_factor_recovery_codes);

        if (! in_array($this->recoveryCode, $recoveryCodes)) {
            $this->addError('recoveryCode', 'The provided recovery code is invalid.');
            return;
        }

        // Remove used recovery code
        $recoveryCodes = array_diff($recoveryCodes, [$this->recoveryCode]);
        $user->update([
            'two_factor_recovery_codes' => encrypt(array_values($recoveryCodes)),
        ]);
    }
}
```

## Recovery Codes

* 8 recovery codes generated on 2FA setup
* Each code is single-use
* Codes are stored encrypted in `users.two_factor_recovery_codes`
* Users can regenerate recovery codes from settings
* Recovery codes bypass the 6-digit TOTP requirement

## Database Schema

```sql
ALTER TABLE users ADD COLUMN two_factor_secret TEXT NULL;
ALTER TABLE users ADD COLUMN two_factor_recovery_codes TEXT NULL;
ALTER TABLE users ADD COLUMN two_factor_confirmed_at TIMESTAMP NULL;
```

## Session Security

After 2FA verification, the session stores:

```php
session(['two_factor_verified' => true]);
```

Middleware checks this flag for sensitive operations:

```php
// TwoFactorMiddleware
if (auth()->check() && auth()->user()->hasTwoFactorEnabled() && ! session('two_factor_verified')) {
    return redirect('/two-factor-challenge');
}
```

| Event | Triggered When |
|---|---|
| `TwoFactorEnabled` | 2FA setup confirmed |
| `TwoFactorDisabled` | 2FA removed from account |
| `RecoveryCodeUsed` | Recovery code used during login |
| `RecoveryCodesRegenerated` | New recovery codes generated |

## Security Notes

* TOTP secret is encrypted at rest
* Recovery codes are encrypted at rest
* Failed 2FA attempts are rate-limited (5 per minute)
* Recovery code usage is logged
* 2FA setup requires password confirmation
* QR code is not stored — generated on demand

## Detailed 2FA Architecture

### TOTP (Time-based One-Time Password) Deep Dive

TOTP is an extension of HOTP (HMAC-based One-Time Password) that generates a new code every 30 seconds based on the current time.

#### TOTP Parameters

| Parameter | Value | Rationale |
|---|---|---|
| Digits | 6 | Standard length, easy to type |
| Period | 30 seconds | Balance between security and usability |
| Algorithm | SHA-1 | Standard algorithm, compatible with all apps |
| Window | 1 | Allow 30-second drift in either direction |

#### TOTP Code Generation

```php
// app/Services/TotpService.php

class TotpService
{
    public function generateSecret(): string
    {
        return $this->google2fa->generateSecretKey();
    }

    public function getQrCodeUri(string $email, string $secret): string
    {
        return $this->google2fa->getQRCodeUri(
            $this->google2fa->getQRCodeUrl(
                config('app.name'),
                $email,
                $secret
            )
        );
    }

    public function verify(string $secret, string $code): bool
    {
        return $this->google2fa->verifyKey($secret, $code, 1);
    }

    public function generateRecoveryCodes(): array
    {
        $codes = [];
        for ($i = 0; $i < 8; $i++) {
            $codes[] = strtoupper(Str::random(4) . '-' . Str::random(4));
        }
        return $codes;
    }
}
```

```php
{

}
```

### Recovery Codes Deep Dive

Recovery codes provide backup access when TOTP is unavailable.

#### Recovery Code Format

```
ABCD-EFGH
IJKL-MNOP
QRST-UVWX
YZAB-CDEF
GHIJ-KLMN
OPQR-STUV
WXAB-CDEF
GHIJ-KLMN
```

#### Recovery Code Storage

```php
// Encrypted in database
$user->two_factor_recovery_codes = encrypt([
    'ABCD-EFGH',
    'IJKL-MNOP',
    // ... 8 codes total
]);
```

#### Recovery Code Usage

```php
// When a recovery code is used
public function verifyRecoveryCode(User $user, string $code): bool
{
    $recoveryCodes = decrypt($user->two_factor_recovery_codes);

    if (in_array($code, $recoveryCodes)) {
        // Remove used code
        $recoveryCodes = array_diff($recoveryCodes, [$code]);
        $user->update([
            'two_factor_recovery_codes' => encrypt(array_values($recoveryCodes)),
        ]);

        return true;
    }

    return false;
}
```

```php
    public function test_recovery_code_is_single_use()
    {

        $recoveryCodes = ['ABCD-EFGH', 'IJKL-MNOP'];

        $user->update([
            'two_factor_recovery_codes' => encrypt($recoveryCodes),
        ]);

        // First use succeeds
        $this->assertTrue(
            in_array('ABCD-EFGH', decrypt($user->two_factor_recovery_codes))
        );

        // Remove used code
        $remainingCodes = array_diff($recoveryCodes, ['ABCD-EFGH']);
        $user->update([
            'two_factor_recovery_codes' => encrypt(array_values($remainingCodes)),
        ]);

        // Second use fails
        $this->assertFalse(
            in_array('ABCD-EFGH', decrypt($user->fresh()->two_factor_recovery_codes))
        );
    }
}
```

| Issue | Cause | Solution |
|---|---|---|
| TOTP code not working | Time drift | Sync device clock |
| Recovery code not working | Already used or invalid | Generate new codes |
| QR code not scanning | Camera permission | Check browser settings |
| 2FA setup fails | Invalid code | Verify code with authenticator app |
| Can't disable 2FA | Password confirmation required | Enter current password |

```php
            'two_factor_recovery_codes' => null,
            'two_factor_confirmed_at' => null,
        ])->save();

// app/Http/Controllers/TwoFactorChallengeController.php

class TwoFactorChallengeController extends Controller
{
    public function show(): View
    {
        return view('auth.two-factor-challenge');
    }

    public function store(Request $request): RedirectResponse
    {
        $request->validate([
            'code' => ['required_without:recovery_code', 'string', 'size:6'],
            'recovery_code' => ['required_without:code', 'string'],
        ]);

        $user = Auth::user();

        if ($request->has('recovery_code')) {
            $this->verifyRecoveryCode($user, $request->recovery_code);
        } else {
            $this->verifyTotpCode($user, $request->code);
        }

        session(['two_factor_verified' => true]);

        return redirect()->intended('/dashboard');
    }

    protected function verifyTotpCode(User $user, string $code): void
    {
        $google2fa = app('pragmarx.google2fa');

        if (! $google2fa->verifyKey(decrypt($user->two_factor_secret), $code)) {
            throw ValidationException::withMessages([
                'code' => 'The provided code is invalid.',
            ]);
        }
    }

    protected function verifyRecoveryCode(User $user, string $code): void
    {
        $recoveryCodes = decrypt($user->two_factor_recovery_codes);

        if (! in_array($code, $recoveryCodes)) {
            throw ValidationException::withMessages([
                'recovery_code' => 'The provided recovery code is invalid.',

        }

        // Remove used code
        $recoveryCodes = array_values(array_diff($recoveryCodes, [$code]));
        $user->update([
            'two_factor_recovery_codes' => encrypt($recoveryCodes),
        ]);

        event(new RecoveryCodeUsed($user));
    }
```

### 2FA Service

```php
// app/Services/TwoFactorService.php

class TwoFactorService
{
    public function generateSecret(): string
    {
        return app('pragmarx.google2fa')->generateSecretKey();
    }

    public function getQrCodeUri(string $email, string $secret): string
    {
        return app('pragmarx.google2fa')->getQRCodeUrl(
            config('app.name'),
            $email,
            $secret
        );
    }

    public function verifyCode(string $secret, string $code): bool
    {
        return app('pragmarx.google2fa')->verifyKey($secret, $code, 1);
    }

    public function generateRecoveryCodes(): array
    {
        $codes = [];
        for ($i = 0; $i < 8; $i++) {
            $codes[] = strtoupper(Str::random(4) . '-' . Str::random(4));
        }
        return $codes;
    }

    public function verifyRecoveryCode(User $user, string $code): bool
    {
        $recoveryCodes = decrypt($user->two_factor_recovery_codes);

        if (! in_array($code, $recoveryCodes)) {
            return false;
        }

        // Remove used code
        $recoveryCodes = array_values(array_diff($recoveryCodes, [$code]));
        $user->update([
            'two_factor_recovery_codes' => encrypt($recoveryCodes),
        ]);

        return true;
    }

    public function enable(User $user, string $secret, string $code): array
    {
        if (! $this->verifyCode($secret, $code)) {
            throw new InvalidTwoFactorCodeException();
        }

        $recoveryCodes = $this->generateRecoveryCodes();

        $user->forceFill([
            'two_factor_secret' => encrypt($secret),
            'two_factor_recovery_codes' => encrypt($recoveryCodes),
            'two_factor_confirmed_at' => now(),
        ])->save();

        return $recoveryCodes;
    }

    public function disable(User $user): void
    {
        $user->forceFill([
            'two_factor_secret' => null,
            'two_factor_recovery_codes' => null,
            'two_factor_confirmed_at' => null,
        ])->save();
    }

    public function isEnabled(User $user): bool
    {
        return $user->two_factor_secret !== null
            && $user->two_factor_confirmed_at !== null;
    }

    public function isVerified(User $user): bool
    {
        return ! $this->isEnabled($user) || session('two_factor_verified', false);
    }
}
```

```php
class RequireTwoFactorAuthentication
{
    public function handle(Request $request, Closure $next)
    {
        $user = $request->user();

        if (! $user) {
            return $next($request);
        }

        $twoFactorService = app(TwoFactorService::class);

        if ($twoFactorService->isEnabled($user) && ! $twoFactorService->isVerified($user)) {
            return redirect('/two-factor-challenge');
        }

        return $next($request);
    }
```

- [ ] Recovery codes are single-use
- [ ] Session stores 2FA verification status

- [ ] Activity logging for all 2FA events
- [ ] IP logging for 2FA verification
- [ ] User agent logging for 2FA verification

### 2FA Challenge Livewire Component

```php
// app/Livewire/Auth/TwoFactorChallengeForm.php

namespace App\Livewire\Auth;

use App\Models\User;
use Illuminate\Support\Facades\Auth;
use Livewire\Component;

class TwoFactorChallengeForm extends Component
{
    public string $code = '';
    public string $recoveryCode = '';
    public bool $usingRecoveryCode = false;
    public bool $isSubmitting = false;
    public string $status = '';

    public function toggleRecoveryCode(): void
    {
        $this->usingRecoveryCode = ! $this->usingRecoveryCode;
        $this->code = '';
        $this->recoveryCode = '';
        $this->resetErrorBag();
    }

    public function authenticate(): void
    {
        if ($this->usingRecoveryCode) {
            $this->validate([
                'recoveryCode' => ['required', 'string'],
            ]);
        } else {
            $this->validate([
                'code' => ['required', 'string', 'digits:6'],
            ]);
        }

        $this->isSubmitting = true;

        try {
            $userId = session('login.id');
            $user = User::find($userId);

            if (! $user) {
                throw new \Exception('User not found.');
            }

            if ($this->usingRecoveryCode) {
                $this->verifyRecoveryCode($user);
            } else {
                $this->verifyTotpCode($user);
            }

            // Complete login
            Auth::login($user, session('login.remember', false));

            session()->regenerate();
            session()->forget('login');
            session(['two_factor_verified' => true]);

            activity()
                ->performedOn($user)
                ->event('2fa_verified')
                ->withProperties([
                    'method' => $this->usingRecoveryCode ? 'recovery_code' : 'totp',
                    'ip' => request()->ip(),
                ])
                ->log('2FA verified');

            $this->status = 'success';

            return redirect()->intended(route('dashboard'));
        } catch (\Exception $e) {
            $this->status = 'error';
            $this->addError('code', 'The provided code is invalid.');
        } finally {
            $this->isSubmitting = false;
        }
    }

    protected function verifyTotpCode(User $user): void
    {
        $secret = decrypt($user->two_factor_secret);

        $google2fa = app('pragmarx.google2fa');

        if (! $google2fa->verifyKey($secret, $this->code, 1)) {
            throw new \Exception('Invalid 2FA code.');
        }
    }

    protected function verifyRecoveryCode(User $user): void
    {
        $recoveryCodes = decrypt($user->two_factor_recovery_codes);

        if (! in_array($this->recoveryCode, $recoveryCodes)) {
            throw new \Exception('Invalid recovery code.');
        }

        // Remove used recovery code
        $recoveryCodes = array_diff($recoveryCodes, [$this->recoveryCode]);
        $user->update([
            'two_factor_recovery_codes' => encrypt(array_values($recoveryCodes)),
        ]);

        event(new RecoveryCodeUsed($user));
    }

    public function render()
    {
        return view('livewire.auth.two-factor-challenge-form');
    }
}
```

```php
// app/Providers/RouteServiceProvider.php

protected function configureRateLimiting(): void
{
    RateLimiter::for('two-factor', function (Request $request) {
        return [
            Limit::perMinute(5)->by($request->ip()),
            Limit::perHour(20)->by($request->ip()),
            Limit::perMinute(3)->by('2fa:' . $request->user()?->id),
        ];
    });

    RateLimiter::for('two-factor-recovery', function (Request $request) {
        return Limit::perHour(3)->by('2fa-recovery:' . $request->user()?->id);
    });
}
```

### 2FA Testing Commands

```php
// app/Console/Commands/TestTwoFactor.php

class TestTwoFactor extends Command
{
    protected $signature = '2fa:test {email} {--code=} {--recovery=}';
    protected $description = 'Test 2FA for a user';

    public function handle(): int
    {
        $user = User::where('email', $this->argument('email'))->first();
        
        if (! $user) {
            $this->error("User not found");
            return 1;
        }

        if (! $user->hasTwoFactorEnabled()) {
            $this->error("2FA not enabled for user");
            return 1;
        }

        $code = $this->option('code');
        $recovery = $this->option('recovery');

        $service = app(TwoFactorService::class);

        if ($code) {
            $secret = decrypt($user->two_factor_secret);
            $valid = $service->verifyCode($secret, $code);
            $this->info($valid ? "TOTP code VALID" : "TOTP code INVALID");
        }

        if ($recovery) {
            $valid = $service->verifyRecoveryCode($user, $recovery);
            $this->info($valid ? "Recovery code VALID" : "Recovery code INVALID");
            
            if ($valid) {
                $remaining = count(decrypt($user->fresh()->two_factor_recovery_codes));
                $this->info("Remaining recovery codes: {$remaining}");
            }
        }

        return 0;
    }
}
```

### 2FA Monitoring Queries

```php
// app/Services/TwoFactorMonitoringService.php

class TwoFactorMonitoringService
{
    public function getAdoptionRate(): float
    {
        $total = User::count();
        $with2fa = User::whereNotNull('two_factor_confirmed_at')->count();
        
        return $total > 0 ? round(($with2fa / $total) * 100, 2) : 0;
    }

    public function getVerificationSuccessRate(int $days = 30): float
    {
        $total = DB::table('activity_log')
            ->where('log_name', 'auth')
            ->where('event', '2fa_verified')
            ->where('created_at', '>', now()->subDays($days))
            ->count();

        $success = DB::table('activity_log')
            ->where('log_name', 'auth')
            ->where('event', '2fa_verified')
            ->where('created_at', '>', now()->subDays($days))
            ->whereJsonContains('properties->method', 'totp')
            ->count();

        $recovery = DB::table('activity_log')
            ->where('log_name', 'auth')
            ->where('event', '2fa_verified')
            ->where('created_at', '>', now()->subDays($days))
            ->whereJsonContains('properties->method', 'recovery_code')
            ->count();

        return $total > 0 ? round((($success + $recovery) / $total) * 100, 2) : 0;
    }

    public function getRecoveryCodeUsageRate(int $days = 30): float
    {
        $total = DB::table('activity_log')
            ->where('log_name', 'auth')
            ->where('event', '2fa_verified')
            ->where('created_at', '>', now()->subDays($days))
            ->count();

        $recovery = DB::table('activity_log')
            ->where('log_name', 'auth')
            ->where('event', 'recovery_code_used')
            ->where('created_at', '>', now()->subDays($days))
            ->count();

        return $total > 0 ? round(($recovery / $total) * 100, 2) : 0;
    }

    public function getFailedAttempts(int $days = 7): int
    {
        return DB::table('activity_log')
            ->where('log_name', 'auth')
            ->where('event', '2fa_failed')
            ->where('created_at', '>', now()->subDays($days))
            ->count();
    }
}
```

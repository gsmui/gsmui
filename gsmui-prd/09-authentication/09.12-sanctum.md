# 09.12 — Sanctum

## Purpose

Define the Laravel Sanctum configuration and integration for GsmUi, covering SPA authentication, API token authentication, and microservice authentication.

## Sanctum Overview

Sanctum provides two authentication mechanisms:

1. **Cookie-based authentication** — for first-party SPAs
2. **Token-based authentication** — for API access, MCP, CLI

## Security Notes

* Tokens hashed with SHA-256 before storage
* Plain-text token shown only once
* Tokens can be revoked individually or all at once
* SPA authentication uses session cookies
* CSRF protection for SPA routes
* Rate limiting on all API endpoints
* Token expiration configurable per token
* IP and user agent logged with each token

### SPA Authentication Flow

```text
1. SPA Initialization
   → SPA loads in browser
   → Check if user is authenticated (GET /api/user)
   → If not authenticated, show login form

2. CSRF Cookie
   → Before login, SPA requests /sanctum/csrf-cookie
   → Browser receives CSRF cookie
   → SPA extracts XSRF-TOKEN from cookie

3. Login Request
   → SPA sends POST /login with credentials
   → Includes X-XSRF-TOKEN header
   → Laravel validates CSRF token
   → Session created
   → User authenticated

4. Subsequent Requests
   → SPA includes session cookie in requests
   → Includes X-XSRF-TOKEN header
   → Laravel authenticates via session
   → User data returned

5. Logout
   → SPA sends POST /logout
   → Session invalidated
   → Cookie cleared
   → Redirect to login
```

```php
Route::post('/login', function (Request $request) {
    $credentials = $request->validate([
        'email' => ['required', 'email'],
        'password' => ['required'],
    ]);

    if (! Auth::attempt($credentials, $request->boolean('remember'))) {
        throw ValidationException::withMessages([
```

## Troubleshooting

### Common Issues

| Issue | Cause | Solution |
|---|---|---|
| `CSRF token mismatch` | Missing CSRF cookie | Call `/sanctum/csrf-cookie` before login |

## Detailed Token Management

### Token Creation Service

```php
// app/Services/SanctumTokenService.php

namespace App\Services;

use App\Models\User;
use App\Models\PersonalAccessToken;
use Illuminate\Support\Str;

class SanctumTokenService
{
    /**
     * Create a new API token with full configuration.
     */
    public function createToken(
        User $user,
        string $name,
        array $abilities = ['*'],
        ?string $expiration = null,
        ?string $prefix = null,
    ): PersonalAccessToken {
        $token = $user->createToken(
            $name,
            $abilities,
            $this->resolveExpiration($expiration),
        );

        if ($prefix) {
            $token->accessToken->update([
                'name' => $prefix . ':' . $name,
            ]);
        }

        activity()
            ->performedOn($user)
            ->withProperties([
                'token_name' => $name,
                'abilities' => $abilities,
                'expiration' => $expiration,
                'ip' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ])
            ->log('Sanctum token created');

        return $token->accessToken;
    }

    /**
     * Create a token for a specific guard.
     */
    public function createGuardToken(
        User $user,
        string $guard,
        string $name,
        array $abilities = ['*'],
    ): PersonalAccessToken {
        return $this->createToken(
            $user->withGuard($guard),
            $name,
            $abilities,
        );
    }

    /**
     * Create a short-lived token.
     */
    public function createShortLivedToken(
        User $user,
        string $name,
        array $abilities = ['*'],
        int $minutes = 60,
    ): PersonalAccessToken {
        return $this->createToken(
            $user,
            $name,
            $abilities,
            now()->addMinutes($minutes)->toIso8601String(),
        );
    }

    /**
     * Create a long-lived token.
     */
    public function createLongLivedToken(
        User $user,
        string $name,
        array $abilities = ['*'],
        int $days = 365,
    ): PersonalAccessToken {
        return $this->createToken(
            $user,
            $name,
            $abilities,
            now()->addDays($days)->toIso8601String(),
        );
    }

    /**
     * Create a token that never expires.
     */
    public function createPermanentToken(
        User $user,
        string $name,
        array $abilities = ['*'],
    ): PersonalAccessToken {
        return $this->createToken(
            $user,
            $name,
            $abilities,
            null, // No expiration
        );
    }

    /**
     * Rotate an existing token.
     */
    public function rotateToken(
        User $user,
        int $tokenId,
        ?string $newName = null,
    ): PersonalAccessToken {
        $oldToken = $user->tokens()->where('id', $tokenId)->first();

        if (! $oldToken) {
            throw new \InvalidArgumentException('Token not found.');
        }

        // Create new token with same abilities
        $newToken = $user->createToken(
            $newName ?? $oldToken->name,
            $oldToken->abilities,
            $oldToken->expires_at,
        );

        // Revoke old token
        $oldToken->delete();

        activity()
            ->performedOn($user)
            ->withProperties([
                'old_token_name' => $oldToken->name,
                'new_token_name' => $newToken->accessToken->name,
                'ip' => request()->ip(),
            ])
            ->log('Sanctum token rotated');

        return $newToken->accessToken;
    }

    /**
     * Get token usage statistics.
     */
    public function getTokenStats(User $user): array
    {
        $tokens = $user->tokens;

        return [
            'total' => $tokens->count(),
            'active' => $tokens->filter(fn($t) => ! $t->expires_at || $t->expires_at->isFuture())->count(),
            'expired' => $tokens->filter(fn($t) => $t->expires_at && $t->expires_at->isPast())->count(),
            'last_used' => $tokens->max('last_used_at'),
            'scopes' => $tokens->flatMap(fn($t) => $t->abilities)->unique()->values()->toArray(),
        ];
    }

    /**
     * Resolve expiration to Carbon instance.
     */
    protected function resolveExpiration(?string $expiration): ?\Carbon\Carbon
    {
        if (! $expiration) {
            return null;
        }

        return \Carbon\Carbon::parse($expiration);
    }
}
```

### Token Validation Service

```php
// app/Services/TokenValidationService.php

namespace App\Services;

use App\Models\PersonalAccessToken;
use App\Models\User;
use Illuminate\Support\Facades\Hash;

class TokenValidationService
{
    /**
     * Validate a token by its plain text value.
     */
    public function validateToken(string $plainTextToken): ?PersonalAccessToken
    {
        $token = PersonalAccessToken::findToken($plainTextToken);

        if (! $token) {
            return null;
        }

        // Check if token is expired
        if ($token->expires_at && $token->expires_at->isPast()) {
            $token->delete();
            return null;
        }

        return $token;
    }

    /**
     * Validate token abilities.
     */
    public function validateAbilities(
        PersonalAccessToken $token,
        array $requiredAbilities,
    ): bool {
        foreach ($requiredAbilities as $ability) {
            if (! in_array($ability, $token->abilities) && ! in_array('*', $token->abilities)) {
                return false;
            }
        }

        return true;
    }

    /**
     * Check if token is rate limited.
     */
    public function isRateLimited(PersonalAccessToken $token): bool
    {
        $rateLimiter = \Illuminate\Support\Facades\RateLimiter;

        $key = 'sanctum:token:' . $token->id;

        return $rateLimiter->tooManyAttempts($key, 60);
    }

    /**
     * Increment rate limiter for token.
     */
    public function incrementRateLimit(PersonalAccessToken $token): void
    {
        $rateLimiter = \Illuminate\Support\Facades\RateLimiter;

        $key = 'sanctum:token:' . $token->id;

        $rateLimiter::hit($key, 60);
    }

    /**
     * Get token owner.
     */
    public function getTokenOwner(PersonalAccessToken $token): ?User
    {
        return $token->tokenable;
    }

    /**
     * Check if token belongs to user.
     */
    public function tokenBelongsToUser(
        PersonalAccessToken $token,
        User $user,
    ): bool {
        return $token->tokenable_id === $user->id
            && $token->tokenable_type === get_class($user);
    }
}
```

## Token-Based API Implementation

### API Authentication Middleware

```php
// app/Http/Middleware/ApiTokenMiddleware.php

namespace App\Http\Middleware;

use App\Models\PersonalAccessToken;
use Closure;
use Illuminate\Http\Request;

class ApiTokenMiddleware
{
    /**
     * Handle an incoming request.
     */
    public function handle(Request $request, Closure $next, string ...$abilities): mixed
    {
        $token = $request->bearerToken();

        if (! $token) {
            return response()->json([
                'message' => 'Token not provided.',
            ], 401);
        }

        $accessToken = PersonalAccessToken::findToken($token);

        if (! $accessToken) {
            return response()->json([
                'message' => 'Invalid token.',
            ], 401);
        }

        // Check expiration
        if ($accessToken->expires_at && $accessToken->expires_at->isPast()) {
            $accessToken->delete();

            return response()->json([
                'message' => 'Token has expired.',
            ], 401);
        }

        // Check abilities
        if ($abilities && ! $accessToken->can($abilities)) {
            return response()->json([
                'message' => 'Insufficient permissions.',
                'required' => $abilities,
            ], 403);
        }

        // Update last used timestamp
        $accessToken->update(['last_used_at' => now()]);

        // Set authenticated user
        auth()->setUser($accessToken->tokenable);

        return $next($request);
    }
}
```

### Token Refresh Endpoint

```php
// app/Http/Controllers/TokenRefreshController.php

namespace App\Http\Controllers;

use App\Models\PersonalAccessToken;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;

class TokenRefreshController extends Controller
{
    /**
     * Refresh an existing token.
     */
    public function refresh(Request $request, int $tokenId): JsonResponse
    {
        $user = $request->user();

        $oldToken = $user->tokens()->where('id', $tokenId)->first();

        if (! $oldToken) {
            return response()->json([
                'message' => 'Token not found.',
            ], 404);
        }

        // Create new token with same abilities
        $newToken = $user->createToken(
            $oldToken->name,
            $oldToken->abilities,
            $oldToken->expires_at,
        );

        // Revoke old token
        $oldToken->delete();

        return response()->json([
            'message' => 'Token refreshed successfully.',
            'data' => [
                'token' => $newToken->plainTextToken,
                'name' => $newToken->accessToken->name,
                'abilities' => $newToken->accessToken->abilities,
                'expires_at' => $newToken->accessToken->expires_at,
            ],
        ]);
    }
}
```

```php
class TokenHashingService
{
    /**
     * Hash a token for storage.
     */
    public function hash(string $token): string
    {
        return hash('sha256', $token);
    }

    /**
     * Verify a token against its hash.
     */
    public function verify(string $token, string $hash): bool
    {

    }
```

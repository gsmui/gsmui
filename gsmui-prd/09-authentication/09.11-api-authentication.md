# 09.11 — API Authentication

## Purpose

Define the API authentication architecture for GsmUi, covering stateless token-based auth, Sanctum integration, and API access patterns.

## API Authentication Methods

| Method | Use Case | Implementation |
|---|---|---|
| Sanctum Token | Third-party integrations | Personal Access Tokens |
| SPA Authentication | First-party SPA | Cookie-based via Sanctum |
| MCP Authentication | AI/MCP clients | Token-based |
| CLI Authentication | Command-line tools | Token-based |

## Authentication Flow (Token)

```text
User creates API token (Settings → API)
    ↓
Token generated (hashed, stored in DB)
    ↓
User includes token in request header
    ↓
Middleware validates token
    ↓
User resolved from token
    ↓
Permissions checked
    ↓
Request processed
```

## Token Request Format

```http
POST /api/v1/themes HTTP/1.1
Host: gsmui.dev
Authorization: Bearer {token}
Content-Type: application/json
Accept: application/json
```

## Token Scopes

Tokens can be granted specific scopes:

| Scope | Description |
|---|---|
| `*` | Full access |
| `themes:read` | View themes |
| `themes:write` | Create/update themes |
| `components:read` | View components |
| `components:write` | Create/update components |
| `templates:read` | View templates |
| `marketplace:read` | Browse marketplace |
| `marketplace:write` | Manage marketplace products |
| `user:read` | View own profile |
| `user:write` | Update own profile |
| `billing:read` | View invoices/billing |
| `admin:*` | Full admin access |

## Security Notes

* Tokens are hashed (SHA-256) before storage
* Plain-text token shown only once at creation
* Tokens can be revoked at any time
* Token scope limits API access
* Tokens logged with creation IP and user agent
* Rate limiting per token and per IP
* Tokens expired after 90 days of inactivity (configurable)

## Detailed API Authentication Architecture

### Authentication Methods Comparison

| Method | Stateless | Use Case | Security | Complexity |
|---|---|---|---|---|
| Sanctum Token | Yes | Third-party APIs | High | Low |
| SPA Cookie | No | First-party SPA | High | Medium |
| MCP Token | Yes | AI/MCP clients | Medium | Low |
| CLI Token | Yes | Command-line tools | Medium | Low |
| Passport JWT | Yes | Microservices | High | High |

### Token-Based Authentication Flow (Detailed)

```text
1. User creates API token
   → Settings → API Tokens → Create New Token
   → Enters name, selects scopes, sets expiration
   → Confirms password (password.confirm middleware)
   → Token generated and displayed once
   → User copies token

2. User includes token in request
   → Authorization: Bearer {token}
   → Request sent to API endpoint

3. Token validation
   → auth:sanctum middleware invoked
   → Token extracted from Authorization header
   → Token hashed and looked up in database
   → Token validated (not expired, not revoked)
   → User resolved from token

4. Scope validation
   → Token abilities checked
   → Scope middleware applied
   → Access granted if scope matches

5. Request processing
   → Controller processes request
   → Rate limiting applied
   → Response returned
```

### SPA Authentication Flow (Detailed)

```text
1. SPA loads
   → SPA makes request to /sanctum/csrf-cookie
   → CSRF cookie set in browser

2. User logs in
   → SPA submits credentials to /login
   → Session cookie set
   → User authenticated via session

3. Subsequent requests
   → SPA includes session cookie
   → X-XSRF-TOKEN header included
   → Laravel validates CSRF token
   → Session-based authentication used

4. Session management
   → Session expires after 120 minutes
   → SPA can refresh session via /sanctum/csrf-cookie
   → Logout invalidates session
```

### MCP Authentication Flow (Detailed)

```text
1. MCP client requests token
   → User creates API token in GsmUi
   → Token configured in MCP client

2. MCP client uses token
   → Authorization: Bearer {token}
   → Request sent to MCP API endpoint

3. Token validation
   → Token validated
   → MCP scope checked (mcp:read, mcp:write)
   → Access granted

4. MCP operations
   → Read themes, components, templates
   → Write themes, components (if permitted)
   → Manage marketplace products (if permitted)
```

### Custom API Authentication Middleware

```php
// app/Http/Middleware/ApiAuthenticate.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class ApiAuthenticate
{
    public function handle(Request $request, Closure $next, string ...$scopes)
    {
        if (! Auth::guard('sanctum')->check()) {
            return response()->json([
                'message' => 'Unauthenticated.',
            ], 401);
        }

        $user = Auth::guard('sanctum')->user();

        if ($scopes && ! $user->tokenCan($scopes)) {
            return response()->json([
                'message' => 'Insufficient permissions.',
                'required' => $scopes,
            ], 403);
        }

        return $next($request);
    }
}
```

## API Token Management

### Token Service

```php
// app/Services/ApiTokenService.php

namespace App\Services;

use App\Models\User;
use App\Models\PersonalAccessToken;
use Illuminate\Support\Str;

class ApiTokenService
{
    /**
     * Create a new API token.
     */
    public function createToken(User $user, string $name, array $scopes, ?string $expiration = null): string
    {
        $token = $user->createToken($name, $scopes);

        if ($expiration) {
            $token->accessToken->update([
                'expires_at' => now()->addSeconds((int) $expiration),
            ]);
        }

        activity()
            ->performedOn($user)
            ->withProperties([
                'token_name' => $name,
                'scopes' => $scopes,
                'ip' => request()->ip(),
                'user_agent' => request()->userAgent(),
            ])
            ->log('API token created');

        return $token->plainTextToken;
    }

    /**
     * Revoke a token.
     */
    public function revokeToken(User $user, int $tokenId): bool
    {
        $token = $user->tokens()->where('id', $tokenId)->first();

        if (! $token) {
            return false;
        }

        $token->delete();

        activity()
            ->performedOn($user)
            ->withProperties([
                'token_name' => $token->name,
                'ip' => request()->ip(),
            ])
            ->log('API token revoked');

        return true;
    }

    /**
     * Revoke all tokens.
     */
    public function revokeAllTokens(User $user): int
    {
        $count = $user->tokens()->count();
        $user->tokens()->delete();

        activity()
            ->performedOn($user)
            ->withProperties([
                'revoked_count' => $count,
                'ip' => request()->ip(),
            ])
            ->log('All API tokens revoked');

        return $count;
    }

    /**
     * Get active tokens for a user.
     */
    public function getActiveTokens(User $user): \Illuminate\Database\Eloquent\Collection
    {
        return $user->tokens()
            ->where(function ($query) {
                $query->whereNull('expires_at')
                    ->orWhere('expires_at', '>', now());
            })
            ->get();
    }

    /**
     * Check if a token is valid.
     */
    public function isTokenValid(PersonalAccessToken $token): bool
    {
        if ($token->expires_at && $token->expires_at->isPast()) {
            return false;
        }

        return true;
    }

    /**
     * Rotate a token (create new, revoke old).
     */
    public function rotateToken(User $user, int $tokenId): ?string
    {
        $oldToken = $user->tokens()->where('id', $tokenId)->first();

        if (! $oldToken) {
            return null;
        }

        // Create new token with same abilities
        $newToken = $user->createToken(
            $oldToken->name,
            $oldToken->abilities
        );

        // Revoke old token
        $oldToken->delete();

        activity()
            ->performedOn($user)
            ->withProperties([
                'old_token_name' => $oldToken->name,
                'new_token_name' => $newToken->accessToken->name,
                'ip' => request()->ip(),
            ])
            ->log('API token rotated');

        return $newToken->plainTextToken;
    }

    /**
     * Get token usage statistics.
     */
    public function getTokenStats(User $user): array
    {
        $tokens = $user->tokens;

        return [
            'total' => $tokens->count(),
            'active' => $tokens->filter(fn($t) => $this->isTokenValid($t))->count(),
            'expired' => $tokens->filter(fn($t) => $t->expires_at && $t->expires_at->isPast())->count(),
            'last_used' => $tokens->max('last_used_at'),
            'scopes' => $tokens->flatMap(fn($t) => $t->abilities)->unique()->values()->toArray(),
        ];
    }
}
```

### Token Controller

```php
// app/Http/Controllers/Api/TokenController.php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Services\ApiTokenService;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class TokenController extends Controller
{
    public function __construct(
        protected ApiTokenService $tokenService,
    ) {}

    /**
     * List all tokens for the authenticated user.
     */
    public function index(Request $request): JsonResponse
    {
        $tokens = Auth::user()->tokens()
            ->orderByDesc('last_used_at')
            ->get();

        return response()->json([
            'data' => $tokens->map(fn($token) => [
                'id' => $token->id,
                'name' => $token->name,
                'abilities' => $token->abilities,
                'last_used_at' => $token->last_used_at?->toISOString(),
                'expires_at' => $token->expires_at?->toISOString(),
                'created_at' => $token->created_at->toISOString(),
            ]),
        ]);
    }

    /**
     * Create a new token.
     */
    public function store(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'name' => ['required', 'string', 'max:255'],
            'abilities' => ['required', 'array'],
            'abilities.*' => ['string', 'in:themes:read,themes:write,components:read,components:write,templates:read,templates:write,marketplace:read,marketplace:write,user:read,user:write,billing:read,admin:*'],
            'expires_at' => ['nullable', 'date', 'after:now'],
        ]);

        $token = $this->tokenService->createToken(
            Auth::user(),
            $validated['name'],
            $validated['abilities'],
            $validated['expires_at'] ?? null,
        );

        return response()->json([
            'message' => 'Token created successfully.',
            'data' => [
                'token' => $token,
                'name' => $validated['name'],
                'abilities' => $validated['abilities'],
                'expires_at' => $validated['expires_at'] ?? null,
            ],
        ], 201);
    }

    /**
     * Revoke a token.
     */
    public function destroy(Request $request, int $id): JsonResponse
    {
        $revoked = $this->tokenService->revokeToken(
            Auth::user(),
            $id,
        );

        if (! $revoked) {
            return response()->json([
                'message' => 'Token not found.',
            ], 404);
        }

        return response()->json([
            'message' => 'Token revoked successfully.',
        ]);
    }

    /**
     * Revoke all tokens.
     */
    public function revokeAll(Request $request): JsonResponse
    {
        $count = $this->tokenService->revokeAllTokens(Auth::user());

        return response()->json([
            'message' => "{$count} token(s) revoked successfully.",
        ]);
    }

    /**
     * Rotate a token.
     */
    public function rotate(Request $request, int $id): JsonResponse
    {
        $newToken = $this->tokenService->rotateToken(Auth::user(), $id);

        if (! $newToken) {
            return response()->json([
                'message' => 'Token not found.',
            ], 404);
        }

        return response()->json([
            'message' => 'Token rotated successfully.',
            'data' => [
                'token' => $newToken,
            ],
        ]);
    }
}
```

## API Error Handling

### Exception Handler

```php
// app/Exceptions/Handler.php

namespace App\Exceptions;

use Illuminate\Foundation\Exceptions\Handler as ExceptionHandler;
use Illuminate\Auth\AuthenticationException;
use Illuminate\Validation\ValidationException;
use Symfony\Component\HttpKernel\Exception\NotFoundHttpException;
use Symfony\Component\HttpKernel\Exception\AccessDeniedHttpException;
use Symfony\Component\HttpKernel\Exception\TooManyRequestsHttpException;

class Handler extends ExceptionHandler
{
    public function register(): void
    {
        $this->reportable(function (\Throwable $e) {
            //
        });
    }

    public function render($request, \Throwable $e)
    {
        if ($request->expectsJson() || $request->is('api/*')) {
            return $this->handleApiException($request, $e);
        }

        return parent::render($request, $e);
    }

    protected function handleApiException($request, \Throwable $e)
    {
        if ($e instanceof ValidationException) {
            return response()->json([
                'message' => 'Validation failed.',
                'errors' => $e->errors(),
            ], 422);
        }

        if ($e instanceof AuthenticationException) {
            return response()->json([
                'message' => 'Unauthenticated.',
            ], 401);
        }

        if ($e instanceof NotFoundHttpException) {
            return response()->json([
                'message' => 'Resource not found.',
            ], 404);
        }

        if ($e instanceof AccessDeniedHttpException) {
            return response()->json([
                'message' => 'Forbidden.',
            ], 403);
        }

        if ($e instanceof TooManyRequestsHttpException) {
            return response()->json([
                'message' => 'Too many requests.',
                'retry_after' => $e->getRetryAfter(),
            ], 429);
        }

        // Generic error
        $statusCode = method_exists($e, 'getStatusCode')
            ? $e->getStatusCode()
            : 500;

        return response()->json([
            'message' => 'Server error.',
        ], $statusCode);
    }

    protected function unauthenticated($request, AuthenticationException $exception)
    {
        if ($request->expectsJson() || $request->is('api/*')) {
            return response()->json([
                'message' => 'Unauthenticated.',
            ], 401);
        }

        return redirect('/');
    }
}
```

## API Response Format

### Standard Response Structure

```php
// app/Http/Controllers/Api/BaseApiController.php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use Illuminate\Http\JsonResponse;

abstract class BaseApiController extends Controller
{
    protected function successResponse($data = null, string $message = 'Success', int $code = 200): JsonResponse
    {
        return response()->json([
            'status' => 'success',
            'message' => $message,
            'data' => $data,
        ], $code);
    }

    protected function errorResponse(string $message = 'Error', int $code = 400, $errors = null): JsonResponse
    {
        $response = [
            'status' => 'error',
            'message' => $message,
        ];

        if ($errors) {
            $response['errors'] = $errors;
        }

        return response()->json($response, $code);
    }

    protected function paginatedResponse($paginator, string $message = 'Success'): JsonResponse
    {
        return response()->json([
            'status' => 'success',
            'message' => $message,
            'data' => $paginator->items(),
            'meta' => [
                'current_page' => $paginator->currentPage(),
                'last_page' => $paginator->lastPage(),
                'per_page' => $paginator->perPage(),
                'total' => $paginator->total(),
            ],
        ]);
    }
}
```

## Security Considerations

### Token Security

| Feature | Implementation |
|---|---|
| Token storage | SHA-256 hashed in database |
| Token display | Plain text shown once at creation |
| Token transmission | Bearer token in Authorization header |
| Token expiration | Configurable per token |
| Token revocation | Individual or bulk |
| Scope limiting | Tokens limited to granted scopes |
| Rate limiting | Per token and per IP |
| IP logging | Creation IP stored |
| User agent logging | Creation user agent stored |
| Audit logging | All token operations logged |

### API Metrics Service

```php
// app/Services/ApiMetricsService.php

namespace App\Services;

use Illuminate\Support\Facades\DB;

class ApiMetricsService
{
    /**
     * Get API usage metrics.
     */
    public function getUsageMetrics(): array
    {
        return [
            'total_requests' => $this->getTotalRequests(),
            'requests_today' => $this->getRequestsToday(),
            'requests_this_week' => $this->getRequestsThisWeek(),
            'requests_this_month' => $this->getRequestsThisMonth(),
            'average_response_time' => $this->getAverageResponseTime(),
            'error_rate' => $this->getErrorRate(),
        ];
    }

    /**
     * Get requests by endpoint.
     */
    public function getRequestsByEndpoint(): array
    {
        return DB::table('api_logs')
            ->select('endpoint', DB::raw('COUNT(*) as count'))
            ->where('created_at', '>=', now()->subDays(30))
            ->groupBy('endpoint')
            ->orderByDesc('count')
            ->limit(20)
            ->get()
            ->toArray();
    }

    /**
     * Get requests by status code.
     */
    public function getRequestsByStatusCode(): array
    {
        return DB::table('api_logs')
            ->select('status_code', DB::raw('COUNT(*) as count'))
            ->where('created_at', '>=', now()->subDays(30))
            ->groupBy('status_code')
            ->orderBy('status_code')
            ->get()
            ->pluck('count', 'status_code')
            ->toArray();
    }

    /**
     * Get requests by user.
     */
    public function getRequestsByUser(): array
    {
        return DB::table('api_logs')
            ->join('users', 'api_logs.user_id', '=', 'users.id')
            ->select('users.email', DB::raw('COUNT(*) as count'))
            ->where('api_logs.created_at', '>=', now()->subDays(30))
            ->groupBy('users.email')
            ->orderByDesc('count')
            ->limit(20)
            ->get()
            ->toArray();
    }

    protected function getTotalRequests(): int
    {
        return DB::table('api_logs')->count();
    }

    protected function getRequestsToday(): int
    {
        return DB::table('api_logs')
            ->where('created_at', '>=', now()->startOfDay())
            ->count();
    }

    protected function getRequestsThisWeek(): int
    {
        return DB::table('api_logs')
            ->where('created_at', '>=', now()->startOfWeek())
            ->count();
    }

    protected function getRequestsThisMonth(): int
    {
        return DB::table('api_logs')
            ->where('created_at', '>=', now()->startOfMonth())
            ->count();
    }

    protected function getAverageResponseTime(): float
    {
        return DB::table('api_logs')
            ->where('created_at', '>=', now()->subDays(30))
            ->avg('response_time') ?? 0;
    }

    protected function getErrorRate(): float
    {
        $total = $this->getRequestsToday();

        if ($total === 0) {
            return 0;
        }

        $errors = DB::table('api_logs')
            ->where('created_at', '>=', now()->startOfDay())
            ->where('status_code', '>=', 400)
            ->count();

        return round(($errors / $total) * 100, 2);
    }
}
```

```php
// app/Http/Middleware/ApiVersionHeader.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class ApiVersionHeader
{
    public function handle(Request $request, Closure $next, string $version = 'v1')
    {
        $response = $next($request);

        $response->headers->set('X-API-Version', $version);
        $response->headers->set('X-API-Deprecated', $this->isDeprecated($version) ? 'true' : 'false');

        if ($this->isDeprecated($version)) {
            $response->headers->set('X-API-Deprecation-Date', $this->getDeprecationDate($version));
            $response->headers->set('X-API-Sunset', $this->getSunsetDate($version));
        }

        return $response;
    }

    protected function isDeprecated(string $version): bool
    {
        return in_array($version, config('api.deprecated_versions', []));
    }

    protected function getDeprecationDate(string $version): string
    {
        return config("api.deprecation_dates.{$version}", '');
    }

    protected function getSunsetDate(string $version): string
    {
        return config("api.sunset_dates.{$version}", '');
    }
}
```

### API Response Transformer

```php
// app/Services/ApiTransformer.php

namespace App\Services;

use Illuminate\Http\JsonResponse;

class ApiTransformer
{
    /**
     * Transform a resource into a standardized API response.
     */
    public static function success($data = null, string $message = 'Success', int $code = 200): JsonResponse
    {
        return response()->json([
            'success' => true,
            'message' => $message,
            'data' => $data,
            'timestamp' => now()->toIso8601String(),
        ], $code);
    }

    /**
     * Transform a collection into a paginated API response.
     */
    public static function paginated($paginator, string $message = 'Success'): JsonResponse
    {
        return response()->json([
            'success' => true,
            'message' => $message,
            'data' => $paginator->items(),
            'meta' => [
                'current_page' => $paginator->currentPage(),
                'last_page' => $paginator->lastPage(),
                'per_page' => $paginator->perPage(),
                'total' => $paginator->total(),
            ],
            'links' => [
                'first' => $paginator->url(1),
                'last' => $paginator->url($paginator->lastPage()),
                'prev' => $paginator->previousPageUrl(),
                'next' => $paginator->nextPageUrl(),
            ],
        ]);
    }

    /**
     * Transform an error into a standardized API error response.
     */
    public static function error(string $message, int $code = 400, array $errors = []): JsonResponse
    {
        $response = [
            'success' => false,
            'message' => $message,
            'timestamp' => now()->toIso8601String(),
        ];

        if (! empty($errors)) {
            $response['errors'] = $errors;
        }
```

### API Rate Limiting Configuration

```php
// app/Providers/ApiRateLimitServiceProvider.php

namespace App\Providers;

use Illuminate\Cache\RateLimiting\Limit;
use Illuminate\Support\Facades\RateLimiter;
use Illuminate\Support\ServiceProvider;

class ApiRateLimitServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        //
    }

    public function boot(): void
    {
        RateLimiter::for('api-general', function (Request $request) {
            return Limit::perMinute(60)->by($request->user()?->id ?: $request->ip());
        });

        RateLimiter::for('api-auth', function (Request $request) {
            return Limit::perMinute(10)->by($request->ip());
        });

        RateLimiter::for('api-heavy', function (Request $request) {
            return Limit::perMinute(5)->by($request->user()?->id ?: $request->ip());
        });
    }
}
```

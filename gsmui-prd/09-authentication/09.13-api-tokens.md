## Token Creation Flow

```text
User clicks "Generate Token"
    ↓
Enters token name
    ↓
Selects scopes
    ↓
Confirms password (password.confirm middleware)
    ↓
Token generated (plain text shown once)
    ↓
User copies and saves token
    ↓
Plain text never shown again
```

## Livewire Component

```php
// app/Livewire/Settings/ApiTokens.php

class ApiTokens extends Component
{
    public string $name = '';
    public array $selectedScopes = [];
    public ?string $plainTextToken = null;

    protected array $rules = [
        'name' => ['required', 'string', 'max:255'],
        'selectedScopes' => ['required', 'array', 'min:1'],
    ];

    public function createToken(): void
    {
        $this->validate();

        $this->plainTextToken = Auth::user()
            ->createToken($this->name, $this->selectedScopes)
            ->plainTextToken;

        event(new ApiTokenCreated(Auth::user(), $this->name));

        $this->reset(['name', 'selectedScopes']);
    }

    public function revokeToken(int $tokenId): void
    {
        Auth::user()->tokens()
            ->where('id', $tokenId)
            ->delete();

        event(new ApiTokenRevoked(Auth::user()));
    }

    public function revokeAllTokens(): void
    {
        Auth::user()->tokens()->delete();

        event(new AllApiTokensRevoked(Auth::user()));
    }
}
```

## Token Security

| Feature | Implementation |
|---|---|
| Storage | SHA-256 hashed |
| Display | Plain text shown once at creation |
| Revocation | Individual or bulk |
| Expiration | Configurable per token |
| Scope limitation | Tokens limited to granted scopes |
| Rate limiting | Per token limits |
| Usage logging | Last used timestamp |
| IP logging | Creation IP stored |

## Rate Limits

| Limit | Window | Scope |
|---|---|---|
| 60 requests | Per minute | Per token |
| 1000 requests | Per hour | Per token |
| 10000 requests | Per day | Per token |

## Cleanup

| Job | Frequency | Purpose |
|---|---|---|
| `CleanupExpiredTokens` | Daily | Remove tokens past expiration |
| `CleanupUnusedTokens` | Weekly | Remove tokens not used in 90 days |

## Complete API Token System

### Token Lifecycle

```text
1. Token Creation
   → User requests new token
   → Name, scopes, expiration provided
   → Password confirmed
   → Token generated (plain text)
   → Token stored (hashed)
   → Plain text shown once

2. Token Usage
   → Token included in Authorization header
   → Token validated against database
   → Scopes checked
   → Request processed
   → Last used timestamp updated

3. Token Rotation
   → User requests token rotation
   → Old token revoked
   → New token created with same abilities
   → New plain text token shown once

4. Token Expiration
   → Token expires after configured period
   → Expired tokens rejected
   → Expired tokens cleaned up by job

5. Token Revocation
   → User revokes specific token
   → Token deleted from database
   → All future requests with token rejected
```

### Token Statistics

```php
// app/Services/TokenStatsService.php

namespace App\Services;

use App\Models\PersonalAccessToken;
use App\Models\User;
use Illuminate\Support\Facades\DB;

class TokenStatsService
{
    /**
     * Get token statistics for a user.
     */
    public function getUserStats(User $user): array
    {
        $tokens = $user->tokens;

        return [
            'total' => $tokens->count(),
            'active' => $tokens->filter(fn($t) => $this->isActive($t))->count(),
            'expired' => $tokens->filter(fn($t) => $this->isExpired($t))->count(),
            'unused' => $tokens->filter(fn($t) => is_null($t->last_used_at))->count(),
            'recently_used' => $tokens->filter(fn($t) =>
                $t->last_used_at && $t->last_used_at->diffInDays(now()) <= 7
            )->count(),
            'scopes' => $tokens->flatMap(fn($t) => $t->abilities)->unique()->count(),
            'last_created' => $tokens->max('created_at'),
            'last_used' => $tokens->max('last_used_at'),
        ];
    }

    /**
     * Get token usage over time.
     */
    public function getUsageOverTime(User $user, int $days = 30): array
    {
        return PersonalAccessToken::where('tokenable_id', $user->id)
            ->selectRaw('DATE(created_at) as date, COUNT(*) as count')
            ->where('created_at', '>=', now()->subDays($days))
            ->groupBy('date')
            ->orderBy('date')
            ->get()
            ->toArray();
    }

    /**
     * Get tokens by scope.
     */
    public function getTokensByScope(User $user): array
    {
        $tokens = $user->tokens;
        $scopeCounts = [];

        foreach ($tokens as $token) {
            foreach ($token->abilities as $ability) {
                $scopeCounts[$ability] = ($scopeCounts[$ability] ?? 0) + 1;
            }
        }

        arsort($scopeCounts);
        return $scopeCounts;
    }

    /**
     * Check if token is active.
     */
    protected function isActive(PersonalAccessToken $token): bool
    {
        return ! $this->isExpired($token);
    }

    /**
     * Check if token is expired.
     */
    protected function isExpired(PersonalAccessToken $token): bool
    {
        return $token->expires_at && $token->expires_at->isPast();
    }
}
```

### Token Security Audit

```php
// app/Services/TokenAuditService.php

namespace App\Services;

use App\Models\PersonalAccessToken;
use App\Models\User;
use Illuminate\Support\Facades\DB;

class TokenAuditService
{
    /**
     * Audit tokens for security issues.
     */
    public function auditTokens(User $user): array
    {
        $tokens = $user->tokens;
        $issues = [];

        foreach ($tokens as $token) {
            // Check for expired tokens
            if ($this->isExpired($token)) {
                $issues[] = [
                    'type' => 'expired',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token is expired and should be revoked.',
                ];
            }

            // Check for tokens with broad scopes
            if (in_array('*', $token->abilities) || in_array('admin:*', $token->abilities)) {
                $issues[] = [
                    'type' => 'broad_scope',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token has broad access scopes.',
                ];
            }

            // Check for old tokens
            if ($token->created_at->diffInDays(now()) > 90) {
                $issues[] = [
                    'type' => 'old_token',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token is older than 90 days.',
                ];
            }

            // Check for tokens not used recently
            if ($token->last_used_at && $token->last_used_at->diffInDays(now()) > 30) {
                $issues[] = [
                    'type' => 'unused',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token has not been used in 30+ days.',
                ];
            }

            // Check for tokens without expiration
            if (is_null($token->expires_at)) {
                $issues[] = [
                    'type' => 'no_expiration',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token has no expiration date.',
                ];
            }
        }

        return $issues;
    }

    /**
     * Get security score for tokens.
     */
    public function getSecurityScore(User $user): array
    {
        $tokens = $user->tokens;
        $totalTokens = $tokens->count();

        if ($totalTokens === 0) {
            return [
                'score' => 100,
                'rating' => 'excellent',
                'message' => 'No tokens found.',
            ];
        }

        $activeTokens = $tokens->filter(fn($t) => $this->isActive($t))->count();
        $tokensWithExpiration = $tokens->filter(fn($t) => ! is_null($t->expires_at))->count();
        $tokensWithBroadScopes = $tokens->filter(fn($t) =>
            in_array('*', $t->abilities) || in_array('admin:*', $t->abilities)
        )->count();

        $score = 100;

        // Deduct for expired tokens
        $score -= ($totalTokens - $activeTokens) * 5;

        // Deduct for tokens without expiration
        $score -= ($totalTokens - $tokensWithExpiration) * 3;

        // Deduct for tokens with broad scopes
        $score -= $tokensWithBroadScopes * 10;

        // Deduct for too many tokens
        if ($totalTokens > 10) {
            $score -= ($totalTokens - 10) * 2;
        }

        $score = max(0, min(100, $score));

        return [
            'score' => $score,
            'rating' => match(true) {
                $score >= 90 => 'excellent',
                $score >= 70 => 'good',
                $score >= 50 => 'fair',
                default => 'poor',
            },
            'message' => $this->getScoreMessage($score),
        ];
    }

    protected function getScoreMessage(int $score): string
    {
        return match(true) {
            $score >= 90 => 'Your token security is excellent.',
            $score >= 70 => 'Your token security is good, but consider reviewing your tokens.',
            $score >= 50 => 'Your token security needs improvement.',
            default => 'Your token security requires immediate attention.',
        };
    }

    protected function isExpired(PersonalAccessToken $token): bool
    {
        return $token->expires_at && $token->expires_at->isPast();
    }
}
```

## Token Management Livewire Component

```php
// app/Livewire/Settings/ApiTokenManager.php

namespace App\Livewire\Settings;

use App\Events\ApiTokenCreated;
use App\Events\ApiTokenRevoked;
use App\Models\PersonalAccessToken;
use App\Services\TokenStatsService;
use App\Services\TokenAuditService;
use Illuminate\Support\Facades\Auth;
use Livewire\Component;

class ApiTokenManager extends Component
{
    public string $name = '';
    public array $selectedScopes = [];
    public ?string $plainTextToken = null;
    public int $expirationDays = 90;
    public array $tokens = [];
    public array $stats = [];
    public array $auditIssues = [];
    public ?string $selectedTokenId = null;
    public bool $showRevokeModal = false;
    public bool $showRevokeAllModal = false;
    public bool $showCreateForm = false;

    protected TokenStatsService $statsService;
    protected TokenAuditService $auditService;

    protected array $rules = [
        'name' => ['required', 'string', 'max:255'],
        'selectedScopes' => ['required', 'array', 'min:1'],
        'expirationDays' => ['required', 'integer', 'min:1', 'max:365'],
    ];

    protected array $messages = [
        'name.required' => 'Token name is required.',
        'name.max' => 'Token name must not exceed 255 characters.',
        'selectedScopes.required' => 'Select at least one scope.',
        'selectedScopes.min' => 'Select at least one scope.',
        'expirationDays.min' => 'Expiration must be at least 1 day.',
        'expirationDays.max' => 'Expiration must not exceed 365 days.',
    ];

    public function boot(): void
    {
        $this->statsService = app(TokenStatsService::class);
        $this->auditService = app(TokenAuditService::class);
    }

    public function mount(): void
    {
        $this->loadTokens();
    }

    public function loadTokens(): void
    {
        $user = Auth::user();
        $this->tokens = $user->tokens()
            ->orderByDesc('last_used_at')
            ->get()
            ->toArray();
        $this->stats = $this->statsService->getUserStats($user);
        $this->auditIssues = $this->auditService->auditTokens($user);
    }

    public function createToken(): void
    {
        $this->validate();

        $user = Auth::user();

        $token = $user->createToken(
            $this->name,
            $this->selectedScopes
        );

        if ($this->expirationDays) {
            $token->accessToken->update([
                'expires_at' => now()->addDays($this->expirationDays),
            ]);
        }

        $this->plainTextToken = $token->plainTextToken;

        event(new ApiTokenCreated($user, $this->name));

        $this->reset(['name', 'selectedScopes', 'expirationDays']);
        $this->showCreateForm = false;

        $this->loadTokens();

        session()->flash('status', 'Token created successfully. Copy it now — it won\'t be shown again.');
    }

    public function confirmRevokeToken(string $tokenId): void
    {
        $this->selectedTokenId = $tokenId;
        $this->showRevokeModal = true;
    }

    public function revokeToken(): void
    {
        $user = Auth::user();

        $token = $user->tokens()
            ->where('id', $this->selectedTokenId)
            ->first();

        if ($token) {
            $tokenName = $token->name;
            $token->delete();

            event(new ApiTokenRevoked($user, $tokenName));

            session()->flash('status', "Token \"{$tokenName}\" revoked successfully.");
        }

        $this->showRevokeModal = false;
        $this->selectedTokenId = null;

        $this->loadTokens();
    }

    public function confirmRevokeAll(): void
    {
        $this->showRevokeAllModal = true;
    }

    public function revokeAllTokens(): void
    {
        $user = Auth::user();
        $count = $user->tokens()->count();

        $user->tokens()->delete();

        session()->flash('status', "{$count} token(s) revoked successfully.");

        $this->showRevokeAllModal = false;

        $this->loadTokens();
    }

    public function cancelRevoke(): void
    {
        $this->showRevokeModal = false;
        $this->showRevokeAllModal = false;
        $this->selectedTokenId = null;
    }

    public function toggleCreateForm(): void
    {
        $this->showCreateForm = ! $this->showCreateForm;
        $this->resetValidation();
    }

    public function getAvailableScopes(): array
    {
        return [
            'themes:read' => 'View themes',
            'themes:write' => 'Create/update themes',
            'components:read' => 'View components',
            'components:write' => 'Create/update components',
            'templates:read' => 'View templates',
            'templates:write' => 'Create/update templates',
            'marketplace:read' => 'Browse marketplace',
            'marketplace:write' => 'Manage marketplace products',
            'user:read' => 'View own profile',
            'user:write' => 'Update own profile',
            'billing:read' => 'View invoices/billing',
            'admin:*' => 'Full admin access',
        ];
    }

    public function render(): \Illuminate\View\View
    {
        return view('livewire.settings.api-token-manager');
    }
}
```

| Monitor token usage | Track token usage patterns |
| Log token operations | Log all token create/revoke operations |
| Use HTTPS only | Tokens must only be transmitted over HTTPS |
| Never store plain text | Store only hashed tokens |

## Token Audit Service

```php
// app/Services/TokenAuditService.php

namespace App\Services;

use App\Models\PersonalAccessToken;
use App\Models\User;
use Illuminate\Support\Facades\DB;

class TokenAuditService
{
    /**
     * Audit tokens for security issues.
     */
    public function auditTokens(User $user): array
    {
        $tokens = $user->tokens;
        $issues = [];

        foreach ($tokens as $token) {
            // Check for expired tokens
            if ($token->expires_at && $token->expires_at->isPast()) {
                $issues[] = [
                    'type' => 'expired',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token is expired and should be revoked.',
                    'severity' => 'medium',
                ];
            }

            // Check for tokens with broad scopes
            if (in_array('*', $token->abilities) || in_array('admin:*', $token->abilities)) {
                $issues[] = [
                    'type' => 'broad_scope',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token has broad access scopes.',
                    'severity' => 'high',
                ];
            }

            // Check for old tokens
            if ($token->created_at->diffInDays(now()) > 90) {
                $issues[] = [
                    'type' => 'old_token',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token is older than 90 days.',
                    'severity' => 'low',
                ];
            }

            // Check for tokens not used recently
            if ($token->last_used_at && $token->last_used_at->diffInDays(now()) > 30) {
                $issues[] = [
                    'type' => 'unused',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token has not been used in 30+ days.',
                    'severity' => 'low',
                ];
            }

            // Check for tokens without expiration
            if (is_null($token->expires_at)) {
                $issues[] = [
                    'type' => 'no_expiration',
                    'token_id' => $token->id,
                    'token_name' => $token->name,
                    'message' => 'Token has no expiration date.',
                    'severity' => 'medium',
                ];
            }
        }

        return $issues;
    }

    /**
     * Get security score for tokens.
     */
    public function getSecurityScore(User $user): array
    {
        $tokens = $user->tokens;
        $totalTokens = $tokens->count();

        if ($totalTokens === 0) {
            return [
                'score' => 100,
                'rating' => 'excellent',
                'message' => 'No tokens found.',
            ];
        }

        $activeTokens = $tokens->filter(fn($t) => ! ($t->expires_at && $t->expires_at->isPast()))->count();
        $tokensWithExpiration = $tokens->filter(fn($t) => ! is_null($t->expires_at))->count();
        $tokensWithBroadScopes = $tokens->filter(fn($t) =>
            in_array('*', $t->abilities) || in_array('admin:*', $t->abilities)
        )->count();

        $score = 100;
        $score -= ($totalTokens - $activeTokens) * 5;
        $score -= ($totalTokens - $tokensWithExpiration) * 3;
        $score -= $tokensWithBroadScopes * 10;

        if ($totalTokens > 10) {
            $score -= ($totalTokens - 10) * 2;
        }

        $score = max(0, min(100, $score));

        return [
            'score' => $score,
            'rating' => match(true) {
                $score >= 90 => 'excellent',
                $score >= 70 => 'good',
                $score >= 50 => 'fair',
                default => 'poor',
            },
            'message' => match(true) {
                $score >= 90 => 'Your token security is excellent.',
                $score >= 70 => 'Your token security is good, but consider reviewing your tokens.',
                $score >= 50 => 'Your token security needs improvement.',
                default => 'Your token security requires immediate attention.',
            },
        ];
    }

    /**
     * Get token usage report.
     */
    public function getUsageReport(User $user, int $days = 30): array
    {
        $tokens = $user->tokens;

        return [
            'total_tokens' => $tokens->count(),
            'active_tokens' => $tokens->filter(fn($t) => ! ($t->expires_at && $t->expires_at->isPast()))->count(),
            'expired_tokens' => $tokens->filter(fn($t) => $t->expires_at && $t->expires_at->isPast())->count(),
            'tokens_used_recently' => $tokens->filter(fn($t) =>
                $t->last_used_at && $t->last_used_at->diffInDays(now()) <= 7
            )->count(),
            'tokens_never_used' => $tokens->filter(fn($t) => is_null($t->last_used_at))->count(),
            'scopes_used' => $tokens->flatMap(fn($t) => $t->abilities)->unique()->count(),
            'last_activity' => $tokens->max('last_used_at'),
        ];
    }
}
```

## Token Rate Limiting

```php
// app/Http/Middleware/TokenRateLimiter.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\RateLimiter;

class TokenRateLimiter
{
    public function handle(Request $request, Closure $next, string $limit = '60,1')
    {
        $token = $request->user()?->currentAccessToken();

        if (! $token) {
            return $next($request);
        }

        $key = 'token:' . $token->id;
        [$maxAttempts, $decayMinutes] = explode(',', $limit);

        if (RateLimiter::tooManyAttempts($key, (int) $maxAttempts)) {
            $seconds = RateLimiter::availableIn($key);

            return response()->json([
                'message' => 'Too many requests.',
                'retry_after' => $seconds,
            ], 429);
        }

        RateLimiter::hit($key, $decayMinutes * 60);

        $response = $next($request);

        $response->headers->set('X-RateLimit-Limit', $maxAttempts);
        $response->headers->set('X-RateLimit-Remaining', RateLimiter::remaining($key, (int) $maxAttempts));

        return $response;
    }
}
```

```php
namespace App\Services;

use App\Models\PersonalAccessToken;
use App\Models\User;
use Illuminate\Support\Facades\DB;

class TokenBatchService
{
    /**
     * Create multiple tokens for a user.
     */
    public function createBatch(User $user, array $tokens): array
    {
        return DB::transaction(function () use ($user, $tokens) {
            $created = [];

            foreach ($tokens as $tokenData) {
                $token = $user->createToken(
                    $tokenData['name'],
                    $tokenData['abilities'] ?? ['*'],
                    now()->addDays($tokenData['expiration_days'] ?? 30)
                );

                $created[] = [
                    'name' => $tokenData['name'],
                    'token' => $token->plainTextToken,
                    'abilities' => $tokenData['abilities'] ?? ['*'],
                ];
            }

            return $created;
        });
    }

    /**
     * Bulk revoke tokens by IDs.
     */
    public function bulkRevoke(User $user, array $tokenIds): int
    {
        return PersonalAccessToken::where('tokenable_id', $user->id)
            ->whereIn('id', $tokenIds)
            ->delete();
    }

    /**
     * Bulk revoke tokens by ability.
     */
    public function revokeByAbility(User $user, string $ability): int
    {
        $tokens = $user->tokens->filter(function ($token) use ($ability) {
            return in_array($ability, $token->abilities) || in_array('*', $token->abilities);
        });

        $count = 0;
        foreach ($tokens as $token) {
            $token->delete();
            $count++;
        }

        return $count;
    }

    /**
     * Bulk update token expiration.
     */
    public function updateExpiration(User $user, array $tokenIds, int $days): int
    {
        return PersonalAccessToken::where('tokenable_id', $user->id)
            ->whereIn('id', $tokenIds)
            ->update(['expires_at' => now()->addDays($days)]);
```

```php
// app/Services/TokenSecurityScanner.php

namespace App\Services;

use App\Models\PersonalAccessToken;
use App\Models\User;

class TokenSecurityScanner
{
    /**
     * Scan for tokens with security issues.
     */
    public function scan(User $user): array
    {
        $tokens = $user->tokens;

        return [
            'expired_tokens' => $this->findExpiredTokens($tokens),
            'overprivileged_tokens' => $this->findOverprivilegedTokens($tokens),
            'unused_tokens' => $this->findUnusedTokens($tokens),
            'old_tokens' => $this->findOldTokens($tokens),
            'recommendations' => $this->generateRecommendations($tokens),
        ];
    }

    protected function findExpiredTokens($tokens): array
    {
        return $tokens->filter(fn($token) => $token->expires_at && $token->expires_at->isPast())
            ->map(fn($token) => [
                'id' => $token->id,
                'name' => $token->name,
                'expired_at' => $token->expires_at->toDateTimeString(),
            ])
            ->toArray();
    }

    protected function findOverprivilegedTokens($tokens): array
    {
        return $tokens->filter(fn($token) => in_array('*', $token->abilities))
            ->map(fn($token) => [
                'id' => $token->id,
                'name' => $token->name,
                'abilities' => $token->abilities,
            ])
            ->toArray();
    }

    protected function findUnusedTokens($tokens): array
    {
        return $tokens->filter(fn($token) => is_null($token->last_used_at))
            ->map(fn($token) => [
                'id' => $token->id,
                'name' => $token->name,
                'created_at' => $token->created_at->toDateTimeString(),
            ])
            ->toArray();
    }

    protected function findOldTokens($tokens): array
    {
        $cutoff = now()->subDays(90);

        return $tokens->filter(fn($token) => $token->created_at->isBefore($cutoff))
            ->map(fn($token) => [
                'id' => $token->id,
                'name' => $token->name,
                'created_at' => $token->created_at->toDateTimeString(),
                'last_used_at' => $token->last_used_at?->toDateTimeString(),
            ])
            ->toArray();
    }

    protected function generateRecommendations($tokens): array
    {
        $recommendations = [];

        if ($tokens->contains(fn($t) => in_array('*', $t->abilities))) {
            $recommendations[] = 'You have tokens with wildcard (*) abilities. Consider restricting to specific permissions.';
        }

        if ($tokens->filter(fn($t) => is_null($t->last_used_at))->count() > 3) {
            $recommendations[] = 'You have multiple unused tokens. Consider revoking tokens you no longer use.';
        }

        if ($tokens->filter(fn($t) => ! $t->expires_at)->count() > 2) {
            $recommendations[] = 'Some tokens have no expiration. Consider setting expiration dates for better security.';
        }

        return $recommendations;
    }
}
```

## Token Export

### Export Token Data

```php
// app/Services/TokenExportService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\Blade;

class TokenExportService
{
    /**
     * Export token usage report.
     */
    public function exportReport(User $user, string $format = 'json'): string
    {
        $data = [
            'user' => [
                'email' => $user->email,
                'exported_at' => now()->toIso8601String(),
            ],
            'tokens' => $user->tokens->map(fn($token) => [
                'name' => $token->name,
                'abilities' => $token->abilities,
                'created_at' => $token->created_at->toIso8601String(),
                'last_used_at' => $token->last_used_at?->toIso8601String(),
                'expires_at' => $token->expires_at?->toIso8601String(),
                'is_expired' => $token->expires_at && $token->expires_at->isPast(),
            ])->toArray(),
        ];

        return match($format) {
            'json' => json_encode($data, JSON_PRETTY_PRINT),
            'csv' => $this->toCsv($data['tokens']),
            'markdown' => $this->toMarkdown($data),
            default => json_encode($data, JSON_PRETTY_PRINT),
        };
    }

    protected function toCsv(array $tokens): string
    {
        $headers = ['Name', 'Abilities', 'Created At', 'Last Used', 'Expires At', 'Status'];
        $rows = array_map(fn($t) => [
            $t['name'],
            implode(', ', $t['abilities']),
            $t['created_at'],
            $t['last_used_at'] ?? 'Never',
            $t['expires_at'] ?? 'Never',
            $t['is_expired'] ? 'Expired' : 'Active',
        ], $tokens);

        $csv = implode(',', $headers) . "\n";
        foreach ($rows as $row) {
            $csv .= implode(',', array_map(fn($cell) => '"' . str_replace('"', '""', $cell) . '"', $row)) . "\n";
        }

        return $csv;
    }

    protected function toMarkdown(array $data): string
    {
        $lines = [
            '# API Token Report',
            '',
            '**User:** ' . $data['user']['email'],
            '**Exported:** ' . $data['user']['exported_at'],
            '',
            '## Tokens',
            '',
            '| Name | Abilities | Created | Last Used | Status |',
            '|------|-----------|---------|-----------|--------|',
        ];

        foreach ($data['tokens'] as $token) {
            $lines[] = sprintf(
                '| %s | %s | %s | %s | %s |',
                $token['name'],
                implode(', ', $token['abilities']),
                $token['created_at'],
                $token['last_used_at'] ?? 'Never',
                $token['is_expired'] ? 'Expired' : 'Active'
            );
        }

        return implode("\n", $lines);
    }
}
```

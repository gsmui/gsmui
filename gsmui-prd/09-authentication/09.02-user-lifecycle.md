# 09.02 — User Lifecycle

## Purpose

Define every state a user account can be in, the transitions between states, and the rules governing those transitions. The user lifecycle is the backbone of authentication — every other system (login, billing, permissions) depends on knowing the current state of a user.

## User States

```text
┌─────────────┐
│  Visitor     │  (not yet registered)
└──────┬──────┘
       │ Register
       ↓
┌─────────────┐
│  Pending     │  (registered, email not verified)
└──────┬──────┘
       │ Verify Email
       ↓
┌─────────────┐
│  Active      │  (email verified, can log in)
└──────┬──────┘
       │ Suspend / Deactivate / Delete
       ↓
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  Suspended   │     │  Deactivated  │     │  Deleted     │
└─────────────┘     └──────────────┘     └─────────────┘
```

## State Definitions

| State | Description | Can Log In | Can Purchase | API Access |
|---|---|---|---|---|
| Visitor | Unauthenticated browser | No | No | No |
| Pending | Registered, email unverified | No | No | No |
| Active | Fully verified account | Yes | Yes | Yes |
| Suspended | Admin-suspended (abuse, violation) | No | No | No |
| Deactivated | User-initiated account closure | No | No | No |
| Deleted | Soft-deleted, data retention period | No | No | No |

## State Transitions

### Visitor → Pending

**Trigger:** Registration form submitted

**Rules:**
* Email must be unique
* Password must meet minimum requirements (8+ characters)
* Username must be unique (if username login enabled)
* Rate limit: 5 registrations per IP per hour

**Actions:**
1. Create user record with `email_verified_at = null`
2. Assign default `User` role (Spatie Permission)
3. Send email verification link
4. Log activity: `user.registered`

### Pending → Active

**Trigger:** Email verification link clicked

**Rules:**
* Verification token must be valid and unexpired (60-minute TTL)
* Token is single-use

**Actions:**
1. Set `email_verified_at = now()`
2. Log activity: `user.email_verified`
3. Send welcome email
4. Create default user settings
5. Redirect to dashboard

### Active → Suspended

**Trigger:** Admin action

**Rules:**
* Only Admin or Super Admin can suspend
* Must provide suspension reason
* Suspension email sent to user

**Actions:**
1. Set `suspended_at = now()`
2. Store `suspended_reason`
3. Revoke all active sessions
4. Revoke all API tokens
5. Log activity: `user.suspended`

### Suspended → Active

**Trigger:** Admin action (unsuspend)

**Actions:**
1. Set `suspended_at = null`
2. Set `suspended_reason = null`
3. Log activity: `user.unsuspended`

### Active → Deactivated

**Trigger:** User action (account settings)

**Rules:**
* User must confirm password before deactivating
* Pending orders/subscriptions must be resolved
* 30-day grace period before permanent deletion

**Actions:**
1. Set `deactivated_at = now()`
2. Revoke all active sessions
3. Revoke all API tokens
4. Cancel active subscriptions
5. Log activity: `user.deactivated`
6. Schedule deletion after 30 days

### Deactivated → Active

**Trigger:** User logs in within 30-day grace period

**Actions:**
1. Set `deactivated_at = null`
2. Restore subscriptions
3. Log activity: `user.reactivated`

### Active/Deactivated → Deleted

**Trigger:** Admin action or 30-day grace period expiration

**Rules:**
* Soft delete first (保留 90 days)
* After 90 days: hard delete via scheduled job
* Marketplace products by the user are archived, not deleted
* Reviews/ratings are anonymized

**Actions:**
1. Set `deleted_at = now()`
2. Anonymize personal data (name → "Deleted User", email → hash)
3. Archive marketplace products
4. Anonymize reviews
5. Log activity: `user.deleted`
6. Schedule hard delete: 90 days

## Lifecycle Events

| Event | Dispatched When | Listeners |
|---|---|---|
| `UserRegistered` | Registration complete | Send verification email, create settings |
| `EmailVerified` | Email verified | Send welcome email, assign default role |
| `UserSuspended` | Admin suspends user | Revoke sessions, revoke tokens, notify user |
| `UserUnsuspended` | Admin unsuspends user | Notify user |
| `UserDeactivated` | User deactivates account | Cancel subscriptions, revoke access |
| `UserReactivated` | User logs in during grace period | Restore subscriptions |
| `UserDeleted` | Soft delete complete | Archive data, anonymize PII |
| `UserHardDeleted` | 90-day retention expired | Permanent data removal |

## Scheduled Jobs

| Job | Frequency | Purpose |
|---|---|---|
| `DeleteDeactivatedUsers` | Daily | Hard delete users past 90-day retention |
| `SendDeactivationReminder` | Daily | Notify deactivated users of remaining grace period |
| `CleanupExpiredVerifications` | Hourly | Remove expired email verification tokens |
| `CleanupExpiredResets` | Hourly | Remove expired password reset tokens |

## Edge Cases

* **User with active subscription deactivates:** Subscription is cancelled, refund handled per billing policy.
* **User with published marketplace products deactivates:** Products are archived but remain visible for existing license holders.
* **User with pending orders deactivates:** Orders must be fulfilled or refunded before deactivation is allowed.
* **Suspended user tries to register with new email:** Allowed — suspension is per-account, not per-person.
* **Deleted user re-registers:** Creates a new account; old data is not recoverable.

## Detailed State Machine

### State Transition Rules

Every state transition must follow strict rules to maintain data integrity and prevent unauthorized access changes.

#### Visitor → Pending (Registration)

**Preconditions:**
- Email address is valid and unique
- Password meets minimum requirements
- Username is unique (if enabled)
- Terms of Service accepted
- Rate limit not exceeded

**Transaction Steps:**
```php
DB::transaction(function () use ($data) {
    $user = User::create([
        'name' => $data['name'],
        'email' => $data['email'],
        'password' => Hash::make($data['password']),
        'username' => $data['username'] ?? null,
        'email_verified_at' => null,
        'created_at' => now(),
    ]);

    $user->assignRole('user');

    event(new UserRegistered($user));

    $user->sendEmailVerificationNotification();
});
```

**Post-conditions:**
- User record exists in database
- User has 'user' role assigned
- Verification email has been queued
- User is NOT logged in (must verify email first)
- Activity log entry created

**Failure Scenarios:**
| Failure | Handling | User Message |
|---|---|---|
| Email already exists | Return validation error | "An account with this email already exists." |
| Username taken | Return validation error | "This username is already taken." |
| Password too weak | Return validation error | "Password must be at least 8 characters." |
| Database error | Log error, return generic message | "Something went wrong. Please try again." |
| Rate limited | Return 429 | "Too many registration attempts." |
| Email service down | Queue for retry | "Account created. Verification email will be sent shortly." |

#### Pending → Active (Email Verification)

**Preconditions:**
- Verification token is valid
- Token has not expired (60-minute TTL)
- Token has not been used
- User exists and is in Pending state

**Transaction Steps:**
```php
DB::transaction(function () use ($user) {
    $user->markEmailAsVerified();

    $user->update([
        'email_verified_at' => now(),
    ]);

    event(new EmailVerified($user));

    // Send welcome email
    WelcomeEmail::dispatch($user);
});
```

**Post-conditions:**
- User's email_verified_at is set to current timestamp
- User can now log in
- Welcome email queued
- User settings created (if not exists)
- Activity log entry created

**Failure Scenarios:**
| Failure | Handling | User Message |
|---|---|---|
| Token expired | Redirect to verification prompt | "Verification link expired. Please request a new one." |
| Token already used | Redirect to verification prompt | "This link has already been used." |
| Token invalid | Redirect to verification prompt | "Invalid verification link." |
| User not found | Redirect to login | "Account not found." |

#### Active → Suspended (Admin Action)

**Preconditions:**
- Admin is authenticated
- Admin has 'suspend-user' permission
- Target user exists and is Active
- Suspension reason is provided

**Transaction Steps:**
```php
DB::transaction(function () use ($admin, $user, $reason) {
    $user->update([
        'suspended_at' => now(),
        'suspended_reason' => $reason,
    ]);

    // Revoke all active sessions
    Session::where('user_id', $user->id)->delete();

    // Revoke all API tokens
    $user->tokens()->delete();

    // Cancel active subscriptions
    $user->subscriptions()->each(function ($subscription) {
        $subscription->cancel();
    });

    event(new UserSuspended($user, $admin, $reason));

    // Send suspension notification
    SuspensionEmail::dispatch($user, $reason);
});
```

**Post-conditions:**
- User cannot log in
- All existing sessions are terminated
- All API tokens are revoked
- Active subscriptions are cancelled
- User receives suspension notification email
- Activity log entry created with admin ID

**Reversal (Unsuspend):**
```php
DB::transaction(function () use ($admin, $user) {
    $user->update([
        'suspended_at' => null,
        'suspended_reason' => null,
    ]);

    event(new UserUnsuspended($user, $admin));

    UnsuspensionEmail::dispatch($user);
});
```

#### Active → Deactivated (User Action)

**Preconditions:**
- User is authenticated
- User has no pending orders
- User confirms password
- User understands the 30-day grace period

**Transaction Steps:**
```php
DB::transaction(function () use ($user) {
    $user->update([
        'deactivated_at' => now(),
    ]);

    // Revoke all sessions except current
    Session::where('user_id', $user->id)
        ->where('id', '!=', session()->getId())
        ->delete();

    // Revoke all API tokens
    $user->tokens()->delete();

    // Cancel active subscriptions
    $user->subscriptions()->each(function ($subscription) {
        $subscription->cancel();
    });

    event(new UserDeactivated($user));

    // Schedule deletion job
    DeleteUserJob::dispatch($user)->delay(now()->addDays(30));
});
```

**Post-conditions:**
- User cannot log in (except within 30-day grace period)
- All other sessions are terminated
- All API tokens are revoked
- Active subscriptions are cancelled
- Deletion scheduled for 30 days
- Activity log entry created

**Grace Period Reactivation:**
```php
// User logs in during grace period
public function reactivate(User $user): void
{
    if ($user->deactivated_at === null) {
        return;
    }

    if ($user->deactivated_at->diffInDays(now()) > 30) {
        throw new AccountExpiredException();
    }

    DB::transaction(function () use ($user) {
        $user->update([
            'deactivated_at' => null,
        ]);

        // Restore subscriptions
        $user->subscriptions()->each(function ($subscription) {
            $subscription->restore();
        });

        event(new UserReactivated($user));

        // Cancel deletion job
        DeleteUserJob::where('user_id', $user->id)->delete();
    });
}
```

#### Active/Deactivated → Deleted (Soft Delete)

**Preconditions:**
- 30-day grace period has expired (deactivated users)
- Admin has initiated deletion
- User has no legal holds

**Transaction Steps:**
```php
DB::transaction(function () use ($user) {
    $user->update([
        'deleted_at' => now(),
    ]);

    // Anonymize personal data
    $user->update([
        'name' => 'Deleted User',
        'email' => 'deleted_' . $user->id . '@anonymized.invalid',
        'password' => Str::random(60),
        'username' => null,
    ]);

    // Archive marketplace products
    $user->themes()->update(['archived' => true]);
    $user->components()->update(['archived' => true]);

    // Anonymize reviews
    Review::where('user_id', $user->id)->update([
        'user_name' => 'Anonymous',
        'user_id' => null,
    ]);

    event(new UserDeleted($user));

    // Schedule hard delete
    HardDeleteUserJob::dispatch($user)->delay(now()->addDays(90));
});
```

**Post-conditions:**
- User cannot log in
- Personal data is anonymized
- Marketplace products are archived
- Reviews are anonymized
- Hard deletion scheduled for 90 days
- Activity log entry created

**Hard Deletion:**
```php
// 90 days after soft delete
DB::transaction(function () use ($user) {
    // Delete all related data
    $user->sessions()->forceDelete();
    $user->tokens()->forceDelete();
    $user->activities()->delete();
    $user->login_history()->delete();

    // Force delete user
    $user->forceDelete();

    event(new UserHardDeleted($user->id));
});
```

### State Validation Middleware

```php
// app/Http/Middleware/ValidateUserState.php

public function handle(Request $request, Closure $next)
{
    $user = $request->user();

    if (! $user) {
        return $next($request);
    }

    if ($user->isSuspended()) {
        Auth::logout();
        return redirect()->route('login')
            ->withErrors(['email' => 'Your account has been suspended.']);
    }

    if ($user->isDeactivated()) {
        Auth::logout();
        return redirect()->route('login')
            ->withErrors(['email' => 'Your account has been deactivated.']);
    }

    if ($user->isDeleted()) {
        Auth::logout();
        return redirect()->route('login')
            ->withErrors(['email' => 'Account not found.']);
    }

    if (! $user->hasVerifiedEmail()) {
        return redirect()->route('verification.notice');
    }

    return $next($request);
}
```

### User State Query Methods

```php
// app/Models/User.php

public function isPending(): bool
{
    return $this->email_verified_at === null
        && $this->suspended_at === null
        && $this->deactivated_at === null
        && $this->deleted_at === null;
}

public function isActive(): bool
{
    return $this->email_verified_at !== null
        && $this->suspended_at === null
        && $this->deactivated_at === null
        && $this->deleted_at === null;
}

public function isSuspended(): bool
{
    return $this->suspended_at !== null
        && $this->deleted_at === null;
}

public function isDeactivated(): bool
{
    return $this->deactivated_at !== null
        && $this->suspended_at === null
        && $this->deleted_at === null;
}

public function isDeleted(): bool
{
    return $this->deleted_at !== null;
}

public function canLogIn(): bool
{
    return $this->isActive()
        || ($this->isDeactivated() && $this->deactivated_at->diffInDays(now()) <= 30);
}

public function canPurchase(): bool
{
    return $this->isActive();
}
```

### Scheduled Jobs Implementation

```php
// app/Jobs/DeleteDeactivatedUsers.php
class DeleteDeactivatedUsers implements ShouldQueue
{
    public function handle(): void
    {
        User::where('deactivated_at', '<=', now()->subDays(30))
            ->whereNull('deleted_at')
            ->each(function ($user) {
                $user->update(['deleted_at' => now()]);
                event(new UserDeleted($user));
                HardDeleteUserJob::dispatch($user)->delay(now()->addDays(90));
            });
    }
}

// app/Jobs/SendDeactivationReminder.php
class SendDeactivationReminder implements ShouldQueue
{
    public function handle(): void
    {
        User::where('deactivated_at', '<=', now()->subDays(25))
            ->where('deactivated_at', '>', now()->subDays(30))
            ->each(function ($user) {
                $daysLeft = 30 - $user->deactivated_at->diffInDays(now());
                DeactivationReminderEmail::dispatch($user, $daysLeft);
            });
    }
}

// app/Jobs/CleanupExpiredVerifications.php
class CleanupExpiredVerifications implements ShouldQueue
{
    public function handle(): void
    {
        DB::table('password_reset_tokens')
            ->where('created_at', '<', now()->subHour())
            ->delete();
    }
}

// app/Jobs/HardDeleteUserJob.php
class HardDeleteUserJob implements ShouldQueue
{
    public function handle(): void
    {
        User::where('deleted_at', '<=', now()->subDays(90))
            ->each(function ($user) {
                $user->sessions()->forceDelete();
                $user->tokens()->forceDelete();
                $user->activities()->delete();
                $user->loginHistory()->delete();
                $user->forceDelete();
            });
    }
}
```

### Troubleshooting Guide

| Issue | Cause | Solution |
|---|---|---|
| User cannot log in after registration | Email not verified | Check verification email sent |
| Suspended user can still access | Session not revoked | Manually revoke sessions |
| Deactivated user data not anonymized | Anonymization job failed | Run job manually |
| Deleted user still appears | Hard delete not run | Check scheduled jobs |
| Reactivation fails | Grace period expired | User must create new account |
| State mismatch | Race condition | Check database locks |

### Migration Considerations

When migrating from an existing system:

1. **Data mapping** — Map existing user states to new states
2. **Historical data** — Preserve audit trail from old system
3. **Rollback plan** — Ability to revert if issues arise
4. **Testing** — Test with production-like data volume
5. **Communication** — Notify users of state changes

### State Transition Guards

Before any state transition, guards must be checked:

```php
// app/Services/UserLifecycleService.php

class UserLifecycleService
{
    public function canTransition(User $user, string $from, string $to): bool
    {
        return match([$from, $to]) {
            ['pending', 'active'] => true,
            ['active', 'suspended'] => true,
            ['active', 'deactivated'] => true,
            ['suspended', 'active'] => true,
            ['deactivated', 'active'] => true,
            ['active', 'deleted'] => true,
            ['deactivated', 'deleted'] => true,
            ['pending', 'deleted'] => true,
            default => false,
        };
    }

    public function transition(User $user, string $to, array $data = []): void
    {
        $from = $this->getState($user);

        if (! $this->canTransition($user, $from, $to)) {
            throw new InvalidStateTransitionException($from, $to);
        }

        $this->applyTransition($user, $from, $to, $data);
        $this->dispatchEvents($user, $from, $to, $data);
        $this->logTransition($user, $from, $to, $data);
    }

    protected function getState(User $user): string
    {
        if ($user->deleted_at !== null) return 'deleted';
        if ($user->suspended_at !== null) return 'suspended';
        if ($user->deactivated_at !== null) return 'deactivated';
        if ($user->email_verified_at === null) return 'pending';
        return 'active';
    }

    protected function applyTransition(User $user, string $from, string $to, array $data): void
    {
        match($to) {
            'active' => $this->activate($user, $from),
            'suspended' => $this->suspend($user, $data),
            'deactivated' => $this->deactivate($user),
            'deleted' => $this->delete($user),
            default => throw new \InvalidArgumentException("Invalid state: {$to}"),
        };
    }

    protected function activate(User $user, string $from): void
    {
        $updates = match($from) {
            'pending' => ['email_verified_at' => now()],
            'suspended' => ['suspended_at' => null, 'suspended_reason' => null],
            'deactivated' => ['deactivated_at' => null],
            default => [],
        };

        $user->update($updates);
    }

    protected function suspend(User $user, array $data): void
    {
        $user->update([
            'suspended_at' => now(),
            'suspended_reason' => $data['reason'] ?? 'No reason provided',
            'suspended_by' => $data['admin_id'] ?? null,
        ]);

        // Revoke all sessions
        Session::where('user_id', $user->id)->delete();

        // Revoke all API tokens
        $user->tokens()->delete();
    }

    protected function deactivate(User $user): void
    {
        $user->update([
            'deactivated_at' => now(),
        ]);

        // Revoke sessions except current
        Session::where('user_id', $user->id)
            ->where('id', '!=', session()->getId())
            ->delete();

        // Revoke all API tokens
        $user->tokens()->delete();

        // Schedule deletion
        DeleteUserJob::dispatch($user)->delay(now()->addDays(30));
    }

    protected function delete(User $user): void
    {
        $user->update([
            'deleted_at' => now(),
        ]);

        // Anonymize personal data
        $user->update([
            'name' => 'Deleted User',
            'email' => 'deleted_' . $user->id . '@anonymized.invalid',
            'password' => Str::random(60),
            'username' => null,
        ]);

        // Schedule hard delete
        HardDeleteUserJob::dispatch($user)->delay(now()->addDays(90));
    }
}
```

```php
class DeleteDeactivatedUsers implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public int $tries = 3;
    public int $timeout = 300;

    public function handle(): void
    {
        User::where('deactivated_at', '<=', now()->subDays(30))
            ->whereNull('deleted_at')
            ->chunkById(100, function ($users) {
                foreach ($users as $user) {
                    DeleteUserJob::dispatch($user);
                }
            });
    }
}

// app/Jobs/HardDeleteUserJob.php
class HardDeleteUserJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        public User $user,
    ) {}

    public function handle(): void
    {
        DB::transaction(function () {
            // Delete all related data
            $this->user->sessions()->forceDelete();
            $this->user->tokens()->forceDelete();
            $this->user->activities()->delete();
            $this->user->loginHistory()->delete();

            // Force delete user
            $this->user->forceDelete();
        });

        event(new UserHardDeleted($this->user->id));
    }
}

            ->each(function ($user) {
                $daysLeft = 30 - $user->deactivated_at->diffInDays(now());

            });
```

```php
    {
```
```php
        $email = $this->argument('email');

{

    protected $description = 'Permanently delete users past retention period';

    public function handle(): int
    {
        $days = $this->option('days');

        $users = User::where('deleted_at', '<=', now()->subDays($days))

            $user->tokens()->forceDelete();

            $user->loginHistory()->delete();

        return 0;
    }
```

```php
    {
        $this->showModal = true;
    }

    {
        $this->showModal = false;
        $this->password = '';
        $this->resetErrorBag();
    }

    public function deactivate(): void
    {
        $this->validate([
            'password' => ['required', 'string'],
        ]);

        $user = Auth::user();

        if (! Hash::check($this->password, $user->password)) {
            $this->addError('password', 'The provided password is incorrect.');
            return;
        }

        $this->isSubmitting = true;

        try {
            $user->deactivate('User requested deactivation');

            event(new UserDeactivated($user));

            Auth::logout();
            session()->invalidate();
            session()->regenerateToken();

            $this->status = 'success';
            $this->showModal = false;

            return redirect()->route('home');
        } catch (\Exception $e) {
            $this->addError('password', 'Failed to deactivate account. Please try again.');
        } finally {
            $this->isSubmitting = false;
        }
    }

    public function render()
    {
        return view('livewire.settings.account-deactivation');
    }
}
```

```php
namespace App\Livewire\Settings;

use App\Models\User;
use Illuminate\Support\Facades\Auth;
use Livewire\Component;

class UserLifecycleStatus extends Component
{
    public ?string $status = null;
    public ?string $suspendedAt = null;
    public ?string $suspendedReason = null;
    public ?string $deactivatedAt = null;
    public ?string $deactivatedReason = null;
    public ?string $deletionScheduledAt = null;
    public int $daysUntilDeletion = 0;
    public bool $canReactivate = false;

    public function mount(): void
    {
        $user = Auth::user();

        $this->status = $user->status;
        $this->suspendedAt = $user->suspended_at?->toIso8601String();
        $this->suspendedReason = $user->suspended_reason;
        $this->deactivatedAt = $user->deactivated_at?->toIso8601String();
        $this->deactivatedReason = $user->deactivated_reason;
        $this->deletionScheduledAt = $user->deletion_scheduled_at?->toIso8601String();

        if ($user->deletion_scheduled_at) {
            $this->daysUntilDeletion = (int) $user->deletion_scheduled_at->diffInDays(now());
        }

        $this->canReactivate = $user->status === 'deactivated' &&
            $user->deactivated_at &&
            $user->deactivated_at->diffInDays(now()) <= 30;
    }

    public function reactivate(): void
    {
        $user = Auth::user();

        if (! $this->canReactivate) {
            return;
        }

        $user->reactivate();

        $this->status = 'active';
        $this->deactivatedAt = null;
        $this->deactivatedReason = null;
        $this->deletionScheduledAt = null;
        $this->daysUntilDeletion = 0;
        $this->canReactivate = false;

        $this->dispatch('reactivated');
    }

    public function render()
    {
        return view('livewire.settings.user-lifecycle-status');
    }
}
```

```php
class SendDeactivationReminder
{
    public function __construct(protected Carbon $deactivatedAt) {}

    public function handle(UserDeactivated $event): void
    {
        $user = $event->user;

        // Send reminders at 7 days, 3 days, and 1 day before deletion
        $daysRemaining = $user->deletion_scheduled_at->diffInDays(now());

        if (in_array($daysRemaining, [7, 3, 1])) {
            $user->notify(new DeactivationReminderNotification($daysRemaining));
        }
    }
```

```php
            'avatar' => null,
        ]);

        // Delete related personal data
        $user->settings()?->delete();
        $user->preferences()?->delete();
        $user->stats()?->delete();
        $user->loginHistory()->delete();
        $user->activities()->delete();
        $user->passkeys()->delete();
        $user->tokens()->delete();
        $user->sessions()->delete();

        // Archive marketplace products (not delete - preserve for license holders)
        $user->themes()->update(['archived' => true, 'archived_at' => now()]);
        $user->components()->update(['archived' => true, 'archived_at' => now()]);

        // Anonymize reviews
        Review::where('user_id', $user->id)->update([
            'user_name' => 'Anonymous',
            'user_id' => null,
        ]);

        // Anonymize comments
        Comment::where('user_id', $user->id)->update([
            'user_name' => 'Anonymous',
            'user_id' => null,
        ]);
    }

    public function getDataRetentionPeriod(): int
    {
        return config('gdpr.retention_days', 90);
    }
}
```

### User Lifecycle Webhooks

```php
// app/Services/WebhookService.php

class WebhookService
{
    public function dispatchUserLifecycleEvent(string $event, User $user, array $data = []): void
    {
        $payload = [
            'event' => $event,
            'timestamp' => now()->toISOString(),
            'user' => [
                'id' => $user->id,
                'email' => $user->email,
                'name' => $user->name,
                'status' => $user->status,
            ],
            'data' => $data,
        ];

        // Dispatch to registered webhook endpoints
        foreach (config('webhooks.endpoints', []) as $endpoint) {
            if (in_array($event, $endpoint['events'] ?? [])) {
                Http::async()->post($endpoint['url'], $payload)
                    ->timeout(10)
                    ->retry(3, 1000);
            }
        }
    }
}

// - user.registered
// - user.email_verified
// - user.suspended
// - user.unsuspended
// - user.deactivated
// - user.reactivated
// - user.deleted
// - user.hard_deleted
```

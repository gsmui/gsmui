# 09.09 — Social Login

## Purpose

Define the OAuth social login system for GsmUi, supporting GitHub, Google, and Microsoft as identity providers.

## Status: Phase 2

Social login is a Phase 2 feature. This document defines the architecture for implementation.

## Supported Providers

| Provider | Status | Scopes |
|---|---|---|
| GitHub | Phase 2 | `user:email` |
| Google | Phase 2 | `email profile` |
| Microsoft | Phase 3 | `email profile` |

## Social Login Flow

```text
User clicks "Sign in with GitHub"
    ↓
Redirect to GitHub OAuth
    ↓
User authorizes GsmUi
    ↓
GitHub redirects back with code
    ↓
Exchange code for access token
    ↓
Fetch user profile (email, name)
    ↓
Check if user exists in database
    ↓
If exists → login
    If not exists → create account + login
    ↓
Email is pre-verified (from OAuth provider)
    ↓
Redirect to dashboard
```

## Callback Handler

```php
// app/Http/Controllers/SocialLoginController.php

public function callback(string $provider): RedirectResponse
{
    $socialUser = Socialite::driver($provider)->user();

    $user = User::where('email', $socialUser->getEmail())->first();

    if (! $user) {
        $user = User::create([
            'name' => $socialUser->getName(),
            'email' => $socialUser->getEmail(),
            'email_verified_at' => now(),
            'password' => null,
        ]);

        $user->assignRole('user');

        // Store provider info
        $user->socialAccounts()->create([
            'provider' => $provider,
            'provider_id' => $socialUser->getId(),
        ]);

        event(new UserRegistered($user));
    }

    Auth::login($user, remember: true);

    event(new SocialLoginSuccess($user, $provider));

    return redirect()->intended('/dashboard');
}
```

## Security Notes

* Email is pre-verified by OAuth provider — skip email verification step
* Rate limit social login callbacks (10 per IP per minute)
* Validate OAuth state parameter to prevent CSRF
* Store only necessary data from OAuth provider
* Allow users to link/unlink social accounts from settings

4. Set Authorization callback URL: `https://yourdomain.com/auth/github/callback`

6. Set `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET` environment variables

```env
GITHUB_CLIENT_SECRET=your_github_client_secret
```

- `id` — Unique GitHub user ID (integer)
- `login` — GitHub username
- `email` — Primary email address (may be null if private)
- `name` — Display name
- `avatar_url` — Profile picture URL
- `html_url` — Profile page URL

## Extended Flow Diagrams

### Complete Social Login Sequence

```text
1. User visits /login
   → GsmUi renders login page with social buttons
   → Buttons show provider icons (GitHub, Google, Microsoft)

2. User clicks "Sign in with GitHub"
   → Livewire component calls redirectToProvider('github')
   → Socialite generates OAuth URL with:
     - client_id
     - redirect_uri
     - scope (user:email)
     - state (CSRF token)
   → Browser redirects to GitHub

3. GitHub OAuth page
   → User reviews permissions requested
   → User clicks "Authorize GsmUi"
   → GitHub generates authorization code
   → GitHub redirects to callback URL

4. Callback received at /auth/github/callback
   → SocialLoginController::callback('github') invoked
   → Socialite exchanges code for access token
   → Socialite fetches user profile from GitHub API
   → Returns SocialiteUser object with email, name, id

5. User matching
   → Check: Does user exist by email?
   → If YES: Skip to login step
   → If NO: Check if social account exists by provider_id
     → If YES: Link existing user
     → If NO: Create new user

6. New user creation (if needed)
   → Create User record:
     - name = socialUser->getName()
     - email = socialUser->getEmail()
     - email_verified_at = now() (pre-verified by OAuth)
     - password = null (no password for OAuth users)
   → Create SocialAccount record:
     - provider = 'github'
     - provider_id = socialUser->getId()
   → Assign default 'user' role
   → Fire UserRegistered event

7. Login
   → Auth::login($user, remember: true)
   → Session created
   → Fire SocialLoginSuccess event
   → Redirect to /dashboard
```

### Account Linking Flow

```text
1. User is logged in
   → Goes to Settings → Security → Connected Accounts

2. User clicks "Connect GitHub"
   → Same OAuth flow as login
   → On callback, SocialiteUser email is checked

3. Email matches authenticated user
   → Social account record created/updated
   → Success message displayed
   → Provider shows as "Connected"

4. Email does NOT match
   → Error: "This GitHub account is associated with a different email"
   → Account not linked
   → User must verify ownership or use matching email
```

### Account Unlinking Flow

```text
1. User is logged in
   → Goes to Settings → Security → Connected Accounts

2. User sees connected providers
   → Lists: GitHub (connected), Google (not connected)

3. User clicks "Disconnect" on GitHub
   → Password confirmation required
   → Check: Is this the user's ONLY login method?
   → If YES: Prevent unlinking, show warning
   → If NO: Remove social account record
   → Success message displayed
```

### ConnectedAccounts Component

```php
// app/Livewire/Settings/ConnectedAccounts.php

class ConnectedAccounts extends Component
{
    public ?string $pendingProvider = null;
    public bool $showConfirmation = false;

    public function getConnectedAccounts(): Collection
    {
        return Auth::user()->socialAccounts()
            ->with('provider')
            ->get();
    }

    public function getAvailableProviders(): array
    {
        $connected = $this->getConnectedAccounts()
            ->pluck('provider')
            ->toArray();

        return collect(['github', 'google', 'microsoft'])
            ->reject(fn($p) => in_array($p, $connected))
            ->toArray();
    }

    public function linkAccount(string $provider): RedirectResponse
    {
        $this->pendingProvider = $provider;

        return Socialite::driver($provider)
            ->scopes($this->getScopes($provider))
            ->redirect();
    }

    public function unlinkAccount(string $provider): void
    {
        $user = Auth::user();
        $account = $user->socialAccounts()
            ->where('provider', $provider)
            ->first();

        if (! $account) {
            $this->addError('unlink', 'Account not found.');
            return;
        }

        // Prevent unlinking if it's the only login method
        if ($user->password === null && $user->socialAccounts()->count() <= 1) {
            $this->addError('unlink', 'Cannot disconnect your only login method. Please set a password first.');
            return;
        }

        $account->delete();

        event(new SocialAccountUnlinked($user, $provider));
    }

    public function confirmUnlink(string $provider): void
    {
        $this->pendingProvider = $provider;
        $this->showConfirmation = true;
    }

    public function cancelUnlink(): void
    {
        $this->pendingProvider = null;
        $this->showConfirmation = false;
    }

    public function render(): View
    {
        return view('livewire.settings.connected-accounts');
    }
}
```

```php
// app/Models/SocialAccount.php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class SocialAccount extends Model
{
    protected $fillable = [
        'user_id',
        'provider',
        'provider_id',
        'provider_token',
        'provider_refresh_token',
        'token_expires_at',
        'nickname',
        'avatar',
        'raw_data',
    ];

    protected $casts = [
        'token_expires_at' => 'datetime',
        'raw_data' => 'array',
    ];

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }

    public function isExpired(): bool
    {
        return $this->token_expires_at &&
               $this->token_expires_at->isPast();
    }

    public function isProvider(string $provider): bool
    {
        return $this->provider === $provider;
    }

    public function getProviderDisplayName(): string
    {
        return match($this->provider) {
            'github' => 'GitHub',
            'google' => 'Google',
            'microsoft' => 'Microsoft',
            'apple' => 'Apple',
            'facebook' => 'Facebook',
            default => ucfirst($this->provider),
        };
    }
}
```

## Controller Implementation

### SocialLoginController

```php
// app/Http/Controllers/SocialLoginController.php

namespace App\Http\Controllers;

use App\Models\SocialAccount;
use App\Models\User;
use App\Events\SocialLoginSuccess;
use App\Events\UserRegistered;
use Illuminate\Http\RedirectResponse;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Str;
use Laravel\Socialite\Facades\Socialite;
use Laravel\Socialite\Contracts\User as SocialiteUser;

class SocialLoginController extends Controller
{
    public function redirect(string $provider): RedirectResponse
    {
        $this->validateProvider($provider);

        return Socialite::driver($provider)
            ->scopes($this->getScopes($provider))
            ->stateless()
            ->redirect();
    }

    public function callback(string $provider): RedirectResponse
    {
        $this->validateProvider($provider);

        try {
            $socialUser = Socialite::driver($provider)
                ->stateless()
                ->user();
        } catch (\Exception $e) {
            return redirect()->route('login')
                ->withErrors(['social' => 'Unable to authenticate with ' . ucfirst($provider) . '. Please try again.']);
        }

        $email = $socialUser->getEmail();

        if (! $email) {
            return redirect()->route('login')
                ->withErrors(['social' => 'Unable to retrieve email from ' . ucfirst($provider) . '. Please ensure your email is public.']);
        }

        // Check for existing social account
        $existingAccount = SocialAccount::where('provider', $provider)
            ->where('provider_id', $socialUser->getId())
            ->first();

        if ($existingAccount) {
            // Existing social account — login
            Auth::login($existingAccount->user, remember: true);

            // Update token if available
            $existingAccount->update([
                'provider_token' => $socialUser->token,
                'provider_refresh_token' => $socialUser->refreshToken,
                'token_expires_at' => $socialUser->expiresIn
                    ? now()->addSeconds($socialUser->expiresIn)
                    : null,
            ]);

            event(new SocialLoginSuccess($existingAccount->user, $provider));

            return redirect()->intended('/dashboard');
        }

        // Check for existing user by email
        $user = User::where('email', $email)->first();

        if (! $user) {
            // Create new user
            $user = User::create([
                'name' => $socialUser->getName() ?? $email,
                'email' => $email,
                'email_verified_at' => now(), // Pre-verified by OAuth
                'password' => null, // No password for OAuth users
                'avatar' => $socialUser->getAvatar(),
            ]);

            $user->assignRole('user');

            event(new UserRegistered($user));
        }

        // Create social account record
        $user->socialAccounts()->create([
            'provider' => $provider,
            'provider_id' => $socialUser->getId(),
            'provider_token' => $socialUser->token,
            'provider_refresh_token' => $socialUser->refreshToken,
            'token_expires_at' => $socialUser->expiresIn
                ? now()->addSeconds($socialUser->expiresIn)
                : null,
            'nickname' => $socialUser->getNickname(),
            'avatar' => $socialUser->getAvatar(),
            'raw_data' => $socialUser->getRaw(),
        ]);

        Auth::login($user, remember: true);

        event(new SocialLoginSuccess($user, $provider));

        return redirect()->intended('/dashboard');
    }

    protected function validateProvider(string $provider): void
    {
        $availableProviders = ['github', 'google', 'microsoft', 'apple', 'facebook'];

        if (! in_array($provider, $availableProviders)) {
            abort(404, 'Provider not supported.');
        }

        // Check if provider is enabled in config
        $configKey = "services.{$provider}.client_id";

        if (! config($configKey)) {
            abort(404, 'Provider not configured.');
        }
    }

    protected function getScopes(string $provider): array
    {
        return match($provider) {
            'github' => ['user:email'],
            'google' => ['email', 'profile'],
            'microsoft' => ['email', 'profile', 'openid'],
            'apple' => ['email', 'name'],
            'facebook' => ['email', 'public_profile'],
            default => [],
        };
    }
}
```

## Error Handling

### Common Error Scenarios

| Error | Cause | Solution |
|---|---|---|
| `Invalid state` | CSRF mismatch | Regenerate state, retry |
| `Redirect mismatch` | Callback URL mismatch | Verify `config/services.php` redirect |
| `Email not available` | Private email | Ask user to make email public |
| `Token expired` | OAuth token expired | Re-authenticate with provider |
| `Account already linked` | Duplicate social account | Show existing connection message |
| `Provider unavailable` | Provider API down | Retry later, show error |

```php
// app/Http/Controllers/SocialLoginController.php

protected function handleProviderError(\Exception $e, string $provider): RedirectResponse
{
    \Log::error("Social login error for {$provider}", [
        'error' => $e->getMessage(),
        'trace' => $e->getTraceAsString(),
    ]);

    $message = match(true) {
        str_contains($e->getMessage(), 'invalid_state') =>
            'Security validation failed. Please try again.',
        str_contains($e->getMessage(), 'redirect_uri_mismatch') =>
            'OAuth configuration error. Please contact support.',
        str_contains($e->getMessage(), 'access_denied') =>
            'You denied the permission request. Please try again.',

    };

    return redirect()->route('login')
        ->withErrors(['social' => $message]);
```

### Token Refresh

```php
// app/Jobs/RefreshSocialToken.php

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;

class RefreshSocialToken implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public function __construct(
        public SocialAccount $account,
    ) {}

    public function handle(): void
    {
        if (! $this->account->provider_refresh_token) {
            return;
        }

        try {
            $provider = Socialite::driver($this->account->provider)
                ->stateless();

            $newToken = $provider->getAccessTokenResponse([
                'grant_type' => 'refresh_token',
                'refresh_token' => $this->account->provider_refresh_token,
            ]);

            $this->account->update([
                'provider_token' => $newToken['access_token'],
                'provider_refresh_token' => $newToken['refresh_token'] ?? $this->account->provider_refresh_token,
                'token_expires_at' => isset($newToken['expires_in'])
                    ? now()->addSeconds($newToken['expires_in'])
                    : null,
            ]);
        } catch (\Exception $e) {
            \Log::error("Failed to refresh social token", [
                'account_id' => $this->account->id,
                'error' => $e->getMessage(),
            ]);
        }
    }
}
```

```php
// app/Services/AvatarCacheService.php

namespace App\Services;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Http;

class AvatarCacheService
{
    public function getAvatar(string $provider, string $providerId): ?string
    {
        $cacheKey = "avatar:{$provider}:{$providerId}";
        $ttl = now()->addDay();

        return Cache::remember($cacheKey, $ttl, function () use ($provider, $providerId) {

            'google' => null, // Google avatars require OAuth token
            'microsoft' => null, // Microsoft avatars require OAuth token
            default => null,
        };
    }

    public function invalidate(string $provider, string $providerId): void
    {
        Cache::forget("avatar:{$provider}:{$providerId}");
    }
}
```

```php
// app/Services/SocialLoginAnalytics.php

namespace App\Services;

use App\Models\SocialAccount;
use Illuminate\Support\Facades\DB;

class SocialLoginAnalytics
{
    /**
     * Get social login statistics.
     */
    public function getStats(): array
    {
        return [
            'total_social_accounts' => SocialAccount::count(),
            'accounts_by_provider' => $this->getAccountsByProvider(),
            'recent_logins' => $this->getRecentLogins(),
            'popular_providers' => $this->getPopularProviders(),
            'conversion_rate' => $this->getConversionRate(),
        ];
    }

    /**
     * Get accounts grouped by provider.
     */
    public function getAccountsByProvider(): array
    {
        return SocialAccount::select('provider', DB::raw('COUNT(*) as count'))
            ->groupBy('provider')
            ->pluck('count', 'provider')
            ->toArray();
    }

    /**
     * Get recent social logins.
     */
    public function getRecentLogins(int $days = 30): array
    {
        return SocialAccount::select('provider', DB::raw('DATE(created_at) as date'), DB::raw('COUNT(*) as count'))
            ->where('created_at', '>=', now()->subDays($days))
            ->groupBy('provider', 'date')
            ->orderBy('date')
            ->get()
            ->toArray();
    }

    /**
     * Get most popular providers.
     */
    public function getPopularProviders(): array
    {
        return SocialAccount::select('provider', DB::raw('COUNT(*) as count'))
            ->groupBy('provider')
            ->orderByDesc('count')
            ->get()
            ->pluck('count', 'provider')
            ->toArray();
    }

    /**
     * Get conversion rate (social logins vs total logins).
     */
    public function getConversionRate(): float
    {
        $totalLogins = DB::table('sessions')->count();
        $socialLogins = SocialAccount::count();

        if ($totalLogins === 0) {
            return 0;
        }

        return round(($socialLogins / $totalLogins) * 100, 2);
    }
}
```

```php
        // If last social account, ensure user has password
        $user = $account->user;
        $activeSocialAccounts = $user->socialAccounts()
            ->where('is_active', true)
            ->count();

        }

            'google' => $user->socialAccounts()->where('provider', 'google')->exists(),
```

```php
namespace App\Services;

{
```

### Rate Limiting Social Login

```php
// app/Http/Requests/SocialCallbackRequest.php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;
use Illuminate\Support\Facades\RateLimiter;

class SocialCallbackRequest extends FormRequest
{
    public function authorize(): bool
    {
        $key = 'social-login:' . $this->ip();

        if (RateLimiter::tooManyAttempts($key, 10)) {
            $seconds = RateLimiter::availableIn($key);
            return false;
        }

        RateLimiter::hit($key, 60);
        return true;
    }
}
```

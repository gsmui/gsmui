# 09.20 — Gates

## Purpose

Define the Laravel Gates for GsmUi, covering global ability checks that are not tied to specific models.

## Gates Overview

Gates are closures that determine if a user is authorized to perform a given ability. They are used for global checks, not resource-specific ones.

## Gate Definitions

```php
// app/Providers/AuthServiceProvider.php

use Illuminate\Support\Facades\Gate;

public function boot(): void
{
    $this->registerPolicies();

    // Admin abilities
    Gate::define('admin', function (User $user) {
        return $user->hasRole(['admin', 'super_admin']);
    });

    Gate::define('super_admin', function (User $user) {
        return $user->hasRole('super_admin');
    });

    // Support abilities
    Gate::define('support', function (User $user) {
        return $user->hasRole(['support', 'admin', 'super_admin']);
    });

    // Content abilities
    Gate::define('editor', function (User $user) {
        return $user->hasRole(['editor', 'admin', 'super_admin']);
    });

    Gate::define('moderator', function (User $user) {
        return $user->hasRole(['moderator', 'editor', 'admin', 'super_admin']);
    });

    // Creator abilities
    Gate::define('creator', function (User $user) {
        return $user->hasRole(['creator', 'admin', 'super_admin']);
    });

    // Billing abilities
    Gate::define('manage_billing', function (User $user) {
        return $user->hasRole(['admin', 'super_admin']);
    });

    // System abilities
    Gate::define('access_admin_panel', function (User $user) {
        return $user->hasRole(['admin', 'super_admin']);
    });

    Gate::define('manage_system', function (User $user) {
        return $user->hasRole('super_admin');
    });

    // Default gate behavior
    Gate::before(function (User $user, string $ability) {
        if ($user->hasRole('super_admin')) {
            return true;
        }
    });
}
```

## Gate Usage

### Blade

```blade
@can('admin')

@endcan

@can('support')

```

### Livewire

```php
if (Gate::allows('admin')) {
    // Show admin features
}

Gate::authorize('access_admin_panel');
```

### Middleware

```php

    Route::get('/admin', AdminController::class);
});

    Route::get('/admin/settings', SettingsController::class);

```

## Gate Response

```php
// Custom response for denied gates
Gate::after(function (User $user, string $ability, $result, $arguments) {
    if (! $result) {
        // Log unauthorized attempt
        activity('authorization')
            ->performedOn($user)
            ->withProperties([
                'ability' => $ability,
                'arguments' => $arguments,
            ])
            ->log('Authorization denied');
    }
});
```

## Gate vs Policy

| Feature | Gates | Policies |
|---|---|---|
| Scope | Global abilities | Resource-specific |
| Arguments | User only | User + Model |
| Naming | `admin`, `super_admin` | `update`, `delete` |
| Usage | Middleware, Blade, Livewire | Blade, Livewire, Controller |
| Example | `Gate::allows('admin')` | `$user->can('update', $theme)` |

## Best Practices

1. Use gates for global abilities (admin, support, editor)
2. Use policies for resource-specific authorization
3. Keep gates simple — role checks only
4. Don't put complex logic in gates
5. Use `Gate::before` for super_admin bypass
6. Log authorization failures for audit

## Gate Service Layer

### Gate Registry Service

```php
// app/Services/GateRegistryService.php

namespace App\Services;

use Closure;
use Illuminate\Support\Facades\Gate;

class GateRegistryService
{
    protected array $registeredGates = [];
    protected array $gateDefinitions = [];

    /**
     * Register a gate with metadata.
     */
    public function register(
        string $name,
        Closure $callback,
        ?string $description = null,
        ?string $group = null
    ): void {
        $this->registeredGates[$name] = [
            'name' => $name,
            'description' => $description,
            'group' => $group,
            'registered_at' => now(),
        ];

        Gate::define($name, $callback);
    }

    /**
     * Register a gate that checks a permission.
     */
    public function registerPermissionGate(string $name, string $permission): void
    {
        $this->register(
            $name,
            fn($user) => $user->can($permission),
            "Permission gate: {$permission}",
            'permissions'
        );
    }

    /**
     * Register a gate that checks multiple roles.
     */
    public function registerRoleGate(string $name, array $roles): void
    {
        $this->register(
            $name,
            fn($user) => $user->hasRole($roles),
            "Role gate: " . implode(', ', $roles),
            'roles'
        );
    }

    /**
     * Get all registered gates with metadata.
     */
    public function getRegisteredGates(): array
    {
        return $this->registeredGates;
    }

    /**
     * Get gates by group.
     */
    public function getGatesByGroup(string $group): array
    {
        return array_filter(
            $this->registeredGates,
            fn($gate) => $gate['group'] === $group
        );
    }

    /**
     * Check if a gate is registered.
     */
    public function isRegistered(string $name): bool
    {
        return isset($this->registeredGates[$name]);
    }

    /**
     * Get gate description.
     */
    public function getGateDescription(string $name): ?string
    {
        return $this->registeredGates[$name]['description'] ?? null;
    }
}
```

```php
                    ->withProperties([
                        'ability' => $ability,
                        'arguments' => array_keys($arguments),
                        'ip_address' => request()->ip(),

                    ->log("Gate denied: {$ability}");
            }

            return $result;
        });
```

### Gate Audit Service

```php
// app/Services/GateAuditService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\DB;

class GateAuditService
{
    /**
     * Log a gate check.
     */
    public function logGateCheck(
        User $user,
        string $ability,
        bool $result,
        ?string $reason = null,
        array $context = []
    ): void {
        DB::table('gate_audit_log')->insert([
            'user_id' => $user->id,
            'ability' => $ability,
            'result' => $result,
            'reason' => $reason,
            'context' => json_encode($context),
            'ip_address' => request()->ip(),
            'user_agent' => request()->userAgent(),
            'created_at' => now(),
        ]);
    }

    /**
     * Get gate audit log for a user.
     */
    public function getUserAuditLog(User $user, int $limit = 100): Collection
    {
        return DB::table('gate_audit_log')
            ->where('user_id', $user->id)
            ->orderBy('created_at', 'desc')
            ->limit($limit)
            ->get();
    }

    /**
     * Get gate denial statistics.
     */
    public function getDenialStats(int $minutes = 60): array
    {
        return DB::table('gate_audit_log')
            ->where('result', false)
            ->where('created_at', '>=', now()->subMinutes($minutes))
            ->select('ability', DB::raw('count(*) as count'))
            ->groupBy('ability')
            ->orderBy('count', 'desc')
            ->get()
            ->pluck('count', 'ability')
            ->toArray();
    }

    /**
     * Get most frequently denied abilities.
     */
    public function getMostDeniedAbilities(int $limit = 10): array
    {
        return DB::table('gate_audit_log')
            ->where('result', false)
            ->select('ability', DB::raw('count(*) as count'))
            ->groupBy('ability')
            ->orderBy('count', 'desc')
            ->limit($limit)
            ->get()
            ->pluck('count', 'ability')
            ->toArray();
    }

    /**
     * Get users with highest denial rates.
     */
    public function getHighDenialUsers(int $limit = 10): Collection
    {
        return DB::table('gate_audit_log')
            ->where('result', false)
            ->where('created_at', '>=', now()->subHours(24))
            ->select('user_id', DB::raw('count(*) as denial_count'))
            ->groupBy('user_id')
            ->orderBy('denial_count', 'desc')
            ->limit($limit)
            ->get();
    }
}
```

```php
    {
        $this->registry->register('test_gate', fn($user) => true, 'Test gate', 'testing');
```

## Gate Quick Reference

| Operation | Code | Description |
|---|---|---|
| Check gate | `Gate::allows('admin')` | Check single gate |
| Check with user | `Gate::forUser($user)->allows('admin')` | Check for specific user |
| Authorize gate | `Gate::authorize('admin')` | Throw if denied |
| Define gate | `Gate::define('name', fn() => ...)` | Register gate |
| Before callback | `Gate::before(fn() => true)` | Global bypass |
| After callback | `Gate::after(fn() => null)` | Audit logging |

| Get abilities | `$user->getAbilities()` | All user abilities |
| Check middleware | `Route::middleware('can:admin')` | Route protection |
| Blade check | `@can('admin') ... @endcan` | Conditional UI |

## Gate Performance Optimization

### Gate Evaluation Pipeline

```text
Gate Evaluation Flow:
    1. Check Gate::before callbacks (super_admin bypass)
    2. Find registered gate definition
    3. Execute gate closure with user + arguments
    4. Check Gate::after callbacks (audit logging)
    5. Return boolean result

Performance Considerations:
    - Gate::before short-circuits for super_admin
    - Gate closures should be lightweight (role checks only)
    - Avoid database queries inside gate closures
    - Use caching for expensive permission lookups
    - Gate definitions are registered once at boot time
```

### Gate Cache Strategy

```php
// app/Services/GateCacheService.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Gate;

class GateCacheService
{
    /**
     * Cache gate results for a user to avoid repeated evaluations.
     */
    public function cachedAllows(User $user, string $ability, $arguments = [], int $ttl = 300): bool
    {
        $cacheKey = $this->buildCacheKey($user, $ability, $arguments);

        return Cache::remember($cacheKey, $ttl, function () use ($user, $ability, $arguments) {
            return Gate::forUser($user)->allows($ability, $arguments);
        });
    }

    /**
     * Clear all cached gate results for a user.
     */
    public function clearUserCache(User $user): void
    {
        $pattern = "gate:user:{$user->id}:*";

        // For Redis
        if (method_exists(Cache::getStore(), 'tags')) {
            Cache::tags(["gate:user:{$user->id}"])->flush();
        }

        // For file/database cache, iterate known keys
        $abilities = $this->getAllRegisteredAbilities();
        foreach ($abilities as $ability) {
            Cache::forget("gate:user:{$user->id}:{$ability}");
        }
    }

    /**
     * Build a unique cache key for a gate evaluation.
     */
    protected function buildCacheKey(User $user, string $ability, array $arguments): string
    {
        $argumentHash = md5(json_encode(array_map(function ($arg) {
            return is_object($arg) ? get_class($arg) . ':' . $arg->id : $arg;
        }, $arguments)));

        return "gate:user:{$user->id}:{$ability}:{$argumentHash}";
    }

    /**
     * Get all registered abilities for cache clearing.
     */
    protected function getAllRegisteredAbilities(): array
    {
        return [
            'admin', 'super_admin', 'support', 'editor', 'moderator',
            'creator', 'manage_billing', 'access_admin_panel', 'manage_system',
            'access_support_panel', 'manage_content', 'publish_content',
            'review_content', 'moderate_content', 'create_themes',
            'create_components', 'manage_own_themes', 'marketplace_access',
            'marketplace_purchase', 'playground_access', 'ai_access',
            'mcp_access', 'api_access', 'settings_read', 'settings_manage',
```

### Gate Rate Limiting

```php
// app/Services/GateRateLimiter.php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Facades\RateLimiter;

class GateRateLimiter
{
    /**
     * Check if a user has exceeded gate evaluation rate limits.
     * Useful for preventing brute-force permission probing.
     */
    public function isRateLimited(User $user, string $ability): bool
    {
        $key = "gate-rate:{$user->id}:{$ability}";

        return ! RateLimiter::attempt($key, 100, function () {
            // Allow if under limit
            return true;
        }, 60); // 100 checks per minute per ability
    }

    /**
     * Check if a user is probing for unauthorized abilities.
     */
    public function isProbing(User $user, int $threshold = 50, int $windowMinutes = 5): bool
    {
        $key = "gate-probe:{$user->id}";
        $attempts = RateLimiter::attempts($key);

        RateLimiter::hit($key, $windowMinutes * 60);

        return $attempts > $threshold;
    }

    /**
     * Get remaining attempts for a user.
     */
    public function getRemainingAttempts(User $user, string $ability): int
    {
        $key = "gate-rate:{$user->id}:{$ability}";

        return RateLimiter::remaining($key, 100);
    }
}
```

### Gate-Based Route Middleware

```php
// app/Http/Middleware/CheckGate.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Gate;
use Symfony\Component\HttpFoundation\Response;

class CheckGate
{
    /**
     * Handle an incoming request.
     *
     * Usage: Route::middleware('gate:admin')
     * Usage: Route::middleware('gate:manage_billing,manage_system')
     */
    public function handle(Request $request, Closure $next, string ...$abilities): Response
    {
        if (! $request->user()) {
            if ($request->expectsJson()) {
                return response()->json(['message' => 'Unauthenticated.'], 401);
            }
            return redirect()->route('login');
        }

        foreach ($abilities as $ability) {
            if (! Gate::forUser($request->user())->allows($ability)) {
                if ($request->expectsJson()) {
                    return response()->json([
                        'message' => 'Forbidden.',
                        'error' => "Missing gate: {$ability}",
                    ], 403);
                }
                abort(403, "Unauthorized. Required gate: {$ability}");
            }
        }

        return $next($request);
    }
}
```

### Any-Gate Middleware

```php
// app/Http/Middleware/CheckAnyGate.php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Gate;
use Symfony\Component\HttpFoundation\Response;

class CheckAnyGate
{
    /**
     * Handle an incoming request.
     *
     * Usage: Route::middleware('any_gate:admin,support,editor')
     */
    public function handle(Request $request, Closure $next, string ...$abilities): Response
    {
        if (! $request->user()) {
            if ($request->expectsJson()) {
                return response()->json(['message' => 'Unauthenticated.'], 401);
            }
            return redirect()->route('login');
        }

        $hasAny = false;
        foreach ($abilities as $ability) {
            if (Gate::forUser($request->user())->allows($ability)) {
                $hasAny = true;
                break;
            }
        }

        if (! $hasAny) {
            if ($request->expectsJson()) {
                return response()->json([
                    'message' => 'Forbidden.',
                    'error' => 'Missing any of gates: ' . implode(', ', $abilities),
                ], 403);
            }
            abort(403, 'Unauthorized. You do not have the required access.');
        }

        return $next($request);
    }
}
```

```php
// app/Providers/BladeServiceProvider.php

namespace App\Providers;

use Illuminate\Support\Facades\Blade;
use Illuminate\Support\ServiceProvider;

class BladeServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // @gates(['admin', 'editor']) — checks if user has any of the listed gates
        Blade::if('gates', function (array $abilities) {
            foreach ($abilities as $ability) {
                if (auth()->check() && \Illuminate\Support\Facades\Gate::allows($ability)) {
                    return true;
                }
            }
            return false;
        });

        // @allgates(['admin', 'manage_system']) — checks if user has all listed gates
        Blade::if('allgates', function (array $abilities) {
            if (! auth()->check()) {
                return false;
            }
            foreach ($abilities as $ability) {
                if (! \Illuminate\Support\Facades\Gate::allows($ability)) {
                    return false;
                }
            }
            return true;
        });

        // @ngate('admin') — inverse of @can
        Blade::if('ngate', function (string $ability) {
            return auth()->guest() || \Illuminate\Support\Facades\Gate::denies($ability);
        });

        // @gateunless('super_admin') — show content unless user has the gate
        Blade::if('gateunless', function (string $ability) {
            return auth()->guest() || \Illuminate\Support\Facades\Gate::denies($ability);
        });
    }
}
```

```php
                'ip_address' => request()->ip(),

namespace App\Listeners;

use App\Events\GateDenied;
use App\Models\User;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Support\Facades\Mail;

class AlertOnSuspiciousGateDenials implements ShouldQueue
{
    /**
     * Critical gates that should trigger alerts when denied repeatedly.
     */
    protected array $criticalGates = [
        'admin', 'super_admin', 'manage_system', 'manage_billing',
        'access_admin_panel', 'manage_settings',
    ];

    public function handle(GateDenied $event): void
    {
        if (! in_array($event->ability, $this->criticalGates)) {
            return;
        }

        // Count recent denials for this user on critical gates
        $recentDenials = DB::table('gate_audit_log')
            ->where('user_id', $event->user->id)
            ->where('result', false)
            ->whereIn('ability', $this->criticalGates)
            ->where('created_at', '>=', now()->subMinutes(15))
            ->count();

        // Alert if 5+ critical gate denials in 15 minutes
        if ($recentDenials >= 5) {
            $admins = User::whereHas('roles', fn($q) => $q->where('name', 'super_admin'))->get();

            foreach ($admins as $admin) {
                Mail::to($admin->email)->send(
                    new \App\Mail\SuspiciousGateDenialMail($event->user, $recentDenials)
                );
            }
        }
    }
}
```

```php
     * Assert that a user is allowed by a gate.
     */
    protected function assertGateAllows(User $user, string $ability, $arguments = []): void
    {
        $result = Gate::forUser($user)->allows($ability, $arguments);

        $this->assertTrue(
            $result,
            "Expected user to be allowed by gate '{$ability}' but was denied."
        );
    }

    /**
     * Assert that a user is denied by a gate.
     */
    protected function assertGateDenies(User $user, string $ability, $arguments = []): void
    {
        $result = Gate::forUser($user)->denies($ability, $arguments);

        $this->assertTrue(
            $result,
            "Expected user to be denied by gate '{$ability}' but was allowed."
        );
    }

    /**
     * Assert that a user is denied by a gate with a specific response.
     */
    protected function assertGateDeniesWithMessage(User $user, string $ability, string $message): void
    {
        $response = Gate::forUser($user)->inspect($ability);

        $this->assertEquals($message, $response->message());
    }

    /**
     * Test a gate against all roles.
     */
    protected function testGateAgainstRoles(
        string $ability,
        array $allowedRoles,
        array $deniedRoles,
        $arguments = []
    ): void {
        foreach ($allowedRoles as $roleName) {
            $user = $this->createUserWithRole($roleName);
            $this->assertGateAllows($user, $ability, $arguments);
        }

        foreach ($deniedRoles as $roleName) {
            $user = $this->createUserWithRole($roleName);
            $this->assertGateDenies($user, $ability, $arguments);
        }
    }

    /**
     * Get all abilities a user has.
     */
    protected function getUserAbilities(User $user): array
    {
        $abilities = [];

        $allGates = [
            'admin', 'super_admin', 'support', 'editor', 'moderator',
            'creator', 'manage_billing', 'access_admin_panel', 'manage_system',
            'access_support_panel', 'manage_content', 'publish_content',
            'create_themes', 'create_components', 'marketplace_access',
            'marketplace_purchase', 'playground_access', 'ai_access',
            'mcp_access', 'api_access', 'settings_read', 'settings_manage',
        ];

        foreach ($allGates as $gate) {
            $abilities[$gate] = Gate::forUser($user)->allows($gate);
        }

        return $abilities;
    }
}
```

# 09.29 — Security Events

## Purpose

Define the security event system for GsmUi, covering event dispatching, handling, alerting, and automated responses.

## Security Event Types

### Authentication Events

| Event | Class | Severity |
|---|---|---|
| Login Successful | `LoginSuccessful` | Info |
| Login Failed | `LoginFailed` | Warning |
| Login from New Device | `LoginFromNewDevice` | Info |
| Login from New Location | `LoginFromNewLocation` | Warning |
| Password Changed | `PasswordChanged` | Info |
| Password Reset Requested | `PasswordResetRequested` | Info |
| Password Reset Completed | `PasswordResetCompleted` | Info |
| 2FA Enabled | `TwoFactorEnabled` | Info |
| 2FA Disabled | `TwoFactorDisabled` | Warning |
| 2FA Challenge Failed | `TwoFactorChallengeFailed` | Warning |
| Recovery Code Used | `RecoveryCodeUsed` | Warning |

### Authorization Events

| Event | Class | Severity |
|---|---|---|
| Unauthorized Access Attempt | `UnauthorizedAccessAttempt` | Warning |
| Role Changed | `RoleChanged` | Info |
| Permission Changed | `PermissionChanged` | Info |
| Account Suspended | `AccountSuspended` | Critical |
| Account Unsuspended | `AccountUnsuspended` | Info |

### Suspicious Activity Events

| Event | Class | Severity |
|---|---|---|
| Multiple Failed Logins | `MultipleFailedLogins` | Critical |
| Brute Force Detected | `BruteForceDetected` | Critical |
| Credential Stuffing Detected | `CredentialStuffingDetected` | Critical |
| Session Hijacking Attempt | `SessionHijackingAttempt` | Critical |
| API Abuse Detected | `ApiAbuseDetected` | Warning |

## Event Listeners

```php
// app/Listeners/SecurityEventDispatcher.php

class SecurityEventDispatcher
{
    public function handleLoginFailed(LoginFailedEvent $event): void
    {
        $email = $event->email;
        $ip = $event->ip;

        // Track failure count
        $failures = Cache::increment("login_failures:{$ip}");

        if ($failures >= 5) {
            event(new BruteForceDetected($ip, $email));
            Mail::to(config('app.admin_email'))->send(new BruteForceAlertEmail($ip, $email));
        }

        // Track per-email failures
        $emailFailures = Cache::increment("login_failures:{$email}");

        if ($emailFailures >= 10) {
            event(new CredentialStuffingDetected($email));
        }
    }

    public function handleSuspiciousActivity(SuspiciousActivityEvent $event): void
    {
        // Log to audit trail
        activity('security')
            ->event($event->getName())
            ->withProperties($event->toArray())
            ->log($event->getDescription());

        // Send alert
        if ($event->severity === 'critical') {
            Mail::to(config('app.admin_email'))
                ->send(new SecurityAlertEmail($event));
        }

        // Notify user if applicable
        if ($event->userId) {
            Mail::to($event->user->email)
                ->send(new SecurityNotificationEmail($event));
        }
    }
}
```

## Event Handling Flow

```text
Security Event Occurs
    ↓
Event Dispatched
    ↓
Listener Handles Event
    ↓
├── Log to Audit Trail (Spatie Activity Log)
├── Send Email Alert (if severity >= warning)
├── Update Cache (for rate limiting)
├── Trigger Automated Response (if critical)
└── Notify Admin (if critical)
```

## Automated Responses

| Event | Automated Response |
|---|---|
| 5+ failed logins | Temp lockout (15 min) + email alert |
| 10+ failed logins | Temp lockout (1 hour) + admin alert |
| New device + suspicious | Require 2FA re-verification |
| Account takeover suspected | Force logout + require password reset |
| API abuse | Temp token suspension |

```php
    abstract public function getDescription(): string;

        public readonly ?string $deviceFingerprint,
        public readonly string $failureReason,
        public readonly string $failureCategory,

    {
        return 'user.login_failed';
    }

    public function getDescription(): string
    {
        return "Failed login attempt for {$this->email} from {$this->ipAddress}";

    {
        if ($this->accountLocked) return 'critical';
        if ($this->failureCountForEmail >= 10) return 'critical';
        if ($this->failureCountForIp >= 5) return 'warning';
        return 'info';

    public function toArray(): array
    {
        return [
            'email' => $this->email,
            'ip' => $this->ipAddress,
            'user_agent' => $this->userAgent,
            'device_fingerprint' => $this->deviceFingerprint,
            'failure_reason' => $this->failureReason,
            'failure_category' => $this->failureCategory,
            'failure_count_email' => $this->failureCountForEmail,
            'failure_count_ip' => $this->failureCountForIp,
            'account_locked' => $this->accountLocked,
        ];
    }

    public function getAttackingIps(): array
    {
        return [$this->ipAddress];
    }
}
```

### Security Event Dispatching

```php
// app/Services/SecurityEventDispatcher.php

class SecurityEventDispatcher
{
    public function __construct(
        private AuditLogService $auditLog,
        private NotificationService $notifications,
        private RateLimitMonitorService $rateLimitMonitor,
    ) {}

    public function dispatchLoginSuccessful(LoginSuccessful $event): void
    {
        // Log to audit trail
        $this->auditLog->log(
            logName: 'auth',
            event: $event->getName(),
            subject: $event->user,
            causer: $event->user,
            description: $event->getDescription(),
            properties: $event->toArray(),
        );

        // Check for new device or location
        if ($event->isNewDevice || $event->isNewLocation) {
            $this->notifications->notifyNewLogin($event->user, $event);
        }

        // Check risk score
        if ($event->riskScore >= 60) {
            $this->handleSuspiciousLogin($event);
        }
    }

    public function dispatchLoginFailed(LoginFailed $event): void
    {
        // Log to audit trail
        $this->auditLog->log(
            logName: 'auth',
            event: $event->getName(),
            subject: null,
            causer: null,
            description: $event->getDescription(),
            properties: $event->toArray(),
        );

        // Check for brute force
        if ($event->failureCountForIp >= 5) {
            $this->dispatch(new BruteForceDetected(
                ipAddress: $event->ipAddress,
                attemptCount: $event->failureCountForIp,
                targetedEmails: [$event->email],
                timeWindow: '15 minutes',
            ));
        }

        // Check for credential stuffing
        if ($event->failureCountForEmail >= 10) {
            $this->dispatch(new CredentialStuffingDetected(
                ipAddress: $event->ipAddress,
                uniqueEmails: $event->failureCountForEmail,
                timeWindowMinutes: 15,
                sampleEmails: [$event->email],
            ));
        }

        // Send user notification on repeated failures
        $user = User::where('email', $event->email)->first();
        if ($user && $event->failureCountForEmail >= 3) {
            $this->notifications->notifyRepeatedFailures($user, $event);
        }
    }

    public function dispatchSessionHijacking(SessionHijackingAttempt $event): void
    {
        $this->auditLog->log(
            logName: 'security',
            event: $event->getName(),
            subject: $event->user,
            causer: $event->user,
            description: $event->getDescription(),
            properties: $event->toArray(),
        );

        $this->notifications->notifySecurityTeam($event);
        $this->notifications->notifyUser($event->user, $event);
    }

    private function handleSuspiciousLogin(LoginSuccessful $event): void
    {
        $this->auditLog->log(
            logName: 'security',
            event: 'security.suspicious_login',
            subject: $event->user,
            causer: $event->user,
            description: "Suspicious login detected for {$event->user->email}",
            properties: array_merge($event->toArray(), ['reason' => 'high_risk_score']),
        );

        if ($event->riskScore >= 80) {
            $this->notifications->notifySuspiciousLogin($event->user, $event);
        }
    }

    private function dispatch(SecurityEvent $event): void
    {
        app('events')->dispatch($event);
    }
}
```

### Security Event Listener Registry

```php
// app/Listeners/Security/LoginFailedListener.php

class LoginFailedListener
{
    public function __construct(
        private LoginHistoryService $historyService,
        private AccountLockoutService $lockoutService,
        private ProgressiveRateLimiter $rateLimiter,
    ) {}

    public function handle(LoginFailed $event): void
    {
        $this->historyService->recordLogin(
            user: User::where('email', $event->email)->first(),
            success: false,
            failureReason: $event->failureReason,
            context: [
                'ip' => $event->ipAddress,
                'user_agent' => $event->userAgent,
                'failure_category' => $event->failureCategory,
            ]
        );

        $this->rateLimiter->recordFailure($event->ipAddress);
        $this->rateLimiter->recordFailure("email:{$event->email}");

        $user = User::where('email', $event->email)->first();
        if ($user) {
            $this->lockoutService->recordFailure($user, $event->ipAddress);
        }
    }
}
```

### Security Event Livewire Components

```php
// app/Livewire/Admin/SecurityEventDashboard.php

class SecurityEventDashboard extends Component
{
    public int $hours = 24;
    public array $summary = [];
    public array $eventTypes = [];
    public array $criticalEvents = [];
    public array $blockedIps = [];

    public function mount(): void
    {
        $this->loadData();
    }

    public function updatedHours(): void
    {
        $this->loadData();
    }

    private function loadData(): void
    {
        $startDate = now()->subHours($this->hours);

        $this->summary = Activity::where('created_at', '>=', $startDate)
            ->selectRaw('
                COUNT(*) as total,
                SUM(CASE WHEN properties.severity = "critical" THEN 1 ELSE 0 END) as critical,
                SUM(CASE WHEN properties.severity = "warning" THEN 1 ELSE 0 END) as warning,
                SUM(CASE WHEN properties.severity = "info" THEN 1 ELSE 0 END) as info
            ')
            ->first()
            ->toArray();

        $this->eventTypes = Activity::where('created_at', '>=', $startDate)
            ->selectRaw('event, COUNT(*) as count')
            ->groupBy('event')
            ->orderByDesc('count')
            ->limit(10)
            ->get()
            ->toArray();

        $this->criticalEvents = Activity::where('created_at', '>=', $startDate)
            ->whereIn('event', [
                'security.brute_force_detected',
                'security.credential_stuffing_detected',
                'security.session_hijacking_attempt',
                'security.account_takeover_suspected',
            ])
            ->with('causer')
            ->orderByDesc('created_at')
            ->limit(10)
            ->get()
            ->toArray();

        $this->blockedIps = Cache::get('blocked_ips', []);
    }

    public function render(): string
    {
        return <<<'blade'
        <div class="space-y-6">
            <div class="flex items-center justify-between">
                <h1 class="text-2xl font-bold">Security Event Dashboard</h1>
                <x-gsmui:select wire:model="hours" :options="[1 => '1 hour', 6 => '6 hours', 24 => '24 hours', 168 => '7 days']" />
            </div>

            <div class="grid grid-cols-4 gap-4">
                <div class="rounded-xl border p-4">
                    <div class="text-2xl font-bold">{{ number_format($this->summary['total'] ?? 0) }}</div>
                    <div class="text-sm text-zinc-500">Total Events</div>
                </div>
```

### Risk Scoring Engine

```php
// app/Services/Security/RiskScoringEngine.php

namespace App\Services\Security;

use App\Models\User;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\DB;

class RiskScoringEngine
{
    protected array $weights = [
        'new_device' => 15,
        'new_location' => 20,
        'unusual_time' => 10,
        'unusual_country' => 25,
        'vpn_detected' => 5,
        'proxy_detected' => 10,
        'tor_detected' => 30,
        'failed_recently' => 15,
        'account_age' => 5,
        'ip_reputation' => 20,
        'velocity_anomaly' => 25,
    ];

    public function calculateLoginRisk(User $user, array $context): int
    {
        $score = 0;

        if ($this->isNewDevice($user, $context['device_fingerprint'])) {
            $score += $this->weights['new_device'];
        }

        if ($this->isNewLocation($user, $context['ip_address'])) {
            $score += $this->weights['new_location'];
        }

        if ($this->isUnusualTime($user)) {
            $score += $this->weights['unusual_time'];
        }

        if ($this->isUnusualCountry($user, $context['ip_address'])) {
            $score += $this->weights['unusual_country'];
        }

        if ($this->isVpn($context['ip_address'])) {
            $score += $this->weights['vpn_detected'];
        }

        if ($this->isProxy($context['ip_address'])) {
            $score += $this->weights['proxy_detected'];
        }

        if ($this->isTor($context['ip_address'])) {
            $score += $this->weights['tor_detected'];
        }

        if ($this->hasRecentFailedLogins($user)) {
            $score += $this->weights['failed_recently'];
        }

        if ($this->isLowReputationIp($context['ip_address'])) {
            $score += $this->weights['ip_reputation'];
        }

        if ($this->hasVelocityAnomaly($user, $context['ip_address'])) {
            $score += $this->weights['velocity_anomaly'];
        }

        return min(100, $score);
    }

    protected function isNewDevice(User $user, string $fingerprint): bool
    {
        $knownDevices = Cache::get("user_devices:{$user->id}", []);
        return !in_array($fingerprint, $knownDevices);
    }

    protected function isNewLocation(User $user, string $ipAddress): bool
    {
        $lastLocation = Cache::get("user_location:{$user->id}");
        $currentLocation = $this->getGeoLocation($ipAddress);

        if (!$lastLocation) return false;

        return $lastLocation['country'] !== $currentLocation['country'];
    }

    protected function isUnusualTime(User $user): bool
    {
        $usualHours = Cache::get("user_usual_hours:{$user->id}", []);
        $currentHour = now()->hour;

        return !empty($usualHours) && !in_array($currentHour, $usualHours);
    }

    protected function isUnusualCountry(User $user, string $ipAddress): bool
    {
        $usualCountries = Cache::get("user_countries:{$user->id}", []);
        $currentCountry = $this->getGeoLocation($ipAddress)['country'] ?? null;

        return !empty($usualCountries) && $currentCountry && !in_array($currentCountry, $usualCountries);
    }

    protected function isVpn(string $ipAddress): bool
    {
        return Cache::get("ip_type:{$ipAddress}") === 'vpn';
    }

    protected function isProxy(string $ipAddress): bool
    {
        return Cache::get("ip_type:{$ipAddress}") === 'proxy';
    }

    protected function isTor(string $ipAddress): bool
    {
        return Cache::get("ip_type:{$ipAddress}") === 'tor';
    }

    protected function hasRecentFailedLogins(User $user): bool
    {
        return DB::table('security_events')
            ->where('user_id', $user->id)
            ->where('event_type', 'login_failed')
            ->where('created_at', '>', now()->subHours(24))
            ->count() > 5;
    }

    protected function isLowReputationIp(string $ipAddress): bool
    {
        $reputation = Cache::get("ip_reputation:{$ipAddress}");
        return $reputation !== null && $reputation < 30;
    }

    protected function hasVelocityAnomaly(User $user, string $ipAddress): bool
    {
        $recentLogins = DB::table('security_events')
            ->where('user_id', $user->id)
            ->where('event_type', 'login_successful')
            ->where('created_at', '>', now()->subMinutes(30))
            ->count();

        return $recentLogins > 5;
    }

    protected function getGeoLocation(string $ipAddress): array
    {
        return Cache::remember("geo:{$ipAddress}", 86400, function () use ($ipAddress) {
            $response = \Illuminate\Support\Facades\Http::get("http://ip-api.com/json/{$ipAddress}");
            return $response->json();
        });
    }

    public function updateUserInfo(User $user, string $deviceFingerprint, string $ipAddress): void
    {
        $devices = Cache::get("user_devices:{$user->id}", []);
        if (!in_array($deviceFingerprint, $devices)) {
            $devices[] = $deviceFingerprint;
            Cache::put("user_devices:{$user->id}", array_slice($devices, -20), now()->addDays(90));
        }

        $location = $this->getGeoLocation($ipAddress);
        Cache::put("user_location:{$user->id}", $location, now()->addDays(90));

        $countries = Cache::get("user_countries:{$user->id}", []);
        if ($location['country'] && !in_array($location['country'], $countries)) {
            $countries[] = $location['country'];
            Cache::put("user_countries:{$user->id}", array_slice($countries, -10), now()->addDays(90));
        }

        $hours = Cache::get("user_usual_hours:{$user->id}", []);
        $hours[] = now()->hour;
        Cache::put("user_usual_hours:{$user->id}", array_unique($hours), now()->addDays(90));
    }
}
```

### Security Event Dispatcher

```php
// app/Services/Security/SecurityEventDispatcher.php

namespace App\Services\Security;

use App\Events\Security\{LoginSuccessful, LoginFailed, BruteForceDetected, CredentialStuffingDetected, SessionHijackingAttempt, SuspiciousActivity};
use App\Models\User;
use App\Services\Audit\AuditLogger;
use Illuminate\Support\Facades\Log;

class SecurityEventDispatcher
{
    public function __construct(
        protected RiskScoringEngine $riskEngine
    ) {}

    public function dispatchLoginSuccessful(User $user, array $context): void
    {
        $riskScore = $this->riskEngine->calculateLoginRisk($user, $context);

        $event = new LoginSuccessful(
            user: $user,
            ipAddress: $context['ip_address'],
            userAgent: $context['user_agent'],
            deviceFingerprint: $context['device_fingerprint'] ?? '',
            sessionId: $context['session_id'] ?? '',
            loginMethod: $context['login_method'] ?? 'password',
            twoFactorUsed: $context['two_factor_used'] ?? false,
            twoFactorMethod: $context['two_factor_method'] ?? null,
            isNewDevice: $this->riskEngine->isNewDevice($user, $context['device_fingerprint'] ?? ''),
            isNewLocation: $this->riskEngine->isNewLocation($user, $context['ip_address']),
            riskScore: $riskScore,
        );

        event($event);
        AuditLogger::logLogin($user, true);

        if ($riskScore > 70) {
            $this->handleHighRiskLogin($user, $riskScore, $context);
        }

        $this->riskEngine->updateUserInfo($user, $context['device_fingerprint'] ?? '', $context['ip_address']);
    }

    public function dispatchLoginFailed(string $email, array $context): void
    {
        $event = new LoginFailed(
            email: $email,
            ipAddress: $context['ip_address'],
            userAgent: $context['user_agent'],
            reason: $context['reason'] ?? 'invalid_credentials',
        );

        event($event);

        $this->checkForBruteForce($context['ip_address']);
        $this->checkForCredentialStuffing($context['ip_address']);
    }

    public function dispatchBruteForceDetected(string $ipAddress, array $context): void
    {
        $event = new BruteForceDetected(
            ipAddress: $ipAddress,
            failedAttempts: $context['failed_attempts'],
            uniqueEmails: $context['unique_emails'] ?? 0,
            timeWindowMinutes: $context['time_window_minutes'] ?? 5,
            blockedUntil: now()->addHours(1),
        );

        event($event);
        AuditLogger::logSecurityEvent('brute_force_detected', null, $context);
    }

    public function dispatchCredentialStuffingDetected(string $ipAddress, array $context): void
    {
        $event = new CredentialStuffingDetected(
            ipAddress: $ipAddress,
            uniqueEmails: $context['unique_emails'],
            timeWindowMinutes: $context['time_window_minutes'] ?? 10,
            sampleEmails: $context['sample_emails'] ?? [],
        );

        event($event);
        AuditLogger::logSecurityEvent('credential_stuffing_detected', null, $context);
    }

    public function dispatchSessionHijackingAttempt(User $user, array $context): void
    {
        $event = new SessionHijackingAttempt(
            user: $user,
            ipAddress: $context['ip_address'],
            userAgent: $context['user_agent'],
            expectedBinding: $context['expected_binding'],
            actualBinding: $context['actual_binding'],
        );

        event($event);
        AuditLogger::logSecurityEvent('session_hijacking_attempt', $user, $context);
    }

    protected function checkForBruteForce(string $ipAddress): void
    {
        $recentFailures = DB::table('security_events')
            ->where('ip_address', $ipAddress)
            ->where('event_type', 'login_failed')
            ->where('created_at', '>', now()->subMinutes(5))
            ->count();

        if ($recentFailures >= 10) {
            $this->dispatchBruteForceDetected($ipAddress, [
                'failed_attempts' => $recentFailures,
                'time_window_minutes' => 5,
            ]);
        }
    }

    protected function checkForCredentialStuffing(string $ipAddress): void
    {
        $recentAttempts = DB::table('security_events')
            ->where('ip_address', $ipAddress)
            ->where('event_type', 'login_failed')
            ->where('created_at', '>', now()->subMinutes(10))
            ->count();

        $uniqueEmails = DB::table('security_events')
            ->where('ip_address', $ipAddress)
            ->where('event_type', 'login_failed')
            ->where('created_at', '>', now()->subMinutes(10))
            ->distinct('email')
            ->count('email');

        if ($uniqueEmails >= 20 && $recentAttempts >= 50) {
            $this->dispatchCredentialStuffingDetected($ipAddress, [
                'unique_emails' => $uniqueEmails,
                'time_window_minutes' => 10,
            ]);
        }
    }

    protected function handleHighRiskLogin(User $user, int $riskScore, array $context): void
    {
        Log::channel('security')->warning('High risk login detected', [
            'user_id' => $user->id,
            'risk_score' => $riskScore,
            'ip_address' => $context['ip_address'],
        ]);

        if ($riskScore > 80) {
            $user->notify(new \App\Notifications\Security\HighRiskLoginNotification(
                $riskScore,
                $context['ip_address'],
                $context['user_agent']
            ));
        }
    }
}
```

```php
        if ($request->has('event_type')) {
            $query->where('event_type', $request->event_type);
        }

        if ($request->has('severity')) {
            $query->where('severity', $request->severity);
        }

        if ($request->has('status')) {
            $query->where('status', $request->status);
        }

        if ($request->has('user_id')) {
            $query->where('user_id', $request->user_id);
        }

        if ($request->has('from_date')) {
            $query->where('created_at', '>=', $request->from_date);
        }

        if ($request->has('to_date')) {
            $query->where('created_at', '<=', $request->to_date);
        }

        if ($request->has('search')) {
            $query->where(function ($q) use ($request) {
                $q->where('description', 'like', "%{$request->search}%")
                  ->orWhere('ip_address', 'like', "%{$request->search}%");
            });
        }

        $events = $query->orderByDesc('created_at')->paginate(50);

        return response()->json($events);
    }

    public function stats(): JsonResponse
    {
        $stats = [
            'total_events_24h' => SecurityEvent::where('created_at', '>', now()->subDay())->count(),
            'critical_events_24h' => SecurityEvent::where('created_at', '>', now()->subDay())->where('severity', 'critical')->count(),
            'high_events_24h' => SecurityEvent::where('created_at', '>', now()->subDay())->where('severity', 'high')->count(),
            'events_by_type' => SecurityEvent::where('created_at', '>', now()->subDay())
                ->select('event_type', \DB::raw('COUNT(*) as count'))
                ->groupBy('event_type')
                ->get()
                ->pluck('count', 'event_type'),
            'events_by_hour' => SecurityEvent::where('created_at', '>', now()->subDay())
                ->select(\DB::raw('HOUR(created_at) as hour'), \DB::raw('COUNT(*) as count'))
                ->groupBy(\DB::raw('HOUR(created_at)'))
                ->get()
                ->pluck('count', 'hour'),
        ];

        return response()->json($stats);
    }

    public function show(SecurityEvent $event): JsonResponse
    {
        return response()->json($event->load('user', 'resolvedBy'));
    }

    public function resolve(Request $request, SecurityEvent $event): JsonResponse
    {
        $request->validate([
            'resolution_notes' => 'required|string',
            'resolution_action' => 'nullable|string',
        ]);

        $event->update([
            'status' => 'resolved',
            'resolved_by' => $request->user()->id,
            'resolved_at' => now(),
            'resolution_notes' => $request->resolution_notes,
            'resolution_action' => $request->resolution_action,
        ]);

        return response()->json($event);
    }

    public function blockIp(Request $request): JsonResponse
    {
        $request->validate([
            'ip_address' => 'required|ip',
            'reason' => 'required|string',
            'duration_hours' => 'required|integer|min:1|max:720',
            'is_permanent' => 'boolean',
        ]);

        \App\Models\BlockedIp::updateOrCreate(
            ['ip_address' => $request->ip_address],
            [
                'reason' => $request->reason,
                'blocked_until' => $request->is_permanent ? now()->addYears(100) : now()->addHours($request->duration_hours),
                'blocked_by' => $request->user()->name,
                'is_permanent' => $request->is_permanent ?? false,
            ]
        );

        return response()->json(['message' => 'IP blocked successfully']);
    }

    public function unblockIp(string $ipAddress): JsonResponse
    {
        \App\Models\BlockedIp::where('ip_address', $ipAddress)->delete();
        return response()->json(['message' => 'IP unblocked successfully']);
    }
```

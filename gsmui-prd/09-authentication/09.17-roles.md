# 09.17 — Roles

## Purpose

Define the role hierarchy for GsmUi, including default roles, role assignment, role-based access, and the admin role management system.

## Role Hierarchy

```text
Super Admin
    ↓ (inherits all)
Admin
    ↓
Editor
    ↓
Support
    ↓
Moderator
    ↓
Creator
    ↓
Pro User
    ↓
User
    ↓
Guest (unauthenticated)
```

## Default Roles

| Role | Description | Hierarchy Level |
|---|---|---|
| Guest | Unauthenticated visitor | 0 |
| User | Registered, email verified | 1 |
| Pro User | Active subscription | 2 |
| Creator | Published marketplace products | 3 |
| Moderator | Content moderation ability | 4 |
| Support | Customer support access | 5 |
| Editor | Content editing access | 6 |
| Admin | Platform administration | 7 |
| Super Admin | Full system access | 8 |

## Role Assignment Rules

| Trigger | Assigned Role |
|---|---|
| Registration | User |
| Email verified | User (confirmed) |
| Subscription activated | Pro User |
| First product published | Creator |
| Admin invitation | Admin |
| Support team invitation | Support |
| Content team invitation | Editor |

## Role Lifecycle Management

### Role Creation Flow

```text
Admin initiates role creation
    ↓
Define role name and description
    ↓
Select guard (web, api, or both)
    ↓
Assign permissions from permission matrix
    ↓
Set hierarchy level
    ↓
Preview role summary
    ↓
Confirm creation
    ↓
Role created and available for assignment
    ↓
Audit log entry recorded
```

### Role Edit Flow

```text
Super Admin selects role to edit
    ↓
Display current role configuration
    ↓
Modify name, description, or permissions
    ↓
Show diff of changes
    ↓
Warning: effects on users with this role
    ↓
Confirm changes
    ↓
Role updated
    ↓
Cache cleared for affected users
    ↓
Audit log entry recorded
```

### Role Deletion Flow

```text
Super Admin selects role to delete
    ↓
Check if role is system role (prevents deletion)
    ↓
Check if role has assigned users
    ↓
If users assigned: show warning and require reassignment
    ↓
If no users: confirm deletion
    ↓
Role deleted
    ↓
Users reassigned to fallback role (if applicable)
    ↓
Cache cleared for all affected users
    ↓
Audit log entry recorded
```

## Role-Based Access Control (RBAC) Implementation

### RBAC Model

The GsmUi RBAC system follows the NIST RBAC standard with four components:

1. **Core RBAC**: Users, roles, permissions, and sessions
2. **Hierarchical RBAC**: Role inheritance and hierarchy levels
3. **Constraint RBAC**: Separation of duty constraints
4. **Reverse RBAC**: Administration of RBAC itself

### RBAC Database Tables

```sql
-- Roles table
CREATE TABLE roles (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(125) NOT NULL,
    guard_name VARCHAR(125) NOT NULL DEFAULT 'web',
    display_name VARCHAR(255) NULL,
    description TEXT NULL,
    hierarchy_level INT UNSIGNED NOT NULL DEFAULT 0,
    is_system_role BOOLEAN DEFAULT FALSE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    UNIQUE KEY unique_role_guard (name, guard_name)
);

-- Permissions table
CREATE TABLE permissions (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(125) NOT NULL,
    guard_name VARCHAR(125) NOT NULL DEFAULT 'web',
    display_name VARCHAR(255) NULL,
    description TEXT NULL,
    group_name VARCHAR(125) NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    UNIQUE KEY unique_permission_guard (name, guard_name)
);

-- Model Has Roles pivot table
CREATE TABLE model_has_roles (
    role_id BIGINT UNSIGNED NOT NULL,
    model_type VARCHAR(255) NOT NULL,
    model_id BIGINT UNSIGNED NOT NULL,
    PRIMARY KEY (role_id, model_id, model_type),
    FOREIGN KEY (role_id) REFERENCES roles(id) ON DELETE CASCADE,
    INDEX index_model (model_type, model_id)
);

-- Model Has Permissions pivot table
CREATE TABLE model_has_permissions (
    permission_id BIGINT UNSIGNED NOT NULL,
    model_type VARCHAR(255) NOT NULL,
    model_id BIGINT UNSIGNED NOT NULL,
    PRIMARY KEY (permission_id, model_id, model_type),
    FOREIGN KEY (permission_id) REFERENCES permissions(id) ON DELETE CASCADE,
    INDEX index_model (model_type, model_id)
);

-- Role Has Permissions pivot table
CREATE TABLE role_has_permissions (
    permission_id BIGINT UNSIGNED NOT NULL,
    role_id BIGINT UNSIGNED NOT NULL,
    PRIMARY KEY (permission_id, role_id),
    FOREIGN KEY (permission_id) REFERENCES permissions(id) ON DELETE CASCADE,
    FOREIGN KEY (role_id) REFERENCES roles(id) ON DELETE CASCADE
);
```

### RBAC Service Layer

```php
// app/Services/RbacService.php

namespace App\Services;

use App\Models\User;
use App\Models\Role;
use App\Models\Permission;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\DB;

class RbacService
{
    public function getAllRolesWithPermissions(): Collection
    {
        return Cache::remember('rbac:all-roles-permissions', 3600, function () {
            return Role::with('permissions')->get();
        });
    }

    public function getRoleHierarchy(): array
    {
        return Cache::remember('rbac:role-hierarchy', 3600, function () {
            $roles = Role::orderBy('hierarchy_level', 'desc')->get();

            $tree = [];
            foreach ($roles as $role) {
                $tree[] = [
                    'id' => $role->id,
                    'name' => $role->name,
                    'display_name' => $role->display_name,
                    'hierarchy_level' => $role->hierarchy_level,
                    'permission_count' => $role->permissions->count(),
                    'user_count' => $role->users->count(),
                ];
            }

            return $tree;
        });
    }

    public function canAssignRole(User $assigner, Role $role): bool
    {
        if ($assigner->hasRole('super_admin')) {
            return true;
        }

        if ($assigner->hasRole('admin')) {
            $assignerLevel = $assigner->roles->max('hierarchy_level');
            return $role->hierarchy_level < $assignerLevel;
        }

        return false;
    }

    public function getUsersWithRole(string $roleName, int $perPage = 25): LengthAwarePaginator
    {
        return User::whereHas('roles', function ($query) use ($roleName) {
            $query->where('name', $roleName);
        })->paginate($perPage);
    }

    public function bulkAssignRole(array $userIds, string $roleName, User $assigner): void
    {
        $role = Role::where('name', $roleName)->firstOrFail();

        if (! $this->canAssignRole($assigner, $role)) {
            throw new \UnauthorizedHttpException('Cannot assign this role.');
        }

        DB::beginTransaction();
        try {
            foreach ($userIds as $userId) {
                $user = User::findOrFail($userId);
                $user->syncRoles([$roleName]);

                activity('role-management')
                    ->performedOn($user)
                    ->withProperties([
                        'role' => $roleName,
                        'assigned_by' => $assigner->id,
                    ])
                    ->log('Role assigned via bulk operation');
            }
            DB::commit();
        } catch (\Exception $e) {
            DB::rollBack();
            throw $e;
        }
    }

    public function clearUserCache(User $user): void
    {
        Cache::forget("user-{$user->id}-roles");
        Cache::forget("user-{$user->id}-permissions");
        Cache::forget("user-{$user->id}-has-all-permissions");
    }

    public function clearAllCaches(): void
    {
        Cache::forget('rbac:all-roles-permissions');
        Cache::forget('rbac:role-hierarchy');

        $users = User::pluck('id')->toArray();
        foreach ($users as $userId) {
            Cache::forget("user-{$userId}-roles");
            Cache::forget("user-{$userId}-permissions");
            Cache::forget("user-{$userId}-has-all-permissions");
        }
    }
}
```

### Role Inheritance Implementation

```php
// app/Traits/HasRoles.php

namespace App\Traits;

use App\Models\Role;
use App\Models\Permission;
use Illuminate\Support\Facades\Cache;

trait HasRoles
{
    public function getAllRolesIncludingInherited(): Collection
    {
        $directRoles = $this->roles;
        $inheritedRoles = collect();

        foreach ($directRoles as $role) {
            $inheritedRoles = $inheritedRoles->merge(
                $this->getInheritedRoles($role)
            );
        }

        return $directRoles->merge($inheritedRoles)->unique('id');
    }

    protected function getInheritedRoles(Role $role): Collection
    {
        $inherited = collect();

        $parentRoles = Role::where('hierarchy_level', '>', $role->hierarchy_level)
            ->orderBy('hierarchy_level', 'asc')
            ->get();

        foreach ($parentRoles as $parentRole) {
            if ($parentRole->hierarchy_level > $role->hierarchy_level) {
                $inherited->push($parentRole);
            }
        }

        return $inherited;
    }

    public function hasRoleOrInherits(string $roleName): bool
    {
        if ($this->hasRole($roleName)) {
            return true;
        }

        $userLevel = $this->roles->max('hierarchy_level') ?? 0;
        $requiredRole = Role::where('name', $roleName)->first();

        if ($requiredRole && $userLevel >= $requiredRole->hierarchy_level) {
            return true;
        }

        return false;
    }

    public function getHighestRoleLevel(): int
    {
        return $this->roles->max('hierarchy_level') ?? 0;
    }

    public function hasHigherRoleThan(User $other): bool
    {
        return $this->getHighestRoleLevel() > $other->getHighestRoleLevel();
    }
}
```

### Role List Component

```php
// app/Livewire/Admin/Roles/RoleList.php

namespace App\Livewire\Admin\Roles;

use Livewire\Component;
use App\Models\Role;
use App\Services\RbacService;

class RoleList extends Component
{
    public string $search = '';
    public string $sortBy = 'hierarchy_level';
    public string $sortDirection = 'desc';
    public int $perPage = 15;

    protected RbacService $rbacService;

    public function boot(RbacService $rbacService): void
    {
        $this->rbacService = $rbacService;
    }

    public function getRolesProperty()
    {
        return Role::query()
            ->when($this->search, function ($query) {
                $query->where('name', 'like', "%{$this->search}%")
                    ->orWhere('display_name', 'like', "%{$this->search}%");
            })
            ->withCount('users', 'permissions')
            ->orderBy($this->sortBy, $this->sortDirection)
            ->paginate($this->perPage);
    }

    public function deleteRole(int $roleId): void
    {
        $role = Role::findOrFail($roleId);

        if ($role->is_system_role) {
            session()->flash('error', 'System roles cannot be deleted.');
            return;
        }

        if ($role->users->count() > 0) {
            session()->flash('error', 'Cannot delete role with assigned users. Reassign users first.');
            return;
        }

        $role->delete();
        $this->rbacService->clearAllCaches();

        activity('role-management')
            ->withProperties(['role' => $role->name])
            ->log('Role deleted');

        session()->flash('success', 'Role deleted successfully.');
    }

    public function toggleRoleActive(int $roleId): void
    {
        $role = Role::findOrFail($roleId);
        $role->is_active = ! $role->is_active;
        $role->save();

        $this->rbacService->clearAllCaches();

        session()->flash('success', "Role {$role->name} " . ($role->is_active ? 'activated' : 'deactivated') . '.');
    }

    public function render()
    {
        return view('livewire.admin.roles.role-list', [
            'roles' => $this->roles,
            'hierarchy' => $this->rbacService->getRoleHierarchy(),
        ]);
    }
}
```

### Role Create/Edit Component

```php
// app/Livewire/Admin/Roles/RoleForm.php

namespace App\Livewire\Admin\Roles;

use Livewire\Component;
use App\Models\Role;
use App\Models\Permission;
use App\Services\RbacService;

class RoleForm extends Component
{
    public ?int $roleId = null;
    public string $name = '';
    public string $displayName = '';
    public string $description = '';
    public int $hierarchyLevel = 0;
    public array $selectedPermissions = [];
    public bool $isActive = true;

    protected array $rules = [
        'name' => ['required', 'string', 'max:125', 'regex:/^[a-z_]+$/'],
        'displayName' => ['required', 'string', 'max:255'],
        'description' => ['nullable', 'string', 'max:1000'],
        'hierarchyLevel' => ['required', 'integer', 'min:0', 'max:8'],
        'selectedPermissions' => ['required', 'array', 'min:1'],
    ];

    protected array $messages = [
        'name.regex' => 'Role name must contain only lowercase letters and underscores.',
        'selectedPermissions.min' => 'A role must have at least one permission.',
    ];

    public function mount(?int $roleId = null): void
    {
        if ($roleId) {
            $role = Role::with('permissions')->findOrFail($roleId);
            $this->roleId = $role->id;
            $this->name = $role->name;
            $this->displayName = $role->display_name ?? $role->name;
            $this->description = $role->description ?? '';
            $this->hierarchyLevel = $role->hierarchy_level;
            $this->selectedPermissions = $role->permissions->pluck('id')->toArray();
            $this->isActive = $role->is_active;
        }
    }

    public function getPermissionsByGroupProperty(): Collection
    {
        return Permission::all()
            ->groupBy('group_name')
            ->map(function ($group) {
                return $group->map(fn($p) => [
                    'id' => $p->id,
                    'name' => $p->name,
                    'display_name' => $p->display_name,
                    'selected' => in_array($p->id, $this->selectedPermissions),
                ]);
            });
    }

    public function save(): void
    {
        $this->validate();

        DB::beginTransaction();
        try {
            $role = Role::updateOrCreate(
                ['id' => $this->roleId],
                [
                    'name' => $this->name,
                    'guard_name' => 'web',
                    'display_name' => $this->displayName,
                    'description' => $this->description,
                    'hierarchy_level' => $this->hierarchyLevel,
                    'is_active' => $this->isActive,
                ]
            );

            $role->syncPermissions($this->selectedPermissions);

            DB::commit();

            $rbacService = app(RbacService::class);
            $rbacService->clearAllCaches();

            activity('role-management')
                ->performedOn($role)
                ->withProperties([
                    'permissions' => $this->selectedPermissions,
                    'hierarchy_level' => $this->hierarchyLevel,
                ])
                ->log($this->roleId ? 'Role updated' : 'Role created');

            session()->flash('success', 'Role saved successfully.');
            redirect()->route('admin.roles.index');
        } catch (\Exception $e) {
            DB::rollBack();
            session()->flash('error', 'Failed to save role: ' . $e->getMessage());
        }
    }

    public function render()
    {
        return view('livewire.admin.roles.role-form', [
            'permissionsByGroup' => $this->permissionsByGroup,
        ]);
    }
}
```

### Role Assignment Component

```php
// app/Livewire/Admin/Roles/RoleAssignment.php

namespace App\Livewire\Admin\Roles;

use Livewire\Component;
use App\Models\User;
use App\Models\Role;
use App\Services\RbacService;

class RoleAssignment extends Component
{
    public int $userId;
    public array $selectedRoles = [];
    public string $searchRoles = '';

    protected RbacService $rbacService;

    public function boot(RbacService $rbacService): void
    {
        $this->rbacService = $rbacService;
    }

    public function mount(int $userId): void
    {
        $this->userId = $userId;
        $user = User::with('roles')->findOrFail($userId);
        $this->selectedRoles = $user->roles->pluck('id')->toArray();
    }

    public function getAvailableRolesProperty(): Collection
    {
        return Role::query()
            ->where('is_active', true)
            ->when($this->searchRoles, function ($query) {
                $query->where('name', 'like', "%{$this->searchRoles}%")
                    ->orWhere('display_name', 'like', "%{$this->searchRoles}%");
            })
            ->orderBy('hierarchy_level', 'desc')
            ->get()
            ->filter(function ($role) {
                return $this->rbacService->canAssignRole(auth()->user(), $role);
            });
    }

    public function getUserProperty(): User
    {
        return User::with('roles')->findOrFail($this->userId);
    }

    public function syncRoles(): void
    {
        $user = $this->user;
        $assigner = auth()->user();

        foreach ($this->selectedRoles as $roleId) {
            $role = Role::findOrFail($roleId);
            if (! $this->rbacService->canAssignRole($assigner, $role)) {
                session()->flash('error', "You cannot assign the role: {$role->name}");
                return;
            }
        }

        $user->syncRoles($this->selectedRoles);
        $this->rbacService->clearUserCache($user);

        activity('role-management')
            ->performedOn($user)
            ->withProperties([
                'roles' => $this->selectedRoles,
                'assigned_by' => $assigner->id,
            ])
            ->log('Roles updated for user');

        session()->flash('success', 'User roles updated successfully.');
    }

    public function addRole(int $roleId): void
    {
        if (! in_array($roleId, $this->selectedRoles)) {
            $this->selectedRoles[] = $roleId;
        }
    }

    public function removeRole(int $roleId): void
    {
        $this->selectedRoles = array_filter($this->selectedRoles, fn($id) => $id !== $roleId);
    }

    public function render()
    {
        return view('livewire.admin.roles.role-assignment', [
            'user' => $this->user,
            'availableRoles' => $this->availableRoles,
        ]);
    }
}
```

```php
// app/Http/Controllers/Api/RoleController.php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\Role;
use App\Services\RbacService;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;

class RoleController extends Controller
{
    public function __construct(
        protected RbacService $rbacService
    ) {}

    public function index(): JsonResponse
    {
        $roles = Role::withCount('users', 'permissions')
            ->orderBy('hierarchy_level', 'desc')
            ->get();

        return response()->json(['data' => $roles]);
    }

    public function store(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'name' => ['required', 'string', 'max:125', 'unique:roles,name'],
            'display_name' => ['nullable', 'string', 'max:255'],
            'description' => ['nullable', 'string', 'max:1000'],
            'hierarchy_level' => ['required', 'integer', 'min:0', 'max:8'],
            'permissions' => ['required', 'array', 'min:1'],
            'permissions.*' => ['integer', 'exists:permissions,id'],
        ]);

        $role = Role::create([
            'name' => $validated['name'],
            'guard_name' => 'web',
            'display_name' => $validated['display_name'],
            'description' => $validated['description'],
            'hierarchy_level' => $validated['hierarchy_level'],
        ]);

        $role->syncPermissions($validated['permissions']);
        $this->rbacService->clearAllCaches();

        activity('role-management')
            ->performedOn($role)
            ->log('Role created via API');

        return response()->json([
            'data' => $role->load('permissions'),
            'message' => 'Role created successfully.',
        ], 201);
    }

    public function show(Role $role): JsonResponse
    {
        return response()->json([
            'data' => $role->load('permissions', 'users'),
        ]);
    }

    public function update(Request $request, Role $role): JsonResponse
    {
        if ($role->is_system_role) {
            return response()->json([
                'message' => 'System roles cannot be modified.',
            ], 403);
        }

        $validated = $request->validate([
            'name' => ['sometimes', 'string', 'max:125', 'unique:roles,name,' . $role->id],
            'display_name' => ['nullable', 'string', 'max:255'],
            'description' => ['nullable', 'string', 'max:1000'],
            'hierarchy_level' => ['sometimes', 'integer', 'min:0', 'max:8'],
            'permissions' => ['sometimes', 'array', 'min:1'],
            'permissions.*' => ['integer', 'exists:permissions,id'],
        ]);

        $role->update(collect($validated)->except('permissions')->toArray());

        if (isset($validated['permissions'])) {
            $role->syncPermissions($validated['permissions']);
        }

        $this->rbacService->clearAllCaches();

        activity('role-management')
            ->performedOn($role)
            ->log('Role updated via API');

        return response()->json([
            'data' => $role->load('permissions'),
            'message' => 'Role updated successfully.',
        ]);
    }

    public function destroy(Role $role): JsonResponse
    {
        if ($role->is_system_role) {
            return response()->json([
                'message' => 'System roles cannot be deleted.',
            ], 403);
        }

        if ($role->users()->count() > 0) {
            return response()->json([
                'message' => 'Cannot delete role with assigned users.',
            ], 422);
        }

        $role->delete();
        $this->rbacService->clearAllCaches();

        activity('role-management')
            ->withProperties(['role' => $role->name])
            ->log('Role deleted via API');

        return response()->json([
            'message' => 'Role deleted successfully.',
        ]);
    }

    public function assign(Request $request, Role $role): JsonResponse
    {
        $validated = $request->validate([
            'user_ids' => ['required', 'array', 'min:1'],
            'user_ids.*' => ['integer', 'exists:users,id'],
        ]);

        foreach ($validated['user_ids'] as $userId) {
            $user = \App\Models\User::findOrFail($userId);
            $user->assignRole($role);
        }

        $this->rbacService->clearAllCaches();

        return response()->json([
            'message' => 'Role assigned to ' . count($validated['user_ids']) . ' users.',
        ]);
    }

    public function unassign(Request $request, Role $role): JsonResponse
    {
        $validated = $request->validate([
            'user_ids' => ['required', 'array', 'min:1'],
            'user_ids.*' => ['integer', 'exists:users,id'],
        ]);

        foreach ($validated['user_ids'] as $userId) {
            $user = \App\Models\User::findOrFail($userId);
            $user->removeRole($role);
        }

        $this->rbacService->clearAllCaches();

        return response()->json([
            'message' => 'Role removed from ' . count($validated['user_ids']) . ' users.',
        ]);
    }

    public function users(Role $role): JsonResponse
    {
        $users = $role->users()
            ->select('id', 'name', 'email', 'created_at')
            ->paginate(25);

        return response()->json($users);
    }
}
```

```php
    }

        }
```

```php
        return $user->hasRole('super_admin');

            return true;

        return false;
```

| Get roles | `$user->getRoleNames()` | Get collection of role names |

### Troubleshooting Roles

| Issue | Solution |
|---|---|
| Role not found | Check `guard_name` matches the current guard |
| Permission denied | Verify role has required permission assigned |
| Cache stale | Run `RbacService::clearAllCaches()` |
| Role not assignable | Check hierarchy level of assigner vs target |
| System role error | System roles cannot be deleted or renamed |
| Inactive role | Check `is_active` flag on the role |

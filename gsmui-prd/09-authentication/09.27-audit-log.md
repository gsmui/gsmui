# 09.27 — Audit Log

## Purpose

Define the audit logging system for GsmUi, tracking all security-relevant and administrative actions for compliance, debugging, and security monitoring.

## Audit Log Architecture

| Component | Technology |
|---|---|
| Package | Spatie Activity Log |
| Storage | Database (activity_log table) |
| Rotation | Monthly archive |
| Retention | 1 year |

## Database Schema

```sql
CREATE TABLE activity_log (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    log_name VARCHAR(255) NULL,
    description TEXT NOT NULL,
    subject_type VARCHAR(255) NULL,
    subject_id BIGINT UNSIGNED NULL,
    event VARCHAR(255) NULL,
    causer_type VARCHAR(255) NULL,
    causer_id BIGINT UNSIGNED NULL,
    properties JSON NULL,
    batch_uuid VARCHAR(36) NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    INDEX (subject_type, subject_id),
    INDEX (causer_type, causer_id),
    INDEX (created_at)
);
```

## Activity Logging Usage

```php
// Log activity
activity('auth')
    ->performedOn($user)
    ->withProperties([
        'ip' => request()->ip(),
        'user_agent' => request()->userAgent(),
    ])
    ->log('User logged in');

// Log with event
activity('auth')
    ->event('user.login')
    ->performedOn($user)
    ->log('User logged in');

// Query activity
$activities = Activity::where('causer_id', $user->id)
    ->where('created_at', '>=', now()->subDays(30))
    ->orderBy('created_at', 'desc')
    ->get();
```

## Cleanup Job

```php
// app/Jobs/CleanupActivityLog.php

public function handle(): void
{
    Activity::where('created_at', '<', now()->subYear())->delete();
}
```

## Security Notes

* Audit logs are append-only
* Logs cannot be modified or deleted by users
* Admin access to audit logs requires super_admin role
* Logs are encrypted at rest (database encryption)
* Sensitive data (passwords, tokens) never logged
* Logs shipped to external monitoring (future)

### Extended Database Schema

```sql
-- Core activity log (Spatie)
CREATE TABLE activity_log (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    log_name VARCHAR(255) NULL,
    description TEXT NOT NULL,
    subject_type VARCHAR(255) NULL,
    subject_id BIGINT UNSIGNED NULL,
    event VARCHAR(255) NULL,
    causer_type VARCHAR(255) NULL,
    causer_id BIGINT UNSIGNED NULL,
    properties JSON NULL,
    batch_uuid VARCHAR(36) NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    INDEX idx_subject (subject_type, subject_id),
    INDEX idx_causer (causer_type, causer_id),
    INDEX idx_event (event),
    INDEX idx_created (created_at),
    INDEX idx_log_name (log_name)
);

-- Extended audit details
CREATE TABLE audit_log_details (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    activity_log_id BIGINT UNSIGNED NOT NULL,
    field_name VARCHAR(255) NOT NULL,
    old_value TEXT NULL,
    new_value TEXT NULL,
    created_at TIMESTAMP NULL,
    FOREIGN KEY (activity_log_id) REFERENCES activity_log(id) ON DELETE CASCADE,
    INDEX idx_activity_field (activity_log_id, field_name)
);

-- Audit log metadata
CREATE TABLE audit_log_metadata (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    activity_log_id BIGINT UNSIGNED NOT NULL,
    key_name VARCHAR(255) NOT NULL,
    value TEXT NULL,
    created_at TIMESTAMP NULL,
    FOREIGN KEY (activity_log_id) REFERENCES activity_log(id) ON DELETE CASCADE,
    INDEX idx_activity_key (activity_log_id, key_name)
);

-- Audit log exports
CREATE TABLE audit_log_exports (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT UNSIGNED NOT NULL,
    filename VARCHAR(255) NOT NULL,
    format ENUM('csv', 'json', 'pdf') NOT NULL,
    filters JSON NULL,
    status ENUM('pending', 'processing', 'completed', 'failed') DEFAULT 'pending',
    file_path VARCHAR(500) NULL,
    file_size BIGINT UNSIGNED NULL,
    expires_at TIMESTAMP NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

-- Audit log retention policies
CREATE TABLE audit_retention_policies (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    log_name VARCHAR(255) NOT NULL,
    retention_days INT NOT NULL,
    archive_enabled BOOLEAN DEFAULT FALSE,
    archive_storage VARCHAR(255) NULL,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL
);
```

### Database Relationships

| Parent Table | Child Table | Relationship | FK |
|---|---|---|---|
| activity_log | audit_log_details | HasMany | activity_log_id |
| activity_log | audit_log_metadata | HasMany | activity_log_id |
| users | activity_log | HasMany (causer) | causer_id |
| users | audit_log_exports | HasMany | user_id |
| audit_retention_policies | activity_log | BelongsTo (via log_name) | log_name |

## Activity Logging Usage — Expanded

### Basic Usage Patterns

```php
// Simple activity logging
activity('auth')
    ->performedOn($user)
    ->withProperties([
        'ip' => request()->ip(),
        'user_agent' => request()->userAgent(),
    ])
    ->log('User logged in');

// Log with event name
activity('auth')
    ->event('user.login')
    ->performedOn($user)
    ->withProperties([
        'ip' => request()->ip(),
        'user_agent' => request()->userAgent(),
        'method' => 'password',
    ])
    ->log('User logged in successfully');

// Log with causer (who performed the action)
activity('admin')
    ->performedOn($targetUser)
    ->causedBy($adminUser)
    ->event('admin.user_suspended')
    ->withProperties([
        'reason' => 'Terms of service violation',
        'duration' => '30 days',
    ])
    ->log('User suspended by admin');

// Log model changes
activity('auth')
    ->performedOn($user)
    ->event('user.email_changed')
    ->withProperties([
        'old' => ['email' => $oldEmail],
        'new' => ['email' => $newEmail],
    ])
    ->log('Email address changed');

// Log with batch (group related activities)
$batchUuid = Str::uuid();
activity('auth')
    ->batch($batchUuid)
    ->performedOn($user)
    ->event('user.password_changed')
    ->log('Password changed');

activity('auth')
    ->batch($batchUuid)
    ->performedOn($user)
    ->event('user.session_revoked')
    ->log('All other sessions revoked');
```

### Advanced Usage Patterns

```php
// Log with custom properties
activity('marketplace')
    ->performedOn($product)
    ->causedBy($seller)
    ->event('marketplace.product_published')
    ->withProperties([
        'product_name' => $product->name,
        'product_price' => $product->price,
        'category' => $product->category->name,
        'tags' => $product->tags->pluck('name'),
        'ip' => request()->ip(),
    ])
    ->log('Product published');

// Log with relationship context
activity('billing')
    ->performedOn($subscription)
    ->causedBy($user)
    ->event('billing.subscription_created')
    ->withProperties([
        'plan' => $subscription->plan->name,
        'amount' => $subscription->amount,
        'currency' => $subscription->currency,
        'payment_method' => $user->defaultPaymentMethod()->type,
    ])
    ->log('Subscription created');

// Log with performance metrics
$startTime = microtime(true);

// ... perform operation ...

$duration = (microtime(true) - $startTime) * 1000;

activity('system')
    ->event('system.operation_completed')
    ->withProperties([
        'operation' => 'bulk_import',
        'duration_ms' => round($duration, 2),
        'records_processed' => $count,
        'memory_usage_mb' => round(memory_get_usage(true) / 1024 / 1024, 2),
    ])
    ->log('Bulk import completed');
```

### Querying Activity Log

```php
// Get all activity for a user
$activities = Activity::where('causer_id', $user->id)
    ->orderByDesc('created_at')
    ->get();

// Get activity for a specific model
$activities = Activity::where('subject_type', User::class)
    ->where('subject_id', $user->id)
    ->orderByDesc('created_at')
    ->get();

// Get activity by event type
$activities = Activity::where('event', 'user.login')
    ->where('created_at', '>=', now()->subDays(30))
    ->orderByDesc('created_at')
    ->get();

// Get activity by log name
$activities = Activity::where('log_name', 'auth')
    ->where('created_at', '>=', now()->subDays(7))
    ->orderByDesc('created_at')
    ->get();

// Get activity with specific properties
$activities = Activity::where('properties->ip', '192.168.1.1')
    ->orderByDesc('created_at')
    ->get();

// Get activity count by event
$counts = Activity::where('created_at', '>=', now()->subDays(30))
    ->selectRaw('event, COUNT(*) as count')
    ->groupBy('event')
    ->orderByDesc('count')
    ->get();

// Get activity timeline for a user
$timeline = Activity::where('causer_id', $user->id)
    ->orWhere('subject_id', $user->id)
    ->orderByDesc('created_at')
    ->limit(100)
    ->get()
    ->groupBy(fn ($activity) => $activity->created_at->format('Y-m-d'));

// Get recent security events
$securityEvents = Activity::where('log_name', 'security')
    ->where('created_at', '>=', now()->subHours(24))
    ->orderByDesc('created_at')
    ->get();
```

```php
// app/Services/AuditLogService.php

class AuditLogService
{
    private const SENSITIVE_FIELDS = [
        'password', 'password_confirmation', 'current_password',
        'two_factor_secret', 'recovery_codes', 'token', 'secret',
        'api_key', 'private_key', 'credit_card', 'cvv',
    ];

    public function log(
        string $logName,
        string $event,
        ?Model $subject,
        ?Model $causer,
        string $description,
        array $properties = [],
        ?string $batchUuid = null,
    ): Activity {
        // Sanitize sensitive data
        $properties = $this->sanitizeProperties($properties);

        $activity = activity($logName)
            ->event($event)
            ->performedOn($subject)
            ->causedBy($causer)
            ->withProperties(array_merge($properties, [
                'ip' => request()->ip(),
                'user_agent' => request()->userAgent(),
                'timestamp' => now()->toIso8601String(),
            ]));

        if ($batchUuid) {
            $activity->batch($batchUuid);
        }

        return $activity->log($description);
    }

    public function logModelChanges(
        string $logName,
        string $event,
        Model $model,
        ?Model $causer,
        array $oldAttributes,
        array $newAttributes,
    ): Activity {
        $changes = [];
        $allKeys = array_unique(array_merge(array_keys($oldAttributes), array_keys($newAttributes)));

        foreach ($allKeys as $key) {
            if ($this->isSensitiveField($key)) continue;

            $old = $oldAttributes[$key] ?? null;
            $new = $newAttributes[$key] ?? null;

            if ($old !== $new) {
                $changes[$key] = ['old' => $old, 'new' => $new];
            }
        }

        if (empty($changes)) {
            return activity($logName)->event($event)->performedOn($model)->causedBy($causer)->log("No changes detected");
        }

        return $this->log(
            logName: $logName,
            event: $event,
            subject: $model,
            causer: $causer,
            description: static::class . ' updated',
            properties: ['changes' => $changes],
        );
    }

    public function getTimeline(Model $subject, int $limit = 50): Collection
    {
        return Activity::where('subject_type', get_class($subject))
            ->where('subject_id', $subject->getKey())
            ->with('causer')
            ->orderByDesc('created_at')
            ->limit($limit)
            ->get();
    }

    public function getUserActivity(User $user, int $days = 30): array
    {
        $startDate = now()->subDays($days);

        $activities = Activity::where('causer_id', $user->id)
            ->where('created_at', '>=', $startDate)
            ->get();

        $byEvent = $activities->groupBy('event')
            ->map(fn ($events) => $events->count())
            ->toArray();

        $byDay = $activities->groupBy(fn ($a) => $a->created_at->format('Y-m-d'))
            ->map(fn ($events) => $events->count())
            ->toArray();

        $byLog = $activities->groupBy('log_name')
            ->map(fn ($events) => $events->count())
            ->toArray();

        return [
            'total' => $activities->count(),
            'by_event' => $byEvent,
            'by_day' => $byDay,
            'by_log' => $byLog,
            'recent' => $activities->take(10)->toArray(),
        ];
    }

    public function search(string $query, int $limit = 100): Collection
    {
        return Activity::where(function ($q) use ($query) {
            $q->where('description', 'LIKE', "%{$query}%")
                ->orWhere('event', 'LIKE', "%{$query}%")
                ->orWhere('properties', 'LIKE', "%{$query}%");
        })
        ->with('causer', 'subject')
        ->orderByDesc('created_at')
        ->limit($limit)
        ->get();
    }

    public function export(
        ?string $event = null,
        ?string $logName = null,
        ?Carbon $from = null,
        ?Carbon $to = null,
        int $limit = 10000,
    ): Collection {
        $query = Activity::with('causer', 'subject');

        if ($event) {
            $query->where('event', $event);
        }

        if ($logName) {
            $query->where('log_name', $logName);
        }

        if ($from) {
            $query->where('created_at', '>=', $from);
        }

        if ($to) {
            $query->where('created_at', '<=', $to);
        }

        return $query->orderByDesc('created_at')->limit($limit)->get();
    }

    private function sanitizeProperties(array $properties): array
    {
        foreach (self::SENSITIVE_FIELDS as $field) {
            if (isset($properties[$field])) {
                $properties[$field] = '[REDACTED]';
            }
        }

        if (isset($properties['changes'])) {
            foreach ($properties['changes'] as $key => $change) {
                if ($this->isSensitiveField($key)) {
                    unset($properties['changes'][$key]);
                }
            }
        }

        return $properties;
    }

    private function isSensitiveField(string $field): bool
    {
        return in_array($field, self::SENSITIVE_FIELDS);
    }
}
```

```php
// app/Jobs/CleanupAuditLog.php

class CleanupAuditLog implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public int $timeout = 600;
    public int $tries = 3;

    public function handle(): void
    {
        $policies = config('audit-log.retention');
        $batchSize = config('audit-log.cleanup.batch_size', 1000);

        foreach ($policies as $logName => $config) {
            $cutoffDate = now()->subDays($config['days']);

            if ($config['archive'] ?? false) {
                $this->archiveOldLogs($logName, $cutoffDate);
            }

            $deleted = Activity::where('log_name', $logName)
                ->where('created_at', '<', $cutoffDate)
                ->orderBy('id')
                ->limit($batchSize)
                ->delete();

            while ($deleted > 0) {
                $deleted = Activity::where('log_name', $logName)
                    ->where('created_at', '<', $cutoffDate)
                    ->orderBy('id')
                    ->limit($batchSize)
                    ->delete();
            }

            Log::info("Cleaned up {$logName} audit logs older than {$config['days']} days");
        }
    }

    private function archiveOldLogs(string $logName, Carbon $cutoffDate): void
    {
        $logs = Activity::where('log_name', $logName)
            ->where('created_at', '<', $cutoffDate)
            ->orderBy('id')
            ->limit(10000)
            ->get();

        if ($logs->isEmpty()) {
            return;
        }

        $filename = "audit-log-{$logName}-" . $cutoffDate->format('Y-m') . ".json.gz";
        $directory = config('audit-log.archive.directory', 'audit-log-archive');
        $disk = config('audit-log.archive.disk', 's3');

        $content = gzencode($logs->toJson());
        Storage::disk($disk)->put("{$directory}/{$filename}", $content);

        Log::info("Archived {$logs->count()} {$logName} logs to {$filename}");
    }
}
```

```php
// app/Services/AuditLogIntegrityService.php

class AuditLogIntegrityService
{
    public function verifyIntegrity(?Carbon $from = null, ?Carbon $to = null): array
    {
        $query = Activity::query();

        if ($from) {
            $query->where('created_at', '>=', $from);
        }

        if ($to) {
            $query->where('created_at', '<=', $to);
        }

        $logs = $query->orderBy('id')->get();
        $issues = [];
        $previousHash = null;

        foreach ($logs as $log) {
            $expectedHash = $this->calculateHash($log, $previousHash);

            if ($log->properties['integrity_hash'] ?? null !== $expectedHash) {
                $issues[] = [
                    'id' => $log->id,
                    'expected' => $expectedHash,
                    'actual' => $log->properties['integrity_hash'] ?? null,
                    'description' => $log->description,
                ];
            }

            $previousHash = $expectedHash;
        }

        return [
            'total' => $logs->count(),
            'issues' => $issues,
            'is_valid' => empty($issues),
        ];
    }

    public function calculateHash(Activity $log, ?string $previousHash): string
    {
        $data = json_encode([
            'id' => $log->id,
            'log_name' => $log->log_name,
            'event' => $log->event,
            'description' => $log->description,
            'subject_type' => $log->subject_type,
            'subject_id' => $log->subject_id,
            'causer_type' => $log->causer_type,
            'causer_id' => $log->causer_id,
            'properties' => $log->properties,
            'created_at' => $log->created_at->toIso8601String(),
            'previous_hash' => $previousHash,
        ]);

        return hash('sha256', $data);
    }

    public function generateIntegrityReport(): array
    {
        $today = now();
        $issues = [];

        // Check last 30 days
        for ($i = 0; $i < 30; $i++) {
            $date = $today->copy()->subDays($i);
            $result = $this->verifyIntegrity(
                $date->copy()->startOfDay(),
                $date->copy()->endOfDay()
            );

            if (! $result['is_valid']) {
                $issues[] = [
                    'date' => $date->format('Y-m-d'),
                    'total' => $result['total'],
                    'issues' => count($result['issues']),
                ];
            }
        }

        return [
            'period' => 'Last 30 days',
            'total_days_checked' => 30,
            'days_with_issues' => count($issues),
            'issues' => $issues,
        ];
    }
}
```

```php
// app/Services/AuditReportService.php

class AuditReportService
{
    public function generateSecuritySummary(int $days = 7): array
    {
        $startDate = now()->subDays($days);

        $loginStats = Activity::where('log_name', 'auth')
            ->where('event', 'user.login')
            ->where('created_at', '>=', $startDate)
            ->selectRaw('COUNT(*) as total, DATE(created_at) as date')
            ->groupBy('date')
            ->get();

        $failedLogins = Activity::where('log_name', 'auth')
            ->where('event', 'user.login_failed')
            ->where('created_at', '>=', $startDate)
            ->selectRaw('COUNT(*) as total, DATE(created_at) as date')
            ->groupBy('date')
            ->get();

        $securityEvents = Activity::where('log_name', 'security')
            ->where('created_at', '>=', $startDate)
            ->selectRaw('event, COUNT(*) as count')
            ->groupBy('event')
            ->orderByDesc('count')
            ->get();

        $adminActions = Activity::where('log_name', 'admin')
            ->where('created_at', '>=', $startDate)
            ->selectRaw('event, COUNT(*) as count')
            ->groupBy('event')
            ->orderByDesc('count')
            ->get();

        return [
            'period' => [
                'from' => $startDate->format('Y-m-d'),
                'to' => now()->format('Y-m-d'),
            ],
            'login_stats' => $loginStats,
            'failed_logins' => $failedLogins,
            'security_events' => $securityEvents,
            'admin_actions' => $adminActions,
        ];
    }

    public function generateUserReport(User $user, int $days = 30): array
    {
        $startDate = now()->subDays($days);

        $activities = Activity::where('causer_id', $user->id)
            ->where('created_at', '>=', $startDate)
            ->get();

        return [
            'user' => [
                'id' => $user->id,
                'email' => $user->email,
            ],
            'period' => [
                'from' => $startDate->format('Y-m-d'),
                'to' => now()->format('Y-m-d'),
            ],
            'total_activities' => $activities->count(),
            'by_event' => $activities->groupBy('event')
                ->map(fn ($e) => $e->count())
                ->toArray(),
            'by_day' => $activities->groupBy(fn ($a) => $a->created_at->format('Y-m-d'))
                ->map(fn ($e) => $e->count())
                ->toArray(),
            'recent_activities' => $activities->take(20)->toArray(),
        ];
    }

    public function generateComplianceReport(string $type, Carbon $from, Carbon $to): array
    {
        return match ($type) {
            'soc2' => $this->generateSoc2Report($from, $to),
            'gdpr' => $this->generateGdprReport($from, $to),
            default => throw new \InvalidArgumentException("Unknown report type: {$type}"),
        };
    }

    private function generateSoc2Report(Carbon $from, Carbon $to): array
    {
        $activities = Activity::whereBetween('created_at', [$from, $to])->get();

        return [
            'report_type' => 'SOC 2',
            'period' => ['from' => $from->format('Y-m-d'), 'to' => $to->format('Y-m-d')],
            'total_events' => $activities->count(),
            'authentication_events' => $activities->where('log_name', 'auth')->count(),
            'authorization_events' => $activities->where('log_name', 'admin')->count(),
            'security_events' => $activities->where('log_name', 'security')->count(),
            'data_access_events' => $activities->where('log_name', 'api')->count(),
            'unique_users' => $activities->pluck('causer_id')->unique()->count(),
            'unique_ips' => $activities->pluck('properties.ip')->unique()->count(),
        ];
    }

    private function generateGdprReport(Carbon $from, Carbon $to): array
    {
        return [
            'report_type' => 'GDPR',
            'period' => ['from' => $from->format('Y-m-d'), 'to' => $to->format('Y-m-d')],
            'data_access_requests' => Activity::where('event', 'user.data_export')->whereBetween('created_at', [$from, $to])->count(),
            'data_deletion_requests' => Activity::where('event', 'user.account_deleted')->whereBetween('created_at', [$from, $to])->count(),
            'consent_changes' => Activity::where('event', 'user.consent_changed')->whereBetween('created_at', [$from, $to])->count(),
        ];
    }
}
```

## Audit Log Best Practices

### Event Naming Conventions

| Pattern | Example | Description |
|---|---|---|
| `{entity}.{action}` | `user.login` | User performed an action |
| `{entity}.{action}.{result}` | `user.login.failed` | Action with result |
| `{entity}.{sub_entity}.{action}` | `user.token.created` | Sub-entity action |
| `{system}.{action}` | `system.cache.cleared` | System action |
| `{security}.{type}` | `security.brute_force_detected` | Security event |

### Log Entry Structure

### Performance Considerations

1. **Async Logging** - Use queues for non-critical logs
2. **Batch Inserts** - Group multiple log entries
3. **Indexing** - Index `created_at`, `log_name`, `event`, `subject_type`
4. **Partitioning** - Partition large tables by date
5. **Archival** - Move old logs to cold storage
6. **Compression** - Compress archived logs

### Security Considerations

1. **Immutable Logs** - Never modify or delete audit logs
2. **Hash Chains** - Verify log integrity with hash chains
3. **Encrypted Storage** - Encrypt sensitive log fields
4. **Access Control** - Restrict log access to authorized personnel
5. **Retention Compliance** - Follow regulatory retention requirements
6. **Tamper Detection** - Alert on unauthorized log modifications

### Monitoring and Alerting

```php
// app/Console/Commands/MonitorAuditLogCommand.php

namespace App\Console\Commands;

use App\Services\Audit\AuditLogService;
use Illuminate\Console\Command;

class MonitorAuditLogCommand extends Command
{
    protected $signature = 'audit:monitor';
    protected $description = 'Monitor audit log for suspicious activity';

    public function handle(AuditLogService $service): int
    {
        $this->info('Checking audit log for anomalies...');

        $anomalies = $service->detectAnomalies(now()->subHour(), now());

        if (!empty($anomalies)) {
            foreach ($anomalies as $anomaly) {
                $this->warn("ANOMALY: {$anomaly['type']} - {$anomaly['description']}");
                $this->warn("  Count: {$anomaly['count']}");
                $this->warn("  Severity: {$anomaly['severity']}");
                $this->newLine();
            }

            return Command::FAILURE;
        }

        $this->info('No anomalies detected.');
        return Command::SUCCESS;
    }
}
```

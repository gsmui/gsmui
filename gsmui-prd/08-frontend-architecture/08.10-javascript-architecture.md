# Purpose

This document defines the GsmUi frontend JavaScript: the `dist/` bundle layout, the upstream build model (no in-repo config), the shared mixin system, the `setAttribute`/`removeAttribute` utilities, the MutationObserver contract, and the input/change event-firing rules. It is the contract for any developer extending or debugging component behavior.

## 1. Bundle Layout (`dist/`)

`dist/` is produced **upstream** — there is no Vite/Rollup/package.json build config in this repo (AGENTS.md). Never commit `dist/` changes unless explicitly asked.

```text
dist/
  gsmui.js            # primary bundle (self-hosted)
  gsmui.module.js     # ESM variant
  gsmui.min.js        # minified
  editor.js           # Monaco-based playground editor
  editor.css          # editor styles
  manifest.json       # asset map
```

| File | Role |
| --- | --- |
| `gsmui.js` | Component behaviors, mixins, utils (`script-src 'self'`) |
| `editor.js` / `editor.css` | Playground Monaco integration |
| `manifest.json` | Versioned asset references for the build pipeline |

CSP: zero external resources — no CDN, no `@font-face`, no `eval()` (AGENTS.md §CSP).

## 2. Mixin System

Components compose via JS mixins. Core mixins:

| Mixin | Responsibility |
| --- | --- |
| `Controllable` | External (`wire:model`) ↔ internal state sync |
| `Disableable` | Disabled-state awareness in interaction logic |
| `Submittable` | Form submit coordination |
| `Focusable` | Focus/blur + focus-visible handling |

Rules:

- Use mixins; don't force one that doesn't fit (a bad abstraction is worse than self-contained logic).
- Sub-elements call methods on the **state root** (not siblings).
- Use `detangle()` to prevent sync loops between Controllable and internal subscriptions.

```js
// Conceptual mixin composition
class GsmuiSlider extends Controllable(Disableable(Focusable(HTMLElement))) {}
```

## 3. `setAttribute` / `removeAttribute` Utilities

Native DOM methods are **not** used directly — the util functions from `utils.js` carry MutationObserver implications.

```js
import { setAttribute, removeAttribute } from "./utils.js";

setAttribute(el, "value", "#0ea5e9");     // triggers observed mutation
removeAttribute(el, "disabled");           // observes attribute removal
```

| Rule | Why |
| --- | --- |
| Always via utils | MutationObserver must see the change |
| Never `el.setAttribute` | Bypasses observation → desync |
| `value` watched | MutationObserver also watches `value` (not just config attrs) |

---

## 4. MutationObserver Contract

Each state-root element observes its own attributes, **including `value`**, plus config attributes.

```js
const observer = new MutationObserver((mutations) => {
  for (const m of mutations) {
    if (m.attributeName === "value") syncFromAttribute();
    else syncConfig();
  }
});
observer.observe(root, { attributes: true });
```

| Watched | Action on change |
| --- | --- |
| `value` | Push to internal state + UI |
| `disabled` | Toggle `Disableable` |
| `aria-*` / config | Re-render bindings |

---

## 5. Event-Firing Rules

Keyboard/range changes must match native `<input type="range">` spec: fire **both** `input` and `change`.

```js
el.dispatchEvent(new Event("input", { bubbles: true }));
el.dispatchEvent(new Event("change", { bubbles: true }));
```

| Event | When |
| --- | --- |
| `input` | On every value change (live) |
| `change` | On pointer commit / keyboard commit — NOT on popover close |
| Both | Slider/color-picker keyboard interaction per native spec |

## 6. Dynamic CSS (`adoptedStyleSheets`)

Runtime theme tokens are applied via `adoptedStyleSheets` (see `08.06-css-architecture.md`), never inline `<style>`. The same util boundary applies: theme pushes go through the managed sheet.

## 9. Deep Dive: Mixin System Architecture

### 9.1 Mixin Composition Order

Mixins are composed via class expression syntax. The order matters because each mixin wraps the previous:

```js
// Correct composition — outermost mixin runs last
class GsmuiSlider extends Controllable(Disableable(Focusable(HTMLElement))) {}

// Execution order on connectedCallback:
// 1. Focusable.init() — sets up focus/blur listeners
// 2. Disableable.init() — checks initial disabled state
// 3. Controllable.init() — reads initial value from attribute
// 4. GsmuiSlider.init() — component-specific setup
```

Rule: **Focusable is always innermost** (closest to HTMLElement), **Controllable is always outermost** (closest to the consumer). This ensures focus state is set up before value sync, and disabled state is checked before external binding.

### 9.2 Controllable Mixin — Full Contract

The Controllable mixin manages the bidirectional sync between external state (Livewire `wire:model`) and internal component state:

```js
function Controllable(Base) {
  return class extends Base {
    #externalValue = null;
    #internalValue = null;
    #syncing = false;

    connectedCallback() {
      super.connectedCallback();
      // Read initial value from attribute (set by Livewire)
      this.#externalValue = this.getAttribute('value');
      this.#internalValue = this.#externalValue;
    }

    // Called by Livewire via setAttribute (through utils.js)
    syncFromAttribute() {
      if (this.#syncing) return;
      this.#syncing = true;
      this.#externalValue = this.getAttribute('value');
      this.#internalValue = this.#externalValue;
      this.render(); // update UI
      this.#syncing = false;
    }

    // Called by internal interaction (click, keyboard)
    commitValue(newValue) {
      if (this.#syncing) return;
      this.#syncing = true;
      this.#internalValue = newValue;
      setAttribute(this, 'value', newValue); // triggers MutationObserver → Livewire
      this.render();
      // Fire events for non-Livewire consumers
      this.dispatchEvent(new Event('input', { bubbles: true }));
      this.dispatchEvent(new Event('change', { bubbles: true }));
      this.#syncing = false;
    }
  };
}
```

**The `#syncing` flag prevents infinite loops.** When `setAttribute` triggers the MutationObserver, the observer calls `syncFromAttribute()`, which checks `#syncing` and exits early because `commitValue()` already set it.

### 9.3 Disableable Mixin — Full Contract

```js
function Disableable(Base) {
  return class extends Base {
    #disabled = false;

    connectedCallback() {
      super.connectedCallback();
      this.#disabled = this.hasAttribute('disabled');
      this.#applyDisabledState();
    }

    attributeChangedCallback(name, oldVal, newVal) {
      if (name === 'disabled') {
        this.#disabled = newVal !== null;
        this.#applyDisabledState();
        super.attributeChangedCallback?.(name, oldVal, newVal);
      }
    }

    #applyDisabledState() {
      if (this.#disabled) {
        this.setAttribute('aria-disabled', 'true');
        this.style.pointerEvents = 'none';
        // Remove from tab order for custom elements
        if (!this.matches('button, input, select, textarea, a')) {
          this.setAttribute('tabindex', '-1');
        }
      } else {
        this.removeAttribute('aria-disabled');
        this.style.pointerEvents = '';
        if (!this.matches('button, input, select, textarea, a')) {
          this.setAttribute('tabindex', '0');
        }
      }
    }

    get disabled() { return this.#disabled; }
    set disabled(val) {
      this.#disabled = val;
      if (val) setAttribute(this, 'disabled', '');
      else removeAttribute(this, 'disabled');
    }
  };
}
```

**Key detail:** CSS `:disabled` only works on native form elements. For custom elements (`<gsmui-slider>`, `<gsmui-color-picker>`), we use `[&[disabled]]:shadow-none!` in Tailwind and `aria-disabled` in ARIA. The mixin handles both.

### 9.4 Submittable Mixin — Full Contract

```js
function Submittable(Base) {
  return class extends Base {
    #form = null;

    connectedCallback() {
      super.connectedCallback();
      // Find the enclosing <form>
      this.#form = this.closest('form');
      if (this.#form) {
        this.#form.addEventListener('submit', this.#handleSubmit.bind(this));
      }
    }

    disconnectedCallback() {
      this.#form?.removeEventListener('submit', this.#handleSubmit.bind(this));
      super.disconnectedCallback?.();
    }

    #handleSubmit(e) {
      // Collect all gsmui components within the form
      const components = this.#form.querySelectorAll('[data-gsmui-component]');
      for (const comp of components) {
        if (typeof comp.validate === 'function' && !comp.validate()) {
          e.preventDefault();
          comp.focus(); // Move focus to first invalid component
          break;
        }
      }
    }

    validate() {
      // Override in component for custom validation
      return true;
    }
  };
}
```

### 9.5 Focusable Mixin — Full Contract

```js
function Focusable(Base) {
  return class extends Base {
    #hasFocusVisible = false;

    connectedCallback() {
      super.connectedCallback();
      this.addEventListener('focus', this.#handleFocus.bind(this));
      this.addEventListener('blur', this.#handleBlur.bind(this));
      // :focus-visible detection for custom elements
      this.addEventListener('focusin', this.#handleFocusVisible.bind(this));
      this.addEventListener('focusout', this.#handleFocusOut.bind(this));
    }

    #handleFocus() {
      this.dispatchEvent(new CustomEvent('gsmui:focus', { bubbles: true }));
    }

    #handleBlur() {
      this.dispatchEvent(new CustomEvent('gsmui:blur', { bubbles: true }));
    }

    #handleFocusVisible(e) {
      // If triggered by keyboard, :focus-visible applies
      if (e.target === this) {
        this.#hasFocusVisible = true;
        this.setAttribute('data-focus-visible', '');
      }
    }

    #handleFocusOut() {
      this.#hasFocusVisible = false;
      this.removeAttribute('data-focus-visible');
    }

    // Used by Tailwind: has-focus-visible:outline-2
    get focusVisible() { return this.#hasFocusVisible; }
  };
}
```

## 10. Deep Dive: setAttribute / removeAttribute Utilities

### 10.1 Full Implementation

```js
// utils.js

/**
 * Set an attribute on an element, triggering MutationObserver.
 * NEVER use el.setAttribute() directly — always use this.
 */
export function setAttribute(el, name, value) {
  if (el.getAttribute(name) === String(value)) return; // no-op if same
  el.setAttribute(name, value);
}

/**
 * Remove an attribute from an element, triggering MutationObserver.
 * NEVER use el.removeAttribute() directly — always use this.
 */
export function removeAttribute(el, name) {
  if (!el.hasAttribute(name)) return; // no-op if already absent
  el.removeAttribute(name);
}
```

### 10.2 Why Not Native DOM Methods?

Native `el.setAttribute()` and `el.removeAttribute()` DO trigger MutationObserver callbacks. However, the utility functions add:

1. **No-op optimization** — skip if the value is already correct (prevents unnecessary observer callbacks).
2. **Consistent API** — all attribute mutations flow through one entry point, making debugging easier.
3. **Future extensibility** — if we need to add logging, dev-mode warnings, or analytics, we add it in one place.

### 10.3 The `value` Attribute Special Case

The `value` attribute is watched by MutationObserver in addition to config attributes:

```js
const observer = new MutationObserver((mutations) => {
  for (const m of mutations) {
    if (m.attributeName === 'value') {
      // Value changed externally (e.g., Livewire wire:model update)
      this.syncFromAttribute();
    } else if (m.attributeName === 'disabled') {
      // Disabled state changed
      this.#applyDisabledState();
    } else {
      // Config attribute changed (e.g., size, variant, format)
      this.syncConfig();
    }
  }
});

observer.observe(this, {
  attributes: true,
  attributeFilter: ['value', 'disabled', 'size', 'variant', 'format', 'placeholder']
});
```

The `attributeFilter` limits observer scope to only the attributes GsmUi cares about, preventing performance overhead from irrelevant mutations.

## 11. Deep Dive: Event-Firing Rules

### 11.1 Native Input Spec Compliance

For components that behave like `<input type="range">` (slider, color-picker hue slider):

| User action | Events fired | Timing |
| --- | --- | --- |
| Arrow key press | `input` | Immediately |
| Arrow key release | `change` | Immediately (keyboard commit) |
| Pointer drag | `input` | On each movement |
| Pointer release | `change` | On pointerup (pointer commit) |
| Popover close | Nothing | Close is NOT a commit event |
| Programmatic value set | `input` + `change` | Both, via `commitValue()` |

### 11.2 Event Bubbling and Custom Events

All GsmUi events bubble (`bubbles: true`) so Livewire and parent components can listen:

```js
// Standard events (bubble to Livewire for wire:model)
this.dispatchEvent(new Event('input', { bubbles: true }));
this.dispatchEvent(new Event('change', { bubbles: true }));

// Custom events for component-specific behavior
this.dispatchEvent(new CustomEvent('gsmui:colorchange', {
  detail: { color: this.#internalValue, format: this.#format },
  bubbles: true,
  composed: true // crosses shadow DOM boundary if applicable
}));
```

### 11.3 Event Naming Convention

| Event type | Naming pattern | Example |
| --- | --- | --- |
| Standard form events | `input`, `change` | Used by all form-like components |
| GsmUi-specific events | `gsmui:<eventname>` | `gsmui:open`, `gsmui:close`, `gsmui:select` |
| Lifecycle events | `gsmui:connected`, `gsmui:disconnected` | For parent components to track children |

Never use unprefixed custom events (e.g. `new Event('open')`) — they risk collision with native or third-party events.

## 12. Deep Dive: MutationObserver Patterns

### 12.1 Observer Lifecycle

```js
class GsmuiComponent extends Controllable(Disableable(Focusable(HTMLElement))) {
  #observer = null;

  connectedCallback() {
    super.connectedCallback();
    this.#observer = new MutationObserver(this.#handleMutations.bind(this));
    this.#observer.observe(this, {
      attributes: true,
      attributeFilter: ['value', 'disabled', 'size', 'variant']
    });
  }

  disconnectedCallback() {
    this.#observer?.disconnect();
    this.#observer = null;
    super.disconnectedCallback?.();
  }

  #handleMutations(mutations) {
    for (const m of mutations) {
      switch (m.attributeName) {
        case 'value':
          this.syncFromAttribute();
          break;
        case 'disabled':
          this.#applyDisabledState();
          break;
        default:
          this.syncConfig();
          break;
      }
    }
  }
}
```

### 12.2 Observer Debouncing

For components with rapid attribute changes (e.g., a slider being dragged), debounce the observer:

```js
#pendingSync = false;

#handleMutations(mutations) {
  if (this.#pendingSync) return;
  this.#pendingSync = true;

  requestAnimationFrame(() => {
    for (const m of mutations) {
      // Process latest state
    }
    this.#pendingSync = false;
  });
}
```

This batches multiple rapid mutations into a single render cycle.

### 12.3 Observer vs Event Listeners

| Approach | Use when | Avoid when |
| --- | --- | --- |
| MutationObserver | External state changes (Livewire `wire:model`) | Internal state changes (use direct method calls) |
| Event listeners | User interactions (click, keydown, input) | State synchronization (use observer) |

## 13. Dynamic CSS: adoptedStyleSheets

### 13.1 Theme Application Pattern

Components apply runtime theme tokens via `adoptedStyleSheets`:

```js
connectedCallback() {
  super.connectedCallback();
  const sheet = new CSSStyleSheet();
  sheet.replaceSync(`
    :host {
      --gsmui-color-surface: ${this.getAttribute('surface-color') || '#ffffff'};
      --gsmui-color-text: ${this.getAttribute('text-color') || '#000000'};
    }
  `);
  this.shadowRoot?.adoptedStyleSheets.push(sheet);
}
```

### 13.2 Why Not Inline `<style>`?

1. **CSP compliance** — `style-src 'self' 'unsafe-inline'` allows inline styles, but `adoptedStyleSheets` is cleaner.
2. **Performance** — `adoptedStyleSheets` is parsed once and shared across all instances of the same sheet object.
3. **No DOM pollution** — no `<style>` elements in the DOM tree that could be accidentally removed or duplicated.

### 13.3 Sheet Management

```js
// Theme sheet is shared across all instances
const themeSheet = new CSSStyleSheet();

function updateThemeSheet(tokens) {
  themeSheet.replaceSync(`
    :host {
      ${Object.entries(tokens).map(([k, v]) => `${k}: ${v};`).join('\n    ')}
    }
  `);
}

// Each component instance adopts the shared sheet
connectedCallback() {
  this.shadowRoot.adoptedStyleSheets = [themeSheet];
}
```

## 15. Error Handling & Resilience

### 15.1 Silent Failure Pattern

GsmUi components fail silently — they never throw errors that break the page:

```js
connectedCallback() {
  try {
    super.connectedCallback();
    this.#setupObserver();
    this.#render();
  } catch (e) {
    console.warn(`[GsmUi] ${this.tagName} failed to initialize:`, e);
    this.setAttribute('data-gsmui-error', '');
  }
}
```

### 15.2 Graceful Degradation

If a required browser API is missing:

| Missing API | Fallback |
| --- | --- |
| `MutationObserver` | Direct attribute polling via `setInterval` (rare) |
| `CSSStyleSheet.replaceSync` | Inline `<style>` element (CSP allows `unsafe-inline`) |
| `navigator.clipboard` | `document.execCommand('copy')` (deprecated but functional) |
| `ResizeObserver` | `window.resize` event listener (less precise) |
| `:focus-visible` | Always show focus ring (no `focus-visible` detection) |

### 15.3 Component Recovery

If a component enters an invalid state (e.g., corrupted internal state):

```js
#recover() {
  // Re-read from attributes
  this.#internalValue = this.getAttribute('value');
  this.#disabled = this.hasAttribute('disabled');
  // Re-render from clean state
  this.render();
  this.setAttribute('data-gsmui-recovered', '');
}
```

## 16. Performance Patterns

### 16.1 Render Batching

Multiple state changes in the same tick should produce a single render:

```js
#renderPending = false;

requestRender() {
  if (this.#renderPending) return;
  this.#renderPending = true;
  requestAnimationFrame(() => {
    this.#render();
    this.#renderPending = false;
  });
}
```

### 16.2 Lazy Component Loading

Components below the fold should use `loading="lazy"` or IntersectionObserver:

```js
connectedCallback() {
  if ('IntersectionObserver' in window) {
    const observer = new IntersectionObserver((entries) => {
      if (entries[0].isIntersecting) {
        this.#initialize();
        observer.disconnect();
      }
    }, { rootMargin: '200px' });
    observer.observe(this);
  } else {
    this.#initialize(); // Fallback: initialize immediately
  }
}
```

### 16.3 Memory Leak Prevention

```js
disconnectedCallback() {
  // Disconnect observer
  this.#observer?.disconnect();
  // Remove event listeners
  this.removeEventListener('focus', this.#handleFocus);
  this.removeEventListener('blur', this.#handleBlur);
  // Clear references
  this.#observer = null;
  this.#form = null;
  // Call parent cleanup
  super.disconnectedCallback?.();
}
```

## 17. Module Loading Strategy

### 17.1 IIFE vs ESM

| Format | File | Use case |
| --- | --- | --- |
| IIFE | `gsmui.js` | Traditional `<script src>` loading (most Laravel apps) |
| ESM | `gsmui.module.js` | Modern bundler consumers (Vite, esbuild) |

Both are produced by the upstream build. The IIFE version registers `window.Gsmui` global; the ESM version exports named exports.

### 17.2 Script Loading Order

```html
<!-- Recommended loading order -->
<script src="{{ asset('vendor/gsmui/gsmui.js') }}" defer></script>
<!-- OR for ESM -->
<script type="module" src="{{ asset('vendor/gsmui/gsmui.module.js') }}"></script>
```

`defer` ensures GsmUi initializes after DOM parsing but before `DOMContentLoaded`, which is the correct timing for custom elements.

### 17.3 Bundle Size Budget

| Bundle | Target | Max |
| --- | --- | --- |
| `gsmui.js` | 40KB | 60KB |
| `gsmui.min.js` | 15KB | 25KB |
| `gsmui.module.js` | 35KB | 55KB |
| `editor.js` | 100KB | 150KB |

These budgets are enforced upstream; this repo's `dist/` files should not be modified.

## 18. Testing Infrastructure

### 18.1 Component Test Pattern

Every GsmUi component follows this test skeleton:

```js
// tests/Browser/slider.spec.js
import { test, expect } from '@playwright/test';

test.describe('gsmui:slider', () => {
  test('renders with default value', async ({ page }) => {
    await page.goto('/gsmui-test/slider');
    const slider = page.locator('gsmui-slider');
    await expect(slider).toHaveAttribute('value', '50');
  });

  test('updates value on arrow key', async ({ page }) => {
    await page.goto('/gsmui-test/slider');
    const slider = page.locator('gsmui-slider');
    await slider.focus();
    await page.keyboard.press('ArrowRight');
    await expect(slider).toHaveAttribute('value', '51');
  });

  test('fires input and change events', async ({ page }) => {
    await page.goto('/gsmui-test/slider');
    const slider = page.locator('gsmui-slider');
    const events = await page.evaluate(() => {
      const log = [];
      slider.addEventListener('input', () => log.push('input'));
      slider.addEventListener('change', () => log.push('change'));
      return log;
    });
    // After keyboard interaction
    expect(events).toContain('input');
    expect(events).toContain('change');
  });

  test('respects disabled state', async ({ page }) => {
    await page.goto('/gsmui-test/slider?disabled=1');
    const slider = page.locator('gsmui-slider');
    await expect(slider).toHaveAttribute('aria-disabled', 'true');
    await slider.focus();
    await page.keyboard.press('ArrowRight');
    await expect(slider).toHaveAttribute('value', '50'); // unchanged
  });
});
```

## 19. Security Considerations

### 19.1 XSS Prevention

GsmUi components never use `innerHTML`, `document.write()`, or `eval()`:

```js
// ❌ FORBIDDEN
element.innerHTML = userInput;
eval(userScript);
new Function(userCode)();

// ✅ SAFE
element.textContent = userInput; // textContent is always safe
element.setAttribute('data-label', userInput); // attributes are escaped
```

### 19.2 CSP Compliance Summary

| Directive | GsmUi compliance |
| --- | --- |
| `script-src 'self'` | All JS in `dist/`, no inline scripts, no eval |
| `style-src 'self' 'unsafe-inline'` | `adoptedStyleSheets` + Tailwind utilities |
| `img-src 'self' data:` | Inline SVG icons only |
| `connect-src 'self'` | No fetch/XHR/WebSocket in component JS |
| `worker-src 'self'` | No Web Workers in component JS |

### 19.3 Input Sanitization

Components that accept user text input (text fields, search, command palette):

```js
// Never render unsanitized HTML
#renderLabel(text) {
  // textContent is safe — no HTML parsing
  this.labelElement.textContent = text;
}

// Attribute values are auto-escaped by the browser
setAttribute(this, 'placeholder', userText);
```

## 21. Component Lifecycle Deep Dive

### 21.1 Custom Element Lifecycle

GsmUi components follow the standard Custom Element lifecycle:

```text
constructor() → connectedCallback() → (attributeChangedCallback) → disconnectedCallback()
```

| Phase | What happens | GsmUi actions |
| --- | --- | --- |
| `constructor()` | Element created, not in DOM | Set default property values, create shadow DOM (if used) |
| `connectedCallback()` | Element inserted into DOM | Initialize mixins, set up MutationObserver, render initial UI |
| `attributeChangedCallback()` | Attribute modified | Sync to internal state via mixin methods |
| `disconnectedCallback()` | Element removed from DOM | Disconnect observers, remove event listeners, clean up |

### 21.2 Constructor Rules

The constructor must NOT:
- Read attributes (the element may not have them yet).
- Append children or modify DOM.
- Access `parentNode` or `children`.

```js
class GsmuiSlider extends Controllable(Disableable(Focusable(HTMLElement))) {
  constructor() {
    super();
    // ✅ Safe: set defaults, create internal elements
    this.#value = 0;
    this.#min = 0;
    this.#max = 100;
  }
}
```

### 21.3 connectedCallback() Rules

The `connectedCallback()` IS the right place to:
- Read attributes (`this.getAttribute('value')`).
- Set up MutationObserver.
- Attach event listeners.
- Access parent/child elements.
- Render initial DOM.

```js
connectedCallback() {
  super.connectedCallback(); // Mixin initialization (order matters)
  this.#readAttributes();
  this.#setupObserver();
  this.#setupEventListeners();
  this.#render();
}
```

### 21.4 disconnectedCallback() Cleanup

Every resource acquired in `connectedCallback()` must be released:

```js
disconnectedCallback() {
  this.#observer?.disconnect();
  this.#abortController?.abort(); // Cancels all addEventListener with this signal
  this.#form?.removeEventListener('submit', this.#handleSubmit);
  super.disconnectedCallback?.();
}
```

### 21.5 Re-entrance Handling

Elements can be moved in the DOM (removed and re-inserted). This triggers `disconnectedCallback()` then `connectedCallback()` again. The component must handle this gracefully:

```js
connectedCallback() {
  super.connectedCallback();
  if (this.#initialized) return; // Prevent double-init on re-entrance
  this.#initialized = true;
  this.#setup();
}
```

## 22. State Management Patterns

### 22.1 Internal State vs External State

| State type | Source | Mechanism | Example |
| --- | --- | --- | --- |
| Internal | User interaction | Direct property mutation | Slider thumb position during drag |
| External | Server/Livewire | `setAttribute` via utils.js | `value` attribute from `wire:model` |
| Config | Blade template | `setAttribute` at render time | `size`, `variant`, `format` |

### 22.2 State Flow Diagram

```text
User interaction
    ↓
Internal state mutation
    ↓
setAttribute('value', newValue) ← via utils.js
    ↓
MutationObserver fires
    ↓
Livewire receives attribute change
    ↓
Server updates
    ↓
Livewire calls setAttribute('value', serverValue)
    ↓
MutationObserver fires
    ↓
syncFromAttribute() → UI update
```

### 22.3 State Consistency Guarantees

| Guarantee | Mechanism |
| --- | --- |
| No infinite loops | `#syncing` flag in Controllable mixin |
| No stale reads | MutationObserver fires synchronously after `setAttribute` |
| No lost updates | `requestAnimationFrame` batching for rapid changes |
| No partial renders | `render()` is atomic — replaces all dynamic DOM at once |

### 22.4 Derived State

Some component state is computed from other state, not stored directly:

```js
get percentage() {
  return ((this.#value - this.#min) / (this.#max - this.#min)) * 100;
}

get formattedValue() {
  return new Intl.NumberFormat(this.#locale).format(this.#value);
}
```

Derived state is recalculated on every `render()` call — never cached.

## 23. Event System Deep Dive

### 23.1 Event Dispatch Patterns

```js
// Standard DOM event (for Livewire wire:model)
this.dispatchEvent(new Event('input', { bubbles: true }));

// Custom event with detail data
this.dispatchEvent(new CustomEvent('gsmui:change', {
  detail: { value: this.#value, previous: oldValue },
  bubbles: true,
  composed: true,
}));

// Cancelable event (allows preventDefault)
this.dispatchEvent(new CustomEvent('gsmui:before-change', {
  detail: { value: newValue },
  bubbles: true,
  cancelable: true,
}));
```

### 23.2 Event Bubbling and Composition

| Property | `bubbles` | `composed` | Use when |
| --- | --- | --- | --- |
| Both true | Event crosses shadow DOM boundary AND bubbles up | Custom events for external consumers |
| `bubbles` only | Event bubbles but stays within shadow DOM | Internal component events |
| Neither | Event only fires on the target element | One-shot notifications |
| `composed` only | Event crosses shadow DOM but doesn't bubble | Rare — focus events |

### 23.3 Event Listener Patterns

```js
// Passive listener for scroll/touch (performance)
this.addEventListener('scroll', this.#handleScroll, { passive: true });

// AbortController for clean cleanup
this.#abortController = new AbortController();
this.addEventListener('click', this.#handleClick, { signal: this.#abortController.signal });

// Once listener
this.addEventListener('gsmui:connected', () => this.#afterConnect(), { once: true });
```

### 23.4 Event Timing

| Event | Timing | Consumer |
| --- | --- | --- |
| `gsmui:connected` | After `connectedCallback()` completes | Parent components |
| `input` | On every value change | Livewire `wire:model.live` |
| `change` | On commit (pointerup, keyboard commit) | Livewire `wire:model` |
| `gsmui:focus` | On focus | Focus management |
| `gsmui:blur` | On blur | Focus management |

## 24. Error Handling Patterns

### 24.1 Component Error Boundary

```js
connectedCallback() {
  try {
    super.connectedCallback();
    this.#initialize();
  } catch (error) {
    console.warn(`[GsmUi] ${this.tagName} initialization failed:`, error);
    this.#renderErrorState();
    this.setAttribute('data-gsmui-error', '');
  }
}

#renderErrorState() {
  this.textContent = '';
  const fallback = document.createElement('span');
  fallback.setAttribute('data-gsmui-fallback', '');
  fallback.textContent = this.getAttribute('value') || '';
  this.appendChild(fallback);
}
```

### 24.2 Graceful Feature Detection

```js
// Clipboard API
async #copyToClipboard(text) {
  if (navigator.clipboard) {
    await navigator.clipboard.writeText(text);
  } else {
    // Fallback for older browsers
    const textarea = document.createElement('textarea');
    textarea.value = text;
    textarea.style.position = 'fixed';
    textarea.style.opacity = '0';
    document.body.appendChild(textarea);
    textarea.select();
    document.execCommand('copy');
    document.body.removeChild(textarea);
  }
}

// ResizeObserver
if ('ResizeObserver' in window) {
  this.#resizeObserver = new ResizeObserver(this.#handleResize.bind(this));
  this.#resizeObserver.observe(this);
} else {
  window.addEventListener('resize', this.#handleResize.bind(this));
}
```

### 24.3 Error Recovery Strategy

| Error type | Recovery |
| --- | --- |
| Missing required attribute | Use default value, log warning |
| Invalid attribute value | Revert to last valid value, set `data-gsmui-error` |
| DOM manipulation failure | Log error, render fallback markup |
| Observer failure | Fall back to polling or event listeners |
| API not supported | Use polyfill or degrade gracefully |

## 27. Performance Patterns Deep Dive

### 27.1 Render Pipeline

```text
State change
    ↓
requestAnimationFrame scheduled (if not already)
    ↓
Next animation frame
    ↓
DOM reads (get positions, sizes)
    ↓
DOM writes (apply changes)
    ↓
Browser paints
```

### 27.2 Layout Thrashing Prevention

Never read layout properties after a write in the same frame:

```js
// ❌ WRONG: Layout thrashing
element.style.width = '100px';
const height = element.offsetHeight; // Forces layout recalculation
element.style.height = height + 'px';

// ✅ CORRECT: Batch reads and writes
const height = element.offsetHeight; // Read first
requestAnimationFrame(() => {
  element.style.width = '100px';
  element.style.height = height + 'px'; // Write second
});
```

### 39.2 Input Sanitization

```javascript
// Sanitize attribute values before use
function sanitize(value) {
    const div = document.createElement('div');
    div.textContent = value;
    return div.innerHTML;
}

// Use in attribute handling
attributeChangedCallback(name, oldValue, newValue) {
    if (name === 'label') {
        this.#label = sanitize(newValue);
    }
}
```

### 39.3 DOM Injection Prevention

```javascript
// Safe DOM creation
function createElement(tag, attrs = {}, text = '') {
    const el = document.createElement(tag);
    for (const [key, value] of Object.entries(attrs)) {
        el.setAttribute(key, sanitize(value));
    }
    if (text) {
        el.textContent = text; // Safe: textContent, not innerHTML
    }
    return el;
}
```

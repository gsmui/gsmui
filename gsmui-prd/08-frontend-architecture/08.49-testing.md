# 08.49 - Testing

**Project:** GsmUi
**Section:** 08 - Frontend Architecture
**Framework:** Playwright · Laravel 13 (Orchestra Testbench) · Livewire 4
**Version:** 1.0.0

---

> See also: `07.55-testing.md` (backend/PHP test strategy), `08.55-frontend-security.md` (CSP header tests). This document specifies the *frontend/browser test contract* and does NOT re-document PHPUnit setup.

# Purpose

GsmUi frontend verification is dominated by **Playwright browser tests** (`tests/Browser/*.spec.js`) plus a PHP-level CSP header test. Per `AGENTS.md`, Playwright verification is mandatory before any component is declared done — screenshots, pixel measurement, and real interaction, not eyeballing. This document pins the test layout, run commands, and the patterns tests must follow.

---

## 1. Test Layout

| Path | Type | Runner |
| --- | --- | --- |
| `tests/Browser/*.spec.js` | Component/interaction | Playwright (`npx playwright test`) |
| `tests/Browser/CspHeaderTest.php` | CSP header assertion | Orchestra Testbench (`@test`) |
| `tests/Browser/README.md` | Setup + run instructions | — |
| `tests/Browser/package.json` | Bootstrapped Playwright deps (NOT repo root) | npm |

---

## 2. Running Tests

```bash
# 1. Start Laravel server with CSP enabled (Playwright baseURL = :8000)
CSP_ENABLED=true php artisan serve --port=8000

# 2. In tests/Browser/, install and run headless
cd tests/Browser
npm install
npx playwright test          # always headless unless asked otherwise
```

CSP verification route: `/gsmui-csp-test`.

---

## 3. What Tests Observe (DOM, Not Internals)

Per `AGENTS.md`, tests inspect **DOM state**, never component internals like `el.state.s`.

| Assertion | Example |
| --- | --- |
| Thumb/position | `getBoundingClientRect()` of slider thumb |
| Input values | `input.value` after keyboard change |
| ARIA attributes | `role="combobox"`, `aria-expanded` |
| Class presence | `.dark` on `<html>` for theme tests |
| Console | zero errors via `browser_console_messages` |

---

## 4. Component Test Pattern (sibling-matched)

Copy the structure of `slider` / `date-picker` specs:

```js
test('date-picker opens popover and is keyboard navigable', async ({ page }) => {
  await page.goto('/gsmui-csp-test');
  await page.getByRole('button', { name: /open calendar/i }).click();
  // popover visible
  await page.locator('.dark\\:bg-zinc-700').first().waitFor();
  await page.keyboard.press('ArrowDown');
  // assert focused date cell
});
```

- Match sibling selectors; don't reinvent per component.
- Always run **headless**.
- Screenshot critical states (base, open, disabled, invalid, sizes) after CSS/behavior changes.

---

## 5. CSP Header Test (PHP)

`CspHeaderTest.php` extends `Orchestra\Testbench\TestCase`, uses `@test`, and asserts the response header contains `script-src 'self'` and no `unsafe-eval`. This guards the PWA/worker additions in `08.48`.

## 7. Test Environment Setup

| --- | --- | --- |

| Firefox | Latest (via Playwright) | Cross-browser verification |
| WebKit | Latest (via Playwright) | Safari engine verification |

### 7.2 Installation Steps

```bash
# 1. Ensure PHP dependencies are installed
composer install

# 2. Navigate to the Browser test directory
cd tests/Browser

# 3. Install Playwright and its browser binaries
npm install
npx playwright install

# 4. Install system dependencies (Linux only)
npx playwright install-deps
```

### 7.3 Environment Variables

| Variable | Required | Default | Description |
| --- | --- | --- | --- |
| `CSP_ENABLED` | Yes | `false` | Must be `true` for CSP tests |
| `APP_ENV` | Recommended | `local` | Prevents production middleware |
| `APP_DEBUG` | Recommended | `true` | Enables detailed error output |
| `DB_CONNECTION` | Optional | `sqlite` | Database for testbench |
| `CACHE_DRIVER` | Optional | `array` | Prevents cache pollution |
| `SESSION_DRIVER` | Optional | `array` | Prevents session leakage |

### 7.4 Port Configuration

The Playwright test suite assumes a running Laravel server on port `8000`. This is hardcoded in `playwright.config.ts`:

```js
// tests/Browser/playwright.config.ts
export default defineConfig({
  baseURL: 'http://localhost:8000',
  timeout: 30000,
  retries: process.env.CI ? 2 : 0,
  use: {
    headless: true,
    viewport: { width: 1280, height: 720 },
    screenshot: 'only-on-failure',
  },
});
```

If port 8000 is unavailable, update `baseURL` in the config and the README.

```js
// tests/Browser/helpers/assertions.js
export async function assertNoConsoleErrors(page) {
  const errors = [];
  page.on('console', msg => {
    if (msg.type() === 'error') errors.push(msg.text());
  });
  await page.waitForTimeout(500);
  return errors;
}

export async function assertAriaAttribute(page, selector, attribute, expected) {
  const value = await page.locator(selector).getAttribute(attribute);
  expect(value).toBe(expected);
}

export async function assertComputedStyle(page, selector, property, expected) {
  const actual = await page.locator(selector).evaluate(
    (el, prop) => getComputedStyle(el)[prop],
    property
  );
  expect(actual).toBe(expected);
}

export async function assertTabularNums(page, selector) {
  const fontVariant = await page.locator(selector).evaluate(
    el => getComputedStyle(el).fontVariantNumeric
  );
  expect(fontVariant).toContain('tabular-nums');
}
```

```js
// tests/Browser/helpers/page-objects.js
export class ComponentPage {
  constructor(page, route) {
    this.page = page;
    this.route = route;

    await this.page.goto(this.route);
    await this.page.waitForLoadState('networkidle');

    await this.page.screenshot({
      path: `tests/Browser/screenshots/${name}.png`,
      fullPage: true,

    return this.page.locator(selector).boundingBox();

    return this.page.locator(selector).evaluate(
      el => el === document.activeElement
    );
  }

  async getAttribute(selector, attr) {
    return this.page.locator(selector).getAttribute(attr);
  }
}
```

## 9. Test Patterns in Detail

### 9.1 Component Rendering Test

Verifies that a component renders correctly with default props:

```js
test('select renders with default props', async ({ page }) => {
  await page.goto(STORY_ROUTES.select);

  // Verify trigger is visible
  const trigger = page.locator('[role="combobox"]');
  await expect(trigger).toBeVisible();

  // Verify default value text
  await expect(trigger).toHaveText('Select an option');

  // Verify ARIA attributes
  await expect(trigger).toHaveAttribute('aria-haspopup', 'listbox');
  await expect(trigger).toHaveAttribute('aria-expanded', 'false');

  // Screenshot
  await page.screenshot({ path: 'screenshots/select-default.png' });
});
```

### 9.2 Interaction Test

Verifies user interactions trigger correct state changes:

```js
test('select opens dropdown on click and selects item', async ({ page }) => {
  await page.goto(STORY_ROUTES.select);

  // Click trigger to open
  await page.locator('[role="combobox"]').click();
  await expect(page.locator('[role="listbox"]')).toBeVisible();
  await expect(page.locator('[role="combobox"]')).toHaveAttribute('aria-expanded', 'true');

  // Select an option
  await page.locator('[role="option"]').first().click();

  // Verify dropdown closes
  await expect(page.locator('[role="listbox"]')).not.toBeVisible();
  await expect(page.locator('[role="combobox"]')).toHaveAttribute('aria-expanded', 'false');
});
```

### 9.3 Keyboard Navigation Test

Verifies keyboard accessibility:

```js
test('select is keyboard navigable', async ({ page }) => {
  await page.goto(STORY_ROUTES.select);

  // Focus the trigger
  await page.locator('[role="combobox"]').focus();

  // Open with Enter
  await page.keyboard.press('Enter');
  await expect(page.locator('[role="listbox"]')).toBeVisible();

  // Navigate with ArrowDown
  await page.keyboard.press('ArrowDown');
  await page.keyboard.press('ArrowDown');

  // Select with Enter
  await page.keyboard.press('Enter');
  await expect(page.locator('[role="listbox"]')).not.toBeVisible();

  // Verify value changed
  const trigger = page.locator('[role="combobox"]');
  await expect(trigger).not.toHaveText('Select an option');
});
```

### 9.4 Disabled State Test

Verifies disabled components are non-interactive:

```js
test('disabled select cannot be opened', async ({ page }) => {
  await page.goto(STORY_ROUTES.select + '?disabled=true');

  const trigger = page.locator('[role="combobox"]');
  await expect(trigger).toHaveAttribute('aria-disabled', 'true');

  // Click should not open
  await trigger.click({ force: true });
  await expect(page.locator('[role="listbox"]')).not.toBeVisible();

  // Keyboard should not open
  await trigger.focus();
  await page.keyboard.press('Enter');
  await expect(page.locator('[role="listbox"]')).not.toBeVisible();
});
```

### 9.5 Invalid State Test

Verifies invalid styling and ARIA:

```js
test('invalid select shows error state', async ({ page }) => {
  await page.goto(STORY_ROUTES.select + '?invalid=true');

  const trigger = page.locator('[role="combobox"]');

  // data-invalid attribute present
  await expect(trigger).toHaveAttribute('data-invalid', '');

  // Error message visible
  await expect(page.locator('[aria-live="polite"]')).toBeVisible();

  // Screenshot for visual verification
  await page.screenshot({ path: 'screenshots/select-invalid.png' });
});
```

### 9.6 Size Variant Test

Verifies size progression:

```js
test('select size variants render at correct heights', async ({ page }) => {
  await page.goto(STORY_ROUTES.select + '?sizes=all');

  const sizes = [
    { name: 'default', expectedHeight: 40 },  // h-10
    { name: 'sm', expectedHeight: 32 },        // h-8
    { name: 'xs', expectedHeight: 24 },        // h-6
  ];

  for (const { name, expectedHeight } of sizes) {
    const trigger = page.locator(`[data-size="${name}"] [role="combobox"]`);
    const box = await trigger.boundingBox();
    expect(box.height).toBe(expectedHeight);
  }
});
```

### 9.7 Dark Mode Test

Verifies dark mode rendering:

```js
test('select renders correctly in dark mode', async ({ page }) => {
  await page.goto(STORY_ROUTES.select);

  // Enable dark mode
  await page.evaluate(() => {
    document.documentElement.classList.add('dark');
  });

  // Verify background color
  const bg = await page.locator('[role="combobox"]').evaluate(
    el => getComputedStyle(el).backgroundColor
  );
  expect(bg).not.toBe('rgb(255, 255, 255)'); // Not white in dark mode

  // Screenshot for visual verification
  await page.screenshot({ path: 'screenshots/select-dark.png' });
});
```

### 9.8 Focus Visible Test

Verifies focus ring visibility:

```js
test('select shows focus-visible ring on keyboard focus', async ({ page }) => {
  await page.goto(STORY_ROUTES.select);

  // Tab to the trigger
  await page.keyboard.press('Tab');

  // Check focus-visible styles
  const trigger = page.locator('[role="combobox"]');
  const outline = await trigger.evaluate(
    el => getComputedStyle(el, ':focus-visible').outlineStyle
  );
  // Native outline should be present (not overridden)
  expect(outline).not.toBe('none');
});
```

### 9.9 Scroll Lock Test

Verifies popover scroll lock behavior:

```js
test('modal locks body scroll when open', async ({ page }) => {
  await page.goto(STORY_ROUTES.modal);

  // Ensure body is scrollable
  const overflowBefore = await page.evaluate(
    () => getComputedStyle(document.body).overflow
  );
  expect(overflowBefore).not.toBe('hidden');

  // Open modal
  await page.locator('button:has-text("Open Modal")').click();
  await expect(page.locator('[role="dialog"]')).toBeVisible();

  // Verify body scroll is locked
  const overflowAfter = await page.evaluate(
    () => getComputedStyle(document.body).overflow
  );
  expect(overflowAfter).toBe('hidden');

  // Close modal and verify scroll restored
  await page.keyboard.press('Escape');
  const overflowRestored = await page.evaluate(
    () => getComputedStyle(document.body).overflow
  );
  expect(overflowRestored).not.toBe('hidden');
});
```

### 9.10 Responsive Test

Verifies responsive behavior across viewports:

```js
test('date picker popover adapts to mobile viewport', async ({ page }) => {
  // Set mobile viewport
  await page.setViewportSize({ width: 375, height: 812 });
  await page.goto(STORY_ROUTES.datePicker);

  // Open popover
  await page.getByRole('button', { name: /open calendar/i }).click();

  // On mobile, popover should be fixed fullscreen
  const popover = page.locator('.max-sm\\:fixed');
  await expect(popover).toBeVisible();

  const box = await popover.boundingBox();
  expect(box.width).toBe(375);
  expect(box.height).toBe(812);

  // Screenshot mobile state
  await page.screenshot({ path: 'screenshots/date-picker-mobile.png' });
});
```

## 10. Screenshot and Visual Regression

### 10.1 Screenshot Capture Strategy

Every CSS change requires a Playwright screenshot to verify the change is visible and correct. Screenshots are captured at specific states:

| State | When to Capture | Notes |
| --- | --- | --- |
| Base render | After initial mount | Default state |
| Hover | After hover interaction | Verify hover styles |
| Focus | After keyboard focus | Verify focus-visible ring |
| Active | During click/press | Verify active state |
| Disabled | With `disabled` prop | Verify opacity/cursor |
| Invalid | With `invalid` prop | Verify error styling |
| Open | Popover/dropdown open | Verify positioning |
| Dark mode | With `.dark` class | Verify theme tokens |
| Mobile | At 375px width | Verify responsive |
| Tablet | At 768px width | Verify responsive |

### 10.2 Screenshot Naming Convention

```text
screenshots/
├── <component>-<state>.png
├── <component>-<state>-dark.png
├── <component>-<state>-mobile.png
├── <component>-<variant>-<size>.png
└── regression/
    ├── <component>-<state>.png  (committed baselines)
    └── ...
```

### 10.3 Pixel Measurement

Playwright's `boundingBox()` and `evaluate()` provide pixel-level measurements. Never guess at spacing — measure with Playwright:

```js
// Measure gap between elements
const triggerBox = await page.locator('.trigger').boundingBox();
const popoverBox = await page.locator('.popover').boundingBox();
const gap = popoverBox.y - (triggerBox.y + triggerBox.height);

// Verify expected gap (e.g., 4px)
expect(gap).toBe(4);
```

### 10.4 Color Verification

Use Playwright to extract and verify computed colors:

```js
// Verify background color in dark mode
const bg = await page.locator('.component').evaluate(
  el => getComputedStyle(el).backgroundColor
);
// rgb(24, 24, 27) = zinc-800
expect(bg).toBe('rgb(24, 24, 27)');
```

## 11. Console Error Monitoring

### 11.1 Error Collection

Every test should monitor the browser console for errors:

```js
test.describe('Component Tests', () => {
  let consoleErrors = [];

  test.beforeEach(async ({ page }) => {
    consoleErrors = [];
    page.on('console', msg => {
      if (msg.type() === 'error') {
        consoleErrors.push(msg.text());
      }
    });
  });

  test.afterEach(async () => {
    expect(consoleErrors).toEqual([]);
  });

  test('component renders without errors', async ({ page }) => {
    await page.goto(STORY_ROUTES.component);
    // ... test logic
  });
});
```

### 11.2 Common Console Errors

| Error | Cause | Fix |
| --- | --- | --- |
| `Failed to load resource` | Missing asset or CDN reference | Ensure self-hosted only |
| `CSP violation` | External script/style blocked | Remove external resources |
| `ResizeObserver loop` | Infinite resize loop | Debounce resize handlers |
| `Cannot read property of undefined` | Uninitialized component state | Check init order |
| `Illegal constructor` | Wrong Web API usage | Verify browser support |

## 12. Accessibility Testing

### 12.1 ARIA Attribute Verification

Every interactive component must have correct ARIA attributes:

```js
test('modal has correct ARIA attributes', async ({ page }) => {
  await page.goto(STORY_ROUTES.modal);

  // Open modal
  await page.locator('button:has-text("Open Modal")').click();

  // Verify role="dialog"
  const dialog = page.locator('[role="dialog"]');
  await expect(dialog).toBeVisible();

  // Verify aria-labelledby
  const labelledby = await dialog.getAttribute('aria-labelledby');
  expect(labelledby).toBeTruthy();

  // Verify aria-modal
  await expect(dialog).toHaveAttribute('aria-modal', 'true');

  // Verify focus is trapped
  const activeElement = await page.evaluate(() => document.activeElement.tagName);
  expect(activeElement).toBe('BUTTON'); // Close button or first interactive
});
```

### 12.2 Focus Management Tests

```js
test('trap focus within modal', async ({ page }) => {
  await page.goto(STORY_ROUTES.modal);

  // Open modal
  await page.locator('button:has-text("Open Modal")').click();

  // Tab through all focusable elements
  const focusableElements = await page.locator(
    '[role="dialog"] button, [role="dialog"] input, [role="dialog"] [tabindex]'
  ).all();

  // Focus should cycle within the modal
  for (let i = 0; i < focusableElements.length; i++) {
    await page.keyboard.press('Tab');
    const focused = await page.evaluate(() => {
      return document.activeElement.closest('[role="dialog"]') !== null;
    });
    expect(focused).toBe(true);
  }
});
```

### 12.3 Screen Reader Announcements

```js
test('live region announces value change', async ({ page }) => {
  await page.goto(STORY_ROUTES.slider);

  // Move slider
  await page.locator('[role="slider"]').focus();
  await page.keyboard.press('ArrowRight');

  // Verify aria-live region updated
  const announcement = await page.locator('[aria-live="polite"]').textContent();
  expect(announcement).toMatch(/\d+/); // Should contain numeric value
});
```

## 13. Cross-Browser Testing

### 13.1 Browser Matrix

| Browser | Engine | Priority | Notes |
| --- | --- | --- | --- |
| Chromium | Blink | Primary | Default test browser |

### 13.2 Browser-Specific Considerations

| Issue | Browser | Workaround |
| --- | --- | --- |
| `:focus-visible` support | Firefox | Polyfill or `tabindex` fallback |
| `adoptedStyleSheets` | Safari < 15.4 | Inline `<style>` fallback |
| `scrollbar-width` | WebKit | Use `-webkit-overflow-scrolling` |
| Color picker native | Firefox | Use custom component only |
| `dialog` element | Older browsers | Use `role="dialog"` pattern |

### 17.1 Flaky Test Prevention

| Anti-pattern | Solution |
| --- | --- |
| Hard-coded timeouts | Use `waitFor()` with conditions |
| Race conditions | Serialize operations with `await` |
| Shared state between tests | Use `beforeEach` for isolation |

### 21.1 Page Object Model

The Page Object Model pattern encapsulates page-specific selectors and actions into reusable classes:

```js
// tests/Browser/helpers/page-objects/SelectPage.js
export class SelectPage {
  constructor(page) {
    this.page = page;
    this.trigger = page.locator('[role="combobox"]');
    this.listbox = page.locator('[role="listbox"]');
    this.options = page.locator('[role="option"]');
    this.searchInput = page.locator('input[type="search"]');
    this.clearButton = page.locator('button[aria-label="Clear"]');
  }

  async goto(route) {
    await this.page.goto(route);
    await this.page.waitForLoadState('networkidle');
    return this;
  }

  async open() {
    await this.trigger.click();
    await this.listbox.waitFor({ state: 'visible' });
    return this;
  }

  async close() {
    await this.trigger.press('Escape');
    await this.listbox.waitFor({ state: 'hidden' });
    return this;
  }

  async selectOption(index) {
    await this.open();
    await this.options.nth(index).click();
    return this;
  }

  async selectByText(text) {
    await this.open();
    await this.page.locator(`[role="option"]:has-text("${text}")`).click();
    return this;
  }

  async search(query) {
    await this.open();
    await this.searchInput.fill(query);
    return this;
  }

  async clear() {
    await this.clearButton.click();
    return this;
  }

  async getSelectedText() {
    return this.trigger.textContent();
  }

  async isOpen() {
    return this.listbox.isVisible();
  }

  async getOptionCount() {
    return this.options.count();
  }

  async focusTrigger() {
    await this.trigger.focus();
    return this;
  }

  async pressKey(key) {
    await this.page.keyboard.press(key);
    return this;
  }
}
```

## 24. Test Reporting and Metrics

### 24.1 Test Results Dashboard

```js
// tests/Browser/helpers/reporter.js
export class TestMetricsReporter {
  constructor() {
    this.metrics = {
      totalTests: 0,
      passed: 0,
      failed: 0,
      skipped: 0,
      duration: 0,
      componentCoverage: {},
    };
  }

  onTestEnd(test, result) {
    this.metrics.totalTests++;
    if (result.status === 'passed') this.metrics.passed++;
    if (result.status === 'failed') this.metrics.failed++;
    if (result.status === 'skipped') this.metrics.skipped++;

    const component = test.title.split(' ')[0];
    if (!this.metrics.componentCoverage[component]) {
      this.metrics.componentCoverage[component] = { passed: 0, failed: 0 };
    }
    if (result.status === 'passed') {
      this.metrics.componentCoverage[component].passed++;
    } else {
      this.metrics.componentCoverage[component].failed++;
    }
  }

  onEnd(result) {
    this.metrics.duration = result.duration;
    console.log(JSON.stringify(this.metrics, null, 2));
  }
}
```

## 25. Continuous Improvement

### 25.1 Test Review Process

1. **New component tests** must follow sibling patterns (slider, date-picker)
2. **PR reviews** must verify Playwright screenshots are attached
3. **Failed tests** must be fixed before merge
4. **Flaky tests** must be quarantined and fixed within one sprint
5. **Coverage reports** must be reviewed monthly

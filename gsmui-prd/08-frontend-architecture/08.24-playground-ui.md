# 08.24 - Playground UI

**Project:** GsmUi
**Section:** 08 - Frontend Architecture
**Framework:** Laravel 13 · Livewire 4 · Blade Components · GsmUi Component Library · Tailwind CSS v4 · Vite · Monaco Editor
**Version:** 1.0.0

---

> See also: `05.19-playground.md` (playground engine), `06.80-playground.md` (playground
> records). This document specifies the *live playground presentation* and does NOT re-document
> the server-side Blade compile/execute sandbox — that lives in 05/06.

# Purpose

This document defines the interactive playground: a Monaco Editor for Blade/HTML source on the
left, a live `gsmui:` preview iframe/region on the right, and a debounced compile loop that posts
source to a Livewire endpoint and streams rendered HTML back. It covers the split layout, the
editor toolbar, and the error overlay.

---

## 1. Page Composition

| Region | GsmUi / Tool | Livewire |
| --- | --- | --- |
| Layout | `gsmui:layouts.app` (full-bleed) | host `Playground` |
| Toolbar | `gsmui:button`, `gsmui:select` (variant), `gsmui:switch` (dark) | `wire:model` |
| Editor | Monaco Editor (bundled, `dist/`) | `source` property |
| Preview | `gsmui:frame` / sandboxed region | compiled HTML |
| Errors | `gsmui:callout` (type="danger") | error bag |

## 2. Component Tree

```text
gsmui:layouts.app (full-bleed)
└── <playground grid>
    ├── <toolbar>
    │   ├── gsmui:button (run / format)
    │   ├── gsmui:select (component variant)
    │   └── gsmui:switch (dark preview)
    ├── <monaco mount>  (Monaco, no CDN — bundled in dist/)
    └── gsmui:frame
        └── live <gsmui:*> preview
        └── gsmui:callout (compile error)
```

## 3. Data Flow — Edit → Compile → Preview

```text
Monaco change
   │  debounce 400ms
   ▼
wire:model.live="source"  ──▶  Playground::$source
   │                                  │
   │  on updatedSource()              ▼
   │                        sandbox compile (05.19)
   │                                  │
   ▼                          $html / $error
<gsmui-frame> srcdoc / innerHTML  ◀──  browser re-render
```

- Monaco is bundled locally in `dist/` (never a CDN script) to honour the CSP zero-external-resource
  profile (`script-src 'self'`).
- The preview region uses `adoptedStyleSheets` for injected theme CSS — no `<style>` tags.
- Compile errors surface through `gsmui:callout` with `data-invalid:` styling, never a JS alert.

## 4. JS Conventions

- Editor interaction logic lives in JS, not Alpine, using `setAttribute`/`removeAttribute` from
  `utils.js` (MutationObserver-aware) when toggling preview state.
- Preview `<gsmui-*>` elements re-read `value` via `MutationObserver` on attribute change.

### 5.1 `Playground` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;
use Livewire\Attributes\Layout;
use Livewire\Attributes\On;
use Illuminate\Support\Facades\Process;
use Illuminate\Support\Str;

#[Layout('gsmui::layouts.app')]
class Playground extends Component
{
    public string $source = '';
    public string $compiledHtml = '';
    public ?string $compileError = null;
    public bool $isCompiling = false;
    public string $variant = 'default';
    public bool $darkPreview = false;
    public bool $autoRun = true;
    public int $compileCount = 0;
    public array $recentSnippets = [];
    public string $selectedSnippet = '';
    public ?string $currentComponent = null;

    private string $defaultSource = <<<'BLADE'
<gsmui:button type="primary">
    Click me
</gsmui:button>
BLADE;

    protected array $listeners = [
        'formatCode' => 'formatSource',
        'resetCode' => 'resetSource',
        'loadSnippet' => 'loadSnippet',
    ];

    public function boot(): void
    {
        if (empty($this->source)) {
            $this->source = $this->defaultSource;
        }
    }

    public function updatedSource(string $value): void
    {
        if ($this->autoRun) {
            $this->compile();
        }
    }

    public function compile(): void
    {
        $this->isCompiling = true;
        $this->compileError = null;
        $this->compiledHtml = '';

        try {
            $result = $this->compileBlade($this->source);

            if ($result['success']) {
                $this->compiledHtml = $result['html'];
                $this->compileCount++;
            } else {
                $this->compileError = $result['error'];
            }
        } catch (\Exception $e) {
            $this->compileError = $e->getMessage();
        } finally {
            $this->isCompiling = false;
        }
    }

    private function compileBlade(string $source): array
    {
        $sanitized = $this->sanitizeSource($source);

        try {
            $compiled = app('blade')->compileString($sanitized);
            $html = $this->renderCompiled($compiled);

            return ['success' => true, 'html' => $html];
        } catch (\InvalidArgumentException $e) {
            return ['success' => false, 'error' => $e->getMessage()];
        }
    }

    private function sanitizeSource(string $source): string
    {
        // Block dangerous directives
        $forbidden = [
            '@php', '@verbatim', '@inject',
            'artisan', 'exec(', 'system(',
            'file_get_contents', 'file_put_contents',
            'shell_exec', 'proc_open', 'popen',
        ];

        foreach ($forbidden as $pattern) {
            if (Str::contains($source, $pattern)) {
                throw new \InvalidArgumentException(
                    "Blocked forbidden pattern: {$pattern}"
                );
            }
        }

        // Limit source length to prevent abuse
        if (strlen($source) > 10000) {
            throw new \InvalidArgumentException('Source code exceeds maximum length of 10,000 characters.');
        }

        return $source;
    }

    private function renderCompiled(string $compiled): string
    {
        ob_start();
        echo eval('?' . '>' . $compiled);
        $html = ob_get_clean();
        return $html ?: '';
    }

    public function formatSource(): void
    {
        $this->source = $this->formatBlade($this->source);
    }

    private function formatBlade(string $source): string
    {
        // Basic Blade formatting: normalize indentation, trim trailing whitespace
        $lines = explode("\n", $source);
        $formatted = array_map(fn($line) => rtrim($line), $lines);
        return implode("\n", array_filter($formatted, fn($line) => $line !== '' || end($formatted) !== ''));
    }

    public function resetSource(): void
    {
        $this->source = $this->defaultSource;
        $this->compileError = null;
        $this->compiledHtml = '';
    }

    public function loadSnippet(string $snippet): void
    {
        $this->selectedSnippet = $snippet;
        $this->source = $this->getSnippets()[$snippet] ?? $this->defaultSource;
        $this->compile();
    }

    public function toggleDarkPreview(): void
    {
        $this->darkPreview = !$this->darkPreview;
    }

    public function toggleAutoRun(): void
    {
        $this->autoRun = !$this->autoRun;
    }

    public function shareSnippet(): ?string
    {
        $encoded = base64_encode($this->source);
        return route('playground.shared', ['code' => $encoded]);
    }

    public function getSnippetsProperty(): array
    {
        return $this->getSnippets();
    }

    private function getSnippets(): array
    {
        return [
            'button-basic' => <<<'BLADE'

    Primary Button
</gsmui:button>

    Ghost Button
</gsmui:button>

    Small Danger
</gsmui:button>
BLADE,
            'input-basic' => <<<'BLADE'
<gsmui:input
    wire:model="name"
    label="Full Name"
    placeholder="Enter your name"
/>

<gsmui:input
    wire:model="email"
    type="email"

    placeholder="you@example.com"
    invalid="Please enter a valid email"
/>
BLADE,
            'card-basic' => <<<'BLADE'
```

### 5.2 `PlaygroundShared` Livewire Component

```php
<?php

namespace App\Livewire;

use Livewire\Component;

class PlaygroundShared extends Component
{
    public string $source = '';
    public string $compiledHtml = '';
    public ?string $compileError = null;

    public function mount(string $code): void
    {
        $this->source = base64_decode($code, true) ?: '';
    }

    public function boot(): void
    {
        if (!empty($this->source)) {
            $result = $this->compileBlade($this->source);
            if ($result['success']) {
                $this->compiledHtml = $result['html'];
            } else {
                $this->compileError = $result['error'];
            }
        }
    }

    public function render()
    {
        return view('playground.shared');
    }
}
```

### 6.2 Playground JavaScript Module

```javascript
// resources/js/playground.js — Monaco initialization and editor logic
import * as monaco from 'monaco-editor';

export function playground() {
    return {
        charCount: 0,

        init() {
            this.charCount = this.$wire.source.length;

            // Update char count when source changes
            this.$watch('$wire.source', (value) => {
                this.charCount = value.length;
            });
        },
    };
}

// Register custom Monaco theme for GsmUi
monaco.editor.defineTheme('gsmui-dark', {
    base: 'vs-dark',
    inherit: true,
    rules: [
        { token: 'tag', foreground: 'f87171' },
        { token: 'attribute.name', foreground: 'fbbf24' },
        { token: 'attribute.value', foreground: '4ade80' },
        { token: 'comment', foreground: '6b7280', fontStyle: 'italic' },
        { token: 'keyword', foreground: 'a78bfa' },
    ],
    colors: {
        'editor.background': '#18181b',
        'editor.foreground': '#fafafa',
        'editorLineNumber.foreground': '#52525b',
        'editorCursor.foreground': '#60a5fa',
        'editor.selectionBackground': '#3b82f633',
    },
});
```

## 8. State Management

### 8.1 Editor State Flow

```text
User types in Monaco
    │
    ▼
Monaco 'onDidChangeModelContent' event
    │
    ├──▶ $wire.set('source', editor.getValue())  [Livewire sync]
    │
    └──▶ $el.dispatchEvent(new CustomEvent('source-change'))
              │
              ▼
         Debounce 400ms (if autoRun enabled)
              │
              ▼
         $wire.call('compile')
              │
              ▼
         Server-side Blade compilation
              │
              ├──▶ $this->compiledHtml = result
              └──▶ $this->compileError = error
                        │
                        ▼
                  Browser re-renders preview region
```

### 8.2 Persistent State

Playground state persists across page refreshes via `localStorage`:

```javascript
// Save editor state to localStorage
function savePlaygroundState(source, variant) {
    localStorage.setItem('gsmui-playground', JSON.stringify({
        source,
        variant,
        timestamp: Date.now(),
    }));
}

// Restore editor state from localStorage
function restorePlaygroundState() {
    const stored = localStorage.getItem('gsmui-playground');
    if (stored) {
        const { source, variant, timestamp } = JSON.parse(stored);
        // Only restore if less than 24 hours old
        if (Date.now() - timestamp < 86400000) {
            return { source, variant };
        }
    }
    return null;
}
```

## 12. Security Considerations

### 12.1 Source Code Sanitization

```php
// Block dangerous patterns in playground source
private array $blockedPatterns = [
    '@php',
    '@verbatim',
    '@inject',
    'artisan',
    'exec(',
    'system(',
    'passthru(',
    'shell_exec(',
    'proc_open(',
    'popen(',
    'file_get_contents(',
    'file_put_contents(',
    'fopen(',
    'fwrite(',
    'unlink(',
    'rmdir(',
    'chmod(',
    'chown(',
    'eval(',
    'base64_decode(',
    'curl_',
    'fsockopen(',
    'stream_socket_client(',
];

private function sanitizeSource(string $source): string
{
    foreach ($this->blockedPatterns as $pattern) {
        if (Str::containsIgnoreCase($source, $pattern)) {
            throw new \InvalidArgumentException(
                "The pattern '{$pattern}' is not allowed in the playground."
            );
        }
    }

    if (strlen($source) > 10000) {
        throw new \InvalidArgumentException('Source exceeds maximum length.');
    }

    if (substr_count($source, '@') > 50) {
        throw new \InvalidArgumentException('Too many Blade directives.');
    }

    return $source;
}
```

### 12.2 Execution Sandbox

- Compile in a separate PHP process with `proc_open()`.
- Set `memory_limit` to 16MB and `max_execution_time` to 5 seconds.
- Output is captured via `ob_start()` / `ob_get_clean()`.
- No access to `$_SERVER`, `$_ENV`, `$_SESSION`, or application singletons.

## 16. Multi-File Playground

### 16.1 Tab Management

```php
// Playground state supports multiple tabs/files
class Playground extends Component
{
    public array $tabs = [];
    public int $activeTabIndex = 0;
    public int $nextTabId = 1;

    public function addTab(string $name = '', string $source = ''): void
    {
        $this->tabs[] = [
            'id' => $this->nextTabId++,
            'name' => $name ?: __('Untitled :count', ['count' => $this->nextTabId]),
            'source' => $source,
            'isDirty' => false,
        ];
        $this->activeTabIndex = count($this->tabs) - 1;
    }

    public function closeTab(int $tabId): void
    {
        $this->tabs = array_values(array_filter($this->tabs, fn ($t) => $t['id'] !== $tabId));

        if ($this->activeTabIndex >= count($this->tabs)) {
            $this->activeTabIndex = max(0, count($this->tabs) - 1);
        }
    }

    public function switchTab(int $index): void
    {
        if (isset($this->tabs[$index])) {
            $this->activeTabIndex = $index;
            $this->source = $this->tabs[$index]['source'];
        }
    }

    public function renameTab(int $tabId, string $newName): void
    {
        foreach ($this->tabs as &$tab) {
            if ($tab['id'] === $tabId) {
                $tab['name'] = $newName;
                break;
            }
        }
    }
}
```

## 21. Performance Monitoring

### 21.1 Compile Time Tracking

```php
// Track compile performance
public function compile(): void
{
    $start = microtime(true);

    $this->isCompiling = true;
    $this->compileError = null;
    $this->compiledHtml = '';

    try {
        $result = $this->compileBlade($this->source);

        if ($result['success']) {
            $this->compiledHtml = $result['html'];
            $this->compileCount++;
        } else {
            $this->compileError = $result['error'];
        }
    } catch (\Exception $e) {
        $this->compileError = $e->getMessage();
    } finally {
        $this->isCompiling = false;
        $this->lastCompileTime = round((microtime(true) - $start) * 1000, 1);
    }
}
```

## 22. Error Recovery

### 22.1 Auto-Recovery from Compile Errors

```php
// When a compile error occurs, suggest fixes
public function getErrorSuggestions(): array
{
    if (!$this->compileError) return [];

    $suggestions = [];

    if (Str::contains($this->compileError, 'Unterminated')) {
        $suggestions[] = __('Check for unclosed tags or quotes.');
    }

    if (Str::contains($this->compileError, 'Undefined variable')) {
        $suggestions[] = __('Variables must be defined in the component or passed via mount().');
    }

    if (Str::contains($this->compileError, 'Class not found')) {
        $suggestions[] = __('Ensure the component name is correct and starts with "gsmui:".');
    }

    if (Str::contains($this->compileError, 'Maximum length')) {
        $suggestions[] = __('Try removing some code or splitting into smaller snippets.');
    }

    return $suggestions;
}
```

### 24.2 Popular Components Counter

```php
// Track which components are used most in playground
public function getPopularComponentsProperty(): array
{
    return Cache::remember('playground-popular-components', 3600, function () {
        $usage = Cache::pull('playground-usage', []);
        $components = [];

        foreach ($usage as $entry) {
            preg_match_all('/<gsmui:([a-z-]+)/', $entry['source'] ?? '', $matches);
            foreach ($matches[1] as $component) {
                $components[$component] = ($components[$component] ?? 0) + 1;
            }
        }

        arsort($components);
        return array_slice($components, 0, 10, true);
    });
}
```

## Open Questions / Risks

- Sandbox isolation: `srcdoc` iframe vs same-origin region? Affects CSP `frame-src`.
- Debounce vs explicit "Run" — both provided; default TBD.
- Monaco bundle adds weight to `dist/` — confirm it ships separately from `gsmui.js`.
- Consider adding a "Reset to example" button that loads a curated demo for beginners.
- Shared snippets via URL may hit URL length limits for large source code — consider hash-based sharing.
- Error line highlighting in Monaco requires mapping server-side error positions back to editor.
- Multi-file tabs: localStorage limit (5MB) may cap saved state. Confirm budget.
- Version history: 20 snapshots × 10KB average = 200KB storage. Confirm acceptable.
- Custom Monaco themes: confirm `defineTheme` API stability across Monaco versions.
- Mobile playground: Monaco performance on iOS Safari needs testing. Consider CodeMirror fallback.
- Playground analytics: GDPR compliance for session tracking. Confirm anonymous-only approach.
- Settings sync: should settings persist across devices via user profile? Defer to v2.
- Collaborative editing: real-time multiplayer playground — defer to v2.
- Playground embed: allow embedding playground in docs pages via `<iframe>`. Confirm CSP `frame-src`.
- Auto-complete for `gsmui:` component tags — requires Monaco language registration.
- Playground export: download compiled HTML as a standalone file. Confirm scope for v1.
- Monaco editor CSS: ensure dark mode styles don't conflict with `gsmui-dark` theme.
- Snippet marketplace: community-contributed snippets with upvoting — defer to v2.
- Playground offline support: service worker caching of Monaco bundle and last source. Confirm scope.
- Monaco TypeScript/JavaScript language mode: consider adding `.blade.php` as custom language for better highlighting.
- Playground URL shortener: convert long shared URLs to short slugs. Confirm infrastructure.
- Component playground mode: click any `gsmui:` component in docs to open it pre-loaded in playground.
- Playground undo/redo: confirm Monaco's built-in undo stack is sufficient or if Livewire state interferes.
- Playground syntax validation: real-time Blade syntax checking before compile. Confirm approach.
- Playground performance profiling: track render time, memory usage, and compile frequency.
- Playground clipboard integration: copy compiled HTML directly from preview pane.
- Playground snippet search: full-text search across all built-in snippets by name and content.

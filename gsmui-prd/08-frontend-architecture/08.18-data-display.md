# Purpose

Data-display components present structured information: tables, lists, cards, badges, avatars, stats, skeletons, and empty states. They are presentational, token-themed via `--gsmui-*`, and CSP-safe (inline SVG icons, no external images). Each follows the sizing/color conventions already established by `gsmui:badge` and `gsmui:avatar`.

---

## 1. `gsmui:table`

`stubs/resources/views/gsmui/table/index.blade.php`:

| Prop | Default | Purpose |
| --- | --- | --- |
| `sortable` | `false` | Enables `tbody` sort dispatcher |
| `striped` | `true` | Row striping |

Structure: outer `rounded-xl border ... bg-white dark:bg-zinc-800`, inner `overflow-x-auto`, `<thead class="bg-zinc-50 dark:bg-zinc-900/50">`. Sorting dispatches `table:sort` with `{key, direction}` for Livewire to handle. Responsive: horizontal scroll on small viewports (`08.14`).

## 2. `gsmui:badge`

`stubs/resources/views/gsmui/badge/index.blade.php` — color system reused across the library:

| Prop | Values |
| --- | --- |
| `variant` | `null` (soft) \| `solid` |
| `color` | `zinc,red,orange,amber,yellow,lime,green,emerald,teal,cyan,sky,blue,indigo,violet,purple,fuchsia,pink,rose` |
| `size` | `sm` \| `lg` \| default |
| `rounded` | bool → `rounded-full` |
| `icon` / `iconTrailing` | inline `<gsmui:icon variant="micro">` |

Soft variant: `bg-{color}-100 text-{color}-700 dark:bg-{color}-900/30 dark:text-{color}-300`. Solid: `bg-{color}-600 text-white`. Never hardcode hex outside the badge map; for status semantics reuse these tokens.

## 3. `gsmui:avatar`

`stubs/resources/views/gsmui/avatar/index.blade.php`:

| Prop | Purpose |
| --- | --- |
| `name` / `initials` | auto-derives initials (`AB` from "Alice Brown") |
| `src` | image URL (inline `<img>`, no CDN requirement) |
| `color` / `colorSeed` | `auto` hashes `crc32(seed)` → stable color |
| `size` | `xs`(6) `sm`(8) `lg`(12) `xl`(16) default(10) |
| `circle` | `rounded-full` |
| `badge` / `badgeColor` / `badgePosition` | status dot/number |

Auto-color palette mirrors `gsmui:badge` colors. `tooltip` prop wraps the avatar in `gsmui:tooltip`. Brand-embedded badge colors use hex literals intentionally (exempt from `--gsmui-*` theming, see `08.11`).

## 4. `gsmui:stat`

`stubs/resources/views/gsmui/stat/index.blade.php`:

| Prop | Purpose |
| --- | --- |
| `label` | muted heading + optional icon |
| `value` | large `tabular-nums` (rapid-width stability, AGENTS.md) |
| `change` / `changeType` | `positive`(green, arrow-up-right) / `negative`(red) / `neutral` |

Numeric values must use `tabular-nums` to prevent width jitter (`08.15` motion stability aside).

## 6. Accessibility for Data Display

- Tables: `<th scope>`, caption where needed; sortable headers expose `aria-sort`.
- Avatars with status: badge must have an `sr-only` label (e.g. "Online") — never color-only (`08.16`).
- Stats: `value` is text; pair trend with icon + sign, not color alone.
- Empty states must not be white-on-white; verify in both themes via Playwright (`08.16`).

## 7. Component Specifications

### 7.1 `gsmui:table` Full Specification

The table component is the primary way to display tabular data. It supports sorting, row actions, selection, pagination, and responsive horizontal scroll.

#### 7.1.1 HTML Structure

```html
<div data-gsmui-table class="rounded-xl border border-zinc-200 bg-white shadow-xs dark:border-white/10 dark:bg-zinc-800">
  <div class="overflow-x-auto">
    <table class="min-w-full divide-y divide-zinc-200 dark:divide-white/10">
      <thead class="bg-zinc-50 dark:bg-zinc-900/50">
        <tr>
          <th scope="col" class="px-4 py-3 text-left text-xs font-medium uppercase tracking-wider text-zinc-500">
            Name
          </th>
          <th scope="col" class="px-4 py-3 text-left text-xs font-medium uppercase tracking-wider text-zinc-500">
            Email
          </th>
          <th scope="col" class="relative px-4 py-3">
            <span class="sr-only">Actions</span>
          </th>
        </tr>
      </thead>
      <tbody class="divide-y divide-zinc-200 dark:divide-white/10">
        <tr class="hover:bg-zinc-50 dark:hover:bg-zinc-700/50">
          <td class="whitespace-nowrap px-4 py-3 text-sm text-zinc-900 dark:text-white">
            Alice Brown
          </td>
          <td class="whitespace-nowrap px-4 py-3 text-sm text-zinc-500">
            alice@example.com
          </td>
          <td class="whitespace-nowrap px-4 py-3 text-right text-sm">
            <!-- row actions -->
          </td>
        </tr>
      </tbody>
    </table>
  </div>
</div>
```

#### 7.1.2 Props

| Prop | Type | Default | Purpose |
|------|------|---------|---------|
| `sortable` | bool | `false` | Enable column sorting |
| `striped` | bool | `true` | Alternating row backgrounds |
| `selectable` | bool | `false` | Row selection checkboxes |
| `hoverable` | bool | `true` | Row hover highlight |
| `compact` | bool | `false` | Reduced padding |
| `bordered` | bool | `false` | Cell borders |

#### 7.1.3 Sortable Column

```blade
<gsmui:table :rows="$users" sortable>
    <gsmui:column key="name" sortable label="{{ __('Name') }}" />
    <gsmui:column key="email" sortable label="{{ __('Email') }}" />
    <gsmui:column key="created_at" sortable label="{{ __('Joined') }}" />
</gsmui:table>
```

Sorting dispatches a Livewire event:

```php
public function sort(string $key, string $direction): void
{
    $this->sortBy = $key;
    $this->sortDirection = $direction;
}
```

#### 7.1.4 Row Actions

```blade
<gsmui:table :rows="$users">
    <gsmui:column key="name">{{ __('Name') }}</gsmui:column>
    <gsmui:column key="actions" class="text-right">
        <gsmui:dropdown>
            <gsmui:button size="xs" icon="ellipsis-vertical" />
            <x-slot:content>
                <gsmui:dropdown-item wire:click="edit({{ $user->id }})">
                    {{ __('Edit') }}
                </gsmui:dropdown-item>
                <gsmui:dropdown-item wire:click="delete({{ $user->id }})" color="red">
                    {{ __('Delete') }}
                </gsmui:dropdown-item>
            </x-slot:content>
        </gsmui:dropdown>
    </gsmui:column>
</gsmui:table>
```

#### 7.1.5 Responsive Behavior

On small screens, the table becomes horizontally scrollable:

```html
<div class="overflow-x-auto">
  <table class="min-w-full">
    <!-- table content -->
  </table>
</div>
```

For very narrow screens, consider a card-based layout:

```blade
@if ($isMobile)
    @foreach ($users as $user)
        <gsmui:card class="mb-3">
            <p class="font-medium">{{ $user->name }}</p>
            <p class="text-sm text-zinc-500">{{ $user->email }}</p>
        </gsmui:card>
    @endforeach
@else
    <gsmui:table :rows="$users" />
@endif
```

### 7.3 `gsmui:avatar` Full Specification

#### 7.3.1 Auto-Initial Generation

```php
function getInitials(string $name): string
{
    $words = explode(' ', $name);
    $initials = '';
    foreach (array_slice($words, 0, 2) as $word) {
        $initials .= mb_strtoupper(mb_substr($word, 0, 1));
    }
    return $initials;
}

// "Alice Brown" → "AB"
// "Bob" → "B"
// "Charlie David Eve" → "CD"
```

#### 7.3.2 Auto-Color Generation

```php
function getAutoColor(string $seed): string
{
    $colors = [
        'red', 'orange', 'amber', 'yellow', 'lime', 'green',
        'emerald', 'teal', 'cyan', 'sky', 'blue', 'indigo',
        'violet', 'purple', 'fuchsia', 'pink', 'rose',
    ];
    $index = crc32($seed) % count($colors);
    return $colors[$index];
}

// "Alice" always gets the same color
// "Bob" always gets a different color
```

| Size | Width | Height | Text | Use Case |

| `sm` | `w-8` | `h-8` | `text-sm` | Comment authors, small avatars |
| default | `w-10` | `h-10` | `text-base` | User profiles, standard display |
| `lg` | `w-12` | `h-12` | `text-lg` | Featured users, cards |

## 15. Accessibility Deep-Dive

### 15.1 Table Accessibility

| Requirement | Implementation |
|-------------|----------------|
| `<th scope>` | Every header cell has `scope="col"` or `scope="row"` |
| Caption | `<caption>` when table has no surrounding context |
| Sortable headers | `aria-sort="ascending"`/`"descending"`/`"none"` |
| Row selection | `aria-selected` on `<tr>` elements |
| Row actions | Accessible name on action buttons |

### 15.2 Avatar Accessibility

| Requirement | Implementation |
|-------------|----------------|

| Requirement | Implementation |
|-------------|----------------|

## 16. Performance Considerations

### 16.1 Virtual Scrolling (Large Tables)

For tables with 1000+ rows, implement virtual scrolling:

```javascript
// Use a virtual scrolling library or implement manually
// Only render visible rows + buffer
const BUFFER_SIZE = 10
const ROW_HEIGHT = 48 // px

function getVisibleRange(scrollTop, containerHeight) {
  const start = Math.floor(scrollTop / ROW_HEIGHT) - BUFFER_SIZE
  const end = Math.ceil((scrollTop + containerHeight) / ROW_HEIGHT) + BUFFER_SIZE
  return { start: Math.max(0, start), end }
}
```

### 28.4 Infinite Scroll with Virtualization

```javascript
class VirtualList {
  constructor(container, items, itemHeight = 48) {
    this.container = container
    this.items = items
    this.itemHeight = itemHeight
    this.buffer = 10
    this.visibleCount = Math.ceil(container.clientHeight / itemHeight) + this.buffer * 2

    this.container.addEventListener('scroll', () => this.render())
    this.render()
  }

  render() {
    const scrollTop = this.container.scrollTop
    const startIndex = Math.max(0, Math.floor(scrollTop / this.itemHeight) - this.buffer)
    const endIndex = Math.min(this.items.length, startIndex + this.visibleCount)

    const visibleItems = this.items.slice(startIndex, endIndex)
    this.container.innerHTML = visibleItems.map((item, i) =>
      `<div style="position:absolute;top:${(startIndex + i) * this.itemHeight}px;height:${this.itemHeight}px;width:100%">
        ${this.renderItem(item)}
      </div>`
    ).join('')
  }

  renderItem(item) {
    return `<div class="p-3 border-b">${item.name}</div>`
  }
}
```

## 32. State Management for Data Display

### 32.1 Table State

```php
class UserIndex extends Component
{
    use WithPagination, WithSorting;

    public string $search = '';
    public string $status = '';
    public array $selected = [];
    public string $sortBy = 'created_at';
    public string $sortDirection = 'desc';
    public int $perPage = 15;

    public function getUsers(): LengthAwarePaginator
    {
        return User::query()
            ->when($this->search, fn ($q) => $q->where('name', 'like', "%{$this->search}%"))
            ->when($this->status, fn ($q) => $q->where('status', $this->status))
            ->orderBy($this->sortBy, $this->sortDirection)
            ->paginate($this->perPage);
    }

    public function updatedSearch(): void
    {
        $this->resetPage();
    }

    public function updatedStatus(): void
    {
        $this->resetPage();
    }
}
```

### 32.2 Filter State

```php
public array $filters = [
    'search' => '',
    'status' => '',
    'role' => '',
    'dateFrom' => '',
    'dateTo' => '',
];

public function applyFilters($query): Builder
{
    return $query
        ->when($this->filters['search'], fn ($q) => $q->where('name', 'like', "%{$this->filters['search']}%"))
        ->when($this->filters['status'], fn ($q) => $q->where('status', $this->filters['status']))
        ->when($this->filters['role'], fn ($q) => $q->where('role', $this->filters['role']))
        ->when($this->filters['dateFrom'], fn ($q) => $q->where('created_at', '>=', $this->filters['dateFrom']))
        ->when($this->filters['dateTo'], fn ($q) => $q->where('created_at', '<=', $this->filters['dateTo']));
}
```

### 32.3 Selection State

```php
public array $selected = [];
public bool $selectAll = false;

public function toggleSelectAll(): void
{
    $this->selectAll = !$this->selectAll;
    $this->selected = $this->selectAll
        ? $this->getUsers()->pluck('id')->toArray()
        : [];
}

public function updatedSelected(): void
{
    $this->selectAll = count($this->selected) === $this->getUsers()->total();
}
```

### 32.4 Sort State

```php
public string $sortBy = 'created_at';
public string $sortDirection = 'desc';

public function sort(string $column): void
{
    if ($this->sortBy === $column) {
        $this->sortDirection = $this->sortDirection === 'asc' ? 'desc' : 'asc';
    } else {
        $this->sortBy = $column;
        $this->sortDirection = 'asc';
    }
}
```

## 41. Open Questions / Risks

- `gsmui:table` sorting is client-dispatched but expects server sort — define the Livewire handler contract in `07.19`.
- Badge/avatar color maps are duplicated; consider a shared `--gsmui-palette-*` token set in `05.16-theme-engine.md` to DRY them.
- `gsmui:stat` `changeType` lacks an `icon` override; add for custom indicators.
- Virtual scrolling for large tables needs a shared implementation across table and list.
- Timeline component needs responsive layout (horizontal on desktop, vertical on mobile).
- Data grid needs drag-and-drop reordering for admin interfaces.
- Description list needs responsive column layout.
- Empty state needs illustration variants (SVG, not external images for CSP).
- Skeleton needs to match actual content shape for accurate loading perception.
- Badge needs tooltip for truncated text.
- Kanban board needs touch-friendly drag handles for mobile.
- Calendar view needs locale-aware week start (Sunday vs Monday).
- Gantt chart needs zoom controls for different time scales.
- Image gallery needs lightbox functionality.
- File preview needs PDF and video preview support.
- Chart needs dark mode color adaptation.
- Print styles need testing across browsers.
- Email-compatible components need Outlook testing.
- Table needs frozen column support for wide datasets.
- Badge needs animation variants for live updates.
- Avatar needs group stacking customization.

# 08.36 - Search UI

**Project:** GsmUi
**Section:** 08 - Frontend Architecture
**Framework:** Laravel 13 · Livewire 4 · Blade Components · GsmUi Component Library · Tailwind CSS v4 · Alpine.js
**Version:** 1.0.0

---

> See also: `05.03.03.02-navigation.md` (navigation and search placement in the IA). This document specifies the *frontend search component contract and results rendering*, and does NOT re-document navigation structure from 05.03.03.02.

# Purpose

The search UI provides a consistent, accessible search input and results surface across the docs portal, component explorer, and marketplace. It reuses the combobox pattern and the date-picker dialog/popover styling so it is visually and behaviorally identical to other GsmUi triggers. The command-palette variant is built on top of this same contract (see `08.41-command-palette.md`).

---

## 1. Search Input Contract

`stubs/resources/views/gsmui/search/index.blade.php` exposes `<gsmui:search>` as a combobox trigger:

```blade
<gsmui:search
    wire:model.live="query"
    :results="$results"
    placeholder="{{ __('Search components…') }}"
    size="md"
/>
```

- The `<input>` carries `role="combobox"`, `aria-expanded`, `aria-controls`, and `aria-autocomplete="list"` per AGENTS.md ARIA rules.
- Input shell copies `gsmui:input` outline classes: `bg-white dark:bg-white/10 border-zinc-200 border-b-zinc-300/80 dark:border-white/10 shadow-xs rounded-lg`.
- `cursor: text` across the whole container; action buttons (clear) use real `<gsmui:button>`.

## 2. Results Popover

Results reuse the verbatim dialog/popover class from AGENTS.md:

```blade
<div class="max-sm:max-h-full! rounded-xl shadow-xl sm:shadow-2xs max-sm:fixed! max-sm:inset-0! sm:backdrop:bg-transparent bg-white dark:bg-zinc-700 sm:border border-zinc-200 dark:border-white/10 p-3">
    @foreach ($results as $r)
        <a href="{{ $r->url }}" role="option" class="flex items-center gap-2 rounded-md px-2 py-1.5 hover:bg-zinc-100 dark:hover:bg-white/10">
            <x-dynamic-component :component="$r->icon" /> {{-- Heroicons/Lucide inline SVG --}}
            <span>{{ $r->title }}</span>
        </a>
    @endforeach
</div>
```

- Scroll is locked while the popover is open (copy the date-picker lock).
- Results list is a listbox (`role="listbox"`) with roving `tabindex` on options and `has-focus-visible:outline-2 has-focus-visible:outline-[-webkit-focus-ring-color]` on the focused item.
- Keyboard: ArrowUp/Down move through options, Enter navigates, Escape closes.

## 3. JavaScript Behavior

Per AGENTS.md, use `setAttribute`/`removeAttribute` from `utils.js`, observe `value` with a MutationObserver, and fire `input` + `change` on query commits. Debounce is handled Livewire-side with `wire:model.live` + `.debounce`.

## 5. Search Backend

### 5.1 Full-Text Search Engine

```php
// app/Services/SearchEngine.php
class SearchEngine
{
    public function __construct(
        private MeiliSearch\Client $client,
        private SearchIndexManager $indexManager,
    ) {}

    public function search(string $query, array $filters = [], int $limit = 20): SearchResultCollection
    {
        $results = $this->client->index('global_search')->search($query, [
            'limit' => $limit,
            'filter' => $this->buildFilters($filters),
            'attributesToHighlight' => ['title', 'description'],
            'attributesToCrop' => ['description:50'],
            'highlightPreTag' => '<mark class="bg-yellow-200 dark:bg-yellow-800">',
            'highlightPostTag' => '</mark>',
        ]);

        return SearchResultCollection::fromMeiliSearch($results);
    }

    public function index(Model $model): void
    {
        $index = $this->indexManager->getIndexForModel($model);
        $index->addDocuments([$model->toSearchableArray()]);
    }

    public function remove(Model $model): void
    {
        $index = $this->indexManager->getIndexForModel($model);
        $index->deleteDocument($model->getKey());
    }

    private function buildFilters(array $filters): array
    {
        $conditions = [];

        if (isset($filters['type'])) {
            $conditions[] = "type = '{$filters['type']}'";
        }

        if (isset($filters['domain'])) {
            $conditions[] = "domain = '{$filters['domain']}'";
        }

        if (isset($filters['tags'])) {
            $tags = implode(' OR ', array_map(fn ($t) => "tags = '{$t}'", $filters['tags']));
            $conditions[] = "({$tags})";
        }

        return $conditions;
    }
}
```

### 6.2 Recent Searches

```javascript
// assets/js/gsmui/search/recent.js
export class RecentSearches {
    constructor(storageKey = 'gsmui_recent_searches', maxItems = 10) {
        this.storageKey = storageKey;
        this.maxItems = maxItems;
    }

    get() {
        try {
            return JSON.parse(localStorage.getItem(this.storageKey)) || [];
        } catch {
            return [];
        }
    }

    add(query) {
        const recent = this.get().filter(r => r.query !== query);
        recent.unshift({
            query,
            timestamp: Date.now(),
        });

        if (recent.length > this.maxItems) {
            recent.pop();
        }

        localStorage.setItem(this.storageKey, JSON.stringify(recent));
        return recent;
    }

    remove(query) {
        const recent = this.get().filter(r => r.query !== query);
        localStorage.setItem(this.storageKey, JSON.stringify(recent));
        return recent;
    }

    clear() {
        localStorage.removeItem(this.storageKey);
        return [];
    }
}
```

## 7. Keyboard Navigation

### 7.1 Search Keyboard Shortcuts

```javascript
// assets/js/gsmui/search/keyboard.js
export class SearchKeyboard {
    constructor(searchInstance) {
        this.search = searchInstance;
        this.currentIndex = -1;
        this.bindGlobalShortcuts();
    }

    bindGlobalShortcuts() {
        document.addEventListener('keydown', (e) => {
            // Cmd/Ctrl + K to open search
            if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
                e.preventDefault();
                this.search.open();
            }

            // / to focus search (when not in input)
            if (e.key === '/' && !this.isInputFocused()) {
                e.preventDefault();
                this.search.focus();
            }
        });
    }

    bindListboxKeyboard(listbox) {
        listbox.addEventListener('keydown', (e) => {
            switch (e.key) {
                case 'ArrowDown':
                    e.preventDefault();
                    this.moveNext();
                    break;
                case 'ArrowUp':
                    e.preventDefault();
                    this.movePrevious();
                    break;
                case 'Home':
                    e.preventDefault();
                    this.moveToFirst();
                    break;
                case 'End':
                    e.preventDefault();
                    this.moveToLast();
                    break;
                case 'Enter':
                    e.preventDefault();
                    this.selectCurrent();
                    break;
                case 'Escape':
                    e.preventDefault();
                    this.search.close();
                    break;
            }
        });
    }

    moveNext() {
        const items = this.search.getResultItems();
        this.currentIndex = Math.min(this.currentIndex + 1, items.length - 1);
        this.updateActiveItem(items);
    }

    movePrevious() {
        const items = this.search.getResultItems();
        this.currentIndex = Math.max(this.currentIndex - 1, 0);
        this.updateActiveItem(items);
    }

    moveToFirst() {
        this.currentIndex = 0;
        this.updateActiveItem(this.search.getResultItems());
    }

    moveToLast() {
        const items = this.search.getResultItems();
        this.currentIndex = items.length - 1;
        this.updateActiveItem(items);
    }

    selectCurrent() {
        const items = this.search.getResultItems();
        if (items[this.currentIndex]) {
            items[this.currentIndex].click();
        }
    }

    updateActiveItem(items) {
        items.forEach((item, index) => {
            item.setAttribute('aria-selected', index === this.currentIndex);
            item.setAttribute('tabindex', index === this.currentIndex ? '0' : '-1');
            if (index === this.currentIndex) {
                item.scrollIntoView({ block: 'nearest' });
            }
        });
    }

    isInputFocused() {
        const active = document.activeElement;
        return active && (active.tagName === 'INPUT' || active.tagName === 'TEXTAREA');
    }
}
```

## 8. Search Analytics

### 8.1 Track Search Queries

```php
// app/Listeners/TrackSearchQuery.php
class TrackSearchQuery
{
    public function handle(SearchPerformed $event): void
    {
        $query = $event->query;
        $results = $event->results;

        // Log search for analytics
        SearchLog::create([
            'user_id' => auth()->id(),
            'query' => $query,
            'results_count' => $results->count(),
            'filters' => $event->filters,
            'duration_ms' => $event->durationMs,
        ]);

        // Update popular searches cache
        Cache::remember('popular_searches', 3600, fn () =>
            SearchLog::selectRaw('query, COUNT(*) as count')
                ->groupBy('query')
                ->orderByDesc('count')
                ->limit(10)
                ->pluck('count', 'query')
        );
    }
}
```

```php
// app/Http/Controllers/Api/SearchController.php
class SearchController extends Controller
{
    public function index(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'query' => 'required|string|min:2|max:200',
            'type' => 'nullable|string|in:component,page,marketplace,user,showcase',
            'domain' => 'nullable|string|in:docs,components,marketplace,community',
            'limit' => 'nullable|integer|min:1|max:50',
            'offset' => 'nullable|integer|min:0',
        ]);

        $startTime = microtime(true);

        $results = app(SearchEngine::class)->search(
            query: $validated['query'],
            filters: array_filter([
                'type' => $validated['type'] ?? null,
                'domain' => $validated['domain'] ?? null,
            ]),
            limit: $validated['limit'] ?? 20
        );

        $durationMs = (microtime(true) - $startTime) * 1000;

        // Track search for analytics
        event(new SearchPerformed(
            query: $validated['query'],
            results: $results,
            filters: $validated,
            durationMs: $durationMs,
            userId: auth()->id(),
        ));

        return response()->json([
            'data' => $results->toArray(),
            'meta' => [
                'total' => $results->total(),
                'query' => $validated['query'],
                'duration_ms' => round($durationMs, 2),
            ],
        ]);
    }

    public function suggest(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'query' => 'required|string|min:1|max:100',
        ]);

        $suggestions = app(SearchSuggester::class)->getSuggestions($validated['query']);

        return response()->json([
            'data' => $suggestions,
        ]);
    }

    public function recent(): JsonResponse
    {
        $recent = app(RecentSearches::class)->getForUser(auth()->id());

        return response()->json([
            'data' => $recent,
        ]);
    }

    public function clearRecent(): JsonResponse
    {
        app(RecentSearches::class)->clearForUser(auth()->id());

        return response()->json(['message' => 'Recent searches cleared']);
    }

    public function track(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'query' => 'required|string',
            'result_id' => 'required|string',
            'position' => 'required|integer|min:0',
        ]);

        event(new SearchResultClicked(
            query: $validated['query'],
            resultId: $validated['result_id'],
            position: $validated['position'],
            userId: auth()->id(),
        ));

        return response()->json(['ok' => true]);
    }
}
```

## 13. Search Livewire Component

### 13.1 Full Search Component

```php
// app/Livewire/Search/SearchBox.php
class SearchBox extends Component
{
    public string $query = '';
    public bool $isOpen = false;
    public bool $isLoading = false;
    public ?string $selectedType = null;
    public int $selectedIndex = -1;

    protected $listeners = [
        'search-open' => 'open',
        'search-close' => 'close',
    ];

    public function updatedQuery(string $value): void
    {
        if (strlen($value) >= config('gsmui-search.min_query_length')) {
            $this->performSearch();
        } else {
            $this->results = collect();
        }
    }

    public function performSearch(): void
    {
        $this->isLoading = true;

        try {
            $results = app(SearchEngine::class)->search(
                query: $this->query,
                filters: array_filter(['type' => $this->selectedType]),
                limit: config('gsmui-search.max_results', 20)
            );

            $this->results = $results;
        } finally {
            $this->isLoading = false;
        }
    }

    public function open(): void
    {
        $this->isOpen = true;
        $this->dispatch('search-opened');
    }

    public function close(): void
    {
        $this->isOpen = false;
        $this->query = '';
        $this->results = collect();
        $this->selectedIndex = -1;
        $this->dispatch('search-closed');
    }

    public function getResultsProperty(): Collection
    {
        return $this->results ?? collect();
    }

    public function getSuggestionsProperty(): array
    {
        if (strlen($this->query) < 1) {
            return app(RecentSearches::class)->getForUser(auth()->id());
        }

        return app(SearchSuggester::class)->getSuggestions($this->query);
    }

    public function render(): View
    {
        return view('livewire.search.search-box');
    }
}
```

```php
// app/Http/Middleware/SearchRateLimit.php
class SearchRateLimit
{
    public function handle(Request $request, Closure $next): Response
    {
        $key = 'search:' . ($request->user()?->id ?? $request->ip());
        $maxAttempts = $request->user() ? 60 : 20; // Per minute

        if (RateLimiter::tooManyAttempts($key, $maxAttempts)) {
            $retryAfter = RateLimiter::availableIn($key);

            return response()->json([
                'message' => 'Too many search requests.',
                'retry_after' => $retryAfter,
            ], 429);
        }

        RateLimiter::hit($key, 60);

        return $next($request);
    }
}
```

### 19.2 Debounce Configuration

```javascript
// assets/js/gsmui/search/debounce.js
export class SearchDebouncer {
    constructor(callback, delay = 300) {
        this.callback = callback;
        this.delay = delay;
        this.timeout = null;
    }

    search(query) {
        if (this.timeout) {
            clearTimeout(this.timeout);
        }

        this.timeout = setTimeout(() => {
            this.callback(query);
        }, this.delay);
    }

    cancel() {
        if (this.timeout) {
            clearTimeout(this.timeout);
            this.timeout = null;
        }
    }

    flush() {
        if (this.timeout) {
            clearTimeout(this.timeout);
            this.callback();
        }
    }
}
```

## 20. Caching Strategy

### 20.1 Search Result Caching

```php
// app/Services/SearchCache.php
class SearchCache
{
    public function __construct(
        private Repository $cache,
    ) {}

    public function remember(string $query, array $filters, int $ttl, callable $callback): SearchResultCollection
    {
        $key = $this->buildKey($query, $filters);

        return $this->cache->remember($key, $ttl, function () use ($callback) {
            return $callback();
        });
    }

    public function invalidate(string $query): void
    {
        $keys = $this->cache->tags(['search'])->getKeys();
        foreach ($keys as $key) {
            if (str_contains($key, md5($query))) {
                $this->cache->forget($key);
            }
        }
    }

    public function warmPopular(): void
    {
        $popular = SearchLog::selectRaw('query, COUNT(*) as count')
            ->groupBy('query')
            ->orderByDesc('count')
            ->limit(100)
            ->pluck('count', 'query');

        foreach ($popular as $query => $count) {
            $this->remember($query, [], 3600, function () use ($query) {
                return app(SearchEngine::class)->search($query);
            });
        }
    }

    private function buildKey(string $query, array $filters): string
    {
        return 'search:' . md5($query . json_encode($filters));
    }
}
```

```php
// app/Services/SearchHighlighter.php
class SearchHighlighter
{
    private string $preTag = '<mark class="bg-yellow-200 dark:bg-yellow-800 rounded px-0.5">';
    private string $postTag = '</mark>';

    public function highlight(string $text, string $query): string
    {
        $words = explode(' ', $query);
        $escaped = array_map(fn ($word) => preg_quote($word, '/'), $words);
        $pattern = '/(' . implode('|', $escaped) . ')/i';

        return preg_replace($pattern, $this->preTag . '$1' . $this->postTag, $text);
    }

    public function highlightArray(array $data, string $query, array $fields): array
    {
        foreach ($fields as $field) {
            if (isset($data[$field])) {
                $data["highlighted_{$field}"] = $this->highlight($data[$field], $query);
            }
        }

        return $data;
    }
}
```

### 24.2 Lazy Loading Results

```javascript
// Virtual scrolling for large result sets
export class VirtualScroller {
    constructor(container, items, itemHeight = 48) {
        this.container = container;
        this.items = items;
        this.itemHeight = itemHeight;
        this.visibleItems = Math.ceil(container.clientHeight / itemHeight) + 5;
        this.startIndex = 0;

        this.container.addEventListener('scroll', () => this.onScroll());
        this.render();
    }

    onScroll() {
        const scrollTop = this.container.scrollTop;
        const newStart = Math.floor(scrollTop / this.itemHeight) - 2;

        if (newStart !== this.startIndex) {
            this.startIndex = Math.max(0, newStart);
            this.render();
        }
    }

    render() {
        const endIndex = Math.min(this.startIndex + this.visibleItems, this.items.length);
        const visibleItems = this.items.slice(this.startIndex, endIndex);

        this.container.innerHTML = '';
        this.container.style.height = `${this.items.length * this.itemHeight}px`;

        visibleItems.forEach((item, index) => {
            const el = this.createItemElement(item);
            el.style.position = 'absolute';
            el.style.top = `${(this.startIndex + index) * this.itemHeight}px`;
            this.container.appendChild(el);
        });
    }
}
```

### 26.2 Filter State Management

```php
// app/Livewire/Search/SearchFilters.php
class SearchFilters extends Component
{
    public array $types = [];
    public array $categories = [];
    public string $dateRange = '';
    public string $sortBy = 'relevance';

    protected $listeners = [
        'filter-changed' => 'applyFilters',
    ];

    public function getActiveFilterCountProperty(): int
    {
        return count($this->types)
            + count($this->categories)
            + ($this->dateRange !== '' ? 1 : 0);
    }

    public function getActiveFiltersProperty(): array
    {
        return array_filter([
            'types' => $this->types ?: null,
            'categories' => $this->categories ?: null,
            'dateRange' => $this->dateRange ?: null,
            'sortBy' => $this->sortBy !== 'relevance' ? $this->sortBy : null,
        ]);
    }

    public function clearFilters(): void
    {
        $this->types = [];
        $this->categories = [];
        $this->dateRange = '';
        $this->sortBy = 'relevance';

        $this->dispatch('filters-cleared');
    }

    public function render(): View
    {
        return view('livewire.search.search-filters');
    }
}
```

```javascript
// assets/js/gsmui/search/shortcuts.js
export class SearchShortcuts {
    constructor(searchInstance) {
        this.search = searchInstance;
        this.shortcuts = new Map();
        this.init();
    }

    init() {
        this.register('ctrl+k', () => this.search.open());
        this.register('meta+k', () => this.search.open());
        this.register('escape', () => this.search.close());
        this.register('/', () => this.search.focus(), () => !this.isInputFocused());

        // Results navigation
        this.register('arrowdown', () => this.search.moveNext(), () => this.search.isOpen);
        this.register('arrowup', () => this.search.movePrevious(), () => this.search.isOpen);
        this.register('enter', () => this.search.selectCurrent(), () => this.search.isOpen);
        this.register('ctrl+enter', () => this.search.openInNewTab(), () => this.search.isOpen);

        document.addEventListener('keydown', (e) => this.handleKeydown(e));
    }

    register(shortcut, callback, condition = null) {
        this.shortcuts.set(shortcut, { callback, condition });
    }

    handleKeydown(event) {
        const key = this.getKeyString(event);
        const shortcut = this.shortcuts.get(key);

        if (shortcut) {
            if (!shortcut.condition || shortcut.condition()) {
                event.preventDefault();
                shortcut.callback();
            }
        }
    }

    getKeyString(event) {
        const parts = [];
        if (event.ctrlKey) parts.push('ctrl');
        if (event.metaKey) parts.push('meta');
        if (event.shiftKey) parts.push('shift');
        if (event.altKey) parts.push('alt');
        parts.push(event.key.toLowerCase());
        return parts.join('+');
    }

    isInputFocused() {
        const active = document.activeElement;
        return active && (active.tagName === 'INPUT' || active.tagName === 'TEXTAREA');
    }
}
```

```php
// app/Services/SearchMetrics.php
class SearchMetrics
{
    public function recordSearch(string $query, int $durationMs, int $resultCount): void
    {
        // StatsD metrics
        statsd_increment('search.queries');
        statsd_timing('search.duration', $durationMs);
        statsd_gauge('search.result_count', $resultCount);

        // Slow query detection
        if ($durationMs > 500) {
            Log::warning('Slow search query', [
                'query' => $query,
                'duration_ms' => $durationMs,
            ]);
        }

        // Zero results tracking
        if ($resultCount === 0) {
            statsd_increment('search.zero_results');
        }
    }
}
```

**Project:** GsmUi
**Section:** 08 - Frontend Architecture
**Framework:** Laravel 13 · Livewire 4 · Blade Components · GsmUi Component Library · Tailwind CSS v4 · Vite · Alpine.js · Monaco Editor (Playground)
**Version:** 1.0.0

> See also: `05.18-docs-engine.md` (documentation engine and prose/code split). This document specifies the *frontend highlighting contract and Monaco integration*, and does NOT re-document the docs content model from 05.18.

# Purpose

GsmUi needs two highlighting paths: a lightweight, dependency-free highlighter for documentation code blocks (CSP-safe, no CDN, no `eval`), and the full Monaco Editor for the interactive Playground. Both share a `<gsmui:code>` Blade component and a token-driven theme so light/dark parity matches the design token engine.

---

## 1. Lightweight Highlighter (Docs)

For docs, ship a self-hosted highlighter bundled in `dist/gsmui.js` — no Prism/CDN. It targets the common web languages (php, blade, js, css, json, bash) using a precompiled grammar table, not a runtime parser fetched over the network.

`stubs/resources/views/gsmui/code/index.blade.php`:

```blade
<pre x-data x-init="$nextTick(() => Gsmui.highlight($el))"
     class="bg-zinc-900 text-zinc-100 rounded-lg p-4 overflow-x-auto text-sm">
    <code class="language-{{ $language }}">{{ $slot }}</code>
</pre>
```

- Styling uses `--gsmui-*` tokens (`--gsmui-code-bg`, `--gsmui-code-fg`, `--gsmui-code-keyword`).
- Generated HTML is escaped server-side; the highlighter only adds `<span>` wrappers, never injects executable content.
- ARIA: the `<pre>` carries `aria-label="{{ __('Code sample') }}"` set from Blade via `__()`.

## 2. Monaco Playground

The Playground uses Monaco with a self-hosted worker. Per CSP, declare `worker-src 'self'` in `stubs/config/gsmui-pro-csp.php` if the editor worker is enabled.

```blade
<gsmui:editor
    wire:model="source"
    language="php"
    :read-only="$locked"
    size="lg"
/>
```

- Monaco assets are bundled under `dist/editor.js` + `dist/editor.css`; the worker is served from `dist/` (not `blob:`).
- Focus ring on the editor host follows AGENTS.md: `has-focus-visible:outline-2 has-focus-visible:outline-[-webkit-focus-ring-color]` since the host is a custom `tabindex="0"` element.
- `input` + `change` events fire on content commit so Livewire `wire:model` stays in sync.

## 3. Theme Alignment

The highlighter and Monaco both read `--gsmui-*` variables so a single theme switch (05.04) recolors every code surface. A `Gsmui::classes()` merge keeps consumer `class` overrides on top of base.

## 5. Lightweight Highlighter Implementation

### 5.1 Grammar Engine

The lightweight highlighter uses a regex-based tokenizer that runs entirely in the browser. No server-side processing, no network requests, no `eval()`.

```javascript
// assets/js/gsmui/highlighter/highlighter.js
export class Highlighter {
    constructor() {
        this.grammars = new Map();
        this.cache = new Map();
    }

    registerGrammar(language, grammar) {
        this.grammars.set(language, grammar);
    }

    highlight(code, language) {
        const cacheKey = `${language}:${code}`;
        if (this.cache.has(cacheKey)) {
            return this.cache.get(cacheKey);
        }

        const grammar = this.grammars.get(language);
        if (!grammar) {
            return this.escapeHtml(code);
        }

        const tokens = this.tokenize(code, grammar);
        const html = this.tokensToHtml(tokens);

        this.cache.set(cacheKey, html);
        return html;
    }

    tokenize(code, grammar) {
        const tokens = [];
        let remaining = code;
        let position = 0;

        while (remaining.length > 0) {
            let matched = false;

            for (const rule of grammar.rules) {
                const match = remaining.match(rule.pattern);
                if (match && match.index === 0) {
                    tokens.push({
                        type: rule.type,
                        value: match[0],
                        position,
                    });
                    remaining = remaining.slice(match[0].length);
                    position += match[0].length;
                    matched = true;
                    break;
                }
            }

            if (!matched) {
                // Accumulate plain text until next match
                const nextMatch = this.findNextMatch(remaining, grammar.rules);
                const plainText = nextMatch > 0 ? remaining.slice(0, nextMatch) : remaining;
                tokens.push({
                    type: TOKEN_TYPES.PLAIN,
                    value: plainText,
                    position,
                });
                remaining = remaining.slice(plainText.length);
                position += plainText.length;
            }
        }

        return tokens;
    }

    findNextMatch(text, rules) {
        let earliest = text.length;
        for (const rule of rules) {
            const match = text.match(rule.pattern);
            if (match && match.index < earliest) {
                earliest = match.index;
            }
        }
        return earliest;
    }

    tokensToHtml(tokens) {
        return tokens.map(token => {
            const className = TOKEN_CLASSES[token.type];
            if (className) {
                return `<span class="${className}">${this.escapeHtml(token.value)}</span>`;
            }
            return this.escapeHtml(token.value);
        }).join('');
    }

    escapeHtml(text) {
        const map = { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#039;' };
        return text.replace(/[&<>"']/g, c => map[c]);
    }
}
```

### 5.2 PHP Grammar

```javascript
// assets/js/gsmui/highlighter/grammars/php.js
export const phpGrammar = {
    name: 'php',
    rules: [
        // Comments
        {
            type: TOKEN_TYPES.COMMENT,
            pattern: /^\/\/[^\n]*/,
        },
        {
            type: TOKEN_TYPES.COMMENT,
            pattern: /^\/\*[\s\S]*?\*\//,
        },
        {
            type: TOKEN_TYPES.COMMENT,
            pattern: /^#[^\n]*/,
        },

        // Strings
        {
            type: TOKEN_TYPES.STRING,
            pattern: /^"(?:[^"\\]|\\.)*"/,
        },
        {
            type: TOKEN_TYPES.STRING,
            pattern: /^'(?:[^'\\]|\\.)*'/,
        },
        {
            type: TOKEN_TYPES.STRING,
            pattern: /^`(?:[^`\\]|\\.)*`/,
        },

        // Variables
        {
            type: TOKEN_TYPES.VARIABLE,
            pattern: /^\$[a-zA-Z_]\w*/,
        },

        // Numbers
        {
            type: TOKEN_TYPES.NUMBER,
            pattern: /^0[xXbBoO][0-9a-fA-F]+/,
        },
        {
            type: TOKEN_TYPES.NUMBER,
            pattern: /^\d+\.?\d*(?:[eE][+-]?\d+)?/,
        },

        // Keywords
        {
            type: TOKEN_TYPES.KEYWORD,
            pattern: /^(?:abstract|and|array|as|break|callable|case|catch|class|clone|const|continue|declare|default|die|do|echo|else|elseif|empty|enddeclare|endfor|endforeach|endif|endswitch|endwhile|eval|exit|extends|final|finally|fn|for|foreach|function|global|goto|if|implements|include|include_once|instanceof|insteadof|interface|isset|list|match|namespace|new|or|print|private|protected|public|readonly|require|require_once|return|static|switch|throw|trait|try|unset|use|var|while|xor|yield|yield from)\b/,
        },

        // Types
        {
            type: TOKEN_TYPES.TYPE,
            pattern: /^(?:int|float|string|bool|array|object|callable|iterable|void|never|self|parent|static|null|true|false)\b/,
        },

        // Functions
        {
            type: TOKEN_TYPES.FUNCTION,
            pattern: /^[a-zA-Z_]\w*(?=\s*\()/,
        },

        // Operators
        {
            type: TOKEN_TYPES.OPERATOR,
            pattern: /^(?:===|!==|==|!=|<=|>=|<=>|<|>|=>|\.\.\.|\?\?|\?->|\?\:|->|\:\:|\+\+|--|\*\*|\+=|-=|\*=|\/=|%=|&=|\|=|\^=|<<=|>>=|&&|\|\||!|~|\^|%|\*|\/|\+|-|\.|@)/,
        },

        // Punctuation
        {
            type: TOKEN_TYPES.PUNCTUATION,
            pattern: /^[(){}[\];:,\.]/,
        },
    ],
};
```

```javascript
// assets/js/gsmui/highlighter/grammars/blade.js
export const bladeGrammar = {
    name: 'blade',
    rules: [
        // Blade directives
        {
            type: TOKEN_TYPES.DIRECTIVE,
            pattern: /^@\w+/,
        },

            type: TOKEN_TYPES.ATTRIBUTE,
            pattern: /^wire:[a-zA-Z_.:-]+/,
        },
        {
            type: TOKEN_TYPES.ATTRIBUTE,
            pattern: /^:[a-zA-Z_]\w*/,
        },
        {
            type: TOKEN_TYPES.ATTRIBUTE,
            pattern: /^(?:class|id|style|href|src|alt|title|role|aria-\w+)(?==)/,
        },

        // CSS
        {
            type: TOKEN_TYPES.PROPERTY,
            pattern: /^(?:bg|text|border|shadow|rounded|p|m|flex|grid|gap|w|h|text-sm|text-base|text-lg|font-medium|font-bold|dark:|hover:|focus:|sm:|md:|lg:|xl:)[\w-]*/,
        },

        // JavaScript
        {
            type: TOKEN_TYPES.KEYWORD,
            pattern: /^(?:function|return|if|else|for|while|switch|case|break|continue|new|this|class|extends|import|from|export|default|const|let|var|async|await|yield)\b/,
        },

        // Strings (reuse PHP strings)
        {
            type: TOKEN_TYPES.STRING,
            pattern: /^"(?:[^"\\]|\\.)*"/,
        },
        {
            type: TOKEN_TYPES.STRING,
            pattern: /^'(?:[^'\\]|\\.)*'/,
        },

        // Variables
        {
            type: TOKEN_TYPES.VARIABLE,
            pattern: /^\$\w+/,
        },

        // Fallback: HTML entities and plain text
        {
            type: TOKEN_TYPES.PLAIN,
            pattern: /^[a-zA-Z0-9_]+/,
        },
    ],
};
```

```javascript
// assets/js/gsmui/code-navigation.js
export class CodeNavigation {
    constructor(element) {
        this.element = element;
        this.element.addEventListener('keydown', (e) => this.onKeyDown(e));
    }

    onKeyDown(event) {
        if (event.ctrlKey || event.metaKey) {
            switch (event.key) {
                case 'a':
                    event.preventDefault();
                    this.selectAll();
                    break;
                case 'c':
                    event.preventDefault();
                    this.copySelection();
                    break;
            }
        }
    }

    selectAll() {
        const range = document.createRange();
        range.selectNodeContents(this.element.querySelector('code'));
        const selection = window.getSelection();
        selection.removeAllRanges();
        selection.addRange(range);
    }

    copySelection() {
        const selection = window.getSelection();
        if (selection.toString()) {
            navigator.clipboard.writeText(selection.toString());
        }
    }
}
```

## 11. Performance Optimization

### 11.1 Token Caching

```javascript
// LRU cache for highlighted code
export class TokenCache {
    constructor(maxSize = 100) {
        this.cache = new Map();
        this.maxSize = maxSize;
    }

    get(key) {
        if (this.cache.has(key)) {
            const value = this.cache.get(key);
            // Move to end (most recently used)
            this.cache.delete(key);
            this.cache.set(key, value);
            return value;
        }
        return null;
    }

    set(key, value) {
        if (this.cache.has(key)) {
            this.cache.delete(key);
        } else if (this.cache.size >= this.maxSize) {
            // Delete oldest (first) entry
            this.cache.delete(this.cache.keys().next().value);
        }
        this.cache.set(key, value);
    }

    clear() {
        this.cache.clear();
    }
}
```

```javascript
// assets/js/gsmui/clipboard.js
export class ClipboardManager {
    static async copy(text) {
        try {
            await navigator.clipboard.writeText(text);
            return true;
        } catch (err) {
            // Fallback for older browsers
            return this.fallbackCopy(text);
        }
    }

    static fallbackCopy(text) {
        const textarea = document.createElement('textarea');
        textarea.value = text;
        textarea.style.position = 'fixed';
        textarea.style.opacity = '0';
        document.body.appendChild(textarea);
        textarea.select();

        try {
            document.execCommand('copy');
            return true;
        } catch (err) {
            return false;
        } finally {
            document.body.removeChild(textarea);
        }
    }

    static async read() {
        try {
            return await navigator.clipboard.readText();
        } catch (err) {
            return null;
        }
    }
}
```

```javascript
// assets/js/gsmui/code-diff.js
export class CodeDiff {
    constructor(original, modified) {
        this.original = original.split('\n');
        this.modified = modified.split('\n');
        this.diff = this.computeDiff();
    }

    computeDiff() {
        const result = [];
        let i = 0, j = 0;

        while (i < this.original.length || j < this.modified.length) {
            if (i < this.original.length && j < this.modified.length) {
                if (this.original[i] === this.modified[j]) {
                    result.push({ type: 'equal', line: this.original[i], originalLine: i + 1, modifiedLine: j + 1 });
                    i++; j++;
                } else {
                    result.push({ type: 'removed', line: this.original[i], originalLine: i + 1 });
                    result.push({ type: 'added', line: this.modified[j], modifiedLine: j + 1 });
                    i++; j++;
                }
            } else if (i < this.original.length) {
                result.push({ type: 'removed', line: this.original[i], originalLine: i + 1 });
                i++;
            } else {
                result.push({ type: 'added', line: this.modified[j], modifiedLine: j + 1 });
                j++;
            }
        }

        return result;
    }

    toHtml() {
        return this.diff.map(part => {
            const className = part.type === 'added' ? 'bg-green-900/30' :
                            part.type === 'removed' ? 'bg-red-900/30' : '';
            return `<div class="${className} px-4"><pre>${this.escapeHtml(part.line)}</pre></div>`;
        }).join('');
    }
}
```

## 37. Event System

### 37.1 Editor Events

```javascript
// assets/js/gsmui/editor-events.js
export class EditorEvents {
    constructor(editor) {
        this.editor = editor;
        this.listeners = new Map();
    }

    on(event, callback) {
        if (!this.listeners.has(event)) {
            this.listeners.set(event, []);
        }
        this.listeners.get(event).push(callback);
    }

    off(event, callback) {
        const callbacks = this.listeners.get(event) || [];
        this.listeners.set(event, callbacks.filter(cb => cb !== callback));
    }

    emit(event, data) {
        const callbacks = this.listeners.get(event) || [];
        callbacks.forEach(cb => cb(data));
    }

    // Monaco-specific events
    bindMonacoEvents() {
        this.editor.onDidChangeModelContent((e) => {
            this.emit('content-change', {
                content: this.editor.getValue(),
                changes: e.changes,
            });
        });

        this.editor.onDidChangeCursorPosition((e) => {
            this.emit('cursor-change', {
                position: e.position,
                selection: this.editor.getSelection(),
            });
        });

        this.editor.onDidChangeCursorSelection((e) => {
            this.emit('selection-change', {
                selection: e.selection,
                text: this.editor.getModel().getValueInRange(e.selection),
            });
        });

        this.editor.onDidFocusEditorText(() => {
            this.emit('focus');
        });

        this.editor.onDidBlurEditorText(() => {
            this.emit('blur');
        });
    }
}
```

```php
// app/Livewire/Playground.php
class Playground extends Component
{
    public string $code = '';
    public string $output = '';
    public string $error = '';
    public string $language = 'php';

    protected $listeners = [
        'editor:content-change' => 'onContentChange',
        'editor:cursor-change' => 'onCursorChange',
    ];

    public function onContentChange(array $payload): void
    {
        $this->code = $payload['content'];
    }

    public function onCursorChange(array $payload): void
    {
        // Update line/column indicator
        $this->dispatch('cursor-position-updated', [
            'line' => $payload['position']['lineNumber'],
            'column' => $payload['position']['column'],
        ]);
    }

    public function run(): void
    {
        try {
            $result = app(CodeExecutor::class)->execute($this->code, $this->language);
            $this->output = $result['output'];
            $this->error = $result['error'] ?? '';
        } catch (\Exception $e) {
            $this->error = $e->getMessage();
        }
    }
}
```

### 38.1 Snippet Management

```php
// app/Models/CodeSnippet.php
class CodeSnippet extends Model
{
    use HasFactory, SoftDeletes;

    protected $fillable = [
        'user_id', 'title', 'language', 'code',
        'output', 'is_public', 'parent_id',
    ];

    protected $casts = [
        'is_public' => 'boolean',
    ];

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }

    public function forks(): HasMany
    {
        return $this->hasMany(self::class, 'parent_id');
    }

    public function parent(): BelongsTo
    {
        return $this->belongsTo(self::class, 'parent_id');
    }

    public function scopePublic(Builder $query): Builder
    {
        return $query->where('is_public', true);
    }

    public function scopePopular(Builder $query): Builder
    {
        return $query->withCount('forks')->orderByDesc('forks_count');
    }
}
```

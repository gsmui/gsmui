# Purpose

This document defines the showcase platform: a public gallery of community-built sites/demos, the
submit flow (URL + thumbnail + description), the detail/view page with an embedded live preview,
and the moderation queue for admins. It reuses the gallery card pattern from `08.27`.

---

## 1. Page Composition

| Screen | GsmUi Components | Livewire |
| --- | --- | --- |
| Gallery | `gsmui:card`, `gsmui:search`, `gsmui:tabs` (sort) | `Showcase::index()` |
| Detail | `gsmui:frame` (preview), `gsmui:text`, `gsmui:rating` | `Showcase::view()` |
| Submit | `gsmui:modal` + `gsmui:input`, `gsmui:file-upload` | `Showcase::submit()` |
| Moderate | `gsmui:table`, `gsmui:button` (approve/reject) | `Moderation::queue()` |

## 2. Component Tree

```text
gsmui:layouts.app (or marketing)
└── <showcase gallery>
    ├── gsmui:search (wire:model.live="q")
    ├── gsmui:tabs (sort: newest/popular)
    └── gsmui:card × N
        ├── gsmui:image (self-hosted thumbnail)
        ├── gsmui:heading, gsmui:badge (tag)
        └── gsmui:button (view)

gsmui:modal (submit)
└── <form wire:submit="submit">
    ├── gsmui:input (wire:model="url")
    ├── gsmui:file-upload (thumbnail)
    └── gsmui:button (send)
```

## 3. Data Flow — Submit → Moderate → Publish

```text
gsmui:button "Submit"
        │  <form wire:submit="submit">
        ▼
Showcase::submit()  ──▶  queue for moderation (05.28)
        │
        ▼ (admin) Moderation::approve($id)  ──▶  published  ──▶  gsmui:toast

gsmui:frame (detail preview)
        │  srcdoc / same-origin render
        ▼
adoptedStyleSheets inject theme  ──▶  live preview (no CDN)
```

- Votes use `gsmui:rating` (read-only display) or a dedicated vote button — interactive rating is
  a separate component per AGENTS.md "separate component" rule.
- Thumbnails self-hosted only (`img-src 'self' data:`); `gsmui:file-upload` to same-origin storage.
- Modal scroll-lock mirrors date-picker pattern (`max-sm:fixed! max-sm:inset-0!`).

## 4. CSP & Styling

- Detail preview iframe uses `srcdoc` with inlined CSS (no external fetch; `connect-src 'self'`).
- Invalid URL input layered with `data-invalid:` classes; silent revert on validation fail.
- ARIA labels via `__()` (e.g. `__('Submit a showcase')`).

## 5. Gallery Card Design System

### 5.1 Card Layout Variants

The showcase gallery supports multiple card layouts to accommodate different content types and viewport sizes. Each layout variant maintains visual consistency while optimizing for the specific content being presented.

| Variant | Use Case | Breakpoint Behavior |
|---------|----------|-------------------|
| `grid` | Default gallery view | 1→2→3→4 columns |
| `list` | Search results, moderation | Single column, horizontal |
| `featured` | Homepage spotlight | Full-width hero card |
| `compact` | Sidebar widgets | Thumbnail + title only |

### 5.2 Card Responsive Behavior

Cards adapt their layout based on viewport width using Tailwind breakpoints:

```css
/* Card grid responsive progression */
.showcase-grid {
    display: grid;
    gap: 1rem;
    grid-template-columns: 1fr;           /* mobile: 1 column */
}

@media (min-width: 640px) {
    .showcase-grid {
        grid-template-columns: repeat(2, 1fr);  /* sm: 2 columns */
    }
}

@media (min-width: 768px) {
    .showcase-grid {
        grid-template-columns: repeat(3, 1fr);  /* md: 3 columns */
    }
}

@media (min-width: 1024px) {
    .showcase-grid {
        grid-template-columns: repeat(4, 1fr);  /* lg: 4 columns */
    }
}
```

**Card image aspect ratios by viewport:**
- Mobile: `aspect-video` (16:9) — maximizes vertical space
- Tablet: `aspect-[4/3]` — slightly taller for better preview
- Desktop: `aspect-video` (16:9) — standard preview ratio

### 6.2 Submit Livewire Component

```php
// app/Livewire/Showcase/SubmitModal.php
class SubmitModal extends Component
{
    public string $url = '';
    public string $title = '';
    public string $description = '';
    public ?int $categoryId = null;
    public ?UploadedFile $thumbnail = null;
    public int $currentStep = 0;
    public bool $showSubmitModal = false;
    public bool $isSubmitting = false;

    protected $rules = [
        'url' => 'required|url|max:2048',
        'title' => 'required|string|max:255',
        'description' => 'required|string|max:1000',
        'categoryId' => 'required|exists:categories,id',
        'thumbnail' => 'required|image|max:5120',
    ];

    public function getHasUnsavedChangesProperty(): bool
    {
        return $this->url !== '' || $this->title !== '' || $this->description !== '';
    }

    public function getCanProceedProperty(): bool
    {
        return match ($this->currentStep) {
            0 => $this->url !== '' && $this->title !== '' && $this->description !== '' && $this->categoryId !== null,
            1 => $this->thumbnail !== null,
            default => true,
        };
    }

    public function updatedUrl(string $value): void
    {
        // Auto-fetch title from URL metadata
        if (filter_var($value, FILTER_VALIDATE_URL)) {
            $this->dispatch('fetch-metadata', url: $value);
        }
    }

    public function nextStep(): void
    {
        $this->validateOnly(match ($this->currentStep) {
            0 => ['url', 'title', 'description', 'categoryId'],
            1 => ['thumbnail'],
        });

        if ($this->currentStep < 2) {
            $this->currentStep++;
        }
    }

    public function previousStep(): void
    {
        if ($this->currentStep > 0) {
            $this->currentStep--;
        }
    }

    public function removeThumbnail(): void
    {
        $this->thumbnail = null;
    }

    public function submit(): void
    {
        $this->validate();
        $this->isSubmitting = true;

        try {
            $showcase = Showcase::create([
                'user_id' => auth()->id(),
                'url' => $this->url,
                'title' => $this->title,
                'description' => $this->description,
                'category_id' => $this->categoryId,
                'status' => 'pending_moderation',
            ]);

            if ($this->thumbnail) {
                $showcase->addMedia($this->thumbnail)
                    ->usingName('thumbnail')
                    ->toMediaCollection('showcases');
            }

            $this->reset();
            $this->showSubmitModal = false;

            $this->dispatch('showcase-submitted', showcase: $showcase->id);
            $this->dispatch('toast', message: __('Showcase submitted for review!'), type: 'success');

        } catch (\Exception $e) {
            $this->dispatch('toast', message: __('Submission failed. Please try again.'), type: 'error');
        } finally {
            $this->isSubmitting = false;
        }
    }

    public function render(): View
    {
        return view('livewire.showcase.submit-modal', [
            'categories' => Category::where('is_active', true)->get(),
            'selectedCategory' => Category::find($this->categoryId),
        ]);
    }
}
```

## 9. Search & Filtering System

### 9.1 Search Implementation

The showcase search combines full-text search with faceted filtering. Results are returned via Livewire for real-time updates without page reloads.

```php
// app/Livewire/Showcase/Gallery.php
class Gallery extends Component
{
    public string $q = '';
    public ?int $categoryId = null;
    public string $sortBy = 'newest';
    public int $page = 1;

    protected $listeners = ['showcase-submitted' => '$refresh'];

    public function getResultsProperty(): Collection
    {
        $query = Showcase::query()
            ->where('status', 'approved')
            ->with(['user', 'category', 'tags']);

        // Full-text search
        if ($this->q !== '') {
            $query->where(function ($q) {
                $q->where('title', 'LIKE', "%{$this->q}%")
                  ->orWhere('description', 'LIKE', "%{$this->q}%")
                  ->orWhereHas('tags', function ($tagQuery) {
                      $tagQuery->where('name', 'LIKE', "%{$this->q}%");
                  });
            });
        }

        // Category filter
        if ($this->categoryId !== null) {
            $query->where('category_id', $this->categoryId);
        }

        // Sorting
        $query->orderBy(match ($this->sortBy) {
            'popular' => 'votes_count',
            'oldest' => 'created_at',
            default => 'created_at',
        }, $this->sortBy === 'oldest' ? 'asc' : 'desc');

        return $query->paginate(12, page: $this->page);
    }

    public function render(): View
    {
        return view('livewire.showcase.gallery', [
            'results' => $this->results,
            'categories' => Category::where('is_active', true)->get(),
        ])->layout('components.gsmui.layouts.app');
    }
}
```

### 10.2 Vote Backend

```php
// app/Models/Concerns/HasVotes.php
trait HasVotes
{
    public function votes(): HasMany
    {
        return $this->hasMany(Vote::class);
    }

    public function isVotedBy(?User $user): bool
    {
        if (!$user) return false;
        return $this->votes()->where('user_id', $user->id)->exists();
    }

    public function toggleVote(int $userId): bool
    {
        $exists = $this->votes()->where('user_id', $userId)->exists();

        if ($exists) {
            $this->votes()->where('user_id', $userId)->delete();
            $this->decrement('votes_count');
            return false;
        } else {
            $this->votes()->create(['user_id' => $userId]);
            $this->increment('votes_count');
            return true;
        }
    }
}
```

```php
class ShowcaseCache
{
    public function getFeatured(): Collection
    {

            Showcase::where('status', 'approved')
```

### 23.1 Input Validation

```php
// app/Actions/Showcase/ValidateSubmission.php
class ValidateSubmission
{
    public function execute(array $data): array
    {
        return Validator::make($data, [
            'url' => [
                'required',
                'url',
                'max:2048',
                Rule::in($this->allowedUrlPatterns()),
            ],
            'title' => 'required|string|max:255',
            'description' => 'required|string|max:1000',
            'categoryId' => 'required|exists:categories,id',
            'thumbnail' => 'required|image|max:5120|mimes:png,jpg,jpeg,webp',
        ])->validate();
    }

    private function allowedUrlPatterns(): array
    {
        return [
            'https://*',
            'http://localhost:*', // Development only
        ];
    }
}
```

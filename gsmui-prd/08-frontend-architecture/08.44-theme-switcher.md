# Purpose

`gsmui:theme-switcher` is the user-facing control that flips between light and dark (and optionally follows the OS). It is a thin Blade/JS wrapper around the toggle contract defined in `08.43-dark-mode.md` and the persistence layer in `06.30-themes.md`. This document pins its markup, states, ARIA, and event contract.

## 0. Architecture Overview

The theme switcher is a thin Blade/JS wrapper around the dark mode toggle contract defined in `08.43-dark-mode.md` and the persistence layer in `06.30-themes.md`. It provides a user-facing control for switching between light and dark modes.

### 0.1 Component Hierarchy


## 3. Markup & Trigger Pattern

Copy the trigger-button pattern verbatim from `date-picker/button.blade.php` (see `08.52-component-guidelines.md`):

```html
<button class="h-10 sm:h-8 text-base sm:text-sm rounded-lg ..." aria-haspopup="dialog">
  <!-- inline SVG icon (system font / inline SVG only, per CSP) -->
</button>
```

- **Native `<button>`** keeps the default cursor (NO `cursor-pointer` — cursor-pointer is for navigation only, per `AGENTS.md`).
- **ARIA:** button trigger uses `aria-haspopup="dialog"` (input trigger would use `role="combobox"` on the `<input>`). Follow the closest sibling pattern; do not invent.
- **Icon:** Heroicons/Lucide inline SVG only — no external icon font (CSP: `img-src 'self' data:`).

## 4. State Contract

| State | Behavior |
| --- | --- |
| `light` | `.dark` removed from `<html>` |
| `dark` | `.dark` added to `<html>` via `setAttribute` utility |
| `system` | Follows `matchMedia('(prefers-color-scheme: dark)')` live |

On change the component: (1) updates `<html>` class via `utils.js setAttribute`, (2) persists via `localStorage`, (3) dispatches `gsmui:theme-changed`, (4) if `wire:model` present, fires the Livewire round-trip to `06.30-themes.md`.

### 17.2 JavaScript Implementation

```javascript
class ThemeSwitcher {
  constructor(options = {}) {
    this.options = {
      storageKey: 'gsmui-theme',
      className: 'dark',
      ...options,
    };
    this.element = null;
  }

  init() {
    this.element = document.querySelector('[data-theme-switcher]');
    if (!this.element) return;

    this.element.addEventListener('click', () => this.toggle());
    this.element.addEventListener('keydown', (e) => {
      if (e.key === 'Enter' || e.key === ' ') {
        e.preventDefault();
        this.toggle();
      }
    });
  }

  toggle() {
    const current = this.get();
    const next = current === 'dark' ? 'light' : 'dark';
    this.set(next);
  }

  get() {
    return document.documentElement.classList.contains(this.options.className)
      ? 'dark'
      : 'light';
  }

  set(mode) {
    if (mode === 'dark') {
      document.documentElement.classList.add(this.options.className);
    } else {
      document.documentElement.classList.remove(this.options.className);
    }

    this.persist(mode);
    this.broadcast(mode);
  }

  persist(mode) {
    try {
      localStorage.setItem(this.options.storageKey, mode);
    } catch (e) {
      // localStorage unavailable
    }
  }

  broadcast(mode) {
    const event = new CustomEvent('gsmui:theme-changed', {
      detail: { mode },
      bubbles: true,
    });
    window.dispatchEvent(event);
  }
}

// Initialize
Gsmui.themeSwitcher = new ThemeSwitcher();
Gsmui.themeSwitcher.init();
```

### 17.3 Livewire Integration

```php
// In Livewire component
class ThemeSwitcher extends Component
{
    public $theme = 'light';

    public function mount()
    {
        $this->theme = session('gsmui-theme', 'light');
    }

    public function updatedTheme($value)
    {
        session(['gsmui-theme' => $value]);
        $this->dispatch('theme-changed', mode: $value);
    }
}
```

## 28. Appendix: Troubleshooting Guide

### 28.1 Common Issues

| Issue | Cause | Solution |
| --- | --- | --- |
| Mode not toggling | JavaScript disabled | Enable JavaScript |
| Mode not persisting | localStorage blocked | Use server-side persistence |

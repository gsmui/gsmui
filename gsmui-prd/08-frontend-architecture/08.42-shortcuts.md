# Purpose

The shortcuts system provides a single, declarative registry of keyboard shortcuts across the app, a consistent `<gsmui:kbd>` display primitive, and a help overlay listing all active shortcuts. It centralizes binding/unbinding so components never attach raw `keydown` listeners ad hoc, keeping behavior consistent with the command palette (08.41) and CSP-safe (no `eval`, self-hosted only).

## 0. Architecture Overview

The shortcuts system provides a centralized keyboard shortcut management layer for the entire GsmUi component library. It ensures consistent keyboard behavior across all components, prevents shortcut conflicts, and provides a user-friendly help overlay.

### 0.1 Component Hierarchy

```
ShortcutRegistry (core)
├── KeyboardListener (event handling)
├── ContextManager (scope management)
├── ConflictDetector (collision detection)
├── StorageManager (persistence)
├── HelpOverlay (UI display)
└── KbdComponent (display primitive)
```

### 0.2 Data Flow

```
Keyboard Event → Event Listener → Context Check → Shortcut Match → Handler Execution
                                         │
                                         ├── Global context
                                         ├── Component context
                                         └── Input field detection
```

### 0.3 Design Principles

1. **Centralized**: All shortcuts registered in one place
2. **Context-aware**: Shortcuts scoped to specific contexts
3. **Conflict-free**: Automatic conflict detection and resolution
4. **CSP-safe**: No `eval()`, no external scripts
5. **Accessible**: Full screen reader support
6. **Internationalized**: All strings localized via `__()`
7. **Persistent**: User customizations saved in localStorage
8. **Performant**: O(1) lookup, minimal event listener overhead

## 1. Shortcut Registry

A single `ShortcutRegistry` (frontend) maps `(combo, context) → handler`. Components register through the `Gsmui` facade helper rather than binding listeners directly.

```js
// assets/js/gsmui/shortcuts.js
Gsmui.shortcuts.register({
  combo: 'meta+k',
  context: 'global',
  handler: () => Gsmui.command.open(),
  description: 'Open command palette',
});
```

- Combos are normalized (`meta`/`ctrl`/`shift`/`alt` + key) into a canonical string for matching against `KeyboardEvent`.
- Handlers are first-party functions bundled in `dist/gsmui.js`; never `Function()`/`eval()`.
- `setAttribute`/`removeAttribute` from `utils.js` toggle `data-shortcuts-enabled` on `<body>` to globally disable when a modal (08.38) or editor (08.35) has focus.

## 2. `<gsmui:kbd>` Display

`stubs/resources/views/gsmui/kbd/index.blade.php`:

```blade
<gsmui:kbd keys="meta+k" />
```

- Renders each token as a `<kbd>` chip styled with `--gsmui-*` tokens: `border-zinc-200 dark:border-white/10 rounded-md px-1.5 py-0.5 text-xs bg-zinc-100 dark:bg-white/10`.
- Tokens are resolved to localized labels (e.g. `meta` → `⌘` on macOS, `Ctrl` elsewhere) in JS; the fallback English string is only a safety net (AGENTS.md JS localization rule).

## 6. Shortcut Conflict Resolution

### 6.1 Conflict Detection

When a new shortcut is registered, the system checks for conflicts:

```javascript
function detectConflict(combo, context, existingShortcuts) {
  const normalized = normalizeShortcut(combo);

  return existingShortcuts.filter((existing) => {
    const existingNormalized = normalizeShortcut(existing.combo);

    // Same key combination
    if (normalized.key !== existingNormalized.key) return false;

    // Overlapping modifiers
    const modifiersOverlap =
      (normalized.meta && existingNormalized.meta) ||
      (normalized.ctrl && existingNormalized.ctrl) ||
      (normalized.shift && existingNormalized.shift) ||
      (normalized.alt && existingNormalized.alt);

    // Same or broader context
    const contextOverlap =
      existing.context === 'global' ||
      context === 'global' ||
      existing.context === context;

    return modifiersOverlap && contextOverlap;
  });
}
```

### 6.2 Conflict Resolution Rules

| Rule | Description |
| --- | --- |
| Global wins over component | A `global` shortcut takes priority over a component-specific one |
| Last registered wins | If two shortcuts have the same combo and context, the last one wins |
| Explicit override | Components can explicitly override a shortcut with `override: true` |
| Conflict warning | Conflicts log a `console.warn` in development mode |

### 6.3 Browser Conflict Avoidance

| Shortcut | Browser Usage | GsmUi Handling |
| --- | --- | --- |
| `Ctrl+K` | Firefox search | Intercept first, `preventDefault()` |
| `Ctrl+L` | Chrome address bar | Not used by GsmUi |
| `Ctrl+T` | New tab | Not used by GsmUi |
| `Ctrl+W` | Close tab | Not used by GsmUi |
| `Ctrl+R` / `F5` | Refresh | Not used by GsmUi |
| `F12` | DevTools | Not used by GsmUi |
| `Ctrl+Shift+I` | DevTools | Not used by GsmUi |

## 7. Context System

### 7.1 Context Definitions

| Context | Scope | Example |
| --- | --- | --- |
| `global` | Always active | `Meta+K` for command palette |
| `palette` | When command palette is open | Arrow keys for navigation |
| `modal` | When a modal is open | Escape to close |
| `editor` | When Monaco editor is focused | Ctrl+S to save |
| `sidebar` | When sidebar is focused | Arrow keys for tree navigation |
| `page` | Page-specific shortcuts | Varies by route |

### 7.2 Context Priority

When multiple contexts have the same shortcut, priority is resolved:

```
1. focused-component (highest priority)
2. modal
3. editor
4. sidebar
5. page
6. global (lowest priority)
```

### 7.3 Context Switching

Contexts are activated/deactivated based on focus and state:

```javascript
function updateContexts() {
  const activeContexts = ['global']; // Always active

  if (document.querySelector('[data-gsmui-modal]')) {
    activeContexts.push('modal');
  }

  if (document.querySelector('[data-gsmui-editor-focused]')) {
    activeContexts.push('editor');
  }

  if (document.querySelector('[data-gsmui-sidebar-focused]')) {
    activeContexts.push('sidebar');
  }

  return activeContexts;
}
```

## 9. Keyboard Event Handling

### 9.1 Event Listener Setup

```javascript
function setupKeyboardListener() {
  document.addEventListener('keydown', handleKeydown, { capture: true });
}

function handleKeydown(event) {
  // Skip if shortcuts are disabled
  if (!isShortcutsEnabled()) return;

  // Skip if in an input field (unless shortcut is explicitly global)
  if (isInputFocused() && !isGlobalShortcut(event)) return;

  // Skip if IME is active
  if (event.isComposing) return;

  // Find matching shortcut
  const shortcut = findMatchingShortcut(event);

  if (shortcut) {
    event.preventDefault();
    if (shortcut.stopPropagation) {
      event.stopPropagation();
    }
    shortcut.handler(event);
  }
}
```

### 9.2 Input Field Detection

```javascript
function isInputFocused() {
  const activeElement = document.activeElement;
  if (!activeElement) return false;

  const tagName = activeElement.tagName.toLowerCase();
  const isInput = tagName === 'input' || tagName === 'textarea' || tagName === 'select';
  const isContentEditable = activeElement.contentEditable === 'true';
  const isMonaco = activeElement.closest('.monaco-editor');

  return isInput || isContentEditable || isMonaco;
}
```

### 9.3 IME Handling

```javascript
function isIMEActive(event) {
  return event.isComposing || event.keyCode === 229;
}

// Skip shortcuts during IME composition
function handleKeydown(event) {
  if (isIMEActive(event)) return;
  // ... rest of handler
}
```

### 9.4 Event Normalization

```javascript
function normalizeEvent(event) {
  return {
    key: event.key.toLowerCase(),
    meta: event.metaKey,
    ctrl: event.ctrlKey,
    shift: event.shiftKey,
    alt: event.altKey,
    code: event.code,
    isComposing: event.isComposing,
  };
}
```

## 13. Performance Considerations

### 13.1 Event Listener Cost

- Single `keydown` listener on `document` (event delegation)
- No per-shortcut listeners
- Listener is passive (no `preventDefault` unless shortcut matches)

### 13.2 Matching Algorithm

- Shortcuts are stored in a `Map` for O(1) lookup
- Matching iterates over active contexts only
- Priority sorting is done at registration time, not at match time

### 13.3 Memory Management

- Shortcuts are cleaned up on component destroy
- Event listeners are removed on destroy
- No memory leaks from closures

## 21. Detailed Implementation Notes

### 21.1 Keyboard Listener Architecture

The shortcuts system uses a single event listener on `document` for maximum efficiency:

```javascript
class KeyboardListener {
  constructor(registry) {
    this.registry = registry;
    this.listener = this.handleKeydown.bind(this);
    this.attached = false;
  }

  attach() {
    if (this.attached) return;
    document.addEventListener('keydown', this.listener, { capture: true });
    this.attached = true;
  }

  detach() {
    if (!this.attached) return;
    document.removeEventListener('keydown', this.listener, { capture: true });
    this.attached = false;
  }

  handleKeydown(event) {
    // Skip if shortcuts globally disabled
    if (!this.registry.isEnabled()) return;

    // Skip if IME is active
    if (event.isComposing || event.keyCode === 229) return;

    // Skip if in input field (unless explicitly enabled)
    if (this.isInputFocused() && !this.registry.options.enableInInputs) return;

    // Normalize event
    const normalized = this.normalizeEvent(event);

    // Find matching shortcut
    const shortcut = this.registry.findMatching(normalized);

    if (shortcut) {
      event.preventDefault();
      if (shortcut.stopPropagation) {
        event.stopPropagation();
      }
      shortcut.handler(event);
      this.registry.dispatch('execute', { combo: shortcut.combo, context: shortcut.context });
    }
  }

  isInputFocused() {
    const el = document.activeElement;
    if (!el) return false;

    const tag = el.tagName.toLowerCase();
    const isInput = tag === 'input' || tag === 'textarea' || tag === 'select';
    const isEditable = el.contentEditable === 'true';
    const isMonaco = el.closest('.monaco-editor');

    return isInput || isEditable || isMonaco;
  }

  normalizeEvent(event) {
    return {
      key: event.key.toLowerCase(),
      meta: event.metaKey,
      ctrl: event.ctrlKey,
      shift: event.shiftKey,
      alt: event.altKey,
      code: event.code,
    };
  }
}
```

    return this.activeContexts;
  }

    return this.activeContexts.includes(context);
  }

  getContextPriority(context) {
    return this.priority.indexOf(context);
  }

  sortByPriority(shortcuts) {
    return shortcuts.sort((a, b) => {

      const priorityB = this.getContextPriority(b.context);
      return priorityA - priorityB;
    });
  }
}

### 21.3 Conflict Detector

```javascript
class ConflictDetector {
  detect(combo, context, existingShortcuts) {
    const normalized = this.normalize(combo);

    return existingShortcuts.filter((existing) => {
      const existingNormalized = this.normalize(existing.combo);

      // Same key
      if (normalized.key !== existingNormalized.key) return false;

      // Overlapping modifiers
      const metaConflict = normalized.meta && existingNormalized.meta;
      const ctrlConflict = normalized.ctrl && existingNormalized.ctrl;
      const shiftConflict = normalized.shift && existingNormalized.shift;
      const altConflict = normalized.alt && existingNormalized.alt;

      const modifiersOverlap = metaConflict || ctrlConflict || shiftConflict || altConflict;

      // Same or broader context
      const contextOverlap =
        existing.context === 'global' ||
        context === 'global' ||
        existing.context === context;

      return modifiersOverlap && contextOverlap;
    });
  }

  normalize(combo) {
    const parts = combo.toLowerCase().split('+');
    const result = { meta: false, ctrl: false, shift: false, alt: false, key: null };

    parts.forEach((part) => {
      if (['meta', 'ctrl', 'shift', 'alt'].includes(part)) {
        result[part] = true;
      } else {
        result.key = part;
      }
    });

    return result;
  }

  resolve(conflicts, newShortcut) {
    // Last registered wins by default
    // If override is set, new shortcut wins
    if (newShortcut.override) {
      return { winner: 'new', conflicts };
    }

    return { winner: 'existing', conflicts };
  }
}
```

### 21.4 Storage Manager

```javascript
class StorageManager {
  constructor(options = {}) {
    this.key = 'gsmui-shortcuts';
    this.maxCustom = options.maxCustomShortcuts || 50;
    this.maxDisabled = options.maxDisabledShortcuts || 20;
    this.persistCustom = options.persistCustom !== false;
    this.persistDisabled = options.persistDisabled !== false;
  }

  load() {
    try {
      const data = localStorage.getItem(this.key);
      return data ? JSON.parse(data) : { custom: [], disabled: [], overrides: {} };
    } catch (e) {
      return { custom: [], disabled: [], overrides: {} };
    }
  }

  save(data) {
    try {
      localStorage.setItem(this.key, JSON.stringify(data));
    } catch (e) {
      // localStorage unavailable
    }
  }

  addCustom(shortcut) {
    if (!this.persistCustom) return;
    const data = this.load();
    if (data.custom.length >= this.maxCustom) return;
    data.custom.push(shortcut);
    this.save(data);
  }

  removeCustom(combo, context) {
    if (!this.persistCustom) return;
    const data = this.load();
    data.custom = data.custom.filter(
      (s) => !(s.combo === combo && s.context === context)
    );
    this.save(data);
  }

  addDisabled(combo) {
    if (!this.persistDisabled) return;
    const data = this.load();
    if (data.disabled.length >= this.maxDisabled) return;
    if (!data.disabled.includes(combo)) {
      data.disabled.push(combo);
      this.save(data);
    }
  }

  removeDisabled(combo) {
    if (!this.persistDisabled) return;
    const data = this.load();
    data.disabled = data.disabled.filter((c) => c !== combo);
    this.save(data);
  }

  isDisabled(combo) {
    const data = this.load();
    return data.disabled.includes(combo);
  }

  clear() {
    localStorage.removeItem(this.key);
  }
}
```

### 21.8 Performance Optimization

The shortcuts system is designed for minimal overhead:

1. **Single event listener**: One `keydown` listener on `document` instead of per-shortcut listeners
2. **O(1) lookup**: Shortcuts stored in a `Map` keyed by normalized combo
3. **Priority sorting at registration**: Not at match time
4. **Passive listener**: No `preventDefault` unless shortcut matches
5. **Lazy help overlay**: DOM built only when help is opened
6. **Minimal DOM operations**: Batch updates when possible

## 27. Appendix: Integration Guide

### 27.1 Registering Shortcuts in a Component

```javascript
// In your component's init method
init() {
  Gsmui.shortcuts.register({
    combo: 'ctrl+shift+f',
    context: 'my-component',
    handler: () => this.openFind(),
    description: 'Open find dialog',
  });
}

destroy() {
  Gsmui.shortcuts.unregister('ctrl+shift+f', 'my-component');
}
```

### 27.2 Using Context-Aware Shortcuts

```javascript
// Register for specific context
Gsmui.shortcuts.register({
  combo: 'enter',
  context: 'my-modal',
  handler: () => this.submit(),
  description: 'Submit form',
});

// Context is activated when modal opens
Gsmui.shortcuts.contextManager.activate('my-modal');

// Context is deactivated when modal closes
Gsmui.shortcuts.contextManager.deactivate('my-modal');
```

### 27.3 Overriding Existing Shortcuts

```javascript
// Override an existing shortcut
Gsmui.shortcuts.register({
  combo: 'meta+k',
  context: 'global',
  handler: () => this.customOpen(),
  description: 'Custom open',
  override: true, // Allows overriding existing shortcut
});
```

### 27.4 Disabling Shortcuts Programmatically

```javascript
// Disable a specific shortcut
Gsmui.shortcuts.disable('meta+k', 'global');

// Disable all shortcuts in a context
Gsmui.shortcuts.disableAll('editor');

// Disable all shortcuts globally
Gsmui.shortcuts.disableAll();
```

## 28. Appendix: Migration Guide

### 28.1 From Raw Event Listeners

**Before:**
```javascript
document.addEventListener('keydown', (e) => {
  if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
    e.preventDefault();
    openCommandPalette();
  }
});
```

**After:**
```javascript
Gsmui.shortcuts.register({
  combo: 'meta+k',
  context: 'global',
  handler: () => Gsmui.commandPalette.open(),
  description: 'Open command palette',
});
```

### 28.2 From Per-Component Listeners

**Before:**
```javascript
// In each component
element.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') {
    close();
  }
});
```

**After:**
```javascript
// Register once
Gsmui.shortcuts.register({
  combo: 'escape',
  context: 'my-component',
  handler: () => close(),
  description: 'Close',
});

// Unregister on destroy
Gsmui.shortcuts.unregister('escape', 'my-component');
```

# Purpose

This document defines the admin panel UI: the resource index/show/edit screens, the form binding
contract for `gsmui:` inputs, the modal-based create/edit flows, and the toast feedback cycle. It
establishes the canonical CRUD page composition reused by every admin resource.

---

## 1. Page Composition

Each admin resource is a Livewire component (`{Resource}Index`, `{Resource}Form`) rendered inside
the same `gsmui:layouts.app` shell as the dashboard. The index page is table-driven; the form page
is field-driven.

| Screen | GsmUi Components | Livewire |
| --- | --- | --- |
| Index | `gsmui:table`, `gsmui:pagination`, `gsmui:search`, `gsmui:dropdown` (row actions) | `{Resource}Index` |
| Create/Edit | `gsmui:field` + `gsmui:input`/`gsmui:select`/`gsmui:textarea`, `gsmui:button` | `{Resource}Form` |
| Confirm | `gsmui:modal`, `gsmui:button` | `$dispatch('confirm')` |
| Feedback | `gsmui:toast` | `session()` flash → `toast()` |

## 2. Component Tree (Index → Form)

```text
gsmui:layouts.app
└── <content>
    ├── gsmui:search (wire:model.live="search")
    ├── gsmui:table (:rows="$rows")
    │   └── gsmui:dropdown (row actions: edit/delete)
    └── gsmui:button (open create modal)

gsmui:modal (create/edit)
└── <form wire:submit="save">
    ├── gsmui:field label=...
    │   └── gsmui:input wire:model="form.name"  (data-invalid: on error)
    ├── gsmui:button type="submit"
    └── gsmui:button as="div" (cancel, nested-safe)
```

## 3. Data Flow to Livewire

```text
gsmui:input wire:model="form.name"
        │  input event (live validation)
        ▼
{Resource}Form::$form  ── validate() ──▶  error bag
        │                                     │
        │  server save (wire:submit)          ▼
        ▼                            data-invalid: class on field
toast("Saved")  ◀──  redirect / refresh $rows
```

- Alpine is used RARELY; interaction logic (disabled awareness, row-action coordination) is pushed
  to JS via `setAttribute`/`removeAttribute` from `utils.js`, not native DOM methods.
- `gsmui:button as="div"` is used only when nested inside another `<button>` (dropdown trigger).

## 4. Styling & CSP

- Inputs copy the `gsmui:input` outline variant: `bg-white dark:bg-white/10`,
  `border-zinc-200 border-b-zinc-300/80 dark:border-white/10`, `shadow-xs`, `rounded-lg`.
- No CDN/external resources — all icons via `gsmui:icon` (Heroicons/Lucide, inlined SVG) and
  dynamic CSS via `adoptedStyleSheets`, satisfying the strict CSP profile.

## 5. Livewire Component Specifications

### 5.1 `{Resource}Index` Livewire Component

```php
<?php

namespace App\Livewire\Admin\Resources;

use Livewire\Component;
use Livewire\WithPagination;
use Livewire\Attributes\Layout;
use Livewire\Attributes\On;
use Illuminate\Support\Facades\Auth;

#[Layout('gsmui::layouts.app')]
class UserIndex extends Component
{
    use WithPagination;

    public string $search = '';
    public string $sortBy = 'id';
    public string $sortDirection = 'desc';
    public int $perPage = 15;
    public array $selected = [];
    public bool $selectAll = false;
    public ?string $confirmDeleteId = null;
    public ?string $confirmBulkDelete = null;

    protected static array $listeners = [
        'deleteConfirmed' => 'deleteRow',
        'bulkDeleteConfirmed' => 'bulkDelete',
    ];

    protected function rules(): array
    {
        return [
            'search' => 'sometimes|string|max:255',
            'sortBy' => 'sometimes|string|in:id,name,email,created_at',
            'sortDirection' => 'sometimes|string|in:asc,desc',
            'perPage' => 'sometimes|integer|in:10,15,25,50',
        ];
    }

    public function updatedSearch(): void
    {
        $this->resetPage();
    }

    public function sortBy(string $field): void
    {
        if ($this->sortBy === $field) {
            $this->sortDirection = $this->sortDirection === 'asc' ? 'desc' : 'asc';
        } else {
            $this->sortBy = $field;
            $this->sortDirection = 'asc';
        }
        $this->resetPage();
    }

    public function toggleSelectAll(): void
    {
        if ($this->selectAll) {
            $this->selected = $this->rows->pluck('id')->toArray();
        } else {
            $this->selected = [];
        }
    }

    public function toggleSelect(string $id): void
    {
        if (in_array($id, $this->selected)) {
            $this->selected = array_filter($this->selected, fn($s) => $s !== $id);
        } else {
            $this->selected[] = $id;
        }
        $this->selectAll = count($this->selected) === $this->rows->count();
    }

    public function deleteRow(string $id): void
    {
        $model = $this->resolveModel();
        $model->findOrFail($id)->delete();
        $this->confirmDeleteId = null;
        $this->dispatch('toast', message: __('Deleted successfully.'));
    }

    public function bulkDelete(): void
    {
        $model = $this->resolveModel();
        $model->whereIn('id', $this->selected)->delete();
        $this->selected = [];
        $this->selectAll = false;
        $this->confirmBulkDelete = null;
        $this->dispatch('toast', message: __('Selected items deleted.'));
    }

    public function getRowsProperty()
    {
        $model = $this->resolveModel();

        return $model::query()
            ->when($this->search, fn($q) => $q->where('name', 'like', "%{$this->search}%"))
            ->orderBy($this->sortBy, $this->sortDirection)
            ->paginate($this->perPage);
    }

    private function resolveModel(): string
    {
        return match(class_basename($this)) {
            'UserIndex' => \App\Models\User::class,
            default => \App\Models\User::class,
        };
    }

    public function render()
    {
        return view('admin.resources.index', [
            'rows' => $this->rows,
        ]);
    }
}
```

### 5.2 `{Resource}Form` Livewire Component

```php
<?php

namespace App\Livewire\Admin\Resources;

use Livewire\Component;
use Livewire\Attributes\On;
use Livewire\Attributes\Validate;
use Illuminate\Support\Facades\Validator;

class UserForm extends Component
{
    public bool $showModal = false;
    public ?string $editingId = null;

    #[Validate('required|string|max:255')]
    public string $name = '';

    #[Validate('required|email|max:255')]
    public string $email = '';

    #[Validate('sometimes|string|in:admin,editor,viewer')]
    public string $role = 'viewer';

    #[Validate('sometimes|boolean')]
    public bool $active = true;

    public function openCreate(): void
    {
        $this->reset(['editingId', 'name', 'email', 'role', 'active']);
        $this->active = true;
        $this->showModal = true;
        $this->dispatch('focus:name');
    }

    public function openEdit(string $id): void
    {
        $model = $this->resolveModel();
        $record = $model::findOrFail($id);

        $this->editingId = $record->id;
        $this->name = $record->name;
        $this->email = $record->email;
        $this->role = $record->role;
        $this->active = $record->active;
        $this->showModal = true;
    }

    public function save(): void
    {
        $this->validate();

        $model = $this->resolveModel();

        if ($this->editingId) {
            $model::findOrFail($this->editingId)->update([
                'name' => $this->name,
                'email' => $this->email,
                'role' => $this->role,
                'active' => $this->active,
            ]);
            $this->dispatch('toast', message: __(':resource updated.', ['resource' => class_basename($model)]));
        } else {
            $model::create([
                'name' => $this->name,
                'email' => $this->email,
                'role' => $this->role,
                'active' => $this->active,
            ]);
            $this->dispatch('toast', message: __(':resource created.', ['resource' => class_basename($model)]));
        }

        $this->showModal = false;
        $this->dispatch('refreshRows');
    }

    public function updated(string $field): void
    {
        $this->validateOnly($field);
    }

    private function resolveModel(): string
    {
        return match(class_basename($this)) {
            'UserForm' => \App\Models\User::class,
            default => \App\Models\User::class,
        };
    }

    public function render()
    {
        return view('admin.resources.form');
    }
}
```

## 8. State Management Patterns

### 8.1 Livewire Property Wiring

Admin state flows through Livewire public properties. The canonical pattern:

| Pattern | Mechanism | Example |
| --- | --- | --- |
| Search filter | `wire:model.live.debounce.300ms` | `search` property on Index |
| Sort column | `wire:click="sortBy('field')"` | Sortable column headers |
| Pagination | `wire:model.live` | Per-page select |
| Form state | `wire:model` (eager) | Form fields bound to `$form` |
| Selection | `wire:model.live` | Checkbox `selected[]` array |
| Modal visibility | `wire:model.live` | `showModal` boolean toggle |
| Confirmation | `x-on:click="$dispatch('confirm')"` | Delete confirmations |

### 8.2 Cross-Component Communication

```text
Index Component
    ├── @on('refreshRows') → $this->refreshPage()
    ├── @dispatch('delete-confirm', ['id' => $id])
    │         └── Alpine → $wire.deleteRow($id)
    ├── @dispatch('toast', ['message' => '...'])
    │         └── Global toast listener
    └── @on('focus:name') → x-effect="$refs.nameInput.focus()"
```

### 8.3 Optimistic UI Patterns

When a user clicks delete or save, the UI should respond instantly:

```php
// In Livewire component
public function deleteRow(string $id): void
{
    // Optimistic: flash the row state before delete
    $deletedRow = $this->resolveModel()::find($id);
    $this->dispatch('rowRemoving', id: $id, data: $deletedRow);

    try {
        $deletedRow->delete();
        $this->dispatch('toast', message: __('Deleted successfully.'));
    } catch (\Exception $e) {
        // Rollback: re-render the row
        $this->dispatch('rowRestored', id: $id, data: $deletedRow);
        $this->dispatch('toast', message: __('Delete failed. Please try again.'));
    }
}
```

### 8.4 URL State Sync

Admin pages should sync critical state to the URL for bookmarkability:

```php
// In Livewire component — use WithBrowserHistory trait
use Livewire\WithBrowserHistory;

class UserIndex extends Component
{
    use WithBrowserHistory;

    public function updatingSearch(string $value): void
    {
        $this->updateBrowserHistory(['search' => $value]);
    }

    public function updatingSortBy(string $value): void
    {
        $this->updateBrowserHistory(['sortBy' => $value, 'sortDirection' => $this->sortDirection]);
    }

    public function boot(): void
    {
        $this->search = request()->query('search', '');
        $this->sortBy = request()->query('sortBy', 'id');
        $this->sortDirection = request()->query('sortDirection', 'desc');
    }
}
```

### 8.5 Debounce & Throttle Strategy

| Interaction | Strategy | Value | Rationale |
| --- | --- | --- | --- |
| Search typing | debounce | 300ms | Avoid flooding server on keystroke |
| Sort click | immediate | 0ms | Instant feedback on header click |
| Per-page change | immediate | 0ms | Page size is discrete, not continuous |
| Form field validation | debounce | 500ms | Validate after user pauses typing |
| Bulk selection | immediate | 0ms | Checkbox toggle is discrete |
| Window resize | throttle | 150ms | Recalculate layout bounds |

### 8.6 Error Recovery

```php
// Canonical error handling pattern for admin forms
public function save(): void
{
    try {
        $this->validate();
        $model = $this->resolveModel();

        if ($this->editingId) {
            $record = $model::findOrFail($this->editingId);
            $record->update($this->only(['name', 'email', 'role', 'active']));
        } else {
            $model::create($this->only(['name', 'email', 'role', 'active']));
        }

        $this->showModal = false;
        $this->dispatch('refreshRows');
        $this->dispatch('toast', message: __('Saved successfully.'));
    } catch (\Illuminate\Validation\ValidationException $e) {
        // Let Livewire handle validation errors — they map to data-invalid: automatically
        throw $e;
    } catch (\Exception $e) {
        $this->dispatch('toast', message: __('Something went wrong. Please try again.'), type: 'error');
    }
}
```

## 11. Toast System Specification

### 11.1 Toast Component

```php
// Livewire Toast component
<?php

namespace App\Livewire;

use Livewire\Component;

class Toast extends Component
{
    public array $toasts = [];
    public int $maxToasts = 5;
    public int $defaultDuration = 4000;

    protected static array $listeners = [
        'toast' => 'addToast',
    ];

    public function addToast(string $message, string $type = 'success', ?int $duration = null): void
    {
        $toast = [
            'id' => uniqid(),
            'message' => $message,
            'type' => $type, // success, error, warning, info
            'duration' => $duration ?? $this->defaultDuration,
        ];

        $this->toasts[] = $toast;

        if (count($this->toasts) > $this->maxToasts) {
            array_shift($this->toasts);
        }

        // Auto-dismiss
        $this->dispatch('toast-scheduled', id: $toast['id'], duration: $toast['duration']);
    }

    public function dismiss(string $id): void
    {
        $this->toasts = array_filter($this->toasts, fn($t) => $t['id'] !== $id);
    }

    public function render()
    {
        return view('components.toast');
    }
}
```


## 19. Security Considerations

### 19.1 CSRF Protection

All Livewire forms include CSRF tokens automatically. For manual AJAX endpoints:

```javascript
// From utils.js — all fetch calls include CSRF
fetch('/admin/api/users', {
    method: 'POST',
    headers: {
        'X-CSRF-TOKEN': document.querySelector('meta[name="csrf-token"]').content,
        'Content-Type': 'application/json',
        'Accept': 'application/json',
    },
    body: JSON.stringify(data),
});
```

### 19.2 XSS Prevention

- All Blade `{{ }}` expressions auto-escape HTML.
- Use `{!! !!}` only for pre-sanitized HTML (markdown-rendered content from a trusted source).
- `wire:model` values are sanitized server-side before display.
- Never pass user input to `x-html` or `{!! !!}` without `strip_tags()`.

### 23.2 CSV Export Livewire Method

```php
public function exportCsv(): void
{
    $model = $this->resolveModel();
    $rows = $model::query()
        ->when($this->search, fn($q) => $q->where('name', 'like', "%{$this->search}%"))
        ->orderBy($this->sortBy, $this->sortDirection)
        ->get();

    $headers = ['Content-Type' => 'text/csv'];
    $callback = function () use ($rows) {
        $handle = fopen('php://output', 'w');
        fputcsv($handle, ['ID', 'Name', 'Email', 'Role', 'Created At']);
        foreach ($rows as $row) {
            fputcsv($handle, [$row->id, $row->name, $row->email, $row->role, $row->created_at]);
        }
        fclose($handle);
    };

    $filename = strtolower(class_basename($model)) . '_' . now()->format('Y-m-d') . '.csv';
    return response()->stream($callback, 200, [
        'Content-Type' => 'text/csv',
        'Content-Disposition' => "attachment; filename=\"{$filename}\"",
    ]);
}
```

# 08.34 - Chart System

**Project:** GsmUi
**Section:** 08 - Frontend Architecture
**Framework:** Laravel 13 · Livewire 4 · Blade Components · GsmUi Component Library · Tailwind CSS v4 · Vite · Chart.js / ApexCharts / ECharts adapter
**Version:** 1.0.0

---

> See also: `05.30-chart-builder.md` (conceptual chart builder engine and chart schema). This document specifies the *frontend adapter contract and Blade/Livewire plumbing*, and does NOT re-document the chart data model or schema that lives in 05.30.

# Purpose

The chart system renders data visualizations on GsmUi surfaces (dashboards, admin reports, the component explorer showcase) through a single adapter interface that can be backed by Chart.js, ApexCharts, or ECharts. The contract is identical across backends so the `<gsmui:chart>` Blade component never changes when the engine is swapped. All chart libraries are self-hosted in `dist/` — no CDN, no `data:`/`blob:` executable content — to satisfy the strict CSP profile in AGENTS.md.

---

## 1. Adapter Strategy

A `ChartAdapterInterface` hides engine specifics behind a normalized `ChartConfig` DTO. The component receives a JSON-serializable config from Livewire and the adapter hydrates the engine instance.

```php
// app/Frontend/Charts/ChartAdapterInterface.php
interface ChartAdapterInterface
{
    public function name(): string;                 // 'chartjs' | 'apex' | 'echarts'
    public function render(array $config): string;  // returns canvas/svg mount HTML
    public function hydrate(string $mountId, array $config): void; // JS bootstrap payload
    public function supports(string $type): bool;   // 'line'|'bar'|'pie'|'radar'...
}
```

- The default adapter is chosen by the `Gsmui` facade: `Gsmui::chartAdapter()` resolves from config `gsmui.chart.driver`.
- `Gsmui::classes()` merges container classes so consumers can pass `class="..."` without breaking base styling.
- Engine bundles are emitted as separate `<script>` entries (`dist/chartjs.js`, `dist/apex.js`, `dist/echarts.js`) imported via Vite; only the active driver is loaded.

## 2. Blade Component Contract

`stubs/resources/views/gsmui/chart/index.blade.php` defines `<gsmui:chart>`:

```blade
<gsmui:chart
    type="line"
    :config="$chartConfig"   {{-- array, JSON-serializable --}}
    driver="chartjs"         {{-- optional, defaults to facade default --}}
    wire:model="selected"    {{-- optional selection binding --}}
    size="md"                {{-- xs|sm|md|lg|xl --}}
/>
```

- Container uses the input/surface tokens: `bg-white dark:bg-white/10 border-zinc-200 border-b-zinc-300/80 dark:border-white/10 shadow-xs rounded-lg p-3`.
- A `<canvas>` (Chart.js) or `<div>` mount (Apex/ECharts) is created with `x-ref` for the adapter.
- The `value` attribute (serialized config) is watched by a MutationObserver per AGENTS.md so Livewire config pushes re-render without a full reload.

## 3. JavaScript Lifecycle

Follow the AGENTS.md JS rules: use `setAttribute`/`removeAttribute` from `utils.js`, observe `value`, and fire `input` + `change` on user-driven updates (e.g. legend toggles, point selection).

```js
// assets/js/gsmui/chart.js
export default class Chart {
  constructor(root) {
    this.root = root;
    this.adapter = window.Gsmui.chart.adapter(this.root.dataset.driver);
    new MutationObserver(() => this.update()).observe(this.root, {
      attributes: true, attributeFilter: ['value'],
    });
    this.mount();
  }
  mount() { this.instance = this.adapter.hydrate(this.root, this.config()); }
  config() { return JSON.parse(this.root.getAttribute('value') || '{}'); }
  update() { this.instance.update(this.config()); this.emit(); }
  emit() { this.root.dispatchEvent(new Event('input')); this.root.dispatchEvent(new Event('change')); }
}
Gsmui.register('chart', Chart);
```

## 4. CSP-Safe Bundling

- No inline `<style>` for chart internals: engines style via `adoptedStyleSheets` injected from `dist/`.
- Tooltips/legends render with inline SVG icons only (Heroicons/Lucide), never external images.
- `connect-src 'self'` only — charts never call `fetch()`/`XHR`; data is provided in `value`.

```php
        }
```

### 6.2 Data Update Animation

```javascript
// assets/js/gsmui/chart-update.js
export class ChartUpdater {
    constructor(chartInstance, config) {
        this.instance = chartInstance;
        this.config = config;
        this.animationDuration = 750;
    }

    update(newData) {
        // Smooth transition between data states
        this.instance.data = this.transformData(newData);
        this.instance.update('active');
    }

    transition(newData) {
        // Animate between old and new data
        const oldData = { ...this.instance.data };
        const targetData = this.transformData(newData);

        this.animateData(oldData, targetData, this.animationDuration);
    }

    animateData(from, to, duration) {
        const startTime = performance.now();
        const animate = (currentTime) => {
            const elapsed = currentTime - startTime;
            const progress = Math.min(elapsed / duration, 1);

            // Easing function (ease-out cubic)
            const eased = 1 - Math.pow(1 - progress, 3);

            this.instance.data.datasets.forEach((dataset, i) => {
                if (to.datasets[i]) {
                    dataset.data = dataset.data.map((val, j) => {
                        const fromVal = from.datasets[i]?.data[j] ?? 0;
                        const toVal = to.datasets[i].data[j] ?? 0;
                        return fromVal + (toVal - fromVal) * eased;
                    });
                }
            });

            this.instance.update('none');

            if (progress < 1) {
                requestAnimationFrame(animate);
            }
        };

        requestAnimationFrame(animate);
    }

    transformData(config) {
        return {
            labels: config.data.labels,
            datasets: config.data.datasets.map(ds => ({
                ...ds,
                data: [...ds.data],
            })),
        };
    }
}
```

### 7.2 Theme Switching

```javascript
// assets/js/gsmui/chart-theme.js
export class ChartTheme {
    constructor(chartInstance) {
        this.instance = chartInstance;
        this.observer = new MutationObserver(() => this.onThemeChange());
        this.observer.observe(document.documentElement, {
            attributes: true,
            attributeFilter: ['class'],
        });
    }

    onThemeChange() {
        const isDark = document.documentElement.classList.contains('dark');
        const colors = this.getTokenColors(isDark);

        this.instance.options.plugins.legend.labels.color = colors.text;
        this.instance.options.scales.x.grid.color = colors.grid;
        this.instance.options.scales.y.grid.color = colors.grid;
        this.instance.options.scales.x.ticks.color = colors.textMuted;
        this.instance.options.scales.y.ticks.color = colors.textMuted;

        this.instance.update('none');
    }

    getTokenColors(isDark) {
        const root = getComputedStyle(document.documentElement);
        return {
            primary: root.getPropertyValue('--gsmui-chart-primary'),
            secondary: root.getPropertyValue('--gsmui-chart-secondary'),
            grid: isDark ? 'rgba(63, 63, 70, 0.5)' : 'rgba(228, 228, 231, 0.5)',
            text: isDark ? '#e4e4e7' : '#18181b',
            textMuted: isDark ? '#a1a1aa' : '#71717a',
        };
    }

    destroy() {
        this.observer.disconnect();
    }
}
```

### 9.2 Keyboard Navigation

```javascript
// assets/js/gsmui/chart-a11y.js
export class ChartAccessibility {
    constructor(chartInstance, element) {
        this.instance = chartInstance;
        this.element = element;
        this.currentPoint = -1;

        this.element.setAttribute('tabindex', '0');
        this.element.addEventListener('keydown', (e) => this.onKeyDown(e));
    }

    onKeyDown(event) {
        const dataset = this.instance.data.datasets[0];
        const pointCount = dataset.data.length;

        switch (event.key) {
            case 'ArrowRight':
                event.preventDefault();
                this.currentPoint = Math.min(this.currentPoint + 1, pointCount - 1);
                this.highlightPoint();
                break;
            case 'ArrowLeft':
                event.preventDefault();
                this.currentPoint = Math.max(this.currentPoint - 1, 0);
                this.highlightPoint();
                break;
            case 'Home':
                event.preventDefault();
                this.currentPoint = 0;
                this.highlightPoint();
                break;
            case 'End':
                event.preventDefault();
                this.currentPoint = pointCount - 1;
                this.highlightPoint();
                break;
        }
    }

    highlightPoint() {
        this.instance.setActiveElements([
            { datasetIndex: 0, index: this.currentPoint }
        ]);
        this.instance.update();

        // Announce to screen reader
        const label = this.instance.data.labels[this.currentPoint];
        const value = this.instance.data.datasets[0].data[this.currentPoint];
        this.announce(`${label}: ${value}`);
    }

    announce(message) {
        const announcement = document.createElement('div');
        announcement.setAttribute('role', 'status');
        announcement.setAttribute('aria-live', 'polite');
        announcement.className = 'sr-only';
        announcement.textContent = message;
        document.body.appendChild(announcement);
        setTimeout(() => announcement.remove(), 1000);
    }
}
```

## 10. Export & Print

### 10.1 PNG/SVG Export

```javascript
// assets/js/gsmui/chart-export.js
export class ChartExporter {
    constructor(chartInstance) {
        this.instance = chartInstance;
    }

    toPNG(filename = 'chart.png', pixelRatio = 2) {
        const url = this.instance.toBase64Image('image/png', pixelRatio);
        this.download(url, filename);
    }

    toSVG(filename = 'chart.svg') {
        const url = this.instance.toBase64Image('image/svg+xml');
        this.download(url, filename);
    }

    toDataCSV(filename = 'chart-data.csv') {
        const data = this.instance.data;
        const csv = this.generateCSV(data);
        const blob = new Blob([csv], { type: 'text/csv' });
        const url = URL.createObjectURL(blob);
        this.download(url, filename);
        URL.revokeObjectURL(url);
    }

    generateCSV(data) {
        const headers = ['Label', ...data.datasets.map(ds => ds.label)];
        const rows = data.labels.map((label, i) => [
            label,
            ...data.datasets.map(ds => ds.data[i]),
        ]);
        return [headers, ...rows].map(row => row.join(',')).join('\n');
    }

    download(url, filename) {
        const link = document.createElement('a');
        link.href = url;
        link.download = filename;
        link.click();
    }
}
```

```php
class RealtimeChart extends Component
```

### 13.2 Data Throttling

```javascript
// Throttle rapid data updates
export class DataThrottler {
    constructor(callback, delay = 100) {
        this.callback = callback;
        this.delay = delay;
        this.timeout = null;
        this.pendingData = null;
    }

    push(data) {
        this.pendingData = data;
        if (!this.timeout) {
            this.timeout = setTimeout(() => {
                this.callback(this.pendingData);
                this.timeout = null;
            }, this.delay);
        }
    }

    flush() {
        if (this.timeout && this.pendingData) {
            clearTimeout(this.timeout);
            this.callback(this.pendingData);
            this.timeout = null;
        }
    }
}
```

### 16.1 Factory Pattern

```php
// app/Factories/ChartFactory.php
class ChartFactory
{
    private array $adapters = [];

    public function __construct(
        private ConfigRepository $config,
    ) {
        $this->registerAdapters();
    }

    private function registerAdapters(): void
    {
        $this->adapters = [
            'chartjs' => ChartJsAdapter::class,
            'apex' => ApexAdapter::class,
            'echarts' => EChartsAdapter::class,
        ];
    }

    public function make(string $driver = null): ChartAdapterInterface
    {
        $driver = $driver ?? $this->config->get('gsmui-charts.default_driver');

        if (!isset($this->adapters[$driver])) {
            throw new \InvalidArgumentException("Unknown chart driver: {$driver}");
        }

        $adapterClass = $this->adapters[$driver];

        return new $adapterClass();
    }

    public function supportedDrivers(): array
    {
        return array_keys($this->adapters);
    }

    public function supportsDriver(string $driver): bool
    {
        return isset($this->adapters[$driver]);
    }
}
```

## 17. Event System

### 17.1 Chart Events

```javascript
// assets/js/gsmui/chart-events.js
export class ChartEventEmitter {
    constructor(chartInstance, element) {
        this.instance = chartInstance;
        this.element = element;
        this.bindEvents();
    }

    bindEvents() {
        // Click events
        this.instance.options.onClick = (event, elements) => {
            if (elements.length > 0) {
                const element = elements[0];
                const dataset = this.instance.data.datasets[element.datasetIndex];
                const label = this.instance.data.labels[element.index];
                const value = dataset.data[element.index];

                this.emit('chart:click', {
                    dataset: dataset.label,
                    label,
                    value,
                    index: element.index,
                });
            }
        };

        // Hover events
        this.instance.options.onHover = (event, elements) => {
            const isHovering = elements.length > 0;
            this.element.toggleAttribute('data-hovering', isHovering);

            if (isHovering) {
                const element = elements[0];
                this.emit('chart:hover', {
                    datasetIndex: element.datasetIndex,
                    index: element.index,
                });
            }
        };

        // Legend click events
        if (this.instance.options.plugins?.legend?.onClick) {
            const originalClick = this.instance.options.plugins.legend.onClick;
            this.instance.options.plugins.legend.onClick = (event, legendItem, legend) => {
                originalClick(event, legendItem, legend);
                this.emit('chart:legend-click', {
                    dataset: legendItem.text,
                    hidden: legendItem.hidden,
                });
            };
        }
    }

    emit(eventName, detail) {
        this.element.dispatchEvent(new CustomEvent(eventName, {
            detail,
            bubbles: true,
            cancelable: true,
        }));
    }
}
```

## 20. Snapshot & Diff

### 20.1 Chart Snapshot System

```javascript
// assets/js/gsmui/chart-snapshot.js
export class ChartSnapshot {
    constructor(chartInstance) {
        this.instance = chartInstance;
        this.snapshots = [];
    }

    capture(label = null) {
        const snapshot = {
            label: label || `snapshot-${this.snapshots.length}`,
            timestamp: Date.now(),
            data: JSON.parse(JSON.stringify(this.instance.data)),
            options: JSON.parse(JSON.stringify(this.instance.options)),
        };
        this.snapshots.push(snapshot);
        return snapshot;
    }

    restore(index) {
        const snapshot = this.snapshots[index];
        if (!snapshot) return;

        this.instance.data = snapshot.data;
        this.instance.options = snapshot.options;
        this.instance.update();
    }

    diff(indexA, indexB) {
        const a = this.snapshots[indexA];
        const b = this.snapshots[indexB];
        if (!a || !b) return null;

        return {
            dataChanged: JSON.stringify(a.data) !== JSON.stringify(b.data),
            optionsChanged: JSON.stringify(a.options) !== JSON.stringify(b.options),
            timeDelta: b.timestamp - a.timestamp,
        };
    }

    clear() {
        this.snapshots = [];
    }
}
```

```javascript
// assets/js/gsmui/chart-metrics.js
export class ChartMetrics {
    constructor(chartInstance) {
        this.instance = chartInstance;
        this.metrics = {
            renderTime: 0,
            dataPoints: 0,
            lastUpdate: null,
        };
    }

    startTimer() {
        this._startTime = performance.now();
    }

    endTimer() {
        this.metrics.renderTime = performance.now() - this._startTime;
        this.metrics.lastUpdate = Date.now();
        this.metrics.dataPoints = this.getDataPointCount();
    }

    getDataPointCount() {
        return this.instance.data.datasets.reduce((sum, ds) => sum + (ds.data?.length || 0), 0);
    }

    getReport() {
        return {
            ...this.metrics,
            memoryUsage: this.getMemoryUsage(),
        };
    }

    getMemoryUsage() {
        if (performance.memory) {
            return {
                used: performance.memory.usedJSHeapSize,
                total: performance.memory.totalJSHeapSize,
            };
        }
        return null;
    }
}
```

## 29. Migration & Upgrade Guide

### 29.1 Version Upgrade Checklist

When upgrading chart engine versions:

1. **Check breaking changes** in the engine's changelog
2. **Update bundle** in `dist/` directory
3. **Run adapter compatibility tests**
4. **Verify theme integration** still works
5. **Test accessibility** features
6. **Check performance** metrics

### 29.2 Driver Migration

```php
// Migrating from Chart.js to ECharts
// Step 1: Update default driver
config(['gsmui-charts.default_driver' => 'echarts']);

// Step 2: Run migration analysis
php artisan gsmui:chart-migration:analyze --from=chartjs --to=echarts

// Step 3: Review and apply migrations
php artisan gsmui:chart-migration:apply --dry-run
php artisan gsmui:chart-migration:apply

// Step 4: Verify all charts
```

```php
// app/Console/Commands/ChartMigrate.php
class ChartMigrate extends Command
{
    protected $signature = 'gsmui:chart-migrate
                            {--from= : Source driver}
                            {--to= : Target driver}
                            {--dry-run : Preview changes without applying}';

    protected $description = 'Migrate chart configurations between drivers';

    public function handle(): int
    {
        $from = $this->option('from');
        $to = $this->option('to');
        $dryRun = $this->option('dry-run');

        $migrations = $this->getMigrations($from, $to);

        foreach ($migrations as $migration) {
            if ($dryRun) {
                $this->info("[DRY RUN] {$migration['file']}: {$migration['change']}");
            } else {
                $this->applyMigration($migration);
                $this->info("Migrated: {$migration['file']}");
            }
        }

        return self::SUCCESS;
    }
}
```

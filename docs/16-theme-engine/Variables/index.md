# CSS Variables

GsmUi uses CSS custom properties (variables) for runtime theming without recompilation.

## Variable System

| Feature | Description |
|---|---|
| Runtime theming | Change themes without rebuild |
| Browser fallbacks | Graceful degradation |
| Dark mode | Automatic dark variant |
| Scoped overrides | Per-component variables |

## Variable Generation

### Generation Process

```
Token definitions
    ↓
Token inheritance resolution
    ↓
CSS variable output
    ↓
Fallback generation
    ↓
Minification
```

### Generated CSS

```css
/* Generated by GsmUi Theme Engine */
:root {
    /* Color Variables */
    --gsmui-color-primary: #2563eb;
    --gsmui-color-primary-hover: #1d4ed8;
    --gsmui-color-primary-light: #dbeafe;
    --gsmui-color-surface: #ffffff;
    --gsmui-color-surface-alt: #f9fafb;
    --gsmui-color-text: #18181b;
    --gsmui-color-text-secondary: #71717a;
    --gsmui-color-border: #e4e4e7;
    --gsmui-color-border-light: #f4f4f5;

    /* Spacing Variables */
    --gsmui-space-1: 0.25rem;
    --gsmui-space-2: 0.5rem;
    --gsmui-space-3: 0.75rem;
    --gsmui-space-4: 1rem;
    --gsmui-space-6: 1.5rem;
    --gsmui-space-8: 2rem;

    /* Radius Variables */
    --gsmui-radius-sm: 0.25rem;
    --gsmui-radius-md: 0.375rem;
    --gsmui-radius-lg: 0.5rem;
    --gsmui-radius-xl: 0.75rem;

    /* Shadow Variables */
    --gsmui-shadow-sm: 0 1px 2px rgba(0,0,0,0.05);
    --gsmui-shadow-md: 0 4px 6px rgba(0,0,0,0.1);
    --gsmui-shadow-lg: 0 10px 15px rgba(0,0,0,0.1);
}
```

### Generation Options

| Option | Default | Description |
|---|---|---|
| `prefix` | `gsmui` | Variable prefix |
| `format` | `css` | Output format |
| `minify` | `true` | Minify output |
| `autoprefix` | `true` | Add vendor prefixes |
| `dark_mode` | `true` | Include dark variables |

## Fallbacks

### Browser Support

| Browser | Support | Fallback |
|---|---|---|
| Chrome 49+ | ✅ Full | — |
| Firefox 31+ | ✅ Full | — |
| Safari 9.1+ | ✅ Full | — |
| Edge 15+ | ✅ Full | — |
| IE 11 | ❌ None | Static fallback |

### Fallback Generation

```css
/* With fallbacks */
.gsmui-button {
    background: #2563eb; /* Fallback */
    background: var(--gsmui-button-bg, #2563eb);
}

.gsmui-button:hover {
    background: #1d4ed8; /* Fallback */
    background: var(--gsmui-button-bg-hover, #1d4ed8);
}
```

### Fallback Strategy

| Method | Description |
|---|---|
| Static values | Hardcoded fallbacks |
| @supports | Feature queries |
| JavaScript | Runtime detection |
| Build tool | PostCSS processing |

## Dark Mode Variables

### Dark Mode CSS

```css
/* Light mode (default) */
:root {
    --gsmui-color-primary: #2563eb;
    --gsmui-color-surface: #ffffff;
    --gsmui-color-text: #18181b;
    --gsmui-color-border: #e4e4e7;
}

/* Dark mode via class */
[data-theme="dark"] {
    --gsmui-color-primary: #3b82f6;
    --gsmui-color-surface: #18181b;
    --gsmui-color-text: #fafafa;
    --gsmui-color-border: #27272a;
}

/* Dark mode via media query */
@media (prefers-color-scheme: dark) {
    :root:not([data-theme]) {
        --gsmui-color-primary: #3b82f6;
        --gsmui-color-surface: #18181b;
        --gsmui-color-text: #fafafa;
        --gsmui-color-border: #27272a;
    }
}
```

### Dark Mode Strategy

| Strategy | Implementation | Use Case |
|---|---|---|
| Class | `[data-theme="dark"]` | Manual toggle |
| Media | `prefers-color-scheme` | System preference |
| Attribute | `[data-mode="dark"]` | Legacy support |

### Dark Mode Variables Map

| Token | Light | Dark |
|---|---|---|
| `primary` | `#2563eb` | `#3b82f6` |
| `surface` | `#ffffff` | `#18181b` |
| `surface-alt` | `#f9fafb` | `#27272a` |
| `text` | `#18181b` | `#fafafa` |
| `text-secondary` | `#71717a` | `#a1a1aa` |
| `border` | `#e4e4e7` | `#27272a` |
| `shadow` | `rgba(0,0,0,0.1)` | `rgba(0,0,0,0.3)` |

## Variable Usage

### In CSS

```css
.gsmui-button {
    background: var(--gsmui-button-bg, var(--gsmui-color-primary));
    color: var(--gsmui-button-text, white);
    border-radius: var(--gsmui-button-radius, var(--gsmui-radius-md));
    padding: var(--gsmui-button-padding, var(--gsmui-space-2) var(--gsmui-space-4));
}
```

### In Tailwind

```javascript
// tailwind.config.js
module.exports = {
    theme: {
        extend: {
            colors: {
                primary: 'var(--gsmui-color-primary)',
                surface: 'var(--gsmui-color-surface)',
            },
        },
    },
};
```

### In Blade

```blade
<div style="color: var(--gsmui-color-text)">
    Text content
</div>
```

## Variable API

### PHP API

```php
use Gsmui\Theme\Variables;

// Get variable value
$value = Variables::get('color.primary');

// Generate CSS
$css = Variables::toCss();

// Generate with fallbacks
$css = Variables::toCss(withFallbacks: true);

// Override variable
Variables::set('color.primary', '#10b981');
```

### Blade API

```blade
{{-- Get variable value --}}
{{ Gsmui::variable('color.primary') }}

{{-- Apply as style --}}
<div style="background: {{ Gsmui::variable('color.primary') }}">
```

## Variable Configuration

```php
// config/theme-engine.php
return [
    'variables' => [
        'prefix' => 'gsmui',
        'format' => 'css',
        'minify' => true,
        'fallbacks' => true,
        'dark_mode' => [
            'strategy' => 'class',
            'attribute' => 'data-theme',
            'value' => 'dark',
        ],
    ],
];
```
